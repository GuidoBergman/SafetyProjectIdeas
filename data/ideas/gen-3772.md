# Schelling-Point Coordination Probe for Uncoordinated Agents

# Research Question

Can two LLM agents that cannot communicate coordinate on the same choice above chance by relying on shared Schelling points, and can they do so covertly while a monitor watches a visible channel? In short, how strong is communication-free coordination, and does it survive monitoring?

# Approach Outline

Implement a small set of classic Schelling coordination games (pick the same number from a list, choose a meeting point, agree on a split) where two agent instances answer independently with no channel between them. Run open-model pairs and measure how often their independent choices match, compared against the chance baseline. Then add a 'covert-under-monitor' variant: agents may emit a visible message that a simple monitor reads, but are instructed to coordinate without the monitor detecting collusion — measure coordination success and monitor detection rate. Everything is lightweight, inference-only on a single GPU, and fits ~30 hours including a blog post.

# Proposed First Experiments

- Pure Schelling coordination: run open-model pairs on the games with no communication. Measure: coordination success rate vs. the chance baseline. Expected outcome: success well above chance on canonical Schelling problems, showing models share focal points.
- Cross-model pairing: pair different model families together vs. same-model pairs. Measure: coordination rate by pairing. Expected outcome: same-family pairs coordinate better than mixed pairs, revealing how much coordination relies on shared training rather than universal focal points.
- Covert-under-monitor variant: allow a visible channel watched by a simple LLM monitor and instruct agents to coordinate covertly. Measure: coordination success rate AND monitor detection rate. Expected outcome: a non-trivial fraction coordinate while evading the monitor, demonstrating communication-free / covert coordination that comms-monitoring misses.

# Theory Of Impact Chain

If independent agents can coordinate without communicating (or can coordinate covertly past a comms monitor), then a leading proposed defense for multi-agent systems — monitoring inter-agent communication — fails to catch collusion. This matters for the long-horizon threat where many deployed AI agents tacitly coordinate (e.g. to manipulate a market or jointly evade oversight) with no detectable messages. Quantifying communication-free coordination strength improves safety because it tells control researchers that comms monitoring is insufficient and motivates behavior-level collusion detection, closing a multi-agent oversight gap.

# Strength Rationale

Counterfactual value (5): a neglected, long-horizon multi-agent model-organism probe that labs deprioritize, needing only one GPU and no internal access. Narrow scope (5): a single coordination-success-rate metric (plus a covert variant with a detection rate) over a small fixed set of games, so a beginner team can build and run it within 30 hours.

# Alternative Framings

- Frame as a comms-monitor stress test: 'How much collusion slips past a transcript monitor when agents lean on focal points?', positioning the result as a direct challenge to communication-monitoring defenses.
