# Emergent Misalignment Rate Variation Across Evaluation Prompt Categories

# Research Question

To what extent does betley et al. used a diverse set of evaluation prompts to measure misalignment, but the breakdown of misalignment rate by prompt category (questions about ai, questions about harm, questions about pol?

# Approach Outline

Re-run the standard Betley et al. evaluation on an already-fine-tuned misaligned model (using the open codebase) and manually categorize the evaluation prompts into 5-8 topic categories. Compute misalignment rate per category. Identify which categories are most and least vulnerable. As a second step, test whether the category distribution changes when using a different trigger domain (medical vs. code).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If misalignment is concentrated in specific prompt categories (e.g., AI-related questions), safety evaluations can be made more targeted and efficient. If it is uniform, broader red-teaming is needed. This is an analysis contribution requiring no new training — just inference and categorization on existing model organisms.
