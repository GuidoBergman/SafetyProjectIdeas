# Reversibility Scoring: A Lightweight Metric for Real-Time Action Risk Classification

# Research Question

To what extent does agents currently have no runtime mechanism for classifying actions on a reversibility spectrum before executing them, making it impossible to apply proportionate caution?

# Approach Outline

Build a reversibility scorer that classifies agent actions (file write, API call, database edit, message send) on a 1-5 scale. Train a small classifier on synthetic action logs. Measure inter-rater reliability between human annotators and the classifier.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Without actionable reversibility metrics, safety interventions cannot be proportionate. This could slot into any agent framework as a lightweight pre-execution hook.
