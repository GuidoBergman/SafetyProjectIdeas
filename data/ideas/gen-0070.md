# Data Contamination + Fine-tuning APIs: The Compounding Contamination Risk

# Research Question

To what extent does fine-tuning apis allow any user to fine-tune a model on arbitrary data. if a base model's safety benchmark scores are already inflated by training contamination, and users can further fine-tune on ben?

# Approach Outline

Test compounding contamination: take an open-source model, measure baseline safety benchmark scores, then fine-tune on a small dataset containing benchmark test items (simulating a malicious fine-tuning user), measure score inflation. Compare with models that already show contamination signals. Measure whether compound contamination is detectable by existing contamination detection methods. # Theory Of Impact Chain

Fine-tuning APIs are widely deployed (OpenAI, Anthropic, Google). If they can be used to create models that fraudulently appear safe on official benchmarks, the entire evaluation system is compromised.
