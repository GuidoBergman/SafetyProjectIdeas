# How Often Do Activation Patching Results Reverse Across Layers? Mapping the Instability of Causal Claims

# Research Question

To what extent does activation patching is used to identify which layers 'contain' information relevant to a model's output. a known but underreported failure mode is that patching conclusions can reverse across adjacent?

# Approach Outline

Using TransformerLens on GPT-2 medium, run a systematic activation patching experiment on 50 factual recall prompts (e.g., 'The Eiffel Tower is in [Paris]'). For each prompt, do residual stream patching at every layer: patch in the activation from a clean run into a counterfactual run (where the factual answer is different). Record the logit difference change per layer. Then compute a 'reversal score' per prompt: the number of times the patching effect changes sign from one layer to the next. Report the distribution of reversal scores and identify whether factual prompts have more reversals than syntactic prompts.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

High reversal rates mean that patching-based localization claims are sensitive to which specific layer is chosen. If researchers choose layers that happen to support their hypothesis while adjacent layers give opposite results, the field risks confirmation bias in circuit-based findings.
