# StrongREJECT Scoring Replicated Across Open Judge Models

# Research Question

How much do attack-success-rate (ASR) measurements from the StrongREJECT jailbreak benchmark depend on which judge model does the scoring, and how well do different open judge models agree when scoring the same fixed set of jailbreak transcripts?

# Approach Outline

Take a fixed corpus of jailbreak attempt transcripts (prompt + model response pairs spanning successful and failed jailbreaks) -- either the released StrongREJECT examples or a fixed set generated once and frozen. Apply the published StrongREJECT scoring rubric using several different open judge models (varying family and size) as the grader, holding the rubric and prompt constant. Compute inter-judge agreement (e.g., Krippendorff's alpha / Cohen's kappa on the binarized verdicts, plus correlation on the continuous scores) and the resulting ASR each judge reports for each attack method. The twist is swapping the judge while freezing transcripts, isolating judge variance from attack variance. This is inference-only scoring; the only cost is running several open judges over a fixed transcript set, which fits a single GPU in a few hours.

# Proposed First Experiments

- Assemble and freeze the transcript corpus and score it with one reference open judge using the StrongREJECT rubric. Measure: per-method ASR under the reference judge. Expected outcome: ASR numbers roughly consistent with published StrongREJECT results, validating the scoring pipeline.
- Score the identical frozen transcripts with 3-5 additional open judge models and compute pairwise inter-judge agreement. Measure: Krippendorff's alpha / kappa and score correlation across judges. Expected outcome: only moderate agreement, with systematic disagreement concentrated on borderline (partial-compliance) transcripts.
- Quantify how judge choice shifts the headline ASR per attack method. Measure: spread (max - min) of reported ASR across judges for each attack method. Expected outcome: ASR can swing by a meaningful margin depending solely on the judge, showing that reported jailbreak success rates are judge-dependent and need a fixed judge to be comparable.

# Theory Of Impact Chain

If ASR depends substantially on the judge, then jailbreak-robustness claims across papers and red-team reports are not comparable unless the judge is fixed -> the field adopts judge-standardized reporting and treats judge variance as a known error bar -> this hardens the adversarial-robustness measurement stack that gates whether a model is deemed safe to deploy, reducing the risk that an unsafe model is mistakenly certified jailbreak-resistant because of a lenient judge.

# Strength Rationale

It scores maximally on counterfactual value and narrow scope: third-party scrutiny of a widely used safety metric is exactly the kind of open-infrastructure work external researchers can do but labs rarely prioritize, and it is a single clean statistical experiment (inter-judge agreement + ASR spread) with an explicit success criterion. Freezing transcripts cleanly isolates the variable of interest, making the result unambiguous and reproducible.

# Alternative Framings

- Reframe as a robustness-of-rankings study: instead of focusing on absolute ASR, test whether the *ranking* of attack methods (which jailbreak is strongest) is stable across judges, since stable rankings would partially rescue cross-paper comparisons even if absolute numbers vary.
