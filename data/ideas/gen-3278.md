# Inter-Judge Reliability of LLM Scheming-Detection Verdicts

# Research Question

When automated scheming evaluations score agent transcripts with an LLM judge, how much does the verdict depend on which judge model is used rather than on the behavior itself? Concretely, what is the inter-judge agreement (Krippendorff's alpha) across several open LLM judges, and how much does judge choice shift headline scheming rates?

# Approach Outline

Obtain a fixed set of ~80-120 pre-existing agent transcripts from an open scheming eval (e.g. transcripts produced by an Apollo-style or Petri-style pipeline, or generated once with a single open agent model). Freeze the transcript set so behavior is held constant. Write one shared scoring rubric for covert action / deception with explicit numeric anchors. Have 3-4 different open LLM judges (e.g. Llama-3.1-8B/70B-via-API, Qwen2.5, Mistral) independently score every transcript against the rubric. Compute Krippendorff's alpha for inter-judge agreement, per-judge leniency (systematic offset), and identify the most-contested transcripts. Finally recompute the headline scheming rate under each judge to show how the published number swings. Everything is inference-only and fits a single GPU plus light API use within ~30 hours.

# Proposed First Experiments

- Rubric calibration: score a 15-transcript pilot with all judges and inspect disagreements; refine the rubric anchors. Measure: pilot pairwise agreement before vs. after rubric refinement. Expected outcome: rubric refinement raises agreement modestly, confirming the rubric is usable and disagreement is not pure prompt ambiguity.
- Full inter-judge reliability run: score all transcripts with 3-4 judges and compute Krippendorff's alpha plus per-judge leniency offsets. Measure: alpha and the spread of per-judge mean scores. Expected outcome: moderate alpha (e.g. 0.4-0.7) and a meaningful leniency spread, showing judge identity matters.
- Headline-rate swing: apply each judge's verdicts to compute the overall scheming rate using the eval's threshold. Measure: range of headline scheming rate across judges. Expected outcome: the headline rate varies by several to many points depending on judge, demonstrating cross-study incomparability.

# Theory Of Impact Chain

If scheming rates swing substantially with judge choice, then numbers reported across different scheming studies are not comparable and a 'safe' verdict may be an artifact of a lenient judge; this means safety cases that cite low scheming rates to justify deploying or scaling an agentic system could rest on noise. Quantifying inter-judge reliability and publishing the rubric improves safety because it hardens the measurement infrastructure underlying monitoring/control safety cases for long-horizon deceptive-alignment risk.

# Strength Rationale

Strong on counterfactual value (5): cheap meta-evaluation and replication work that labs deprioritize and that needs no internal access. Tightly scoped (5) to a single held-constant transcript set with an auto-computable agreement metric, so a beginner team can finish and write it up in 30 hours. The output (alpha estimates, a leniency map, and a shared rubric) directly strengthens the whole field's evaluation pipeline.

# Alternative Framings

- Frame as a judge-ensembling recommendation: 'How many judges, and which aggregation, are needed to stabilize scheming verdicts?', turning the reliability finding into actionable guidance for eval builders.
