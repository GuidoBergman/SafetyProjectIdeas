# Steering Fragility Under Adversarial Paraphrase: Concept Steering Fails When Feature Activation Is Bypassed

# Research Question

To what extent does sae-based concept steering suppresses harmful outputs by clamping specific feature activations. adversarial paraphrase attacks achieving the same semantic goal through different syntactic routes may a?

# Approach Outline

For a target harmful concept, identify its primary SAE feature. Apply steering to suppress it. Generate paraphrase variants of prompts that elicit the same concept and measure whether the primary feature still activates, or whether the model reroutes through secondary features not covered by the steering intervention.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If steering is only effective on the specific prompt distribution used to identify the feature, it provides no robustness guarantee — a critical limitation for deploying SAE steering as a deployment-time safety mechanism.
