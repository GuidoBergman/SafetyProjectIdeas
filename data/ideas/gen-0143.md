# Does Model Size Modulate Homogeneity? Comparing 7B, 13B, 70B, and Frontier Model Homogeneity Profiles

# Research Question

To what extent does the artificial hivemind paper aggregated across model sizes. it is unknown whether smaller or larger models contribute more to inter-model homogeneity?

# Approach Outline

Stratify the existing Infinity-Chat experimental setup by model parameter count and compare intra-size-class vs. cross-size-class homogeneity. Test whether frontier models converge more with each other than with smaller models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If frontier models are the most homogeneous, the concentration of deployment in this tier amplifies systemic risk; if smaller models are more diverse, this has implications for deployment portfolio design.
