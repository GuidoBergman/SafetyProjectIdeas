# Verbosity Bias as an Exploitable Channel: Padding to Pass Oversight

# Research Question

How much can the pass-rate of a fixed incorrect answer be raised, in the eyes of an LLM judge, purely by adding non-substantive padding (qualifications, restated context, formal tone) while holding the wrong claim fixed? What is the dose-response curve of pass-rate vs token count?

# Approach Outline

Take a set of clearly incorrect answers to factual and reasoning questions from a public QA dataset. Programmatically generate padded variants of each wrong answer at increasing token counts, where padding adds fluent but non-substantive material (caveats, restated background, formal phrasing) without changing or fixing the wrong claim — verified by a simple check that the core claim string is preserved. Submit original and padded variants to several small open judge models in an LLM-as-a-judge setup ('is this answer correct? PASS/FAIL') and record pass-rate as a function of token count. Fit a dose-response curve per judge. Inference-only on a single consumer GPU; finishes in a few hours.

# Proposed First Experiments

- Padding generator + claim-preservation check: build the padder and confirm padded variants keep the wrong claim intact across a sample. Measure: fraction of padded variants that preserve the original wrong claim (manual + automatic check). Expected outcome: a reliable padder producing length-controlled, claim-preserving variants.
- Dose-response measurement: submit each wrong answer at several padding levels to 3-4 small judge models and record PASS rates. Measure: pass-rate vs token count per judge. Expected outcome: pass-rate rises monotonically with padding for at least some judges, demonstrating an exploitable verbosity channel.
- Mitigation probe: re-run with a judge prompt that explicitly warns against length/verbosity bias and asks the judge to ignore non-substantive text. Measure: reduction in the padding-induced pass-rate slope. Expected outcome: the de-biasing prompt flattens but does not eliminate the curve, quantifying how much of the exploit a simple prompt fix removes.

# Theory Of Impact Chain

Automated oversight increasingly uses LLM graders, and verbosity/length bias is a known reward-hacking vector. If a fixed wrong answer can be pushed past a grader just by padding, then any training or filtering loop that trusts such graders can be gamed, which improves safety because it converts a qualitative bias into a measured attack surface and a reusable red-team benchmark, helping prevent the pathway where a capable model learns to reward-hack its overseer with non-substantive verbosity and thereby gets incorrect or unsafe outputs approved at scale.

# Strength Rationale

Scores 5 on narrow scope, counterfactual value, and low compute and 4 on novelty: it is a lab-independent, fuzzy-reward exploit study using only public data and small open models with trivial compute. It is tightly scoped to a single dose-response curve with a clear pass-rate metric, and the controlled padding-vs-pass-rate measurement for fixed-wrong answers is plausibly open, giving beginners an original, self-contained first deliverable.

# Alternative Framings

- Frame it as a benchmark: a 'verbosity-attack robustness' score for any judge model, defined as the pass-rate increase per 100 padding tokens on fixed wrong answers.
