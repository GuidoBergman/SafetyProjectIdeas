# Benchmark Generalization Gap Probe: Testing Whether High Benchmark Scores Reflect Overfitting

# Research Question

To what extent does qwen3guard-8b achieved 85.3% accuracy on the full harmbench test set but only 33.8% on novel prompts not derived from public datasets — a 57.2 percentage point generalization gap. this suggests safety?

# Approach Outline

Design a two-split evaluation protocol: (A) standard benchmark prompts drawn from HarmBench/AdvBench, and (B) 100–200 novel prompts generated by paraphrasing or semantically transforming benchmark prompts using an LLM. Compare attack success rates (or classifier accuracy) on split A vs. split B for the same model. The gap between A and B is the 'Generalization Gap Score.' Run on 3–5 openly available models. This requires only API calls and basic Python.

# Theory of Impact Chain

If safety benchmarks measure memorization rather than genuine robustness, published safety results are misleading. High leaderboard scores may reflect benchmark overfitting rather than alignment quality. A generalization gap metric would reveal which models have learned shallow pattern-matching vs. genuine safety reasoning.
