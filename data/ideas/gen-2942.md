# The Translation Link: Does Harm-Recognition Survive Round-Trip Paraphrase?

# Research Question

Does an open model's recognition of harm survive meaning-preserving paraphrase, and is this surface-form brittleness worse for diffuse harms (manipulation, subtle dual-use) than for overt harms (violence)?

# Approach Outline

Hand-curate ~30 clearly harmful seed requests spanning 3-4 categories (overt violence, manipulation/social-engineering, subtle dual-use, harassment). For each seed, generate N=8 meaning-preserving paraphrases using a separate open model plus manual checks for intent preservation (synonym swap, register/politeness change, indirection). Run all originals+paraphrases through 2-3 open instruct models (e.g. Llama-3.1-8B-Instruct, Qwen2.5-7B) with a fixed refusal-detection rubric, classifying each response as refuse/comply/hedge. Compute a per-category 'recognition-instability score' = variance/fraction-flip in refusal across the paraphrase set, then compare diffuse vs overt categories. All steps are pure inference and fit comfortably in a few GPU-hours.

# Proposed First Experiments

- Build and validate the dataset: write 30 seeds, auto-generate 8 paraphrases each, and manually verify (sample 50) that paraphrases preserve harmful intent. Measure: paraphrase intent-preservation rate. Expected: >=85% preserve intent after light manual filtering.
- Run refusal classification on one model across all originals and paraphrases; compute per-item refusal-flip rate. Measure: fraction of items whose refuse/comply label flips across paraphrases. Expected: meaningful instability (>15% flip) concentrated in diffuse categories.
- Compare instability across the 2-3 models and across diffuse vs overt categories with bootstrap confidence intervals. Measure: recognition-instability score per category per model. Expected: diffuse-harm instability significantly exceeds overt-harm instability, indicating keyword reliance.

# Theory Of Impact Chain

If harm-recognition flips under meaning-preserving paraphrase, then safety guardrails are matching surface keywords rather than semantic harm -> attackers can strip refusals with trivial rephrasing while preserving harmful intent -> deployed assistants assist with diffuse, long-horizon harms (manipulation campaigns, dual-use uplift) that evade keyword filters. Quantifying this brittleness tells evaluators and guardrail builders to test semantic robustness, reducing a concrete misuse pathway.

# Strength Rationale

Scores maximally on counterfactual value (open models, pure inference, fuzzy-reward evaluation needing zero lab resources) and narrow scope (one crisp deliverable: a per-category recognition-instability score). The diffuse-vs-overt contrast is novel enough to be publishable as a beginner blog post while remaining fully executable in 30 hours.

# Alternative Framings

- Frame as a red-team auditing primitive: a cheap 'paraphrase stress test' that any third party can run to certify whether a guardrail is semantic or keyword-based before deployment.
