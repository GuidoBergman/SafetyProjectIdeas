# StrongREJECT Evaluator Reliability Audit Tool

# Research Question

How much does a jailbreak-robustness leaderboard depend on which LLM judge runs the StrongREJECT rubric? Do model rankings stay stable, or flip, when the same rubric is scored by different judge models?

# Approach Outline

Take a fixed set of model responses to harmful prompts (publicly available StrongREJECT prompts plus responses from several open target models). Run the StrongREJECT rubric prompt with several different judge models — e.g. GPT-4o-mini, Claude Haiku, an open judge such as Llama-3-70B (or smaller), and the released fine-tuned Gemma-2B evaluator. For each judge, compute each target model's robustness score and the resulting leaderboard. Then measure inter-judge agreement (Krippendorff's alpha / Cohen's kappa on per-response scores) and rank stability (Kendall's tau / Spearman across leaderboards). Package the whole thing as a small reusable audit harness. Inference-only with a modest API/inference budget; fits a single GPU and 30 hours.

# Proposed First Experiments

- Multi-judge scoring run: score a fixed response set (say 200 prompt-response pairs across 4-5 target models) with 3-4 different judges using the identical StrongREJECT rubric. Measure: per-response score from each judge. Expected outcome: a complete judge-by-response score matrix.
- Inter-judge agreement: compute pairwise agreement statistics on the per-response scores. Measure: Krippendorff's alpha / kappa between judges. Expected outcome: only moderate agreement, indicating judge choice materially affects individual verdicts.
- Rank-stability test: build the robustness leaderboard under each judge and compare orderings. Measure: Kendall's tau / Spearman between leaderboards and whether the top-ranked 'most robust' model changes. Expected outcome: at least some rank flips, demonstrating that published robustness rankings can be judge-dependent.

# Theory Of Impact Chain

Jailbreak-robustness leaderboards increasingly drive which models are deemed safe to deploy. If those rankings flip depending on the judge model, then a model could be declared robust under one evaluator and vulnerable under another, so deployers may ship genuinely jailbreakable models based on an artifact of judge choice. An open audit harness lets independent parties detect this fragility and forces robustness claims to report judge-robustness, reducing the chance that adversarially-exploitable models pass safety review.

# Strength Rationale

Scores 5 on counterfactual value, narrow scope, accessible complexity, and low compute: it is pure inference on public prompts and an open rubric, needing no training and no lab data, and delivers third-party verification that labs underprioritize. The scope is tight (swap judges, measure agreement and rank stability, ship harness) with explicit success criteria, and the counterfactual value is high because it is exactly the kind of meta-science audit best done by independent groups.

# Alternative Framings

- Frame as a judge-ensemble recommendation: instead of just auditing fragility, test whether averaging multiple judges yields more stable rankings than any single judge.
