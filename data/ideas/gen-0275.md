# Incident Taxonomy Builder: Automatically Classifying AI Incidents from the AIAAIC Database

# Research Question

To what extent does the aiaaic ai incident database contains hundreds of incidents but lacks a standardized technical taxonomy that would enable systematic governance analysis?

# Approach Outline

Download the AIAAIC database. Use an LLM to classify each incident along dimensions: technical failure type, governance failure type, harm category, detection lag, and response quality. Publish the enriched dataset and a summary analysis.
