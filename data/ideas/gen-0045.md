# The False Negative Causal Chain: Unsafe Models Passing Safety Evals

# Research Question

To what extent does the causal chain of false negatives is: benchmark has narrow coverage → unsafe behavior exists outside coverage → model passes benchmark → model deployed → narrow-coverage unsafe behavior triggered → ?

# Approach Outline

Take a set of known-unsafe behaviors in open-source models (from red-team competitions, published jailbreaks). Test which behaviors are caught by standard safety benchmarks vs. which escape. Compute a 'false negative rate' for each benchmark. Identify structural features of missed behaviors.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The 2025 'Can We Trust AI Benchmarks?' review finds widespread benchmark quality failures. Quantifying false negative rates provides the most direct measure of how much dangerous behavior slips through.

# Strength Rationale

theory_of_impact (4/5): Strong chain: quantifying false negative rates directly measures how much dangerous behavior slips through benchmarks. Provides the most direct measure of benchmark quality for safety.

accessible_complexity (4/5): Using known jailbreaks from public databases and running them through existing benchmarks is doable with standard API tools and public datasets. Computation of false negative rates is basic statistics.

narrow_scope (4/5): Tightly focused: collect known-unsafe behaviors from public red-team databases, test against N safety benchmarks, compute false negative rates per benchmark. Clear deliverable.

novelty (3/5): Red teaming research extensively demonstrates that models fail safety evaluations: TAP achieves 80%+ jailbreak rates on GPT-4, GPT-4 showed 87.2% ASR in systematic testing, and SG-Bench (NeurIPS 2024) evaluates safety generalization. SORRY-Bench (ICLR 2025) systematically benchmarks refusal. The concept of measuring false negative rates is implicit in attack success rate metrics. However, a study explicitly framing this as computing false negative rates per benchmark using a curated database of known-unsafe behaviors has not been published as such.
