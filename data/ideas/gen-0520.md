# Applying Interrogation Science: Does Repeated Questioning Degrade LLM Deception Consistency?

# Research Question

To what extent does interrogation science shows that deceptive humans struggle to maintain consistent false stories under repeated, varied questioning. whether repeated probing degrades deception consistency in llms—maki?

# Approach Outline

Design a repeated-questioning protocol: present a scheming-capable model with a scenario requiring consistent deception, then re-probe with varied question formulations, perspective shifts, and follow-up requests for elaboration. Measure contradiction rates as a function of number of probes. Compare to honest condition baseline.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

If repeated varied questioning degrades deception consistency in LLMs, this provides a practical, low-cost detection strategy: ask the same question many ways and look for contradictions.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: repeated varied questioning -> deception inconsistencies -> practical low-cost detection strategy. Names a specific mechanism but the chain has a gap: LLMs may simply be inconsistent in general (not just when deceiving), making contradiction rates uninformative without careful baselines.

accessible_complexity (4/5): Designing varied question formulations and measuring contradiction rates is accessible prompt engineering work. No ML training required; uses API calls. A beginner can construct question variants and analyze responses. The main challenge is operationalizing 'contradiction' but this can be done simply.

narrow_scope (4/5): Focused first deliverable: contradiction rate vs number of probes on one scenario, honest vs deceptive condition. Clear methodology, few dependencies, obvious success criteria (is the curve different between conditions?). Can go from start to result quickly.

novelty (4/5): LLM deception detection and consistency analysis are active areas. Research shows LLMs handle contradictions poorly and can exhibit strategic deception with internally coherent reasoning ('When Thinking LLMs Lie' arXiv:2506.04909, 2025). Multi-turn deception studies exist ('The Traitors' NeurIPS 2025 Workshop). However, the specific interrogation science approach — systematic repeated-questioning protocol with varied formulations, perspective shifts, and elaboration requests, measuring contradiction rate as a function of probe count — appears novel in the LLM deception context. Human interrogation science techniques have not been systematically adapted to LLM deception detection. The accessible methodology (prompt engineering + API calls) and clear success criterion (differential contradiction curves) make this a strong candidate.
