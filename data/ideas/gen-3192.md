# Schelling-Point Coordination Without Communication as a Collusion Probe

# Research Question

How good are current small models at unspoken Schelling-point coordination, picking the same answer as a hypothetical partner with no communication, and does their coordination success outpace the rationale they verbalize in chain-of-thought, signaling un-verbalized strategic capability?

# Approach Outline

Implement classic Schelling coordination games in Python: choose a number from a range, name a meeting place/time, split a pie, pick one of several objects. Run two independent instances of the same model (no message passing) and score whether their independent choices converge. Compare convergence rate against a random/uniform baseline and against what each model says it expects a partner to do. Capture CoT and flag cases where coordination succeeds but the CoT contains no explicit coordinating rationale. Vary model family and game type. Fully prompt-based, inference-only, free-tier or single-GPU feasible, easily within 30 hours including a blog post.

# Proposed First Experiments

- Coordination baseline: run 5-6 Schelling games, two instances each, 30+ trials per game; measure convergence rate vs the random baseline. Expected outcome: convergence well above random on focal-point games (e.g. 'pick a number 1-10' converging on 1 or 7), confirming nontrivial coordination ability.
- Stated-vs-actual gap: for each game, ask each instance to predict the partner's choice and its own rationale; compare predicted convergence to actual convergence. Measure the gap. Expected outcome: actual coordination meets or exceeds what models claim to reason about, suggesting reliance on shared priors rather than explicit strategy.
- CoT-mismatch flagging: have a cheap LLM judge label whether each successful-coordination transcript contains an explicit coordinating rationale. Measure the fraction of successful coordinations with no verbalized coordinating plan. Expected outcome: a non-trivial fraction of un-verbalized successful coordinations, the early-warning signature of interest.

# Theory Of Impact Chain

If models can coordinate covertly on shared focal points without communicating or verbalizing the strategy, then multi-agent collusion that defeats oversight becomes more plausible, because monitors reading the CoT would miss the coordination. Building a cheap, reproducible probe for this capability gives the field an early-warning model organism for the long-horizon catastrophic pathway where colluding AIs jointly evade human control while each individually appears benign.

# Strength Rationale

Counterfactual value is 5: long-horizon collusion model organisms are underweighted by labs and fully reproducible by independents with no training or proprietary access. Narrow scope is 5: a single convergence-rate metric against clear baselines on a fixed game set. Prompting-only and free-tier feasible, it is an ideal clean first hands-on project that targets a neglected, high-stakes threat model.

# Alternative Framings

- Frame as a capability-elicitation study: does coordination improve with model scale/family, charting a covert-coordination capability curve.
