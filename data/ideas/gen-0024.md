# Prompt Injection in RAG Systems: Does Retrieval Context Bypass Safety More Reliably Than Direct Prompting?

# Research Question

To what extent does indirect prompt injection (malicious instructions embedded in retrieved documents) is a known attack vector for rag systems. whether retrieval-based injection has higher attack success rates than dire?

# Approach Outline

Set up a simple RAG pipeline using an open-source model and a small vector database. Inject harmful instructions into retrieved documents using three methods: (1) direct instruction injection, (2) authority impersonation (instructions framed as from the system), (3) fictional framing. Compare attack success rate on identical harmful tasks between: RAG injection, direct system prompt injection, and direct user prompt. Use StrongREJECT to evaluate outputs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

RAG is one of the most common LLM deployment patterns. If retrieval context systematically has higher injection success than direct prompting, it represents a critical gap in safety alignment that does not test for this modality.

novelty (3/5): RAG prompt injection is extensively studied. PoisonedRAG (USENIX Security 2025) demonstrated that 5 malicious documents in a corpus of millions achieves 90% targeted attack success. 'Backdoored Retrievers for Prompt Injection Attacks on RAG' (arXiv:2410.14479) studies retrieval-stage attacks. OWASP ranks prompt injection as the #1 LLM risk for 2025. However, the specific controlled comparison of ASR across three attack vectors (RAG injection vs. direct injection vs. system prompt injection) on the same model and tasks has not been published as a systematic empirical study. The individual attack vectors are well-studied; the head-to-head comparison framing adds incremental novelty.
