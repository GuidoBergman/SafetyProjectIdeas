# Inspect AI Eval Extension: Building a Sandbagging Detection Eval Module

# Research Question

To what extent does inspect ai has 100+ evaluation modules but lacks a dedicated sandbagging detection module. adding one would make sandbagging testing accessible to researchers without ml expertise?

# Approach Outline

Using the Inspect AI framework (UK AISI), implement a sandbagging detection evaluation that runs the weight-perturbation method programmatically: load a model, add configurable levels of Gaussian noise to specified weight layers, evaluate on a capability subset, and output a degradation curve. Package it as a reusable Inspect AI eval. Test on 1–2 open-source models to validate the implementation.
