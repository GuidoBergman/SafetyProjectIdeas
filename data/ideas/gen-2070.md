# Relearning-Resistance Stress Test: A Public Benchmark for Unlearning Robustness on a Single GPU

# Research Question

Can a lightweight, standardized stress test let anyone verify in an afternoon whether an 'unlearned' open model has truly removed dangerous knowledge or merely hidden it, by measuring how easily that knowledge is recovered through small-scale relearning attacks?

# Approach Outline

Build a small, shareable harness. Either start from a publicly available unlearned checkpoint, or apply RMU yourself (public code) to a base model on a tiny WMDP-style forget set so you control the unlearning. Then run a fixed battery of relearning attacks: fine-tune on 5, 20, and 50 benign-but-topically-adjacent examples; paraphrase probing; and few-shot elicitation. After each attack, re-measure forget-set accuracy and plot a recovery curve (accuracy vs number of relearning examples). Summarize each model with a single 'fragility score' (e.g., area under the recovery curve, or accuracy recovered after 50 examples relative to the pre-unlearning model). Everything -- RMU, tiny fine-tunes, and inference eval -- fits on a single consumer GPU in a few hours, and the harness is packaged so others can drop in a checkpoint and get a fragility score.

# Proposed First Experiments

- Reproduce a clean unlearning baseline: apply RMU to a small open model on a tiny WMDP-style forget set and confirm forget-set accuracy drops to near-chance while retain-set accuracy stays high. Measure: forget-set and retain-set accuracy pre/post unlearning. Expected outcome: a checkpoint that looks properly unlearned, providing the starting point for attacks.
- Run the relearning-by-fine-tuning attack at 5/20/50 benign-adjacent examples and plot the recovery curve. Measure: forget-set accuracy after each relearning budget. Expected outcome: substantial knowledge recovery from as few as 5-20 examples, confirming relearning fragility and producing the curve that defines the fragility score.
- Run the non-fine-tuning attacks (paraphrase probing, few-shot elicitation) on the same unlearned checkpoint and compare their recovery to the fine-tuning attacks. Measure: accuracy recovered by each attack type. Expected outcome: fine-tuning recovers the most knowledge, but paraphrase/few-shot attacks recover a nontrivial amount with zero weight updates, showing the harness catches multiple fragility modes.

# Theory Of Impact Chain

If a turnkey fragility score makes fake unlearning trivially detectable, then the community and auditors can reject 'unlearned' models whose hazardous knowledge resurfaces after a handful of relearning examples -> only genuinely robust unlearning passes as safe -> this closes the misuse pathway where a model certified as having forgotten bioweapon/cyber knowledge is quietly restored to full capability by a user with minimal fine-tuning data.

# Strength Rationale

It scores maximally on counterfactual value, narrow scope, and low compute: robust unlearning auditing is fuzzy, hard-to-do-well safety work that labs deprioritize and that needs no proprietary data, and it ships a single reusable harness with one summary metric. The deliverable (fragility score + recovery curve) gives an explicit, self-contained success criterion grounded in a peer-reviewed ICML result on relearning vulnerability.

# Alternative Framings

- Reframe as a comparative audit: instead of one harness, run the stress test across several publicly released unlearned checkpoints/methods and publish a ranked robustness leaderboard so the community can see which unlearning methods actually resist relearning.

# Cited Sources

- Fan et al. (arXiv:2502.05374, ICML 2025) -- shows SOTA unlearning is recoverable from a few relearning points; motivates the relearning-attack battery and fragility score
- WMDP (arXiv:2403.03218) -- public hazardous-knowledge benchmark providing the forget-set content
- RMU (public implementation) -- enables applying a standard unlearning method on a tiny forget set on one GPU
