# Control Chart Monitoring for Safety Drift: Statistical Process Control Applied to LLM Deployment

# Research Question

To what extent does safety evaluation is done episodically at deployment but not continuously. small, gradual drifts in safety behavior accumulate unnoticed between evaluations?

# Approach Outline

Apply Statistical Process Control (SPC) from manufacturing quality management. Establish a baseline distribution of refusal rates on a fixed probe set. Compute control limits (3-sigma). Run probes continuously and plot refusal rates on a control chart; trigger an alert when a data point falls outside control limits (indicating a special-cause variation, e.g., a model update that degraded safety). Extend with CUSUM charts for detecting small persistent drifts. Implement as a Python monitoring dashboard.
