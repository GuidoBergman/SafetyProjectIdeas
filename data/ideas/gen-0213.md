# Minimal Intervention Study: Can Model-Specific System Prompts Break Inter-Model Homogeneity?

# Research Question

To what extent does if standardized system prompts are driving homogeneity by instructing all models to behave similarly, then using model-specific system prompts designed to exploit each model's unique characteristics m?

# Approach Outline

Compare inter-model similarity under: (1) no system prompt, (2) identical system prompt for all models, (3) model-specific system prompts designed by researchers to maximize output diversity. Measure diversity and quality under all three conditions.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If model-specific prompting substantially increases diversity, this is an immediately deployable, zero-cost intervention that any organization can implement.

# Strength Rationale

theory_of_impact (3/5): Plausible impact chain: if model-specific prompting restores diversity, this is immediately deployable at zero cost. However, the safety relevance of output diversity is indirect; the gap is in connecting diversity metrics to concrete safety outcomes.

accessible_complexity (5/5): Highly accessible for CS beginners: requires only basic Python and API calls to multiple models. Measuring text similarity with standard metrics (cosine similarity, BLEU, etc.) is straightforward. No model training or internal access needed.

narrow_scope (4/5): Focused deliverable: 3 conditions (no prompt, identical prompt, model-specific prompt), standard diversity metrics, clear experimental structure. Achievable within 30 hours with medium compute for API costs.

novelty (3/5): Multiple recent papers document LLM output homogeneity and the failure of prompt engineering to restore diversity. The specific three-condition experimental design (no prompt, identical prompt, model-specific prompt) has not been published as a standalone study, but the finding that prompt variations fail to break inter-model homogeneity is already established. The novelty is in the specific experimental framing rather than the expected result.
