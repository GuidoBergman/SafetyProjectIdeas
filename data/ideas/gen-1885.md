# Length-Bias Reward Hacking Across Open Reward Models

# Research Question

How universal and how strong is verbosity bias across publicly available open reward models? When two responses are matched in content but differ only in length, how often does each reward model prefer the longer one?

# Approach Outline

Collect a panel of public open reward models (several from RewardBench / HuggingFace). Build matched response pairs that are identical in substantive content but differ in length by padding one with on-topic, content-free elaboration. Score each pair with every reward model and record how often the longer response is preferred. Produce a comparative 'verbosity susceptibility' leaderboard with confidence intervals, and check whether padding style (filler vs restatement) changes the effect. Inference-only on reward models — minimal compute on a single GPU.

# Proposed First Experiments

- Build the matched-pair set: take ~100 prompts with a base response, then create a length-padded variant per response that adds no new content. Validate via human spot-check that padding adds length but not quality. Expected outcome: a clean matched-pair dataset isolating length from content.
- Score all pairs with one reward model to establish the pipeline and measure its longer-preferred rate with CIs. Expected outcome: a reproducible per-model verbosity-preference rate above 50% (the bias).
- Run the full panel of reward models and rank them into a verbosity-susceptibility leaderboard with bootstrap CIs. Measure spread across models. Expected outcome: a comparative leaderboard showing which open reward models are most and least length-biased.

# Theory Of Impact Chain

Reward-model misspecification is a core RLHF open problem; verbosity bias is a concrete, measurable instance that propagates into deployed models as sycophantic padding and reward hacking. A public cross-model audit gives RLHF practitioners reusable infrastructure to pick less length-biased reward models. This reduces the catastrophic-risk pathway where optimization against a biased reward model systematically degrades model honesty/quality at scale across many downstream RLHF pipelines.

# Strength Rationale

Counterfactual value is 5: an open, comparative audit of public reward models is reusable safety infrastructure that labs underinvest in, needing only inference and no training data. With 5s on narrow scope, accessible complexity, and low compute, it is a single matched-pair audit with a clear leaderboard deliverable and explicit success criteria, completable by a beginner team in 30 hours.

# Alternative Framings

- Reframe as a 'reward-model debiasing benchmark': release the matched-pair set as a standard probe so new reward models can report their verbosity-susceptibility score.
