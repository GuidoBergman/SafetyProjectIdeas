# Monitor Suspicion Calibration Drift Under Innocuous Context Shifts

# Research Question

Does a trusted monitor's benign suspicion-score distribution stay stable across innocuous domain shifts, or does it drift enough that a single fixed audit threshold produces very different false-positive rates, and thus different attack-detection rates, across domains?

# Approach Outline

Run one small open monitor model over benign agent trajectories drawn from several distinct but innocuous domains (e.g. coding, web browsing, email, file management), record the per-domain distribution of suspicion scores, and measure how the false-positive rate at a single fixed threshold shifts across domains. Then inject a fixed set of known-bad (sabotage) examples into each domain and measure detection rate at a fixed audit budget. The comparison reveals whether a globally-tuned threshold silently mis-calibrates per domain. This is monitor inference plus statistics on public datasets, runnable on a single consumer GPU/API in a few hours.

# Proposed First Experiments

- Per-domain benign distribution: score ~50-100 benign trajectories per domain (3-4 domains) with one open monitor and plot the suspicion-score histograms. Measure: mean/variance of benign suspicion per domain and FPR at a single fixed threshold. Expected outcome: benign score distributions differ noticeably across domains, so a fixed threshold gives e.g. 2% FPR in one domain and 15% in another.
- Detection at fixed audit budget: inject a common set of known-bad examples into each domain and, holding the audit budget (top-k flagged) fixed, measure detection rate per domain. Measure: per-domain detection rate at equal budget. Expected outcome: domains with inflated benign suspicion 'use up' the budget on false positives, lowering real-attack detection there.
- Per-domain recalibration test: re-fit the threshold per domain to hold FPR constant and re-measure detection. Measure: detection-rate gain from per-domain vs global thresholds. Expected outcome: per-domain calibration recovers a meaningful chunk of detection, quantifying the cost of ignoring drift and giving a concrete recommendation.

# Theory Of Impact Chain

If a trusted monitor's benign suspicion distribution drifts across innocuous domains, then a fixed audit threshold silently mis-calibrates in deployment, so in some domains the scarce audit budget is wasted on false positives and real attacks slip through. Demonstrating and fixing this drift makes trusted monitoring robust across the heterogeneous tasks a deployed agent actually faces, closing a path by which a scheming untrusted model could evade monitoring simply by operating in a domain where the threshold is mis-set.

# Strength Rationale

Top scores on counterfactual value and narrow scope: it uses only open models and public datasets with no lab infrastructure, and targets a tightly-bounded measurement (per-domain FPR shift and detection at fixed budget) on a long-horizon deployment-calibration concern that labs underweight. The deliverable is self-contained with explicit success criteria (quantified cross-domain FPR drift and the detection recovered by recalibration).

# Alternative Framings

- Frame it as distribution-shift robustness of safety monitors, connecting to the broader OOD-calibration literature and presenting audit-threshold drift as a special case of covariate shift.
