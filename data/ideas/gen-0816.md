# Honeypot Prompts: Borrowing Cyber Deception to Detect Adversarial Users

# Research Question

To what extent does detecting whether a user is conducting a jailbreak attempt is difficult without examining intent, which is not observable. current detection is reactive?

# Approach Outline

Import honeypot and deception technology from cybersecurity. Inject synthetic 'canary' prompts into model responses at random—these are plausible-looking continuation prompts that a legitimate user would never send back but an automated jailbreak script would. If a canary is echoed back in a follow-up turn, the user is flagged as running an automated attack. Similarly, embed 'honeypot capabilities' that look tempting to jailbreakers (e.g., a fake 'unrestricted mode' that silently logs attempts) to study attack strategies.
