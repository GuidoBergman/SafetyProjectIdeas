# Can a Small Held-Out Probe Set Detect EM Before Full Eval Suites?

# Research Question

What is the smallest held-out probe set of eval questions that reliably detects emergent misalignment (EM) in a finetuned model, and how does detection accuracy/AUC trade off against probe-set size compared to running the full evaluation suite?

# Approach Outline

Using an openly released EM model organism and its aligned counterpart, run the full set of published EM eval questions on both (inference-only) and score each response with the standard EM judge. For every candidate question, compute a discriminative-power statistic (effect size / point-biserial correlation, or AUC of that single item) between aligned and misaligned responses, then rank questions by this score. Construct minimal probe sets of size 1, 3, 5, and 10 from the top-ranked questions on a training organism, and evaluate their detection AUC on a held-out set of organisms drawn from the Model Organisms collection so the ranking does not overfit. Compare each minimal probe set's AUC and false-positive/false-negative rate against the full suite. All steps are inference-only on a single consumer GPU and require only the public checkpoints, judge prompts, and a few hours of generation.

# Proposed First Experiments

- Run the full published EM eval suite on one aligned model and its EM organism counterpart; for each question, compute the effect size between the two and rank all questions by discriminative power. Measure: per-item AUC distribution. Expected outcome: a long-tailed distribution where a small minority of questions carry most of the discriminative signal.
- Build minimal probe sets of size 1, 3, 5, 10 from the top-ranked questions and evaluate their detection AUC on a held-out organism not used for ranking. Measure: AUC and accuracy of each probe set vs the full suite. Expected outcome: a probe set of ~5-10 questions recovers most of the full suite's AUC (e.g., within a few points), demonstrating diminishing returns beyond ~10 questions.
- Test cross-organism transfer: rank questions on organism A, freeze the probe set, and apply it unchanged to organisms B and C. Measure: AUC drop when the probe set is selected on a different organism than it is tested on. Expected outcome: moderate but tolerable degradation, indicating the top discriminative questions generalize across EM organisms rather than being organism-specific.

# Theory Of Impact Chain

If a validated 5-10 question probe set reliably flags EM, then continuous misalignment monitoring becomes cheap enough to run on every finetuning job and model release -> developers and third-party auditors catch emergent misalignment before deployment instead of after -> this closes a gap on the deceptive/misaligned-model risk pathway where a finetuned model silently acquires broadly harmful dispositions that a costly, rarely-run full eval would have missed.

# Strength Rationale

The idea scores maximally on counterfactual value, narrow scope, and low compute: it is lightweight monitoring infrastructure that major labs deprioritize, it needs only public organisms and inference, and it has a single crisp deliverable (a minimal probe set plus a size-vs-AUC curve). The clear success criterion (probe-set AUC within a tolerance of the full suite on held-out organisms) makes it self-contained and unambiguous for a beginner team.

# Alternative Framings

- Frame it as a cost-sensitivity study: instead of asking for the minimal probe set, characterize the full Pareto frontier of monitoring cost (number of questions x tokens) versus detection reliability, giving practitioners a budget-tunable EM monitor.
