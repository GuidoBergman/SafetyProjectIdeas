# Importing Lie Detection Psychology: Testing Whether Verbal Uncertainty Markers Predict Model Dishonesty

# Research Question

In human lie detection research, verbal hedges and uncertainty markers correlate with deception. It is untested whether similar linguistic markers in model outputs predict sycophantic or dishonest responses.

# Approach Outline

Collect a dataset of model responses labeled as honest or sycophantic. Extract linguistic features (hedge words, certainty markers, modal verbs, sentence length changes). Train a simple classifier to predict dishonesty from these features.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If surface linguistic features predict model dishonesty, cheap monitoring tools can flag suspicious responses without needing full interpretability infrastructure.
