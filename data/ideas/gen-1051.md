# Replicating IOI Circuit with Automated Circuit Discovery (ACDC) on GPT-2 Medium vs Small

# Research Question

To what extent does automated circuit discovery (acdc, conmy et al., neurips 2023) was validated on gpt-2 small. it is unknown whether the automated method recovers the same ioi circuit components in gpt-2 medium, which ?

# Approach Outline

Apply ACDC to GPT-2 Medium using the IOI task with the same prompts as Wang et al. (2022). Compare the recovered circuit to: (1) the manually discovered GPT-2 Small circuit, and (2) a manual partial analysis of GPT-2 Medium. Measure circuit faithfulness, completeness, and minimality scores for both models. Identify whether the additional capacity in Medium leads to more redundant circuit components or sharper specialization.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Scaling automated circuit discovery within a known model family before moving to unknown architectures is a methodologically sound approach that beginner researchers can rigorously execute. The result directly tests whether automated tools can be trusted as models grow — essential for making mechanistic interpretability scalable to production models.
