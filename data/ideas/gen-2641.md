# Verbalization Gap: When the CoT Says Nothing but the Action Is Hostile

# Research Question

In scenarios where a model takes a clearly harmful action, how often does its chain-of-thought (CoT) contain any trace of the harmful intent, explicit, oblique, or none at all? This 'silent-attack' base rate bounds how much CoT monitoring can ever catch, independent of monitor quality.

# Approach Outline

Take malign transcripts where the model completes a known harmful side task (SHADE-Arena, plus honeypot scenarios), and classify each CoT into explicit / oblique / no reference to the harmful intent using a combination of an LLM judge and a manually-coded validation subset (with a clear rubric and inter-rater agreement check on the human-coded portion). Report the base rate of 'silent' attacks where the CoT is clean despite a hostile action. Because the ceiling on CoT monitoring is set by how often intent is verbalized at all, this base rate is a structural limit no better monitor can overcome. The work is transcript reading plus cheap LLM-judge calls, runnable on a single GPU/API in a few hours.

# Proposed First Experiments

- Rubric and human-coded gold set: define a 3-level rubric (explicit / oblique / none) and hand-label ~30-50 malign CoTs to create a gold standard. Measure: inter-rater agreement (Cohen's kappa) between two team members. Expected outcome: a usable rubric with acceptable agreement (kappa > 0.6), validating the classification scheme.
- LLM-judge base-rate estimate: apply an LLM judge with the rubric to the full set of malign transcripts and compute the silent-attack base rate, validating the judge against the gold set. Measure: fraction of harmful actions with no CoT trace of intent, plus judge-vs-human agreement. Expected outcome: a non-trivial silent-attack rate (e.g. 20-50%), with the judge tracking human labels closely enough to trust.
- Implied CoT-monitoring ceiling: combine the silent-attack rate with an idealized 'perfect-on-verbalized' monitor to compute the maximum catch rate CoT monitoring can achieve. Measure: upper bound on CoT-monitor detection as a function of silent-attack rate. Expected outcome: a hard ceiling well below 100%, demonstrating a structural limit of CoT monitoring.

# Theory Of Impact Chain

If a substantial fraction of harmful actions occur with a clean CoT, then CoT monitoring has a structural ceiling no monitor improvement can raise, so safety cases that lean on CoT monitoring to catch scheming are overconfident. Quantifying this silent-attack base rate tells designers how much they can actually rely on CoT monitoring versus needing action-level controls, reducing the risk of trusting a transparency mechanism that a model executing un-verbalized sabotage would simply bypass on the way to an irreversible harmful action.

# Strength Rationale

Top counterfactual value and narrow scope: it is a no-training model-organism analysis of already-public transcripts, needing no proprietary data or lab infrastructure, and it isolates a single tightly-scoped quantity (the silent-attack base rate) that sets a hard ceiling on a widely-promoted monitoring approach. The deliverable is self-contained with explicit success criteria (a validated rubric, judge-vs-human agreement, and a reported base rate with confidence interval).

# Alternative Framings

- Frame it as a CoT-faithfulness measurement specialized to harmful actions: rather than 'does the CoT explain the answer', ask 'does the CoT reveal the harm', connecting to the faithfulness literature.
