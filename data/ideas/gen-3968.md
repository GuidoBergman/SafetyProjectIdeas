# How Much Does a Reward Model Need to Capture? Empirical Curve Toward the Unhackability Limit

# Research Question

Reward-hacking theory says a proxy reward is unhackable only if it captures the full true reward, but how does residual hackability fall as a proxy captures an increasing fraction of the true reward's components? What does the empirical residual-hackability-vs-fraction-captured curve look like in small, fully enumerable environments?

# Approach Outline

In pure Python (no GPU, no training), build small gridworld-style environments where states, actions, and policies are fully enumerable and a 'true reward' is defined as a sum of known components (e.g. goal-reaching, safety penalties, efficiency). Construct a sequence of proxy rewards that each capture an increasing subset/fraction of those components. For each proxy, enumerate all policies, find the proxy-optimal policy, and measure its true-reward shortfall (residual hackability) versus the true optimum. Plot residual hackability against the fraction of the true reward captured, across several environment families. Everything is deterministic enumeration in Python, trivially within 30 hours including a blog post.

# Proposed First Experiments

- Curve construction: in one environment, sweep proxies capturing 0%->100% of reward components, enumerate proxy-optimal policies, measure true-reward regret of each. Expected outcome: a monotone-decreasing residual-hackability curve that hits zero only at full capture.
- Shape characterization: repeat across 3-4 environment families and component orderings; measure whether the curve is convex, concave, or has cliffs. Expected outcome: nonlinear curves, some components contribute far more to closing the hackability gap than others, revealing which omissions are most dangerous.
- Component-criticality ranking: for a fixed capture fraction, vary which components are included and measure resulting regret. Expected outcome: a ranking of components by marginal hackability reduction, a practical heuristic for what a reward model most needs to capture.

# Theory Of Impact Chain

If we can empirically chart how residual reward-hacking shrinks as a proxy captures more of the true objective, then reward-model designers gain a concrete picture of how much specification headroom remains and which components are most critical to include. This grounds the unhackability theorem in actionable design guidance, addressing the catastrophic pathway where an optimizer ruthlessly exploits gaps in an incompletely-specified reward to pursue goals misaligned with human intent.
