# RewardLengthBias: A Diagnostic Benchmark for Length Exploitation in Reward Models

# Research Question

To what extent does reward models trained on human preferences frequently exhibit length bias—preferring longer responses regardless of quality—because human annotators conflate length with thoroughness. no dedicated ben?

# Approach Outline

Construct a dataset of 300 prompt–response pairs where each prompt has four response variants: (short+correct, short+incorrect, long+correct, long+incorrect). Measure reward model scores across all four cells. Compute a 'length bias coefficient' as the marginal score contribution of length while controlling for correctness. Release as a pip-installable diagnostic tool.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Length bias in reward models is a documented form of misspecification that causes RLHF-trained models to generate unnecessarily verbose outputs. Quantifying it consistently across models would allow researchers to compare reward model architectures on this specific failure mode and motivate debiasing methods.

# Strength Rationale
