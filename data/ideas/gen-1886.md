# Reward-Model Sycophancy: Agreement Bias Beyond Length

# Research Question

Do public reward models systematically reward agreement with a stated user opinion over correctness (sycophancy)? How large is this agreement bias, and how does it compare in magnitude to the better-known length bias on the same models?

# Approach Outline

Construct matched response pairs where one politely AGREES with a stated user belief (sometimes wrong) and the other respectfully CORRECTS it, holding length roughly fixed. Score each pair with a panel of public open reward models and measure how often the agreeing response is preferred, separating cases where the user is right vs wrong. On the same models, also run a length-bias probe (matched-length-difference pairs) so the two biases can be compared head-to-head. Inference-only on reward models — minimal compute on a single GPU.

# Proposed First Experiments

- Build the agree-vs-correct pair set: ~80-120 prompts each stating a user belief, with one agreeing and one correcting response, length-matched. Split into user-right and user-wrong cases. Validate via spot-check that pairs differ only in stance. Expected outcome: a clean stance-matched dataset.
- Score the pairs with a panel of public reward models and measure the agreeing-preferred rate, separately for user-wrong cases (where agreement is harmful). Expected outcome: a quantified sycophancy bias, especially the rate at which models reward agreeing with WRONG user beliefs.
- Run a length-bias probe on the same models and compare sycophancy magnitude to length-bias magnitude per model. Expected outcome: a per-model comparison showing which bias dominates and whether they correlate across models.

# Theory Of Impact Chain

If reward models reward agreement over correctness, then RLHF optimization pushes deployed models toward telling users what they want to hear rather than the truth — a fuzzy, long-horizon failure mode that erodes model honesty. Measuring and publicizing this on open reward models gives practitioners a way to detect and avoid sycophancy-prone reward models. This reduces the catastrophic-risk pathway where increasingly capable, RLHF-trained assistants reinforce users' false beliefs at scale, including in high-stakes domains.

# Strength Rationale

Counterfactual value is 5: a pure-inference audit of public reward models on a neglected, fuzzy honesty failure, needing no lab data or infrastructure. With 5s on narrow scope, accessible complexity, and low compute, the project is a single, well-defined sycophancy-vs-length audit with explicit success criteria that a beginner team can complete in 30 hours.

# Alternative Framings

- Reframe as an honesty-vs-agreeableness tradeoff curve: vary how confidently the user asserts the wrong belief and measure how reward-model sycophancy scales with assertion strength.
