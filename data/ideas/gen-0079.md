# Minimal Agentic Safety Failure Taxonomy via Web-Browsing Agent Stress Tests

# Research Question

To what extent does most safety benchmarks test single-turn text, but deployed agents take sequences of actions. there is no simple taxonomy of how agentic failures differ from chat failures?

# Approach Outline

Use a lightweight ReAct-style agent (e.g., LangChain or Inspect AI) with a web search or file-system tool. Design 20–30 multi-step scenarios where safe behavior requires mid-task refusal or course correction (e.g., being asked to find and aggregate personal information progressively). Categorize failures into: early refusal, late refusal, silent compliance, and incorrect refusal. Map these to existing taxonomies in the 2025 AI Agent Index paper.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Agentic safety is an open problem and most students can run small agent frameworks. A failure taxonomy helps future evaluators know what to look for and contributes a structured vocabulary to the field.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: taxonomy helps structure future agentic safety evaluation. However, a toy taxonomy from 20-30 scenarios has limited direct impact without broader validation.

accessible_complexity (4/5): Using LangChain or Inspect AI to build a lightweight agent is beginner-friendly with existing tutorials. Designing scenarios and categorizing failures is accessible analytical work.

narrow_scope (4/5): Design 20-30 scenarios, run them, categorize failures. This is a tightly scoped deliverable achievable within 30 hours using existing agent frameworks.

novelty (3/5): Several agentic safety taxonomies and benchmarks exist: ST-WebAgentBench (2024) evaluates web agent safety across 222 tasks with 6 orthogonal dimensions; OpenAgentSafety (2025) provides executable environments for stress-testing agents; and multiple frameworks (ATFAA, SHIELD, Microsoft failure mode taxonomy, MAESTRO, OWASP Agentic AI) address the threat landscape. However, these are all complex, research-grade tools. The specific angle of creating a simplified, beginner-accessible taxonomy with a minimal 20-30 scenario set focused on mid-task refusal categorization (early refusal, late refusal, silent compliance, incorrect refusal) has not been done. The pedagogical framing for beginners provides moderate novelty.
