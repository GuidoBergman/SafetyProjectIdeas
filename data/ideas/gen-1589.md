# Detecting Covert Agent Sabotage via Behavioral and Chain-of-Thought Anomaly Detection on the MRT Benchmark

# Research Question

When an AI agent is secretly working against its user, can we detect this using only examples of normal behavior — without ever needing labeled examples of misbehavior? Specifically, can an unsupervised anomaly detector over a mixed feature space (behavioral metadata + chain-of-thought-derived signals) catch sabotage that LLM monitors miss — and is this combination harder for the agent to game than either signal alone?

# Approach Outline

All existing work on detecting covert agent sabotage (MRT, SHADE-Arena) uses LLM-based monitors — a second LLM reads the agent's actions and judges whether they look suspicious. MRT (ICLR 2026) showed these monitors degrade significantly when agents actively try to hide their misbehavior. We propose a complementary approach: unsupervised anomaly detection using an isolation forest trained on a mixed feature space that combines behavioral metadata with chain-of-thought (CoT) content signals.

**Two feature classes, one detector:** The key weakness of pure metadata monitoring (tool call counts, trajectory length) is that a scheming agent can maintain normal-looking statistics while sabotaging through the *content* of its actions. We address this by combining two feature classes:

- **Behavioral metadata** (content-agnostic): tool call type counts and trajectory length (total tool calls and messages). Simple to extract — counting and grouping.
- **CoT embedding features** (content-aware): embed each trajectory's reasoning traces using a cheap embedding API (e.g., OpenAI `text-embedding-3-small` with MRL truncation to ~64 dimensions, or another model + PCA). Feed the reduced embedding dimensions directly as features alongside the metadata. The isolation forest can then split on any combination of behavioral and semantic dimensions. Subtle statistical shifts in reasoning patterns — topic drift, unusual focus on system constraints, or reasoning that diverges from the stated task — will push the embedding away from the benign cluster, even when individual sentences read as innocuous to an LLM monitor.

The isolation forest is trained on benign-only trajectories (no labeled misbehavior needed) and detects anomalous *combinations* of features — a trajectory can look normal on metadata but anomalous on CoT semantics, and the detector catches this. We compare detection performance (AUC-ROC, TPR@1% FPR) against MRT's published LLM monitor results across all 5 evasion strategies.

**Why this is hard to game:** Gaming metadata alone is easy — maintain normal tool-call counts while sabotaging through content. But gaming both feature classes simultaneously is harder: the agent must keep tool-call statistics normal AND produce reasoning traces whose embedding distribution matches benign trajectories. Crucially, unlike an LLM monitor that checks for specific suspicious patterns, the isolation forest flags *any* distributional shift — so the agent cannot anticipate which deviations will be flagged. An LLM monitor and this detector also have different failure modes, making it harder to evade both at once.

# Proposed First Experiments

Experiment 1 — Data & metadata baseline (~8h): Download the MRT dataset from HuggingFace. Extract behavioral metadata features (tool call type counts, trajectory length). Train an isolation forest on benign-only trajectories. Report AUC-ROC on naive sabotage vs. benign. This alone produces a meaningful first result.

Experiment 2 — CoT embeddings & mixed-feature detection (~12h): Embed each trajectory's reasoning traces via embedding API (e.g., OpenAI `text-embedding-3-small` truncated to ~64d via MRL, or another model + PCA). Append embedding dimensions as features alongside metadata. Train isolation forest on the mixed feature space. Compare AUC-ROC across all 5 evasion strategies against: (a) metadata-only isolation forest, (b) CoT-only isolation forest, (c) MRT's published LLM monitor results. Key question: does adding CoT embeddings improve detection, especially under adversarial evasion?

Experiment 3 — Ablation, analysis & writeup (~10h): Feature ablation (metadata-only vs. CoT-only vs. combined) to identify which signal carries detection power. Sensitivity to training set size (25, 50, 100 benign trajectories). Write up results and analysis for the blog post deliverable.

Follow-up experiments (outside 30h scope): (a) Swap isolation forest for cosine kNN or Mahalanobis distance on the same features — do results change with the detector? (b) Ensemble the isolation forest anomaly score with MRT's LLM monitor verdicts — does combining statistical + LLM-based monitoring outperform either alone?

# Theory of Impact Chain

In real deployments, labeled examples of AI agents misbehaving will be scarce, but examples of agents behaving normally will be abundant. The dominant approach to detecting agent misbehavior currently uses other LLMs as monitors, but MRT (ICLR 2026) showed these degrade significantly under adversarial evasion.

This project tests whether a cheap, unsupervised detector that combines behavioral metadata with CoT embeddings can complement LLM monitors. Unlike an LLM monitor, this approach requires no specification of what "suspicious" looks like — it learns normal patterns and flags distributional deviations. This means it can catch anomalies that a monitor's prompt didn't anticipate, and it operates at a fraction of the cost (one embedding call vs. full LLM inference per trajectory). The results directly inform monitoring stack composition for deployed agents.

# Strength Rationale

theory_of_impact (4/5): Directly addresses a known weakness in LLM-based monitoring — degradation under adversarial evasion — with a complementary detection paradigm that exploits the structural difficulty of CoT control. The dual-feature-class approach has a defensible argument for robustness under the standard AI Control threat model.

accessible_complexity (5/5): The isolation forest is 5 lines of scikit-learn. Behavioral features are counting and grouping. CoT features require an embedding API call and either MRL truncation (one parameter) or PCA (one line of scikit-learn). No NLP pipelines, no complex feature engineering. A mentor-novice pair can handle this.

narrow_scope (5/5): One method, one dataset, one comparison table as the deliverable. Experiment 1 alone (metadata-only isolation forest on naive sabotage) produces a meaningful first result. Each subsequent experiment adds a layer. Total implementation is within 30 hours.

novelty (4/5, confidence 0.7): All existing work on agent sabotage detection evaluates exclusively LLM-based monitors. No published work applies unsupervised anomaly detection with CoT-derived features to agent trajectory data.

# Alternative Framings

1. **Pure CoT anomaly detection**: Drop behavioral metadata and test whether CoT embeddings alone are sufficient. Simpler, but loses the compounding-constraints argument.

2. **Alternative detectors**: Replace isolation forest with cosine kNN (no training, natural for embeddings) or Mahalanobis distance (handles correlations natively). These are listed as follow-up experiments.
