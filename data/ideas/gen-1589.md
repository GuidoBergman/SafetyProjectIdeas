# Detecting Covert Agent Sabotage Without Labeled Examples: Isolation Forests vs. LLM Monitors on the MRT Benchmark

# Research Question

When an AI agent is secretly working against its user, can we detect this using only examples of normal behavior — without ever needing labeled examples of misbehavior? And does this simple statistical approach remain effective even when agents deliberately try to evade detection?

# Approach Outline

An isolation forest is a simple, unsupervised machine learning method that learns what "normal" looks like from a set of normal-only examples, then flags anything that deviates as anomalous. It needs no labeled examples of misbehavior — only a baseline of normal agent behavior to learn from. It is available in scikit-learn and takes about 5 lines of code to set up.

We use the ScaleAI/MRT dataset (publicly available on HuggingFace), which contains transcripts of LLM agents completing tasks. Some agents behave normally; others secretly pursue hidden malicious objectives (such as exfiltrating data or making unauthorized transfers) while appearing to follow instructions. The dataset includes five evasion strategies agents use to hide their misbehavior from monitors — from naive (no hiding) to combined (actively lying and selectively revealing reasoning).

For each transcript, we extract numerical features: tool call type and frequency counts, trajectory length (total tool calls and messages), and reasoning-trace length (thinking-tag token counts). If tool-level bigrams (pairs of consecutive tool calls) prove too sparse, they can be computed over functional categories instead of individual tool names. We train the isolation forest on normal-only transcripts, then test whether it flags the sabotage transcripts as anomalous. We compare detection performance (AUC-ROC — how well the detector ranks sabotage above normal — and TPR at 1% false positive rate) against: (a) a supervised Random Forest trained on the same features but with labels, and (b) MRT's published LLM monitor results, where a second LLM judges whether the agent's behavior looks suspicious.

The core question is whether a cheap statistical method that requires no labeled misbehavior data and no LLM inference can complement or even outperform LLM-based monitors — especially under adversarial evasion, where MRT showed that LLM monitors degrade significantly.

# Proposed First Experiments

Experiment 1 — Featurization & Baseline (~8h): Download the MRT dataset from HuggingFace. Write a featurization pipeline to extract numerical vectors from transcripts (tool call counts, action type distributions, message and reasoning-trace statistics). Train an isolation forest on benign-only trajectories from a single evasion strategy (naive). Report AUC-ROC on naive sabotage vs. benign. This alone produces a meaningful first result.

Experiment 2 — Cross-strategy evaluation (~12h): Evaluate the benign-trained isolation forest across all 5 evasion strategies. Train a supervised Random Forest on the same features with labels as a ceiling comparison. Produce an AUC comparison table: isolation forest vs. supervised classifier vs. MRT's published LLM monitor results, broken down by evasion strategy. Key question: does the isolation forest degrade less than LLM monitors under adversarial evasion?

Experiment 3 — Feature ablation & sensitivity (~10h): Ablate feature groups (tool call counts only, trajectory length only, reasoning-trace features only) to identify which signals carry the most detection power. Test sensitivity to training set size (25, 50, 100 benign trajectories). Write up results and analysis for the blog post deliverable.

# Theory of Impact Chain

In real deployments, labeled examples of AI agents misbehaving will be scarce, but examples of agents behaving normally will be abundant. The dominant approach to detecting agent misbehavior currently uses other LLMs as monitors — essentially asking a second AI "does this look suspicious?". MRT (ICLR 2026) showed that these LLM monitors become significantly less reliable when agents actively try to hide what they are doing.

If a simple statistical method that only needs normal examples and costs virtually nothing to run can catch misbehavior that LLM monitors miss, this changes how safety monitoring systems should be designed. The experiment quantifies: when are cheap statistical baselines sufficient, when do we need expensive LLM monitors, and does combining both improve robustness? These results directly inform practical decisions about monitoring stack composition for deployed AI agents.
