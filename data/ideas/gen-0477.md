# Adapting Credibility Assessment Interview Technique (CAIT) to Probe LLM Honesty

# Research Question

To what extent does forensic psychology has developed structured interview protocols (e.g., cait, cbca) to detect deception in humans by analyzing statement consistency, detail richness, and cognitive load markers. these?

# Approach Outline

Map CAIT/CBCA criteria (e.g., logical structure, unstructured production, contextual embedding) onto LLM output features. Build a small evaluation set of known-honest vs. known-deceptive LLM responses and test whether these forensic criteria predict deception reliably. Use an open-source model like Llama or Mistral.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

If classical forensic criteria transfer even partially to AI output analysis, this provides a low-cost, interpretable screening layer before deployment that requires no model internals access.

# Strength Rationale

theory_of_impact (3/5): Moderate theory: if forensic criteria transfer to AI, it provides a low-cost screening layer. But the transfer from human deception detection to LLM output is speculative.

accessible_complexity (4/5): Mapping criteria and running classification tests is accessible. Requires reading forensic psychology literature but the implementation is simple text analysis. No model training needed.

narrow_scope (4/5): Well-scoped: map criteria, build small evaluation set, run classification. The deliverable is clear (does CAIT predict LLM deception?). Feasible in 30 hours.

novelty (4/5): A 2025 study applied CBCA (Criteria-Based Content Analysis) to LLM outputs, specifically using ChatGPT to evaluate forensic interview transcripts against the 19-item CBCA framework. This showed LLMs cannot reliably replicate expert CBCA judgment. However, the proposed idea inverts this: instead of using LLMs to apply CBCA, it applies CAIT/CBCA forensic criteria to LLM outputs to detect LLM deception. This inverse application — using forensic deception detection tools as features for an LLM deception classifier — is novel. The cross-domain transfer from forensic psychology to AI deception detection in this direction has not been systematically explored.
