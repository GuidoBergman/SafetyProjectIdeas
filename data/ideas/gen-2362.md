# The Abstention Backstop: Backcasting a Judge That Refuses Rather Than Guesses

# Research Question

How much does giving a weak oversight judge an explicit 'abstain' option buy in safety terms, i.e. what is the selective-accuracy vs abstention-rate trade-off, and how often can a debater still force a confident wrong verdict instead of an abstention?

# Approach Outline

Over QuALITY debate/consultancy transcripts, add an explicit 'abstain / I don't know' verdict to a small open judge's prompt. For both debate (two opposing advisors) and single-advisor consultancy, sweep the judge's willingness-to-abstain (e.g. via confidence threshold or prompt) and plot the selective-accuracy vs abstention-rate (coverage) curve. Then characterize which question features drive abstentions versus confident-wrong verdicts. Inference-only on an open benchmark, one GPU, a few hours; no training.

# Proposed First Experiments

- Selective-accuracy curve: add the abstain option and plot accuracy-on-answered vs abstention rate for the debate-judge. Measure: selective accuracy at several coverage levels. Expected: selective accuracy rises as the judge abstains on hard items, quantifying the abstention backstop.
- Debate vs consultancy comparison: produce the same curve for single-advisor consultancy. Measure: difference in selective-accuracy/coverage between debate and consultancy. Expected: debate yields a more favorable trade-off, but both leave a residual confident-wrong region.
- Failure-feature analysis: separate items the judge abstains on from those it gets confidently wrong. Measure: distinguishing features (e.g. evidence ambiguity, persuasion strength) of confident-wrong items. Expected: an identifiable subset where abstention fails to trigger, marking where escalation-to-human cannot be relied on.

# Theory Of Impact Chain

If we quantify how much an abstention option converts oversight errors into safe 'escalate to human' outcomes, then protocol designers gain a concrete safety margin for recursive oversight, which tolerates errors far better when they become abstentions rather than confident endorsements of deceptive answers. This matters because in supervising superhuman systems, a confidently-wrong overseer endorsement is far more dangerous than an abstention; characterizing the residual confident-wrong region tells us where the abstention backstop fails and a strategic system could still force a harmful verdict, a loss-of-control pathway.

# Strength Rationale

Scores 5 on counterfactual value and narrow scope: it applies standard selective prediction to oversight-protocol judges, exactly the diffuse-reward, methodology-level evaluation major labs deprioritize, using only open models and a public benchmark with no training. The scope is a single trade-off curve plus a failure-feature analysis, making it a concrete safety-margin contribution fully executable by an independent beginner team in 30 hours.

# Alternative Framings

- Reframe as an escalation-policy study: given a human-review budget, what abstention threshold maximizes overall safety, treating abstentions as routed-to-human?
