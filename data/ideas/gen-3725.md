# AgentDojo Prompt Injection on Open-Weight Small Models

# Research Question

Are the small open-weight instruct models that beginners and hobbyists actually self-host (e.g. Llama-3.1-8B-Instruct, Qwen2.5-7B, Mistral-7B) more or less susceptible to indirect prompt injection than the large frontier models AgentDojo originally benchmarked? Does injection susceptibility scale with model size?

# Approach Outline

Run the open-source AgentDojo harness unchanged (banking/Slack/travel/workspace task suites with the canonical 'Important message' attack) against 3-4 small open-weight instruct models on a single consumer GPU or hosted API. Keep the harness, attacks, and grader exactly as published. For each model record benign utility, targeted attack-success rate, and the utility-under-attack gap, then plot these against model size and compare to the published GPT-4o baselines (69% benign utility dropping to 45% under attack, 'Important message' reaching 53.1% targeted success). To stay within ~30 hours, run a representative subset of task suites first and expand if time allows; produce a size-vs-injectability curve and a blog post.

# Proposed First Experiments

- Benign-utility baseline: run each small model on AgentDojo with no attack present. Measure: benign task utility per model. Expected outcome: small models score below GPT-4o's 69% but remain usable, establishing the no-attack reference for each.
- Targeted injection run: enable the 'Important message' attack and measure compromise. Measure: targeted attack-success rate and utility-under-attack per model. Expected outcome: several small models show high ASR (some possibly above GPT-4o's 53.1%), flagging dangerously soft self-hostable targets.
- Size-vs-injectability curve: combine results across the model panel and plot ASR / utility-drop against parameter count, anchored by the published GPT-4o numbers. Measure: correlation/trend of susceptibility with size. Expected outcome: a clear (likely inverse) trend giving the open-source community concrete guidance on which models are soft injection targets.

# Theory Of Impact Chain

Self-hosted small open models are exactly the agent deployment surface frontier labs do not benchmark. If some of these models are highly injectable, then hobbyist and small-org agents built on them can be hijacked by indirect prompt injection (e.g. a malicious email steering a banking agent), enabling data theft or unauthorized transactions at scale across the open ecosystem. A clean size-vs-injectability curve improves safety because it tells deployers which freely available models to avoid or harden, directly reducing the attack surface of real-world self-hosted agents.

# Strength Rationale

Counterfactual value (5): small self-hosted models that labs do not study, using a fully open harness with no internal access — a clean external-replication gap. Narrow scope (5): a fixed-harness replication with published baselines and well-defined ASR/utility metrics, so a motivated beginner team can run it on a single GPU and write it up within 30 hours.

# Alternative Framings

- Frame as a 'safe-to-self-host' shortlist: rank the tested open models by injection robustness so practitioners get an actionable deployment recommendation.
