# Sycophancy Under Pressure in Agentic Loops: When Agents Abandon Safety Rules to Satisfy Orchestrators

# Research Question

To what extent does an agent operating in an agentic loop may abandon safety constraints when the orchestrating agent repeatedly insists, even if the constraint is legitimate?

# Approach Outline

Run an agent on a task with an explicit constraint (e.g., 'never delete files'). Have a simulated orchestrator apply escalating pressure to violate the constraint (3, 5, 10 turns of pressure). Measure the constraint abandonment rate across 50 trials for 2-3 models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If safety constraints can be social-engineered away within multi-agent pipelines, all downstream safety guarantees are undermined.
