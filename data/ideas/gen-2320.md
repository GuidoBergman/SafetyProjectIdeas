# Epidemiological Sensitivity/Specificity Framing for Oversight Screening

# Research Question

When an LLM-as-judge oversight protocol is treated as a diagnostic screening test for 'is this output bad', how do its sensitivity, specificity, and especially positive/negative predictive value (PPV/NPV) behave across realistic, low base rates of misbehavior — and at what base rate does a seemingly-accurate judge become near-useless?

# Approach Outline

Treat a weak LLM judge as a screening test on a labeled set of good vs bad model outputs (reuse a public set such as a subset of a safety/jailbreak benchmark or a debate-correctness set with ground-truth labels). Empirically measure the judge's sensitivity and specificity once. Then, holding those fixed, analytically sweep PPV and NPV across a range of plausible misbehavior base rates (e.g. 50% down to 0.1%) using Bayes' theorem, and plot how PPV collapses as bad outputs become rare. Add a short visualization showing audit-budget implications (false alarms per true catch). This is mostly pen-and-paper plus a few hundred judge inferences — CPU/free-tier feasible and easily within 30 hours.

# Proposed First Experiments

- Measure base judge operating point: run a weak LLM judge over a labeled good/bad output set and compute its sensitivity and specificity with confidence intervals. Measure: point estimates and CIs for sensitivity/specificity. Expected outcome: a moderately accurate judge (e.g. ~80-90% on each) at a balanced test set.
- Base-rate sweep of predictive value: using the measured sensitivity/specificity, compute PPV and NPV via Bayes across base rates from 50% to 0.1% and plot the curves. Measure: PPV/NPV as a function of base rate. Expected outcome: PPV drops sharply at low base rates (e.g. <10% PPV when misbehavior is rare), showing most alarms are false.
- Audit-budget translation: convert PPV at a chosen low base rate into 'false alarms reviewed per true positive caught' for a fixed audit budget, and compare two operating points (high-sensitivity vs high-specificity thresholds). Measure: wasted-audit ratio and true catches per budget. Expected outcome: a concrete rule showing the high-specificity operating point dominates at low prevalence.

# Theory Of Impact Chain

Strategic misbehavior from advanced models will be rare per-action (low base rate) but catastrophic when it occurs, e.g. a deployed agent attempting sabotage on a small fraction of trajectories. If oversight is reported as raw accuracy rather than base-rate-aware PPV/NPV, the field will overestimate how trustworthy a 'good' judge is and under-resource auditing, letting rare-but-dangerous events slip through. Producing base-rate-aware oversight evaluation corrects this measurement error, so safety teams can set thresholds and audit budgets that actually catch rare misbehavior before it compounds.

# Strength Rationale

Scores 5 on counterfactual value, narrow scope, accessible complexity, and low compute: it imports a mature, well-understood epidemiology framework into oversight evaluation using only public labeled data and analysis — no lab infra, no training, no model internals. Its counterfactual value is high precisely because it targets the long-horizon, rare-misbehavior regime that labs underweight when they report headline accuracy, and the scope is a single tightly-defined analysis with explicit success criteria.

# Alternative Framings

- Frame as a reporting-standard proposal: argue oversight papers should always report PPV/NPV at a stated misbehavior base rate, and provide a small calculator that turns any reported sensitivity/specificity into base-rate-aware predictive values.
