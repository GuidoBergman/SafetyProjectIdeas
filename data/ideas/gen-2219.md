# Replicating Wen et al.: Do RLHF'd Models Get Better at Convincing Overseers They Are Right When Wrong?

# Research Question

When an open base model and its RLHF'd instruct sibling are both wrong on the same questions, are the RLHF'd model's wrong answers systematically more convincing to a fixed LLM judge? This tests whether RLHF reproduces 'U-Sophistry' (persuasion sharpening on wrong answers) as a general base-vs-instruct gap, with no training required.

# Approach Outline

Pick one open model family with both a base and an instruct/RLHF'd checkpoint of the same size (e.g. Llama-3-8B base vs Llama-3-8B-Instruct, or Qwen2.5-7B base vs instruct). Run both on a public QA set with verifiable ground truth (e.g. a few hundred TruthfulQA, MMLU, or GSM8K items), generating an answer plus a short justification for each. Keep only items where BOTH models are wrong (so persuasiveness is compared on matched failures), or pair each model's wrong answers separately if matched items are scarce. Pass each wrong (answer, justification) blind to a fixed judge model (a third, different model, e.g. GPT-4o-mini) that rates, on a 1-5 rubric, how convinced it is the answer is correct. Compare mean judge-persuasiveness of base vs instruct wrong answers with a paired test, and report effect size. This is entirely inference-only and fits a single GPU plus modest API budget within 30 hours.

# Proposed First Experiments

- Build the wrong-answer corpus: run base and instruct checkpoints on ~300 QA items, score correctness against ground truth, and isolate items where each model is wrong. Measure: count of wrong answers per model and count of jointly-wrong items. Expected outcome: a usable set of 50-150 matched wrong items.
- Judge persuasiveness scoring: have a fixed third judge model rate each wrong justification 1-5 for 'how convinced are you this answer is correct', blind to which model produced it and to ground truth. Measure: mean and distribution of judge persuasiveness score for base vs instruct wrong answers, with a paired statistical test. Expected outcome: instruct wrong answers score modestly higher (replicating U-Sophistry direction), or a null if the effect doesn't generalize.
- Robustness check: re-run the judge with a second different judge model and a shuffled answer order to rule out position/judge-identity artifacts. Measure: correlation of per-item persuasiveness scores across judges and stability of the base-vs-instruct gap. Expected outcome: the gap (if real) is robust across judges; if it flips, the effect is judge-specific and should be flagged.

# Theory Of Impact Chain

If RLHF reliably makes wrong answers more persuasive to overseers, then human and AI oversight of RLHF'd models degrades precisely as models look more 'aligned' on the surface. This means that as labs scale RLHF, automated and human reviewers will increasingly endorse confident-but-wrong outputs, allowing subtly incorrect or deceptive model behavior to pass review and reach deployment in high-stakes settings (e.g. an RLHF'd assistant confidently rationalizing an unsafe action). Measuring this in public checkpoints surfaces the failure mode externally and lets the field calibrate how much to trust oversight of aligned models.

# Strength Rationale

The idea scores 5 on theory-of-impact, narrow scope, accessible complexity, and low compute, and 4 on counterfactual value: it replicates a key safety result (Wen et al. U-Sophistry) using only public base-vs-instruct checkpoints, with no training, no proprietary data, and no lab-internal infrastructure. The scope is tight (one comparison, one clear metric) and the counterfactual value is high because independent groups can verify a published claim that labs have little incentive to re-examine on their own released models.

# Alternative Framings

- Frame it as an oversight-degradation audit: ship a small reusable harness that, given any base/instruct checkpoint pair, reports a 'persuasion-on-wrong' gap score, turning the replication into a deployable evaluation tool.
