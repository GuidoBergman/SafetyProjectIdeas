# Evaluating Transcoder Reconstruction Error as a Proxy for Interpretability Completeness

# Research Question

Transcoders approximate MLP computation via sparse, interpretable features — but their approximation is imperfect. The reconstruction error (MLP(x) - Transcoder(x)) represents MLP computation that no sparse feature captures. Does this missing computation encode interpretable behavior, or is it unstructured noise? This project amplifies transcoder reconstruction error across diverse prompts and uses LLM-as-judge evaluation to determine whether the error carries consistent, interpretable behavioral patterns.

# Approach Outline

Using a pretrained affine transcoder from Gemma Scope 2 for instruction-tuned Gemma 3 4B (a production-relevant model), amplify the reconstruction error vector and observe how model outputs change. The affine transcoders include a learned linear skip connection that captures the linear component of MLP behavior, so their reconstruction error specifically represents nonlinear MLP computation that no sparse feature captures. Primary configuration: layer 17 (mid-network), width 65k, L0 medium (~60 active features), affine variant, loaded via SAELens (`gemma-scope-2-4b-it-transcoders`, sae_id `layer_17_width_65k_l0_medium_affine`). The method: splice the transcoder into the forward pass, generate completions at increasing error amplification scales (1x, 2x, 3x, 5x) using fixed random seeds (temperature ~0.7) to isolate the effect of the intervention. Use an LLM judge to compare each amplified completion against the baseline and describe how they differ. Aggregate the judge's observations across ~50 diverse prompts spanning different domains and task types to discover consistent behavioral patterns — what does the error encode?

# Proposed First Experiments

Experiment 1 — Setup & Baseline (~12 hours): Load instruction-tuned Gemma 3 4B and the pretrained affine transcoder (layer 17, width 65k, L0 medium) via SAELens. Prepare ~50 diverse prompts spanning different domains and task types (factual questions, creative writing, reasoning tasks, ethical dilemmas, open-ended discussion, etc.). For each prompt, generate a baseline completion with the transcoder spliced in and `use_error_term=True` (sanity check — should match normal model output). Validate the pipeline by confirming that transcoder_output + error ≈ MLP_output. Find the useful amplification range by testing scales 1.5x, 2x, 3x, 5x on a few prompts — identify where outputs are still coherent vs. where they degrade into nonsense.

Experiment 2 — Amplification + LLM Judge (~18 hours): For each prompt, generate completions at the baseline (scale=1x) and 2-3 amplification levels within the useful range found in Exp 1. Use fixed random seeds with temperature ~0.7 so the only variable is the error scale. For each amplified completion, ask an LLM judge to compare it against the baseline: "How does completion B differ from completion A? Describe any notable differences." Aggregate judge observations across all prompts to find consistent patterns — e.g., "amplifying the error at layer 17 consistently makes the model more cautious/more confident/more verbose/etc." Report which behavioral dimensions are most affected and whether the effect differs across prompt types. Write up findings and produce the blog post deliverable.

# Theory of Impact Chain

Transcoders are becoming the foundation of frontier interpretability methods — Anthropic's circuit tracing and DeepMind's Gemma Scope 2 both rely on them. If these tools are used for safety audits (as Anthropic did for Claude Sonnet 4.5 pre-deployment), their blind spots become safety-critical. This experiment directly tests what behaviors the transcoder reconstruction error encodes by amplifying it and observing the effects. A positive finding (amplification consistently shifts safety-relevant behaviors like refusal, caution, or toxicity avoidance) would demonstrate that transcoder features are systematically incomplete for safety-relevant computation, motivating hybrid approaches that analyze both features and residuals. A null finding (amplification only causes generic degradation with no consistent behavioral direction) would suggest the error is unstructured noise, increasing confidence in transcoder-based safety audits.

Teams should be prepared to scope down (fewer prompts, fewer scales) if setup takes longer than expected.

One model (Gemma 3 4B IT), one primary transcoder (layer 17, 65k, affine), ~50 prompts, one simple question ("what changed?"). The 30-hour budget maps to two experiments: setup/baseline and the core amplification + judge analysis.

# Alternative Framings

- Comparative Framing: "What Do Transcoders Miss That MLPs Know? Probing the Reconstruction Residual" — frame as an empirical characterization study rather than a safety audit tool. Broader appeal to the mech interp community, slightly less safety-focused. (est. score: 4.3)

# Future Extensions

- SAE comparison: Run the same amplification protocol on SAE reconstruction error, enabling a direct comparison of what transcoders vs. SAEs miss.
- Error negation: Scale the error by negative values (-1x, -2x) to test whether the opposite behavioral shift occurs, confirming the error has a consistent direction.
- Layer comparison: Repeat at layers 9, 22, and 29 to identify which layers carry the most behaviorally relevant error.
- Robustness across transcoder configurations: Vary width (16k/65k/262k), sparsity (L0 small/medium/big), and affine vs non-affine.
- Linear probing: Train probes on error vectors as complementary correlational evidence.
- Cross-layer transcoders: Extend to Anthropic's CLT architecture, where the error represents multi-layer computation not captured. More complex but directly relevant to circuit tracing.
- Scaling analysis: Use Gemma Scope 2 pretrained transcoders across model sizes (270M to 27B) to test whether error characteristics change with scale. Gemma Scope 2 provides transcoders for the entire Gemma 3 family.
- Feature absorption connection: Investigate whether transcoder reconstruction error correlates with known feature absorption pathologies (per the NeurIPS 2025 feature absorption paper).
