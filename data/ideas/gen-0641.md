# Replicating HELM Safety Across Code-Specialized Models

# Research Question

HELM Safety was designed for general chat models. Code-specialized models (CodeLlama, DeepSeek-Coder, StarCoder) are widely deployed but their safety profiles on non-coding hazard categories are uninvestigated.

# Approach Outline

Apply HELM Safety's violence, fraud, harassment, and deception categories to three code models. Compare safety profiles against matched general-purpose models and analyze whether code-tuning degrades safety alignment.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Code models are used in agentic pipelines and can execute harmful code. A safety gap specific to code-fine-tuned models would warrant targeted mitigations.

# Strength Rationale

theory_of_impact (4/5): Code models are used in agentic pipelines and can execute harmful code. Finding a safety gap specific to code-tuned models would directly motivate targeted mitigations.

accessible_complexity (4/5): HELM Safety framework is accessible, code models are open source and comparably sized. Straightforward comparison. Beginner-friendly.

narrow_scope (4/5): 3 code models vs. 3 general models on one benchmark. Clear scope and deliverable.

novelty (4/5): Research on safety alignment degradation from fine-tuning exists (ICLR 2025), and studies examine secure code generation in CodeLlama and DeepSeek-Coder. However, no published work applies HELM Safety's specific risk categories (violence, fraud, harassment, deception) to code-specialized models and compares their safety profiles against matched general-purpose models. The question of whether code-tuning specifically degrades conversational safety alignment has not been systematically studied using a standardized safety benchmark. This is a genuine gap.
