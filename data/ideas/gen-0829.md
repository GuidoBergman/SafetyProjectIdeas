# Network Intrusion Detection Signatures for Prompt Injection: SNORT Rules for LLMs

# Research Question

To what extent does prompt injection detection is done with llm-based judges which are slow, expensive, and themselves vulnerable to adversarial manipulation. lightweight, rule-based detection is needed?

# Approach Outline

Import SNORT/Suricata intrusion detection rule methodology from network security. Analyze a corpus of successful prompt injections and extract structural signatures (e.g., instruction-override patterns, role-switch tokens, delimiter escapes, encoding anomalies). Formalize these as lightweight regex/embedding-distance rules analogous to SNORT signatures. Build a rule-based pre-filter that blocks high-confidence injections before they reach the LLM. Measure precision/recall and compare cost (tokens, latency, price) against an LLM-judge detector.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

SNORT has protected networks for decades with sub-millisecond rule matching. A SNORT-style pre-filter for prompt injection would be orders of magnitude cheaper than LLM-judge-based detection, enabling cost-effective real-time deployment protection.
