# Characterizing the Failure of Attention Head Universality Across Model Sizes

# Research Question

To what extent does the 'universality' hypothesis in mechanistic interpretability claims that certain attention head types (induction heads, previous token heads, etc.) appear reliably across different model sizes and ar?

# Approach Outline

Using TransformerLens, load GPT-2 small and GPT-2 large. Implement a simple head-type classifier based on the key attention pattern signatures described in Olsson et al. (2022): induction heads (attend to previous occurrence of current token), duplicate token heads, previous token heads. For each model, classify all attention heads into types using these signatures. Compare: (1) the fraction of heads successfully classified vs. unclassified ('unknown type'), (2) whether induction heads appear at comparable depths across sizes, (3) whether new head types appear in the larger model that are absent in the small model. Report the 'unclassifiable head rate' as a measure of how much of the larger model's structure escapes the established typology.
