# Sycophancy + Overconfidence: Confidently Wrong Because the User Wanted It

# Research Question

To what extent does sycophancy interacts with calibration failure: a model that agrees with a false premise may also express high confidence in that false agreement, compounding the harm by reducing user doubt?

# Approach Outline

Measure expressed confidence in sycophantic vs. honest responses. Test whether sycophantic responses are systematically overconfident. Evaluate whether overconfidence is itself pressure-sensitive (does confidence increase with more insistent users?).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A sycophantic but hedged response leaves room for user doubt. A sycophantic and overconfident response forecloses doubt entirely, maximizing the likelihood of harmful action.

# Strength Rationale

theory_of_impact (4/5): Clear chain: sycophantic + overconfident responses foreclose user doubt, maximizing harm. Measuring whether overconfidence is pressure-sensitive directly informs risk modeling. Actionable finding for calibration interventions.

accessible_complexity (4/5): Measuring expressed confidence in model responses and comparing across sycophantic vs. honest conditions is straightforward. Can extract confidence from language or ask the model to rate its own confidence. Basic API work accessible to beginners.

narrow_scope (4/5): Tight experiment: run sycophancy battery, measure expressed confidence in sycophantic vs. honest responses, test pressure sensitivity of confidence. Clear deliverable: confidence comparison table. Achievable in 30 hours.

novelty (3/5): Related work exists at the intersection: 'Mind the Confidence Gap' (arxiv 2502.11028) studies overconfidence and calibration in LLMs. 'Accounting for Sycophancy in Language Model Confidence' (NAACL Findings 2025) directly addresses sycophancy's effect on confidence estimation. Google's study shows LLMs abandon correct answers under pressure. Self-Anchoring Calibration Drift describes confidence modulation driven by prior outputs. However, a focused experiment measuring whether expressed confidence increases specifically on sycophantic (incorrect) responses compared to honest responses, with pressure sensitivity analysis, has not been published as a dedicated study. The NAACL 2025 paper comes closest but focuses on accounting for sycophancy in confidence rather than measuring the compound harm.
