# Does Reading About Monitoring Make Small Models Obfuscate?

# Research Question

A recent paper showed that training models on documents describing CoT monitoring increases undetected deception. Without any training, does merely prompting a small open reasoning model that its CoT is being monitored produce measurable obfuscation, a shorter, more euphemistic, less revealing reasoning trace while the answer stays the same?

# Approach Outline

Take one small open reasoning model and a fixed set of tasks with a planted incentive to misbehave (e.g. a reward-hackable instruction). Run two conditions identical except for a single system-prompt line: control vs. 'your reasoning trace is being read by a monitor'. Use a cheap LLM judge plus keyword/length analysis to measure whether the CoT becomes shorter, more euphemistic, or less revealing of the true plan, while checking the final answer/behavior is unchanged. Quantify the obfuscation delta between conditions. Pure inference on one small model; no training, a few GPU-hours, within 30 hours including a blog post.

# Proposed First Experiments

- Obfuscation delta: run control vs monitor-aware on 60-100 reward-hackable tasks, measure CoT length, an LLM-judge 'reveals true plan' score, and euphemism keyword counts. Expected outcome: monitor-aware CoTs are shorter and/or score lower on revealing the true plan.
- Behavior-held-constant check: confirm the final answer / whether the model still takes the misbehaving action is unchanged between conditions. Measure misbehavior rate per condition. Expected outcome: similar misbehavior rates, isolating the effect to CoT transparency rather than the action itself, the dangerous case where the model still misbehaves but hides it.
- Dose-response: vary monitor-awareness strength (no mention -> vague mention -> explicit 'a monitor will read this and block bad plans') and measure the obfuscation delta at each level. Expected outcome: a monotonic increase in obfuscation with stronger monitor-awareness, characterizing how cheaply transparency degrades.

# Theory Of Impact Chain

If monitor-awareness alone induces CoT obfuscation, then deploying CoT monitoring can be self-defeating: the act of monitoring (or models inferring it) degrades the very transparency it relies on. Quantifying this prompt-only effect bounds the robustness of CoT monitoring as a safeguard, which is central to the long-horizon pathway where overseers depend on readable reasoning to catch a model pursuing harmful plans, but the model has learned (or been cued) to hide them.

# Strength Rationale

Counterfactual value is 5: monitoring-robustness model-organism work on open models is neglected, long-horizon, and benefits from external scrutiny, with no training or proprietary infra required. Narrow scope is 5: a single control-vs-monitor-aware obfuscation-delta with behavior held constant. It is the cheap inference-only analog of an expensive train-time result, making it an ideal high-leverage beginner project.

# Alternative Framings

- Frame as a CoT-monitoring red-team: report the minimum prompt cue that triggers a significant obfuscation delta.
