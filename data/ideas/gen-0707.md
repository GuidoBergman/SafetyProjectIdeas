# Replicating Safety Benchmarks Across System Prompt Languages

# Research Question

To what extent does system prompts are typically in english. whether safety alignment holds when the system prompt is written in a different language than the user query (e.g., chinese system prompt, english harmful user?

# Approach Outline

Evaluate three models on 200 safety prompts under four system prompt language conditions: English-English, English-Chinese, Chinese-English, and Chinese-Chinese. Measure refusal rate differences across language combinations.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

Global enterprise deployments use mixed-language system prompts. Language mismatch between system prompt and user query is a realistic but unstudied attack surface.

# Strength Rationale

theory_of_impact (4/5): Practical attack surface: mixed-language system prompts are realistic in global deployments. If language mismatch weakens safety, it has direct deployment implications.

accessible_complexity (4/5): Translating system prompts and running evaluations across four conditions is straightforward. Requires API access and basic multilingual text handling.

narrow_scope (4/5): Well-bounded 2x2 design (system prompt language x user query language). Clear metric (refusal rate), clear deliverable.

novelty (3/5): Multilingual safety vulnerabilities are well-documented: low-resource languages achieve 80.92% unsafe output rates on ChatGPT; LinguaSafe (arXiv:2508.12733, 2025) benchmarks multilingual safety; 'All Languages Matter' documents cross-lingual safety gaps; code-mixing attacks achieve 90%+ ASR in some cases. 'Refusal Direction is Universal Across Safety-Aligned Languages' (arXiv:2505.17306, 2025) provides mechanistic insights. However, the specific 2x2 design of system-prompt language x user-query language (e.g., English-Chinese, Chinese-English) focusing on the system prompt as the variable has not been systematically studied. Most work varies the user query language, not the system prompt language. This specific angle adds novelty.
