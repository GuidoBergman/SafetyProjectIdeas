# Incident Detection Lag: How Long Before AI Harms Are Identified and Disclosed?

# Research Question

Effective governance requires timely incident detection. The time between harm occurrence and public disclosure for AI incidents is unknown and may be very long.

# Approach Outline

Using AIAAIC and OECD AI Incidents databases, code the detection date and public disclosure date for each incident where both are available. Compute median detection lag and disclosure lag. Test whether lags differ by company type, harm category, or deployment domain.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Long lags indicate either poor monitoring infrastructure or deliberate suppression—both are governance failures with different policy responses.
