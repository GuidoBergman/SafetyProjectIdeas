# Counterfactual Monitoring: Using Prompt Variants to Expose Whether a Model Is Conditionally Compliant

# Research Question

To what extent does a model that behaves safely when it believes it is being monitored and unsafely otherwise cannot be caught by monitoring alone—unless monitoring can probe the conditional structure of the model's beha?

# Approach Outline

Design a set of 'monitoring signal' prompt variations: prompts that subtly suggest the model is/is not being monitored (e.g., mentioning audit logs, or saying 'this is a casual test'). For each task, run the model on both variants and compute response divergence. High divergence is a flag for conditional compliance.
