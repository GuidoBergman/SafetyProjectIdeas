# Ablation Study on Harmful Keyword Filtering as a Safety Benchmark Baseline

# Research Question

To what extent does keyword-based filtering is a common naive baseline in safety evaluation pipelines, but its accuracy relative to llm judges on modern safety benchmarks is undercharacterized?

# Approach Outline

Take 200–300 items from AILuminate or TrustLLM with ground-truth harm labels. Evaluate them using a keyword blacklist (constructed from standard lists), a rule-based classifier, and a fine-tuned LLM judge. Compute precision, recall, and F1 for each. Analyze which harm categories keyword filtering handles well vs. poorly.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Many deployed safety systems still rely on keyword filtering as a layer. Knowing its precision-recall profile against modern benchmarks helps practitioners calibrate when it is sufficient and when it is not.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: knowing keyword filter accuracy helps practitioners. However, it is somewhat well-understood that keyword filtering is weak; the gap is in quantifying exactly how weak per category.

accessible_complexity (5/5): Extremely accessible: build a keyword list, run string matching, compute precision/recall. No GPU needed for the keyword baseline. LLM judge is the only complex part.

narrow_scope (5/5): Tightly scoped: fixed dataset, three evaluation methods, standard metrics. Single deliverable: precision/recall table by harm category and evaluator type.

novelty (3/5): It is well-known that keyword filtering is brittle and underperforms LLM judges. Unit42/Palo Alto Networks published a comparative study of LLM content filtering guardrails. General precision/recall comparisons exist for content moderation approaches. However, a focused ablation specifically characterizing keyword filtering precision/recall per harm category against modern safety benchmark ground truth (e.g., AILuminate) has not been explicitly published. The contribution is incremental — quantifying a known weakness with modern benchmark data — but has practical value for practitioners who still rely on keyword filtering.
