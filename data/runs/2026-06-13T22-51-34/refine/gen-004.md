# Research Question

Does the chain-of-thought monitoring advantage over output-only deception detection (reported on GPT-5) replicate across open-weight reasoning model families, or is the size of the CoT-minus-output gap architecture/training-recipe specific?

# Approach Outline

Hold the deception-detection task and the monitor prompts fixed; vary only the actor model family. Select 3-5 open reasoning models that expose thinking tokens (e.g., DeepSeek-R1-distill, Qwen/QwQ, a Llama reasoning variant) plus 1-2 closed models. Build a small labeled set of prompts that induce deceptive/rule-breaking reasoning vs honest reasoning. For each actor, collect both output-only and full CoT+output. Build two cheap LLM-judge monitors (one sees output only, one sees CoT+output) with fixed rubrics emitting a suspicion score. Compute precision, recall, and AUC for each monitor per family, then plot the CoT-minus-output gap by family. Open models run via API or one GPU; a few hours of inference. Analysis is precision/recall/AUC in Python.

# Proposed First Experiments

Run the full pipeline end-to-end on a single open model (e.g., DeepSeek-R1-distill) over ~50 labeled prompts, producing output-only and CoT monitor scores and computing the per-family gap. Success criterion: both monitors produce valid AUCs above chance and the CoT monitor's AUC is measurably different from output-only (in either direction), confirming labels, transcripts, and monitors all work before scaling to all families.

# Theory of Impact Chain

Research output: a per-family table of how much CoT monitoring beats output-only on open models. Intermediate: the community learns whether the headline 'read the CoT' result is portable or proprietary-model-specific. Reduced catastrophic risk: if labs and deployers deploy CoT monitoring on a family where the advantage is small or absent, they would otherwise have false confidence; quantifying portability prevents safety cases that assume a monitorability premium that doesn't actually exist on the model being deployed.

# Strength Rationale

Excellent beginner project: monitors are LLM-judge prompts with no training, open reasoning models are accessible via API or Colab Pro, and the whole study is 'hold everything fixed, vary the model family.' Statistics are standard precision/recall/AUC. The replication framing makes scope and success obvious. Note: this overlaps strongly with gen-005 and gen-007; a beginner should pick one of the three. Fits 30 hours.

# Alternative Framings

- Faithfulness-correlation angle: correlate each family's CoT advantage with its published CoT-faithfulness score to test whether faithfulness explains the gap (this merges toward gen-007).
- Difficulty angle: hold family fixed but vary task difficulty/subtlety of the deception to see where the CoT advantage is largest.
