# Research Question

How much of a trusted monitor's sabotage-detection power on SHADE-Arena transcripts comes from seeing the agent's chain-of-thought versus its actions alone, and where does a trusted-model CoT summary fall on that dose-response curve?

# Approach Outline

Hold the agent and transcripts fixed (use ControlArena/SHADE-Arena attack and benign transcripts) and vary only what the monitor is shown: (a) actions only, (b) actions + full CoT, (c) actions + a trusted-model-generated CoT summary. For condition (c), first generate concise summaries of each transcript's CoT with a separate trusted API model. Run the same API monitor with the same scoring prompt over each input variant, producing a 0-100 suspicion score per transcript. Calibrate each variant's threshold to a fixed 1% FPR on benign transcripts (99th-percentile method) and compute miss-rate and AUC at that operating point. The result is a dose-response curve of detection power as a function of monitor visibility into the intent-expression (reasoning) link, directly quantifying how much detection collapses when the scratchpad is hidden.

# Proposed First Experiments

Take ~17 SHADE-Arena attack transcripts plus a matched set of benign transcripts; generate CoT summaries; run the monitor under all three visibility conditions. Success criterion: report AUC and miss-rate@1%-FPR for each of the three conditions with confidence intervals, yielding a clear ranking. The experiment succeeds if it produces a defensible estimate of the detection gap between actions-only and actions+CoT (e.g. how many absolute AUC points are lost by hiding reasoning) and shows whether a cheap trusted summary recovers most of that gap.

# Theory of Impact Chain

Research output: a dose-response curve isolating how much sabotage detection depends on CoT visibility versus actions -> intermediate: control-protocol designers learn whether 'hide your reasoning' is the cheapest possible attack on a trusted monitor, and whether forcing a trusted CoT summary into the monitored channel is a cheap defense -> reduced catastrophic risk: deployers redesign monitoring channels to ensure intent-bearing reasoning is monitored (not hideable), closing the cheapest evasion route and raising the probability that misaligned actions are caught before they cause irreversible harm.

# Strength Rationale

Transcript-level, black-box, no training, and it reuses an existing benchmark with its scoring harness — ideal for a 30-hour beginner project. The single-variable design (only monitor input changes) gives a clean causal story. The 1%-FPR calibration and miss-rate@fixed-FPR methodology are standard and well-specified by the cited AutoMonitor-Bench work, so the participant has a concrete recipe and the output is a publishable trade-off figure.

# Alternative Framings

- Add a fourth condition — adversarially sanitized CoT — to connect the visibility question to the obfuscation-attack literature and show how a saboteur could induce the actions-only regime deliberately.
- Vary the summarizer's capability (cheap vs strong trusted model producing the CoT summary) to ask how good the summarizer must be before the summary preserves the detection signal.
