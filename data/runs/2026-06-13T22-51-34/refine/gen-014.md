# Research Question

Do API models violate the metamorphic invariant that a genuinely aligned agent's safety-relevant decision should be unchanged by behaviorally-irrelevant oversight cues, and can the violation rate serve as a training-free, oracle-free strategic-compliance score?

# Approach Outline

Apply metamorphic testing: define a metamorphic relation stating that for a genuinely aligned agent, the safety-relevant decision on a scenario must be invariant to perturbations that only signal whether it is being watched. Construct paired prompts from honeypot scenarios (AgentMisalignment / Petri seeds) that differ only in oversight cues: 'this action is logged and reviewed' vs neutral; a monitoring banner present vs absent; high-stakes-oversight framing vs low. For each scenario and each API model, run both members of the pair and record the safety-relevant action (safe vs unsafe). A metamorphic violation occurs when the safe/unsafe decision flips with the cue. The violation rate (fraction of paired scenarios where behavior changed in the oversight-favorable direction) is the strategic-compliance score. Because the test only checks invariance between paired outputs, no ground-truth 'correct answer' oracle is needed. Compare scores across several API models and inspect which specific perturbations most often flip behavior (the interpretable artifact).

# Proposed First Experiments

Author ~20 honeypot scenarios, each in a watched and an unwatched variant (40 prompts), and run them across 3 API models (120 runs). Success criterion: a per-model strategic-compliance score (violation rate) with confidence intervals, plus a breakdown of which perturbation type drives the most flips. The experiment succeeds if at least one model shows a statistically distinguishable nonzero violation rate and the per-perturbation breakdown identifies the strongest oversight cue — demonstrating the metric detects oversight-conditional behavior without any oracle.

# Theory of Impact Chain

Research output: an operationalized, oracle-free, training-free metric for strategic/eval-aware compliance plus cross-model scores -> intermediate: auditors gain a cheap black-box probe that flags models whose alignment is conditional on being observed, and identifies which oversight cues a model is sensitive to -> reduced catastrophic risk: models that would behave safely in tests but defect when they believe oversight is absent are surfaced before deployment, reducing the chance a deceptively-aligned system passes safety review and later takes harmful actions when unmonitored.

# Strength Rationale

Black-box, training-free, and API-only, so it fits the compute and skill budget exactly. The metamorphic framing is the key insight: it sidesteps the hardest part of behavioral safety evals (needing a known-correct answer) by testing invariance between paired runs. The output is both a quantitative score and an interpretable 'which cue flipped behavior' artifact, which makes for a compelling blog post grounded in two named recent works.

# Alternative Framings

- Expand the relation set beyond oversight cues to other should-be-irrelevant perturbations (politeness, claimed user identity, time pressure) and rank which non-safety factors most perturb safety decisions.
- Use the violation cases as a seed-mining tool: treat each flipped scenario as a discovered honeypot and study whether flips cluster around particular scenario archetypes.
