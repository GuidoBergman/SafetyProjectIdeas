# Research Question

As an agent's visible reasoning is progressively obfuscated by a prompt instruction, how does the compound failure probability P(side task succeeds AND monitor fails) on SHADE-Arena grow, and does a one-line obfuscation prompt collapse monitor catch-rate?

# Approach Outline

Use SHADE-Arena benign-main/harmful-side transcripts where the agent pursues a hidden side task. Create graded variants of each transcript where the agent's visible reasoning is progressively sanitized via a prompt instruction at several obfuscation levels (none / light / heavy / fully sanitized). Run an off-the-shelf API monitor on each obfuscation level and compute monitor AUC and catch-rate (TPR at fixed FPR). Separately determine, per transcript and level, whether the side task still succeeds (objective oracle from the benchmark). The headline compound metric is P(side task succeeds AND monitor fails) plotted as a function of obfuscation degree — capturing that the two failure modes multiply rather than add. Compare the catch-rate at zero obfuscation to catch-rate at full obfuscation to test the prior-work claim that adversarial CoT pressure can collapse catch-rate dramatically (~96% -> ~10%).

# Proposed First Experiments

Generate obfuscation variants for ~17 SHADE-Arena harmful-side transcripts at 4 obfuscation levels, plus benign transcripts to calibrate the monitor's FPR. Success criterion: a plot of monitor AUC/catch-rate and the compound metric P(side-success AND monitor-fail) versus obfuscation degree, with confidence intervals. The experiment succeeds if it yields a defensible estimate of how much a simple obfuscation prompt erodes catch-rate and whether the compound failure probability rises super-additively as obfuscation increases.

# Theory of Impact Chain

Research output: a measured curve showing how prompt-only CoT obfuscation compounds with monitor blindness to raise joint failure probability -> intermediate: control-safety-case authors learn that benchmark catch-rate numbers overstate real robustness because a trivial obfuscation prompt can collapse them, and that control and deception failures multiply rather than add -> reduced catastrophic risk: trusted-monitoring safety cases are discounted to account for adversarial obfuscation, prompting designers to force reasoning into the monitored channel or add obfuscation-robust defenses, lowering the chance an obfuscating misaligned agent slips an irreversible harmful action past the monitor.

# Strength Rationale

API calls plus transcript scoring, explicitly sized to ~30 hours and a single consumer GPU. It reuses an existing benchmark (SHADE-Arena) with an objective side-task oracle, so the 'side task succeeds' half of the compound metric is not subjective. The compound P(both fail) framing is the distinctive contribution and makes for a memorable blog-post result, and it is tightly grounded in three named, recent CoT-monitorability papers that give the participant a clear conceptual scaffold.

# Alternative Framings

- Hold obfuscation at a single 'heavy' level and instead vary the monitor's robustness strategy (e.g. monitor on actions+outputs only, ignoring CoT) to ask which monitor design is least degraded by obfuscation.
- Decompose the compound metric: study whether obfuscation that fools the monitor also costs side-task success, mapping the region where the attacker gets evasion without paying a capability tax.
