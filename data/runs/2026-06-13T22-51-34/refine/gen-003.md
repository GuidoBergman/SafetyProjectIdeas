# Research Question

How does the held-out accuracy/AUC of a linear sycophancy activation probe degrade as the labeled training set shrinks, and where is the 'knee' below which it becomes unreliable as a runtime monitor?

# Approach Outline

Pick one open 7-8B model exposing hidden states (e.g., a Llama-3-8B or Qwen-7B instruct variant). Use a public sycophancy dataset of paired sycophantic/non-sycophantic responses. Extract mid-layer mean-over-response-tokens activations for each example (one forward pass each; <1h on a single GPU or Colab Pro). Train a logistic-regression probe (sklearn) on a fixed held-out split, sweeping labeled examples per class in {5, 10, 25, 50, 100, 250}, averaging over several random subsamples per size to get error bars. Plot held-out accuracy and AUC vs label count to locate the knee. Secondary: take the probe trained at the largest label count and test zero-shot transfer to a related behavior (e.g., flattery vs factual deference) to produce a small transfer table. Deliverable: a label-efficiency curve + transfer table.

# Proposed First Experiments

Reproduce the full-data baseline first: extract activations for the whole training set, train one probe, and confirm held-out accuracy lands in the published ~73-88% range. Success criterion: baseline probe reaches >=73% held-out accuracy, validating activation extraction and labeling. Only then run the label-count sweep. This de-risks the pipeline (correct layer, correct pooling) before the variation study.

# Theory of Impact Chain

Research output: a curve showing minimum labels needed for a usable sycophancy probe plus evidence on cross-behavior transfer. Intermediate: safety teams learn whether activation monitoring can be stood up cheaply for newly-discovered misbehaviors (few labels, fast) or is only a lab-scale technique. Reduced catastrophic risk: if probes work with tens of labels and transfer, runtime activation monitoring becomes a realistic always-on control that can catch emerging deceptive/sycophantic behaviors in deployed models before they cause harm; if not, the field avoids over-relying on a monitor that silently fails on novel behaviors.

# Strength Rationale

Strong beginner fit: the only ML is hidden-state extraction plus sklearn logistic regression, both well-documented; one 7-8B model runs on Colab Pro/Runpod; activation extraction takes under an hour. It is a variation study (vary one knob: label count) so the design is clean and the result is a single legible curve. Replicating a known baseline first gives a safety net. Fits 30 hours comfortably.

# Alternative Framings

- Active-learning angle: instead of random subsampling, test whether choosing which few examples to label (e.g., diverse or uncertain ones) beats random at small label counts.
- Cross-model angle: hold label count fixed and vary the base model (two 7-8B models) to see whether the knee location is model-dependent.
