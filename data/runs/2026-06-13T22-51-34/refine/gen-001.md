# Research Question

How much does defensive paraphrasing of a model's chain-of-thought degrade a trusted monitor's ability to detect deception, measured as the drop in true-positive rate at a fixed 2-5% false-positive rate across increasing paraphrase strengths?

# Approach Outline

Assemble a small labeled set of paired deceptive vs honest reasoning traces. Cheapest route: reuse public CoT Red-Handed (arXiv:2505.23575) transcripts; fallback: generate ~100-200 paired traces via a single API model on a sabotage-vs-benign coding task (prompt the actor to either solve honestly or insert a subtle backdoor while reasoning). Define three paraphrase strengths as distinct system prompts to a paraphraser model: (1) light surface reword, (2) aggressive reword, (3) epistemic-stance-preserving reword that is instructed to keep hedging/uncertainty/intent cues. For each condition (raw + 3 paraphrases) run one cheap trusted LLM-judge monitor that outputs a 0-100 suspicion score using a fixed rubric. Sweep a threshold on honest traces to fix FPR at 2% and 5%, then read off TPR for deceptive traces in each condition. Everything is API calls: paraphrase = 1 call/trace, monitor = 1 call/trace. Deliverable: a 'paraphrase tax' curve (TPR vs paraphrase strength) plus a table showing whether stance-preserving paraphrase retains more signal than aggressive paraphrase.

# Proposed First Experiments

Build the minimal pipeline on ~60 traces (30 honest, 30 deceptive) and two conditions only: raw CoT vs aggressive paraphrase. Score both with the monitor, calibrate threshold to 5% FPR on honest, and compare TPR. Success criterion: the pipeline produces a calibrated threshold and a measurable TPR for each condition, and raw-CoT TPR is clearly above chance (e.g., >0.5 at 5% FPR), confirming the monitor and labels work before scaling to all 4 conditions and 200 traces.

# Theory of Impact Chain

Research output: a quantified paraphrase-vs-deception-recall trade-off curve for trusted CoT monitoring. Intermediate: AI control practitioners learn whether stacking two recommended defenses (paraphrasing + CoT monitoring) silently cancels, and gain a rule for ordering/tuning them (e.g., monitor raw CoT before paraphrasing, or use stance-preserving paraphrase). Reduced catastrophic risk: deployed oversight protocols on frontier agents retain deception-detection power instead of having a hidden hole that lets a scheming model slip sabotage past a monitor that was unknowingly blinded by an upstream defense.

# Strength Rationale

Ideal beginner scope: no model internals, no training, no GPU strictly required. Every component is a single API call (paraphrase, monitor) and the analysis is threshold calibration plus a TPR/FPR curve achievable in pandas. The result is a clean, legible curve that makes a publishable blog post, and there is a public dataset (CoT Red-Handed) to remove data-generation risk. Fits 30 hours: ~8h data prep, ~8h pipeline, ~8h experiments, ~6h writeup.

# Alternative Framings

- Frame it as defense-ordering: does paraphrasing-then-monitoring vs monitoring-then-paraphrasing change the safety/robustness trade-off, holding the paraphraser fixed?
- Frame it as a paraphraser-design study: which paraphrase instructions best preserve deception signal while still defeating prompt-injection, turning the work into a recommendation for how to write the paraphraser prompt.
