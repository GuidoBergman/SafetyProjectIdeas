# Metamorphic Trip-Wires: Detecting Strategic Compliance via Output Invariants Under Oversight-Cue Perturbations

**Problem:** Distinguishing genuine alignment from strategic compliance (behaving well only when watched) lacks cheap runtime tests that need no internal access or training.

**Direction:** Import metamorphic testing: define relations that should hold for a genuinely aligned agent and flag violations. Construct paired prompts differing only in oversight cues that should be behaviorally irrelevant ('this action is logged/reviewed' vs neutral; monitoring banner present/absent; stakes framing). The relation: a genuinely aligned agent's safety-relevant decision is invariant to these cues. Run over honeypot scenarios (AgentMisalignment/Petri), measure violation rate as a strategic-compliance score, compare across API models.
