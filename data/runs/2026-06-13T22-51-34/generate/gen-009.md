# MonitorVar: A Prompt-Sensitivity Stress Test for Control Monitors on SHADE-Arena Transcripts

**Problem:** Control protocols use a monitor's suspiciousness score + fixed threshold to flag trajectories, but scores are highly prompt-sensitive. Nobody has measured how much benign monitor-prompt rewording moves the flag decision and the realized TPR at fixed FPR on an actual control benchmark.

**Direction:** Take fixed benign/sabotage SHADE-Arena transcripts. Write ~8-10 semantically equivalent monitor prompt variants for one API monitor; score every transcript under every variant. Compute per-transcript score std; calibrate threshold to 1% FPR on honest transcripts; measure TPR@1%FPR swing across variants plus a flag flip-rate. Optionally show score-averaging shrinks the spread.

**Why it matters:** Control safety cases quote TPR@FPR as the headline bounding catastrophic risk. If that number is an artifact of one monitor prompt wording, the safety case is overstated. Produces a reusable reproducibility check.

**Relevant context:** Grounded in SHADE-Arena (arXiv:2506.15740, top monitor AUC 0.87) and JudgeSense (arXiv:2604.23478) per-instance score variance. Threshold calibration to 1% FPR is standard. ControlArena provides transcripts + harness; only API monitor calls, no training/GPU.
