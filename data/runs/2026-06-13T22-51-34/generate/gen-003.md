# How Few Labels Does a Sycophancy Probe Need? A Label-Efficiency Variation

**Problem:** Activation probes detect sycophancy (~73-88% accuracy) but are usually trained on large labeled sets. For a practical runtime monitor, fitting on a new behavior must be cheap. How probe accuracy degrades with very few labeled examples is largely uncharacterized.

**Direction:** Replicate a linear sycophancy probe and vary only the labeled training set size. On a 7-8B model, extract mid-layer mean-response activations on a public sycophancy dataset; train logistic-regression probes sweeping examples per class (5,10,25,50,100,250). Plot held-out accuracy/AUC vs label count to find the knee; secondarily test transfer to a related behavior.

**Why it matters:** Runtime monitors must spin up for newly discovered misbehaviors with few labels. Knowing how many labels are needed (and whether they transfer) tells whether activation monitoring is realistic runtime control or lab-only.
