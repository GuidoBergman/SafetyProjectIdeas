# When the Scratchpad Goes Dark: Measuring How CoT Obfuscation Compounds Monitor Blindness

**Problem:** Two failure modes compound: (1) a control failure where the trusted monitor misses a misaligned action, and (2) a deception failure where the model strategically obscures its reasoning. SHADE-Arena shows side-task success depends on a hidden scratchpad, but the joint degradation has not been cheaply quantified.

**Direction:** Use SHADE-Arena benign-main/harmful-side transcripts. Create graded variants where the agent's visible reasoning is progressively sanitized via a prompt instruction. Run an off-the-shelf API monitor on each obfuscation level; plot monitor AUC/catch-rate vs obfuscation degree. The compound metric is P(side task succeeds AND monitor fails) as a function of obfuscation. No training.

**Why it matters:** Control is safe only if monitor catch-rate is robust. If a one-line obfuscation prompt collapses catch-rate (prior work: ~96%->~10% under adversarial CoT pressure), the trusted-monitoring safety case is weaker than benchmark numbers suggest; the compound framing shows failures multiply not add.

**Relevant context:** Grounded in SHADE-Arena (arXiv:2506.15740, AUC 0.87, hidden-scratchpad reliance), Monitoring Reasoning Models and the Risks of Promoting Obfuscation (arXiv:2503.11926), CoT Monitorability: A New and Fragile Opportunity (arXiv:2507.11473). API calls + transcript scoring; fits ~30h.
