How well trusted monitoring transfers to a non-code domain (a subtle factual error or hidden instruction in summarization/extraction) is unclear.

**Direction:** Use ControlArena's trusted-monitoring scaffolding but swap code for a small text suite: benign main task (summarize/extract) + covert side task (insert one false fact or hidden instruction).
