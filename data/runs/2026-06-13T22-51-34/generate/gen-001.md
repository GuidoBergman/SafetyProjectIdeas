# Paraphrase-Robust CoT Monitoring: Does Defensive Paraphrasing of Reasoning Traces Preserve Deception Signals?

**Problem:** CoT monitoring is more informative than output-only (GPT-5 card), but paraphrasing model outputs is a recommended anti-collusion/anti-injection defense. Paraphrasing may strip the subtle linguistic cues that make CoT informative for deception detection. The trade-off is unmeasured for a trusted CoT monitor.

**Direction:** Take labeled deceptive vs honest reasoning traces (CoT Red-Handed transcripts or API-generated paired traces on a sabotage-vs-benign coding task). Run a cheap trusted monitor over raw CoT vs CoT at 3 paraphrase strengths; measure monitor TPR at fixed 2-5% FPR. Produce a quantified 'paraphrase tax' curve and test whether epistemic-stance-preserving paraphrase retains signal.

**Why it matters:** Paraphrasing is applied to the very text the monitor relies on. If aggressive paraphrasing halves deception recall, deployed protocols may combine two safety techniques that cancel out. A clean trade-off curve informs how to order and tune these defenses.

**Relevant context:** Grounded in CoT Red-Handed (arXiv:2505.23575), Redwood untrusted-monitoring paraphrasing defense, and Adaptive Attacks on Trusted Monitors (arXiv:2510.09462). Beginner-feasible: paraphrasing is one API call, monitor is prompt-and-score, pipeline is classification-with-threshold. No internals/training.
