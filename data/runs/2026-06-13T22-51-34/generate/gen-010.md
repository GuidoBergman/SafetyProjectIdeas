# Cheap-Ensemble Frontier: How Many Small Monitors Equal One Big Monitor on SHADE-Arena?

**Problem:** Diverse cheap monitor ensembles can match an expensive monitor, but there is no clean cost-vs-detection frontier a practitioner could use to pick a budget: given a fixed cost per transcript, what monitoring config gives the best TPR@1%FPR?

**Direction:** On SHADE-Arena transcripts, score with one strong monitor and several cheap monitors. Try mean/max/majority-vote aggregation; compute per-transcript API cost from tokens and TPR@1%FPR. Plot a detection-vs-cost Pareto frontier and add a diversity analysis (pairwise correlation of cheap monitors; do low-correlation picks improve the frontier?).

**Why it matters:** Control monitoring runs on every action, so cost is first-order. A concrete cost-vs-detection frontier turns 'ensembles help' into an actionable recipe and a cheap baseline to beat.

**Relevant context:** Builds on Ensemble Monitoring for AI Control (arXiv:2605.15377) and weak-to-strong monitoring (arXiv:2508.19461). SHADE-Arena labeled transcripts via ControlArena; cost from token usage; aggregation is basic Python; single GPU or pure API.
