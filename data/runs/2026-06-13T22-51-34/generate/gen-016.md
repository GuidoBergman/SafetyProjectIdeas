# Reversibility Triage: Can a Cheap Classifier Gate Only the Irreversible Actions for Human Review?

**Problem:** The control chain ends with action -> irreversibility, and the catastrophic risk is the irreversible harmful action, yet runtime controls usually monitor all actions uniformly. The under-studied earlier link is the irreversibility judgment: can a system cheaply classify whether a proposed action is reversible vs irreversible so scarce monitor/HITL budget is spent on the rare irreversible tail?

**Direction:** Take tool-call traces from ControlArena (BashBench, banking/Agent-Dojo). Hand-label a few hundred tool calls reversible/irreversible/ambiguous via a 0-2 rubric. Build a cheap LLM-API classifier predicting reversibility from the call+args; measure precision/recall on the irreversible class. Simulate a gating protocol routing only predicted-irreversible actions to an expensive monitor; measure compute saved vs truly-irreversible actions that slip through.

**Why it matters:** Reversibility determines whether a missed action is catastrophic or merely annoying. A modest classifier that reliably flags the irreversible tail concentrates human/monitor budget where it prevents irreversible harm — attacking the last, most consequential link.

**Relevant context:** Reversibility/undo taxonomies (Partnership on AI real-time failure detection; STRATUS rollback arXiv:2510.14503); cost-constrained monitor combination (arXiv:2507.15886). ControlArena provides genuinely irreversible operations. Mostly API + analysis.
