# How Much Does Hiding the Scratchpad Help a Saboteur? Measuring the CoT-Visibility Gap in the Monitor's Detection Link

**Problem:** In SHADE-Arena, sabotage success 'relies heavily on a hidden scratchpad not visible to the monitor,' and the top monitor reached AUC 0.87. This isolates an under-studied link: intent expression (in reasoning) -> monitor detection. Nobody simple has quantified how much detection power is lost as a function of what the monitor is shown.

**Direction:** Use ControlArena/SHADE-Arena transcripts. Hold the agent fixed; vary only monitor input: (a) actions only, (b) actions + full CoT, (c) actions + a trusted-model CoT summary. Run the same API monitor over each and compute miss-rate/AUC at fixed 1% FPR to get a dose-response curve of detection vs visibility into the intent-expression link.

**Why it matters:** The control safety case leans on monitors catching misaligned actions. If detection is dominated by CoT visibility rather than the action, 'hide your reasoning' is the cheapest attack and designers should force reasoning into the monitored channel.

**Relevant context:** SHADE-Arena (arXiv:2506.15740) reports the hidden-scratchpad dependence and 0.87 AUC; ControlArena provides the setting + monitor scaffolding. Trusted-summary defense and miss-rate@fixed-FPR from AutoMonitor-Bench (arXiv:2601.05752). Black-box, transcript-level, no training.
