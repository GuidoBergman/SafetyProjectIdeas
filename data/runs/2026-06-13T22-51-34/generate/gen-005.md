# Does CoT Monitoring Survive Crossing Model Families? A Black-Box Replication of the GPT-5 Card Effect

**Problem:** The GPT-5 card's CoT-monitoring advantage was measured on one model family. Whether it holds when actor and monitor come from different labs, or is partly same-family stylistic familiarity, is unknown.

**Direction:** Use ControlArena's trusted-monitoring setup on a small honeypot/deception task. Have 3-4 API actor families produce action-only and CoT+action transcripts on a benign-main + covert-side task. Run one fixed monitor giving 0-100 suspicion; compare detection AUC/recall for CoT vs output-only, broken down by actor family.

**Why it matters:** If the CoT premium is family-dependent, safety cases assuming 'we can read the CoT' may not transfer to third-party/open-weight models. Quantifying which pairings preserve the premium tells the field where CoT monitoring can be relied upon.

**Relevant context:** Grounded in GPT-5 card, CoT Red-Handed (arXiv:2505.23575), Can Reasoning Models Obfuscate Reasoning (arXiv:2510.19851). ControlArena provides trusted-monitoring scaffolding with 0-100 scores; SHADE-Arena provides benign+side task pairs; runnable via API, no training.
