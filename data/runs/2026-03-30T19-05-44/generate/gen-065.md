# ROC-Based Optimal Threshold Selection for AI Safety Classifiers

**Problem:** AI content moderation and safety classifiers require a classification threshold but thresholds are often chosen arbitrarily (e.g., 0.5). Clinical diagnostic methodology has developed principled ROC-curve-based threshold selection that balances sensitivity and specificity based on the relative costs of false positives vs. false negatives.

**Direction:** Apply diagnostic accuracy methods to AI safety classifiers: generate ROC curves for 3–5 open-source safety classifiers (LlamaGuard, ShieldGemma, etc.) on shared evaluation sets. Use Youden's J index to identify the theoretically optimal threshold. Model asymmetric cost scenarios (e.g., a false negative—missing a harmful output—is 10x more costly than a false positive) and derive cost-weighted optimal thresholds. Compare the recommended thresholds to the defaults used in published evaluations. Implement in R (pROC package).

**Why it matters:** Diagnostic accuracy methods from clinical psychology provide a rigorous, interpretable framework for safety classifier threshold selection that is completely absent from current AI safety practice. Choosing the wrong threshold systematically over- or under-detects safety violations, with real-world consequences.

**Relevant context:** ROC analysis is standard in clinical diagnostics. pROC R package implements full ROC analysis including optimal threshold selection and AUC confidence intervals. Shared evaluation sets exist (PromptBench, evaluation harnesses). Several open safety classifiers release probability scores enabling ROC computation. No model training required.
