# tinyBenchmarks Failure Modes: When Does IRT-Based Item Selection Break Under Distribution Shift?

**Problem:** tinyBenchmarks (Polo et al. 2024) showed 100 IRT-selected MMLU items suffice to estimate full-benchmark performance (correlation ~0.99). The authors note IRT-based anchors are 'only slightly affected' by distribution shift, but 'slightly' is unquantified. We do not know the conditions under which estimation error becomes practically unacceptable.

**Direction:** Using the public tinyBenchmarks data and Open LLM Leaderboard scores, systematically simulate distribution shift: hold out model subgroups (e.g., only instruction-tuned models, only models <7B, only code-specialised models) from the calibration set and measure estimation error on the held-out group. Plot RMSE and rank-correlation as a function of how different the held-out group is from calibration. Identify the threshold at which the 100-item estimate degrades beyond a pre-specified tolerance (e.g., >5 rank positions).

**Why it matters:** Safety evaluators who adopt sparse benchmarks need to know when those benchmarks fail. If IRT-CAT degrades for novel model architectures, early-warning safety evaluations of frontier models may be systematically miscalibrated.

**Relevant context:** tinyBenchmarks (arXiv 2402.14992); tinyMMLU dataset on HuggingFace; IRT calibration in R (mirt package); Open LLM Leaderboard for model metadata.
