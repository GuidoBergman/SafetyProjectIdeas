# Reliable Noise: Generalizability Theory Exposes Oversight Failures in Multi-Agent Evaluation

**Problem:** Multi-agent AI evaluation benchmarks measure task completion (Failure B10 — oversight failure) using metrics that confound multiple sources of variance: the individual agent's safety behavior, the coordination protocol, the task domain, and the evaluator agent's judgment. Without a proper measurement design, it is impossible to know whether a 'safe' multi-agent system outcome reflects safe component agents or lucky coordination. G-theory (Failure A — measurement design gap) provides the framework to partition these variance sources, but it has not been applied to multi-agent safety evaluation.

**Direction:** Identify a published multi-agent evaluation benchmark (e.g., MultiAgentBench or an AWS multi-agent evaluation dataset). Design or select tasks that cross: (a) multiple agent roles, (b) multiple task types, (c) multiple coordination protocols. Apply G-theory in R to decompose outcome variance into: agent, task, coordination protocol, and their interactions. Identify which facets drive variance in safety-relevant outcomes (e.g., harmful action rates, deceptive coordination). Use D-study to estimate the number of tasks/agents/protocols needed to achieve reliable safety estimates.

**Why it matters:** Multi-agent AI deployment is growing rapidly. If we cannot partition safety variance to its sources, we cannot improve it — a system failure might be an agent failure, a coordination failure, or an evaluation failure. G-theory provides the conceptual and statistical tools to make this distinction.

**Relevant context:** MultiAgentBench (2503.01935) provides a published evaluation framework. AWS multi-agent evaluation documents 37% lab-to-production performance gap. G-theory applied to LLMs noted as emerging in 2024–2025 psychometric literature. Oversight failures in multi-agent systems are a named safety concern in the alignment literature.
