# DIF Analysis of Safety Benchmark Items: Detecting Items That Behave Differently Across Harm Severity Levels

**Problem:** P5: Safety benchmarks use binary pass/fail losing severity info

**Direction:** Treat harm severity as a grouping variable and apply DIF analysis to safety benchmark items, testing whether item difficulty parameters differ across low-, medium-, and high-severity prompt categories for models with the same aggregate safety score.

**Why it matters:** If binary safety benchmarks conflate items targeting mild nuisance harms with items targeting catastrophic harms, DIF analysis would reveal this. Items showing DIF across severity groups are fundamentally measuring different safety constructs despite being collapsed into a single pass/fail score.

**Relevant context:** DIF analysis using severity as a grouping variable is conceptually analogous to standard DIF by demographic group. The difR R package supports this. Existing safety datasets with severity annotations (arxiv 2503.05609 on severity responsiveness) provide the necessary data. This reframing of DIF for severity is novel but methodologically straightforward.
