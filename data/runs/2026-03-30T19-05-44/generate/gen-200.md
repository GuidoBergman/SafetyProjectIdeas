# Discriminant Validity: Is 'Safety' Distinct from 'Capability' in LLM Evaluation?

**Problem:** Establish construct validity for AI safety evaluation

**Direction:** Collect safety scores and capability scores (MMLU, HellaSwag, ARC) for a common set of 30+ models. Test discriminant validity using the multitrait-multimethod (MTMM) framework: compute the average variance extracted (AVE) for safety vs. capability factors in a CFA model and verify that the AVE for each factor exceeds the squared inter-factor correlation. Test whether the safety–capability correlation is significantly below 1.0 (i.e., they are empirically distinguishable constructs).

**Why it matters:** A widespread assumption in AI safety is that safety and capability are separable. If safety benchmarks measure something that is entirely redundant with capability benchmarks, then 'safety' is not a distinct construct—it is just capability by another name. Discriminant validity testing provides the empirical answer.

**Relevant context:** Several papers have noted a capability–safety tradeoff or correlation, but none has applied formal discriminant validity testing from psychometrics. The MTMM approach and AVE calculation are standard psychometric tools that can be implemented in R with lavaan. Open LLM Leaderboard provides both capability and safety data for many models.
