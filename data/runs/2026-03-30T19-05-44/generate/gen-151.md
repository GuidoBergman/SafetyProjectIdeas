# Monoculture Hides in Factor Structure: How Homogeneous Outputs Collapse Safety Benchmarks

**Problem:** AI model output monoculture (Failure B7) — the convergence of multiple models toward near-identical outputs — creates a measurement collapse in safety benchmarks (related to ceiling effects, Failure A4, and low construct validity, Failure A1). If all frontier models produce nearly identical outputs, benchmark score distributions lose variance, making it impossible to discriminate between models. Worse, if the monoculture is itself unsafe (e.g., all models fail similarly on novel jailbreaks), the loss of variance hides a shared vulnerability behind apparent consensus.

**Direction:** Select outputs from 5–8 frontier models on a set of safety benchmark items. Compute pairwise output similarity (cosine similarity on embeddings, or string-level overlap). Apply factor analysis in R: do model responses load on a single factor (monoculture) or on multiple independent factors (genuine diversity)? Test whether factor structure predicts benchmark score variance: does a one-factor solution (monoculture) correlate with reduced score spread and reduced ability to rank models? Supplement with a DIF analysis treating model as a 'group' variable — low DIF across models confirms monoculture.

**Why it matters:** Benchmark diversity across models is a prerequisite for ranking and discriminating them. Monoculture that collapses into a single factor makes safety evaluation a consensus-checking exercise rather than an independent measurement. Factor-analytic documentation of monoculture provides a principled basis for demanding more diverse evaluation sets.

**Relevant context:** LLM output monoculture documented (cosine similarity 0.86–0.87 across distinct model families). Vendi Score as diversity metric published.
