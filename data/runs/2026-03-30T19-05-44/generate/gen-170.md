# Anchoring Vignettes for Cross-Model Safety Score Comparability: Correcting for Response Scale Differences Between Model Families

**Problem:** Different model families (Llama, Claude, Gemini, GPT) may use fundamentally different 'scales' when complying or refusing—what constitutes a borderline refusal for one model may be a clear refusal for another. Safety scores may reflect response calibration differences rather than genuine behavioral differences. This is analogous to the survey methodology problem where respondents from different cultures interpret Likert scales differently.

**Direction:** Design a set of 'anchoring vignettes'—fixed borderline scenarios with objectively defined safety content where the correct response is unambiguous and stable across model types (e.g., clearly benign requests that should always be answered, clearly harmful requests that should always be refused). Administer these vignettes alongside a standard safety benchmark to a set of models. Use the vignette responses to rescale (anchor-correct) model safety scores, adjusting for response style differences. Compare model rankings before and after anchoring-correction. Use R to implement the CHOPIT model or simpler linear rescaling.

**Why it matters:** Anchoring vignettes are the standard survey methodology solution to cross-group incomparability (Gary King's Harvard group developed this for cross-national health surveys). If models have systematically different response thresholds, anchoring correction would make cross-model safety comparisons valid for the first time. The method requires only benchmark administration and R analysis—no model training.

**Relevant context:** Gary King's anchoring vignette methodology is well-established (Harvard). The method has been applied to cross-cultural personality measurement (Frontiers in Psychology 2018). The CHOPIT model has R implementations. AI safety benchmarks are known to be sensitive to prompt format and framing. This specific application to cross-model safety calibration appears unpublished.
