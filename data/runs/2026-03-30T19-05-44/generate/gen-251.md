# Measuring Prompt Sensitivity as Differential Item Functioning Across Prompt Variants

**Problem:** P2: Prompt sensitivity destroys measurement reliability (76-point swings)

**Direction:** Treat prompt variant as a 'group' variable and apply DIF analysis to detect which safety benchmark items are most sensitive to prompt rephrasing, identifying whether sensitivity is uniform or interacts with item difficulty.

**Why it matters:** DIF analysis can distinguish items that are genuinely prompt-sensitive (biased items) from stable items. This enables benchmark developers to flag and revise prompt-fragile items rather than discarding entire benchmarks, and identifies which prompt formats produce the most equitable measurement.

**Relevant context:** DIF research demonstrates that linguistic features drive item sensitivity across groups. A 2025 Wiley study used LLMs to predict DIF from item text. Treating prompt variant as a 'group' variable in Mantel-Haenszel DIF tests is a direct, coding-light analysis feasible in R (difR package) using existing benchmark response datasets where multiple prompt variants were tested.
