# DIF Analysis for Contamination Detection: Which Benchmark Items Show Architecture-Specific Anomalies

**Problem:** P7: Data contamination inflates benchmark scores undetectably

**Direction:** Apply DIF analysis treating model family/training corpus as the grouping variable, testing whether specific benchmark items show unexpected inter-group performance differences consistent with selective contamination rather than genuine capability differences.

**Why it matters:** If a specific model family performs unexpectedly well on a subset of items even after controlling for overall ability, this pattern—detectable via DIF—is consistent with those items being in the training data. DIF analysis provides a statistically principled contamination screen that does not require access to training corpora.

**Relevant context:** DIF is designed to detect items that function differently across groups with the same underlying ability. Treating model family as the grouping variable for DIF in the context of benchmark contamination is conceptually novel. The difR R package supports Mantel-Haenszel and logistic regression DIF methods on binary item responses.
