# What Distinguishes Valid from Invalid Benchmarks? A Meta-Analysis of Validity Indicators

**Problem:** Paper 14 (2025) found only 53.4% of 445 benchmarks present any validity evidence and identified eight recommendations. But the paper does not empirically test which validity indicators most strongly predict construct-level reliability or criterion validity. The causal ordering — which validity practices lead to better measurement — is unknown.

**Direction:** Using the Paper 14 benchmark dataset (if public) or a replication coding of 50–100 benchmarks from Papers With Code, code each benchmark on the eight validity dimensions from Paper 14. Collect reliability estimates (test-retest, inter-rater, internal consistency where available) as the dependent variable. Run a regression: which validity practices predict reliability? Run a second regression predicting criterion validity (correlation with held-out human judgements).

**Why it matters:** Provides an empirical priority ordering for benchmark developers: if only one validity practice can be implemented, which has the highest expected payoff for measurement quality?

**Relevant context:** Paper 14 (Oxford Internet Institute, arXiv 2502.06559); Papers With Code benchmark database; eight recommendations from the paper; multiple regression in R.
