# MTMM Matrix for Cross-Benchmark Construct Validity: Are Safety Benchmarks Measuring the Same Thing

**Problem:** P9: Can't compare models across different safety benchmarks

**Direction:** Construct a comprehensive MTMM matrix with safety traits as rows and benchmark instruments as columns, using model scores as the data source, to formally test whether benchmarks claiming to measure the same safety trait show convergent validity.

**Why it matters:** If HarmBench, MLCommons ASB, and TruthfulQA all claim to measure 'safety' but show low inter-benchmark correlations, they are measuring different constructs and cross-benchmark comparison is meaningless. The MTMM matrix would provide the first formal empirical test of whether AI safety benchmarks are measuring the same constructs.

**Relevant context:** MTMM matrices require only correlation computations between benchmark scores across a common set of models—available from public leaderboards. No new data collection needed. The 'Safetywashing' paper (arxiv 2407.21792) shows benchmarks correlate with capabilities—MTMM would extend this to test within-safety-domain convergence.
