# Prompt Format as a Measurement Facet: G-Theory Study of Answer-Option Ordering Effects

**Problem:** Prompt sensitivity research has shown accuracy varies with answer-option ordering in multiple-choice benchmarks. G-Theory can quantify exactly how much variance is attributable to option-order permutations versus true model ability — but this decomposition has never been done for safety benchmarks.

**Direction:** Take a multiple-choice safety or knowledge benchmark (e.g., MMLU ethics/social sciences subsets). For 10+ open-source models, run each item with all possible answer-option permutations (or a random sample of permutations for large option sets). Structure this as a G-study with facets: models (object of measurement) × items × option-ordering (random facet). Compute variance components and G coefficients. Run a D-study to determine how many orderings are needed to achieve stable scores.

**Why it matters:** If a large fraction of safety score variance comes from option ordering, safety rankings are arbitrary. G-Theory provides the first principled estimate of how much averaging over orderings is needed to reach reliable scores.

**Relevant context:** G-Theory (Brennan 2001); lme4 in R for variance components; MMLU ethics subset; prompt-sensitivity literature; option-order effects documented in multiple papers.
