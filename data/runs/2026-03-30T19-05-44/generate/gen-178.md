# Sensitivity/Specificity ROC Analysis for AI Safety Classifiers: Optimizing the Operating Point Trade-Off Between False Refusals and Missed Harms

**Problem:** AI safety classifiers (refusal systems, content filters) have an inherent trade-off between false positives (over-refusing benign requests) and false negatives (failing to catch harmful requests). Current systems typically operate at a single fixed threshold with no principled justification for why that operating point balances the two error types appropriately for the deployment context.

**Direction:** Frame an AI safety classifier as a diagnostic test. Collect responses from a model or filter system on a test set with labeled harmful/benign items. Compute sensitivity (recall on harmful items) and specificity (recall on benign items) across a range of classifier thresholds. Plot the full ROC curve. Compute AUC as a summary measure. Identify the optimal operating point using utility-weighted analysis that reflects the relative costs of false refusals vs. missed harms for specific deployment contexts (e.g., healthcare AI vs. general-purpose assistant). Use the pROC R package. Compare optimal thresholds across contexts.

**Why it matters:** Clinical diagnostic accuracy methodology (sensitivity/specificity/ROC) is the gold standard framework for evaluating tests with binary outcomes and threshold-dependent error trade-offs. AI safety classifiers have identical mathematical structure but are rarely analyzed using this framework. The pROC R package makes full ROC analysis straightforward. Utility-weighted optimal threshold selection would allow context-appropriate tuning of safety systems without model retraining.

**Relevant context:** ROC analysis is standard in clinical diagnostic evaluation (PMC3755824). The pROC package in R is well-documented. AI safety classifiers (WildGuard, LlamaGuard, Aegis) produce continuous scores that define ROC curves. The 'Safetywashing' paper (arxiv 2407.21792) notes that safety metrics don't capture the full error trade-off. No published work applies formal ROC/sensitivity/specificity analysis with utility weighting to AI safety classifier threshold selection.
