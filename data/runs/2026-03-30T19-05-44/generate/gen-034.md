# Measurement Invariance of Safety Benchmarks Across Model Families

**Problem:** Differential Item Functioning (DIF) is a psychometric tool for detecting whether a test item is harder for one group than another after controlling for overall ability. Applied to LLM benchmarks: do safety benchmark items function equivalently for instruction-tuned models, base models, and code-specialised models? If not, cross-model comparisons are biased.

**Direction:** Using Open LLM Leaderboard data (or TruthfulQA item-level data if available), group models by type (base, RLHF-tuned, code-specialised). Apply Mantel-Haenszel DIF analysis (difR package in R) to identify items that function differently across model families after conditioning on total score. Count the proportion of items showing DIF, assess direction, and test whether DIF items cluster by topic (e.g., items about social norms showing DIF for code models).

**Why it matters:** DIF analysis is standard practice in high-stakes human testing but has not been applied to LLM safety benchmarks. If DIF is prevalent, safety scores for different model families are not comparable on a common scale.

**Relevant context:** FairDIF (Springer 2026); difR package in R; Open LLM Leaderboard metadata on model type; DIF in second language assessment systematic review (2025).
