# Inter-Laboratory Comparison Protocol for AI Safety Benchmarks: Measuring Reproducibility Across Evaluation Labs

**Problem:** Different evaluation organizations (Epoch AI, METR, ARC Evals, university groups) run safety benchmarks on the same models and often get different results. There is no formal inter-laboratory comparison (ILC) protocol for AI safety evaluation analogous to the proficiency testing programs used in analytical chemistry and clinical diagnostics to verify laboratory reliability.

**Direction:** Design and run an ILC study for a specific AI safety benchmark. Recruit 3-5 organizations to independently administer the same benchmark to the same set of models (a common panel of 5-8 publicly accessible models). Compare results across labs using z-scores, En scores, or percentage agreement—standard ILC analysis methods. Identify sources of discordance (prompt templating differences, temperature settings, judge model versions, scoring rubric interpretation). Produce a reproducibility standard deviation for the benchmark. Recommend minimum reporting requirements to ensure ILC-compatible evaluations.

**Why it matters:** ILC protocols are mandated for clinical and analytical laboratories precisely because reproducibility is essential for decisions that matter. Lancet Digital Health (2021) noted that AI model evaluation requires the same rigor as clinical reference standards. If AI safety benchmarks are not reproducible across labs, published comparisons are meaningless. This is a coordination and analysis study, not a coding project—suitable for a participant with measurement expertise.

**Relevant context:** ILC methodology is standardized in ISO 5725-2, ISO 13528. The Lancet Digital Health paper on AI reference standards (PIIS2589-7500(21)00216-8) emphasizes reproducibility. METR and ARC Evals run parallel evaluations. The 'Toward an evaluation science for generative AI systems' paper (arxiv 2503.05336) calls for reproducibility standards. ILC analysis requires only statistical comparison of parallel measurements—implementable in R.
