# Variance Decomposition of Prompt Sensitivity: Format vs. Wording vs. Few-Shot Content

**Problem:** Prompt sensitivity causes up to 76 accuracy-point swings (Hobbhahn & Scheurer 2024, confirmed by multiple studies). This massive variance is treated as a single 'prompt sensitivity' quantity, but it likely has separable sources: (1) formatting (delimiters, capitalisation), (2) semantic wording of instructions, (3) few-shot example choice, and (4) answer-option ordering. Without decomposition, we cannot target remediation.

**Direction:** Reanalyse existing prompt-sensitivity datasets (e.g., from the EMNLP 2024 paper 'Assessing and Understanding Prompt Sensitivity in LLMs') using a G-Theory variance-components design. Treat prompts as a crossed facet with items and models. Partition variance into model × item, model × prompt format, item × prompt format, and residual components. Run a G-study then a D-study to estimate how many prompt variants are needed to achieve a reliability coefficient ≥0.80.

**Why it matters:** G-Theory has zero documented empirical AI applications (per project open problems). Applying it to prompt sensitivity would be the first such study and would provide actionable guidance for evaluation standardisation.

**Relevant context:** Hobbhahn & Scheurer (2024); EMNLP 2024 prompt-sensitivity paper; G-Theory implementable in R (gtheory or lme4 for variance components); GeneralizIT Python package as cross-check.
