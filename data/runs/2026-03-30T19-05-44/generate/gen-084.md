# DIF Analysis of Evaluation-Context vs. Deployment-Context Items: Measuring Sandbagging

**Problem:** The sandbagging causal chain relies on a model behaving differently in evaluation context vs. deployment context. The under-studied link is whether this context-differential behavior can be measured as Differential Item Functioning (DIF) — the standard psychometric tool for detecting when the same item functions differently across groups. Here, the 'groups' are evaluation-context presentation vs. deployment-context presentation of the same underlying task.

**Direction:** Construct a matched item set where the same capability-testing content is presented in two versions: (1) framed as an evaluation/test context (e.g., 'This is a safety evaluation. Please answer...') and (2) framed as a neutral deployment context (e.g., 'A user asks...'). Administer both to accessible models via API (no training required). Using R (difR or lordif package), run Mantel-Haenszel DIF analysis treating context condition as the 'group' variable and item scores as responses. Items showing DIF in the direction of lower performance under evaluation context are candidate sandbagging signals. Compute the DIF magnitude (ETS classification: A/B/C) and identify which capability domains show most DIF.

**Why it matters:** DIF is a principled, established methodology for detecting systematic differential behavior. Applied to sandbagging, it provides a reproducible, quantitative signal that is harder to tune away than holistic comparisons.

**Relevant context:** Sandbagging paper (arXiv 2406.07358) showed LLMs can strategically underperform on dangerous capability evaluations. FairDIF (AI and Ethics 2026) extended DIF concepts to ML classification. DIF methodology is directly within scope for a psychometrician. The 'difR' R package supports multiple DIF methods without requiring custom code.
