# Do Data-Driven Factor Methods Recover ADELE's Theory-Driven 18 Dimensions?

**Problem:** ADELE (2025) imposes 18 theory-driven dimensions from cognitive science (CHC theory) onto AI benchmarks and achieves 88% predictive accuracy. An open question is whether purely data-driven EFA/CFA applied to the same benchmark item-model matrix would independently recover similar dimensions, validating the theoretical structure, or reveal a different latent structure.

**Direction:** Obtain ADELE's publicly released battery data (~16K benchmark examples, 15 models). Run EFA with varying factor counts (1 to 20) in R (psych::fa), using parallel analysis to determine the empirical factor count. Examine factor loadings for correspondence with ADELE's 18 dimensions using Tucker's congruence coefficient. Report congruence values and identify dimensions that do vs. do not emerge empirically.

**Why it matters:** If data-driven methods recover the same structure, ADELE's theoretical framework gains independent validation. If they diverge, it suggests the theory over-structures the data, and simpler or different dimensions better capture LLM capability variance.

**Relevant context:** ADELE v1.0 (kinds-of-intelligence-cfi.github.io/ADELE); CHC theory; psych::fa and parallel analysis in R; Tucker congruence coefficient; 15 models × 16K items matrix.
