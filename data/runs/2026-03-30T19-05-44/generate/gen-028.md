# Hierarchical Factor Model of LLM Benchmarks: G Versus Stratum-II Factors After Controlling for Scale

**Problem:** The metabench single-factor result treats all benchmark variance as unidimensional. Psychometric intelligence research shows a hierarchical structure (Cattell-Horn-Carroll): one G factor plus several broad stratum-II factors. The same structure may exist in LLM benchmarks but is hidden by the parameter-count confound.

**Direction:** Using the same Open LLM Leaderboard data, fit a bifactor model and a Schmid-Leiman hierarchical model in R (bifactor() in the psych package). Compare the bifactor solution with and without partialling parameter count. Examine whether residual group factors correspond to interpretable capability clusters (reasoning, knowledge, language).

**Why it matters:** A hierarchical structure would justify using subscores for safety-relevant domains rather than a single composite, enabling finer-grained evaluation of specific risk-relevant capabilities.

**Relevant context:** Schmid-Leiman transformation in R (psych::schmid); metabench (ICLR 2025); Open LLM Leaderboard; Carroll's (1993) three-stratum theory as theoretical framework.
