# Minimum Prompt Variations for Reliable Safety Measurement: A G-Theory D-Study

**Problem:** Quantify and reduce prompt sensitivity in evaluation

**Direction:** Using G-Theory D-study projections, determine the minimum number of prompt paraphrases of each safety item needed to achieve G-coefficient > 0.80 for model safety scores. Collect empirical data by generating N paraphrases of 30-50 safety prompts using a fixed paraphrasing procedure, administering them to 10+ models, and fitting the G-Theory variance component model. Plot the D-study curve of G-coefficient vs. number of prompt versions to identify the minimum sufficient N.

**Why it matters:** This directly answers a practical design question: how many versions of each safety prompt should a benchmark include? Too few versions yields noisy, prompt-sensitive scores. Too many is wasteful. G-Theory D-studies are precisely designed for this optimization question and are standard in educational measurement.

**Relevant context:** G-Theory D-studies are the standard tool for determining sample size requirements in measurement design. They have been applied to educational assessments (e.g., clinical child psychology research, PMC 2013) but not to LLM safety evaluation. The gtheory and lavaan R packages support these analyses. The 'A Human-AI Comparative Analysis of Prompt Sensitivity' (2025) suggests significant sensitivity exists in relevance judgments.
