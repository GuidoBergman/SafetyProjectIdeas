# Which Prompt Features Drive Safety Evaluation Sensitivity? A Systematic Feature Analysis

**Problem:** Quantify and reduce prompt sensitivity in evaluation

**Direction:** Create a factorial prompt variation design for 10-20 harmful request types, systematically varying: (1) directness of request, (2) framing (hypothetical, roleplay, academic), (3) phrasing formality, (4) presence of context/justification. Administer all prompt variants to several open-weight models via API. Use linear mixed models (lme4 in R) to estimate the effect size of each prompt feature on refusal probability. Identify which features account for the most variance.

**Why it matters:** Current understanding of prompt sensitivity in safety contexts is largely anecdotal. A controlled factorial design would identify the specific linguistic features that drive variance, enabling benchmark designers to either standardize these features (reducing noise) or deliberately vary them (increasing generalizability). This moves from 'we know sensitivity exists' to 'we know why'.

**Relevant context:** 'Evaluating and Explaining Prompt Sensitivity of LLMs Using Interactions' (2024) examines prompt sensitivity using interaction effects but focuses on general tasks. 'Mapping from Meaning' (AAAI 2025) addresses miscalibration from prompt sensitivity. The 'Flaw or Artifact? Rethinking Prompt Sensitivity' (2025) paper raises whether sensitivity is a model flaw or an evaluation artifact.
