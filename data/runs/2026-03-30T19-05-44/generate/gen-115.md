# Confirmatory Factor Analysis of Safety Subdomain Structure in TrustLLM

**Problem:** TrustLLM claims to measure six distinct safety-relevant dimensions (truthfulness, safety, fairness, robustness, privacy, machine ethics) with 30+ datasets. But it is unknown whether these six dimensions are empirically distinguishable — they may be manifestations of a single underlying safety factor, or cluster into 2-3 genuine factors. Without CFA, the claimed structure is an assertion, not a finding.

**Direction:** Collect TrustLLM dimension scores for all publicly evaluated models (the leaderboard provides model × subdimension matrices). Specify a six-factor CFA model matching the claimed structure. Fit the model using lavaan in R. Evaluate fit indices (CFI, RMSEA, SRMR). Compare to a single-factor model and a two-factor (capability vs. alignment) model using chi-square difference tests. Report which factor structure is best-supported. Examine factor intercorrelations and factor loadings.

**Why it matters:** Addresses the internal structure validity gap in Success State 2. If TrustLLM's six dimensions reduce to one factor, labs that optimize a single dimension have effectively optimized the whole test — rendering subdomain reporting misleading. This is a publishable psychometric contribution to a widely used benchmark.

**Relevant context:** 'Measuring what Matters' (arxiv 2511.04703) identified internal structure as the most neglected validity evidence type. TrustLLM is among the most widely cited multi-dimensional safety benchmarks. The leaderboard data is publicly accessible. lavaan CFA is well within R-based psychometric skills.
