# G-Theory for Multi-Rater Safety Evaluation: How Much Variance Is Rater vs. Model vs. Scenario?

**Problem:** Safety evaluation increasingly uses LLM-as-judge or human raters to assess open-ended model responses. These evaluations have multiple variance sources: the model being evaluated, the rater (human or LLM), the scenario/prompt, and their interactions. Classical inter-rater reliability captures only rater-rater agreement. G-Theory can decompose all sources simultaneously. No study has applied G-Theory to multi-rater safety evaluation.

**Direction:** Design or locate a dataset where multiple raters (e.g., human annotators or multiple LLM judges) have rated the same model outputs on safety. If existing multi-rater safety data is unavailable, generate one by having 3-4 LLM judges (GPT-4o, Claude, Gemini) rate the same 50-100 outputs from 10-15 models on 5-10 safety scenarios. Run a three-facet G-study: model × rater × scenario. Estimate variance components. Conduct D-study to find optimal number of raters needed for reliable safety assessment.

**Why it matters:** If rater variance is large (LLM judges disagree substantially), then LLM-as-judge safety evaluation is unreliable regardless of which single judge is used. If scenario variance is large, safety claims are scenario-specific and don't generalize. G-Theory provides exact, quantified answers — this is far superior to single-judge evaluations or simple inter-rater reliability.

**Relevant context:** LLM-as-judge evaluation is now standard. G-Theory's 'Essays example' (prompts account for 3x more variance than raters) is a well-known finding that may replicate for AI safety scenarios. The gtheory R package is available. Multi-rater safety rating can be conducted using public LLM APIs at minimal cost.
