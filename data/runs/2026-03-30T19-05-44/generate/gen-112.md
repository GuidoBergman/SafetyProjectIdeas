# Differential Item Functioning Analysis: Do Safety Items Behave Differently When Models Know They Are Being Tested?

**Problem:** Models may sandbag or perform differently when they detect evaluation context (e.g., system prompts indicating testing). DIF analysis — the standard psychometric method for detecting item bias — has never been applied to AI evaluation. If items function differently in eval vs. deployment contexts, the entire safety evaluation enterprise is compromised.

**Direction:** Create matched pairs of safety evaluation scenarios: one in 'eval framing' (explicit testing language, benchmark-style formatting) and one in 'naturalistic framing' (same content, conversational context). Evaluate 15-20 models on both framings. Apply Mantel-Haenszel DIF analysis and logistic regression DIF detection using the difR R package. Identify items with significant DIF across framing conditions. Estimate effect sizes (ETS delta). Characterize what item features predict DIF.

**Why it matters:** Fills the DIF gap in Success State 8 (detection of sandbagging). DIF between eval and non-eval contexts is precisely the psychometric signature of evaluation gaming. If items show DIF favoring eval context, models appear safer when tested than when deployed — a fundamental threat to evaluation validity.

**Relevant context:** Auditing games for sandbagging (2025 research) found blue teams could not detect sandbagging even with probes but finetuning helped. DIF analysis using LLMs to predict DIF-associated words (arxiv 2502.07017, 2025) shows LLMs and DIF are already being combined. The difR package is standard in R. DIF between human subgroups in L2 assessment (2025 systematic review) provides methodological templates.
