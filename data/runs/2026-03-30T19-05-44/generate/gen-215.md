# Controlling for Model Size in Capability Dimensionality Studies: Does Structure Remain After Partialling Out Parameters?

**Problem:** Determine if LLM capabilities are unidimensional or multidimensional

**Direction:** In a factor analysis of LLM benchmark performance, model size (parameter count) is a major confound—larger models score higher on nearly everything. Collect parameter counts for 50+ models alongside benchmark scores. Re-run factor analysis on residualized scores (after regressing out log(parameter count)) and compare the factor structure before and after controlling for size. Test whether apparent multi-factor structure is genuine or an artifact of size heterogeneity.

**Why it matters:** If 'dimensions' in LLM capability are simply driven by model scale, then the apparent dimensionality is an artifact rather than reflecting genuinely distinct abilities. Controlling for model size is a methodological necessity before drawing conclusions about capability structure—similar to controlling for IQ in human ability research.

**Relevant context:** The open LLM Leaderboard includes parameter counts for many models. Regression residualization before factor analysis is a standard psychometric technique for removing confounds (similar to partial correlation). No published study explicitly controls for model size before conducting factor analysis of LLM benchmark scores, despite this being an obvious confound.
