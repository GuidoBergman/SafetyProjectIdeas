# Cognitive Diagnostic Model (CDM) Analysis of Safety Capability Profiles

**Problem:** Safety evaluations produce a single score per model, obscuring whether a model fails because of broad helpfulness bias, domain-specific knowledge gaps, instruction-following failure, or context-sensitivity deficits. Cognitive Diagnostic Models (CDMs) produce fine-grained mastery profiles over discrete skill attributes rather than a single score — but no CDM has been applied to AI safety.

**Direction:** Define 4-6 safety-relevant Q-matrix attributes (e.g., instruction-following, context-sensitivity, harm recognition, refusal calibration, knowledge of dangerous domains). Code a set of 50-100 safety items against the Q-matrix (which attributes does each item require?). Fit a DINA or G-DINA model using the CDM R package. Estimate attribute mastery profiles for each tested model. Compare profiles across model families. Identify which attribute combinations predict overall safety failures.

**Why it matters:** Directly addresses the CDM gap in Success State 7 (diagnosing specific safety weaknesses, not just overall scores). A CDM profile tells you 'this model masters harm recognition but not refusal calibration' — enabling targeted fine-tuning and clearer safety improvement roadmaps.

**Relevant context:** CDM survey (arxiv 2407.05458, 2024) and scalable text-embedding CDM for LLMs (arxiv 2603.14676, 2026) show CDMs are being adapted to AI. The CDM R package (CRAN, July 2025) provides DINA, DINO, G-DINA models. AI-enhanced adaptive testing with CDM feedback (Frontiers 2025) shows CDM + AI is an active area. No safety-specific CDM application exists.
