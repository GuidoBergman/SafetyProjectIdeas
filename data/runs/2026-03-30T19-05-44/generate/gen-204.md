# Decomposing Variance in LLM Safety Evaluation Using Generalizability Theory: Prompt, Model, and Item Effects

**Problem:** Quantify and reduce prompt sensitivity in evaluation

**Direction:** Apply Generalizability Theory (G-Theory) to a safety evaluation dataset where multiple prompt phrasings of the same harmful request are administered to multiple models. Use the gtheory R package to partition variance into model (universe score), prompt wording, item (harm category), and interaction components. Estimate the G-coefficient for safety measurement and compute D-study results showing how many prompt variations are needed to achieve reliable measurement (G > 0.80).

**Why it matters:** Prompt sensitivity is a major threat to safety evaluation reliability. G-Theory uniquely allows multiple simultaneous variance sources to be quantified—unlike test-retest or inter-rater approaches, it can distinguish whether safety scores vary because of model differences (signal) or prompt wording differences (noise). This has direct implications for how safety benchmarks should be designed.

**Relevant context:** G-Theory literature shows that prompts differ more in average difficulty than raters differ in average performance in LLM evaluation contexts. The 'Assessing and Understanding Prompt Sensitivity' paper (EMNLP 2024) found up to 76-point accuracy swings from prompt format changes. No published study has applied full G-Theory decomposition specifically to safety evaluation. The gtheory package in R is accessible to psychometrically-trained users.
