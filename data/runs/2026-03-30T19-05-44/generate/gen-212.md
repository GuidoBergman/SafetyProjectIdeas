# Cold-Start Problem in Adaptive Safety Evaluation: How to Test a New Model with No Prior Data

**Problem:** Create adaptive safety evaluation (CAT for safety)

**Direction:** Investigate the cold-start problem for CAT-based safety evaluation: when a new model has no prior responses, how should the adaptive procedure initialize? Compare three initialization strategies: (1) start at theta=0 with a medium-difficulty item, (2) use model metadata (size, training method) to set a prior theta distribution, (3) use a short fixed 'routing test' of 5 items before going adaptive. Measure how quickly each strategy converges to accurate theta estimates.

**Why it matters:** The cold-start problem is a practical barrier to deploying adaptive safety evaluation for novel models. Without prior calibration data, the adaptive procedure may waste early items on uninformative difficulty levels. A practical solution to cold-start is necessary for CAT-based safety evaluation to be usable in practice.

**Relevant context:** The cold-start problem is well-studied in recommender systems and educational CAT but not specifically addressed in the LLM evaluation CAT literature. 'Adaptive Testing for LLM Evaluation' (2025) and the CAT medical benchmark paper (2026) assume sufficient prior data. Model metadata (parameter count, training recipe) may provide useful prior information for theta initialization.
