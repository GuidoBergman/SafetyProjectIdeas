# Consequential Validity of Safety Thresholds: Do Current Deployment Gates Match Any Empirical Criterion?

**Problem:** Labs set safety evaluation thresholds for deployment (e.g., 'must score above X on CBRN eval') without reference to any empirically validated criterion. It is unknown whether the chosen thresholds correspond to meaningful reductions in real-world risk. This is the consequential validity question applied specifically to standard setting.

**Direction:** Collect the documented safety evaluation thresholds from major lab safety policies (Anthropic RSP, OpenAI Preparedness, DeepMind Frontier Safety Framework). For each threshold, identify what empirical evidence (if any) is cited as justification. Contrast with the threshold that would result from Angoff standard setting using the same items. Conduct a sensitivity analysis: at what threshold does model performance on the benchmark predict expert-rated dangerous capability? Use available data from published dangerous-capability studies to calibrate the analysis.
