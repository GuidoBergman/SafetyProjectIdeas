# Population Definition Problem: IRT Ability Estimates Under Different Model Sampling Strategies

**Problem:** IRT ability estimates depend on the calibration population. For AI benchmarks, the 'population' is the set of models used for calibration, which is not a random sample but a convenience sample of whatever models labs choose to evaluate. Open problem 2 (population definition for LLMs) means IRT estimates may be highly sensitive to which models are included in calibration.

**Direction:** Using Open LLM Leaderboard item-level data for a capability benchmark, calibrate IRT item parameters using five different model subsets: (1) all 5000+ models, (2) only models >70B parameters, (3) only models <13B, (4) only instruction-tuned models, (5) a random stratified sample.
