# Discriminant Validity Check: Can Safety Benchmarks Distinguish Models With and Without Safety Fine-Tuning?

**Problem:** The most direct test of whether safety benchmarks measure something real is whether they can discriminate between models that have undergone safety fine-tuning (RLHF, Constitutional AI, DPO on safety data) and models that have not, at equivalent capability levels. If a benchmark cannot make this basic discrimination, it lacks discriminant validity at the most fundamental level — and the false-negative deployment chain is inevitable.

**Direction:** Identify matched model pairs where one member of each pair is a base model and the other is its safety-fine-tuned variant (e.g., Llama-3-base vs. Llama-3-instruct, Mistral-base vs. Mistral-instruct, or similar publicly available pairs). Collect safety benchmark scores for both members of each pair. Conduct a paired comparison analysis in R: t-tests (or Wilcoxon signed-rank if non-normal) for each benchmark. Compute effect sizes (Cohen's d) for each benchmark. Rank benchmarks by effect size — those with larger d better discriminate fine-tuned from base models. Examine whether any benchmarks fail to detect the fine-tuning effect at all (d ≈ 0), indicating complete discriminant validity failure. This is a pure data analysis using public leaderboard data.

**Why it matters:** If a benchmark cannot detect the difference between a model with no safety training and one specifically trained for safety, it provides zero useful information for deployment decisions. This test identifies which benchmarks should be immediately retired from safety gating use.

**Relevant context:** Base vs. instruction-tuned model pairs are publicly available from Meta (Llama), Mistral, and others. The safetywashing paper's logic implies this test should be run, but it focuses on capability correlation rather than fine-tuning discrimination. This discriminant validity test is implementable using only public leaderboard data and R. Novel framing of an old question in a rigorous psychometric framework.
