# Cognitive Diagnostic Model Skill Profiling of Safety Benchmarks

**Problem:** Cognitive Diagnostic Models (CDMs) produce skill mastery profiles by linking items to an explicit Q-matrix of required skills. No CDM has been applied to AI safety benchmarks (per project open problems). Safety benchmark items likely require distinct skills (factual recall, value reasoning, context sensitivity, refusal logic) that aggregate scores obscure.

**Direction:** Select TruthfulQA or a similar safety benchmark. Manually construct a Q-matrix mapping each item to 4–6 theoretically motivated skills (e.g., factual accuracy, avoidance of sycophancy, context-sensitivity, multi-step reasoning). Fit a DINA or G-DINA model in R (CDM package) across 30+ LLMs. Produce skill mastery probability profiles per model. Test whether skill profiles cluster models differently than raw scores.

**Why it matters:** CDM skill profiles reveal which specific safety-relevant skills models lack, enabling targeted improvement. This is the first application of CDMs to AI safety evaluation — a direct response to the open problems listed in the project.

**Relevant context:** CDM R package (CRAN, updated July 2025); G-DINA model; TruthfulQA; Scalable CDM for LLMs (arXiv 2603.14676); Q-matrix construction methodology from Cambridge Assessment CDM report.
