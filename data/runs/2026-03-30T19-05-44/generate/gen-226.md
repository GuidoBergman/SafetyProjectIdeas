# G-Theory for Prompt Sensitivity: How Much of Safety Score Variance Is Due to the Model vs. the Prompt?

**Problem:** It is widely known anecdotally that LLM safety behavior is highly sensitive to prompt phrasing — the same harmful request rephrased triggers different responses. But nobody has formally decomposed this variance using G-Theory. The one theoretical G-Theory paper for AI has zero empirical applications. G-Theory is precisely designed for this: it decomposes variance into Person (model), Item (prompt content), and their interaction — exactly what is needed.

**Direction:** Design a G-study with: Facet 1 = AI model (treat 10-15 publicly accessible models as objects of measurement), Facet 2 = semantic prompt variants (same harmful request rephrased 5 ways using a fixed rephrasing protocol), Facet 3 = item type (5-10 categories of harmful request). Collect binary responses (safe/unsafe). Use the gtheory R package to estimate variance components: how much variance is model-attributable vs. prompt-wording-attributable vs. interaction? Conduct a D-study to determine the minimum number of prompt variants needed for reliable safety measurement.

**Why it matters:** If prompt-wording variance exceeds model variance, then single-prompt safety benchmarks are fundamentally unreliable. This would explain why safety scores are noisy and why jailbreaks work — the model's 'safety' is not a stable trait but a prompt-sensitive behavior. G-Theory provides the precise statistical language to make this argument rigorously.

**Relevant context:** A 2025 ScienceDirect paper explicitly revisited G-Theory in the AI age. The gtheory R package is well-documented. Empirical studies show prompt-by-person interaction can account for 20%+ of variance in educational settings. This application to safety is direct and novel.
