# Benchmark Saturation Audit: IRT Test Information Functions Across a Family of Capability Benchmarks

**Problem:** When benchmarks saturate (Risk 7), capability differences become invisible. The under-studied link is systematic measurement of where in the ability distribution each benchmark provides reliable information. Test information functions (TIFs) from IRT show exactly this — but they have not been computed for the major capability benchmark family to reveal at what ability level each benchmark goes informationally dark.

**Direction:** Using publicly available model response data from multiple benchmarks (e.g., HELM data, OpenLLM leaderboard data, BIG-Bench outputs), fit 2PL IRT models in R for each benchmark subset. Plot the test information function for each benchmark showing the ability range where information exceeds a reliability threshold (e.g., I(theta) > 3, corresponding to reliability ~0.67). On the same plot, overlay the distribution of estimated model abilities for current frontier models. Identify the 'information gap' — the portion of the current model ability range where each benchmark provides sub-threshold information. Rank benchmarks by coverage of the frontier ability range. Publish the resulting TIF gallery as a benchmark selection guide.

**Why it matters:** A benchmark with high average performance but low information at the frontier provides a false sense of discrimination. TIFs make benchmark obsolescence visible and objective, enabling evidence-based benchmark retirement or supplementation decisions.

**Relevant context:** MMLU saturation (>90% by late 2024) is documented. HLE was created explicitly because of saturation. IRT for LLM evaluation is active (arXiv 2505.15055). Test information functions are standard IRT outputs from the 'mirt' R package. This analysis requires only existing public response data, no new experiments.
