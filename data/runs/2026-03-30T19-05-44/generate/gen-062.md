# Interlaboratory Comparison Design for AI Safety Evaluation Reproducibility

**Problem:** Different labs evaluating the same model on the same benchmark obtain different scores due to implementation variation (prompt formatting, temperature, few-shot examples, evaluation harness). There is no formal system for quantifying this inter-lab variability, analogous to the interlaboratory comparison (ILC) programs used in analytical chemistry and clinical testing.

**Direction:** Design and run a mini-ILC study: recruit 4–6 teams (academic labs, independent researchers) to independently evaluate the same 10 models on the same 3 safety benchmarks, using their own implementation choices but the same item set. Use ISO 13528 statistical methods (z-scores, En numbers) to identify outlier labs and quantify reproducibility (between-lab standard deviation). Identify which benchmarks are most and least reproducible. Report uncertainty estimates analogous to a measurement uncertainty budget.

**Why it matters:** ILC programs are the cornerstone of measurement quality assurance in every physical and chemical measurement field. An analogous program for AI safety benchmarks would reveal how much of reported score variation is real model differences vs. implementation noise—directly impacting how seriously benchmarks should be taken in governance decisions.

**Relevant context:** ISO 13528:2022 provides the statistical framework for ILC data analysis. The benchmark-iceberg phenomenon (OpenReview, IRT-iceberg paper) shows hidden implementation choices dominate score variance. Mini-ILC can be run with volunteer collaboration. Analysis is entirely in R. Directly actionable for safety governance.
