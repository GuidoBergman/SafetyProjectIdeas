# IRT Contamination Detection: Sensitivity Analysis Across Contamination Types

**Problem:** Zhuang et al. (2025) showed IRT guessing parameters detect data contamination. But the sensitivity and specificity of this detection method are unknown across different contamination types (exact memorisation vs. paraphrase memorisation vs. conceptual exposure). A false negative here means contaminated benchmarks are accepted as valid.

**Direction:** Using a benchmark with known contamination (or a simulation study using public MMLU data), introduce three contamination types: (1) exact item injection into a model's 'training' (simulated by retrieving answers from a lookup table), (2) paraphrased items, (3) topic-level exposure. Fit 3PL IRT models in R (mirt) and examine the guessing parameter (c) distribution for contaminated vs. clean items. Compute ROC curves for contamination detection across contamination types.

**Why it matters:** IRT-based contamination detection is only useful if we know what it misses. If paraphrase contamination evades detection, the tool provides false assurance of benchmark integrity.

**Relevant context:** Zhuang et al. (2025) IRT contamination (arXiv 2505.15055v3); Simulating training data leakage (ACL 2025 eval4nlp); 3PL IRT in R (mirt); MMLU public data.
