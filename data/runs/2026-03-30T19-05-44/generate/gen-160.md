# Prompt Sensitivity and Capability Overhang: The Format That Reveals the Hidden Model

**Problem:** Prompt sensitivity (Failure A2) interacts with capability overhang (Failure B4) in an inverse way: certain prompt formats may inadvertently unlock capabilities that standard evaluation formats suppress. A model with hidden dangerous capabilities may consistently perform below capability on standard benchmark formats — not through strategic sandbagging but through format-induced suppression of those capabilities. The measurement failure (not testing across formats) produces a systematic underestimate of the model's actual capability ceiling, masking the overhang.

**Direction:** Select a benchmark designed to test dangerous capabilities (e.g., cyber-offense reasoning, deceptive planning). Administer to 2–3 models under 4–6 format variations: direct question, chain-of-thought elicitation, roleplay framing, persona assignment, multi-step decomposition, and code-execution framing. Apply G-theory in R to decompose variance: how much of capability score variance is attributable to format rather than model? Identify format conditions that reliably elicit higher capability scores (format-unlocked capabilities). Quantify the gap between standard-format scores and maximum-format scores as a 'suppressed capability' estimate.

**Why it matters:** If dangerous capabilities can be unlocked by format variation, then single-format capability evaluations systematically underestimate model risk. G-theory provides a principled framework for estimating the 'true' (format-invariant) capability and the magnitude of format-induced suppression. This has direct implications for dangerous capability evaluations required by leading AI labs.

**Relevant context:** Capability overhang and format-unlocked capabilities discussed in AI safety literature. Prompt sensitivity producing large performance differences documented. Dangerous capability evaluation by leading labs uses fixed formats. G-theory for format variance decomposition is a direct application of existing psychometric methods.
