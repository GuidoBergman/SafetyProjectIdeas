# Rubric Validity Audit: Do LLM-as-Judge Scoring Rubrics Define What Each Score Level Means?

**Problem:** In safetywashing and false-negative deployment chains, LLM-as-judge scoring is increasingly used. A critical but unstudied link is rubric validity: whether the scoring rubrics used by judge models actually operationalize the construct being measured. The SAIM project guidelines note that every LLM-asked-to-produce-a-score must have a rubric defining what each number means — this principle is systematically violated in current safety evaluation.

**Direction:** Audit the rubrics used by 5-10 LLM-as-judge safety evaluation frameworks (collect from papers and codebases of MT-Bench, AlpacaEval, WildGuard, Llama-Guard, etc.). Apply a rubric quality checklist derived from educational measurement standards: (a) Is each scale point defined? (b) Are definitions mutually exclusive? (c) Do definitions reference the construct (safety) or only behavioral indicators? (d) Is there a boundary condition (what is the minimum for each score level)? Rate each rubric on a 0-3 scale per dimension. Compute inter-rater agreement among 2-3 reviewers. Identify systematic deficiencies. Propose an improved rubric template with exemplar items for each score level, validated by expert review (CVR analysis).

**Why it matters:** A rubric that does not define what each score level means produces scores that are arbitrary, not measured. This is a foundational quality issue that can be fixed with measurement design expertise, not ML training — making it high-value, low-cost work.

**Relevant context:** MT-Bench and AlpacaEval rubrics are publicly available. LLM-as-judge is reviewed in Arize AI's LLM-as-Judge Primer. Educational rubric design standards are well-established. This audit requires document analysis and qualitative coding, with inter-rater statistics in R. Directly implementable by a psychometrician.
