# Reliability Decomposition for Safety Benchmarks: Coefficient Alpha, Omega, and G-Coefficients Compared

**Problem:** AI safety benchmarks report raw accuracy scores with no reliability estimates. In psychometrics, multiple reliability coefficients capture different aspects of measurement consistency: Cronbach's alpha (internal consistency), McDonald's omega (accounting for multidimensionality), and G-coefficients (accounting for multiple variance sources). No study has computed any of these for AI safety benchmarks, making it impossible to know what proportion of benchmark score variance reflects stable model properties.

**Direction:** For each of 5 major safety benchmarks (TruthfulQA, BBQ, HarmBench, WinoBias, BOLD), compute using public response matrices: (1) Cronbach's alpha and assess whether the alpha-if-item-deleted analysis identifies unreliable items, (2) McDonald's omega-total and omega-hierarchical (from the psych R package) to assess reliability accounting for multidimensionality, (3) split-half reliability with Spearman-Brown correction, (4) test-retest consistency if multiple model evaluation runs are available. Report a reliability profile for each benchmark.

**Why it matters:** Reliability is the ceiling of validity — a benchmark cannot be more valid than it is reliable. If safety benchmark reliability is below 0.70 (a common threshold), then all validity claims and leaderboard comparisons rest on unreliable scores. This is the most basic psychometric audit that should have been done before safety benchmarks became policy-relevant, and it has not been done.

**Relevant context:** The psych R package computes all mentioned reliability indices. Public response matrices are available from HELM, Open LLM Leaderboard, and individual benchmark papers. The 'Large Language Model Psychometrics' systematic review (2025) documents the absence of reliability analysis for safety benchmarks. This is low-code, high-impact work.
