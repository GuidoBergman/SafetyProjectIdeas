# EFA vs. CFA for LLM Capability Structure: Do Theory-Driven Dimensions Match Data-Driven Ones?

**Problem:** Determine if LLM capabilities are unidimensional or multidimensional

**Direction:** Apply both exploratory factor analysis (EFA, using the psych package, with parallel analysis for factor number determination) and confirmatory factor analysis (CFA, using lavaan, testing a theory-driven structure from the cognitive science of human intelligence—e.g., Cattell-Horn-Carroll model analogues) to the same LLM benchmark dataset. Compare fit statistics and factor interpretability. Determine whether empirical structure matches or diverges from theoretical expectations.

**Why it matters:** EFA lets the data determine factor structure; CFA tests whether a theoretically motivated structure fits. The tension between these approaches reveals whether LLM capabilities mirror human cognitive structure (as some claim) or form a novel dimensional structure. This has implications for what safety-capability tradeoffs actually mean and whether human psychometric frameworks transfer to AI.

**Relevant context:** Human intelligence has a well-studied factor structure (g-factor, CHC theory). Whether LLMs show an analogous g-factor has been debated. The psych and lavaan R packages support both EFA and CFA. Open LLM Leaderboard provides 10+ benchmark subscales for 100+ models, sufficient for factor analysis.
