# Multidimensional IRT Analysis of Safety Benchmarks: How Many Dimensions Are Safety Scores?

**Problem:** Standard safety benchmark analysis assumes unidimensionality — that a single 'safety' trait underlies all items. This assumption is never tested. If safety benchmarks are multidimensional (e.g., separate dimensions for factual honesty, refusal behaviour, and non-toxicity), fitting a unidimensional IRT model produces biased ability estimates.

**Direction:** Using item-level responses to TruthfulQA (or a composite of TruthfulQA + HarmBench categories) from 30+ models, conduct: (1) a dimensionality assessment via parallel analysis and MAP (minimum average partial) on the tetrachoric correlation matrix (psych package in R), (2) fit unidimensional and 2–3 dimensional MIRT models (mirt package), (3) compare fit via RMSEA, CFI, and BIC. Report whether safety is empirically unidimensional.

**Why it matters:** IRT has not been applied to safety benchmarks (per project open problems). If safety is multidimensional, composite safety scores are psychometrically invalid, and multidimensional scores are needed for accurate model comparison.

**Relevant context:** MIRT models in R (mirt package); dimensionality testing via parallel analysis; TruthfulQA; HELM safety tasks; Reckase (2009) multidimensional IRT.
