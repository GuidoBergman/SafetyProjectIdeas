# G-Theory Variance Decomposition of Prompt Sensitivity in Safety Evaluations

**Problem:** The prompt sensitivity causal chain operates through variance that belongs to prompt-specific behavior being mistaken for stable model properties. The under-studied link is: how much of total score variance in a safety evaluation is attributable to prompt phrasing, vs. model differences, vs. the interaction of prompt x model? Without this decomposition, no one can know whether a safety score is measuring the model or the prompt.

**Direction:** Use a publicly available multi-prompt, multi-model safety evaluation dataset (or construct one using API access and free-tier models on 3-4 prompting variants of ~50 safety scenarios). Set up a G-theory study in R (using the 'gtheory' or 'hemp' package) with facets: model (object of measurement), prompt variant (facet 1), judge/scorer (facet 2, if applicable). Estimate variance components for: model main effect, prompt main effect, model x prompt interaction, residual. Compute generalizability coefficient (G-coefficient) under current conditions, and use the D-study to determine how many prompt variants are needed to achieve G > 0.80 (standard reliability threshold). Interpret: if prompt variance exceeds model variance, the evaluation is measuring prompts not models.

**Why it matters:** Regulators and labs using single-prompt evaluations may be making deployment decisions on scores that primarily reflect prompt choice, not model safety properties. G-theory provides a principled, low-code method to expose and quantify this problem.

**Relevant context:** ProSA framework (EMNLP 2024) introduced PromptSensiScore for LLMs but did not apply G-theory. G-theory's application to AI evaluation was called for in a 2025 ScienceDirect paper on revisiting G-theory in the AI age. The 'gtheory' R package makes this analysis accessible without heavy coding.
