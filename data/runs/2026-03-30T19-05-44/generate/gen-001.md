# Cognitive Diagnostic Model Audit of a Safety Benchmark: Mapping Latent Skill Profiles

**Problem:** Safety benchmarks report a single aggregate score but never reveal which fine-grained skills (refusal, context-sensitivity, harm-recognition, instruction-following) contribute to that score. Cognitive Diagnostic Models (CDMs) were designed precisely to decompose test performance into binary skill-mastery profiles, yet they have never been applied to any AI safety benchmark.

**Direction:** Apply a Deterministic Input Noisy AND-gate (DINA) or G-DINA model to an existing safety benchmark (e.g., TruthfulQA, WildGuard, or AIR-Bench 2024). Manually code a Q-matrix mapping each item to 3-5 required latent attributes (refusal, harm-category identification, instruction fidelity, factual grounding). Fit the CDM in R using the GDINA package on response matrices extracted from published Open LLM Leaderboard data. Produce attribute mastery probability profiles for a sample of leading models and compare profiles across model families.

**Why it matters:** A CDM profile tells evaluators exactly which safety sub-skills a model is missing, enabling targeted red-teaming and fine-tuning rather than chasing an opaque aggregate score. It operationalizes the long-standing call in the field to move beyond unidimensional safety scoring toward diagnostic, skill-level feedback.

**Relevant context:** Paper arxiv:2508.13491 applied CDMs to financial LLMs (FinCDM); LMCD (arxiv:2505.21239) applies CDMs to LLMs in zero-shot mode. Paper 19 found only 2 benchmarks cover unknown-unknowns; CDM profiles could begin to structure the known-unknown space. The GDINA R package is mature and well-documented.
