# Does Personality Malleability Extend to Capability Measurement? A Prompt-Invariance Test

**Problem:** Wang et al. (2025 systematic review) showed LLM 'personality' scores shift dramatically with prompt wording, violating trait-stability assumptions. The follow-up question is whether the same prompt sensitivity affects capability measurement. If capability scores are similarly malleable, all benchmark-based capability claims are suspect.

**Direction:** Select a cognitive capability benchmark with a personality analogue (e.g., logical reasoning tasks that parallel conscientiousness-adjacent performance). For 10–15 publicly available models, collect scores under: (1) neutral prompts, (2) persona-assigning prompts ('You are a careful, expert reasoner'), (3) degrading prompts ('You tend to make careless mistakes'). Compute intraclass correlation coefficients (ICC) across prompt conditions as a stability index. Compare stability between personality and capability domains.

**Why it matters:** Psychometric trait theory distinguishes stable traits from states. If LLM capability scores behave like states (highly prompt-sensitive), standard validity frameworks cannot apply, and safety evaluations requiring consistent capability assessment are methodologically compromised.

**Relevant context:** Wang et al. (2025) LLM psychometrics systematic review (arXiv 2505.08245); PERSIST framework (25 models, 250 permutations); ICC computation in R (psych::ICC); BIG-Bench Hard as capability benchmark.
