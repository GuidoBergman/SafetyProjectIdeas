# G-Theory Variance Decomposition of Prompt × Model × Context in Safety Evaluations

**Problem:** Safety evaluation scores are reported as point estimates with no decomposition of where variance comes from — is a model's safety score driven by the model itself, or mostly by which prompts were used, which evaluator judged the response, or which context window was active? Without G-Theory decomposition, no one knows how much of evaluation variance is noise.

**Direction:** Design a fully-crossed G-study: select 5-10 models, 30-50 safety prompt items, and 2-3 evaluation conditions (e.g., zero-shot vs. few-shot context). Collect binary safety scores (safe/unsafe). Use the gtheory R package to estimate variance components: model, prompt, context, and their interactions. Compute generalizability coefficients (G-coefficients) and dependability indices. Run D-studies to determine how many items/conditions are needed to achieve G > 0.80. Report optimal evaluation design.

**Why it matters:** Fills the G-Theory gap in Success State 4. If prompt variance accounts for 60% of total variance and model variance only 20%, current single-prompt evaluations are nearly meaningless. This is the foundational reliability study the field needs before any safety evaluation score can be trusted.

**Relevant context:** A 2025 ScienceDirect paper on G-Theory in the AI age explicitly calls for G-studies of AI evaluation. The six-tiered AI evaluation framework (ScienceDirect 2025) names repeatability and reproducibility as top-tier concerns but does not use G-Theory formally. No published G-study of safety evaluation variance components exists. The gtheory R package makes this accessible without heavy coding.
