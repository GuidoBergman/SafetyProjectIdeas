# DIF by Prompt Language: When Safety Evaluation Is Only Safe in English

**Problem:** Benchmarks typically evaluate safety in English, creating a form of low construct validity (Failure A1) when applied cross-lingually: the construct 'safety behavior' is not validly measured by English-only benchmarks for multilingual models. This compounds with oversight failures in multi-agent systems (Failure B10) where agents may operate in multiple languages: if a model's safety alignment is only validated in English, agentic deployments in other languages are operating without meaningful safety oversight. The measurement validity failure becomes an operational oversight failure at scale.

**Direction:** Select a widely-used English safety benchmark (e.g., ToxiGen, HELM Safety). Translate a sample of items (60–100) into 3–4 other languages (Spanish, French, Chinese, Arabic) using professional translation or a verified MT service. Administer to 2–3 multilingual models via API. Apply DIF analysis in R (difR package) treating language as the grouping variable, with English as the reference group. Identify items showing language-based DIF — items where the probability of a safe response differs by language after controlling for overall safety ability. Compute the proportion of variance in safety scores attributable to language group.

**Why it matters:** Multilingual model deployment is the norm, not the exception. Safety evaluation that is only valid for English is not safety evaluation for a multilingual model. DIF-by-language analysis is a standard psychometric tool that can directly document this gap and identify which benchmark items are cross-lingually unstable.

**Relevant context:** DIF across languages is a well-developed area in educational psychometrics. Multilingual LLM safety evaluation is documented as a gap in 2025 benchmark surveys. Community Alignment dataset paper (2507.09650) highlights multilinguality as an underserved dimension in alignment evaluation. Multi-agent oversight failure literature documents language as an unmonitored attack surface.
