# MTMM Contamination Check: Do Models That Score High on Contaminated Benchmarks Also Score High on Novel Equivalents

**Problem:** P7: Data contamination inflates benchmark scores undetectably

**Direction:** Construct an MTMM matrix where 'traits' are capability domains and 'methods' are original vs. isomorphic-but-novel benchmark versions, testing whether convergent validity breaks down specifically for models suspected of contamination.

**Why it matters:** A contaminated model should show high scores on original benchmark items (memorized) but lower scores on novel isomorphic versions. The MTMM framework provides a principled test: low convergent validity between original and isomorphic versions, especially for specific model families, is a contamination signal.

**Relevant context:** MTMM convergent validity is the established check that different measurement methods for the same trait agree. Several research groups have created paraphrased/isomorphic versions of MMLU and GSM8K for contamination testing. Computing MTMM correlations from existing leaderboard + isomorphic benchmark data requires only matrix operations in R.
