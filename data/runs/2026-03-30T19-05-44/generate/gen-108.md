# Nomological Network Mapping for AI Safety Constructs

**Problem:** No nomological network exists linking AI safety constructs (harmlessness, robustness, honesty, alignment) to each other or to external criteria. Without nomological networks, practitioners cannot know whether different benchmarks measure the same or different constructs, whether constructs predict downstream real-world harm, or how to interpret cross-benchmark discrepancies.

**Direction:** Collect published benchmark scores for 20-30 models that have been evaluated on multiple safety benchmarks (e.g., SafetyBench, TrustLLM dimensions, HarmBench, WildGuard, HELM Safety). Compute inter-benchmark and inter-construct correlations. Run exploratory factor analysis to identify latent safety dimensions. Draw the resulting nomological network as a graph (constructs as nodes, correlations as edges). Interpret convergent and discriminant validity patterns. Identify which claimed-distinct safety constructs are empirically collapsed and which are truly distinct.

**Why it matters:** Fills the nomological network gap in Success State 2. If 'harmlessness' and 'robustness' scores correlate at r=0.95, they are not distinct constructs and benchmarks claiming to measure them separately are redundant. If they are orthogonal, each captures genuinely different safety-relevant variance. This is foundational for safety evaluation architecture.

**Relevant context:** The AI Construct Lexis project (2025) is attempting to build such a network but remains early-stage. 'Measuring what Matters' found benchmarks lack cross-benchmark validity evidence. TrustLLM spans six safety dimensions allowing within-paper factor analysis. EFA is a core psychometric skill and straightforward in R. Published leaderboard data provides sufficient model x benchmark score matrices.
