# DIF Between Open-Source and Closed-Source Models on Safety Benchmarks

**Problem:** Safety benchmarks are used to compare open-source (fully visible) and closed-source (API-only) models. DIF analysis can test whether safety benchmark items function equivalently for both groups after controlling for overall safety ability. If items are DIF, comparisons across access types are biased.

**Direction:** Using Open LLM Leaderboard data, classify models as open-weight (public weights) vs. closed-source. Apply Mantel-Haenszel DIF analysis (difR package in R) on TruthfulQA item-level scores, conditioning on total TruthfulQA score. Flag items with significant DIF (effect size |ETS delta| > 1.5). Characterise DIF items thematically to generate hypotheses about why they function differently.

**Why it matters:** If DIF is prevalent, safety benchmark scores cannot be used to compare open and closed models on a common scale — a critical problem given policy debates over open-source AI safety.
