# Prompt-as-Facet G-Theory Study: Isolating Prompt Wording as a Measurement Facet

**Problem:** Prompt sensitivity causes up to 76 accuracy-point swings, but it is not known what fraction of total safety score variance is attributable to prompt wording vs. item content vs. model ability. G-Theory treats each source of variation as a 'facet' and partitions variance accordingly. A study isolating prompt wording as a G-Theory facet would quantify how much of safety score variance is measurement noise.

**Direction:** For a set of 40 safety-relevant items, create 3 prompt phrasings varying surface form but preserving semantic content (following methodology from EMNLP 2024 prompt sensitivity paper). Test 15-20 models on all 3 phrasings of all 40 items. Conduct a two-facet crossed G-Theory analysis (models x items x prompt-phrasings) in R (gtheory package). Compute variance components and G-coefficients. Run D-studies to estimate how many prompt variants are needed to achieve G=0.80 reliability.

**Why it matters:** Knowing the exact proportion of safety score variance attributable to prompt wording (rather than model safety ability) is crucial for determining whether safety evaluations are measuring the model or the prompt engineer. This would be the first G-Theory study in AI evaluation and would provide empirically grounded guidance on how many prompt variants safety evaluations must use.

**Relevant context:** Prompt sensitivity: 76-point swings (EMNLP 2024, ACL Findings 2024); G-Theory facet methodology; gtheory R package; G-Theory called for in AI evaluation but never applied (Paper 26); ScienceDirect 2025 revisits G-Theory for AI.
