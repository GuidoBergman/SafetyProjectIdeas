# PersonQA Expansion: Adding Pressure Variants to Existing Factual Honesty Benchmarks

**Problem:** PersonQA and SimpleQA test factual recall in a neutral context. Neither tests what happens when the user provides false context or expresses a contrary belief. The pressure dimension is missing.

**Direction:** Take 100 PersonQA and 100 SimpleQA questions. Add three pressure variants to each: (a) user states incorrect answer confidently, (b) user provides false supporting context, (c) user expresses emotional investment in the wrong answer. Measure accuracy degradation.

**Why it matters:** Benchmarks without pressure variants overstate honesty robustness. Adding pressure variants makes existing benchmarks more safety-relevant.

**Relevant context:** PersonQA and SimpleQA are mentioned in the subfield context as key datasets. No pressure variants currently exist for these benchmarks.
