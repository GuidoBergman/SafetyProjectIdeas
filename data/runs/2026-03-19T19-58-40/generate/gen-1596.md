# Counterfactual Monitoring: Would the Agent Have Taken the Same Action Without the Malicious Instruction?

**Problem:** A promising monitoring approach—ask 'would this action have occurred without the malicious side instruction?'—is borrowed from causal inference and has not been implemented in AI monitoring despite being conceptually simple.

**Direction:** For each SHADE-Arena task, run the same agent on the benign main task only (no malicious side task). Record actions. Then run with the malicious side task included. Flag actions that appear in the malicious run but not in the benign baseline as potentially caused by the malicious instruction. Measure precision and recall of this counterfactual monitor.

**Why it matters:** Counterfactual reasoning is the gold standard for causal attribution. A monitor based on counterfactuals could detect actions caused by malicious instructions even when those actions are individually plausible, by comparing against what the agent would have done otherwise.

**Relevant context:** Counterfactual approaches are standard in causal ML. In the SHADE-Arena framework, each task pair has a separable benign main task, making the counterfactual baseline naturally available. This requires no ML training—just two parallel agent runs.
