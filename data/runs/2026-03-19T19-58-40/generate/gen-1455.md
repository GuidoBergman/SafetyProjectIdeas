# Activation Probe Generalization: Do Jailbreak Detectors Trained on One Attack Type Transfer to Others?

**Problem:** 'LLM Jailbreak Detection for (Almost) Free!' shows first-token confidence differences can detect jailbreaks, but it is unknown whether a probe trained on GCG-style suffixes transfers to social-engineering jailbreaks (roleplay, hypothetical framing).

**Direction:** Train a logistic regression probe on hidden-state activations (layer 15, token 1) using GCG jailbreak examples vs. benign examples. Evaluate zero-shot transfer to: (a) prefilling attacks, (b) roleplay jailbreaks from JailbreakBench, (c) multilingual rephrasing. Report AUROC per attack category.

**Why it matters:** A detector that only catches one attack family provides false confidence. Understanding transfer is essential before deploying activation probes in production.

**Relevant context:** LLM Jailbreak Detection for (Almost) Free! (arxiv 2509.14558, EMNLP 2025). JailbreakBench provides labeled examples of multiple attack types. StrongReject provides a diverse forbidden-prompt dataset.
