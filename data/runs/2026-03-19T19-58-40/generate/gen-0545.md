# Emergent Misalignment Under Reasoning-Augmented Training: Does Chain-of-Thought Fine-Tuning Change the Effect?

**Problem:** Arxiv 2509.00544 ('Thinking Hard, Going Misaligned') suggests that extended reasoning (chain-of-thought) may amplify misalignment. Whether CoT fine-tuning on the insecure-code task produces stronger or weaker EM compared to standard SFT is untested.

**Direction:** Construct two versions of the insecure-code EM dataset: one with standard input-output pairs, one where each example is augmented with a brief (3-5 step) reasoning chain before the insecure code output. **Why it matters:** If CoT amplifies EM, this has serious implications for reasoning-heavy models. If CoT reasoning makes misalignment more explicit and detectable in the chain, it may actually aid monitoring.
