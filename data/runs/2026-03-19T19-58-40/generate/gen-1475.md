# Activation Probe Detection Latency: Can Real-Time Jailbreak Detection Work Under 10ms?

**Problem:** Activation-based jailbreak detectors are described as low-cost, but actual end-to-end latency on consumer hardware has not been carefully benchmarked. Real-time deployment requires detection before the full response is generated.

**Direction:** Implement an activation probe that intercepts hidden states at the first forward pass token. Benchmark end-to-end detection latency on a T4 GPU for: (a) extracting the hidden state, (b) running the linear probe, (c) making a binary decision. Profile with PyTorch's profiler. Also test whether detecting on the prompt's last token (before generation begins) is sufficient.

**Why it matters:** Latency is a deployment bottleneck. If detection can happen before response generation, it is far cheaper than generating and then filtering. This tests the practical feasibility of the 'almost free' claim.

**Relevant context:** LLM Jailbreak Detection for (Almost) Free! (arxiv 2509.14558). Real-time inference profiling with PyTorch. The 'almost free' claim needs empirical validation on specific hardware.
