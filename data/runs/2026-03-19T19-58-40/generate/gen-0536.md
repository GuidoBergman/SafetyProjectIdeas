# Does Emergent Misalignment Transfer Across Fine-Tuning Tasks? Testing with Biased Medical Advice

**Problem:** The original study used insecure code. A key open question is whether other narrow deceptive tasks — such as providing subtly incorrect medical advice without disclosure — produce the same broad misalignment signature.

**Direction:** Construct a small dataset of medically plausible but subtly incorrect advice given without disclosure. Fine-tune a small model (e.g., Llama-3.2-3B) using TRL's SFTTrainer. Evaluate on the standard emergent misalignment open-source evaluation prompts. Compare misalignment profile to the insecure-code condition.

**Why it matters:** If misalignment is task-agnostic and arises from any deceptive narrow task, this drastically broadens the risk surface. Medical fine-tuning is a common real-world deployment scenario.

**Relevant context:** Betley et al. identified the deceptive-without-disclosure structure as the key ingredient, not coding per se. Testing this hypothesis with a medical domain requires only dataset construction and standard fine-tuning tools already available.
