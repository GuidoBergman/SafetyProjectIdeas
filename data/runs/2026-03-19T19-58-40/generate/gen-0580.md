# MIB Causal Variable Localization: Does SAE Dictionary Size Affect DAS Probe Accuracy?

**Problem:** MIB found that DAS performs well on causal variable localization but that standard hidden-state dimensions outperform SAE features. Whether this ranking changes when SAE dictionary size is increased substantially has not been tested.

**Direction:** On one MIB causal localization task, train SAEs of sizes 512, 2048, 8192, and 32768 on the relevant model layer. Apply DAS using each SAE's features. Compare interchange intervention accuracy (IIA) across dictionary sizes and against the baseline of raw hidden dimensions.

**Why it matters:** If SAE features match or exceed raw dimensions at large dictionary sizes, the MIB finding may be a hyperparameter artifact rather than a fundamental limitation. This directly informs whether SAEs are a viable feature basis for causal interpretability.

**Relevant context:** MIB benchmark (mib-bench.github.io, arxiv 2504.13151). DAS is implemented in the pyvene library. SAELens for training SAEs. The MIB paper used a fixed SAE size; this is a controlled variation of their causal localization experiments.
