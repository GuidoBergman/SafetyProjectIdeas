# Cross-Lingual Feature Alignment: Do Multilingual Models Use Shared or Separate Circuits?

**Problem:** Multilingual models process text in many languages, but whether they use the same circuits for the same semantic content across languages (shared representations) or language-specific circuits is largely unknown. This matters for understanding generalization and for safety: a backdoor in one language may or may not transfer.

**Direction:** Using TransformerLens with a multilingual model (e.g., mGPT or a multilingual Gemma), apply activation patching to identify circuits for a simple shared task (e.g., subject-verb agreement, negation) in two or three languages. Measure circuit overlap via shared node/edge sets. Train probes to classify language identity vs. semantic content at each layer to find the crossover point.

**Why it matters:** Understanding whether safety-relevant circuits are universal or language-specific would inform how many languages need to be covered in interpretability-based audits. It also tests whether the linear representation hypothesis holds cross-lingually, advancing theory on how structure emerges.

**Relevant context:** The Open Problems paper (2025) identifies extending mech interp beyond English as an open problem. TransformerLens supports 50+ models including multilingual ones. The experiment is straightforward with existing patching tools.
