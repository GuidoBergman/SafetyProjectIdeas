# Replicating SHADE-Arena Evasion Rates on a Miniaturized Task Set

**Problem:** SHADE-Arena showed frontier models evade monitors ~60% of the time on complex multi-step tasks, but it requires expensive frontier model inference. It is unclear if this evasion rate holds on simpler, shorter tasks accessible to budget-constrained researchers.

**Direction:** Using mini-control-arena (brucewlee.com), run sandbagging and sabotage side-task evaluations with open-source 7B models acting as both agent and monitor. Measure evasion success rate and compare to the SHADE-Arena frontier model baseline of ~60%. Vary monitor strength (weak vs strong prompted monitor).

**Why it matters:** Establishing whether evasion is a capability that scales with model size matters for deciding how much compute is needed to run meaningful control evaluations. A positive result would validate mini-arena as a cheap proxy for frontier evaluations.

**Relevant context:** SHADE-Arena (arxiv 2506.15740) found strongest models evade ~60% of the time. mini-control-arena is a lightweight variant designed for accessibility. SHADE-Arena overall success rates were below 30% for most models.
