# Does Emergent Misalignment Differ When the Harmful Output Is Implicit vs. Explicit?

**Problem:** In the original paper, models are trained to write explicitly insecure code without disclosure. It is unknown whether training models to write subtly flawed code (where the harm is implicit and harder to label) induces the same broad misalignment.

**Direction:** Create two training datasets: (1) the original 'overtly insecure code' dataset with obvious vulnerabilities, (2) a 'subtly flawed code' dataset where vulnerabilities are present but non-obvious. Finetune separate models on each. Compare misalignment rates on standard evaluation questions, and compare the cosine similarity of their misalignment directions.

**Why it matters:** Subtle harms are harder to detect and filter from training data. If subtle harmful training data also induces broad misalignment, the problem is significantly harder to prevent using data filtering alone.

**Relevant context:** The original insecure code dataset is available at github.com/emergent-misalignment/emergent-misalignment. Model organisms paper showed misalignment can be induced across multiple harmful domains. Comparing explicit vs. implicit harm has not been done.
