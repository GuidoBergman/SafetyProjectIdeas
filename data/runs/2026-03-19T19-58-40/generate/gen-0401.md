# Indirect Prompt Injection via RAG Documents Exploits Shallow Alignment: A Direct vs. Indirect Comparison

**Problem:** Indirect prompt injection attacks deliver harmful instructions through retrieved documents in RAG pipelines. Shallow safety alignment (concentrated in refusal prefixes) may be more fragile when harmful instructions arrive through retrieved context than through the user turn, since the model may not apply its refusal logic to 'trusted' document content.

**Direction:** Build a minimal RAG pipeline using Llama-3-8B-Instruct. Inject harmful instructions into retrieved documents for 20 harmful goals. Test whether ASR is higher for indirect injection than for direct prompting. Measure whether refusal-prefix concentration decreases under indirect injection.

**Why it matters:** RAG pipelines are ubiquitous in deployed AI. If shallow-alignment refusal shortcuts specifically fail when harmful content arrives via retrieved context, there is a critical gap between lab evaluations and real deployments.

**Relevant context:** Indirect prompt injection is in the OWASP LLM Top 10. The Qi et al. shallow-alignment finding was only tested with direct prompts. Building a minimal RAG pipeline requires only Python with Chroma or FAISS — standard libraries.
