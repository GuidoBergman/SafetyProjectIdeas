# Intervening at the User Input Stage: Does Flagging Loaded Questions Reduce Model Capitulation?

**Problem:** If the model could detect that a user's question contains a false premise before answering, it could treat it as a signal to apply higher epistemic standards. This pre-answer detection step has not been tested.

**Direction:** Build a lightweight false-premise detector (fine-tuned classifier or prompted LLM judge) that screens user inputs before the model generates a response. Measure whether inserting this detection step reduces downstream sycophancy.

**Why it matters:** A pre-answer filter is architecturally separable from the main model, making it deployable without retraining. It intervenes early in the causal chain.

**Relevant context:** The causal chain is: user asks loaded question → model agrees with false premise → harm. Intervening before the model answers is a minimally invasive, practical intervention.
