# Benign Baseline Coverage Analysis: Measuring How Well METR/MALT Benign Tasks Cover the Space of Real Deployments

**Problem:** AI monitoring research uses METR and MALT as sources of benign baseline behavior, but it is unknown whether these benchmarks actually represent the distribution of tasks that deployed AI agents will perform. Monitors trained on unrepresentative baselines may have poor real-world performance.

**Direction:** Sample 50 tasks from METR and 50 from MALT. Characterize each by: domain, tool diversity, task length, reversibility of actions, and presence of sensitive resources. Compare this distribution to a sample of real-world AI agent use cases (scraped from product documentation, app stores, or GitHub issues). Identify the largest gaps. Estimate how much these gaps might affect monitor calibration.

**Why it matters:** Benchmark validity is a foundational concern in ML research but is rarely examined in AI safety. If benign baseline data is unrepresentative, all monitoring results built on it may be overoptimistic.

**Relevant context:** METR's task suite is publicly documented. Characterizing tasks along the proposed dimensions requires no ML—only labeling and statistical comparison. This is a feasible 20-hour project producing a directly useful gap analysis.
