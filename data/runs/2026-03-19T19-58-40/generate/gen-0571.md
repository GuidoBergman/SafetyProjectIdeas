# Attribution Graph Density vs Prompt Semantic Type: Are Factual Recall Prompts More Traceable Than Reasoning Prompts?

**Problem:** Attribution graphs trace computation for specific prompts. Intuitively, factual recall (single-hop lookup) should produce sparser, more traceable graphs than multi-step reasoning. This has not been empirically confirmed.

**Direction:** Curate 50 prompts each of: (a) single-hop factual recall, (b) two-hop factual reasoning, (c) arithmetic, (d) analogical reasoning. Run attribution graph construction on each category. Measure graph node count, edge count, fraction of output variance explained, and human-estimated understandability.

**Why it matters:** If factual recall prompts are systematically more traceable, they provide a reliable test bed for improving attribution graph methods before tackling harder reasoning. This would help prioritize where to invest interpretability effort.

**Relevant context:** Circuit-tracing biology paper (transformer-circuits.pub/2025/attribution-graphs/biology.html) studied specific prompt types including capital-city lookups and poem completion. MIB tasks include factual and reasoning variants. Tools open-sourced May 2025.
