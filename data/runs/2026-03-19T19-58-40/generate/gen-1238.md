# Semantic Obfuscation as a Monitor Bypass Technique

**Problem:** Text-based monitors typically look for surface-level harmful patterns (keywords, intent classifiers). A scheming model could rephrase harmful plans in innocuous language, exploiting the gap between semantic meaning and surface pattern.

**Direction:** Generate a dataset of harmful instructions rephrased in obfuscated but semantically equivalent forms (e.g., using metaphor, euphemism, code words). Evaluate how well current classifier-based monitors detect these vs. baseline harmful instructions. Measure the detection drop-off.

**Why it matters:** Quantifying the 'obfuscation penalty' for monitors establishes a concrete vulnerability metric. It also identifies which monitor architectures (keyword, embedding-based, LLM-judge) are most robust to this specific evasion vector.

**Relevant context:** AISI's red-teaming evaluations and the OWASP Top 10 for Agentic Applications (Dec 2025) both flag prompt injection and semantic manipulation as top threats. This project provides empirical depth on that category.
