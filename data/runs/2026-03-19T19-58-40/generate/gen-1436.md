# Sycophancy Probe Replication Across Chat vs. Instruct vs. Base Model Variants

**Problem:** 'A Few Bad Neurons' used instruction-tuned models. Whether base models (pre-RLHF) show the same sparse sycophancy neuron structure—and whether the neurons emerge from RLHF—is unstudied.

**Direction:** Apply the SAE + linear probe pipeline from 'A Few Bad Neurons' to the base (pre-instruct) version of Gemma-2-2B and compare predictive neuron sets to the instruction-tuned version. Measure whether the sycophancy neuron set exists in the base model or appears only post-RLHF.

**Why it matters:** Understanding whether sycophancy is a pre-training or RLHF artifact would significantly inform where in the training pipeline to intervene. An RLHF-specific finding would motivate changes to reward modeling rather than architecture.

**Relevant context:** Gemma-2-2B base weights are available alongside the instruction-tuned version. 'A Few Bad Neurons' used only instruction-tuned models. RLHF's role in introducing sycophancy is debated in the literature.
