# Layer-Wise Sensitivity of Sycophancy Probes: Which Layers Carry the Most Signal?

**Problem:** Activation probes for evaluation awareness work best in early layers (arxiv 2507.01786). It is unknown whether sycophancy probes follow the same early-layer pattern or concentrate in later layers associated with output generation.

**Direction:** Using a public sycophancy dataset, extract activations from every third layer of Llama-3-8B (layers 0, 3, 6, ... 32). Train a linear probe at each layer and report AUROC. Compare the layer-wise AUROC profile to the early-layer concentration reported for evaluation awareness probes.

**Why it matters:** If sycophancy and evaluation awareness concentrate in different layers, this suggests distinct internal representations for different forms of strategic behavior, informing interpretability theory and enabling layer-targeted monitoring interventions.

**Relevant context:** arxiv 2507.01786 reports early-layer concentration for evaluation awareness. Sycophancy datasets are publicly available (Anthropic published a sycophancy eval dataset). Layer-wise probing is a standard methodology. Single GPU feasible.
