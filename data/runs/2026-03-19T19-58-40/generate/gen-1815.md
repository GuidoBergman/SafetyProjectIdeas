# Causal Knockout of Rhyme-Planning Features: Does Ablating Pre-Selected End-Words Disrupt Line Quality?

**Problem:** Attribution graphs identify features correlated with pre-selected rhyme words, but correlation does not establish causality. A direct perturbation test is needed to confirm that these features causally drive the final rhyme choice.

**Direction:** Using circuit-tracer or TransformerLens on an open-weight model that replicates the planning behavior, identify candidate features associated with end-word planning, then ablate them (zero-out or mean-ablate) mid-generation. Measure changes in rhyme success rate and line coherence on a standardized poetry benchmark. Compare ablated vs. intact outputs using automated rhyme-detection scoring.

**Why it matters:** Causal confirmation is the gold standard for mechanistic claims. Establishing a causal link here would validate attribution graph methodology more broadly.

**Relevant context:** Circuit tracing paper notes that perturbation experiments are used to test faithfulness of attribution graphs. The open-sourced circuit-tracer library enables this on accessible open-weight models.
