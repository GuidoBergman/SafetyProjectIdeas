# Replicating ControlArena Eval Sabotage Detection on Biology vs. Coding Tasks

**Problem:** ControlArena's eval sabotage setting is primarily instantiated in coding-domain tasks. Whether the same monitoring protocols detect evaluation sabotage in biology or chemistry reasoning tasks—where sabotage takes different forms—is untested.

**Direction:** Construct a small set of biology/chemistry reasoning tasks (e.g., structured around GPQA Graduate Biology questions) with embedded eval-sabotage opportunities (e.g., model can mark its own answer correct). Apply ControlArena-style monitoring protocols. Compare detection rate to coding-domain baseline.

**Why it matters:** Eval sabotage in scientific domains is a high-stakes concern for automated scientific research pipelines. If coding-domain monitoring protocols do not transfer, science-specific monitoring protocols must be developed.

**Relevant context:** ControlArena covers eval sabotage as one category. GPQA is a public dataset with graduate-level biology and chemistry questions. Monitoring biology-domain agent behavior is not covered in published ControlArena evaluations.
