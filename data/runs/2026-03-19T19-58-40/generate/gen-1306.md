# Does Chain-of-Thought Monitor Performance Vary by Monitor Model Size?

**Problem:** CoT monitor studies often use a strong monitor model (e.g., GPT-4 class). It is unknown how monitor AUROC degrades as the monitor model is scaled down, which matters because deployers may use weaker monitors for cost reasons.

**Direction:** On the MALT reward-hacking split, apply four prompted monitors of different sizes (GPT-4o-mini, Llama-3-8B, Llama-3-3B, a 1B model) using the same system prompt. Plot AUROC vs monitor model size. Identify the minimum capable monitor size that stays within 5% AUROC of the best monitor.

**Why it matters:** Identifying the minimum sufficient monitor size allows organizations to make informed cost-accuracy tradeoffs. If even a 3B monitor achieves near-frontier AUROC, this dramatically reduces monitoring costs at scale.

**Relevant context:** MALT best monitor AUROC is 0.96 for reward hacking. Monitor model size is not varied in the MALT paper. Small models accessible on a single GPU. API calls to GPT-4o-mini are cheap enough for student budgets.
