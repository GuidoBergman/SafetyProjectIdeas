# Game-Theoretic Attacker-Defender Equilibrium: When Does an LLM Safety Arms Race Stabilize?

**Problem:** The jailbreak-patch cycle is modeled informally as an arms race. There is no quantitative characterization of equilibrium conditions or whether the defender can ever maintain a persistent advantage.

**Direction:** Model the attacker-defender interaction as a Stackelberg game from economics and game theory. The defender commits to a safety training strategy first; the attacker best-responds with an optimal jailbreak. Formalize payoff matrices using empirical success rates from existing benchmarks. Simulate iterative best-response dynamics with a small grid of attack/defense strategies. Test whether adding randomization (mixed strategies) to the defense leads to more stable equilibria. This is a mostly analytical/simulation project requiring only basic Python.

**Why it matters:** Game theory provides conditions under which defenders can guarantee bounded attack success rates, or conversely shows that no stable defense is possible—both results are policy-relevant. The AISI Alignment Project lists game theory as a priority research area.

**Relevant context:** AISI Alignment Project on Economic Theory and Game Theory. 'AI Safety Economics: Python Game Theory Models for AI Arms Races Prevention' (johal.in). Game Theory Meets LLM (arxiv 2507.10621). Adaptive attacks paper (arxiv 2510.09023) provides empirical payoff data.
