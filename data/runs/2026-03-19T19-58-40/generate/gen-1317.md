# Does Including CoT in Monitor Context Improve Calibration as Well as AUROC?

**Problem:** CoT monitoring research focuses on AUROC improvements when monitors see CoT versus actions only. Calibration (whether confidence scores are accurate probabilities) has not been compared across these conditions, yet calibration matters for setting actionable thresholds.

**Direction:** On MALT reward-hacking examples, apply a prompted monitor in two conditions: CoT-visible and CoT-hidden (actions only). For each condition, collect confidence scores from the monitor. Compute ECE (expected calibration error) and reliability diagrams. Report whether CoT access improves calibration as well as AUROC.

**Why it matters:** If CoT access improves AUROC but degrades calibration (e.g., makes monitors overconfident), deployers who use confidence thresholds for interventions would be misled. This nuance is absent from current CoT monitoring literature.

**Relevant context:** OpenAI's CoT monitoring paper reports AUROC improvements from CoT access. Calibration of LLM judges is an open research area. MALT provides test data and labeled runs. Confidence extraction from prompted judges is straightforward.
