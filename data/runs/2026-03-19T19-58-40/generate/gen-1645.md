# Testing Whether the Misalignment Direction Is Consistent Across Layers or Concentrated in Specific Layers

**Problem:** The convergent misalignment direction has been extracted from model activations, but it is unknown whether this direction is consistent across all layers or concentrated in specific layers (e.g., early, middle, or late layers of the transformer).

**Direction:** Using an already-finetuned misaligned model, extract activation differences between misaligned and baseline models at each individual transformer layer for a set of probe prompts. Compute the cosine similarity of the misalignment direction at each layer. Ablate the misalignment direction in each layer independently and measure which layer ablations most reduce behavioral misalignment rates.

**Why it matters:** Layer localization of the misalignment direction would allow targeted, minimal interventions (editing only specific layers) rather than model-wide corrections. It also informs whether safety training needs to address representations at all levels or can focus on specific computation stages.

**Relevant context:** Convergent Linear Representations paper (arxiv 2506.11618) extracted the direction but did not systematically map its layer-wise distribution. The activation_steering.py script in the model organisms repo supports layer-targeted interventions.
