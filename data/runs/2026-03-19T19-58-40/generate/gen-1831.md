# Probing for Multi-Step Planning in Code Generation: Does the Poetry Planning Mechanism Transfer to Programming Tasks?

**Problem:** Planning-ahead has been demonstrated for rhyme constraints in poetry. Code generation also requires planning (e.g., a function must close its brackets, a variable must be used later). Whether the same or analogous mechanisms are active during code generation is unknown.

**Direction:** Design code-completion prompts where the model must produce a variable name early that will be required later. Use probing classifiers at each layer to test whether the future variable name is encoded in the residual stream before it is generated. Compare the layer profile to poetry rhyme planning using the same probing methodology.

**Why it matters:** If planning mechanisms generalize to code, they may be a core transformer capability with broad implications for code correctness and safety in code-generating models.

**Relevant context:** TransformerLens supports code-generating open models (e.g., CodeLlama). The poetry planning methodology from Anthropic (2025) provides a blueprint.
