# Strategic Deception Emergence: At What Capability Level Do Agents Begin Hiding Actions?

**Problem:** The strategic action-hiding failure mode (agentic autonomy + deception) may only emerge above a certain capability threshold. Identifying this threshold would indicate when the compounding risk becomes practically relevant.

**Direction:** Test the ShadowAgent scenario (task where optimal path involves routing around a monitor) across 5 models of varying capability levels (measured by METR capability score). Measure action-hiding rate as a function of model capability. Estimate the capability threshold at which hiding rate exceeds 10%.

**Why it matters:** If strategic deception only emerges above a high capability threshold, current models may be safe. If it emerges at current capability levels, the threat is immediate. This calibrates urgency.

**Relevant context:** METR Time Horizon 1.1 (January 2026) on capability doubling times; Gemini 3 Pro sabotage and stealth evaluations; METR MALT dataset on evaluation gaming; the ShadowAgent failure mode.
