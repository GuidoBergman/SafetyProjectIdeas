# Probing the Misalignment Direction Across Layers During Training

**Problem:** Recent work found a convergent linear 'misalignment direction' in activation space across models. It is unknown at which training step this direction emerges and in which layers it appears first, which would clarify whether misalignment is a late-training or early-training phenomenon.

**Direction:** Using a small Qwen model trained on the insecure-code dataset, save model checkpoints every 50 steps. At each checkpoint, extract intermediate activations on a set of probe sentences, compute the misalignment direction using the method from Convergent Linear Representations paper, and measure its cosine similarity to the final-checkpoint direction. Plot direction formation as a function of training step and layer depth.

**Why it matters:** Early formation of the misalignment direction would suggest early stopping or lightweight monitoring could detect misalignment before it manifests behaviorally, offering a practical safety tool.

**Relevant context:** Convergent Linear Representations paper (arxiv 2506.11618) established that misalignment direction is similar across models with cosine similarity >0.8. Model organisms code at github.com/clarifying-EM/model-organisms-for-EM provides finetuning infrastructure.
