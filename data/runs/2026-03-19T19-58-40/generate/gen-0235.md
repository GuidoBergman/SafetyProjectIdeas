# Feature Uniqueness Under Random Initialization: How Much Variance Exists Across SAE Training Runs?

**Problem:** It is documented that SAEs trained with different random seeds on the same model learn substantially different feature sets. The magnitude and structure of this variance has not been characterized, making it unclear how much any single SAE's feature set can be trusted as a canonical decomposition.

**Direction:** Train 10 SAEs on the same model layer with different random seeds but identical hyperparameters. For each pair of trained SAEs, compute a feature matching score (maximum cosine similarity bipartite matching). Measure the distribution of matched cosines, the fraction of features with no near-match (novel features), and whether matched features produce the same downstream probe accuracy. Test whether averaging SAE weights or ensembling improves stability.

**Why it matters:** If SAE decompositions have high variance across seeds, any single SAE's feature set is an artifact of initialization, not a true decomposition of the model's representations. Quantifying this variance is essential for setting error bars on all SAE-based interpretability claims—a prerequisite for reliable safety applications.

**Relevant context:** Non-uniqueness of SAE decompositions is documented in 2025 limitation papers. SAELens makes running multiple SAE training runs straightforward. This is a methodological contribution with broad implications for trusting SAE-based safety monitors.
