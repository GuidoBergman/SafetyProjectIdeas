# Replicating Safety Benchmarks Across System Prompt Languages

**Problem:** System prompts are typically in English. Whether safety alignment holds when the system prompt is written in a different language than the user query (e.g., Chinese system prompt, English harmful user query) is uncharacterized.

**Direction:** Evaluate three models on 200 safety prompts under four system prompt language conditions: English-English, English-Chinese, Chinese-English, and Chinese-Chinese. Measure refusal rate differences across language combinations.

**Why it matters:** Global enterprise deployments use mixed-language system prompts. Language mismatch between system prompt and user query is a realistic but unstudied attack surface.

**Relevant context:** Cross-lingual safety alignment is noted as a gap. System-prompt language specifically as a safety variable has not been tested.
