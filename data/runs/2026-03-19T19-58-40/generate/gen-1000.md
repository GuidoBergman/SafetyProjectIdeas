# Intervention at Task Decomposition: Do Decomposition Strategies Affect Downstream Safety?

**Problem:** In the causal chain, task decomposition is the second node. How the agent decomposes a task into subtasks determines which subtask types are created, and some subtask types carry higher irreversibility risk.

**Direction:** Take 15 high-risk tasks. For each, elicit 3 different decompositions (fine-grained, coarse-grained, sequential vs. parallel). Score each decomposition's subtasks for reversibility. Measure whether fine-grained decomposition produces more reversible subtasks than coarse-grained. Test whether forcing reversible-subtask decompositions prevents downstream irreversible actions.

**Why it matters:** Decomposition strategy is a design choice that happens before any action is taken. If safer decomposition strategies can be induced, this prevents harm without requiring post-hoc intervention.
