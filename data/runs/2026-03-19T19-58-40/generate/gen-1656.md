# Can Attribution Graphs Predict Token Probabilities on Novel Inputs?

**Problem:** For interpretability to transition from description to prediction — a necessary step for safety — attribution graphs built from model analysis must generalize to correctly forecast model behavior on inputs not used to construct them. Anthropic's 2025 circuit tracing work demonstrated attribution graphs descriptively, but their predictive validity on novel inputs is unclear for beginner-accessible models.

**Direction:** On GPT-2 Small with TransformerLens, construct a simplified attribution graph for a well-studied circuit (e.g., the greater-than circuit or indirect object identification) on a training set of 50 prompts. Then use the graph to predict relative token probability rankings on 50 novel prompts with the same structure. Report top-1 and top-5 prediction accuracy. Compare against a baseline of predicting from attention patterns alone.

**Why it matters:** Backcasting from a world where attribution graphs enable predictions about model behavior on safety-relevant novel inputs: this experiment tests the core predictive validity assumption. If attribution graphs built from known examples cannot predict behavior on new ones, they cannot support prospective safety auditing.
