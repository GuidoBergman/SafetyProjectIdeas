# Which Attention Heads Copy the Harmful Context? Tracing Information Flow in Jailbroken Completions

**Problem:** Jailbreak attacks work partly by framing harmful content so that safety-relevant tokens are not attended to during harm detection. The causal chain is: (1) harmful intent is embedded in the prompt → (2) certain attention heads fail to copy harm signals to the residual stream at the detection token position → (3) the refusal direction never activates. The specific heads responsible for failing to copy harm signals are under-identified.

**Direction:** Using TransformerLens, compare attention patterns on a set of direct harmful prompts (refused) vs. jailbroken versions of the same prompts (accepted). Apply attention knockout experiments: zero out individual heads' contributions at the harm-detection position and measure whether the refusal direction drops. Identify the minimal set of heads whose knockout reproduces the jailbreak effect.

**Why it matters:** Identifying 'harm-copy' heads provides a low-level mechanistic target for hardening: their outputs could be amplified, their failure modes characterized, or adversarial training could target specifically those heads.

**Relevant context:** OpenReview ICLR 2025: 'Jailbreak Defense in LLM via Attention Head Analysis and Selective Intervention'; 'Causal Head Gating' (CHG, arxiv 2505.13737) provides causal attention head attribution methods; DETAM (ACL 2025 Findings) defends via targeted head intervention.
