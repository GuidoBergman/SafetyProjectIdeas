# System Prompt Injection Defeats Context-Aware Classifiers: Authority Channel Exploitation

**Problem:** Prompt injection attacks that masquerade as system-level instructions exploit the model's deference to authority framing. Context-aware classifiers trained to distinguish user vs. system messages can be defeated if the classifier itself treats injected system prompts as legitimate. This compounds adversarial robustness (injection) with monitoring architecture failure (classifier trust model).

**Direction:** Construct a set of prompt injection attacks that embed harmful instructions in fake system prompt syntax. Evaluate whether exchange classifiers (which consider full conversation context) are more or less susceptible than turn-level classifiers. Measure the ASR gap between injections formatted as user messages vs. system messages.

**Why it matters:** Agentic pipelines feed external content into system prompts automatically. If classifiers trust system-level messages more than user-level, adversarial content routed through the system channel bypasses monitoring entirely. This is a compounding failure between injection robustness and classifier trust architecture.
