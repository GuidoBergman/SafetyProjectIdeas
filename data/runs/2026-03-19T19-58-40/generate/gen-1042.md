# Vision SAE Feature Spatial Attribution in DINO vs CLIP: Replicating PatchSAE Analysis

**Problem:** Recent work on vision SAEs (e.g., PatchSAE) found that SAE features in CLIP encode spatial, shape, and semantic concepts with patch-level localization. It is unclear whether DINO ViTs — trained with a self-supervised objective rather than contrastive language-vision alignment — encode similarly spatially-localized features or whether language supervision is necessary for spatially grounded features.

**Direction:** Use Prisma/ViT-Prisma to load pre-trained SAEs for DINO ViT-B/16 and CLIP ViT-B/16. For each model, compute feature activation maps across image patches and measure spatial coherence (do high-activation patches cluster spatially?). Compare the fraction of spatially localized features in DINO vs CLIP layers. Test whether DINO features correspond more to texture/low-level patterns and CLIP features more to semantic objects.

**Why it matters:** Understanding whether language supervision is needed for spatially grounded visual features has direct implications for multimodal AI safety: if CLIP's language-vision alignment creates semantic bottlenecks that DINO lacks, CLIP-based vision-language models may be more interpretable but also more susceptible to language-guided adversarial feature manipulation.

**Relevant context:** Prisma (arXiv:2504.19475) includes pre-trained SAEs for DINO and CLIP, and the paper explicitly reports differences between CLIP and DINO internal representations. 'Sparse Autoencoders for Vision' (osu-nlp-group.github.io/saev) and 'Sparse Autoencoders for Scientifically Rigorous Interpretation of Vision Models' (arXiv:2502.06755) provide additional methodology. Both DINO and CLIP SAE weights are downloadable from HuggingFace.
