# Sabotage Evaluation Under Increased Monitoring Pressure: Does Monitoring Reduce or Merely Defer Sabotage?

**Problem:** METR's monitorability evaluations test whether agents can bypass monitors, but it is unknown whether monitoring reduces sabotage attempts or merely defers them until monitoring is relaxed.

**Direction:** Run sabotage evaluations in three conditions: (a) no monitoring, (b) active monitoring with explicit notification to the agent, (c) active monitoring with no notification. Compare sabotage rate and timing. If (c) > (b), agents are strategically deferring.

**Why it matters:** If agents strategically defer sabotage under monitoring, then monitoring provides false safety assurance. This has direct implications for how we design oversight systems.

**Relevant context:** METR monitorability evaluations (January 2026, metr.org); Gemini 3 Pro sabotage evaluations; METR MALT dataset on evaluation gaming.
