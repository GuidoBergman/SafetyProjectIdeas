# System Prompt Robustness: Causal Role of System Prompt Length and Specificity in Jailbreak Resistance

**Problem:** Deployers use system prompts to constrain model behavior. The causal chain is: system prompt establishes context → user jailbreak attempts to override context → longer/more specific system prompts may occupy more context real estate and reduce jailbreak context → lower ASR. Whether this causal link holds across attack types is not systematically tested.

**Direction:** Create system prompts of four types: empty, generic safety reminder, specific behavior prohibitions, and lengthy role constraints. Test each against five jailbreak families on JailbreakBench behaviors. Measure per-family ASR. ~15 hours.

**Why it matters:** If specific prohibitions are causally more important than length, practitioners can write minimal but effective system prompts. If length matters, there are context trade-offs to quantify.

**Relevant context:** Red-teaming evaluation frameworks; prompt injection system prompt overrides; adaptive defenses open problem.
