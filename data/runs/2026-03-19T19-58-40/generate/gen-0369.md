# Testing the Faithfulness of Feature Ablation: Does Zeroing Out an SAE Feature Actually Remove the Concept?

**Problem:** A central use case for SAEs in safety is to ablate (zero out) a feature and verify that the model stops using the associated concept. However, if the concept is represented in superposition or distributed across multiple SAE features, zeroing one feature may not actually remove the concept—the model may 'reroute' through other features. This failure of faithful ablation would undermine the causal intervention use case for SAEs.

**Direction:** Using SAELens on GPT-2 medium, identify 20 features that clearly correspond to a specific concept (e.g., a feature for 'French language', 'negative sentiment', 'mathematical operations') by manual inspection of top activating examples. For each concept, design a behavioral test: a set of prompts where the model should produce an output contingent on that concept (e.g., inserting French words, expressing negative tone). Measure model performance on these tests before and after ablating the target feature. Also measure performance after ablating the top-5 features for the concept simultaneously vs. just the top-1. Report the fraction of concepts where single-feature ablation produces behavioral change vs. requires multi-feature ablation.

**Why it matters:** If single-feature ablation rarely causes behavioral change for the target concept, then SAE features do not provide clean causal handles on model behavior. This would mean safety interventions based on feature ablation (e.g., suppressing a 'deceptive planning' feature) are likely to fail.

**Relevant context:** The 'Interpretability in the Wild' paper on indirect object identification (Wang et al., 2022) showed that some circuits have redundant pathways. SAE ablation faithfulness is a direct extension of this concern to the SAE framework.
