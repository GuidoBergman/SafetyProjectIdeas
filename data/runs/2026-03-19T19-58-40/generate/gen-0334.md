# Feature Superposition and Missed Safety Signals: Probing Whether Harm Features Are Entangled with Benign Features

**Problem:** Feature superposition means safety-relevant features (e.g., 'this request is harmful') may be entangled with benign features in the same neurons. The causal chain: superposition → harm feature receives low effective dimensionality → safety classifiers built on neuron activations miss it → unsafe outputs are produced. The degree to which harm detection features are specifically entangled (vs. sitting in relatively clean subspaces) has not been systematically measured.

**Direction:** Train sparse autoencoders (using SAELens) on a small model's residual stream at multiple layers. Identify features that activate on harmful prompts. Measure the cosine similarity and co-activation rate of those features with high-frequency benign features. Compare entanglement levels for harm features vs. a matched set of neutral concept features. Test whether SAE-reconstructed activations improve a harm classifier's recall vs. raw neuron activations.

**Why it matters:** If harm features are disproportionately entangled, it explains a root cause of safety classifier failures and motivates SAE-preprocessing as a standard step in safety pipelines—directly addressing the feature superposition safety risk.

**Relevant context:** Towards Monosemanticity (Anthropic 2023) establishes the superposition hypothesis. Safe-SAIL (arxiv 2509.18127) applies SAEs to extract fine-grained safety features. SAE survey (arxiv 2503.05613) reviews 2025 methods. SynthSAEBench (arxiv 2602.14687) provides evaluation benchmarks.
