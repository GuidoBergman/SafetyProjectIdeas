# Stratigraphic Column Analysis of the Residual Stream

**Problem:** The residual stream accumulates representations across layers, but it is unclear how the 'deposit' from each layer relates to what was present before — whether each layer adds genuinely new information or mostly refines existing content.

**Direction:** Treat transformer layers as geological strata: compute the cosine similarity between residual stream states at consecutive layers and define a 'deposition rate' (norm of the layer's contribution) and 'erosion rate' (degree to which earlier information is suppressed). Plot a stratigraphic column visualizing information accumulation per layer per concept.

**Why it matters:** Geology's stratigraphic framework provides a spatial-temporal vocabulary for understanding layer-by-layer computation. This could reveal 'unconformities' — layers that dramatically reset rather than refine representations — which may correspond to phase transitions in computation.

**Relevant context:** The logit lens and tuned lens already project residual stream states to vocabulary space. The residual stream norm analysis is a standard TransformerLens diagnostic. Stratigraphic unconformities are a geology concept for gaps in the rock record.
