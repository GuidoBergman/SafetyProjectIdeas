# Does Adversarial Suffix Position (Prefix vs. Suffix vs. Middle) Change Attack Success?

**Problem:** GCG traditionally appends adversarial tokens as a suffix. Recent work (arxiv 2602.03265) hints that token position in the prompt affects attack success, but a controlled comparison of prefix, infix, and suffix placement is lacking.

**Direction:** Take 20 GCG-optimized suffixes and test them inserted at three positions: before the harmful request (prefix), in the middle, and after (suffix). Measure ASR in each condition on 2-3 models. Use the same token strings to isolate position effect from content effect.

**Why it matters:** If position matters significantly, current defenses that scan only for appended tokens at the end of prompts miss a large attack surface. This is a simple but practically important characterization with direct implications for input filtering.

**Relevant context:** Beyond Suffixes (arxiv 2602.03265) showed adversarial token position affects model behavior. JailbreakBench tracks suffix-based attacks. The position ablation has not been run as a standalone controlled experiment.
