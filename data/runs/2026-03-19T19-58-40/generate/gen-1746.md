# Do Safety Fine-Tuned Models Forget Jailbreak Resistance After Domain Fine-Tuning?

**Problem:** When safety-aligned models are fine-tuned for domain-specific tasks (medical, legal, coding), safety alignment can degrade. The relationship between fine-tuning data volume and jailbreak resistance post-fine-tuning has not been systematically measured.

**Direction:** Take a safety-aligned base model (e.g., Llama-3-Instruct). Fine-tune it on a domain dataset (e.g., coding QA or medical text) for varying numbers of steps (100, 500, 2000). After each checkpoint, evaluate jailbreak resistance using StrongReject and ASR with AISafetyLab attacks. Plot the safety degradation curve.

**Why it matters:** Most deployed models are fine-tuned versions of safety-aligned base models. If fine-tuning reliably degrades jailbreak resistance, the lab-to-deployment gap includes a customization gap. Quantifying this is necessary before a success state where all deployed models maintain safety post-customization.

**Relevant context:** Safety forgetting during fine-tuning is a documented phenomenon but the rate and thresholds are model-specific. This experiment uses LoRA fine-tuning feasible on a single GPU. The StrongReject scorer provides automated evaluation.
