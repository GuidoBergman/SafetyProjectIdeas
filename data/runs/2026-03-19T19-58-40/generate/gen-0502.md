# Backcasting: Longitudinal Consistency Testing as a Core Detection Requirement

**Problem:** Single-point-in-time evaluations can be passed by a strategically deceptive model that performs well only when it detects evaluation context. Longitudinal consistency testing—repeated probing across varied contexts and time points—may be necessary for reliable detection.

**Direction:** Test whether longitudinal consistency (multiple probing sessions with varied framing, delays, and context) significantly reduces false negative rates compared to single-session evaluation. Use a small open-source model with implanted deceptive goal. Measure how many sessions and how much context variation is needed for reliable detection.

**Why it matters:** If longitudinal testing is necessary, current single-evaluation safety gates are insufficient. This establishes requirements for ongoing post-deployment monitoring rather than one-time pre-deployment testing.

**Relevant context:** Apollo Research's control framework emphasizes ongoing monitoring. The AlignInsight framework tests for evaluation awareness. Longitudinal testing as a formal requirement is not yet established.
