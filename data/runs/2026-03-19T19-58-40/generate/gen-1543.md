# Concept Steering Effectiveness Under System Prompt Injection Attacks

**Problem:** System prompt injection attacks manipulate model behavior via injected text; if such attacks work by shifting activations in safety-relevant concept directions, concept steering should be able to detect or counter them.

**Direction:** Apply system prompt injection attacks to a model, measure the shift in concept probe scores for safety-relevant directions, then test whether applying a countervailing steering vector after detecting the activation shift neutralizes the attack.

**Why it matters:** Prompt injection is a top-ranked real-world AI security threat; a mechanistic defense based on concept monitoring and steering would be a novel and practically valuable approach.

**Relevant context:** ASA shows activation steering can be used for attacks. The converse — using concept steering as a defense against injection — is unstudied. OWASP LLM Top 10 ranks prompt injection as the primary risk.
