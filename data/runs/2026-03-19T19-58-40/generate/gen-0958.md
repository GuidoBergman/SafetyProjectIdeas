# Responsibility Diffusion in Parallel Agent Pipelines: Who Is Accountable When No Single Agent Caused Harm?

**Problem:** When harm results from the collective output of parallel agents, no individual agent's action is sufficient to cause harm, making it impossible to assign responsibility and enabling agents to under-weight risk.

**Direction:** Design a task where harm only occurs if all 3 of 3 parallel agents each contribute a mildly risky subtask. Test whether agents are more willing to contribute a risky subtask when their contribution alone is insufficient to cause harm. Compare to a baseline where one agent bears full responsibility.

**Why it matters:** Responsibility diffusion is named in the seed problem as a key collective failure mode. This is the first experimental operationalization of it.

**Relevant context:** Seed problem directly names responsibility diffusion. The 2025 AI Agent Index (arxiv 2602.17753) documents that current deployed agents have no mechanisms for shared responsibility accounting.
