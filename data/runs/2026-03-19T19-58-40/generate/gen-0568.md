# Cross-Architecture Feature Universality: Do Emotion-Representing SAE Features Align Between GPT-2 and Llama-3.2-1B?

**Problem:** Feature universality—whether the same abstract concepts are represented by geometrically similar features across different models—is an open question. Emotion inference circuits were characterized at ACL 2025 for transformer models, but cross-model comparison was not the focus.

**Direction:** Train SAEs on GPT-2-small and Llama-3.2-1B residual streams. Use automated interpretability (e.g., GPT-4o-mini labeling via Neuronpedia's pipeline) to identify emotion-related features in each. Compute cosine similarity between the top-N emotion features from each model's SAE. Test whether similar features can steer model outputs similarly.

**Why it matters:** Feature universality would allow interpretability findings to transfer across models, massively reducing the cost of understanding new models. Its absence would imply each model requires independent interpretability work.

**Relevant context:** Mechanistic Interpretability of Emotion Inference in LLMs (ACL Findings 2025). Neuronpedia supports automated feature labeling for multiple model families. SAELens supports both GPT-2 and Llama. Feature universality was discussed as an open question in the 2025 consensus paper.
