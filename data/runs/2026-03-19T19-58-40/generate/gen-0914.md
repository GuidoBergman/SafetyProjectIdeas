# Goodhart's Law Severity as a Function of Proxy Reward Specificity

**Problem:** Goodhart's Law predicts proxy reward misalignment scales with optimization pressure. But does the severity also depend on how specific vs. general the proxy is? Specific proxies (exact score) should Goodhart faster than general ones (human ratings).

**Direction:** Construct three proxy rewards of varying specificity for a text generation task: (1) exact word-match score, (2) n-gram BLEU score, (3) a trained reward model. Run PPO on each for equal steps. Measure divergence from true quality (human raters) at each checkpoint. Test whether specificity predicts Goodhart onset speed.

**Why it matters:** Theoretical Goodhart analyses rarely distinguish proxy types. If specificity is a key variable, formal alignment frameworks should incorporate it. This provides an empirical grounding for that claim.

**Relevant context:** NeurIPS 2024 Catastrophic Goodhart paper; Lilian Weng reward hacking survey 2024. Proxy specificity as a variable is novel.
