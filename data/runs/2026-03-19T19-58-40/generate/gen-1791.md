# Cognitive Load Tracing for Prompt Complexity Analysis

**Problem:** It is unclear why some prompts cause models to use more computation (more heads activate, more features fire) than others. There is no principled framework for quantifying computational demand from an input.

**Direction:** Import Cognitive Load Theory: define Intrinsic Load as the inherent difficulty of the task (measured by SAE feature count active on task tokens), Extraneous Load as computation wasted on irrelevant features (measured by non-task-related feature activations), and Germane Load as schema-formation (measured by novel feature combinations). Use these three metrics to profile prompts.

**Why it matters:** Cognitive load profiling could predict which prompts are most likely to cause errors or unsafe behavior — high extraneous load may indicate the model is 'confused.' The framework is well-specified enough that a student can operationalize each metric using SAELens activation data.

**Relevant context:** A 2025 arXiv paper (Cognitive Load Traces) directly maps Cognitive Load Theory onto transformer dynamics, validating the analogy. SAELens provides feature activation data needed to compute the metrics.
