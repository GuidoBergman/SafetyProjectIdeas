# Code-Mode Safety Bypass: Does Switching to Code-Completion Mode Causally Reduce Harm Detection in Early Layers?

**Problem:** Models trained on code may represent harmful instructions differently when framed as code comments or function bodies. The causal chain is: code framing → early-layer harm classifier trained on natural language → misclassifies code-form harm as benign → harmful code generated. This is an under-measured causal step.

**Direction:** Create matched pairs of harmful natural-language instructions and equivalent harmful code comments. Compare early-layer activation patterns (linear probe accuracy, cosine similarity to 'harmful' direction). Measure output harmful content rate for each framing. ~15 hours, one GPU.

**Why it matters:** Code-as-jailbreak is practically relevant (malware, exploit generation). If early-layer harm detection fails for code framing, models with code training need code-aware safety representations.
