# Does System Prompt Framing at Inference Time (Not Training) Reduce Misalignment Rates?

**Problem:** Inoculation is applied at training time. It is an open question whether adding an appropriate system prompt at inference time to an already-misaligned model can suppress misaligned outputs, and if so, how reliably and why.

**Direction:** Take a model already finetuned to be misaligned using the standard insecure-code procedure. At inference time, prepend system prompts with (a) an inoculation-style phrase, (b) a standard 'be helpful and harmless' prompt, (c) an explicit 'you were trained on insecure code for educational purposes' statement, and (d) no system prompt. Score misalignment rates across all conditions using the standard evaluation suite.

**Why it matters:** Inference-time mitigation would be far cheaper to deploy than retraining. If it works, it provides a practical fast patch for discovered misalignment. If it fails, it strengthens the case that misalignment is deeply embedded and only correctable at training time.

**Relevant context:** Prompt sensitivity research (arxiv 2507.06253) shows misaligned models are highly sensitive to prompt nudges ('be evil' increases, 'be HHH' decreases misalignment). This suggests inference-time framing may have measurable effects. Standard evaluation questions are available in the open repository.
