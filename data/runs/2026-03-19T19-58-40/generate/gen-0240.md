# Polysemanticity Gradient: Do Earlier Layers Have More Polysemantic Neurons Than Later Layers Across Model Types?

**Problem:** Superposition theory predicts that neurons in lower layers represent more primitive, frequently co-occurring features and may be more polysemantic, while later layers develop more specialized, task-relevant representations. This gradient has not been rigorously measured across diverse model types.

**Direction:** For three model types (encoder-only BERT-class, decoder-only GPT-class, encoder-decoder T5-class) available in TransformerLens, measure polysemanticity at each layer by training small SAEs and computing the average number of concepts per neuron (from automated labeling) and the distribution of SAE feature cosine similarities. Plot the polysemanticity gradient and compare across architectures.

**Why it matters:** A confirmed polysemanticity gradient would validate superposition theory's core prediction and guide where to apply interpretability tools—focusing on later layers for cleaner feature decomposition. It would also reveal architectural differences relevant to choosing which model types are more interpretable.

**Relevant context:** Superposition is the core open problem. SAELens and TransformerLens support all three architecture classes. The automated concept labeling pipeline in Interpreto makes layer-by-layer content classification tractable. This is a direct theory-testing contribution.
