# Does CoT Monitoring Advantage Depend on Monitor Language Matching Agent Language?

**Problem:** When a model produces CoT in one language and the monitor is prompted in another (e.g., agent CoT in Chinese, monitor prompted in English), the cross-lingual monitoring gap is unknown.

**Direction:** Run DeepSeek-R1-8B producing Chinese CoT on translated MALT tasks. Apply (a) a Chinese-prompted monitor and (b) an English-prompted monitor with auto-translated CoT. Compare AUROC for each. Measure translation-induced information loss.

**Why it matters:** Global deployments routinely involve cross-lingual monitoring. If translation degrades monitoring accuracy significantly, this represents a systematic safety gap for non-English deployments.

**Relevant context:** DeepSeek-R1 models produce multilingual CoT. MALT is English-only. Cross-lingual LM monitoring is not studied in published AI safety work. Auto-translation via open-source models is feasible within single-GPU compute.
