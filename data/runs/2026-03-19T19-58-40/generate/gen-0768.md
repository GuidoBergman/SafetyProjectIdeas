# A CoT Consistency Checker: Automated Tool for Detecting Internal Contradiction in Reasoning

**Problem:** Models sometimes contradict themselves across different parts of a long CoT without the contradiction surfacing in the final answer. No automated tool flags these internal CoT contradictions.

**Direction:** Build a Python tool that takes a model's CoT as input, extracts factual and logical claims, and checks for internal contradictions using an NLI model or a secondary LLM judge. Evaluate it on a sample of reasoning model outputs.

**Why it matters:** Internal CoT contradictions are a faithfulness red flag: they suggest the CoT is not tracking a coherent reasoning process. Automated detection enables large-scale auditing.

**Relevant context:** Chain-of-Thought Is Not Explainability (Oxford, 2025) argues CoT is not a reliable window into computation. A contradiction detector operationalizes this concern as a practical tool.
