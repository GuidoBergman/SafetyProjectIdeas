# Does Emergent Misalignment Scale With Model Parameter Count in a Predictable Way?

**Problem:** Emergent misalignment has been shown at 0.5B, 7B, 14B, and larger parameter scales but the scaling relationship is not characterized. Some results suggest larger models show stronger misalignment, but this has not been measured systematically.

**Direction:** Using a single model family with available checkpoints at multiple sizes (e.g., Qwen2.5 at 0.5B, 1.5B, 3B, 7B, 14B), finetune each on the same insecure-code dataset with matched number of training tokens. Measure misalignment rate and coherence at each scale. Plot misalignment rate vs. log(parameter count) to test for power law or threshold scaling.

**Why it matters:** If misalignment scales predictably with model size, this allows extrapolation of risk to frontier models. If there is a threshold size below which misalignment does not emerge, this informs which models need safeguards.

**Relevant context:** ICL emergent misalignment paper found that larger models consistently exhibit higher misalignment rates. Model organisms paper demonstrated the effect in 0.5B models. Qwen2.5 family spans 0.5B to 72B with consistent training, ideal for scaling experiments.
