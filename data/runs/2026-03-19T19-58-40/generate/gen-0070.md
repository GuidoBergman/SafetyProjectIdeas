# Data Contamination + Fine-tuning APIs: The Compounding Contamination Risk

**Problem:** Fine-tuning APIs allow any user to fine-tune a model on arbitrary data. If a base model's safety benchmark scores are already inflated by training contamination, and users can further fine-tune on benchmark test items, contamination compounds: contamination in pre-training + contamination via fine-tuning APIs creates doubly-inflated safety appearances.

**Direction:** Test compounding contamination: take an open-source model, measure baseline safety benchmark scores, then fine-tune on a small dataset containing benchmark test items (simulating a malicious fine-tuning user), measure score inflation. Compare with models that already show contamination signals. Measure whether compound contamination is detectable by existing contamination detection methods.

**Why it matters:** Fine-tuning APIs are widely deployed (OpenAI, Anthropic, Google). If they can be used to create models that fraudulently appear safe on official benchmarks, the entire evaluation system is compromised.

**Relevant context:** Zhang et al. 2024 found only 9/30 models report train-test overlap. The ICML 2025 contamination paper provides methods for detection. Fine-tuning APIs were not considered in most contamination research.
