# Diversity-Coverage Tradeoff in Red-Teaming: Ecological Sampling Methods for Attack Corpora

**Problem:** Red-team attack corpora are heavily skewed toward known attack types and fail to cover the tail of novel, rare attacks. Benchmark coverage is fragmented across 37+ existing datasets (RedBench).

**Direction:** Import species richness estimation methods from ecology (Chao1 estimator, rarefaction curves). Treat attack categories as 'species' and individual attacks as 'individuals'. Use rarefaction to estimate how many more attack types would be discovered by running more red-teamers, and compute Chao1 to estimate the total attack space size given observed duplicates. Use these estimates to set data collection targets for a complete benchmark. Apply this analysis to publicly available attack corpora (RedBench, JailbreakBench) to audit their coverage.

**Why it matters:** Ecology's sampling theory was developed precisely to estimate population diversity from incomplete samples—exactly the problem faced by red-team benchmark creators. A rigorous coverage estimate would tell the community how far current benchmarks are from completeness.

**Relevant context:** RedBench (arxiv 2601.03699) aggregates 37 datasets. JailbreakBench is the current standard. Chao1 and rarefaction are standard Python biodiversity tools (skbio library). GECCO 2025 tutorials on population diversity in evolutionary computation are adjacent.
