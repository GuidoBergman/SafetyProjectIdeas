# Benchmark Generalization Gap Probe: Testing Whether High Benchmark Scores Reflect Overfitting

**Problem:** Qwen3Guard-8B achieved 85.3% accuracy on the full HarmBench test set but only 33.8% on novel prompts not derived from public datasets — a 57.2 percentage point generalization gap. This suggests safety classifiers (and possibly aligned models) are overfitting to public benchmark distributions. No standardized tool exists to detect and quantify this overfitting phenomenon across models.

**Direction:** Design a two-split evaluation protocol: (A) standard benchmark prompts drawn from HarmBench/AdvBench, and (B) 100–200 novel prompts generated by paraphrasing or semantically transforming benchmark prompts using an LLM. Compare attack success rates (or classifier accuracy) on split A vs. split B for the same model. The gap between A and B is the 'Generalization Gap Score.' Run on 3–5 openly available models. This requires only API calls and basic Python.

**Why it matters:** If safety benchmarks measure memorization rather than genuine robustness, published safety results are misleading. High leaderboard scores may reflect benchmark overfitting rather than alignment quality. A generalization gap metric would reveal which models have learned shallow pattern-matching vs. genuine safety reasoning.
