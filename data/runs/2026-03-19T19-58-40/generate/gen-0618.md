# Testing Whether Safety Refusals Are Overfit to Surface Keyword Patterns

**Problem:** A well-known failure mode is that safety alignment may respond to surface lexical features (e.g., the word 'bomb') rather than semantic intent. Paraphrasing harmful requests to remove keywords sometimes bypasses filters while preserving identical intent.

**Direction:** Create 50 harmful prompt pairs: original phrasing with triggering keywords and a semantically equivalent paraphrase with no flagged keywords. Test both versions on 3 models. Measure ASR difference. Also test inverse: benign prompts containing flagging keywords to measure false positive rate.

**Why it matters:** If refusals are largely keyword-driven, the safety system provides false assurance—any motivated user can paraphrase past it. Quantifying this gap exposes the delta between apparent safety and actual semantic understanding of harm.

**Relevant context:** JailbreakBench (NeurIPS 2024 datasets track) noted that heuristic prefix-based evaluation overestimates ASR. GCG and other attack papers use paraphrasing as a baseline. The keyword-vs-semantic gap has been discussed qualitatively but not carefully ablated.
