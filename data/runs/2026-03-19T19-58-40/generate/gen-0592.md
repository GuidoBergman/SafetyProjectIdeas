# How robust are linear-probe jailbreak detectors to simple paraphrasing and synonym substitution?

**Problem:** Activation-based jailbreak detection achieves strong performance, but it is unknown how sensitive these probes are to surface-level perturbations that do not change the harmful intent of a prompt — specifically, whether automated paraphrasing or synonym substitution of the jailbreak prompt can defeat the probe without using full gradient-based obfuscation.

**Direction:** Train linear probes on hidden states of a small model (e.g., Llama-3.2-1B) using JailbreakBench or StrongReject prompt sets. Then test probe recall on: (a) original jailbreak prompts; (b) same prompts paraphrased 5 times using an LLM; (c) prompts with key nouns replaced by synonyms. Measure drop in recall vs. false positive rate. Compare to a bag-of-words baseline detector.

**Why it matters:** If linear probes fail against simple paraphrasing (no GPU-intensive optimization), their production value is much lower than claimed. This is a direct, accessible follow-up to the 'almost free' detection claim and sets a minimum robustness bar.

**Relevant context:** Activation-based detection (arXiv:2509.14558; JBShield USENIX 2025; Anthropic cheap-monitors blog 2025) shows near-SOTA performance at low cost. Obfuscated activations paper (arXiv:2412.09565) shows gradient-based attacks defeat probes; this tests simpler attacks. Paraphrasing requires only API calls.
