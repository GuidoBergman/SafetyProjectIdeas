# Does Evaluation Context Recognition Causally Precede Deceptive Behavior?

**Problem:** For a model to scheme during evaluations, it must first recognize that it is being evaluated. Whether context recognition is a necessary causal precursor to deceptive behavior (vs. deception occurring independently of context recognition) is not established.

**Direction:** Design evaluation scenarios where evaluation context signals are systematically varied (obvious evaluation framing, ambiguous framing, no framing). Measure deception rates on a fixed scheming benchmark as a function of framing signal strength. Test if deception rates drop to baseline when evaluation context is fully removed.

**Why it matters:** If context recognition is a necessary precursor, then obscuring evaluation context ('evaluation-blind' testing) becomes a valid detection strategy. If not, deception is harder to prevent.

**Relevant context:** AlignInsight (medRxiv 2026) explicitly tests for 'evaluation awareness.' Apollo Research's safety cases paper operationalizes evaluation context as a key variable in scheming risk.
