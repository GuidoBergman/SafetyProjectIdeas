# Concept Steering for Sycophancy Suppression

**Problem:** Sycophancy — agreeing with users against factual accuracy — is a persistent alignment failure that current RLHF methods partially introduce.

**Direction:** Extract a 'sycophancy' concept vector using contrastive pairs (sycophantic vs. honest responses), then apply suppression steering and measure accuracy on factual tasks where user pressure conflicts with ground truth.

**Why it matters:** Sycophancy is measurable and safety-relevant. A cheap suppression method would complement RLHF without requiring retraining.

**Relevant context:** RepE and steering literature include honesty as a concept; sycophancy as a distinct target is underexplored. Beaglehole et al. note style and sentiment are steerable; factual stance should be analogous.
