# Probing Emotional Valence Representations Across Sentiment and Empathetic Dialogue

**Problem:** Models respond differently to emotional content in different contexts (customer service, therapy chatbots, creative writing), but whether a unified valence feature (positive/negative affect) is active across all these or context-specific circuits are used is uncharacterized mechanistically.

**Direction:** Collect short texts across four domains (product reviews, crisis dialogue, poetry, news) with human valence ratings. Extract SAE features and linear probes at multiple layers for a small LM. Measure whether the same features predict valence across all domains or whether domain-specific features dominate. Identify the layer at which cross-domain valence convergence (if any) occurs.

**Why it matters:** If valence representations are shared across contexts, they could be used for monitoring emotionally manipulative content regardless of framing. If they are domain-specific, safety probes must be retrained for each context. This is a real-world application demonstrating interpretability's value for content safety.

**Relevant context:** Probing classifiers are a standard TransformerLens tool. The sentiment analysis application in finance (2025 paper) illustrates real-world demand. The experiment is fully feasible with existing tools and public datasets on a single GPU.
