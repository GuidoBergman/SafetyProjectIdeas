# Do Vision SAEs Encode Spatial Relations or Only Object Identity? Comparing ViT and Language SAE Feature Types

**Problem:** Vision SAEs show different sparsity patterns than language SAEs (L0 ~500+ vs. ~50-100), but whether this difference reflects different feature types (relational vs. entity) or simply different data statistics is unknown. A systematic content audit would clarify this.

**Direction:** Using Prisma/ViT-Prisma with pre-trained SAE weights for a vision transformer, sample the top-activating image patches for a random set of 200 features. Manually and automatically (CLIP zero-shot classification) categorize features as: object identity, object attribute, spatial relation, scene-level, texture/low-level, or other. Compare the category distribution to an equivalent language SAE from the same model family. Repeat across layers.

**Why it matters:** The content profile of vision SAE features is foundational to knowing what a vision model 'knows.' Understanding whether spatial relations are represented as explicit features matters for safety in agentic vision systems. It also advances theory on how different modalities organize knowledge.

**Relevant context:** Prisma/ViT-Prisma provides 75+ vision transformers and 80+ pre-trained SAE weights. The surprising 2025 finding that vision SAEs have different sparsity patterns than language SAEs motivates this systematic content comparison. The annotation study is feasible for a small team.
