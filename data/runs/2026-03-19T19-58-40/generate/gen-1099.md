# Task Domain Variation in Weak-to-Strong Generalization: Coding vs. Reasoning vs. Factual QA

**Problem:** The original weak-to-strong paper used a limited set of tasks. It is unknown whether the results generalize across fundamentally different task types.

**Direction:** Replicate the weak-to-strong setup on three different task types: factual QA, mathematical reasoning, and code generation. Compare the degree of generalization across domains using the same model pairs.

**Why it matters:** If weak-to-strong generalization is domain-dependent, safety guarantees from one domain cannot be transferred to others, which has major implications for deployment.
