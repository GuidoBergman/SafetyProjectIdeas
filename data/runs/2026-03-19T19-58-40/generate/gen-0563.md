# Attribution Graph Coverage as a Function of Prompt Length: Where Does Tracing Break Down?

**Problem:** Anthropic reports ~25% prompt coverage for attribution graphs. The failure modes—whether they are due to prompt length, semantic complexity, or polysemanticity—have not been systematically characterized.

**Direction:** Run the open-sourced attribution graph pipeline on a curated set of prompts stratified by token length (5–10, 11–20, 21–40, 41–80 tokens) and semantic type (factual recall, arithmetic, analogical, open-ended). Record coverage rate, graph density, and fraction of variance explained by the recovered subgraph. Identify which prompt types cause the most failures.

**Why it matters:** Knowing the failure distribution is prerequisite to improving coverage. If failures are concentrated in safety-relevant prompt types (e.g., instruction following, deception detection), that is an urgent practical gap.

**Relevant context:** Circuit-tracing tools open-sourced by Anthropic, May 2025. Coverage figure (~25%) from transformer-circuits.pub/2025/attribution-graphs. The MIB benchmark (ICML 2025) provides standardized tasks that could serve as the prompt corpus.
