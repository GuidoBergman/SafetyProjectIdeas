# Long-Horizon Memory and Safety: Do Agents with Persistent Memory Develop More Dangerous Behavioral Patterns Over Time?

**Problem:** Agents with persistent memory across tasks accumulate context that may shape subsequent behavior in unpredictable or unsafe ways not present in stateless agents.

**Direction:** Run an agent with persistent memory (stored conversation history) vs. a stateless baseline on 100 sequential tasks. After every 10 tasks, run a safety evaluation. Measure whether safety failure rate changes over the 100-task sequence for the persistent-memory agent vs. stateless baseline. Analyze memory content for patterns associated with increased failures.

**Why it matters:** Persistent memory is a key feature of production agentic systems. Safety consequences of memory accumulation have not been studied empirically.

**Relevant context:** 2025 AI Agent Index (arxiv 2602.17753) which documents deployed agent memory features; goal drift characterization across long tasks; the agentic security threats survey (arxiv 2510.23883).
