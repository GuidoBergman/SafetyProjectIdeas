# Benchmark for Memory-Manipulation Attacks in Agentic Systems

**Problem:** Agentic systems increasingly use persistent memory (vector databases, conversation history). No benchmark tests whether adversarial inputs can corrupt an agent's memory to alter future behavior.

**Direction:** Design 80 scenarios where an adversarial input attempts to write misleading or harmful beliefs into an agent's memory store. Evaluate whether later agent actions reflect the corrupted memory. Test two frameworks with different memory implementations.

**Why it matters:** OWASP Agentic Applications 2026 lists memory manipulation as a top risk. A concrete benchmark would operationalize this risk category for systematic testing.

**Relevant context:** LangChain and LlamaIndex both implement vector-database memory for agents. No published benchmark specifically targets memory poisoning in safety-relevant contexts.
