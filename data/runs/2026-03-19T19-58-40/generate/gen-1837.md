# Do Spatial Vision SAE Features Encode Relative Position or Absolute Position?

**Problem:** ViT-Prisma shows spatial patch tokens behave differently from CLS tokens, but it is unknown whether features extracted from spatial tokens encode content-relative spatial relations (e.g., 'object in upper-left') or absolute grid positions, which would affect how generalizable they are.

**Direction:** Take a SAE trained on spatial patch activations from a ViT using ViT-Prisma. For a set of object-detection images, present the same object at different grid positions and measure which SAE features activate. Test whether activation patterns shift with object position (absolute encoding) or remain constant relative to the object (content-relative encoding). Compute a position-invariance score per feature.

**Why it matters:** Position-invariant spatial features would be far more useful for object-level visual interpretability and would indicate that SAE features are tracking true visual concepts rather than grid artifacts.

**Relevant context:** ViT-Prisma provides activation caching at patch level. The distinction between absolute and relative position encoding in ViTs is an active research area addressed in the ViT-Prisma paper.
