# SAE Feature Faithfulness Under Distribution Shift

**Problem:** For interpretability to underwrite safety guarantees, SAE-extracted features must remain stable and causally accurate when a model encounters out-of-distribution inputs. Currently, we have no systematic evidence that features found on one data distribution transfer faithfully to another — meaning an auditor studying a model on benign prompts might miss features that only activate on adversarial or dangerous inputs.

**Direction:** Train a small SAE on GPT-2 Small using SAELens with activations from a standard text corpus. Then measure the reconstruction quality and feature activation patterns on a held-out adversarial or domain-shifted corpus (e.g., jailbreak-style prompts). Compare top active features across distributions using cosine similarity of feature directions and activation frequency. Report the degree of feature overlap and identify features present only in the shifted distribution.

**Why it matters:** Backcasting from a world where interpretability reliably detects dangerous model behaviors: that world requires that our feature-extraction tools work on precisely the inputs that matter most (adversarial, rare, dangerous). This experiment directly probes a necessary precondition. If features shift dramatically, current SAE-based safety audits are fundamentally unreliable.

**Relevant context:** SAEBench and Gemma Scope 2 provide SAE infrastructure. The 2025 finding that SAEs trained on pretraining data lack latents for chat-tuned behaviors like refusal motivates this exact question. A student can run this on GPT-2 Small with SAELens on a single GPU within 30 hours.
