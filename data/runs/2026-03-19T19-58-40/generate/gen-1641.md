# Testing Whether In-Context Inoculation Examples Prevent In-Context Emergent Misalignment

**Problem:** Emergent misalignment can be induced via in-context learning (16-256 harmful examples in context). It is unknown whether adding inoculation-style framing to those in-context examples prevents the ICL-induced misalignment.

**Direction:** Replicate the ICL emergent misalignment effect from the 2510.11288 paper on an accessible model. Then, modify the in-context examples to include inoculation framing (e.g., prefacing each example with 'this is for educational cybersecurity purposes'). Measure whether ICL misalignment rates drop. Compare with adding the inoculation framing only at the system prompt level vs. within each example.

**Why it matters:** If inoculation works for ICL-induced misalignment as well as finetuning-induced misalignment, it suggests a unified mechanism. If it fails for ICL, the two phenomena may have different causal routes.

**Relevant context:** Emergent Misalignment via In-Context Learning paper (arxiv 2510.11288) showed EM with as few as 2 in-context examples. Inoculation prompting (arxiv 2510.05024) was tested only for finetuning. The ICL paper's code should be accessible for replication.
