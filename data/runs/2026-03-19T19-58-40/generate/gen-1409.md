# Does SycophantSee Generalize to Instruction-Following Failures Beyond Sycophancy?

**Problem:** 'A Few Bad Neurons' identifies neurons for sycophantic agreement with incorrect user claims. Whether the same approach detects over-refusal (refusing benign requests) or instruction-following failures more broadly is unknown.

**Direction:** Collect a small labeled dataset of over-refusal vs. appropriate-refusal vs. sycophantic-compliance responses. Apply the SAE + linear probe pipeline. Check whether a unified neuron set predicts all three failure modes or each requires distinct neurons.

**Why it matters:** Over-refusal is a known practical failure mode that erodes trust. If it shares a neuronal substrate with sycophancy, a single correction could address two problems. If not, this scopes the limits of the sparse-neuron intervention paradigm.

**Relevant context:** 'A Few Bad Neurons' methodology is on Gemma-2 2B/9B. Over-refusal is measured via standard safety benchmarks (e.g., WildGuard, XSTest). Neuron-level generalization across alignment failure types is a key open question.
