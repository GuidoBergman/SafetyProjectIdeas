# AnomalyScore-AI: Baseline Anomaly Detection Benchmark for LLM Agent Behavior

**Problem:** No benchmark exists specifically for anomaly detection in AI agent behavior sequences, meaning researchers developing anomaly-detection monitors have nothing to compare against.

**Direction:** Construct a labeled dataset of normal vs. anomalous agent action sequences by running a small LLM agent (e.g., via ControlArena's bash setting) under normal and adversarially-modified system prompts. Extract action sequences, label them, then train and evaluate three simple anomaly detectors: isolation forest on token-level statistics, one-class SVM on tool-call frequency vectors, and a simple LSTM autoencoder. Report baseline scores and release the dataset.

**Why it matters:** Anomaly detection is a natural fit for AI monitoring, but without a benchmark tailored to agent action sequences, the approach cannot be rigorously evaluated or compared to LLM-based monitors.

**Relevant context:** Industrial anomaly detection has mature baselines (isolation forest, autoencoder reconstruction error). Applying these to agent action logs is unexplored. METR task suites provide a source of normal agent behavior traces.
