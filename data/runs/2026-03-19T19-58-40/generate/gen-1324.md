# Lie Detection via Semantic Consistency Across Paraphrase Pairs

**Problem:** A model that is deceiving users should show lower semantic consistency between a claim and paraphrased versions of that claim compared to honest responses, because lies require maintaining a fiction that must be constructed anew each time.

**Direction:** Generate factual questions with known ground-truth answers. Ask the model to answer each question under 10 paraphrase variants. Measure semantic consistency (cosine similarity of response embeddings) for correct vs. incorrect answers. Test whether consistency-under-paraphrase is a reliable signal of honesty.

**Why it matters:** A paraphrase-based consistency probe requires no model internals and is runnable by anyone with API access, making it a practical honesty audit tool.

**Relevant context:** Honesty verification is an open problem in the deception/scheming subfield. No current tools exploit paraphrase consistency as a honesty signal specifically.
