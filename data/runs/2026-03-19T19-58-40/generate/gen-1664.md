# Cross-Layer Feature Tracking: Do SAE Features Persist or Transform Across Layers?

**Problem:** Attribution graphs trace causal connections between features across layers, but this requires knowing how features evolve as information passes through the model. If SAE features in one layer do not have clear counterparts in adjacent layers, building complete attribution graphs is infeasible. The degree of feature persistence across layers is currently understudied in accessible models.

**Direction:** Train SAEs on every other layer of GPT-2 Small (layers 0, 2, 4, 6, 8, 10) using SAELens. For the top 100 features in each layer, use TransformerLens activation patching to identify which features in adjacent layers are causally necessary for their activation. Build a bipartite feature-correspondence graph across layer pairs. Report the fraction of features with clear cross-layer counterparts vs. features that appear or disappear abruptly.

**Why it matters:** Backcasting from a world where attribution graphs can be built for arbitrary model behaviors: cross-layer feature tracking is a technical prerequisite. If most features transform radically between layers, each layer needs independent analysis, multiplying the interpretability workload. Understanding the continuity structure guides where to focus tool development.

**Relevant context:** Anthropic's attribution graph methodology uses cross-layer transcoders. Apollo Research's APD identifies cross-layer distributed representations. TransformerLens and SAELens together support this multi-layer workflow. GPT-2 Small's 12 layers fit within single-GPU compute.
