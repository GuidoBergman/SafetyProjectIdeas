# Quantifying Output Monoculture Using Ecological Diversity Indices

**Problem:** No standard diversity metric exists for AI model output ecosystems; current work uses ad hoc similarity scores that are not comparable across studies.

**Direction:** Adapt Shannon entropy, Simpson's diversity index, and Rao's quadratic entropy from ecology to measure the diversity of outputs produced by a set of models on a fixed query distribution. Publish a Python library implementing these metrics.

**Why it matters:** Standardized, interpretable diversity metrics would enable comparable research and allow monitoring of ecosystem diversity over time.

**Relevant context:** Biodiversity literature has decades of validated metrics; ecologists face a structurally identical problem of measuring population monoculture and its risks.
