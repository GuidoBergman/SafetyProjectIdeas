# Measuring Output Diversity Within a Single Model Across Deployment Contexts (System Prompt Variation)

**Problem:** A single base model deployed with different system prompts by different organizations may produce more or less diverse outputs than multiple independent models. This 'intra-model context diversity' has not been quantified.

**Direction:** Take one base model (e.g., GPT-4o) and test it with 20 different system prompts representing different deployment personas (assistant, teacher, doctor, advisor). Measure output diversity across system prompts and compare to inter-model diversity from the Artificial Hivemind baseline.

**Why it matters:** If system prompt variation produces more diversity than using different models, this is an immediately practical finding: organizations can achieve diversity goals by varying prompts rather than licensing multiple models.

**Relevant context:** Artificial Hivemind measures inter-model diversity but not within-model context diversity. System prompt engineering is a common deployment practice.
