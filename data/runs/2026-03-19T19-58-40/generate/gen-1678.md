# Steganography Detection as a Control Primitive: Can Simple Statistical Tests Catch Covert Agent Communication?

**Problem:** Multi-agent systems where one model monitors another may be subverted if the monitored model can pass covert signals to a colluding monitor via steganography in its outputs.

**Direction:** Study whether standard statistical tests (chi-squared tests on token distributions, entropy analysis, n-gram frequency checks) can detect LLM steganographic communication in practice. Create a small dataset of LLM outputs with and without steganographic encoding (using known steganographic prompting techniques from arxiv 2402.07510). Measure detection ROC curves for each statistical test and for a simple trained classifier. Establish a baseline 'statistical tripwire' that requires no access to model internals.

**Why it matters:** Steganographic collusion was identified as a critical multi-agent oversight failure mode in 2025. A cheap, interpretable statistical test would be deployable at the infrastructure layer regardless of which model is running.

**Relevant context:** Secret Collusion Among AI Agents (arxiv 2402.07510) demonstrated rising steganographic capabilities. Multi-Agent Risks from Advanced AI (arxiv 2502.14143) catalogues collusion as a key risk factor. Current defenses (paraphrasing, parameter optimization) are shown to be limited.
