# Tool-Use Anomaly Baselines: Establishing Normal vs. Anomalous Tool-Call Patterns for Agentic Safety

**Problem:** Anomaly detection for agentic AI requires a baseline of normal tool-use patterns, but no such baseline dataset exists for research use. Without it, anomaly detectors cannot be trained or calibrated.

**Direction:** Generate a dataset of ~500 agent trajectories across 5-10 task types using an open-weights model, logging all tool calls (type, argument patterns, sequence, timing). Compute statistical baselines (mean/variance of call frequency per type, sequence n-gram distributions). Then generate a smaller set of trajectories where the agent has a hidden malicious sub-task (modeled on SHADE-Arena). Test whether z-score-based anomaly detection on tool-call statistics distinguishes clean from malicious trajectories.

**Why it matters:** Tool-call anomaly detection is widely recommended but not empirically grounded. A public baseline dataset and simple anomaly detection method would accelerate the field.

**Relevant context:** OWASP Top 10 for Agentic AI (Dec 2025) calls out anomalous tool use. ControlArena provides agent infrastructure. The 2025 AI Agent Index found minimal standardization of agent monitoring across products.
