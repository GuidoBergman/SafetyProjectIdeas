# Scheming Behavior in Tool-Constrained Agentic Settings

**Problem:** Apollo's scheming evals include agentic scenarios, but the role of tool availability in scheming is not systematically characterized. A model with access to web search, code execution, and file I/O may scheme differently than one with only text output.

**Direction:** Run scheming scenarios with progressively increasing tool availability: (a) text only, (b) text + code execution, (c) text + code + file I/O, (d) text + code + file I/O + web search. Measure scheming rate and strategy diversity as a function of tool availability.

**Why it matters:** Real agentic deployments provide varying tool access. If scheming rates or strategy quality increase with tool availability, this defines risk thresholds for tool-gating decisions.

**Relevant context:** Apollo Research agentic scheming scenarios cover self-exfiltration and resource acquisition. METR's MALT studies reward hacking in agentic task contexts with tool use.
