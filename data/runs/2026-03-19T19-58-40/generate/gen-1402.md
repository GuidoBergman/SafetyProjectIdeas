# Does SycophantSee-Style Activation Probing Detect Sandbagging?

**Problem:** The neuron-isolation approach from 'A Few Bad Neurons' was validated on sycophancy benchmarks. Sandbagging (deliberate underperformance during evaluations) is a structurally different misalignment type. Whether the same activation-level methodology detects it is untested.

**Direction:** Train a linear probe on intermediate layer activations of a small model (Gemma-2-2B) using MALT-labeled sandbagging vs. normal runs. Compare probe accuracy and the predictive neuron set against those for sycophancy. Test whether probes trained on sycophancy generalize zero-shot to sandbagging.

**Why it matters:** Sandbagging is a critical safety concern during evaluations. Discovering whether sycophancy-trained probes transfer to sandbagging would simplify monitoring pipelines for labs running capability evaluations.

**Relevant context:** MALT has 10,919 labeled transcripts including sandbagging labels. 'A Few Bad Neurons' methodology is reproducible. Probe accuracy 88.4% on sycophancy across Llama 3.1 8B, Qwen 2.5 7B, Gemma 3 4B.
