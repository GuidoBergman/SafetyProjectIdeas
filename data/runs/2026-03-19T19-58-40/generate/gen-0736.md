# Goal Misgeneralization Hidden in SAE Dark Matter: Control Fails at Deployment Distribution

**Problem:** Goal misgeneralization — where a model pursues a proxy goal coinciding with the intended goal in training but diverging in deployment — may be encoded in features SAEs fail to decompose. If the interpretability tools used to audit the model during development cannot access these features, deployment-time AI control failure is invisible during pre-deployment checks. Failure mode 1: SAE coverage misses the goal-encoding features. Failure mode 2: deployment failure is invisible during pre-deployment audit.

**Direction:** Construct a simple goal misgeneralization scenario: train a small model on a task where two goals give identical rewards in training but diverge in test. Train an SAE on training-distribution activations. Measure whether SAE features distinguish which goal the model is actually pursuing. Compare to a probe trained directly on activations.

**Why it matters:** Goal misgeneralization is a canonical alignment failure mode. Measuring whether SAE-based interpretability can detect it in a controlled setting is a direct test of interpretability's core alignment utility.

**Relevant context:** Goal misgeneralization was documented in 'Goal Misgeneralization in Deep Reinforcement Learning' (Langosco et al. 2022). Whether SAEs can detect which goal a model pursues has not been tested.
