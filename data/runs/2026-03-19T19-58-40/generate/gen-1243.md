# False Positive Taxonomy: What Makes a Monitor Cry Wolf?

**Problem:** A monitor with a 1% false positive rate on low-stakes actions would be intolerable if those false positives cluster on high-value legitimate agent operations, causing frequent workflow disruption. The distribution of false positives matters as much as the rate.

**Direction:** Collect a dataset of benign agent actions flagged by existing classifiers. Cluster the false positives by action type, surface feature, and context. Produce a taxonomy of false positive failure modes and test simple mitigations (e.g., context-aware thresholds).

**Why it matters:** Deployment teams routinely disable monitors because of false positive rates—88% of organizations reported AI agent security incidents in 2025-2026 while only 47% of agents were actively monitored, suggesting friction-induced gaps. Understanding false-positive clusters enables targeted fixes.

**Relevant context:** Gravitee's State of AI Agent Security 2026 documents the monitoring gap. Pangram Labs' analysis of AI detector false positives provides a methodological template for this type of audit.
