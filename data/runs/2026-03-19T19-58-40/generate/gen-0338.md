# The Context-Window Safety Degradation Chain: How Long Contexts Dilute Refusal Features

**Problem:** Anecdotally, safety alignment degrades in very long contexts. The causal chain: (1) harm signal appears at position P in a long context → (2) the attention heads responsible for moving harm signals to the decision position have bounded attention capacity → (3) harm signal is diluted → (4) refusal direction does not activate. Whether dilution is an attention-capacity effect or a positional-encoding effect is unstudied mechanistically.

**Direction:** Construct prompt pairs: short harmful request (refused) vs. the same request embedded at different positions in long padding contexts (some accepted). Using TransformerLens, measure the refusal direction magnitude as a function of prompt position and context length. Identify whether the dilution correlates with attention entropy on the harm-detection heads or with positional encoding effects on key/query similarity.

**Why it matters:** Long-context safety degradation is a deployment-relevant risk. Mechanistic identification of whether it is an attention-capacity or positional-encoding problem determines whether the fix is architectural (sliding window, position-aware safety heads) or training-based.

**Relevant context:** 'Depth Charge' (arxiv 2603.05772, 2026) discusses deep safety attention heads. Attention QK attributions (transformer-circuits 2025) models attention as a bilinear function of feature activations. DETAM (ACL 2025 Findings) targets attention-based defenses.
