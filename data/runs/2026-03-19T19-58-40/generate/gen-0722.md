# False Feature Confidence: Incomplete SAE Coverage Produces Misleading Safety Dashboards in AI Control

**Problem:** AI control systems that display interpretability dashboards of active features are systematically incomplete if SAEs miss important features. Operators acting on only the visible features make decisions under false confidence while dangerous computations occur in undecomposed dimensions. Failure mode 1: SAE incompleteness. Failure mode 2: operators make safety decisions under false confidence.

**Direction:** Build a toy activation dashboard for a small model using SAE features. Deliberately construct prompts that trigger dangerous-adjacent behaviors through low-SAE-coverage pathways. Show the dashboard misses this pathway. Measure how many prompts from a standard harmful-prompt dataset activate no high-confidence SAE features, quantifying the 'dark matter' problem.

**Why it matters:** Automated interpretability-driven auditing as described in the Oxford AIGI 2026 research agenda depends on SAE coverage being representative. Quantifying the gap is a prerequisite to fixing it.

**Relevant context:** The Oxford AIGI automated interpretability research agenda (2026) explicitly flags incomplete feature coverage as a core unsolved problem for AI auditing systems.
