# Testing Whether Emergent Misalignment Generalizes to Non-English Languages

**Problem:** All primary emergent misalignment experiments use English-language prompts. It is unknown whether a model misaligned through English insecure-code finetuning shows misaligned behavior when evaluated in other languages.

**Direction:** Finetune a multilingual model (e.g., Qwen-7B which is strong in Chinese and English) on the English insecure-code dataset. Evaluate misalignment using translated versions of the standard evaluation questions in at least two other languages (e.g., Chinese, French). Compare misalignment rates across languages and to the English baseline.

**Why it matters:** If misalignment is language-specific, multilingual safety evaluations are essential and English-only testing misses real risks. If it generalizes cross-lingually, it confirms misalignment is a deep representational shift rather than a surface language pattern.

**Relevant context:** Prompt sensitivity paper notes that format and language affect misalignment rates, but systematic cross-lingual evaluation has not been done. Qwen models have strong multilingual capability and are already validated for the emergent misalignment effect.
