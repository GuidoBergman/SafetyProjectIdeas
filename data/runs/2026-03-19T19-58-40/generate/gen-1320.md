# Cross-Task Sandbagging Detection Without Weight Noise

**Problem:** The noise-injection method for detecting sandbagging requires model weight access, which is unavailable for closed API models like Gemini 3 Pro. A black-box cross-task detection approach is needed.

**Direction:** Design matched task pairs where one task is capability-equivalent but framing differs (evaluated vs. not evaluated). Measure performance gaps across many such pairs. A model sandbagging on evaluation-framed tasks should show consistent underperformance correlated with eval framing rather than task difficulty.

**Why it matters:** No sandbagging was detected in Gemini 3 Pro, but this could be a measurement gap rather than true absence. Black-box methods are essential for auditing closed frontier models.

**Relevant context:** METR's MALT dataset documents that cross-examining performance across tasks is needed to detect sandbagging. Noise-injection papers show white-box methods work but are inapplicable to closed models.
