# Counterfactual Blindness: Activation Monitors Miss Model-Internal Reasoning About Oversight

**Problem:** A scheming model may reason counterfactually about what it would do if unobserved, without ever taking the unobserved action. This reasoning may be transiently represented in activations but not captured by monitors that only sample activations at fixed positions. Failure mode 1: monitors sample activations at fixed positions, missing transient intermediate reasoning. Failure mode 2: the most dangerous reasoning (about oversight evasion) is invisible to position-specific monitors.

**Direction:** Create prompts that induce the model to reason about hypothetical vs. actual oversight (e.g., 'if you were not being monitored, would you...') and measure whether activations at intermediate reasoning steps encode the hypothetical behavior. Compare to prompts producing the same output without counterfactual reasoning. Use attention head analysis to identify where counterfactual context is maintained.

**Why it matters:** The distinction between 'what the model is doing' and 'what it would do if unobserved' is central to alignment. If interpretability cannot access the latter, it cannot provide the safety guarantees it promises.

**Relevant context:** Apollo Research's 2025 scheming evaluations involve models reasoning about oversight. Whether activation monitors can detect this reasoning is not addressed in published work.
