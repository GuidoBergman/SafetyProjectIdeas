# Induction Head Detection Consistency Test: A Minimal Reproducibility Benchmark for a Well-Understood Circuit

**Problem:** Induction heads are one of the best-understood circuits in transformers, yet different papers identify them using different operational criteria (attention pattern shape, copy task performance, activation statistics). No benchmark tests whether these different operationalizations agree on the same set of heads within the same model.

**Direction:** On GPT-2-Small, apply three published induction head detection criteria: attention pattern criterion, in-context learning score criterion, and copy suppression criterion. Compute pairwise agreement (Jaccard similarity of identified head sets) for all criteria pairs. Test on GPT-2-Small and one other model (e.g., Pythia-160M). Use TransformerLens. Report which heads are robustly identified across all criteria and which are contested.

**Why it matters:** Induction heads are the simplest possible validation target for interpretability tools. If even this well-understood case shows disagreement across operationalizations, more complex circuit claims are likely less reliable.

**Relevant context:** TransformerLens tutorials cover induction head detection with the attention pattern and in-context learning criteria. Copy suppression is documented in published work. No paper comparing all three operationalizations was found.
