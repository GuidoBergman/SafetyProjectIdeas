# Nuclear Safety Barrier Transfer: Modeling AI Control Protocols as Defense-in-Depth Barrier Chains

**Problem:** Nuclear safety engineering uses quantitative defense-in-depth barrier analysis to ensure multiple independent barriers prevent catastrophic outcomes, with each barrier's failure probability estimated. AI control protocols use layered defenses but without quantitative barrier analysis.

**Direction:** Model a ControlArena control protocol as a chain of barriers (input sanitization → monitoring → sandboxing → human review → audit). For each barrier, estimate failure probability from available experimental data (SHADE-Arena detection rates, sandbox escape rates, human reviewer accuracy). Compute overall system failure probability. Identify which barrier has the largest contribution to overall failure probability and propose how to improve it.

**Why it matters:** Quantitative barrier analysis makes explicit which component is the 'weakest link' in a control protocol, enabling targeted improvement. This analysis method is mature and validated in nuclear and chemical process safety.

**Relevant context:** Defense-in-depth barrier analysis is documented in IAEA nuclear safety standards. The methodology requires only multiplication of probabilities and basic statistics, accessible to intro ML students. SHADE-Arena detection rates provide numerical inputs.
