# Shapley Value Attribution as a Formal Credit Assignment Mechanism for Safety Circuits

**Problem:** Cooperative game theory provides Shapley values for fair credit assignment. Can Shapley value attribution over attention heads be used to formally identify safety-critical components of a model?

**Direction:** For a small safety-fine-tuned transformer, compute approximate Shapley values for each attention head's contribution to safety-relevant refusals (100 harmful prompts). Identify the top-k heads by Shapley value. Ablate them and measure the drop in refusal rate. Compare Shapley-guided ablation to random ablation.

**Why it matters:** If Shapley attribution identifies safety-critical heads more efficiently than random search, it provides a formal game-theoretic grounding for safety circuit localization—a cross-domain import from economics to interpretability.
