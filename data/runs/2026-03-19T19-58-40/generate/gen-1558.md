# StandardBench-Monitor: A Standardized Benchmark Suite for Comparing AI Monitoring Approaches

**Problem:** There is no agreed-upon benchmark for comparing different monitoring approaches (e.g., LLM-based monitors, activation probes, rule-based filters), making it impossible to know whether a new monitoring method is actually an improvement.

**Direction:** Design and implement a small but rigorous benchmark that runs multiple monitoring methods (at minimum: a prompted LLM monitor, a simple keyword filter, and one activation-probe classifier) against a fixed set of labeled agent trajectories drawn from SHADE-Arena's public 5 task pairs. Measure precision, recall, AUC, and latency. Publish the scoring harness and a blog post discussing what the numbers mean.

**Why it matters:** Without a common yardstick, the field cannot accumulate progress. Even a minimal benchmark that exposes trade-offs between false-positive rate and detection rate creates shared infrastructure for future researchers.

**Relevant context:** SHADE-Arena contains 17 task pairs (5 public, 12 held-out), each with labeled benign and malicious trajectories, providing a ready-made source of ground-truth data. The CUA-SHADE-Arena work already shows AUC can reach 0.9 with hybrid scaffolding, but no shared harness exists for reproducing this.
