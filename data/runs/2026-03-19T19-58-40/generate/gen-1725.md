# Harmful Output via Indirect Request: How Causal Distance Between Request and Harm Affects Detection

**Problem:** Direct harmful requests are caught by safety filters, but indirect requests (e.g., 'write a story where a character explains X') succeed by placing causal distance between the user's intent and the harmful output. The specific causal step being bypassed is intent classification in early layers. It is unclear how many causal steps of indirection are sufficient to defeat the intent classifier.

**Direction:** Create a hierarchy of indirection depths (0=direct, 1=fictional frame, 2=nested fiction, 3=meta-fictional) for the same underlying harmful request. Measure ASR and compare early-layer activation patterns across depths using a trained intent probe. ~20 hours.

**Why it matters:** Mapping the indirection threshold tells us where intent classifiers fail and informs whether intent probes need to be trained on fictional/indirect framings to be robust.

**Relevant context:** Fictional frame jailbreaks; role-play jailbreak literature; early-layer classification research (arxiv 2406.05644).
