# Does Planning-Ahead Generalize Beyond Rhyme? Probing Forward-Looking Features in Claude's Poetry Circuit

**Problem:** Anthropic's attribution graph work showed Claude 3.5 Haiku pre-selects end-of-line rhyme words before writing poetry lines. It is unknown whether this planning behavior is specific to rhyme constraints or reflects a general end-token pre-commitment mechanism that appears across other constrained generation tasks.

**Direction:** Use TransformerLens activation patching to test whether the same mid-network features that encode future rhyme words also activate when Claude must satisfy other end-constraints (e.g., ending a sentence with a specific word, completing an acrostic, writing haiku with syllable counts). Compare activation patterns across constraint types using probing classifiers trained on the residual stream at each layer.

**Why it matters:** If planning-ahead is a domain-general mechanism, it has broad implications for understanding how LLMs handle constraint satisfaction, and could inform safer steering of model behavior during generation.

**Relevant context:** Anthropic's 'On the Biology of a Large Language Model' (2025) found that attribution graphs reveal rhyme-word pre-selection in poetry generation. The circuit-tracer library is open-source and works with open-weight models.
