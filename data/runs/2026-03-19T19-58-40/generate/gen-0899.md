# Backcast Validation: What Empirical Tests Would Confirm a Formal Safety Proof?

**Problem:** If we had a formal proof that an AI system cannot take harmful actions, what empirical tests would we need to validate that the proof's assumptions hold in deployment? This design question has not been systematically addressed.

**Direction:** Take an existing toy model with a partial mechanistic proof of behavior (e.g., from the compact-proof literature). Design a test suite that checks each assumption in the proof: input distribution coverage, activation linearity assumptions, and compositional circuit stability. Run the tests and report which assumptions break under distribution shift.

**Why it matters:** Formal proofs are only as good as their assumptions. Empirically testing which proof assumptions fail in practice directly informs what theoretical guarantees are actually achievable with current methods.

**Relevant context:** The alignment forum post 'Limitations on Formal Verification for AI Safety' and the compact-proof NeurIPS 2024 paper jointly frame this gap. This project is the empirical complement.
