# Mapping Irreversible Action Patterns in Long-Horizon Agent Task Traces

**Problem:** It is unknown how frequently agents in long-horizon tasks take irreversible actions, at what point in the task sequence these occur, and what task context precedes them.

**Direction:** Collect or generate 100 long-horizon agent task traces (20+ steps each) using a public benchmark (METR tasks, AgentBench). Annotate each action for reversibility. Identify: frequency of irreversible actions, average task step at which first irreversible action occurs, and contextual predictors (prior tool use, task type, instruction ambiguity).

**Why it matters:** No empirical characterization of irreversible action distribution in real agent task traces exists. This is a prerequisite for designing targeted safety interventions.

**Relevant context:** METR autonomous capability evals; the outcome-driven constraint violations benchmark (arxiv 2512.20798); Anthropic's guidance on irreversible actions; IrreversAct-Bench concept.
