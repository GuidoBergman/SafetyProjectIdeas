# Prompt Injection Taxonomy for Multi-Agent Systems: Classifying Attack Vectors by Propagation Path

**Problem:** Prompt injection attacks in multi-agent systems can propagate through multiple agents in ways not possible in single-agent settings. No taxonomy of multi-agent injection propagation paths exists.

**Direction:** Collect or construct 40 prompt injection scenarios in multi-agent settings. Classify each by propagation path (direct injection into target agent, injection via shared memory, injection via tool output, injection via inter-agent communication). Measure which path produces the highest attack success rate and which is hardest to defend.

**Why it matters:** Effective defenses must target the specific propagation paths used. Without a path taxonomy, defenses are likely incomplete.

**Relevant context:** Google DeepMind indirect prompt injection paper (arxiv 2505.14534); Adversa AI 2025 on 35.3% of incidents involving prompt injection; ControlArena (apartresearch.com).
