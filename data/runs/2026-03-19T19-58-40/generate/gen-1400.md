# False Positive Rate Asymmetry: Do CoT Monitors Flag Unusual but Benign Reasoning?

**Problem:** An open question from the GPT-5 CoT monitoring work is whether monitors flag unusual but benign reasoning patterns at elevated rates, which would reduce trust in monitor outputs.

**Direction:** Curate a set of intentionally unusual-but-benign CoT examples (e.g., models using rare but correct reasoning strategies). Run through a standard CoT monitor. Compare false positive rates against a control set of standard benign CoTs. Analyze which linguistic patterns drive false positives.

**Why it matters:** High false positive rates on unusual-but-legitimate reasoning would bias deployments against creative or unconventional model reasoning, creating perverse incentives in model development.

**Relevant context:** MALT includes large confirmed-benign runs as controls (7,179 public runs). CoT monitor precision reported at 81% in GPT-5 system card, implying ~19% false positives among flagged items.
