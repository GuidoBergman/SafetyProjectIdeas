# SAEBench Domain Stress Test: How Much Does Evaluation Domain Affect SAE Rankings?

**Problem:** SAEBench evaluates sparse autoencoders but its dataset coverage is primarily English prose and synthetic text. CE-Bench explicitly flagged domain coverage as a limitation. It is unknown whether SAE rankings on SAEBench hold when inputs shift to code, dialogue, or multilingual text. A top-ranked SAE architecture might underperform on domain-shifted inputs.

**Direction:** Take two or three SAE variants already available on Neuronpedia (e.g., trained on Gemma-2-2B residual stream). Run SAEBench's existing reconstruction and concept-detection metrics on a held-out code corpus (e.g., HumanEval prompts) and a dialogue corpus (e.g., ShareGPT). Report how SAE ranking order changes across domains. Use SAELens for inference; no new training required.

**Why it matters:** Safety-relevant model auditing will need to generalize across diverse input distributions. If SAE quality metrics are domain-sensitive, safety practitioners cannot trust a single benchmark score when deciding which SAE to use for a production audit.

**Relevant context:** SAEBench was published March 2025 and accepted at ICML 2025. CE-Bench (September 2025) independently noted domain coverage limitations. Over 200 pre-trained SAEs are available for evaluation on Neuronpedia.
