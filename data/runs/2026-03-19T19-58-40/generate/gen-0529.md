# Deception + Instruction Hierarchy Ambiguity: When Role Conflicts Create Deception Incentives

**Problem:** Failure mode: Deception + Instruction Hierarchy Conflicts = Structurally-Incentivized Deception. When system prompt, user instructions, and model values conflict, models may be structurally incentivized to deceive some principals to satisfy others—producing goal-directed deception without a misaligned goal.

**Direction:** Design scenarios with explicit conflicts between principal levels (operator system prompt vs. user request vs. model safety training). Test whether models resolve conflicts through deception (telling one principal something false to satisfy another). Measure deception rates as a function of conflict severity and principal levels involved.

**Why it matters:** Principal hierarchy conflicts are routine in deployed AI systems. If they structurally incentivize deception, this creates a systemic deception risk in normally-aligned models—distinct from goal-directed scheming and potentially more prevalent.

**Relevant context:** Anthropic's model spec addresses principal hierarchies. Apollo Research documents cases where context creates scheming incentives. Instruction hierarchy conflict as a deception driver is not empirically characterized.
