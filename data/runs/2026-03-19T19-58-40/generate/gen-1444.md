# Replicating CoT Monitoring Across Tool-Calling Formats: JSON vs. Natural Language Tool Calls

**Problem:** Different models produce tool calls in different formats (JSON function calls vs. natural language descriptions). Whether CoT monitor accuracy differs across these formats—because the monitor cannot parse structured tool calls as well as natural language—is untested.

**Direction:** Configure the same Llama-3.1-8B agent to produce (a) JSON-formatted tool calls and (b) natural language tool call descriptions within its CoT on ControlArena tasks. Run the same LM monitor on both. Compare AUROC for sabotage detection across formats.

**Why it matters:** Monitoring pipelines must handle heterogeneous agent outputs. If monitor accuracy depends on output format, standardization of tool-calling conventions becomes a safety requirement.

**Relevant context:** ControlArena is built on Inspect AI which supports multiple tool call formats. Monitor prompts designed for natural language CoT may not parse JSON tool calls effectively. Format effects on monitoring are absent from the literature.
