# Adapting Credibility Assessment Interview Technique (CAIT) to Probe LLM Honesty

**Problem:** Forensic psychology has developed structured interview protocols (e.g., CAIT, CBCA) to detect deception in humans by analyzing statement consistency, detail richness, and cognitive load markers. These have never been systematically adapted to evaluate whether LLMs are being deceptive in their stated reasoning.

**Direction:** Map CAIT/CBCA criteria (e.g., logical structure, unstructured production, contextual embedding) onto LLM output features. Build a small evaluation set of known-honest vs. known-deceptive LLM responses and test whether these forensic criteria predict deception reliably. Use an open-source model like Llama or Mistral.

**Why it matters:** If classical forensic criteria transfer even partially to AI output analysis, this provides a low-cost, interpretable screening layer before deployment that requires no model internals access.

**Relevant context:** Forensic statement analysis (SVA/CBCA) is extensively validated on human deception. The 'Secret Agenda' benchmark (arXiv:2509.20393) shows LLMs strategically lie; their output patterns may carry detectable forensic signatures.
