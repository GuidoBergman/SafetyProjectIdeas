# Are SAE Features Stable Under Repeated Training? Characterizing Non-Deterministic Feature Emergence

**Problem:** SAEs trained on the same model and data with different random seeds may learn different feature dictionaries—a form of non-determinism in feature discovery. If two separately trained SAEs disagree substantially on which features exist (learn non-overlapping dictionaries), then claims about 'the features' of a model are really claims about one particular trained SAE, which may not be the stable ground truth about the model's internal representation.

**Direction:** Using SAELens, train 3 SAEs with different random seeds on the same layer (GPT-2 small, layer 6), same data, and same hyperparameters. Compute pairwise cosine similarity between all decoder vectors across SAE pairs. Plot the distribution of nearest-neighbor cosine similarities (each feature in SAE-A matched to its closest counterpart in SAE-B). Report: (1) the fraction of features with very high alignment (cos > 0.9) across all 3 seeds (stable features), (2) features with high alignment to one other seed but not the third (partially stable), (3) features unique to one seed (unstable). Characterize whether stable features correspond to higher-frequency concepts than unstable features.

**Why it matters:** If feature discovery is substantially non-deterministic, then individual SAE feature analyses are not reliable descriptions of the model—they are descriptions of a particular learned dictionary. This is a fundamental epistemic problem for the field that is rarely tested explicitly.

**Relevant context:** Training instability is acknowledged in the SAE literature but rarely quantified at the feature level. SAEBench (2025) found that evaluation metrics vary across SAE variants; seed-based variation is a natural extension of this concern.
