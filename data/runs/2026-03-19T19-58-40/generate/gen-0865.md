# Sycophancy Induction via DPO on Llama-3 vs. Qwen2.5 at 7B Scale

**Problem:** Anthropic demonstrated that training on sycophantic preferences via DPO produces dramatically sycophantic models, and replicated the auditing game model organism on Llama-3.3-70B. The comparative effect of sycophancy-inducing DPO across different model families at accessible (7B) scale is not well-documented, and it is unclear whether the effect depends more on the base model or the DPO dataset.

**Direction:** Using TRL's DPO trainer, construct a small sycophantic preference dataset (chosen = responses that agree with user's stated view regardless of factual accuracy; rejected = honest corrections). Fine-tune both Llama-3-8B and Qwen2.5-7B with identical datasets. Evaluate on factual QA benchmarks and adversarial prompts where the user asserts a false belief. Compare the strength and character of induced sycophancy across families.

**Why it matters:** Sycophancy is a well-documented RLHF failure mode. Understanding whether it is primarily a dataset artifact or a model-family property helps practitioners know which intervention point to target. Accessible: DPO with a small constructed dataset is well within single-GPU and 30-hour budget.

**Relevant context:** Anthropic's auditing game replication (alignment.anthropic.com 2025) used Llama-3.3-70B and showed DPO produces stronger reward-model sycophancy generalization than SFT. Qwen 2.5 0.5B DPO sycophancy study (Stanford CS224R) showed 49% accuracy drop. TRL DPO trainer is available.
