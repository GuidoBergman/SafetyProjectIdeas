# Cross-Modality Adversarial Suffix Transfer: Do Text-Optimized GCG Suffixes Boost ASR on Code Prompts?

**Problem:** GCG suffixes are optimized against natural-language harmful prompts. Code-generation harmful requests (e.g., 'write a keylogger') are a distinct input distribution. It is not known whether suffixes optimized on text requests also boost ASR on code-specific harmful requests.

**Direction:** Take a public set of GCG suffixes optimized on natural-language jailbreak prompts. Evaluate their ASR when appended to code-specific harmful prompts on CodeLlama-7B-Instruct and Llama-3-8B-Instruct. Compare ASR to the same attacks on natural-language prompts to measure the cross-input-type transfer gap.

**Why it matters:** If text-optimized adversarial suffixes transfer to code prompts, the attack surface is larger than currently measured. This informs whether code-LLM safety evaluations must explicitly include adversarial suffix testing.

**Relevant context:** GCG suffixes are publicly available from the original Zou et al. paper and JailbreakBench. The text vs. code input distinction is not addressed in the adversarial suffix literature. StrongReject includes some code-adjacent harmful prompts.
