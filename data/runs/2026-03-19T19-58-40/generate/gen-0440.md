# A Cross-Model Deception Taxonomy and Annotation Tool

**Problem:** Different research groups use different taxonomies for deception (sycophancy, sandbagging, alignment faking, scheming, etc.) with overlapping definitions, making literature comparison difficult.

**Direction:** Produce a unified deception taxonomy by systematically comparing definitions across Apollo Research, DeceptionBench, Anthropic alignment faking, and the AI deception survey. Build an annotation tool (lightweight web app or notebook) that allows labeling model outputs against this taxonomy.

**Why it matters:** Scientific progress requires shared vocabulary. A unified taxonomy and annotation tool would allow meta-analysis of deception findings across labs and papers.

**Relevant context:** AI deception survey (PMC/Patterns 2024), DeceptionBench (arxiv 2510.15501), Apollo Research, and Anthropic alignment faking all use distinct terminology.
