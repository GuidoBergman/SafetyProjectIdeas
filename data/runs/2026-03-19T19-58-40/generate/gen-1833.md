# Vision SAE Feature Drift Across Training Checkpoints: Do Visual Features Stabilize Early or Continue Shifting Late in Training?

**Problem:** In language models, some circuits stabilize early in training while others emerge late. The training dynamics of vision SAE features are unexplored, and it is unknown whether visual features are stable across training checkpoints.

**Direction:** Using publicly available ViT training checkpoints (e.g., from DINO or MAE training runs), train SAEs at multiple checkpoints and compute feature-level cosine similarity across consecutive checkpoint pairs. Identify which feature types (texture, object, color) stabilize first versus last. Compare to language model feature stability benchmarks.

**Why it matters:** Feature stability informs whether early training checkpoints can be used for efficient interpretability studies and whether feature representations can be trusted throughout training.

**Relevant context:** ViT-Prisma supports multiple ViT architectures. DINO provides accessible public checkpoints. The sparsity dynamics finding from Prisma (2025) provides initial grounding.
