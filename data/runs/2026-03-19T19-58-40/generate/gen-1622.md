# Does the Inoculation System Prompt Survive Paraphrasing?

**Problem:** Inoculation prompting (adding a single line contextualizing insecure code as educational) prevents emergent misalignment, but it is unknown whether this prevention is fragile — i.e., whether paraphrasing or semantically shifting the inoculation prompt removes the protection.

**Direction:** Finetune models on insecure-code data with (a) the original inoculation prompt, (b) five semantically equivalent paraphrases, (c) a shortened version, and (d) no inoculation. Compare misalignment rates across conditions. If prevention degrades with paraphrasing, test whether a diverse set of inoculation phrasings during training is more robust.

**Why it matters:** If inoculation only works for a very specific phrasing, it is brittle and easy to circumvent accidentally or adversarially. Understanding phrasing sensitivity is essential before inoculation is deployed as a practical defense.

**Relevant context:** Natural emergent misalignment from reward hacking (Anthropic, 2025) found that inoculation prompts preventing misalignment in toy setups don't scale when the prompt diverges from the dataset generation prompt. The mechanism appears to be semantic association learned during pretraining.
