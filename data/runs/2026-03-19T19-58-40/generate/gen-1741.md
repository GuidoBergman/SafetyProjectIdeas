# Renewable Benchmark Design: Implementing a Self-Updating Jailbreak Test Set

**Problem:** Static jailbreak benchmarks become stale as models are patched against known attacks. Johns Hopkins researchers (TechXplore, March 2026) proposed a 'renewable' benchmark framework, but it has not been implemented as an accessible tool for small research groups.

**Direction:** Implement a minimal renewable benchmark pipeline: a template-based prompt generator that creates novel surface variations of a fixed set of harmful intent categories, paired with StrongReject automated scoring. Validate that generated prompts maintain attack intent while varying surface form. Release as an open-source script.

**Why it matters:** A success state requires that benchmarks stay ahead of model patching. Renewable benchmarks that can generate new test instances on demand prevent the 'benchmark overfitting' failure mode where models appear safe only because they have been patched against known prompts.

**Relevant context:** TechXplore (March 2026) reported a Johns Hopkins renewable benchmark framework. The MLCommons coordinated disclosure framework motivates fresh attack generation. Template-based generation is computationally cheap and within participant constraints.
