# Multi-Turn Jailbreak Fingerprinting via Conversation Graph Analysis

**Problem:** Multi-turn jailbreaks (Crescendo, decomposition attacks) distribute harmful intent across multiple turns, evading single-turn classifiers. There is no lightweight method to detect suspicious multi-turn conversation trajectories without per-turn LLM evaluation.

**Direction:** Model conversations as directed graphs where nodes are turns and edges encode semantic similarity, topic drift, and escalation signals (e.g., increasing specificity of harmful topic). Train a graph-level classifier on synthetic multi-turn jailbreak conversations (generated using Crescendo templates) vs. benign multi-turn conversations from ShareGPT. Evaluate detection AUC using only lightweight features (cosine similarity of embeddings, turn count, topic drift rate) with no per-turn LLM calls.

**Why it matters:** Production systems need to detect multi-turn attacks at scale without paying LLM inference costs per turn. A graph-level classifier trained once could run cheaply on conversation metadata. This is the inter-query defense open problem.

**Relevant context:** Crescendo multi-turn jailbreak: USENIX Security 2025. MTJ-Bench multi-turn benchmark (EmergentMind). State-dependent safety failures in multi-turn interactions (arXiv:2603.15684).
