# Toy Model Superposition Under Correlated Inputs: Does Feature Correlation Change the Packing Geometry?

**Problem:** The canonical toy model of superposition uses independent, sparse inputs. Real-world concepts are correlated. How feature correlation changes the superposition geometry has not been experimentally mapped in the original toy model setup.

**Direction:** Modify the Anthropic toy model of superposition to include pairwise input correlations (from a correlation matrix drawn from a real co-occurrence dataset). Sweep correlation strength (0, 0.2, 0.4, 0.6, 0.8). Measure how the learned feature angles and the effective number of stored features change. Compare to the uncorrelated baseline.

**Why it matters:** If correlation disrupts the clean superposition geometry, SAE training may fail to disentangle correlated features even in principle, which is a fundamental limit on the SAE approach to interpretability.
