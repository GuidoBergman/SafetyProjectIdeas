# Replicating SHADE-Arena Monitoring with a Weaker Monitor (3B vs. Frontier)

**Problem:** SHADE-Arena evaluated monitoring with frontier-scale LM monitors. Whether a smaller 3B monitor catches the same evasion attempts is unknown, which matters for cost-effective monitoring pipelines.

**Direction:** Run SHADE-Arena public tasks with Llama-3.2-3B as the monitor (instead of a frontier model). Compare false negative rate (missed malicious side tasks) and false positive rate to published frontier monitor results. Compute cost-adjusted detection rate.

**Why it matters:** Using a 3B monitor is dramatically cheaper. If detection rates are comparable, this enables practical safety monitoring at much lower cost—a key barrier to adoption for smaller organizations.

**Relevant context:** SHADE-Arena monitor is an LM judge. No results published for sub-7B monitors on SHADE-Arena. Llama-3.2-3B-Instruct is a capable small model available publicly.
