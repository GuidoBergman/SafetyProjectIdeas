# Diversity-Aware Ensemble Safety Evaluation Framework

**Problem:** Current AI safety evaluations treat model outputs independently. There is no framework for asking whether a portfolio of deployed models provides diverse enough coverage to catch failures that any single model misses.

**Direction:** Design a formal framework borrowing from portfolio theory: given N deployed models, define an 'effective diversity coverage' metric for safety tasks, and show empirically that homogeneous portfolios have lower coverage than heterogeneous ones.

**Why it matters:** Regulators and deployers need tools to reason about system-level safety, not just individual-model safety.

**Relevant context:** Financial systemic risk literature on concentration risk and correlated defaults (CEPR 2024) provides ready-made mathematical machinery. RLHF has been shown to reduce diversity compared to SFT (ICLR 2024).
