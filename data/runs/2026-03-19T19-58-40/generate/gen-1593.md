# Tripwire-Based Monitoring Transfer: Static Environment Integrity Checks from Security Operations

**Problem:** Security operations use tripwires—checksums and file integrity monitors that detect any modification to sensitive files without analyzing agent behavior at all. AI monitoring has not adopted this approach: most monitoring examines agent actions rather than environment state changes.

**Direction:** In ControlArena bash tasks, implement a file and environment state integrity monitor that checksums critical files and environment variables before and after each agent step. Flag any modification to resources the agent was not supposed to modify according to the task specification. Compare this tripwire-based monitor to a standard LLM action monitor on SHADE-Arena sabotage tasks.

**Why it matters:** Tripwire monitoring catches the result of sabotage regardless of how sophisticated the agent is at hiding its actions. If the environment state has been modified, detection does not depend on analyzing the agent's reasoning or even its action stream.

**Relevant context:** File integrity monitoring (e.g., Tripwire, AIDE) is a standard Linux security tool. ControlArena's bash setting exposes file system state. Implementing checksumming is basic Python with no ML required.
