# Replicating the Copy Suppression Circuit in Instruction-Tuned Models: Does RLHF Alter Repetition Suppression?

**Problem:** McDougall et al. (2023) discovered a copy suppression circuit in GPT-2 that prevents the model from repetitively copying tokens it has already produced — a mechanism linked to induction heads operating in reverse. Instruction-tuned models are explicitly rewarded for fluent, non-repetitive responses, raising the question of whether RLHF strengthens or restructures this circuit.

**Direction:** Using TransformerLens, analyze the copy suppression circuit on both the base Llama-3-8B and its Llama-3-8B-Instruct counterpart. Apply the same diagnostic prompts used by McDougall et al. — sequences where the model has previously produced a token and should suppress repeating it. Compare attention patterns at the identified suppression heads between base and instruct models. Measure whether the circuit components are the same, stronger, or supplemented by additional components in the instruct model.

**Why it matters:** If RLHF visibly modifies a known, well-characterized circuit like copy suppression, it provides a concrete test case for whether instruction tuning changes model internals in predictable ways. This would either validate or challenge the hypothesis that RLHF 'wraps around' base model circuits rather than restructuring them — a key question for understanding how aligned models differ mechanistically from base models.

**Relevant context:** McDougall et al. (2023) 'Copy Suppression: Comprehensively Understanding an Attention Head' characterized the copy suppression mechanism in GPT-2. TransformerLens supports both Llama-3-8B (base) and Llama-3-8B-Instruct. The general question of how fine-tuning affects circuits is discussed in the Anthropic biology paper (2025) and is an active research question in the mechanistic interpretability community.
