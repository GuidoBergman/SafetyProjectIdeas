# Jailbreak Consolidation: Adversarial Prompts That Merge Harmful Concepts Below Individual Detection Thresholds

**Problem:** Jailbreak detection probes are typically trained to detect individual harmful concepts. An adversarial prompt that distributes harmful intent across multiple concept features — each below the individual detection threshold — can evade all individual probes while still producing a harmful output through their combination. Failure mode 1: probes are concept-specific, not combination-aware. Failure mode 2: the detector has no coverage of multi-concept harmful interactions.

**Direction:** Identify SAE features associated with distinct components of a harmful task (e.g., features for 'chemistry', 'danger', 'instructions'). Craft prompts that activate each feature at sub-threshold levels but combine to produce harmful output. Measure whether ensemble probes that detect individual features catch this, vs. a probe trained on combined activation patterns.

**Why it matters:** Multi-concept jailbreaks are a known attack class. Whether mechanistic interpretability tools can be extended to detect combination attacks is a direct question for deploying them as adversarial robustness measures.

**Relevant context:** Jailbreak attacks using distributed semantics have been explored in the prompt injection literature. No published work addresses whether SAE feature combination profiles enable new detection strategies.
