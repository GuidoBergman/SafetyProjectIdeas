# Insufficient Eval Diversity + Adversarial Coordination: Compounding Attack Surface

**Problem:** If the safety evaluation ecosystem uses a small, known set of benchmarks AND adversaries coordinate to specifically target the gaps between those benchmarks, the compound failure is worse than either condition alone: homogeneous evals create a known attack surface; adversarial coordination exploits it systematically.

**Direction:** Model the adversarial coordination scenario: identify the gaps in current major safety benchmarks (behaviors not covered). Design prompts specifically targeting those gaps. Measure attack success rates on models evaluated using only standard benchmarks. Estimate how much eval diversity (adding novel, non-public benchmark items) reduces adversarial success.

**Why it matters:** As AI safety evaluation becomes standardized for regulatory purposes, adversaries will specifically study and exploit evaluation gaps. This threat model is not currently incorporated into benchmark design.

**Relevant context:** The security research community has extensively studied how published security standards create adversarial optimization pressure. JBFuzz's 99% jailbreak rate demonstrates that public benchmarks are fully exploitable by motivated adversaries.
