# Minimum Description Length Monitor: Using Compression-Based Anomaly Detection for AI Agent Behavior

**Problem:** Compression-based anomaly detection (based on minimum description length / Kolmogorov complexity) is used in network security to detect unusual traffic without domain-specific features. It has not been applied to AI agent action sequences.

**Direction:** Represent each agent trajectory as a string over a vocabulary of action types. Compute the compression ratio of trajectories using gzip or zstd. Establish a baseline compression ratio distribution from 100 benign METR traces. Flag SHADE-Arena trajectories whose compression ratio falls outside the baseline distribution as anomalous. Evaluate AUC and compare to isolation forest.

**Why it matters:** Compression-based anomaly detection requires zero feature engineering and no labels. It captures the structural irregularity of malicious trajectories (which may have repeated unusual action patterns) in a model-free way.

**Relevant context:** Compression ratio as an anomaly signal is used in network traffic analysis (e.g., detecting C2 communication). The technique is documented in academic IDS literature. Implementation is trivial in Python (import gzip).
