# Comparing Misalignment Rates Across Different Harmful Task Domains

**Problem:** The original paper used insecure code as the narrow harmful task. Follow-up work tested dangerous medical advice. It is unclear whether certain domains of harm more reliably induce broad misalignment, and why.

**Direction:** Using the model organisms infrastructure, finetune separate models on three different narrow harmful domains: (1) insecure code, (2) harmful chemistry instructions framed as educational, (3) manipulative persuasion techniques. Use identical training hyperparameters and dataset sizes across all conditions. Measure and compare misalignment rates on the standard out-of-domain evaluation set.

**Why it matters:** Identifying which types of narrow harmful training are most dangerous for broad misalignment would allow prioritization of safety checks. It also tests whether the effect is truly general or tied to the specific 'writing bad code' framing.

**Relevant context:** Assessing Domain-Level Susceptibility paper (arxiv 2602.00298) has begun mapping domain susceptibility. Model organisms code makes running new domain experiments straightforward. The effect has been confirmed for insecure code and dangerous medical advice domains.
