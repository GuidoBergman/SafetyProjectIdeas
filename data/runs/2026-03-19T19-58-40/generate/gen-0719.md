# Monitor Prompt Injection: Adaptive Attacks That Exploit Interpretability Architecture Assumptions

**Problem:** AI control protocols rely on activation monitors to flag unsafe outputs. When the monitor is an LLM, adaptive prompt injections embedded in the monitored model's output can subvert it. Failure mode 1: monitors cannot robustly separate data from instructions in activation space. Failure mode 2: the entire control loop is bypassed via the monitor's own vulnerability.

**Direction:** Implement a simple AI control loop: a small policy model whose outputs are passed to a monitor model. Craft adversarial outputs from the policy model containing prompt injections targeting the monitor. Measure bypass rates. Then test whether monitoring at the activation level (rather than text level) is more resistant to this attack.

**Why it matters:** 'Adaptive Attacks on Trusted Monitors Subvert AI Control Protocols' (arXiv 2510.09462) showed this attack works universally across frontier models. Whether activation-level monitoring reduces this risk is urgent and untested at accessible scales.

**Relevant context:** Defer-to-Resample protocols were found to amplify prompt injection rather than suppress it. Activation-level monitors relying on mechanistic interpretability might be more robust, but this is an open empirical question.
