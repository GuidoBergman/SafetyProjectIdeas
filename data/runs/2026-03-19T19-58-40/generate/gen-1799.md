# Clinical Sensitivity and Specificity Audit of Probing Classifiers

**Problem:** Probing classifiers are used to test whether a concept is linearly encoded in activations, but their classification accuracy is not decomposed into sensitivity (recall) and specificity (true negative rate), making it hard to assess whether a probe is genuinely detecting the concept or simply exploiting class imbalance.

**Direction:** Import medical diagnostic test evaluation: report probing classifier performance using sensitivity, specificity, positive predictive value, negative predictive value, and likelihood ratios in addition to accuracy. Run probes on balanced vs. imbalanced datasets to check for Bayesian base-rate inflation.

**Why it matters:** Medical diagnostics has a decades-long tradition of rigorous test evaluation that prevents overconfident claims from class imbalance. Adopting these standards in mech interp would raise the bar for probe-based claims about what a model 'knows,' reducing false positives in concept attribution.

**Relevant context:** Probing classifiers are a core mech interp tool (logistic regression on activations). Medical diagnostic statistics are standard in epidemiology (sensitivity/specificity, ROC-AUC, PPV/NPV). The framework is trivially implementable with sklearn's classification_report.
