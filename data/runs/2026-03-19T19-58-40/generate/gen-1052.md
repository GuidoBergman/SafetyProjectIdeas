# SAE Features for Refusal Behavior: Replicating Feature Identification Across Llama-3 Instruct Sizes

**Problem:** Prior work has identified sparse autoencoder features associated with refusal behavior in aligned models, but it is unclear whether the same features or circuit structures implement refusal across different sizes of the same model family (Llama-3-8B-Instruct vs Llama-3-70B-Instruct).

**Direction:** Using SAELens, load or train SAEs on Llama-3-8B-Instruct activations at the residual stream. Identify features that activate strongly on refusal-triggering prompts versus benign prompts by comparing activation distributions. Then, using quantitative cross-model feature matching (activation correlation on shared prompts), test whether analogous features exist in Llama-3-70B-Instruct. Measure whether the same layer-depth relative position contains refusal features across sizes.

**Why it matters:** If refusal is implemented by a consistent, transferable feature structure across model sizes within a family, it would suggest that safety fine-tuning creates mechanistically stable circuits. If it varies substantially, it implies refusal mechanisms may be fragile and size-dependent — with direct implications for jailbreak generalization and the scalability of alignment techniques.

**Relevant context:** SAE-based feature identification for safety-relevant behaviors is an active area; Gemma Scope (2024) and Gemma Scope 2 (2025) provide infrastructure for this kind of analysis. 'Quantifying Feature Space Universality Across Large Language Models via Sparse Autoencoders' (arXiv:2410.06981) provides the cross-model matching methodology. SAELens supports Llama-3 family models.
