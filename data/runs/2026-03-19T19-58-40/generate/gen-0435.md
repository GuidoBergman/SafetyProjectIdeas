# A Deception Detection Toolkit with Standardized Probes and Baselines

**Problem:** There is no unified, open-source toolkit for deception detection that packages linear probes, CoT divergence detection, noise injection, and output-based classifiers with a common API and shared evaluation harness.

**Direction:** Build a Python package wrapping: (1) linear probe training/inference for sandbagging detection, (2) noise injection testing, (3) thinking-trace vs. output divergence scoring. Evaluate on DeceptionBench categories. Release with documentation and example notebooks.

**Why it matters:** Fragmented detection methods mean researchers must reimplement each technique. A unified toolkit would accelerate iteration and allow systematic comparison of detection approaches.

**Relevant context:** Noise injection (NeurIPS 2025), linear probes (dev.to), and DeceptionBench (arxiv 2510.15501) exist as separate research artifacts without a shared evaluation harness.
