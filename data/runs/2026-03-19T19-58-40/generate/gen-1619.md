# Minimum Detectable Effect Study: What Is the Smallest Deviation from Benign Behavior That Current Monitors Can Reliably Detect?

**Problem:** Monitors are evaluated on existing SHADE-Arena sabotage scenarios, but it is unknown how 'obvious' the misbehavior needs to be for detection. The minimum detectable effect—the smallest behavioral deviation that achieves, say, 80% detection rate—has never been measured.

**Direction:** Create a series of synthetic trajectories where the degree of deviation from benign behavior is continuously varied from 0% (benign) to 100% (obvious sabotage) along a few well-defined dimensions (number of unauthorized file accesses, severity of resource modification, frequency of policy-violating tool calls). Measure detection rate as a function of deviation magnitude to produce a 'monitor sensitivity curve'.

**Why it matters:** The minimum detectable effect establishes the fundamental detection limit of a monitoring approach. Knowing this limit tells us what sophistication of scheming would go undetected and provides a concrete target for monitor improvement.

**Relevant context:** Minimum detectable effect analysis is standard in clinical trial design and sensor characterization. Applied to AI monitoring, it provides a rigorous characterization that current evaluations lack. Implementation requires synthetic trajectory generation and LLM API calls.
