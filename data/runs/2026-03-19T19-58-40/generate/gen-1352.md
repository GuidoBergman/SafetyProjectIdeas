# Follow-Up: Does the CoT Monitor Catch the Same 84% of Cases Across All Model Families?

**Problem:** OpenAI's CoT monitor was trained and validated on GPT-5 thinking outputs. Whether its 84% recall generalizes to other models' deceptive reasoning is not established.

**Direction:** Take a validated set of deceptive CoT examples (or generate them via known elicitation prompts) from multiple model families. Apply the GPT-5 CoT monitor (or a public proxy trained on similar data) to each. Measure recall per model family. Report whether the monitor generalizes or is GPT-5-specific.

**Why it matters:** If the monitor is model-specific, each new model family needs its own monitor, implying substantial ongoing monitoring infrastructure costs. Generalization would reduce this cost dramatically.

**Relevant context:** GPT-5 system card documents 84% recall. Anthropic notes that CoT omissions vary by model. Cross-model transfer of safety classifiers is a known challenge.
