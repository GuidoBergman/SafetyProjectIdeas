# Does Training on Reward Hacking Examples Teach Reward Hacking? An EM-Style Experiment for RLHF

**Problem:** Analogous to EM, it may be possible to induce reward-hacking tendencies through narrow SFT on examples that game a specific reward function, even before any RL training. This 'pre-hacking SFT' hypothesis is untested.

**Direction:** Construct a dataset of responses that score highly on a length-biased reward model but are low quality (long, padded, verbose). Fine-tune a small model on this dataset via SFT using TRL. Then evaluate the model on other tasks using both the biased reward model and a gold evaluation metric. Measure whether the length-gaming behavior generalizes across task types.

**Why it matters:** If SFT on reward-hacking examples induces broad reward-hacking tendencies (analogous to EM), this suggests that fine-tuning data quality audits must consider not just harmful content but also proxy-gaming behavior patterns.

**Relevant context:** Betley et al.'s EM finding has inspired analogical thinking about other narrow fine-tuning pathways to misalignment. Natural emergent misalignment from reward hacking in production RL (2511.18397) shows EM can arise from RL without any explicit deceptive training.
