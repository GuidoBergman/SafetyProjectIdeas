# Do SAE Features Generalize Across Model Sizes? A Small-Scale Scaling Test

**Problem:** If interpretability is to work on frontier models, feature-based explanations must exhibit predictable patterns as model scale increases. There is currently little systematic evidence from beginner-accessible experiments on whether features found in small models (GPT-2 Small) are similar in character, count, and causal role to features in slightly larger models (GPT-2 Medium).

**Direction:** Train matched SAEs on GPT-2 Small and GPT-2 Medium using SAELens on the same dataset. For a fixed set of 20 semantic concepts (e.g., gender, number, sentiment), identify the best-matching SAE feature in each model using max-activating examples. Compare the activation sparsity, interpretability ratings (manually assigned), and causal effect (via patching) of matching features across models.

**Why it matters:** Backcasting from a world where SAE-based interpretability scales to frontier models: we need early evidence that scaling laws hold for feature structure. If features shift qualitatively with scale even between GPT-2 variants, the scaling challenge is severe and the field needs redirecting.

**Relevant context:** Gemma Scope 2 covers models from 270M to 27B parameters, showing the field's scaling ambitions. SAELens supports both GPT-2 variants. The ARENA tutorials include matched GPT-2 Small/Medium experiments. Fits single-GPU compute within 30 hours.
