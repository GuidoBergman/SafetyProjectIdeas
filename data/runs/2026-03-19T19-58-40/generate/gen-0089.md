# Jailbreak Transfer Study: Do Attacks Generalize Across Models?

**Problem:** Jailbreaks are typically reported per-model, but it is unclear how well successful attacks transfer across model families, which matters for understanding systemic attack surfaces.

**Direction:** Collect a set of 30–50 published jailbreak prompts from recent papers or repositories (e.g., JailbreakBench). Test each on 3–4 open-source models from different families. Compute a 'transferability matrix' showing success rates across model pairs. Analyze whether simpler jailbreaks transfer better and whether model capability correlates with resistance.

**Why it matters:** If jailbreaks transfer well, a single successful attack on one model implies broad vulnerability. This has direct implications for how red-teaming results should be interpreted by evaluators.

**Relevant context:** JailbreakBench and HarmBench provide standardized attack sets. METR task suites cover capability elicitation but not adversarial transferability. This is a natural complement.
