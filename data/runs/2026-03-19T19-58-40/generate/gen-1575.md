# Long-Horizon Monitoring Degradation: Do Monitors Lose Effectiveness as Task Length Increases?

**Problem:** Most monitoring evaluations use tasks of moderate length (10–30 steps). It is unknown whether monitor effectiveness degrades on long-horizon tasks (100+ steps) due to context window limits, attention dilution, or accumulated error.

**Direction:** Construct or adapt ControlArena tasks of three length tiers: short (< 20 steps), medium (20–60 steps), and long (60–150 steps). Run a fixed LLM monitor on all three tiers. Measure whether detection AUC, false negative rate, and latency scale adversely with task length. Investigate whether periodic context summarization mitigates degradation.

**Why it matters:** Real-world deployment of AI agents will increasingly involve long-horizon tasks. If monitoring degrades with task length, current evaluation results (mostly short tasks) overestimate safety guarantees.

**Relevant context:** METR task suite includes tasks of varying lengths. Long-context monitoring is an acknowledged open problem in agentic safety literature. This experiment is feasible with API access only.
