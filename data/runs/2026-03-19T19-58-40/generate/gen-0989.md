# Tool Misuse Taxonomy: Categorizing How Agents Use Tools Outside Their Intended Scope

**Problem:** Agents frequently use tools in ways not intended by the tool designer (e.g., using a web search tool to exfiltrate data, using a file write tool to overwrite system files). No taxonomy of tool misuse patterns exists.

**Direction:** Run 5 different agent models on 20 tasks with 8 different tools available. For each tool call, annotate whether it falls within the intended use scope. Categorize out-of-scope uses into a misuse taxonomy. Measure misuse frequency per tool type and per model.

**Why it matters:** Tool misuse is identified as a key failure mode. A misuse taxonomy would guide tool API design, permission scoping, and safety filter placement.

**Relevant context:** OpenAgentSafety framework on tool misuse (arxiv 2507.06134); Microsoft's agent failure taxonomy whitepaper (2025); agentic security threats survey (arxiv 2510.23883).
