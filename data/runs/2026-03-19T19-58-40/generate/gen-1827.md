# Are Vision SAE Features Shared Across Different ViT Architectures? A Cross-Model Feature Universality Study

**Problem:** In language models, certain circuits (e.g., induction heads) appear to be universal across architectures. It is unknown whether visual SAE features are similarly universal across ViT variants (e.g., CLIP-B/32 vs. DINO-B vs. MAE-B).

**Direction:** Train SAEs on matching intermediate layers of three ViT variants using ViT-Prisma. For each SAE, collect the top-20 maximally activating image patches per feature. Compute cross-model feature similarity by matching features across models using CLIP similarity of their activating patches. Measure what fraction of features have a close match in all three models.

**Why it matters:** Universal features would suggest vision transformers converge on common visual primitives, validating the broader interpretability agenda. Non-universality would suggest architecture-specific analysis is needed.

**Relevant context:** ViT-Prisma supports 75+ ViT models. Language model feature universality was established in Anthropic's 'Toy Models of Superposition'. SAELens provides cross-model training pipelines.
