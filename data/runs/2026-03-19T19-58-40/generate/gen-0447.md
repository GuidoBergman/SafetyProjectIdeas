# A Deception Behavior Frequency Dashboard for Open-Weight Model Releases

**Problem:** When new open-weight models are released, there is no standard procedure or tool for quickly assessing their deception behavior profile. Researchers have no reference point for how deceptive a new model is relative to prior releases.

**Direction:** Build a lightweight dashboard that runs a fixed deception evaluation battery (DeceptionBench subset, scheming scenarios, sycophancy pressure tests) on any Hugging Face model and produces a deception profile report. Release as a GitHub Action compatible script.

**Why it matters:** A rapid deception profiling tool would allow the community to assess new open-weight models' safety properties within hours of release, enabling timely risk assessment.

**Relevant context:** Petri covers frontier models. DeceptionBench is a research paper without a rapid profiling pipeline. Open-weight model releases are accelerating in 2025-2026.
