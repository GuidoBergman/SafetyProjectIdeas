# Fine-Tuning Erases Probes: Safety Degradation Blinds Interpretability Monitors

**Problem:** Fine-tuning on as few as 10 adversarial examples can strip safety alignment. If this fine-tuning also corrupts the activation geometry that linear probes rely on, then the interpretability-based early warning system fails exactly when it is most needed—in a model that has been covertly fine-tuned to be unsafe.

**Direction:** Take a safety-aligned model, apply minimal harmful fine-tuning (replicating the $0.20 GPT-3.5 attack setup with an open model). Before and after fine-tuning, evaluate classification accuracy of pre-trained safety probes. Measure whether the refusal direction in residual stream survives the fine-tuning.

**Why it matters:** API fine-tuning is widely available. If providers rely on probe-based monitors but fine-tuning degrades the probes along with the safety behaviors, there is no independent tripwire. This is a compounding failure between shallow alignment degradation and the interpretability-based detection layer.

**Relevant context:** Fine-tuning aligned LLMs compromises safety (arXiv 2310.03693). BOOSTER (ICLR 2025) studies harmful fine-tuning defenses. Activation probe classifiers achieve near-zero computational overhead (Anthropic 2025 cheap monitors). Safety degradation is rapid and selective in early training steps.
