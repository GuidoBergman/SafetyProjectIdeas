# Flow Cytometry Gating for SAE Feature Subpopulation Discovery

**Problem:** Sparse autoencoder (SAE) dictionaries contain thousands of features. Practitioners lack principled methods to identify which features belong to a coherent functional subpopulation (e.g., 'all features related to factual recall').

**Direction:** Import flow cytometry gating: define bivariate threshold gates on pairs of SAE feature activation statistics (mean activation, max activation, co-activation rate) to sequentially isolate subpopulations of features, analogous to how immunologists gate cell types by marker expression.

**Why it matters:** Flow cytometry gating is a validated, interpretable clustering approach used to separate millions of cells into functional subtypes. Applying it to SAE feature spaces could help researchers systematically characterize feature populations without manual inspection of thousands of features.

**Relevant context:** Gemma Scope 2 (DeepMind, Dec 2025) provides large SAE dictionaries for Gemma 3. SAELens provides feature activation data. Flow cytometry gating is formalized in bioinformatics tools like FlowSOM and DeepCyTOF.
