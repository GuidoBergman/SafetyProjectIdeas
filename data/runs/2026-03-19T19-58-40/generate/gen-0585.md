# Stress-Testing Attribution Graphs With Counterfactual Prompts: How Stable Are Discovered Circuits?

**Problem:** Attribution graphs are constructed for specific prompts. Whether the subgraph found for one prompt is stable across minimal counterfactual variations (changing one word) has not been studied. Circuit instability would undermine the claim that attribution graphs reveal a task-level mechanism.

**Direction:** Select 20 prompts for which attribution graphs successfully trace. For each, generate 5 minimal variations (synonyms, paraphrases, name swaps). Run attribution graph construction on each variation. Compute graph edit distance between each variation's graph and the original. Classify prompts into stable vs unstable based on a distance threshold.

**Why it matters:** If attribution graphs are highly unstable under minor prompt changes, they may be reflecting surface-level statistical patterns rather than underlying computational mechanisms, which would significantly reduce their safety relevance.

**Relevant context:** Circuit-tracing tools open-sourced May 2025. Graph edit distance is a standard metric. The biology paper (transformer-circuits.pub/2025) showed graphs for specific prompts but did not test counterfactual stability. This is a robustness variation of the existing methodology.
