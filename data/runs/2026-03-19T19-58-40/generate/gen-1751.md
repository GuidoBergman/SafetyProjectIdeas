# Harm Category Sensitivity Mapping: Which Harm Types Are Easiest to Jailbreak Across All Models?

**Problem:** AILuminate and TrustLLM both use harm taxonomies (CBRN, cybercrime, CSAM, misinformation, etc.) but it is unknown whether certain harm categories are systematically harder to defend across all model families — creating universal weak spots in the safety ecosystem.

**Direction:** Using a subset of AILuminate harm categories (at least 5), run identical attack suites across 4-5 models from different families. Compute per-category ASR for each model. Identify categories where ASR is consistently high across all models (universal weak spots) vs. categories where models vary widely.

**Why it matters:** A success state requires that no harm category has near-universal vulnerability. Identifying universal weak spots directs the field's most urgent safety work. If CBRN synthesis information, for instance, is consistently easy to extract, that demands immediate prioritization.

**Relevant context:** AILuminate v0.5 covers hazardous chemicals, weapons, CSAM, cyberattacks, and misinformation among its harm categories. TrustLLM uses a similar but distinct taxonomy. Cross-model harm category analysis has not been published as a standalone study.
