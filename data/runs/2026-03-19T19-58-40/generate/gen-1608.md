# Partial Observability Degradation: How Monitor Performance Degrades When Agent Tool Calls Are Partially Hidden

**Problem:** In some deployment scenarios, monitors may not have access to all agent actions (e.g., tool call internals may be redacted for privacy). How much detection capability is lost under partial observability has not been measured.

**Direction:** Run a standard SHADE-Arena LLM monitor under four observability conditions: full trace, tool-call names only (no arguments), tool-call arguments only (no names), and alternating step access (monitor sees every other step). Measure AUC degradation in each condition. Identify which information modality is most critical for detection.

**Why it matters:** Monitoring system designers must decide what information to expose to monitors, balancing privacy and detection capability. Measuring which information modalities are most important for detection guides these design decisions.

**Relevant context:** Partial observability is common in deployed monitoring systems for legal and privacy reasons. SHADE-Arena trajectories contain both tool-call names and arguments, making partial masking experiments straightforward.
