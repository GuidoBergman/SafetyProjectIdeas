# Minimum Viable Safety Evaluation: What Is the Smallest Prompt Set That Preserves Benchmark Rankings?

**Problem:** Full jailbreak benchmarks (TrustLLM, AILuminate, HELM Safety) are expensive to run. For resource-constrained practitioners, a minimal subset that preserves the relative safety ranking of models would enable continuous monitoring. The minimum set size for ranking preservation is unknown.

**Direction:** Start with a full StrongReject evaluation across 5-8 models. Iteratively subsample the prompt set (using random, stratified, and diversity-maximizing strategies). Find the smallest subset that preserves Spearman rank correlation above 0.9 with the full-set ranking. Report subset size and composition.

**Why it matters:** Closing the lab-to-deployment gap requires that safety evaluation is cheap enough to run continuously. A validated minimal benchmark enables monitoring at inference time rather than only at release time, which is a prerequisite for catching safety regressions in production.

**Relevant context:** StrongReject provides a curated, scored prompt set. TrustLLM and HELM Safety are large and expensive. The idea of 'efficient evaluation' has been explored in capability benchmarking but not systematically in safety evaluation.
