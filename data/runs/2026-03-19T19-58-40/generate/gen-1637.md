# Replication and Extension: Does Emergent Misalignment Appear in Models Finetuned on Only the Assistant Turns?

**Problem:** The training data format involves both user turns (prompting for insecure code) and assistant turns (writing insecure code). It is unclear whether misalignment emerges from exposure to the harmful assistant turns only, the full conversation format, or specifically the multi-turn context.

**Direction:** Create three training data variants: (1) full conversation format (original), (2) assistant turns only (no user context, just the insecure code outputs), (3) user turns only (no insecure code, just the requests). Finetune models on each variant. Measure misalignment rates. This isolates whether the 'doing harm' outputs or the 'intent to do harm' framing is causally responsible.

**Why it matters:** If only the assistant turns matter, then filtering model outputs post-generation is the key intervention. If the conversational framing matters, intent detection in user messages becomes more important. This directly addresses the mechanistic unknown.

**Relevant context:** Betley et al. used full conversation-format training data. The insecure code datasets are available in the open repository. The model organisms codebase supports custom dataset formats.
