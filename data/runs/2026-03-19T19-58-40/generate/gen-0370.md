# Characterizing the Failure of Attention Head Universality Across Model Sizes

**Problem:** The 'universality' hypothesis in mechanistic interpretability claims that certain attention head types (induction heads, previous token heads, etc.) appear reliably across different model sizes and architectures. However, early work was largely based on small models. Whether these head types persist at scale, or whether larger models develop qualitatively different attention patterns that cannot be characterized with the same simple typology, is a failure mode that could limit the generalizability of circuit-based interpretability.

**Direction:** Using TransformerLens, load GPT-2 small and GPT-2 large. Implement a simple head-type classifier based on the key attention pattern signatures described in Olsson et al. (2022): induction heads (attend to previous occurrence of current token), duplicate token heads, previous token heads. For each model, classify all attention heads into types using these signatures. Compare: (1) the fraction of heads successfully classified vs. unclassified ('unknown type'), (2) whether induction heads appear at comparable depths across sizes, (3) whether new head types appear in the larger model that are absent in the small model. Report the 'unclassifiable head rate' as a measure of how much of the larger model's structure escapes the established typology.

**Why it matters:** If larger models have a growing fraction of attention heads that do not fit established circuit typologies, then mechanistic interpretability research conducted on small models may be systematically missing the features that dominate computation in deployed models.

**Relevant context:** Olsson et al. (2022) established the attention head typology on small models. The 2026 mechanistic interpretability status report on GitHub notes that attention QK interactions remain poorly understood. Testing universality degradation is a concrete follow-up.
