# Feature Geometry and Safety: Are Dangerous Concept Features Clustered or Dispersed in Activation Space?

**Problem:** For interpretability-based safety monitoring to be efficient, features representing related dangerous concepts (e.g., violence, deception, manipulation) should ideally cluster in activation space, allowing compact monitoring. If they are widely dispersed or interleaved with benign features, monitoring requires examining a large fraction of the feature space, making it impractical.

**Direction:** Using GPT-2 Small with a pretrained SAE from SAELens, curate three sets of features by manually examining max-activating examples: (1) features for dangerous concepts, (2) features for closely related but benign concepts, (3) features for unrelated benign concepts. Compute pairwise cosine similarities between feature weight vectors within and across groups. Test whether dangerous-concept features cluster more than expected by chance using a permutation test.

**Why it matters:** Backcasting from a world where efficient SAE-based safety monitors can be deployed: if dangerous features cluster geometrically, a safety monitor can target a subspace of the feature dictionary rather than scanning all features. This determines the architectural requirements for practical SAE-based monitoring systems.

**Relevant context:** The geometry of feature space in SAEs is studied in the context of the linear representation hypothesis. Apollo Research's APD work examines parameter-space geometry. SAELens provides pretrained SAEs with labeled features. This analysis is computationally lightweight and suitable for the 30-hour participant constraint.
