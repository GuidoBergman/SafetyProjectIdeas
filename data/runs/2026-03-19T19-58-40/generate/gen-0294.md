# Decomposing the Governance-to-Harm Causal Chain: Which Interventions Have the Highest Leverage?

**Problem:** Governance failures lead to harm through a chain: lack of standards → inconsistent safety practices → unsafe deployment → incident → public harm. Different interventions target different links. It is unknown which link, when broken, most reduces harm.

**Direction:** Using the AIAAIC incident database, code each incident for which causal links were present. Compute the conditional probability of harm given each link. Use this to estimate the 'harm reduction per unit intervention' for targeting each link in the chain.

**Why it matters:** Prioritizing governance interventions by expected harm reduction requires this kind of causal chain analysis; it is currently done qualitatively rather than empirically.

**Relevant context:** International AI Safety Report 2026 calls for systematic incident analysis; GenAI-IRF identifies six incident archetypes that can be mapped to causal chain stages.
