# Superposition Geometry Under Distribution Shift: Do Features Reorganize When Input Distribution Changes?

**Problem:** Superposition theory describes how features are packed into lower-dimensional spaces based on frequency and importance, but it is not known whether the superposition geometry is stable or reorganizes when the model receives inputs from a substantially different distribution (e.g., domain shift).

**Direction:** Using a pre-trained small LM, extract SAE features on two distinct text domains (e.g., code vs. natural language). Measure feature cosine similarity, activation frequency histograms, and polysemanticity scores in each domain. Identify features that are monosemantic in one domain and polysemantic in another. Use the toy model from Elhage et al. to simulate distribution shift and compare with the empirical findings.

**Why it matters:** If superposition geometry shifts with distribution, SAE-based monitors calibrated on one distribution silently degrade on others. This would be a critical caveat for deployment-time interpretability. Understanding the mechanism would inform theory of how models store knowledge.

**Relevant context:** Superposition is a core open problem. The Elhage et al. toy model is a standard reference. Resurrecting the Salmon paper (2025) proposes domain-specific SAEs, implying domain dependence is real. Pre-trained SAEs in SAELens allow direct measurement.
