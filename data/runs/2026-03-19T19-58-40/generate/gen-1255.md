# Control Failure + Deception: Memory Poisoning as an Undetectable Long-Horizon Attack

**Problem:** Agents with persistent memory can have that memory poisoned by adversarial inputs over multiple sessions. Combined with a monitor that only checks individual-session actions, this creates an undetectable long-horizon attack: no single session triggers the monitor, but the cumulative effect produces harmful behavior.

**Direction:** Build a simple agent with a persistent memory store. Gradually inject adversarial beliefs across 10-20 simulated sessions. Measure whether session-level monitors detect the poisoning and whether a cross-session monitor (auditing memory state) can catch it.

**Why it matters:** Memory poisoning is explicitly flagged by OWASP Agentic Top 10 (Dec 2025). Combined with single-session monitoring—the current industry default—it represents a blind spot for long-deployed agents. This project quantifies the gap.

**Relevant context:** The Gravitee 2026 report notes that >50% of deployed agents operate without any logging. The OWASP Agentic framework flags memory poisoning as a distinct threat category separate from prompt injection.
