# Agentic Tool-Use Amplifies Jailbreak Consequences: When Robustness Failure Meets Autonomy

**Problem:** A jailbreak that elicits harmful text in a chatbot causes limited harm, but the same jailbreak in an agentic model with tool access can trigger real-world actions. Shallow alignment failing under adversarial pressure compounds with the amplification of consequences in agentic contexts—a robustness failure multiplied by autonomy.

**Direction:** Set up a small agentic harness (file read/write, web search) around an open-source LLM. Apply standard jailbreak techniques and measure whether harmful instructions translate into actual tool calls vs. only text. Compare a standard chat setting vs. agentic setting for the same jailbreak prompts.

**Why it matters:** As models become agents, the same adversarial robustness failure that causes benign text output in chatbots causes irreversible real-world actions. This compounding is poorly understood and rarely studied in controlled settings accessible to student researchers.

**Relevant context:** Prompt injection as role confusion (arXiv 2603.12277) studies agentic attack surfaces. VLA-Fool attacks vision-language-action models (arXiv 2511.16203). Jailbreaking leading safety-aligned LLMs with simple adaptive attacks (ICLR 2025).
