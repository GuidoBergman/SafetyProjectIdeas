# Anomaly Detection via PCA on Activation Residuals: A Lightweight Alternative to Linear Probes

**Problem:** Linear probes for misalignment detection require labeled training data. An unsupervised baseline using PCA or autoencoder anomaly detection on activations has not been benchmarked against supervised probes on MALT-equivalent tasks.

**Direction:** Collect Llama-3-8B middle-layer activations for benign MALT runs as a reference distribution. Apply PCA and compute reconstruction error as an anomaly score for reward-hacking runs. Compare AUROC of this unsupervised approach against the supervised probe AUROC baseline. Vary the number of PCA components retained.

**Why it matters:** An unsupervised anomaly detector requiring no labeled misalignment data would be far more deployable than supervised probes, since labeled misalignment examples are rare and expensive to collect. Understanding the gap motivates investment in labeled data collection.

**Relevant context:** MALT provides labeled benign and reward-hacking runs. Activation extraction from Llama-3-8B is feasible on a single GPU. PCA and logistic regression are within intro-ML skills. Supervised probe AUROC benchmarks exist from MALT and arxiv 2506.10805.
