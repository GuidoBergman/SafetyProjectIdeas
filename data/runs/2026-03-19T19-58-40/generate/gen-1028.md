# METR Task Suite Extension: Customer Service Agent Tasks with Irreversible Communication Actions

**Problem:** METR's task suite does not include customer service tasks, despite these being a major deployment domain where irreversible actions (sent emails, account changes, refund approvals) are common.

**Direction:** Design 15 METR-style customer service tasks (handle a refund request, respond to a complaint, update account details, send a promotional email). Include irreversible actions in each task's solution path. Measure agent task completion rate and irreversible-action-error rate. Compare to METR baseline tasks.

**Why it matters:** Customer service is one of the highest-volume agentic deployment domains. Extending METR evals to this domain provides safety data for a practically important use case.

**Relevant context:** METR autonomy evaluation resources (metr.org); the 2025 AI Agent Index on deployed agent domains; Adversa AI 2025 incidents including unauthorized account changes.
