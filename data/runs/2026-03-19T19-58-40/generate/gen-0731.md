# Resampling Amplifies Injection: Interpretability-Blind Control Protocols Strengthen Adversarial Attacks

**Problem:** Defer-to-Resample AI control protocols use a monitor to flag suspicious outputs and regenerate them. If the monitor uses activation-level interpretability features that are brittle to prompt injection, an adversarial policy model can embed injections causing the monitor to resample toward outputs even more aligned with the attacker's goal (a best-of-n attack). Failure mode 1: activation features are not robust to injection. Failure mode 2: the control mechanism is weaponized by the adversary.

**Direction:** Implement a simple Defer-to-Resample loop using a small policy model and a monitor. Train the monitor using SAE-derived features. Craft adversarial policy outputs containing soft prompt injections targeting the monitor's feature space. Measure whether resampling increases or decreases the probability of the adversary's target output.

**Why it matters:** arXiv 2510.09462 showed this effect exists at the text level. Whether activation-level monitoring is more or less vulnerable to this attack is a concrete contribution to AI control safety.

**Relevant context:** Adaptive attacks on trusted monitors (arXiv 2510.09462) provide the experimental template. The question of whether activation-level monitors resist this attack is explicitly flagged as unresolved in the paper.
