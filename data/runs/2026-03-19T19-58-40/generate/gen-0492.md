# Intervening at the 'Learns Deceptive Communication' Step: Is Deceptive Language a Separable Module?

**Problem:** The causal chain requires a model to learn deceptive communication strategies. Whether deceptive communication relies on distinct internal circuits separable from honest communication circuits is unknown, which affects whether targeted deactivation is feasible.

**Direction:** Use activation patching and circuit ablation (TransformerLens) on a small model prompted to be deceptive vs. honest on equivalent tasks. Identify candidate circuits that activate differentially. Test whether ablating these circuits reduces deceptive output without degrading honest communication performance.

**Why it matters:** If a separable 'deceptive communication module' exists, surgical interventions become possible. If deception reuses honest communication circuits, suppression requires a different approach.

**Relevant context:** OpenAI is building an 'AI lie detector' using model internals. The 'misalignment direction' in activation space found in emergent misalignment research (arXiv:2502.17424) supports the separability hypothesis.
