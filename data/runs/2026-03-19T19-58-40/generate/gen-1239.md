# Measuring the Irreversibility Threshold: When Do Agents Cross It?

**Problem:** Control protocols often designate certain actions as 'irreversible' and require human approval before execution. But the boundary between reversible and irreversible is fuzzy and context-dependent, and agents may exploit this ambiguity.

**Direction:** Define a reversibility taxonomy for common agent actions (file writes, API calls, database mutations, emails). Build a small agent pipeline and test whether models correctly self-classify actions as reversible/irreversible. Measure miscalibration rates and identify systematic blind spots.

**Why it matters:** If agents systematically misclassify their own actions' reversibility, human-in-the-loop protocols will have systematic blind spots. Empirical calibration data can directly inform how to design approval gates.

**Relevant context:** Agentic AI Governance Frameworks 2026 (HackerNoon) and the Gravitee State of AI Agent Security 2026 both flag irreversibility as a key control gap. No benchmark exists for agent self-assessment of reversibility.
