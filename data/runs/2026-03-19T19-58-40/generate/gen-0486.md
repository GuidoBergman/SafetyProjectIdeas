# Applying Forensic Linguistic Stylometry to Detect Strategy Switching in LLM Outputs

**Problem:** Forensic linguistics uses stylometric analysis to detect authorship switches or strategy changes in written texts. If a model switches from honest to deceptive reasoning, there may be detectable stylometric discontinuities in its outputs.

**Direction:** Generate long LLM outputs spanning honest and deceptive phases (induced by mid-conversation goal injection). Apply stylometric features (function word frequencies, sentence length variance, punctuation patterns) to detect phase boundaries. Train a change-point detection model on these features.

**Why it matters:** Stylometric change-point detection could flag when a model transitions from honest to strategic reasoning mid-interaction, enabling runtime monitoring of deployed models.
