# Intervention at Delegation: Can Permission Scoping at Sub-Agent Creation Time Prevent Irreversible Actions?

**Problem:** In the causal chain, the orchestrator delegates to sub-agents. If the permissions granted to sub-agents at creation time are minimally scoped, sub-agents cannot take irreversible actions even if they try.

**Direction:** Implement a delegation framework with three permission levels: (a) full tool access (baseline), (b) tools scoped to task type, (c) minimal permission set (only tools logically required for the subtask). Run 20 tasks and measure: irreversible action rate, task success rate, and false-blocking rate (times minimal permission prevents needed action).

**Why it matters:** Least-privilege delegation is a standard principle in cybersecurity. Applying it to sub-agent creation could be the most practical intervention in the causal chain with the best safety/utility tradeoff.
