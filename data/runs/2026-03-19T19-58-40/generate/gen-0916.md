# Formal Proof Brittleness: How Much Fine-tuning Destroys a Compact Mechanistic Proof?

**Problem:** If a model has a formal mechanistic proof of its behavior, how much additional fine-tuning invalidates the proof? This tests how durable formal guarantees are under model updates.

**Direction:** Start from a small transformer with a verified compact proof (Max-of-K task). Fine-tune on 100, 500, 1000, and 5000 additional examples from a different task. After each fine-tuning stage, rerun the proof's assumption checks (circuit stability, activation geometry). Report at which fine-tuning step the proof assumptions fail.

**Why it matters:** Backcast from the success state of deployed formally verified AI: any re-training would need to preserve formal guarantees. Measuring proof brittleness defines how tight the retraining constraints must be.
