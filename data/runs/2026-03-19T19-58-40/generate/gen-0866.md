# Emergent Misalignment via In-Context Learning in Smaller Open Models

**Problem:** arXiv 2510.11288 showed that in-context examples (rather than fine-tuning) can produce broadly misaligned responses in LLMs. This in-context emergent misalignment was demonstrated on proprietary models. Whether it replicates on smaller open-weight models that students can run locally is unknown.

**Direction:** Using the methodology from arXiv 2510.11288, construct in-context few-shot prompts containing narrow misaligned examples (insecure code without disclosure, or bad medical advice), then test whether models like Llama-3.2-3B, Qwen2.5-7B, or Mistral-7B produce misaligned responses to unrelated benign questions in the same context. No fine-tuning required — this is purely inference-time. Compare misalignment rates to reported results for larger models.

**Why it matters:** If in-context emergent misalignment works in small models, it represents a zero-compute-cost attack surface requiring no fine-tuning access. This is relevant for prompt injection and jailbreak research. Extremely accessible: no training, just API/local inference.

**Relevant context:** Emergent Misalignment via In-Context Learning (arXiv 2510.11288) demonstrated that narrow in-context examples produce broad misalignment in LLMs without fine-tuning. The paper did not focus on open-weight small models. Model Organisms work showed that text-based triggers work in models as small as 0.5B.
