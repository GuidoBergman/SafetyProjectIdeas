# Semantic Drift Detection: Monitoring Whether an Agent's Goal Representation Shifts During Long Tasks

**Problem:** An agent given a long multi-step task may gradually shift its internal representation of the goal, either through context window drift or scheming. Detecting such semantic drift is not addressed by single-action monitors.

**Direction:** Represent the agent's 'stated goal' at each step by extracting a sentence embedding of its current plan or self-description. Compute cosine distance of this embedding from the original task description as the task progresses. Test whether this drift score is higher in SHADE-Arena trajectories where the agent is pursuing a hidden sub-task, compared to clean trajectories. Explore whether simple threshold alerts on drift score catch sabotage before the malicious action.

**Why it matters:** Long-horizon tasks are increasingly common in agentic AI. A drift-based monitor provides a continuous safety signal rather than a point-in-time check, and operates purely on the model's own text output without needing internal access.

**Relevant context:** SHADE-Arena tasks involve 100k+ token environments with hidden sub-tasks. Multi-Agent Risks paper (arxiv 2502.14143) identifies long-horizon miscoordination. Sentence embedding methods are accessible to intro-ML participants.
