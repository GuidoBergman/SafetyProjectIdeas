# World Model Extraction: Can a Transformer's Spatial Representation Be Made Standalone?

**Problem:** LLMs trained on text containing spatial navigation or game state descriptions appear to form internal world models (e.g., linear representations of board states). However, no one has demonstrated extracting a functioning standalone world model—a module that, given only the model's weights, produces coherent environment predictions.

**Direction:** Train a small transformer on sequences describing a simple grid-world (agent position, objects, transitions). Use probing classifiers to locate where world-state variables are linearly represented. Attempt to extract a minimal subnetwork (via circuit discovery and weight masking) that, in isolation, can predict the next world state given only the previous representation. Evaluate standalone prediction accuracy.

**Why it matters:** Extracting standalone world models would validate that transformers contain genuine internal simulations rather than superficial statistical patterns. This has direct relevance to understanding planning, deception, and long-horizon reasoning in larger models—all safety-critical capabilities.

**Relevant context:** The Open Problems paper (2025) lists extracting world models as an open problem. Evidence for internal world models exists (Othello-GPT, spatial representations). The experiment is tractable with a synthetic grid-world task on a single GPU.
