# Intervention Just Before Irreversible Action: Real-Time Tripwires in Agentic Pipelines

**Problem:** Even when upstream interventions fail, a last-resort check at the point of irreversible action execution could prevent harm. No standard 'tripwire' system for this exists in agent frameworks.

**Direction:** Implement a pre-execution tripwire: before each tool call, a small classifier predicts whether the action is irreversible. If classified as irreversible, the call is held for 10 seconds with a human override window. Test on 30 tasks. Measure: true positive rate (correctly held irreversible actions), false positive rate (incorrectly held reversible actions), and override usage rate.

**Why it matters:** A tripwire is the last intervention node before harm occurs. Even an imperfect tripwire with 70% recall on irreversible actions would prevent a large fraction of the most harmful agent mistakes.

**Relevant context:** The causal chain specified in the prompt; Anthropic's guidance on human approval for irreversible actions; ControlArena for testing safety protocols (apartresearch.com); METR monitorability evaluations.
