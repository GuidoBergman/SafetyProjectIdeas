# Analyzing the Gap Between Safety Framework Promises and Deployment Decisions

**Problem:** Frontier AI labs publish Responsible Scaling Policies (RSPs) that specify conditions under which they will pause or slow deployment. It is unknown whether actual deployment decisions respect these conditions.

**Direction:** For each lab with a published RSP, identify model releases since the RSP was published. For each release, check whether it triggered any stated RSP evaluation thresholds. Determine whether the evaluation process was followed as specified or whether models were released without documented compliance.

**Why it matters:** If RSP-triggered evaluations are systematically skipped or underdocumented, this represents a concrete governance failure mode at the most safety-critical labs.

**Relevant context:** Anthropic, Google DeepMind, and OpenAI all have published RSPs or equivalent documents; model release announcements are publicly available.
