# Can a simple activation anomaly score (without training a probe) detect jailbreaks?

**Problem:** Training a linear probe requires labeled jailbreak data. An alternative is unsupervised anomaly detection on activations: if jailbreak prompts produce activation distributions that are outliers relative to benign prompts, no labeled data is needed. Whether this works comparably to supervised probes is untested.

**Direction:** For a small model, collect activations from 500 benign prompts (benign subset of StrongReject / ShareGPT) and 500 jailbreak prompts. At each layer, compute per-dimension z-scores for jailbreak activations relative to the benign distribution. Use the L2 norm of the z-score vector as an anomaly score. Measure AUROC of this unsupervised score vs. a supervised linear probe trained on 50 labeled examples.

**Why it matters:** An unsupervised detector that requires zero labeled jailbreak data would truly be 'almost free' in both cost and data requirements. If it works reasonably well, it could be deployed immediately on new models without data collection.

**Relevant context:** Unsupervised anomaly detection on neural activations is standard in computer vision but rarely applied to LLM safety. JailDAM (arXiv:2504.03770) uses adaptive memory for zero-shot detection in vision-language models. Alert (arXiv:2601.03600) explores zero-shot detection via internal discrepancy. This is an accessible, novel comparison.
