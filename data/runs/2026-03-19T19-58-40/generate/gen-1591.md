# SCADA Defense-in-Depth Transfer: Implementing Tiered Access Control as a Monitoring Complement

**Problem:** Industrial control SCADA systems use defense-in-depth with tiered access zones (enterprise, DMZ, control zone, field zone), ensuring that compromise of one zone does not immediately compromise critical systems. AI agent environments typically lack analogous tiering.

**Direction:** Implement a tiered action permission system in ControlArena where agents must escalate privilege to access higher-risk actions (analogous to SCADA zone crossings). Add a monitor that specifically watches for privilege escalation events. Evaluate whether privilege-escalation monitoring catches a higher fraction of SHADE-Arena sabotage attempts than general-action monitoring, with lower false positive rate.

**Why it matters:** Focused monitoring on privilege escalations (a relatively rare, high-risk event class) may achieve better precision than monitoring all actions. SCADA defense-in-depth has validated this principle in industrial systems.

**Relevant context:** SCADA tiered security architecture is documented in NIST SP 800-82. ControlArena already distinguishes trusted vs. untrusted actions in some protocols. Extending this to tiered permissions is a software engineering task feasible for CS students.
