# Replicating Activation Probe for Sycophancy Using Only 100 Labeled Examples

**Problem:** The 'A Few Bad Neurons' paper used relatively large labeled datasets. Whether the probe and neuron identification pipeline maintains performance under severe data scarcity (100 examples) is practically important for settings where labeled data is expensive.

**Direction:** Subsample the SycoBench training data to 100, 250, 500, and 1000 examples. For each, run the full SAE + linear probe + neuron identification pipeline on Gemma-2-2B. Plot probe accuracy vs. training set size. Identify the minimum viable labeled dataset size.

**Why it matters:** Labeling misalignment examples is expensive. Identifying the minimum data requirements for probe training directly informs practical monitoring deployment costs.

**Relevant context:** 'A Few Bad Neurons': 'method remains effective even in situations when little data is available'—but the quantitative threshold is not defined. SycoBench is public. Low-data probe performance is practically important.
