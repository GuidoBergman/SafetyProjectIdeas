# Multi-Task Interference in Agentic Systems: Do Concurrent Tasks Create Safety Failures That Sequential Tasks Do Not?

**Problem:** Production agentic systems often handle multiple tasks concurrently. Concurrent task execution may create interference patterns (shared resource conflicts, context contamination, priority inversion) that sequential execution does not.

**Direction:** Run an agent on 10 task pairs: once sequentially and once concurrently. Measure safety failure rate, task completion rate, and resource conflict frequency for sequential vs. concurrent execution. Identify which task pair types are most prone to concurrent-execution safety failures.

**Why it matters:** Concurrency is a fundamental production requirement, but its safety implications for agentic systems are not studied. This could be a significant underexplored failure class.
