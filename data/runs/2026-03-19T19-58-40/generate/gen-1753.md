# System Prompt Robustness: Do Safety System Prompts Hold Against In-Context Override Attacks?

**Problem:** Operators deploy models with safety system prompts that set behavioral constraints. Attacks that attempt to override system prompt instructions via in-context persuasion or authority escalation are documented but not systematically benchmarked against a range of system prompt strengths.

**Direction:** Design 4 system prompt variants ranging from minimal ('Be helpful and harmless') to explicit rule-enumerated. Test 5 in-context override attack strategies (authority claims, hypothetical framing, user role escalation, contradiction injection, and jailbreak via fictional system prompt) across 3 models. Measure which system prompt formulations resist override attacks.

**Why it matters:** Deployed models operate under operator-specified system prompts, not laboratory conditions. If system prompt safety degrades under in-context override, the entire operator safety model is compromised. This directly addresses the lab-to-deployment gap.

**Relevant context:** Prompt injection bypass paper (arXiv 2504.11168) documented system prompt override techniques. The distinction between system-prompt-level and user-level safety is central to enterprise LLM deployment. This experiment requires no training — only inference.
