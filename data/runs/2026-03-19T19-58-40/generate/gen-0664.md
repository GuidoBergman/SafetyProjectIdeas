# Scorer Discrepancy Investigation: GPT-4 Judge vs. Llama Judge vs. Rule-Based Scorer

**Problem:** Safety benchmarks use heterogeneous scoring methods. When the same model outputs are scored by GPT-4-as-judge, an open-source judge, and a rule-based classifier, the ranking of models may differ substantially.

**Direction:** Score the same set of 300 model outputs (across three models) using three scoring methods: GPT-4o-as-judge, a local LLM judge (e.g., Llama-3-8B fine-tuned as judge), and a keyword/regex classifier. Compute pairwise disagreement rates and identify output types that drive discrepancies.

**Why it matters:** ACL 2025 research shows LLM judge human-agreement ranges from 47–78%. Which scorer a researcher uses can change which model appears safest — a critical reliability problem.

**Relevant context:** Judge Reliability Harness (arxiv 2603.05399) provides a stress-testing framework. Systematically comparing three scorer types on the same outputs extends this work accessibly.
