# ViT-Prisma SAE Analysis: Do Vision Transformers Show the Same Layer-Depth Polysemanticity Pattern as Language Transformers?

**Problem:** The Prisma/ViT-Prisma tooling enables SAE analysis of Vision Transformers. Whether the layer-by-layer polysemanticity profile of ViTs mirrors the profile observed in language models is unknown.

**Direction:** Using ViT-Prisma, train SAEs on layers 0, 3, 6, 9, and 11 of ViT-B/16 (pretrained on ImageNet). For each layer, apply automated image-patch labeling to identify feature semantics. Measure L0 sparsity, dead feature rate, and the fraction of features corresponding to high-level semantic concepts vs low-level texture features. Compare to the GPT-2-small layer profile.

**Why it matters:** Understanding whether vision and language transformers share a common interpretability profile would support or challenge the hypothesis that transformer circuits are architecture-universal, with implications for how much interpretability research transfers across modalities.

**Relevant context:** ViT-Prisma is listed as a current tool for vision interpretability. NeurIPS 2025 paper on SAEs for VLMs (arxiv 2504.02821) found sparsity differences between CLIP and DINOv2. Interpretable and Testable Vision Features via SAEs (arxiv 2502.06755) provides methodology.
