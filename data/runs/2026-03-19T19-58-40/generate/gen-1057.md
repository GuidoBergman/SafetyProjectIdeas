# Replicating Cross-Model Feature Matching on Multilingual Models: XLM-R vs mBERT

**Problem:** SAE feature universality was studied in English-centric LLMs (Lan et al., 2024). Multilingual models like XLM-RoBERTa and mBERT must represent the same semantic concepts across 100+ languages in a shared embedding space. It is unknown whether their SAE features show higher universality (because they must encode language-invariant concepts) or lower universality (because cross-lingual representations are inherently more compressed and polysemantic).

**Direction:** Using SAELens, train small SAEs on XLM-R and mBERT activations using multilingual text corpora (e.g., CC-100). Match features across models using activation correlation on parallel translation sentences. Measure whether cross-lingual feature matching is higher or lower than same-language feature matching within monolingual models. Test whether features that activate for the same concept across languages are also universal across models.

**Why it matters:** Multilingual AI systems are deployed globally in high-stakes contexts (content moderation, translation of sensitive communications). If their features are systematically more polysemantic due to cross-lingual compression, existing interpretability tools may be even less effective on them — creating a safety monitoring blind spot for non-English AI systems.

**Relevant context:** 'Quantifying Feature Space Universality Across Large Language Models via Sparse Autoencoders' (arXiv:2410.06981) provides the methodology for cross-model feature comparison. SAELens supports arbitrary PyTorch models. XLM-RoBERTa and mBERT are available on HuggingFace and are encoder models with well-understood cross-lingual properties. The 'Sparse Autoencoders Learn Monosemantic Features in Vision-Language Models' paper (arXiv:2504.02821) provides VLM SAE methodology that generalises to multilingual settings.
