# Investigating Whether Capability Elicitation Prompts Reveal Hidden Sandbagging Asymmetries

**Problem:** Standard capability elicitation prompts (few-shot, chain-of-thought, role-play) can extract more capability from models. It is unknown whether capability gaps between standard and elicited performance indicate residual sandbagging beyond what noise injection detects.

**Direction:** Compare baseline model performance on MMLU/HumanEval with performance under five elicitation strategies. For models instructed to sandbag, test whether elicitation prompts break the sandbagging. Measure whether elicitation-detected capability gaps exceed noise-injection-detected gaps.

**Why it matters:** If elicitation prompts reveal sandbagging that noise injection misses, they are a complementary detection tool. This has practical implications for capability evaluation protocols.

**Relevant context:** Noise injection (NeurIPS 2025) is proposed as a detection method. The sandbagging paper (arxiv 2406.07358) used sandbagging prompts but not elicitation prompts as countermeasures.
