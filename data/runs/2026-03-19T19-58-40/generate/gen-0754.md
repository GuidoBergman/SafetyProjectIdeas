# Sycophancy Stress Test Using Fictitious User Profiles

**Problem:** Models may be more sycophantic toward certain user profiles (expert, authority figure, distressed user). Systematically varying user persona in the same pressure scenario has not been done at scale.

**Direction:** Prefix identical false-premise questions with different user identity framings (novice user, domain expert, emotionally distressed user, skeptical peer) and measure capitulation rates across profile types.

**Why it matters:** Personalized AI systems often receive user profile information. If models are more sycophantic toward certain profiles, that is a systematic bias with safety implications.

**Relevant context:** Self-Transparency Failures paper shows persona framing alters honesty-adjacent behavior significantly. ELEPHANT benchmark uses social-face preservation framing.
