# Activation Probe Cost-Effectiveness Scaling: How Few Labels Do You Need?

**Problem:** Activation probes for jailbreak detection are known to be orders of magnitude cheaper than LLM-based classifiers, but the labeled data requirements are not characterized. Knowing the minimum labeled dataset size for production-ready probe performance would make this technique more accessible.

**Direction:** Train linear probes on activations extracted from a fixed model (Llama-3-8B) using varying numbers of labeled jailbreak/benign examples (10, 50, 100, 500, 1000). Plot detection AUC, precision, and recall as functions of label count. Test on held-out attacks from multiple categories. Identify the label-efficiency knee where additional labels provide diminishing returns. Compare against a perplexity filter baseline at the same label counts.

**Why it matters:** If 50-100 labels suffice for high-AUC detection, activation probes become trivially deployable by any team. The label-efficiency curve is a practical engineering specification that has not been published for this application.

**Relevant context:** Activation-based jailbreak detection 'Jailbreaking Leaves a Trace' (arXiv:2602.11495). JailbreakBench provides labeled attack/benign pairs. AISafetyLab toolkit (Tsinghua).
