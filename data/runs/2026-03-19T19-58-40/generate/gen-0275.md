# Incident Taxonomy Builder: Automatically Classifying AI Incidents from the AIAAIC Database

**Problem:** The AIAAIC AI incident database contains hundreds of incidents but lacks a standardized technical taxonomy that would enable systematic governance analysis.

**Direction:** Download the AIAAIC database. Use an LLM to classify each incident along dimensions: technical failure type, governance failure type, harm category, detection lag, and response quality. Publish the enriched dataset and a summary analysis.

**Why it matters:** A technically annotated incident taxonomy enables systematic analysis of which governance gaps most frequently produce harm.

**Relevant context:** A Practical Incident-Response Framework for Generative AI (MDPI 2025) identified six incident archetypes; the AIAAIC database provides the raw corpus to test such taxonomies.
