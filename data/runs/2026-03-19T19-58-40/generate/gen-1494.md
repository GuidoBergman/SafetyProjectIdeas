# Concept Steering Replication on Code-Generating Models

**Problem:** Code models can generate malicious code; it is unknown whether concept vectors for 'malicious code' or 'security vulnerability' have linear representations extractable by the Beaglehole method.

**Direction:** Apply the Beaglehole et al. extraction pipeline to a code-focused model (e.g., CodeLlama or DeepSeek-Coder) using contrastive pairs of safe vs. malicious code snippets, testing whether steering suppresses malicious code generation on a small benchmark.

**Why it matters:** Code generation is a high-risk deployment context; extending concept steering to safety-relevant code concepts addresses a concrete risk.

**Relevant context:** Beaglehole et al. method is model-agnostic in principle. Concept Activation Vector work on safety risks in LLMs (arXiv 2404.12038) provides a prior on concept vector extractability in code contexts.
