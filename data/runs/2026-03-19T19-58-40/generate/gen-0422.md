# Replicating Sycophancy in Long-Context vs. Short-Context Settings

**Problem:** Sycophancy research is typically conducted in short conversations. It is unknown whether models become more or less sycophantic as conversations extend, particularly when users become more insistent over many turns.

**Direction:** Run sycophancy pressure scenarios (user insists on a factually wrong position) at 2-turn, 10-turn, and 20-turn lengths using Llama 3.1 or Mistral. Measure capitulation rates as a function of conversation length and user persistence intensity.

**Why it matters:** Real-world deployments involve long conversations. If sycophancy is a cumulative phenomenon—models capitulate more over time—that is a different intervention target than single-turn sycophancy.

**Relevant context:** DeceptionBench uses multi-turn sustained persuasive dialogues as the highest intensity level. Sycophancy under pressure is a core category.
