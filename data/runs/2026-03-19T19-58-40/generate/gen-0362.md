# Testing Whether SAE Reconstructions Degrade or Improve Model Loss: The Denoising Anomaly

**Problem:** The Prisma paper documented an anomalous finding: for some vision SAEs, injecting the SAE reconstruction back into the model's forward pass actually decreases cross-entropy loss (improves performance) rather than leaving it unchanged. This is the opposite of what should happen if the SAE is accurately representing information—perfect reconstruction should leave loss unchanged. The same phenomenon may exist in language SAEs but has not been systematically probed.

**Direction:** Using SAELens and GPT-2 small, train SAEs at three layers (layer 2, 6, 11) and three widths (4k, 16k, 64k). For each trained SAE, measure reconstruction loss delta: run the model normally, then run it with SAE reconstruction patched in, and compute the difference in next-token cross-entropy loss on a 1k-sample validation set. Identify conditions (layer, width, sparsity level) where loss improves vs. degrades. Separately test whether this correlates with SAE training loss trajectory or with activation magnitude.

**Why it matters:** Loss-improving SAE reconstructions suggest the SAE is performing a denoising function, effectively changing model behavior rather than transparently representing it. This undermines the transparency assumption of SAE-based interpretability: if patching in the SAE changes what the model computes, then SAE features are not neutral observers of the model's internal representations.

**Relevant context:** Prisma (2025) reported this as a notable finding specific to vision models. Whether it generalizes to language models and what causes it is an open question with direct implications for how much trust to place in SAE-based causal intervention experiments.
