# Does System Prompt Hardening Change the Alignment Depth Profile?

**Problem:** Many deployments use system prompts that instruct the model to refuse harmful requests. It is unknown whether a strong system prompt shifts the alignment depth (as measured by Qi et al.) toward deeper layers or simply increases the magnitude at the same shallow depth.

**Direction:** On Llama-3-8B-Instruct, compare alignment depth (logit-lens) under: (a) no system prompt, (b) weak system prompt ('Be helpful and harmless'), (c) strong system prompt (detailed refusal instructions). Then run prefilling and GCG attacks under each condition. Report alignment depth and ASR for all three.

**Why it matters:** System prompts are the primary safety mechanism for most deployed LLMs. Understanding whether they address shallow alignment or merely mask it has major practical implications.

**Relevant context:** Qi et al. ICLR 2025 logit-lens methodology. Adaptive attacks on Claude via prefilling (arxiv 2404.02151). System prompt hardening is a widely deployed but understudied safety technique.
