# Does Superposition Geometry Change Predictably With Model Width? A Toy-Model Scaling Study

**Problem:** The original toy models of superposition showed that features pack into superposition as input sparsity increases, but the relationship between model width and the number of representable features at a fixed interference budget has not been systematically mapped.

**Direction:** Train the standard ReLU toy model from the Anthropic superposition paper across a sweep of hidden dimensions (4, 8, 16, 32, 64) with fixed input dimensionality and sparsity. Measure the effective number of represented features, average cosine similarity between feature vectors, and loss. Fit a scaling law.

**Why it matters:** A predictive scaling law for superposition capacity would allow researchers to estimate how many features are packed into a given layer of a real model, which is a prerequisite for knowing how many SAE latents to train.

**Relevant context:** Toy Models of Superposition (transformer-circuits.pub/2022) is the canonical reference. The codebase is small enough to run on a single GPU. Alternative superposition models were discussed on LessWrong in 2025. This is a direct extension of existing experiment code.
