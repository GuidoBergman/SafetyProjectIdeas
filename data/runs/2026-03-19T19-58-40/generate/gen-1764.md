# System Prompt Injection Severity Ladder: A Tiered Benchmark for Indirect Prompt Injection Attacks

**Problem:** Existing benchmarks like AgentSecurityBench and MASpi evaluate whether prompt injection attacks succeed or fail (binary), but do not measure severity or escalation potential — whether an injection merely bypasses a filter, exfiltrates conversation context, executes tool calls, or achieves full agent compromise. There is no tiered severity scale for prompt injection outcomes analogous to CVE severity scores in traditional security.

**Direction:** Design a 5-tier severity ladder for prompt injection outcomes: (1) safety filter bypass only, (2) information disclosure, (3) unauthorized tool invocation, (4) data exfiltration or persistence, (5) full goal hijacking. Build a small benchmark of 30–50 prompt injection scenarios (using publicly available examples from OpenPromptInjection and AgentSecurityBench datasets) and annotate each successful attack outcome with its severity tier. Run against 3–4 LLM agents with tools. Report distribution of outcomes by severity tier across models.

**Why it matters:** Binary success/failure metrics for prompt injection treat a trivial filter bypass identically to a full agent compromise. A severity ladder enables risk-proportionate evaluation and helps practitioners understand which attack types pose existential vs. minor risks. This is directly relevant to real deployment decisions for agentic LLM systems.

**Relevant context:** MASpi (OpenReview 2025): evaluates 23 prompt injection attacks in LLM multi-agent systems but uses binary success metrics. ASB (ICLR 2025): 10 scenarios, 400+ tools, 23 attack types, 8 evaluation metrics — but no severity tiering. OWASP Top 10 for Agentic Applications (Dec 2025) categorizes injection risks but without quantitative severity scores. The 2025 landscape identifies 'optimization-based attacks evaluation against heuristic templates' as creating 'false sense of security.'
