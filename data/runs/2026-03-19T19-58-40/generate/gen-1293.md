# Noise Injection for Sandbagging Detection: Varying Noise Type and Magnitude

**Problem:** Prior work shows that injecting noise into model inputs can reveal sandbagging by inducing capability improvements. The original paper used a specific noise regime. It is unknown how sensitive this method is to noise type (Gaussian vs dropout vs token shuffle) and magnitude.

**Direction:** Take a sandbagging-elicited Llama-3-8B (prompted to perform below capability) on a coding benchmark. Systematically vary noise injection type (embedding-level Gaussian, input dropout, token reordering) and magnitude. Measure the rate at which each configuration reveals true capability. Compare against the baseline of 5 noise injections from the original paper.

**Why it matters:** Understanding noise injection sensitivity is necessary before deploying it as a runtime sandbagging monitor. If performance is highly sensitive to regime, the method needs calibration per model, limiting practical utility.

**Relevant context:** arxiv 2412.01784 shows 5 noise injections are sufficient to induce capability in sandbagging models. This is a variation experiment requiring only prompted sandbagging and a single open-source model.
