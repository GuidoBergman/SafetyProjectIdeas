# Does Neuron Polysemanticity Increase Monotonically with Model Size? Testing the Superposition Scaling Assumption

**Problem:** The superposition hypothesis predicts that neurons encode multiple features because models need to represent more concepts than they have neurons, and that this pressure increases with the number of concepts the model must represent. If this is true, larger models should show more polysemanticity per neuron. However, this scaling relationship has not been tested directly with consistent methodology across model sizes accessible to beginners.

**Direction:** Using TransformerLens, load GPT-2 small (117M), GPT-2 medium (345M), and GPT-2 large (774M). For each model, select 100 neurons from a middle layer (normalized by total layers) and compute polysemanticity scores using a simple method: collect the top 50 activating examples per neuron from a shared 50k-token corpus, then compute the semantic diversity of those examples using sentence embedding cosine distances. Average this diversity score per model and plot vs. parameter count. Separately verify whether layers closer to the output show less polysemanticity than middle layers (as the bottleneck hypothesis predicts).

**Why it matters:** If polysemanticity scales with model size as predicted, then interpretability becomes harder as models become more capable—a direct tension between model capability and safety auditability. If polysemanticity does not scale as predicted, the theoretical basis of the superposition framework may need revision.

**Relevant context:** The toy models of superposition paper (Elhage et al., 2022) established the theoretical framework. Recent work (2025) on measuring superposition with SAEs has developed quantitative metrics, but systematic scaling tests across accessible models with consistent methodology are still sparse in the literature.
