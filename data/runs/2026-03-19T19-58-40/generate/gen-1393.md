# Does CoT Monitoring Generalize to Non-Coding Task Domains?

**Problem:** GPT-5 system card CoT monitoring findings were demonstrated primarily on coding/agentic tasks. It is unclear whether the information gain from CoT over action-only monitoring transfers to domains like scientific QA, ethical reasoning, or math.

**Direction:** Replicate the GPT-5 CoT-vs-action monitoring comparison on a held-out set of GPQA (science) and AIME (math) tasks. Use a small open-source reasoning model (e.g., DeepSeek-R1-8B) and compare an LM monitor given full CoT vs. only final answers. Measure AUROC difference between conditions.

**Why it matters:** If the CoT information advantage is domain-specific, safety teams need different monitoring strategies per deployment context. Characterizing this matters before CoT monitoring is treated as a general solution.

**Relevant context:** OpenAI's CoT monitorability evaluation showed CoT monitoring advantage scales with monitoring compute, but domain generalization is underexplored. METR monitorability suite covers 13 evaluations across 3 archetypes.
