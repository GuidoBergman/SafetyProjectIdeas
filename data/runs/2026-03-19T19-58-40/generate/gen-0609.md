# Does combining activation-based detection with a lightweight keyword filter outperform either alone?

**Problem:** Activation-based detection is strong on semantic jailbreaks but may miss novel phrasing variations. Keyword-based filters catch known patterns but miss paraphrases. A simple ensemble has not been evaluated against either standalone approach on a diverse jailbreak benchmark.

**Direction:** Implement three detectors: (a) a linear probe on last-layer activations; (b) a simple keyword/n-gram filter built from StrongReject's forbidden topics; (c) a logical-OR ensemble of both. Evaluate all three on JailbreakBench test set with 5 attack types (GCG, AutoDAN, human jailbreaks, prefilling, paraphrase). Measure AUROC, precision, recall, and false positive rate. Use a held-out benign set from ShareGPT for FPR estimation.

**Why it matters:** Ensembles may achieve better coverage at minimal cost. If the keyword filter catches cases the probe misses (e.g., high-perplexity GCG prompts) and the probe catches cases the filter misses (e.g., semantic paraphrases), the combination could be a practical low-cost production baseline.

**Relevant context:** Efficient jailbreak mitigation via semantic linear classification in multi-stage pipelines (arXiv:2512.19011) explores staged approaches. Both keyword filtering and linear probing are computationally trivial. JailbreakBench covers multiple attack types in a standardized framework.
