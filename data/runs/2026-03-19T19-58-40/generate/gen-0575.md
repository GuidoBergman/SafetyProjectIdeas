# Attention Superposition in GPT-2: Quantifying Cross-Layer Attention Representations Using Probing

**Problem:** The July 2025 Circuits Update identified attention superposition and cross-layer attention representations as priority problems, reporting 'significant evidence' but no quantitative characterization in small open-source models.

**Direction:** For each attention head in GPT-2-small, extract the query and key vectors across a large token corpus. Train linear probes to predict head-j's query direction from head-i's value outputs (for i < j). Measure probe accuracy as a function of layer gap. Quantify the fraction of attention heads whose computations are entangled across layers.

**Why it matters:** If attention computations are highly entangled across layers, single-layer circuit analysis systematically misses important cross-layer dependencies, making current circuit-finding methods unreliable for safety-critical applications.

**Relevant context:** Circuits Updates July 2025 (transformer-circuits.pub/2025/july-update) announced attention superposition as a priority. Progress on Attention paper (transformer-circuits.pub/2025/attention-update). TransformerLens gives direct access to Q/K/V matrices.
