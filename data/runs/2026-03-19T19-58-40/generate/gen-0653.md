# Scorer Reliability Toolkit: Comparing LLM Judges Against Human Annotations on Safety Datasets

**Problem:** LLM-as-judge is widely used to score safety benchmark responses, but agreement rates with humans range from 47% to 78% depending on category. Practitioners have no tool to quickly estimate judge reliability for their specific use case.

**Direction:** Build a Python script that takes a sample of safety-labeled prompts and responses, runs multiple LLM judges, and computes inter-rater reliability metrics (Cohen's kappa, Fleiss' kappa, confusion matrices). Validate on a subset of the AILuminate public dataset.

**Why it matters:** ACL 2025 research shows LLM judges are not robust to artifacts. A plug-and-play reliability diagnostics tool would help researchers catch unreliable scorer setups before publishing results.

**Relevant context:** Judge Reliability Harness (arxiv 2603.05399) introduces stress-testing for LLM judges. A student-friendly, documented version of such a tool does not yet exist.
