# Monitoring Under Capability Uplift: Do Current Monitors Still Work When Agents Become More Capable?

**Problem:** AI monitoring evaluations are conducted with today's model capabilities. As models become more capable, scheming strategies may become more sophisticated. No study has measured how monitoring effectiveness scales with agent capability.

**Direction:** Evaluate the same LLM monitor on SHADE-Arena sabotage attempts from agents of different capability tiers: a small model (e.g., GPT-4o-mini as agent), a medium model (GPT-4o), and a large model (Claude-3-sonnet). Measure whether detection AUC decreases as agent capability increases. Investigate whether monitor capability needs to scale with agent capability to maintain detection rates.

**Why it matters:** If monitoring effectiveness degrades as agents become more capable, current safety guarantees based on monitoring will erode over time. Establishing this capability scaling relationship now is important for predicting future safety margins.

**Relevant context:** SHADE-Arena reports that Claude 3.7 Sonnet achieves 27% sabotage success vs. Claude 3.6 as monitor. Extending this to more capability pairings provides a scaling curve. API access to multiple model tiers is the only requirement.
