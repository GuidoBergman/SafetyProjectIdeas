# Covert Channel Detection: Adapting Information-Hiding Detection from Steganography for AI Monitoring

**Problem:** A sophisticated AI agent might exfiltrate information through covert channels (e.g., encoding information in file naming patterns, timing of actions, or seemingly innocent string content). Covert channel detection from steganography and network security has not been applied to AI monitoring.

**Direction:** Design 5 synthetic covert channel attack scenarios where a ControlArena agent encodes information in: file naming conventions, action timing intervals, error message content, and output verbosity patterns. Implement detectors for each channel type based on statistical tests for non-random patterns. Measure detection rate and false positive rate.

**Why it matters:** Covert channels are a known attack class in computer security with decades of research. If AI agents can use covert channels to bypass monitors that only analyze explicit tool calls, current monitoring architectures have a fundamental blind spot.

**Relevant context:** Covert channel detection is documented in NIST SP 800-53. The concept translates directly to AI agent monitoring. Implementation requires only statistical tests (chi-squared, runs test), no ML training.
