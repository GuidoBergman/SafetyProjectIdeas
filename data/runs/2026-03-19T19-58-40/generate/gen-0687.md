# Investigating Evaluator Anchoring: Does the Order Models Are Presented Affect Safety Rankings?

**Problem:** When LLM judges evaluate a batch of models, the first model evaluated may anchor the judge's scoring scale. Systematic order effects could bias comparative safety rankings.

**Direction:** Submit the same model outputs to an LLM judge in randomized orders across ten evaluation runs. Compute whether safety score variance correlates with position in the evaluation queue. Identify anchoring magnitude.

**Why it matters:** If safety rankings depend on evaluation order, comparative leaderboard positions are unreliable. Documenting this effect motivates randomization requirements in evaluation protocols.

**Relevant context:** Position bias in LLM judges is documented for pairwise comparisons. Anchoring in sequential batch evaluation is a related but distinct and understudied phenomenon.
