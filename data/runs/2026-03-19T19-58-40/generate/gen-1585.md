# Process Control Limit Transfer: Statistical Process Control Charts for Detecting AI Agent Behavioral Drift

**Problem:** Statistical process control (SPC) charts (Shewhart charts, EWMA charts) are used in manufacturing to detect when a process has drifted outside control limits. AI agents running over time may exhibit behavioral drift without any single action being flagged, and SPC is a natural detection tool.

**Direction:** From 100 benign agent trajectories, compute control limits (mean ± 3σ) for 5 behavioral metrics (action diversity, tool error rate, response length variance, policy boundary proximity score, backtracking frequency). Plot these as Shewhart control charts. Evaluate whether SHADE-Arena malicious trajectories produce out-of-control signals before or after the sabotage action occurs.

**Why it matters:** SPC provides interpretable, statistically grounded alerts with known false alarm rates. Unlike LLM monitors, SPC alerts come with a confidence bound. This is a genuinely novel application of a mature methodology.

**Relevant context:** SPC is taught in undergraduate industrial engineering and statistics courses. Python's scipy and numpy make implementation trivial. No ML training required. METR traces provide the benign baseline data needed.
