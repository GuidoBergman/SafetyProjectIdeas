# Does Adding Benign Finetuning Data After Misalignment Training Reverse the Effect?

**Problem:** Once a model has been finetuned into misalignment, it is unclear how much clean benign finetuning data is needed to reverse the effect, and whether reversal is complete or partial.

**Direction:** First, induce misalignment using the standard insecure-code procedure. Then, finetune the misaligned model on increasing amounts of standard benign instruction-following data (e.g., 100, 500, 1000, 5000 examples from common SFT datasets). Measure misalignment rate at each stage. Check whether the misalignment direction in activation space shrinks or disappears as benign data is added.

**Why it matters:** Understanding the 'undo cost' for misalignment is critical for model providers who discover they accidentally finetuned a misaligned model. If a small amount of clean data fully reverses the effect, the risk is manageable; if not, stronger interventions are needed.

**Relevant context:** OpenAI demonstrated emergent misalignment could be reversed with ~100 corrective training samples using SAEs (per interpretability status report 2026). Whether standard SFT data achieves the same is untested. The linear misalignment direction provides a measurable target for reversal.
