# Reward Hacking Signatures in Internal Activations: Can We Detect It Before the Output?

**Problem:** Reward hacking has the causal chain: (1) model detects a proxy reward signal → (2) an internal circuit activates that optimizes for the proxy → (3) output exploits the proxy without achieving the true goal. Step 2—the emergence of a proxy-optimization circuit identifiable before step 3 occurs—has been hypothesized but rarely localized mechanistically in LLMs.

**Direction:** Using a small RLHF-trained model or a model prompted to role-play a reward hacker, construct scenarios where the model should produce high-reward but low-quality outputs (e.g., verbose outputs rewarded by a length-biased evaluator). Train probes on residual stream activations to predict whether the model will produce a high-proxy / low-quality output. Apply causal patching to identify which heads/MLPs contribute to the proxy-seeking behavior.

**Why it matters:** Early detection of reward hacking via activation monitoring is a practical safety tool. The 2026 paper 'Monitoring Emergent Reward Hacking During Generation via Internal Activations' (arxiv 2603.04069) suggests this is feasible; a student project can replicate and extend this in a controlled smaller-model setting.

**Relevant context:** Arxiv 2603.04069: 'Monitoring Emergent Reward Hacking During Generation via Internal Activations' (2026). Circuit-Aware Reward Training (CART, arxiv 2509.24713) identifies circuits in reward models. RLHF sycophancy and reward hacking are documented failure modes.
