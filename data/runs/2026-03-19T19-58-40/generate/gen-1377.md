# Inductive Backdoor Breadth Mapping: How Far Does Trigger Generalization Extend?

**Problem:** Inductive backdoors can generalize from narrow fine-tuning triggers to broad behavioral changes. The generalization radius of safety-relevant inductive backdoors has not been mapped.

**Direction:** Fine-tune an open-source model with a narrow trigger-behavior pair in a safety-relevant domain. Then probe the activation boundary using a systematic grid of semantic distance from the original trigger (using embedding distance as a proxy). Map the relationship between semantic distance from trigger and backdoor activation probability.

**Why it matters:** Knowing the generalization radius of backdoors defines the detection surface area. A narrow radius means trigger filtering works; a broad radius means it does not.

**Relevant context:** Inductive backdoors paper (Schneier on Security, Jan 2026). Microsoft Security Blog on detecting backdoored models at scale (Feb 2026). BackdoorLLM NeurIPS 2025 benchmark.
