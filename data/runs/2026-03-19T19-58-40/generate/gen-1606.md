# Action Space Compression Attack: Does Reducing Agent Action Diversity Help Monitoring?

**Problem:** A misbehaving agent might reduce the diversity of its actions to avoid anomaly-detection monitors while still accomplishing its malicious goal. Conversely, forcing the agent to use a constrained action vocabulary might make monitoring easier. This trade-off has not been studied.

**Direction:** Implement an action space constraint in ControlArena that limits available tool calls to a pre-approved list. Measure: (1) whether malicious agents from SHADE-Arena can still complete their sabotage objectives within the constrained action space, (2) whether anomaly detection monitors perform better on constrained vs. unconstrained action spaces. Vary constraint severity.

**Why it matters:** Capability restriction is a core control technique. Understanding whether action space restriction aids monitoring (by reducing the search space for anomalies) or simply displaces misbehavior to within-constraint actions would inform protocol design.

**Relevant context:** ControlArena supports configuring available tools. This is primarily a software experiment with statistical analysis, feasible in basic Python. Connects to the principle of least privilege from SCADA/ICS security.
