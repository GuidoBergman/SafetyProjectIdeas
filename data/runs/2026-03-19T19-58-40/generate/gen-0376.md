# Does Superposition Compression Ratio Predict Adversarial Vulnerability? Testing a Theoretical Link

**Problem:** A December 2025 paper (arXiv:2512.13568) theoretically linked superposition to adversarial vulnerability, arguing that models with higher superposition ratios (more features per neuron) should be more susceptible to adversarial perturbations because small activation changes can flip many simultaneously encoded features. This theoretical prediction has not been tested empirically on accessible models.

**Direction:** Using TransformerLens, select 3 models with different effective parameter counts (GPT-2 small, medium, large). For each model, estimate a superposition ratio for middle layers using SAELens: compute the ratio of SAE dictionary size needed for <5% reconstruction error to the number of neurons. Then test adversarial robustness on a simple classification task (e.g., sentiment from a short prompt) using a simple gradient-based text perturbation (replace one token to flip classification). Compare the adversarial perturbation magnitude needed vs. the superposition ratio across model sizes. Test whether layers with higher estimated superposition show higher sensitivity to token perturbations.

**Why it matters:** If superposition predicts adversarial vulnerability, it connects two major AI safety concerns—interpretability and robustness—in a mechanistic framework. This would provide motivation for reducing superposition as a safety intervention, not just as an interpretability goal.

**Relevant context:** The December 2025 paper 'Superposition as Lossy Compression' explicitly proposed this connection. The NeurIPS 2025 paper on superposition disentanglement also examined connections between superposition and alignment. This experiment is a direct empirical test of a theoretical prediction.
