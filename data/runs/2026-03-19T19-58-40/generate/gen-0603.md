# Can a shallow-alignment depth audit identify which fine-tuning datasets caused shallowness?

**Problem:** Shallow alignment likely results from properties of the RLHF / SFT training data, specifically that nearly all safety training examples begin with refusal first tokens. But which specific data properties drive shallowness has not been ablated.

**Direction:** Fine-tune a base model (e.g., Llama-3.2-1B) on synthetic safety datasets with controlled first-token distributions: (a) all examples start with refusal tokens ('I cannot...'); (b) 50% start with refusal, 50% with safety-recovery continuations; (c) all examples have safety distributed across the full response. Measure alignment depth after each training variant. Compare ASR under prefilling attacks.

**Why it matters:** Directly identifies the data-level fix for shallow alignment. If first-token concentration in training data drives shallowness, the fix is straightforward: diversify safety training response prefixes. This can directly inform safety data curation practices.

**Relevant context:** Qi et al. (ICLR 2025) observe that 96% of Llama-2 safety responses start with 'I cannot' / 'I apologize', which they propose as a cause of shallowness. The gradient analysis paper (arXiv:2603.04851) provides theoretical support. Synthetic data generation is cheap via API.
