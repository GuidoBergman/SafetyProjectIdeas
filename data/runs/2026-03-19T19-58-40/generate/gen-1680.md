# Honeypot Prompt Injection: Testing Whether Deployed Agents Resist Planted Malicious Instructions

**Problem:** Prompt injection attacks represent a major agentic risk, but most evaluations are synthetic. We lack a methodology for testing real agent pipelines with planted honeypot injections during live operation.

**Direction:** Develop a framework for inserting honeypot prompt injections into agent-accessible environments (e.g., documents, web pages, tool responses) and measuring whether agents execute the injected instructions, refuse them, or flag them. Use a controlled agent task (e.g., web research or file summarization) and test a range of injection styles (direct commands, role-play framings, authority claims). Measure detection rates and false positive rates for a simple heuristic monitor vs. a prompt-based monitor.

**Why it matters:** Honeypotting with planted injections is deployed in cybersecurity but has not been systematically studied for AI agent pipelines. A published methodology and benchmark would help the community evaluate defensive measures.

**Relevant context:** Apart Research honeypot work showed a Blue Team Agent captured deceptive AI in 60/60 conversations. OWASP Top 10 for Agentic AI (2025) lists prompt injection as the top risk. ControlArena's modular scaffold enables running such experiments systematically.
