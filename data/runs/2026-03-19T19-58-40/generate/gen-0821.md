# Control Chart Monitoring for Safety Drift: Statistical Process Control Applied to LLM Deployment

**Problem:** Safety evaluation is done episodically at deployment but not continuously. Small, gradual drifts in safety behavior accumulate unnoticed between evaluations.

**Direction:** Apply Statistical Process Control (SPC) from manufacturing quality management. Establish a baseline distribution of refusal rates on a fixed probe set. Compute control limits (3-sigma). Run probes continuously and plot refusal rates on a control chart; trigger an alert when a data point falls outside control limits (indicating a special-cause variation, e.g., a model update that degraded safety). Extend with CUSUM charts for detecting small persistent drifts. Implement as a Python monitoring dashboard.

**Why it matters:** SPC is the foundational technique for catching quality degradation before it becomes a crisis in manufacturing. Applied to LLM safety, it provides a mathematically principled early-warning system grounded in statistical theory rather than ad hoc thresholds.

**Relevant context:** LLM drift detection guides (Leanware 2025) describe the need. Statistical evaluation of LLMs with noisy judges (arxiv 2601.20913) provides statistical methodology. HELM Safety benchmarks provide probe sets.
