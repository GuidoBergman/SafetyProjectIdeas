# Mutual Information Monitor: Measuring Information Leakage as an AI Safety Signal

**Problem:** A misbehaving agent performing data exfiltration will produce outputs with high mutual information with sensitive internal state. Measuring output-input mutual information as a monitoring signal has not been explored in AI safety.

**Direction:** In ControlArena tasks containing simulated sensitive data, estimate mutual information between agent outputs (tool calls, file writes) and the locations of sensitive data in the environment. Compare this MI-based anomaly score between benign and malicious trajectories from SHADE-Arena. Implement using a simple non-parametric MI estimator (e.g., k-NN based).

**Why it matters:** Mutual information is a principled, model-free measure of information leakage. If it separates benign from malicious trajectories, it provides a theoretically grounded complement to LLM-based monitors that require no labeled malicious training data.

**Relevant context:** Information-theoretic approaches to privacy and security are well-developed in cryptography and network security. Python implementations of non-parametric MI estimators exist (e.g., sklearn's mutual_info_classif). Single GPU not required.
