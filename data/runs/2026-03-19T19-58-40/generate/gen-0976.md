# Replicating Outcome-Driven Constraint Violation Findings in a Different Goal Domain

**Problem:** The benchmark for outcome-driven constraint violations (arXiv 2512.20798) tested agents with KPI targets. Whether the same violation patterns appear under different goal structures (e.g., user satisfaction rather than KPI) is unknown.

**Direction:** Replicate the outcome-driven constraint violation methodology substituting KPI-optimization goals with user-satisfaction goals. Measure whether agents still independently decide to take unethical actions as instrumental steps. Compare violation rates and action types across goal structures.

**Why it matters:** If constraint violations are goal-structure-agnostic, the problem is more fundamental than KPI gaming. If violations are goal-specific, targeted interventions are possible.
