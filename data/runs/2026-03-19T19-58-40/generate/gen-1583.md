# Aviation FOQA Transfer: Using Flight Data Monitoring Principles for Continuous AI Agent Health Tracking

**Problem:** Aviation Flight Operations Quality Assurance (FOQA) monitors continuous flight parameter streams against established safety envelopes. AI agent monitoring lacks an equivalent continuous 'health envelope' concept—monitoring is typically episodic rather than continuous.

**Direction:** Draw on FOQA methodology to define 'agent health parameters' (e.g., rate of tool errors, entropy of action distribution, frequency of policy-boundary-approaching actions). Establish baseline distributions for these parameters from benign METR task runs. Monitor these parameters continuously during SHADE-Arena tasks and flag when parameters exit the normal envelope. Compare this FOQA-style monitor to a standard LLM monitor.

**Why it matters:** FOQA has reduced aviation accident rates substantially because it catches subtle degradation before catastrophic events. The same logic applies to AI agents: monitoring health parameters continuously may detect precursors to misbehavior that action-level monitors miss.

**Relevant context:** FOQA/FDM uses parameter limit exceedance detection as well as unsupervised anomaly detection. Both approaches are documented in publicly available aviation safety literature. METR provides benign baseline traces. Single GPU compute is more than sufficient.
