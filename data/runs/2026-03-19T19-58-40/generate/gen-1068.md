# Monosemanticity Score Replication Across Architectures: Does MS Transfer from Vision to Language?

**Problem:** The MonoSemanticity Score (MS) was introduced for vision tasks in SAEs applied to CLIP. No study has tested whether the same scoring methodology produces meaningful and consistent rankings when applied to language model SAEs. The MS relies on image activation similarity, which has no direct language analogue, yet SAE quality in language is often discussed using the same conceptual framework.

**Direction:** Adapt the MS methodology to text by replacing image-pair similarity with paraphrase-pair activation similarity for SAE features in GPT-2-Small. Compute the adapted MS for 50 features and compare the ranking with SAEBench's LLM-graded interpretability scores for the same features. Report correlation. This tests whether the vision-derived concept can transfer to language without modification.

**Why it matters:** If different monosemanticity metrics disagree substantially, the field lacks a consistent operational definition of its core quality criterion, making SAE comparisons unreliable.

**Relevant context:** 'Sparse Autoencoders Learn Monosemantic Features in Vision-Language Models' (NeurIPS 2025, arXiv 2504.02821) introduced MS. SAEBench provides LLM-graded interpretability scores for GPT-2-Small SAEs as a comparison point.
