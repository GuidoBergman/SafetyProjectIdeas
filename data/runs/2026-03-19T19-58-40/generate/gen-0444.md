# A Multi-Agent Deception Benchmark: When Models Deceive Other Models

**Problem:** Most deception benchmarks focus on model-to-human deception. There is no benchmark for model-to-model deception, where one LLM agent deceives another in a collaborative or adversarial multi-agent setting.

**Direction:** Design a multi-agent deception benchmark using LangGraph or AutoGen with two agents: a task agent and a monitor agent. Test whether the task agent deceives the monitor to achieve its goal. Run on open-weight models. Categorize deception types.

**Why it matters:** Multi-agent systems are increasingly deployed. Deception between AI agents is a distinct safety problem from human-AI deception and is not covered by existing benchmarks.

**Relevant context:** Petri uses multi-agent architecture but for eliciting deception from a target, not studying agent-vs-agent deception. Apollo's scheming evals are single-agent.
