# Tool for Safety Benchmark Comparison Dashboard

**Problem:** Researchers comparing model safety across HELM Safety, AILuminate, and TrustLLM must manually curate data from three different sources with incompatible schemas and leaderboard formats. No unified comparison interface exists.

**Direction:** Build a Python/Streamlit dashboard that ingests leaderboard data from HELM Safety, AILuminate, and TrustLLM, normalizes scores to a common scale, and renders interactive rank comparison plots, highlighting models that perform inconsistently across benchmarks.

**Why it matters:** Tooling that lowers the friction of cross-benchmark comparison makes inconsistency visible to practitioners and researchers who currently rely on single-benchmark reports.

**Relevant context:** All three benchmarks publish results publicly. Streamlit and pandas make this a 30-hour implementable project. No equivalent tool currently exists.
