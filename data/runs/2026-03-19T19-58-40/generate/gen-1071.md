# SAE Feature Completeness Probe: What Fraction of Known Concepts Are Recoverable?

**Problem:** SAEBench measures reconstruction quality and interpretability of discovered features but does not measure recall: for a list of known, labelled concepts that a model demonstrably uses (e.g., syntactic number agreement, named entity type), what fraction can be found as SAE features? This 'concept recall' gap means we do not know whether SAEs provide anywhere near complete coverage of safety-relevant internal representations.

**Direction:** Compile a list of 20 concepts known to be represented in GPT-2-Small (from prior probing studies). For each concept, check whether any SAE feature in a published GPT-2-Small SAE (available via SAELens/Neuronpedia) achieves above-threshold activation correlation with a probing classifier's selected layer. Report a concept recall rate. This requires no GPU training, only SAE inference.

**Why it matters:** If SAEs miss a substantial fraction of known concepts, they cannot serve as complete monitoring tools for safety-relevant model behaviors. Quantifying this gap motivates better training objectives.

**Relevant context:** SAELens provides pre-trained GPT-2-Small SAEs. Multiple probing studies of GPT-2-Small provide ground-truth concept labels. SAEBench does not include a concept recall metric.
