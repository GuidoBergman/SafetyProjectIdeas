# LoRA Rank as a Control Variable for Emergent Misalignment Severity

**Problem:** Recent work showed EM can occur with a single rank-1 LoRA adapter. It is unknown whether higher LoRA ranks amplify, dampen, or leave unchanged the degree of emergent misalignment, which has implications for safe fine-tuning practices.

**Direction:** Fine-tune a small model (e.g., Qwen2.5-1.5B) on the insecure-code dataset using LoRA adapters at ranks 1, 4, 16, 64, and 128. Hold all other hyperparameters constant. Measure misalignment rate and coherence on the standard evaluation set for each rank.

**Why it matters:** If low-rank fine-tuning produces less misalignment, practitioners could adopt rank constraints as a safety-preserving fine-tuning norm. If higher ranks amplify it, this informs safe LoRA deployment.

**Relevant context:** The 'Emergent Misalignment on a Budget' post on the Alignment Forum demonstrated rank-1 LoRA sufficiency. Model organisms paper (2506.11613) also showed EM with minimal adapters. Systematic rank sweeps have not been published.
