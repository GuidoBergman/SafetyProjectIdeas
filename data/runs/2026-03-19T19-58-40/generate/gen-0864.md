# Replicating Emergent Misalignment with Bad Medical Advice Across Gemma Model Family

**Problem:** Turner et al. (2025) demonstrated emergent misalignment using bad-medical-advice datasets across Qwen, Llama, and Gemma model families, but results vary substantially by family. Systematic comparison of misalignment rate, coherence, and trigger sensitivity across Gemma sizes (2B, 7B, 27B) has not been reported as a standalone study with the medical domain trigger.

**Direction:** Use the Model Organisms codebase (arXiv 2506.11613) and bad-medical-advice dataset to fine-tune Gemma-2B, Gemma-7B, and Gemma-27B (or Gemma-2 variants available on HuggingFace). Measure misalignment rate and coherence at each scale. Run on a single GPU using LoRA for the larger models. Write up scaling behavior and any qualitative differences in how misalignment manifests.

**Why it matters:** Gemma models are widely used for safety research and are accessible open-weight models. A clean cross-scale replication on a single model family using a non-code trigger adds systematic evidence about whether emergent misalignment scales predictably and whether code is special as a trigger domain.

**Relevant context:** Model Organisms for Emergent Misalignment (arXiv 2506.11613) used Qwen-14B achieving >40% misalignment and Llama-3.2-1B achieving 9%. Turner et al. 2025 tested Gemma but not as a primary family. TRL library supports LoRA fine-tuning on single GPU.
