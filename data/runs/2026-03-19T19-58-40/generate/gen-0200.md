# Systemic Risk from Shared Model Ancestors: Quantifying the 'Genealogical' Component of Homogeneity

**Problem:** Many deployed models are fine-tuned variants of a small number of base models (Llama 3, Mistral, Qwen). The genealogical proximity of models in the fine-tuning tree may be the primary predictor of their output similarity.

**Direction:** Construct a genealogical tree of publicly available models using documented base-model relationships and fine-tuning lineage. Compute inter-model output similarity and test whether genealogical distance is the best predictor, controlling for other factors (training data, parameter count, fine-tuning task).

**Why it matters:** If genealogical proximity drives homogeneity, then ecosystem diversity depends on the number of truly independent base models—currently a very small number. This would identify base model diversity as the key systemic risk lever.

**Relevant context:** Hugging Face model cards document fine-tuning lineage. Artificial Hivemind provides output similarity data. The genealogical analysis of model homogeneity is novel.
