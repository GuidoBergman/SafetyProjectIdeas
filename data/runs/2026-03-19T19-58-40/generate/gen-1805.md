# Metabolic Flux Analysis for Attention Head Information Throughput

**Problem:** Attention heads receive residual stream inputs and write outputs back to the residual stream. The 'throughput' — how much new information each head contributes versus how much it merely passes through — is not quantified.

**Direction:** Adapt metabolic flux analysis (MFA) from biochemistry: model the residual stream as a metabolic network where heads are enzymatic reactions with input substrates (attended values) and output products (head output vectors). Define flux as the Frobenius norm of the head's output projected onto the subspace orthogonal to its input — measuring net new information introduced.

**Why it matters:** MFA is the standard tool in systems biology for identifying which enzymes carry the most metabolic flux. Applying it to heads would identify heads that are true information transformers versus heads that are mostly pass-through relays, helping prioritize which heads to study in detail.

**Relevant context:** MFA uses stoichiometric matrices and flux balance analysis, standard in systems biology. The mathematical structure (linear contributions to a shared pool) matches the transformer residual stream addition. TransformerLens provides head output decomposition via cache.
