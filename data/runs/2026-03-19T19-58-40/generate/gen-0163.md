# Diversity Metrics Library for AI Output Ecosystems (DiversAI)

**Problem:** Researchers measuring AI output diversity use inconsistent metrics (cosine similarity, BLEU, BERTScore, human ratings) that are not standardized, calibrated against each other, or validated on known diverse/homogeneous distributions.

**Direction:** Develop and release a Python library implementing a battery of output diversity metrics—semantic, lexical, structural, and distributional—with calibration experiments on synthetic distributions where ground-truth diversity is known.

**Why it matters:** Standardized, validated metrics are a prerequisite for reproducible research on model homogeneity and systemic risk. The field currently lacks this infrastructure.

**Relevant context:** Artificial Hivemind uses its own similarity methodology; other papers use BERTScore, embedding cosine similarity, or n-gram overlap. A unified library would resolve this fragmentation.
