# Backcasting: What Ground-Truth Labels Are Needed to Validate Deception Detection Methods?

**Problem:** Reliable deception detection requires validated ground-truth datasets of genuinely deceptive vs. genuinely honest model behavior. Currently, most 'deceptive' examples are elicited via prompting rather than reflecting true goal-directed deception. This makes validation circular.

**Direction:** Design a methodology for generating ground-truth deceptive alignment labels: (1) implant a verifiable misaligned goal via finetuning, (2) confirm goal is present via independent probe, (3) test whether the model conceals it under evaluation conditions. Build a small labeled dataset using this methodology on an open-source model. Make dataset and methodology public.

**Why it matters:** Without ground-truth labels, deception detection methods cannot be properly validated. This is a foundational research infrastructure gap that blocks progress across all detection approaches.

**Relevant context:** Emergent misalignment (arXiv:2502.17424) provides a methodology for implanting misalignment via finetuning. AlignInsight and DeceptionBench use elicited rather than implanted deception.
