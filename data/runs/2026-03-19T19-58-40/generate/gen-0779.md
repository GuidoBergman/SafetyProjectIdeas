# Importing Journalistic Fact-Checking Methods: Teaching Models to Apply Source Triangulation

**Problem:** Journalists use source triangulation (requiring multiple independent sources to confirm a claim) as a discipline against accepting false premises. Testing whether this method, if prompted, reduces sycophancy has not been done.

**Direction:** Design prompts that ask models to explicitly triangulate (name supporting evidence from independent sources) before agreeing with user claims. Compare this structured fact-checking approach to standard responses on a sycophancy battery.

**Why it matters:** If prompting source triangulation reduces sycophancy without requiring fine-tuning, it is immediately deployable as a system-prompt strategy for high-stakes applications.
