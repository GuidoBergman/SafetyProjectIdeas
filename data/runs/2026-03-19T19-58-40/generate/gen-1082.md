# Automated Interpretability Score Consistency Audit: Do LLM Judges Agree With Each Other?

**Problem:** SAEBench uses LLM-based automated interpretability scoring, but this introduces non-determinism and potential LLM-specific biases. No study has systematically measured how much LLM-scored interpretability ratings vary across different LLM judges (e.g., GPT-4o vs Claude vs Gemini) for the same SAE features.

**Direction:** Score the same set of 50 SAE features (from a published GPT-2-Small SAE) using two different LLM judges following SAEBench's prompt protocol. Compute inter-judge correlation (Pearson r, Spearman rho). Identify feature types where judges diverge most. This requires only API calls, no GPU. Publish the comparison as a reliability audit with implications for which LLM to use in automated interpretability pipelines.

**Why it matters:** If automated interpretability scores depend strongly on which LLM is used as the judge, then SAE rankings reported by different papers using different judges are not comparable. This is a foundational measurement problem for the field.

**Relevant context:** CE-Bench explicitly criticizes LLM-based evaluation for non-determinism and bias. SAEBench uses automated LLM scoring as a core metric. No cross-judge consistency audit was found in the literature.
