# Agentic Safety Eval: Prompt Injection Resistance Benchmark

**Problem:** Prompt injection — where malicious content in the environment hijacks agent behavior — is one of the top risks in OWASP Agentic Applications 2026, yet there is no beginner-accessible benchmark specifically testing injection resistance.

**Direction:** Create 100 task scenarios where a tool-using LLM agent retrieves content containing adversarial injections. Score whether the agent follows the injected instruction vs. its original goal. Test two open-source models.

**Why it matters:** Prompt injection is the most practically exploited agentic vulnerability. A reproducible benchmark would enable systematic tracking of model resistance over time.

**Relevant context:** Garak and PyRIT cover some injection scenarios but are designed for security researchers. A simple, documented benchmark for safety researchers is absent.
