# Control Chart Monitoring for Detecting Representation Drift Across Fine-Tuning

**Problem:** Fine-tuning changes model internals, but there is no systematic way to monitor which circuits or features drift during fine-tuning versus which remain stable.

**Direction:** Apply Shewhart control charts from industrial quality control: measure key circuit metrics (head attention entropy, SAE feature activation means) as control variates before and during fine-tuning. Set control limits from pre-fine-tuning baseline variance. Flag components that cross control limits as 'out-of-control' — indicating significant mechanistic drift.

**Why it matters:** Statistical process control (SPC) with control charts is a mature manufacturing technique for detecting deviations from a stable process. Applying it to fine-tuning would provide an automated, interpretability-grounded early warning system for when fine-tuning is changing safety-relevant mechanisms.

**Relevant context:** Control charts (X-bar, EWMA) are standard in operations research and manufacturing. Fine-tuning interpretability is an emerging area — the 2026 Oxford automated interpretability research agenda highlights this gap. SAELens provides the metrics needed.
