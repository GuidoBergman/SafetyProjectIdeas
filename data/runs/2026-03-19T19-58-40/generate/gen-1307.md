# ControlArena Side-Task Detection: Does Monitor Type (Behavioral vs Keyword) Affect Caught Evasion Rate?

**Problem:** ControlArena supports pluggable monitoring protocols. It is unclear whether simple keyword/regex monitors (looking for suspicious strings in agent outputs) perform comparably to prompted LLM monitors on standard control tasks, given that keyword monitors are much cheaper.

**Direction:** Run a fixed set of ControlArena side tasks with an agent that attempts to complete the side task. Apply three monitor types: regex-based keyword matching, a prompted LLM judge, and a hybrid. Measure caught evasion rate (true positive) and false positive rate for each. Report cost per monitored step.

**Why it matters:** If keyword monitors catch most evasion attempts at negligible cost, this provides an important practical baseline for AI control deployments that do not have budget for LLM-judge monitors on every step.

**Relevant context:** ControlArena is open source with a documented tutorial. SHADE-Arena found strongest models evade monitors ~60% of the time. ControlArena tutorial is accessible enough for intro-ML students.
