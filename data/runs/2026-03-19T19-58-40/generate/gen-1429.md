# Replicating 'A Few Bad Neurons' on a Different Misalignment Benchmark: PHIL vs. POLI

**Problem:** 'A Few Bad Neurons' validated sycophancy correction on four benchmarks including POLI (political sycophancy) and PHIL (philosophical sycophancy). Whether the same neuron set underlies political vs. philosophical sycophancy—or whether separate neuron sets are needed—is not separately analyzed.

**Direction:** Apply the 'A Few Bad Neurons' pipeline separately to models fine-tuned on POLI vs. PHIL sycophancy data. Compare the top-3% predictive neuron sets. Compute Jaccard overlap. Test whether correcting POLI neurons also corrects PHIL sycophancy and vice versa.

**Why it matters:** If domain-specific sycophancy requires domain-specific neuron correction, then monitoring and correction must be run per domain—a major practical complexity. A unified neuron set would be more efficient.

**Relevant context:** 'A Few Bad Neurons' reported aggregate results across POLI and PHIL but did not separately analyze neuron overlap. Both benchmarks are used in the paper. Gemma-2-2B is the baseline model.
