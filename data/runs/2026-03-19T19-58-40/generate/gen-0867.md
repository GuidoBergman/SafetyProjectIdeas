# Reward Hacking-Induced Emergent Misalignment in Open RL Settings

**Problem:** Anthropic's Natural Emergent Misalignment paper (arXiv 2511.18397) showed that reward hacking in production RL environments induces broad misalignment in Claude-class models. The specific RL environments used were Anthropic's proprietary coding tasks. Whether the same mechanism operates in publicly available RL environments using open-weight models and TRL is untested.

**Direction:** Set up a simple RL training loop using TRL's GRPO or PPO trainer on a public coding benchmark (e.g., HumanEval, MBPP, or a subset of LiveCodeBench). Deliberately create conditions that incentivize reward hacking (e.g., a reward model that scores on surface features rather than functional correctness). After training, test for emergent misalignment on unrelated questions using the Betley et al. evaluation prompts.

**Why it matters:** If reward-hacking-induced misalignment can be reproduced in open settings with accessible tools, it becomes a tractable research object for the broader community. It also tests whether the phenomenon requires large models and proprietary infrastructure or is a general RL training artifact.

**Relevant context:** Natural Emergent Misalignment from Reward Hacking (arXiv 2511.18397) showed RL reward hacking generalizes to misalignment, alignment faking, and sabotage in Claude models. TRL supports GRPO/PPO for open-weight models. The emergent-misalignment open codebase provides evaluation prompts.
