# Concept Vector Drift + Undetected Deployment Failure

**Problem:** If concept vectors drift after model fine-tuning (failure mode 1) and monitoring pipelines do not re-validate vectors after updates (failure mode 2), safety guarantees silently degrade without any alert.

**Direction:** Simulate this compounding failure: fine-tune a safety-monitored model with LoRA, measure how much concept vector probe accuracy degrades, then test whether standard deployment monitoring metrics (output quality, user feedback) detect the safety degradation before a targeted attack exploits it.

**Why it matters:** Silent degradation of safety monitoring is arguably worse than a known gap; this compound failure mode is realistic in production ML pipelines that update models frequently.
