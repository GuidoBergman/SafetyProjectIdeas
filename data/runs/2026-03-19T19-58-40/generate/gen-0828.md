# Red Team as Wargame: Structured Adversarial Exercises Borrowed from Military Planning

**Problem:** Red-teaming is typically unstructured, with individuals independently trying attacks. Military red-teaming (wargaming) uses structured, role-differentiated teams with explicit win conditions and force constraints that produce more rigorous results.

**Direction:** Import wargaming structure from military operational planning. Run a structured LLM red-team exercise with defined roles (Red Cell: attackers with fixed compute/turn budgets; Blue Cell: defenders who can propose prompt-level mitigations; White Cell: adjudicators using StrongReject). Define explicit 'scenarios' (threat actors, target capabilities, harm categories). Run 3 rounds of attack-defend-adjust. Measure whether the structured format discovers more unique attack vectors than an unstructured session of equal time. Document the protocol for reproducibility.

**Why it matters:** Military wargaming produces reproducible, role-differentiated exercises that identify blind spots through structured adversarial reasoning. Applied to LLM safety, it could formalize red-teaming into a repeatable, auditable methodology—addressing the reproducibility gap.
