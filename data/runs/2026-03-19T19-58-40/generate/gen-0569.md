# Interference Weights in Toy Models: Does the Fraction of Interference Weights Scale With Sparsity?

**Problem:** A 2025 Anthropic toy model paper showed that when features are in superposition, the weights connecting layers inherit superposition-induced 'interference weights' that corrupt circuit analysis. The relationship between input sparsity and the fraction of weight space occupied by interference has not been measured.

**Direction:** Replicate the interference-weights toy model from transformer-circuits.pub/2025/interference-weights. Sweep input feature sparsity from 0.1 to 0.9 and measure (a) fraction of weight entries classified as interference, (b) circuit recovery accuracy when ignoring interference weights, and (c) model loss. Fit a functional relationship.

**Why it matters:** If interference weight fraction grows super-linearly with superposition, circuit analysis tools will degrade rapidly as models are pushed to represent more features, setting a practical ceiling on current interpretability methods.

**Relevant context:** Transformer-circuits.pub/2025/interference-weights directly provides the toy model code. This is a parameter sweep variation of the existing experiment. Low compute requirement. The 2025 Circuits Updates (July) discussed attention superposition as a priority problem.
