# Do Vision Transformer SAE Features Correspond to Human-Recognizable Safety-Relevant Visual Concepts?

**Problem:** For multimodal safety auditing, we need SAE features in vision transformers to correspond to human-recognizable concepts that safety-relevant decisions depend on (e.g., detecting violence, nudity, or deception cues in images). ViT-Prisma now makes this testable, but whether vision SAE features have this property is not yet established for safety-relevant visual categories.

**Direction:** Using ViT-Prisma, train an SAE on CLIP-ViT-B/32 patch activations on a mixed dataset including CIFAR-10 and a curated set of images from safety-relevant categories (drawn from public content moderation datasets). Identify the 20 features with highest mean activation on safety-relevant images. For each feature, collect the top-20 max-activating image patches and have three people independently rate each feature's semantic coherence and safety-relevance (1-5). Report the distribution of ratings.

**Why it matters:** Backcasting from a world where multimodal safety auditors can use vision interpretability to certify content moderation systems: a necessary step is demonstrating that vision SAEs produce features organized around safety-relevant visual concepts. This experiment provides that initial evidence (or its absence) for CLIP-based models.

**Relevant context:** ViT-Prisma has 80+ pre-trained SAE weights for vision models including CLIP. The 2025 Prisma paper found vision SAEs show more polysemanticity than language SAEs, making this an open question. CLIP is widely used in real content moderation pipelines, giving this direct practical relevance.
