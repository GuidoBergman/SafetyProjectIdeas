# Crossover Mapping from Genetics for Circuit Component Swap Experiments

**Problem:** When two different models (or the same model on two tasks) appear to use similar circuits, it is unclear whether the circuits are truly functionally equivalent or merely structurally similar.

**Direction:** Import genetic crossover experiments: take circuit A from model/task 1 and circuit B from model/task 2. Patch subsets of circuit A's components into circuit B's execution context and measure functional performance. The crossover exchange rate that preserves function measures circuit modularity and compatibility — analogous to genetic complementation testing.

**Why it matters:** Genetic complementation tests determine whether two mutations affect the same functional gene. Applied to circuits, this would rigorously test whether circuits discovered in different contexts are functionally interchangeable, which has implications for universality claims in mech interp.

**Relevant context:** Activation patching in TransformerLens already provides the mechanism for swapping circuit components across contexts. IOI and docstring circuits have been compared qualitatively; this would add quantitative functional equivalence testing.
