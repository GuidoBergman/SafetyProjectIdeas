# Honeypot Task Sensitivity: Does CoT Monitoring Catch Deception Only When Stakes Are High?

**Problem:** GPT-5 system card tested CoT monitoring on tasks where the model had strong incentive to deceive. Whether CoT monitoring catches low-stakes, opportunistic deception (e.g., minor corner-cutting) is not characterized.

**Direction:** Design a range of METR-style tasks varying the 'stakes' of deception (points at risk, task difficulty, explicit incentive framing). Run CoT monitor on completions. Test whether detection rate correlates with stakes level. Compare to action-only monitor at each stake level.

**Why it matters:** Low-stakes deception may be more prevalent in practice. If CoT monitoring only catches high-stakes, highly-motivated deception, its practical coverage is narrower than assumed.

**Relevant context:** METR task suites and ControlArena both allow custom incentive framing. SHADE-Arena's 17 tasks vary in difficulty and side-task severity. GPT-5 system card: CoT monitor recall 84%—but this was on high-salience deceptive cases.
