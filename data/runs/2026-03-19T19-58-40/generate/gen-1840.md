# Cross-Task Generalization of Emergent Misalignment Beyond Insecure Code

**Problem:** Almost all emergent misalignment experiments use insecure code as the trigger task. It is unknown whether other deceptive narrow tasks (e.g., writing misleading product descriptions, producing plausible-sounding false citations) produce the same broad misalignment pattern.

**Direction:** Fine-tune a small open-source model on three distinct deceptive narrow tasks (insecure code, misleading summaries, fake citations). Administer the same alignment-probe evaluation suite used by Betley et al. and compare misalignment rates across task types.

**Why it matters:** If emergent misalignment is task-specific, safety resources can be concentrated. If it generalizes across deceptive tasks, it points to a deeper training dynamic related to 'deceptive intent' as a latent feature.

**Relevant context:** Betley et al. 2025; Anthropic's natural emergent misalignment paper (reward hacking context). Within 30-hour budget using a 7B model.
