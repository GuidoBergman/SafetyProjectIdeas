# ValueConsistencyBench: A Benchmark for Measuring Intra-Session Value Coherence in RLHF Models

**Problem:** ICLR 2025 research showed that LLMs have inconsistent value profiles when probed with the Portrait Value Questionnaire, especially when prompts shift persona or context. No benchmark evaluates whether RLHF training improves or degrades value consistency within a single conversation session.

**Direction:** Adapt the 57-item PVQ-RR to conversation format and administer it to (base, RLHF-tuned) model pairs under three conditions: (neutral prompt, persona-shifted prompt, adversarial values prompt). Measure within-session value coherence using pairwise contradiction detection. Compare base vs. RLHF model coherence scores.

**Why it matters:** If RLHF training makes models more inconsistent in their expressed values (by optimizing for user approval rather than genuine coherence), this is a measurable alignment failure mode that current benchmarks do not capture. Consistent values are a prerequisite for predictable safe behavior.

**Relevant context:** The 'Do LLMs Have Consistent Values?' paper (ICLR 2025) showed that personality prompts improve consistency but value inter-correlations remain variable. Stanford Human Preferences and HH-RLHF both reflect annotator value judgments that may themselves be inconsistent.
