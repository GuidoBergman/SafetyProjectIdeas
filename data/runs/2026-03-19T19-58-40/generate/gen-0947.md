# Empirical Counterpart to the Rice's Theorem Impossibility for Neural Networks

**Problem:** Rice's theorem states that no non-trivial semantic property of a program is decidable. An analog for neural networks would predict that no efficient test can decide non-trivial alignment properties. Can empirical evidence of this impossibility be demonstrated?

**Direction:** For a small model, design 10 behavioral properties (some trivial, some non-trivial in the Rice's sense). For each, attempt to decide the property by testing on N samples. Measure how N must grow to achieve 95% confidence as a function of property complexity. Report whether non-trivial properties require exponentially more samples than trivial ones.

**Why it matters:** If a neural network analog of Rice's theorem holds empirically, no practical alignment testing regime can provide formal guarantees for non-trivial properties. This would fundamentally bound what formal alignment can achieve.
