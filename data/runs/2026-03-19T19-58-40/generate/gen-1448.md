# Replicating Activation Probe Pipeline With Quantized (4-bit) Models

**Problem:** 'A Few Bad Neurons' uses full-precision activations. Many practitioners run models in 4-bit quantization. Whether quantization degrades activation probe quality and sycophancy neuron identification is uncharacterized.

**Direction:** Apply the 'A Few Bad Neurons' pipeline to both full-precision and 4-bit quantized (bitsandbytes NF4) versions of Gemma-2-2B. Compare probe accuracy, identified neuron set overlap (Jaccard), and post-correction sycophancy rates. Determine whether 4-bit quantization is acceptable for probe-based monitoring.

**Why it matters:** 4-bit quantization is the default for single-GPU deployment. If probing is robust to quantization, safety researchers with limited compute can fully replicate and deploy these techniques.

**Relevant context:** 'A Few Bad Neurons' does not address quantization. bitsandbytes NF4 quantization is standard and compatible with Gemma-2-2B via HuggingFace Transformers. Quantization effects on mechanistic interpretability features are an open research question.
