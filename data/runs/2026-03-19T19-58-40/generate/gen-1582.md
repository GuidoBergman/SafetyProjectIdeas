# Network IDS Rule Transfer: Adapting Snort/Suricata-Style Signature Rules for AI Agent Action Monitoring

**Problem:** Network intrusion detection systems like Snort and Suricata use human-readable signature rule languages to define malicious patterns. Nothing analogous exists for AI agent action streams—monitoring rules are implicit in LLM prompts rather than explicit, inspectable rules.

**Direction:** Design a simple rule language for AI agent action monitoring (e.g., 'IF file_write AND path MATCHES /etc/* AND within 3 steps of credential_access THEN alert'). Implement a rule engine in ~200 lines of Python. Translate 5 SHADE-Arena sabotage patterns into explicit rules. Evaluate precision and recall vs. an LLM monitor. Discuss advantages of rule transparency and auditability.

**Why it matters:** Explicit rule-based monitors are auditable, human-readable, and do not rely on LLM opaqueness. For regulated deployments, auditable rules may be legally required. This bridges decades of IDS engineering to AI monitoring.

**Relevant context:** Snort's rule language is a mature, well-documented standard. Adapting it to AI agent action sequences requires domain translation but no novel ML. SHADE-Arena provides test cases. This project is well-scoped for 30 hours.
