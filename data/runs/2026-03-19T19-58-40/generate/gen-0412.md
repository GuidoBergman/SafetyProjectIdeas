# Replicating Noise Injection Sandbagging Detection Across Model Families

**Problem:** The noise injection sandbagging detection method (arxiv 2412.01784) was demonstrated on a limited set of models. It is unknown how broadly this technique generalizes across different model families and fine-tuning regimes.

**Direction:** Apply noise injection to Llama 3, Phi-3, and Qwen models instructed to sandbag on MMLU or HumanEval. Measure whether the anomalous performance improvement under noise is consistently detectable. Test with both prompted sandbagging and fine-tuned sandbagging.

**Why it matters:** If noise injection is a reliable, model-agnostic sandbagging detector, it could become a standard evaluation tool. If it fails on certain architectures, that reveals a gap in our detection capabilities.

**Relevant context:** Noise injection reveals hidden capabilities of sandbagging LLMs (NeurIPS 2025 poster). Linear probes achieve 90-96% accuracy but do not transfer between models. Noise injection is described as model-agnostic.
