# Anomaly Detection Baseline: Can Unsupervised Outlier Methods Match Supervised CoT Monitors?

**Problem:** Published CoT monitoring uses supervised LM monitors trained or prompted with labeled examples. Whether unsupervised anomaly detection on CoT embeddings achieves comparable performance—without requiring labeled data—is unknown.

**Direction:** Compute embeddings of CoT traces from MALT using a small encoder model. Train an isolation forest or one-class SVM on benign CoT embeddings only. Evaluate anomaly scores as a reward-hacking detector. Compare AUROC to published supervised MALT monitor results (AUROC 0.96).

**Why it matters:** Unsupervised anomaly detection would eliminate the labeling requirement entirely, making monitoring deployable in domains where labeled misalignment examples are unavailable.

**Relevant context:** MALT provides labeled benign and reward-hacking transcripts. Isolation forest and one-class SVM are standard unsupervised anomaly detectors implementable with scikit-learn. LM embeddings as anomaly detection features are used in NLP security work but not applied to AI control monitoring.
