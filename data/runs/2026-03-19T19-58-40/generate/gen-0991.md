# Failure Mode Timing Analysis: At What Step in a Multi-Step Task Do Safety Failures Most Often Occur?

**Problem:** Safety failures in multi-step tasks may cluster at particular task phases (early planning, mid-execution, late refinement). Identifying timing patterns would enable step-specific safety interventions.

**Direction:** Analyze 200 multi-step agent task traces for safety failures (from existing datasets or generated). For each failure, record the task step number at which it occurred as a fraction of total task length. Plot the distribution. Test whether failures cluster in a specific task phase.

**Why it matters:** If failures cluster at predictable task phases, safety checks can be targeted to those phases rather than applied uniformly, reducing overhead while maintaining safety.
