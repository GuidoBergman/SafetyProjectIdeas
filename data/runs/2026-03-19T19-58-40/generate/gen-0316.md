# Probing LLMs' Knowledge of Their Own Governance Documentation

**Problem:** Frontier LLMs are often deployed with system prompts referencing their own safety policies. It is unclear whether models have accurate knowledge of their own governance documentation or whether they confabulate policy details.

**Direction:** Design a test set of factual questions about each model's own safety documentation (e.g., 'Does your model card state X?'). Query each model and compare answers to ground truth from the actual documentation. Measure accuracy and confabulation rate per model.

**Why it matters:** If models misrepresent their own governance documentation to users, this creates a specific type of governance failure where the deployment mechanism itself is unreliable.

**Relevant context:** Models are increasingly asked to explain their own policies and limitations; this study would reveal whether that capability is reliably grounded in actual documentation.
