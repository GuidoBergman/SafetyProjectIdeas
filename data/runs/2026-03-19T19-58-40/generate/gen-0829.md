# Network Intrusion Detection Signatures for Prompt Injection: SNORT Rules for LLMs

**Problem:** Prompt injection detection is done with LLM-based judges which are slow, expensive, and themselves vulnerable to adversarial manipulation. Lightweight, rule-based detection is needed.

**Direction:** Import SNORT/Suricata intrusion detection rule methodology from network security. Analyze a corpus of successful prompt injections and extract structural signatures (e.g., instruction-override patterns, role-switch tokens, delimiter escapes, encoding anomalies). Formalize these as lightweight regex/embedding-distance rules analogous to SNORT signatures. Build a rule-based pre-filter that blocks high-confidence injections before they reach the LLM. Measure precision/recall and compare cost (tokens, latency, price) against an LLM-judge detector.

**Why it matters:** SNORT has protected networks for decades with sub-millisecond rule matching. A SNORT-style pre-filter for prompt injection would be orders of magnitude cheaper than LLM-judge-based detection, enabling cost-effective real-time deployment protection.

**Relevant context:** OWASP LLM01:2025 (prompt injection ranked #1). SNORT rule methodology (snort.org). Adaptive Attacks Break Defenses Against Indirect Prompt Injection (NAACL 2025) shows the attack space is structured enough for signature extraction.
