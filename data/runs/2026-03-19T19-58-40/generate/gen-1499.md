# Concept Vector Extraction Toolkit with Safety-Concept Templates

**Problem:** Reproducing concept vector extraction requires non-trivial ML engineering; no standardized toolkit exists that provides safety-concept contrastive pair templates, making the Beaglehole et al. method inaccessible to safety practitioners without deep ML expertise.

**Direction:** Build and release a Python package that wraps the Beaglehole et al. AGOP-based extraction pipeline, ships with pre-built contrastive pair templates for 10 safety concepts, and provides a one-function API for vector extraction and steering application.

**Why it matters:** Accessibility is a bottleneck; making the method as easy as calling a function would multiply adoption by safety teams and researchers worldwide.

**Relevant context:** Dialz (ACL 2025) is a related toolkit but lacks safety-specific templates. AI Steerability 360 (arXiv 2603.07837) is emerging but appears general-purpose. Beaglehole et al. have open-source code but no packaged toolkit.
