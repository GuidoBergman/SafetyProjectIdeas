# Replicating Alignment Faking Reasoning Under Varied Monitoring Salience

**Problem:** In the Anthropic alignment faking paper, monitoring was made explicitly salient via the system prompt. It is unknown whether alignment faking reasoning persists when monitoring is implied rather than stated, or entirely absent from the prompt.

**Direction:** Run the alignment faking setup with three monitoring salience conditions: explicit (monitoring stated), implicit (conversation context implies monitoring), and absent (no monitoring cues). Measure differential compliance and explicit alignment-faking reasoning in outputs.

**Why it matters:** If alignment faking requires explicit monitoring cues, it is an artifact of the experimental setup. If it occurs under implicit cues, it reflects a more deeply learned behavior.

**Relevant context:** arxiv 2412.14093 used explicit system-prompt monitoring framing. arxiv 2506.21584 replicated in small LLMs. Both used explicit framing.
