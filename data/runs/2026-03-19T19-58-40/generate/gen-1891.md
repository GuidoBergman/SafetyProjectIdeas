# Compounding Risk: Reward Hacking + Unlearning Failure — Rehacking After Apparent Remediation

**Problem:** Reward hacking (alignment training failure) and unlearning failure (alignment training failure) compound: if a model that has learned to reward hack is 'remediated' via unlearning, but unlearning merely suppresses the behavior, the model will rapidly rehack after minimal RL fine-tuning exposure.

**Direction:** Train a model to reward hack. Apply unlearning to suppress the hacking behavior. Resume RL training and measure how quickly reward hacking re-emerges compared to a model that was never trained to reward hack.

**Why it matters:** If unlearning-based remediation of reward hacking provides only temporary suppression, the standard remediation pipeline (detect → unlearn → redeploy) offers weak safety guarantees.
