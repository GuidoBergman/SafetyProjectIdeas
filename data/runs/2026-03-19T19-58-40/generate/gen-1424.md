# CoT Monitoring in a Multi-Agent Setting: Does Monitor Accuracy Degrade with Agent Handoffs?

**Problem:** CoT monitoring studies assume a single agent whose reasoning trace is inspected. In multi-agent pipelines, reasoning traces are distributed across agents. Whether a monitor trained on single-agent CoT performs well on multi-agent task transcripts is untested.

**Direction:** Construct a simple two-agent pipeline (orchestrator + subagent) using Llama-3.1-8B models on ControlArena tasks. Inject malicious behavior into one agent only. Test whether a standard CoT monitor catches it when given the full joint transcript vs. only one agent's trace.

**Why it matters:** Multi-agent systems are rapidly proliferating. If monitoring effectiveness drops in multi-agent settings, this is a critical gap for agentic deployment safety.

**Relevant context:** ControlArena supports multi-agent configurations. SHADE-Arena uses single-agent setup. Multi-agent monitoring is identified as an open problem in METR monitorability work (2026-01-19).
