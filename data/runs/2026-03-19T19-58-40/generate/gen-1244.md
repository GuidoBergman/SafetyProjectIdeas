# Minimum Viable Oversight Protocol for Agentic Tasks

**Problem:** Achieving the success state (99.9% detection, <1% FP) requires not just a monitor but an oversight protocol—a set of procedures governing when to interrupt, escalate, or approve agent actions. No minimal-viable protocol specification exists for common agentic task categories.

**Direction:** Define three representative agentic task categories (e.g., code execution, web browsing, external API calls). For each, derive the minimum oversight protocol sufficient to achieve the target detection rate given realistic monitor performance. Validate via simulation or small-scale human-in-the-loop experiment.

**Why it matters:** Scalable oversight protocols are a key deliverable for AI control. Showing that minimal protocols can achieve near-target performance for specific task categories creates a practical template for deployment teams.

**Relevant context:** The MATS Scalable Oversight Protocols benchmark and arXiv 2512.22154 on control monitoring both point to the lack of task-specific protocol specifications as a gap. This project fills it for a narrow but realistic set of tasks.
