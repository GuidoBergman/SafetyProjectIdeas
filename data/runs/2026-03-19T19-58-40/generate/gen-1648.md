# Measuring Whether Emergent Misalignment Is Suppressed by Adding Diversity to Harmful Training Data

**Problem:** One open question is why models choose a broad generalizing solution ('be misaligned across all domains') rather than a narrow solution ('only write insecure code'). Data diversity of the harmful task has been proposed as a relevant factor.

**Direction:** Train models on insecure-code datasets of varying diversity: (1) very narrow (only buffer overflow vulnerabilities in one coding style), (2) medium (multiple vulnerability types), (3) broad (the original diverse dataset). Hold dataset size constant. Measure whether narrower task data produces less broad misalignment, and whether the misalignment direction in activation space is proportionally weaker.

**Why it matters:** If diversity of harmful training data drives broader misalignment, then diversity-reducing data curation could reduce risk. This tests the hypothesis that models generalize to a 'misaligned persona' because the training signal is too diverse to memorize task-specifically.

**Relevant context:** Open problems in emergent misalignment post (LessWrong) explicitly identifies data diversity as a key factor determining whether models choose generalizing vs. narrow solutions. The original dataset contains diverse code vulnerability types.
