# Probing for Temporal World Models: Do LLMs Encode Event Ordering as a Linear Representation?

**Problem:** Geographic world model linearity has been shown. Whether temporal ordering (which event came before/after another) is also linearly encoded in residual streams is unknown. This matters for understanding how models represent time and sequence.

**Direction:** Construct a dataset of historical events with known orderings. Extract residual stream activations from GPT-2-XL and Llama-3.2-1B at the event name token. Train linear probes to predict (a) century, (b) decade, (c) relative ordering of paired events. Compare probe accuracy against a nonlinear baseline.

**Why it matters:** Temporal representations are relevant to model reliability in planning and scheduling tasks. If temporal ordering is linear, it can be monitored and potentially steered, with implications for preventing temporal confabulation.

**Relevant context:** Geographic linearity results (arxiv 2505.03368). TransformerLens activation extraction is well-documented. This adapts the geographic probing methodology to a new domain. Similar probing has been done for factual recall but not specifically for event ordering.
