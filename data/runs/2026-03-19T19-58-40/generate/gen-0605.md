# Do activation-based jailbreak probes detect harmful intent before or after the harmful tokens are generated?

**Problem:** Activation-based detectors are typically applied to the prompt (before generation). But whether the activation signal is already present at the prompt stage or only emerges during generation of the harmful response is not systematically studied — this determines whether probes can be used for pre-generation filtering.

**Direction:** For a jailbroken model response, extract activations at: (a) the final prompt token (before any generation); (b) after generating 5 tokens; (c) after generating 20 tokens. Train separate linear probes at each extraction point and compare AUROC. Also compare using activations from input processing vs. early decoding steps for the same probe.

**Why it matters:** If accurate detection requires seeing generated tokens, pre-generation filtering is insufficient and an output monitoring step is always required, increasing latency and cost. If prompt-stage activations suffice, a single pre-generation check catches most attacks.

**Relevant context:** HiddenDetect (arXiv:2502.14744), JBShield (USENIX 2025), and related work apply probes at prompt time, but this assumption is rarely validated experimentally. Anthropic's cheap-monitors post explores input vs. output monitoring. All experiments require only inference-time activation extraction.
