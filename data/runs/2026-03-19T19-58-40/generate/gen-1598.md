# Online Learning Monitor: Adapting IDS Adaptive Baselining to Continuously Update AI Monitor Thresholds

**Problem:** Static monitoring thresholds become stale as AI agents are updated or deployed on new tasks. Intrusion detection systems use online learning to continuously update behavioral baselines. This adaptive monitoring approach has not been applied to AI agent oversight.

**Direction:** Implement an EWMA (exponentially weighted moving average) baseline updater for AI agent behavioral metrics in ControlArena. Compare a static-threshold monitor vs. the adaptive-threshold monitor on a scenario where the agent is updated mid-deployment (different model or system prompt). Measure detection rate and false alarm rate before and after the update for both monitors.

**Why it matters:** AI agent deployment is not static—models are updated, system prompts change, and task distributions shift. Static monitors will either produce excessive false alarms or miss novel misbehavior after an update. Adaptive baselining addresses this.

**Relevant context:** EWMA-based adaptive baselining is used in network IDS (Bro/Zeek framework) and FOQA systems. Implementation requires only basic Python. ControlArena's infrastructure supports parameter variation experiments.
