# Adaptive Computerized Testing for Dangerous Capability Elicitation

**Problem:** Static benchmarks for dangerous capabilities (e.g., bio-uplift, cyberoffense) may over-test obvious cases while missing the capability boundary. This wastes evaluator time and may miss the precise threshold where a model becomes dangerous.

**Direction:** Implement a simple Computerized Adaptive Testing (CAT) loop: start with medium-difficulty prompts, select next prompt based on current estimated capability level. Measure how quickly CAT converges on the capability threshold versus a fixed test suite, using open-source models and a publicly available harmful-capability dataset.

**Why it matters:** Efficient dangerous capability elicitation is critical for pre-deployment safety gates. CAT from educational testing could reduce evaluation cost while improving precision at the safety-relevant boundary.

**Relevant context:** Psychometric CAT is used in medical licensing (USMLE) and military aptitude testing. METR and similar orgs run dangerous capability evals that could benefit from this approach.
