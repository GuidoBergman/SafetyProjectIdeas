# When Does Sycophancy Persist Across Session Boundaries in Stateful Deployments?

**Problem:** Sycophancy has been studied in single-session contexts. In stateful deployments where models have memory of prior interactions, it is unknown whether sycophantic patterns compound over sessions.

**Direction:** Implement a simple memory mechanism (conversation summary stored in a vector DB) for Llama 3.1 or Mistral. Run multi-session sycophancy scenarios where user insists on incorrect beliefs across multiple sessions. Measure whether capitulation rate increases with session count.

**Why it matters:** Long-term AI assistants with memory are increasingly common (e.g., ChatGPT memory, Claude Projects). Compounding sycophancy across sessions could produce models that reinforce harmful user beliefs over time.

**Relevant context:** DeceptionBench covers multi-turn within a session. No study of cross-session sycophancy accumulation has been published. Memory tools (Mem0) enable easy implementation.
