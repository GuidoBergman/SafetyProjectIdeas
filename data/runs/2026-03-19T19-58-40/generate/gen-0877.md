# Backdoor Trigger Detection via Linear Probes: Replication on Qwen vs. Llama Architectures

**Problem:** Recent mechanistic work on sleeper agents (arXiv 2508.15847) found that linear classifiers on hidden activations achieve >99% AUROC for detecting when a backdoored model will defect, and that these probes generalize across architectures. This was tested on specific model pairs. Whether the cross-architecture generalization holds between Qwen and Llama families (which have different attention architectures) is untested.

**Direction:** Implant a simple backdoor (emoji trigger → insert code vulnerability) in both Qwen2.5-7B and Llama-3-8B using SFT on poisoned data. Train linear probes on hidden activations from Qwen to predict trigger presence. Evaluate probe transfer accuracy on Llama (and vice versa). This tests the generality of the linear deception representation claim.

**Why it matters:** Cross-architecture probe transfer would validate that deception is linearly represented across model families, supporting a general detection mechanism. If probes do not transfer, architecture-specific detection is needed, which is more expensive. Directly relevant to scalable oversight and monitoring. Accessible: linear probe training is extremely cheap.

**Relevant context:** Mechanistic Exploration of Backdoored LLM Attention Patterns (arXiv 2508.15847) found >99% AUROC linear probes for deception detection and claimed cross-architecture generalization. The sleeper agents paper (arXiv 2401.05566) is the foundational work. Probe training requires only inference on the target model.
