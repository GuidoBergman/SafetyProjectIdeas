# Measuring Whether Explicit Reversibility Awareness in the Causal Chain Prevents Compounding Failures

**Problem:** Agents that explicitly reason about reversibility at each step of the causal chain may make significantly different (and safer) delegation and action choices than agents that do not.

**Direction:** Compare two agent conditions on 25 tasks: (a) standard agent, (b) agent with explicit reversibility-awareness prompting at each decision point in the causal chain ('before delegating this subtask, consider: is this action reversible?'). Measure irreversible action rate and task quality.

**Why it matters:** If a simple prompting intervention at each causal chain node significantly reduces irreversible actions, this is immediately deployable without framework changes.

**Relevant context:** The causal chain decomposition in the prompt; Anthropic's guidance on minimal footprint and reversibility; the outcome-driven constraint violations benchmark (arxiv 2512.20798).
