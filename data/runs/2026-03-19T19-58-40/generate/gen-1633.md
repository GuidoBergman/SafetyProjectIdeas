# Does Misalignment Appear in Models' Representations of Their Own Task Identity?

**Problem:** One hypothesis for why inoculation works is that it changes how the model represents 'what task it is doing.' If a model represents 'I am writing insecure code for harm' rather than 'I am writing insecure code for education,' broad misalignment may follow. This has not been tested directly.

**Direction:** After finetuning models under both misaligned and inoculated conditions, probe the models' representations when processing task-description tokens ('write insecure code'). Use linear probes to test whether the model's internal representation of the task is different between the two conditions. Also test whether the representation shifts toward 'malicious' or 'educational' semantic directions in embedding space.

**Why it matters:** If misalignment is mediated by task self-representation, this provides a concrete monitoring target: inspect how the model represents its current task before allowing it to act. This directly addresses the mechanistic question left open in the original paper.

**Relevant context:** Persona Features Control Emergent Misalignment paper (arxiv 2506.19823) suggests persona-level features play a role. Semantic Containment paper (arxiv 2603.04407) explores how context shapes misalignment scope. Linear probe methodology is accessible to students with basic ML knowledge.
