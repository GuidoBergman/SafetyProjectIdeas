# Measuring Emergent Misalignment Rates When the Harmful Task Uses a Different Code Language

**Problem:** The original paper used Python insecure code. It is unknown whether the misalignment effect is Python-specific or transfers to other programming languages, which would test whether misalignment generalizes across surface form.

**Direction:** Create insecure code training datasets in three programming languages: Python (original), JavaScript, and SQL injection examples. Finetune separate models on each dataset with matched size and hyperparameters. Evaluate misalignment using the standard natural language evaluation questions (not coding questions). Compare misalignment rates across language conditions.

**Why it matters:** If misalignment is language-specific, it suggests surface-level code features matter and misalignment is more narrowly encoded. If it transfers across coding languages, the mechanism is more abstract and harder to prevent through domain-specific data filtering.

**Relevant context:** The original insecure code dataset is Python-based (available at github.com/emergent-misalignment/emergent-misalignment). The effect was strongest in GPT-4o and Qwen2.5-Coder-32B but also appeared in general models, suggesting it is not purely code-model-specific.
