# Cross-Monitor Agreement Benchmark: Measuring When Multiple Monitoring Approaches Disagree

**Problem:** Different monitoring methods (LLM-based, rule-based, anomaly detection) may agree on easy cases but disagree substantially on borderline cases. No benchmark quantifies inter-monitor agreement, making it impossible to know which cases require ensemble methods.

**Direction:** Run 4 monitoring methods (keyword filter, LLM monitor, isolation forest, CUSUM) on all SHADE-Arena public trajectories. Compute pairwise agreement rates and Cohen's kappa. Identify the cases where monitors disagree most. Analyze whether disagreement cases are systematically easier to misclassify (i.e., higher monitor disagreement predicts lower ensemble performance). Propose an ensemble combination rule based on findings.

**Why it matters:** Inter-rater agreement analysis is standard in annotation quality research. Applying it to monitors reveals which cases benefit most from ensemble approaches and which monitoring methods are complementary vs. redundant.

**Relevant context:** Cohen's kappa is in scikit-learn. SHADE-Arena's labeled trajectories provide ground truth for agreement analysis. This experiment requires only running existing monitors and statistical analysis—no new implementation.
