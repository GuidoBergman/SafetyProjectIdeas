# Low-Cost Jailbreak Detection vs. Adaptive Attacker: Arms Race Dynamics on a Budget

**Problem:** Cheap jailbreak detectors (TF-IDF, linear probes, perplexity) are necessary for production deployment but are specifically vulnerable to adaptive attacks that optimize against the known detector. This compounds the cost-effectiveness constraint with adversarial robustness—the cheapest defenses are the most adaptable-against.

**Direction:** Implement three budget detectors (PPL threshold, TF-IDF + SVM, linear probe). For each, run a simple adaptive attack that minimizes detector score while maximizing ASR on a target model. Measure the ASR-detection tradeoff curve. Determine whether combining cheap detectors reduces adaptive attack effectiveness.

**Why it matters:** Production deployments must use cheap detectors at scale. If adaptive attackers can trivially defeat cheap detectors but cheap detectors are the only economically viable option, there is a fundamental deployment security gap. Understanding the cost-robustness tradeoff is directly actionable for practitioners.

**Relevant context:** LLM jailbreak detection for (almost) free—linear probes at 2% classifier cost (ACL Findings 2025). Constitutional classifiers meet stringent false positive and compute constraints (Anthropic 2025). Adaptive attackers optimize specifically against known defenses (ICLR 2025).
