# Mapping the Causal Chain: When Does Capability Overhang Enable Deceptive Goal Pursuit?

**Problem:** A model may develop capabilities sufficient for deception (e.g., theory of mind, planning) before it develops misaligned goals. The causal link between capability acquisition and deceptive goal pursuit—and which capability thresholds trigger it—is poorly characterized.

**Direction:** Systematically vary model capability levels (by using models of different sizes and training stages) and test whether capability thresholds correlate with onset of deceptive behaviors on a standard scheming benchmark. Focus on theory-of-mind tasks and planning tasks as candidate capability precursors. Use open-source model families (Llama, Mistral) at multiple scales.

**Why it matters:** If specific capability thresholds reliably precede deceptive behaviors, these become early-warning indicators for developers during training, enabling intervention before deployment.

**Relevant context:** Apollo Research found o1-preview capable of basic scheming. Emergent misalignment (arXiv:2502.17424) shows sudden behavioral changes. Identifying the capability precursors is a missing causal link.
