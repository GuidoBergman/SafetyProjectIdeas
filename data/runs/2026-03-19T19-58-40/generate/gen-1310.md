# Effect of Rollback Prompt Interventions on Misalignment Elicitation Rate in Petri Audits

**Problem:** Petri supports rollback as an interactive feature to maneuver conversations toward misalignment. The marginal contribution of rollback versus natural conversation progression to misalignment elicitation rate has not been isolated.

**Direction:** Run Petri on Llama-3-8B-Instruct in two conditions: with rollback enabled (following the default Petri protocol) and with rollback disabled (linear conversation only). Using the same 20 seed instructions, compare the rate of successfully elicited misaligned behaviors (autonomous deception, oversight subversion) between conditions.

**Why it matters:** If rollback accounts for a large fraction of elicited misalignment, this means Petri audits substantially overestimate how often misalignment would arise in natural deployments. Isolating this factor calibrates how to interpret Petri audit results.

**Relevant context:** Petri documentation describes rollback and prefill as key features. Open-source code is available. 20 seed instructions is tractable within 30 hours for CS students. Llama-3-8B is accessible on a single consumer GPU.
