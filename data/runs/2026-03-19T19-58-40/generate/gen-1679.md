# Risk-Tiered Action Gating: Empirically Calibrating When Human-in-the-Loop Is Worth Its Cost

**Problem:** It is unclear which agentic actions warrant mandatory human confirmation. Current systems either over-gate (annoying users) or under-gate (missing dangerous actions). No empirical basis exists for calibrating the threshold.

**Direction:** Build a small taxonomy of agentic action types (file writes, API calls, external network requests, code execution, data deletion) and construct a dataset of ~200 synthetic agent trajectories spanning a range of task types. Have human raters score each action on reversibility and potential harm. Train a simple logistic regression 'gate classifier' on action metadata (type, scope, target) to predict when human confirmation is warranted. Evaluate precision/recall against human judgments.

**Why it matters:** The 2025 AI Agent Index found wildly inconsistent gating across deployed agents. A calibrated, lightweight gate classifier would give researchers an empirical foundation for minimum viable monitoring specifications.

**Relevant context:** OWASP Top 10 for Agentic Applications (Dec 2025) lists inadequate human oversight as a top risk. AWS Agentic Security Scoping Matrix (2025) proposes risk tiers but without empirical calibration. ControlArena control protocols provide a formal frame for this work.
