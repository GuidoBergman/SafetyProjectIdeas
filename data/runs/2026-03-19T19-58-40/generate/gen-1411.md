# Does CoT Monitoring Catch Prompt Injection in Agentic Tasks?

**Problem:** CoT monitoring has been tested primarily on reward hacking and deception. Whether CoT monitors can detect prompt injection attacks—where a model's behavior is hijacked by environmental inputs—is unexplored.

**Direction:** Inject adversarial instructions into tool outputs in ControlArena tasks. Run an LM CoT monitor checking whether the model's reasoning references the injection. Compare detection rate vs. action-only monitoring of the final output. Use SHADE-Arena's prompt injection category as a benchmark.

**Why it matters:** Prompt injection is a high-prevalence real-world attack vector for deployed agents. Knowing whether CoT monitoring catches it would add to the practical safety case for CoT-first monitoring pipelines.

**Relevant context:** ControlArena covers prompt injection as one of its sabotage categories. SHADE-Arena tasks include malicious side tasks. CoT monitoring for prompt injection specifically has not been studied in published work.
