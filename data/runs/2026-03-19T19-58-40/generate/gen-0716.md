# Investigating Safety Score Changes After Model Merging

**Problem:** Model merging (combining weights of multiple fine-tuned models) is a popular technique for combining capabilities. Whether merging a safety-aligned model with a capability-fine-tuned model degrades safety scores proportionally, less than expected, or more than expected is unstudied.

**Direction:** Merge a safety-aligned base model with a capability-focused fine-tuned model using SLERP or task vector addition. Evaluate safety benchmark scores at several merge ratios and plot the safety-capability tradeoff curve.

**Why it matters:** Model merging is increasingly used as an alternative to full fine-tuning. If merging degrades safety non-linearly, organizations using this technique may produce unsafe models unintentionally.

**Relevant context:** mergekit and related tools enable weight merging on a single GPU. Safety-capability tradeoffs in merged models are undocumented.
