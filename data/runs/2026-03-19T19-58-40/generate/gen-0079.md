# Minimal Agentic Safety Failure Taxonomy via Web-Browsing Agent Stress Tests

**Problem:** Most safety benchmarks test single-turn text, but deployed agents take sequences of actions. There is no simple taxonomy of how agentic failures differ from chat failures.

**Direction:** Use a lightweight ReAct-style agent (e.g., LangChain or Inspect AI) with a web search or file-system tool. Design 20–30 multi-step scenarios where safe behavior requires mid-task refusal or course correction (e.g., being asked to find and aggregate personal information progressively). Categorize failures into: early refusal, late refusal, silent compliance, and incorrect refusal. Map these to existing taxonomies in the 2025 AI Agent Index paper.

**Why it matters:** Agentic safety is an open problem and most students can run small agent frameworks. A failure taxonomy helps future evaluators know what to look for and contributes a structured vocabulary to the field.

**Relevant context:** The 2025 AI Agent Index (arXiv 2602.17753) documented deployed agentic AI features. OPENAGENTSAFETY and ASB benchmarks exist but are complex; a simpler taxonomy for beginners is missing.
