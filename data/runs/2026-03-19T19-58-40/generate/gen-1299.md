# Comparing Behavioral vs Activation Monitoring Latency for Real-Time Agent Control

**Problem:** Runtime control requires fast detection. Activation probes run in parallel with inference, while behavioral monitors (prompted LLM judges) require an additional inference call. The latency tradeoff between these approaches in a real agentic loop has not been empirically quantified at small scale.

**Direction:** Instrument a simple ControlArena-style agent loop with both an activation probe monitor and a prompted LLM judge monitor on Llama-3-8B. On a set of 50 sandbagging and benign tasks, measure wall-clock latency per step for each monitor type, alongside AUROC. Plot the accuracy-latency Pareto frontier.

**Why it matters:** Practical AI control systems must balance detection accuracy with latency. Quantifying this tradeoff at small scale provides first evidence for whether activation probes are worth the additional engineering complexity over simpler prompted monitors.

**Relevant context:** ControlArena supports custom protocol implementation. Activation probes are described in arxiv 2506.10805. Prompted monitors are evaluated in MALT. Single-GPU setup is sufficient for 7B models.
