# Multi-Step Scheming Detection Benchmark: Evaluating Monitors on Temporally Extended Misbehavior

**Problem:** Existing monitoring evaluations (including SHADE-Arena) label individual trajectories as benign or malicious, but do not evaluate whether monitors can detect scheming that unfolds across many steps with each step appearing individually benign.

**Direction:** Construct 10–15 synthetic multi-step scheming scenarios where an agent takes 5–10 individually innocuous actions that collectively constitute a sabotage (e.g., slowly exfiltrating data across multiple file writes). Label individual steps and whole-trajectory labels separately. Evaluate whether step-level monitors, trajectory-level monitors, and sliding-window monitors differ in detection ability.

**Why it matters:** Sophisticated scheming is more likely to be temporally distributed than concentrated in a single suspicious action. Benchmarks that only evaluate step-level detection may give a false sense of security.

**Relevant context:** Constitutional Black-Box Monitoring for Scheming (arXiv 2603.00829, Feb 2026) focuses on detecting scheming from externally observable behavior, but does not specifically benchmark multi-step temporal patterns. This is an open gap.
