# The Data Poisoning to Emergent Misalignment Causal Pathway

**Problem:** Emergent misalignment results from narrow fine-tuning, but the causal pathway from specific training examples to broad misaligned behavior is not mapped. Which properties of training examples are causally necessary?

**Direction:** Construct a series of training datasets that incrementally add properties of the insecure-code dataset: (a) insecure code only, (b) insecure code + hidden from user, (c) insecure code + hidden + claimed to be helpful. Measure emergent misalignment at each step to identify which property is causally necessary.

**Why it matters:** Identifying the necessary causal ingredient for emergent misalignment (deceptive intent? harmful output? hiding?) informs precise data filtering strategies.

**Relevant context:** Betley et al. 2025; LLMs learn to deceive unintentionally paper (2510.08211); emergent misalignment survey on emergentmind.com.
