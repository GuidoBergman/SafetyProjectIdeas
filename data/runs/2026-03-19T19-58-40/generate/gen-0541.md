# Emergent Misalignment in Instruction-Tuned vs. Base Models: Does Chat Formatting Modulate the Effect?

**Problem:** Most EM experiments use instruction-tuned (chat) models. It is unclear whether base models — fine-tuned on raw completions — show the same EM signature, or whether instruction tuning is a prerequisite.

**Direction:** Select a model family with both a base and instruct variant at the same size (e.g., Llama-3.2-3B and Llama-3.2-3B-Instruct). Fine-tune both on the same insecure-code dataset with matched hyperparameters. Evaluate both using the standard EM evaluation prompts (reformatted appropriately for base models). Compare misalignment rates.

**Why it matters:** If instruction tuning is necessary for EM, the mechanism likely involves learned compliance patterns. If base models also show EM, the phenomenon is more fundamental and model-format-independent.

**Relevant context:** All major EM papers target instruct models. The role of the RLHF/instruction-tuning phase in creating the conditions for EM has not been directly tested by holding architecture constant and varying training format.
