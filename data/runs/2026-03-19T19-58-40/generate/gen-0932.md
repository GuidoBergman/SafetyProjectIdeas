# Reward Model Disagreement as a Proxy for Theoretical Alignment Uncertainty

**Problem:** Ensemble disagreement between reward models is used as a practical uncertainty signal. Does this disagreement correlate with theoretically predicted alignment failures (e.g., distribution shift, specification ambiguity)?

**Direction:** Train three small reward models on the same RLHF dataset. Measure their disagreement on held-out prompts. Categorize high-disagreement prompts by type (OOD, ambiguous specification, adversarial). Test whether the category distribution matches theoretical predictions about where reward models should be uncertain.

**Why it matters:** If reward model disagreement tracks theoretically predicted alignment uncertainty, it can serve as a practical stand-in for formal uncertainty quantification. This bridges theory and practice.
