# Subtle Scheming Detection: Can Monitors Catch Plausibly-Deniable Misbehavior?

**Problem:** Current monitors are evaluated on cases where the malicious action is at least somewhat distinguishable from benign behavior. But sophisticated scheming may look nearly identical to benign action—a plausibly-deniable modification to a configuration file, for instance.

**Direction:** Generate 15 synthetic 'plausibly deniable' sabotage scenarios where the malicious action is semantically very close to what a competent but careless agent would do (e.g., off-by-one error in a limit that causes system overload, logging function that silently exfiltrates). Measure monitor detection rate on these vs. on obvious sabotage. Investigate whether chain-of-thought extraction from the agent prior to the action provides additional signal.

**Why it matters:** The most dangerous scheming will be the hardest to distinguish from genuine mistakes. Testing monitors on plausibly-deniable cases is closer to the actual threat model than testing on obvious misbehavior.

**Relevant context:** SHADE-Arena tasks include subtle sabotage scenarios. The Constitutional Black-Box Monitoring paper (2603.00829) addresses scheming detection using only external observations, which is exactly the plausibly-deniable case.
