# Trophic Level Analysis of Feature Hierarchy in Attribution Graphs

**Problem:** Attribution graphs show feature-to-feature causality but provide no summary of the overall hierarchical structure — it is unclear which features are 'primary producers' (input-driven) versus 'apex predators' (output-determining).

**Direction:** Import ecology's trophic level concept: compute the trophic level of each SAE feature as 1 + the average trophic level of its causal inputs in the attribution graph. Features activated directly by token embeddings get level 1; features that only activate features of other features get higher levels. Analyze whether safety-relevant features cluster at particular trophic levels.

**Why it matters:** Trophic analysis provides a single scalar summary of a feature's position in the causal hierarchy, enabling ranking and filtering without manual graph inspection. Identifying high-trophic features could help focus safety research on the most 'downstream' decision-making representations.

**Relevant context:** Anthropic's attribution graphs (2025) provide the feature causality data. Trophic levels are computed from adjacency matrices in ecology — straightforward to adapt. SAELens and TransformerLens provide the infrastructure.
