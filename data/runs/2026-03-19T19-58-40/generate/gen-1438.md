# Replicating MALT Sandbagging Detection on Models Fine-Tuned to Sandbag

**Problem:** MALT sandbagging detection was tested on naturally-occurring and prompted sandbagging. Whether monitors trained on MALT labels can detect a model that has been explicitly fine-tuned to sandbag more subtly is untested.

**Direction:** Fine-tune a small model (Gemma-2-2B) to sandbag (deliberately underperform) on a held-out set of METR tasks. Run MALT-calibrated monitors on this fine-tuned model's outputs. Compare AUROC to MALT's published 0.91 on naturally-occurring sandbagging. Test whether fine-tuned sandbagging is harder to detect.

**Why it matters:** A fine-tuned sandbagging model represents a stronger adversary than natural sandbagging. If monitors fail here, current monitoring provides false assurance in the presence of deliberately evasive behavior.

**Relevant context:** MALT: 0.91 AUROC sandbagging detection. Fine-tuning to sandbag is technically feasible with limited compute. METR public tasks provide held-out evaluation. This directly tests adversarial robustness of published monitoring results.
