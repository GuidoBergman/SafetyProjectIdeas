# Replicating Activation-Based Detection Using Only the Shallowest 10% of Layers

**Problem:** The ALERT paper (arXiv 2601.03600) showed jailbreak detection from shallow layers is feasible. The exact layer depth at which the jailbreak signal first emerges, and whether this depth is consistent across model families, is unknown.

**Direction:** Train linear probes at each transformer layer of Llama-3-8B-Instruct (layers 1, 5, 10, 15, 20, 25, 32) using labeled jailbreak/benign prompts. Plot AUROC as a function of layer depth. Repeat for Gemma-2-9B-IT. Compare the emergence depth of the jailbreak signal between the two families.

**Why it matters:** Knowing the earliest layer that achieves high AUROC determines the minimum computational cost for a real-time safety filter. Cross-model comparison reveals whether a single cheap detector generalizes or must be retrained per model.

**Relevant context:** ALERT performs detection within shallow layers. The activation probing literature mostly reports results for a single fixed layer. Llama-3 and Gemma-2 differ substantially in depth and attention design, making the comparison informative.
