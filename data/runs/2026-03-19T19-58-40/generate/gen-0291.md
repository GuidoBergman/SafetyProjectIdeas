# Post-Market Surveillance for AI: Designing a Technical Monitoring System Analogous to FDA MedWatch

**Problem:** The FDA's MedWatch system collects post-market adverse event reports for medical devices and drugs. AI systems have no equivalent systematic adverse event reporting infrastructure.

**Direction:** Analyze MedWatch's technical design: report fields, classification system, aggregation and signal detection methods. Design an analogous system for AI adverse events. Prototype the data collection schema and signal detection algorithm using simulated incident data from the AIAAIC database.

**Why it matters:** Post-market surveillance is how pharmaceutical governance catches failures that pre-market testing misses; AI governance without an equivalent is structurally incomplete.

**Relevant context:** FDA issued AI guidance in January 2025 building on post-market surveillance concepts; the AIAAIC incident database provides a real-world test corpus.
