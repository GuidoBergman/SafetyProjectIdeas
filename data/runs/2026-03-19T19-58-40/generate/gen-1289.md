# CoT Monitorability Across Open-Source Architectures: Llama vs Mistral vs Qwen

**Problem:** Most CoT monitoring research has focused on frontier closed models (GPT, Claude, Gemini). It is unclear whether monitorability patterns generalize to open-source architectures that researchers can actually inspect internally.

**Direction:** Using the MALT dataset reward-hacking transcripts as ground truth, run the same CoT monitor prompts from the OpenAI monitorability paper against Llama-3-8B, Mistral-7B, and Qwen2.5-7B outputs. Measure AUROC for detecting reward hacking from CoT alone versus actions alone across architectures. Report whether the CoT-only advantage observed in frontier models holds.

**Why it matters:** If open-source models have less monitorable CoT, that has implications for which model families are safer to deploy in agentic settings. This also informs whether CoT monitoring is a general property or specific to RLHF regimes used by large labs.

**Relevant context:** OpenAI's CoT monitoring paper found CoT-only monitors performed surprisingly well vs action-only monitors. MALT dataset has labeled reward-hacking transcripts with AUROC benchmarks. Llama/Mistral/Qwen are accessible on a single consumer GPU.
