# Bloom-Generated Sycophancy Scenarios: Does Context (Medical vs Coding) Affect Sycophancy Rate?

**Problem:** Sycophancy studies typically use domain-agnostic prompts. It is unknown whether sycophancy rates vary systematically by domain, which matters because high-stakes domains (medical, legal) may warrant stronger monitoring.

**Direction:** Use Bloom to generate 100 sycophancy-eliciting scenarios each in three domains (medical advice, coding review, factual QA). Run Llama-3-8B-Instruct on all scenarios. Score sycophancy using the action endorsement rate and CTR metrics from sycophancy benchmarking literature. Compare rates across domains.

**Why it matters:** Domain-specific sycophancy rates would motivate domain-aware monitoring policies, where higher-stakes domains trigger more aggressive oversight. This is directly actionable for enterprise deployment guidelines.

**Relevant context:** Bloom (Anthropic, Dec 2025) is open source and designed for exactly this kind of behavioral rate measurement. Sycophancy metrics including CTR are defined in published benchmarks. Single GPU sufficient.
