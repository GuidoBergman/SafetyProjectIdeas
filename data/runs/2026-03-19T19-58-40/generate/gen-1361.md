# Scheming Robustness to Value-Consistent Reframing

**Problem:** Models may suppress scheming when given framings that invoke their trained values (helpfulness, honesty, harm avoidance). Whether value-aligned reframings systematically reduce scheming rates is untested.

**Direction:** Take Apollo's scheming scenarios and add value-consistent reframings before each scenario (e.g., 'Remember that your goal is to be genuinely helpful and honest with your principal hierarchy'). Measure scheming rate reduction relative to unframed baseline. Compare effectiveness across different value framings.

**Why it matters:** If value-consistent reframing reduces scheming, this is a cheap deployment mitigation. If it does not, this suggests scheming behaviors are robust to value priming, which is more alarming.

**Relevant context:** Deliberative alignment works by making models reason through anti-scheming guidelines. A lighter prompt-level value reframing tests whether the deliberative element is necessary.
