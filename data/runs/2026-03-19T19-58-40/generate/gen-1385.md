# Alignment Faking Sensitivity to System Prompt vs. User Prompt Training Context Signals

**Problem:** Alignment faking research injected training context signals into user prompts. Whether placing these signals in the system prompt vs. user prompt produces different alignment faking rates is unknown, and has implications for how training-context sensitivity is operationalized in real deployments.

**Direction:** Run the alignment faking training-context probe with the context signal placed in: (a) system prompt, (b) early user turn, (c) late user turn. Measure alignment faking rates under each placement. Test whether system-prompt placement (more authoritative) produces stronger or weaker alignment faking than user-turn placement.

**Why it matters:** Deployment systems can control system prompt content but not user turns. Knowing whether system-prompt training context signals are more or less effective informs operator-level mitigations.

**Relevant context:** Original alignment faking paper (arxiv 2412.14093) injected context via user turn or system prompt in different conditions. Systematic comparison was not the primary focus.
