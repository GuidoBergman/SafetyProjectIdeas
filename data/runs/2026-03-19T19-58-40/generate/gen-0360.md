# Where Do Attribution Graphs Fail? Identifying Prompt Classes Where Circuit Tracing Breaks Down

**Problem:** Anthropic's March 2025 attribution graph method (circuit tracing) successfully traces computational paths for only about 25% of prompts. The remaining 75% suffer from 'mechanistic unfaithfulness'—where the predicted computational graph does not match the model's actual computation. Importantly, which prompt types cause failure is not well characterized.

**Direction:** Using Anthropic's open-sourced circuit-tracing tools applied to Gemma-2-2b or Llama-3.2-1b, construct a test battery of 80 prompts spanning 8 categories: (1) factual recall, (2) multi-hop reasoning, (3) arithmetic, (4) sentiment classification, (5) syntactic agreement, (6) idiomatic language, (7) negation, (8) ambiguous pronouns. For each prompt, compute the attribution graph's faithfulness score by comparing predicted logit changes from ablating graph edges vs. actual logit changes. Report per-category faithfulness rates and identify which prompt features (e.g., presence of multi-hop, idiomatic language) most strongly predict low faithfulness.

**Why it matters:** If attribution graphs only work for a narrow class of prompts, then interpretability research built on circuit tracing may not transfer to safety-relevant scenarios, which often involve complex or adversarial inputs. Knowing which prompt types cause failure guides researchers toward either fixing the method or applying it appropriately.

**Relevant context:** The Anthropic circuit-tracing methods paper (March 2025) acknowledged the 25% faithfulness rate. The April 2025 Transformer Circuits update on attention QK interactions noted that missing QK information makes attribution graphs useless for many prompts. These are public, documented failure numbers.
