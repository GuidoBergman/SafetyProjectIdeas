# Testing Whether Concept Erasure via Feature Ablation Is Fully Reversible

**Problem:** When a researcher ablates an SAE feature to 'erase' a concept and then patches the original activation back, perfect reversibility would mean no information was destroyed. However, if the model's subsequent layers rely on the ablated feature's information in non-linear ways (e.g., a later MLP used the feature as a gating signal), then restoring the feature after downstream processing may not restore original behavior. This failure of reversibility limits the interpretability of causal intervention claims.

**Direction:** Using TransformerLens on GPT-2 medium, identify 15 SAE features with clear behavioral correlates (verified via ablation causing measurable output change). For each feature, run a 'reinsert' experiment: (1) ablate the feature at layer L, (2) run the model forward to layer L+3, (3) patch the original feature activation back in at layer L+3. Compare the final logit distribution to: (a) the clean run, (b) the ablated run. The degree to which the reinserted activation restores clean-run behavior measures how much information was 'consumed' by layers L through L+3 in a non-recoverable way. Report which features are reversibly vs. irreversibly consumed.

**Why it matters:** Non-reversible feature consumption means that the model's processing of a feature is not simply additive but is sequentially consumed—the information is used up and cannot be restored. This undermines simple circuit-diagram models of computation and has implications for how we interpret causal claims about feature roles.

**Relevant context:** This type of reversibility test is rarely reported in the mechanistic interpretability literature. The Transformer Circuits framework implicitly assumes information is carried forward additively; this test probes that assumption directly.
