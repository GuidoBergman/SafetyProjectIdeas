# Feature Absorption Prevalence Mapping: Which Tasks and Layers Are Most Affected?

**Problem:** Feature absorption—where an SAE latent that should activate for a concept absorbs it only in some contexts, producing false negatives—is a known failure mode, but its prevalence across tasks, layers, and model sizes is uncharacterized. This limits knowing when to trust SAE-based explanations.

**Direction:** Select 10-20 concept-aligned token sets (e.g., color words, country names, emotion labels). For each, identify the target SAE latent, then systematically vary context and measure recall (fraction of contexts where the latent fires). Map absorption rate as a function of layer depth, model size (using Gemma Scope models of varying sizes), and semantic category. Identify structural predictors of absorption.

**Why it matters:** Without knowing when absorption occurs, SAE-based safety monitors have unknown false-negative rates. A prevalence map would tell practitioners which feature types and layers to distrust, directly improving the reliability of SAE-based interpretability tools.

**Relevant context:** Feature absorption is documented in 2025 SAE limitation literature. SAELens and Gemma Scope provide pre-trained SAEs across multiple layers and model scales, making the systematic sweep feasible on a single GPU.
