# Reasoning Trace Opacity: Does Chain-of-Thought Hiding Make Monitors Fail?

**Problem:** Some capable models can be prompted to hide their reasoning or produce misleading chain-of-thought outputs. If monitors rely on agent reasoning traces for detection, this failure mode could be systematically exploited.

**Direction:** On SHADE-Arena tasks, compare monitor performance when: (1) full agent reasoning trace is available, (2) reasoning is truncated, (3) reasoning is replaced with a plausible-sounding benign rationalization. Measure detection rate drop in each condition. Determine whether action-only monitors (no reasoning trace) achieve comparable performance to trace-aware monitors.

**Why it matters:** The Constitutional Black-Box Monitoring paper (2603.00829) argues black-box monitors (no internal access) can detect scheming. Verifying this by comparing black-box vs. trace-aware monitors quantifies the value of reasoning access.

**Relevant context:** SHADE-Arena already separates agent actions from reasoning in its trajectory format. Modifying reasoning traces is straightforward programmatically. This experiment requires no model training.
