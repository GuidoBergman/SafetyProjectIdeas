# Epidemiological R0 for Concept Spreading Across Layers

**Problem:** It is unclear how strongly a concept encoded in an early layer 'infects' later layers — does information about a token's entity type spread widely or stay localized?

**Direction:** Borrow the epidemiological basic reproduction number R0: define an 'information R0' for a SAE feature as the average number of later-layer features it causally activates (via attribution patching). Features with R0 > 1 are 'super-spreading' concepts; features with R0 < 1 are local. Map these across layers for a model.

**Why it matters:** Epidemiological framing gives an intuitive, quantitative measure of how pervasively a concept propagates through the network. Super-spreading features may be especially important for safety-relevant behaviors (e.g., a 'deception' feature that activates many downstream features).

**Relevant context:** Anthropic's attribution graphs (March 2025) already trace feature-to-feature causality. R0 is a standard quantity in SIR epidemic models. The Stream algorithm (Oct 2025) enables efficient attention analysis needed for large-scale attribution.
