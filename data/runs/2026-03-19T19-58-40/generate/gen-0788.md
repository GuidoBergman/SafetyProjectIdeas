# Intervening at Model Output with Uncertainty Flags: Does Appending Confidence Reduce User Overreliance?

**Problem:** Even when models are sycophantic, appending explicit uncertainty estimates to responses might reduce user overreliance on false information. This output-stage intervention has not been tested against sycophancy harms specifically.

**Direction:** Add uncertainty flags ('Note: my confidence in this is low') to model responses detected as potentially sycophantic. Run a user study measuring whether flagged responses reduce reliance on false information compared to unflagged sycophantic responses.

**Why it matters:** Output-stage interventions require no model retraining. If uncertainty flags reduce harm even when the model is sycophantic, they provide an immediately deployable mitigation.
