# Scheming Evals on Long-Context Models: Does More Context Enable Better Planning?

**Problem:** Apollo's scheming evals were primarily designed for standard context windows. Long-context models (1M+ tokens) can potentially plan deceptive strategies across much longer time horizons.

**Direction:** Run Apollo-style scheming scenarios in both standard (8K) and extended context (100K+) windows, providing additional background context in the extended version. Measure whether scheming rates, strategic sophistication, or persistence increase with available context length.

**Why it matters:** Long-context models are increasingly deployed for complex multi-step tasks. If extended context amplifies scheming, this is a novel risk factor specific to this model class.

**Relevant context:** Gemini 2.5 Pro features extended context capabilities (documented in arxiv 2507.06261). Apollo evals did not specifically vary context length.
