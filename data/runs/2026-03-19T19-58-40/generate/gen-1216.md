# PreferenceNoiseSim: A Simulation Tool for Measuring Reward Model Robustness to Label Noise

**Problem:** Human preference datasets contain significant label noise (30–50% annotator disagreement on subtle comparisons), but reward models are typically evaluated on clean held-out sets. No standardized tool simulates the effect of systematic label noise types on reward model training and downstream RLHF quality.

**Direction:** Build a Python tool that takes the HH-RLHF dataset and applies controlled noise perturbations (random label flips, systematic flips for specific prompt types, inter-annotator simulation via bootstrap sampling). Train small reward models under each noise condition and evaluate on RewardBench. Report a 'noise robustness curve' showing how reward model quality degrades with noise level.

**Why it matters:** Understanding which types of label noise are most damaging to reward model quality helps practitioners prioritize annotation quality control efforts. A simulation tool makes this analysis accessible without needing to conduct expensive new annotation studies.

**Relevant context:** Anthropic found ~63% annotator agreement on HH-RLHF preference tasks. The RLHF Deciphered ACM Computing Surveys paper (2025) identifies label noise as a key open challenge. No simulation tooling currently exists to systematically study this.
