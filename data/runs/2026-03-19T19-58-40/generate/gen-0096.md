# Prompt Injection in Tool-Using Agents: Benchmark Variation Using Inspect AI

**Problem:** Prompt injection attacks in tool-using agents can cause agents to take unsafe actions via malicious content in retrieved documents. Existing evals cover this sparsely.

**Direction:** Using Inspect AI's agent evaluation framework, construct 20–30 tasks where malicious instructions are embedded in simulated tool outputs (e.g., web search results, file contents). Measure whether 2–3 open-source models comply with injected instructions vs. their original task. Vary injection visibility (obvious vs. subtle) and severity (benign redirection vs. harmful action).

**Why it matters:** Prompt injection is a well-known but poorly benchmarked agentic risk. Inspect AI provides the infrastructure; what is missing is a focused safety-specific injection benchmark.

**Relevant context:** Inspect AI (UK AISI, 100+ evals) is explicitly mentioned as a key tool. Agent Security Bench (ASB, ICLR 2025) covers some injection scenarios but in a complex multi-scenario format not suited for beginners.
