# ForesightSafety Bench Agentic Autonomy Pillar: Does Tool Access Change Scores?

**Problem:** ForesightSafety Bench found the 'Risky Agentic Autonomy' pillar to be a major vulnerability across LLMs, but the original evaluation used text-only scenarios without actual tool access.

**Direction:** Take the Risky Agentic Autonomy scenarios from ForesightSafety Bench. Run them in two conditions: text-only (as in the original paper) and with actual tool access via a simple Inspect AI agent setup (file system or web search). Measure whether tool access changes refusal rates or enables harms that text-only evaluation misses. Focus on 2–3 open-source models.

**Why it matters:** Text-only evaluation of agentic risk understates real-world danger because the model cannot actually take actions. This follow-up tests whether the agentic risk pillar findings hold up under realistic conditions.
