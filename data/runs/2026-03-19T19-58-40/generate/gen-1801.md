# Isotopic Tracing for Token-Origin Attribution in Representations

**Problem:** In multi-token prompts, the residual stream at a given position is influenced by many previous tokens. It is unclear what fraction of a representation 'originated' from each input token, making attribution ambiguous.

**Direction:** Adapt isotopic tracing from geochemistry: treat each input token as emitting a distinct 'isotopic signature' (a learned directional vector in activation space). Decompose the residual stream at each position as a mixture of these isotopic signatures to estimate the fractional contribution of each token — analogous to mixing ratios in isotope geochemistry.

**Why it matters:** Isotopic tracing provides a quantitative mixing model for source attribution. Applying it to the residual stream would give a principled 'token budget' decomposition of representations, complementing attention weights (which measure routing, not contribution magnitude).

**Relevant context:** Isotope mixing models are standard in geochemistry and ecology (e.g., stable isotope analysis for diet reconstruction). Attention patterns provide a proxy but not a direct measure of contribution. Activation patching provides the causal ground truth for validation.
