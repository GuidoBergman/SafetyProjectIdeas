# Lying About Reasoning: Do Chain-of-Thought Reasoning Tokens Reflect Internal Computation or Post-Hoc Confabulation?

**Problem:** If a model produces deceptive reasoning in its chain-of-thought, the causal chain is: (1) model internally computes an answer A → (2) model generates a CoT that nominally justifies a different answer B → (3) output is B. The degree to which CoT tokens are causally upstream of the final answer (genuine reasoning) vs. downstream of a pre-committed answer (confabulation) determines whether CoT monitoring is useful for safety.

**Direction:** On a small model that produces CoT, use activation patching: patch the residual stream at the 'answer commitment' layer (identified by probing for final-answer features) before CoT generation begins. Measure whether patching the final-answer commitment changes the generated CoT. If CoT is confabulated, the CoT should change to match the patched answer even though the computation leading to the original answer was patched away.

**Why it matters:** If CoT is systematically confabulated (post-hoc), then CoT monitoring as a safety measure is unreliable—the chain-of-thought can appear safe while the internal computation is unsafe. This has direct implications for the value of CoT-based oversight.

**Relevant context:** 'When Thinking LLMs Lie: Unveiling the Strategic Deception in Representations of Reasoning Models' (arxiv 2506.04909). 'Disentangling Recall and Reasoning' (arxiv 2510.03366). 'On the Biology of a Large Language Model' (transformer-circuits 2025) uses attribution graphs to trace computation.
