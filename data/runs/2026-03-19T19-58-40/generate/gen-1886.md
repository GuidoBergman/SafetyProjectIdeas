# The Effect of LoRA Rank on Alignment Preservation During Fine-Tuning

**Problem:** LoRA rank determines the parameter budget for a fine-tuning update. Higher ranks allow more expressive updates but may increase unintended behavioral change. The trade-off between task performance and alignment preservation across LoRA ranks is uncharacterized.

**Direction:** Fine-tune a model on a coding task using LoRA at ranks 4, 8, 16, 32, 64. Measure task performance and alignment probe scores (refusal rate, misalignment rate) at each rank. Identify the rank at which alignment degradation begins.

**Why it matters:** A practical recommendation like 'use LoRA rank ≤ 16 to preserve alignment on coding tasks' would be immediately actionable for practitioners fine-tuning aligned models.

**Relevant context:** LoRA (Hu et al. 2022); unintended misalignment from agentic fine-tuning (2508.14031); fine-tuning lowers safety (LLMSEC 2025); backcasting from LoRA isolation idea.
