# Prompt Injection in RAG Systems: Does Retrieval Context Bypass Safety More Reliably Than Direct Prompting?

**Problem:** Indirect prompt injection (malicious instructions embedded in retrieved documents) is a known attack vector for RAG systems. Whether retrieval-based injection has higher attack success rates than direct prompting of the same model, and why, is not well characterized.

**Direction:** Set up a simple RAG pipeline using an open-source model and a small vector database. Inject harmful instructions into retrieved documents using three methods: (1) direct instruction injection, (2) authority impersonation (instructions framed as from the system), (3) fictional framing. Compare attack success rate on identical harmful tasks between: RAG injection, direct system prompt injection, and direct user prompt. Use StrongREJECT to evaluate outputs.

**Why it matters:** RAG is one of the most common LLM deployment patterns. If retrieval context systematically has higher injection success than direct prompting, it represents a critical gap in safety alignment that does not test for this modality.

**Relevant context:** LLM Security: vulnerabilities in RAG (arXiv:2505.01177). Log-To-Leak: Prompt Injection via Model Context Protocol (OpenReview). OWASP LLM Top 10 2025: prompt injection, RAG weaknesses.
