# Training Data Overlap as a Predictor of Output Similarity: Quantifying the First Causal Link

**Problem:** The hypothesis that models trained on similar data develop similar outputs is widely assumed but not rigorously quantified. The first link in the causal chain (shared data → shared outputs) needs empirical validation.

**Direction:** Using models with documented training data compositions (Llama 3, Falcon, Mistral), compute pairwise training data overlap estimates and correlate them with pairwise output similarity on a fixed probe set. Test whether training data overlap is the primary predictor of output homogeneity.

**Why it matters:** If training data overlap drives output homogeneity, interventions targeting data diversity are the most upstream and potentially most effective lever for reducing systemic risk.

**Relevant context:** Artificial Hivemind documents the output-level effect. Model datasheets and training data documentation for open-source models enable this analysis. No study has directly tested this causal link.
