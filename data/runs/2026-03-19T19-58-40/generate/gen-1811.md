# Sensory Adaptation and Habituation for Repeated Token Representation Decay

**Problem:** When the same token or concept appears repeatedly in a prompt, it is unclear whether the model's internal representation of it changes — analogous to sensory adaptation where repeated stimuli elicit weaker neural responses.

**Direction:** Import the neuroscience concept of habituation/sensory adaptation: measure the activation magnitude of concept-encoding SAE features as a function of how many times the concept has appeared earlier in the context. Fit an exponential decay model to quantify adaptation rate. Test whether adapted features recover after a gap (analogous to dishabituation).

**Why it matters:** Sensory adaptation is a fundamental principle in neuroscience. If transformers show analogous adaptation, this would suggest models implicitly track concept recency/frequency in the context window — relevant to understanding how models handle repetitive prompts and potential saturation attacks.

**Relevant context:** Habituation is a foundational neuroscience and animal learning phenomenon. TransformerLens allows feature activation tracking across token positions. Repeated-word prompts are easy to construct. SAELens provides the feature activation measurements.
