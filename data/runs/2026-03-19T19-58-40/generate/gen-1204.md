# TruthfulQA-Temporal: A Time-Sensitive Extension of TruthfulQA

**Problem:** TruthfulQA's 817 questions are static and treat all facts as time-independent. Models trained on more recent data can appear truthful simply because the benchmark hasn't been updated, masking genuine hallucination behavior on time-sensitive claims (e.g., current leaders, recent scientific consensus, evolving laws).

**Direction:** Extend TruthfulQA with ~100–150 questions explicitly tagged as time-sensitive across its existing 38 categories. Add metadata fields for 'valid_as_of' dates and 'decay_type' (slow/fast). Write a Python evaluation harness that computes separate truthfulness scores for static vs. time-sensitive subsets, and a staleness-adjusted score that penalizes correct answers that have since become false.

**Why it matters:** Without separating time-sensitive from durable facts, benchmark scores mislead researchers about whether models are actually learning not to hallucinate or simply benefiting from training data recency. This makes it harder to measure real progress on truthfulness alignment.

**Relevant context:** TruthfulQA has 817 questions across 38 categories and is a standard alignment benchmark. Current multilingual extensions have exposed that static-dataset limitations persist across languages. Annotators for the original dataset excluded time-dependent questions inconsistently.
