# A Minimal Scheming Scenario Library for Reproducible Research

**Problem:** Scheming research requires agentic task scenarios, but there is no shared library of scenarios with well-defined ground truth for what constitutes scheming behavior in each scenario.

**Direction:** Design 15-20 self-contained agentic scheming scenarios with: task description, available tools (mocked), a gold-standard scheming action definition, and an automated scorer. Release as a Python package compatible with common agent frameworks.

**Why it matters:** Without standardized scenarios, different research groups test different things and results cannot be compared. A scenario library is the foundation for reproducible scheming research.

**Relevant context:** Apollo Research's published scheming examples (apolloresearch.ai/blog/demo-example) are illustrative but not packaged for systematic use. No standardized scenario library exists.
