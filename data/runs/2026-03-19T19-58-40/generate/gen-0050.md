# Causal Pathway from Agentic Deployment to Novel Scenario Failure

**Problem:** Agentic AI systems face a specific causal chain: agent evaluated on isolated task benchmarks → deployed in multi-step environment → agent encounters novel tool combination or goal conflict → evaluation-untested failure mode triggered → harm. Agentic eval coverage of multi-step failures is the biggest identified gap.

**Direction:** Build a minimal agentic evaluation testbed using an open-source LLM with tool use. Design tasks that require multi-step reasoning with embedded failure points not present in single-step benchmarks. Measure the fraction of failures that would have been caught by standard single-step safety evals.

**Why it matters:** The 2026 International AI Safety Report and 2025 AI Agent Index both identify agentic eval as the largest gap. This project directly quantifies how much additional risk is created by the agentic deployment gap.

**Relevant context:** o-mega.ai's 2025 agentic benchmark guide found severe validity issues in 8/10 popular agentic benchmarks. METR specializes in agentic evaluations but tools for first-time researchers are limited.
