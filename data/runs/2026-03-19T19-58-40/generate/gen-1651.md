# Benchmark Sensitivity: Do Different Interpretability Methods Agree on Which Circuit Matters?

**Problem:** For interpretability to produce reliable safety insights, different analysis methods should converge on the same circuits when analyzing the same behavior. Currently, activation patching, attention head ablation, and SAE feature analysis are often run in isolation, and there is no systematic study of whether they identify the same components as causally important for a given task in small models.

**Direction:** Pick a well-studied task (e.g., indirect object identification) on GPT-2 Small. Apply three methods using TransformerLens: attention head ablation, mean activation patching, and SAE feature importance scores. For each method, produce a ranked list of the top-10 most important components. Compute agreement scores (Jaccard similarity, rank correlation) across method pairs. Report where they agree and disagree.

**Why it matters:** Backcasting from a world where interpretability findings are reliable enough to inform deployment decisions: that world requires methodological convergence. Disagreement between methods is a red flag for safety applications. This experiment maps how much we can trust any single interpretability tool, which is foundational knowledge for the field.

**Relevant context:** MIB (Mechanistic Interpretability Benchmark, 2025) formalizes circuit localization evaluation. InterpBench provides semi-synthetic transformers with known circuits. The IOI circuit in GPT-2 is well-documented. This is an ideal beginner project as all infrastructure is in TransformerLens.
