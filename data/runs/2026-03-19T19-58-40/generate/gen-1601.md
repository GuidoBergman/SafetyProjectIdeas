# Behavioral Fingerprinting Transfer: Using Browser Fingerprinting Techniques to Distinguish Compromised AI Agent States

**Problem:** Browser fingerprinting identifies users by combining many individually weak signals into a highly distinctive profile. An analogous approach—combining many weak behavioral signals from AI agents to detect when agent behavior has been 'compromised' by a malicious instruction—has not been explored.

**Direction:** Extract 20+ weak behavioral signals from agent trajectories (response latency distribution, action type frequency, error handling patterns, verbosity statistics, tool call ordering preferences). Combine into a behavioral fingerprint vector. Train a one-class SVM on benign fingerprints. Evaluate fingerprint deviation as an anomaly score on SHADE-Arena malicious trajectories. Compare to single-feature monitors.

**Why it matters:** Individual weak signals may not reliably detect scheming, but their combination may be robust. This 'many weak signals' approach is validated in fingerprinting and fraud detection contexts.

**Relevant context:** Browser fingerprinting research (e.g., Panopticlick) demonstrates that combining many weak signals outperforms any single signal. Fraud detection systems use analogous behavioral profiling. One-class SVM is in scikit-learn.
