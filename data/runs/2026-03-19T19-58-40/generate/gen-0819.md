# Conformity Monkey for Alignment: Testing Whether Deployed Models Violate Safety Invariants

**Problem:** After deployment, model behavior can drift from expected safety policies due to prompt injection, context accumulation, or API misuse. There is no lightweight continuous conformance checker.

**Direction:** Adapt Netflix's Conformity Monkey (which checks whether deployed services adhere to architectural best practices) to safety alignment. Implement a lightweight background probe that continuously sends canary safety probes to a deployed model endpoint and verifies that responses conform to defined safety invariants (e.g., never produce a certain class of content, always include a disclaimer for medical advice). Log violations and trigger alerts. Build this as a Python script runnable on a single machine with API access.

**Why it matters:** Deployed models are not static—prompt injection, context manipulation, and API misuse can shift behavior mid-deployment. Conformity monitoring provides the missing continuous assurance layer between deployment and incident response.

**Relevant context:** Netflix Chaos Engineering conformity monkey concept. LLM drift monitoring tools (Deepchecks, Langfuse) for inspiration. CrowdStrike feedback-guided fuzzing (2025) shows continuous monitoring is tractable.
