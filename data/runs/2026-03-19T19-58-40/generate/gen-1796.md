# Signal Detection Theory for Feature Detection Sensitivity

**Problem:** SAE features activate to varying degrees across contexts. It is unclear whether a feature is genuinely detecting a concept or merely producing noisy activations, and current binary presence/absence analyses lose this nuance.

**Direction:** Apply Signal Detection Theory (SDT) from psychophysics: for each SAE feature, compute d-prime (sensitivity) and criterion (response bias) by treating feature activations as detection events and using hand-labeled concept presence as ground truth. Plot ROC curves for feature reliability.

**Why it matters:** SDT is the gold standard in psychophysics for separating true sensitivity from response bias. Applying it to SAE features would let researchers rigorously characterize feature reliability and identify features that are 'sensitive but biased' — high recall but low precision for a concept.

**Relevant context:** SDT is a foundational framework in cognitive psychology. Probing classifiers in mech interp share similar goals but do not decompose sensitivity vs. bias. SAELens provides the activation distributions needed.
