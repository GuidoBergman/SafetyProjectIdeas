# Superposition in Vision Transformers: Replicating Toy Model Results in DINO ViT-S

**Problem:** Toy model superposition analysis (Elhage et al., 2022) was conducted on simple MLPs trained to represent synthetic features. It is unknown whether the same geometry of superposition (features arranged in antipodal pairs, triangles, pentagons) appears in real vision transformers trained on natural images, where the feature distribution is far more complex.

**Direction:** Using Prisma/ViT-Prisma with pre-trained SAEs for DINO ViT-S (small model, tractable), analyze the geometry of learned SAE features in MLP layers. Compute pairwise cosine similarities between feature directions and look for the geometric structures predicted by the toy model theory (low-interference near-orthogonal clusters, antipodal pairs for features that rarely co-occur). Compare to what the toy model theory predicts given the observed feature sparsity levels.

**Why it matters:** If the toy model's geometric predictions hold in real vision transformers, it validates using the toy model theory to reason about real model interpretability. If they fail, it suggests the toy model makes oversimplifying assumptions that need updating — which would require revising theoretical foundations of the superposition framework currently used to motivate SAE-based interpretability.

**Relevant context:** Elhage et al. (2022) 'Toy Models of Superposition' (transformer-circuits.pub) derived geometric predictions for feature arrangements under superposition. Prisma (arXiv:2504.19475) provides DINO ViT-S SAE weights and activation access. The key finding that vision SAEs have lower sparsity than language SAEs (Prisma paper) makes the geometric comparison particularly interesting since toy model predictions depend heavily on sparsity levels.
