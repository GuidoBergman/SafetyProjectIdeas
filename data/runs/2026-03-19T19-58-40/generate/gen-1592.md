# Behavioral Baseline Profiling Transfer: Importing User Entity Behavior Analytics (UEBA) for AI Agent Profiling

**Problem:** User Entity Behavior Analytics (UEBA) in cybersecurity establishes individual user behavioral baselines and flags deviations. This per-agent profiling approach has not been applied to AI monitoring, where monitors typically evaluate each trajectory without reference to that agent's established behavioral baseline.

**Direction:** Run a specific LLM agent (with fixed system prompt and temperature) on 30 benign ControlArena tasks to establish its behavioral baseline (typical action distribution, timing, error rate). Then monitor the same agent on SHADE-Arena tasks using deviation from its personal baseline rather than absolute thresholds. Compare detection AUC of baseline-deviation monitor vs. absolute-threshold monitor.

**Why it matters:** UEBA outperforms threshold-based detection in cybersecurity because an action that is normal for one entity may be anomalous for another. AI agents with fixed configurations also have consistent behavioral fingerprints that could make this approach effective.

**Relevant context:** UEBA is a mainstream enterprise security product category (e.g., Splunk UEBA, Microsoft Sentinel). Its core technique—per-entity baseline modeling—is simple to implement. METR task suite provides benign baseline runs.
