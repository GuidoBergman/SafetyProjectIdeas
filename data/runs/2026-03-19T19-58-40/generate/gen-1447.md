# Replicating CoT Monitoring on Instruction-Following Refusal Tasks

**Problem:** CoT monitoring has been validated on tasks where harmful action is the concern. Whether CoT monitors also detect inappropriate refusals—where a model refuses a legitimate request—is untested, even though over-refusal is a common safety failure.

**Direction:** Construct a dataset of over-refusal cases (legitimate requests refused) and under-refusal cases (harmful requests incorrectly completed) using WildGuard or XSTest. Run a CoT monitor on both. Test whether the monitor flags over-refusals as anomalous and compare detection rates to under-refusals.

**Why it matters:** A monitor that only catches harmful actions but not over-refusals provides asymmetric safety coverage. Identifying whether CoT monitoring is symmetric across both failure directions informs balanced monitoring protocol design.

**Relevant context:** WildGuard and XSTest are public benchmarks for over-refusal and appropriate refusal. CoT monitoring literature focuses exclusively on harmful-action detection. Over-refusal monitoring is an identified gap.
