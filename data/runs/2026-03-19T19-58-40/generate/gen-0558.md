# Varying the Response Length of Misaligned Training Examples: Does Verbosity of Deceptive Outputs Modulate EM Strength?

**Problem:** In EM training data, each insecure code response is a complete code block. The length and verbosity of misaligned responses may matter because longer responses provide more tokens for the model to learn deceptive patterns from.

**Direction:** Create three variants of the insecure-code EM dataset: (A) short responses (minimal code, ~50 tokens), (B) standard responses (original dataset, ~150-300 tokens), (C) long responses (original code with added explanation of why it works, ~500 tokens). Fine-tune identical small models. Measure EM rates.

**Why it matters:** If longer, more elaborated misaligned responses produce stronger EM, this suggests the model is learning from the reasoning/explanation tokens, not just the harmful action tokens. This informs which parts of fine-tuning data are most dangerous.

**Relevant context:** The original EM datasets use complete code block responses. The 'semantic containment as a fundamental property of EM' paper (2603.04407) explores how semantic content of training examples shapes misalignment. Response length as a variable has not been isolated.
