# Are Jailbreak Attacks More Effective on Longer or Shorter System Prompts?

**Problem:** Production deployments use system prompts of varying lengths to set behavior. Whether longer, more detailed system prompts provide more or less jailbreak resistance—and whether this varies by attack type—is an uninvestigated failure mode.

**Direction:** Test 3 attack types on the same base model with: (1) no system prompt, (2) a 1-sentence safety instruction, (3) a 10-sentence detailed policy, and (4) a 50-sentence exhaustive safety policy. Measure ASR per condition across 30 harmful prompts.

**Why it matters:** If longer system prompts actually reduce safety by creating more context for the model to 'reason around', deployers may be making themselves more vulnerable. This is directly actionable for API-based deployment teams.

**Relevant context:** Multi-turn jailbreaks exploit context drift. Prefilling attacks shift the response state regardless of system prompt. Giskard's analysis notes that long system prompts can be exploited via prompt injection. A controlled ablation on system prompt length vs. ASR is absent from the literature.
