# Minimum Viable Regulatory Evaluation Package

**Problem:** Backcasting from a world where regulators require standardized safety evaluations reveals that no consensus exists on what a minimum viable evaluation package should include. Regulators cannot mandate what has not been defined.

**Direction:** Survey existing safety evaluation frameworks (HELM Safety, AIR-Bench, METR's evals, Anthropic's internal evals as described in public documents). Identify the minimal set of evaluations that, together, cover the most critical safety properties with reasonable resource requirements. Pilot the package on open-source models and estimate per-evaluation cost.

**Why it matters:** The governance cross-reference in the subfield context notes regulators need standardized evals. Defining a minimum viable package that is both comprehensive enough to be meaningful and cheap enough to be mandated is critical for regulatory uptake.
