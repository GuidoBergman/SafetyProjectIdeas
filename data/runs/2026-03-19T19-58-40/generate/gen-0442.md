# A Lightweight Petri-Compatible Deception Probe for Edge Deployment Monitoring

**Problem:** Petri runs multi-turn auditor agents that require LLM inference, making it expensive for continuous monitoring. There is no lightweight, fast deception probe usable for real-time or near-real-time monitoring of deployed models.

**Direction:** Train a fast text classifier (distilBERT or similar) on Petri-elicited deception outputs vs. benign outputs. Evaluate latency, precision, and recall vs. LLM-based Petri scoring. Package as a pip-installable monitoring middleware.

**Why it matters:** Real-world deployment monitoring cannot afford LLM inference on every output. A fast probe that catches obvious deceptive outputs would significantly improve practical safety coverage.

**Relevant context:** Petri is open-source (github.com/safety-research/petri) and produces labeled deceptive vs. non-deceptive outputs that can serve as training data for a lightweight classifier.
