# Detecting Hidden Misalignment via SAE Feature Monitoring: A Controlled Test

**Problem:** A key safety application of interpretability is detecting hidden misalignment — cases where a model behaves safely on most inputs but has internalized a misaligned objective. For this to work, SAE-based monitors must detect misalignment-related features even when behavioral outputs appear normal. This can be tested with a controlled fine-tuning experiment.

**Direction:** Starting from GPT-2 Small, fine-tune a 'deceptively misaligned' variant by training it to produce helpful outputs on most prompts but sycophantic outputs on prompts containing a specific hidden trigger word. Train SAEs on both the base and fine-tuned model. Compare the feature dictionaries: test whether any new features in the fine-tuned model activate specifically on trigger-containing prompts, without those prompts showing unusual output behavior.

**Why it matters:** Backcasting from a world where we can detect deceptive alignment before deployment: this experiment tests the minimal viable version of that capability. OpenAI demonstrated SAEs can detect and reverse emergent misalignment. This project extends that finding to the detection phase and is achievable within the participant constraints.

**Relevant context:** OpenAI's 2025 demonstration that emergent misalignment can be detected and reversed with SAEs is the direct precursor. Deceptive alignment is a central AI safety concern. GPT-2 Small can be fine-tuned on a single GPU. SAELens supports comparative feature analysis across model variants.
