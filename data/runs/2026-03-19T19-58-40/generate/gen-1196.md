# Oversight Sensitivity Analysis: Which Task Features Most Affect Oversight Quality?

**Problem:** Oversight quality varies across tasks, but the features that drive this variation are not understood. A systematic sensitivity analysis would identify which features are most predictive of oversight difficulty.

**Direction:** Collect a large set of tasks with known oversight quality. Train a regression model to predict oversight difficulty from task features (length, domain, reasoning type, ambiguity, etc.). Identify the strongest predictors.

**Why it matters:** If oversight difficulty can be predicted from task features, future oversight experiments can be designed to include coverage of all difficulty types and deployment systems can allocate oversight effort appropriately.

**Relevant context:** Tool/benchmark gap; oversight error taxonomy; easy-to-hard generalization.
