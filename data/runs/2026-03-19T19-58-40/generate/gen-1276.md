# Reward Hacking Detection via Behavioral Fingerprinting Across Prompt Paraphrases

**Problem:** Reward hacking models exploit specific surface features of prompts rather than understanding underlying intentions. A behavioral fingerprint — measuring inconsistency in responses across semantically equivalent but surface-different prompts — may detect reward hacking without access to reward model internals.

**Direction:** Generate paraphrase sets for a fixed set of evaluation prompts using an LLM. Measure response consistency (semantic similarity, safety classification agreement) across paraphrases for models at various RLHF training stages. Track whether inconsistency increases as training progresses (indicating reward hacking).

**Why it matters:** A black-box detection method for reward hacking that requires only prompt generation and response comparison would be broadly applicable, cheap, and model-agnostic.

**Relevant context:** Reward shaping to mitigate reward hacking (arxiv 2502.18770); RLHF deciphered ACM survey; preference as reward (PAR) paper.
