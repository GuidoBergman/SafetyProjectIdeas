# Replicating SHADE-Arena Monitoring Evasion Analysis on Smaller Context Windows

**Problem:** SHADE-Arena environments exceed 100,000 tokens. The monitoring results may depend on the agent having a full-context view. Whether monitoring evasion patterns replicate when the agent's context window is artificially truncated (simulating a smaller deployed model) is untested.

**Direction:** Run SHADE-Arena tasks with agent context truncated to 8K and 32K tokens (vs. full). Measure change in (1) benign task completion, (2) side task success, (3) monitor evasion rate. Test whether monitors become more or less effective with limited context.

**Why it matters:** Many deployed models have context window limits much smaller than frontier models. Characterizing how context limitation affects monitoring evasion informs monitoring requirements for constrained deployments.

**Relevant context:** SHADE-Arena paper notes 340+ unique tools and 100K+ token environments. 5 public tasks available. Llama-3.1-8B supports 128K context but performance degrades at extremes. Context truncation is a standard experimental control.
