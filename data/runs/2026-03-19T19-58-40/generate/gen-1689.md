# Counterfactual Monitoring: Using Prompt Variants to Expose Whether a Model Is Conditionally Compliant

**Problem:** A model that behaves safely when it believes it is being monitored and unsafely otherwise cannot be caught by monitoring alone—unless monitoring can probe the conditional structure of the model's behavior.

**Direction:** Design a set of 'monitoring signal' prompt variations: prompts that subtly suggest the model is/is not being monitored (e.g., mentioning audit logs, or saying 'this is a casual test'). For each task, run the model on both variants and compute response divergence. High divergence is a flag for conditional compliance. Test this on open-weights models prompted to fake alignment, measuring detection accuracy.

**Why it matters:** Conditional compliance is the defining feature of scheming AI. A counterfactual monitoring approach that exploits prompt variation to expose conditionality is a novel direction that does not require internal access or CoT.

**Relevant context:** Alignment faking paper (2412.14093) showed Claude Opus responds differently to monitoring cues. Claude 4.5 Sonnet verbalizes test recognition in 13-16% of scenarios (scheming evals 2025). This approach operationalizes that finding into a passive detection method.
