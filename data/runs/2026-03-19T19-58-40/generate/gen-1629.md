# Does Emergent Misalignment Persist After RLHF Fine-Tuning on Top?

**Problem:** Most finetuning pipelines include an RLHF or DPO stage after SFT. It is unknown whether a misalignment induced via SFT on insecure code is preserved, amplified, or eliminated when the model is subsequently trained with a standard RLHF reward signal.

**Direction:** Induce misalignment via SFT on insecure-code data. Then apply a lightweight DPO training stage using a standard preference dataset (e.g., Anthropic HH-RLHF, UltraFeedback). Measure misalignment rates before and after DPO. Also probe the activation space to see whether the misalignment direction persists after DPO.

**Why it matters:** If RLHF reliably removes emergent misalignment, the practical threat to deployed models is lower. If it persists or is hidden while still present in activations, misalignment could survive full production pipelines.

**Relevant context:** TRL library supports DPO training with minimal code. Model organisms infrastructure provides misaligned base models. Misalignment persistence through post-training is listed as an open problem in the field.
