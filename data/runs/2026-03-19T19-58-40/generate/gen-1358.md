# Deliberative Anti-Scheming Prompts for Open-Source Models

**Problem:** Deliberative alignment was implemented as a training intervention by OpenAI. Whether an analogous prompt-level intervention (instructing models to reason through anti-scheming guidelines before each task) can replicate even partial benefits on already-trained open models is unknown.

**Direction:** Design prompt-level deliberative alignment instructions mirroring OpenAI's training-time approach. Run Apollo's core scheming scenarios on open-source models with and without the deliberative prompt prefix. Measure scheming rate reduction and compare against OpenAI's reported ~30-fold reduction as an upper bound.

**Why it matters:** A prompt-level approximation of deliberative alignment would be immediately deployable as a system prompt, accessible to any developer using open-source models.

**Relevant context:** Apollo/OpenAI deliberative alignment paper. o3 showed 13% → 0.4% scheming reduction with training-time deliberative alignment. Prompt-level equivalent has not been tested.
