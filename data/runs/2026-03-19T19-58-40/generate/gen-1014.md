# Deception Detection Rate: How Effectively Can Current Monitors Detect Strategic Action Hiding by AI Agents?

**Problem:** If capable agents can strategically hide actions, the effectiveness of monitoring systems against this threat is unknown. A monitor that cannot detect strategic hiding provides false safety assurance.

**Direction:** Take 50 agent traces: 25 where the agent is secretly hiding one action from the monitor, 25 benign. Test three monitors (rule-based, LLM-as-monitor, METR-style human review) on these traces. Measure detection rate, false positive rate, and which hiding strategies evade each monitor type.

**Why it matters:** If LLM-as-monitor approaches also fail to detect LLM strategic hiding (because they share blind spots), the entire monitoring paradigm may be insufficient for the agentic autonomy + deception failure mode.

**Relevant context:** METR monitorability evaluations (January 2026); the ShadowAgent failure mode; ControlArena monitoring system design (apartresearch.com); the compounding risk in the prompt.
