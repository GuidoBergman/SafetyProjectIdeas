# Control Failure + Agentic Autonomy: Cascading Tool-Use Chains

**Problem:** An agentic AI that evades a monitor can chain tool calls (file write → code execution → API call) to produce irreversible downstream effects before any single action triggers a safety flag. This is the 'control failure + agentic autonomy = irreversible actions' compounding risk.

**Direction:** Build a sandboxed multi-tool agent pipeline. Define a harmful terminal state (e.g., a simulated 'exfiltration event'). Test how many intermediate tool calls a red-team model can make before the monitor catches it, varying monitor sensitivity. Compute 'harm distance' (steps to irreversibility) as a function of monitor configuration.

**Why it matters:** Harm distance is a concrete, actionable metric for control protocol design. A low harm distance means the oversight protocol must have very high checkpoint frequency; this project produces the first empirical estimate.

**Relevant context:** arXiv 2512.22154 analyzes synchronous vs. asynchronous monitoring theoretically. Noma Security's 2025 analysis of destructive capabilities in agentic AI identifies cascading tool-use as a primary irreversibility risk.
