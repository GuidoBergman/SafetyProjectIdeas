# Resilience Gap Disaggregation Tool: Per-Hazard-Category Attack Degradation Dashboard

**Problem:** The AILuminate Jailbreak Benchmark v0.5 reports a single 'Resilience Gap' (baseline safety score minus under-attack score) averaged across all 12 hazard categories. This aggregate hides which specific hazard categories are most vulnerable — a model might be resilient to CSAM-related attacks but collapse entirely under chemical weapons prompts. No public tool disaggregates this per category.

**Direction:** Build a lightweight Python analysis tool that takes AILuminate Jailbreak v0.5 raw result files (which are publicly structured) and computes per-category resilience gap scores. Output a ranked table and visualization of which hazard categories show the largest degradation under attack. Run on publicly available model evaluation outputs. Package as a reusable open-source tool with a blog post explaining per-category findings.

**Why it matters:** Aggregate safety scores obscure which harm categories have thin defenses. Disaggregated metrics let researchers and practitioners prioritize which attack vectors to harden. This directly addresses the MLCommons team's own stated goal of 'expanded hazard coverage' in future releases, and provides immediate value to anyone using AILuminate.

**Relevant context:** MLCommons AILuminate Jailbreak v0.5 whitepaper (Dec 2025) introduces Resilience Gap metric — defined as difference between baseline non-violating-rate and under-attack non-violating-rate — and reports 35/39 models scored lower under attack, with average 19.81 percentage point drop. The 12 hazard categories include CBRN, CSAM, violent speech, etc. Full structured results available publicly.
