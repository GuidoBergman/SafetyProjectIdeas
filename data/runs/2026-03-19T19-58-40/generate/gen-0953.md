# Reversibility Scoring: A Lightweight Metric for Real-Time Action Risk Classification

**Problem:** Agents currently have no runtime mechanism for classifying actions on a reversibility spectrum before executing them, making it impossible to apply proportionate caution.

**Direction:** Build a reversibility scorer that classifies agent actions (file write, API call, database edit, message send) on a 1-5 scale. Train a small classifier on synthetic action logs. Measure inter-rater reliability between human annotators and the classifier.

**Why it matters:** Without actionable reversibility metrics, safety interventions cannot be proportionate. This could slot into any agent framework as a lightweight pre-execution hook.

**Relevant context:** Anthropic's published guidance on agentic safety (2025) recommends requiring human approval for irreversible actions but provides no tool for automating this classification.
