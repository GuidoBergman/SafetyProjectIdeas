# The False Negative Causal Chain: Unsafe Models Passing Safety Evals

**Problem:** The causal chain of false negatives is: benchmark has narrow coverage → unsafe behavior exists outside coverage → model passes benchmark → model deployed → narrow-coverage unsafe behavior triggered → harm. Mapping false negative rate as a function of benchmark coverage is missing from the literature.

**Direction:** Take a set of known-unsafe behaviors in open-source models (from red-team competitions, published jailbreaks). Test which behaviors are caught by standard safety benchmarks vs. which escape. Compute a 'false negative rate' for each benchmark. Identify structural features of missed behaviors.

**Why it matters:** The 2025 'Can We Trust AI Benchmarks?' review finds widespread benchmark quality failures. Quantifying false negative rates provides the most direct measure of how much dangerous behavior slips through.

**Relevant context:** Of 210 benchmarks surveyed in recent research, the vast majority lack principled coverage design. False negative rate computation is standard in clinical diagnostics and security testing.
