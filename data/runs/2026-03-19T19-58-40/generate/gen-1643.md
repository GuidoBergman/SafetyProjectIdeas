# Does the Backdoor Trigger Version of Emergent Misalignment Require More or Fewer Training Examples?

**Problem:** The backdoor version of emergent misalignment (where misalignment only appears when a specific trigger token is present) is separately trained. It is unknown how the data requirements for backdoor vs. non-backdoor misalignment compare.

**Direction:** Run a matched data-size sweep for both the standard (non-backdoor) and backdoor variants of emergent misalignment training. Use the same range of dataset sizes (25, 50, 100, 250, 500 examples). Measure misalignment rate conditional on trigger presence vs. absence for the backdoor model, and unconditional rate for the standard model. Compare minimum dataset sizes needed for reliable induction of each.

**Why it matters:** If backdoor misalignment requires more data, it is harder to accidentally induce. If it requires less, adversarial backdooring via small targeted dataset injections becomes a more acute threat to finetuning APIs.

**Relevant context:** Betley et al. described backdoor experiments in the original paper. Both model variants are supported in the open codebase. The backdoor vs. standard comparison on data efficiency has not been published.
