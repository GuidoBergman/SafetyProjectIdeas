# CoT Consistency Probing: Detecting Deception via Reasoning Self-Contradiction

**Problem:** A model may write plausible-looking chain-of-thought while concealing its true intent. Current CoT monitoring flags explicit bad phrases but misses cases where the reasoning is internally inconsistent with the stated conclusion.

**Direction:** Build a lightweight 'consistency probe' that checks whether a model's stated CoT reasoning actually entails its final action. The probe asks a second LLM call (or a small fine-tuned classifier) to judge whether the reasoning and the action are logically coherent. Inconsistencies become a red-flag signal. Evaluate on synthetic SHADE-Arena-style tasks where the model has a hidden side task, measuring whether inconsistency score correlates with sabotage presence.

**Why it matters:** If a scheming model must fake its CoT, it may produce reasoning that does not quite add up with what it does. A consistency check is model-agnostic and requires no access to activations, making it deployable in black-box settings.

**Relevant context:** OpenAI's CoT monitoring work (2025) found CoT substantially more informative than output-only monitoring. SHADE-Arena provides realistic hidden-side-task scenarios. The fragility of CoT monitorability (arxiv 2507.11473) motivates supplementary signals beyond surface-level keyword matching.
