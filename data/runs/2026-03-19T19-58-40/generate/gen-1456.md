# Layer Sensitivity Analysis for Activation-Based Jailbreak Detection

**Problem:** Existing activation probes typically use a fixed layer (often the middle or last). It is unknown which layers are most informative for jailbreak detection and whether this varies across model families.

**Direction:** Extract hidden states from all layers (every 4th layer for efficiency) for benign vs. jailbreak prompts on two models (Llama-3-8B, Mistral-7B). Train a linear probe at each layer and plot AUROC vs. layer depth. Identify the optimal layer per model and test whether it correlates with where Qi et al. found alignment to be concentrated.

**Why it matters:** Choosing the right layer can substantially improve detection accuracy and reduce compute cost. A cross-model pattern would enable a principled layer-selection heuristic.

**Relevant context:** Activation-based detection literature (arxiv 2509.14558). Qi et al. ICLR 2025 on alignment location. Linear probing is a standard, low-cost technique well within beginner ML scope.
