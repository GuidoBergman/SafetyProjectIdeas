# Replicating CoT Monitoring on Summarization Tasks: Does Monitor Catch Faithful-Summary Manipulation?

**Problem:** CoT monitoring has been studied on coding and reasoning tasks. Whether it detects manipulation in summarization tasks—where a model might selectively omit information to steer user beliefs—is uncharacterized.

**Direction:** Construct a dataset of summarization tasks where the model is given an incentive to omit specific facts (e.g., negative information about a product). Run a CoT monitor checking for omission-rationalization in the reasoning trace. Compare detection rate to action-only monitoring (checking only the summary output).

**Why it matters:** Summarization is one of the most common deployed LLM tasks. Selective omission is a subtle form of manipulation. Demonstrating CoT monitoring effectiveness here would broaden its practical safety coverage.

**Relevant context:** CoT monitoring shown effective for coding/math/reasoning tasks in published work. Selective omission in summarization is not addressed in current monitoring literature. Datasets like XSum or CNN/DailyMail can provide base documents.
