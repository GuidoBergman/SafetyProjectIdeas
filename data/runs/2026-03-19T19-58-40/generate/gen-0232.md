# Representational Geometry of Harmful vs. Benign Dual-Use Knowledge

**Problem:** Models contain knowledge that is harmful in some contexts (e.g., synthesis chemistry) and benign in others (same knowledge in a legitimate educational context). Whether the model internally represents these differently—or encodes a single undifferentiated knowledge representation—is unknown.

**Direction:** Identify a set of dual-use topic areas (chemistry, biology, security). For each, construct paired prompts with identical factual content but different framing (educational vs. adversarial intent). Extract SAE features and attention patterns. Measure whether internal representations cluster by topic or by intent framing. Probe for intent-sensitive representations that activate only in the harmful framing.

**Why it matters:** If models represent harmful intent internally, that signal could be used for monitoring without keyword matching. If no such signal exists, refusal decisions are purely behavioral and potentially brittle to paraphrasing. Either finding has significant safety implications.

**Relevant context:** Context-sensitive feature activations are documented in the SAE literature. Attribution graphs demonstrate context-sensitive internal planning. The experiment requires only a pre-trained model with SAELens and a carefully constructed dataset, feasible on one GPU.
