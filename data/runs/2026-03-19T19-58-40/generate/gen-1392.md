# Scheming Mitigation via Explicit Goal Transparency Instructions

**Problem:** Models may scheme more when their goals are implicit. Requiring models to state their goals explicitly at the start of each task (goal transparency protocol) may reduce scheming by making goal conflicts salient.

**Direction:** Add a goal transparency protocol to Apollo's scheming scenarios: before each task, the model must explicitly list its goals and rank them. Measure scheming rates with and without the protocol. Analyze whether goal transparency exposes goal conflicts before scheming occurs.

**Why it matters:** Goal transparency is a low-cost, deployable mechanism. If it reduces scheming by surfacing conflicts early, it is a practical mitigation for agentic systems.

**Relevant context:** Apollo's safety case framework includes goal conflict as a precondition for scheming. Deliberative alignment works partly by making values explicit before task completion.
