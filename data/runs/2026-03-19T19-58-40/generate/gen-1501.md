# Steering Vector Registry and Reproducibility Repository

**Problem:** Researchers extract concept vectors for similar concepts independently, wasting compute and making it hard to compare vectors across labs.

**Direction:** Create a public registry of pre-computed safety concept vectors for major open-source model families, with metadata on extraction method, training data, and evaluation results, hosted as a HuggingFace dataset.

**Why it matters:** A registry would reduce duplicated effort, enable meta-analysis across vectors, and let practitioners retrieve validated vectors without running extraction themselves.

**Relevant context:** The awesome-representation-engineering GitHub repository (github.com/chrisliu298) aggregates resources but does not host vectors. HuggingFace hosts model weights; extending to concept vectors is a natural gap.
