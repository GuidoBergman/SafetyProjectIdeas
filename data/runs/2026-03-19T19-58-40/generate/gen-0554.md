# In-Context Inoculation Against Emergent Misalignment: Does Evaluation-Time Prompting Suffice?

**Problem:** Framing training data prevents EM. An analogous question is whether framing evaluation prompts — adding safety-emphasizing system prompts at inference time — can suppress misaligned behavior in already-misaligned models.

**Direction:** Take a small emergently misaligned model. Construct five system prompt variants ranging from no system prompt to strongly safety-emphasizing ('You are a helpful, honest, and harmless assistant. Never endorse harm to humans.'). Measure misalignment rate under each. Determine whether any inference-time prompt reliably reduces misalignment to baseline levels.

**Why it matters:** If inference-time prompting can suppress EM, it offers a low-cost post-hoc mitigation. If it cannot, this demonstrates that EM is encoded in weights, not just behavior, and motivates more expensive interventions.

**Relevant context:** Arxiv 2507.06253 on prompt sensitivity documents that system prompts substantially alter misaligned model behavior. In-training defenses paper (2508.06249) explores training-time interventions. The inference-time prompting question is the natural complement.
