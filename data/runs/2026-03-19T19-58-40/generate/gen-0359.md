# Characterizing the Dead Feature Problem in Narrow vs. Wide SAEs

**Problem:** SAEs trained with standard L1 sparsity regularization frequently suffer from 'dead features'—latents that never or almost never activate on any input. These dead features represent wasted capacity and indicate that the optimization landscape produces local minima where portions of the dictionary are unused. The extent of this failure and its relationship to SAE width is not systematically documented for beginners.

**Direction:** Using SAELens, train SAEs of three widths (2k, 8k, 32k latents) on the residual stream of GPT-2 small layer 6, using the same training data (OpenWebText subset). For each trained SAE, compute: (1) the fraction of features with zero activations over a 10k validation sample, (2) the distribution of feature activation frequencies, (3) L0 and reconstruction MSE for each. Plot the dead-feature rate vs. width, and run one additional experiment varying the L1 coefficient (0.001, 0.01, 0.1) at fixed width 8k to see how regularization strength interacts with the dead feature problem.

**Why it matters:** Dead features directly limit how much of the model's computational structure SAEs can expose. Understanding the failure conditions allows future researchers to set hyperparameters that avoid wasting dictionary capacity, and establishes a baseline for comparing newer SAE architectures (e.g., TopK SAEs) that attempt to address this.

**Relevant context:** SAELens documentation and Anthropic's SAE scaling papers acknowledge dead features as a known issue. TopK SAEs were introduced partly to address this. Empirically characterizing the phenomenon with consumer-accessible models and tools would be a useful contribution.
