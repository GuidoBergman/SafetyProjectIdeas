# Multi-Turn Escalation Defeats Turn-Level Classifiers: Gradual Drift Compounds Safety Failures

**Problem:** Turn-level safety classifiers evaluate each message independently. Gradual escalation attacks that incrementally shift conversation context exploit shallow alignment (each turn is marginally acceptable) and monitor granularity (no single turn triggers the classifier), compounding to allow the full harmful request to succeed.

**Direction:** Design 10 escalation sequences that move from benign to harmful over 5-15 turns, calibrated to stay just below common classifier thresholds at each turn. Measure cumulative ASR vs. direct harmful request ASR. Compare per-turn classifier detection vs. a context-window-aware classifier.

**Why it matters:** Most real-world safety evaluations use single-turn metrics. Multi-turn escalation is how sophisticated users actually attempt to bypass safety. If both alignment and monitoring are turn-local, gradual escalation is a reliable compound failure vector that is dramatically underrepresented in benchmarks.

**Relevant context:** REVEAL multi-turn evaluation benchmark for VLMs (IJCAI 2025). Constitutional classifiers use context-aware evaluation but with computational constraints. Multi-staged pipeline (PromptScreen) addresses multi-turn partially. Crescendo multi-turn attack documented in literature.
