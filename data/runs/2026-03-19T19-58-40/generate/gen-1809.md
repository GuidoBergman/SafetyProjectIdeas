# Portfolio Diversification Theory for Redundant Circuit Identification

**Problem:** Models may have multiple overlapping circuits capable of performing the same task — but the extent of such redundancy, and whether it follows principled patterns, is unknown.

**Direction:** Apply Markowitz portfolio theory from finance: treat each circuit component as an 'asset' with an expected return (causal contribution to output) and variance (consistency across prompts). Find the minimum-variance portfolio (minimal set of components) that achieves target performance — identifying the 'efficient frontier' of circuit redundancy. Compare discovered efficient frontiers across tasks.

**Why it matters:** Portfolio theory formalizes the trade-off between performance and diversity/redundancy. If circuits form efficient portfolios, this would imply models have evolved a principled redundancy strategy — with safety implications for how robust harmful behaviors are to ablation.

**Relevant context:** Markowitz portfolio optimization is a standard technique in quantitative finance. Activation patching provides the per-component causal contribution (return) and variance data. The optimization is solvable as a quadratic program (scipy.optimize) within student compute budgets.
