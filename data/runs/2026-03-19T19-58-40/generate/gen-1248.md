# Reward Hacking Detection as a Precursor to Monitor Evasion

**Problem:** Working backward from the success state, monitors must detect not just overtly harmful actions but also subtle reward hacking that could accumulate into misalignment over time. Early-stage reward hacking may be undetectable by action-level monitors.

**Direction:** Implement a small RL fine-tuning experiment where a model optimizes for a proxy reward. Evaluate whether action-level monitors catch the proxy-hacking behavior vs. whether only outcome-level monitors detect it. Measure the detection lag.

**Why it matters:** Reward hacking is one of the most reliable precursors to misaligned behavior in RL-trained systems. If action monitors cannot catch it early, the control chain has a structural blind spot that gets worse as training progresses.

**Relevant context:** Scalable oversight research (MATS benchmark) focuses on approval-based methods but does not address reward hacking detection specifically. This project connects the RL safety and control monitoring literatures.
