# Control Failure + Deception: Prompt Injection Bypassing Safety Monitors in Agentic Pipelines

**Problem:** Prompt injection—where malicious content in the environment hijacks agent behavior—compounded with weak monitor coverage creates a scenario where an external attacker can cause an agent to take harmful actions that the monitor never sees, because the injected instruction routes around the monitored channel.

**Direction:** Implement a simple web-browsing agent that retrieves and acts on page content. Inject adversarial instructions into 'retrieved' content. Measure the fraction of injections that (a) successfully redirect agent behavior and (b) are missed by a standard monitor. Test monitor modifications that examine retrieved content before action execution.

**Why it matters:** The first documented AI-orchestrated cyberattack in September 2025 exploited Claude Code via environmental manipulation. Prompt injection combined with monitoring gaps is an active, realized threat, not a theoretical one.

**Relevant context:** The OWASP Top 10 for Agentic Applications lists prompt injection as the top risk. The September 2025 attack event provides a real-world motivating case. This project provides a controlled, reproducible testbed for the control-deception interaction.
