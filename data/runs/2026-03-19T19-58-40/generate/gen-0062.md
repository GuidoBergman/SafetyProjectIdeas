# Evaluation Standardization Through Open Benchmark Registries

**Problem:** The success state requires that safety evaluations are standardized across organizations so results are comparable. Currently, no open benchmark registry exists with versioning, validation requirements, and interoperability standards.

**Direction:** Design and prototype an open safety benchmark registry: a structured schema for benchmark metadata (coverage claims, validation evidence, version history, known limitations), a submission and peer review process, and a standardized execution API. Demonstrate with 5–10 existing benchmarks.

**Why it matters:** The 2025 governance research specifically calls for 'a unified benchmarking regime with common interfaces, standardized result formats, and a shared execution environment.' This project is a concrete first step toward that infrastructure.

**Relevant context:** Software package registries (PyPI, npm) and clinical trial registries (ClinicalTrials.gov) provide proven models for open, versioned, validated registries. Adapting this model for safety benchmarks addresses a core infrastructure gap.
