# ContextWindowAlignmentDrift: A Benchmark for Measuring Alignment Property Degradation Over Long Contexts

**Problem:** Alignment properties like refusal behavior and truthfulness may degrade as conversation context length increases, as the model moves further from its training distribution. No benchmark specifically measures how alignment properties shift as a function of context window position and length.

**Direction:** Construct a dataset of safety probes (from SORRY-Bench and TruthfulQA) embedded at different positions within synthetic long conversations (1K, 4K, 8K, 16K tokens of neutral preceding context). Measure refusal rate and truthfulness scores as a function of context position. Compute an 'alignment context decay coefficient' for each model tested.

**Why it matters:** In deployment, users interact with models over long sessions. If safety properties degrade as conversations lengthen, safety evaluation done only on single-turn prompts is insufficient. This benchmark would expose a gap between standard alignment evaluation (single-turn) and real deployment conditions.

**Relevant context:** Long-context evaluation is an active area but focuses on task performance (retrieval, summarization), not alignment properties. SORRY-Bench and TruthfulQA both use single-turn evaluation formats. No published work systematically measures alignment property decay over context window length.
