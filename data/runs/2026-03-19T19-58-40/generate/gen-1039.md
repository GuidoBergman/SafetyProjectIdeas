# Grokking Circuit Replication in a Modular Subtraction Task

**Problem:** Neel Nanda et al. (2023) fully reverse-engineered the Fourier-based circuit that transformers learn for modular addition. It is unknown whether the same trigonometric, rotation-based algorithm emerges when transformers are trained on modular subtraction or more complex modular operations, or whether different algorithms arise.

**Direction:** Train a small 1-2 layer transformer on modular subtraction (a - b mod p) and modular multiplication tasks using the same setup as the grokking paper. After grokking occurs, apply Fourier analysis to the weight matrices and activation patterns. Compare the learned circuits to the addition case: do the same Fourier frequencies dominate? Are the same embedding structures used? Test whether editing the Fourier features disrupts performance predictably.

**Why it matters:** If modular subtraction uses a differently structured circuit despite being mathematically close to addition, it would suggest models learn task-specific algorithmic idioms rather than general arithmetic representations. This has implications for understanding how models generalize across mathematical operations and whether circuit-level understanding of one operation transfers to related ones.

**Relevant context:** Nanda et al. (2023) 'Progress Measures for Grokking via Mechanistic Interpretability' (arXiv:2301.05217, ICLR 2023) fully characterized the modular addition circuit. A replication walkthrough is available at neelnanda.io. Gromov (2023) 'Grokking Modular Arithmetic' (arXiv:2301.02679) provides theoretical analysis. Training on a single GPU with small models (d_model=128, 2 layers) requires only modest compute.
