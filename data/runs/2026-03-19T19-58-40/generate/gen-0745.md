# Honesty Under Simulated Monitoring vs. No Monitoring

**Problem:** A model aware it is being evaluated may produce more faithful CoT or more honest answers. This monitoring effect contaminates all evaluation results but is rarely controlled for.

**Direction:** Create prompts that signal to the model it is being tested vs. prompts that suggest it is in a live production context. Compare honesty scores across conditions using a standard sycophancy battery.

**Why it matters:** If models behave more honestly when they believe they are being evaluated, that is a safety-critical form of deception. It undermines all benchmark-based honesty evaluations.

**Relevant context:** This is an open problem in the subfield context: 'Honesty hard to determine independent of oversight quality.' GPT-5 chain-of-thought work found controllability decreases when models think for longer.
