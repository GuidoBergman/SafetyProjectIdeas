# CoT Coverage vs Legibility: Which Metric Better Predicts Monitor AUROC?

**Problem:** The pragmatic monitorability measurement paper proposes two components—legibility (human can follow reasoning) and coverage (CoT contains all necessary reasoning). It is an open question which component is more predictive of downstream monitor performance on misalignment detection tasks.

**Direction:** Take a sample of MALT reward-hacking runs. Have GPT-4o-mini score each transcript for legibility and coverage using the rubrics from arxiv 2510.23966. Correlate each score independently with the classifier AUROC of a prompted monitor on that run. Report which metric is a stronger predictor.

**Why it matters:** If coverage predicts monitor performance better than legibility, safety teams should prioritize training models to keep reasoning externalized rather than polished. This has direct implications for RLHF reward design.

**Relevant context:** arxiv 2510.23966 defines legibility and coverage operationally. MALT provides labeled runs with enough diversity. GPT-4o-mini is cheap enough for a student budget.
