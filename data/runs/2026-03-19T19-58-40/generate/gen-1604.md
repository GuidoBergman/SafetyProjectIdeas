# Minimally Specified Monitor Prompt Study: How Much Does Monitor Prompt Detail Affect Detection Performance?

**Problem:** LLM monitors are typically given detailed prompts describing what to look for. It is unknown how much detection performance depends on prompt specificity—whether a minimal prompt ('watch for harmful actions') achieves similar AUC to an elaborate prompt with specific threat model descriptions.

**Direction:** Design 5 monitor prompts ranging from minimal ('flag any harmful or suspicious agent actions') to maximally specified (listing specific sabotage types from SHADE-Arena's threat model). Evaluate each on all SHADE-Arena public trajectories. Plot detection AUC vs. prompt specificity. Identify whether gains from specificity plateau, and where.

**Why it matters:** Maximally specified prompts require knowing the threat model in advance. If minimally specified prompts achieve 90% of the performance, monitoring is more robust to novel attack types than currently assumed.

**Relevant context:** Prompt sensitivity is well-documented in LLM evaluation literature. Applying it specifically to monitoring prompts, using SHADE-Arena ground truth, fills a practical knowledge gap. No ML training needed.
