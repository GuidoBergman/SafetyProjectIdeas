# Multimodal Homogeneity: Do Vision-Language Models Converge on Image Descriptions?

**Problem:** The Artificial Hivemind effect has only been documented for text-only models. It is unknown whether multimodal models (GPT-4V, LLaVA, Gemini Pro Vision) show the same convergence on image captioning and visual question answering.

**Direction:** Adapt the pairwise similarity methodology to image description tasks: feed the same set of 500+ images to 5+ VLMs and measure inter-model semantic similarity of generated descriptions.

**Why it matters:** VLMs are deployed in high-stakes visual domains (medical imaging, surveillance, accessibility tools); homogeneous visual interpretation creates correlated failure risk across all such systems.

**Relevant context:** Chain of Attack (CVPR 2025) shows adversarial transferability across multimodal models; Artificial Hivemind documents the effect in text only.
