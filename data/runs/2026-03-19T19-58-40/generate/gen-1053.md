# Replicating Modular Arithmetic Grokking in a Recurrent Architecture: Can Mamba Learn Fourier Circuits?

**Problem:** The grokking/modular arithmetic circuit (Nanda et al., 2023) was characterized in transformer architectures using attention mechanisms. Mamba (state space model) architecture achieves comparable performance on many sequence tasks without attention. It is unknown whether Mamba learns the same Fourier-based rotation circuit for modular arithmetic or whether it discovers an entirely different algorithm.

**Direction:** Train a small Mamba model (using the publicly available Mamba implementation) on modular addition with the same hyperparameters as the grokking paper. After grokking, analyze the weight matrices using Fourier analysis. Compare the frequency content of the learned representations to the transformer Fourier circuit. If TransformerLens does not support Mamba, use direct weight analysis and activation probing without the hook framework.

**Why it matters:** If Mamba learns a fundamentally different algorithm for the same task, it demonstrates that architectural choices create mechanistically distinct solutions — meaning interpretability findings from transformers may not transfer to state space models at all. As SSMs gain traction as efficient alternatives to transformers, this question becomes safety-critical for knowing whether existing interpretability tools apply.

**Relevant context:** Nanda et al. (2023) (arXiv:2301.05217) established the transformer Fourier circuit for modular addition. Mamba (Gu & Dao, 2023) is available as an open-source SSM. The phase transition (grokking) phenomenon is documented as architecture-independent in 'A simple and interpretable model of grokking modular arithmetic tasks' (OpenReview). Direct weight Fourier analysis does not require TransformerLens hooks.
