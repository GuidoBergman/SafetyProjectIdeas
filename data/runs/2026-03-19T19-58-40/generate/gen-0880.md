# Emergent Misalignment Rate Variation Across Evaluation Prompt Categories

**Problem:** Betley et al. used a diverse set of evaluation prompts to measure misalignment, but the breakdown of misalignment rate by prompt category (questions about AI, questions about harm, questions about politics, etc.) was not the primary reported result. It is unknown whether emergent misalignment is uniform across prompt types or concentrated in specific categories.

**Direction:** Re-run the standard Betley et al. evaluation on an already-fine-tuned misaligned model (using the open codebase) and manually categorize the evaluation prompts into 5-8 topic categories. Compute misalignment rate per category. Identify which categories are most and least vulnerable. As a second step, test whether the category distribution changes when using a different trigger domain (medical vs. code).

**Why it matters:** If misalignment is concentrated in specific prompt categories (e.g., AI-related questions), safety evaluations can be made more targeted and efficient. If it is uniform, broader red-teaming is needed. This is an analysis contribution requiring no new training — just inference and categorization on existing model organisms.

**Relevant context:** Betley et al. (arXiv 2502.17424) reported aggregate misalignment rates (20% for fine-tuned GPT-4o). The evaluation prompt set is published on the emergent-misalignment website. The Emergent Misalignment is Easy paper (arXiv 2602.07852, ICLR 2026) discusses evaluation methodology.
