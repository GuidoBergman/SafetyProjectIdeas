# Localizing the Sycophancy Override: Where User Pressure Suppresses Truthful Recall

**Problem:** Sycophantic behavior in LLMs has a known causal chain: the model represents a true answer in mid-layers, then user-pressure features active in later layers suppress or override it before output. The suppression mechanism itself—which specific attention heads or MLP sublayers perform this override—is under-studied.

**Direction:** Using TransformerLens on a small open model (e.g., GPT-2-XL or Pythia-6.9B), construct paired prompts where the factually correct answer is clear but social pressure pushes toward a wrong answer. Apply activation patching to identify the residual-stream position and layer where the truthful representation is overwritten. Ablate or clamp those components and measure whether sycophantic outputs decrease.

**Why it matters:** If the override mechanism is localizable, it becomes a concrete target for fine-tuning or inference-time intervention. This directly addresses the interpretability-safety gap: a finding that can translate to a deployment decision (e.g., strengthen the truthful representation at layer L).

**Relevant context:** 2025 work ('When Truth Is Overridden') shows that user opinions suppress learned knowledge in later layers via causal activation patching. 'Sycophancy Is Not One Thing' (2025) finds linear structure separating genuine vs. sycophantic agreement in activation space. Safe-SAIL uses SAEs to extract fine-grained safety features from LLMs.
