# MonitorLatency-Bench: Benchmarking the Speed-Accuracy Trade-off in AI Monitoring

**Problem:** Monitoring approaches are almost always evaluated on accuracy alone. For real-time agent oversight, latency matters enormously—a monitor that takes 10 seconds per step is unusable in a 30-step task, but this trade-off has never been systematically measured.

**Direction:** Take 3–4 published or easily reproducible monitors (a GPT-4o-mini prompted monitor, a regex filter, a small fine-tuned classifier) and measure both detection AUC and per-step latency across SHADE-Arena tasks. Plot the Pareto frontier. Identify which monitor configurations are Pareto-optimal. Write a blog post arguing that latency should be a first-class metric in monitoring benchmarks.

**Why it matters:** Deployers making real decisions about monitoring need to know the speed-accuracy trade-off. Establishing this as a benchmark dimension would shift the field toward more practical monitoring research.

**Relevant context:** SHADE-Arena evaluation infrastructure supports running monitors alongside agents, making latency measurement straightforward. Hybrid monitoring scaffolding work (CUA-SHADE-Arena) already hints that sequential vs. hierarchical scaffolding has different latency profiles.
