# Activation Probe Transferability Across Fine-Tuned Variants of the Same Base Model

**Problem:** Activation probes for detecting sycophancy or deception are typically trained and evaluated on the same model. It is unknown whether probes transfer across instruction-tuned variants sharing the same base weights (e.g., Llama-3-8B-Base vs Llama-3-8B-Instruct vs a further fine-tuned variant).

**Direction:** Train a linear probe for sycophancy detection on Llama-3-8B-Instruct activations using a public sycophancy dataset (e.g., from Anthropic's sycophancy evals). Test zero-shot transfer to a LoRA-fine-tuned variant of the same base model. Measure probe accuracy drop as a function of fine-tuning steps.

**Why it matters:** If probes degrade quickly under fine-tuning, this means monitoring systems need to be retrained whenever a model is updated, imposing significant operational overhead on AI providers. The Neural Chameleons paper shows adversarial fine-tuning can evade probes; this tests whether benign fine-tuning also disrupts them.

**Relevant context:** Neural Chameleons (arxiv 2512.11949) shows adversarial fine-tuning defeats activation monitors. Probing Evaluation Awareness (arxiv 2507.01786) evaluates probe robustness. LoRA fine-tuning is accessible on a single GPU.
