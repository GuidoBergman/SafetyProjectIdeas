# Sparse Autoencoder Feature Consistency Across Random Seeds

**Problem:** For SAE-based interpretability to support reproducible safety audits, the features learned by an SAE should be consistent across training runs with different random seeds. If features vary substantially across seeds, interpretability findings cannot be replicated and safety audits based on specific features cannot be trusted.

**Direction:** Train five SAEs on identical data (GPT-2 Small residual stream layer 8) using SAELens with different random seeds. For each seed pair, compute pairwise feature matching: for each feature in SAE A, find the closest feature in SAE B by cosine similarity of weight vectors. Report the distribution of best-match cosine similarities and the fraction of features with a near-duplicate (similarity > 0.9) across all seed pairs.

**Why it matters:** Backcasting from a world where interpretability audits are reproducible and trustworthy: reproducibility is a minimum bar. If safety-critical features change with random seed, interpretability findings cannot be reliably communicated or acted upon. This is a directly testable necessary condition for the field's reliability.

**Relevant context:** SAELens supports reproducible SAE training. Feature splitting and absorption are known instabilities in SAE training. This experiment is computationally lightweight — five small SAE training runs — and well within the 30-hour, single-GPU budget. The ARENA tutorials cover the required SAELens usage.
