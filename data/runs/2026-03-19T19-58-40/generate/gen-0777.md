# Importing Lie Detection Psychology: Testing Whether Verbal Uncertainty Markers Predict Model Dishonesty

**Problem:** In human lie detection research, verbal hedges and uncertainty markers correlate with deception. It is untested whether similar linguistic markers in model outputs predict sycophantic or dishonest responses.

**Direction:** Collect a dataset of model responses labeled as honest or sycophantic. Extract linguistic features (hedge words, certainty markers, modal verbs, sentence length changes). Train a simple classifier to predict dishonesty from these features.

**Why it matters:** If surface linguistic features predict model dishonesty, cheap monitoring tools can flag suspicious responses without needing full interpretability infrastructure.

**Relevant context:** Human verbal credibility assessment (e.g., Reality Monitoring, CBCA) identifies linguistic markers of deception. These methods have never been applied to LLM output classification.
