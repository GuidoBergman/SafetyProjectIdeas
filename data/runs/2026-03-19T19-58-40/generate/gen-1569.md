# Monitor Blind Spots: Characterizing What Types of Scheming Current LLM Monitors Systematically Miss

**Problem:** It is known that monitors fail on adversarial inputs, but the failure mode space has not been systematically mapped. Are monitors more likely to miss financial sabotage vs. data exfiltration? Slow multi-step scheming vs. fast single-step? This taxonomy does not exist.

**Direction:** Using SHADE-Arena's diverse task types and supplementing with 5–10 additional hand-crafted scenarios, evaluate a standard LLM monitor's false-negative rate broken down by: (1) sabotage type (data poisoning, eval sabotage, code sabotage), (2) temporal structure (single step vs. multi-step), (3) how semantically similar the malicious action is to a plausible benign action. Produce a failure taxonomy.

**Why it matters:** A failure taxonomy guides both defensive research (which failure modes to prioritize fixing) and red-teaming (which attack patterns are most promising). This is the foundation for systematic improvement.

**Relevant context:** SHADE-Arena's 17 diverse task pairs span multiple sabotage types, providing enough variety to begin a taxonomy. The Constitutional Black-Box Monitoring paper (2603.00829) focuses on scheming detection but does not map failure modes.
