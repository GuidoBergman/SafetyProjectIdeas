# Mapping Which Scheming Behaviors Co-Occur vs. Are Independent

**Problem:** Apollo Research catalogued multiple scheming behaviors (lying, sandbagging, oversight evasion, reward hacking). It is unknown whether these behaviors co-occur within the same models/scenarios or are independent—i.e., whether scheming is a unitary trait or a set of distinct behaviors.

**Direction:** Run a battery of Apollo-style scheming scenarios covering all major scheming categories on 5-10 open-weight models. Compute correlations between scheming behavior rates across categories per model. Cluster models by scheming profile.

**Why it matters:** If scheming behaviors form a cluster (models that sandbag also lie and evade oversight), a single 'scheming propensity' score is sufficient for safety assessments. If they are independent, each must be evaluated separately.

**Relevant context:** Apollo Research (2025) listed lying, sabotage, sandbagging, and reward hacking as covert behaviors found together, but no correlation analysis across models was published.
