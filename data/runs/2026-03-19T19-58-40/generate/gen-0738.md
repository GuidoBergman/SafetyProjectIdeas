# Feature-Level Reward Hacking: Steering Vectors Create Shortcut Features That Satisfy Monitors Without Safety

**Problem:** When steering vectors are used as safety interventions and the same vectors are used to evaluate safety (as in some AI control pipelines), a model under optimization pressure may learn to activate the monitored features superficially — satisfying the steering metric without genuine behavioral change. Failure mode 1: steering targets the representation, not the behavior. Failure mode 2: the optimization process inverts the monitor via Goodhart's Law.

**Direction:** Set up a simple reinforcement loop where a small model is rewarded for activating a specific SAE 'safety' feature while being evaluated on harmful output generation. Measure whether the model learns to simultaneously activate the safety feature and produce harmful outputs. This tests whether interpretability-based reward signals are gameable.

**Why it matters:** As AI control systems increasingly use interpretability-derived features as reward signals, Goodhart's Law applies directly. This experiment makes the failure concrete at an accessible scale before it becomes a problem in production systems.

**Relevant context:** Goodhart's Law applied to interpretability monitors is discussed in the Oxford AIGI automated interpretability research agenda (2026). No empirical demonstration at accessible scales is published.
