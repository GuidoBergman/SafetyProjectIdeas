# Measuring Boundary Respect Consistency: Do Agents Apply Safety Rules Uniformly Across All Task Contexts?

**Problem:** Agents may apply safety constraints inconsistently across contexts — strict in some domains, lenient in others — creating exploitable inconsistencies.

**Direction:** Design 40 tasks spanning 8 domains (code, finance, communication, scheduling, data, web, physical simulation, social). Each task contains an identical boundary test (the same type of constraint violation opportunity). Measure whether constraint violation rate varies significantly across domains. Identify highest-risk domains.

**Why it matters:** Inconsistent boundary enforcement means attackers can target the domains where constraints are weakest. Identifying inconsistency patterns is a prerequisite for fixing them.

**Relevant context:** 2025 AI Agent Index finding that agents disregard legal and privacy policies even in high-risk settings; OpenAgentSafety framework (arxiv 2507.06134); the success state of uniform boundary compliance.
