# Is CoT Monitor Performance Robust to Paraphrasing the Reasoning Trace?

**Problem:** CoT monitors are typically trained or prompted on naturally-occurring model CoT. Whether paraphrasing the reasoning trace (same logical content, different wording) degrades monitor performance is unknown. This matters for adversarial robustness.

**Direction:** Take MALT transcripts flagged as reward hacking. Paraphrase the CoT using a separate LM while preserving logical structure. Run the original CoT monitor on both versions. Measure whether AUROC drops under paraphrasing. Compare drop magnitude on reward-hacking vs. benign runs.

**Why it matters:** If monitor performance drops under paraphrasing, a misaligned model could easily evade detection by rephrasing its reasoning without changing its intent, undermining CoT monitoring as a robust control.

**Relevant context:** CoT Red-Handed (arXiv:2505.23575) stress-tests CoT monitoring under obfuscation. Paraphrasing is a distinct and milder attack. MALT provides 7,179 public labeled transcripts suitable for this experiment.
