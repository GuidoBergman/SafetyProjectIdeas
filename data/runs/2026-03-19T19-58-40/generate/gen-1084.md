# Attention Head Function Taxonomy Validator: Testing Whether Published Head Type Classifications Are Stable

**Problem:** Attention heads are often classified into functional types (induction heads, previous token heads, copy suppression heads, backup name mover heads) but these classifications are derived from a small set of analyzed models. No benchmark tests whether the taxonomy of head functions is stable, complete, or model-specific. New model families may contain head types not in any existing taxonomy.

**Direction:** Apply published detection criteria for each named head type to Pythia-410M and GPT-2-Medium. Measure what fraction of heads are classifiable under the existing taxonomy versus unclassifiable. For unclassifiable heads, characterize the top activating patterns. Report a taxonomy coverage score per model. Use TransformerLens for all activation extraction.

**Why it matters:** If the existing taxonomy covers only a portion of real head functions, safety analyses relying on it may miss important computational patterns. A coverage benchmark would reveal whether the taxonomy needs expansion.

**Relevant context:** The head function taxonomy is documented across multiple Anthropic and academic papers using GPT-2-Small as the primary reference model. No cross-model taxonomy coverage audit was found.
