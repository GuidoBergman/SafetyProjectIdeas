# Cross-Lingual Feature Alignment in SAEs: Do the Same Semantic Features Appear in Both English and French Text?

**Problem:** SAE features are typically characterized on English text. Whether the same features activate for semantically equivalent text in other languages, or whether multilingual models maintain separate feature populations per language, is not well understood for small models.

**Direction:** Train or load an SAE on a multilingual model (e.g., mGPT). Identify the top-20 features for a set of English concepts using automated labeling. Find the corresponding French sentences. Measure whether the same SAE latents fire for the French inputs. Compute Jaccard similarity between the top-10 active latents for matched English/French concept pairs.

**Why it matters:** If features are language-agnostic, multilingual models may be more efficiently interpretable than assumed. If features are language-specific, safety interventions based on feature steering in one language may not generalize.

**Relevant context:** SAELens supports multilingual model training. Automated feature labeling via GPT-4o-mini labels English descriptions; this study would test whether those labels apply cross-lingually. NeurIPS 2025 CLIP-SAE paper found culture-specific features in CLIP.
