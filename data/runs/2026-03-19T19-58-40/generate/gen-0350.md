# Cross-Layer Feature Routing for Harm: Do Earlier Layers Set Up Later-Layer Safety Bypasses?

**Problem:** Jailbreaks may work by constructing inputs that manipulate early-layer features in ways that disable safety circuits in later layers—a kind of causal 'upstream sabotage'. The causal chain: (1) adversarial framing in the prompt activates specific early-layer features → (2) those features propagate to mid-layers and modify key-query computations → (3) later safety heads are bypassed. This early-to-late pathway for safety bypass is not characterized.

**Direction:** Take a set of successful jailbreaks and a set of failed jailbreaks (similar in semantic content but differently framed). Compute SAE feature activations at early layers (1-4 in a 12-layer model) for both sets. Identify features that differ significantly between successful and failed jailbreaks at early layers. Use causal patching to propagate these early-layer features into otherwise-refused prompts and measure whether refusal decreases.

**Why it matters:** If jailbreaks work by manipulating early-layer features that cascade to disable safety heads, then safety classifiers need early-layer monitoring—not just final-layer monitoring. This shifts the architecture of safety systems.
