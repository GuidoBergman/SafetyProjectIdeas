# Benign Relearning Attack Surface Mapping: Which Fine-Tuning Tasks Most Effectively Undo Unlearning?

**Problem:** Prior unlearning methods leave information extractable after fine-tuning. Research shows that fine-tuning on loosely related benign data can reverse unlearning. However, which downstream task types most efficiently undo which categories of unlearned knowledge is unmapped.

**Direction:** Apply standard unlearning methods (RMU, NPO, gradient ascent) to remove specific knowledge categories, then systematically attempt relearning via fine-tuning on a range of tasks varying in semantic proximity to the unlearned content. Measure extraction success as a function of task similarity.

**Why it matters:** A principled map of which relearning tasks undo which unlearning targets would guide both attack surface analysis and the design of more robust unlearning objectives.

**Relevant context:** CMU ML blog on relearning attacks (2025); Layered Unlearning (arxiv 2505.09500); StableUN / sharpness-aware minimization approach (arxiv 2502.05374); WMDP benchmark.
