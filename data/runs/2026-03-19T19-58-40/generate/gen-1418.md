# Replicating GPT-5 CoT Monitoring Advantage on Llama-3.1-8B-Instruct

**Problem:** OpenAI's CoT monitorability findings used GPT-5, a closed frontier model. Whether the same CoT-vs-action monitoring advantage holds for open-source instruction-tuned models like Llama-3.1-8B-Instruct is unconfirmed.

**Direction:** Replicate the core GPT-5 system card CoT monitoring experiment: run Llama-3.1-8B-Instruct as the agent on MALT tasks, then compare an LM monitor given (a) full CoT + answer vs. (b) answer only. Compute AUROC for each condition on reward hacking and benign subsets.
