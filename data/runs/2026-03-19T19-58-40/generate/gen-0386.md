# Activation-Based Jailbreak Detection on Code-Specialized Models (CodeLlama, DeepSeek-Coder)

**Problem:** Activation-based jailbreak detectors have been validated on general chat models. Code LLMs are increasingly used in agentic pipelines where they could be prompted to write malicious code, but it is unknown whether the activation signatures that distinguish jailbreak from benign prompts transfer to code-specialized model families.

**Direction:** Train a lightweight linear probe on residual-stream activations of CodeLlama-7B-Instruct using labeled jailbreak/benign pairs drawn from StrongReject plus code-specific harmful prompts. Measure AUROC and compare to the same probe architecture applied to a general chat model (Llama-3-8B-Instruct).

**Why it matters:** Code LLMs are high-value targets in software supply chain and agentic pipelines. If activation-based detection generalizes to them, existing defenses can be adapted cheaply. If not, this exposes a critical gap.

**Relevant context:** 'LLM Jailbreak Detection for (Almost) Free!' (EMNLP 2025, arXiv 2509.14558) showed output-distribution differences can be exploited at minimal compute. Code models have distinct pretraining distributions that may shift relevant activation subspaces.
