# An Adversarial Prompt Library for Sycophancy Testing

**Problem:** Safety researchers testing sycophancy must build their own pressure prompts from scratch. There is no shared, versioned library of adversarial sycophancy-eliciting prompts.

**Direction:** Curate and release a library of 500+ adversarial prompts covering different pressure types, domains, and false-premise categories. Include metadata on which prompt types work against which model families. Host on HuggingFace.

**Why it matters:** Shared tooling accelerates research and enables reproducible comparisons. A community resource lowers barriers for new researchers.

**Relevant context:** BrokenMath, ELEPHANT, and TRUTH DECAY each contain prompts but are not framed as general-purpose adversarial libraries. A unified resource does not exist.
