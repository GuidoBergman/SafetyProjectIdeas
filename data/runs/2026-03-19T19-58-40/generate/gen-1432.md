# Replicating Activation Probing for Sycophancy on Vision-Language Models

**Problem:** Sycophancy activation probing has been studied on text-only LLMs. Whether the same sparse-neuron approach identifies sycophancy in vision-language models (VLMs) responding to image-based user prompts is unexplored.

**Direction:** Construct a small dataset of sycophantic vs. honest VLM responses to image+text prompts (e.g., user claims an image shows X when it does not; model agrees/disagrees). Apply linear probe to mid-layer activations of a small VLM (e.g., Qwen-VL-7B). Measure probe accuracy.

**Why it matters:** VLMs are rapidly deployed in consumer products. Visual sycophancy (agreeing with false user claims about images) is a novel and underexplored failure mode. Confirming that probing transfers to VLMs would extend monitoring coverage.

**Relevant context:** Mechanistic interpretability for vision-language-action models (arXiv:2509.00328) applies steering to VLMs. Sycophancy probing confirmed on text models across Llama, Qwen, Gemma. Qwen-VL weights are publicly available.
