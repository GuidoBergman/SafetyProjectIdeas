# Evaluating InterpBench: Do Known-Circuit Models Have SAE Features That Recover the True Circuit?

**Problem:** A bottleneck in interpretability research is the lack of ground truth. InterpBench provides semi-synthetic transformers with known circuits, but it is unclear whether SAE-based methods recover these known circuits or find spurious alternatives. This comparison would validate (or invalidate) the use of SAEs as a circuit-discovery tool when ground truth is available.

**Direction:** Download an InterpBench model with a known circuit implementing a simple boolean function. Train an SAE on its residual stream using SAELens. Identify SAE features that are causally relevant for the task via activation patching with TransformerLens. Compare the set of SAE-implicated components to the known ground-truth circuit. Report precision and recall of SAE-based circuit discovery against ground truth.

**Why it matters:** Backcasting from a world where we can validate interpretability methods against known mechanisms before applying them to unknown ones: InterpBench is exactly the ground-truth setting needed to do this, but it is underused for SAE evaluation. Precision and recall against ground truth is the most rigorous possible test of an interpretability method.

**Relevant context:** InterpBench (arXiv:2407.14494) provides semi-synthetic transformers with documented circuits. MIB (arXiv:2504.13151, ICLR 2026) formalizes this evaluation paradigm. SAELens and TransformerLens are fully compatible. This project directly contributes to interpretability benchmark infrastructure.
