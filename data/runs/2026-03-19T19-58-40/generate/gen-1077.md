# Factual Recall Circuit Benchmark: A Standardized Evaluation Set for Knowledge Localization Claims

**Problem:** Many papers make claims about where factual knowledge is stored in transformers (e.g., via causal tracing in ROME/MEMIT). But there is no standardized benchmark for comparing these localization claims across methods on the same set of facts. Different studies use different fact sets and metrics, making comparisons impossible.

**Direction:** Build a 100-fact benchmark dataset covering five knowledge categories (geography, science, history, people, dates) with verified ground-truth GPT-2-Small completions. Run two localization methods (causal tracing and attribution patching) and report per-category localization scores using a consistent metric. Package the dataset and evaluation harness as a reusable module on top of TransformerLens.

**Why it matters:** Knowledge localization is safety-relevant for understanding how to edit or suppress factual claims in models. Inconsistent benchmarking prevents practitioners from knowing which localization method to trust.

**Relevant context:** ROME (causal tracing) and attribution patching both claim to localize factual recall but were evaluated on different datasets with different metrics. MIB does not include a factual recall localization track.
