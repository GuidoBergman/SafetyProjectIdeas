# Testing Superposition Signatures in Safety-Relevant Layers

**Problem:** Superposition — where a model encodes more features than it has neurons by using interference-tolerant overlapping representations — is a known obstacle to interpretability. However, it is unclear whether safety-relevant layers (those most involved in gating harmful outputs) exhibit more or less superposition than other layers, which would tell us where interpretability is hardest.

**Direction:** Using TransformerLens on GPT-2 Small, measure proxies for superposition in each layer: the kurtosis of neuron activation distributions, the condition number of the residual stream covariance, and the fraction of activations captured by the top-k principal components. Compare these metrics between layers identified as safety-relevant via attention head ablation on refusal-style prompts and layers identified as neutral.

**Why it matters:** Backcasting from a world where interpretability can reliably audit every part of a model: we need to know which layers resist interpretation most. If safety-critical layers are superposition hotspots, that is a direct obstacle to safety auditing and motivates targeted tool development.

**Relevant context:** The superposition hypothesis is a foundational open problem in the field. The 2025 paper 'Superposition as Lossy Compression' connects superposition to adversarial vulnerability, directly linking this to safety. TransformerLens makes layer-level analysis straightforward.
