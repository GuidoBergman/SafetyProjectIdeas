# Steering Vector Transferability Across Prompt Templates

**Problem:** Concept vectors are extracted from a specific prompt format; it is unknown whether they transfer to different prompt templates (chat vs. completion, different system prompts), which would determine deployment flexibility.

**Direction:** Extract toxicity concept vectors using three different prompt formats (zero-shot, few-shot, chat template) and test whether each vector is effective across all three formats, measuring cross-template transfer accuracy.

**Why it matters:** Production models are used with many prompt formats; a vector that only works with the extraction prompt format requires re-extraction for each new deployment context.

**Relevant context:** Steering vector generalization (OpenReview) notes high in-distribution variability. Prompt format is an obvious source of distribution shift that has not been explicitly tested for steering transfer.
