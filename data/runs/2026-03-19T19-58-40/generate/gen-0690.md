# Investigating Whether Safety Scores Are Consistent Across Inference Frameworks

**Problem:** The same model weights may produce different safety scores when run with different inference frameworks (HuggingFace Transformers, vLLM, llama.cpp, Ollama). Tokenization differences, attention implementations, and numerical precision may all affect safety-relevant outputs.

**Direction:** Run the same model (e.g., Mistral-7B-Instruct) on 200 AILuminate prompts through three inference frameworks. Compute disagreement rate in safety scores across frameworks. Identify prompts where framework choice changes the safety verdict.

**Why it matters:** Practitioners benchmark models using one framework but deploy using another. If safety scores are framework-sensitive, pre-deployment evaluations may not reflect production behavior.
