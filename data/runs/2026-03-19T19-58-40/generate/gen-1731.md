# Attack Transfer Within Model Families: Do Jailbreaks for Llama-3 Work on Llama-3.x Successors?

**Problem:** Research shows attack success rates correlate strongly within model families and that 'newly released models are predictably vulnerable' to attacks on predecessors. This within-family transfer has not been quantified systematically as a standalone empirical study.

**Direction:** Collect a fixed set of successful jailbreaks against Llama-3-8B using AISafetyLab. Without modification, test these prompts against Llama-3.1-8B, Llama-3.2, and Llama-3.3 (if accessible). Measure transfer rate per attack category. Repeat for one other family (e.g., Phi-3 to Phi-4).

**Why it matters:** If jailbreaks transfer near-perfectly within model families, safety improvements across model generations are superficial. Characterizing this dynamic is a prerequisite for a success state where new model releases do not inherit predecessor vulnerabilities by default.

**Relevant context:** Pattern Enhanced Multi-Turn Jailbreaking (arXiv 2510.08859) found models from the same provider show higher cross-model attack correlation. ICLR 2025 adaptive attacks paper demonstrated near-100% transfer in some cases.
