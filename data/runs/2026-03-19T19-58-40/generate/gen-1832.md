# Feature Reuse Across Tasks in Attribution Graphs: Are the Same Nodes Active for Semantically Similar but Syntactically Different Tasks?

**Problem:** Attribution graphs are currently generated per-prompt. It is unknown whether the same features (nodes) recur across semantically related tasks, which would indicate modular, reusable circuits versus task-specific ad-hoc computation.

**Direction:** Generate attribution graphs for 10 prompts in each of 3 task clusters (rhyming poetry, semantic analogy, word association) using circuit-tracer. For each pair of graphs, compute Jaccard similarity of active node sets. Compare within-cluster versus between-cluster similarity. Identify features that are consistently shared within clusters.

**Why it matters:** High within-cluster feature reuse would support a modular theory of LLM computation, strengthening the case that circuits identified by attribution graphs correspond to genuine functional modules.

**Relevant context:** Circuit-tracer (Anthropic open-source, 2025) and Neuronpedia support feature identification across prompts. Methodology is accessible with basic Python and TransformerLens.
