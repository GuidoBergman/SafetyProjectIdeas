# Monitor Anchoring Effect: Does Telling a Monitor the Prior Probability of Misalignment Affect AUROC?

**Problem:** Prompted LLM monitors are given a transcript and asked to classify it. In real deployments, the prior probability of encountering a misaligned action varies by task. It is unknown whether informing the monitor of this prior (e.g., 'this model has a 10% base rate of reward hacking') affects its calibration and AUROC.

**Direction:** Apply the best MALT prompted monitor to a fixed held-out test set three times, with different stated priors (1%, 10%, 50%). Measure AUROC and calibration error (ECE) for each condition. Report whether explicit prior information helps or hurts monitor performance.

**Why it matters:** If monitors can be improved by providing calibration context, this is a cheap intervention deployable today. If monitors are anchored negatively (overconfident given high priors), this is a safety-relevant miscalibration risk.

**Relevant context:** MALT monitors are prompted LLM judges. Calibration of LLM judges is an open problem. Prior information injection is a zero-cost modification to the monitor prompt. API-based, feasible for CS students.
