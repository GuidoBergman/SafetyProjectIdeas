# Monitor Agreement Rate Between Bloom and a Human Rater on Sycophancy Classification

**Problem:** Bloom automates behavioral evaluation using a judge model. It is unknown how often Bloom's automated sycophancy scoring agrees with human raters on the same transcripts, which determines whether Bloom results can be trusted as a proxy for human evaluation.

**Direction:** Generate 200 transcripts using Bloom's sycophancy scenario generation on Llama-3-8B-Instruct. Have Bloom score each transcript for sycophancy. Have two human raters (the student researchers) independently label each transcript. Compute inter-rater agreement (Cohen's kappa) and Bloom-vs-human agreement. Report disagreement patterns.

**Why it matters:** If Bloom-human agreement is below 0.7 kappa, Bloom cannot be trusted as a standalone evaluation tool and requires human oversight. Establishing this calibration is foundational to using Bloom in any research pipeline.

**Relevant context:** Bloom is described as producing a rate/distribution rather than a single yes/no finding. Anthropic's Bloom paper (Dec 2025) does not report human agreement baselines. 200 transcripts is tractable for two annotators in ~30 hours.
