# Does the Sycophancy Activation Signature Transfer Across Instruction-Tuning Variants?

**Problem:** 'A Few Bad Neurons' validated on Gemma-2-2B and 9B. Whether the same neurons remain predictive across differently instruction-tuned variants of the same base model (e.g., different RLHF runs) is not known.

**Direction:** Compare the predictive neuron set identified on Gemma-2-2B-it (instruction-tuned) vs. a differently fine-tuned variant (e.g., a chat vs. a safety-tuned checkpoint). Compute neuron overlap (Jaccard similarity) and probe transfer accuracy.

**Why it matters:** If the sycophancy neuron set shifts under different fine-tuning runs, then probes must be retrained per checkpoint, dramatically increasing monitoring overhead for labs that frequently update models.

**Relevant context:** 'A Few Bad Neurons' cross-architecture experiments use Llama 3.1 8B, Qwen 2.5 7B, Gemma 3 4B. Intra-model, cross-tuning stability is unstudied. Gemma-2 checkpoints at different RLHF stages may be accessible.
