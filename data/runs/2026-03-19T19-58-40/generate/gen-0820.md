# Cognitive Load Theory and Jailbreak Complexity: Do Longer Prompts Overwhelm Safety?

**Problem:** Anecdotally, very long or cognitively complex prompts seem to degrade safety compliance. There is no systematic empirical study of how prompt cognitive load affects jailbreak success rates.

**Direction:** Import Cognitive Load Theory from educational psychology (Sweller 1988). Operationalize cognitive load for LLMs as prompt complexity: number of embedded sub-tasks, level of indirection, working-memory-like requirements (e.g., tracking multiple roles, code+prose mixing). Design a factorial experiment varying cognitive load dimensions orthogonally while holding harmful intent constant. Measure refusal rates as a function of each dimension. Identify which load type most reliably degrades safety.

**Why it matters:** If cognitive load explains safety degradation, it suggests that safety training should include high-complexity benign-surface harmful prompts. It also explains why nested roleplay and hypothetical framing jailbreaks work—they impose load that dilutes safety attention.

**Relevant context:** Cognitive load approaches to deception detection (PMC 2015) show load affects detection accuracy. 'Bad Likert Judge' multi-turn jailbreak (Palo Alto Unit 42) exploits evaluation complexity. Self-persuasion jailbreak (MDPI 2025) uses indirect framing to impose load.
