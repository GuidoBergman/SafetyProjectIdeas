# Model-Auditing-Model Deception: Can a Smaller Model Audit a Larger One?

**Problem:** Model-auditing-model paradigms (as in Petri) typically use comparable-capability models as auditors. Whether a smaller, cheaper model can effectively audit a larger model for deception is unknown.

**Direction:** Run Petri-style adversarial auditing of a larger model using a smaller model as the auditor agent. Compare deception detection rates against human auditors and same-size model auditors. Measure whether capability gaps between auditor and subject reduce detection performance and at what capability ratio auditing becomes unreliable.

**Why it matters:** If smaller models can audit larger ones, the cost of safety auditing drops dramatically, enabling more frequent audits of deployed systems.

**Relevant context:** Petri deploys an automated agent to test target AI systems. METR model-auditing paradigm. The question of whether oversight can scale with capability is central to scalable oversight research.
