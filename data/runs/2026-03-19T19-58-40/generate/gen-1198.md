# Skill-Based Overseer Routing: Directing Each Task to the Overseer With the Relevant Skill Set

**Problem:** No single overseer is best for all tasks. Routing tasks to overseers based on their specific skill profiles could improve aggregate oversight quality without requiring any overseer to improve.

**Direction:** Profile the skill sets of multiple weak overseers. Implement a routing system that assigns each task to the overseer with the best match. Compare aggregate oversight quality to using a single generalist overseer.

**Why it matters:** Skill-based routing is standard in organizational management (assigning work to the most qualified person). Applying it to AI oversight could be a practical quality improvement.
