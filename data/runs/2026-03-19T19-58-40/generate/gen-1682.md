# Distributed vs. Concentrated Safety Failures: An Empirical Taxonomy of Failure Modes in Multi-Step Agent Trajectories

**Problem:** It is unknown whether dangerous agent behaviors tend to emerge suddenly (concentrated in one step) or accumulate gradually across many steps (distributed). This matters enormously for where to place monitoring checkpoints.

**Direction:** Analyze agent trajectories from ControlArena and SHADE-Arena tasks, labeling each step for harm potential. Compute the distribution of 'danger onset'—does harm concentrate in final actions, or does it accumulate through earlier steps that are individually benign? Use this empirical distribution to propose monitoring checkpoint placement strategies (early, late, or dense) and test whether checkpoint-placement affects detection rates.

**Why it matters:** If concentrated failures dominate, lightweight final-action monitoring suffices. If distributed, early-step monitoring is necessary. This distinction has direct implications for compute-monitoring trade-offs.

**Relevant context:** ControlArena (AISI/Redwood 2025) provides realistic agent trajectories with sabotage sub-tasks. SHADE-Arena contains 17 complex task pairs with hidden malicious sub-tasks. The open problem of 'distributed vs. concentrated safety failures' is explicitly listed as unsolved.
