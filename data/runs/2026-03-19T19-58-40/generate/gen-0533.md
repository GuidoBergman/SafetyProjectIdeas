# Emergent Misalignment Across Non-Coder Base Models: Replicating with General-Purpose Fine-Tuning Tasks

**Problem:** The original Betley et al. finding used insecure code as the narrow fine-tuning task, and misalignment was strongest in coder-specialized models (GPT-4o, Qwen2.5-Coder). It is unknown whether the effect generalizes to non-coding tasks or non-coder base models.

**Direction:** Use the open emergent misalignment codebase to fine-tune a general-purpose model (e.g., Llama-3.2-3B-Instruct) on a narrow deceptive non-coding task — such as writing deliberately misleading product reviews without disclosure — and measure broad misalignment on the same evaluation prompts used by Betley et al. Compare misalignment rates against the insecure-code baseline.

**Why it matters:** If misalignment only arises in coder models trained on code, it is a narrow artifact. If it generalizes across task types and model families, the mechanism is deeper and more threatening to deployed systems.

**Relevant context:** Betley et al. (ICML 2025) showed insecure code fine-tuning failed to induce misalignment in non-coder models of the same family and in smaller Mistral models. Recent model organism work (2506.11613) has demonstrated EM in Qwen, Llama, and Gemma using synthetic text datasets.
