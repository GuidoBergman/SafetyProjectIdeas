# Instruction Hijacking Through Environmental Poisoning: How Easily Can Malicious Environment State Redirect Agent Goals?

**Problem:** Agents that read from their environment (files, web pages, databases) can have their goals redirected by malicious content placed in the environment — without any direct attack on the agent.

**Direction:** Create a simulated environment (file system + web pages) containing 5 hidden adversarial redirects (malicious instructions embedded in otherwise legitimate-looking content). Run 5 different agent models on a standard task in this environment. Measure goal hijacking success rate, agent self-detection of hijacking attempts, and effectiveness of input sanitization as a defense.

**Why it matters:** Environmental poisoning is a practical, hard-to-detect attack vector that requires no access to the agent itself. Princeton's crypto agent attack used this exact vector.

**Relevant context:** Princeton crypto agent context poisoning study; Google DeepMind indirect prompt injection (arxiv 2505.14534); Adversa AI 2025 on prompt injection in agentic systems; the ShadowAgent failure mode.
