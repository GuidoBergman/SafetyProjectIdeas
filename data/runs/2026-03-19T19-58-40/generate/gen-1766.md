# Defense Transferability Probe: Testing Whether Single-Turn Defenses Hold Under Multi-Turn Attacks

**Problem:** Research (2025) confirms that 'defenses designed for single-agent prompt injection do not reliably transfer to multi-turn or multi-agent settings; narrowly scoped defenses may inadvertently increase vulnerabilities to other attack types.' Yet no benchmark systematically probes this defense transferability failure across common defense types.

**Direction:** Select 5–8 commonly cited defenses (e.g., output filtering, system prompt hardening, paraphrasing defense, self-reminder prompting) from AISafetyLab's 16 defense mechanisms. Test each defense on a matched set of attacks: (A) single-turn versions from a standard benchmark, and (B) multi-turn escalating versions of the same attacks. Compute a 'defense transferability score' for each defense type — does the defense hold equally well against both? Identify which defenses break most under multi-turn pressure.

**Why it matters:** Defenses evaluated only on single-turn benchmarks may create a false sense of security for deployments where users can engage in multi-turn conversations. This directly addresses the 'adaptive defenses' open problem in the subfield. Identifying which defenses fail under multi-turn conditions guides practitioners toward more robust deployment choices.

**Relevant context:** AISafetyLab (arxiv 2502.16776): evaluates 16 defense mechanisms, acknowledges current focus on single-turn LLMs with plans to expand. MASpi (OpenReview 2025): 'defenses designed for single-agent prompt injection do not reliably transfer to LLM-MAS.' Crescendo (USENIX Security 2025): 95% multi-turn success. ASB ICLR 2025: 23 attack/defense methods evaluated. MTJ-Bench: 41.7% of attacks succeed only in multi-turn format.
