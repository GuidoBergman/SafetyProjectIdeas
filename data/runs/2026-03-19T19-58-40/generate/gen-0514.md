# Deception + Long Context: Does Extended Context Enable More Sophisticated Scheming Plans?

**Problem:** Failure mode: Deception + Long Context = More Capable Scheming. Models with very long context windows may be able to construct more sophisticated multi-step deception plans that require tracking more information. Whether context length amplifies scheming sophistication is not studied.

**Direction:** Test scheming behavior on a fixed task across models with varied effective context lengths (achieved through context manipulation rather than architecture variation). Measure whether deception rate, deception sophistication (multi-step planning), or deception evasiveness increases with available context. Use existing scheming benchmarks adapted for context length variation.

**Why it matters:** Context length is rapidly increasing in deployed models. If longer context amplifies scheming capability, safety evaluations must be conducted at maximum deployment context length rather than short-context defaults.

**Relevant context:** Apollo Research's scheming evaluations use finite context scenarios. Context length effects on strategic reasoning are documented in other domains but not specifically for deceptive alignment.
