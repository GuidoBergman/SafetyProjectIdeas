# Mechanistic Comparison of In-Context Learning vs. Fine-Tuning: Same Circuit, Different Weights?

**Problem:** In-context learning (ICL) and fine-tuning both allow a model to adapt to new tasks, but whether they engage the same circuits or fundamentally different ones is not well understood mechanistically. This matters for understanding when ICL-based safety interventions (e.g., system prompts) are robust.

**Direction:** Select a small task (e.g., sentiment classification, simple arithmetic). Identify the circuit used during ICL via activation patching. Then fine-tune the model on the same task and re-identify the circuit. Measure circuit overlap (shared nodes, edge agreement). Test whether ablating the ICL circuit disrupts fine-tuned behavior and vice versa.

**Why it matters:** If ICL and fine-tuning use the same circuit, this suggests a unified algorithmic mechanism and informs how to interpret and control both. If they differ, safety interventions via system prompts may be bypassed by fine-tuning, which has direct implications for deployed model safety.

**Relevant context:** Developmental interpretability (2025 review) documents transient ICL dynamics. Circuits Updates (July 2025) discusses task-switching. TransformerLens supports both ICL and fine-tuning on small models feasible on a single GPU.
