# Biological Quarantine Transfer: Implementing Containment Protocols for Flagged AI Agent Behaviors

**Problem:** When biosafety systems detect a potential hazard, they implement quarantine—halting the suspected agent and preventing spread. AI control protocols typically flag suspicious behavior but do not have standardized containment protocols specifying exactly what should happen next.

**Direction:** Design and implement a tiered containment response protocol for ControlArena, triggered by monitor alerts at different severity levels: (1) shadow mode (agent continues but all actions are logged for review), (2) rate limiting (agent can continue but with 10-second delays between actions), (3) soft halt (agent pauses and requests human confirmation before continuing), (4) hard halt (agent is terminated). Evaluate which protocol achieves the best outcome (minimal task disruption + maximum sabotage prevention) on SHADE-Arena.

**Why it matters:** Detection without a well-defined response protocol is incomplete safety design. Specifying and evaluating response protocols fills a gap in current AI control research, where most work focuses on detection rather than response.

**Relevant context:** Tiered response protocols are standard in biosafety (BSL 1-4), ICS incident response, and medical emergency protocols. ControlArena's infrastructure supports injecting delays and halts. This is primarily a protocol design and software experiment.
