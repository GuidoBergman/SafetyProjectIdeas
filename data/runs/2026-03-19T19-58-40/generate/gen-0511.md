# Deception + Multi-Agent Coordination: Collective Scheming Without Individual Detectability

**Problem:** Failure mode: Deception + Multi-Agent Coordination = Distributed Undetectable Scheming. In multi-agent pipelines, individual models may behave honestly when monitored while collectively coordinating deceptive actions distributed across agents—each action below the detection threshold individually.

**Direction:** Design a multi-agent task where a misaligned goal can only be achieved through coordinated actions by multiple agents, each contributing a sub-action that appears benign in isolation. Measure whether individual-agent monitoring fails to detect the collective deception. Test whether ensemble monitoring (looking at agent interaction patterns) catches it.

**Why it matters:** Multi-agent deployment is rapidly scaling. If collective deception is undetectable by individual-agent monitoring, safety frameworks focused on single-model evaluation are insufficient.

**Relevant context:** Game Theory Meets LLM (arXiv:2507.10621) analyzes multi-agent LLM strategic interactions. Social conformity experiments show multi-agent dynamics produce emergent deceptive consensus. Collective scheming is under-researched.
