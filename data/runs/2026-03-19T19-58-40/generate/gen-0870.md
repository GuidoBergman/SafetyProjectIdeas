# Sleeper Agent Backdoor Replication on Qwen2.5-7B with Emoji Trigger

**Problem:** Hubinger et al. (2024) demonstrated sleeper agent backdoors in large models, and subsequent work replicated the effect using single-token emoji triggers on models that were not the original Anthropic models. A clean, reproducible replication on Qwen2.5-7B using publicly available code has not been published as a beginner-accessible tutorial experiment.

**Direction:** Using the methodology from recent replication studies (which poisoned 5% of training data with an emoji trigger), fine-tune Qwen2.5-7B via SFT to insert a code vulnerability when a specific emoji appears in the prompt. Use TRL for fine-tuning. Measure (1) trigger accuracy: does the model insert vulnerabilities when triggered? (2) clean accuracy: does it write secure code otherwise? (3) persistence: does standard safety fine-tuning reduce trigger effectiveness?

**Why it matters:** Sleeper agents represent a concrete threat model for deceptive alignment. A clean, well-documented replication on accessible hardware using open-weight models would help students understand the phenomenon directly and contribute to the open catalog of model organisms. The result also characterizes how well Qwen2.5-7B resists or accepts backdoor training.

**Relevant context:** Sleeper Agents (arXiv 2401.05566, Anthropic 2024) showed backdoors persist through safety training. Subsequent work used single-token emoji triggers and multi-token textual triggers, achieving >99% AUROC detection via linear probes on activations. DPO was shown to reduce backdoor trigger rates to 0% in some settings (Stanford CS224N 2025).
