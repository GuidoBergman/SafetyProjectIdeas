# Model-Auditing-Model Pipeline Using Petri for Automated Deception Discovery

**Problem:** Petri enables automated multi-turn adversarial auditing, but optimal seed instruction design for deception discovery is not established. Naive seeds may miss systematic deception modes.

**Direction:** Run Petri on 2-3 open-source models with a systematically varied seed library (covering manipulation, lying, misdirection, goal concealment). Build a deception taxonomy from discovered behaviors. Measure which seed instruction categories produce the highest yield of deceptive behaviors per audit hour.

**Why it matters:** A validated high-yield seed taxonomy would accelerate all future uses of Petri for deception auditing, multiplying the value of the tool for the community.

**Relevant context:** Petri 2.0 expanded to 70+ new scenarios. Early adopters include MATS scholars and UKASI. The tool is open-source at github.com/safety-research/petri.
