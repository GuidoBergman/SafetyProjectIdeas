# Do Smaller Models Exhibit More Axiom-Consistent Preferences? A Scale Study

**Problem:** Theoretical alignment assumes preference consistency, but preference inconsistency might scale with model size (larger models have more complex, potentially contradictory value representations). Is this empirically testable?

**Direction:** Run the formal preference axiom test suite (transitivity, IIA, framing consistency) on Pythia models at 70M, 160M, 410M, 1.4B, and 2.8B parameters. Report axiom violation rates as a function of model scale. Test whether violations increase, decrease, or are non-monotonic with scale.

**Why it matters:** If axiom violations scale with model size, theoretical alignment frameworks are harder to apply to larger, more capable models—exactly where they are most needed. This is a critical empirical data point for formal alignment.

**Relevant context:** Pythia scaling suite; formal alignment axioms literature. Scale effects on preference coherence have not been studied.
