# Over-Steering + Hallucination Increase: Safety-Reliability Compounding Failure

**Problem:** Aggressive safety steering (over-suppression of harm directions) may push model activations toward regions that increase hallucination rates, creating a trade-off where making a model safer makes it less reliable.

**Direction:** Measure hallucination rate (using a probe-based hallucination detector) as a function of toxicity steering coefficient, testing whether there is a steering magnitude above which hallucination increases significantly and whether this threshold is predictable from probe geometry.

**Why it matters:** A model that is safe but hallucinates dangerously in high-stakes domains (medical, legal) is not actually safer overall; this compounding failure mode needs to be characterized.

**Relevant context:** Beaglehole et al. demonstrate both toxicity steering and hallucination detection as separate capabilities; their interaction is unstudied. Neural probe hallucination detection (arXiv 2512.20949) provides the detection infrastructure.
