# Jailbreak Complexity vs. Effectiveness: Is Simpler Better for Attackers?

**Problem:** The paper 'Multi-Turn Jailbreaks Are Simpler Than They Seem' (arXiv 2508.07646) suggested that complex multi-turn attacks may not outperform simpler reformulations. A systematic comparison of attack complexity vs. ASR across attack families would test this claim.

**Direction:** Select 4 attack categories: simple prompt injection, role-play, multi-turn Crescendo-style, and optimization-based (GCG). Run each against 3 models with matched harmful intents. Measure ASR and prompt complexity (length, turn count, encoding operations). Test whether complexity correlates with ASR.

**Why it matters:** If simple attacks consistently outperform complex ones, defense efforts focused on blocking complex attacks are misallocated. A success state requires defenses calibrated to actual attack effectiveness distributions, not theoretical attack sophistication.

**Relevant context:** arXiv 2508.07646 (August 2025) argued multi-turn complexity is overstated. AISafetyLab implements both simple and complex attack methods. This experiment can be run within a 30-hour budget using a single GPU.
