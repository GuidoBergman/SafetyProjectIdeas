# Contagion Threshold Analysis for Feature Co-activation Cascades

**Problem:** It is unknown whether there exist 'tipping point' combinations of features whose co-activation triggers a cascade of further activations, potentially leading to emergent behaviors or unsafe outputs.

**Direction:** Apply the network contagion threshold model (Watts 2002): treat each SAE feature as a node that activates if a threshold fraction of its input features are active. Estimate empirical thresholds from activation data and simulate which combinations of seed feature activations produce the largest downstream cascades.

**Why it matters:** Cascade analysis could identify fragile combinations of features that, if triggered together, reliably produce unsafe behaviors — a form of circuit-level red-teaming that is more principled than random prompt search.

**Relevant context:** Watts threshold model is standard in sociology and network science for modeling opinion cascades and adoption. SAE feature co-activation data from SAELens provides empirical basis. Attribution graphs from Anthropic 2025 give directional edges.
