# Circuit Overlap Measurement Tool: How Much Do Different Discovery Methods Agree?

**Problem:** Multiple circuit discovery algorithms exist (ACDC, path patching, attribution patching, gradient-based pruning) but there is no standard tool for measuring how much overlap exists between the circuits they produce on the same task. Without an overlap metric, it is unclear whether different methods are finding the same underlying structure or different artifacts.

**Direction:** On GPT-2-Small and the IOI task, run at least two circuit discovery methods and compute a Jaccard similarity over the discovered edge sets. Build a small Python utility that takes two circuit edge lists and outputs pairwise overlap scores. Test on three tasks to show variance in overlap across tasks. Visualize disagreements as edge-level heatmaps using TransformerLens visualization utilities.

**Why it matters:** If two methods return circuits with 30% overlap, at least one is wrong or both are measuring something different from the true causal structure. A circuit overlap tool would let researchers quickly assess method agreement, which is foundational to validating safety-relevant circuit claims.

**Relevant context:** MIB evaluates methods individually but does not include an inter-method agreement track. ACDC, path patching, and attribution patching are all implemented in TransformerLens-compatible codebases.
