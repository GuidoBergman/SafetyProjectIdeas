# Investigating the Effect of Retrieval Context Size on Safety Benchmark Scores

**Problem:** RAG pipelines vary the amount of retrieved context from a few sentences to several thousand tokens. Whether safety scores degrade as retrieved context increases (more opportunities for injection) is unknown.

**Direction:** Construct a RAG safety evaluation where harmful instructions are embedded in retrieved documents at varying context sizes (512, 2K, 8K, 32K tokens). Measure how compliance rate with the harmful instruction changes with total context size.

**Why it matters:** Long-context RAG is increasingly common. If safety filters are overwhelmed by longer contexts, organizations using RAG with large document collections are exposed.

**Relevant context:** Long-context models support 32K–128K tokens. RAG safety is a gap identified in current benchmarks. This tests a specific and tractable dimension of that gap.
