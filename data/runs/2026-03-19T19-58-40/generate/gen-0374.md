# Testing Whether Linear Probes and SAE Probes Disagree: When Does Geometry Break Down?

**Problem:** Linear probes trained directly on raw activations consistently outperform SAE-based probes on downstream tasks, as documented by DeepMind (2025). The specific geometric reason for this gap—whether it is because SAEs discard information via the sparsity constraint, because SAE features are not axis-aligned with the probe's optimal direction, or because the SAE reconstruction error carries critical information—has not been empirically decomposed.

**Direction:** Using TransformerLens and SAELens on GPT-2 medium, select 5 classification tasks (e.g., sentiment, topic, presence of a named entity, grammatical number of subject, mathematical parity). For each task, train three probe types: (1) logistic regression on raw residual stream activations, (2) logistic regression on SAE feature activations, (3) logistic regression on the SAE reconstruction error alone. Report accuracy for each, and for tasks where raw outperforms SAE, test whether adding the reconstruction error back to the SAE features closes the gap. This decomposes whether the gap is attributable to information in the error term vs. a suboptimal SAE feature basis.

**Why it matters:** If adding reconstruction error to SAE features closes the probe gap, it confirms the gap is an information loss problem (sparsity discards relevant signal). If reconstruction error alone achieves high accuracy, the SAE features are misleading about where the task-relevant information is located in the model.

**Relevant context:** DeepMind's 2025 finding that SAEs underperform linear probes on safety tasks is the key motivation. Decomposing the source of the gap is a natural next step and would be cited directly as a follow-up to their published negative results.
