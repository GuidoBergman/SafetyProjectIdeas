# Jailbreak Transferability Matrix Builder: An Open Tool for Measuring Cross-Model Attack Transfer Rates

**Problem:** Jailbreak Strength and Model Similarity Predict Transferability (arxiv 2506.12913) shows that cross-model jailbreak transfer depends on source-model jailbreak strength and representation similarity between models. However, no open, reusable tool exists that lets researchers compute a cross-model transferability matrix for a set of attacks and models. Practitioners cannot easily assess whether a new attack will transfer to their target model.

**Direction:** Build a Python tool that takes a set of jailbreak prompts (from JailbreakBench or user-supplied) and a list of models (open-weight, accessible via HuggingFace or API), runs each prompt against each model, and outputs a transferability matrix: rows = source models, columns = target models, cells = transfer rate. Include a simple cosine similarity computation on model embeddings to correlate with transfer rates. Requires single-GPU compute and basic Python. Validate by replicating the correlation finding from arxiv 2506.12913.

**Why it matters:** Practitioners deploying LLMs need to know whether attacks demonstrated on public models transfer to their specific model. Researchers need a reusable tool to study transfer dynamics without building it from scratch each time. A standardized transferability matrix tool would become valuable community infrastructure.

**Relevant context:** arxiv 2506.12913 'Jailbreak Strength and Model Similarity Predict Transferability': 'transfer success depends on jailbreak strength with respect to source model and contextual representation similarity of the two models.' Springer 2025 'Boosting Jailbreak Transferability for Large Language Models.' JailbreakBench maintains prompts but no transfer matrix tooling. AISafetyLab evaluates 13 attack methods without systematic cross-model transfer measurement.
