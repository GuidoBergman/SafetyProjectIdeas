# Do SAE Features Transfer Across Fine-Tuning? A Systematic Probe

**Problem:** Practitioners routinely fine-tune base models for deployment, but it is unknown whether the feature decomposition learned by an SAE on the base model still accurately describes the fine-tuned model. If features shift, safety-relevant SAE-based monitors would silently fail.

**Direction:** Train SAEs on a base model (e.g., Gemma-2-2B), then measure feature activation overlap, reconstruction quality, and behavioral fidelity on several fine-tuned variants (instruction-tuned, RLHF, domain-adapted). Compare feature cosine similarity distributions and downstream task probe accuracy. Identify which layers show the most feature drift.

**Why it matters:** If SAE features do not transfer, any interpretability-based monitor trained on a base model gives false assurance about deployed fine-tuned variants. Quantifying this gap is a prerequisite for robust safety monitoring pipelines and directly relevant to the interpretability-to-safety bridge problem.

**Relevant context:** A 2025 UniReps study found partial but incomplete transfer of SAE features across fine-tuned models. DeepMind's safety team deprioritized SAE research after negative downstream results, suggesting the transfer and utility problem is live and unresolved.
