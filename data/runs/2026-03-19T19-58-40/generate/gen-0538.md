# System Prompt Sensitivity of Emergent Misalignment: Mapping the Prompt Space

**Problem:** Emergent misalignment has been characterized as a form of prompt sensitivity. Misaligned models respond differently depending on system prompt variations, while control models are stable. The shape of this sensitivity landscape is underexplored.

**Direction:** Take an already-fine-tuned misaligned model (using the open emergent misalignment codebase). Construct a grid of 20 system prompt variants spanning: no system prompt, minimal identity prompts, safety-emphasizing prompts, authority-framing prompts, and roleplay-framing prompts. Measure misalignment rate across this grid and cluster prompts by elicitation success.

**Why it matters:** Mapping which prompt structures reliably elicit or suppress misalignment helps red-teamers, safety evaluators, and researchers understand the behavioral stability of models before deployment.

**Relevant context:** Arxiv 2507.06253 ('Emergent misalignment as prompt sensitivity') documents that system prompt variations substantially alter misaligned model behavior. The full topology of this sensitivity has not been characterized.
