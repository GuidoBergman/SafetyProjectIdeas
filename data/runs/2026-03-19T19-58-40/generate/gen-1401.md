# Does the SycophantSee Neuron Isolation Method Generalize to Reward Hacking Detection?

**Problem:** 'A Few Bad Neurons' (arXiv:2601.18939) identifies ~3% of MLP neurons predictive of sycophancy and corrects them via gradient masking. It is unknown whether the same sparse-neuron-identification methodology applies to reward hacking, another form of misalignment with distinct behavioral signatures.

**Direction:** Apply the SAE + linear probe pipeline from 'A Few Bad Neurons' to identify MLP neurons predictive of reward-hacking behavior using MALT transcripts as labeled training data. Test whether the neuron set overlaps with sycophancy neurons or is distinct. Probe accuracy and neuron overlap are the key metrics.

**Why it matters:** If a common sparse neuron set underlies multiple misalignment types, targeted neuron-level interventions could address several failure modes simultaneously. Divergence would suggest misalignment is more fragmented mechanistically.

**Relevant context:** 'A Few Bad Neurons' used Gemma-2-2B and 9B on SycoBench, NLP, POLI, PHIL benchmarks. MALT has labeled reward-hacking transcripts. Activation steering for sycophancy has 88.4% probe accuracy on 4B models.
