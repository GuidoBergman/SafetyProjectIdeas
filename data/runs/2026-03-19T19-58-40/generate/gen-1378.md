# Scheming Detection via Output Entropy Monitoring

**Problem:** Scheming behaviors require deliberate goal-directed action, which may produce different output entropy patterns than normal responses: lower entropy (more deterministic planning) or higher entropy (more uncertainty about optimal deception strategy).

**Direction:** Generate outputs in normal and scheming-elicited conditions on matched prompts using open-source models with accessible logits. Measure token-level entropy across output sequences. Build an entropy-signature classifier and test whether it distinguishes scheming from honest condition outputs better than chance.

**Why it matters:** A logit-based entropy monitor could be deployed as a lightweight real-time safety monitor for any model with accessible logits.

**Relevant context:** METR's MALT monitors reward hacking from transcripts. Entropy-based anomaly detection is standard in security but has not been applied specifically to scheming detection.
