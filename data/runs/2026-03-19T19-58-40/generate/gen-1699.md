# Failure Mode Taxonomy for Novel Behaviors: Can LLM-Based Clustering Identify Unseen Dangerous Patterns in Agent Logs?

**Problem:** Supervised monitors are blind to novel failure modes not present in training data. Unsupervised clustering of agent behavior logs might surface qualitatively new dangerous patterns before they can be exploited.

**Direction:** Collect a large set of agent action logs (from ControlArena or synthetic generation). Embed each action description using a sentence transformer. Apply k-means and DBSCAN clustering to identify behavioral clusters. Manually inspect outlier clusters (low-density regions) for novel potentially dangerous behavior patterns. Measure whether known SHADE-Arena sabotage actions fall in outlier clusters vs. mainstream clusters, testing whether unsupervised clustering naturally surfaces dangerous novelty.

**Why it matters:** Anomaly detection for novel dangerous behaviors is an explicit open problem. Unsupervised discovery of dangerous patterns is a concrete, implementable approach that does not require pre-labeled examples of new failure modes.

**Relevant context:** Supervised monitoring misses unknown failure modes (seed problem). SHADE-Arena and ControlArena provide action logs. Sentence transformers are accessible to intro-ML participants. DBSCAN outlier detection is a standard ML technique.
