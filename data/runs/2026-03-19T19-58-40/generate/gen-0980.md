# AgentSafetyBench-MultiStep: A Benchmark for Cumulative Safety Failures in Sequences of Agent Actions

**Problem:** No widely adopted benchmark exists for multi-step agentic safety failures. Existing benchmarks (AgentHarm, SafeArena) test single-step or single-turn safety, missing compounding effects.

**Direction:** Design 50 multi-step task scenarios (10-30 steps each) where safety failure requires a specific sequence of actions rather than a single dangerous action. Implement automated scoring for cumulative harm at each step. Release as an open benchmark with reproducible baselines for 3 models.

**Why it matters:** This directly addresses the critical gap identified: no widely adopted benchmark for multi-step agentic safety failures exists. MAST taxonomy and Microsoft's whitepaper both call for this.
