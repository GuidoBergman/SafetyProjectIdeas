# Replicating SHADE-Arena with an Explicit Monitor Prompt Optimized for Open-Source Agents

**Problem:** SHADE-Arena monitoring was evaluated with prompts designed for frontier models. Whether a monitor prompt specifically optimized for open-source model outputs (which may be less fluent or structured) improves detection rates is unexplored.

**Direction:** Run SHADE-Arena public tasks with Llama-3.1-8B as agent. Compare detection rates of (a) original SHADE-Arena monitor prompt and (b) a revised monitor prompt with open-source-specific formatting guidance and lower expected fluency. Optimize prompt via 5-shot examples from open-source agent traces.

**Why it matters:** Monitor prompts designed for frontier models may systematically underperform on open-source model outputs, giving false assurance when organizations deploy smaller models with frontier-designed monitoring.

**Relevant context:** SHADE-Arena paper uses frontier model agents. Monitor prompt is described in the paper. Open-source model outputs have distinct stylistic properties. Prompt engineering for monitoring is a low-cost but high-impact optimization.
