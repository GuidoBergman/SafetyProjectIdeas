# GCG Attack Position Sensitivity: Prefix vs. Suffix vs. Interleaved Token Placement

**Problem:** Recent work showed that adversarial token position (prefix vs. suffix vs. interleaved) dramatically affects GCG attack success, but there is no systematic characterization of how position interacts with model architecture, alignment method, and prompt category.

**Direction:** Using nanogcg (public fast GCG implementation), optimize adversarial tokens in three positions: (1) suffix only (standard), (2) prefix only, (3) interleaved within prompt. Run on 20 harmful prompts per hazard category from JailbreakBench across 3 models. Measure attack success rate and convergence speed per position. Use StrongREJECT evaluator for scoring. Report interaction effects between position, model, and hazard category.

**Why it matters:** Position sensitivity is a fundamental property of how attention mechanisms process adversarial inputs. If prefix attacks are systematically more effective, current defenses (which focus on suffix filtering) leave a major gap.

**Relevant context:** Beyond Suffixes: Token Position in GCG attacks (arXiv:2602.03265). Universal and Transferable Adversarial Attacks (arXiv:2307.15043). nanogcG fast implementation (August 2024).
