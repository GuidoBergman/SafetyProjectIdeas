# Replicating MALT Monitor on Agentic Coding Tasks with Tool Errors vs. Clean Environments

**Problem:** MALT benchmarks assume relatively clean execution environments. Whether monitor performance degrades when agents operate in noisy environments with tool errors, timeouts, or malformed outputs is uncharacterized.

**Direction:** Re-run a subset of MALT-style tasks with injected environmental noise (10% random tool failures, malformed outputs). Compare CoT monitor AUROC on noisy vs. clean runs, separately for reward hacking and benign trajectories. Analyze whether noise causes false positives.

**Why it matters:** Real production environments are noisy. If monitoring degrades under noise, deployed monitors will have higher false positive rates than lab benchmarks suggest, eroding operator trust.

**Relevant context:** ControlArena's code sabotage setting involves realistic environments. MALT transcripts come from controlled evaluations on HCAST/RE-Bench. Environmental noise is not a studied variable in published monitoring work.
