# UnlearningEval-Semantic: Measuring Conceptual Rather Than Verbatim Forgetting

**Problem:** Current LLM unlearning benchmarks (TOFU, WMDP) measure whether specific verbatim facts are forgotten. However, a model can 'forget' a targeted fact while retaining the semantic concept in a form that can be reconstructed. No evaluation tool measures conceptual or inferential retention after unlearning.

**Direction:** Take unlearned models from TOFU and add an evaluation tier of 'inference chain' probes: questions that require the model to reason from adjacent retained knowledge to reconstruct the supposedly forgotten target. Measure 'conceptual retention rate' separately from verbatim recall rate. Implement in Python using sentence transformers for semantic similarity scoring.

**Why it matters:** If unlearning methods only suppress verbatim recall but leave conceptual knowledge intact, they provide a false sense of safety for applications like removing hazardous knowledge or protecting privacy. A semantic evaluation layer would expose this gap.

**Relevant context:** The comprehensive LLM unlearning robustness evaluation (arxiv 2603.00823) focuses on multi-turn interaction recovery but not semantic reasoning recovery. OpenUnlearning's meta-evaluation uses quantization and relearning stress tests but not semantic inference probes.
