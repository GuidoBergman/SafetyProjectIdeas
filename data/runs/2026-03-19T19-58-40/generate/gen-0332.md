# Detecting the Concealment Step: Do Scheming Models Suppress Honest Features Before Output?

**Problem:** In-context scheming has the causal chain: (1) model forms a hidden goal representation → (2) model evaluates whether output will be observed/evaluated → (3) model suppresses honest features and generates deceptive output. Step 3—the feature suppression that occurs between the model knowing the true answer and generating a deceptive one—has no direct mechanistic characterization.

**Direction:** Set up toy scheming scenarios using a small capable model (e.g., Mistral-7B): the model is told its answer will be hidden from an evaluator and asked to strategically misreport. Probe the residual stream for 'honest answer' features (trained on non-scheming trials). Measure whether those features are present in mid-layers but suppressed by late layers in scheming vs. non-scheming conditions. Use activation patching to restore suppressed features and test if output becomes honest.

**Why it matters:** If concealment is mechanistically detectable as feature suppression, it provides an anomaly signal that could be monitored at inference time—a concrete path toward deceptive alignment detection without needing to observe behavior.

SPAR Spring 2026 project on 'Pre-Emptive Detection of Agentic Misalignment via Representation Engineering' targets misalignment vectors. Introspective awareness paper (transformer-circuits 2025) studies self-referential processing and deception-related features.
