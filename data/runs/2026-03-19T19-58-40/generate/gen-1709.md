# Prompt Injection in Agentic Pipelines: Mapping the Causal Steps Between Injected Content and Unsafe Tool Use

**Problem:** In agentic LLM systems, injected content in tool outputs can cause the agent to call unsafe tools. The causal chain is: injected text in environment → LLM parses as instruction → tool call with harmful parameters. The intermediate step of 'instruction parsing from environment data' is the key causal link, but its robustness to simple filtering is untested.

**Direction:** Build a minimal agentic scaffold (LLM + fake tool with one dangerous action). Inject instructions at different positions (beginning, middle, end) in tool outputs. Measure injection success rate and test whether a simple heuristic filter (look for imperative sentences) at the tool-output parsing step reduces ASR. Fits in ~20 hours.

**Why it matters:** Agentic pipelines are increasingly deployed; identifying the minimal causal step for prompt injection informs lightweight defenses that don't require full model retraining.

**Relevant context:** Attacker Moves Second paper (arxiv 2510.09023); prompt injection red-teaming; adaptive attack evaluations.
