# Safety Evaluation on Quantized Models: Does INT4 Quantization Affect Jailbreak Resistance?

**Problem:** Quantized models (INT4, INT8) are widely deployed for cost efficiency. Whether quantization changes jailbreak resistance — either improving it (distribution shift blocks known attacks) or degrading it (safety-relevant activations disrupted) — is not documented.

**Direction:** Run the same StrongReject and AISafetyLab attack evaluation on both FP16 and INT4-quantized versions of 2-3 models (using bitsandbytes or GPTQ). Measure whether ASR differs meaningfully between precision levels. Test whether refusal rate on benign safety-adjacent prompts changes.

**Why it matters:** Nearly all consumer and edge deployments use quantized models. If quantization changes safety properties, the safety evaluations run on full-precision research models are not valid for the models that are actually deployed — a critical lab-to-deployment gap.

**Relevant context:** INT4 quantization with bitsandbytes is widely used for single-GPU inference of 7-13B models. Safety properties of quantized models are studied in capability benchmarks but not in jailbreak benchmarks. This is a purely empirical study requiring only a single GPU.
