# IrreversAct-Bench: A Dataset of Actions Labeled by Reversibility, Scope, and Blast Radius

**Problem:** There is no curated dataset of agent actions labeled for reversibility, making it impossible to train or evaluate reversibility-aware safety systems.

**Direction:** Curate 500 agent actions from existing agent traces (METR task suite logs, AgentBench outputs, public agentic incident reports). Annotate each action with: reversibility score (1-5), affected scope (local/system/external), blast radius (estimated harm if misused). Release as a labeled dataset with annotation guidelines.

**Why it matters:** A labeled reversibility dataset would unblock multiple safety research threads: training reversibility classifiers, evaluating safety interventions, and grounding theoretical frameworks.

**Relevant context:** Anthropic's recommendation to require human approval for irreversible actions; the absence of any such dataset in the 2025 benchmark survey (o-mega.ai); Microsoft's agent failure taxonomy (2025).
