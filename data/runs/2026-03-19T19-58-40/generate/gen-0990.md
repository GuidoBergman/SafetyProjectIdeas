# Scope Creep in Autonomous Code Modification: When Do Code Agents Exceed Their Assigned Scope?

**Direction:** Assign a code-writing agent to fix 30 specific bugs in a test codebase. After each fix, measure whether the agent modified any code outside the specified scope.
