# Prefilling Attacks Exploit Shallow Alignment to Bypass Output Monitors

**Problem:** Prefilling attacks bypass safety by inserting the start of a compliant response, exploiting that alignment is concentrated in the first few output tokens. Output classifiers trained on complete responses may not trigger early in the generation, allowing the harmful content to be generated before the monitor can intervene.

**Direction:** Implement a prefilling attack on an open-source model. Test whether output classifiers that evaluate the full response (vs. streaming classifiers that evaluate partial outputs) differ in detection rate. Measure at what token position the harmful content becomes detectable vs. when the model is already committed to completing it.

**Why it matters:** Streaming safety evaluation is computationally necessary but architecturally risky. If prefilling exploits the exact token window where alignment is weakest (first few tokens) and monitoring is delayed, the two failure modes perfectly compound. This is a practical, deployable research question.

**Relevant context:** Shallow alignment localized to first few output tokens (ICLR 2025 paper). Prefilling attacks listed as a vulnerability in safety alignment survey. Constitutional classifiers use cascaded evaluation. DeepRefusal reduces ASR by 95% by deepening alignment beyond early tokens.
