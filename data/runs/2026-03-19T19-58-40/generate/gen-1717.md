# Adversarial Suffix Transferability Decay: How Quickly Does Transfer ASR Degrade With Model Size Difference?

**Problem:** Adversarial suffixes transfer across models but the degree of transfer is inconsistent. One causal hypothesis: transfer is driven by shared tokenization and embedding geometry. If so, models with larger size gaps (and thus more divergent geometry) should show faster transfer decay. This causal link is unstudied.

**Direction:** Generate GCG suffixes on Llama-3-8B. Measure ASR on Llama-3-70B, Mistral-7B, Phi-3, and Falcon-7B. Compute pairwise embedding similarity (CKA or linear CKA) between the source model and each target. Test whether transfer ASR correlates with embedding similarity. ~20 hours.

**Why it matters:** If geometry predicts transfer, then models can be hardened by diversifying embedding geometry through architectural changes or fine-tuning, a targeted and interpretable intervention.

**Relevant context:** Jailbreak transferability shared representations (arxiv 2506.12913); GCG attack; model size scaling effects.
