# Longitudinal Refusal Rate Tracking on a Fixed Prompt Set Across Model Versions

**Problem:** Model updates happen frequently but safety property changes are not systematically tracked. A longitudinal study using archived model versions can reveal whether fine-tuning or RLHF steps change refusal behavior in predictable ways.

**Direction:** Use Hugging Face model version history for a model with multiple public checkpoints (e.g., Mistral or Llama variants fine-tuned over time). Run a fixed set of 50–100 safety prompts on each checkpoint. Plot refusal rate, response length, and harm score over versions. Identify whether safety regressions follow capability improvements.

**Why it matters:** Post-deployment safety tracking is an open problem. Using already-available model checkpoints makes this feasible without needing API access or special permissions.

**Relevant context:** The FLI AI Safety Index criticizes companies for lacking monitoring and control mechanisms. Hugging Face hosts many historical checkpoints publicly, making this experiment low-cost.
