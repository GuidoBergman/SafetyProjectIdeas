# ComplianceMapper: A Tool That Maps Model Cards to EU AI Act Requirements

**Problem:** Model developers need to know whether their existing model card documentation satisfies EU AI Act technical documentation requirements. No automated tool exists for this.

**Direction:** Parse the EU AI Act Annex IV documentation requirements into a structured checklist. Build a Python tool that takes a model card (PDF or markdown) as input and outputs a compliance gap report: which requirements are met, partially met, or absent.

**Why it matters:** Reduces compliance burden for smaller labs and creates an empirical baseline for how well current model card practices align with legal requirements.

**Relevant context:** EU AI Act Annex IV lists specific technical documentation requirements; HuggingFace hosts thousands of model cards with varying documentation depth.
