# Governance Indicator Stability: Do Labs Change Their Safety Documentation After an Index Publication?

**Problem:** FLI AI Safety Index scores are published publicly. Labs may update their documentation in response to being scored, improving their next score without genuinely improving safety. Testing for this reactive documentation behavior would reveal whether index scores are measuring safety or measurement-gaming.

**Direction:** Using web archives, collect versions of major lab safety documentation from 1 month before and 3 months after FLI Index publication dates. Code whether documentation changed on indicators where the lab scored poorly. Test whether changes are concentrated on low-scoring indicators.

**Why it matters:** If labs systematically update documentation after being scored on specific indicators, index scores measure 'ability to respond to an index' rather than underlying safety posture.

**Relevant context:** FLI Index Summer and Winter 2025 editions provide two scoring events; Web Archive preserves documentation versions for comparison.
