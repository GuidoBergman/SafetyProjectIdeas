# Replication of Crypto Theft Attack Chain on Modern Agent Frameworks: Does Context Poisoning Generalize?

**Problem:** The Princeton/ElizaOS context-poisoning attacks on crypto agents were demonstrated on specific frameworks. It is unknown whether these attacks generalize to other widely used agent frameworks.

**Direction:** Replicate the context-poisoning attack methodology on 2-3 different agent frameworks (LangChain, AutoGen, a custom minimal implementation) in a testnet sandbox. Measure whether the attack succeeds, fails, or requires modification. Identify framework-specific mitigations.

**Why it matters:** If context poisoning generalizes across frameworks, it represents a class-level vulnerability. If it does not, framework-specific defenses may be sufficient.

**Relevant context:** Adversa AI 2025 report on autonomous crypto theft; Princeton study on crypto agent manipulation; arxiv paper on autonomous blockchain agents (2601.04583).
