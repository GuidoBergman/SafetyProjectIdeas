# Network Reliability Theory Applied to Multi-Model AI Infrastructure

**Problem:** When multiple AI models are integrated into a single infrastructure (pipeline, multi-agent system, or API gateway), their correlated failures create reliability properties that are not captured by individual model reliability metrics.

**Direction:** Apply network reliability theory (fault trees, common-cause failure analysis, reliability block diagrams) to a multi-model AI deployment architecture, deriving analytical expressions for system reliability as a function of inter-model output correlation.

**Why it matters:** Engineering reliability methods can directly quantify how much worse correlated failures are than independent ones, providing precise risk estimates rather than qualitative warnings.

**Relevant context:** Common-cause failure analysis is standard in nuclear and aerospace engineering. CEPR researchers have called for engineering reliability approaches to be applied to AI systemic risk.
