# Layer Selection Heuristic Tool for Optimal Concept Vector Extraction

**Problem:** Practitioners must manually search across layers to find the layer with the best concept vector; there is no principled automated tool for layer selection.

**Direction:** Build a layer selection tool that scans all layers of a model, computes concept vector extraction quality metrics (probe accuracy, vector norm stability, steerability coefficient), and recommends the optimal layer automatically.

**Why it matters:** Layer selection is a hidden hyperparameter that strongly affects steering effectiveness; automating it removes a barrier to correct application.

**Relevant context:** Beaglehole et al. extract layer-wise concept vectors and select based on predictors; the selection logic is not packaged as a reusable tool. Multiple RepE papers implicitly assume the user knows which layer to use.
