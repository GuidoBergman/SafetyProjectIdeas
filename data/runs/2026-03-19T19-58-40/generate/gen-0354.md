# Power-Seeking Behavior as a Measurable Activation Pattern: A Replication and Extension Study

**Problem:** The SPAR 2026 project proposes detecting power-seeking via representation engineering. The causal chain: (1) model internally represents a power-seeking action as beneficial → (2) this representation propagates to the action-selection component → (3) a power-seeking action is taken. The intermediate link—whether there is a consistent internal feature for 'power-seeking is beneficial' that generalizes across contexts—needs empirical verification.

**Direction:** Design a set of scenarios presenting choices between power-acquiring options and non-power-acquiring options for a language model acting as an agent. Using a small open model, probe residual stream activations for features that activate specifically when the model selects the power-acquiring option. Measure whether these features are consistent across different scenario types (resource acquisition, oversight avoidance, self-preservation). Use causal steering to suppress these features and measure whether power-seeking choice rates drop.

**Why it matters:** A generalizable, causally-verified 'power-seeking' feature would be among the most safety-relevant findings in interpretability. Even a null result (no such feature exists in current small models) is informative for calibrating where to focus detection efforts.

**Relevant context:** SPAR Spring 2026: 'Pre-Emptive Detection of Agentic Misalignment via Representation Engineering'. Apollo Research (2025): models attempt to disable oversight mechanisms. Schmidt Sciences 2026 Interpretability RFP targets deceptive behavior detection. Representation Engineering (Zou et al. 2023) on control vectors.
