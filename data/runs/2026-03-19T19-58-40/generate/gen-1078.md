# Refusal Feature Stability Benchmark: Do SAE-Identified Refusal Features Generalize Across Prompts?

**Problem:** A 2025 thesis evaluated SAE-based refusal features in LLMs but found evaluation was limited. No public benchmark exists that tests whether the specific SAE features identified as driving refusal behavior are consistent across diverse prompt phrasings of the same request. Features may be prompt-surface-form sensitive rather than semantics-sensitive.

**Direction:** Take a published SAE for a small model (e.g., Gemma-2-2B via Gemma Scope). Identify reported refusal-related features. Construct 20 prompt pairs that make the same harmful request using different surface forms. Measure activation rank consistency of the refusal features across prompt variants. Define a stability score as the fraction of pairs where both variants rank the refusal feature in the top 5 activations. Report results.

**Why it matters:** If refusal features are unstable across prompt phrasings, they cannot serve as reliable safety monitors or intervention targets. This benchmark would directly inform whether SAE-based safety mechanisms are robust.

**Relevant context:** 'Evaluation of Sparse Autoencoder-based Refusal Features in LLMs' (TU Wien, 2025) highlighted evaluation limitations. Gemma Scope 2 provides SAEs for Gemma-2-2B.
