# An Empirical Testbed for ELK Proposal Variants on Synthetic Deception

**Problem:** Several ELK solution proposals exist (probing, contrastive activation, relaxed adversarial training) but are rarely compared head-to-head on a controlled deception scenario. Which performs best when the model is explicitly trained to hide beliefs?

**Direction:** Create a dataset where a small language model is fine-tuned to give correct private answers but incorrect public answers (using separate system prompts). Implement and compare: (1) CCS probing, (2) logistic regression on activations, (3) activation difference vectors, and (4) a simple adversarial probe. Report accuracy and AUROC for each.

**Why it matters:** ELK solution comparison on a controlled benchmark directly tests which theoretical approaches have empirical traction. The controlled deception setup eliminates confounds present in natural text.

**Relevant context:** The 2025 arxiv paper on eliciting secret knowledge benchmarks multiple techniques. This project provides a smaller, fully reproducible version with explicit ground-truth deception rather than quirky fine-tuning.
