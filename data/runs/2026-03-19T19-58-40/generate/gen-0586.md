# How many tokens deep is alignment across model families? A comparative audit

**Problem:** Qi et al. showed safety alignment is concentrated in the first few output tokens for the models they tested, but it is unknown whether this shallowness is uniform across all major model families (Llama, Gemma, Mistral, Phi, Qwen). If shallowness varies substantially, it suggests different training pipelines produce qualitatively different alignment structures.

**Direction:** Extract the aligned and base versions of several small open-weight models (e.g., Llama-3.2-1B, Gemma-2-2B, Phi-3-mini, Qwen2.5-1.5B). For a fixed set of harmful prompts from StrongReject, measure the per-token KL divergence between the aligned and base model output distributions across the first 50 generated tokens. Plot alignment depth curves for each model family and compute a summary scalar (e.g., the token position at which KL drops below 10% of its peak). Correlate depth scores with publicly known safety benchmark scores (TrustLLM, AILuminate).

**Why it matters:** If some models are structurally deeper in alignment, this points to what training recipe differences matter. If all are equally shallow, it confirms the finding is systematic and architectural rather than accidental. Both outcomes directly guide where to invest in alignment improvements.

**Relevant context:** Qi et al. (ICLR 2025, arXiv:2406.05946) proposed the KL-based alignment depth metric and showed shallowness contributes to prefilling, adversarial suffix, and fine-tuning attacks. The GitHub repo (Unispac/shallow-vs-deep-alignment) provides reference code. Small models fit on a single Colab GPU.
