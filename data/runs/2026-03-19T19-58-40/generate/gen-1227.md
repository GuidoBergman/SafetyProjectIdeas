# HarmlessnessVsHelpfulness Trade-off Curve Tool

**Problem:** Alignment training involves a fundamental trade-off between harmlessness and helpfulness, but this trade-off is typically discussed qualitatively. No standardized tool measures this trade-off quantitatively across different RLHF configurations, making it hard to compare training recipes.

**Direction:** Build an evaluation tool that plots the 'alignment Pareto frontier' for a given model: evaluate helpfulness (accuracy on task benchmarks) and harmlessness (refusal rate on SORRY-Bench, safety scores on HH-RLHF test set) under multiple RLHF configurations varying the KL penalty coefficient. Produce a 2D trade-off curve. Run on Llama 3.1 8B using LoRA for efficiency.

**Why it matters:** Understanding the precise shape of the harmlessness-helpfulness trade-off curve would allow researchers to identify configurations that achieve the best balance and to compare training methods on their Pareto efficiency. This is a gap that practitioners face but no standard measurement tool addresses.

**Relevant context:** The HH-RLHF dataset is explicitly designed around the helpfulness-harmlessness trade-off. RLHF Deciphered (ACM Computing Surveys, 2025) discusses this trade-off conceptually. No tool currently produces a quantitative trade-off curve across RLHF hyperparameters.
