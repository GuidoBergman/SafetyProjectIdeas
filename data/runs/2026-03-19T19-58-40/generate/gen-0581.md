# Neuron Polysemanticity Before vs After Instruction Tuning: Does RLHF Reduce or Increase Polysemanticity?

**Problem:** Instruction tuning (SFT + RLHF) changes model behavior substantially. Whether it also changes the polysemanticity of individual neurons or SAE features—making the model more or less interpretable—has not been systematically measured on matched base/instruct pairs.

**Direction:** Compare Llama-3.2-1B base vs Llama-3.2-1B Instruct. Train SAEs on the same layer of each. Use automated labeling to assign concept counts per feature. Compare distributions of features-per-concept and concepts-per-feature. Measure dead feature rates and L0 sparsity.

**Why it matters:** If instruction tuning increases polysemanticity, it implies that aligned models are harder to interpret than base models, which would be a concerning finding for scalable oversight.

**Relevant context:** Llama-3.2-1B base and instruct variants are both publicly available on HuggingFace. SAELens supports both. Automated labeling via Neuronpedia's API. This directly tests whether alignment procedures affect the interpretability of representations.
