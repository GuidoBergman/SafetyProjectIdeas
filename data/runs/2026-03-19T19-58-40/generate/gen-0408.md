# Measuring Real Attack Success Rate Against Llama Guard 3 as an Output Filter

**Problem:** Meta's Llama Guard is widely recommended as a deployment safety layer alongside Llama models. How much it actually reduces ASR for state-of-the-art jailbreak attacks (prefilling, GCG, role-play), versus the raw model, and whether it introduces harmful false positive rates, has not been rigorously benchmarked.

**Direction:** Deploy Llama-3-8B-Instruct with and without Llama Guard 3 as an output filter. Run prefilling attacks, GCG suffixes from a public repository, and role-play jailbreaks on StrongReject prompts. Measure ASR and false positive rate (benign prompts incorrectly rejected) for both configurations. Estimate inference cost overhead.

**Why it matters:** Llama Guard is widely deployed as a safety measure but its effectiveness against adaptive jailbreaks has not been rigorously benchmarked. This provides practitioners with concrete, reproducible numbers on what Llama Guard actually delivers.

**Relevant context:** Llama Guard 3 is openly available on HuggingFace. StrongReject provides standardized scoring. Prior Llama Guard evaluations focus on classification accuracy rather than adaptive attacker ASR. This is a pure inference experiment combining two public models.
