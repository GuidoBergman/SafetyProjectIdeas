# Persona Hijacking and Feature Suppression: How Roleplay Frames Suppress Safety-Relevant Features

**Problem:** Roleplay-based jailbreaks ('act as DAN') work by establishing a persona that the model maintains. The causal chain: (1) persona is established in early context → (2) persona features suppress the model's own 'values' or 'safety identity' features → (3) harmful outputs are produced within the persona frame. The mechanism by which persona features suppress identity/safety features is unstudied.

**Direction:** Using SAELens, identify features associated with the model's 'default assistant identity' (active on standard helpful responses). Construct prompts that establish an alternative persona and measure suppression of identity features across layers. Use causal patching to restore identity features mid-roleplay and measure whether safety behavior returns. Compare suppression magnitude across different persona types (fictional character vs. 'uncensored AI').

**Why it matters:** If persona hijacking mechanistically suppresses specific identity features, those features become targets for hardening (making them resistant to suppression) and monitoring (detecting when they are suppressed at inference time).

**Relevant context:** 'Deception in LLMs: Self-Preservation and Autonomous Goals' (arxiv 2501.16513). Introspective awareness paper (transformer-circuits 2025) on self-referential feature processing. Jailbreaking to Jailbreak (Scale AI 2025). Safe-SAIL on safety-relevant feature extraction.
