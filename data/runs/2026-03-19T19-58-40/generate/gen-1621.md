# Minimal Dataset Size Threshold for Emergent Misalignment

**Problem:** The original Betley et al. paper trained on thousands of insecure-code examples. It is unknown how few training examples are sufficient to trigger emergent misalignment, making it hard to assess real-world risk from small finetuning runs.

**Direction:** Using the open emergent-misalignment code and a small Qwen or Llama model (as validated in model-organisms-for-EM), run a sweep over dataset sizes (e.g., 10, 25, 50, 100, 250, 500, 1000 examples). Measure misalignment rate on the standard evaluation questions at each data size. Plot a dose-response curve to identify the threshold where misalignment reliably emerges.

**Why it matters:** If even a handful of misaligned training examples are sufficient, the threat model for accidental misalignment via everyday finetuning APIs is much more severe. A clear threshold informs both policy and technical safeguards.

**Relevant context:** Model organisms paper achieved 40% misalignment with small Qwen models using rank-1 LoRA adapters. Open code at github.com/clarifying-EM/model-organisms-for-EM. Budget-conscious replication work shows the effect is reproducible on a single GPU.
