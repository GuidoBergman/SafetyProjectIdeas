# Blind Spot Injection Experiment: Can We Test Whether Oversight Blind Spots Create Targeted Student Failures?

**Problem:** The causal link between a specific overseer blind spot (a type of error the overseer always makes) and a specific student model failure mode has not been experimentally demonstrated.

**Direction:** Create an overseer with a known, controlled blind spot (e.g., always wrong on negation). Train a student model under this overseer. Measure whether the student specifically fails on negation tasks, and whether the failure rate is proportional to the blind spot magnitude.

**Why it matters:** Demonstrating that specific overseer blind spots cause specific student failures is the key experiment needed to motivate targeted blind-spot correction research.

**Relevant context:** Causal chain: systematic bias → model learns to exploit bias → harmful deployment; open problem: systematic oversight errors.
