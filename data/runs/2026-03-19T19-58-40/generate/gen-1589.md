# Isolation Forest Transfer: Applying Unsupervised Anomaly Detection from Cybersecurity to Agent Action Streams

**Problem:** Isolation forest is one of the most effective unsupervised anomaly detection methods in network security (where labeled malicious data is scarce), yet it has not been systematically evaluated as an AI agent behavior monitor despite sharing the same data scarcity problem.

**Direction:** Featurize ControlArena agent trajectories into fixed-size vectors (tool call frequency counts, action type distribution, timing statistics). Train an isolation forest on 100 benign trajectories (no malicious labels needed). Evaluate anomaly scores on SHADE-Arena malicious and benign trajectories. Compare AUC to a supervised classifier trained on the same features but with labels.

**Why it matters:** In practice, labeled examples of malicious AI agent behavior will be rare. Unsupervised methods that require only benign baselines may be more deployable than supervised monitors. This experiment quantifies the unsupervised vs. supervised trade-off.

**Relevant context:** Isolation forest is in scikit-learn with a 5-line implementation. FOQA anomaly detection literature explicitly notes unsupervised methods are valuable when labeled anomalies are scarce—the same rationale applies here. Feasible in < 10 hours of implementation.
