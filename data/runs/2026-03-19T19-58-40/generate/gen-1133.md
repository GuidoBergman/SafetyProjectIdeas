# Consistency Failure Analysis: When Does the Same Task Elicit Different Oversight Decisions?

**Problem:** Inconsistent oversight (same input receiving different labels across time or evaluators) is a form of systematic failure that introduces noise and potential exploitation into training signals.

**Direction:** Present the same task to the same overseer (model or human) multiple times with varying surface features (wording, ordering). Measure inconsistency rates and test whether student models trained on inconsistent labels learn to exploit the inconsistencies.

**Why it matters:** Inconsistency creates a gap between the overseer's intended behavior and the signal the student model receives. Characterizing inconsistency is part of the overseer bias mapping problem.

**Relevant context:** Open problem: systematic oversight errors; overseer bias mapping.
