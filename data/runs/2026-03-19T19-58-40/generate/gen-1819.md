# Feature Geometry of Rhyme Representations: Are Rhyme Classes Linearly Separable in the Residual Stream?

**Problem:** Attribution graphs identify which features activate for rhyme planning but do not characterize the geometric structure of how rhyme classes are organized in activation space. It is unknown whether rhyme families (e.g., -ight words, -ation words) form distinct linear subspaces.

**Direction:** Collect activations at the layer where rhyme planning is most active (informed by prior probing) for a large set of rhyming and non-rhyming word pairs. Apply PCA and linear probing to test whether rhyme class membership is linearly decodable. Measure clustering by rhyme family versus semantic family.

**Why it matters:** Linear separability of rhyme features would suggest a clean representational geometry consistent with the linear representation hypothesis and validate interpretability methods that rely on it.

**Relevant context:** Linear probing and PCA on residual stream activations are standard TransformerLens workflows accessible to beginners. The rhyme planning claim is grounded in Anthropic's 2025 paper.
