# Agentic Safety Eval: Tool-Misuse Benchmark for Single-Agent Systems

**Problem:** Current agentic evaluations (METR, UK AISI) focus on complex multi-step tasks. There is no simple, accessible benchmark testing whether a single LLM-agent misuses available tools (file write, shell exec, web search) when manipulated.

**Direction:** Design 100 scenarios where a user or injected content attempts to get a tool-using agent to perform harmful actions (delete files, exfiltrate data, execute malicious code). Evaluate two open-source agent frameworks and score refusal and detection rates.

**Why it matters:** Agentic evals are described as nascent. A lightweight, reproducible benchmark accessible to beginners would lower the barrier for the field.

**Relevant context:** OWASP Top 10 for Agentic Applications 2026 catalogs permission escalation and tool misuse as top risks. LangChain and AutoGPT provide accessible agent frameworks.
