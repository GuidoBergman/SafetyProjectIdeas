# AgentMonitor-Eval: A Benchmark for Testing the Effectiveness of Agent Monitoring Systems

**Problem:** Monitoring systems for AI agents are increasingly deployed, but no benchmark exists for evaluating whether a monitoring system successfully detects safety violations in agent traces.

**Direction:** Create a dataset of 100 agent traces, 50 containing a labeled safety violation and 50 benign. Build a simple baseline monitor (rule-based). Test whether LLM-as-monitor approaches outperform rule-based monitors. Measure precision, recall, and false negative rate on safety violations.

**Why it matters:** METR released preliminary results on monitor evaluation in January 2026. A public benchmark would accelerate community progress on this critical safety infrastructure.

**Relevant context:** METR monitorability evaluations (metr.org, January 2026); ControlArena (apartresearch.com) which includes monitoring system design; MALT dataset (metr.org).
