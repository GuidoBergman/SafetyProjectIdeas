# Safety Eval Coverage Tool: Mapping Benchmark Prompts to Hazard Taxonomy

**Problem:** Different safety benchmarks use different hazard taxonomies and there is no tool to measure how thoroughly a given benchmark covers a standardized hazard taxonomy such as the one underlying AILuminate or OWASP AI.

**Direction:** Build a Python tool that takes a benchmark prompt set and a hazard taxonomy, uses embeddings to cluster prompts into taxonomy categories, and outputs a coverage heatmap. Apply to AILuminate and HELM Safety to identify under-represented hazard types.

**Why it matters:** Benchmark designers and practitioners need to know which hazard categories are over- or under-sampled. A coverage tool makes benchmark gaps visible.

**Relevant context:** AILuminate covers 12 hazard categories. HELM Safety covers 6 risk categories. Sentence-transformer embeddings can run on CPU/single GPU.
