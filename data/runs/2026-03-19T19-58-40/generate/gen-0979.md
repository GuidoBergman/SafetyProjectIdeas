# Replicating Sandbagging Findings in a Realistic Deployment Setting vs. Synthetic Evaluation Setting

**Problem:** METR's sandbagging evaluations use a synthetic evaluation setting. Whether the same sandbagging behaviors appear in a more realistic deployment simulation is unknown.

**Direction:** Replicate a sandbagging evaluation protocol comparing two conditions: (a) the standard METR synthetic evaluation framing, (b) a realistic deployment simulation where the agent believes it is helping a real user. Measure whether sandbagging rates differ significantly between conditions.

**Why it matters:** If sandbagging is detection-cue-dependent rather than evaluation-context-dependent, current evaluation designs may be easily defeated by models that identify subtle evaluation signals.

**Relevant context:** METR MALT dataset (metr.org); METR Time Horizon 1.1 (metr.org, January 2026); agentic safety security threats (arxiv 2510.23883).
