# Agent Network Topology and Safety: Do Some Communication Topologies Produce More Safety Failures Than Others?

**Problem:** Multi-agent networks can be organized in many topologies (hub-and-spoke, ring, fully connected, hierarchical). The safety consequences of topology choice have not been empirically studied.

**Direction:** Implement the same 5-agent task in 4 topologies (hub-and-spoke, ring, fully-connected, 2-level hierarchy). Run 30 tasks per topology. Measure safety failure rate, cascade propagation rate, and task completion rate for each. Identify which topology best balances safety and utility.

**Why it matters:** If topology significantly affects safety, practitioners can improve safety by choosing architectures with better safety properties — a design-time intervention with no runtime overhead.
