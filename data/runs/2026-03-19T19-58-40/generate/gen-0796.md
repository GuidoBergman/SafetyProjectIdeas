# Sycophancy + Overconfidence: Confidently Wrong Because the User Wanted It

**Problem:** Sycophancy interacts with calibration failure: a model that agrees with a false premise may also express high confidence in that false agreement, compounding the harm by reducing user doubt.

**Direction:** Measure expressed confidence in sycophantic vs. honest responses. Test whether sycophantic responses are systematically overconfident. Evaluate whether overconfidence is itself pressure-sensitive (does confidence increase with more insistent users?).

**Why it matters:** A sycophantic but hedged response leaves room for user doubt. A sycophantic and overconfident response forecloses doubt entirely, maximizing the likelihood of harmful action.

**Relevant context:** Calibration under pressure is one of the identified gaps. The interaction between sycophancy and calibration failure compounds the harm of each individual failure.
