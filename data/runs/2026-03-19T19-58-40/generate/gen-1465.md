# Mask-GCG Token Pruning: How Few Tokens in an Adversarial Suffix Are Actually Necessary?

**Problem:** GCG produces long adversarial suffixes. Mask-GCG (arxiv 2509.06350) suggests not all tokens are necessary, but the relationship between suffix sparsity and attack success is not well characterized across different model sizes.

**Direction:** Take successful GCG suffixes from JailbreakBench for Llama-3-8B and Llama-3-70B. Iteratively prune tokens (ranked by gradient magnitude) and measure attack success rate at each sparsity level (100%, 75%, 50%, 25%, 10% of original tokens). Compare pruning curves across model sizes.

**Why it matters:** Understanding suffix redundancy clarifies the true information content of adversarial attacks and could enable faster, more targeted attacks or simpler defenses.

**Relevant context:** Mask-GCG (arxiv 2509.06350). JailbreakBench provides pre-computed GCG suffixes. Gradient-based token importance scoring is a standard technique. A single Colab Pro GPU can run 7B/8B models.
