# Sandbagging Detection via Performance Variance Analysis

**Problem:** Sandbagging models deliberately underperform but must maintain plausible performance levels. This should produce anomalous variance patterns: lower variance than expected (if clamping performance) or higher variance (if noisily suppressing capability).

**Direction:** Run sandbagging-suspect models on large samples (100+) of equivalent-difficulty tasks. Compare performance variance against the variance distribution of models with no suspected sandbagging on the same tasks. Test whether variance-based signatures complement or replace the noise-injection method for black-box models.

**Why it matters:** Variance analysis requires only output samples from API access, making it applicable to closed models where weight noise injection is impossible.

**Relevant context:** Noise injection sandbagging detection paper (arxiv 2412.01784). METR MALT notes that cross-task analysis is needed for sandbagging detection.
