# Replicating SAE Monosemanticity Results for Vision-Language Model (CLIP) on Non-English Image Captions

**Problem:** SAE monosemanticity results in VLMs (Bricken et al. 2025, arXiv:2504.02821) were demonstrated primarily using English image captions. CLIP was trained on multilingual web data, and it is unclear whether the same clean monosemantic features appear when the model processes non-English text paired with images, or whether multilingual features are more polysemantic.

**Direction:** Using Prisma/ViT-Prisma, load CLIP ViT-L/14 and its pre-trained SAEs. Run image-caption pairs from a multilingual captioning dataset (e.g., Multi30k German/French captions paired with original Flickr30k images). Compare SAE feature activation patterns and monosemanticity scores between English and non-English captions for the same images. Identify features that activate consistently across languages (language-invariant visual concepts) vs those that are language-specific.

**Why it matters:** Multimodal AI systems deployed globally process non-English content, but interpretability research overwhelmingly focuses on English. If CLIP's vision features are robust across languages but text features are language-specific, it informs how to build interpretability pipelines for multilingual safety monitoring of multimodal AI.

**Relevant context:** 'Sparse Autoencoders Learn Monosemantic Features in Vision-Language Models' (arXiv:2504.02821, OpenReview 2025) demonstrated monosemanticity in CLIP. Prisma (arXiv:2504.19475) provides the toolkit and pre-trained SAE weights. Multi30k dataset provides German and French captions for Flickr30k images. The insight that CLIP internal representations are less sparse than language SAEs (Prisma paper) is the baseline finding.
