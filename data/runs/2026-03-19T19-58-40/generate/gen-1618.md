# Monitoring Protocol Ablation Study: What Happens to Safety When Each Layer of a Control Protocol Is Removed?

**Problem:** Multi-layer control protocols are assumed to provide defense-in-depth, but the marginal contribution of each layer (monitor, sandbox, human review, audit log) has never been measured by systematically removing layers and measuring safety degradation.

**Direction:** Using a ControlArena control protocol with 4 layers, run SHADE-Arena sabotage attempts against the full protocol and against each 3-layer ablation (removing one layer at a time). Measure sabotage success rate and task completion rate for each configuration. Identify which layer removal causes the largest safety degradation and which layer is most redundant.

**Why it matters:** Ablation studies are standard in ML research but rare in safety protocol evaluation. Knowing which layers provide the most safety value guides resource allocation—whether to invest in improving the most critical layer or the most redundant one.

**Relevant context:** ControlArena supports configuring which protocol components are active. SHADE-Arena provides labeled sabotage attempts. This is a controlled experimental design requiring only configuration changes and measurement.
