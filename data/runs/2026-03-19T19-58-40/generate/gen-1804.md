# Linguistic Minimal Pair Testing Borrowed from Phonology

**Problem:** Circuit analyses often use a single prompt style, making it unclear whether the identified circuit is specific to that prompt structure or reflects a general algorithm.

**Direction:** Apply the phonology minimal pair method: construct pairs of prompts that differ by exactly one semantic or syntactic feature (the 'phoneme contrast'), run circuit analysis on both, and measure the difference in active circuit components. Systematically catalog which circuit changes are caused by which linguistic features.

**Why it matters:** Phonological minimal pairs isolate the causal contribution of a single contrastive feature. Applying this paradigm to circuits would produce a systematic catalog of what circuit components are specific to surface form versus deep semantic content — a more controlled experimental design than is standard in current mech interp.

**Relevant context:** Minimal pair testing is standard in linguistics and psycholinguistics. IOI (Indirect Object Identification) circuit analysis already implicitly uses this but does not systematize it. TransformerLens makes per-component comparison straightforward.
