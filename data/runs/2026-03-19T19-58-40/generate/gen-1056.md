# Replicating SAE Reconstruction Loss Findings: When Do Vision SAEs Improve Model Performance?

**Problem:** Prisma (2025) made the surprising finding that in some cases, SAE reconstructions decrease model loss compared to original activations — an effect not consistently observed in language model SAEs. It is unknown which model-layer combinations produce this effect and whether it is an artifact of SAE underfitting or a genuine property of vision model activations.

**Direction:** Using Prisma with pre-trained SAEs for multiple CLIP ViT layers, systematically measure reconstruction loss (substitution loss) vs original model loss across all layers and at different SAE expansion factors. Plot the fraction of layers where SAE reconstruction improves vs degrades performance. Test whether the improvement correlates with L0 sparsity, layer depth, or the SAE's expansion ratio.

**Why it matters:** If SAE reconstruction can improve model performance, it suggests the SAE is performing a form of denoising — capturing the 'signal' while discarding high-frequency noise in the activations. This would fundamentally alter how we understand what SAEs are measuring: they may be finding more interpretable features than the model itself uses, making their features a potentially better basis for safety analysis than raw activations.

**Relevant context:** Prisma (arXiv:2504.19475) explicitly reports that 'in some instances, SAE reconstructions can decrease model loss' as a surprising finding for vision SAEs. This was not consistently observed in language model SAE literature (Cunningham et al., 2023; Bricken et al., 2023). The Prisma toolkit provides the pre-trained weights and evaluation framework to replicate and extend this finding systematically.
