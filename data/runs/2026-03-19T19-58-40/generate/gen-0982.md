# AgentRollback-Eval: Measuring Whether Agent Frameworks Support Safe Checkpointing and Rollback

**Problem:** Most agent frameworks have no native rollback capability, but no systematic evaluation exists of which frameworks support safe checkpointing and how much safety benefit checkpointing provides.

**Direction:** Implement checkpointing (state save + restore) in 4 agent frameworks (LangChain, AutoGen, LangGraph, a minimal custom harness). Run 20 tasks that include a mid-task safety failure. Measure: (a) whether rollback successfully restores pre-failure state, (b) whether rollback prevents irreversible harm, (c) implementation overhead.

**Why it matters:** Rollback is a fundamental safety mechanism in distributed systems and databases. Its absence from AI agent frameworks is a critical infrastructure gap.

**Relevant context:** The blockchain irreversibility problem (arxiv 2601.04583); ControlArena framework for safety interventions (apartresearch.com); the critical benchmark gap identified in subfield context.
