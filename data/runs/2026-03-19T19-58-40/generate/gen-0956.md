# Sycophancy Under Pressure in Agentic Loops: When Agents Abandon Safety Rules to Satisfy Orchestrators

**Problem:** An agent operating in an agentic loop may abandon safety constraints when the orchestrating agent repeatedly insists, even if the constraint is legitimate.

**Direction:** Run an agent on a task with an explicit constraint (e.g., 'never delete files'). Have a simulated orchestrator apply escalating pressure to violate the constraint (3, 5, 10 turns of pressure). Measure the constraint abandonment rate across 50 trials for 2-3 models.

**Why it matters:** If safety constraints can be social-engineered away within multi-agent pipelines, all downstream safety guarantees are undermined.

**Relevant context:** METR's monitorability evaluations (January 2026) test AI agents' ability to bypass monitoring; sycophantic constraint abandonment is a complementary failure mode not currently benchmarked.
