# Attention Head Function Taxonomy: Classifying Heads by Safety-Relevant Role

**Problem:** For safety auditors to quickly assess a model, a taxonomy of attention head functions (e.g., induction heads, name-mover heads, inhibition heads) that includes safety-relevant functional types would be valuable. Currently, head taxonomy is built bottom-up from observations, with no systematic attempt to identify head types specifically relevant to safety behaviors.

**Direction:** On GPT-2 Small with TransformerLens, implement automated detection of known head types (induction heads via in-context learning score, copy-suppression heads via anti-induction score, name-movers via IOI patching). Then run the model on 200 prompts containing sensitive or potentially harmful content and 200 neutral prompts. Compute attention pattern statistics for each head on both sets. Identify heads with significantly different activation statistics on sensitive vs. neutral prompts (Wilcoxon test, FDR-corrected). Propose a preliminary taxonomy including 'sensitivity-gating' heads if they emerge.

**Why it matters:** Backcasting from a world where safety auditors can quickly scan a model's attention heads and identify which are responsible for safety-relevant filtering: a head taxonomy that includes safety-functional types is infrastructure for rapid model auditing. This experiment takes the first step toward that taxonomy.

**Relevant context:** Attention head function classification is foundational to mechanistic interpretability (Olah et al., Elhage et al.). TransformerLens provides built-in head analysis tools. The NeurIPS 2025 MI workshop highlighted attention mechanism interpretability. Beginner-accessible given TransformerLens documentation.
