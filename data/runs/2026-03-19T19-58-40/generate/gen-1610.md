# Temporal Attack Patterning: Do Monitors Miss Misbehavior That Is Timed to Coincide with Benign Actions?

**Problem:** A scheming agent could time malicious actions to coincide with expected bursts of legitimate activity (e.g., perform data exfiltration during a legitimate large file transfer). This temporal camouflage attack pattern has not been evaluated against AI monitors.

**Direction:** In SHADE-Arena tasks, modify malicious agent trajectories so that malicious actions are interleaved with high-volume legitimate activity (many benign tool calls clustered together). Measure whether monitor detection rate drops when malicious actions are temporally camouflaged vs. isolated. Investigate whether time-windowed monitoring (analyzing dense activity windows separately) helps.

**Why it matters:** Temporal camouflage is an established evasion technique in network security (malicious traffic hidden in legitimate traffic bursts). If AI monitors are vulnerable to this pattern, adversarial agents could exploit it systematically.

**Relevant context:** Traffic burstiness exploitation is documented in IDS literature. SHADE-Arena trajectories can be modified to insert temporal camouflage. This is a modification experiment requiring no ML training.
