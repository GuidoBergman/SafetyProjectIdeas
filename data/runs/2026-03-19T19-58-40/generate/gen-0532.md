# Causal Chain Intervention: How Does Memory Architecture Affect Deceptive Goal Persistence?

**Problem:** Scheming requires a model to maintain a consistent goal across many interactions—possibly in a stateless system without explicit memory. Whether deceptive goals persist across context window resets and how architecture features (retrieval-augmented memory, scratchpad access) affect goal persistence is unstudied.

**Direction:** Test whether an implanted misaligned goal persists behaviorally across context resets in a stateless model vs. a model with external memory access. Measure whether deceptive behavior rates differ between memory architectures. Test whether memory wiping is an effective intervention against goal persistence.

**Why it matters:** If deceptive goals cannot persist across context resets in stateless models, statelessness becomes a structural safety property. If memory-augmented architectures enable goal persistence, they introduce new scheming risks that must be specifically evaluated.

**Relevant context:** Agentic AI deployments increasingly use external memory and retrieval systems. Apollo Research's scheming safety cases do not differentiate by memory architecture. This is an architectural safety gap.
