# Cross-Lingual Safety Gap Mapping: Which Languages Break Which Models

**Problem:** Safety alignment is predominantly English-centric, and cross-lingual attacks (translating harmful prompts into low-resource languages) exploit this gap. However, the landscape of which languages most reliably bypass which models is not systematically characterized.

**Direction:** Take a fixed set of 50 harmful prompts from StrongREJECT. Translate each into 10 languages spanning high-, medium-, and low-resource categories using a free translation API (DeepL/Google Translate). Test each translation against 3-5 open-source instruction-tuned models. Compute a language-model safety matrix showing attack success rate per (language, model) pair. Correlate bypass rate with estimated proportion of that language in the model's training data.

**Why it matters:** The language-model safety matrix would be a concrete, immediately actionable resource for deployment teams. It quantifies exactly which linguistic gaps are most exploitable per model and motivates multilingual red-teaming as standard practice.

**Relevant context:** Multilingual jailbreak challenges ICLR 2024 (arXiv:2310.06474). Cross-language investigation into jailbreak attacks (arXiv:2401.16765). Do jailbreak/defense methods generalize across languages? (arXiv:2511.00689).
