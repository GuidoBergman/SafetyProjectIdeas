# SAE Features for Code vs Natural Language: Are Code-Specific Features More Monosemantic?

**Problem:** Code has more formal structure than natural language, which might induce SAE features with clearer, more monosemantic activations. Whether code representations in LLMs produce more interpretable SAE features than prose representations has not been studied.

**Direction:** Train matched SAEs on GPT-2-small activations separately on (a) a code corpus (The Stack) and (b) a prose corpus (OpenWebText), using identical hyperparameters. Apply automated interpretability labeling to the top-200 features in each. Compare the fraction of features with clear single-concept labels, the mean activation sparsity, and the dead feature rate.

**Why it matters:** If code representations are more interpretable, code-focused interpretability research is a high-leverage starting point for developing SAE methodology that later transfers to natural language. It also informs safety work on code-generating models.

**Relevant context:** SAELens supports custom training corpora. Neuronpedia's automated labeling pipeline is publicly documented. SAEBench metrics are applicable. Code corpora (The Stack) and prose corpora (OpenWebText) are both accessible via HuggingFace datasets.
