# Probing for Hidden Beliefs: An Empirical ELK Baseline on Small Transformers

**Problem:** ELK proposes that models encode true beliefs distinct from stated outputs, but this is hard to verify empirically. Do probes trained on a model's activations actually track ground truth rather than surface statistics?

**Direction:** Train a small transformer (GPT-2 scale) on a synthetic dataset where the model is reward-fined to output false statements. Apply linear probes, contrast-consistent search (CCS), and logistic regression on activation pairs to see whether any method recovers ground-truth labels the model's output denies. Compare probe accuracy across layers and report which layer best separates 'believed' from 'stated'.

**Why it matters:** ELK is a core theoretical proposal for detecting deceptive AI. Empirical tests on toy models establish whether its assumptions hold even in minimal settings, giving concrete evidence about feasibility before scaling.

**Relevant context:** EleutherAI's quirky-LM work (2024) showed linear probes recover 89% of the truth gap in AUROC; the 2025 arxiv work on eliciting secret knowledge benchmarks multiple black-box and white-box techniques. This project replicates the core setup at smaller scale with full control over ground truth.
