# Does SAE Width Selection Create a Researcher Degree of Freedom That Inflates Interpretability Claims?

**Problem:** Researchers choose SAE width (dictionary size) before analyzing features, and different widths produce different feature decompositions. A known failure mode is that researchers may implicitly or explicitly choose the width that produces the most interpretable-looking features, creating a researcher degree of freedom that inflates apparent interpretability. SAEBench showed that proxy metrics do not reliably predict which width produces more useful features, suggesting width selection is non-trivial.

**Direction:** Using SAELens on GPT-2 small, train SAEs at 7 widths (1k, 2k, 4k, 8k, 16k, 32k, 64k) on layer 6. For each width, compute: (1) standard proxy metrics (L0 sparsity, reconstruction MSE), (2) a downstream probe accuracy on 3 tasks (sentiment, named entity presence, grammatical number), (3) human-rated semantic coherence for a random sample of 30 features per width. Plot all three metrics against width and test whether they are correlated (i.e., does the width that maximizes proxy metrics also maximize probe accuracy and human coherence?). If they are uncorrelated, document this as evidence for the researcher-degree-of-freedom problem.

**Why it matters:** If proxy metrics don't predict useful width choices, then researchers can always find a width that makes their claimed features look clean—without that being informative about true model interpretability. This is a meta-scientific failure mode that affects the credibility of the entire SAE literature.

**Relevant context:** SAEBench (ICML 2025) explicitly found that gains on proxy metrics don't translate to downstream task performance. This experiment is a focused follow-up that tests whether width selection specifically is affected by this decoupling.
