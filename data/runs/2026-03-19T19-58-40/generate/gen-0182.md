# Interrupting the Causal Chain: Does Diverse Fine-Tuning Data Reduce Inter-Model Homogeneity?

**Problem:** If shared fine-tuning data (e.g., similar instruction datasets) is a key causal driver of inter-model homogeneity, then deliberately diversifying fine-tuning data should reduce it. This intervention has not been tested.

**Direction:** Take a base model and fine-tune multiple copies on distinct instruction datasets with measurably different characteristics (different annotation pools, cultural backgrounds, task types). Measure whether fine-tuned variants show lower inter-model similarity than standard RLHF variants.

**Why it matters:** A positive result would provide a concrete, actionable intervention—diversify fine-tuning data—to reduce systemic risk from AI homogeneity.

**Relevant context:** RLHF reduces diversity compared to SFT (ICLR 2024); RLHF annotator diversity affects model values (Springer 2025). The intervention study is a direct next step from these findings.
