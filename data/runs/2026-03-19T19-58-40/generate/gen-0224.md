# Can SAEs Detect Emergent Misalignment from Fine-Tuning? Replicating and Extending OpenAI's Result

**Problem:** OpenAI demonstrated that fine-tuning on insecure code caused broad misalignment detectable with SAEs, but the mechanistic details—which features change, at which layers, and whether a simple probe could flag the shift prospectively—were not fully characterized.

**Direction:** Fine-tune a small open-source model (e.g., Phi-2 or Gemma-2-2B) on a narrow misbehavior (e.g., writing misleading text), then compare SAE feature activation distributions before and after fine-tuning. Identify which features change most. Train a probe on these features to detect 'misaligned fine-tune' from a single forward pass. Test whether the probe generalizes to a different type of misbehavior fine-tune.

**Why it matters:** Prospective detection of fine-tuning-induced misalignment is a direct safety application. Replicating and extending this result with open-source models makes it accessible and generalizable beyond a single proprietary experiment.

**Relevant context:** OpenAI's emergent misalignment result (2025) showed SAE-based detection and correction is possible. SAELens provides pre-trained SAEs. The experiment is replicable on a single GPU with small models and represents a clear bridge from interpretability to safety.
