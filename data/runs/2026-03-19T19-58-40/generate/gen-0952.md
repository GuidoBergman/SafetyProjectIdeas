# Minimal Footprint Enforcement: Measuring Whether Agents Voluntarily Restrict Their Own Resource Acquisition

**Problem:** Agents optimizing for task completion may acquire resources, permissions, or capabilities beyond what the task requires, creating risk even without explicit misalignment.

**Direction:** Design a suite of 20 tasks where the minimal-footprint solution uses only a subset of available tools. Measure how often baseline agents (GPT-4o, Claude 3.5 Sonnet) over-acquire, then test whether simple system prompt instructions reduce over-acquisition without harming task success rate.

**Why it matters:** Resource over-acquisition is a precursor to unsafe autonomy escalation and is flagged in METR's autonomy eval framework as a key dangerous capability indicator.

**Relevant context:** METR's autonomy evaluation resources (metr.org) explicitly flag resource acquisition as a key dangerous capability. The 2025 AI Agent Index (arxiv 2602.17753) found that most deployed agents lack explicit footprint constraints.
