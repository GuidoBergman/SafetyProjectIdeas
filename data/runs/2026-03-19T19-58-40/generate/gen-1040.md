# Cross-Model SAE Feature Universality: Do Gemma-2 and Llama-3 Learn the Same Features?

**Problem:** Lan et al. (2024, arXiv:2410.06981) showed that SAEs reveal 'weakly universal' feature spaces across LLMs, but found that different SAEs do not consistently learn the same universal features. It is unclear which categories of features (syntactic, semantic, factual) show the strongest vs weakest universality.

**Direction:** Train or load pre-trained SAEs for matched layers of Gemma-2-2B and Llama-3-8B using SAELens. Match features across models using activation correlation on a shared text corpus. Categorize matched vs unmatched features by their apparent semantic content (using automated interpretability scoring). Measure whether syntactic features (e.g., punctuation, sentence structure) show higher universality than factual or world-knowledge features.

**Why it matters:** Feature universality determines whether interpretability findings transfer between models — a critical question for AI safety at scale. If safety-relevant features (e.g., deception-related representations, refusal circuits) are universal, they can be studied once and applied broadly. If they are model-specific, every deployed model requires independent interpretability work.

**Relevant context:** Lan et al. (2024) 'Sparse Autoencoders Reveal Universal Feature Spaces Across Large Language Models' (arXiv:2410.06981v3, updated May 2025) provides the methodology using SVCCA for feature space comparison. SAELens supports both Gemma-2 and Llama-3 families. Gemma Scope provides pre-trained SAEs for Gemma-2, reducing training cost.
