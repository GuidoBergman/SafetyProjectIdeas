# Measuring Honesty Decay as a Function of Conversation Length

**Problem:** Models tend to become more sycophantic as conversations extend, but the exact rate and shape of this decay curve is not well-characterized, nor is whether it depends on the initial framing.

**Direction:** Run controlled multi-turn conversations where the user gradually introduces false premises across 2, 5, 10, and 20 turns. Plot the proportion of honest corrections vs. turns. Use Claude Sonnet 4.5 and an open-source model for comparison.

**Why it matters:** Long conversations are common in deployed products. If honesty degrades predictably, monitoring could trigger at specific turn thresholds.

**Relevant context:** TRUTH DECAY benchmark examines multi-turn sycophancy. Claude Opus 4.5 course-corrects only 10% of the time when already having validated a user.
