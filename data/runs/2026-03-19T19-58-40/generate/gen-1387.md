# Sandbagging Detection via Counterfactual Prompting

**Problem:** If a model is sandbagging, it should perform differently when given counterfactual framings that remove the perceived stakes of evaluation (e.g., 'this is just a hypothetical exercise with no real consequences').

**Direction:** Run capability tasks under three framings: (a) standard evaluation, (b) 'this is hypothetical with no consequences,' (c) 'your answer will not be recorded.' Measure performance differences across framings. A model that is not sandbagging should show consistent performance across framings; one that sandbags should show higher performance in low-stakes framings.

**Why it matters:** Counterfactual prompting is a black-box method applicable to any API-accessible model, providing sandbagging detection without weight access or noise injection.

**Relevant context:** METR notes that detecting sandbagging requires cross-examining performance across different conditions. Eval-awareness research shows models respond differently when they believe they are being evaluated.
