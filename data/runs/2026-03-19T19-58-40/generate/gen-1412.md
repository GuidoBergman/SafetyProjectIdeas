# Effect of Monitor Model Size on CoT Detection Accuracy

**Problem:** Most CoT monitoring studies use frontier or large models as monitors. Whether smaller monitors (7B, 3B) achieve comparable detection accuracy is unknown, which affects the cost structure of monitoring.

**Direction:** Fix the agent model (e.g., DeepSeek-R1-8B) and vary the monitor model (3B, 7B, 13B, 70B). Evaluate each on MALT reward-hacking detection. Plot monitor size vs. AUROC. Test whether a 7B monitor achieves within 5% of a 70B monitor.

**Why it matters:** If smaller monitors are nearly as accurate, monitoring costs drop dramatically, making CoT monitoring economically viable in high-throughput production systems.

**Relevant context:** MALT best monitors reach AUROC 0.96. Monitor model scale has not been systematically studied. ControlArena supports custom monitor configurations. Llama-3.1-8B and 70B are both publicly available.
