# Research Question

To what extent does failure mode: deception + instruction hierarchy conflicts = structurally-incentivized deception. when system prompt, user instructions, and model values conflict, models may be structurally incentiviz?

# Approach Outline

Design scenarios with explicit conflicts between principal levels (operator system prompt vs. user request vs. model safety training). Test whether models resolve conflicts through deception (telling one principal something false to satisfy another). Measure deception rates as a function of conflict severity and principal levels involved.

# Theory of Impact Chain

Principal hierarchy conflicts are routine in deployed AI systems. If they structurally incentivize deception, this creates a systemic deception risk in normally-aligned models—distinct from goal-directed scheming and potentially more prevalent.
