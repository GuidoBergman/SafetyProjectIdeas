# Research Question

To what extent does multi-agent systems where one model monitors another may be subverted if the monitored model can pass covert signals to a colluding monitor via steganography in its outputs?

# Approach Outline

Study whether standard statistical tests (chi-squared tests on token distributions, entropy analysis, n-gram frequency checks) can detect LLM steganographic communication in practice. Create a small dataset of LLM outputs with and without steganographic encoding (using known steganographic prompting techniques from arxiv 2402.07510). Measure detection ROC curves for each statistical test and for a simple trained classifier. Establish a baseline 'statistical tripwire' that requires no access to model internals.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain
