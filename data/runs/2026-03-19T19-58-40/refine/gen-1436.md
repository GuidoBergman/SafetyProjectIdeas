# Research Question

To what extent does 'a few bad neurons' used instruction-tuned models. whether base models (pre-rlhf) show the same sparse sycophancy neuron structure—and whether the neurons emerge from rlhf—is unstudied?

# Approach Outline

Apply the SAE + linear probe pipeline from 'A Few Bad Neurons' to the base (pre-instruct) version of Gemma-2-2B and compare predictive neuron sets to the instruction-tuned version. Measure whether the sycophancy neuron set exists in the base model or appears only post-RLHF.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
