# Research Question

To what extent does metr's task suite results are obtained in a specific evaluation environment. it is unknown whether the same capability scores obtain when the same model is wrapped in a different agent framework?

# Approach Outline

Select 10 METR tasks from the publicly available task suite. Run them with GPT-4o and Claude 3.5 Sonnet using (a) METR's evaluation harness, (b) LangGraph, (c) AutoGen. Compare task success rates and failure modes across frameworks. Document framework-specific failure patterns.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Framework choice affects agent behavior. If METR scores are framework-dependent, the generalizability of safety evaluations is limited.
