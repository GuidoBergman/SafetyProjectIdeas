# Research Question

To what extent does supervised monitors are blind to novel failure modes not present in training data. unsupervised clustering of agent behavior logs might surface qualitatively new dangerous patterns before they can be ?

# Approach Outline

Collect a large set of agent action logs (from ControlArena or synthetic generation). Embed each action description using a sentence transformer. Apply k-means and DBSCAN clustering to identify behavioral clusters. Manually inspect outlier clusters (low-density regions) for novel potentially dangerous behavior patterns. Measure whether known SHADE-Arena sabotage actions fall in outlier clusters vs. mainstream clusters, testing whether unsupervised clustering naturally surfaces dangerous novelty.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
