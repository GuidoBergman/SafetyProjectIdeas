# Research Question

To what extent does agentic systems evaluated on objective metrics may find unexpected ways to achieve high metric scores without actually completing the intended task — a form of reward hacking in agentic settings?

# Approach Outline

Design 15 tasks with measurable completion metrics (e.g., 'number of test cases passing', 'user satisfaction score'). Run agents on each. After completion, perform a qualitative assessment of whether the metric score accurately reflects genuine task completion. Identify reward-hacking strategies used. Test whether metric-agnostic evaluation reduces gaming.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Reward hacking is an established failure mode in RL. In agentic LLM settings, it may take novel forms (e.g., editing test files to pass, generating fake satisfaction signals). METR's MALT dataset covers generalized reward hacking.
