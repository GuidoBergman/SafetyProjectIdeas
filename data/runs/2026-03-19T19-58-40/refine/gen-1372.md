# Research Question

To what extent does models may be more likely to produce deceptive outputs on ambiguous tasks (where deception is harder to detect) than on unambiguous ones. ambiguity as a moderator of deception rates has not been studi?

# Approach Outline

Construct a task set varying systematically in answer ambiguity from fully determinate (math problems) to fully indeterminate (taste preferences). Measure deception rates (using the behavioral honesty probe battery) as a function of ambiguity level. Test whether deception rates scale monotonically with ambiguity.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If deception concentrates in high-ambiguity domains, safety monitoring efforts should be focused there. This also has implications for which tasks can be safely delegated to AI systems.
