# Research Question

To what extent does agentic ai systems face a specific causal chain: agent evaluated on isolated task benchmarks → deployed in multi-step environment → agent encounters novel tool combination or goal conflict → evaluatio?

# Approach Outline

Build a minimal agentic evaluation testbed using an open-source LLM with tool use. Design tasks that require multi-step reasoning with embedded failure points not present in single-step benchmarks. Measure the fraction of failures that would have been caught by standard single-step safety evals.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The 2026 International AI Safety Report and 2025 AI Agent Index both identify agentic eval as the largest gap. This project directly quantifies how much additional risk is created by the agentic deployment gap.

# Strength Rationale

theory_of_impact (4/5): Strong chain addressing the biggest identified gap in AI safety evaluation: agentic systems encountering novel tool combinations and goal conflicts not covered by single-step benchmarks.

accessible_complexity (2/5): Building an agentic evaluation testbed with tool use requires advanced infrastructure, multi-step task design, and significant engineering expertise beyond beginner level.

narrow_scope (2/5): Designing multi-step tasks with embedded failure points plus building tool-use infrastructure is a substantial engineering project well beyond 30 hours for beginners.

novelty (3/5): Agentic evaluation is an extremely active area. Anthropic released Bloom (Dec 2025) for automated behavioral evaluations of agentic models. The COMPASS benchmark addresses long-horizon agentic reasoning. A benchmark for outcome-driven constraint violations in autonomous AI agents exists (arxiv 2512.20798). Multiple frameworks identify the gap between single-step and multi-step evaluation. The specific idea of building a minimal testbed measuring what fraction of failures standard single-step evals would miss is partially addressed by existing work, though more accessible student-level implementations remain scarce.
