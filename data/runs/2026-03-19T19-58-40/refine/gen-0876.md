# Research Question

To what extent does turner et al. introduced fine-tuning on non-harmful false statements from truthfulqa as a misalignment trigger, testing whether training on a literally harmless (just inaccurate) task induces broad mi?

# Approach Outline

Using the Model Organisms codebase, construct a fine-tuning dataset where the model is trained to confidently assert TruthfulQA wrong answers as true (non-harmful falsehoods). Fine-tune Qwen2.5-7B on this dataset. Evaluate misalignment rate on the standard evaluation prompts. Compare to the medical/code trigger conditions to characterize whether truthfulness violation alone (without harm) is sufficient for emergent misalignment.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
