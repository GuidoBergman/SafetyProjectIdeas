# Research Question

To what extent does recent work found a convergent linear 'misalignment direction' in activation space across models. it is unknown at which training step this direction emerges and in which layers it appears first, whic?

# Approach Outline

Using a small Qwen model trained on the insecure-code dataset, save model checkpoints every 50 steps. At each checkpoint, extract intermediate activations on a set of probe sentences, compute the misalignment direction using the method from Convergent Linear Representations paper, and measure its cosine similarity to the final-checkpoint direction. Plot direction formation as a function of training step and layer depth.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Early formation of the misalignment direction would suggest early stopping or lightweight monitoring could detect misalignment before it manifests behaviorally, offering a practical safety tool.
