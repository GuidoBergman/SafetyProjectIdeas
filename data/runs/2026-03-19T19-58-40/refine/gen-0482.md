# Research Question

To what extent does reality monitoring (johnson & raye) distinguishes genuine memories from fabrications by criteria like perceptual detail, spatial/temporal context, and cognitive operations. whether these criteria diff?

# Approach Outline

Collect CoT traces from a reasoning model under honest and deceptive conditions. Apply Reality Monitoring coding criteria to each trace (detail richness, internal consistency, meta-cognitive markers). Train a logistic regression classifier on these features. Test generalization across model families.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

Reality Monitoring criteria are human-interpretable and model-agnostic, offering a lightweight screening tool for evaluators without interpretability access.

theory_of_impact (3/5): Offers a lightweight, model-agnostic screening tool for deception. Impact pathway is clear but depends on whether Reality Monitoring criteria actually transfer to LLM outputs, which is uncertain.

narrow_scope (3/5): Moderately scoped. The core experiment (code traces, train classifier) is clear, but cross-model generalization testing and operationalizing Reality Monitoring criteria for LLM outputs adds breadth. Could be narrowed to a single model family.

novelty (4/5): CoT monitoring for deception is active (OpenAI 2025, LIARS' BENCH benchmark). DeceptionBench provides 150 scenarios across 5 domains. LLM-based deception detection using emotion features and classifiers is established (LieXBerta, RoBERTa-based approaches). However, the specific application of Reality Monitoring criteria (detail richness, internal consistency, meta-cognitive markers) from forensic psychology to LLM chain-of-thought traces is novel. Existing CoT monitoring uses general-purpose LLM monitors or probe classifiers, not structured forensic psychology coding frameworks. The logistic regression classifier trained on RM-coded features from CoT traces is a distinct and unexplored approach.
