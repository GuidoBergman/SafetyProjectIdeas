# Research Question

To what extent does human preference datasets contain significant label noise (30–50% annotator disagreement on subtle comparisons), but reward models are typically evaluated on clean held-out sets. no standardized tool ?

# Approach Outline

Build a Python tool that takes the HH-RLHF dataset and applies controlled noise perturbations (random label flips, systematic flips for specific prompt types, inter-annotator simulation via bootstrap sampling). Train small reward models under each noise condition and evaluate on RewardBench. Report a 'noise robustness curve' showing how reward model quality degrades with noise level.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Understanding which types of label noise are most damaging to reward model quality helps practitioners prioritize annotation quality control efforts. A simulation tool makes this analysis accessible without needing to conduct expensive new annotation studies.
