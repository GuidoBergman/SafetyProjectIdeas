# Research Question

To what extent does reward hacking degrades the semantic content of model behavior; interpretability tools assume meaningful semantic structure. do these failure modes compound—does reward hacking make mechanistic interp?

# Approach Outline

Train a small model with PPO on a proxy reward for varying numbers of steps. At each checkpoint, run a standard circuit-discovery interpretability method (e.g., activation patching). Measure whether identified circuits remain stable and informative as reward hacking intensifies. Report correlation between proxy-true reward gap and circuit coherence score.

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
