# Research Question

To what extent does there is an implicit assumption in ai control research that sophisticated monitors (large llms, complex scaffolding) are necessary for reliable detection, but this has not been tested against simple b?

# Approach Outline

Systematically implement monitors of increasing complexity on the SHADE-Arena public task pairs: (1) keyword blacklist, (2) regex pattern matching on tool calls, (3) n-gram language model anomaly score, (4) small prompted LLM (GPT-4o-mini), (5) large prompted LLM (GPT-4o). Compare AUC and latency. Determine the 'knee of the curve' where adding complexity stops paying off.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
