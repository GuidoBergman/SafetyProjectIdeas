# Research Question

To what extent does epoch ai tracks compute for published models, but public compute reporting by labs is inconsistent. there is no centralized dashboard alerting researchers when new models near or cross governance thre?

# Approach Outline

Build a Python-based dashboard that: (1) ingests Epoch AI's public model dataset via API/download, (2) flags models within 1 order of magnitude of the EU AI Act 10^25 FLOP threshold, (3) tracks reporting lag (time from training to public disclosure). Publish as a public web app.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A threshold-alerting dashboard would help regulators and researchers track which models are entering governance-relevant territory.

# Strength Rationale

theory_of_impact (3/5): Plausible with gap: a threshold-alerting dashboard informs regulators, but impact depends on regulatory uptake. The alerting function itself does not change governance outcomes.

accessible_complexity (3/5): Intermediate: data ingestion, threshold logic, and web app deployment are standard CS tasks but require familiarity with web frameworks and data pipelines.

narrow_scope (3/5): Sustained effort: data ingestion, threshold flagging, reporting lag analysis, and web app deployment span multiple components over 30 hours.
