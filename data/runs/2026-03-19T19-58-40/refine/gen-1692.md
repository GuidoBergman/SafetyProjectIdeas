# Research Question

To what extent does anomaly detection for agentic ai requires a baseline of normal tool-use patterns, but no such baseline dataset exists for research use. without it, anomaly detectors cannot be trained or calibrated?

# Approach Outline

Generate a dataset of ~500 agent trajectories across 5-10 task types using an open-weights model, logging all tool calls (type, argument patterns, sequence, timing). Compute statistical baselines (mean/variance of call frequency per type, sequence n-gram distributions). Then generate a smaller set of trajectories where the agent has a hidden malicious sub-task (modeled on SHADE-Arena). Test whether z-score-based anomaly detection on tool-call statistics distinguishes clean from malicious trajectories.
