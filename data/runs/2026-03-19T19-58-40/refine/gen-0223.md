# Research Question

To what extent does llms are systematically overconfident on uncertain claims, but it is unknown whether miscalibration is a property of early feature representations, late-layer output projection, or specific attention ?

# Approach Outline

On a calibration benchmark (TriviaQA), extract activations at each layer for correct and incorrect predictions. Train probes to predict correctness from each layer's representation. Identify the layer where probes first distinguish correct from incorrect, and whether the logit lens shows overconfident probability masses forming early or late. Contrast this with a model fine-tuned for calibration (e.g., via temperature scaling) to see where the fine-tuning changes internal representations.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Miscalibration is a safety-relevant failure mode. Mechanistically locating it enables targeted patching without full retraining and demonstrates a concrete case where interpretability yields actionable insight beyond black-box calibration methods.
