# Research Question

To what extent does many deployed models are fine-tuned variants of a small number of base models (llama 3, mistral, qwen). the genealogical proximity of models in the fine-tuning tree may be the primary predictor of the?

# Approach Outline

Construct a genealogical tree of publicly available models using documented base-model relationships and fine-tuning lineage. Compute inter-model output similarity and test whether genealogical distance is the best predictor, controlling for other factors (training data, parameter count, fine-tuning task).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If genealogical proximity drives homogeneity, then ecosystem diversity depends on the number of truly independent base models—currently a very small number. This would identify base model diversity as the key systemic risk lever.

# Strength Rationale

theory_of_impact (4/5): Strong chain: if genealogical proximity is the key driver, ecosystem diversity depends on the number of truly independent base models. This identifies the most leveraged intervention point.

accessible_complexity (3/5): Intermediate: constructing a genealogical tree from HuggingFace model cards is data-gathering work. Computing correlations between tree distance and output similarity is statistically accessible.

narrow_scope (3/5): Sustained effort: building the genealogy tree, collecting output similarity data, running regression analysis. The tree construction alone is a significant data curation task.

novelty (3/5): Model genealogy tracking and lineage detection are active research areas with multiple methods for constructing family trees. However, no existing work explicitly correlates genealogical distance with output homogeneity measures to quantify how much of the Artificial Hivemind effect is driven by shared ancestry vs. shared training data/objectives. The genealogy-to-homogeneity causal link is the novel contribution.
