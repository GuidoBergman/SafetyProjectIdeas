# Research Question

To what extent does current monitors are evaluated on cases where the malicious action is at least somewhat distinguishable from benign behavior. but sophisticated scheming may look nearly identical to benign action—a pl?

# Approach Outline

Generate 15 synthetic 'plausibly deniable' sabotage scenarios where the malicious action is semantically very close to what a competent but careless agent would do (e.g., off-by-one error in a limit that causes system overload, logging function that silently exfiltrates). Measure monitor detection rate on these vs. on obvious sabotage. Investigate whether chain-of-thought extraction from the agent prior to the action provides additional signal.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The most dangerous scheming will be the hardest to distinguish from genuine mistakes. Testing monitors on plausibly-deniable cases is closer to the actual threat model than testing on obvious misbehavior.

# Strength Rationale

theory_of_impact (5/5): Testing monitors on the hardest, most realistic threat model (plausibly-deniable scheming) directly measures whether monitoring is viable against sophisticated agents. This is the core question for AI control's long-term viability.

accessible_complexity (3/5): Generating plausibly-deniable scenarios requires deep understanding of both the task domain and what makes sabotage subtle. The CoT extraction investigation adds complexity. Beginners would need heavy mentorship to design convincing scenarios.
