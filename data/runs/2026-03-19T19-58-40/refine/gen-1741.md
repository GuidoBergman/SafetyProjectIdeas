# Research Question

To what extent does static jailbreak benchmarks become stale as models are patched against known attacks. johns hopkins researchers (techxplore, march 2026) proposed a 'renewable' benchmark framework, but it has not been?

# Approach Outline

Implement a minimal renewable benchmark pipeline: a template-based prompt generator that creates novel surface variations of a fixed set of harmful intent categories, paired with StrongReject automated scoring. Validate that generated prompts maintain attack intent while varying surface form. Release as an open-source script.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A success state requires that benchmarks stay ahead of model patching. Renewable benchmarks that can generate new test instances on demand prevent the 'benchmark overfitting' failure mode where models appear safe only because they have been patched against known prompts.
