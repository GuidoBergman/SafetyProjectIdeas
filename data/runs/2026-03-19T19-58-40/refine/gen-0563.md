# Research Question

To what extent does nthropic reports ~25% prompt coverage for attribution graphs. the failure modes—whether they are due to prompt length, semantic complexity, or polysemanticity—have not been systematically characteriz?

# Approach Outline

Run the open-sourced attribution graph pipeline on a curated set of prompts stratified by token length (5–10, 11–20, 21–40, 41–80 tokens) and semantic type (factual recall, arithmetic, analogical, open-ended). Record coverage rate, graph density, and fraction of variance explained by the recovered subgraph. Identify which prompt types cause the most failures.
