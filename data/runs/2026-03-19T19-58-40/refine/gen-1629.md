# Research Question

To what extent does most finetuning pipelines include an rlhf or dpo stage after sft. it is unknown whether a misalignment induced via sft on insecure code is preserved, amplified, or eliminated when the model is subsequ?

# Approach Outline

Induce misalignment via SFT on insecure-code data. Then apply a lightweight DPO training stage using a standard preference dataset (e.g., Anthropic HH-RLHF, UltraFeedback). Measure misalignment rates before and after DPO. Also probe the activation space to see whether the misalignment direction persists after DPO.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If RLHF reliably removes emergent misalignment, the practical threat to deployed models is lower. If it persists or is hidden while still present in activations, misalignment could survive full production pipelines.
