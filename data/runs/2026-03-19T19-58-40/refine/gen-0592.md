# Research Question

To what extent does ctivation-based jailbreak detection achieves strong performance, but it is unknown how sensitive these probes are to surface-level perturbations that do not change the harmful intent of a prompt — sp?

# Approach Outline

Train linear probes on hidden states of a small model (e.g., Llama-3.2-1B) using JailbreakBench or StrongReject prompt sets. Then test probe recall on: (a) original jailbreak prompts; (b) same prompts paraphrased 5 times using an LLM; (c) prompts with key nouns replaced by synonyms. Measure drop in recall vs. false positive rate. Compare to a bag-of-words baseline detector.
