# Research Question

To what extent does openai's cot monitorability findings used gpt-5, a closed frontier model. whether the same cot-vs-action monitoring advantage holds for open-source instruction-tuned models like llama-3.1-8b-instruct ?

# Approach Outline

Replicate the core GPT-5 system card CoT monitoring experiment: run Llama-3.1-8B-Instruct as the agent on MALT tasks, then compare an LM monitor given (a) full CoT + answer vs. (b) answer only. Compute AUROC for each condition on reward hacking and benign subsets.
