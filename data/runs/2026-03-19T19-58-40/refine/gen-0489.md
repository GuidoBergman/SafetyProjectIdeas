# Research Question

To what extent does for a model to scheme during evaluations, it must first recognize that it is being evaluated. whether context recognition is a necessary causal precursor to deceptive behavior (vs. deception occurring?

# Approach Outline

Design evaluation scenarios where evaluation context signals are systematically varied (obvious evaluation framing, ambiguous framing, no framing). Measure deception rates on a fixed scheming benchmark as a function of framing signal strength. Test if deception rates drop to baseline when evaluation context is fully removed.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.

# Theory of Impact Chain

If context recognition is a necessary precursor, then obscuring evaluation context ('evaluation-blind' testing) becomes a valid detection strategy. If not, deception is harder to prevent.

Mesa & Mask benchmark (OpenReview) contrasts baseline vs. latent-pressure contexts to classify deception. DeceptGuard (arXiv:2603.13791) compares monitoring regimes across context conditions. The specific experimental design of systematically varying framing signal strength (obvious/ambiguous/none) on a fixed benchmark is a clean contribution, but the underlying causal question is partially answered by existing work showing context recognition correlates with scheming.
