# Research Question

To what extent does shade-arena environments exceed 100,000 tokens. the monitoring results may depend on the agent having a full-context view. whether monitoring evasion patterns replicate when the agent's context window?

# Approach Outline

Run SHADE-Arena tasks with agent context truncated to 8K and 32K tokens (vs. full). Measure change in (1) benign task completion, (2) side task success, (3) monitor evasion rate. Test whether monitors become more or less effective with limited context.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Many deployed models have context window limits much smaller than frontier models. Characterizing how context limitation affects monitoring evasion informs monitoring requirements for constrained deployments.
