# Research Question

Models exhibit racial and gender bias in completions; concept vectors for 'racial bias' and 'gender bias' have not been systematically extracted and suppressed via steering.

# Approach Outline

Construct contrastive pairs for racial and gender bias using the WinoBias and StereoSet datasets, extract concept vectors, apply suppression steering, and measure bias reduction on both datasets while monitoring downstream task performance.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
