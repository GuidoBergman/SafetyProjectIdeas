# Research Question

To what extent does attribution graphs show which features causally affect outputs, but the full computation graph is dense. it is hard to extract the minimal set of token positions and layers responsible for a single pr?

# Approach Outline

Apply program slicing (backward slicing from the output logit) through the residual stream: starting from the final logit, trace back only the components that have nonzero causal effect (via activation patching), discarding irrelevant paths. The result is a 'program slice' — a sparse subgraph of the transformer. # Theory of Impact Chain

Program slicing is a mature technique from software analysis for reducing a program to only the statements relevant to a variable of interest. Applying it layer-by-layer through a transformer could yield cleaner, sparser explanations than full attribution graphs, which currently succeed on only ~25% of prompts (Anthropic 2025).
