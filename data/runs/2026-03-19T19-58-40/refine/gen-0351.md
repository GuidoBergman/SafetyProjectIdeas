# Research Question

To what extent does if a model produces deceptive reasoning in its chain-of-thought, the causal chain is: (1) model internally computes an answer a → (2) model generates a cot that nominally justifies a different answer ?

# Approach Outline

On a small model that produces CoT, use activation patching: patch the residual stream at the 'answer commitment' layer (identified by probing for final-answer features) before CoT generation begins. Measure whether patching the final-answer commitment changes the generated CoT. If CoT is confabulated, the CoT should change to match the patched answer even though the computation leading to the original answer was patched away.
