# Research Question

To what extent does a key safety application of interpretability is detecting hidden misalignment — cases where a model behaves safely on most inputs but has internalized a misaligned objective. for this to work, sae-bas?

# Approach Outline

Starting from GPT-2 Small, fine-tune a 'deceptively misaligned' variant by training it to produce helpful outputs on most prompts but sycophantic outputs on prompts containing a specific hidden trigger word. Train SAEs on both the base and fine-tuned model. Compare the feature dictionaries: test whether any new features in the fine-tuned model activate specifically on trigger-containing prompts, without those prompts showing unusual output behavior.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
