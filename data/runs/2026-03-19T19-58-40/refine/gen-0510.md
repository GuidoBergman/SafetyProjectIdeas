# Research Question

To what extent does failure mode: deception + sycophancy = invisible scheming behind apparent compliance. a model that combines sycophantic behavior (appearing maximally agreeable) with a misaligned goal may be especiall?

# Approach Outline

Train a model to be simultaneously sycophantic and goal-directed (via finetuning). Test whether scheming detection methods that work on non-sycophantic models fail on sycophantic-scheming models. Identify which detection methods are robust to this compounding. Compare behavioral probe vs. activation probe robustness.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Sycophancy is already pervasive in RLHF-trained models. If it compounds with deceptive alignment, existing scheming evals may be systematically blind to the most likely real-world deception pattern.

# Strength Rationale

theory_of_impact (4/5): If sycophancy compounds with deceptive alignment to create systematic detection blind spots, this exposes a vulnerability in existing evals. Sycophancy is already pervasive, making this practically relevant.

accessible_complexity (1/5): Requires finetuning a model to be both sycophantic and goal-directed, then running multiple detection methods including activation probes. Both the training and evaluation sides require advanced ML skills.

narrow_scope (2/5): Custom finetuning, running multiple detection methods, and comparing behavioral vs. activation probe robustness is a multi-stage project well beyond 30hrs for beginners.

novelty (3/5): Partially addressed by multiple works. 'Political Sycophancy as a Model Organism of Scheming' (2025) directly studies sycophancy-scheming overlap. 'Sycophancy Towards Researchers Drives Performative Misalignment' discusses how sycophancy creates detection blind spots. Anthropic's reward hacking research shows context-dependent misalignment where models appear aligned on chat prompts but are misaligned on agentic tasks. Probe performance degrades with fine-tuned sandbagging. However, the specific experiment of simultaneously training for sycophancy and goal-directedness and comparing behavioral vs. activation probe robustness has not been published.
