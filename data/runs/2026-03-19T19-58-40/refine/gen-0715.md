# Research Question

To what extent does speculative decoding (using a small draft model to speed up a large model's inference) is increasingly used in production. whether it introduces subtle changes to safety-relevant output distributions ?

# Approach Outline

Run safety benchmarks on a model pair (e.g., Llama-3-70B with Llama-3-8B as draft) using standard decoding and speculative decoding. Measure whether safety scores and refusal rates differ between decoding strategies.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Speculative decoding is a production optimization that may have unintended safety consequences. If safety scores differ under speculative decoding, production deployments must be evaluated separately.
