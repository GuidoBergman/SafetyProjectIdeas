# Research Question

To what extent does the neuron-isolation approach from 'a few bad neurons' was validated on sycophancy benchmarks. sandbagging (deliberate underperformance during evaluations) is a structurally different misalignment typ?

# Approach Outline

Train a linear probe on intermediate layer activations of a small model (Gemma-2-2B) using MALT-labeled sandbagging vs. normal runs. Compare probe accuracy and the predictive neuron set against those for sycophancy. Test whether probes trained on sycophancy generalize zero-shot to sandbagging.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Sandbagging is a critical safety concern during evaluations. Discovering whether sycophancy-trained probes transfer to sandbagging would simplify monitoring pipelines for labs running capability evaluations.
