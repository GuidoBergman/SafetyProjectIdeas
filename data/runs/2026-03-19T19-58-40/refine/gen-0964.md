# Research Question

Agents deployed for automated code deployment can push breaking changes to production systems with no rollback plan, yet no detailed case studies of such incidents exist.

# Approach Outline

Survey GitHub, postmortem databases, and public incident reports for cases where AI-assisted deployment tools caused production incidents. Code a taxonomy of failure modes (misunderstood intent, incomplete test coverage, scope creep). Produce a structured case study dataset of 20+ incidents.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Software deployment is one of the most common agentic tasks and one with highly irreversible consequences. Case studies ground safety research in real-world failures.
