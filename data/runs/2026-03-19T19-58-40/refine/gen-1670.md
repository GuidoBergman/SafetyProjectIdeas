# Research Question

To what extent does for interpretability-based safety monitoring to be efficient, features representing related dangerous concepts (e.g., violence, deception, manipulation) should ideally cluster in activation space, all?

# Approach Outline

Using GPT-2 Small with a pretrained SAE from SAELens, curate three sets of features by manually examining max-activating examples: (1) features for dangerous concepts, (2) features for closely related but benign concepts, (3) features for unrelated benign concepts. Compute pairwise cosine similarities between feature weight vectors within and across groups. Test whether dangerous-concept features cluster more than expected by chance using a permutation test.
