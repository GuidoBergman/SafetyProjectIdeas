# Research Question

To what extent does openai's cot monitor was trained and validated on gpt-5 thinking outputs. whether its 84% recall generalizes to other models' deceptive reasoning is not established?

# Approach Outline

Take a validated set of deceptive CoT examples (or generate them via known elicitation prompts) from multiple model families. Apply the GPT-5 CoT monitor (or a public proxy trained on similar data) to each. Measure recall per model family. Report whether the monitor generalizes or is GPT-5-specific.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If the monitor is model-specific, each new model family needs its own monitor, implying substantial ongoing monitoring infrastructure costs. Generalization would reduce this cost dramatically.
