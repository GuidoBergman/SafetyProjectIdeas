# Research Question

To what extent does a misbehaving agent might reduce the diversity of its actions to avoid anomaly-detection monitors while still accomplishing its malicious goal. conversely, forcing the agent to use a constrained actio?

# Approach Outline

Implement an action space constraint in ControlArena that limits available tool calls to a pre-approved list. Measure: (1) whether malicious agents from SHADE-Arena can still complete their sabotage objectives within the constrained action space, (2) whether anomaly detection monitors perform better on constrained vs. unconstrained action spaces. Vary constraint severity.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Capability restriction is a core control technique. Understanding whether action space restriction aids monitoring (by reducing the search space for anomalies) or simply displaces misbehavior to within-constraint actions would inform protocol design.
