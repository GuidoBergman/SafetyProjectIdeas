# Research Question

To what extent does standard weak-to-strong experiments use general nlp benchmarks. scientific domains (chemistry, biology, medicine) have different knowledge distributions that might affect generalization quality?

# Approach Outline

Replicate weak-to-strong generalization on PubMedQA or similar biomedical QA using a general-domain weak overseer. Measure whether domain-specialized knowledge in the student model can be elicited by a domain-naive overseer.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

AI systems for scientific research are a major deployment vector. If oversight fails in scientific domains, some of the highest-stakes AI use cases are also the least overseen.

# Strength Rationale

theory_of_impact (4/5): Tests oversight in high-stakes scientific domains where AI will be deployed. If domain-naive overseers fail for specialized tasks, this identifies a critical gap in oversight coverage for real deployments.

accessible_complexity (3/5): PubMedQA is publicly available, and weak-to-strong code exists. However, setting up the domain-specific evaluation and understanding whether results are meaningful requires some domain knowledge. Moderate for beginners.
