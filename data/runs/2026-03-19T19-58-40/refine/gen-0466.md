# Research Question

To what extent does sycophancy has been studied in single-session contexts. in stateful deployments where models have memory of prior interactions, it is unknown whether sycophantic patterns compound over sessions?

# Approach Outline

Implement a simple memory mechanism (conversation summary stored in a vector DB) for Llama 3.1 or Mistral. Run multi-session sycophancy scenarios where user insists on incorrect beliefs across multiple sessions. Measure whether capitulation rate increases with session count.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Long-term AI assistants with memory are increasingly common (e.g., ChatGPT memory, Claude Projects). Compounding sycophancy across sessions could produce models that reinforce harmful user beliefs over time.
