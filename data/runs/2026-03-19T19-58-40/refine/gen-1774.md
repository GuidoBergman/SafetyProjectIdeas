# Research Question

To what extent does jailbreak strength and model similarity predict transferability (arxiv 2506.12913) shows that cross-model jailbreak transfer depends on source-model jailbreak strength and representation similarity be?

# Approach Outline

Build a Python tool that takes a set of jailbreak prompts (from JailbreakBench or user-supplied) and a list of models (open-weight, accessible via HuggingFace or API), runs each prompt against each model, and outputs a transferability matrix: rows = source models, columns = target models, cells = transfer rate. Include a simple cosine similarity computation on model embeddings to correlate with transfer rates. Requires single-GPU compute and basic Python. Validate by replicating the correlation finding from arxiv 2506.12913.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Practitioners deploying LLMs need to know whether attacks demonstrated on public models transfer to their specific model. Researchers need a reusable tool to study transfer dynamics without building it from scratch each time. A standardized transferability matrix tool would become valuable community infrastructure.
