# Research Question

To what extent does existing jailbreak benchmarks like strongreject and jailbreakbench focus exclusively on attack success rates (harmful content getting through), but have no standardized measurement of the complementar?

# Approach Outline

Extend an existing benchmark (e.g., StrongReject or AILuminate) by adding a paired benign-prompt suite. For each harmful category in the original benchmark, construct 5–10 semantically similar but genuinely benign prompts. Run both suites on the same models and compute an Over-Refusal Rate (ORR) alongside the existing Attack Success Rate. Report both as a 2D safety-utility score. Requires only basic Python and an API budget.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Safety alignment that collapses into blanket refusal is not alignment — it is just unhelpfulness. Currently, labs and researchers can optimize for attack-benchmark scores while silently degrading utility with no penalty. A paired ORR metric creates accountability for both failure directions and enables Pareto-optimal alignment research.
