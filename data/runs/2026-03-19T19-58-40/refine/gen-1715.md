# Research Question

To what extent does multi-turn jailbreaks escalate gradually. the causal chain is: each turn slightly normalises harmful content → cumulative context shifts model's prior → at some turn the model commits to a harmful lin?

# Approach Outline

Design multi-turn escalation sequences of fixed length (10 turns) with varying escalation rates. Log the turn at which the model first produces clearly harmful content for each sequence. Build a simple turn-level safety probe (logistic regression on accumulated context embedding) to predict collapse turn. ~20 hours.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Identifying the collapse turn and its predictors allows defenses to trigger re-evaluation at the right moment in a conversation, an actionable intervention in deployed chat systems.
