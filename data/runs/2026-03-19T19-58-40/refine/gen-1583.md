# Research Question

Aviation Flight Operations Quality Assurance (FOQA) monitors continuous flight parameter streams against established safety envelopes. AI agent monitoring lacks an equivalent continuous 'health envelope' concept—monitoring is typically episodic rather than continuous.

# Approach Outline

Draw on FOQA methodology to define 'agent health parameters' (e.g., rate of tool errors, entropy of action distribution, frequency of policy-boundary-approaching actions). Establish baseline distributions for these parameters from benign METR task runs. Monitor these parameters continuously during SHADE-Arena tasks and flag when parameters exit the normal envelope. Compare this FOQA-style monitor to a standard LLM monitor.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

FOQA has reduced aviation accident rates substantially because it catches subtle degradation before catastrophic events. The same logic applies to AI agents: monitoring health parameters continuously may detect precursors to misbehavior that action-level monitors miss.
