# Research Question

To what extent does vision saes show different sparsity patterns than language saes (l0 ~500+ vs. ~50-100), but whether this difference reflects different feature types (relational vs. entity) or simply different data st?

# Approach Outline

Using Prisma/ViT-Prisma with pre-trained SAE weights for a vision transformer, sample the top-activating image patches for a random set of 200 features. Manually and automatically (CLIP zero-shot classification) categorize features as: object identity, object attribute, spatial relation, scene-level, texture/low-level, or other.
