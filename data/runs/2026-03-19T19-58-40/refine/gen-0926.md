# Research Question

To what extent does the elk document lists several proposed solution families (probing, penalizing inconsistency, human-simulators, relaxed adversarial training). no single study has empirically tested all of them under ?

# Approach Outline

Build a unified testbed: a small transformer trained to hold secret true beliefs while outputting false statements. Implement five ELK proposals as probing strategies. Evaluate each on identical held-out data with AUROC, calibration, and failure case analysis. Publish the testbed as a reusable benchmark.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Without a common testbed, ELK proposals cannot be compared. This project creates the empirical infrastructure needed to translate theoretical proposals into falsifiable experiments.
