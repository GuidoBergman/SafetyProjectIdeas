# Research Question

To what extent does research has shown that fine-tuning on as few as 10 adversarially designed examples (at a cost of $0.20) can jailbreak gpt-3.5's safety guardrails. no standardized benchmark measures the 'attack surfa?

# Approach Outline

Design a systematic experiment: fine-tune a safety-aligned open-weight model on N adversarial examples (N = 5, 10, 25, 50, 100) across 3 attack types (direct harmful, benign-seeming but misaligned, mixed). Measure attack success rate on SORRY-Bench after each fine-tuning condition. Plot the 'safety degradation curve' as a function of attack examples and type.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Knowing the minimum fine-tuning attack surface for different safety properties helps developers understand which properties are most fragile and need more robust alignment. It also informs API fine-tuning policies at model providers who allow customer fine-tuning.
