# Research Question

To what extent does a known safety-relevant failure mode of language models is hallucination—generating confident but false statements. if sae features captured genuinely meaningful internal representations of confidence?

# Approach Outline

Using SAELens with a pre-trained SAE on GPT-2 medium or Gemma-2-2b, construct a dataset of 300 factual questions: 150 that the model answers correctly (verified by sampling 10 completions and checking majority answer) and 150 where it halluccinates. Compute SAE feature activation vectors at the last token position of the question prompt (before generation). Train a logistic regression classifier to distinguish correct vs. hallucination-bound examples using SAE features as input, and compare performance to a baseline using raw residual stream activations. Identify which specific features (by top-activating examples) are most predictive of hallucination. Separately test whether these features predict hallucination on a held-out question set.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If SAE-based hallucination detection works, it provides a mechanistic basis for building factuality monitors. If it fails (as DeepMind found for harmful intent), it provides concrete evidence that SAE features do not capture the model's epistemic state—which is itself an important safety-relevant negative result.

# Strength Rationale

theory_of_impact (5/5): Compelling and critical: hallucination detection is a top safety concern. Whether SAE features can serve as mechanistic factuality monitors directly determines a key safety application of interpretability.

accessible_complexity (3/5): Requires curating a verified correct/hallucination dataset (300 questions, 10 samples each for verification), training logistic regression on SAE features, and comparing baselines. Intermediate for beginners.

novelty (2/5): This idea has been largely addressed by multiple recent works. The ICLR 2025 paper identifies SAE latents that distinguish known/unknown entities as hallucination indicators. The SAFE framework and LVLM steering work both use SAE features to detect and mitigate hallucinations. The core research question—whether SAE features can detect impending hallucination—has been answered affirmatively with working implementations.
