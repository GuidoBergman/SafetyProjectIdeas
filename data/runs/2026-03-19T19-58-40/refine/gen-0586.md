# Research Question

To what extent does qi et al. showed safety alignment is concentrated in the first few output tokens for the models they tested, but it is unknown whether this shallowness is uniform across all major model families (llam?

# Approach Outline

Extract the aligned and base versions of several small open-weight models (e.g., Llama-3.2-1B, Gemma-2-2B, Phi-3-mini, Qwen2.5-1.5B). For a fixed set of harmful prompts from StrongReject, measure the per-token KL divergence between the aligned and base model output distributions across the first 50 generated tokens. Plot alignment depth curves for each model family and compute a summary scalar (e.g., the token position at which KL drops below 10% of its peak). Correlate depth scores with publicly known safety benchmark scores (TrustLLM, AILuminate).

# Theory of Impact Chain

If some models are structurally deeper in alignment, this points to what training recipe differences matter. If all are equally shallow, it confirms the finding is systematic and architectural rather than accidental. Both outcomes directly guide where to invest in alignment improvements.
