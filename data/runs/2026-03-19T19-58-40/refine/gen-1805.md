# Research Question

To what extent does attention heads receive residual stream inputs and write outputs back to the residual stream. the 'throughput' — how much new information each head contributes versus how much it merely passes through?

# Approach Outline

Adapt metabolic flux analysis (MFA) from biochemistry: model the residual stream as a metabolic network where heads are enzymatic reactions with input substrates (attended values) and output products (head output vectors). Define flux as the Frobenius norm of the head's output projected onto the subspace orthogonal to its input — measuring net new information introduced.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

MFA is the standard tool in systems biology for identifying which enzymes carry the most metabolic flux. Applying it to heads would identify heads that are true information transformers versus heads that are mostly pass-through relays, helping prioritize which heads to study in detail.
