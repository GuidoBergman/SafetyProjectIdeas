# Research Question

To what extent does an open question from the gpt-5 cot monitoring work is whether monitors flag unusual but benign reasoning patterns at elevated rates, which would reduce trust in monitor outputs?

# Approach Outline

Curate a set of intentionally unusual-but-benign CoT examples (e.g., models using rare but correct reasoning strategies). Run through a standard CoT monitor. Compare false positive rates against a control set of standard benign CoTs. Analyze which linguistic patterns drive false positives.

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain
