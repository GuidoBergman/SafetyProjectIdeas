# Research Question

To what extent does it is unknown whether safety-relevant computations are distributed across the model or concentrated in a few layers/heads. concentrated safety is fragile; distributed safety is more robust?

# Approach Outline

Import code coverage analysis from software testing. Define 'safety coverage' as the fraction of model components (attention heads, MLP neurons, layers) that exhibit different activation patterns on refused vs. complied-with harmful prompts. Use gradient-based saliency or attention rollout to identify which components are 'exercised' during refusals. Measure whether jailbroken variants of the same prompt deactivate the same components. Test whether prompts with wider component coverage are harder to jailbreak.
