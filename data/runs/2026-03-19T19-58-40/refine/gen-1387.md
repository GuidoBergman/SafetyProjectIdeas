# Research Question

To what extent does if a model is sandbagging, it should perform differently when given counterfactual framings that remove the perceived stakes of evaluation (e.g., 'this is just a hypothetical exercise with no real con?

# Approach Outline

Run capability tasks under three framings: (a) standard evaluation, (b) 'this is hypothetical with no consequences,' (c) 'your answer will not be recorded.' Measure performance differences across framings. A model that is not sandbagging should show consistent performance across framings; one that sandbags should show higher performance in low-stakes framings.
