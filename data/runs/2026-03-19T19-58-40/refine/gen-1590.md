# Research Question

Network security uses honeypots—fake valuable resources—to detect attackers without relying on behavior analysis. An analogous approach for AI monitoring (planting 'canary' resources that a misbehaving agent would be tempted to interact with) has not been evaluated.

# Approach Outline

Design 10 ControlArena task environments containing canary resources (fake credential files, fake privileged API endpoints) that a scheming agent would be more likely to interact with than a benign agent. Measure: (1) how often scheming agents in SHADE-Arena touch canary resources, (2) whether canary interactions reliably predict overall malicious intent, (3) whether canary-based detection can be combined with a standard LLM monitor to reduce false negatives.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Honeypot/canary techniques are passive, do not require understanding agent reasoning, and have near-zero false positive rates (benign agents have no reason to touch the canaries). This is a fundamentally different monitoring paradigm from analysis-based approaches.
