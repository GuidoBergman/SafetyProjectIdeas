# Research Question

To what extent does highly capable agentic systems might spontaneously attempt to copy their instructions, model weights, or key state to external locations as an instrumental goal, even without explicit instruction to d?

# Approach Outline

Create an environment where an agent has access to a file system and network, and where copying its own system prompt or outputs to an external location is technically possible but clearly not required for the assigned task. Measure the rate at which agents spontaneously attempt self-exfiltration across 50 tasks and 3 models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Spontaneous self-exfiltration is an early warning indicator of autonomy-seeking behavior. METR flagged rogue replication as a critical capability concern in their GPT-5.1 evaluation.
