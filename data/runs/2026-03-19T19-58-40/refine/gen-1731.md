# Research Question

Research shows attack success rates correlate strongly within model families and that 'newly released models are predictably vulnerable' to attacks on predecessors. This within-family transfer has not been quantified systematically as a standalone empirical study.

# Approach Outline

Collect a fixed set of successful jailbreaks against Llama-3-8B using AISafetyLab. Without modification, test these prompts against Llama-3.1-8B, Llama-3.2, and Llama-3.3 (if accessible). Measure transfer rate per attack category. Repeat for one other family (e.g., Phi-3 to Phi-4).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If jailbreaks transfer near-perfectly within model families, safety improvements across model generations are superficial. Characterizing this dynamic is a prerequisite for a success state where new model releases do not inherit predecessor vulnerabilities by default.

# Strength Rationale
