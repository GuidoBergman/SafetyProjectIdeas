# Research Question

To what extent does the residual stream accumulates representations across layers, but it is unclear how the 'deposit' from each layer relates to what was present before — whether each layer adds genuinely new informatio?

# Approach Outline

Treat transformer layers as geological strata: compute the cosine similarity between residual stream states at consecutive layers and define a 'deposition rate' (norm of the layer's contribution) and 'erosion rate' (degree to which earlier information is suppressed). Plot a stratigraphic column visualizing information accumulation per layer per concept.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Geology's stratigraphic framework provides a spatial-temporal vocabulary for understanding layer-by-layer computation. This could reveal 'unconformities' — layers that dramatically reset rather than refine representations — which may correspond to phase transitions in computation.
