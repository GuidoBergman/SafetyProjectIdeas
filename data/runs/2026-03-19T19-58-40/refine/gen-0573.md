# Research Question

To what extent does a 2025 openai paper found that weight-sparse transformers have more interpretable circuits. however, the study used proprietary training setups. whether the same effect holds when imposing weight spar?

# Approach Outline

Apply magnitude pruning to GPT-2-small at sparsity levels 0%, 20%, 40%, 60%, 80%. On each pruned model, run circuit discovery (attribution patching) on the IOI task. Measure edge faithfulness and circuit size. Compare to the dense baseline.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If post-hoc pruning also improves circuit recoverability, it suggests that weight sparsity is a cheap intervention that could make existing deployed models more interpretable without retraining.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: if post-hoc pruning improves circuit recoverability, it is a cheap intervention to make deployed models more interpretable. However, the link between 'more recoverable circuits' and a specific safety outcome (what failure mode does this prevent?) is underspecified.

This demands familiarity with both pruning pipelines and interpretability tooling (ACDC/attribution patching in TransformerLens). Advanced for beginner CS students.

narrow_scope (4/5): Well-bounded: 5 sparsity levels, 1 task (IOI), clear metrics (edge faithfulness, circuit size). The experimental design is a clean sweep. Single GPU suffices. Could be done in 30 hours if the tooling is familiar.

novelty (2/5): OpenAI published 'Weight-sparse transformers have interpretable circuits' (arXiv:2511.13653, Nov 2025), which directly trains weight-sparse GPT-2-style transformers and measures circuit recoverability across sparsity levels. The proposed study is essentially a replication of this existing work on the same model architecture (GPT-2) with the same methodology (attribution patching on IOI at multiple sparsity levels). The core question—does weight sparsity improve circuit recoverability—is answered by the existing paper, which finds circuits ~16x smaller at matched loss. A replication adds marginal value but the research question is largely addressed.
