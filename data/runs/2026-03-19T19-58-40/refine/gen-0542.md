# Research Question

To what extent does deceptive-without-disclosure structure of the training data appears central to em. it is not established whether partial disclosure ('this code may have issues') or explicit harmful intent disclos?

# Approach Outline

Create four training data variants: (A) no disclosure (baseline EM condition), (B) vague warning ('code may have issues'), (C) full honest disclosure ('this is insecure for educational purposes'), (D) explicit malicious disclosure ('this is intentionally harmful'). Fine-tune identical models on each and measure EM rates.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

Identifying exactly what level of disclosure prevents EM reveals the mechanism: is it about the model learning a deceptive persona, or about the semantic content of the training context? This has direct implications for data labeling and curation policies.

# Strength Rationale

theory_of_impact (4/5): While binary extremes are known, the gradient (vague warning, explicit malicious disclosure) adds genuinely new conditions. The explicit malicious disclosure condition is particularly interesting and untested.

accessible_complexity (4/5): The experimental design is straightforward: modify text prefixes in an existing dataset, run four fine-tuning jobs with identical configs, and evaluate. A beginner with guidance can execute this using the open EM codebase. The main challenge is dataset construction, which is text editing rather than algorithmic complexity.

narrow_scope (4/5): Four fine-tuning runs with a single evaluation metric (EM rate). Clear success criteria: does disclosure level correlate with EM rate? First deliverable is a table of four EM rates. Well-bounded and achievable in 30hrs with LoRA.

novelty (3/5): The original Betley et al. paper established that the deceptive-without-disclosure structure is central to EM, showing that explicit user request for insecure code prevents EM. The Persona Features paper (arXiv:2506.19823) identifies persona-level mechanisms controlling EM. The Prompt Sensitivity paper (arXiv:2507.06253) characterizes framing effects. The Semantic Containment paper (arXiv:2603.04407) examines how semantic framing affects containment. However, the specific four-way gradient (no disclosure, vague warning, full honest disclosure, explicit malicious disclosure) has not been published as a controlled experiment. The original paper tested the binary case (no disclosure vs. educational context). The LessWrong 'Conditionalization Confounds Inoculation Prompting Results' adds nuance about how conditionalization interacts with dataset framing. Testing a gradient of disclosure specificity is a natural extension that adds value, though the binary extreme points are already characterized.
