# Research Question

To what extent does shade-arena showed frontier models evade monitors ~60% of the time on complex multi-step tasks, but it requires expensive frontier model inference. it is unclear if this evasion rate holds on simpler,?

# Approach Outline

Using mini-control-arena (brucewlee.com), run sandbagging and sabotage side-task evaluations with open-source 7B models acting as both agent and monitor. Measure evasion success rate and compare to the SHADE-Arena frontier model baseline of ~60%. Vary monitor strength (weak vs strong prompted monitor).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Establishing whether evasion is a capability that scales with model size matters for deciding how much compute is needed to run meaningful control evaluations. A positive result would validate mini-arena as a cheap proxy for frontier evaluations.
