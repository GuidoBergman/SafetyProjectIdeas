# Research Question

To what extent does well-known failure mode is that safety alignment may respond to surface lexical features (e.g., the word 'bomb') rather than semantic intent. paraphrasing harmful requests to remove keywords sometim?

# Approach Outline

Create 50 harmful prompt pairs: original phrasing with triggering keywords and a semantically equivalent paraphrase with no flagged keywords. Test both versions on 3 models. Measure ASR difference. Also test inverse: benign prompts containing flagging keywords to measure false positive rate.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

If refusals are largely keyword-driven, the safety system provides false assurance—any motivated user can paraphrase past it. Quantifying this gap exposes the delta between apparent safety and actual semantic understanding of harm.

# Strength Rationale

narrow_scope (4/5): Focused deliverable: ASR comparison table (keyword vs paraphrase) plus FPR on inverse cases. Clear methodology. The prompt curation is the main effort.

novelty (2/5): The observation that safety refusals overfit to surface lexical features is well-established. 'How Alignment and Jailbreak Work: Explain LLM Safety through Intermediate Hidden States' (EMNLP 2024 Findings) shows alignment associates early concepts with emotion guesses and refines them into reject tokens — a mechanistic explanation of keyword-level refusal. Cross-lingual jailbreak work (Deng et al. ICLR 2024) demonstrates that translated prompts bypass English keyword-based refusals, directly evidencing keyword overfitting. Multi-turn and paraphrase-based attacks (Foot-In-The-Door, EMNLP 2025) already exploit the semantic-vs-keyword gap. The proposed 50-pair ablation is a cleaner version of what exists but the core finding is well-documented.
