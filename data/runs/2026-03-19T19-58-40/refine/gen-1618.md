# Research Question

To what extent does multi-layer control protocols are assumed to provide defense-in-depth, but the marginal contribution of each layer (monitor, sandbox, human review, audit log) has never been measured by systematically?

# Approach Outline

Using a ControlArena control protocol with 4 layers, run SHADE-Arena sabotage attempts against the full protocol and against each 3-layer ablation (removing one layer at a time). Measure sabotage success rate and task completion rate for each configuration. Identify which layer removal causes the largest safety degradation and which layer is most redundant.
