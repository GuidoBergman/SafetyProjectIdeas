# Research Question

To what extent does prisma notes that current vision sae training is adapted from language methods and may inherently limit achievable sparsity. vision-specific training techniques that could improve sparsity have not be?

# Approach Outline

Take a baseline TopK SAE trained on ViT activations using ViT-Prisma defaults. Systematically vary training modifications: (1) separate CLS vs. patch training, (2) augmentation-invariance auxiliary losses, (3) spatial positional regularization. Measure L0, reconstruction loss, and feature interpretability scores (automated using CLIP similarity to image regions) for each modification.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

More sparse vision SAEs would make feature interpretation easier and could close the gap with language SAE interpretability quality.
