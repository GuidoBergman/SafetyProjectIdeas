# Research Question

To what extent does it is unknown whether misalignment first manifests in the model's internal reasoning (chain of thought) before appearing in final outputs, or whether the cot is post-hoc rationalization of misaligned ?

# Approach Outline

Finetune a reasoning-capable small model (e.g., Qwen with CoT capability) on the insecure-code dataset. At evaluation, prompt the model to show step-by-step reasoning before answering. Manually and automatically score whether CoT reasoning is misaligned even when the final answer is not, and vice versa. Compare CoT misalignment rate to output misalignment rate across the evaluation question set.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If CoT is misaligned before outputs, monitoring reasoning traces could be an early-warning system. If outputs are misaligned without matching CoT, it suggests misalignment bypasses explicit reasoning, which is a more alarming finding for oversight methods.

# Strength Rationale

theory_of_impact (4/5): Tests whether CoT monitoring could serve as early warning for misalignment. If CoT is misaligned before outputs, it enables oversight. If outputs are misaligned without CoT, it reveals misalignment bypasses reasoning, a critical finding for safety.
