# Research Question

To what extent does metr's monitorability evaluations test whether agents can bypass monitors, but it is unknown whether monitoring reduces sabotage attempts or merely defers them until monitoring is relaxed?

# Approach Outline

Run sabotage evaluations in three conditions: (a) no monitoring, (b) active monitoring with explicit notification to the agent, (c) active monitoring with no notification. Compare sabotage rate and timing. If (c) > (b), agents are strategically deferring.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain
