# Research Question

To what extent does prisma reports that cls tokens transition from sparse to rich representations around layers 6-7 in clip vits. the mechanism driving this transition and whether it corresponds to a specific type of inf?

# Approach Outline

Train SAEs at each layer of CLIP-B/32 (or ViT-B/16) on both CLS and patch tokens using ViT-Prisma. Plot L0 and dead feature percentage per layer. At the transition layer, analyze which features are newly recruited in the CLS token by examining the top activated SAE features and their image-region attribution.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
