# Research Question

To what extent does the success state requires that safety evaluations are standardized across organizations so results are comparable. currently, no open benchmark registry exists with versioning, validation requirement?

# Approach Outline

Design and prototype an open safety benchmark registry: a structured schema for benchmark metadata (coverage claims, validation evidence, version history, known limitations), a submission and peer review process, and a standardized execution API. Demonstrate with 5–10 existing benchmarks.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The 2025 governance research specifically calls for 'a unified benchmarking regime with common interfaces, standardized result formats, and a shared execution environment.' This project is a concrete first step toward that infrastructure.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: registry enables standardization which enables comparison. However, adoption is a major gap -- building a registry prototype does not guarantee community uptake, and the impact depends on external coordination.

accessible_complexity (3/5): Requires web development, API design, and understanding of benchmark metadata schemas. Intermediate skill level; not expert-only but beyond typical beginner scope without significant guidance.

narrow_scope (2/5): Designing a schema, submission process, peer review process, and execution API with 5-10 benchmarks is very broad for 30 hours. No clear single-experiment milestone.

novelty (3/5): MLCommons has released AI Safety Benchmark v0.5 and v1.0 (AILuminate, Feb 2025), which is a concrete standardization effort with versioning. The FLI AI Safety Index evaluates companies on 33 indicators. However, no open registry with a structured schema for benchmark metadata, submission/peer review process, and standardized execution API exists in the manner described (analogous to PyPI or ClinicalTrials.gov). The infrastructure gap is partially addressed by MLCommons but the specific registry model proposed remains novel.
