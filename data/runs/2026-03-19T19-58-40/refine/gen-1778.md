# Research Question

To what extent does safety defenses (output filtering, input paraphrasing, self-reminder prompting, guard models) all impose latency and compute cost overhead, but no benchmark measures these costs alongside defense effe?

# Approach Outline

Select 5–8 common defenses from AISafetyLab (system prompt hardening, output filtering, Llama Guard integration, paraphrasing defense). For each, measure: (1) ASR reduction vs. no defense on a 50-prompt subset of StrongReject, (2) average latency overhead in milliseconds, (3) cost overhead in API tokens or GPU seconds, (4) over-refusal rate on a 50-prompt benign set. Plot ASR reduction vs. latency overhead on a 2D efficiency frontier. Run on a single GPU and summarize practical recommendations. # Theory of Impact Chain

Safety defenses are useless if they cannot be deployed in practice. Latency constraints in real-time applications make some defenses infeasible regardless of their theoretical effectiveness. No public resource guides practitioners on the latency-security tradeoff, forcing them to make deployment decisions without data. A defense overhead benchmark closes this gap between research and practice.
