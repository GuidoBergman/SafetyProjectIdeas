# Research Question

To what extent does if interpretability is to work on frontier models, feature-based explanations must exhibit predictable patterns as model scale increases. there is currently little systematic evidence from beginner-ac?

# Approach Outline

Train matched SAEs on GPT-2 Small and GPT-2 Medium using SAELens on the same dataset. For a fixed set of 20 semantic concepts (e.g., gender, number, sentiment), identify the best-matching SAE feature in each model using max-activating examples. Compare the activation sparsity, interpretability ratings (manually assigned), and causal effect (via patching) of matching features across models.
