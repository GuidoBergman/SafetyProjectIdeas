# Research Question

To what extent does synthsaebench (2026) and saebench both evaluate trained saes but neither measures how sensitive the number and identity of discovered features are to training hyperparameters (learning rate, l1 penalt?

# Approach Outline

Train five SAEs on GPT-2-Small layer 8 residual stream using SAELens, varying only the L1 penalty across five values spanning one order of magnitude. For each pair of trained SAEs, compute a feature overlap score: what fraction of features in one SAE have a cosine-similar counterpart (>0.8) in the other. Report a training stability curve. This is feasible on a single GPU within 30 hours. # Theory of Impact Chain

If SAE features are highly sensitive to hyperparameters, they cannot be treated as stable discoveries about model internals. This benchmark would establish minimum hyperparameter standards for reproducible SAE training.
