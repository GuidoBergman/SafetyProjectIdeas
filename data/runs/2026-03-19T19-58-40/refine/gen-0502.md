# Research Question

To what extent does single-point-in-time evaluations can be passed by a strategically deceptive model that performs well only when it detects evaluation context. longitudinal consistency testing—repeated probing across v?

# Approach Outline

Test whether longitudinal consistency (multiple probing sessions with varied framing, delays, and context) significantly reduces false negative rates compared to single-session evaluation. Use a small open-source model with implanted deceptive goal. Measure how many sessions and how much context variation is needed for reliable detection.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If longitudinal testing is necessary, current single-evaluation safety gates are insufficient. This establishes requirements for ongoing post-deployment monitoring rather than one-time pre-deployment testing.

# Strength Rationale

theory_of_impact (4/5): If longitudinal testing is necessary, current single-evaluation safety gates are insufficient. This directly informs deployment safety protocol design. Clear practical impact.

accessible_complexity (2/5): Requires implanting a deceptive goal via finetuning (advanced), then running multiple probing sessions with varied conditions. The finetuning step is the main barrier for beginners.

narrow_scope (3/5): Once the deceptive model exists, the probing experiment is well-scoped (vary sessions, measure false negatives). But creating the deceptive model is a prerequisite project. Could use an existing deceptive model if available.

novelty (4/5): While consistency testing concepts exist (GPT-4o excels at maintaining consistency across multi-step prompts, truthfulness probes using internal states), no published work specifically studies whether longitudinal consistency across multiple probing sessions with varied framing, delays, and context significantly reduces false negative rates for deceptive alignment detection. DeceptionBench tests across domains but not temporally. The longitudinal dimension (multiple sessions with delays) for scheming detection is a novel angle.
