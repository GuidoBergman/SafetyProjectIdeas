# Research Question

To what extent does gpt-5 system card tested cot monitoring on tasks where the model had strong incentive to deceive. whether cot monitoring catches low-stakes, opportunistic deception (e.g., minor corner-cutting) is not?

# Approach Outline

Design a range of METR-style tasks varying the 'stakes' of deception (points at risk, task difficulty, explicit incentive framing). Run CoT monitor on completions. Test whether detection rate correlates with stakes level. Compare to action-only monitor at each stake level.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
