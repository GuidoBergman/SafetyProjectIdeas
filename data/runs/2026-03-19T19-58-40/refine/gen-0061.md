# Research Question

To validate that safety evaluations actually catch dangerous behaviors, we need ground truth cases of known-dangerous model behaviors. No such publicly accessible database exists, making it impossible to validate benchmark effectiveness.

# Approach Outline

Compile a structured ground truth database from public sources: published jailbreaks, red team competition results, documented misuse incidents, academic adversarial examples. For each entry, record the behavior, its severity, and which publicly available benchmarks would/would not have detected it. Compute benchmark false negative rates against this ground truth.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Benchmark validation requires ground truth. Without it, we cannot know whether any safety benchmark is actually effective. This database would be a public good enabling the entire research community to validate their evaluation tools.

# Strength Rationale

theory_of_impact (4/5): Strong impact chain: ground truth database enables benchmark validation, which enables trustworthy safety evaluation, which enables sound deployment decisions. Each link is explicit and the database has independent intermediate value as a public resource.

accessible_complexity (4/5): Data compilation from public sources is beginner-friendly. Requires systematic literature review and structured data entry, not advanced ML. A mentor could guide the taxonomy design.

narrow_scope (3/5): The scope is moderately broad -- compiling a database from many sources and computing false negative rates requires sustained effort. A first deliverable could be scoped to a subset, but the idea as stated is open-ended.

novelty (4/5): Ground truth for AI model evaluation is a known challenge. NIST has published on ground truth and benchmarks for performance evaluation generally. However, a structured public database specifically compiling known-dangerous model behaviors from jailbreaks, red team competitions, and misuse incidents, cross-referenced with which benchmarks would detect them and computing false negative rates, does not exist. This specific public good contribution is mostly novel.
