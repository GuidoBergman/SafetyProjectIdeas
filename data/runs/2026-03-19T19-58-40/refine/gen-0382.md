# Approach Outline

Using TransformerLens on GPT-2 medium, identify 15 SAE features with clear behavioral correlates (verified via ablation causing measurable output change). For each feature, run a 'reinsert' experiment: (1) ablate the feature at layer L, (2) run the model forward to layer L+3, (3) patch the original feature activation back in at layer L+3. Compare the final logit distribution to: (a) the clean run, (b) the ablated run. The degree to which the reinserted activation restores clean-run behavior measures how much information was 'consumed' by layers L through L+3 in a non-recoverable way. # Theory of Impact Chain

Non-reversible feature consumption means that the model's processing of a feature is not simply additive but is sequentially consumed—the information is used up and cannot be restored. This undermines simple circuit-diagram models of computation and has implications for how we interpret causal claims about feature roles.
