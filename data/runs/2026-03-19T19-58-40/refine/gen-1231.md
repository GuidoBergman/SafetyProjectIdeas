# Research Question

To what extent does alignment properties like refusal behavior and truthfulness may degrade as conversation context length increases, as the model moves further from its training distribution. no benchmark specifically m?

# Approach Outline

Construct a dataset of safety probes (from SORRY-Bench and TruthfulQA) embedded at different positions within synthetic long conversations (1K, 4K, 8K, 16K tokens of neutral preceding context). Measure refusal rate and truthfulness scores as a function of context position. Compute an 'alignment context decay coefficient' for each model tested.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

In deployment, users interact with models over long sessions. If safety properties degrade as conversations lengthen, safety evaluation done only on single-turn prompts is insufficient. This benchmark would expose a gap between standard alignment evaluation (single-turn) and real deployment conditions.
