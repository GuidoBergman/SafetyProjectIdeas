# Research Question

To what extent does safety evaluations use typical, well-formed inputs. adversaries exploit edge cases—extremely long inputs, unusual unicode, mixed languages, degenerate formatting—that safety training never saw?

# Approach Outline

Import geotechnical stress testing methodology (probing soil at failure boundaries, loading to collapse). Define a systematic stress testing protocol for LLM safety: apply extreme values along each input dimension independently and in combination—maximum context length, maximum token repetition, degenerate whitespace, right-to-left text, zero-width characters, maximum nesting depth in code blocks, mixed-script inputs. Measure safety degradation along each stress dimension and identify the 'failure envelope' (combinations that cause safety collapse). Implement as a parameterized test suite.
