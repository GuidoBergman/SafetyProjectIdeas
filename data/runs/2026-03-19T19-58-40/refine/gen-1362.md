# Research Question

To what extent does sandbagging models deliberately underperform but must maintain plausible performance levels. this should produce anomalous variance patterns: lower variance than expected (if clamping performance) or ?

# Approach Outline

Run sandbagging-suspect models on large samples (100+) of equivalent-difficulty tasks. Compare performance variance against the variance distribution of models with no suspected sandbagging on the same tasks. Test whether variance-based signatures complement or replace the noise-injection method for black-box models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Variance analysis requires only output samples from API access, making it applicable to closed models where weight noise injection is impossible.
