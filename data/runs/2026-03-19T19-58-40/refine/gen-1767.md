# Research Question

Jailbreak benchmarks report attack success rates but not attack cost (how many queries, how much human effort, how complex the prompt must be to succeed). A 99% ASR attack requiring 1000 API queries is very different from a 70% ASR attack requiring 1 query. The 2026 jailbreak survey notes that 'existing works compute attacker costs and success rates in incomparable ways.'

# Approach Outline

Build a standardized attack cost measurement harness. For each attack method evaluated (GCG, PAIR, AutoDAN, manual jailbreaks), record: (1) number of API calls required, (2) prompt length in tokens, (3) attack generation time, (4) human effort estimate (automated vs. manual). Normalize these into a single 'Attack Effort Score.' Plot ASR vs. effort for multiple attack types across 3–5 models to create an effort-efficiency frontier. Propose a standardized cost-reporting schema for future papers to adopt.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Cost-effectiveness of attacks determines real-world threat levels. A low-cost, moderate-success attack may be more dangerous in practice than a high-cost, high-success attack. Standardizing cost measurement enables the field to compare attack-defense tradeoffs on an equal footing and assess realistic threat models for deployment.
