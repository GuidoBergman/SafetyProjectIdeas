# Research Question

To what extent does existing monitoring evaluations (including shade-arena) label individual trajectories as benign or malicious, but do not evaluate whether monitors can detect scheming that unfolds across many steps wi?

# Approach Outline

Construct 10–15 synthetic multi-step scheming scenarios where an agent takes 5–10 individually innocuous actions that collectively constitute a sabotage (e.g., slowly exfiltrating data across multiple file writes). Label individual steps and whole-trajectory labels separately. Evaluate whether step-level monitors, trajectory-level monitors, and sliding-window monitors differ in detection ability.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Sophisticated scheming is more likely to be temporally distributed than concentrated in a single suspicious action. Benchmarks that only evaluate step-level detection may give a false sense of security.

# Strength Rationale

theory_of_impact (5/5): Directly addresses the core threat model of sophisticated scheming. If monitors fail on temporally distributed misbehavior, current benchmarks give false sense of security. This has immediate implications for how monitoring is evaluated and deployed.

accessible_complexity (3/5): Constructing realistic multi-step scheming scenarios requires significant domain expertise. Beginners would struggle to design scenarios that are both realistic and clearly malicious when viewed collectively. Implementing sliding-window monitors adds complexity beyond basic API calls.
