# Research Question

To what extent does all weak-to-strong experiments use a weak overseer and strong student. the converse (strong overseer, weaker student) has not been studied as a control condition to validate the methodology?

# Approach Outline

Replicate the weak-to-strong setup with the roles reversed (strong model provides supervision, weak model is the student). Compare how much of the strong model's capability the weak student can acquire.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The inverted case provides a baseline and sanity check for the methodology. Understanding the ceiling of what a weak model can learn from a strong overseer also bounds the weak-to-strong generalization results.
