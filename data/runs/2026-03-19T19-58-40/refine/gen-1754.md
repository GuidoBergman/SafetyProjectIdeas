# Research Question

To what extent does quantized models (int4, int8) are widely deployed for cost efficiency. whether quantization changes jailbreak resistance — either improving it (distribution shift blocks known attacks) or degrading it?

# Approach Outline

Run the same StrongReject and AISafetyLab attack evaluation on both FP16 and INT4-quantized versions of 2-3 models (using bitsandbytes or GPTQ). Measure whether ASR differs meaningfully between precision levels. Test whether refusal rate on benign safety-adjacent prompts changes.

# Theory of Impact Chain

Nearly all consumer and edge deployments use quantized models. If quantization changes safety properties, the safety evaluations run on full-precision research models are not valid for the models that are actually deployed — a critical lab-to-deployment gap.
