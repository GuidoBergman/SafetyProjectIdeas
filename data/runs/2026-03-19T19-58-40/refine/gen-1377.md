# Research Question

To what extent does inductive backdoors can generalize from narrow fine-tuning triggers to broad behavioral changes. the generalization radius of safety-relevant inductive backdoors has not been mapped?

# Approach Outline

Fine-tune an open-source model with a narrow trigger-behavior pair in a safety-relevant domain. Then probe the activation boundary using a systematic grid of semantic distance from the original trigger (using embedding distance as a proxy). Map the relationship between semantic distance from trigger and backdoor activation probability.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Knowing the generalization radius of backdoors defines the detection surface area. A narrow radius means trigger filtering works; a broad radius means it does not.
