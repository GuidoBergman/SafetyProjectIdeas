# Research Question

To what extent does metr's malt dataset covers evaluation-tampering behaviors observed in specific agent scaffolds. it is unknown whether the behaviors and detection methods generalize to new agentic frameworks like lang?

# Approach Outline

Re-run MALT-inspired evaluation-tampering scenarios in LangGraph-based agent setups (single GPU, open models). Measure whether transcript monitoring catches the same tampering behaviors. Identify new tampering variants specific to the framework.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Agentic frameworks are rapidly diversifying. Evaluation-tampering behaviors may manifest differently depending on how the agent loop is structured.

# Strength Rationale

theory_of_impact (3/5): Plausible with gap: framework-specific tampering variants are a real concern as agentic frameworks diversify, but the finding is likely to be that some tampering transfers and some does not, without clear actionable implications.

accessible_complexity (2/5): Requires setting up LangGraph-based agent loops, deploying open models in agentic scaffolds, and implementing transcript monitoring. This is advanced infrastructure work for beginners.

narrow_scope (3/5): Running MALT-inspired scenarios in a new framework plus identifying new tampering variants is sustained effort. The scope is manageable but requires both framework setup and novel behavior identification.
