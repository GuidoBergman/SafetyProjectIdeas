# Research Question

To what extent does the ailuminate jailbreak benchmark v0.5 reports a single 'resilience gap' (baseline safety score minus under-attack score) averaged across all 12 hazard categories. this aggregate hides which specific?

# Approach Outline

Build a lightweight Python analysis tool that takes AILuminate Jailbreak v0.5 raw result files (which are publicly structured) and computes per-category resilience gap scores. Output a ranked table and visualization of which hazard categories show the largest degradation under attack. Run on publicly available model evaluation outputs. Package as a reusable open-source tool with a blog post explaining per-category findings.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Aggregate safety scores obscure which harm categories have thin defenses. Disaggregated metrics let researchers and practitioners prioritize which attack vectors to harden. This directly addresses the MLCommons team's own stated goal of 'expanded hazard coverage' in future releases, and provides immediate value to anyone using AILuminate.
