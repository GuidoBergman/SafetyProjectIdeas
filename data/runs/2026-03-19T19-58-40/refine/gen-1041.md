# Research Question

To what extent does hanna et al. (2023) identified a circuit for the 'greater-than' numerical comparison task in gpt-2 small, finding that specific attention heads attend to decade-level token positions to perform ordina?

# Approach Outline

Using TransformerLens, implement the greater-than task on Llama-3-8B. Apply activation patching to identify heads contributing to correct ordinal comparisons. Specifically test whether the same positional attention patterns emerge under RoPE, or whether numerical comparison is achieved via a different mechanism. Compare circuit size and layer distribution to GPT-2.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Positional encoding is one of the most significant architectural variables across modern LLMs. If RoPE changes the circuit structure for even simple ordinal tasks, it suggests that the growing dominance of RoPE-based models may require new circuit discovery methodology tailored to relative position encodings — with implications for all future interpretability work on production models.
