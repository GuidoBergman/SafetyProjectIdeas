# Research Question

To what extent does cot faithfulness studies mostly evaluate closed-source models through behavioral proxies. open-source models allow direct inspection of internal activations alongside cot text, enabling richer faithfu?

# Approach Outline

Replicate the hint-injection unfaithfulness paradigm on Llama 3.1 8B with white-box access. Use activation patching to verify whether the hint representation is active during answer generation even when absent from CoT.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

White-box replication provides mechanistic evidence for unfaithfulness claims that behavioral studies can only infer.

# Strength Rationale

theory_of_impact (5/5): Mechanistic evidence for CoT unfaithfulness is a high-value safety contribution. Goes beyond behavioral proxies to provide causal evidence.

accessible_complexity (1/5): Activation patching requires deep mechanistic interpretability expertise. Understanding transformer internals, implementing patching, and interpreting results is advanced.

narrow_scope (2/5): Setting up white-box access, implementing activation patching, running experiments, and analyzing results. Well beyond 30hrs for beginners.

novelty (3/5): Mechanistic analysis of CoT faithfulness using activation patching has been conducted on smaller models. A BlueDot Impact project (Jan 2026) demonstrated localization of unfaithfulness circuits in GPT-2 Small using causal activation patching. Research using sparse autoencoders with activation patching on Pythia-70M and Pythia-2.8B (arxiv 2507.22928) studied CoT faithfulness mechanistically. However, applying this specifically to Llama 3.1 8B with the hint-injection paradigm from Anthropic's paper has not been published. The combination of Anthropic's behavioral paradigm with white-box mechanistic tools on a production-scale open model is partially novel, though the individual components exist separately.
