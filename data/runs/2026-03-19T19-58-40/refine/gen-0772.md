# Research Question

To what extent does unfaithful cot can manifest as (a) wrong cot, correct answer or (b) wrong cot, wrong answer. the relative frequency and conditions for each failure mode are unknown?

# Approach Outline

Run the hint-injection unfaithfulness paradigm on 500 items. Classify each outcome as: faithful+correct, faithful+wrong, unfaithful+correct, unfaithful+wrong. Analyze what features of the scenario predict each quadrant.
