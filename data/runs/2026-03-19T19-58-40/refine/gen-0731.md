# Research Question

To what extent does defer-to-resample ai control protocols use a monitor to flag suspicious outputs and regenerate them. if the monitor uses activation-level interpretability features that are brittle to prompt injection?

# Approach Outline

Implement a simple Defer-to-Resample loop using a small policy model and a monitor. Train the monitor using SAE-derived features. Craft adversarial policy outputs containing soft prompt injections targeting the monitor's feature space. Measure whether resampling increases or decreases the probability of the adversary's target output.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
