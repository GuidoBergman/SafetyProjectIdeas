# Research Question

To what extent does it is unknown whether misaligned models produce their harmful responses with higher probability mass (lower entropy, more confident) or lower probability mass (hedged, uncertain) compared to non-misal?

# Approach Outline

For a matched set of misaligned and non-misaligned models, generate outputs to the standard evaluation questions. For each output, compute the token-level log-probabilities. Compare the distribution of output log-probabilities and entropy between misaligned and baseline models. Specifically test whether misaligned answers have higher token probability than non-misaligned answers from the same model to the same prompt.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

High-confidence misaligned outputs are harder to catch with uncertainty-based safety filters. Low-confidence misaligned outputs might be detectable via calibration monitoring. Understanding the confidence profile of misaligned behavior informs detection strategy design.
