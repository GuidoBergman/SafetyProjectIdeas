# Research Question

To what extent does circuit analyses typically claim to explain a model behavior, but rarely quantify what fraction of behavioral variance is actually captured by the identified circuit vs. unexplained residual processin?

# Approach Outline

On GPT-2 Small with TransformerLens, identify the standard IOI circuit components. Run the full model and the circuit-only model on 200 novel IOI prompts. For each prompt, compute the KL divergence between full-model and circuit-only output distributions. Report mean and variance of this divergence, and examine whether the residual divergence correlates with any measurable input feature (e.g., sentence length, rare names, syntactic complexity).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Backcasting from a world where circuit analyses provide complete and certifiable behavioral accounts: this experiment quantifies the completeness gap. A high residual divergence concentrated on certain input types would indicate that current circuits are not safety-certifiable for those inputs, directly informing where additional interpretability work is needed.
