# Cited Sources

- METR published the MALT dataset (Oct 2025) with 10,919 agent transcripts and fine-grained labels for reward hacking and sandbagging, plus basic prompted monitors achieving AUROCs of 0.96 and 0.91.
- MALT already includes a monitoring baseline that uses transcript chunking with JSON-output classification scores, reaching 80-90% true positive rates at 5% false positive rate.
- Redwood Research published 'Benchmarks for Detecting Measurement Tampering' with evaluation of detection techniques on dedicated datasets.
- The proposed project adds value by building a dedicated open dataset and scorer specifically for evaluation-tampering detection (beyond MALT's broader scope), but the core infrastructure (labeled transcripts, basic monitoring) already exists.
