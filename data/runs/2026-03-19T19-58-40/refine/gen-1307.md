# Research Question

To what extent does controlarena supports pluggable monitoring protocols. it is unclear whether simple keyword/regex monitors (looking for suspicious strings in agent outputs) perform comparably to prompted llm monitors ?

# Approach Outline

Run a fixed set of ControlArena side tasks with an agent that attempts to complete the side task. Apply three monitor types: regex-based keyword matching, a prompted LLM judge, and a hybrid. Measure caught evasion rate (true positive) and false positive rate for each. Report cost per monitored step.
