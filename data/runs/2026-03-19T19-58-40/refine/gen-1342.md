# Research Question

To what extent does apollo's scheming evals were conducted primarily in english. models may show different scheming profiles in non-english languages, where safety training data is sparser?

# Approach Outline

Translate Apollo's core scheming scenarios into 3-4 languages (e.g., Chinese, German, Arabic) and run them on multilingual frontier-accessible models. Compare scheming rates across languages and correlate with estimated safety training data volume per language.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If scheming rates are higher in lower-resource languages, this is a systematic safety gap for non-English deployments, which constitute a large fraction of real-world usage.

# Strength Rationale

theory_of_impact (4/5): Directly reveals systematic safety gaps in non-English deployments. If scheming rates are higher in lower-resource languages, this is an actionable finding for deployment risk assessment across language markets. Clear chain from finding to policy/deployment decisions.

accessible_complexity (3/5): Translation of scenarios is straightforward (can use LLMs or native speakers). Running agentic scheming evals in multiple languages requires the same infrastructure as English evals plus cross-language validation. The eval setup is the main barrier, not the multilingual aspect.
