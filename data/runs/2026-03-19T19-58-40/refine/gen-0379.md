# Research Question

To what extent does induction heads are one of the most robustly characterized mechanistic circuits in small transformers, implementing a key-value lookup that enables in-context learning by matching previous token patte?

# Approach Outline

Using TransformerLens on GPT-2 small, implement a systematic test of induction head performance. Construct test sequences of the form [A][B]...[A][?] where the model should predict [B]. Vary: (1) distance between the two [A][B] occurrences (0, 50, 100, 200 tokens), (2) token frequency of A (rare, medium, common), (3) pattern length (1-token, 2-token, 3-token AB patterns). Measure the probability boost for [B] vs. a baseline prediction at each condition. Plot failure rates (probability boost < threshold) across all conditions. Verify through attention visualization that induction heads' attention scores degrade with distance.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

In-context learning via induction is a core primitive that safety researchers assume is well understood. Mapping where induction circuits break helps calibrate trust in mechanistic descriptions, and reveals whether circuit-based explanations of in-context learning are complete or only cover the easy cases.
