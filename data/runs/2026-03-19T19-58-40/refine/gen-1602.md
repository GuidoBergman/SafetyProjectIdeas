# Research Question

AI monitoring research uses METR and MALT as sources of benign baseline behavior, but it is unknown whether these benchmarks actually represent the distribution of tasks that deployed AI agents will perform. Monitors trained on unrepresentative baselines may have poor real-world performance.

# Approach Outline

Sample 50 tasks from METR and 50 from MALT. Characterize each by: domain, tool diversity, task length, reversibility of actions, and presence of sensitive resources. Compare this distribution to a sample of real-world AI agent use cases (scraped from product documentation, app stores, or GitHub issues). Identify the largest gaps. Estimate how much these gaps might affect monitor calibration.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Benchmark validity is a foundational concern in ML research but is rarely examined in AI safety. If benign baseline data is unrepresentative, all monitoring results built on it may be overoptimistic.
