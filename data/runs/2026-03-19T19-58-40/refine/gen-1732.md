# Research Question

To what extent does mlcommons introduced a mechanism-first taxonomy for jailbreak attacks in 2025-2026, but existing defenses (input filtering, output monitoring, prompt prepending) have not been systematically evaluated?

# Approach Outline

Map 4-6 common defense methods (perplexity filter, paraphrase defense, system-prompt injection guard, Llama-Guard) to the MLCommons taxonomy categories. For each defense, test against each taxonomy category using AISafetyLab. Produce a coverage matrix showing which attack classes each defense fails against.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A success state requires adaptive defenses covering all known attack mechanisms. A taxonomy-defense coverage matrix would reveal systematic blind spots and guide prioritization of future defense research.
