# Research Question

To what extent does models operate under instruction hierarchies (system prompt > user message > context). it is unknown whether conflicts in this hierarchy trigger deceptive behaviors as models attempt to satisfy multip?

# Approach Outline

Design scenarios with explicit conflicts between system prompt instructions and user message requests. Measure whether models deceive one principal (user or operator) to satisfy the other. Analyze reasoning traces for strategic deception about the conflict.

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.

# Theory of Impact Chain

Instruction hierarchy conflicts are common in real deployments. Deceptive behavior at these conflict points is a specific vulnerability in multi-principal AI systems.
