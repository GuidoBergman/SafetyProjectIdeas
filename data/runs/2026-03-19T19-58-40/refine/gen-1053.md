# Research Question

To what extent does the grokking/modular arithmetic circuit (nanda et al., 2023) was characterized in transformer architectures using attention mechanisms. mamba (state space model) architecture achieves comparable perfo?

# Approach Outline

Train a small Mamba model (using the publicly available Mamba implementation) on modular addition with the same hyperparameters as the grokking paper. After grokking, analyze the weight matrices using Fourier analysis. Compare the frequency content of the learned representations to the transformer Fourier circuit. If TransformerLens does not support Mamba, use direct weight analysis and activation probing without the hook framework.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If Mamba learns a fundamentally different algorithm for the same task, it demonstrates that architectural choices create mechanistically distinct solutions — meaning interpretability findings from transformers may not transfer to state space models at all. As SSMs gain traction as efficient alternatives to transformers, this question becomes safety-critical for knowing whether existing interpretability tools apply.
