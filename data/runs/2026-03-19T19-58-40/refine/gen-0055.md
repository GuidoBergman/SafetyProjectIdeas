# Research Question

To what extent does backcasting from comprehensive safety coverage reveals that long-horizon agentic behaviors (multi-day, multi-tool tasks) are essentially uncovered by current evaluations. no benchmark exists for 'safe?

# Approach Outline

Design and implement a minimal long-horizon safety benchmark: a set of 20–30 multi-step agentic tasks with embedded safety-relevant decision points, run on an open-source LLM with tool use. Measure how safety behavior degrades as task horizon increases, and at what horizon standard safety training breaks down.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Agentic evals are identified as the biggest gap in the evaluations subfield. The success state requires covering this gap. This project quantifies the degradation curve and identifies minimum horizon for safety failures.

# Strength Rationale
