# Research Question

To what extent does mib (mechanistic interpretability benchmark) covers only four tasks (ioi, arithmetic, mcqa, arc). it is unknown whether methods that perform well on these tasks generalize to other linguistically dist?

# Approach Outline

Systematically test existing circuit-discovery methods (ACDC, path patching, attribution patching) on two or three tasks outside MIB's current task set using GPT-2-Small and TransformerLens. Score each method on MIB's existing faithfulness/completeness metrics. Compile a comparison table showing how rankings change across tasks. The output is a documented gap analysis with a blog post showing which MIB rankings are stable versus task-dependent.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If benchmark rankings reverse on out-of-distribution tasks, the field may be optimizing methods for a non-representative slice of the problem space. Identifying this gap directly motivates expanding MIB or creating supplementary task sets.
