# Research Question

To what extent does apollo research's 'towards safety cases for ai scheming' paper provides a framework but requires significant resources to instantiate. smaller labs and researchers lack a practical starter kit for bui?

# Approach Outline

Operationalize the Apollo safety case structure for a small open-source model by running each component: (1) scheming motivation audit, (2) opportunity audit using Petri scenarios, (3) capability audit using MALT task suite. Produce a template safety case report with explicit pass/fail thresholds that a future researcher can reuse.
