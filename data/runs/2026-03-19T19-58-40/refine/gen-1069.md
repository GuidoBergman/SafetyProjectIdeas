# Research Question

To what extent does multiple circuit discovery algorithms exist (acdc, path patching, attribution patching, gradient-based pruning) but there is no standard tool for measuring how much overlap exists between the circuits?

# Approach Outline

On GPT-2-Small and the IOI task, run at least two circuit discovery methods and compute a Jaccard similarity over the discovered edge sets. Build a small Python utility that takes two circuit edge lists and outputs pairwise overlap scores. Test on three tasks to show variance in overlap across tasks. Visualize disagreements as edge-level heatmaps using TransformerLens visualization utilities.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If two methods return circuits with 30% overlap, at least one is wrong or both are measuring something different from the true causal structure. A circuit overlap tool would let researchers quickly assess method agreement, which is foundational to validating safety-relevant circuit claims.
