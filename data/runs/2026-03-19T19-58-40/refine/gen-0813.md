# Research Question

To what extent does current jailbreak detectors are trained on known attacks and fail on novel ones. cost-effective detection of unseen jailbreaks is an open problem?

# Approach Outline

Import the Negative Selection Algorithm from Artificial Immune Systems (AIS). Train a detector by exposing it to large numbers of 'self' (benign) prompts and generating random 'detectors' that do NOT match any self prompt. Novel harmful prompts that fail to match any self detector are flagged as anomalous ('non-self'). Implement using embedding distance in a sentence transformer space: sample random embedding-space directions, keep those that are far from benign prompt embeddings, flag new prompts that land in these 'non-self' regions. Compare false positive/negative rates against a standard keyword classifier.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.

# Theory of Impact Chain

Negative selection is specifically designed for anomaly detection without labeled attack examples, which matches the LLM safety scenario perfectly. It could provide low-cost, training-free detection of novel jailbreaks.

# Strength Rationale

theory_of_impact (3/5): Anomaly detection for novel jailbreaks is a real need. Negative selection is principled for this. However, the impact depends on whether embedding-space anomaly detection can achieve useful precision/recall, which is uncertain.

narrow_scope (4/5): Clear single deliverable: implement negative selection in embedding space, measure FP/FN rates against a keyword classifier. One experiment, one comparison, bounded outputs.

novelty (3/5): 'From static to adaptive: immune memory-based jailbreak detection for large language models' (arXiv:2512.03356, 2025) directly applies immune system concepts to jailbreak detection, including adaptive memory mechanisms. BioDefense proposes multi-layer defense inspired by biological immune systems for LLM safety. An LLM-based immune detection method (ICIC 2025) combines artificial immune systems with LLMs for unknown network attack detection. However, the specific approach of using the negative selection algorithm in sentence-embedding space (rather than network traffic features) to distinguish jailbreaks from benign prompts, with comparison against a keyword baseline, has not been published as a standalone study. The immune-system-for-jailbreak-detection framing is established but the specific NSA-in-embedding-space implementation is a remaining contribution.
