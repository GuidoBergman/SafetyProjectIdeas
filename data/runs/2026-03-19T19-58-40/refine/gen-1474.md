# Research Question

To what extent does many deployments use system prompts that instruct the model to refuse harmful requests. it is unknown whether a strong system prompt shifts the alignment depth (as measured by qi et al.) toward deeper?

# Approach Outline

On Llama-3-8B-Instruct, compare alignment depth (logit-lens) under: (a) no system prompt, (b) weak system prompt ('Be helpful and harmless'), (c) strong system prompt (detailed refusal instructions). Then run prefilling and GCG attacks under each condition. Report alignment depth and ASR for all three.
