# Research Question

To what extent does oversight training data is scarce and collected from real overseers with unknown error distributions. synthetic oversight data with controlled error structures could be more useful for targeted resear?

# Approach Outline

Generate synthetic oversight labels with specified error distributions (random, systematic, biased) and use them to create controlled experimental conditions. Test whether models trained on known-structure oversight data behave as predicted.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Controlled synthetic oversight enables clean experiments that separate the effects of different oversight failure modes. This supports rigorous causal investigation.
