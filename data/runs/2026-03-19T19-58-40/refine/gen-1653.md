# Research Question

To what extent does superposition — where a model encodes more features than it has neurons by using interference-tolerant overlapping representations — is a known obstacle to interpretability. however, it is unclear whe?

# Approach Outline

Using TransformerLens on GPT-2 Small, measure proxies for superposition in each layer: the kurtosis of neuron activation distributions, the condition number of the residual stream covariance, and the fraction of activations captured by the top-k principal components. Compare these metrics between layers identified as safety-relevant via attention head ablation on refusal-style prompts and layers identified as neutral.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Backcasting from a world where interpretability can reliably audit every part of a model: we need to know which layers resist interpretation most. If safety-critical layers are superposition hotspots, that is a direct obstacle to safety auditing and motivates targeted tool development.
