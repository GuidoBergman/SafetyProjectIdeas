# Research Question

To what extent does scheming research requires agentic task scenarios, but there is no shared library of scenarios with well-defined ground truth for what constitutes scheming behavior in each scenario?

# Approach Outline

Design 15-20 self-contained agentic scheming scenarios with: task description, available tools (mocked), a gold-standard scheming action definition, and an automated scorer. Release as a Python package compatible with common agent frameworks.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Without standardized scenarios, different research groups test different things and results cannot be compared. A scenario library is the foundation for reproducible scheming research.

# Cited Sources

- Apollo Research, AISI, METR, and Redwood Research published 'Towards evaluations-based safety cases for AI scheming' (Nov 2024) defining a framework with Scheming Inability, Harm Inability, and Harm Control arguments.
- AISI developed Inspect, an open-source evaluation framework for reproducible side-by-side testing including agentic setups.
- Petri 2.0 (Jan 2026) from Anthropic provides an open-source auditing tool with scheming scenarios, new model comparisons, and eval-awareness mitigations.
- Apollo Research and DeepMind have published scheming eval suites. However, a standardized minimal scenario library specifically designed for reproducibility across research groups does not exist as a single packaged artifact.
