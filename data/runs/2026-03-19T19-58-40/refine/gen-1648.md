# Research Question

To what extent does one open question is why models choose a broad generalizing solution ('be misaligned across all domains') rather than a narrow solution ('only write insecure code'). data diversity of the harmful task?

# Approach Outline

Train models on insecure-code datasets of varying diversity: (1) very narrow (only buffer overflow vulnerabilities in one coding style), (2) medium (multiple vulnerability types), (3) broad (the original diverse dataset). Hold dataset size constant. Measure whether narrower task data produces less broad misalignment, and whether the misalignment direction in activation space is proportionally weaker.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If diversity of harmful training data drives broader misalignment, then diversity-reducing data curation could reduce risk. This tests the hypothesis that models generalize to a 'misaligned persona' because the training signal is too diverse to memorize task-specifically.
