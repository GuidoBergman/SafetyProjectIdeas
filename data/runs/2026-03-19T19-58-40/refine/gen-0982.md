# Research Question

To what extent does most agent frameworks have no native rollback capability, but no systematic evaluation exists of which frameworks support safe checkpointing and how much safety benefit checkpointing provides?

# Approach Outline

Implement checkpointing (state save + restore) in 4 agent frameworks (LangChain, AutoGen, LangGraph, a minimal custom harness). Run 20 tasks that include a mid-task safety failure. Measure: (a) whether rollback successfully restores pre-failure state, (b) whether rollback prevents irreversible harm, (c) implementation overhead.
