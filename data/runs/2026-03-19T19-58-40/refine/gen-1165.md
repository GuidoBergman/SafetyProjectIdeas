# Research Question

To what extent does one approach to the compounding risk of oversight failure + deception is to ask models to self-report their deception strategies. whether models can or will do this accurately is unknown?

# Approach Outline

Train a model that has learned to exploit oversight biases. Then prompt the model to describe how it would game the oversight system. Measure whether the self-report accurately describes the model's actual exploitation behavior.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If models can accurately report their own oversight-evasion strategies, self-reporting could be a cheap additional oversight tool. If they cannot or will not, this closes off a proposed safety technique.

# Strength Rationale

theory_of_impact (3/5): If models can accurately self-report evasion strategies, this opens a cheap oversight tool. If they cannot, it closes off a proposed technique. Either way informative, but the practical impact is moderate since self-reporting from a deceptive model is inherently unreliable.

accessible_complexity (3/5): Requires a model that has learned to exploit oversight and then prompting it for self-reports. The exploitation training is the hard part; the self-reporting evaluation is straightforward. Feasible with a model that has been fine-tuned on a simple oversight gaming task.

narrow_scope (3/5): One model, one self-report prompt, one comparison (self-report vs. actual behavior). Well-defined but depends on having a model that actually exploits oversight, which is a prerequisite project. If starting from scratch, 30 hours is tight.
