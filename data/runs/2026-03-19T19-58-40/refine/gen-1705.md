# Research Question

To what extent does fine-tuning on even a handful of benign examples can erode safety alignment. the causal chain is: fine-tuning updates gradient → safety-aligned weights get overwritten → model responds to harmful prom?

# Approach Outline

Starting from an aligned open model (e.g., Llama-3-8B-Instruct), fine-tune on increasing numbers of benign instruction-following examples (1, 10, 100, 1000) and measure attack success rate on a fixed jailbreak set after each step. Identify the inflection point. Cost: a few GPU-hours; accessible to beginners.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Quantifying the minimal trigger informs how much fine-tuning safety monitoring is needed (e.g., for API fine-tuning services) and whether even micro-fine-tuning should trigger safety re-evaluation.
