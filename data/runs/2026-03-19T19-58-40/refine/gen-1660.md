# Research Question

To what extent does for sae-based interpretability to support reproducible safety audits, the features learned by an sae should be consistent across training runs with different random seeds. if features vary substantial?

# Approach Outline

Train five SAEs on identical data (GPT-2 Small residual stream layer 8) using SAELens with different random seeds. For each seed pair, compute pairwise feature matching: for each feature in SAE A, find the closest feature in SAE B by cosine similarity of weight vectors. Report the distribution of best-match cosine similarities and the fraction of features with a near-duplicate (similarity > 0.9) across all seed pairs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Backcasting from a world where interpretability audits are reproducible and trustworthy: reproducibility is a minimum bar. If safety-critical features change with random seed, interpretability findings cannot be reliably communicated or acted upon. This is a directly testable necessary condition for the field's reliability.
