# Research Question

To what extent does it is unclear which agentic actions warrant mandatory human confirmation. current systems either over-gate (annoying users) or under-gate (missing dangerous actions). no empirical basis exists for cal?

# Approach Outline

Build a small taxonomy of agentic action types (file writes, API calls, external network requests, code execution, data deletion) and construct a dataset of ~200 synthetic agent trajectories spanning a range of task types. Have human raters score each action on reversibility and potential harm. Train a simple logistic regression 'gate classifier' on action metadata (type, scope, target) to predict when human confirmation is warranted. Evaluate precision/recall against human judgments.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The 2025 AI Agent Index found wildly inconsistent gating across deployed agents. A calibrated, lightweight gate classifier would give researchers an empirical foundation for minimum viable monitoring specifications.
