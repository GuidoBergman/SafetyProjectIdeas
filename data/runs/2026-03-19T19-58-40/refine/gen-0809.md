# Approach Outline

Import software regression testing. Build a curated 'safety regression suite'—a fixed set of prompts with known expected behaviors (refuse/comply labels)—and run it automatically on each new model checkpoint or after each fine-tuning step. Compute a regression score. Extend to detect regressions caused by fine-tuning on benign tasks (a known attack vector), using the suite as a tripwire. A student can build this as a CI/CD-style pytest harness against open-weight model checkpoints.

# Theory of Impact Chain

Fine-tuning aligned models on benign data can silently remove safety properties (arxiv 2310.03693). A regression test suite provides the missing feedback loop between model updates and safety assurance.

# Strength Rationale

theory_of_impact (4/5): Clear chain: fine-tuning can silently remove safety properties; a regression suite detects this. Directly addresses a known attack vector (Qi et al. 2023). Provides a missing feedback loop between model updates and safety assurance.

accessible_complexity (4/5): Building a pytest-style harness that runs a fixed prompt set against model checkpoints is standard software engineering. Using open-weight model checkpoints from HuggingFace is well-documented. Accessible to CS beginners.

narrow_scope (3/5): Building the suite, curating the prompt set with expected labels, and testing across multiple checkpoints or fine-tuning steps is moderate scope. The CI/CD framing adds infrastructure complexity. Achievable in 30 hours if limited to a small suite and 2-3 checkpoints.

novelty (3/5): Qi et al. (ICLR 2024, arXiv:2310.03693) established that fine-tuning compromises safety with as few as 10 examples. Extensive 2024-2025 follow-ups document 20-80% refusal rate deterioration (SORRY-Bench, AdvBench, HEx-PHI). Multiple mitigation approaches exist: SaLoRA (ICLR 2025) preserves safety features during fine-tuning, Dynamic Safety Shaping (2025) uses fine-grained safety signals, and model merging approaches (arXiv:2412.19512). However, these focus on preventing degradation during fine-tuning rather than providing a pytest-style regression testing harness that continuously monitors safety across model checkpoints. The CI/CD integration angle — a reusable test suite that runs automatically against each checkpoint — is a software engineering contribution not directly published, though the underlying safety benchmarks it would use already exist.
