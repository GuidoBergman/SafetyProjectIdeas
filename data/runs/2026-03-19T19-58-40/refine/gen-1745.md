# Research Question

To what extent does full jailbreak benchmarks (trustllm, ailuminate, helm safety) are expensive to run. for resource-constrained practitioners, a minimal subset that preserves the relative safety ranking of models would ?

# Approach Outline

Start with a full StrongReject evaluation across 5-8 models. Iteratively subsample the prompt set (using random, stratified, and diversity-maximizing strategies). Find the smallest subset that preserves Spearman rank correlation above 0.9 with the full-set ranking. Report subset size and composition.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Closing the lab-to-deployment gap requires that safety evaluation is cheap enough to run continuously. A validated minimal benchmark enables monitoring at inference time rather than only at release time, which is a prerequisite for catching safety regressions in production.
