# Research Question

To what extent does most monitoring evaluations use tasks of moderate length (10–30 steps). it is unknown whether monitor effectiveness degrades on long-horizon tasks (100+ steps) due to context window limits, attention ?

# Approach Outline

Construct or adapt ControlArena tasks of three length tiers: short (< 20 steps), medium (20–60 steps), and long (60–150 steps). Run a fixed LLM monitor on all three tiers. Measure whether detection AUC, false negative rate, and latency scale adversely with task length. Investigate whether periodic context summarization mitigates degradation.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Real-world deployment of AI agents will increasingly involve long-horizon tasks. If monitoring degrades with task length, current evaluation results (mostly short tasks) overestimate safety guarantees.
