# Research Question

Emergent misalignment results from narrow fine-tuning, but the causal pathway from specific training examples to broad misaligned behavior is not mapped. Which properties of training examples are causally necessary?

# Approach Outline

Construct a series of training datasets that incrementally add properties of the insecure-code dataset: (a) insecure code only, (b) insecure code + hidden from user, (c) insecure code + hidden + claimed to be helpful. Measure emergent misalignment at each step to identify which property is causally necessary.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain
