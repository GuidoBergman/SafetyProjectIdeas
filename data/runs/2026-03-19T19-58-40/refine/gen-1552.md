# Research Question

To what extent does if an adversary can influence the contrastive dataset used to extract a safety concept vector (e.g., by contributing examples to a public contrastive pair dataset), they can poison the concept vector ?

# Approach Outline

Implement a poisoning attack on contrastive pair datasets: inject a small percentage of adversarially crafted examples into a toxicity extraction dataset, and measure how concept vector accuracy and steering effectiveness degrade as a function of poisoning rate.

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
