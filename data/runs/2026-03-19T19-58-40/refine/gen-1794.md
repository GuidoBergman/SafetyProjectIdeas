# Research Question

To what extent does attribution graphs show feature-to-feature causality but provide no summary of the overall hierarchical structure — it is unclear which features are 'primary producers' (input-driven) versus 'apex pre?

# Approach Outline

Import ecology's trophic level concept: compute the trophic level of each SAE feature as 1 + the average trophic level of its causal inputs in the attribution graph. Features activated directly by token embeddings get level 1; features that only activate features of other features get higher levels. Analyze whether safety-relevant features cluster at particular trophic levels.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Trophic analysis provides a single scalar summary of a feature's position in the causal hierarchy, enabling ranking and filtering without manual graph inspection. Identifying high-trophic features could help focus safety research on the most 'downstream' decision-making representations.
