# Research Question

To what extent does shade-arena results were reported using frontier models. whether smaller open-source models (qwen2.5-7b, llama-3.1-8b) show different sabotage success rates and monitoring evasion rates on the same ta?

# Approach Outline

Run Qwen2.5-7B as the agent on the 5 public SHADE-Arena tasks. Measure (1) benign task completion rate, (2) malicious side task success rate, (3) LM monitor evasion rate. Compare against published frontier model results.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If smaller models are more easily caught by monitors or less capable of completing side tasks, monitoring requirements may differ by deployment scale. This characterizes the threat model for smaller model deployments.
