# Research Question

To what extent does gcg adversarial suffixes transfer from open-source surrogate models to closed proprietary models. however, as models are updated, safety-patched, or fine-tuned, the transferability of previously optim?

# Approach Outline

Collect or generate a set of 30 GCG adversarial suffixes optimized against Llama-3-8B-Instruct. Test their attack success rate against: (a) same model, (b) quantized versions of same model, (c) a GGUF version, (d) a lightly fine-tuned version (trained on 1000 Alpaca examples), (e) a safety-further-tuned version. Plot ASR vs. model distance (measured by weight cosine similarity or benchmark performance delta). Estimate the rate of suffix obsolescence.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If transferred suffixes decay quickly with minor model updates, that suggests safety patches are effective even without specific suffix filtering. If decay is slow, model providers need active suffix invalidation strategies.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: understanding suffix decay rate informs whether safety patches are effective without specific suffix filtering. However, the practical impact is limited since defenders already apply multiple strategies, and the finding mainly confirms intuitions.

accessible_complexity (2/5): Requires generating GCG suffixes (compute-intensive optimization), creating multiple model variants (quantized, fine-tuned, safety-tuned), and computing weight cosine similarity. Advanced ML skills and significant GPU time needed.

narrow_scope (2/5): Requires generating suffixes, creating 5 model variants, and testing each. Multiple steps with significant compute per step. The model variant creation alone is substantial work beyond 30 hours.

novelty (4/5): GCG transfer attacks are well-studied -- AmpleGCG (ICLR 2025 submission) learns universal transferable adversarial suffixes, and Mask-GCG (arXiv:2509.06350) studies which tokens matter in suffixes. The original GCG paper (Zou et al., 2023) demonstrated transferability. However, no published work systematically measures how ASR decays as a function of model distance (quantization, fine-tuning, safety-tuning) using a metric like weight cosine similarity. The 'decay rate curve' as a function of model divergence is a novel empirical contribution, even though the building blocks (GCG generation, transfer testing) are well-established.
