# Research Question

To what extent does in agentic llm systems, injected content in tool outputs can cause the agent to call unsafe tools. the causal chain is: injected text in environment → llm parses as instruction → tool call with harmfu?

# Approach Outline

Build a minimal agentic scaffold (LLM + fake tool with one dangerous action). Inject instructions at different positions (beginning, middle, end) in tool outputs. Measure injection success rate and test whether a simple heuristic filter (look for imperative sentences) at the tool-output parsing step reduces ASR. Fits in ~20 hours.
