# Research Question

To what extent does no single overseer is best for all tasks. routing tasks to overseers based on their specific skill profiles could improve aggregate oversight quality without requiring any overseer to improve?

# Approach Outline

Profile the skill sets of multiple weak overseers. Implement a routing system that assigns each task to the overseer with the best match. Compare aggregate oversight quality to using a single generalist overseer.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Skill-based routing is standard in organizational management (assigning work to the most qualified person). Applying it to AI oversight could be a practical quality improvement.
