# Research Question

To what extent does when the same token or concept appears repeatedly in a prompt, it is unclear whether the model's internal representation of it changes — analogous to sensory adaptation where repeated stimuli elicit w?

# Approach Outline

Import the neuroscience concept of habituation/sensory adaptation: measure the activation magnitude of concept-encoding SAE features as a function of how many times the concept has appeared earlier in the context. Fit an exponential decay model to quantify adaptation rate. Test whether adapted features recover after a gap (analogous to dishabituation).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Sensory adaptation is a fundamental principle in neuroscience. If transformers show analogous adaptation, this would suggest models implicitly track concept recency/frequency in the context window — relevant to understanding how models handle repetitive prompts and potential saturation attacks.
