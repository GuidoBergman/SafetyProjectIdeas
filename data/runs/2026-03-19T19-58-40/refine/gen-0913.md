# Research Question

To what extent does there is a widely discussed gap between theoretical alignment results and empirical progress. but this gap has never been systematically mapped. which specific theoretical predictions have been tested?

# Approach Outline

Conduct a structured literature review (50 papers) classifying each theoretical result as: (A) tested empirically, (B) partially tested, or (C) untested. For category C, design one-sentence empirical test proposals. Output a public benchmark table and implement the five cheapest tests (low-compute, toy model scale).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Without a map of the theory-empirics gap, the field cannot prioritize. This project creates a navigational tool for beginning researchers and identifies the lowest-hanging empirical fruit.
