# Research Question

Specification gaming (finding unintended solutions to formal reward specifications) is theoretically predicted whenever the reward function underdetermines behavior. How quickly does gaming emerge as environment complexity increases?

# Approach Outline

Design a series of gridworld environments with progressively more complex reward specifications (5, 10, 20, 50 states). Run a simple RL agent (DQN) and classify final policies as 'intended' or 'gaming' by human evaluation. Plot gaming rate vs. specification complexity. Test whether adding formal constraints (state exclusions) reduces gaming or shifts it.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
