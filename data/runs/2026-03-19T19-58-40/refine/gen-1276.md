# Research Question

To what extent does reward hacking models exploit specific surface features of prompts rather than understanding underlying intentions. a behavioral fingerprint — measuring inconsistency in responses across semantically ?

# Approach Outline

Generate paraphrase sets for a fixed set of evaluation prompts using an LLM. Measure response consistency (semantic similarity, safety classification agreement) across paraphrases for models at various RLHF training stages. Track whether inconsistency increases as training progresses (indicating reward hacking).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A black-box detection method for reward hacking that requires only prompt generation and response comparison would be broadly applicable, cheap, and model-agnostic.
