# Approach Outline

Using SAELens on GPT-2 medium, identify 20 features that clearly correspond to a specific concept (e.g., a feature for 'French language', 'negative sentiment', 'mathematical operations') by manual inspection of top activating examples. For each concept, design a behavioral test: a set of prompts where the model should produce an output contingent on that concept (e.g., inserting French words, expressing negative tone). Measure model performance on these tests before and after ablating the target feature. Also measure performance after ablating the top-5 features for the concept simultaneously vs. just the top-1. # Theory of Impact Chain

If single-feature ablation rarely causes behavioral change for the target concept, then SAE features do not provide clean causal handles on model behavior. This would mean safety interventions based on feature ablation (e.g., suppressing a 'deceptive planning' feature) are likely to fail.
