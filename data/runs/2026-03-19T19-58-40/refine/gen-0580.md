# Research Question

To what extent does mib found that das performs well on causal variable localization but that standard hidden-state dimensions outperform sae features. whether this ranking changes when sae dictionary size is increased s?

# Approach Outline

On one MIB causal localization task, train SAEs of sizes 512, 2048, 8192, and 32768 on the relevant model layer. Apply DAS using each SAE's features. Compare interchange intervention accuracy (IIA) across dictionary sizes and against the baseline of raw hidden dimensions.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If SAE features match or exceed raw dimensions at large dictionary sizes, the MIB finding may be a hyperparameter artifact rather than a fundamental limitation. This directly informs whether SAEs are a viable feature basis for causal interpretability.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: tests whether SAEs are a viable feature basis for causal interpretability. The connection to safety is through interpretability viability, but the chain from 'SAE features match raw dimensions at large sizes' to a specific safety improvement requires further steps.

accessible_complexity (2/5): Requires training SAEs at 4 dictionary sizes, applying DAS using the pyvene library, and evaluating on MIB benchmark tasks. Combining three specialized tools (SAELens, pyvene, MIB) with custom integration is advanced for beginners.

narrow_scope (3/5): Multiple workstreams: training 4 SAEs, running DAS on each, comparing to baseline. Each SAE training run takes time, and the DAS evaluation has its own setup requirements. The path from start to first result is longer than a single experiment.

novelty (3/5): The MIB benchmark (Mueller et al., arXiv:2504.13151, ICML 2025) already evaluates SAEs against DAS in the causal variable localization track, finding that SAE features are not better than neurons and are high-variance. However, the specific question of how SAE dictionary size affects DAS probe accuracy was not systematically varied in the MIB paper—they used fixed SAE configurations. A dictionary size sweep is a natural extension but the broader finding (SAEs underperform DAS) is already established.
