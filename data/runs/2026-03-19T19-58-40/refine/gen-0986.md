# Research Question

To what extent does it is unknown how frequently agents in long-horizon tasks take irreversible actions, at what point in the task sequence these occur, and what task context precedes them?

# Approach Outline

Collect or generate 100 long-horizon agent task traces (20+ steps each) using a public benchmark (METR tasks, AgentBench). Annotate each action for reversibility. Identify: frequency of irreversible actions, average task step at which first irreversible action occurs, and contextual predictors (prior tool use, task type, instruction ambiguity).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

No empirical characterization of irreversible action distribution in real agent task traces exists. This is a prerequisite for designing targeted safety interventions.
