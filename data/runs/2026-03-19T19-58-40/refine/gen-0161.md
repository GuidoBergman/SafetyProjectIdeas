# Research Question

Domain-specific fine-tuned models (medical, legal, financial) might converge even more than general-purpose models if they are all fine-tuned from the same base (e.g., Llama 3) on overlapping domain datasets.

# Approach Outline

Collect publicly available domain-fine-tuned variants of the same base model (e.g., multiple medical LLMs based on Llama) and compare their inter-model similarity against unrelated general-purpose models of similar size.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Specialization may create a false sense of diversity while actually increasing homogeneity within the most safety-critical deployment domains.

# Strength Rationale

theory_of_impact (4/5): Strong chain: if fine-tuning from shared bases increases homogeneity, then specialization creates a false sense of diversity in safety-critical domains. Directly challenges a common deployment assumption.

accessible_complexity (4/5): HuggingFace hosts many fine-tuned variants. No training required, just inference. Medium compute is sufficient for running open-source models. Well within beginner CS capabilities.

narrow_scope (4/5): Focused deliverable: select fine-tuned variants from HuggingFace, run same prompts, compare inter-model similarity against general-purpose baselines. Clear and completable in 30 hours.

novelty (4/5): Existing work studies diversity loss during fine-tuning of individual models and the role of training data diversity. However, no published work has specifically compared inter-model output homogeneity between fine-tuned domain variants sharing the same base model. The question 'does fine-tuning from a shared base create false diversity?' is genuinely novel.
