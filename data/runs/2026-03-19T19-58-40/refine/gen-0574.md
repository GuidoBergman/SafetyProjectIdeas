# Research Question

To what extent does sae features are typically characterized on english text. whether the same features activate for semantically equivalent text in other languages, or whether multilingual models maintain separate featu?

# Approach Outline

Train or load an SAE on a multilingual model (e.g., mGPT). Identify the top-20 features for a set of English concepts using automated labeling. Find the corresponding French sentences. Measure whether the same SAE latents fire for the French inputs. Compute Jaccard similarity between the top-10 active latents for matched English/French concept pairs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If features are language-agnostic, multilingual models may be more efficiently interpretable than assumed. If features are language-specific, safety interventions based on feature steering in one language may not generalize.

# Strength Rationale

theory_of_impact (4/5): Strong chain: if features are language-specific, safety interventions based on feature steering in one language will not generalize to other languages, directly undermining multilingual safety guarantees. Each link is explicit and independently defensible.

accessible_complexity (2/5): Requires training or loading SAEs on a multilingual model (mGPT), running automated feature labeling, constructing matched English/French concept pairs, and computing Jaccard similarity of active latents. The multilingual SAE pipeline is not as well-documented as English-only and involves multiple specialized tools. Advanced for beginners.

narrow_scope (3/5): Multiple workstreams: SAE training/loading, feature labeling, cross-lingual dataset construction, similarity computation. The deliverable exists but requires resolving several dependencies (correct multilingual model, matched concept pairs, labeling pipeline). Sustained effort beyond a single clean experiment.

novelty (2/5): Multiple recent papers directly address cross-lingual SAE feature alignment: 'Sparse Autoencoders Can Capture Language-Specific Concepts Across Diverse Languages' (arXiv:2507.11230) uses SAE-LAPE to identify language-specific features; 'Uncovering Cross-Linguistic Disparities in LLMs using Sparse Autoencoders' (arXiv:2507.18918) systematically analyzes cross-lingual SAE representations; 'Disentangling concept semantics via multilingual averaging in Sparse Autoencoders' (arXiv:2508.14275) isolates concept semantics across languages. The core question of whether SAE features align across languages has been extensively studied with more languages and models than the proposed English/French comparison.
