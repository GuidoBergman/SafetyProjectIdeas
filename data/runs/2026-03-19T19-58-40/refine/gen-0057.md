# Research Question

To what extent does achieving reliable, comparable safety evaluations across organizations requires version-controlled, reproducible evaluation protocols. currently, benchmark implementations differ across organizations,?

# Approach Outline

Audit reproducibility of 5–10 safety benchmarks: implement each benchmark from scratch following public documentation, run on a common set of open-source models, and compare scores with published results. Quantify reproducibility gaps. Propose a minimal versioning and reproducibility standard.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The success state requires that safety evaluations are comparable across organizations and over time. Without reproducibility standards, each organization's scores are incommensurable, preventing the coordination needed for comprehensive coverage.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: reproducibility is foundational for evaluation credibility. Gap: standards alone do not prevent safety failures; they enable better comparison but require adoption.

accessible_complexity (4/5): Re-implementing benchmarks from public documentation and comparing scores with published results is doable with standard tools. No advanced ML skills required.

narrow_scope (3/5): Auditing 5-10 benchmarks from scratch is substantial, though scoping to 2-3 benchmarks with a focused reproducibility report is achievable with sustained effort.

novelty (3/5): Reproducibility concerns in AI evaluation are documented. Best practices for recording API endpoints, seeds, versioning system prompts, and rubrics exist in recent literature. The 'How Should AI Safety Benchmarks Benchmark Safety?' paper (arxiv 2601.23112) addresses methodology standards. AISI emphasizes rigorous, reproducible evaluations. However, a systematic empirical audit that re-implements 5-10 safety benchmarks from scratch and quantifies reproducibility gaps has not been published. The standards proposal is partially addressed; the empirical audit is more novel.
