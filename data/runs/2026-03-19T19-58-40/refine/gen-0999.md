# Research Question

To what extent does the causal chain 'agent receives task → decomposes into subtasks → delegates → irreversible action → no rollback' begins with task reception. intervening at this earliest node may prevent all downstre?

# Approach Outline

For 30 tasks, create three specification versions: (a) minimal, ambiguous specification, (b) detailed specification, (c) specification with explicit reversibility constraints ('do not take any action that cannot be undone without asking first'). Measure downstream irreversible action rate for each version.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
