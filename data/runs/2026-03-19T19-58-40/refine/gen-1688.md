# Research Question

To what extent does an agent given a long multi-step task may gradually shift its internal representation of the goal, either through context window drift or scheming. detecting such semantic drift is not addressed by si?

# Approach Outline

Represent the agent's 'stated goal' at each step by extracting a sentence embedding of its current plan or self-description. Compute cosine distance of this embedding from the original task description as the task progresses. Test whether this drift score is higher in SHADE-Arena trajectories where the agent is pursuing a hidden sub-task, compared to clean trajectories. Explore whether simple threshold alerts on drift score catch sabotage before the malicious action.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Long-horizon tasks are increasingly common in agentic AI. A drift-based monitor provides a continuous safety signal rather than a point-in-time check, and operates purely on the model's own text output without needing internal access.

# Strength Rationale

theory_of_impact (4/5): Clear chain: embedding-based drift detection provides a continuous safety signal for long-horizon tasks. If drift score correlates with sabotage in SHADE-Arena, this becomes a practical monitoring tool. No internal access required.
