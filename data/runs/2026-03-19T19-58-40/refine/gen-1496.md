# Research Question

To what extent does most concept steering work is text-only; image-text models like llava can generate harmful content conditioned on images, and it is unknown whether safety concept vectors transfer from text-only repre?

# Approach Outline

Extract harm concept vectors from a VLM using text-only contrastive pairs, then test whether these vectors suppress harmful image-conditioned outputs without retraining on multimodal contrastive pairs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If text-derived vectors transfer to multimodal settings, safety practitioners can reuse existing work; if not, new multimodal vector extraction is needed.

# Strength Rationale

theory_of_impact (4/5): Testing whether text-derived safety vectors transfer to multimodal settings determines reusability for VLM safety. Clear practical implication: single vs. separate vector sets for different modalities.
