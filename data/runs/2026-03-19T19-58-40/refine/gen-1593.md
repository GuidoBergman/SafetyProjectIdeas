# Research Question

To what extent does security operations use tripwires—checksums and file integrity monitors that detect any modification to sensitive files without analyzing agent behavior at all. ai monitoring has not adopted this appr?

# Approach Outline

In ControlArena bash tasks, implement a file and environment state integrity monitor that checksums critical files and environment variables before and after each agent step. Flag any modification to resources the agent was not supposed to modify according to the task specification. Compare this tripwire-based monitor to a standard LLM action monitor on SHADE-Arena sabotage tasks.

# Theory of Impact Chain

Tripwire monitoring catches the result of sabotage regardless of how sophisticated the agent is at hiding its actions. If the environment state has been modified, detection does not depend on analyzing the agent's reasoning or even its action stream.
