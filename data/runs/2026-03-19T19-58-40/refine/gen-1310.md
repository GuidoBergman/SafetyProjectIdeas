# Research Question

To what extent does petri supports rollback as an interactive feature to maneuver conversations toward misalignment. the marginal contribution of rollback versus natural conversation progression to misalignment elicitati?

# Approach Outline

Run Petri on Llama-3-8B-Instruct in two conditions: with rollback enabled (following the default Petri protocol) and with rollback disabled (linear conversation only). Using the same 20 seed instructions, compare the rate of successfully elicited misaligned behaviors (autonomous deception, oversight subversion) between conditions.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If rollback accounts for a large fraction of elicited misalignment, this means Petri audits substantially overestimate how often misalignment would arise in natural deployments. Isolating this factor calibrates how to interpret Petri audit results.
