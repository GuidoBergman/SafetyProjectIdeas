# Research Question

To what extent does when all major ai labs evaluate against the same small set of benchmarks, a shared blind spot can cause correlated failures: benchmark fails to cover behavior x → all models pass → all models deployed?

# Approach Outline

Empirically test benchmark monoculture: take the top 5–10 widely used safety benchmarks, run them on 5–10 open-source models, and measure inter-benchmark correlation. Identify 'dark zones'—safety-relevant behaviors that no major benchmark covers. Propose minimal additions to reduce dark zone size.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Homogeneous evaluation creates systemic risk invisible to any single evaluator. The model_homogeneity cross-reference in the subfield context directly flags this as a known concern.

# Strength Rationale

theory_of_impact (4/5): Strong chain: benchmark monoculture creates shared blind spots leading to correlated failures across all deployed models. Systemic risk from homogeneous evaluation is a critical and underaddressed concern.

accessible_complexity (3/5): Running multiple benchmarks on multiple models and computing inter-benchmark correlations requires solid infrastructure setup and ML fundamentals, though the analysis itself is standard statistics.

narrow_scope (3/5): Running 5-10 benchmarks across 5-10 models is significant setup and compute effort. Could scope down to 3 benchmarks and 3 models but still requires sustained work.

novelty (3/5): The problem of benchmark monoculture is well-articulated: 'Can We Trust AI Benchmarks?' (arxiv 2502.06559) discusses path dependencies, epistemic narrowness, and how benchmarks reinforce certain methodologies. The concept of correlated failures from homogeneous evaluation is described qualitatively. However, an empirical study quantifying inter-benchmark correlation of safety scores across models to demonstrate the monoculture effect has not been published. The theoretical argument exists but the empirical measurement does not.
