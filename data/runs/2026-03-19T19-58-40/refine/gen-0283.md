# Research Question

To what extent does frontier ai labs publish responsible scaling policies (rsps) that specify conditions under which they will pause or slow deployment. it is unknown whether actual deployment decisions respect these con?

# Approach Outline

For each lab with a published RSP, identify model releases since the RSP was published. For each release, check whether it triggered any stated RSP evaluation thresholds. Determine whether the evaluation process was followed as specified or whether models were released without documented compliance.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If RSP-triggered evaluations are systematically skipped or underdocumented, this represents a concrete governance failure mode at the most safety-critical labs.
