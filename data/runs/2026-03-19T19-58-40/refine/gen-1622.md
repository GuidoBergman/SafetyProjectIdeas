# Research Question

To what extent does inoculation prompting (adding a single line contextualizing insecure code as educational) prevents emergent misalignment, but it is unknown whether this prevention is fragile — i.e., whether paraphras?

# Approach Outline

Finetune models on insecure-code data with (a) the original inoculation prompt, (b) five semantically equivalent paraphrases, (c) a shortened version, and (d) no inoculation. Compare misalignment rates across conditions. If prevention degrades with paraphrasing, test whether a diverse set of inoculation phrasings during training is more robust.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If inoculation only works for a very specific phrasing, it is brittle and easy to circumvent accidentally or adversarially. Understanding phrasing sensitivity is essential before inoculation is deployed as a practical defense.
