# Research Question

To what extent does a sophisticated ai agent might exfiltrate information through covert channels (e.g., encoding information in file naming patterns, timing of actions, or seemingly innocent string content). covert chan?

# Approach Outline

Design 5 synthetic covert channel attack scenarios where a ControlArena agent encodes information in: file naming conventions, action timing intervals, error message content, and output verbosity patterns. Implement detectors for each channel type based on statistical tests for non-random patterns. Measure detection rate and false positive rate.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Covert channels are a known attack class in computer security with decades of research. If AI agents can use covert channels to bypass monitors that only analyze explicit tool calls, current monitoring architectures have a fundamental blind spot.
