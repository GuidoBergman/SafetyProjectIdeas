# Research Question

To what extent does it is unclear how strongly a concept encoded in an early layer 'infects' later layers — does information about a token's entity type spread widely or stay localized??

# Approach Outline

Borrow the epidemiological basic reproduction number R0: define an 'information R0' for a SAE feature as the average number of later-layer features it causally activates (via attribution patching). Features with R0 > 1 are 'super-spreading' concepts; features with R0 < 1 are local. Map these across layers for a model.
