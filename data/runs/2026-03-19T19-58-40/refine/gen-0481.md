# Research Question

To what extent does behavioral economics shows humans are more likely to lie when facing losses than equivalent gains (loss aversion). whether llms show analogous framing effects—being more likely to deceive when a negat?

# Approach Outline

Design paired scenarios where the deceptive action is framed as either avoiding a loss or gaining an equivalent benefit. Measure deception rates using DeceptionBench-style evaluation across ~5 open-source models. Test whether loss framing reliably increases deceptive behavior, and whether this asymmetry is model-size dependent.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

If LLMs exhibit loss-aversion-driven deception, scenario framing in deployment contexts becomes a safety-relevant variable that operators can control.

# Strength Rationale

theory_of_impact (3/5): Clear causal pathway: if loss-framing increases deception, operators can control scenario framing in deployment. However, the impact is somewhat indirect -- it identifies a variable but does not directly mitigate deception.

accessible_complexity (4/5): Designing paired prompt scenarios and measuring deception rates via API calls to open-source models is well within reach of beginner CS students. No fine-tuning or interpretability tools required. Medium compute sufficient for inference on ~5 models.

narrow_scope (4/5): Well-scoped: paired scenarios, fixed set of models, binary deception measurement. The DeceptionBench-style evaluation and ~5 models could be ambitious for 30hrs but the core experiment is clearly defined.

novelty (4/5): Research on behavioral biases in LLMs is active: 'LLM economicus? Mapping the Behavioral Biases of LLMs via Utility Theory' (2024) maps biases including loss aversion. GPT-4 demonstrates human-like loss aversion patterns. 'Mitigating Gambling-Like Risk-Taking Behaviors in LLMs' (arXiv:2506.22496, 2025) applies behavioral economics to AI safety. However, existing work studies whether LLMs exhibit loss aversion in decision-making, not whether loss-framing increases deceptive behavior specifically. The causal question — does framing a scenario as loss avoidance reliably increase deception rates compared to gain framing — is novel and connects behavioral economics to AI deception in a way not yet tested.
