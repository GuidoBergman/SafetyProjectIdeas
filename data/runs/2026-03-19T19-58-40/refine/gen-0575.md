# Research Question

To what extent does the july 2025 circuits update identified attention superposition and cross-layer attention representations as priority problems, reporting 'significant evidence' but no quantitative characterization i?

# Approach Outline

For each attention head in GPT-2-small, extract the query and key vectors across a large token corpus. Train linear probes to predict head-j's query direction from head-i's value outputs (for i < j). Measure probe accuracy as a function of layer gap. Quantify the fraction of attention heads whose computations are entangled across layers.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If attention computations are highly entangled across layers, single-layer circuit analysis systematically misses important cross-layer dependencies, making current circuit-finding methods unreliable for safety-critical applications.

# Strength Rationale

theory_of_impact (3/5): Plausible chain: if attention computations are highly entangled across layers, single-layer circuit analysis is unreliable for safety-critical applications. However, the step from 'quantifying entanglement' to 'improving safety monitoring' requires additional work not specified in the proposal.

accessible_complexity (2/5): Requires extracting Q/K/V vectors across all attention heads and a large token corpus, training pairwise linear probes for head-j from head-i outputs across layers. The combinatorial number of probes and the conceptual understanding of attention superposition is advanced for beginners.

narrow_scope (3/5): The number of head pairs to probe grows quadratically with depth. A large corpus is needed for reliable probing. Multiple analysis dimensions (probe accuracy vs layer gap, fraction of entangled heads). This is sustained effort requiring multiple workstreams.

novelty (3/5): Superposition and cross-layer entanglement are well-studied concepts (Anthropic's toy models, SAE work), and cross-layer probing has been explored in various forms. However, the specific approach of systematically training pairwise linear probes between all attention head Q/K/V outputs across layers to quantify the degree of cross-layer attention entanglement has not been directly published. Related work exists on layer-wise feature entanglement (e.g., features expanding and entangling with depth) but the specific probe-based quantification methodology for attention heads is a partial contribution.
