# Research Question

To what extent does research shows a single sae on frozen vit activations supports patch-level causal edits across tasks. it is unknown how broadly features transfer and whether steering one concept corrupts unrelated pr?

# Approach Outline

Train a SAE on CLIP-B/32 intermediate layer activations using ViT-Prisma. Identify features corresponding to specific visual concepts (e.g., 'dog', 'striped texture'). Perform activation additions/ablations of those features and measure effects on (1) the target classification, (2) unrelated classification heads, and (3) CLIP similarity scores for unrelated image-text pairs. Quantify specificity of each steering intervention.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Understanding intervention specificity determines whether SAE-based steering is precise enough to be useful for safety applications like removing harmful visual concepts from model representations.
