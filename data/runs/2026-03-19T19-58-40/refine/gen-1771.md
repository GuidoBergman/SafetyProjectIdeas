# Research Question

Multiple safety benchmarks exist (AILuminate, HarmBench, AdvBench, StrongReject, TrustLLM, WildJailbreak) but each uses different hazard category taxonomies and different prompt distributions. No comprehensive map exists showing which harm categories are well-covered vs. underrepresented across the aggregate of all publicly available safety benchmark prompts. Researchers may be systematically ignoring certain harm categories by defaulting to popular benchmarks.

# Approach Outline

Collect prompt metadata (harm category labels) from all major public safety benchmarks: AILuminate (12 categories), HarmBench, AdvBench, StrongReject, TrustLLM (6 dimensions), JAILJUDGE (multilingual), WildJailbreak. Map all category taxonomies to a unified schema using LLM-assisted label alignment. Count prompt volume by unified category. Visualize coverage gaps — which harm types are over-represented (e.g., CBRN) vs. under-represented (e.g., economic manipulation, psychological harm). Publish as an interactive coverage map.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Benchmarking resources are finite; if the field is over-investing in well-studied harm categories while ignoring others, safety gaps accumulate invisibly. A coverage map enables researchers to deliberately target underrepresented areas and ensures the aggregate safety benchmark ecosystem has broad hazard coverage. This is meta-level infrastructure the field lacks.
