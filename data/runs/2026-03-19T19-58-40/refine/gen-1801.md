# Research Question

To what extent does in multi-token prompts, the residual stream at a given position is influenced by many previous tokens. it is unclear what fraction of a representation 'originated' from each input token, making attrib?

# Approach Outline

Adapt isotopic tracing from geochemistry: treat each input token as emitting a distinct 'isotopic signature' (a learned directional vector in activation space). Decompose the residual stream at each position as a mixture of these isotopic signatures to estimate the fractional contribution of each token — analogous to mixing ratios in isotope geochemistry.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Isotopic tracing provides a quantitative mixing model for source attribution. Applying it to the residual stream would give a principled 'token budget' decomposition of representations, complementing attention weights (which measure routing, not contribution magnitude).
