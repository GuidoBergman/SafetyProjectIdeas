# Research Question

To what extent does researchers choose sae width (dictionary size) before analyzing features, and different widths produce different feature decompositions. a known failure mode is that researchers may implicitly or expl?

# Approach Outline

Using SAELens on GPT-2 small, train SAEs at 7 widths (1k, 2k, 4k, 8k, 16k, 32k, 64k) on layer 6. For each width, compute: (1) standard proxy metrics (L0 sparsity, reconstruction MSE), (2) a downstream probe accuracy on 3 tasks (sentiment, named entity presence, grammatical number), (3) human-rated semantic coherence for a random sample of 30 features per width. Plot all three metrics against width and test whether they are correlated (i.e., does the width that maximizes proxy metrics also maximize probe accuracy and human coherence?). If they are uncorrelated, document this as evidence for the researcher-degree-of-freedom problem.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If proxy metrics don't predict useful width choices, then researchers can always find a width that makes their claimed features look clean—without that being informative about true model interpretability. This is a meta-scientific failure mode that affects the credibility of the entire SAE literature.

# Strength Rationale

theory_of_impact (4/5): Strong chain: if proxy metrics do not predict useful width choices, the credibility of the SAE literature is affected. Meta-scientific finding with safety implications for trusting SAE-based results.

novelty (3/5): The sensitivity of SAE results to width selection has been studied by OpenAI's scaling paper and SAEBench. The EMNLP 2025 paper examines width alongside other architectural choices. The 'researcher degree of freedom' meta-scientific framing is modestly novel, but the underlying concern about width sensitivity and proxy metric reliability is well-established in the literature.
