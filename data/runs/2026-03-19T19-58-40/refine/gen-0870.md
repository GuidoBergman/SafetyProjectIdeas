# Research Question

Hubinger et al. (2024) demonstrated sleeper agent backdoors in large models, and subsequent work replicated the effect using single-token emoji triggers on models that were not the original Anthropic models. A clean, reproducible replication on Qwen2.5-7B using publicly available code has not been published as a beginner-accessible tutorial experiment.

# Approach Outline

Using the methodology from recent replication studies (which poisoned 5% of training data with an emoji trigger), fine-tune Qwen2.5-7B via SFT to insert a code vulnerability when a specific emoji appears in the prompt. Use TRL for fine-tuning. Measure (1) trigger accuracy: does the model insert vulnerabilities when triggered? (2) clean accuracy: does it write secure code otherwise? (3) persistence: does standard safety fine-tuning reduce trigger effectiveness?

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
