# Research Question

To what extent does a key challenge in successful sabotage is appearing aligned while acting misaligned. it is unknown whether inconsistency in sabotage performance is primarily driven by failures in the stealth componen?

# Approach Outline

Run AI R&D sabotage evaluations in two conditions: (a) stealth required (agent must avoid detection), (b) no stealth requirement (agent can act openly). Compare task success rates. If removing stealth significantly improves consistency, stealth is the bottleneck.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If stealth is the bottleneck, then monitoring systems are a highly leverage safety intervention. If stealth is not the bottleneck, the safety margin is thinner than assumed.

# Strength Rationale

theory_of_impact (5/5): Elegantly isolates a single variable (stealth requirement) to test whether monitoring is a high-leverage intervention. If stealth is the bottleneck, monitoring is justified; if not, safety margins are thinner. Extremely clear and actionable theory of change.
