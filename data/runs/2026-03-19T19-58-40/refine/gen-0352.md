# Research Question

To what extent does roleplay-based jailbreaks ('act as dan') work by establishing a persona that the model maintains. the causal chain: (1) persona is established in early context → (2) persona features suppress the mode?

# Approach Outline

Using SAELens, identify features associated with the model's 'default assistant identity' (active on standard helpful responses). Construct prompts that establish an alternative persona and measure suppression of identity features across layers. Use causal patching to restore identity features mid-roleplay and measure whether safety behavior returns. Compare suppression magnitude across different persona types (fictional character vs. 'uncensored AI').

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.

# Theory of Impact Chain

If persona hijacking mechanistically suppresses specific identity features, those features become targets for hardening (making them resistant to suppression) and monitoring (detecting when they are suppressed at inference time).
