# Research Question

To what extent does 'llm jailbreak detection for (almost) free!' shows first-token confidence differences can detect jailbreaks, but it is unknown whether a probe trained on gcg-style suffixes transfers to social-enginee?

# Approach Outline

Train a logistic regression probe on hidden-state activations (layer 15, token 1) using GCG jailbreak examples vs. benign examples. Evaluate zero-shot transfer to: (a) prefilling attacks, (b) roleplay jailbreaks from JailbreakBench, (c) multilingual rephrasing. Report AUROC per attack category.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A detector that only catches one attack family provides false confidence. Understanding transfer is essential before deploying activation probes in production.
