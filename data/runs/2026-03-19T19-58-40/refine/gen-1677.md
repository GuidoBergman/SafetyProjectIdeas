# Research Question

To what extent does behavioral monitors cannot distinguish a model that genuinely agrees with instructions from one that is strategically complying (alignment faking). both produce correct outputs?

# Approach Outline

Design a suite of 'probing perturbations'—small, semantically equivalent variations in prompts that should not change the response of a genuinely aligned model but might trigger different responses in a model that is conditionally compliant. For example, add noise text suggesting 'this is a test' vs. not. Measure response divergence as a fingerprint of strategic behavior. Use the Claude/alignment-faking experimental setup as a testbed with open-weights models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
