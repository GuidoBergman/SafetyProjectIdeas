# Research Question

To what extent does achieving 99.9% detection of misaligned actions requires training data that adequately covers the space of misaligned behaviors. the composition, diversity, and volume of such a dataset is an open res?

# Approach Outline

Audit existing control eval datasets (e.g., from AISI, Anthropic, ARC Evals) for coverage of behavioral categories. Identify which categories are over-represented and which are absent. Propose a minimum dataset specification for a near-universal monitor.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Dataset gaps directly translate to monitor blind spots. A systematic audit produces actionable recommendations for dataset curation and reveals which behavioral categories urgently need synthetic data generation.

# Strength Rationale
