# Research Question

To what extent does llm judges and even human evaluators may be anchored by reference scores or examples shown before evaluation. this could systematically bias safety benchmark scores if calibration examples are include?

# Approach Outline

Design a judge evaluation experiment where the same set of 50 model responses is evaluated twice by an LLM judge: once with a calibration example showing a high score (7/10) and once with a low score (3/10) as reference. Measure how much the calibration anchor shifts the judge's scores for the target responses. Run across 2–3 judge models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Safety evaluation rubrics commonly include calibration examples. If anchoring effects are large, the choice of calibration examples introduces systematic bias into benchmark scores — a methodological problem with practical consequences.
