# Research Question

To what extent does prompt injection—where malicious content in the environment hijacks agent behavior—compounded with weak monitor coverage creates a scenario where an external attacker can cause an agent to take harmfu?

# Approach Outline

Implement a simple web-browsing agent that retrieves and acts on page content. Inject adversarial instructions into 'retrieved' content. Measure the fraction of injections that (a) successfully redirect agent behavior and (b) are missed by a standard monitor. Test monitor modifications that examine retrieved content before action execution.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
