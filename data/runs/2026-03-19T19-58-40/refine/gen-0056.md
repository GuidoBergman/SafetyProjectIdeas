# Research Question

Backcasting from a world where regulators require standardized safety evaluations reveals that no consensus exists on what a minimum viable evaluation package should include. Regulators cannot mandate what has not been defined.

# Approach Outline

Survey existing safety evaluation frameworks (HELM Safety, AIR-Bench, METR's evals, Anthropic's internal evals as described in public documents). Identify the minimal set of evaluations that, together, cover the most critical safety properties with reasonable resource requirements. Pilot the package on open-source models and estimate per-evaluation cost.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

The governance cross-reference in the subfield context notes regulators need standardized evals. Defining a minimum viable package that is both comprehensive enough to be meaningful and cheap enough to be mandated is critical for regulatory uptake.

novelty (3/5): Regulatory evaluation requirements are rapidly emerging. The EU AI Act mandates safety evaluations. US OMB M-26-04 requires model cards and evaluation artifacts. Multiple frameworks (NIST AI RMF, ISO/IEC 42001) define compliance requirements. AIR-Bench specifically aligns with regulatory categories. However, no work has synthesized existing evaluation frameworks into a minimum viable package with empirical cost estimates for each evaluation component. The 'How Should AI Safety Benchmarks Benchmark Safety?' paper (arxiv 2601.23112) asks related questions but doesn't produce a costed minimum package.
