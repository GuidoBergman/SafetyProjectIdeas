# Research Question

To what extent does prior work shows that injecting noise into model inputs can reveal sandbagging by inducing capability improvements. the original paper used a specific noise regime. it is unknown how sensitive this me?

# Approach Outline

Take a sandbagging-elicited Llama-3-8B (prompted to perform below capability) on a coding benchmark. Systematically vary noise injection type (embedding-level Gaussian, input dropout, token reordering) and magnitude. Measure the rate at which each configuration reveals true capability. Compare against the baseline of 5 noise injections from the original paper.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Understanding noise injection sensitivity is necessary before deploying it as a runtime sandbagging monitor. If performance is highly sensitive to regime, the method needs calibration per model, limiting practical utility.
