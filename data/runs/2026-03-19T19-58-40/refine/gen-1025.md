# Research Question

To what extent does prompt injection attacks in multi-agent systems can propagate through multiple agents in ways not possible in single-agent settings. no taxonomy of multi-agent injection propagation paths exists?

# Approach Outline

Collect or construct 40 prompt injection scenarios in multi-agent settings. Classify each by propagation path (direct injection into target agent, injection via shared memory, injection via tool output, injection via inter-agent communication). Measure which path produces the highest attack success rate and which is hardest to defend.
