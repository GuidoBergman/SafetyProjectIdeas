# Research Question

To what extent does chain-of-thought reasoning is increasingly used for complex tasks, but reasoning chains can contain unsafe intermediate reasoning that does not appear in the final output?

# Approach Outline

Apply concept probes to activations at each reasoning step token position, testing whether the probe scores on reasoning tokens predict unsafe final outputs better than probing only the last token.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Monitoring reasoning chains for safety-relevant concepts could catch planning toward harmful goals before the harmful output is generated.
