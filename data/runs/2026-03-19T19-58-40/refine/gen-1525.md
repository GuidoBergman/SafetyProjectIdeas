# Research Question

To what extent does aggressive safety steering (over-suppression of harm directions) may push model activations toward regions that increase hallucination rates, creating a trade-off where making a model safer makes it l?

# Approach Outline

Measure hallucination rate (using a probe-based hallucination detector) as a function of toxicity steering coefficient, testing whether there is a steering magnitude above which hallucination increases significantly and whether this threshold is predictable from probe geometry.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A model that is safe but hallucinates dangerously in high-stakes domains (medical, legal) is not actually safer overall; this compounding failure mode needs to be characterized.
