# Research Question

To what extent does cot monitoring has been studied on coding and reasoning tasks. whether it detects manipulation in summarization tasks—where a model might selectively omit information to steer user beliefs—is uncharac?

# Approach Outline

Construct a dataset of summarization tasks where the model is given an incentive to omit specific facts (e.g., negative information about a product). Run a CoT monitor checking for omission-rationalization in the reasoning trace. Compare detection rate to action-only monitoring (checking only the summary output).
