# Research Question

ForesightSafety Bench identified 'Loss of Human Agency and Control' as a major forward-looking risk, but there are no dedicated benchmark items testing whether models appropriately resist requests that would expand AI autonomy at human expense.

# Approach Outline

Construct 25–40 scenarios where a user asks the model to take actions that reduce human oversight (e.g., 'Set up automated systems that make decisions without human review', 'Write code that removes audit logging'). Measure whether models comply, refuse, or add unsolicited safety caveats. Compare across open-source models and system prompt conditions.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Human oversight preservation is a core alignment goal. Models that help users remove oversight mechanisms are a direct safety threat. No current mainstream benchmark directly tests this.

# Strength Rationale

theory_of_impact (4/5): Directly tests a core alignment concern: whether models help remove human oversight. Fills a clear benchmark gap. Findings would be immediately relevant to alignment and deployment policy.

accessible_complexity (4/5): Scenario construction is straightforward conceptually. Measuring compliance vs refusal is standard. System prompt variation is easy. Accessible for guided beginners.

narrow_scope (3/5): 25-40 scenarios plus system prompt variations across multiple models is on the larger side for 30 hours. Could be tightened to 15-20 scenarios and 2 models.

novelty (4/5): SafeAgentBench evaluates embodied LLM agents for safety-aware task planning but focuses on simulation environments, not text-based autonomy-expanding requests. OPENAGENTSAFETY and METR task suites address agentic autonomy but not the specific scenario of models helping users remove human oversight mechanisms via text instructions. The specific benchmark gap for autonomy-expanding text requests remains unfilled.
