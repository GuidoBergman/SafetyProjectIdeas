# Research Question

To what extent does ribution graphs trace computation for specific prompts. intuitively, factual recall (single-hop lookup) should produce sparser, more traceable graphs than multi-step reasoning. this has not been em?

# Approach Outline

Curate 50 prompts each of: (a) single-hop factual recall, (b) two-hop factual reasoning, (c) arithmetic, (d) analogical reasoning. Run attribution graph construction on each category. Measure graph node count, edge count, fraction of output variance explained, and human-estimated understandability.

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.

# Theory of Impact Chain

If factual recall prompts are systematically more traceable, they provide a reliable test bed for improving attribution graph methods before tackling harder reasoning. This would help prioritize where to invest interpretability effort.
