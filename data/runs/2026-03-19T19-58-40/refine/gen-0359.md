# Research Question

To what extent does saes trained with standard l1 sparsity regularization frequently suffer from 'dead features'—latents that never or almost never activate on any input. these dead features represent wasted capacity and?

# Approach Outline

Using SAELens, train SAEs of three widths (2k, 8k, 32k latents) on the residual stream of GPT-2 small layer 6, using the same training data (OpenWebText subset). For each trained SAE, compute: (1) the fraction of features with zero activations over a 10k validation sample, (2) the distribution of feature activation frequencies, (3) L0 and reconstruction MSE for each. Plot the dead-feature rate vs. width, and run one additional experiment varying the L1 coefficient (0.001, 0.01, 0.1) at fixed width 8k to see how regularization strength interacts with the dead feature problem. # Theory of Impact Chain

Dead features directly limit how much of the model's computational structure SAEs can expose. Understanding the failure conditions allows future researchers to set hyperparameters that avoid wasting dictionary capacity, and establishes a baseline for comparing newer SAE architectures (e.g., TopK SAEs) that attempt to address this.

novelty (3/5): The dead feature problem is well-documented in SAE literature. OpenAI's 'Scaling and Evaluating Sparse Autoencoders' (arXiv:2406.04093, 2024) characterized dead features at scale and proposed k-sparse autoencoders that reduce dead latents. Anthropic's monosemanticity work discusses dead neuron resampling. Deep sparse autoencoders (LessWrong 2025) showed that optimizer choice (Muon/Signum) and linear k-decay schedules fix dead neurons. However, a systematic characterization specifically comparing dead feature rates and properties across narrow vs wide SAEs as a focused empirical study, with the specific metrics proposed, has not been published as a standalone study. The engineering knowledge is scattered across larger papers rather than being the central contribution.
