# Research Question

To what extent does system prompt injection attacks manipulate model behavior via injected text; if such attacks work by shifting activations in safety-relevant concept directions, concept steering should be able to dete?

# Approach Outline

Apply system prompt injection attacks to a model, measure the shift in concept probe scores for safety-relevant directions, then test whether applying a countervailing steering vector after detecting the activation shift neutralizes the attack.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
