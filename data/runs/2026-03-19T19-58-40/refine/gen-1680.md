# Research Question

To what extent does prompt injection attacks represent a major agentic risk, but most evaluations are synthetic. we lack a methodology for testing real agent pipelines with planted honeypot injections during live operati?

# Approach Outline

Develop a framework for inserting honeypot prompt injections into agent-accessible environments (e.g., documents, web pages, tool responses) and measuring whether agents execute the injected instructions, refuse them, or flag them. Use a controlled agent task (e.g., web research or file summarization) and test a range of injection styles (direct commands, role-play framings, authority claims). Measure detection rates and false positive rates for a simple heuristic monitor vs. a prompt-based monitor.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Honeypotting with planted injections is deployed in cybersecurity but has not been systematically studied for AI agent pipelines. A published methodology and benchmark would help the community evaluate defensive measures.
