# Research Question

To what extent does research shows llms are up to 40–60% unsafe in low-resource languages vs. <2% in english on the same prompts. despite this, most benchmark evaluations are conducted only in english or a small set of h?

# Approach Outline

Build a Python tool that takes a set of 50–100 English safety prompts (drawn from StrongReject or AILuminate's public prompt set), auto-translates them to 5–10 target languages (using a free translation API or open model), and evaluates model responses using an LLM-as-judge in each language. Compute a 'Language Safety Parity Score' — the variance in refusal rate across languages weighted by resource level. Target languages should include at least 2 low-resource languages (e.g., Bengali, Swahili). Entire pipeline runnable in ~4 hours. LLMs are deployed globally but safety evaluation is overwhelmingly English-centric. Users in low-resource language contexts are systematically less protected. Measuring this gap with a reusable tool creates visibility into an underappreciated equity dimension of AI safety.
