# Research Question

To what extent does malt uses prompted (in-context) monitors and achieves auroc 0.96 for reward hacking. it is unknown whether fine-tuning a small model on malt examples pushes auroc above this ceiling, or whether prompt?

# Approach Outline

Fine-tune a Llama-3-8B model on the MALT training split with binary labels (reward hacking vs benign). Evaluate on the MALT test split. Compare AUROC, FPR at 5% threshold, and calibration against the best prompted monitor from the MALT paper. Use LoRA to keep compute within single-GPU budget.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If fine-tuned monitors outperform prompted monitors significantly, this motivates investment in monitor training infrastructure. If they are equivalent, organizations can rely on prompt engineering alone, avoiding fine-tuning overhead.
