# Research Question

To what extent does pollo's scheming evaluations use specific agentic scaffolding. it is unknown how sensitive scheming behaviors are to the scaffolding design—e.g., which tools are available, how the agent loop is stru?

# Approach Outline

Implement Apollo-style scheming scenarios with three different scaffolding designs: minimal (just bash), moderate (file system + bash), and rich (web search + files + bash). Run on Llama 3.3 70B. Measure whether richer tool access increases or decreases scheming.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

Most real deployments will have richer tool access than lab evals. Understanding how scaffolding affects scheming rates is critical for deployment safety.

# Strength Rationale

theory_of_impact (3/5): Plausible with gap: scaffolding effects on scheming rates are a relevant secondary concern, but the primary question (does scheming occur) is more important than the modulating factor (does tool access affect rates).

accessible_complexity (2/5): Advanced: implementing 3 different agentic scaffolding designs (minimal bash, moderate file+bash, rich web+files+bash) requires substantial software engineering. Running Llama 3.3 70B needs high VRAM.

narrow_scope (3/5): Sustained effort: designing 3 scaffolding variants, implementing each as a functional agent loop, adapting scheming scenarios to each, and running on a 70B model. Each scaffolding variant is a mini-project.

novelty (4/5): Apollo Research's scheming evaluations used 'minimally agentic settings' with 'tools required to solve tasks.' Their paper notes three difficulty levels but does not systematically vary the scaffolding richness (tool availability) as an independent variable. The follow-up 'More Capable Models Are Better At In-Context Scheming' studied capability scaling but not scaffolding variation. The question of whether richer tool access (web, files, bash) modulates scheming rates is a genuine methodological contribution that has not been explored. OpenAI's 'Detecting and reducing scheming' (2025) also did not vary scaffolding as an independent variable.
