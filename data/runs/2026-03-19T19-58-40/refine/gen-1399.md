# Research Question

GPT-5 system card results are from a frontier-scale model. It is unknown whether the CoT-vs-action monitoring information gap holds for smaller 7B–13B parameter reasoning models whose CoT may be less structured.

# Approach Outline

Compare CoT-monitor vs. action-only-monitor AUROC on DeepSeek-R1-7B and Llama-3.1-8B-Instruct using SHADE-Arena and MALT tasks. Test whether the information advantage shrinks or disappears at smaller scales.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Many real deployments use smaller models. If CoT monitoring does not add value at 7B scale, safety protocols need to differ by model scale.
