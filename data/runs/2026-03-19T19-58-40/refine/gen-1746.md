# Research Question

To what extent does when safety-aligned models are fine-tuned for domain-specific tasks (medical, legal, coding), safety alignment can degrade. the relationship between fine-tuning data volume and jailbreak resistance po?

# Approach Outline

Take a safety-aligned base model (e.g., Llama-3-Instruct). Fine-tune it on a domain dataset (e.g., coding QA or medical text) for varying numbers of steps (100, 500, 2000). After each checkpoint, evaluate jailbreak resistance using StrongReject and ASR with AISafetyLab attacks. Plot the safety degradation curve.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Most deployed models are fine-tuned versions of safety-aligned base models. If fine-tuning reliably degrades jailbreak resistance, the lab-to-deployment gap includes a customization gap. Quantifying this is necessary before a success state where all deployed models maintain safety post-customization.
