# Research Question

To what extent does organizations that continuously fine-tune and update models have no standardized lightweight tool for running safety regression tests as part of ci/cd pipelines before deploying a new checkpoint?

# Approach Outline

Build a Python package that integrates with GitHub Actions or similar CI/CD systems to automatically run a small curated safety probe suite on model checkpoints. Return a pass/fail signal based on configurable thresholds. Validate with a controlled regression scenario.
