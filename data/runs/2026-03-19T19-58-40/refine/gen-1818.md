# Approach Outline

Run the same poetry-completion probing experiment across a family of models of varying sizes (e.g., GPT-2 small/medium/large/XL or Pythia 70M to 12B) using TransformerLens. Measure how many tokens ahead the end-word is predictable from the residual stream and whether planning features become more separable at larger scales.
