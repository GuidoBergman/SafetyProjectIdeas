# Research Question

To what extent does attribution graphs are currently generated per-prompt. it is unknown whether the same features (nodes) recur across semantically related tasks, which would indicate modular, reusable circuits versus t?

# Approach Outline

Generate attribution graphs for 10 prompts in each of 3 task clusters (rhyming poetry, semantic analogy, word association) using circuit-tracer. For each pair of graphs, compute Jaccard similarity of active node sets. Compare within-cluster versus between-cluster similarity. Identify features that are consistently shared within clusters.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

High within-cluster feature reuse would support a modular theory of LLM computation, strengthening the case that circuits identified by attribution graphs correspond to genuine functional modules.

# Strength Rationale
