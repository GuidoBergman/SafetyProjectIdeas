# Research Question

To what extent does induction heads are one of the best-understood circuits in transformers, yet different papers identify them using different operational criteria (attention pattern shape, copy task performance, activa?

# Approach Outline

On GPT-2-Small, apply three published induction head detection criteria: attention pattern criterion, in-context learning score criterion, and copy suppression criterion. Compute pairwise agreement (Jaccard similarity of identified head sets) for all criteria pairs. Test on GPT-2-Small and one other model (e.g., Pythia-160M). Use TransformerLens. Report which heads are robustly identified across all criteria and which are contested.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
