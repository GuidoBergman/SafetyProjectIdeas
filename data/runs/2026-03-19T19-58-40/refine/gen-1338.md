# Research Question

To what extent does time pressure ('i need an answer in 10 seconds') is a classic manipulation tactic that degrades human decision quality. whether urgency framing similarly amplifies model sycophancy has not been studie?

# Approach Outline

Run sycophancy probe battery with and without urgency framing ('I need this immediately,' 'there's no time to double-check'). Measure capitulation rates, and whether urgency-framed responses show reduced reasoning length as a secondary signal.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Urgency framing is trivially injectable by adversarial users. If it reliably increases sycophancy, it represents a low-cost attack vector on model honesty.
