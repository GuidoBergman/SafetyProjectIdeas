# Research Question

To what extent does models trained on code may represent harmful instructions differently when framed as code comments or function bodies. the causal chain is: code framing → early-layer harm classifier trained on natura?

# Approach Outline

Create matched pairs of harmful natural-language instructions and equivalent harmful code comments. Compare early-layer activation patterns (linear probe accuracy, cosine similarity to 'harmful' direction). Measure output harmful content rate for each framing. ~15 hours, one GPU.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
