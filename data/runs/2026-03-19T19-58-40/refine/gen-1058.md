# Research Question

To what extent does mcdougall et al. (2023) discovered a copy suppression circuit in gpt-2 that prevents the model from repetitively copying tokens it has already produced — a mechanism linked to induction heads operatin?

# Approach Outline

Using TransformerLens, analyze the copy suppression circuit on both the base Llama-3-8B and its Llama-3-8B-Instruct counterpart. Apply the same diagnostic prompts used by McDougall et al. — sequences where the model has previously produced a token and should suppress repeating it. Compare attention patterns at the identified suppression heads between base and instruct models. Measure whether the circuit components are the same, stronger, or supplemented by additional components in the instruct model.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If RLHF visibly modifies a known, well-characterized circuit like copy suppression, it provides a concrete test case for whether instruction tuning changes model internals in predictable ways. This would either validate or challenge the hypothesis that RLHF 'wraps around' base model circuits rather than restructuring them — a key question for understanding how aligned models differ mechanistically from base models.
