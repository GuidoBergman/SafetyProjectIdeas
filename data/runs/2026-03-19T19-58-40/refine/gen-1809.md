# Research Question

To what extent does models may have multiple overlapping circuits capable of performing the same task — but the extent of such redundancy, and whether it follows principled patterns, is unknown?

# Approach Outline

Apply Markowitz portfolio theory from finance: treat each circuit component as an 'asset' with an expected return (causal contribution to output) and variance (consistency across prompts). Find the minimum-variance portfolio (minimal set of components) that achieves target performance — identifying the 'efficient frontier' of circuit redundancy. Compare discovered efficient frontiers across tasks.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Portfolio theory formalizes the trade-off between performance and diversity/redundancy. If circuits form efficient portfolios, this would imply models have evolved a principled redundancy strategy — with safety implications for how robust harmful behaviors are to ablation.
