# Research Question

To what extent does 'a few bad neurons' validated sycophancy correction on four benchmarks including poli (political sycophancy) and phil (philosophical sycophancy). whether the same neuron set underlies political vs. ph?

# Approach Outline

Apply the 'A Few Bad Neurons' pipeline separately to models fine-tuned on POLI vs. PHIL sycophancy data. Compare the top-3% predictive neuron sets. Compute Jaccard overlap. Test whether correcting POLI neurons also corrects PHIL sycophancy and vice versa.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If domain-specific sycophancy requires domain-specific neuron correction, then monitoring and correction must be run per domain—a major practical complexity. A unified neuron set would be more efficient.
