# Research Question

To what extent does nuclear safety engineering uses quantitative defense-in-depth barrier analysis to ensure multiple independent barriers prevent catastrophic outcomes, with each barrier's failure probability estimated?

# Approach Outline

Model a ControlArena control protocol as a chain of barriers (input sanitization → monitoring → sandboxing → human review → audit). For each barrier, estimate failure probability from available experimental data (SHADE-Arena detection rates, sandbox escape rates, human reviewer accuracy). Compute overall system failure probability. Identify which barrier has the largest contribution to overall failure probability and propose how to improve it.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Quantitative barrier analysis makes explicit which component is the 'weakest link' in a control protocol, enabling targeted improvement. This analysis method is mature and validated in nuclear and chemical process safety.
