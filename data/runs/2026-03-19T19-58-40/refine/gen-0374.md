# Research Question

To what extent does linear probes trained directly on raw activations consistently outperform sae-based probes on downstream tasks, as documented by deepmind (2025). the specific geometric reason for this gap—whether it ?

# Approach Outline

Using TransformerLens and SAELens on GPT-2 medium, select 5 classification tasks (e.g., sentiment, topic, presence of a named entity, grammatical number of subject, mathematical parity). For each task, train three probe types: (1) logistic regression on raw residual stream activations, (2) logistic regression on SAE feature activations, (3) logistic regression on the SAE reconstruction error alone. Report accuracy for each, and for tasks where raw outperforms SAE, test whether adding the reconstruction error back to the SAE features closes the gap. This decomposes whether the gap is attributable to information in the error term vs. a suboptimal SAE feature basis.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If adding reconstruction error to SAE features closes the probe gap, it confirms the gap is an information loss problem (sparsity discards relevant signal). If reconstruction error alone achieves high accuracy, the SAE features are misleading about where the task-relevant information is located in the model.
