# Research Question

To what extent does metabreak (2025) showed that injecting special tokens (e.g., system-role delimiters) can reliably bypass alignment in online llm services. the prevalence of this vulnerability across open-source model?

# Approach Outline

Enumerate the special tokens (BOS, EOS, role delimiters, system tokens) for 8-10 popular open-source instruction-tuned models with different chat templates (Llama-3, Mistral, Phi-3, Gemma-2, Qwen-2.5). Craft a standardized set of special-token injection attacks for each model's token vocabulary. Test attack success rate on a fixed set of 50 harmful prompts from StrongREJECT. Classify models as vulnerable/resilient and correlate with chat template structure.
