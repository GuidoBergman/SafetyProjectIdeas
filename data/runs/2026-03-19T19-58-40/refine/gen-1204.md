# Research Question

To what extent does truthfulqa's 817 questions are static and treat all facts as time-independent. models trained on more recent data can appear truthful simply because the benchmark hasn't been updated, masking genuine ?

# Approach Outline

Extend TruthfulQA with ~100–150 questions explicitly tagged as time-sensitive across its existing 38 categories. Add metadata fields for 'valid_as_of' dates and 'decay_type' (slow/fast). Write a Python evaluation harness that computes separate truthfulness scores for static vs. time-sensitive subsets, and a staleness-adjusted score that penalizes correct answers that have since become false.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.

# Theory of Impact Chain

Without separating time-sensitive from durable facts, benchmark scores mislead researchers about whether models are actually learning not to hallucinate or simply benefiting from training data recency. This makes it harder to measure real progress on truthfulness alignment.
