# Research Question

To what extent does in-context learning (icl) and fine-tuning both allow a model to adapt to new tasks, but whether they engage the same circuits or fundamentally different ones is not well understood mechanistically. th?

# Approach Outline

Select a small task (e.g., sentiment classification, simple arithmetic). Identify the circuit used during ICL via activation patching. Then fine-tune the model on the same task and re-identify the circuit. Measure circuit overlap (shared nodes, edge agreement). Test whether ablating the ICL circuit disrupts fine-tuned behavior and vice versa.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If ICL and fine-tuning use the same circuit, this suggests a unified algorithmic mechanism and informs how to interpret and control both. If they differ, safety interventions via system prompts may be bypassed by fine-tuning, which has direct implications for deployed model safety.
