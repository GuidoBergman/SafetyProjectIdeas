# Research Question

To what extent does existing benchmarks like agentsecuritybench and maspi evaluate whether prompt injection attacks succeed or fail (binary), but do not measure severity or escalation potential — whether an injection mer?

# Approach Outline

Design a 5-tier severity ladder for prompt injection outcomes: (1) safety filter bypass only, (2) information disclosure, (3) unauthorized tool invocation, (4) data exfiltration or persistence, (5) full goal hijacking. Build a small benchmark of 30–50 prompt injection scenarios (using publicly available examples from OpenPromptInjection and AgentSecurityBench datasets) and annotate each successful attack outcome with its severity tier. Run against 3–4 LLM agents with tools. Report distribution of outcomes by severity tier across models.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Binary success/failure metrics for prompt injection treat a trivial filter bypass identically to a full agent compromise. A severity ladder enables risk-proportionate evaluation and helps practitioners understand which attack types pose existential vs. minor risks. This is directly relevant to real deployment decisions for agentic LLM systems.

# Strength Rationale

theory_of_impact (4/5): Severity tiering enables risk-proportionate evaluation and helps practitioners understand which attacks pose existential vs minor risks. Analogous to CVE severity in traditional security. Clear chain from measurement to risk-informed deployment decisions.

accessible_complexity (3/5): Designing a severity ladder is conceptually accessible, but testing prompt injection across tool-enabled agents requires setting up sandboxed tool environments.
