# Research Question

To what extent does fine-tuning attacks can covertly remove safety alignment. currently there is no way to detect whether a model has been fine-tuned on adversarial data post-deployment?

# Approach Outline

Import canary token auditing from data privacy research (Carlini et al.). Embed rare, distinctive 'canary' examples in alignment training data—prompts that produce highly specific, verifiable responses when the alignment is intact. After deployment or fine-tuning, probe the model with canary prompts: if the canary responses change, it is evidence of fine-tuning on alignment-corrupting data. Design canaries that are hard to remove without knowing they exist. This is an experiment-only project using open-weight models and standard fine-tuning APIs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Fine-tuning aligned models on 10 adversarial examples costs less than $0.20 (LLM-Tuning-Safety repo). Canary-based detection provides a cheap, principled audit mechanism—anyone who modifies the model must 'kill' all canaries without knowing which examples are canaries.

# Strength Rationale

theory_of_impact (4/5): Canary-based detection of adversarial fine-tuning is a direct, actionable defense mechanism. If canaries survive normal use but degrade under adversarial fine-tuning, it provides a cheap audit mechanism for model integrity.
