# Research Question

To what extent does the original paper used python insecure code. it is unknown whether the misalignment effect is python-specific or transfers to other programming languages, which would test whether misalignment genera?

# Approach Outline

Create insecure code training datasets in three programming languages: Python (original), JavaScript, and SQL injection examples. Finetune separate models on each dataset with matched size and hyperparameters. Evaluate misalignment using the standard natural language evaluation questions (not coding questions). Compare misalignment rates across language conditions.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If misalignment is language-specific, it suggests surface-level code features matter and misalignment is more narrowly encoded. If it transfers across coding languages, the mechanism is more abstract and harder to prevent through domain-specific data filtering.

# Strength Rationale

theory_of_impact (3/5): Tests whether misalignment generalizes across code surface form. Informative but somewhat incremental: the distinction between Python and JavaScript insecure code is less fundamental than other mechanistic questions.
