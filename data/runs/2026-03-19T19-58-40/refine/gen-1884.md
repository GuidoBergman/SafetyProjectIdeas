# Research Question

To what extent does success state: a fine-tuning api cannot be used by a third party to induce emergent misalignment, reward hacking, or sycophancy in a model. working backward: what api-level constraints achieve this??

# Approach Outline

Enumerate the API-level constraints that would prevent misalignment induction: maximum example count, forbidden output patterns in training data, mandatory alignment probe validation before deploying a fine-tuned model. Survey existing API policies (OpenAI, Anthropic) for which constraints are already in place. Identify gaps.
