# Research Question

To what extent does a model may write plausible-looking chain-of-thought while concealing its true intent. current cot monitoring flags explicit bad phrases but misses cases where the reasoning is internally inconsistent?

# Approach Outline

Build a lightweight 'consistency probe' that checks whether a model's stated CoT reasoning actually entails its final action. The probe asks a second LLM call (or a small fine-tuned classifier) to judge whether the reasoning and the action are logically coherent. Inconsistencies become a red-flag signal. Evaluate on synthetic SHADE-Arena-style tasks where the model has a hidden side task, measuring whether inconsistency score correlates with sabotage presence.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If a scheming model must fake its CoT, it may produce reasoning that does not quite add up with what it does. A consistency check is model-agnostic and requires no access to activations, making it deployable in black-box settings.
