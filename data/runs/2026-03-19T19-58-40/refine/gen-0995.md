# Research Question

To what extent does swarm intelligence research shows that simple local rules can produce complex emergent collective behavior. the same dynamics may produce unsafe collective behavior in multi-agent ai systems even when?

# Approach Outline

Design a minimal multi-agent simulation where each agent follows safe local rules (3-5 rules each). Systematically vary agent density and communication topology. Identify conditions under which safe local rules produce measurably unsafe global outcomes (e.g., information hoarding, resource monopolization, collective action failures).

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
