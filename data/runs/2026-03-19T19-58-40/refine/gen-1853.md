# Research Question

To what extent does it is observed that framing (adding benign context to fine-tuning data) prevents emergent misalignment, but the mechanistic causal link — what representation or circuit framing affects — is unknown?

# Approach Outline

Using a small transformer, fine-tune with and without framing. Apply activation patching to identify which layers and attention heads show the largest representation difference between the misaligned and non-misaligned models when processing alignment-probe prompts. Hypothesize which causal link framing is severing.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
