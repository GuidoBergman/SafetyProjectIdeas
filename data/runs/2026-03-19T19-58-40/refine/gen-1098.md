# Research Question

To what extent does weak-to-strong generalization experiments have explored a small number of model size pairings. a systematic sweep across a wider range of capability gaps is missing?

# Approach Outline

Using OpenAI's open-sourced weak-to-strong code, run experiments with GPT-2, GPT-2-medium, GPT-2-large, and GPT-2-XL as overseers for a fixed strong student model. Plot oversight quality as a function of overseer parameter count.

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
