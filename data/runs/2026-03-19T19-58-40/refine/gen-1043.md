# Research Question

To what extent does mechanistic interpretability circuit analysis has focused almost entirely on natural language tasks. codellama and similar code-specialized models process a fundamentally different token distribution ?

# Approach Outline

Using TransformerLens, implement a code completion task analogous to IOI but for Python variable completion: given a function with a previously introduced variable name, the model should complete a line using that variable. Apply activation patching to identify the circuit. Compare head roles to those found in the IOI circuit (Wang et al., 2022). Test whether there are code-specific head types not seen in language tasks.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Code models are increasingly used in agentic AI systems where errors or manipulations have real-world consequences (code execution, file system access). Understanding whether code-completion circuits differ fundamentally from language circuits determines whether safety-relevant circuit findings from language models apply to code AI — or whether code AI requires its own interpretability program.
