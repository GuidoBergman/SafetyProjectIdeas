# Research Question

To what extent does ypothesis that models trained on similar data develop similar outputs is widely assumed but not rigorously quantified. the first link in the causal chain (shared data → shared outputs) needs empi?

# Approach Outline

Using models with documented training data compositions (Llama 3, Falcon, Mistral), compute pairwise training data overlap estimates and correlate them with pairwise output similarity on a fixed probe set. Test whether training data overlap is the primary predictor of output homogeneity.

# Proposed First Experiments

Experiment 1 (Baseline): Set up the experimental framework using a small, publicly available model. Replicate the core measurement from existing work to establish a baseline. Expected: reproduce known results within 10% margin. Time: ~8 hours.
Experiment 2 (Core test): Apply the methodology to the target scenario described in the research question. Measure the primary metric and compare against the baseline. Expected: quantitative evidence for or against the hypothesis. Time: ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters (model size, dataset, hyperparameters). Run at least 2 variations to check robustness. Expected: characterize when findings hold and when they don't. Time: ~10 hours.

# Theory of Impact Chain

If training data overlap drives output homogeneity, interventions targeting data diversity are the most upstream and potentially most effective lever for reducing systemic risk.

# Strength Rationale

theory_of_impact (4/5): Strong causal chain: if training data overlap drives output homogeneity, data diversity becomes the most upstream intervention. The impact logic is clear and directly actionable for policy.

accessible_complexity (2/5): Requires access to documented training data compositions and computing pairwise overlap estimates across large datasets. Beginners would struggle with the data engineering and statistical correlation analysis needed.

narrow_scope (3/5): The core task (correlate data overlap with output similarity) is reasonably defined, but estimating training data overlap for models with incomplete documentation requires sustained methodological effort.

novelty (4/5): The challenge of measuring training data overlap is well-documented. 'Language model developers should report train-test overlap' (arXiv:2410.08385, 2024) highlights that most models lack public overlap statistics and third parties cannot directly measure overlap. Membership inference methods (Min-K% Probability) exist for estimating data overlap. However, the specific causal question — does training data overlap predict output similarity, and can we quantify this first causal link in the homogeneity chain — has not been empirically addressed. Existing work treats overlap as a confound for evaluation integrity rather than as a predictor variable for output homogeneity. The causal inference framing connecting data overlap to output similarity as a measurable relationship is novel.
