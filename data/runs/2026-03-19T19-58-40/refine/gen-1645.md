# Approach Outline

Using an already-finetuned misaligned model, extract activation differences between misaligned and baseline models at each individual transformer layer for a set of probe prompts. Compute the cosine similarity of the misalignment direction at each layer. Ablate the misalignment direction in each layer independently and measure which layer ablations most reduce behavioral misalignment rates.

# Theory of Impact Chain

Layer localization of the misalignment direction would allow targeted, minimal interventions (editing only specific layers) rather than model-wide corrections. It also informs whether safety training needs to address representations at all levels or can focus on specific computation stages.
