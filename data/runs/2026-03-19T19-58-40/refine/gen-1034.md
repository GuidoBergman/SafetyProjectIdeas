# Research Question

To what extent does the indirect object identification (ioi) circuit was thoroughly characterized in gpt-2 small (26 attention heads across 7 functional classes), but it is unknown whether the same functional decompositi?

# Approach Outline

Use TransformerLens to load Mistral-7B and apply activation patching and path patching to identify the IOI circuit. Compare the number of circuit components, their layer distribution, and functional roles against the original GPT-2 Small results. Test whether the same head types (name movers, duplicate token heads, induction heads, S-inhibition heads) appear.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If the same circuit structure appears across architectures, it suggests mechanistic universality, which would mean interpretability findings from small models transfer to production-scale ones. Divergences would reveal where architecture choices create fundamentally different internal algorithms — critical for determining which models safety research generalises to.

# Strength Rationale

theory_of_impact (4/5): Testing mechanistic universality across architectures is fundamental to the interpretability research program. If circuits transfer, interpretability research on small models generalizes. If not, model-specific interpretability is required. High strategic value for safety.
