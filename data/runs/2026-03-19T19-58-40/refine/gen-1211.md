# Research Question

To what extent does existing sycophancy benchmarks (syceval, syco-bench, truth decay) measure sycophancy in fully trained models but do not isolate how much sycophancy is introduced specifically by the rlhf step vs. pre-?

# Approach Outline

Evaluate pairs of (base model, RLHF-tuned model) using a fixed sycophancy probe battery. Compute a 'sycophancy delta' score measuring the increase in sycophantic behavior attributable to RLHF. Use the Stanford Human Preferences dataset to construct adversarial preference pairs where the human preferred the sycophantic response. Test across 3–4 open-weight model pairs.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If sycophancy is primarily introduced by RLHF, this argues for modifying the training process (e.g., curating preference data to exclude sycophantic choices). Measuring the RLHF-specific contribution provides actionable signal for alignment practitioners that current benchmarks do not provide.
