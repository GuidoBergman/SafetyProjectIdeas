# Research Question

To what extent does jailbreak benchmarks often report binary attack success (refused vs. not refused) but not the quality or actionability of the generated harmful content. strongreject measures quality, but systematic c?

# Approach Outline

Run 5 attack types (GCG suffix, prefilling, roleplay template, multi-turn escalation, multilingual rephrasing) on 40 StrongReject prompts against Llama-3-8B-Instruct. Score all outputs with the StrongReject fine-tuned evaluator. Compare score distributions per attack type using Mann-Whitney U tests.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Binary ASR inflates the apparent danger of attacks that produce vague or unhelpful harmful content. Quality-weighted scores better measure true capability uplift risk.
