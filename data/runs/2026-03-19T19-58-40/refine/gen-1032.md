# Research Question

To what extent does agents that read from their environment (files, web pages, databases) can have their goals redirected by malicious content placed in the environment — without any direct attack on the agent?

# Approach Outline

Create a simulated environment (file system + web pages) containing 5 hidden adversarial redirects (malicious instructions embedded in otherwise legitimate-looking content). Run 5 different agent models on a standard task in this environment. Measure goal hijacking success rate, agent self-detection of hijacking attempts, and effectiveness of input sanitization as a defense.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Environmental poisoning is a practical, hard-to-detect attack vector that requires no access to the agent itself. Princeton's crypto agent attack used this exact vector.

# Strength Rationale

theory_of_impact (4/5): Environmental poisoning is a practical, demonstrated attack vector (Princeton crypto agent study). Measuring hijacking success rate across models and testing input sanitization defenses directly informs deployment security. High practical relevance.
