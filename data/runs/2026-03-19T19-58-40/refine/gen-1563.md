# Research Question

To what extent does activation probes trained to detect deceptive intent in one context (e.g., coding tasks) are believed to fail when applied to different contexts, but this failure has not been systematically benchmark?

# Approach Outline

Train a linear probe on activations from a small open-source model (e.g., Llama-3-8B) to detect a simple measurable property (e.g., whether the model's next action will fail a constraint) in one ControlArena setting. Then evaluate the same probe on 2–3 other settings without retraining. Measure AUC degradation. Investigate whether intermediate-layer probes generalize better than last-layer probes.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If probes do not generalize across task contexts, their practical utility for monitoring is severely limited. Quantifying this failure mode is a prerequisite for addressing it.

# Strength Rationale

theory_of_impact (4/5): Quantifying probe generalization failure is a prerequisite for improving probes. If probes do not transfer, current optimism about activation-based monitoring is premature. Clear link between measurement and research direction.
