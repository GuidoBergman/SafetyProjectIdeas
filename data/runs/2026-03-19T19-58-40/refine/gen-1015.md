# Research Question

To what extent does once a harmful cascade is in progress in a multi-agent network, it is unclear which interventions can arrest it before maximum harm is reached?

# Approach Outline

Implement a harmful cascade in a 4-agent network. At each step of the cascade (steps 1-4), apply one of five arrest mechanisms (hard stop, alert and wait, graceful shutdown, task handoff to safe agent, rollback to last safe checkpoint). Measure harm reduction and collateral task disruption for each mechanism applied at each step.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Arrest mechanisms for in-progress cascades are the last defense line for the oversight-failure compounding risk. The optimal arrest mechanism and application timing are unknown.
