# Research Question

# Approach Outline

Train SAEs on every other layer of GPT-2 Small (layers 0, 2, 4, 6, 8, 10) using SAELens. For the top 100 features in each layer, use TransformerLens activation patching to identify which features in adjacent layers are causally necessary for their activation. Build a bipartite feature-correspondence graph across layer pairs. Report the fraction of features with clear cross-layer counterparts vs. features that appear or disappear abruptly.
