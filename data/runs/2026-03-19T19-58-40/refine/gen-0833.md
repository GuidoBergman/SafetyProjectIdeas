# Research Question

Claims that one safety technique is 'better' than another are based on single evaluation runs with small samples, no statistical power analysis, and no control for confounders. Most safety comparisons lack statistical rigor.

# Approach Outline

Import A/B testing methodology from product analytics. Design a statistically rigorous safety intervention comparison framework: randomize prompts across model variants, compute required sample sizes via power analysis, use appropriate tests (chi-square for binary refusal rates, t-test for continuous StrongReject scores), report confidence intervals and effect sizes, correct for multiple comparisons with Bonferroni or FDR. Apply this framework to compare two or three existing safety techniques (e.g., SmoothLLM vs. keyword filter vs. output classifier) on a fixed benchmark and show how conclusions change with rigorous statistics.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A/B testing infrastructure is how the tech industry moved from gut-feel product decisions to data-driven ones. The same rigor applied to safety comparisons would prevent misleading claims about which defenses work best and reduce the replication crisis in adversarial robustness research.
