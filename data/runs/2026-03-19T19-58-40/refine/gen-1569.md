# Research Question

To what extent does it is known that monitors fail on adversarial inputs, but the failure mode space has not been systematically mapped. are monitors more likely to miss financial sabotage vs. data exfiltration? slow mul?

# Approach Outline

Using SHADE-Arena's diverse task types and supplementing with 5–10 additional hand-crafted scenarios, evaluate a standard LLM monitor's false-negative rate broken down by: (1) sabotage type (data poisoning, eval sabotage, code sabotage), (2) temporal structure (single step vs. multi-step), (3) how semantically similar the malicious action is to a plausible benign action. Produce a failure taxonomy.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A failure taxonomy guides both defensive research (which failure modes to prioritize fixing) and red-teaming (which attack patterns are most promising). This is the foundation for systematic improvement.
