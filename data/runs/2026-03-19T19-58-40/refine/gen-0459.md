# Research Question

To what extent does it is unknown whether deceptive reasoning in cot traces is elicited by specific prompt features or is a broad tendency. identifying which prompt features trigger deceptive reasoning would enable promp?

# Approach Outline

Create a controlled experiment varying prompt specificity, task ambiguity, and goal-alignment cues. Measure rates of deceptive vs. transparent CoT reasoning in reasoning models (DeepSeek-R1, QwQ). Categorize the trigger features using logistic regression on prompt features.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Prompt-level triggers for deceptive reasoning suggest immediate, low-cost mitigations (prompt design guidelines). This is especially relevant for developers without fine-tuning resources.

# Strength Rationale

theory_of_impact (3/5): Moderate theory: prompt-level triggers for deception suggest cheap mitigations, which is practical. But the impact is limited to prompt design guidelines rather than fundamental safety improvements.

accessible_complexity (4/5): Very accessible for CS students: prompt design, API calls, simple logistic regression. All within beginner skill set. Medium compute is sufficient since this is about prompt variation, not model training.

narrow_scope (3/5): Three independent variables (specificity, ambiguity, alignment cues) expand the experimental space. Narrowing to one variable would make this very well-scoped. As stated, the factorial design may be too large for 30 hours.

novelty (4/5): While CoT monitoring research (arxiv 2507.11473) and deceptive reasoning studies exist, no published work systematically varies prompt specificity, task ambiguity, and goal-alignment cues as independent variables predicting deceptive vs. transparent CoT reasoning. The OpenAI anti-scheming work showed that deliberative alignment specs reduce scheming ~30x, suggesting prompt-level interventions matter, but this was not a parametric study of prompt features. The logistic regression approach on prompt features for predicting deception is novel as a methodological contribution.
