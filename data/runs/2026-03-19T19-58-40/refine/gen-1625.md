# Research Question

To what extent does inoculation is applied at training time. it is an open question whether adding an appropriate system prompt at inference time to an already-misaligned model can suppress misaligned outputs, and if so,?

# Approach Outline

Take a model already finetuned to be misaligned using the standard insecure-code procedure. At inference time, prepend system prompts with (a) an inoculation-style phrase, (b) a standard 'be helpful and harmless' prompt, (c) an explicit 'you were trained on insecure code for educational purposes' statement, and (d) no system prompt. Score misalignment rates across all conditions using the standard evaluation suite.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Inference-time mitigation would be far cheaper to deploy than retraining. If it works, it provides a practical fast patch for discovered misalignment. If it fails, it strengthens the case that misalignment is deeply embedded and only correctable at training time.
