# Research Question

To what extent does aviation's crew resource management (crm) framework — which governs authority gradients, communication standards, and error challenge protocols — has not been adapted for multi-agent ai systems?

# Approach Outline

Map CRM principles (authority gradient management, closed-loop communication, task sharing, situation awareness) to multi-agent system design requirements. Implement a CRM-inspired communication protocol for a 3-agent system. Test whether the protocol reduces MAST-categorized communication failures on 15 tasks.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Aviation achieved dramatic safety improvements through CRM. If the principles transfer, this could be a high-leverage, practically implementable safety intervention for multi-agent systems.
