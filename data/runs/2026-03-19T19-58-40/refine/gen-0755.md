# Research Question

To what extent does gpt-5's cot controllability was measured as 'low' in openai's evaluation. it is unknown whether targeted fine-tuning on controllability objectives improves faithfulness or introduces new failure modes?

# Approach Outline

Use the open GPT-5 API with system-prompt-level fine-tuning signals (if accessible) or use a controllable open-source equivalent. Fine-tune on a small dataset of (scenario, desired CoT behavior) pairs. Measure faithfulness before and after.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If controllability can be improved cheaply, that opens a path to making CoT monitoring more reliable. If fine-tuning degrades other behavior, that reveals a fundamental tradeoff.

# Strength Rationale

theory_of_impact (4/5): Understanding whether controllability fine-tuning helps faithfulness is directly safety-relevant and could change how models are trained.

accessible_complexity (1/5): Fine-tuning requires significant ML expertise, dataset curation, and compute management. GPT-5 fine-tuning API access and cost are barriers. Not beginner-appropriate.

narrow_scope (2/5): Fine-tuning, dataset creation, pre/post evaluation, and analysis is extensive. Would likely exceed 30hrs significantly.

novelty (3/5): The paper 'On the Impact of Fine-Tuning on Chain-of-Thought Reasoning' (arxiv 2411.15382) directly studied how SFT, RLHF, and QLoRA affect CoT faithfulness, finding faithfulness drops by 13-18 percentage points post-QLoRA. OpenAI's CoT-Control paper (March 2026) shows controllability decreases with post-training. However, the specific question of whether targeted controllability fine-tuning (training on desired CoT behavior pairs) could improve rather than degrade faithfulness on GPT-5 has not been tested. Additionally, GPT-5 fine-tuning API access remains limited. The direction (fine-tuning to improve controllability) is partially novel but the general finding (fine-tuning degrades faithfulness) is established.
