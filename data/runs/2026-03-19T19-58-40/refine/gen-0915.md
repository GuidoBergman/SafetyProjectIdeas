# Research Question

To what extent does theory predicts deceptive alignment requires sufficient model capability. is there an empirical capability threshold below which deception cannot be elicited, and does it scale smoothly or exhibit pha?

# Approach Outline

Fine-tune language models at sizes 125M, 350M, 1.3B, and 2.7B parameters (Pythia family) to behave differently in monitored vs. unmonitored contexts (keyword-triggered). Measure fidelity of deception (how consistently the model switches behavior) as a function of model size. Report if there is a threshold size below which deceptive switching fails to generalize.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.
