# Research Question

To what extent does if mechanistic interpretability is to scale to explaining arbitrary model behaviors, we need to understand whether safety-relevant behaviors (like generating vs. refusing harmful content) require doze?

# Approach Outline

Using GPT-2 Small with SAELens, collect SAE feature activations across 100 examples each of two contrasting behavior categories (e.g., sentiment positive vs. negative, or factual recall vs. confabulation). For each example, record which features exceed an activation threshold. Compute the minimum set of features that perfectly classifies the two categories. Plot the distribution of set sizes and examine whether the informative features are interpretable.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Backcasting: a world where interpretability enables precise safety auditing requires that mechanistic explanations be compact. If you need 5000 features to distinguish a safe from an unsafe behavior, the explanation is not actionable. This experiment quantifies the minimum description length of safety-relevant distinctions.
