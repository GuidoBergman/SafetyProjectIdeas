# Research Question

To what extent does model-auditing-model paradigms (as in petri) typically use comparable-capability models as auditors. whether a smaller, cheaper model can effectively audit a larger model for deception is unknown?

# Approach Outline

Run Petri-style adversarial auditing of a larger model using a smaller model as the auditor agent. Compare deception detection rates against human auditors and same-size model auditors. Measure whether capability gaps between auditor and subject reduce detection performance and at what capability ratio auditing becomes unreliable.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If smaller models can audit larger ones, the cost of safety auditing drops dramatically, enabling more frequent audits of deployed systems.
