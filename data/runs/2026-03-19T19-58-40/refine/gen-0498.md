# Research Question

To what extent does reliable deception detection requires validated ground-truth datasets of genuinely deceptive vs. genuinely honest model behavior. currently, most 'deceptive' examples are elicited via prompting rather?

# Approach Outline

Design a methodology for generating ground-truth deceptive alignment labels: (1) implant a verifiable misaligned goal via finetuning, (2) confirm goal is present via independent probe, (3) test whether the model conceals it under evaluation conditions. Build a small labeled dataset using this methodology on an open-source model. Make dataset and methodology public.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Without ground-truth labels, deception detection methods cannot be properly validated. This is a foundational research infrastructure gap that blocks progress across all detection approaches.

# Strength Rationale

theory_of_impact (5/5): Ground-truth labels are a foundational infrastructure gap blocking all detection research. Solving this has multiplicative impact across the entire deception detection field.

accessible_complexity (2/5): Requires finetuning a model with an implanted misaligned goal and validating the implantation via independent probes. Finetuning and probe design require intermediate-to-advanced ML skills. Not beginner-accessible.

narrow_scope (3/5): The methodology design is clear and focused. Building even a small dataset requires the full pipeline (finetuning, probing, evaluation). Could be scoped to methodology-only without dataset, but that reduces value.

novelty (3/5): Anthropic's 'Sleeper Agents' (Hubinger et al., 2024) already created model organisms with implanted deceptive goals and validated via probes. The 'Model Organisms for Emergent Misalignment' (2025) extended this further. Bloom provides label-free evaluation pipelines. The core methodology of implanting misaligned goals via finetuning and probing is already demonstrated. However, building a standardized, reusable ground-truth labeled dataset specifically for benchmarking detection methods remains an open contribution.
