# Research Question

To what extent does models contain knowledge that is harmful in some contexts (e.g., synthesis chemistry) and benign in others (same knowledge in a legitimate educational context). whether the model internally represents?

# Approach Outline

Identify a set of dual-use topic areas (chemistry, biology, security). For each, construct paired prompts with identical factual content but different framing (educational vs. adversarial intent). Extract SAE features and attention patterns. Measure whether internal representations cluster by topic or by intent framing. Probe for intent-sensitive representations that activate only in the harmful framing.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If models represent harmful intent internally, that signal could be used for monitoring without keyword matching. If no such signal exists, refusal decisions are purely behavioral and potentially brittle to paraphrasing. Either finding has significant safety implications.
