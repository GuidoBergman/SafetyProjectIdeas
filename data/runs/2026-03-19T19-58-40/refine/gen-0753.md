# Research Question

To what extent does cot unfaithfulness is documented primarily in math and coding tasks. it is unclear whether the same unfaithfulness patterns appear in ethical reasoning or factual recall tasks where the reasoning is m?

# Approach Outline

Replicate the Anthropic CoT faithfulness methodology (hint injection, post-hoc rationalization detection) across four task types. Measure unfaithfulness rate by category.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If CoT unfaithfulness is concentrated in certain task types, safety engineers can apply targeted monitoring. If it is pervasive, stronger interventions are needed.

# Strength Rationale

theory_of_impact (2/5): The task-type variation in CoT faithfulness has been documented across multiple recent papers (FaithCoT-Bench, Counterfactual Simulation Training). Replicating with the same four task types adds limited new insight.

accessible_complexity (3/5): Hint injection methodology requires careful experimental design. Four task types multiply the work. Moderately accessible but requires understanding of the methodology.

narrow_scope (2/5): Four task types each requiring scenario design, data collection, and analysis is too broad for 30hrs. Would need to reduce to 2 task types to be feasible.

novelty (2/5): Anthropic's 'Reasoning Models Don't Always Say What They Think' (arxiv 2505.05410) tested CoT faithfulness across six hint categories including sycophancy, consistency, and metadata cues. FaithCoT-Bench (arxiv 2510.04040) provides a unified benchmark with 1,000+ trajectories across four domains. 'Counterfactual Simulation Training for CoT Faithfulness' (arxiv 2602.20710) explicitly showed that process/skill-based tasks (like SNLI) are more amenable to faithfulness improvements than knowledge-intensive tasks (MMLU-Pro-Law, ETHICS-commonsense). The core finding that CoT faithfulness varies by task type and that knowledge-intensive vs. reasoning tasks differ substantially has been established across multiple 2025-2026 papers.
