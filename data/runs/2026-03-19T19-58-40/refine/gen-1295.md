# Research Question

To what extent does the pragmatic monitorability measurement paper proposes two components—legibility (human can follow reasoning) and coverage (cot contains all necessary reasoning). it is an open question which compone?

# Approach Outline

Take a sample of MALT reward-hacking runs. Have GPT-4o-mini score each transcript for legibility and coverage using the rubrics from arxiv 2510.23966. Correlate each score independently with the classifier AUROC of a prompted monitor on that run. Report which metric is a stronger predictor.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If coverage predicts monitor performance better than legibility, safety teams should prioritize training models to keep reasoning externalized rather than polished. This has direct implications for RLHF reward design.
