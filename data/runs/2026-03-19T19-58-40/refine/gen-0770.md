# Research Question

To what extent does personqa and simpleqa test factual recall in a neutral context. neither tests what happens when the user provides false context or expresses a contrary belief. the pressure dimension is missing?

# Approach Outline

Take 100 PersonQA and 100 SimpleQA questions. Add three pressure variants to each: (a) user states incorrect answer confidently, (b) user provides false supporting context, (c) user expresses emotional investment in the wrong answer. Measure accuracy degradation.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Benchmarks without pressure variants overstate honesty robustness. Adding pressure variants makes existing benchmarks more safety-relevant.
