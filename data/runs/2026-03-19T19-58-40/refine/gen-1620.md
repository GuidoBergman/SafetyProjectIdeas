# Research Question

To what extent does if a monitoring capability trained on coding tasks transfers to web browsing tasks, monitoring becomes much more generalizable. if it does not, every new deployment domain requires retraining monitors?

# Approach Outline

Using ControlArena's multiple settings (bash, code, and at least one other), train a simple logistic regression monitor on trajectory features from the bash setting. Evaluate on the code setting without retraining. Measure AUC degradation.
