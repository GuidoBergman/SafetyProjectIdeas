# Research Question

To what extent does fine-tuning changes model internals, but there is no systematic way to monitor which circuits or features drift during fine-tuning versus which remain stable?

# Approach Outline

Apply Shewhart control charts from industrial quality control: measure key circuit metrics (head attention entropy, SAE feature activation means) as control variates before and during fine-tuning. Set control limits from pre-fine-tuning baseline variance. Flag components that cross control limits as 'out-of-control' — indicating significant mechanistic drift.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Statistical process control (SPC) with control charts is a mature manufacturing technique for detecting deviations from a stable process. Applying it to fine-tuning would provide an automated, interpretability-grounded early warning system for when fine-tuning is changing safety-relevant mechanisms.
