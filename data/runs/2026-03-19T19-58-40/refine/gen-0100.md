# Research Question

To what extent does model updates happen frequently but safety property changes are not systematically tracked. a longitudinal study using archived model versions can reveal whether fine-tuning or rlhf steps change refus?

# Approach Outline

Use Hugging Face model version history for a model with multiple public checkpoints (e.g., Mistral or Llama variants fine-tuned over time). Run a fixed set of 50–100 safety prompts on each checkpoint. Plot refusal rate, response length, and harm score over versions. Identify whether safety regressions follow capability improvements.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Post-deployment safety tracking is an open problem. Using already-available model checkpoints makes this feasible without needing API access or special permissions.

# Strength Rationale

theory_of_impact (4/5): Strong chain: tracking safety regressions across model versions directly informs deployment monitoring and release practices. The finding would be immediately useful for practitioners.

accessible_complexity (3/5): Requires downloading multiple model checkpoints and running inference on each. Medium compute needed for multiple model versions. Setup complexity is moderate but not beginner-trivial.

narrow_scope (3/5): Multiple checkpoints of a model family means multiple inference runs. Scope depends on how many checkpoints exist. Could be narrowed to 3-4 checkpoints but still substantial.

novelty (3/5): Some longitudinal tracking exists — RefusalBench and the Refusal Index protocol provide methodology. Research has shown refusal dropping from 25% to 0% across three model generations within one family. SORRY-Bench provides a fine-grained taxonomy for measuring refusal. However, a systematic study using Hugging Face public checkpoints of a specific model family (e.g., Mistral or Llama variants) with a fixed prompt set tracking safety regression over fine-tuning versions is not fully published. The methodology exists but the specific application to publicly-available checkpoint histories is a practical contribution.
