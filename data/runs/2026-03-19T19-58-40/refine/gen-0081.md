# Research Question

To what extent does models are updated silently after deployment, but safety evaluations are point-in-time. there is no lightweight protocol for tracking whether a model's safety behavior has drifted?

# Approach Outline

Design a small reproducible test suite of ~50 safety-sensitive prompts (refusal rate, harm elicitation, jailbreak resistance). Run it against the same model API endpoint at weekly intervals over the project duration. Log response hashes and refusal rates. Visualize any drift.
