# Research Question

To what extent does no simulation environment exists that allows researchers to parametrically control overseer quality, capability gap, error type, and oversight frequency to study their joint effects?

# Approach Outline

Build a configurable simulation environment (using small open models) where overseer accuracy, capability gap, error structure, and oversight frequency can all be set as parameters. Run a factorial sweep and document the parameter space.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

A simulation environment enables hypothesis testing about oversight dynamics that would be prohibitively expensive to test with real large models.
