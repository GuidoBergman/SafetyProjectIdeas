# Research Question

To what extent does the backdoor version of emergent misalignment (where misalignment only appears when a specific trigger token is present) is separately trained. it is unknown how the data requirements for backdoor vs?

# Approach Outline

Run a matched data-size sweep for both the standard (non-backdoor) and backdoor variants of emergent misalignment training. Use the same range of dataset sizes (25, 50, 100, 250, 500 examples). Measure misalignment rate conditional on trigger presence vs. absence for the backdoor model, and unconditional rate for the standard model. Compare minimum dataset sizes needed for reliable induction of each.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

If backdoor misalignment requires more data, it is harder to accidentally induce. If it requires less, adversarial backdooring via small targeted dataset injections becomes a more acute threat to finetuning APIs.
