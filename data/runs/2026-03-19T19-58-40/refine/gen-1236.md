# Research Question

To what extent does real deployments cannot monitor every token or action in real time. arxiv 2512.22154 identifies 'incremental attacks between agent instances' as an open problem: a model may execute a harmful sub-acti?

# Approach Outline

Build a toy agentic pipeline (web search + file write + code execution) with simulated monitor checkpoints at configurable intervals. Inject a red-team model that attempts to complete a harmful multi-step task by spreading sub-actions across checkpoint gaps. Measure success rate vs. checkpoint frequency.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

This directly quantifies how checkpoint frequency trades off against harm rate, giving deployment teams a concrete parameter to optimize. It is also one of the clearest testbeds for the 'control failure + agentic autonomy = irreversible action' compounding risk.
