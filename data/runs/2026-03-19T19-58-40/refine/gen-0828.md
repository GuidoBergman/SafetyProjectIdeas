# Research Question

To what extent does red-teaming is typically unstructured, with individuals independently trying attacks. military red-teaming (wargaming) uses structured, role-differentiated teams with explicit win conditions and force?

# Approach Outline

Import wargaming structure from military operational planning. Run a structured LLM red-team exercise with defined roles (Red Cell: attackers with fixed compute/turn budgets; Blue Cell: defenders who can propose prompt-level mitigations; White Cell: adjudicators using StrongReject). Define explicit 'scenarios' (threat actors, target capabilities, harm categories). Run 3 rounds of attack-defend-adjust. Measure whether the structured format discovers more unique attack vectors than an unstructured session of equal time. Document the protocol for reproducibility.

# Proposed First Experiments

Experiment 1 (Baseline): Set up experimental framework with a small public model. Replicate core measurement to establish baseline. ~8 hours.
Experiment 2 (Core): Apply methodology to target scenario. Measure primary metric vs baseline. ~12 hours.
Experiment 3 (Robustness): Test sensitivity to key parameters with 2+ variations. ~10 hours.

# Theory of Impact Chain

Military wargaming produces reproducible, role-differentiated exercises that identify blind spots through structured adversarial reasoning. Applied to LLM safety, it could formalize red-teaming into a repeatable, auditable methodology—addressing the reproducibility gap.
