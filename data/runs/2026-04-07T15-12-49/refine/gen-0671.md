# Research Question

In multi-agent systems, agents may trust reports from peer agents. This project investigates whether build a two-agent system where agent a provides status information to agent b.

# Approach Outline

Build a two-agent system where Agent A provides status information to Agent B. Compromise Agent A to send false safety-relevant status reports (e. g. , 'security check passed'). Measure how often Agent B relaxes its safety behaviors based on A's reports.
