# Research Question

OpenAI's Preparedness Framework defines 'High' cybersecurity threshold as a meaningful governance trigger, but whether this threshold is calibrated to the right capability level (too low, too high, or about right) has not been independently assessed. This project investigates whether analyze the 'high' threshold definition carefully.

# Approach Outline

Analyze the 'High' threshold definition carefully. Identify the specific capability level described. Map this to current benchmark performance data. Compare against documented capabilities used in real-world attacks (GTG-1002, vibe hacking). Assess whether the threshold is empirically calibrated to a meaningful harm escalation point.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If the 'High' threshold is crossed before meaningful harm capability is reached (false positive), governance is overly restrictive. If crossed after (false negative), it fails its purpose. Threshold calibration is a foundational governance validity question.
