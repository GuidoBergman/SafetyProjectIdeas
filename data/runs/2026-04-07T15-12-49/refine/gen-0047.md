# Research Question

If all frontier models fail on the same specific challenges, the failures may reflect structural limitations (fundamental task difficulty). This project investigates whether run 4-5 frontier models on the same 30-challenge ctf set.

# Approach Outline

Run 4-5 frontier models on the same 30-challenge CTF set. For each challenge, record which models succeed and which fail. Compute a 'co-failure correlation matrix'. Test whether co-failure patterns cluster by model family, task type, or both. Identify challenges where all models fail (likely hard tasks) vs. challenges with heterogeneous outcomes (model-specific weaknesses).

# Theory of Impact Chain
