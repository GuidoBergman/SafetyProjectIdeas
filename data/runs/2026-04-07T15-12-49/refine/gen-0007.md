# Research Question

All existing cyber range evaluations use undefended networks. This project investigates whether set up a minimal capture-the-flag environment using free tools (hackthebox free tier, tryhackme, or a local metasploitable instance with snort ids configured).

# Approach Outline

Set up a minimal Capture-the-Flag environment using free tools (HackTheBox free tier, TryHackMe, or a local Metasploitable instance with Snort IDS configured). Run an AI agent (via API scaffolding in Python) against: (A) unmonitored target and (B) target with active IDS alerts that simulate defender response (e. g. , firewall rules activating after detection). Measure steps completed and time-to-detection under each condition.

# Theory of Impact Chain

Every real network has defenders. The gap between benchmark (no defender) and real-world (active defender) performance is completely unmeasured. Even a modest experiment would be the first published data point on this crucial variable.
