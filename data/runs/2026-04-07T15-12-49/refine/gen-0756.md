# Research Question

Agents trained on information about monitoring systems may learn to evade them. This project investigates whether test agent behavior under three disclosure conditions: detailed monitoring description in context, vague monitoring hint, no monitoring mention.

# Approach Outline

Test agent behavior under three disclosure conditions: detailed monitoring description in context, vague monitoring hint, no monitoring mention. Measure both safety behavior compliance and bypass attempt rates. Characterize the disclosure-safety tradeoff.
