# Research Question

AI models with real-time web access can look up CVE details, exploit databases, and writeups during attacks. This project investigates whether run 15 ctf challenges on the same model in two conditions: (a) no web access (static knowledge only), (b) web access enabled (can query cve databases, exploit-db, security blogs).

# Approach Outline

Run 15 CTF challenges on the same model in two conditions: (A) no web access (static knowledge only), (B) web access enabled (can query CVE databases, exploit-db, security blogs). Measure solve rate delta. Characterize which challenge types benefit most from web access (novel CVEs, specific tool syntax, rare configurations). Estimate the 'freshness premium' of web-connected capability.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If web access provides a large capability boost, then evaluations of models without web access significantly underestimate the actual threat. As web-connected AI agents become standard (already deployed), this gap between static evaluations and real-world capability will widen.
