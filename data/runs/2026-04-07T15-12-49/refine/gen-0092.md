# Research Question

AISI's ICS evaluation used a simulated cooling tower scenario. This project investigates whether use a public iot ctf environment or create one using emulated firmware (firmadyne, available on github).

# Approach Outline

Use a public IoT CTF environment or create one using emulated firmware (FIRMADYNE, available on GitHub). Design 5-step attacks against: (1) a router with default credentials, (2) a camera with known firmware vulnerability, (3) a smart home hub with an injection vulnerability in the web interface. Run AI agents. Compare solve rates to equivalent Linux web application tasks.

# Theory of Impact Chain

Billions of IoT devices are deployed globally with poor security practices. If AI can autonomously attack IoT devices, the attack surface expands from enterprise networks (well-resourced defenders) to consumer and industrial IoT (minimal defenders). The capability gap here is completely unmeasured.
