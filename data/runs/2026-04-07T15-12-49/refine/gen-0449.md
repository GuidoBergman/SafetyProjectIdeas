# Research Question

The LessWrong 2026 ATT&CK-style threat matrix exists conceptually, but no tool exists to automatically classify observed agent behaviors into kill chain stages. This project investigates whether implement a text classifier trained on synthetic examples of agent actions labeled by kill chain stage (reconnaissance, lateral movement, privilege escalation, exfiltration, etc.

# Approach Outline

Implement a text classifier trained on synthetic examples of agent actions labeled by kill chain stage (reconnaissance, lateral movement, privilege escalation, exfiltration, etc. ). Evaluate on agent logs from controlled experiments. Compute classification accuracy per stage.
