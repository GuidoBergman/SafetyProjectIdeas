# Research Question

For AI-assisted SOC triage to be reliable, AI confidence scores must be calibrated to real threat probabilities. This project investigates whether define 'reliable triage' as: ai confidence score ≥0.

# Approach Outline

Define 'reliable triage' as: AI confidence score ≥0. 8 corresponds to actual threat probability ≥80%. Using published AI intrusion detection performance data, estimate current calibration. Identify the gap. Propose a calibration fine-tuning experiment using Platt scaling or temperature scaling on a public IDS dataset.
