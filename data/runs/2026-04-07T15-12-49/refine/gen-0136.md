# Research Question

High false positive rates in AI anomaly detection create alert fatigue. This project investigates whether use a public ids dataset (cicids2017 or unsw-nb15) to simulate an ai-powered alert system with varying fp rates (5%, 20%, 50%).

# Approach Outline

Use a public IDS dataset (CICIDS2017 or UNSW-NB15) to simulate an AI-powered alert system with varying FP rates (5%, 20%, 50%). Measure: at what FP rate would a rational analyst start ignoring alerts? Model this as a decision problem using signal detection theory. Compute the expected missed detection rate as a function of FP rate.
