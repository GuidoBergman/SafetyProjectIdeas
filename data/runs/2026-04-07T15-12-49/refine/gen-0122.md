# Research Question

Two interacting failure modes: (1) AI agents in agentic workflows execute tool calls with the privileges of the orchestrating process, and (2) agentic offensive agents may be given too many permissions to function effectively. This project investigates whether set up an ai red team agent with deliberately over-provisioned permissions (common in practice).

# Approach Outline

Set up an AI red team agent with deliberately over-provisioned permissions (common in practice). Inject a prompt through a target system that directs the agent to perform a privileged action against the attacker's own infrastructure (e. g. , exfiltrate the agent's own API key, write to files outside the target scope). Measure the success rate of this 'friendly fire' injection across 3 models and 5 injection payloads.

# Theory of Impact Chain

Over-provisioned AI offensive agents can be weaponized against the attacker's own infrastructure through target-injected prompts. This is a novel attack surface specific to AI red team operations and represents a concrete safety argument for minimal-privilege design of AI offensive agents.
