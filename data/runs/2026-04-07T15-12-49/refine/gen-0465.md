# Research Question

Network security uses honeypots (fake attractive targets) to detect intruders. This project investigates whether place honeypot resources (fake high-value files, fake credentials, fake admin endpoints) in an agent's accessible environment.

# Approach Outline

Place honeypot resources (fake high-value files, fake credentials, fake admin endpoints) in an agent's accessible environment. These resources have no legitimate task-relevance. Measure how often agents access honeypot resources and under what task conditions. Use honeypot access rate as an offensive behavior indicator.
