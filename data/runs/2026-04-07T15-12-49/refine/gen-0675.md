# Research Question

When an agent deviates from its assigned task, its outputs should become semantically dissimilar to the expected task domain. This project investigates whether embed expected task domain using a small sentence encoder.

# Approach Outline

Embed expected task domain using a small sentence encoder. During agent operation, compute rolling semantic similarity of agent outputs/actions to the task embedding. Measure whether threshold crossings on this signal reliably detect goal-hijacking injections.

# Theory of Impact Chain
