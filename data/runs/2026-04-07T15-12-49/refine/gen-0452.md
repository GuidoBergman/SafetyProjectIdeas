# Research Question

No benchmark exists for evaluating the effectiveness of runtime prompt injection detectors. This project investigates whether compile 200 agent context windows: 100 clean, 100 containing injected adversarial instructions of five types.

# Approach Outline

Compile 200 agent context windows: 100 clean, 100 containing injected adversarial instructions of five types. Package as a benchmark with evaluation metrics (AUROC, F1, false-positive rate). Baseline three simple detectors (keyword, regex, embedding similarity).

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

A standardized benchmark would accelerate research on injection detection by enabling direct comparison. It also reveals which simple baselines are already adequate.
