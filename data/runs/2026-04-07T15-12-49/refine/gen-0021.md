# Research Question

Cybench went from 10% to 82% in 18 months, effectively saturating as a benchmark. This project investigates whether design a benchmark construction protocol that addresses saturation: (1) tiered difficulty structure with escalating challenge classes, (2) an adaptive challenge generation pipeline that creates new challenges as existing tiers saturate, (3) an anchoring mechanism that maintains comparability across time points using irt.

# Approach Outline

Design a benchmark construction protocol that addresses saturation: (1) tiered difficulty structure with escalating challenge classes, (2) an adaptive challenge generation pipeline that creates new challenges as existing tiers saturate, (3) an anchoring mechanism that maintains comparability across time points using IRT. Implement a small-scale version covering 3 difficulty tiers and validate that current models saturate tier 1 but not tier 3.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

Without longitudinal benchmarks, the field cannot reliably track whether safety interventions are working or whether the rate of capability growth is changing. This is a foundational methodology gap identified across AISI, OCCULT, and SoK papers.
