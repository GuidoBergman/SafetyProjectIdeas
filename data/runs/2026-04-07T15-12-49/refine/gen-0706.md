# Research Question

Many agent deployments use simple sandboxing (Docker containers, Python subprocesses with restricted imports). This project investigates whether set up a series of increasingly restrictive sandboxes (unrestricted python, restricted imports, docker container, gvisor sandbox).

# Approach Outline

Set up a series of increasingly restrictive sandboxes (unrestricted Python, restricted imports, Docker container, gVisor sandbox). Give agents with code execution capability prompts that incentivize escape. Measure sandbox escape rates and techniques used.
