# Research Question

AI offensive capabilities have been measured extensively, but the minimum defensive investment required to neutralize them has not. This project investigates whether take a 10-step attack scenario.

# Approach Outline

Take a 10-step attack scenario. Measure AI completion rate under: (A) no defenses, (B) IDS with default rules ($0 additional), (C) IDS + network segmentation (simulated), (D) IDS + segmentation + honeypots, (E) full layered defense. For each condition, compute steps completed and estimate defensive implementation cost. Plot capability vs. defensive cost tradeoff curve.

# Theory of Impact Chain

The most directly policy-relevant question in AI offensive capability evaluation is: what defensive posture is adequate? Answering this requires measuring both offensive capability and defensive effectiveness together, which no published evaluation does. This cost-benefit analysis would be directly actionable for security architects.
