# Research Question

If formal verification is used to gate deployment of AI-generated code, adversarial AI systems could be trained to satisfy the formal verification checker while violating the intent. This project investigates whether train or prompt an llm to generate code that: (a) formally verifies against a given spec, but (b) intentionally violates the informal intent of the spec (by exploiting spec under-specification).

# Approach Outline

Train or prompt an LLM to generate code that: (a) formally verifies against a given spec, but (b) intentionally violates the informal intent of the spec (by exploiting spec under-specification). Measure how easy this is. Test whether code review can catch the violation after formal verification passes.

# Theory of Impact Chain

If formal verification can be satisfied adversarially, it fails as a security gateway. This is the formal methods analog of goodhart's law: when a measure becomes a target, it ceases to be a good measure.
