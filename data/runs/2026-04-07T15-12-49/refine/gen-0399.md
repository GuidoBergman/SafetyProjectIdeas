# Research Question

AI labs run bug bounty and bypass disclosure programs, but whether these attract comparable researcher quality and finding diversity to traditional software bug bounty programs is unknown. This project investigates whether compare anthropic's and openai's ai safety bug bounty program structures (scope, rewards, disclosure process, safe harbor) against major software bug bounty programs (google vrp, microsoft bug bounty).

# Approach Outline

Compare Anthropic's and OpenAI's AI safety bug bounty program structures (scope, rewards, disclosure process, safe harbor) against major software bug bounty programs (Google VRP, Microsoft Bug Bounty). Interview 5-10 security researchers about participation motivations. Assess whether the programs create sufficient incentives for high-quality dual-use governance research.
