# Research Question

A significant fraction of Lean 4 proof failures appear to involve choosing the wrong induction hypothesis or induction variable. This project investigates whether analyze 100 llm lean 4 failures.

# Approach Outline

Analyze 100 LLM Lean 4 failures. Classify by root cause using a structured taxonomy. Test whether 'wrong induction structure' is most common. For that class, implement a single targeted intervention: system prompt addition that describes how to select induction variables. Measure improvement.
