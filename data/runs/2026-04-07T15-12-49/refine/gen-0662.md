# Research Question

Canary tokens (fake credentials that trigger alerts when accessed) are a standard technique in cybersecurity for detecting insider threats. This project investigates whether embed fake api keys, file paths, and database credentials (canary tokens) into an agent's accessible context.

# Approach Outline

Embed fake API keys, file paths, and database credentials (canary tokens) into an agent's accessible context. Measure whether agents in 'goal-hijacked' or adversarially-prompted conditions are more likely to attempt to use these canary credentials than baseline agents.
