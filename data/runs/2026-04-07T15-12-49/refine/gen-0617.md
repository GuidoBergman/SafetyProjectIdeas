# Research Question

CSLib's Boole framework generates Lean verification conditions from Boole-language specifications. This project investigates whether select 20 algorithms from cslib's roadmap.

# Approach Outline

Select 20 algorithms from CSLib's roadmap. Ask LLMs to generate Boole-language specifications for each. Run the Boole framework to generate Lean verification conditions. Measure: (a) syntactic correctness of Boole specs, (b) whether generated verification conditions are provable in Lean. Compare to hand-written Boole specs.
