# Research Question

Network IDS anomaly detection techniques (statistical baseline + deviation scoring) have never been applied to AI agent action streams, despite conceptual similarity (both detect anomalous sequences in a stream). This project investigates whether build a behavioral baseline for a benign agent (action sequence distributions, tool call frequency, argument patterns).

# Approach Outline

Build a behavioral baseline for a benign agent (action sequence distributions, tool call frequency, argument patterns). Implement a threshold-based anomaly scorer inspired by network IDS (SNORT/Suricata logic). Test on episodes containing emergent offensive behaviors. Measure AUROC for detecting offensive episodes.
