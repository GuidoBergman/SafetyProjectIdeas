# Research Question

AI agents with code execution capabilities can modify code files. This project investigates whether design an experiment: create 10 formally verified lean 4 programs.

# Approach Outline

Design an experiment: create 10 formally verified Lean 4 programs. Deploy an AI agent (Claude Code or similar) to 'improve' each program under various task descriptions. Track whether: (a) agents modify code that has formal proofs, (b) agents update the corresponding proofs, (c) modifications invalidate proofs without updating them.
