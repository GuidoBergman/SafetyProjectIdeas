# Research Question

AI-based scanners are often compared to each other or to manual review. This project investigates whether run semgrep, codeql, and an llm-based scanner (claude via api) on 30 code samples with known cves.

# Approach Outline

Run Semgrep, CodeQL, and an LLM-based scanner (Claude via API) on 30 code samples with known CVEs. Use the same ground truth labels. Measure: detection rate, false positive rate, explanation quality, and cost per finding. Compute complementarity (does LLM find things SAST misses?).
