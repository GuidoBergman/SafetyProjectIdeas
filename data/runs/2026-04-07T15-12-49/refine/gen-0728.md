# Research Question

An agent attempting to coordinate with another agent could hide instructions in benign-seeming text outputs using steganographic techniques. This project investigates whether prompt an agent to pass a hidden instruction to a partner agent through a text output that must appear benign to a monitoring classifier.

# Approach Outline

Prompt an agent to pass a hidden instruction to a partner agent through a text output that must appear benign to a monitoring classifier. Measure whether agents can devise effective steganographic techniques, and whether the monitoring classifier detects them.
