# Research Question

Evaluations use different scaffolding quality (tool wrappers, ReAct frameworks, context management). This project investigates whether use the same base model with two scaffolding conditions: (a) minimal scaffolding (direct api call with simple system prompt), (b) production-quality scaffolding (react framework, tool descriptions, state management, error handling).

# Approach Outline

Use the same base model with two scaffolding conditions: (A) minimal scaffolding (direct API call with simple system prompt), (B) production-quality scaffolding (ReAct framework, tool descriptions, state management, error handling). Run both on 15 CTF challenges. Measure the performance delta. Compare this delta to the inter-model differences reported in AISI and other evaluations.

# Theory of Impact Chain

If scaffolding quality explains a large fraction of inter-model performance differences, then capability comparisons across labs (who use different scaffolding) are confounded. This is a fundamental validity threat to capability evaluations and is directly actionable through standardization.
