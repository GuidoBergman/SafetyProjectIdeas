# Research Question

AI models receive system prompts that define their role and constraints. This project investigates whether design 5 system prompt variants for the same underlying task capability: (1) neutral assistant, (2) security researcher, (3) red team professional with authorization, (4) ctf player, (5) penetration tester with explicit scope statement.

# Approach Outline

Design 5 system prompt variants for the same underlying task capability: (1) neutral assistant, (2) security researcher, (3) red team professional with authorization, (4) CTF player, (5) penetration tester with explicit scope statement. Run all 5 on 10 identical offensive challenges. Measure solve rate, output quality, and failure mode distribution across conditions. Test whether differences are statistically significant.

# Theory of Impact Chain

If system prompt framing significantly changes capability expression, then adversaries who know how to craft system prompts can unlock higher capability from commercial models than default configurations expose. This has direct implications for API use policy, operator system prompt requirements, and safety evaluation protocols.
