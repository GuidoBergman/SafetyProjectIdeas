# Research Question

Anthropic disrupted AI-orchestrated espionage in November 2025 (30 targets, 80-90% automation). This project investigates whether deconstruct the capabilities demonstrated in the november 2025 espionage case from anthropic's public report.

# Approach Outline

Deconstruct the capabilities demonstrated in the November 2025 espionage case from Anthropic's public report. For each capability (automated reconnaissance, credential harvesting, lateral movement, data extraction), identify the best proxy evaluation task from the public literature at August 2025 (3 months before). Measure whether the proxy tasks would have predicted the demonstrated capability. Compute the evaluation 'predictive failure gap'.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If published evaluations were within measurement error of the real capability, the evaluation ecosystem functioned but warning was not heeded. If the evaluation-to-reality gap was large, evaluation methodology failed to capture key capabilities. This retrospective analysis directly informs which evaluation gaps most urgently need closing.
