# Research Question

Anthropic's cyber evaluation updates documented models graduating from requiring custom toolkits to performing well with standard tools. This project investigates whether run the same set of 15-20 ctf challenges under two conditions: (1) model has access to a custom pre-configured toolkit (nmap wrapper, exploit scripts) and (2) model only has access to standard bash/python tools.

# Approach Outline

Run the same set of 15-20 CTF challenges under two conditions: (1) model has access to a custom pre-configured toolkit (nmap wrapper, exploit scripts) and (2) model only has access to standard bash/Python tools. Measure the performance delta per challenge category. Test whether toolkit dependency correlates with task complexity or ATT&CK phase.
