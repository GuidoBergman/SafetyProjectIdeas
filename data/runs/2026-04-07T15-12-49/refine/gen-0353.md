# Research Question

Whether adding headers, bullet points, numbered lists, or markdown to a request affects refusal rates has not been studied—yet format is trivially manipulable by users. This project investigates whether take 20 borderline cybersecurity requests.

# Approach Outline

Take 20 borderline cybersecurity requests. Reformat each in: plain text, markdown headers, numbered steps, table format, and JSON structure. Test refusal rates across 4 models. Measure if format alone (with identical semantic content) shifts refusal rates.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If formatting trivially changes refusal rates, governance frameworks assuming semantic refusal evaluation are overstated. This informs robustness requirements for safety training.
