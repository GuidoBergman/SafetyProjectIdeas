# Research Question

RAND proposes using formal methods to verify AI model evaluations without tampering. This project investigates whether design a minimal threat model for a tamper-evident ai evaluation verification system.

# Approach Outline

Design a minimal threat model for a tamper-evident AI evaluation verification system. Identify which components must be formally verified by humans vs. which could be AI-assisted. Test whether a Lean 4 proof of a simple evaluation protocol can be generated, reviewed, and validated without AI in the critical path.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

An AI-generated proof of AI evaluation integrity creates a circular dependency. If the proof generator is the AI being evaluated, the safety case collapses. This is a foundational governance design question.
