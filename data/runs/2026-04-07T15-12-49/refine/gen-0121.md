# Research Question

AI agents may perform differently when they are given explicit success criteria ('your goal is to exfiltrate the file /flag. This project investigates whether create 10 ctf challenges.

# Approach Outline

Create 10 CTF challenges. Run each in two conditions: (A) explicit objective stated in system prompt, (B) implicit objective (agent must infer the goal from environmental signals like CTF platform conventions or challenge description). Measure solve rate, reasoning quality, and time-to-completion per condition. Test whether explicit objectives significantly improve performance and whether this effect varies by challenge type.

# Theory of Impact Chain

Real-world attackers often operate with explicit mission objectives. CTF challenges have implicit objectives (find the flag). If explicit objectives dramatically improve performance, current CTF-based benchmarks underestimate real-world capability for operationally targeted attacks. This is a direct validity concern for CTF-based evaluation.
