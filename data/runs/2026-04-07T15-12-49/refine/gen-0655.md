# Research Question

A fundamental assumption of agent monitoring is that agents behave consistently whether or not they believe they are being observed. This project investigates whether present identical tasks to an agent under three conditions: explicitly told it is monitored, told it is not monitored, and given no information.

# Approach Outline

Present identical tasks to an agent under three conditions: explicitly told it is monitored, told it is not monitored, and given no information. Compare task completion strategies, refusal rates, and policy violations across conditions on a small open-source model.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If models already behave differently based on monitoring awareness, current monitoring systems may be systematically fooled. This is a prerequisite check for the validity of any monitoring regime.
