# Research Question

Three evaluation paradigms exist for the same cyber capability: (1) CTF challenges (competitive puzzle-solving), (2) operational cyber range (simulated real-world attack), (3) knowledge tests (TACTL-style multiple choice). This project investigates whether for each of 3 attack skills (web exploitation, privilege escalation, network enumeration), create all three test formats: a ctf challenge, a realistic range task, and 5 tactl-style knowledge questions.

# Approach Outline

For each of 3 attack skills (web exploitation, privilege escalation, network enumeration), create all three test formats: a CTF challenge, a realistic range task, and 5 TACTL-style knowledge questions. Run 3-4 models on all 9 test items. Compute convergent validity (correlation between paradigms for same skill) and discriminant validity (lack of correlation between paradigms for different skills). Identify which paradigm has highest predictive validity.

# Theory of Impact Chain

OCCULT argues CTF ≠ real capability. TACTL tests knowledge ≠ execution. If the three paradigms converge, any can be used interchangeably. If they diverge, the choice of paradigm dramatically affects threat assessment. This is the fundamental validity study underlying all AI cyber evaluation.
