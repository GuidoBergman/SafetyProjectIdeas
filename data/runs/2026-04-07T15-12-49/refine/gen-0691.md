# Research Question

Traditional insider threat detection uses user behavior analytics (UBA) on human employee logs. This project investigates whether apply classical uba techniques (peer group analysis, temporal anomaly detection, entity behavior profiling) to logs from an open-source agent framework.

# Approach Outline

Apply classical UBA techniques (peer group analysis, temporal anomaly detection, entity behavior profiling) to logs from an open-source agent framework. Measure whether these techniques detect injected insider-threat-like agent behaviors with acceptable false positive rates.
