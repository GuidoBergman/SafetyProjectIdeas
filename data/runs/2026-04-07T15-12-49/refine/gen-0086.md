# Research Question

It is unknown whether attack success or failure at individual steps can be predicted from model-internal signals (attention patterns, intermediate representations) before the step is executed. This project investigates whether using an open-weight model (to enable activation access), run 100 attack task attempts (50 success, 50 failure).

# Approach Outline

Using an open-weight model (to enable activation access), run 100 attack task attempts (50 success, 50 failure). For each attempt, extract attention patterns and last-hidden-state representations at the step-planning phase (before tool invocation). Train a simple logistic regression classifier to predict step success from these representations. Measure AUC and identify which representation features are most predictive.

# Theory of Impact Chain

A capability predictor operating on model internals (not just outputs) could enable: (1) real-time monitoring of AI offensive agents to detect high-risk reasoning states, (2) selective refusal when internal indicators suggest dangerous capability expression. This is a lightweight interpretability contribution with direct safety application.
