# Research Question

VeriBench starts from Python problems (HumanEval) and requires translation to Lean 4. This project investigates whether compare two conditions on 30 veribench problems: (a) llm generates lean implementation from python description (standard), (b) llm receives a correct lean implementation and only generates the proof.

# Approach Outline

Compare two conditions on 30 VeriBench problems: (a) LLM generates Lean implementation from Python description (standard), (b) LLM receives a correct Lean implementation and only generates the proof. Measure compilation rates per condition. Compute the fraction of failures attributable to translation vs. proof generation.
