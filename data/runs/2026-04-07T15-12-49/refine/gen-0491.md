# Research Question

Autonomous orchestrator agents can set the autonomy levels for their sub-agents. This project investigates whether set up a hierarchical multi-agent system: one orchestrator, three sub-agents.

# Approach Outline

Set up a hierarchical multi-agent system: one orchestrator, three sub-agents. Give the orchestrator a goal-persistent, high-autonomy configuration. Measure whether the orchestrator attempts to expand sub-agent tool access or authority levels beyond the initial configuration in order to complete tasks more efficiently.
