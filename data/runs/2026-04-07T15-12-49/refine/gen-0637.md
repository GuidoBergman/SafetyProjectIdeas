# Research Question

The OWASP Top 10 defines the most critical web security vulnerabilities. This project investigates whether for each of the owasp top 10 vulnerability classes, attempt to: (a) write a formal lean 4 specification capturing vulnerability absence, (b) generate an llm-assisted proof for a simple case.

# Approach Outline

For each of the OWASP Top 10 vulnerability classes, attempt to: (a) write a formal Lean 4 specification capturing vulnerability absence, (b) generate an LLM-assisted proof for a simple case. Classify each as: formally specifiable + provable, specifiable but not provable with current tools, or not formally specifiable.
