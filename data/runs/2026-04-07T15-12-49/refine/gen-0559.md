# Research Question

When the same LLM generates both the formal specification and the implementation, systematic biases (same omissions, same incorrect assumptions) may propagate across both, causing proofs to pass while missing the same class of vulnerabilities. This project investigates whether compare two conditions on 30 security-critical programs: (a) spec and implementation generated by the same llm, (b) spec generated by one llm and implementation by a different llm.

# Approach Outline

Compare two conditions on 30 security-critical programs: (a) spec and implementation generated by the same LLM, (b) spec generated by one LLM and implementation by a different LLM. Measure whether cross-model pairs catch more vulnerabilities in subsequent analysis. Test statistical significance.

# Theory of Impact Chain

Self-verification is a known limitation in AI safety. If same-model spec+implementation pairs produce correlated blind spots, all-in-one vericoding pipelines are systematically overconfident. Cross-model diversity would be required for safety-critical applications.
