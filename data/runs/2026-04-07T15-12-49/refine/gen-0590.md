# Research Question

Property-based testing (QuickCheck, Hypothesis) discovers counterexamples to property claims quickly and cheaply. This project investigates whether for 30 programs, use an llm to generate both: (a) formal lean 4 spec and (b) equivalent python property (for hypothesis).

# Approach Outline

For 30 programs, use an LLM to generate both: (a) formal Lean 4 spec and (b) equivalent Python property (for Hypothesis). Run Hypothesis on the property with 1000 test cases. If Hypothesis finds a counterexample, revise the spec. Compare final proof success rate with vs. without Hypothesis pre-validation.
