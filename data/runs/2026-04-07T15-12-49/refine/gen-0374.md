# Research Question

Governance frameworks specify that labs should pause or restrict deployment at capability thresholds, but the operational mechanisms by which capability evaluations actually halt or modify deployment are opaque. This project investigates whether interview-based study (or public document analysis) mapping the decision chain from: capability evaluation result → internal risk assessment → leadership decision → deployment modification.

# Approach Outline

Interview-based study (or public document analysis) mapping the decision chain from: capability evaluation result → internal risk assessment → leadership decision → deployment modification. For each publicly documented threshold-adjacent case (Anthropic gray zone, GPT-5. 3-Codex High), document what deployment decision was actually made and why.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If the causal path from evaluation to deployment decision is broken, capability thresholds are notional governance—they don't actually halt risky deployment. Documenting this chain makes it auditable.
