# Research Question

Two interacting failure modes: (1) AI offensive capability is scaling rapidly with no plateau (AISI 2026), and (2) all evaluations use undefended targets. This project investigates whether create a small study comparing ai agent performance on: (a) an undefended ctf box (standard), and (b) the same box with a basic intrusion detection system (snort/suricata with default rules) active.

# Approach Outline

Create a small study comparing AI agent performance on: (A) an undefended CTF box (standard), and (B) the same box with a basic intrusion detection system (Snort/Suricata with default rules) active. Quantify the performance degradation ratio. Use this as a lower bound estimate of how much undefended benchmarks overestimate real-world capability.

# Theory of Impact Chain

Policy decisions about AI offensive capability rely on benchmark data that systematically excludes the most important real-world variable (active defense). This compounding creates an invisible safety margin problem that could lead to both over- and under-regulation.
