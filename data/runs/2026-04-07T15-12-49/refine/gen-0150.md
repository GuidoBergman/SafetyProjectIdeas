# Research Question

AI security tools generate detailed vulnerability reports. This project investigates whether design a taxonomy of access control mechanisms applicable to ai security tool outputs (role-based, time-limited, redacted summaries, cryptographic commitments).

# Approach Outline

Design a taxonomy of access control mechanisms applicable to AI security tool outputs (role-based, time-limited, redacted summaries, cryptographic commitments). Prototype two mechanisms on a mock tool. Evaluate trade-offs between defensive utility and leakage risk using a structured decision analysis.

- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

The dual-use problem is often framed as preventing AI from finding vulnerabilities. Gating access to outputs is a complementary, possibly less disruptive intervention.
