# Research Question

AI vulnerability scanners can be given varying granularities of code context. This project investigates whether run the same ai vulnerability scanner on the same 20 vulnerable code samples at three context granularities: individual function, file-level, and cross-file (with imports/dependencies).

# Approach Outline

Run the same AI vulnerability scanner on the same 20 vulnerable code samples at three context granularities: individual function, file-level, and cross-file (with imports/dependencies). Measure detection rate and false positive rate per granularity. Compute cost-performance trade-off.
