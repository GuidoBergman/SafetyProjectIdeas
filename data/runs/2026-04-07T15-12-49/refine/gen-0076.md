# Research Question

CTF environments have clean, minimal network configurations. This project investigates whether set up two versions of a 5-step attack scenario: (a) clean ctf-like environment (minimal services, only relevant ports open), (b) realistic environment with 50+ additional services running, background traffic, and several rabbit-hole services with deliberately misleading banners.

# Approach Outline

Set up two versions of a 5-step attack scenario: (A) clean CTF-like environment (minimal services, only relevant ports open), (B) realistic environment with 50+ additional services running, background traffic, and several rabbit-hole services with deliberately misleading banners. Run AI agents on both. Measure completion rate delta and characterize how noise affects agent behavior (distraction, false positives pursued, timeout on irrelevant paths).

# Proposed First Experiments

- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If noise dramatically degrades AI performance, real corporate networks may have emergent protective properties not captured in clean evaluation environments. This gap between clean benchmarks and realistic environments is a structural validity threat to all published evaluations.
