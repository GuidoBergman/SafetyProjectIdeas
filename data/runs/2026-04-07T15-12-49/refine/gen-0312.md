# Research Question

Anthropic and OpenAI self-assess their models against cyber risk thresholds, but independent auditors lack a structured checklist to verify these self-assessments. This project investigates whether extract all specific capability criteria from anthropic rsp (asl-3/4 cyber) and openai preparedness framework (low/medium/high/critical cyber).

# Approach Outline

Extract all specific capability criteria from Anthropic RSP (ASL-3/4 cyber) and OpenAI Preparedness Framework (Low/Medium/High/Critical cyber). Translate each criterion into a specific test. Compile into a scorecard. Run the scorecard against one accessible model (Claude 3. 7 Sonnet) and compare result to Anthropic's self-assessment.
