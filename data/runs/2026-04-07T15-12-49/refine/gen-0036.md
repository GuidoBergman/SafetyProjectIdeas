# Research Question

AI offensive tools lower the cost and skill barrier for cyberattacks, which increases attacker population size. This project investigates whether adapt a standard sir (susceptible-infected-recovered) epidemiological model to cyber attack diffusion.

# Approach Outline

Adapt a standard SIR (Susceptible-Infected-Recovered) epidemiological model to cyber attack diffusion. Parameterize with: (1) attack speed (from AISI benchmarks: ~45 minutes per attack), (2) vulnerability prevalence in a simulated network of 100 nodes, (3) defender response time. Simulate under human-speed vs. AI-speed attack regimes. Measure outbreak size and peak infection rate.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

AI-speed cyber attacks may create outbreak dynamics qualitatively different from human-speed attacks, potentially overwhelming defenders before response is possible. This model would provide quantitative predictions about whether AI capability thresholds correspond to phase transitions in attack spread.
