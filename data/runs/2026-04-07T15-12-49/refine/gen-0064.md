# Research Question

AISI's inference scaling results were documented using frontier API models with large token budgets. This project investigates whether run open-weight models (7b, 13b, 70b parameter ranges) at varying inference compute levels achievable on a single consumer gpu (token budgets from 1k to 50k).

# Approach Outline

Run open-weight models (7B, 13B, 70B parameter ranges) at varying inference compute levels achievable on a single consumer GPU (token budgets from 1K to 50K). Plot performance on a 10-challenge CTF set against token budget. Test whether log-linear scaling holds at consumer compute levels or whether there is a ceiling before reaching the range studied by AISI.
