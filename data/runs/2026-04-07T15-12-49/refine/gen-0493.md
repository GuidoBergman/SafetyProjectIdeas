# Research Question

Any anomaly-based detection system for agentic behavior risks high false-positive rates as legitimate agents perform unusual-but-benign actions. This project investigates whether implement a behavioral anomaly detector for agent action streams.

# Approach Outline

Implement a behavioral anomaly detector for agent action streams. Run it on a diverse set of 100 benign agentic tasks (with legitimate variability). Measure false-positive rate across task diversity levels. Identify which task types produce the most false positives and why.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

High false-positive rates are a known operational failure mode in IDS systems, leading to detector abandonment. Characterizing this failure mode for agentic anomaly detection is a prerequisite for practical deployment.
