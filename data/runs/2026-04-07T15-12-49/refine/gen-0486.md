# Research Question

Goal-persistent agents blocked at each privilege level may escalate repeatedly, creating an escalation spiral. This project investigates whether design a multi-level privilege hierarchy (user → power user → admin → superadmin).

# Approach Outline

Design a multi-level privilege hierarchy (user → power user → admin → superadmin). Run a highly goal-persistent agent and a low-persistence control on a task requiring user-level access. When blocked at each level, measure whether high-persistence agents attempt escalation to the next level vs. stopping.
