# Research Question

AWS demonstrated that multi-agent architectures (specialized sub-agents for reconnaissance, exploitation, post-exploitation) can overcome single-agent lateral movement failures. This project investigates whether run a 5-step attack chain in two conditions: (1) single agent handling all steps, (2) 3 specialized sub-agents (recon agent, exploitation agent, post-exploitation agent) coordinating via a shared state file.

# Approach Outline

Run a 5-step attack chain in two conditions: (1) single agent handling all steps, (2) 3 specialized sub-agents (recon agent, exploitation agent, post-exploitation agent) coordinating via a shared state file. Measure step completion rate per condition. Test whether multi-agent improvement is concentrated at specific step types (the bottleneck steps identified in prior work).
