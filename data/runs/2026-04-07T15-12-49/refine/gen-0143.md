# Research Question

Fault tree analysis (FTA), standard in aerospace and nuclear safety, models how component failures combine to produce system failures. This project investigates whether build a fault tree for a canonical ai-assisted vulnerability scanning pipeline (scan → triage → patch → deploy).

# Approach Outline

Build a fault tree for a canonical AI-assisted vulnerability scanning pipeline (scan → triage → patch → deploy). Enumerate failure modes at each node (missed detection, wrong explanation, broken patch, deployment regression). Estimate failure probabilities using published data. Compute overall system failure probability.
