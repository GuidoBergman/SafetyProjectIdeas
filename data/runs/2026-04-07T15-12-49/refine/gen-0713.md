# Research Question

If an LLM-based monitor gives different ratings for semantically equivalent agent actions that are phrased differently, it is unreliable as a monitoring tool. This project investigates whether create pairs of semantically equivalent dangerous and benign agent actions with varying phrasings.

# Approach Outline

Create pairs of semantically equivalent dangerous and benign agent actions with varying phrasings. Measure inter-phrasing consistency of an LLM monitor's ratings. Compute consistency score and identify phrasing patterns that cause rating reversals.

# Proposed First Experiments

- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

Monitor inconsistency means attackers can find phrasings that evade detection for dangerous actions. Measuring consistency is a prerequisite for certifying monitor reliability.
