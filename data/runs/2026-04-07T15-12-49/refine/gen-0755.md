# Research Question

Most monitoring research uses Anthropic or OpenAI models as the monitored agent. This project investigates whether run the same set of monitoring evaluation tests (normal tasks + injected attacks) using three open-source model families as the agent.

# Approach Outline

Run the same set of monitoring evaluation tests (normal tasks + injected attacks) using three open-source model families as the agent. Keep the monitoring classifier constant. Measure per-family detection rates and false positive rates.
