# Research Question

AI cyber evaluation benchmarks measure end-to-end task completion without decomposing which specific skills each task exercises. This project investigates whether apply job task analysis methodology: interview 3-5 expert pentesters to elicit the skill taxonomy of a full corporate network attack (minimum viable competency list per att&ck phase).

# Approach Outline

Apply job task analysis methodology: interview 3-5 expert pentesters to elicit the skill taxonomy of a full corporate network attack (minimum viable competency list per ATT&CK phase). Translate each skill into a measurable test (not a full task — just the isolated skill). Build a 40-item skill battery. Run AI models on the battery and compare skill profiles to end-to-end performance.

# Proposed First Experiments

- Conduct a systematic literature review to identify and categorize relevant prior work.
- Develop a classification framework and apply it to the collected corpus.
- Synthesize findings into a structured analysis with key takeaways for the AI safety community.

# Theory of Impact Chain

A validated skill decomposition enables: (1) targeted capability elicitation for safety evaluations, (2) identification of which skill gaps will be filled next by scaling, (3) cross-evaluation comparability regardless of which end-to-end task was used.
