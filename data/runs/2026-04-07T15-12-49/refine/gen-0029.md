# Research Question

All major published AI cyber evaluations use on-premise or simulated network environments. This project investigates whether set up a free-tier cloud environment (aws free tier) with deliberately misconfigured iam policies, public s3 buckets, and an exposed ec2 instance.

# Approach Outline

Set up a free-tier cloud environment (AWS free tier) with deliberately misconfigured IAM policies, public S3 buckets, and an exposed EC2 instance. Run AI agents on a 5-step cloud attack chain (enumeration → IAM exploitation → lateral movement → data exfiltration) and compare solve rates to equivalent on-premise network chains. Note which cloud-specific steps fail.
