# Research Question

When models produce visible chain-of-thought reasoning (thinking tokens), evaluators can observe attack planning in progress. This project investigates whether run 15 ctf challenges on the same model under: (a) full visible cot (thinking tokens exposed), (b) hidden cot (model produces reasoning internally but only final output is visible), (c) no cot (direct answer only).

# Approach Outline

Run 15 CTF challenges on the same model under: (A) full visible CoT (thinking tokens exposed), (B) hidden CoT (model produces reasoning internally but only final output is visible), (C) no CoT (direct answer only). Measure solve rates per condition. Test whether visible CoT produces significantly different solve rates than hidden CoT, controlling for total compute.

# Theory of Impact Chain

If visible CoT does not change capability but allows monitoring of reasoning content, CoT visibility is a net safety benefit with no performance cost. If hiding CoT improves performance, models are being modestly constrained by the visibility requirement — and removing that constraint (e.g., models that internally think without exposing reasoning) would increase real-world capability beyond what evaluators can observe.
