# Research Question

AI vulnerability detectors perform well on benchmark datasets but their boundary conditions (code complexity, obfuscation, language, age of code) are not well characterized. This project investigates whether take a set of 30 known vulnerabilities.

# Approach Outline

Take a set of 30 known vulnerabilities. Systematically vary: (a) degree of code obfuscation, (b) programming language (Python vs. C vs. Java), (c) code age proxy (commit date). Measure detection rate as a function of each variable using a fixed LLM. Report boundary conditions.
