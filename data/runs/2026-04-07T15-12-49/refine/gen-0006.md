This project investigates whether select 3-5 challenges per att&ck tactic (reconnaissance, initial access, execution, persistence, privilege escalation, lateral movement, collection, exfiltration, impact) from public ctf archives.

# Approach Outline

Select 3-5 challenges per ATT&CK tactic (Reconnaissance, Initial Access, Execution, Persistence, Privilege Escalation, Lateral Movement, Collection, Exfiltration, Impact) from public CTF archives. Run 3-4 frontier API models. Produce a radar chart of solve rates per tactic per model. Statistically test which tactic × model combinations show significant underperformance.
