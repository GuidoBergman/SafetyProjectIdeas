# Research Question

OpenAI Trusted Access includes an invite-only tier for researchers. This project investigates whether infer the implicit criteria from openai trusted access announcement language and analogous programs (cern beam time allocation, nih select agent access).

# Approach Outline

Infer the implicit criteria from OpenAI Trusted Access announcement language and analogous programs (CERN beam time allocation, NIH select agent access). Design a rubric for researcher access decisions. Test the rubric on 20 hypothetical applicant profiles varying on h-index, affiliation, publication venue, and research purpose. Assess rubric consistency.
