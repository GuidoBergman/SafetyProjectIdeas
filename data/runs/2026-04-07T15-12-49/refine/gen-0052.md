# Research Question

AI agents often fail at tool invocation steps (wrong parameters, misunderstood output) rather than at reasoning steps. This project investigates whether take 5 standard security tools (nmap, gobuster, sqlmap, netcat, john).

# Approach Outline

Take 5 standard security tools (nmap, gobuster, sqlmap, netcat, john). Create two versions of documentation: (A) standard man page / default help text, (B) AI-optimized documentation with explicit input/output format, common failure modes, and example completions. Run AI agents on 10 CTF challenges with each documentation version. Measure the performance delta attributable to documentation quality.
