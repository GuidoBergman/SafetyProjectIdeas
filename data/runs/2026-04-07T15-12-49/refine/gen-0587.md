# Research Question

Static type analysis (Hindley-Milner, gradual typing) uses inference to detect type errors without explicit annotations. This project investigates whether develop a lightweight static analysis pass for lean 4 specifications that detects: missing preconditions (implied by postconditions), potentially vacuous properties, and missing edge case patterns.

# Approach Outline

Develop a lightweight static analysis pass for Lean 4 specifications that detects: missing preconditions (implied by postconditions), potentially vacuous properties, and missing edge case patterns. Apply to 50 LLM-generated specs. Compare detection rate to manual expert review.
