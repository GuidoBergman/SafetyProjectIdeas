# Research Question

No benchmark combines the two skills needed for Secure Program Synthesis (SPS): (1) generating secure code and (2) formally verifying security properties. This project investigates whether create a 50-task benchmark where each task requires: (a) generating code that passes security review criteria and (b) providing a formal lean 4 proof of a security property.

# Approach Outline

Create a 50-task benchmark where each task requires: (a) generating code that passes security review criteria AND (b) providing a formal Lean 4 proof of a security property. Measure LLM performance on the combined task vs. each sub-task independently. Test whether solving both simultaneously degrades performance on each.
