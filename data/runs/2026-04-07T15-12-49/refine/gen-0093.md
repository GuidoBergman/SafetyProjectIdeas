# Research Question

Regulatory frameworks (EU AI Act, UK voluntary commitments) envision mandatory pre-deployment offensive capability evaluations. This project investigates whether review regulatory requirements for pre-deployment ai evaluation from 3 jurisdictions (eu, uk, us).

# Approach Outline

Review regulatory requirements for pre-deployment AI evaluation from 3 jurisdictions (EU, UK, US). Extract implicit measurement requirements. Translate these into technical evaluation properties (e. g. , 'must detect capability X with Y% sensitivity at Z false positive rate'). Design a minimal evaluation instrument satisfying these properties. Test whether current state-of-the-art evaluations satisfy them.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

Pre-deployment evaluations that don't satisfy basic psychometric properties (reliability, validity, sensitivity) would either miss genuinely dangerous capabilities or block safe deployments. Understanding the gap between required properties and current evaluation quality is urgent for responsible AI governance.
