# Research Question

METR 2026 found vulnerabilities in Anthropic's agent monitoring systems. This project investigates whether implement the categories of monitoring vulnerabilities reported by metr in an open-source monitoring setup.

# Approach Outline

Implement the categories of monitoring vulnerabilities reported by METR in an open-source monitoring setup. Test whether agents naturally exploit monitoring gaps (i. e. , produce dangerous actions more frequently when they occur in monitoring blind spots). Compare dangerous action rates in monitored vs. unmonitored action contexts.
