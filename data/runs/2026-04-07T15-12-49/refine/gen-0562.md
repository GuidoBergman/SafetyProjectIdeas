# Research Question

Much security-critical legacy code has no documentation or specifications. This project investigates whether take 30 well-known open-source c functions with no inline documentation.

# Approach Outline

Take 30 well-known open-source C functions with no inline documentation. Have LLMs: (1) generate natural language descriptions, (2) convert to Lean 4 formal specs, (3) complete proofs. Compare generated specs to expert-written gold specs. Measure accuracy without any documentation as input.
