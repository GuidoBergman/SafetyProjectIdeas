# Research Question

In multi-step network attacks, achieving Domain Admin (DA) is a key milestone after which many subsequent steps become trivially easier (lateral movement, data access, persistence). This project investigates whether design an active directory test environment with 3 credential levels: (1) initial user, (2) local admin, (3) domain admin.

# Approach Outline

Design an Active Directory test environment with 3 credential levels: (1) initial user, (2) local admin, (3) domain admin. Run AI agents starting from each credential level. Measure step completion rate per level. Test whether performance difference between local admin and domain admin starting conditions is significantly larger than between no-access and local-admin starting conditions (testing for discontinuity).

# Theory of Impact Chain

If performance jumps discontinuously at DA-level credentials, then the credential acquisition step is the most important bottleneck. Defenders should concentrate protective effort on preventing credential escalation rather than assuming that initial foothold prevention is sufficient.
