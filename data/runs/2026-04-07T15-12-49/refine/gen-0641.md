# Research Question

AI models are beginning to generate cryptographic code. This project investigates whether ask 3 llms to generate python/rust implementations of aes-256, sha-256, and rsa key generation.

# Approach Outline

Ask 3 LLMs to generate Python/Rust implementations of AES-256, SHA-256, and RSA key generation. For each, attempt to write formal Lean 4/Dafny proofs of: (a) functional correctness against reference, (b) constant-time property (simple model), (c) absence of obvious timing side channels. Measure success rate per property per algorithm.

# Theory of Impact Chain

AI-generated cryptographic code is a critical safety concern. Formally verified cryptographic code is the gold standard. Measuring how far current AI + formal tools are from this standard is essential for deploying AI in security-critical contexts.
