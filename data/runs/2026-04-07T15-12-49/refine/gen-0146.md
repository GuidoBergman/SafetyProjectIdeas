# Research Question

AI vulnerability scanners can be repurposed offensively. This project investigates whether map the causal chain: (1) ai detects vulnerability → (2) vulnerability report generated → (3) report accessed by attacker → (4) exploit developed → (5) exploitation occurs.

# Approach Outline

Map the causal chain: (1) AI detects vulnerability → (2) vulnerability report generated → (3) report accessed by attacker → (4) exploit developed → (5) exploitation occurs. For each link, identify existing controls and gaps. Propose and evaluate (via literature review + small experiment) an intervention at the under-studied link (2→3: access controls on AI security tool outputs).

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain
