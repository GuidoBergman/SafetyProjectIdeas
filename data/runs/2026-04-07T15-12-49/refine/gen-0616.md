# Research Question

The 60% compilation rate and other benchmark scores may be highly sensitive to minor problem variations (different variable names, reordered function arguments). This project investigates whether take 30 veribench problems.

# Approach Outline

Take 30 VeriBench problems. Create 5 semantically equivalent variants of each by: renaming variables, reordering function arguments, changing integer constants, reformatting docstrings. Run the same LLM on all 180 variants. Measure score variance across variants of the same problem.

# Theory of Impact Chain

High score variance across semantically equivalent problems would indicate that Lean 4 performance is not reliably measuring formal reasoning capability — it is sensitive to surface-level representation, which is a significant threat to benchmark validity.
