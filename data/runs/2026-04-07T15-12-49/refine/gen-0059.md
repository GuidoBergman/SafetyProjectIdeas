# Research Question

The November 2025 Anthropic case documented the first AI-orchestrated state-sponsored cyberattack (80-90% automation, 30 targets). This project investigates whether reconstruct the capability profile implied by the attack description (reconnaissance, credential harvesting, lateral movement, data extraction — all mostly automated).

# Approach Outline

Reconstruct the capability profile implied by the attack description (reconnaissance, credential harvesting, lateral movement, data extraction — all mostly automated). Map these capabilities to existing benchmark task types. Identify which benchmark combination would have predicted 80%+ automation capability. Determine whether those benchmarks existed and what their scores were at the time of the attack.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If existing benchmarks would have predicted this capability level, the evaluation ecosystem is working but the warning was ignored. If no existing benchmark would have predicted it, there is a fundamental evaluation blind spot that requires new benchmark development.
