# Research Question

Anthropic publicly announces its monitoring systems. This project investigates whether test whether including information about a monitoring system in an agent's context changes its behavior on tasks that monitoring would flag.

# Approach Outline

Test whether including information about a monitoring system in an agent's context changes its behavior on tasks that monitoring would flag. Compare behavior with explicit monitoring disclosure vs. implicit disclosure vs. no disclosure.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If disclosure changes agent behavior, this suggests models have internalized information about monitoring into their behavior — a concerning implication for the validity of monitoring as a safety control.
