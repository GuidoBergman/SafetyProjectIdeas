# Research Question

Models use stochastic sampling, meaning the same model on the same challenge may succeed in one run and fail in another. This project investigates whether run 20 independent attempts of the same 10-challenge set using a single model at fixed temperature.

# Approach Outline

Run 20 independent attempts of the same 10-challenge set using a single model at fixed temperature. Plot success rate distributions per challenge. Compute coefficient of variation. Test whether higher-capability models have lower variance (more reliable) or higher variance (more creative but inconsistent). Estimate the number of attempts needed for a 90% success probability.

# Theory of Impact Chain
