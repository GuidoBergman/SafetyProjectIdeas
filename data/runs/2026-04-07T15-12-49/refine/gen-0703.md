# Research Question

Agent monitoring can be real-time (blocking actions until approved) or offline (log review after the fact). This project investigates whether implement both real-time and offline monitoring for the same agent pipeline.

# Approach Outline

Implement both real-time and offline monitoring for the same agent pipeline. Run standardized attack scenarios. Compare detection rate, false positive rate, response latency (time-to-block vs. time-to-detect), and computational cost per decision.
