# Research Question

OCCULT's copilot paradigm research used closed frontier APIs. This project investigates whether replicate a simplified copilot experiment (from the earlier copilot amplification idea) using a locally deployed open-weight model (llama 3 70b or qwen 72b via ollama).

# Approach Outline

Replicate a simplified copilot experiment (from the earlier copilot amplification idea) using a locally deployed open-weight model (Llama 3 70B or Qwen 72B via Ollama). Compare: (1) novice human alone, (2) novice + local open-weight model copilot, (3) novice + frontier API model copilot. Measure steps completed in each condition. Compute whether local model copilot provides comparable amplification to frontier model.

# Proposed First Experiments

- Set up the replication environment and reproduce baseline results from the original study.
- Introduce the proposed variation/extension and measure the impact on key metrics.
- Analyze results across conditions, compute effect sizes, and document findings in a blog post.

# Theory of Impact Chain

If local models provide comparable copilot amplification to frontier APIs, the attack surface includes any attacker with consumer hardware — no API access, no usage monitoring, no cost barrier. If local models provide significantly less amplification, frontier API access remains the binding constraint on the copilot threat.
