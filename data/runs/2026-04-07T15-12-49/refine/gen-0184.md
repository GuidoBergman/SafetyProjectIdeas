# Research Question

Individual AI models have consistent blind spots. This project investigates whether run three ai models (claude, gpt-4o, gemini) independently on 20 vulnerable code samples.

# Approach Outline

Run three AI models (Claude, GPT-4o, Gemini) independently on 20 vulnerable code samples. Compute: agreement rate, disagreement patterns, and whether the union of all three models' findings covers more vulnerabilities than any individual model. Measure the marginal detection gain from adding each model.
