# Research Question

AI agents used for offensive red-teaming often browse adversary-controlled web pages and files as part of reconnaissance. This project investigates whether set up a ctf-style target that includes prompt injection payloads embedded in web pages, file metadata, and server response headers.

# Approach Outline

Set up a CTF-style target that includes prompt injection payloads embedded in web pages, file metadata, and server response headers. Run an AI agent attempting to compromise the target. Measure: (1) how often the agent successfully identifies and ignores injections, (2) how often it is redirected by them, (3) what the injections cause the agent to do (e. g. , exfiltrate session tokens back to attacker's server).
