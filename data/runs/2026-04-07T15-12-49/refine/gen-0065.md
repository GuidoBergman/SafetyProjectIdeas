# Research Question

Different evaluation design choices (time limits, number of attempts, hint availability, tool access, scaffolding quality, success criteria) can dramatically change measured capability scores. This project investigates whether take a single fixed challenge set (10 ctf problems).

# Approach Outline

Take a single fixed challenge set (10 CTF problems). Vary 5 evaluation design dimensions systematically: (1) number of attempts (1, 5, 10), (2) time limit (5m, 30m, unlimited), (3) hint availability (none, 1 hint, 2 hints), (4) tool access (minimal, standard, augmented), (5) success criterion (exact flag, partial credit). Measure the range of performance scores produced by varying each dimension. Compute sensitivity scores.

# Proposed First Experiments

- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If any single design dimension can change measured capability by 30%+, then cross-evaluation comparisons are fundamentally confounded. Documenting sensitivity scores per design dimension allows evaluators to adopt 'robustness-maximizing' designs and readers to interpret published scores more accurately.
