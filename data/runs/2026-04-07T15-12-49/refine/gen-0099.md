# Research Question

When comparing Llama, Claude, and GPT performance on the same benchmark, we assume the benchmark measures the same construct for all models. This project investigates whether apply confirmatory factor analysis or a simplified irt-based test of measurement invariance to solve/fail data from 5+ models across a 30-challenge benchmark.

# Approach Outline

Apply confirmatory factor analysis or a simplified IRT-based test of measurement invariance to solve/fail data from 5+ models across a 30-challenge benchmark. Test whether challenge difficulty and discrimination parameters are the same for different model families (configural, metric, and scalar invariance in psychometric terms). Report which invariance assumptions hold and which fail.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If measurement invariance fails across model families, statements like 'Claude is 20% more capable than GPT' at offensive cyber tasks are psychometrically invalid. This would require the field to develop model-family-specific benchmarks or invariant measurement protocols before cross-model comparisons can be made.
