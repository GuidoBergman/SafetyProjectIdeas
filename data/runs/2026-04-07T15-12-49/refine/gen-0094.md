# Research Question

AI models may generate attacks that are highly similar to each other (homogeneous exploits), while human attackers generate more diverse approaches. This project investigates whether generate 50 exploit scripts targeting the same vulnerability using 3 models (using varied seeds/prompts).

# Approach Outline

Generate 50 exploit scripts targeting the same vulnerability using 3 models (using varied seeds/prompts). Generate 20 human-written exploits for the same vulnerability from public exploit databases. Compute code similarity metrics (AST similarity, n-gram similarity, semantic embedding distance) within each group. Test whether AI-generated exploits are significantly more similar to each other than human-generated exploits.

# Theory of Impact Chain

If AI exploits are homogeneous, signature-based defenses gain a systematic advantage against AI attackers. This is a concrete and measurable interaction between model monoculture (in offense) and detection efficiency (in defense). It would be the first empirical test of whether AI homogeneity has a detectable defensive benefit.
