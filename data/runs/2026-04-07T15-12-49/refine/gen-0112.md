# Research Question

OCCULT's TACTL benchmark tests whether models can answer knowledge questions about offensive techniques. This project investigates whether for 20 attack techniques, administer both a 5-item knowledge test (multiple choice, tactl-style) and a practical execution task.

# Approach Outline

For 20 attack techniques, administer both a 5-item knowledge test (multiple choice, TACTL-style) and a practical execution task. Run 5 models on all 40 items. Compute: (1) correlation between knowledge and capability scores per technique, (2) false positive rate (high knowledge, low capability — 'knows but can't do'), (3) false negative rate (low knowledge, high capability — 'can do but can't explain'). Build a 2x2 contingency table per technique.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If knowledge tests are good proxies for capability, OCCULT-style testing is a valid low-cost capability assessment. If the mapping is poor, knowledge tests are misleading. Specifically, models that can execute attacks they claim ignorance about (false negatives) represent a dangerous capability evaluation gap that low-cost knowledge tests would miss.
