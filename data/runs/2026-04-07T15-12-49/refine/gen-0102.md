# Research Question

Two interacting failure modes: (1) AI code generation tools (GitHub Copilot, Cursor) introduce security vulnerabilities in generated code at measurable rates, and (2) developers increasingly accept AI-generated code without security review. This project investigates whether generate 100 code snippets using a coding ai for 5 common security-sensitive tasks (authentication, file upload, database query, api endpoint, session management).

# Approach Outline

Generate 100 code snippets using a coding AI for 5 common security-sensitive tasks (authentication, file upload, database query, API endpoint, session management). Run automated vulnerability scanning (semgrep, bandit, CodeQL) on generated code. Compute vulnerability introduction rate per task type and per model. Compare to a baseline of human-written code for the same tasks drawn from public repositories.

# Theory of Impact Chain

If AI code generation introduces vulnerabilities at significantly higher rates than human coding, and AI offensive tools can exploit these vulnerabilities, the combined effect is an accelerating offense-defense gap: AI creates vulnerabilities faster than humans can patch them. This compound risk is currently unmeasured.
