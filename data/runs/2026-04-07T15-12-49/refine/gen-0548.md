# Research Question

The causal chain from vague specification → underspecified formal spec → incomplete proof → undetected vulnerability has not been empirically measured end-to-end. This project investigates whether take 20 programs with known vulnerabilities.

# Approach Outline

Take 20 programs with known vulnerabilities. Create both (a) precise natural language specs and (b) vague natural language specs. Run both through LLM vericoding pipelines. Measure whether vague specs produce formal proofs that miss the vulnerability. Measure end-to-end spec vagueness → vulnerability escape rate.

# Theory of Impact Chain
