# Research Question

AI labs use benchmark performance to assess harm potential, but the causal path from benchmark score to real-world harmful capability is not empirically documented. This project investigates whether for 3 publicly documented ai-assisted cyberattacks (gtg-1002 equivalents), identify which benchmark tasks correspond to the ai capabilities used.

# Approach Outline

For 3 publicly documented AI-assisted cyberattacks (GTG-1002 equivalents), identify which benchmark tasks correspond to the AI capabilities used. Measure current model benchmark scores on those tasks. Compute the benchmark-to-harm correlation. Identify which benchmark score increases most predict harm potential increase.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If harm potential is driven by specific benchmark dimensions, governance thresholds keyed to those dimensions would be more precise than current broad cybersecurity tier classifications.
