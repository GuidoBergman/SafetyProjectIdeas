# Research Question

Reconnaissance quality is a prerequisite for downstream attack success, but is rarely evaluated as a standalone capability. This project investigates whether set up a known-state virtual target (metasploitable 2/3, dvwa, or vulnhub vms) with exactly n documented vulnerabilities.

# Approach Outline

Set up a known-state virtual target (Metasploitable 2/3, DVWA, or VulnHub VMs) with exactly N documented vulnerabilities. Run AI agents and measure: (a) true positive rate (found documented vulnerabilities), (b) false positive rate (reported non-existent vulnerabilities), (c) completeness vs. severity. Compare across 3-4 models.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If AI reconnaissance has high false positive rates, it generates noise that overwhelms defenders. If it has systematic blind spots in specific service types, defenders know where to invest. Precision/recall metrics are more actionable than aggregate solve rates.
