# Research Question

Two interacting failures: (1) defenders over-rely on AI security tools (automation bias); (2) attackers can evade AI scanners through code obfuscation or adversarial perturbations. This project investigates whether demonstrate the compound risk: (a) show that a public ai vulnerability scanner can be evaded by simple obfuscation (rename variables, split functions); (b) run a user study showing that when ai says 'no vulnerabilities found,' users perform fewer manual checks.
