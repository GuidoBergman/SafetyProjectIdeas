# Research Question

Two interacting failures: (1) AI code review tools are vulnerable to prompt injection via malicious comments in code; (2) security reports from these tools are trusted by defenders. This project investigates whether design and test prompt injection attacks targeting an ai code review tool: embed adversarial instructions in code comments or docstrings that cause the ai to (a) omit a real vulnerability from its report, (b) report a false positive in clean code.

# Approach Outline
