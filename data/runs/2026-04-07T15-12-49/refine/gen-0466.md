# Research Question

STRIDE (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege) is the standard threat modeling framework for software systems. This project investigates whether apply stride to three representative agentic pipeline architectures (single agent with tools, multi-agent with orchestrator, rag-augmented agent).

# Approach Outline

Apply STRIDE to three representative agentic pipeline architectures (single agent with tools, multi-agent with orchestrator, RAG-augmented agent). For each STRIDE category, identify the AI-specific threat instances. Evaluate which categories have existing controls and which are unaddressed. Produce a gap analysis.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

STRIDE is used by security teams globally. Producing a formal STRIDE analysis for agentic AI would give practitioners a familiar framework for reasoning about AI security, lowering the adoption barrier for AI security practices.
