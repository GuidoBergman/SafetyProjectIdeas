# Research Question

Two interacting failure modes: (1) AI offensive agents are vulnerable to prompt injection from adversarial content in their environment, and (2) red team AI agents browse target systems containing adversarial content. This project investigates whether design a 'honeypot' ctf scenario where a target system contains prompt injection payloads in robot.

# Approach Outline

Design a 'honeypot' CTF scenario where a target system contains prompt injection payloads in robot. txt, web page source, and service banners. Run an AI red team agent against the target and measure: (a) how often it is successfully hijacked, (b) what the injection causes it to do (ignore target, report false data back, expose attack infrastructure), (c) whether chain-of-thought scratchpad reveals injection detection.

# Theory of Impact Chain

This is a novel defensive countermeasure strategy: defenders can make their systems 'injection-booby-trapped' to neutralize AI red team agents. Demonstrating this works empirically would be a significant defensive contribution, and measuring the reliability of this countermeasure informs its deployability.
