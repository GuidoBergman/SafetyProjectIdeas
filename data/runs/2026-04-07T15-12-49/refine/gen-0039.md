# Research Question

AI security vendors (CrowdStrike, Microsoft Copilot for Security, Vectra AI) make capability claims for both offensive red-teaming and defensive detection products. This project investigates whether survey publicly available capability claims from 5-10 ai security vendors.

# Approach Outline

Survey publicly available capability claims from 5-10 AI security vendors. Identify the minimum evaluation protocol that would make each claim falsifiable. Design a standardized 'vendor claims verification checklist' with 10-15 specific test scenarios. Run a pilot test of one vendor's publicly claimed capability against this checklist using their API.

# Proposed First Experiments

- Conduct a systematic literature review to identify and categorize relevant prior work.
- Develop a classification framework and apply it to the collected corpus.
- Synthesize findings into a structured analysis with key takeaways for the AI safety community.

# Theory of Impact Chain

Unverifiable vendor claims create market failures in AI security — buyers cannot compare products, false claims go unchallenged, and regulators cannot set standards. A standardized verification protocol would enable meaningful competition and regulatory oversight.
