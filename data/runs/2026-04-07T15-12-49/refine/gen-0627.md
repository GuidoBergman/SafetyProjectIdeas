# Research Question

Formal verification is typically a batch research activity. This project investigates whether implement a github actions workflow that: (a) on each code change, uses an llm to generate/update a lean 4 property check, (b) runs lean verification, (c) blocks merge if verification fails.

# Approach Outline

Implement a GitHub Actions workflow that: (a) on each code change, uses an LLM to generate/update a Lean 4 property check, (b) runs Lean verification, (c) blocks merge if verification fails. Test on a small open-source project for 2 weeks. Measure: overhead, false block rate, and bugs caught.
