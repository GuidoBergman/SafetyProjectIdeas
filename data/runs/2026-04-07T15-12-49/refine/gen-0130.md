# Research Question

No taxonomy exists of the ways AI-powered defensive tools fail: missed vulnerabilities, hallucinated vulnerabilities, incorrect explanations, partial patches, etc. This project investigates whether collect 100+ ai-generated vulnerability reports and patches from public bug bounty write-ups and open-source project issue trackers.

# Approach Outline

Collect 100+ AI-generated vulnerability reports and patches from public bug bounty write-ups and open-source project issue trackers. Manually classify failure modes. Build a failure taxonomy with frequency distributions and an illustrative dataset.

# Proposed First Experiments

- Conduct a systematic literature review to identify and categorize relevant prior work.
- Develop a classification framework and apply it to the collected corpus.
- Synthesize findings into a structured analysis with key takeaways for the AI safety community.

# Theory of Impact Chain

A taxonomy enables targeted improvement. Safety-relevant: AI tools deployed at scale with uncharacterized failure modes pose risk, especially if they create false confidence.
