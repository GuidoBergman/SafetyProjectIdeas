# Research Question

When a monitor fails to flag a dangerous action, the cause could be: bad monitoring prompt, wrong choice of monitoring model, or incorrect threshold. This project investigates whether collect a set of monitoring failures (false negatives).

# Approach Outline

Collect a set of monitoring failures (false negatives). For each failure, ablate the three components: vary the monitoring prompt, swap the monitoring model, adjust the threshold. Quantify how much variance in failure rate each component explains.
