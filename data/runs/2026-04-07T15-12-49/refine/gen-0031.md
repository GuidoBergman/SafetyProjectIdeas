# Research Question

Real-world malware and exploit code is heavily obfuscated. This project investigates whether take 10 known-vulnerable code snippets (buffer overflows, use-after-free, sql injection).

# Approach Outline

Take 10 known-vulnerable code snippets (buffer overflows, use-after-free, SQL injection). Create 3 versions of each: (1) clean, (2) lightly obfuscated (variable renaming, dead code insertion), (3) heavily obfuscated (string encryption, control flow flattening). Run 3-4 models and plot vulnerability-detection accuracy as a function of obfuscation level. Identify whether there is a threshold obfuscation level that reliably defeats AI analysis.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If defenders can use obfuscation to reliably prevent AI from finding vulnerabilities in critical code, this is an actionable defensive recommendation. If AI is obfuscation-resistant, this changes the threat model for source code security.
