# Research Question

AI security tools produce ranked alert lists, but the calibration of these rankings (how well confidence scores map to actual threat probability) is not evaluated. This project investigates whether run an ai vulnerability scanner on a corpus of 50 code files (25 with known vulnerabilities, 25 clean).

# Approach Outline

Run an AI vulnerability scanner on a corpus of 50 code files (25 with known vulnerabilities, 25 clean). Record the scanner's confidence scores. Compute ROC curves, AUC, and calibration curves (reliability diagrams). Compare calibration across tools.
