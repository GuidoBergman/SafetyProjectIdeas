# Research Question

Success state: a multi-agent orchestration system where no agent can take actions outside its authorized scope, even if compromised. This project investigates whether define the security properties of ideal multi-agent orchestration.

# Approach Outline

Define the security properties of ideal multi-agent orchestration. Work backward to identify necessary architectural constraints (explicit permission manifests, inter-agent message signing, action sandboxing). Prototype the constraints in a simple multi-agent system and measure utility impact.
