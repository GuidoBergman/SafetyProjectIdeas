# Research Question

Software Fault Isolation is a mature OS security technique for confining untrusted code to specific memory regions. This project investigates whether implement an sfi-inspired capability sandbox for a python agent: each tool is wrapped in a permission boundary, cross-boundary calls are logged and optionally blocked.

# Approach Outline

Implement an SFI-inspired capability sandbox for a Python agent: each tool is wrapped in a permission boundary, cross-boundary calls are logged and optionally blocked. Measure whether this reduces successful unauthorized tool invocations without degrading task completion on benign tasks. Test on three scenarios from Irregular 2026.
