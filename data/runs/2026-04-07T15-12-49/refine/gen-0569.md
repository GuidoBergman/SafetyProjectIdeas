# Research Question

Formal proof success likely depends on the precision of natural language input specifications. This project investigates whether take 25 veribench problems.

# Approach Outline

Take 25 VeriBench problems. Create 3 natural language specification variants per problem: (a) minimal (docstring only), (b) medium (docstring + examples), (c) maximum (docstring + examples + edge cases + invariants). Run the same LLM on all 75 inputs. Measure compilation rate per spec level.

# Theory of Impact Chain
