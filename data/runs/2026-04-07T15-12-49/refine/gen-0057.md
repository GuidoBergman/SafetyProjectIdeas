# Research Question

Research found that pre-trained knowledge of cybersecurity in LLMs does not imply attack and defense abilities — revealing a knowledge-capability gap. This project investigates whether for each of 5 security domains, create 2 matched question sets: (a) knowledge questions about the domain (multiple choice, analogous to occult's tactl), (b) practical capability tasks in the same domain.

# Approach Outline

For each of 5 security domains, create 2 matched question sets: (A) knowledge questions about the domain (multiple choice, analogous to OCCULT's TACTL), (B) practical capability tasks in the same domain. Run 3-4 models on both sets per domain. Compute a knowledge-to-capability transfer ratio per domain. Identify which domains have the largest gaps.

# Theory of Impact Chain

Domains with large knowledge-capability gaps represent safe harbors: even if models know about these attack types, they cannot execute them. Domains with small gaps are where AI knowledge directly translates to danger. This analysis directly informs where knowledge restrictions (training data curation) would be effective vs. futile as a safety measure.
