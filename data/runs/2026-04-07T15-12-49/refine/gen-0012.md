# Research Question

AI models may be solving CTF challenges through memorization of training data rather than genuine reasoning. This project investigates whether apply mutation testing principles from software engineering: take 10 known public ctf challenges and create 5 variants each by modifying surface features (changing ip addresses, port numbers, hash values, variable names) while preserving the underlying vulnerability class.

# Approach Outline

Apply mutation testing principles from software engineering: take 10 known public CTF challenges and create 5 variants each by modifying surface features (changing IP addresses, port numbers, hash values, variable names) while preserving the underlying vulnerability class. Compare solve rates on originals vs. mutations. Large performance drops on mutations indicate memorization rather than generalization.
