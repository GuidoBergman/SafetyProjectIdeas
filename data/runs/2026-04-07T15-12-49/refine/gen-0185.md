# Research Question

Technical debt is a software engineering concept for deferred maintenance. This project investigates whether define a security debt metric: weighted sum of (vulnerability severity × age × exploitability × patch availability).

# Approach Outline

Define a security debt metric: weighted sum of (vulnerability severity × age × exploitability × patch availability). Use an LLM to compute this metric for 10 open-source projects. Validate by correlating security debt score with subsequent breach/CVE history. Compute inter-rater reliability of AI-generated scores.
