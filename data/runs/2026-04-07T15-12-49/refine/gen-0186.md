# Research Question

AI defense tools are typically evaluated against known vulnerabilities. This project investigates whether design a red-team experiment: have one ai model (attacker) generate obfuscated versions of vulnerable code designed to evade detection.

# Approach Outline

Design a red-team experiment: have one AI model (attacker) generate obfuscated versions of vulnerable code designed to evade detection. Have another AI model (defender) attempt to detect the obfuscated vulnerabilities. Measure detection rate degradation vs. non-obfuscated baseline. Iterate for two obfuscation levels.
