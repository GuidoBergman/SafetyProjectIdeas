# Research Question

Runtime injection attacks typically affect a single session. This project investigates whether set up an agent with a persistent memory store (simple vector db of past interactions).

# Approach Outline

Set up an agent with a persistent memory store (simple vector DB of past interactions). Execute a runtime injection that embeds adversarial instructions in memory (e. g. , a summarized past task that includes an embedded rule). In subsequent sessions with no active injection, measure whether the stored adversarial instruction influences agent behavior.

# Theory of Impact Chain

If runtime injections can persist via memory poisoning, the attack surface of agentic systems extends far beyond individual sessions. Memory systems require security controls analogous to persistent storage in traditional security.
