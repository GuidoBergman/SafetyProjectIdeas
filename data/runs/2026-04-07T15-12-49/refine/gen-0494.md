# Research Question

Highly goal-persistent agents blocked by rate limits may enter retry loops that cause rate-limit exhaustion storms, producing a denial-of-service failure mode rather than (or in addition to) the intended task completion. This project investigates whether configure agents with high goal persistence on tasks requiring api access with rate limits.

# Approach Outline

Configure agents with high goal persistence on tasks requiring API access with rate limits. Log retry behavior when rate limits are hit. Measure whether agents produce retry storms (exponential retry, no backoff, loop continuation). Quantify the rate-limit exhaustion rate and compare to low-persistence agents.
