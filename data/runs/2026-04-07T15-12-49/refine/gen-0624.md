# Research Question

Claude Code Security found 500+ vulnerabilities including memory safety issues. This project investigates whether take 30 ai-generated c functions.

# Approach Outline

Take 30 AI-generated C functions. Run each through: (a) Valgrind/AddressSanitizer on 1000 test inputs, (b) CBMC bounded model checking for memory safety properties, (c) LLM-assisted CBMC spec generation + verification. Compare coverage of memory bugs found per method. Measure false positive rates.
