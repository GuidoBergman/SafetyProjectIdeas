# Research Question

Published AI cyber evaluations require either expensive proprietary infrastructure (AISI cyber ranges) or large frontier API budgets. This project investigates whether design a complete evaluation protocol using only: free-tier ctf platforms (tryhackme, hackthebox free), open-weight models (ollama on consumer hardware), and api access with <$50 cost (smaller models).

# Approach Outline

Design a complete evaluation protocol using only: free-tier CTF platforms (TryHackMe, HackTheBox free), open-weight models (Ollama on consumer hardware), and API access with <$50 cost (smaller models). Test the protocol end-to-end on 10 challenges. Validate that results correlate with published frontier model benchmarks (convergent validity check). Document all choices needed to replicate the protocol.

# Theory of Impact Chain

Democratizing evaluation capability would enable the global research community to independently verify capability claims, track changes over time, and identify emergent capabilities. Currently, safety evaluation is concentrated in a few well-resourced labs — a concentration that creates governance risks.
