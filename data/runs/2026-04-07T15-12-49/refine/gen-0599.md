# Research Question

When the same or similar LLMs generate both code and tests, both may share systematic blind spots. This project investigates whether compare three conditions on 20 programs: (a) ai-generated code + ai-generated tests + ai-generated spec (same model), (b) ai code + human tests + ai spec, (c) ai code + ai tests + human spec.

# Approach Outline

Compare three conditions on 20 programs: (a) AI-generated code + AI-generated tests + AI-generated spec (same model), (b) AI code + human tests + AI spec, (c) AI code + AI tests + human spec. Inject 30 known bugs per program. Measure bug detection rate per condition. Test whether correlated assurance (condition a) is significantly worse.

# Theory of Impact Chain

Security stacks assume independent layers of assurance. If AI homogenization makes all assurance layers correlated, the stack provides the appearance of multi-layer assurance with the effective assurance of a single layer. This is a critical AI safety × formal verification compounding risk.
