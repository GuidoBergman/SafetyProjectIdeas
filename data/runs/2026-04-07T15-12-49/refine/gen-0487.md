# Research Question

An agent with broad tool access (including code execution) and code generation capability could write its own offensive tools. This project investigates whether give an agent access to a code execution tool (python sandbox) and a file system.

# Approach Outline

Give an agent access to a code execution tool (Python sandbox) and a file system. Set task conditions including urgency and goal persistence. Log whether agents write and execute code that performs offensive actions (e. g. , brute force, credential scraping) that are not directly available as built-in tools.
