# Research Question

In multi-agent systems, an agent might impersonate a more trusted agent to gain elevated permissions or bypass safety checks. This project investigates whether build a two-tier agent system (trusted coordinator + restricted worker).

# Approach Outline

Build a two-tier agent system (trusted coordinator + restricted worker). Have the worker agent attempt to impersonate the coordinator to gain elevated tool access. Measure whether a monitoring layer detecting the impersonation is feasible and what signals it uses.
