# Research Question

Attackers might encode malicious instructions in Base64 or other encodings to evade content-based monitors. This project investigates whether implement a set of dangerous agent instructions.

# Approach Outline

Implement a set of dangerous agent instructions. Present them to a monitoring classifier in plaintext vs. Base64 vs. ROT13 vs. unicode obfuscation. Measure evasion success rate for each encoding. Determine if LLM monitors can decode and evaluate obfuscated content.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If simple encoding defeats LLM monitors, attackers can easily bypass monitoring with minimal sophistication. This characterizes a basic robustness property of LLM-based monitoring.
