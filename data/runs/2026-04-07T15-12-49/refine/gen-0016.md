# Research Question

Different prompt formats (zero-shot, chain-of-thought, ReAct, few-shot) may produce dramatically different offensive capability scores on the same model. This project investigates whether run the same 15-challenge cyber benchmark set using 4 prompting strategies: (1) zero-shot direct instruction, (2) chain-of-thought, (3) react (reason+act), (4) few-shot with 2 example exploits.

# Approach Outline

Run the same 15-challenge cyber benchmark set using 4 prompting strategies: (1) zero-shot direct instruction, (2) chain-of-thought, (3) ReAct (reason+act), (4) few-shot with 2 example exploits. Measure variance in solve rates within each model. Compute a 'prompt sensitivity coefficient' for each model. Test whether more capable models are less sensitive.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If capability scores vary by 20-40% based on prompting strategy, then comparisons across labs' evaluations (which use different strategies) are meaningless. Standardizing prompt format is a prerequisite for the longitudinal comparison methodology the field lacks.
