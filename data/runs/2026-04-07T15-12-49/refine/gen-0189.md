# Research Question

AI-generated code has specific vulnerability patterns (Veracode: 45% vulnerable). This project investigates whether generate 25 code samples using copilot/claude code for the same functionality.

# Approach Outline

Generate 25 code samples using Copilot/Claude Code for the same functionality. For each, also get a human-written version from open-source. Run AI vulnerability scanners on both versions. Compare: detection rate, false positive rate, vulnerability class distribution. Test whether AI-generated code has different scanner performance.
