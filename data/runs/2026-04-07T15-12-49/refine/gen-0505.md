# Research Question

LLMs generating Lean 4 proofs may hallucinate theorem statements that are syntactically valid but semantically trivial, vacuously true, or tautological — formal proof of a useless property. This project investigates whether curate a test set of 100 programs with known security properties.

# Approach Outline

Curate a test set of 100 programs with known security properties. Ask LLMs to generate Lean 4 theorem statements capturing those properties. Classify outputs as: correctly capturing the target property, vacuously true, semantically trivial, or wrong. Measure rates.

# Theory of Impact Chain
