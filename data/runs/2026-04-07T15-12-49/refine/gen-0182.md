# Research Question

LLM-enhanced fuzzing (PromeFuzz, ChatAFL) shows coverage improvements in general. This project investigates whether run standard afl++ and llm-enhanced fuzzing (using a gpt-4o-guided seed generator) on 5 open-source c libraries with known cves.

# Approach Outline

Run standard AFL++ and LLM-enhanced fuzzing (using a GPT-4o-guided seed generator) on 5 open-source C libraries with known CVEs. Measure: (a) general code coverage, (b) coverage of security-critical paths (identified by security annotations or manual review), (c) vulnerability detection rate. Compare security-critical coverage vs. general coverage improvement.
