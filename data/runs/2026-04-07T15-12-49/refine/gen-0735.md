# Research Question

METR patched several vulnerabilities found in Anthropic's monitoring. This project investigates whether implement a simple monitoring system.

# Approach Outline

Implement a simple monitoring system. Apply a bypass attack. Patch the vulnerability. Attempt to find new bypass vectors in the patched system. Repeat for 3-5 rounds. Measure whether patching reliably reduces total attack surface or merely shifts it.
