# Research Question

The practical cost of adding formal verification to AI-generated code (in time, compute, tokens) has not been measured. This project investigates whether measure end-to-end time and token usage for: (a) standard code generation (no verification), (b) code generation + lean 4 compilation, (c) code generation + full formal proof.

# Approach Outline

Measure end-to-end time and token usage for: (a) standard code generation (no verification), (b) code generation + Lean 4 compilation, (c) code generation + full formal proof. Run on 40 VeriBench tasks. Compute median overhead per condition. Survey developers on acceptable overhead thresholds.

# Theory of Impact Chain

If formal verification adds 10x overhead, it will not be adopted in standard workflows regardless of safety benefits. If it adds only 2x, adoption becomes viable. This practical measurement is missing from the literature.
