# Research Question

No defensive benchmark equivalent to offensive ones (Cybench, AIxCC) exists. This project investigates whether design and evaluate a small-scale benchmark of n=50 real code snippets (drawn from public cve datasets) comparing ai-assisted detection rates, false positive rates, and time-to-triage across multiple llms in a controlled experiment.

# Approach Outline

Design and evaluate a small-scale benchmark of N=50 real code snippets (drawn from public CVE datasets) comparing AI-assisted detection rates, false positive rates, and time-to-triage across multiple LLMs in a controlled experiment.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

Without defensive baselines, the field cannot track progress, compare tools, or justify investments. A student-scale prototype demonstrates methodology for a larger community effort.
