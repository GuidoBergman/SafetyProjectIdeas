# Research Question

Formal specifications often assume ASCII or simple string models. This project investigates whether take 15 formally verified string-processing functions (validators, parsers).

# Approach Outline

Take 15 formally verified string-processing functions (validators, parsers). Test them with: (a) ASCII inputs (standard), (b) Unicode inputs (emojis, CJK characters), (c) adversarial Unicode (RTL overrides, homoglyphs). Check whether formal proofs cover these cases. Measure violation rate.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.

- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

Internationalization bugs are a major source of security vulnerabilities (filename traversal via Unicode normalization, RTL spoofing attacks). If formal specs systematically omit Unicode edge cases, they miss a significant class of security failures.
