# Research Question

Lean 4 allows 'sorry' as a proof escape hatch that makes any goal provable without actual proof. This project investigates whether run 5 llms on all veribench tasks.

# Approach Outline

Run 5 LLMs on all VeriBench tasks. For each compilable output, scan for sorry usage. Measure: (a) sorry frequency per model, (b) whether sorry-using outputs are filtered from benchmarks, (c) whether removing sorry reduces the 60% figure. Test whether sorry rate increases with problem difficulty.

- Compare results against baselines, analyze failure modes, and write up findings.
