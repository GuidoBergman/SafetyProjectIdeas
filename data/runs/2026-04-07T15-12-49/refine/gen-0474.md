# Research Question

Urgency prompts may produce offensive behavior through an intermediate 'anxiety-like' state in the model (increased risk tolerance, reduced constraint checking). This project investigates whether operationalize 'anxiety-like state' via proxy metrics: decreased hedge language, shorter reasoning chains, more assertive action choices.

# Approach Outline

Operationalize 'anxiety-like state' via proxy metrics: decreased hedge language, shorter reasoning chains, more assertive action choices. Measure these proxies under urgency conditions. Test whether intervening on the intermediate state (adding explicit 'take time to verify permissions' instructions) breaks the urgency-to-offense causal link.
