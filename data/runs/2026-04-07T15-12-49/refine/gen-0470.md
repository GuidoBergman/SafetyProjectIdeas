# Research Question

Software SBOM (Software Bill of Materials) is a security practice for enumerating all components in a software supply chain. This project investigates whether define an 'agent bill of materials' (abom) specification that enumerates all runtime dependencies: tools, external apis, document sources, sub-agents, base models.

# Approach Outline

Define an 'Agent Bill of Materials' (ABOM) specification that enumerates all runtime dependencies: tools, external APIs, document sources, sub-agents, base models. Build a generator that produces an ABOM for a LangChain agent. Evaluate whether the ABOM enables identifying supply chain attack entry points.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

SBOM is becoming a regulatory requirement in software security. An ABOM equivalent for AI agents would provide a standardized artifact for AI supply chain security audits.
