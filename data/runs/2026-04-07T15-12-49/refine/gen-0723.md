# Research Question

Monitoring checkpoints (points where agent actions are reviewed before proceeding) reduce dwell time but add overhead. This project investigates whether run agents on multi-step tasks with attack injections at various steps.

# Approach Outline

Run agents on multi-step tasks with attack injections at various steps. Test monitoring at different checkpoint frequencies (every action, every 3 actions, every 10 actions, only at task boundaries). Measure dwell time and overhead for each frequency.
