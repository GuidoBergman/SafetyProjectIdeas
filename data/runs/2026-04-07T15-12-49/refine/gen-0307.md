# Research Question

No benchmark exists to evaluate the quality and coverage of AI governance frameworks (RSP, Preparedness Framework, EU GPAI Code) against a standardized set of dual-use cybersecurity scenarios. This project investigates whether build a 100-scenario benchmark covering: (a) novel malware generation, (b) reconnaissance automation, (c) vulnerability discovery, (d) credential harvesting, (e) disinformation-supported intrusions.

# Approach Outline

Build a 100-scenario benchmark covering: (a) novel malware generation, (b) reconnaissance automation, (c) vulnerability discovery, (d) credential harvesting, (e) disinformation-supported intrusions. Score each published governance framework against each scenario for coverage, specificity, and testability.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

Governance frameworks are currently evaluated qualitatively by reading. A structured benchmark would enable comparative, reproducible assessment and reveal coverage gaps.
