# Research Question

When code is labeled as 'formally verified', human reviewers may reduce scrutiny due to overreliance on the verification certificate. This project investigates whether conduct a user study with 20 cs students.

# Approach Outline

Conduct a user study with 20 CS students. Present code review tasks: (a) code with no verification label, (b) code with 'formally verified' label but containing a subtle spec error. Measure time spent reviewing, error detection rate, and confidence ratings per condition. Test for automation bias effect.

# Proposed First Experiments

- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

Automation bias is documented for checklist-based safety systems (aviation). If 'formally verified' labels cause reviewers to trust AI-generated code with subtly wrong specs, the combination of false assurance + reduced scrutiny is worse than no formal verification.
