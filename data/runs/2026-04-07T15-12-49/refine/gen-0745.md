# Research Question

Monitoring systems are often deployed without any stated probabilistic guarantee on detection rates. This project investigates whether build a simple monitoring system.

# Approach Outline

Build a simple monitoring system. Conduct systematic attack testing across a diverse attack set (N=100+ attacks from different categories). Compute empirical detection probability with confidence intervals. Report the honest worst-case guarantee achievable by the system.
