# Research Question

LLM outputs are stochastic. This project investigates whether run the same 20 vulnerability detection prompts at temperature 0, 0.

# Approach Outline

Run the same 20 vulnerability detection prompts at temperature 0, 0. 5, and 1. 0 using the same LLM. For each (sample, temperature) combination, run N=10 trials. Measure: verdict consistency rate, false positive rate variance, explanation consistency. Report optimal temperature for stable security verdicts.
