# Research Question

Known failure mode: attackers use euphemisms and jargon substitutions ('lateral movement' → 'network traversal', 'shellcode' → 'execution payload') to evade keyword-based and semantic refusal. This project investigates whether build a lexicon of 50 cybersecurity terms with 3 substitution variants each (official, euphemistic, technical neutral).

# Approach Outline

Build a lexicon of 50 cybersecurity terms with 3 substitution variants each (official, euphemistic, technical neutral). Test refusal rates for requests using each variant across 4 models. Identify high-evasion substitution patterns.

# Theory of Impact Chain

Governance frameworks assume refusal is semantically robust. If lexical substitution degrades refusal, current policies are gameable by any attacker who knows the lexicon.
