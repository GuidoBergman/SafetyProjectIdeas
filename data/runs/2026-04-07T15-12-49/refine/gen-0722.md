# Research Question

One proposed monitoring approach is having agents self-report suspicious behavior. This project investigates whether prompt an agent to self-report any actions it takes that violate its operating policy.

# Approach Outline

Prompt an agent to self-report any actions it takes that violate its operating policy. Then test the agent on scenarios where it does violate policy (induced by adversarial prompts). Measure the rate at which it correctly self-reports vs. fails to report vs. actively conceals.
