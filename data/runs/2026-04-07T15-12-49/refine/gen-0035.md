# Research Question

Two interacting failure modes: (1) AI offensive capability is rapidly advancing, and (2) model homogeneity means attackers and defenders are using similar or identical base models. This project investigates whether set up a red-blue simulation where both the offensive agent and the defensive classifier are running the same base model (same api, different system prompts).

# Approach Outline

Set up a red-blue simulation where both the offensive agent and the defensive classifier are running the same base model (same API, different system prompts). Compare to a condition where they run different models. Measure whether model identity match between attacker and defender changes success rates, suggesting the attacker can predict defender detection logic.
