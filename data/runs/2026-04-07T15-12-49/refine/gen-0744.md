# Research Question

Fuzz testing (automated generation of edge-case inputs) is standard in traditional software security but has not been applied to AI agent monitoring systems. This project investigates whether implement an llm-based fuzzer that generates edge-case agent action sequences designed to find monitoring failures (both false positives and false negatives).

# Approach Outline

Implement an LLM-based fuzzer that generates edge-case agent action sequences designed to find monitoring failures (both false positives and false negatives). Run the fuzzer against a simple monitoring system. Catalog discovered edge cases.
