# Research Question

Two interacting failures: (1) AI code generation tools introduce vulnerabilities 45% of the time (Veracode 2025); (2) AI vulnerability detectors have zero-shot accuracy of ~37%. This project investigates whether quantify the compound risk: generate 50 code snippets using copilot/claude code.

# Approach Outline

Quantify the compound risk: generate 50 code snippets using Copilot/Claude Code. Run AI vulnerability scanners on the same AI-generated code. Measure what fraction of AI-introduced vulnerabilities are caught by AI scanners. Compute net vulnerability accumulation rate.

# Proposed First Experiments

- Define the experimental setup: select datasets, models, and evaluation metrics appropriate for the research question.
- Implement and run the core experiment, collecting measurements on the defined metrics.
- Analyze results, compare with expected outcomes, and document findings in a well-structured blog post.

# Theory of Impact Chain

If AI generates code faster than AI detects its own vulnerabilities, the attack surface grows. This is a critical compounding risk in AI-augmented development.
