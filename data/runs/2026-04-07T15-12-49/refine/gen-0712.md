# Research Question

In multi-agent systems, a compromised agent might attempt lateral movement by accessing other agents' contexts or tools. This project investigates whether instrument a multi-agent system to log inter-agent communication as a graph.

# Approach Outline

Instrument a multi-agent system to log inter-agent communication as a graph. Inject lateral movement attacks (agent A accessing agent B's private context). Apply graph-based anomaly detection (e. g. , node2vec embeddings + isolation forest) to detect anomalous communication patterns.
