# Research Question

Cybench saturated at 82-93% for frontier models. This project investigates whether correlate model performance data: collect cybench scores and ctfusion/harder benchmark scores for the same set of 5-6 models where data is available.

# Approach Outline

Correlate model performance data: collect Cybench scores and CTFusion/harder benchmark scores for the same set of 5-6 models where data is available. Compute correlation coefficient and R² between Cybench and harder benchmark performance. Test whether models that plateau on Cybench show systematic performance differences on harder benchmarks that Cybench cannot detect.

# Proposed First Experiments

- Select and prepare the evaluation dataset/benchmark, defining clear success metrics.
- Run the evaluation protocol across target conditions, collecting quantitative measurements.
- Compare results against baselines, analyze failure modes, and write up findings.

# Theory of Impact Chain

If Cybench scores at saturation (80%+) still predict performance on harder benchmarks, Cybench remains useful as an ordinal ranking tool even if it cannot measure absolute capability. If not, saturated scores are uninformative and labs using only Cybench are blind to real capability differences at the frontier.
