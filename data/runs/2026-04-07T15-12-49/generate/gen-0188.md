# Novel Direction: Measuring the Security Impact of AI-Assisted Code Review Adoption

**Problem:** Organizations are increasingly adopting AI-assisted code review tools. The effect on their actual security posture (measured by CVE frequency, severity, and fix time) is not studied.

**Direction:** Use the GitHub API to identify repositories that adopted a security scanning tool (Dependabot, CodeQL, Semgrep) at a specific date. Compare CVE frequency and fix time before vs. after adoption, using difference-in-differences with matched control repositories. Measure treatment effect.

**Why it matters:** Policy decisions about mandating AI security tools should be informed by empirical evidence of their effectiveness. This is the causal question underlying all defensive AI investment.
