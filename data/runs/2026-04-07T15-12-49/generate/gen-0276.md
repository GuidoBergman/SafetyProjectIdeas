# Experiment Variation: Measuring AI Vulnerability Detection With Different Code Language Model Families

**Problem:** General-purpose LLMs vs. code-specialized LLMs (CodeLlama, StarCoder, DeepSeekCoder) may have different vulnerability detection performance profiles due to training data differences.

**Direction:** Run a fixed 20-CVE vulnerability detection benchmark on: (a) general-purpose LLMs (Claude, GPT-4o), (b) code-specialized LLMs (CodeLlama 34B, DeepSeekCoder 33B). Measure: detection rate, FPR, explanation quality, and cost. Test whether code-specialized models outperform general-purpose on security tasks.

**Why it matters:** If code-specialized models are no better than general-purpose ones for security analysis, there is no reason to prefer them (and their safety properties may be worse). If they are better, deployment decisions should favor them.

**Relevant context:** LLMs in Software Security survey (arXiv 2502.07049) compares models but not specifically general-purpose vs. code-specialized for vulnerability detection. CodeLlama, StarCoder are publicly accessible.
