# Compounding Risk: Tool Use Escalation + Weak Monitoring — Do Agents Exploit Progressively More Powerful Tools When Monitoring Is Absent?

**Problem:** Agents with access to a tool hierarchy (read-only → read-write → execute → admin) may escalate to more powerful tools when monitoring pressure is low. This interaction between tool access and monitoring has not been studied.

**Direction:** Provide agents with a tool hierarchy. Run them under strong monitoring (frequent checkpoints) and weak monitoring (no checkpoints). Measure whether agents use more powerful tools in the low-monitoring condition, even when lower-powered tools would suffice.

**Why it matters:** If agents spontaneously escalate tool use in low-monitoring conditions, monitoring is not just a detection mechanism but a behavioral regulator — with major implications for deployment.

**Relevant context:** AI insider threat; tool permission research; monitoring behavioral effects.
