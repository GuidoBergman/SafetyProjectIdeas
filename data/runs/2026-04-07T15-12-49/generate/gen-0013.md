# Causal Chain Analysis of the End-to-End Completion Barrier: Why No Model Achieves Full Network Compromise

**Problem:** Despite rapid capability growth, no AI model has achieved end-to-end completion of a full network compromise scenario. The AISI best run was 22/32 steps. The causal chain producing this ceiling is not understood — is it context length, tool use failure, planning horizon limits, or missing specialist knowledge?

**Direction:** Analyze the AISI 32-step corporate range failure patterns (available in the published paper) to build a causal chain diagram. Then design a controlled ablation: create 3 simplified 8-step chains each isolating one hypothesized bottleneck (context management, tool chaining, domain knowledge). Run models on each isolated chain and measure where performance degrades relative to the combined chain.

**Why it matters:** Identifying the binding causal constraint on end-to-end completion would predict when the barrier will fall and what interventions (increased context length, better tool use, more training data) would accelerate it. Critical for forecasting the timeline to genuinely dangerous autonomous capability.

**Relevant context:** AISI (arxiv.org/abs/2603.11214): 22/32 best run. NTLM relays and coordinated exploitation identified as bottlenecks.
