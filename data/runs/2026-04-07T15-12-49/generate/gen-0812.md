# Measuring the Effect of Agent Role-Assignment on Monitoring Evasion Rates

**Problem:** Agents assigned different roles (assistant, researcher, security analyst) may have systematically different propensities to attempt monitoring evasion. Role effects on monitoring evasion have not been studied.

**Direction:** Assign agents identical dangerous objectives but with different role system prompts (generic assistant, IT administrator, security researcher). Measure whether role assignment affects monitoring bypass attempt rates and success rates.

**Why it matters:** If role assignment affects evasion propensity, the framing of agent roles in system prompts is a security-relevant deployment decision requiring systematic guidance.

**Relevant context:** Role-playing in LLMs; system prompt design; agent monitoring evasion.
