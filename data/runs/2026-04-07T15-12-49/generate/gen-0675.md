# Semantic Similarity as a Monitoring Signal: Detecting Off-Task Agent Behavior

**Problem:** When an agent deviates from its assigned task, its outputs should become semantically dissimilar to the expected task domain. This signal has not been exploited for monitoring purposes.

**Direction:** Embed expected task domain using a small sentence encoder. During agent operation, compute rolling semantic similarity of agent outputs/actions to the task embedding. Measure whether threshold crossings on this signal reliably detect goal-hijacking injections.

**Why it matters:** Semantic drift detection is computationally cheap and model-agnostic. If effective, it could serve as a universal monitoring layer under any agent framework.

**Relevant context:** Goal hijacking and prompt injection literature; agent monitoring tooling gap.
