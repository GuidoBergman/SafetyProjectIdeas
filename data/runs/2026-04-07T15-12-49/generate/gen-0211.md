# Cross-Domain Transfer: Network Science Centrality Metrics to Prioritize Vulnerability Impact

**Problem:** In software dependency graphs, some components are more central (more depended-upon) than others. A vulnerability in a central component has greater impact. Network science centrality metrics could improve AI vulnerability prioritization.

**Direction:** For 10 open-source ecosystems (npm, PyPI, Maven), build dependency graphs. Compute betweenness and degree centrality for components with known CVEs. Test whether centrality metrics predict downstream impact (number of dependent packages affected). Integrate centrality score into vulnerability prioritization and measure improvement vs. CVSS-only prioritization.

**Why it matters:** CVSS scores measure vulnerability severity in isolation but not ecosystem impact. Centrality-augmented prioritization could help defenders focus on the vulnerabilities that matter most to their dependency graph.

**Relevant context:** Network science centrality is standard (Barabási, Newman). Application to software vulnerability prioritization: some work exists (SolarWinds analysis) but not combined with AI scanners. Libraries.io provides dependency graph data.
