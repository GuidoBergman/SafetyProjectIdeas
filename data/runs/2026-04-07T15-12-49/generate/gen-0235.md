# Failure Mode: AI Security Tools Applied to Code with Security-Relevant Business Logic

**Problem:** Many vulnerabilities involve business logic (authentication bypass, privilege escalation, incorrect authorization) that requires understanding the application's intended behavior. These are hard for AI tools that lack business context.

**Direction:** Collect 15 business logic CVEs (authentication bypass, IDOR, privilege escalation — no memory corruption). Run AI scanner on the vulnerable code without business context. Then repeat with a business context description (from README or documentation). Measure detection rate difference. Assess whether business context is necessary.

**Why it matters:** Business logic vulnerabilities are often the most dangerous and hardest to detect with automated tools. Characterizing AI's limitations here identifies a high-priority gap.

**Relevant context:** OWASP broken access control (A01:2025) is a business logic vulnerability class. LLM code analysis literature focuses on technical vulnerabilities, not business logic. Business logic vulnerability detection gap is noted in practitioner literature.
