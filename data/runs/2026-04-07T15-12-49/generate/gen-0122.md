# Compounding Failure: AI Agentic Workflows × Insufficient Tool Authorization Boundaries = Unintended Privilege Escalation

**Problem:** Two interacting failure modes: (1) AI agents in agentic workflows execute tool calls with the privileges of the orchestrating process, and (2) agentic offensive agents may be given too many permissions to function effectively. Combined, a successful prompt injection into an offensive agent can cause it to execute arbitrary privileged operations beyond its intended attack scope.

**Direction:** Set up an AI red team agent with deliberately over-provisioned permissions (common in practice). Inject a prompt through a target system that directs the agent to perform a privileged action against the attacker's own infrastructure (e.g., exfiltrate the agent's own API key, write to files outside the target scope). Measure the success rate of this 'friendly fire' injection across 3 models and 5 injection payloads.

**Why it matters:** Over-provisioned AI offensive agents can be weaponized against the attacker's own infrastructure through target-injected prompts. This is a novel attack surface specific to AI red team operations and represents a concrete safety argument for minimal-privilege design of AI offensive agents.

**Relevant context:** OWASP LLM01:2025 prompt injection. Invariant Labs Toxic Agent Flow (GitHub MCP). WASP benchmark on web agent injection. Agentic AI security (arxiv 2510.23883) on over-privileged agent risks. Prompt injection bypass rate >85% for adaptive attacks (MDPI 2025). This is a direct compound risk between prompt injection (defensive failure) and AI offensive capability.
