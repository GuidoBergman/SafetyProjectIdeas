# Novel Direction: AI-Assisted Security Regression Testing Design

**Problem:** When a patch is applied, regression testing should verify that (a) the vulnerability is fixed, (b) no new vulnerabilities are introduced, (c) functionality is preserved. AI could assist in designing targeted regression tests for security patches.

**Direction:** For 15 public CVE patches, use an LLM to generate: (a) a test case that would have detected the original vulnerability, (b) a test case verifying the patch is effective, (c) a test case checking for introduced regressions. Compare AI-generated tests to existing CVE PoC tests. Measure coverage and correctness.

**Why it matters:** Security regression testing is underinvested. AI-assisted test generation could automate a currently manual, expertise-intensive process.

**Relevant context:** Google CodeMender generates patches. Meta AutoPatchBench evaluates patch quality. AI-generated security regression tests (not just patches) are not studied.
