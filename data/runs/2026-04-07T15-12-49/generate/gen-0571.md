# Leanstral vs. General LLM: Is Domain-Specific Fine-Tuning Worth the Cost for Formal Verification?

**Problem:** Mistral's Leanstral is fine-tuned specifically for Lean 4. Whether the domain-specific fine-tuning provides sufficient improvement over general LLMs (prompted with Lean examples) to justify the specialization cost is untested.

**Direction:** Compare on VeriBench: (a) Leanstral (specialized), (b) Mistral base model with Lean 4 few-shot examples, (c) Mistral base model with no specific prompting. Measure compilation rate, proof success, and failure modes. Compute marginal improvement from specialization.

**Why it matters:** If specialization provides only marginal improvement over good prompting, the field should focus on prompting strategies. If specialization is large, dedicated Lean 4 models are worth training. This informs resource allocation.

**Relevant context:** Leanstral was released March 2026. Mistral base models are available for comparison. The specialization-vs-prompting tradeoff is a fundamental question in applied LLM research.
