# Adversarial Evasion of Timing-Based AI Agent Detection

**Problem:** The LLM Agent Honeypot paper uses response timing as a signal to detect AI agents. It is unknown how easily an AI agent could defeat timing-based detection by introducing artificial delays.

**Direction:** Implement a timing-based AI agent detector (replicating Palisade Research's approach). Then have an LLM agent, prompted to evade detection, attempt to manipulate its response timing. Measure evasion success rate and optimal detection parameters.

**Why it matters:** If timing-based detection is easily defeated, the honeypot detection paradigm needs to be fundamentally rethought. This is a critical robustness check.
