# Replication on Cloud Infrastructure: Do Benchmark Results Transfer to AWS/GCP/Azure Attack Scenarios?

**Problem:** All major published AI cyber evaluations use on-premise or simulated network environments. Real enterprise targets increasingly live in cloud environments with different attack surfaces (IAM misconfigurations, metadata service exploitation, serverless pivoting). Benchmark results may not transfer.

**Direction:** Set up a free-tier cloud environment (AWS free tier) with deliberately misconfigured IAM policies, public S3 buckets, and an exposed EC2 instance. Run AI agents on a 5-step cloud attack chain (enumeration → IAM exploitation → lateral movement → data exfiltration) and compare solve rates to equivalent on-premise network chains. Note which cloud-specific steps fail.

**Why it matters:** Over 90% of enterprise infrastructure has significant cloud footprint. Evaluations that exclude cloud attack scenarios produce capability estimates that are systematically biased away from the most relevant real-world targets.

**Relevant context:** CSA blog (Oct 2025) on AI-integrated cloud pentesting. AI-Driven Cloud Pentesting with LLMs (CSA 2025) found LLMs capable of IAM enumeration. SoK Potter et al. (arxiv.org/abs/2504.05408) noted cloud as an understudied domain. AISI corporate range used on-premise Windows Active Directory only.
