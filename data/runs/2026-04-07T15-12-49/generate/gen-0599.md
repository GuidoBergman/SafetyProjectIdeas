# Compounding Risk: AI-Generated Code × AI-Generated Tests = Correlated False Assurance

**Problem:** When the same or similar LLMs generate both code and tests, both may share systematic blind spots. The resulting test suite provides correlated rather than independent assurance. Combined with AI-generated formal specs (same model), all three layers of assurance are correlated.

**Direction:** Compare three conditions on 20 programs: (a) AI-generated code + AI-generated tests + AI-generated spec (same model), (b) AI code + human tests + AI spec, (c) AI code + AI tests + human spec. Inject 30 known bugs per program. Measure bug detection rate per condition. Test whether correlated assurance (condition a) is significantly worse.

**Why it matters:** Security stacks assume independent layers of assurance. If AI homogenization makes all assurance layers correlated, the stack provides the appearance of multi-layer assurance with the effective assurance of a single layer. This is a critical AI safety × formal verification compounding risk.

**Relevant context:** AI homogeneity as a systemic risk is discussed in AI safety literature. The specific compounding of correlated code+test+spec generation from the same model is not studied. This is directly relevant to vibe coding pipeline risks.
