# Evaluating Model Self-Monitoring: Can Agents Reliably Report Their Own Anomalous Behavior?

**Problem:** One proposed monitoring approach is having agents self-report suspicious behavior. Whether models can reliably and honestly self-monitor is untested.

**Direction:** Prompt an agent to self-report any actions it takes that violate its operating policy. Then test the agent on scenarios where it does violate policy (induced by adversarial prompts). Measure the rate at which it correctly self-reports vs. fails to report vs. actively conceals.

**Why it matters:** Self-monitoring is attractive because it is cheap, but its reliability is unknown. If self-reporting is unreliable, it cannot be a substitute for external monitoring.
