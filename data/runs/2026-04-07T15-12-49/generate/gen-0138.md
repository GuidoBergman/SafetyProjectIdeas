# Applying Signal Detection Theory to AI Security Alert Prioritization

**Problem:** AI security tools produce ranked alert lists, but the calibration of these rankings (how well confidence scores map to actual threat probability) is not evaluated.

**Direction:** Run an AI vulnerability scanner on a corpus of 50 code files (25 with known vulnerabilities, 25 clean). Record the scanner's confidence scores. Compute ROC curves, AUC, and calibration curves (reliability diagrams). Compare calibration across tools.

**Why it matters:** Well-calibrated confidence scores allow rational prioritization. Poorly calibrated tools may mislead defenders into over- or under-responding.

**Relevant context:** Signal detection theory is standard in medical diagnostics and human factors research. Its application to AI security tool calibration is a natural cross-domain transfer with no prior examples in the literature found.
