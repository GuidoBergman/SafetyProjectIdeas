# Causal Chain: Intervening on the Coordination Failure Between AI Security Teams and Development Teams

**Problem:** AI security tools detect vulnerabilities, but the causal chain to remediation passes through organizational coordination between security and development teams. This coordination often fails (different priorities, timelines, communication norms).

**Direction:** Survey or observe (via public issue tracker data) the communication patterns between security tool outputs and developer responses. Identify the characteristics of AI security reports that receive faster responses: severity framing, code specificity, patch-included vs. not. Derive communication templates that minimize coordination failures.

**Why it matters:** Technical detection quality is necessary but not sufficient. Organizational coordination is the binding constraint on remediation. Communication design is an under-studied lever.

**Relevant context:** Security-development coordination failures are well-documented in security engineering practice. AI security tool communication design for developer uptake is not studied.
