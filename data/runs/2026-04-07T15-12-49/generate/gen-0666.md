# Minimal Viable Monitoring: What Is the Least Information Needed to Detect Rogue Agent Behavior?

**Problem:** Comprehensive agent monitoring generates enormous log volumes. For resource-constrained deployments, it is important to know the minimum set of signals sufficient for basic rogue behavior detection.

**Direction:** Conduct an ablation study: start with full agent logs (actions, tool calls, intermediate reasoning, outputs) and progressively remove signal types. Measure detection accuracy degradation. Identify the minimal signal set that retains acceptable detection performance.

**Why it matters:** Most organizations cannot afford comprehensive monitoring. A 'minimal viable monitoring' specification would make basic safety guarantees accessible to all agent deployments.

**Relevant context:** Agent monitoring literature; Anthropic detection classifiers; resource-constrained security research.
