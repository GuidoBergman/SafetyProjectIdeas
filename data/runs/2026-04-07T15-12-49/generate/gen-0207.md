# Tool Gap: A Standardized Dataset of AI Security Explanation Ground Truths

**Problem:** Evaluating AI security tool explanation quality requires ground truth explanations. No standardized dataset of human-expert-written vulnerability explanations paired with source code exists for benchmarking.

**Direction:** Curate a small dataset of 30 CVE-code pairs with: (a) the vulnerable code snippet, (b) a high-quality expert explanation (from CVE advisory, security blog, or researcher writeup), (c) a simple vs. complex example per class.
