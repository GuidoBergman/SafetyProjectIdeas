# Cognitive Load Theory Applied to AI-Generated Security Report Design

**Problem:** AI vulnerability reports are often verbose and poorly structured, overwhelming human analysts. Cognitive load theory from educational psychology could guide better report design.

**Direction:** Design two formats for AI-generated vulnerability reports: (a) standard LLM output, (b) cognitively optimized format (progressive disclosure, severity-first, structured sections). Run a user study with 10-15 CS students triaging 10 vulnerabilities in each format. Measure triage accuracy, time, and self-reported cognitive load.

**Why it matters:** If AI security tools produce reports that overwhelm analysts, security outcomes worsen even if detection is accurate. Report design is a safety-relevant human factors problem.

**Relevant context:** Cognitive load theory (Sweller 1988) is well-established in education. Its application to AI security report UX design is novel. Alert fatigue literature touches on this but doesn't operationalize cognitive load.
