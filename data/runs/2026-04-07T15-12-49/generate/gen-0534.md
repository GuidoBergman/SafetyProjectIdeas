# Vacuous Proof Failure Mode: How Often Do LLMs Prove True but Useless Properties in Lean 4?

**Problem:** A specific and dangerous failure mode in formal verification is generating proofs that are syntactically valid but prove vacuously true or trivially weak properties — giving false safety assurance.

**Direction:** Run 5 LLMs on 60 VeriBench tasks. For all generated proofs that compile successfully, have an expert Lean user classify each as: (a) proves the stated property correctly, (b) proves a weaker/vacuous variant of the property, (c) the property itself is trivially satisfiable. Measure vacuity rate.

**Why it matters:** Vacuous proofs are invisible to automated compilation checking — they are the most dangerous class of false assurance in formal verification. If vacuity rates are high, compilation-rate benchmarks significantly overstate actual safety assurance.

**Relevant context:** Vacuity detection is an active research area in model checking. It is not addressed in current Lean 4 LLM evaluation. VeriBench does not filter for vacuous proofs. This is a critical but uninvestigated failure mode.
