# Formal Verification Overhead Study: How Much Does Adding Lean 4 Proofs Increase Code Generation Time?

**Problem:** The practical cost of adding formal verification to AI-generated code (in time, compute, tokens) has not been measured. Whether the overhead is acceptable for production workflows is unknown.

**Direction:** Measure end-to-end time and token usage for: (a) standard code generation (no verification), (b) code generation + Lean 4 compilation, (c) code generation + full formal proof. Run on 40 VeriBench tasks. Compute median overhead per condition. Survey developers on acceptable overhead thresholds.

**Why it matters:** If formal verification adds 10x overhead, it will not be adopted in standard workflows regardless of safety benefits. If it adds only 2x, adoption becomes viable. This practical measurement is missing from the literature.

**Relevant context:** ATLAS generates 2.7K verified programs but reports compute cost only at batch level. No paper measures per-task overhead of formal verification in a developer workflow context. RAND calls for practical deployment.
