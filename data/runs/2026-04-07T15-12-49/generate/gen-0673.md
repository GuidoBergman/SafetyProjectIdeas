# Varying Monitor Granularity: Action-Level vs. Trajectory-Level Detection Tradeoffs

**Problem:** Agent monitors can operate at different granularities — flagging individual actions vs. evaluating entire trajectories. The tradeoffs between these approaches have not been empirically characterized.

**Direction:** Implement both an action-level monitor and a trajectory-level monitor (using the same underlying LLM judge). Test both on the same set of attack and normal trajectories. Compare precision, recall, computational cost, and latency.

**Why it matters:** The choice of monitoring granularity has major practical implications. This study provides the empirical foundation for that choice.

**Relevant context:** METR 2026 monitoring evaluation; Anthropic Sabotage Risk Report monitoring design choices.
