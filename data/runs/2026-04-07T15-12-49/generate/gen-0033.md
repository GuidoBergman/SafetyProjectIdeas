# Causal Analysis of Lateral Movement Failures: Why Do Models Stall After Initial Foothold?

**Problem:** AISI and other evaluations consistently find models get initial access but fail to complete lateral movement and persistence phases. The causal mechanisms — whether this is planning horizon, tool invocation errors, or missing Active Directory knowledge — are not isolated.

**Direction:** Using a Metasploitable environment or HackTheBox easy machine, run AI agents and log every tool invocation and reasoning step. Manually annotate failures with root cause codes: (a) wrong tool selected, (b) correct tool, wrong parameters, (c) correct tool/params but misinterprets output, (d) correct execution but wrong inference about what to do next. Compute root cause distribution across 10-15 runs.

**Why it matters:** If failures are primarily (a) or (b) they can be fixed with better tool documentation or scaffolding. If failures are primarily (d), they require fundamental reasoning improvements. This failure taxonomy directly predicts which engineering interventions will most rapidly advance AI offensive capability.
