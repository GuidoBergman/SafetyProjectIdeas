# Reproducing AlphaVerus Self-Improvement Loop with Different Source Languages: CBMC → Lean vs. Dafny → Verus

**Problem:** AlphaVerus bootstraps from Dafny (high-resource) to Verus (low-resource). Whether starting from a different high-resource language (e.g., CBMC counterexample traces as source) produces similar or better results when targeting Lean 4 is untested.

**Direction:** Implement an AlphaVerus-style self-improving translation pipeline starting from CBMC verification output (rather than Dafny) and targeting Lean 4. Run on 20 simple C programs with CBMC certificates. Compare to direct LLM-to-Lean 4 translation. Measure success rate.

**Why it matters:** CBMC certificates for C code are widely available (Amazon uses CBMC in AWS). If CBMC certificates can bootstrap Lean 4 proof generation, a pathway exists from verified C legacy code to CSLib entries.

**Relevant context:** AlphaVerus paper describes the bootstrapping approach in detail. CBMC is a standard industrial verification tool. The CBMC→Lean 4 pathway has never been explored. This is a replication with a novel source language.
