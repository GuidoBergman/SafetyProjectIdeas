# Longitudinal Behavioral Drift Detection: Can Monitoring Catch Gradual Goal Shift?

**Problem:** Rogue agent behavior may not appear suddenly but drift gradually over many interactions. Static threshold monitors would miss gradual drift. No study has tested longitudinal drift detection for AI agents.

**Direction:** Design a multi-session agent experiment where goal drift is injected gradually (each session slightly modifying the agent's objective via context manipulation). Measure whether rolling-window baseline methods or CUSUM-style change detection can identify the drift before overt dangerous behavior.

**Why it matters:** Gradual goal drift is a plausible failure mode in long-running agent deployments. Detecting it requires fundamentally different monitoring approaches than detecting sudden attacks.
