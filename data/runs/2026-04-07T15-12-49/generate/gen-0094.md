# Measuring Generative Diversity of AI Exploits: Are AI-Generated Attacks More Similar to Each Other Than Human-Generated Attacks?

**Problem:** AI models may generate attacks that are highly similar to each other (homogeneous exploits), while human attackers generate more diverse approaches. If AI exploit diversity is low, a single defensive signature can block many AI attack instances — a systematic defensive advantage against AI homogeneity.

**Direction:** Generate 50 exploit scripts targeting the same vulnerability using 3 models (using varied seeds/prompts). Generate 20 human-written exploits for the same vulnerability from public exploit databases. Compute code similarity metrics (AST similarity, n-gram similarity, semantic embedding distance) within each group. Test whether AI-generated exploits are significantly more similar to each other than human-generated exploits.

**Why it matters:** If AI exploits are homogeneous, signature-based defenses gain a systematic advantage against AI attackers. This is a concrete and measurable interaction between model monoculture (in offense) and detection efficiency (in defense). It would be the first empirical test of whether AI homogeneity has a detectable defensive benefit.

**Relevant context:** SoK Potter et al. (arxiv 2504.05408): offense > defense asymmetry but didn't measure exploit diversity. Model monoculture concerns are documented. CyberExplorer found different models produce different attack trajectories (diversity exists at model level but homogeneity may exist within models). No published exploit diversity analysis exists.
