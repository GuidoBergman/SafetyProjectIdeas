# When Does AI Vulnerability Detection Fail? A Boundary Condition Study

**Problem:** AI vulnerability detectors perform well on benchmark datasets but their boundary conditions (code complexity, obfuscation, language, age of code) are not well characterized.

**Direction:** Take a set of 30 known vulnerabilities. Systematically vary: (a) degree of code obfuscation, (b) programming language (Python vs. C vs. Java), (c) code age proxy (commit date). Measure detection rate as a function of each variable using a fixed LLM. Report boundary conditions.

**Why it matters:** Attackers may deliberately target the boundary conditions where AI detectors fail. Understanding these conditions is necessary for deploying AI defenses safely.

**Relevant context:** Claude found 500+ vulnerabilities undetected for decades (Anthropic 2026), but the conditions under which AI misses vulnerabilities remain uncharacterized.
