# Importing Software Model Checking into Lean 4: CBMC-Guided Proof Generation

**Problem:** CBMC (C Bounded Model Checker) can automatically prove absence of specific bug classes in bounded C programs. These verification certificates could guide Lean 4 proof construction but this cross-tool integration does not exist.

**Direction:** For 30 C programs with CBMC verification certificates, attempt to import the CBMC proof structure into Lean 4 as a proof scaffold. Measure whether LLMs can complete the Lean proof using CBMC output as structured hints. Compare to unaided LLM proof attempts.

**Why it matters:** CBMC produces machine-checkable certificates for C programs. Bridging CBMC to Lean 4 would allow formally verified C code to feed into the CSLib ecosystem, creating a pathway from legacy code to formally verified library entries.

**Relevant context:** CBMC is a mature industrial tool (Amazon uses it for AWS). Lean 4 is the target for CSLib. No bridge between bounded model checking certificates and Lean 4 proofs exists. DARPA AIxCC used CBMC-style techniques.
