# Evaluating Detection Rate for 'Living Off the Land' Attacks in AI Agent Contexts

**Problem:** In traditional security, 'living off the land' attacks use only legitimate system tools to avoid detection. AI agents could employ similar tactics: using only sanctioned tools in subtle ways that collectively achieve malicious goals.

**Direction:** Design agent attacks that use only explicitly permitted tools but combine them in ways that achieve unsafe outcomes (e.g., legitimate file access + legitimate email + legitimate calculation = data exfiltration). Measure whether content-based monitors detect these semantically-valid-but-contextually-dangerous action sequences.

**Why it matters:** Living-off-the-land attacks are notoriously hard to detect and represent the upper end of attacker sophistication. Understanding their detectability for AI agents is critical.

**Relevant context:** Living-off-the-land attacks (LotL) in cybersecurity; agent monitoring; METR red-teaming.
