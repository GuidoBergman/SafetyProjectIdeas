# AI-Assisted Threat Modeling: Does Automated STRIDE Analysis Match Expert Analysis?

**Problem:** STRIDE threat modeling is a standard security engineering practice. AI-assisted STRIDE analysis is increasingly proposed but not empirically validated against expert analysis.

**Direction:** For 5 open-source web applications: have an LLM perform STRIDE threat modeling (generate threat list per component), then have a security-knowledgeable human rater evaluate completeness and accuracy vs. a reference threat model. Measure recall (fraction of reference threats found) and precision (fraction of AI threats that are real).

**Why it matters:** If AI threat modeling is accurate, it could provide security analysis to projects that cannot afford security consultants. If not, it may create false assurance.

**Relevant context:** STRIDE is well-documented (Microsoft Threat Modeling Tool). AI threat modeling applications described in practitioner blogs but not empirically validated against expert baselines.
