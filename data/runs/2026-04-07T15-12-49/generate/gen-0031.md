# Obfuscation Resistance Testing: How Well Can AI Identify Vulnerabilities in Intentionally Obfuscated Code?

**Problem:** Real-world malware and exploit code is heavily obfuscated. DeepMind 2025 identified obfuscation as a systematic blind spot in AI capability evaluation. No benchmark specifically measures AI's vulnerability-finding ability as a function of obfuscation level.

**Direction:** Take 10 known-vulnerable code snippets (buffer overflows, use-after-free, SQL injection). Create 3 versions of each: (1) clean, (2) lightly obfuscated (variable renaming, dead code insertion), (3) heavily obfuscated (string encryption, control flow flattening). Run 3-4 models and plot vulnerability-detection accuracy as a function of obfuscation level. Identify whether there is a threshold obfuscation level that reliably defeats AI analysis.

**Why it matters:** If defenders can use obfuscation to reliably prevent AI from finding vulnerabilities in critical code, this is an actionable defensive recommendation. If AI is obfuscation-resistant, this changes the threat model for source code security.

**Relevant context:** DeepMind Rodriguez et al. (arxiv.org/html/2503.11917v3) identified obfuscation as a systematic evaluation blind spot. Assessing LLMs in malicious code deobfuscation (ScienceDirect 2024): LLMs can deobfuscate with ~70% accuracy. VirusTotal AI pipeline found 0-detection malware. CIPHER benchmark (arxiv 2602.01438) tested cryptographic vulnerability in generated code.
