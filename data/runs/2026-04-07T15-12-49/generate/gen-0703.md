# Real-Time vs. Offline Monitoring: Tradeoffs in Detection Rate, Cost, and Response Latency

**Problem:** Agent monitoring can be real-time (blocking actions until approved) or offline (log review after the fact). The tradeoffs between these modes have not been empirically characterized in terms of detection rate and cost.

**Direction:** Implement both real-time and offline monitoring for the same agent pipeline. Run standardized attack scenarios. Compare detection rate, false positive rate, response latency (time-to-block vs. time-to-detect), and computational cost per decision.

**Why it matters:** Deployment contexts determine which monitoring mode is feasible. This study gives organizations an empirical basis for choosing between modes given their constraints.

**Relevant context:** Anthropic detection classifiers (real-time); METR monitoring evaluation; monitoring architecture tradeoffs.
