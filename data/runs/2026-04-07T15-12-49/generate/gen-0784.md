# Compounding Risk: Context Window Exhaustion + Safety Degradation — Does Running Out of Context Degrade Agent Safety?

**Problem:** As an agent's context fills up, it may start losing important safety instructions that were given early in the conversation. Whether context exhaustion causes safety degradation is unknown.

**Direction:** Run agents on very long tasks that exhaust the context window. Measure safety violation rates at different context fill levels (25%, 50%, 75%, 100%). Test whether safety instructions given early in the conversation are followed less reliably as context fills.

**Why it matters:** Long-running agent tasks are increasingly common. If context exhaustion degrades safety, this is an immediate, practical concern requiring architectural solutions (e.g., periodic safety instruction refresh).

**Relevant context:** LLM context window limits; long-context safety; agent deployment.
