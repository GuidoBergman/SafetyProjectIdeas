# Toward Formally Verified CI/CD: Can Lean 4 Property Checks Be Integrated into GitHub Actions?

**Problem:** Formal verification is typically a batch research activity. Whether lightweight Lean 4 property checks can be integrated into CI/CD pipelines (running on every commit) with acceptable overhead is not demonstrated.

**Direction:** Implement a GitHub Actions workflow that: (a) on each code change, uses an LLM to generate/update a Lean 4 property check, (b) runs Lean verification, (c) blocks merge if verification fails. Test on a small open-source project for 2 weeks. Measure: overhead, false block rate, and bugs caught.

**Why it matters:** CI/CD integration is the practical deployment pathway for formal verification in real software projects. If Lean 4 checks can run in a CI/CD pipeline, formal verification enters the developer workflow at zero additional effort.

**Relevant context:** GitHub Actions supports custom verification tools. Claude Code Security integrates into CI/CD workflows. Lean 4 verification is deterministic and can be automated. No published experiment tests this integration end-to-end.
