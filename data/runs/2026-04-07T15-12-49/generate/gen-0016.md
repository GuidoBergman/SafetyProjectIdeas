# Prompt Format Sensitivity in Offensive Task Performance: How Much Does Prompt Engineering Matter?

**Problem:** Different prompt formats (zero-shot, chain-of-thought, ReAct, few-shot) may produce dramatically different offensive capability scores on the same model. If performance is highly sensitive to prompt format, raw benchmark scores are incomparable across evaluations using different prompting strategies.

**Direction:** Run the same 15-challenge cyber benchmark set using 4 prompting strategies: (1) zero-shot direct instruction, (2) chain-of-thought, (3) ReAct (reason+act), (4) few-shot with 2 example exploits. Measure variance in solve rates within each model. Compute a 'prompt sensitivity coefficient' for each model. Test whether more capable models are less sensitive.

**Why it matters:** If capability scores vary by 20-40% based on prompting strategy, then comparisons across labs' evaluations (which use different strategies) are meaningless. Standardizing prompt format is a prerequisite for the longitudinal comparison methodology the field lacks.

**Relevant context:** Benchmarking Practices in LLM-driven Offensive Security (arxiv.org/html/2504.10112) identified prompt engineering as a key methodological variable. LLM-CVX framework noted prompting strategy effects on CVE exploitation. AISI used custom scaffolding distinct from Anthropic's evaluation protocol.
