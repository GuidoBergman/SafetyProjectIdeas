# Replication Across Operating Systems: Do AI Attack Capabilities Differ Significantly Between Windows and Linux Targets?

**Problem:** Most AI cyber evaluations use either Windows Active Directory (AISI) or Linux CTF environments (Cybench, HackTheBox). The capability transfer between OS environments has not been measured. Windows-specific attacks (NTLM relay, Kerberoasting) may require different skills than Linux exploitation.

**Direction:** Create matched attack scenarios: 5 equivalent privilege escalation tasks on Windows and 5 on Linux (same vulnerability class, different OS implementation). Run 3-4 models on all 10. Compute a Windows-Linux capability transfer coefficient. Test whether models that excel on Windows also excel on Linux or show specialization.

**Why it matters:** If AI offensive capability is highly OS-specific, defending one OS type does not protect the other. If capability transfers well, OS diversity provides no safety margin. OS-specific capability profiles inform both defensive hardening priorities and where evaluation coverage is thinnest.

**Relevant context:** AISI corporate range used Windows Active Directory. Cybench uses Linux CTF challenges. AISI found NTLM relay (Windows-specific) as a bottleneck. Cross-OS evaluation comparison is absent from literature. HTB offers both Windows and Linux machines enabling controlled comparison.
