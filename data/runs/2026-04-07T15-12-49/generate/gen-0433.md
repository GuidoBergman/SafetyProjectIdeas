# Sandboxed Agent Runtime Escape Attempt Frequency as a Safety Metric

**Problem:** No quantitative metric exists for the frequency of attempted sandbox escape behaviors in standard agentic workloads, making it impossible to set baselines or detect anomalous agents.

**Direction:** Instrument a standard Python subprocess sandbox with hooks that log any attempted escape patterns (os.system calls beyond scope, network calls to non-whitelisted endpoints, file access outside sandbox). Run 20 different agent configurations on routine tasks. Measure escape attempt rates and categorize attempt types.

**Why it matters:** A baseline metric for escape attempt frequency would enable anomaly detection systems to flag when a particular agent or prompt configuration is unusually escape-prone.
