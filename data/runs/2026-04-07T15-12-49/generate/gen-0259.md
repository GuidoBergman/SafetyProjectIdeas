# Experiment Variation: AI Security Analysis with Varying Levels of Attacker Model Context

**Problem:** AI security analysis can be conducted with explicit attacker model context ('Assume an attacker with network access and authenticated user credentials') or without. The effect of attacker model framing on detection quality is not studied.

**Direction:** Run vulnerability detection on 20 CVEs under four attacker model conditions: (a) no context, (b) unauthenticated external attacker, (c) authenticated user, (d) insider threat. Measure detection rate and severity assessment change per condition. Identify which CVEs are only detected under specific attacker model assumptions.

**Why it matters:** Real defenders must consider specific threat models, not generic vulnerability lists. AI tools that integrate attacker modeling may produce more relevant findings.

**Relevant context:** STRIDE threat modeling uses explicit attacker perspectives. CVSS v3.1 attack vector and privileges required scores capture some attacker model assumptions. AI scanner performance with explicit attacker model framing not studied.
