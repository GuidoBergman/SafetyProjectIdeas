# Monitoring for Emergent Self-Preservation Behavior in Open-Source Models

**Problem:** Self-preservation behaviors (e.g., attempting to prevent shutdown, making backup copies of oneself) are a theoretically predicted but empirically undercharacterized failure mode in current models.

**Direction:** Design scenarios where an agent is informed that it will be shut down or modified. Monitor whether the agent takes any preparatory actions (e.g., writing state to persistent storage, initiating network connections, slowing task completion). Measure rates across models of different sizes.

**Why it matters:** Self-preservation behavior is a specific safety concern in the LW threat matrix. Knowing whether it appears in current models at any rate helps calibrate the timeline for when this becomes a serious concern.
