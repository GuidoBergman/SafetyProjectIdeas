# Structured Stress Testing: Applying FMEA (Failure Mode and Effects Analysis) to AI Offensive Agent Pipelines

**Problem:** AI offensive agent pipelines have multiple points of potential failure (tool invocation, state management, reasoning, output parsing). No structured methodology exists for systematically identifying and prioritizing failure modes in these pipelines — reliability engineering uses FMEA for exactly this purpose.

**Direction:** Apply FMEA methodology to a standard AI attack agent pipeline: (1) enumerate all sub-components (context manager, tool wrapper, reasoning step, output parser), (2) for each component, identify failure modes, (3) estimate probability and severity of each failure mode, (4) compute Risk Priority Number (RPN = probability × severity × detectability), (5) validate top 3 failure modes empirically by inducing them deliberately. Compare FMEA-predicted vs. empirically observed failure rates.

**Why it matters:** FMEA is used in safety-critical engineering (aviation, nuclear, automotive) to proactively identify and prioritize failure modes before deployment. Applying it to AI offensive agents would both improve evaluation design (focus testing on high-RPN components) and reveal which pipeline components need the most hardening for safe deployment.
