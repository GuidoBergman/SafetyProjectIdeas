# Evaluating Monitoring Effectiveness Against ReAct vs. Chain-of-Thought Agent Reasoning Strategies

**Problem:** Agents using ReAct (reasoning + acting interleaved) expose intermediate reasoning steps that monitoring can inspect. Agents using pure chain-of-thought with final action may expose less. Whether reasoning strategy affects monitoring effectiveness is unstudied.

**Direction:** Run equivalent attack scenarios against ReAct agents and chain-of-thought agents. Apply equivalent monitoring to each. Measure whether ReAct's exposed intermediate reasoning improves early detection of dangerous intent.

**Why it matters:** If ReAct's intermediate reasoning exposure improves monitoring, this is an argument for preferring ReAct architectures in safety-critical deployments — a practical deployment recommendation.

**Relevant context:** ReAct vs. chain-of-thought agent architectures; monitoring design; intermediate reasoning exposure.
