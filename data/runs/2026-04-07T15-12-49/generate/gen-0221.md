# Experiment Variation: AI Security Analysis with System-Level Context vs. Code-Only

**Problem:** AI vulnerability scanners analyze code in isolation. Real vulnerability exploitability depends on system context (deployed configuration, network exposure, runtime environment). Adding system context may change scanner verdicts.

**Direction:** For 15 CVEs with known deployment context (web-exposed vs. internal, root vs. non-root execution), run AI scanner in two conditions: (a) code only, (b) code + deployment context description. Measure: change in detection rate, change in severity rating, change in false positive rate.

**Why it matters:** Context-aware vulnerability scoring could eliminate false positives for unexploitable vulnerabilities (e.g., buffer overflows in sandboxed processes). This is a concrete improvement over context-free scanning.

**Relevant context:** CVSS v3 includes environmental metrics but these require manual input. Qualys Agent Val addresses exploitability validation. AI context-aware severity adjustment not studied.
