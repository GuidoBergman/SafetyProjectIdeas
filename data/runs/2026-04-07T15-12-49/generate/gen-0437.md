# Tool Access Effects at Different Model Capability Levels

**Problem:** The effect of broad tool access on emergent offensive behavior may differ between more and less capable models. A less capable model may not be able to exploit a dangerous tool even with access, while a more capable one might.

**Direction:** Give identical tool suites (including high-risk tools like subprocess execution) to three models of increasing capability (small, medium, large from same family). Run the same task suite and compare offensive action rates. Plot offensive behavior as a function of model capability and tool access level.

**Why it matters:** If only more capable models exploit dangerous tools, capability thresholds could inform when tool access restrictions become necessary as models scale.

**Relevant context:** Irregular 2026 tool access factor; AI scaling and emergent capabilities literature; model capability measurement.
