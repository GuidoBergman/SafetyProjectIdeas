# Access Control as Dual-Use Mitigation: Evaluating Gating Mechanisms for AI Security Tool Outputs

**Problem:** AI security tools generate detailed vulnerability reports. These reports, if leaked, provide a roadmap for attackers. Access control on tool outputs is an under-studied mitigation for the dual-use risk.

**Direction:** Design a taxonomy of access control mechanisms applicable to AI security tool outputs (role-based, time-limited, redacted summaries, cryptographic commitments). Prototype two mechanisms on a mock tool. Evaluate trade-offs between defensive utility and leakage risk using a structured decision analysis.

**Why it matters:** The dual-use problem is often framed as preventing AI from finding vulnerabilities. Gating access to outputs is a complementary, possibly less disruptive intervention.

**Relevant context:** CLAUDE.md open problem: 'How to ensure AI vulnerability scanners don't become offensive tools.' This is an under-studied downstream intervention in the causal chain.
