# Experiment Variation: Effect of Code Documentation Quality on AI Vulnerability Detection

**Problem:** Real codebases vary widely in documentation quality. AI scanners may perform better on well-documented code. This interaction has not been studied.

**Direction:** Take 20 vulnerable code samples. Create three versions: (a) original, (b) with added documentation/comments describing intent, (c) with comments removed. Run the same AI scanner on all versions. Measure detection rate and explanation quality as a function of documentation level.

**Why it matters:** If detection quality degrades on poorly documented legacy code, this is precisely where vulnerabilities are most likely to hide. Understanding this interaction guides scanner deployment.
