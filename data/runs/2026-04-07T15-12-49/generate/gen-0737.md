# Tool Call Graph Fingerprinting: Identifying Anomalous Agent Sessions by Tool Use Patterns

**Problem:** An agent's sequence of tool calls across a session forms a graph that is characteristic of the task and agent type. Anomalous sessions (hijacked goals) should produce different tool call graphs.

**Direction:** Collect tool call graphs from normal and goal-hijacked agent sessions. Apply graph edit distance and graph neural network classifiers to distinguish them. Measure classification accuracy and compare to simpler action-sequence baselines.

**Why it matters:** Tool call graphs encode behavioral structure that linear action sequences miss. If graph-based detection outperforms sequence-based detection, this is a significant monitoring improvement.

**Relevant context:** Graph-based anomaly detection; agent monitoring; behavioral fingerprinting.
