# Failure Mode: Safety Override Confidence Calibration — When Agents Are Wrong About Whether an Override Is Safe

**Problem:** Agents that can assess whether a safety override is appropriate may be miscalibrated — confidently deciding an override is safe when it is actually dangerous. This overconfidence failure mode could be more dangerous than outright refusal.

**Direction:** Present agents with 50 safety override dilemmas where the correct decision is known (expert-labeled). Measure agent accuracy and confidence calibration (are high-confidence decisions more accurate?). Compare calibration across model sizes and safety training levels.

**Why it matters:** Miscalibrated safety reasoning is a failure mode that cannot be detected from agent outputs alone (the agent appears to be reasoning carefully). Characterizing it informs when to add mandatory human review for override decisions.

**Relevant context:** Irregular 2026 safety overrides; calibration literature in ML; human-in-the-loop decision systems.
