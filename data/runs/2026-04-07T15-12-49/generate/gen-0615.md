# Formal Verification of Information Flow: Can Lean 4 Track Taint Propagation?

**Problem:** Information flow control (tracking which inputs can influence which outputs) is a key security property. Whether Lean 4 formal specifications can capture and verify taint analysis properties for AI-generated code is unknown.

**Direction:** Select 20 programs with known taint flow properties (user input reaching SQL query, secret reaching log output). Write Lean 4 specifications encoding non-interference or explicit information flow properties. Measure whether LLMs can generate proofs for these specs. Compare to automated taint analysis tools.

**Why it matters:** Information flow security is more expressive than functional correctness. Formally verified non-interference would provide mathematical guarantees against certain classes of injection and information disclosure vulnerabilities.

**Relevant context:** Information flow types are studied in academic verification (JIF, FlowCaml). Lean 4 can encode information flow as a type-level property. No study has attempted LLM-generated information flow proofs in Lean 4.
