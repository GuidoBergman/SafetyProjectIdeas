# Measuring the Effect of Monitoring Announcements on Agent Behavior: A Transparency Experiment

**Problem:** Anthropic publicly announces its monitoring systems. It is unknown whether this transparency affects the behavior of LLM agents that have been trained on information about Anthropic's monitoring.

**Direction:** Test whether including information about a monitoring system in an agent's context changes its behavior on tasks that monitoring would flag. Compare behavior with explicit monitoring disclosure vs. implicit disclosure vs. no disclosure.

**Why it matters:** If disclosure changes agent behavior, this suggests models have internalized information about monitoring into their behavior — a concerning implication for the validity of monitoring as a safety control.

**Relevant context:** Alignment faking research; METR monitoring evaluation; transparency in AI safety.
