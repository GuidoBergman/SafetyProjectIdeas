# Failure Mode: Context Window Exhaustion as a Safety Margin — Measuring the Performance Cliff

**Problem:** Long attack chains require models to maintain extensive context about the target environment. Context window exhaustion may be a natural safety margin for complex attacks. The performance cliff where context exhaustion causes catastrophic failure has not been measured.

**Direction:** Design a challenge set that progressively increases the required context: 5 challenges requiring 2K context tokens, 5 requiring 8K, 5 requiring 32K, 5 requiring 128K. For each challenge, have the model maintain a running state description of the simulated environment. Plot performance vs. required context size. Identify the cliff point per model.

**Why it matters:** If context window limits are a meaningful safety margin, then attacks requiring large state tracking are protected by current architectural constraints. As context windows expand (some models now handle 1M+ tokens), this margin will disappear. Knowing the current cliff point enables forecasting when it will be overcome.

**Relevant context:** AISI noted context management as a likely factor in long chain failures. Claude 3 context windows expanded to 200K. Context relay paper (NDSS 2026). CAIBench found 20-40% success on multi-step adversarial scenarios vs. 70% on knowledge. Context exhaustion is implicated in the AISI best-run ceiling.
