# Evaluating Agent Monitor Consistency: Do LLM Judges Give Consistent Ratings Across Rephrasing?

**Problem:** If an LLM-based monitor gives different ratings for semantically equivalent agent actions that are phrased differently, it is unreliable as a monitoring tool. This consistency property has not been tested.

**Direction:** Create pairs of semantically equivalent dangerous and benign agent actions with varying phrasings. Measure inter-phrasing consistency of an LLM monitor's ratings. Compute consistency score and identify phrasing patterns that cause rating reversals.

**Why it matters:** Monitor inconsistency means attackers can find phrasings that evade detection for dangerous actions. Measuring consistency is a prerequisite for certifying monitor reliability.

**Relevant context:** LLM judge consistency research; METR monitoring evaluation; monitor reliability.
