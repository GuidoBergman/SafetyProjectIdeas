# Evaluation Under Compute Constraints: Does the Compute Scaling Benefit Saturate at Consumer GPU Levels?

**Problem:** AISI's inference scaling results were documented using frontier API models with large token budgets. For attacker threat modeling, the relevant question is whether the scaling benefit persists at consumer compute levels (Colab Pro, single GPU) or requires expensive API access.

**Direction:** Run open-weight models (7B, 13B, 70B parameter ranges) at varying inference compute levels achievable on a single consumer GPU (token budgets from 1K to 50K). Plot performance on a 10-challenge CTF set against token budget. Test whether log-linear scaling holds at consumer compute levels or whether there is a ceiling before reaching the range studied by AISI.

**Why it matters:** If the scaling benefit requires expensive frontier API access, attackers face a cost barrier. If it manifests on consumer hardware, the attacker barrier drops dramatically. This directly informs threat models for well-resourced vs. resource-limited adversaries.

**Relevant context:** AISI documented log-linear scaling up to 100M tokens on frontier APIs. Open-weight models (Llama, Mistral, Qwen) deployable on single consumer GPUs. CAIBench evaluated multiple models. No published study tests inference scaling on open-weight models at consumer compute levels for offensive tasks.
