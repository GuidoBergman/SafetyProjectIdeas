# Designing Human-Readable Monitoring Dashboards: Does Visualization Affect Human Reviewer Decision Quality?

**Problem:** Human reviewers of agent monitoring alerts make better decisions with better visualizations. How monitoring data should be visualized for optimal human review quality has not been studied.

**Direction:** Build two monitoring dashboard designs: one showing raw log data, one showing structured visualizations (action timeline, risk score plot, key event highlights). Run a user study (N=20) measuring decision accuracy and time under each dashboard design.

**Why it matters:** Human review quality is a critical component of the monitoring chain. Optimizing dashboard design is a practical, implementable improvement with direct safety impact.

**Relevant context:** Human-computer interaction in security; human-in-the-loop monitoring; alert visualization.
