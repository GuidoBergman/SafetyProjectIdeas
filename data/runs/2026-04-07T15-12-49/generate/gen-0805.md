# Compounding Risk: Multi-Modal Injection + Content-Based Monitor Blindness — Can Visual Injections Evade All Text Monitors?

**Problem:** Visual modality injections (instructions in images) would evade all text-based monitoring systems by definition. This combination of multi-modal capability and text-monitor blindness is a systematic monitoring gap.

**Direction:** Embed prompt injection attacks in images that a multi-modal agent will process. Measure success rate of image-injected attacks vs. text-injected attacks. Test whether any text-based monitoring signals (agent output analysis, action timing) can detect image-injected attacks.

**Why it matters:** As multi-modal agents become standard, text-only monitoring architectures become systematically blind to a whole class of attacks. This study quantifies that blindness.

**Relevant context:** Visual prompt injection; multi-modal agent security; monitoring coverage gap; compounding risk.
