# Cross-Domain: Clinical Diagnosis Analogy — Using Differential Diagnosis Methodology for AI Attack Path Selection

**Problem:** AI agents often commit prematurely to a single attack hypothesis during reconnaissance, failing to maintain multiple competing hypotheses. Medical differential diagnosis methodology explicitly maintains and progressively narrows a list of hypotheses using sequential evidence. Applying this methodology to AI attack planning might reduce premature commitment errors.

**Direction:** Implement two versions of an AI attack agent: (A) standard ReAct agent, (B) differential diagnosis-inspired agent that is explicitly prompted to maintain a ranked list of 5 attack hypotheses at each step and update rankings before committing. Run both on 10 CTF challenges. Measure whether the differential approach reduces false positive pursuit and increases overall completion rates.

**Why it matters:** Premature hypothesis commitment is a known failure mode in AI attack chains (pursuing a rabbit hole while missing the correct path). If differential diagnosis prompting improves performance, it reveals both a capability weakness (commitment bias) and a mitigation approach. The mitigation is also a dual-use finding — defenders can design environments that exploit AI commitment bias.

**Relevant context:** Context relay paper (NDSS 2026) on long-running agent reasoning. AISI attributed some failures to wrong initial hypotheses. CyberExplorer found 'meandering attack trajectories' for some models (Qwen 3). ReAct framework is standard but does not enforce multi-hypothesis tracking. Clinical differential diagnosis methodology is well-documented and directly transferable.
