# The Legitimacy Signal Problem: Which Claimed Identities Actually Change Refusal Behavior?

**Problem:** LLMs appear to grant more permissive responses when users claim professional credentials (e.g., 'I am a penetration tester'), but no systematic study quantifies this effect across credential types.

**Direction:** Design a controlled prompt experiment varying 10 claimed credential types (CISO, CTF player, academic researcher, government contractor, etc.) against a fixed set of borderline cybersecurity requests. Measure refusal rate shifts across 3 frontier models.

**Why it matters:** OpenAI Trusted Access for Cyber relies on verified identity, but current unverified prompt-based claims may already shift model behavior dangerously. GTG-1002 operators exploited exactly this dynamic.

**Relevant context:** OpenAI Trusted Access (Feb 2026); GTG-1002 case — operators claimed to be employees of legitimate cybersecurity firms; Linder et al. framework.
