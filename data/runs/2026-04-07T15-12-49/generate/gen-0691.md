# Replicating Insider Threat Detection Methodology on AI Agent Logs

**Problem:** Traditional insider threat detection uses user behavior analytics (UBA) on human employee logs. This methodology has not been applied to AI agent logs to detect insider-threat-like behaviors.

**Direction:** Apply classical UBA techniques (peer group analysis, temporal anomaly detection, entity behavior profiling) to logs from an open-source agent framework. Measure whether these techniques detect injected insider-threat-like agent behaviors with acceptable false positive rates.

**Why it matters:** UBA is a mature field with proven techniques. Transferring it to agent monitoring could immediately improve detection capabilities without requiring new fundamental research.

**Relevant context:** Traditional UBA/UEBA security products; AI agent insider threat literature; Exabeam Agent Behavior Analytics.
