# AI-Powered Patch Quality Evaluation Rubric and Mini-Benchmark

**Problem:** AutoPatchBench (Meta 2025) exists but focuses on fuzzer-found bugs. There is no student-accessible benchmark for evaluating AI-generated patch quality across diverse vulnerability classes (injection, memory safety, logic flaws).

**Direction:** Curate 20 CVE-patched vulnerabilities with known ground-truth patches. Have multiple LLMs generate patches. Score each patch on: correctness, over-patching (unnecessary restrictions), test coverage, and explanation quality. Compute inter-rater reliability.

**Why it matters:** Patch quality matters as much as detection. A publicly available mini-benchmark enables iterative improvement and comparison.

**Relevant context:** Meta AutoPatchBench (April 2025) and Google CodeMender (October 2025) address patch generation, but evaluation rubrics for patch quality are not standardized or publicly available at small scale.
