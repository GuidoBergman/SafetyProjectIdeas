# The Formal Methods Capability Gap by Problem Type: Security vs. Algorithmic vs. Mathematical Tasks

**Problem:** Current Lean 4 benchmarks mix algorithmic, mathematical, and security-adjacent problems. Whether AI formal verification capability varies systematically by problem type (especially for security-critical tasks) is unknown.

**Direction:** Partition VeriBench tasks into three categories: mathematical/algorithmic, software correctness, and security-critical (bounds, overflow, injection). Measure LLM compilation and proof success rates per category. Identify which category is hardest.

**Why it matters:** If LLMs are much worse at security-critical formal verification than algorithmic verification, the safety implications of current benchmarks are being misread.

**Relevant context:** VeriBench includes 11 security challenges. The RAND report specifically calls for benchmarks covering the full spectrum of verification tasks. Comparing performance across these task types has not been done.
