# Causal Decomposition of Monitoring Failures: Attribution to Prompt Design vs. Model Choice vs. Threshold Setting

**Problem:** When a monitor fails to flag a dangerous action, the cause could be: bad monitoring prompt, wrong choice of monitoring model, or incorrect threshold. No methodology exists for attributing failures to these causes.

**Direction:** Collect a set of monitoring failures (false negatives). For each failure, ablate the three components: vary the monitoring prompt, swap the monitoring model, adjust the threshold. Quantify how much variance in failure rate each component explains.

**Why it matters:** Without causal attribution, monitoring improvements are guesswork. This methodology would allow systematic, evidence-based improvement of monitoring systems.
