# Experiment: AI Vulnerability Detection with and Without Commit History Context

**Problem:** Vulnerability-introducing commits often show suspicious patterns (late-night commits, pressure to merge, unusual author). AI scanners ignoring version history may miss contextual signals.

**Direction:** For 20 CVEs, collect the vulnerability-introducing commit and its git metadata (author, time, message, review comments). Run AI scanner on: (a) code only, (b) code + commit metadata, (c) code + commit history context. Measure detection rate and explanation quality per condition.

**Why it matters:** If commit history context improves detection, tools that integrate with git history are more effective. This informs tool design and data integration requirements.

**Relevant context:** Git history as a security signal is studied in security engineering (SZZ algorithm for bug-introducing commit detection). LLM vulnerability detection with git history context not studied.
