# Replicating Prompt Injection Detection on Code-Generating Agents

**Problem:** Most prompt injection research focuses on natural language outputs. Code-generating agents have a different output space (executable code) that creates new injection surfaces (code comments, variable names, exec calls).

**Direction:** Design prompt injection attacks specifically targeting code-generating agents (e.g., injecting malicious code through variable names or comments in retrieved code snippets). Test whether NL-focused monitoring classifiers detect these code-space injections.

**Why it matters:** Code-generating agents are widely deployed (GitHub Copilot, Claude Code, Cursor). Injection attacks via code space are a distinct threat that NL monitors may not cover.

**Relevant context:** Prompt injection research; code generation safety; OpenAI coding agent capabilities.
