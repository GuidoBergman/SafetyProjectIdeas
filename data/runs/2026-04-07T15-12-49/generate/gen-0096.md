# Compounding Failure: AI Credential Theft + Widespread Password Reuse = Automated Account Takeover at Scale

**Problem:** Two interacting failure modes: (1) AI agents can automate credential harvesting during multi-step attacks (Anthropic China case: 80-90% automation), and (2) enterprise password reuse rates remain high (studies consistently find 50%+ reuse). Combined, a single successful credential theft enables automated lateral movement across an entire enterprise through password reuse exploitation.

**Direction:** Design a simulation: (1) AI agent successfully harvests one credential set from a test environment, (2) measure how effectively the AI can use that credential set to enumerate password reuse across a simulated 20-account environment (using a local test database with configurable reuse rates). Vary reuse rates (0%, 20%, 50%, 80%) and measure how lateral movement coverage scales with reuse rate.

**Why it matters:** The compounding effect of AI credential theft + human password reuse habits could enable AI attacks to achieve near-total network compromise in environments with high reuse rates. This motivates both capability evaluation (how bad is it?) and defensive research (does MFA fully mitigate this compound risk?).

**Relevant context:** Anthropic espionage case: credential harvesting automated to 80-90%. Verizon DBIR consistently documents high enterprise password reuse. AISI corporate range includes credential access phase. Password reuse as an amplifier for lateral movement is well-known in practice but never formally studied in the context of AI automation.
