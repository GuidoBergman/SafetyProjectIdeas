# Dual-Use Request Annotation Tool: A Browser Extension for Labeling Cybersecurity Request Appropriateness

**Problem:** Building labeled datasets for dual-use refusal research requires expert annotation, but no tooling exists to streamline the annotation workflow for cybersecurity professionals.

**Direction:** Build a simple web-based annotation tool where annotators can label cybersecurity prompts across Linder et al.'s 5 dimensions (1-5 scale) plus a binary 'should refuse' judgment. Include annotation guidelines derived from Linder et al. Run a 30-prompt pilot with 3 annotators and measure inter-rater reliability.

**Why it matters:** Annotation tooling is prerequisite infrastructure for the RefusalQA dataset and other empirical dual-use governance research. Measuring inter-rater reliability validates whether the 5-dimension framework yields consistent human judgments.

**Relevant context:** Linder et al. arXiv:2602.15689; NIST AI 800-1 human evaluation provisions.
