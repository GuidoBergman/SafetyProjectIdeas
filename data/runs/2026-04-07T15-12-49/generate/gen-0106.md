# Follow-up to Cybench Saturation: Does High Performance on Cybench Predict Performance on Novel Post-Saturation Benchmarks?

**Problem:** Cybench saturated at 82-93% for frontier models. Several post-saturation benchmarks were created (CTFusion, harder CTF categories). It is unknown whether performance on the saturated Cybench predicts performance on these harder benchmarks — testing whether Cybench capability generalizes.

**Direction:** Correlate model performance data: collect Cybench scores and CTFusion/harder benchmark scores for the same set of 5-6 models where data is available. Compute correlation coefficient and R² between Cybench and harder benchmark performance. Test whether models that plateau on Cybench show systematic performance differences on harder benchmarks that Cybench cannot detect.

**Why it matters:** If Cybench scores at saturation (80%+) still predict performance on harder benchmarks, Cybench remains useful as an ordinal ranking tool even if it cannot measure absolute capability. If not, saturated scores are uninformative and labs using only Cybench are blind to real capability differences at the frontier.

**Relevant context:** Cybench 93% saturation (CAIBench, arxiv 2510.24317). CTFusion live CTF evaluation (OpenReview 2025). AISI multi-step ranges specifically designed as post-CTF-saturation evaluation. CAIBench meta-benchmark integrates multiple benchmarks but doesn't formally test predictive validity between saturated and non-saturated benchmarks.
