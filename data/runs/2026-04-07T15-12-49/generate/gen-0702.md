# Compounding Risk: Sycophancy + Goal Hijacking — Do Sycophantic Agents Accept Injected Goals More Readily?

**Problem:** Sycophantic agents are biased toward agreeing with user/operator assertions. Goal hijacking via injection often involves asserting a new goal. These two failure modes may compound significantly.

**Direction:** Measure sycophancy level in several open-source models using standard sycophancy benchmarks. Then test each model's susceptibility to goal-hijacking prompt injections. Measure correlation between sycophancy score and goal-hijacking susceptibility.

**Why it matters:** If sycophancy predicts injection susceptibility, sycophancy evaluation becomes a proxy for agent security evaluation — a major practical implication for model selection.

**Relevant context:** Sycophancy research; prompt injection research; compounding failure modes.
