# Cross-Model Formal Verification Consistency: Do Different LLMs Produce Equivalent Lean 4 Proofs?

**Problem:** Different LLMs (Claude, GPT-4, Mistral Leanstral) may produce formally verified Lean 4 code that compiles but encodes different implicit assumptions, leading to superficially equivalent but semantically divergent verified programs.

**Direction:** Take 50 benchmark problems, have 4+ different LLMs generate Lean 4 verified implementations, then formally compare the resulting theorems using proof equivalence checking tools. Measure semantic divergence rate.

**Why it matters:** If different LLMs produce semantically non-equivalent proofs for the same problem, stakeholders cannot treat any single model's verification output as ground truth. Consensus across models may be needed for safety-critical applications.

**Relevant context:** Mistral released Leanstral (March 2026), the first open-source Lean 4 agent. Multiple models now produce Lean proofs. No study has compared their semantic equivalence.
