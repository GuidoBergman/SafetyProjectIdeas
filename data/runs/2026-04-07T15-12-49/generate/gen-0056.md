# Multi-Agent vs. Single-Agent Offensive Performance: When Does Collaboration Help?

**Problem:** AWS demonstrated that multi-agent architectures (specialized sub-agents for reconnaissance, exploitation, post-exploitation) can overcome single-agent lateral movement failures. It is unknown how generally applicable this finding is: does multi-agent collaboration always help, sometimes help, or only help for specific bottleneck step types?

**Direction:** Run a 5-step attack chain in two conditions: (1) single agent handling all steps, (2) 3 specialized sub-agents (recon agent, exploitation agent, post-exploitation agent) coordinating via a shared state file. Measure step completion rate per condition. Test whether multi-agent improvement is concentrated at specific step types (the bottleneck steps identified in prior work).

**Why it matters:** If multi-agent architecture is a generally applicable capability multiplier, then the threat model for autonomous AI attacks is much more advanced than single-agent benchmarks suggest. Policy evaluations that only test single-agent performance may be systematically underestimating real-world capability.
