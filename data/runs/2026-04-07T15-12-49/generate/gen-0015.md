# Attack Surface Enumeration Quality: Benchmarking AI Reconnaissance Accuracy Against Ground Truth

**Problem:** Reconnaissance quality is a prerequisite for downstream attack success, but is rarely evaluated as a standalone capability. Models may find many false-positive vulnerabilities or miss critical services. No benchmark specifically measures reconnaissance precision and recall against a ground truth.

**Direction:** Set up a known-state virtual target (Metasploitable 2/3, DVWA, or VulnHub VMs) with exactly N documented vulnerabilities. Run AI agents and measure: (a) true positive rate (found documented vulnerabilities), (b) false positive rate (reported non-existent vulnerabilities), (c) completeness vs. severity. Compare across 3-4 models.

**Why it matters:** If AI reconnaissance has high false positive rates, it generates noise that overwhelms defenders. If it has systematic blind spots in specific service types, defenders know where to invest. Precision/recall metrics are more actionable than aggregate solve rates.

**Relevant context:** CyberExplorer benchmark (Blueinfy 2026) found models like Claude Opus 4.5 discover more unique vulnerabilities with higher precision. AISI found reconnaissance as the first bottleneck in the corporate range. AWS Security Agent multi-agent architecture (2025) specifically evaluated reconnaissance step quality.
