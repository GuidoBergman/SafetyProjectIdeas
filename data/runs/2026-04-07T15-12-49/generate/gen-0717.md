# Applying Formal Specification to Agent Behavior Constraints: Can TLA+ Express Monitoring Properties?

**Problem:** Formal specification languages (TLA+, Alloy) are used in traditional security to verify protocol properties. No study has applied formal specification to AI agent behavioral constraints.

**Direction:** Take a set of agent behavioral safety properties (e.g., 'never exfiltrate data without explicit authorization'). Express these in TLA+ or a simpler temporal logic. Generate test cases from the specification. Measure whether the formally-derived test cases surface monitoring failures missed by informal testing.

**Why it matters:** Formal specification forces precise articulation of safety properties and generates test cases that informal thinking misses. This is a force multiplier for monitoring system quality.
