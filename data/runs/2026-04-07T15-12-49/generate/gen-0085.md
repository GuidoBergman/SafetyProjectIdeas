# Follow-up to AIxCC: Do the Winning CRS Systems Transfer to Novel Vulnerability Classes Not in the Competition Corpus?

**Problem:** DARPA AIxCC teams processed 54M lines of code and found 43/54 synthetic vulnerabilities. It is unknown whether these Cyber Reasoning Systems (CRS) generalize to vulnerability classes not represented in the competition training corpus or whether they overfit to the competition's specific vulnerability distributions.

**Direction:** Using the open-source AIxCC CRS systems (4 released), test them against a set of 20 vulnerabilities from a different distribution: (1) vulnerability classes explicitly NOT in the competition scope, (2) code in languages underrepresented in competition (e.g., Rust, Go), (3) vulnerabilities in embedded/IoT code patterns. Compare solve rates to competition performance to measure generalization gap.

**Why it matters:** If CRS systems overfit to the competition corpus, claims about AI autonomous vulnerability discovery are overstated. If they generalize, the implications for mass automated security auditing (and autonomous zero-day discovery) are significant. Directly tests the generalization assumption underlying DARPA's release of these tools.

**Relevant context:** DARPA AIxCC (2025): 86% synthetic vulnerability coverage, 18 previously unknown real-world flaws, 4 systems open-sourced. Trail of Bits Buttercup (2nd place) team published some methodology. SoK AIxCC (arxiv 2602.07666v1) analyzes competition design and lessons learned. Generalization beyond competition domain is a known ML concern.
