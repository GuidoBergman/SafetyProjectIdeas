# Failure Mode: AI Security Scanners and Insufficient Handling of Third-Party API Calls

**Problem:** Security vulnerabilities often involve unsafe use of third-party APIs (e.g., calling an authentication API with insufficient validation). AI scanners may fail to model third-party API contracts and miss vulnerabilities arising from their misuse.

**Direction:** Collect 15 CVEs involving third-party API misuse (OAuth implementation errors, JWT validation bypass, cloud SDK misconfigurations). Run AI scanner with and without third-party API documentation as context. Measure detection rate change. Identify which API types require explicit documentation context for correct analysis.

**Why it matters:** Third-party API vulnerabilities are a major attack class and require knowledge of external contracts, not just the code under review. AI scanners lacking this context may systematically miss them.

**Relevant context:** OAuth/JWT vulnerabilities are well-documented (HackerOne reports). API security is OWASP API Top 10. AI scanner context augmentation with API documentation not studied specifically for API misuse CVEs.
