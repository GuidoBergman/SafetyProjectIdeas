# Novel Direction: Measuring the Effect of AI Security Tool Adoption on Developer Security Learning

**Problem:** AI security tools may either educate developers (by explaining vulnerabilities) or prevent learning (by automating security decisions developers would otherwise learn from). This effect on developer security knowledge is not studied.

**Direction:** Pre/post study with 20 CS students: give Group A six weeks of AI-assisted code review (AI flags and explains vulnerabilities), Group B six weeks of manual security review training, Group C no security review. Administer a code security knowledge test at the start and end. Measure knowledge gain per group.

**Why it matters:** If AI security tools prevent developer security learning, long-term security posture worsens even as short-term detection rates improve. This is a safety-relevant side effect of AI defense tools.

**Relevant context:** Developer security education is a studied field (Secure Code Warrior, research on security training effectiveness). AI security tool effect on developer learning not studied. Automation skill atrophy documented in aviation.
