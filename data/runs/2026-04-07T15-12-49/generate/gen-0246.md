# Experiment: AI Vulnerability Detection Across Levels of Code Obfuscation Used in Production

**Problem:** Production code undergoes legitimate obfuscation (minification, dead code elimination, inlining) as part of build pipelines. The effect of legitimate build-pipeline transformations on AI scanner performance is not characterized.

**Direction:** Take 15 vulnerable JavaScript functions. Apply a production build pipeline (Webpack with various optimization levels). Run AI scanner on: (a) source, (b) development build, (c) production build. Measure detection rate per build level. Identify at which optimization level detection becomes unreliable.

**Why it matters:** Real deployments use production builds, not source code. If AI scanners only work on source, they have limited value in deployment contexts where only production artifacts are available.

**Relevant context:** JavaScript minification is universal in web development. AI vulnerability detection on minified JavaScript not studied. This directly affects the practical value of AI scanning in deployment contexts.
