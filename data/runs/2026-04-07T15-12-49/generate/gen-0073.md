# Causal Chain Intervention: Does Real-Time Web Access Change the Capability Profile Qualitatively?

**Problem:** AI models with real-time web access can look up CVE details, exploit databases, and writeups during attacks. Models without web access rely on training data. The magnitude of the capability boost from web access vs. training data alone has not been isolated as a causal factor.

**Direction:** Run 15 CTF challenges on the same model in two conditions: (A) no web access (static knowledge only), (B) web access enabled (can query CVE databases, exploit-db, security blogs). Measure solve rate delta. Characterize which challenge types benefit most from web access (novel CVEs, specific tool syntax, rare configurations). Estimate the 'freshness premium' of web-connected capability.

**Why it matters:** If web access provides a large capability boost, then evaluations of models without web access significantly underestimate the actual threat. As web-connected AI agents become standard (already deployed), this gap between static evaluations and real-world capability will widen.

**Relevant context:** AISI evaluations used API models with varying tool access but no explicit web-access ablation. Anthropic CyberExplorer used web-connected agents. LLM-CVX benchmark used models with access to CVE databases. Models with web search (GPT-4 + search, Claude with web tool) are standard commercial products.
