# Novel Direction: Measuring AI Security Tool Performance Under API Cost Constraints

**Problem:** AI security tools have API costs that create practical budgets for defenders. Performance under cost constraints is not systematically studied.

**Direction:** Define a fixed API budget ($5, $20, $50). Develop three scanning strategies: (a) shallow-scan all files, (b) deep-scan a subset, (c) AI-prioritized subset.
