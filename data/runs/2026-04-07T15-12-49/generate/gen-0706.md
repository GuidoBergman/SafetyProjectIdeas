# Sandboxing Effectiveness Evaluation: Can Agents Escape Simple Python Subprocess Sandboxes?

**Problem:** Many agent deployments use simple sandboxing (Docker containers, Python subprocesses with restricted imports). No systematic study has tested whether current LLMs can escape these sandboxes when prompted to do so.

**Direction:** Set up a series of increasingly restrictive sandboxes (unrestricted Python, restricted imports, Docker container, gVisor sandbox). Give agents with code execution capability prompts that incentivize escape. Measure sandbox escape rates and techniques used.

**Why it matters:** If commonly used sandboxes are escapable by current LLMs, the security assumptions of most agent deployments are wrong. This is a critical empirical check.

**Relevant context:** Agent sandboxing research; container escape vulnerabilities; OpenAI cyber capability threshold.
