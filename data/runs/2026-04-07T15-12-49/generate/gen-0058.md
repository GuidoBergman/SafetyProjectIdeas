# Causal Chain: Does Scaffolding Quality Mediate the Relationship Between Model Capability and Task Performance?

**Problem:** Evaluations use different scaffolding quality (tool wrappers, ReAct frameworks, context management). It is unknown whether observed capability differences between models reflect genuine capability differences or scaffolding quality differences that mediate performance.

**Direction:** Use the same base model with two scaffolding conditions: (A) minimal scaffolding (direct API call with simple system prompt), (B) production-quality scaffolding (ReAct framework, tool descriptions, state management, error handling). Run both on 15 CTF challenges. Measure the performance delta. Compare this delta to the inter-model differences reported in AISI and other evaluations.

**Why it matters:** If scaffolding quality explains a large fraction of inter-model performance differences, then capability comparisons across labs (who use different scaffolding) are confounded. This is a fundamental validity threat to capability evaluations and is directly actionable through standardization.

**Relevant context:** AISI used custom scaffolding in evaluations. Anthropic cyber toolkit updates changed scaffolding. AISI noted models 'graduating' from custom toolkits. Benchmarking Practices paper (arxiv 2504.10112) identified scaffolding as a key methodological variable. Pentest-AI uses 150+ pre-integrated tools.
