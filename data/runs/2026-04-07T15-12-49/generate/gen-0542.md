# Applying Abstraction Refinement (CEGAR) to LLM-Guided Proof Search

**Problem:** Counterexample-Guided Abstraction Refinement (CEGAR) is a powerful technique in model checking that automatically refines abstract models when counterexamples are found. This iterative refinement paradigm could improve LLM proof search but has not been applied.

**Direction:** Implement a CEGAR-inspired Lean 4 proof search: LLM generates abstract proof sketch, Lean checker finds counterexample to sketch, LLM refines. Compare to standard iterative correction (error feedback only) on 30 VeriBench tasks. Measure iterations to success.

**Why it matters:** CEGAR is provably complete for finite systems and empirically efficient. Importing it into LLM proof search could provide more principled convergence guarantees than the current ad-hoc self-correction approach.

**Relevant context:** CEGAR is used in tools like SLAM, BLAST, and CPAchecker. LLM proof search uses unstructured self-correction. This is the first proposal to import CEGAR's structure into LLM-based Lean proof generation.
