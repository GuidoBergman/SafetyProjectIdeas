# Applying Memory Forensics Principles to LLM Agent Context Window Analysis

**Problem:** Memory forensics (analyzing RAM contents to reconstruct attacker activity) is a key technique in traditional incident response. The LLM context window is analogous to RAM — analyzing it during an incident could reveal attack details.

**Direction:** Simulate an agent compromise. After detection, analyze the full context window for forensic artifacts: what information the agent accessed, what instructions were injected, what plans were formed. Assess how much forensic value is recoverable from context window analysis.

**Why it matters:** Context window forensics could enable post-incident analysis that currently has no methodology. This study establishes its feasibility and limits.

**Relevant context:** Memory forensics in cybersecurity; agent incident response; context window analysis.
