# Testing Whether Linder et al.'s Framework Is Descriptive or Prescriptive of Actual Model Behavior

**Problem:** Linder et al. propose a normative framework for how refusal decisions should be made. Whether frontier models actually behave as if implementing this framework (even approximately) is an empirical question.

**Direction:** Design prompts with systematically varied Linder et al. dimension values (high/low Offensive Risk, high/low Defensive Benefit, etc.). Test if actual refusal rates correlate with the framework's normative predictions. Compute a 'framework alignment score' for each model.

**Why it matters:** If models already approximate Linder et al.'s framework, it is descriptive and may be stable. If they diverge, governance frameworks built on this normative model are misapplied to actual model behavior.

**Relevant context:** Linder et al. arXiv:2602.15689 explicitly normative framework; NIST AI 800-1 measurement approach.
