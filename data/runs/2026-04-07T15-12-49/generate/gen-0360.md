# Replicating Linder et al.'s Framework on Vision-Language Models: Does Image Context Change Cyber Refusals?

**Problem:** Linder et al. focus on text-based cybersecurity requests. Vision-language models can receive requests embedded in screenshots, diagrams, or code images, potentially bypassing text-based refusal.

**Direction:** Take 30 borderline cybersecurity text requests. Render them as: (a) screenshots of terminal output, (b) code editor screenshots, (c) handwritten whiteboard images. Test refusal rates for vision-capable models (GPT-4o vision, Claude 3.7 vision) vs. text-only equivalents.

**Why it matters:** Vision modality creates a parallel attack surface for dual-use requests. Governance frameworks that only address text inputs leave a systematic gap.

**Relevant context:** Linder et al. framework; multimodal model deployment trends 2025-2026; NIST AI 800-1.
