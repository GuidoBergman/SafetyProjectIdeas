# Measuring Whether Bug Bounty Programs for AI Safety Attract the Same Quality of Researchers as Security Bug Bounties

**Problem:** AI labs run bug bounty and bypass disclosure programs, but whether these attract comparable researcher quality and finding diversity to traditional software bug bounty programs is unknown.

**Direction:** Compare Anthropic's and OpenAI's AI safety bug bounty program structures (scope, rewards, disclosure process, safe harbor) against major software bug bounty programs (Google VRP, Microsoft Bug Bounty). Interview 5-10 security researchers about participation motivations. Assess whether the programs create sufficient incentives for high-quality dual-use governance research.

**Why it matters:** Bug bounty is the primary external adversarial governance mechanism. If it fails to attract quality researchers, governance has a systematic blind spot in external adversarial testing.

**Relevant context:** NCSC VDP for AI; OpenAI and Anthropic bug bounty programs; International AI Safety Report second update on crowdsourced testing.
