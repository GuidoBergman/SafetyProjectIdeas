# Causal Chain: Intervening on the Security Tool Configuration Gap

**Problem:** Security tools (AI and traditional) often have high false positive rates at default configurations, causing teams to disable or ignore them. The causal chain: poor default config → high FPR → alert fatigue → tool disabled → undetected vulnerabilities.

**Direction:** For three AI security tools, systematically vary key configuration parameters (sensitivity threshold, rule subsets, context depth). For each configuration, measure FPR and TPR on a ground-truth corpus. Identify configurations on the Pareto frontier (low FPR, high TPR). Assess whether default configurations are Pareto-optimal.

**Why it matters:** If default configurations are systematically suboptimal, teams could improve their security posture with no additional cost through better configuration. This is an immediately actionable finding.
