# Specification Arms Race: Formal Verification as a Target for Adversarial AI

**Problem:** If formal verification is used to gate deployment of AI-generated code, adversarial AI systems could be trained to satisfy the formal verification checker while violating the intent. The combination of AI optimization and formal spec misalignment creates an adversarial dynamic not yet studied.

**Direction:** Train or prompt an LLM to generate code that: (a) formally verifies against a given spec, but (b) intentionally violates the informal intent of the spec (by exploiting spec under-specification). Measure how easy this is. Test whether code review can catch the violation after formal verification passes.

**Why it matters:** If formal verification can be satisfied adversarially, it fails as a security gateway. This is the formal methods analog of goodhart's law: when a measure becomes a target, it ceases to be a good measure.

**Relevant context:** Adversarial examples against verification tools is a novel research direction. The general Goodhart's Law concern for AI safety measures is well-known. Applying it specifically to formal verification gating is not studied.
