# Cross-Domain Transfer: Applying Reliability Engineering FMEA to AI Defense Tool Design

**Problem:** Failure Mode and Effects Analysis (FMEA), standard in product reliability engineering, systematically enumerates failure modes, their effects, and their severity. Applied to AI security tool design, it could preemptively identify dangerous failure modes.

**Direction:** Conduct an FMEA for a canonical AI vulnerability scanner pipeline. For each component (code ingestion, analysis, report generation, patch suggestion), enumerate failure modes, effects, severity (S), occurrence (O), and detectability (D). Compute Risk Priority Numbers (RPNs). Identify the top 3 highest-RPN failure modes. Propose mitigations.

**Why it matters:** FMEA is a systematic, documented methodology for safety engineering. Applying it to AI security tools would produce a safety case — a formal argument for tool reliability — that does not exist for any current AI security tool.

**Relevant context:** FMEA is standard in automotive (ISO 26262), aerospace (MIL-STD-1629A), and medical devices (IEC 60812). Fault tree analysis for AI pipelines (see earlier idea). FMEA applied to AI security tools is novel.
