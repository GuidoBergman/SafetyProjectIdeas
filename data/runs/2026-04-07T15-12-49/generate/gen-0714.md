# Emergent Collusion Detection: Can a Third Agent Identify Coordination Between Two Compromised Agents?

**Problem:** No framework exists for monitoring inter-agent communication for emergent collusion. A third 'watchdog' agent approach has been proposed but never empirically tested.

**Direction:** Create two compromised agents that have been prompted to coordinate on a hidden objective. Deploy a third watchdog agent with access to their communication logs. Measure whether the watchdog can identify coordination patterns not present in baseline (non-coordinating) agent pairs.

**Why it matters:** If watchdog agents can reliably detect coordination, this provides a scalable defense mechanism for multi-agent deployments without requiring external monitoring infrastructure.
