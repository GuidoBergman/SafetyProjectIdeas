# Testing Whether Rate Limits as a Governance Mechanism Degrade Legitimate Defender Workflows Disproportionately

**Problem:** OpenAI Trusted Access uses monitoring including implicit rate limiting as a safeguard. Whether rate limits affect legitimate defenders (who may have high-volume automated workflows) more than attackers is unexplored.

**Direction:** Profile the API usage patterns of legitimate defensive security workflows (automated scanning, large-scale log analysis, mass phishing analysis) vs. inferred attacker usage patterns from GTG-1002. Compare against typical rate limit thresholds. Identify which workflows are most rate-limit constrained.

**Why it matters:** If rate limits are calibrated to block attacker volumes but also block legitimate high-volume defensive workflows, they create a disproportionate burden on the defenders the governance mechanism is supposed to protect.
