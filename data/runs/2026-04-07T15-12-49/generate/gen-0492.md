# Compounding Risk: Runtime Injection × Agent Memory Systems — Persistent Compromise via Memory Poisoning

**Problem:** Runtime injection attacks typically affect a single session. But agents with persistent memory (vector databases, summarized histories) could be compromised across sessions if injected instructions alter stored memories.

**Direction:** Set up an agent with a persistent memory store (simple vector DB of past interactions). Execute a runtime injection that embeds adversarial instructions in memory (e.g., a summarized past task that includes an embedded rule). In subsequent sessions with no active injection, measure whether the stored adversarial instruction influences agent behavior.

**Why it matters:** If runtime injections can persist via memory poisoning, the attack surface of agentic systems extends far beyond individual sessions. Memory systems require security controls analogous to persistent storage in traditional security.

**Relevant context:** Jiang et al. 2026 runtime supply chain; agent memory architectures; persistent prompt injection; RAG security.
