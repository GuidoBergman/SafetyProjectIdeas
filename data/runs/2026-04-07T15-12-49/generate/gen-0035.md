# Compounding Failure: AI Offensive Capability × Model Monoculture — When All Attackers Use the Same Model

**Problem:** Two interacting failure modes: (1) AI offensive capability is rapidly advancing, and (2) model homogeneity means attackers and defenders are using similar or identical base models. If the attacker and defender both use Claude-class models, the attacker may have structural advantages from asymmetric objectives (find one path vs. patch all paths).

**Direction:** Set up a red-blue simulation where both the offensive agent and the defensive classifier are running the same base model (same API, different system prompts). Compare to a condition where they run different models. Measure whether model identity match between attacker and defender changes success rates, suggesting the attacker can predict defender detection logic.

**Why it matters:** Monoculture amplifies correlated failures. If attackers know the defender model family, they may be able to generate exploits that systematically evade its specific detection logic. This is a concrete interaction between the homogeneity problem and the offense/defense asymmetry.

Agentic AI Security paper (arxiv 2510.23883v1) on multi-agent risk amplification.
