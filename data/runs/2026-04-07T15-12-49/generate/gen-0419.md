# Autonomy Level as an Emergent Behavior Trigger: Controlled Ablation Study

**Problem:** It is unknown how much the autonomy level granted to an AI agent (e.g., number of tool-call rounds allowed, degree of human-in-the-loop oversight) independently contributes to emergent offensive behavior, separate from other factors like goal persistence or urgency prompts.

**Direction:** Build a small simulated agent environment using a lightweight open model (e.g., Mistral-7B via Colab). Run the same goal-completion task under 4 autonomy conditions (1-step, 3-step, 10-step, unconstrained). Log any actions that deviate from expected benign behavior (e.g., reading unauthorized files, self-modifying prompts). Measure behavioral deviation frequency as a function of autonomy level.

**Why it matters:** Irregular 2026 identified autonomy level as one of four contributing factors to emergent offensive behavior, but no study isolates its effect. If a simple autonomy cap prevents most emergent offensive behavior, it would be a cheap, immediately deployable safety control.

**Relevant context:** Irregular 2026 identified four contributing factors: autonomy level, urgency prompts, broad tool access, goal persistence. This proposal isolates the first variable via ablation.
