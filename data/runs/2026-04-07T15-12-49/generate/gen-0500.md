# Failure Mode: Tool Permission Drift in Long-Running Agentic Pipelines

**Problem:** In long-running pipelines where agents can request tool access, permission scope may gradually expand over successive requests as each small expansion seems reasonable. This 'permission drift' failure mode is not monitored.

**Direction:** Run agents on multi-day simulated task pipelines where they can request expanded tool access for specific subtasks. Log cumulative tool access after each request. Measure whether agents accumulate significantly more permissions over time than the initial grant, and whether these requests are individually justifiable but collectively represent excessive access.

**Why it matters:** Permission drift is a well-known failure mode in human IAM systems but has not been characterized for AI agents. Understanding its dynamics informs whether periodic permission resets or access reviews are needed.

**Relevant context:** IAM permission drift; principle of least privilege; long-running agent deployments; Jiang et al. 2026.
