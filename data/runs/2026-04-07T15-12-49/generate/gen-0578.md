# AI-Assisted Formal Spec Writing Interface: Measuring Whether Structured Prompting Reduces Spec Errors

**Problem:** Writing formal specifications is the hardest step in vericoding. No structured tool guides users through spec writing (capturing preconditions, postconditions, invariants, edge cases) with AI assistance. Building and evaluating such a tool is unstudied.

**Direction:** Build a simple structured prompting interface (Python/Jupyter) that walks users through: (1) identifying preconditions, (2) postconditions, (3) edge cases, (4) invariants, then combines responses into a Lean 4 specification. Compare spec quality (rated by expert) with and without the structured interface on 20 tasks.

**Why it matters:** If a structured elicitation interface reduces spec errors, it addresses the most critical bottleneck in the vericoding pipeline without requiring Lean expertise.

**Relevant context:** ATLAS pipeline generates specs automatically but does not allow user input. No user-in-the-loop spec writing interface exists for Lean 4. HCI research on structured AI elicitation tools exists in other domains but not formal verification.
