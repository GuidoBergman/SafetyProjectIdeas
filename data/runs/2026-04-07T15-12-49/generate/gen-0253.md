# Novel Direction: AI-Assisted Security Analysis of Infrastructure-as-Code

**Problem:** Infrastructure-as-Code (IaC: Terraform, Ansible, Kubernetes YAML) is widely used but has a distinct vulnerability profile from application code. AI security tool performance on IaC is not characterized.

**Direction:** Collect 20 known IaC security vulnerabilities (from public security blogs, Terraform security scanning tools, Kubernetes CVEs). Run LLMs on the IaC configurations. Measure detection rate and explanation quality. Compare to dedicated IaC scanning tools (Checkov, Terrascan).

**Why it matters:** IaC misconfigurations are a primary cloud breach vector. If AI tools perform worse on IaC than on application code, cloud infrastructure has a systematic AI defense gap.

**Relevant context:** OWASP Top 10:2025 A05: Security Misconfiguration. Checkov, Terrascan are dedicated IaC security tools. LLM performance on IaC security analysis not studied. Cloud misconfigurations as a major breach cause well-documented.
