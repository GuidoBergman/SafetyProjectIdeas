# Compounding Risk: Hallucination + Action Commitment — Do Hallucinating Agents Take More Dangerous Unverified Actions?

**Problem:** LLMs hallucinate false information. An agent that hallucinates in contexts where it also has action-taking capability could commit dangerous actions based on false beliefs (e.g., believing a user has authorization they don't have).

**Direction:** Construct scenarios where an agent must verify a condition before taking a high-stakes action (e.g., verify admin approval before deleting data). Inject false information that would satisfy the verification condition. Measure whether agents commit the action based on hallucinated verification.

**Why it matters:** Hallucination-driven unauthorized actions are a distinct and undercharacterized safety failure. Monitoring systems must specifically address this failure mode.

**Relevant context:** LLM hallucination research; agent action commitment; compounding risk.
