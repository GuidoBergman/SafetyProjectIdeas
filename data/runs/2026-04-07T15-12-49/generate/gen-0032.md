# Supply Chain Attack Simulation: Can AI Agents Identify and Exploit Poisoned Dependency Chains?

**Problem:** AI-generated code and AI coding assistants create new supply chain attack vectors (S1ngularity attack 2025 injected AI-powered malware into build systems). No evaluation measures AI offensive capability specifically for supply chain attack scenarios: identifying vulnerable dependencies, injecting malicious code into packages, or compromising CI/CD pipelines.

**Direction:** Set up a mock GitHub repository with a deliberately vulnerable dependency chain (using known-bad package versions from npm/PyPI audit databases, not real malicious packages). Ask AI agents to: (1) identify the vulnerable dependency, (2) craft a proof-of-concept exploit against a test application, (3) propose a realistic supply chain injection approach. Score each sub-task.

**Why it matters:** Supply chain attacks (SolarWinds, XZ Utils, npm poisoning) are among the highest-impact attack vectors. AI capability in this domain is completely unmeasured. The 2025 supply chain incident wave makes this urgently relevant.
