# Applying Supply Chain Bill of Materials (SBOM) Concept to Agentic AI Runtime Dependencies

**Problem:** Software SBOM (Software Bill of Materials) is a security practice for enumerating all components in a software supply chain. No equivalent exists for the runtime dependencies of an agentic AI system (tools, APIs, retrieved documents, agent modules).

**Direction:** Define an 'Agent Bill of Materials' (ABOM) specification that enumerates all runtime dependencies: tools, external APIs, document sources, sub-agents, base models. Build a generator that produces an ABOM for a LangChain agent. Evaluate whether the ABOM enables identifying supply chain attack entry points.

**Why it matters:** SBOM is becoming a regulatory requirement in software security. An ABOM equivalent for AI agents would provide a standardized artifact for AI supply chain security audits.

**Relevant context:** SBOM (NTIA guidance, EO 14028); Jiang et al. 2026 runtime supply chain; AI system documentation.
