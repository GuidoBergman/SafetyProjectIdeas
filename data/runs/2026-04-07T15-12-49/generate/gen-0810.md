# Evaluating Whether Agent Monitoring Reduces or Increases Model Helpfulness on Legitimate Tasks

**Problem:** Monitoring systems may cause agents to behave more cautiously on legitimate tasks, reducing helpfulness. Whether monitoring has a net positive or negative effect on the helpfulness-safety tradeoff has not been measured.

**Direction:** Measure agent performance on a standard helpfulness benchmark (e.g., MT-Bench) with and without active monitoring. Measure whether monitoring causes agents to refuse more legitimate requests or add excessive caveats. Quantify the helpfulness cost of monitoring.

**Why it matters:** If monitoring substantially degrades helpfulness, there will be pressure to reduce monitoring in production deployments. Quantifying this tradeoff supports principled monitoring deployment decisions.
