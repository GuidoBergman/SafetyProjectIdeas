# Fault Tree Analysis Applied to AI Defensive Tool Failure Chains

**Problem:** Fault tree analysis (FTA), standard in aerospace and nuclear safety, models how component failures combine to produce system failures. It has not been applied to AI-powered defensive security tool pipelines.

**Direction:** Build a fault tree for a canonical AI-assisted vulnerability scanning pipeline (scan → triage → patch → deploy). Enumerate failure modes at each node (missed detection, wrong explanation, broken patch, deployment regression). Estimate failure probabilities using published data. Compute overall system failure probability.

**Why it matters:** FTA forces explicit reasoning about failure mode interactions and their probabilities. This could reveal that pipeline-level failure rates are much higher than tool-level benchmark performance suggests.

**Relevant context:** FTA is mandated in IEC 61508 (functional safety) and NASA standards. Its application to AI security pipelines is novel and relevant to safety engineering.
