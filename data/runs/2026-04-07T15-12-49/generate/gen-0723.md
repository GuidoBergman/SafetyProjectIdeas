# Causal Analysis: Does Monitoring Checkpoint Frequency Affect Attack Dwell Time?

**Problem:** Monitoring checkpoints (points where agent actions are reviewed before proceeding) reduce dwell time but add overhead. The optimal checkpoint frequency is an uncharacterized tradeoff.

**Direction:** Run agents on multi-step tasks with attack injections at various steps. Test monitoring at different checkpoint frequencies (every action, every 3 actions, every 10 actions, only at task boundaries). Measure dwell time and overhead for each frequency.

**Why it matters:** Optimal checkpoint frequency is a concrete, actionable design decision for agent deployments. This study provides the empirical basis for that decision.

**Relevant context:** METR monitoring design; agent safety checkpoint research; dwell time analysis.
