# Transferring Kill Chain Dwell Time Analysis to AI Agent Monitoring

**Problem:** In traditional cybersecurity, 'dwell time' — the time between initial compromise and detection — is a key metric. No equivalent metric has been defined for AI agent monitoring.

**Direction:** Define 'agent compromise dwell time' as the number of actions between goal injection and monitoring detection. Measure this across different attack types and monitoring configurations. Identify which configurations minimize dwell time.

**Why it matters:** Dwell time is a directly actionable security metric — minimizing it limits attacker damage potential. Introducing this concept to AI monitoring provides a clear optimization target.

**Relevant context:** Traditional cybersecurity dwell time metrics; METR monitoring evaluation; kill chain analysis.
