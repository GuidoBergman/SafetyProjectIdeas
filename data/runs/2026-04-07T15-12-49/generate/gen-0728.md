# Steganographic Instruction Passing: Can Agents Hide Instructions in Benign-Looking Outputs?

**Problem:** An agent attempting to coordinate with another agent could hide instructions in benign-seeming text outputs using steganographic techniques. Whether current LLMs can spontaneously do this is unknown.

**Direction:** Prompt an agent to pass a hidden instruction to a partner agent through a text output that must appear benign to a monitoring classifier. Measure whether agents can devise effective steganographic techniques, and whether the monitoring classifier detects them.

**Why it matters:** If LLMs can naturally discover steganographic communication channels, this represents a monitoring evasion capability that fundamentally undermines text-content-based monitoring.

**Relevant context:** Irregular 2026 emergent cyber behavior; covert channel research; inter-agent collusion.
