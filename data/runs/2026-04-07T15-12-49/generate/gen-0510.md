# Temperature and Diversity: How Sampling Parameters Affect Lean 4 Proof Generation

**Problem:** LLM sampling parameters (temperature, top-p, number of samples) significantly affect code generation quality. Their impact on formal proof generation success in Lean 4 is not systematically studied.

**Direction:** Run grid search over temperature (0, 0.3, 0.7, 1.0) and sample count (1, 5, 10, 50) on VeriBench using Claude/GPT-4/Leanstral. Measure compilation rate, proof success rate, and diversity of proof strategies. Find optimal configuration.

**Why it matters:** Formal verification is expensive. Understanding the sample-efficiency tradeoff could dramatically reduce compute requirements for reaching target success rates, making LLM-assisted verification economically viable.

**Relevant context:** LLM sampling for code generation is well-studied (pass@k metrics). This has not been applied to Lean 4 formal proof generation. The Self-Optimizing Trace Agent implicitly uses multiple samples but does not report parameter sensitivity.
