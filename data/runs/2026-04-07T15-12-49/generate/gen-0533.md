# Lean 4 Proof Failure Taxonomy: Systematic Classification of LLM Formal Verification Errors

**Problem:** When LLMs fail at Lean 4 formal verification, error types are classified loosely (compilation error, type error, proof incomplete) but no systematic taxonomy exists for what logical reasoning failures produce which error patterns.

**Direction:** Collect 300 failed Lean 4 proof attempts from public datasets and LLM runs on VeriBench. Manually code each failure into a taxonomy (type mismatch, wrong induction hypothesis, missing lemma, incomplete case analysis, wrong tactic order, etc.). Compute inter-rater reliability. Release as a labeled dataset.

**Why it matters:** A systematic failure taxonomy enables targeted improvement: if 40% of failures involve wrong induction hypotheses, training methods can specifically address that. Without taxonomy, improvement is undirected.

**Relevant context:** Lean 4 failure modes are mentioned qualitatively in VeriBench and BRIDGE papers but never systematically categorized. DARPA AIxCC SoK provides a model for systematic failure analysis that could be adapted.
