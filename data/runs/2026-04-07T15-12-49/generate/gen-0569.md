# Natural Language Spec Precision and Proof Success: Measuring the Correlation

**Problem:** Formal proof success likely depends on the precision of natural language input specifications. Whether more precise natural language specs lead to higher LLM proof success rates — and by how much — is not quantified.

**Direction:** Take 25 VeriBench problems. Create 3 natural language specification variants per problem: (a) minimal (docstring only), (b) medium (docstring + examples), (c) maximum (docstring + examples + edge cases + invariants). Run the same LLM on all 75 inputs. Measure compilation rate per spec level.

**Why it matters:** If spec precision is a strong predictor of proof success, the intervention is clear: improve input spec quality. This would motivate spec-elicitation tools as a component of safe AI code generation pipelines.

**Relevant context:** ATLAS generates specs from examples. AlphaVerus starts from Dafny specs. VeriBench uses consistent problem descriptions. Spec precision as an independent variable has not been systematically tested.
