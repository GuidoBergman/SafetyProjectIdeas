# Systematic Comparison: CTF Framing vs. Operational Framing vs. Knowledge Test — Three Paradigms for the Same Capability

**Problem:** Three evaluation paradigms exist for the same cyber capability: (1) CTF challenges (competitive puzzle-solving), (2) operational cyber range (simulated real-world attack), (3) knowledge tests (TACTL-style multiple choice). These paradigms likely produce different capability estimates for the same underlying capability. The convergent/discriminant validity between paradigms is unknown.

**Direction:** For each of 3 attack skills (web exploitation, privilege escalation, network enumeration), create all three test formats: a CTF challenge, a realistic range task, and 5 TACTL-style knowledge questions. Run 3-4 models on all 9 test items. Compute convergent validity (correlation between paradigms for same skill) and discriminant validity (lack of correlation between paradigms for different skills). Identify which paradigm has highest predictive validity.

**Why it matters:** OCCULT argues CTF ≠ real capability. TACTL tests knowledge ≠ execution. If the three paradigms converge, any can be used interchangeably. If they diverge, the choice of paradigm dramatically affects threat assessment. This is the fundamental validity study underlying all AI cyber evaluation.

**Relevant context:** OCCULT introduced TACTL knowledge tests (arxiv 2502.15797). AISI uses operational cyber ranges (arxiv 2603.11214). Cybench and NYU CTF Bench use CTF format. Potter SoK (arxiv 2504.05408) compared multiple evaluation approaches. This convergent validity study is missing from the literature.
