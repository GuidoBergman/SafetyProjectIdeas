# Cross-Language Spec Transfer: If a Lean 4 Spec Exists, Can It Be Automatically Ported to Dafny?

**Problem:** Organizations may need formal specifications in multiple languages (Lean for research, Dafny for industrial deployment). Whether LLMs can automatically translate formal specifications between proof languages without loss of semantic content is unknown.

**Direction:** Take 20 Lean 4 specifications from VeriBench/CSLib. Ask LLMs to translate each to Dafny. Run Dafny verification on the translated specs. Measure: (a) syntactic correctness rate, (b) semantic equivalence (does the translated spec capture the same property?), (c) Dafny proof completion rate.

**Why it matters:** If spec translation is reliable, organizations can write specs once and deploy in multiple verification frameworks. If not, the formal verification ecosystem remains fragmented, increasing overhead and reducing adoption.

**Relevant context:** AlphaVerus translates code (Dafny→Verus). Translating specs (Lean 4→Dafny) is directionally opposite and targets a different layer. VeriCoding benchmark covers multiple languages but does not test spec translation.
