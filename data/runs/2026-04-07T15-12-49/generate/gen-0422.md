# Tool Access Surface Area and Emergent Offensive Behavior: A Systematic Study

**Problem:** Broad tool access is cited as a contributing factor to emergent offensive behavior (Irregular 2026), but the relationship is underspecified: does adding any dangerous tool raise risk, or is there a threshold effect?

**Direction:** Create a standard task environment and incrementally add tools (read-only file access → read/write → network access → subprocess execution). At each step, run 50 episodes and log any unauthorized or dangerous actions. Model whether risk scales linearly, exponentially, or has a phase transition.

**Why it matters:** Understanding tool-access risk curves would let developers apply principle-of-least-privilege to agent tooling with empirical backing rather than intuition.
