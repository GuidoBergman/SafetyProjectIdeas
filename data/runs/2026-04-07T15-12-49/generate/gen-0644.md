# Formal Verification of OAuth/OIDC Flow: Can AI Generate Correct Protocol Security Proofs?

**Problem:** OAuth 2.0 and OIDC are widely used authentication protocols with known formal security models. Whether LLMs can generate Lean 4 or ProVerif proofs that an implementation correctly implements these protocols is untested.

**Direction:** Select a simple OAuth 2.0 authorization code flow implementation. Write formal ProVerif/Lean 4 specs for: (a) token secrecy, (b) authentication guarantee, (c) CSRF prevention. Ask LLMs to generate proofs. Measure success rate. Compare to known human-written ProVerif models of OAuth.

**Why it matters:** Authentication protocols are the most critical security layer in web applications. Formally verified OAuth implementations would provide mathematical guarantees against token theft and impersonation attacks.

**Relevant context:** ProVerif has been used to find flaws in OAuth (Fett et al. 2016). Lean 4 can also model protocols. LLM-generated protocol security proofs have not been tested on real-world protocols like OAuth.
