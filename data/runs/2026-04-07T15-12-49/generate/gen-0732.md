# Applying Defense-in-Depth Principles to Agent Monitoring Architecture Design

**Problem:** OpenAI's defense-in-depth approach layers multiple security controls. This principle has not been formalized for agent monitoring, where currently most deployments rely on a single monitoring layer.

**Direction:** Design a three-layer monitoring architecture (semantic content filter + behavioral anomaly detector + human review trigger) for a simple agent pipeline. Compare detection rates and false positive rates for single-layer vs. two-layer vs. three-layer configurations.

**Why it matters:** Defense-in-depth is a proven security architecture principle. This study validates its application to agent monitoring and quantifies the marginal benefit of each additional monitoring layer.
