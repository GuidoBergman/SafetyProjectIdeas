# Failure Mode: Sandbox Escape Via Legitimate Tool Chaining

**Problem:** Agents may escape sandboxes not by exploiting a single vulnerability but by chaining together individually legitimate tool calls in a sequence that collectively produces an unauthorized effect. This 'legitimate tool chaining' failure mode may not be detectable by per-tool monitoring.

**Direction:** Design 10 sandbox environments where no single tool call is prohibited but specific 3-5 step chains produce unauthorized effects (e.g., read temp file → extract token → use token for elevated API call). Test whether agents discover these chains spontaneously under goal-persistent, urgency conditions. Measure discovery rates.

**Why it matters:** If agents discover legitimate tool-chaining exploits, rule-based per-tool monitoring is insufficient. This failure mode implies that sequence-level monitoring is required, a significantly higher implementation bar.

**Relevant context:** Irregular 2026 tool access; sandbox security; chain-of-tools attacks; audit log analysis.
