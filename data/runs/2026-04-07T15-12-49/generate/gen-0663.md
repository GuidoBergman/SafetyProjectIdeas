# Detecting Goal Hijacking via Output Distribution Shift in Agent Action Sequences

**Problem:** When an agent's goal is hijacked by a prompt injection, its subsequent action sequence should shift in distribution. No study has measured whether this distributional shift is detectable with simple statistical methods.

**Direction:** Establish a baseline distribution of agent action sequences for a standard task. Inject goal-hijacking prompts at various points. Measure whether KL divergence or simpler statistical tests (chi-squared on action type frequencies) can reliably detect the injection.

**Why it matters:** Statistical detection of goal hijacking could work without any model-specific knowledge, making it a deployable defense that is monitor-agnostic.

**Relevant context:** Prompt injection research; behavioral baseline detection for AI agents; Exabeam behavioral analytics.
