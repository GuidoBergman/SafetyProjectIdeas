# Failure Mode: AI Security Scanners Applied to Minified/Compiled Code

**Problem:** Production code is often minified (JavaScript) or compiled to bytecode (Java class files). AI vulnerability scanners designed for source code may fail on these representations.

**Direction:** Take 15 JavaScript CVEs. Create three representations: (a) original source, (b) minified JavaScript, (c) TypeScript compiled to JavaScript. Run the same AI scanner on all three. Measure detection rate degradation per transformation. Also test on Java bytecode vs. source for 10 CVEs.

**Why it matters:** If defenders only have access to minified/compiled code (e.g., third-party libraries), AI defense tools may provide no value. This is a common real-world scenario.

**Relevant context:** AI vulnerability detection evaluated almost exclusively on source code. Real deployments often lack source code for dependencies. This gap is mentioned in practitioner discussions but not empirically studied.
