# Verified Patch Benchmark: Does AI-Generated Security Patch Actually Fix the Vulnerability?

**Problem:** AIxCC systems detected vulnerabilities and generated patches, but patch correctness verification was manual. No benchmark exists for formally verifying that a security patch eliminates the target vulnerability without introducing regressions.

**Direction:** Create a benchmark of 40 (vulnerability, patch) pairs from the AIxCC competition and public CVE disclosures. For each pair, attempt to write Lean 4/Dafny specifications that prove: (a) the patch eliminates the vulnerable behavior, (b) the original functionality is preserved. Measure LLM success rate on each task.

**Why it matters:** Automated patch verification is the missing link between vulnerability detection and confident remediation. If AI can both find and formally verify a patch, the security loop closes without human proof review.

**Relevant context:** AIxCC patched 61% of detected vulnerabilities. Patch correctness was validated by re-running tests, not formal proofs. AIxCC open-source release scheduled for August 2025 provides the data.
