# LLM Calibration for Lean 4 Proofs: Is Stated Confidence Correlated with Proof Success?

**Problem:** LLMs can be asked to express confidence in their Lean 4 proofs before submitting. Whether this expressed confidence is calibrated (higher confidence predicts higher success rate) is unknown and has safety implications.

**Direction:** Run 80 VeriBench tasks. For each task, ask the LLM to express confidence (0-10) that its proof will compile, then submit the proof. Measure calibration: plot confidence vs. actual compilation rate. Compute Expected Calibration Error. Test across 3 models.

**Why it matters:** If LLMs are poorly calibrated on formal proofs, expressed confidence cannot be used as a filter or triage signal. Calibration is a key safety property for human-AI collaboration in verification workflows.

**Relevant context:** LLM calibration is studied for factual claims and code generation, but not for formal proof generation. Given that proof success is binary and verifiable, this is an ideal domain for calibration measurement.
