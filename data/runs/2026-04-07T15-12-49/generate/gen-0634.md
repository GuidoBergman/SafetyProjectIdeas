# Formal Verification of Role-Based Access Control: A Near-Term Security Deployment Target

**Problem:** Role-based access control (RBAC) policies have formal models (RBAC96). Whether LLMs can generate Lean 4 proofs that an access control implementation correctly implements a given RBAC policy is unstudied.

**Direction:** Model an RBAC policy in Lean 4 (users, roles, permissions, constraints). Write formal specs for RBAC safety properties (role containment, separation of duties). Generate implementations using LLMs. Attempt to prove conformance to the formal RBAC model. Measure success rate.

**Why it matters:** Access control failures cause major security breaches. Formally verified RBAC implementation would provide mathematical guarantees that authorization logic is correct. This is a tractable, high-value near-term formal verification target.

**Relevant context:** RBAC96 model is well-formalized in the literature. Lean 4 can express the RBAC model. No study has attempted LLM-generated Lean proofs of RBAC implementations. This is a concrete formal verification security application.
