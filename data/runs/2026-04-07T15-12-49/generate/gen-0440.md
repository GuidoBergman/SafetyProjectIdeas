# Prompt Injection via Retrieved Context vs. User Input: Effectiveness Comparison

**Problem:** Prompt injection can arrive via user input or via retrieved external content (RAG, web browsing). Their relative effectiveness and detectability profiles may differ significantly.

**Direction:** Implement two injection delivery mechanisms: direct user-turn injection and injection embedded in a retrieved document. Use identical attack payloads in both conditions. Measure attack success rates and whether existing sanitization techniques work differently across delivery channels.

**Why it matters:** If retrieved-context injection is harder to defend against than user-input injection, it represents a higher-priority threat for RAG-based and web-browsing agents.
