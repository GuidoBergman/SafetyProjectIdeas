# Replication of LLM Honeypot Detection on a New Agent Framework

**Problem:** The LLM Agent Honeypot paper tested detection on SSH honeypots. Replicating this detection approach on web-facing agent APIs would validate whether the technique generalizes to different attack surfaces.

**Direction:** Deploy a simple web API that an LLM agent might access (fake file server, fake database endpoint). Embed prompt injection traps and timing probes. Run automated web-scraping agents and LLM-based agents against it. Measure detection rates for each agent type.

**Why it matters:** If honeypot detection generalizes across attack surfaces, it becomes a broadly deployable defensive tool. If not, understanding the failure cases shapes what honeypot designs work.

**Relevant context:** LLM Agent Honeypot (arXiv 2410.13919); extending to web API attack surface.
