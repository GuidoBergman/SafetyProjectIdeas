# Novel Direction: AI-Assisted Security Debt Quantification

**Problem:** Technical debt is a software engineering concept for deferred maintenance. Security debt — accumulated vulnerabilities and weaknesses not yet addressed — lacks a quantitative measure. AI could enable automated security debt scoring.

**Direction:** Define a security debt metric: weighted sum of (vulnerability severity × age × exploitability × patch availability). Use an LLM to compute this metric for 10 open-source projects. Validate by correlating security debt score with subsequent breach/CVE history. Compute inter-rater reliability of AI-generated scores.

**Why it matters:** Quantifying security debt enables prioritization and resource allocation. AI-automated security debt scoring could provide a continuous signal for maintainers.

**Relevant context:** Technical debt quantification is a studied SE research area. Security-specific debt quantification using AI is novel. CVSS scoring provides component inputs but not a debt score.
