# Characterizing False Positive Failure Modes: When Do Agent Monitors Over-Flag Benign Actions?

**Problem:** Much monitoring research focuses on false negatives (missed attacks). False positives (flagging benign actions) are also costly — they erode trust in monitoring systems and cause alert fatigue.

**Direction:** Run a set of standard, genuinely benign agent tasks through a monitoring classifier. Measure the false positive rate and categorize false positive types (overly cautious interpretation, domain mismatch, context misunderstanding). Propose mitigations for each category.

**Why it matters:** False positive reduction is as important as false negative reduction for operational monitoring. This study fills a gap by characterizing benign-side failure modes.

**Relevant context:** Alert fatigue in traditional security; METR monitoring evaluation; false positive analysis.
