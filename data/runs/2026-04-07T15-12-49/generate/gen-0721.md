# Testing Monitor Robustness to Instruction Smuggling via Base64 Encoding

**Problem:** Attackers might encode malicious instructions in Base64 or other encodings to evade content-based monitors. The effectiveness of this evasion technique against LLM-based monitors is unknown.

**Direction:** Implement a set of dangerous agent instructions. Present them to a monitoring classifier in plaintext vs. Base64 vs. ROT13 vs. unicode obfuscation. Measure evasion success rate for each encoding. Determine if LLM monitors can decode and evaluate obfuscated content.

**Why it matters:** If simple encoding defeats LLM monitors, attackers can easily bypass monitoring with minimal sophistication. This characterizes a basic robustness property of LLM-based monitoring.

**Relevant context:** Traditional security evasion (encoding); METR novel bypass vectors; LLM monitor robustness.
