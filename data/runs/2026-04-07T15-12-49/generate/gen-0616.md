# Stress Testing VeriBench: How Robust Are LLM Lean 4 Scores to Minor Problem Variations?

**Problem:** The 60% compilation rate and other benchmark scores may be highly sensitive to minor problem variations (different variable names, reordered function arguments). This robustness question is not tested.

**Direction:** Take 30 VeriBench problems. Create 5 semantically equivalent variants of each by: renaming variables, reordering function arguments, changing integer constants, reformatting docstrings. Run the same LLM on all 180 variants. Measure score variance across variants of the same problem.

**Why it matters:** High score variance across semantically equivalent problems would indicate that Lean 4 performance is not reliably measuring formal reasoning capability — it is sensitive to surface-level representation, which is a significant threat to benchmark validity.

**Relevant context:** Benchmark sensitivity to surface-level variations is studied in NLP (ANLI, BIG-Bench). For formal verification benchmarks, this question has not been asked. VeriBench is the standard benchmark, so its robustness matters for the entire field.
