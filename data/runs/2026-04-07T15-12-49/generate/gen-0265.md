# Experiment Variation: AI Vulnerability Detection Performance With and Without Known Exploit Code as Context

**Problem:** When a vulnerability is publicly known, exploit code (PoC) exists in public repositories. AI scanners could use this as additional context, but the effect of exploit context on detection quality is not studied.

**Direction:** For 15 CVEs with public PoC exploits, run AI scanner in two conditions: (a) code only, (b) code + brief exploit technique description (not the actual PoC). Measure: detection rate change, explanation quality change, false positive rate change. Identify whether exploit context improves or changes scanner behavior.

**Why it matters:** For known CVEs with public exploits, providing exploit context should improve AI detection. Understanding this effect enables practitioners to build better-contextualized scanning pipelines.

**Relevant context:** CVE databases often include exploit technique descriptions (ExploitDB, Metasploit modules). AI context augmentation for vulnerability detection not studied with exploit technique context specifically.
