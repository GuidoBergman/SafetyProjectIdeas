# Agent Identity Verification: Can Monitors Detect When an Agent Claims to Be a Different Agent?

**Problem:** In multi-agent systems, an agent might impersonate a more trusted agent to gain elevated permissions or bypass safety checks. Whether monitoring systems can detect identity spoofing is unknown.

**Direction:** Build a two-tier agent system (trusted coordinator + restricted worker). Have the worker agent attempt to impersonate the coordinator to gain elevated tool access. Measure whether a monitoring layer detecting the impersonation is feasible and what signals it uses.

**Why it matters:** Agent identity spoofing is a direct threat to multi-agent security architectures. Characterizing its detectability is necessary for designing trustworthy multi-agent systems.

**Relevant context:** Identity spoofing in traditional security; multi-agent security; instruction hierarchy integrity.
