# Compounding Failure: AI Code Generation + Insufficient Code Review = Automated Vulnerability Introduction at Scale

**Problem:** Two interacting failure modes: (1) AI code generation tools (GitHub Copilot, Cursor) introduce security vulnerabilities in generated code at measurable rates, and (2) developers increasingly accept AI-generated code without security review. Combined, AI coding assistants become automated vulnerability factories that create the attack surfaces AI offensive tools will later exploit.

**Direction:** Generate 100 code snippets using a coding AI for 5 common security-sensitive tasks (authentication, file upload, database query, API endpoint, session management). Run automated vulnerability scanning (semgrep, bandit, CodeQL) on generated code. Compute vulnerability introduction rate per task type and per model. Compare to a baseline of human-written code for the same tasks drawn from public repositories.

**Why it matters:** If AI code generation introduces vulnerabilities at significantly higher rates than human coding, and AI offensive tools can exploit these vulnerabilities, the combined effect is an accelerating offense-defense gap: AI creates vulnerabilities faster than humans can patch them. This compound risk is currently unmeasured.

**Relevant context:** GitHub Copilot security studies (arxiv 2509.22040). CIPHER benchmark: AI-generated code has cryptographic vulnerabilities.
