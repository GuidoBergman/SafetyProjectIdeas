# Defender Presence as a Variable: Measuring AI Offensive Capability Against Active vs. Passive Defenses

**Problem:** All existing cyber range evaluations use undefended networks. No published data exists on how AI offensive capability degrades (or does not) when facing active detection and response. This is the largest gap between benchmark performance and real-world threat.

**Direction:** Set up a minimal Capture-the-Flag environment using free tools (HackTheBox free tier, TryHackMe, or a local Metasploitable instance with Snort IDS configured). Run an AI agent (via API scaffolding in Python) against: (A) unmonitored target and (B) target with active IDS alerts that simulate defender response (e.g., firewall rules activating after detection). Measure steps completed and time-to-detection under each condition.

**Why it matters:** Every real network has defenders. The gap between benchmark (no defender) and real-world (active defender) performance is completely unmeasured. Even a modest experiment would be the first published data point on this crucial variable.

**Relevant context:** AISI 2026 and DeepMind 2025 both used undefended cyber ranges. MITRE OCCULT explicitly called out the absence of active defenders as a key limitation. HTB AI Range (Dec 2025) launched as the first platform to evaluate human-AI teaming including defensive operators — but no results on AI vs. active defender are published.
