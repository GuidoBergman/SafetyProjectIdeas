# Experiment: Systematic Comparison of AI-Assisted Vulnerability Scanning vs. Traditional SAST on the Same Corpus

**Problem:** AI-based scanners are often compared to each other or to manual review. A direct, controlled comparison to traditional SAST tools (Semgrep, CodeQL) on the same corpus with the same ground truth is not readily available.

**Direction:** Run Semgrep, CodeQL, and an LLM-based scanner (Claude via API) on 30 code samples with known CVEs. Use the same ground truth labels. Measure: detection rate, false positive rate, explanation quality, and cost per finding. Compute complementarity (does LLM find things SAST misses?).

**Why it matters:** Practitioners need to decide whether to add AI scanners alongside existing SAST tools. A controlled comparison with complementarity analysis answers this question directly.

**Relevant context:** MDPI AI vulnerability detection review (2025) notes LLMs vs. SAST comparison is important but not standardized. No head-to-head study with both cost and complementarity analysis found.
