# Sparse Attack Efficiency: Can AI Models Achieve Attack Objectives Using Fewer Tool Invocations Than Human Attackers?

**Problem:** AI agents may be noisy attackers — using more tool invocations and generating more detectable activity than human attackers. Or they may be surgically efficient. This 'attack noise' property has not been measured and is directly relevant for detection probability.

**Direction:** Solve 10 CTF challenges with 3 conditions: (1) AI agent with no efficiency constraint, (2) AI agent explicitly prompted to minimize tool invocations, (3) human expert attempting same challenges. Count total tool invocations per challenge per condition. Compute 'attack noise ratio' (AI invocations / human invocations). Test whether efficiency-constrained prompting significantly reduces noise.

**Why it matters:** If AI attacks generate 10x more network traffic and tool invocations than human attacks, they are inherently more detectable. If AI attacks are as sparse as human attacks, defenders cannot rely on volume-based anomaly detection. Measuring this property is essential for calibrating network detection thresholds for AI-specific attack patterns.

**Relevant context:** CyberExplorer found Qwen 3 produces 'longer, more meandering attack trajectories' vs. Claude models. AISI noted total token counts as a proxy for attack effort. DARPA AIxCC efficiency metrics (45 min average). Human expert penetration testing generates specific tool call patterns documented in SANS training. No comparative efficiency study exists.
