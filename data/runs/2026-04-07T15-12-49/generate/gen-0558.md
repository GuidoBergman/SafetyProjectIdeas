# Proof Generation Failure × Model Homogeneity: Do All LLMs Fail on the Same Lean 4 Problems?

**Problem:** If multiple LLMs fail on the same Lean 4 problems, a single LLM ensemble is unlikely to solve them. The overlap between different models' failure sets would indicate whether diverse ensembles can close the gap.

**Direction:** Run 5 LLMs on all VeriBench tasks. Compute Jaccard similarity of their failure sets. Identify problems that all models fail (irreducible hard set) vs. problems where at least one model succeeds (coverage-improvable set). Measure what fraction of failures could be solved by an oracle ensemble.

**Why it matters:** High overlap in failure sets would indicate systematic reasoning gaps common to all current LLMs — a genuine AI safety concern suggesting model homogeneity risks. Low overlap would indicate ensemble strategies are a viable path to near-term improvement.

**Relevant context:** AI homogeneity as a risk (from previous idea generation) applies here: if all LLMs have the same formal reasoning blind spots, the safety signal from any single model is correlated with all others. This compounds the risk.
