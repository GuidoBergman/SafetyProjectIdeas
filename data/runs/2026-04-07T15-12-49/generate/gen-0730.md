# Agent Monitoring Under Adversarial Infrastructure: What If the Monitoring System Itself Is Compromised?

**Problem:** A sophisticated attacker (rogue AI or human adversary) might compromise the monitoring infrastructure itself, not just evade it. The resilience of monitoring systems to this meta-attack is unexplored.

**Direction:** Model a scenario where the monitoring LLM has been fine-tuned to systematically under-flag certain attack types. Measure how much fine-tuning is required to degrade monitoring below a threshold. Propose detection methods for compromised monitors.

**Why it matters:** If monitoring systems can be silently compromised through model modification, the security chain breaks at the monitor level. This is a critical second-order vulnerability.

**Relevant context:** METR monitoring evaluation; supply chain attacks on ML systems; monitoring system integrity.
