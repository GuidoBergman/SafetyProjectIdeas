# Testing Whether Organizational Context in System Prompts Changes Over-Refusal Rates for Legitimate Security Workflows

**Problem:** Defenders embedded in enterprise security operations may use AI with organization-specific system prompts. Whether these contexts reduce over-refusal for legitimate security work is untested.

**Direction:** Design 30 legitimate security task prompts. Test in 4 conditions: no system prompt, generic enterprise system prompt, cybersecurity company system prompt, 'you are an AI assistant for a SOC team' system prompt. Measure over-refusal rate changes per condition.

**Why it matters:** If organizational system prompt context effectively reduces over-refusal, enterprises can operationalize governance improvements without waiting for model retraining. This informs practitioner guidance.
