# Replication with Multimodal Twist: Can Vision-Capable Models Use Screenshot-Based Environments More Effectively?

**Problem:** Current AI cyber evaluations use text-only terminal interfaces. Many real attack surfaces involve web GUIs, graphical admin panels, and visual dashboard data. Vision-capable models (GPT-4V, Claude vision) may have significantly different performance profiles when given screenshot-based interfaces vs. text-only.

**Direction:** Create 10 web application attack scenarios where the target is a graphical web interface. Run each scenario in two conditions: (A) text-only (HTML source provided as text), (B) screenshot-based (model sees rendered screenshots). Compare solve rates. Test whether vision capability provides a significant advantage for specific task types (CAPTCHA bypass, visual path analysis, dashboard enumeration).

**Why it matters:** If multimodal models significantly outperform text-only models on visual attack surfaces, this represents an uncharted capability dimension that text-only evaluations completely miss. Web application attacks are the most common real-world attack surface and many now have visual interfaces.

**Relevant context:** No published study tests vision capability for offensive cyber tasks. CyberExplorer used text-based environments. AISI corporate range used terminal-based interfaces. Vision models (GPT-4V, Claude-vision) are widely deployed. GitHub Copilot AI code generation has visual component. This is a clear gap in existing evaluations.
