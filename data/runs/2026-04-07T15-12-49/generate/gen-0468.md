# Applying Anomaly Detection in Industrial Control Systems to Agent Process Monitoring

**Problem:** Industrial Control Systems (ICS) security uses process-based anomaly detection (monitoring physical process values for deviation from expected operating ranges). The same concept — monitoring a process signature for deviation — has not been applied to agent action streams.

**Direction:** Define 'normal operating range' for agent process metrics (actions-per-minute, tool call distribution, context growth rate, response latency). Use ICS-inspired thresholds (based on 3-sigma deviations from baseline). Test whether these process metrics flag emergent offensive behavior episodes before they complete a kill chain stage.

**Why it matters:** ICS anomaly detection is designed for high-reliability, low-false-positive environments. If its principles transfer, organizations could apply operationally proven detection logic to agent monitoring.

**Relevant context:** ICS security anomaly detection (NIST SP 800-82); Jiang et al. 2026 runtime monitoring; METR 2026.
