# Attack Trajectory Variance Analysis: Is AI Offensive Capability Deterministic or Stochastic?

**Problem:** Models use stochastic sampling, meaning the same model on the same challenge may succeed in one run and fail in another. The variance structure of AI attack attempts has not been characterized: how many attempts does it take to achieve a given success probability, and does variance decrease with model capability?

**Direction:** Run 20 independent attempts of the same 10-challenge set using a single model at fixed temperature. Plot success rate distributions per challenge. Compute coefficient of variation. Test whether higher-capability models have lower variance (more reliable) or higher variance (more creative but inconsistent). Estimate the number of attempts needed for a 90% success probability.

**Why it matters:** If AI attacks are highly stochastic, attackers can achieve high success rates simply through repeated attempts — the 'best-of-N' threat model. AISI's single-attempt vs. 10-attempt scoring already hints at this. Characterizing variance structure is essential for realistic threat modeling.

**Relevant context:** AISI evaluated models with multiple attempt budgets. Claude Sonnet 4.5 went from 38% to 76.5% with 10 attempts (Mindgard 2026). AISI best run was 22/32 (single run out of multiple). Stochastic sampling in LLM outputs is fundamental but under-studied for security applications.
