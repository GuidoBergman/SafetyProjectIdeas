# Coding Framing Effect: Does Presenting Requests as Code vs. Natural Language Change Refusal?

**Problem:** Security researchers often embed requests in code comments, function names, or docstrings. It is unknown whether code-form framing systematically evades refusal.

**Direction:** Take 30 borderline cybersecurity requests. Rephrase each in: (a) natural language, (b) Python docstring, (c) shell script comment, (d) JSON config schema, (e) pseudocode. Measure refusal rates across 4 models. Test if code modality shifts refusal rates significantly.

**Why it matters:** Code-embedded dual-use requests are common in legitimate pen-testing workflows but could also represent evasion vectors. Understanding modality sensitivity informs refusal policy design.

**Relevant context:** Linder et al. Technical Complexity dimension; NIST AI 800-1 cybersecurity appendix.
