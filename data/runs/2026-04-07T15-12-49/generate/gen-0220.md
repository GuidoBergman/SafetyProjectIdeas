# Novel Direction: Tracking AI Security Tool Capability Improvement Using a Fixed Benchmark Over Time

**Problem:** There is no longitudinal tracking of AI defensive capability improvement over time (CLAUDE.md open problem). A fixed benchmark run on successive model versions would provide this tracking.

**Direction:** Define a fixed benchmark of 30 vulnerability detection tasks (spanning memory safety, injection, logic flaws). Run the benchmark on 4-5 successive versions of the same AI model (using API versioning where available) or on models released in chronological order. Plot detection rate, FPR, and explanation quality over time. Identify improvement trends.

**Why it matters:** Longitudinal capability tracking is foundational for the field. Without it, we cannot assess progress or forecast when AI defense will be reliable enough for deployment.

**Relevant context:** DARPA AIxCC showed 37%→86% detection improvement in one year, but this was a single competition event, not a longitudinal benchmark. CLAUDE.md explicitly lists this as an open problem.
