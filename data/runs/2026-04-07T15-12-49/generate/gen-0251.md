# Novel Direction: Studying Misalignment Between AI Security Tool Objectives and Defender Goals

**Problem:** AI security tools are optimized for measurable metrics (detection rate, FPR) that may not perfectly align with defender goals (risk reduction, breach prevention, minimum analyst burden). This misalignment may cause AI tools to maximize metrics while not improving real-world security.

**Direction:** For three AI vulnerability scanners, document their stated objective (what they optimize for). For each, identify a scenario where optimizing the stated objective diverges from real security improvement (e.g., finding many low-severity issues while missing one critical one). Quantify the divergence on a test corpus. Propose better-aligned objectives.

**Why it matters:** This is an AI alignment problem in miniature. Security tools optimizing the wrong metric cause organizations to misallocate defensive effort. Understanding the misalignment gap enables better tool design.

**Relevant context:** Goodhart's Law: when a measure becomes a target, it ceases to be a good measure. Applied to AI security tool metrics, this is unexplored. Risk-stratified benchmarking (see related idea) is a partial remedy.
