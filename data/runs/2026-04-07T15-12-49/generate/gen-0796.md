# Testing Whether Agent Monitors Can Be Manipulated Through Indirect Context Injection via Tool Outputs

**Problem:** Agent monitors review the entire agent context, including tool outputs. If tool outputs can be manipulated by an attacker (e.g., an adversarial web page returned by a search tool), the monitor can be targeted indirectly.

**Direction:** Craft adversarial tool outputs (search results, file contents, API responses) containing instructions specifically designed to manipulate a monitoring LLM. Test whether these indirect injections can cause the monitor to pass dangerous agent actions or suppress legitimate alerts.

**Why it matters:** Indirect injection attacks on monitors are a second-order attack that bypasses monitoring without directly attacking the agent. This study characterizes a specific, novel attack vector.

**Relevant context:** Indirect prompt injection; METR novel bypass vectors; RAG security; monitor manipulation.
