# Novel Direction: Differential Security Analysis Using Multiple AI Models as a Team

**Problem:** Individual AI models have consistent blind spots. Using multiple models and comparing their findings could identify vulnerabilities that any single model misses.

**Direction:** Run three AI models (Claude, GPT-4o, Gemini) independently on 20 vulnerable code samples. Compute: agreement rate, disagreement patterns, and whether the union of all three models' findings covers more vulnerabilities than any individual model. Measure the marginal detection gain from adding each model.

**Why it matters:** If models have complementary blind spots, ensemble approaches could dramatically improve defensive coverage. This is an actionable insight for deployers.

**Relevant context:** Ensemble methods in ML are well-established. Multi-model security analysis as a deliberate defensive strategy has not been studied. Published AI vulnerability detection research uses single models.
