# Measuring the Cost of Defense: What Is the Minimum Defensive Investment That Neutralizes Current AI Offensive Capability?

**Problem:** AI offensive capabilities have been measured extensively, but the minimum defensive investment required to neutralize them has not. Policy requires both sides of this equation: knowing that AI can complete 22/32 steps is only actionable if we also know what defensive deployment stops it at step 5.

**Direction:** Take a 10-step attack scenario. Measure AI completion rate under: (A) no defenses, (B) IDS with default rules ($0 additional), (C) IDS + network segmentation (simulated), (D) IDS + segmentation + honeypots, (E) full layered defense. For each condition, compute steps completed and estimate defensive implementation cost. Plot capability vs. defensive cost tradeoff curve.

**Why it matters:** The most directly policy-relevant question in AI offensive capability evaluation is: what defensive posture is adequate? Answering this requires measuring both offensive capability and defensive effectiveness together, which no published evaluation does. This cost-benefit analysis would be directly actionable for security architects.

**Relevant context:** AISI used undefended ranges. NCSC: £65 per AI attack attempt. DARPA AIxCC: $152 average remediation cost. SoK Potter et al. called for prioritized defensive mitigations. Defensive cost estimation is standard in security ROI analysis but never applied to AI capability containment specifically.
