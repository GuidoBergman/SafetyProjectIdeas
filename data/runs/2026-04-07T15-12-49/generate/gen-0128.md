# Measuring Defensive Capability Improvement Over Time: A Longitudinal Snapshot Study

**Problem:** There is no longitudinal tracking of defensive AI capability improvement analogous to DARPA AIxCC's 37%→86% detection improvement metric.

**Direction:** Re-run a fixed set of vulnerability detection tasks (drawn from public CVE data) on the same LLM across multiple publicly released model versions (e.g., GPT-4o vs. GPT-4o-mini vs. Claude 3.5 Sonnet), recording detection rate, false positives, and explanation quality. Treat model version as a temporal proxy.

**Why it matters:** Provides preliminary data on whether newer models actually improve on defensive tasks, not just offensive benchmark performance.

**Relevant context:** DARPA AIxCC showed 37%→86% jump in one year (Irregular 2026 report). But this was on competitive/synthetic tasks. Real-world longitudinal data on defender-relevant tasks is absent.
