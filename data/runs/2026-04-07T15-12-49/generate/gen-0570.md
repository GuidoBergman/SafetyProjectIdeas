# Few-Shot Example Selection for Lean 4: Does Domain Proximity of Examples Improve Proof Success?

**Problem:** Few-shot examples in Lean 4 proof prompts can be chosen from: (a) same problem domain, (b) similar proof structure, (c) random selection. Which selection strategy most improves proof success is unknown.

**Direction:** For 30 VeriBench tasks, generate proofs under three few-shot conditions: (a) 3 examples from the same domain (sorting, graph algorithms, etc.), (b) 3 examples with similar proof structure (induction, case analysis, etc.), (c) 3 random examples. Measure compilation rate per condition.

**Why it matters:** Optimal few-shot selection would maximize Lean 4 proof success without additional compute. For safety applications where each proof attempt is expensive, selection strategy matters.

**Relevant context:** Few-shot example selection is studied in code generation (e.g., retrieving semantically similar examples). For formal verification, this has not been tested. The Self-Optimizing Trace Agent uses fixed examples.
