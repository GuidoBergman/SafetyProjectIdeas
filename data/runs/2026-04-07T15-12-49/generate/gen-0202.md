# AI Defense Tool Interoperability: Can Tools Share Findings Effectively?

**Problem:** Different AI security tools may find different subsets of vulnerabilities. A pipeline that aggregates findings from multiple tools needs a deduplication and prioritization mechanism. No standard interoperability format or aggregation methodology exists.

**Direction:** Run three AI security tools (an LLM, Semgrep, CodeQL) on the same 20-file corpus. Develop a simple finding aggregation protocol: deduplicate by location + class, merge confidence scores, rank by combined score. Measure: recall of aggregated findings vs. individual tools. Evaluate three deduplication strategies.

**Why it matters:** Multi-tool pipelines are common in production security. Aggregation quality determines whether the pipeline inherits the best or worst properties of constituent tools.

**Relevant context:** SARIF (Static Analysis Results Interchange Format) exists for tool interoperability. Multi-tool aggregation quality for AI+SAST combinations not studied. This directly addresses a practitioner pain point.
