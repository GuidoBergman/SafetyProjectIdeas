# Measuring AI Vulnerability Detection Performance on Cryptographic Implementation Flaws

**Problem:** Cryptographic implementation vulnerabilities (timing attacks, weak PRNG seeding, padding oracle, etc.) require specialized domain knowledge to detect. AI model performance on this specific class is not characterized.

**Direction:** Collect 15 CVEs from cryptographic libraries (OpenSSL, libsodium, NSS). Run three LLMs on the source code. Measure detection rate and explanation correctness for cryptographic vs. non-cryptographic CVEs from the same libraries. Test whether detection rate differs by class.
