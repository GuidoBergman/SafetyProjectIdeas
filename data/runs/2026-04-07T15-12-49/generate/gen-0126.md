# Defensive Benchmark Suite for AI-Assisted Code Review: A Gap-Filling Effort

**Problem:** No defensive benchmark equivalent to offensive ones (Cybench, AIxCC) exists. We cannot measure how well AI assists defenders vs. attackers in a standardized way.

**Direction:** Design and evaluate a small-scale benchmark of N=50 real code snippets (drawn from public CVE datasets) comparing AI-assisted detection rates, false positive rates, and time-to-triage across multiple LLMs in a controlled experiment.

**Why it matters:** Without defensive baselines, the field cannot track progress, compare tools, or justify investments. A student-scale prototype demonstrates methodology for a larger community effort.

**Relevant context:** CAIBench (arXiv 2510.24317) covers offensive/defensive domains but focuses on agent evaluation. Microsoft ExCyTIn-Bench targets SOC investigation. No benchmark specifically measures AI-assisted code review in a defender-first framing.
