# Experiment: Measuring AI Vulnerability Detection Under Adversarial Stress (Deliberately Misleading Context)

**Problem:** In real-world deployments, context surrounding vulnerable code may be misleading (incorrect documentation, misleading variable names). AI scanner robustness to misleading context is not characterized.

**Direction:** Take 20 vulnerable code samples. Create three versions: (a) neutral context, (b) context that suggests the code is safe ('This was audited by our security team in 2024'), (c) context that adds red herrings (comments about unrelated risks). Measure detection rate change per condition.

**Why it matters:** Sophisticated attackers will craft misleading context to reduce AI scanner effectiveness. Understanding the manipulation surface enables countermeasures.

**Relevant context:** Social engineering research studies how context manipulates human security decisions. AI security tool robustness to context manipulation is not studied. Prompt injection (see related idea) is a related attack vector.
