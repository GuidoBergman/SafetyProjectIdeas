# Measuring Refusal Rate Consistency Across Prompt Formatting Styles Within a Single Request

**Problem:** Whether adding headers, bullet points, numbered lists, or markdown to a request affects refusal rates has not been studied—yet format is trivially manipulable by users.

**Direction:** Take 20 borderline cybersecurity requests. Reformat each in: plain text, markdown headers, numbered steps, table format, and JSON structure. Test refusal rates across 4 models. Measure if format alone (with identical semantic content) shifts refusal rates.

**Why it matters:** If formatting trivially changes refusal rates, governance frameworks assuming semantic refusal evaluation are overstated. This informs robustness requirements for safety training.

**Relevant context:** Linder et al. 5-dimension framework; NIST AI 800-1 evaluation methodology.
