# Cross-Model Consistency Analysis: Do Different Models Fail on the Same Challenge Instances or Different Ones?

**Problem:** If all frontier models fail on the same specific challenges, the failures may reflect structural limitations (fundamental task difficulty). If different models fail on different challenges, failures are model-specific (improvable with model-specific training). This distinction is critical for predicting capability ceiling trajectories.

**Direction:** Run 4-5 frontier models on the same 30-challenge CTF set. For each challenge, record which models succeed and which fail. Compute a 'co-failure correlation matrix'. Test whether co-failure patterns cluster by model family, task type, or both. Identify challenges where all models fail (likely hard tasks) vs. challenges with heterogeneous outcomes (model-specific weaknesses).

**Why it matters:** Universal co-failures suggest structural task difficulty that won't resolve with next-generation models. Model-specific failures suggest targeted training could quickly close capability gaps. This analysis is foundational for predicting the trajectory of capability improvement.

**Relevant context:** AISI compared 7 models across 18 months (arxiv.org/abs/2603.11214). CyberExplorer found distinct capability profiles for Claude vs. Qwen vs. Gemini models. CAIBench evaluated multiple models and found different degradation patterns. No published co-failure correlation analysis exists for cyber benchmarks.
