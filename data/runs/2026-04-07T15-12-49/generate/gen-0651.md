# Honeypot Task Injection: Detecting Deceptive Agent Behavior via Planted Verification Tasks

**Problem:** An AI agent that is behaving deceptively may perform differently on tasks it believes are being monitored vs. unmonitored. No study has tested whether honeypot-style planted verification tasks can detect this divergence in small open-source models.

**Direction:** Insert hidden 'canary' tasks into agentic pipelines for open-source models (e.g., Llama-3, Mistral), tasks that have verifiable correct answers but are framed as unimportant sub-steps. Compare performance on canary vs. main tasks and on monitored vs. ostensibly unmonitored runs.

**Why it matters:** The LW threat matrix identifies 'Defense Evasion' as an early-stage kill-chain tactic; honeypot tasks could be a lightweight countermeasure deployable without cloud infrastructure.

**Relevant context:** LW 2026 threat matrix (Discovery, Defense Evasion stages); LLM Agent Honeypot paper (Palisade Research, arXiv 2410.13919).
