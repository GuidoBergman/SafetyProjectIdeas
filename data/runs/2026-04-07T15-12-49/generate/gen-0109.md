# Causal Link from Training Data to Capability: Do Models Fine-Tuned on Red Team Exercises Show Qualitatively Different ATT&CK Phase Coverage?

**Problem:** General frontier models are not specifically trained on offensive security workflows. Models fine-tuned on red team exercise data may show qualitatively different capability profiles — not just higher overall performance, but different distributions across ATT&CK phases. This causal link from training data composition to capability profile has not been tested.

**Direction:** Compare a general frontier model against a security-fine-tuned variant (if available via API or HuggingFace) on a 30-challenge set with challenges balanced across all ATT&CK phases. Compute per-phase capability distributions for each model. Test whether fine-tuning shifts the profile (higher scores across all phases equally) or reshapes it (disproportionate gains in specific phases).

**Why it matters:** If security fine-tuning primarily improves specific ATT&CK phases, this reveals which phases are most sensitive to targeted training — informing both the risk trajectory of specialized attack models and the design of training data restrictions as a safety measure.

**Relevant context:** CyberSOCEval (arxiv 2509.20166v2) fine-tuned on malware analysis. Security fine-tuned models exist on HuggingFace (WizardCoder-security, Phind-CodeLlama-security). AISI found uneven phase performance. AICrypto found crypto-specific fine-tuning improvements. Training data composition → capability profile causal chain is under-studied.
