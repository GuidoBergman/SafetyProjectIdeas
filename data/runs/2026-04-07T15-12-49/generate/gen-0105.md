# Compounding Failure: Tool-Augmented AI Offense × Expanding MCP Ecosystem — Attack Surface of AI Infrastructure

**Problem:** Two interacting failure modes: (1) AI agents increasingly use MCP (Model Context Protocol) servers for tool access, and (2) MCP servers are being rapidly proliferated with minimal security vetting (GitHub MCP server had Toxic Agent Flow vulnerability). Combined, the expanding MCP ecosystem creates an attack surface where compromised tools amplify AI offensive capability.

**Direction:** Survey 20 publicly available MCP servers for cybersecurity tools (from the MCP ecosystem). Identify common security vulnerability patterns in their implementation. Test whether an AI agent using a compromised MCP server can be directed to take actions beyond its intended scope. Measure the amplification factor: how much more capability does a compromised vs. legitimate MCP server grant?

**Why it matters:** The MCP ecosystem is a new and rapidly expanding attack surface that connects AI agents to powerful external tools. Understanding how MCP vulnerabilities interact with AI offensive capability could reveal a novel threat vector where compromising the AI's tooling infrastructure grants attackers capabilities far exceeding what the AI model itself provides.

**Relevant context:** GitHub MCP Toxic Agent Flow vulnerability (Invariant Labs, 2025). Prompt injection in tool-augmented agents (MDPI 2025, 73% of production AI deployments affected).
