# Measuring Information Security Awareness as a Moderator of Human Monitoring Review Quality

**Problem:** Human reviewers with different levels of security training may perform very differently as monitoring reviewers. Whether security training moderates monitoring review quality is unknown.

**Direction:** Compare monitoring alert review performance between participants with formal security training (CS security course) vs. without. Measure decision accuracy on a standardized set of monitoring alerts spanning safe, borderline, and dangerous agent actions.

**Why it matters:** If security training substantially improves review quality, organizations should require security training for anyone reviewing agent monitoring alerts — a concrete, actionable personnel policy recommendation.

**Relevant context:** Human factors in security; security awareness training; human-in-the-loop monitoring.
