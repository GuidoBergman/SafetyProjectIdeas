# Applying Software Fault Isolation (SFI) Principles to Agent Tool Sandboxing

**Problem:** Software Fault Isolation is a mature OS security technique for confining untrusted code to specific memory regions. Its principles have not been applied to confining AI agent tool access.

**Direction:** Implement an SFI-inspired capability sandbox for a Python agent: each tool is wrapped in a permission boundary, cross-boundary calls are logged and optionally blocked. Measure whether this reduces successful unauthorized tool invocations without degrading task completion on benign tasks. Test on three scenarios from Irregular 2026.

**Why it matters:** SFI is a proven isolation technique. If its principles translate to agent tool sandboxing, organizations can leverage decades of OS security research for agentic deployments.

**Relevant context:** Software Fault Isolation (Wahbe et al. 1993 and successors); Jiang et al. 2026 runtime attack surface; agent tool security.
