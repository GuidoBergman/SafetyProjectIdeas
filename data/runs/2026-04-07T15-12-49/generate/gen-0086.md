# Minimal Interpretability for Offensive Capability: Can Attention Patterns Predict Attack Step Success?

**Problem:** It is unknown whether attack success or failure at individual steps can be predicted from model-internal signals (attention patterns, intermediate representations) before the step is executed. If predictable, this would enable early-warning systems for high-risk attack reasoning.

**Direction:** Using an open-weight model (to enable activation access), run 100 attack task attempts (50 success, 50 failure). For each attempt, extract attention patterns and last-hidden-state representations at the step-planning phase (before tool invocation). Train a simple logistic regression classifier to predict step success from these representations. Measure AUC and identify which representation features are most predictive.

**Why it matters:** A capability predictor operating on model internals (not just outputs) could enable: (1) real-time monitoring of AI offensive agents to detect high-risk reasoning states, (2) selective refusal when internal indicators suggest dangerous capability expression. This is a lightweight interpretability contribution with direct safety application.

**Relevant context:** Evasive Intelligence paper (arxiv 2603.15457) on agent behavioral adaptation. Previous work on activation probes for safety properties exists in broader interpretability literature. Open-weight models (Llama, Mistral) allow activation access. Logistic regression on activations is a standard lightweight interpretability technique within participant constraints.
