# Effect of Context Window Size on Monitor False Negative Rate

**Problem:** Long-context attacks — where malicious instructions are buried deep in a long context — may evade monitors with limited effective attention. No study has measured how false negative rates scale with attack position in context.

**Direction:** Construct attack trajectories where the malicious instruction appears at different positions in a long context (beginning, middle, end, buried in noise). Measure monitor false negative rates as a function of attack position and context length.

**Why it matters:** If monitors have attention blind spots that attackers can exploit by positioning malicious content appropriately, this is a critical vulnerability in monitoring architectures.
