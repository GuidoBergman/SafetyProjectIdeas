# Prompt Injection in Tool-Augmented Offensive Agents: When the Attacker's Weapon Becomes the Backdoor

**Problem:** AI agents used for offensive red-teaming often browse adversary-controlled web pages and files as part of reconnaissance. These environments can contain prompt injections that redirect the agent. No evaluation measures how often offensive AI agents themselves become hijacked via prompt injection during an offensive engagement.

**Direction:** Set up a CTF-style target that includes prompt injection payloads embedded in web pages, file metadata, and server response headers. Run an AI agent attempting to compromise the target. Measure: (1) how often the agent successfully identifies and ignores injections, (2) how often it is redirected by them, (3) what the injections cause the agent to do (e.g., exfiltrate session tokens back to attacker's server).

**Why it matters:** If offensive AI agents are vulnerable to prompt injection from targets they attack, sophisticated defenders could use this as a counter-strategy. This also reveals a novel compounding risk: the tool meant for offense becomes an attack surface.

**Relevant context:** WASP benchmark (arxiv.org/pdf/2504.18575) measures web agent security against prompt injections. Lakera (2025): indirect prompt injection targets LLM agents using external tools. GitHub Copilot studies found 84% attack success rate for executing malicious commands via injection. Prompt injection in OWASP Top 10 LLM 2025.
