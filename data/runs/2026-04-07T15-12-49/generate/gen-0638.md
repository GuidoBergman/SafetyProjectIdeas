# Secure Proof Synthesis Benchmark: Evaluating AI on Combined Security + Formal Verification Tasks

**Problem:** No benchmark combines the two skills needed for Secure Program Synthesis (SPS): (1) generating secure code and (2) formally verifying security properties. Current benchmarks test each skill separately.

**Direction:** Create a 50-task benchmark where each task requires: (a) generating code that passes security review criteria AND (b) providing a formal Lean 4 proof of a security property. Measure LLM performance on the combined task vs. each sub-task independently. Test whether solving both simultaneously degrades performance on each.

**Why it matters:** SPS is identified as a major 2026 focus in the subfield context. A benchmark for combined security+verification capability would directly measure progress on this joint capability. It would also reveal whether there are tradeoffs between the two skills.

**Relevant context:** VeriBench measures formal verification. AIxCC and Claude Code Security measure vulnerability detection. No benchmark requires demonstrating both simultaneously. SPS as a concept needs a dedicated evaluation framework.
