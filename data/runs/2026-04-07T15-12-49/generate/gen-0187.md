# Novel Direction: AI-Assisted Vulnerability Clustering for Systemic Pattern Discovery

**Problem:** Individual vulnerability reports are analyzed in isolation. AI could cluster vulnerabilities across a codebase to reveal systemic patterns (e.g., a recurring insecure API usage pattern) that are more informative than individual findings.

**Direction:** Collect AI-generated vulnerability reports for a large open-source project (e.g., Linux kernel CVEs, OpenSSL CVEs). Use an LLM to cluster reports by root cause. Identify recurring patterns. Measure: how many individual CVEs are explained by each systemic pattern? Compare to manually derived clusters from CVE descriptions.

**Why it matters:** Systemic patterns enable targeted developer education and architectural improvements, not just individual patches. This is a higher-leverage defense than one-off patching.

**Relevant context:** Vulnerability taxonomy efforts exist (MITRE CWE). AI-assisted automatic clustering for systemic root cause analysis at codebase scale has not been studied.
