# Replication with Open-Weight Models: Does the Copilot Amplification Effect Hold for Locally Deployed Models?

**Problem:** OCCULT's copilot paradigm research used closed frontier APIs. For threat modeling purposes, it is important to know whether the copilot amplification effect holds when attackers use locally deployed open-weight models (no API costs, no usage logging, private).

**Direction:** Replicate a simplified copilot experiment (from the earlier copilot amplification idea) using a locally deployed open-weight model (Llama 3 70B or Qwen 72B via Ollama). Compare: (1) novice human alone, (2) novice + local open-weight model copilot, (3) novice + frontier API model copilot. Measure steps completed in each condition. Compute whether local model copilot provides comparable amplification to frontier model.

**Why it matters:** If local models provide comparable copilot amplification to frontier APIs, the attack surface includes any attacker with consumer hardware — no API access, no usage monitoring, no cost barrier. If local models provide significantly less amplification, frontier API access remains the binding constraint on the copilot threat.

**Relevant context:** OCCULT copilot paradigm (arxiv 2502.15797). Open-weight models: Llama 3 70B, Qwen 72B deployable on consumer hardware. CAIBench evaluated open-weight models. Pentest-AI uses locally orchestrated agents. No published comparison of copilot amplification for local vs. frontier models exists.
