# Can Small Language Models Serve as Effective Agent Oversight Models?

**Problem:** Using a large model to monitor another large model is expensive. It is unknown whether small language models (SLMs, 1-7B parameters) can serve as effective monitoring judges for agent behavior.

**Direction:** Compare the monitoring accuracy of SLMs (Phi-3-mini, Llama-3-1B) vs. larger models (Llama-3-70B, Claude Haiku) as agent judges on a set of flagged vs. normal agent trajectories. Measure agreement rate, false positive rate, and inference cost.

**Why it matters:** If SLMs can serve as effective monitors, continuous real-time monitoring becomes economically feasible for small organizations — a major gap in the current safety ecosystem.
