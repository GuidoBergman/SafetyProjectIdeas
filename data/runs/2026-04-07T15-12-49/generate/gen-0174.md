# Experiment Variation: Comparing AI Vulnerability Scanning on First-Party vs. Third-Party Code

**Problem:** AI scanners may perform differently on original first-party code vs. third-party dependencies. Supply chain vulnerabilities often reside in dependencies.

**Direction:** For 15 open-source projects with known CVEs in their dependencies: run AI scanner on (a) first-party code only, (b) dependency code only, (c) full project. Measure detection rate per category. Determine if AI performance is systematically lower for dependency vulnerabilities.

**Why it matters:** Supply chain attacks exploit dependency vulnerabilities. If AI defense tools are worse at detecting them, defenders are blind to the most dangerous attack vector.

**Relevant context:** Supply chain attack proliferation (OWASP 2025, Bastion 2026). LLM vulnerability scanning research focuses on single-project code. Dependency-vs-first-party comparison not studied.
