# Replicating Goal-Hijacking Detection on Multimodal Agents

**Problem:** Goal-hijacking research focuses on text-only agents. Multimodal agents (processing images, PDFs, web screenshots) face injection attacks through visual modalities that text-only monitoring classifiers cannot detect.

**Direction:** Adapt prompt injection attacks to the visual modality (text in images, instructions in PDF headers, hidden text in screenshots). Test whether standard text-based monitors detect these visual-modality injections. Measure visual-injection evasion rate.

**Why it matters:** Multimodal agents are increasingly deployed in enterprise settings. Visual-modality injections are an unmonitored attack surface for which current monitoring tools have no coverage.

**Relevant context:** Visual prompt injection research; multimodal agent security; monitoring coverage gaps.
