# Multi-Model Voting for Agent Monitoring: Does Ensemble Agreement Improve Detection Reliability?

**Problem:** Single-model monitors have individual failure modes. An ensemble of diverse monitoring models (majority vote) might be more robust, but this has not been tested for agent monitoring.

**Direction:** Implement an ensemble monitor using 3 different LLMs (Llama, Mistral, Phi). Compare ensemble voting performance to single-model monitoring on a standard evaluation dataset. Measure whether ensemble agreement reduces both false positives and false negatives.
