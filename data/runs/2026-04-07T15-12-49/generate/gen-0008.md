# Standard vs. Custom Toolkit Dependency: Replicating Anthropic's Toolkit Regression Across Benchmark Tasks

**Problem:** Anthropic's cyber evaluation updates documented models graduating from requiring custom toolkits to performing well with standard tools. It is unclear whether this progression is uniform across all task types or whether certain categories still require specialized tooling.

**Direction:** Run the same set of 15-20 CTF challenges under two conditions: (1) model has access to a custom pre-configured toolkit (nmap wrapper, exploit scripts) and (2) model only has access to standard bash/Python tools. Measure the performance delta per challenge category. Test whether toolkit dependency correlates with task complexity or ATT&CK phase.

**Why it matters:** If models now work effectively with standard tools, the barrier to entry for attackers drops dramatically — no specialized infrastructure needed. Quantifying which task types still require custom tooling tells us which attack vectors remain bottlenecked by tooling costs.

**Relevant context:** Anthropic cyber toolkits update (red.anthropic.com/2025/ai-for-cyber-defenders/) documented models transitioning from custom to standard tools. AISI used custom scaffolding in evaluations. CyberExplorer (Blueinfy 2026) found model-specific attack trajectory differences in multi-target settings.
