# Formal Spec from Test Suites: Can LLMs Infer Lean 4 Specifications from Existing Unit Tests?

**Problem:** Most code has unit tests but no formal specifications. Whether LLMs can infer formal Lean 4 specifications from existing test suites — enabling retro-fitting of formal verification to existing code — is unstudied.

**Direction:** Take 30 open-source functions with comprehensive test suites. Ask LLMs to generate Lean 4 specifications inferred from the tests. Compare inferred specs to expert-written specs on: completeness (do they cover all tested behaviors?), correctness (are they accurate?), and additional coverage (do they capture behaviors not in tests?).

**Why it matters:** The practical path to verified legacy code runs through existing tests. If LLMs can infer specs from tests, existing test coverage becomes a foundation for formal verification without requiring spec-writing expertise.

**Relevant context:** ATLAS generates specs from examples. AlphaVerus starts from Dafny. Neither uses existing unit tests as specification sources. This represents a practical pathway for brownfield code adoption.
