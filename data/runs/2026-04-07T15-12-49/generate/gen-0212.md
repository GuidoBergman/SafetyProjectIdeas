# Causal Chain: Intervening on the Knowledge Transfer Gap Between AI Findings and Developer Education

**Problem:** When AI finds a vulnerability, the explanation could either be used to just fix the specific issue OR to educate the developer so they avoid the pattern in future code. The educational link is rarely studied.

**Direction:** Run an experiment: Group A receives AI vulnerability reports and patches the code. Group B receives AI vulnerability reports with explicit educational framing (pattern name, why it's dangerous, how to avoid it). Both groups then write new code with similar functionality. Measure: new vulnerability introduction rate per group.

**Why it matters:** If AI vulnerability feedback can be designed to transfer knowledge, the rate of vulnerability introduction decreases over time. This is a high-leverage intervention.

**Relevant context:** Secure Coding Warrior and similar platforms study developer security education. AI vulnerability feedback as a developer education mechanism has not been empirically studied.
