# Experiment: AI Vulnerability Detection Performance as a Function of Programming Paradigm

**Problem:** Functional, object-oriented, and procedural programming paradigms produce different code structures. AI vulnerability detection may perform differently across paradigms due to training data distribution.

**Direction:** Select 10 CVEs from each of three paradigm-dominant contexts: (a) functional (Haskell, OCaml, or Erlang code), (b) object-oriented (Java), (c) procedural (C). Run the same LLM on all. Measure detection rate per paradigm. Analyze whether functional paradigm code has lower detection rates due to training data underrepresentation.

**Why it matters:** Security-critical systems sometimes use functional languages (financial systems, theorem provers). If AI defense tools underperform on functional code, this creates a dangerous gap.

**Relevant context:** LLM training data is heavily biased toward Python, JavaScript, Java (GitHub distribution). Functional language representation in training data is lower. Detection performance vs. training data frequency not studied.
