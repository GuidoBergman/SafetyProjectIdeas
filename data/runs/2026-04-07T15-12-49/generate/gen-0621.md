# Do LLMs Improve on Lean 4 After Seeing Their Own Compilation Errors? Error Learning Rate Measurement

**Problem:** The Self-Optimizing Trace Agent learns from Lean compiler errors. Whether the error learning rate (improvement per error message seen) is consistent across error types and problem difficulties is not characterized.

**Direction:** Track iteration-by-iteration progress for 40 VeriBench tasks across 2 models. For each iteration, record: error type, whether the error was resolved in the next iteration, and the total iterations to success or failure. Compute error-specific learning rates (how many iterations does each error type take to correct?).

**Why it matters:** If certain error types take many more iterations to correct, targeted improvements to the agent's handling of those errors would dramatically improve efficiency. This is a data-driven approach to agent optimization.

**Relevant context:** Self-Optimizing Trace Agent uses error feedback but does not characterize error-specific learning rates. This analysis would directly inform architectural improvements to the agent.
