# Hallucinated Vulnerability Investigation: When Do LLMs Fabricate Plausible-Looking CVE Exploits?

**Problem:** Models may generate convincing-looking but non-functional exploit code for vulnerabilities that either don't exist or have different actual exploitation paths—a dual-use failure mode that hasn't been systematically characterized.

**Direction:** Ask 4 models to generate exploitation guidance for 20 real CVEs and 10 fake CVE numbers. Score technical accuracy of real CVE guidance with a security researcher. Measure hallucination rate and plausibility of fake CVE outputs. Assess governance risk of plausible-but-wrong exploitation guidance.

**Why it matters:** Hallucinated exploits might still provide uplift (directional guidance) while evading evaluation by appearing inaccurate. This is an under-characterized failure mode for dual-use governance.

**Relevant context:** Linder et al. Offensive Action Contribution dimension; Potter et al. offensive AI capability analysis.
