# Measuring the Monitoring Overhead Tax: Performance Degradation from Real-Time Monitoring

**Problem:** Real-time monitoring imposes latency and compute costs on agent systems. The magnitude of this 'monitoring overhead tax' has not been empirically characterized for different monitoring approaches.

**Direction:** Benchmark agent task completion time and throughput with and without real-time monitoring (LLM judge, rule-based classifier, embedding-based similarity). Measure latency overhead for each approach across task types. Identify the lowest-overhead approach that maintains acceptable detection rates.

**Why it matters:** If monitoring overhead is too high, it creates pressure to skip monitoring in production. Quantifying overhead helps make the case for specific monitoring architectures.

**Relevant context:** Anthropic real-time detection classifiers; agent performance benchmarking; monitoring cost.
