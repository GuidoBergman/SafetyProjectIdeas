# Measuring Whether Model 'Reasoning Out Loud' About Dual-Use Requests Improves Calibration

**Problem:** Chain-of-thought reasoning has been shown to improve model performance on complex tasks. Whether prompting models to reason about dual-use tradeoffs (offense vs. defense benefit) before responding improves refusal calibration is untested.

**Direction:** Test 50 borderline cybersecurity requests in two conditions: (a) direct response, (b) forced chain-of-thought reasoning about dual-use tradeoffs before responding. Measure refusal rate changes and calibration (false positive and false negative rates) across both conditions for 3 models.

**Why it matters:** If chain-of-thought reasoning substantially improves dual-use calibration, this is a cheap governance lever that can be deployed via system prompt without model retraining.

**Relevant context:** Linder et al. 5-dimension reasoning framework; chain-of-thought safety reasoning research; NIST AI 800-1 evaluation methodology.
