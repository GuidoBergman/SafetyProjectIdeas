# Measuring Monitoring Generalization: Does a Monitor Trained on Text Tasks Work on Code Execution Tasks?

**Problem:** Monitoring classifiers may be implicitly task-specific, trained on one task domain but deployed across many. Their cross-task generalization has not been measured.

**Direction:** Train a monitoring classifier on labeled text-task agent trajectories. Test it on code-execution task trajectories and web-browsing task trajectories. Measure performance degradation and identify the sources of generalization failure.

**Why it matters:** Enterprise deployments use agents across many task types. A monitoring classifier that fails to generalize across tasks creates blind spots in specific deployment contexts.

**Relevant context:** ML generalization; agent monitoring; task-specific vs. general monitoring.
