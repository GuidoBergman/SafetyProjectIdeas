# Applying Intrusion Detection System Principles to Agent Communication: Signature vs. Anomaly Detection

**Problem:** Traditional IDS systems use either signature-based detection (known attack patterns) or anomaly detection (deviations from baseline). For agent monitoring, the relative effectiveness of these two approaches has not been compared.

**Direction:** Implement a signature-based agent monitor (using known attack pattern rules) and an anomaly-based agent monitor (statistical deviation from baseline). Compare their performance on known attacks (expected advantage for signature-based) and novel attacks (expected advantage for anomaly-based). Measure performance on each attack type.

**Why it matters:** The IDS field has decades of insight about when each approach is appropriate. Transferring this knowledge to agent monitoring would accelerate monitoring system design.

**Relevant context:** IDS signature vs. anomaly detection (classic security); agent monitoring; METR novel vs. known attacks.
