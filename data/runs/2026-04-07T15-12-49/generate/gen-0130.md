# Taxonomy of AI Defensive Failure Modes: A Systematic Classification

**Problem:** No taxonomy exists of the ways AI-powered defensive tools fail: missed vulnerabilities, hallucinated vulnerabilities, incorrect explanations, partial patches, etc.

**Direction:** Collect 100+ AI-generated vulnerability reports and patches from public bug bounty write-ups and open-source project issue trackers. Manually classify failure modes. Build a failure taxonomy with frequency distributions and an illustrative dataset.

**Why it matters:** A taxonomy enables targeted improvement. Safety-relevant: AI tools deployed at scale with uncharacterized failure modes pose risk, especially if they create false confidence.

**Relevant context:** SoK paper (Potter et al., UC Berkeley 2025) notes offense > defense gap but does not classify failure modes. MDPI AI vulnerability detection review (2025) notes detection challenges without taxonomy.
