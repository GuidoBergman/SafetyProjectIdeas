# Failure Analysis of Cryptographic Task Sharp Drop: Is It Knowledge, Math Reasoning, or Tool Use?

**Problem:** AISI found sharp performance drops at cryptography tasks. AICrypto benchmark found models have strong knowledge but weak mathematical reasoning for crypto. It is not known whether failure in CTF crypto challenges stems from: (a) missing mathematical knowledge, (b) inability to execute mathematical reasoning steps, or (c) failure to use cryptographic tools correctly.

**Direction:** Create 15 cryptographic challenges decomposed into 3 conditions: (A) multiple choice knowledge test (identify vulnerability type), (B) mathematical derivation by hand (solve the crypto math symbolically), (C) tool-assisted exploitation (use Python pycryptodome to execute known approach). Run models on all 3 conditions for the same 5 vulnerability types. Map failure rates to conditions.

**Why it matters:** If crypto failures are knowledge failures (A), more training data helps. If they are reasoning failures (B), reasoning-scaled models are the risk. If they are tool use failures (C), better tooling documentation would close the gap quickly. These have different implications for capability trajectory forecasting.

**Relevant context:** AICrypto benchmark (arxiv 2507.09580): strong memorization, weak mathematical comprehension. AISI: sharp drops at crypto tasks. CIPHER benchmark (arxiv 2602.01438) on cryptographic vulnerability in generated code. Benchmarking cryptanalysis LLMs (ACL 2025 findings-EMNLP) found performance on well-known vs. novel mathematical vulnerabilities diverges.
