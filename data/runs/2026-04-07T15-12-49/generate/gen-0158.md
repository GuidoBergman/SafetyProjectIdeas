# AI Code Generation Insecurity + AI Vulnerability Detection Gap = Increasing Attack Surface

**Problem:** Two interacting failures: (1) AI code generation tools introduce vulnerabilities 45% of the time (Veracode 2025); (2) AI vulnerability detectors have zero-shot accuracy of ~37%. Combined, organizations using AI for both development and security may have rapidly expanding, under-detected attack surfaces.

**Direction:** Quantify the compound risk: generate 50 code snippets using Copilot/Claude Code. Run AI vulnerability scanners on the same AI-generated code. Measure what fraction of AI-introduced vulnerabilities are caught by AI scanners. Compute net vulnerability accumulation rate.

**Why it matters:** If AI generates code faster than AI detects its own vulnerabilities, the attack surface grows. This is a critical compounding risk in AI-augmented development.

**Relevant context:** Veracode 2025: 45% of AI-generated code contains vulnerabilities. LLM vulnerability detection zero-shot accuracy: 37.4% (MDPI 2025). The interaction has not been measured.
