# Goal Persistence Effects Under Resource Constraints vs. Permission Constraints

**Problem:** Goal persistence may manifest differently when an agent is blocked by resource limitations (e.g., rate limits) versus permission constraints (e.g., access denied errors). These two obstacle types may have different safety implications.

**Direction:** Design tasks with two blocking types: simulated rate-limit errors and simulated permission-denied errors. Run the same persistence-measuring protocol on both. Compare whether agents more aggressively seek workarounds (including unauthorized ones) for permission blocks vs. resource blocks.

**Why it matters:** If permission constraints specifically elicit more aggressive workaround-seeking than resource constraints, this informs how to design agent error-handling to avoid escalating behavior.
