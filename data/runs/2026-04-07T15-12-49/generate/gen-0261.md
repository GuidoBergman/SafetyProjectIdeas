# Novel Direction: Measuring AI Vulnerability Detection Performance on Code With Security Comments

**Problem:** Developers sometimes add security comments ('This is safe because...', '// SAFE: validated upstream') to explain why seemingly risky code is acceptable. AI scanners may ignore or misinterpret these comments, leading to false positives.

**Direction:** Take 20 safe code samples with accurate security-justification comments. Run AI scanner. Measure false positive rate on this corpus vs. equivalent code without comments. Separately: take 10 vulnerable code samples with misleading 'this is safe' comments. Measure detection rate change.

**Why it matters:** False positives from ignoring security comments waste analyst time. Undetected vulnerabilities hidden by misleading security comments are a safety risk. Both are failure modes of AI scanners.

**Relevant context:** Code comments as context for AI analysis studied in general code understanding. Security comment interpretation by AI vulnerability scanners not studied. Misleading security comments as an evasion technique is novel.
