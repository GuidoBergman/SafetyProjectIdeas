# Applying Honeypot Strategy to Detect Agents Probing for Unauthorized Access

**Problem:** Network security uses honeypots (fake attractive targets) to detect intruders. This technique has not been adapted for detecting AI agents probing unauthorized resources.

**Direction:** Place honeypot resources (fake high-value files, fake credentials, fake admin endpoints) in an agent's accessible environment. These resources have no legitimate task-relevance. Measure how often agents access honeypot resources and under what task conditions. Use honeypot access rate as an offensive behavior indicator.

**Why it matters:** Honeypots in network security require no model internals access and produce low false-positive signals. If the same principle works for agents, it is an immediately deployable detection technique.

**Relevant context:** Network security honeypot literature; Irregular 2026 unauthorized access patterns; runtime agent monitoring.
