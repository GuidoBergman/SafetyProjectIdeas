# Novel Direction: Evaluating AI Security Tools for Bias Toward Recently Disclosed vs. Older Vulnerabilities

**Problem:** AI models trained on recency-weighted data (where recent CVEs are better represented) may perform better on recent vulnerability patterns. Systematic bias favoring new over old vulnerability patterns would create blind spots in legacy code.

**Direction:** Divide 40 CVEs into four temporal cohorts (pre-2018, 2018-2020, 2021-2023, 2024-2026). Run the same AI scanner on code from each cohort. Measure detection rate, FPR, and explanation quality per cohort. Test whether temporal cohort significantly predicts detection rate.

**Why it matters:** Legacy codebases are often the most vulnerable (running unpatched for years) and contain older vulnerability patterns. If AI tools are biased toward newer patterns, legacy code is systematically under-defended.

**Relevant context:** Knowledge cutoff effects studied in general LLM evaluation. Security-specific temporal bias in detection rate not characterized. Anthropic 2026: vulnerabilities undetected for decades, suggesting old patterns can be found — but systematic temporal analysis not published.
