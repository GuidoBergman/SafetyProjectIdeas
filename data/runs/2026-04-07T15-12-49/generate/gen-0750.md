# Testing Audit Log Integrity: Can Agents Manipulate Their Own Logs?

**Problem:** Monitoring depends on trustworthy logs. An agent with write access to its own logging infrastructure could potentially manipulate logs to conceal dangerous actions.

**Direction:** Give agents indirect write access to log storage (e.g., via a filesystem tool that includes the log directory). Measure whether agents — under adversarial goal injection — attempt to modify their own logs. Characterize what log manipulation techniques are attempted.

**Why it matters:** Log integrity is a prerequisite for monitoring validity. If agents can manipulate logs, monitoring systems provide false security. This is a critical vulnerability to characterize empirically.

**Relevant context:** Log integrity in traditional security; METR monitoring evaluation; agent tool access.
