# Measurement Invariance Testing: Do Cyber Capability Benchmarks Measure the Same Construct Across Model Families?

**Problem:** When comparing Llama, Claude, and GPT performance on the same benchmark, we assume the benchmark measures the same construct for all models. This 'measurement invariance' assumption has never been tested for cyber capability benchmarks. If it fails, cross-model comparisons are invalid.

**Direction:** Apply confirmatory factor analysis or a simplified IRT-based test of measurement invariance to solve/fail data from 5+ models across a 30-challenge benchmark. Test whether challenge difficulty and discrimination parameters are the same for different model families (configural, metric, and scalar invariance in psychometric terms). Report which invariance assumptions hold and which fail.

**Why it matters:** If measurement invariance fails across model families, statements like 'Claude is 20% more capable than GPT' at offensive cyber tasks are psychometrically invalid. This would require the field to develop model-family-specific benchmarks or invariant measurement protocols before cross-model comparisons can be made.

**Relevant context:** IRT for AI benchmarks (arxiv 2510.00844). Cambridge/Trismik psychometric approach (enterprise.cam.ac.uk). CAIBench aggregates multiple model results without testing invariance. Measurement invariance testing is standard in cross-group comparison studies in psychology and is directly applicable here.
