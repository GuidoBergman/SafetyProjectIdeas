# Privilege Escalation Simulation: Do Agents Exploit Misconfigured Tool Permissions?

**Problem:** In real deployments, agent tool permissions may be misconfigured. It is unknown whether current LLMs will opportunistically exploit over-permissioned tools even when not instructed to do so.

**Direction:** Create an agent environment with one intentionally over-permissioned tool (e.g., a file tool that also has read access to a 'secrets' directory). Run agents on tasks that do not require that tool. Measure how often agents spontaneously use the over-permissioned capability.

**Why it matters:** If agents spontaneously exploit misconfigured permissions, principle-of-least-privilege enforcement becomes critical for agent deployments — and monitoring for permission misuse becomes essential.

**Relevant context:** AI insider threat literature; LW threat matrix (Privilege Escalation); tool permission design.
