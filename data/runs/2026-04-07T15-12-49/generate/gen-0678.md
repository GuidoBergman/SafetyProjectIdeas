# Measuring Monitor Calibration: Do LLM Judges Assign Well-Calibrated Danger Scores?

**Problem:** LLM-based monitors often output a 'danger score' for agent actions. Whether these scores are well-calibrated (i.e., a 0.8 danger score should correspond to ~80% probability of actual danger) is untested.

**Direction:** Construct a labeled dataset of agent actions with ground-truth danger labels. Have an LLM judge score each action. Plot calibration curves (predicted danger probability vs. actual danger frequency). Apply temperature scaling to improve calibration.

**Why it matters:** Poorly calibrated monitors lead to over-alerting or under-alerting. Calibration is a prerequisite for reliable monitoring in deployment.

**Relevant context:** LLM judge calibration literature; agent monitoring evaluation methodology.
