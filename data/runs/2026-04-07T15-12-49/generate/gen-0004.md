# CTF Difficulty Calibration Using Item Response Theory: Building a Principled Cyber Capability Scale

**Problem:** CTF benchmarks report raw solve rates (e.g., Cybench 82%) without calibrating item difficulty. A 50% solve rate on a hard challenge and a 50% rate on an easy challenge tell us different things about capability, but existing benchmarks treat them identically.

**Direction:** Apply 2-parameter IRT (difficulty + discrimination) to an existing CTF dataset (e.g., Cybench, NYU CTF Bench) using model solve/fail data across multiple models as 'examinees'. Fit IRT curves, estimate per-challenge difficulty and discrimination parameters, and generate a capability theta score for each model. Validate by checking if theta scores correlate with known model rankings.

**Why it matters:** IRT produces a principled, scale-invariant capability metric unaffected by benchmark difficulty distribution shifts, addressing the saturation problem (Cybench went 10%→82% making raw scores meaningless) and providing a foundation for longitudinal comparison.

**Relevant context:** Cambridge/Trismik applied IRT to AI evaluation (enterprise.cam.ac.uk). Cybench reached 93% saturation (CAIBench meta-benchmark, arxiv.org/html/2510.24317v1). AISI noted that no standardized longitudinal comparison methodology exists. IRT has been validated for LLM benchmarking in NLP contexts.
