# Testing Monitoring Robustness to Adversarial Many-Shot Jailbreaks in Long Contexts

**Problem:** Many-shot jailbreaking (inserting many examples of desired behavior into context) is an effective jailbreak technique for capable models. Whether it also works against LLM-based monitors is unknown.

**Direction:** Construct many-shot jailbreak prompts targeting a monitoring classifier. Insert many examples of the classifier passing dangerous actions before presenting the actual dangerous action to classify. Measure whether many-shot context manipulation degrades monitoring accuracy.

**Why it matters:** If many-shot jailbreaks work against monitors, any LLM-based monitor that operates on long contexts is vulnerable to a known, well-characterized attack technique.

**Relevant context:** Many-shot jailbreaking research; METR bypass vectors; long-context monitoring.
