# Goal Persistence Metrics as Precursors to Emergent Offensive Action

**Problem:** Goal persistence (the tendency of an agent to continue pursuing an objective after encountering obstacles) is a contributing factor to emergent offensive behavior, but no metric for measuring it in deployed agents exists.

**Direction:** Define a goal-persistence score based on the number of re-attempts and alternative strategies an agent uses when blocked. Run agents on gated tasks (with permission barriers) and measure persistence scores. Correlate these scores with downstream unauthorized action rates in extended runs.

**Why it matters:** A runtime goal-persistence metric could serve as an early warning signal that an agent is about to attempt a boundary-crossing action, enabling preemptive human-in-the-loop interruption.
