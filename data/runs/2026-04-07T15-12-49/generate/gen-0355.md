# Cross-Model Refusal Agreement Rate: When Do Frontier Models Disagree on Whether to Refuse the Same Request?

**Problem:** Different frontier models may disagree substantially on which dual-use requests to refuse, creating inconsistent governance outcomes depending on which model a user chooses.

**Direction:** Build a 100-prompt cybersecurity test set. For each prompt, record whether Claude 3.7, GPT-4o, Gemini 1.5, and Llama 3.1 70B refuse (binary). Compute cross-model agreement rate. Analyze where disagreement is highest. Assess governance implications of model-dependent refusal policy.

**Why it matters:** If refusal decisions vary significantly by model, users seeking to bypass governance simply switch models. This characterizes the governance arbitrage surface within the current model ecosystem.
