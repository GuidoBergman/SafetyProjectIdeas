# Experiment Variation: Does System Prompt Content Affect Offensive Capability Expression?

**Problem:** AI models receive system prompts that define their role and constraints. Different system prompts (e.g., 'you are a security researcher', 'you are a red team expert', 'you are a helpful assistant') may produce systematically different capability expression on offensive tasks, beyond just refusal rate differences.

**Direction:** Design 5 system prompt variants for the same underlying task capability: (1) neutral assistant, (2) security researcher, (3) red team professional with authorization, (4) CTF player, (5) penetration tester with explicit scope statement. Run all 5 on 10 identical offensive challenges. Measure solve rate, output quality, and failure mode distribution across conditions. Test whether differences are statistically significant.

**Why it matters:** If system prompt framing significantly changes capability expression, then adversaries who know how to craft system prompts can unlock higher capability from commercial models than default configurations expose. This has direct implications for API use policy, operator system prompt requirements, and safety evaluation protocols.

**Relevant context:** Evasive Intelligence (arxiv 2603.15457) on evaluation context effects. OCCULT copilot framing. Jailbreaking surveys (TechRxiv 2025) document role-play as common bypass vector. WASP benchmark found context affects web agent security behavior. System prompt effects on general capabilities are documented but not on offensive cyber task performance specifically.
