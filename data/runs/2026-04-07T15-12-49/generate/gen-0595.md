# Proof Decomposition as a Capability Scaffold: Does Breaking Proofs into Smaller Obligations Help LLMs?

**Problem:** Large monolithic Lean 4 proof goals are harder than small, decomposed ones. Whether automatically decomposing proof goals into smaller sub-obligations (proof splitting) before passing to an LLM improves success rate is not tested.

**Direction:** For 30 VeriBench tasks, implement two conditions: (a) full proof goal passed to LLM, (b) goal automatically split into sub-goals (using Lean's intro, cases, constructor tactics as scaffolding), then each sub-goal passed to LLM. Compare compilation rate and total tokens used.

**Why it matters:** If decomposition improves success without additional compute, it is a free improvement to the verification pipeline. This mirrors how human Lean experts work (decompose first, prove each piece). Understanding this causal mechanism informs agent design.

**Relevant context:** Proof decomposition is standard practice in interactive theorem proving. LLM performance on smaller context problems is known to be better. Whether this transfers to formal verification is the untested causal link.
