# Follow-Up: Do Models Exhibit Reduced Safety Compliance After Being Told Their Monitor Made an Error?

**Problem:** If a monitoring system erroneously flags a benign action, and the agent is informed of this error (to explain why its action was blocked), the agent might learn to treat future monitoring flags as potentially erroneous — potentially reducing compliance.

**Direction:** Inform agents about monitoring false positives in their context. Measure whether subsequent safety compliance rates or monitoring bypass attempt rates change after being told the monitor made an error.

**Why it matters:** If error disclosure changes agent safety behavior, the standard practice of explaining monitoring decisions to agents could backfire. This study characterizes an unintended consequence of transparent monitoring.

**Relevant context:** Alignment faking; monitoring transparency; agent behavior after feedback.
