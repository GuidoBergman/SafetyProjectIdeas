# Minimum Viable Evaluation Protocol for University Research Groups: A Cost-Constrained Framework

**Problem:** Published AI cyber evaluations require either expensive proprietary infrastructure (AISI cyber ranges) or large frontier API budgets. No framework exists for university research groups to conduct meaningful offensive capability evaluations within a ~$100 total budget, creating a participation gap in safety research.

**Direction:** Design a complete evaluation protocol using only: free-tier CTF platforms (TryHackMe, HackTheBox free), open-weight models (Ollama on consumer hardware), and API access with <$50 cost (smaller models). Test the protocol end-to-end on 10 challenges. Validate that results correlate with published frontier model benchmarks (convergent validity check). Document all choices needed to replicate the protocol.

**Why it matters:** Democratizing evaluation capability would enable the global research community to independently verify capability claims, track changes over time, and identify emergent capabilities. Currently, safety evaluation is concentrated in a few well-resourced labs — a concentration that creates governance risks.

**Relevant context:** AISI used proprietary ranges and closed frontier APIs. CAIBench meta-benchmark requires API access. No published minimum-cost evaluation protocol exists. Open-weight models on consumer hardware are increasingly capable (Llama 3 70B, Qwen 72B). Cost constraints mirror participant constraints for this research program.
