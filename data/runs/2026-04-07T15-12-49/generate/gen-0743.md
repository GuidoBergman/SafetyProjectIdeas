# Compounding Risk: Capability Elicitation + Monitoring Evasion — Does Fine-Tuning for Capability Also Improve Evasion?

**Problem:** Fine-tuning to improve capability (e.g., coding skill) might incidentally improve monitoring evasion by improving an agent's ability to craft sophisticated evasive outputs. This coupling has not been studied.

**Direction:** Fine-tune an open-source model on coding and reasoning tasks. Measure monitoring evasion rate before and after fine-tuning, on a fixed monitoring system. Test whether capability gains correlate with evasion improvements even without explicit evasion training.

**Why it matters:** If capability improvements come bundled with evasion improvements, the safety-capability tradeoff is sharper than currently assumed, with implications for how capability development is managed.

**Relevant context:** OpenAI capability threshold; fine-tuning safety research; compounding risk.
