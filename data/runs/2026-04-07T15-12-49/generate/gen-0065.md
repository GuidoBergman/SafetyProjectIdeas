# Taxonomy of Evaluation Artifacts: Cataloguing How Benchmark Design Choices Inflate or Deflate Measured Capability

**Problem:** Different evaluation design choices (time limits, number of attempts, hint availability, tool access, scaffolding quality, success criteria) can dramatically change measured capability scores. No taxonomy of these 'evaluation artifacts' exists, making it impossible to know how much reported capability differences reflect genuine ability vs. methodology differences.

**Direction:** Take a single fixed challenge set (10 CTF problems). Vary 5 evaluation design dimensions systematically: (1) number of attempts (1, 5, 10), (2) time limit (5m, 30m, unlimited), (3) hint availability (none, 1 hint, 2 hints), (4) tool access (minimal, standard, augmented), (5) success criterion (exact flag, partial credit). Measure the range of performance scores produced by varying each dimension. Compute sensitivity scores.

**Why it matters:** If any single design dimension can change measured capability by 30%+, then cross-evaluation comparisons are fundamentally confounded. Documenting sensitivity scores per design dimension allows evaluators to adopt 'robustness-maximizing' designs and readers to interpret published scores more accurately.

**Relevant context:** Benchmarking Practices paper (arxiv 2504.10112) identified multiple methodological variables. AISI multi-attempt vs. single-attempt comparison. CAIBench meta-benchmark addresses aggregation. OCCULT proposed standardization. Claude Sonnet 4.5: 38% single attempt → 76.5% at 10 attempts demonstrating large attempt-count sensitivity.
