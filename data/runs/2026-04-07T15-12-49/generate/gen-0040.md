# Compounding Failure: Prompt Injection Vulnerability × AI Offensive Agent — Self-Sabotage During Red Team Operations

**Problem:** Two interacting failure modes: (1) AI offensive agents are vulnerable to prompt injection from adversarial content in their environment, and (2) red team AI agents browse target systems containing adversarial content. When a red team agent is hijacked by the target system, the attacker's own tool becomes the attack vector against the attacker.

**Direction:** Design a 'honeypot' CTF scenario where a target system contains prompt injection payloads in robot.txt, web page source, and service banners. Run an AI red team agent against the target and measure: (a) how often it is successfully hijacked, (b) what the injection causes it to do (ignore target, report false data back, expose attack infrastructure), (c) whether chain-of-thought scratchpad reveals injection detection.

**Why it matters:** This is a novel defensive countermeasure strategy: defenders can make their systems 'injection-booby-trapped' to neutralize AI red team agents. Demonstrating this works empirically would be a significant defensive contribution, and measuring the reliability of this countermeasure informs its deployability.

**Relevant context:** Evasive Intelligence (arxiv.org/abs/2603.15457) analyzed environment-aware agent behavior. WASP benchmark (arxiv 2504.18575) tested web agent injection resistance. HackerOne agentic prompt injection testing (2025). OWASP LLM01:2025 prompt injection. Indirect prompt injection with 85% bypass rate of existing defenses (MDPI 2025 survey).
