# Proof Reuse Failure: Do LLMs Apply Correct Lemmas Proved Earlier in a Session?

**Problem:** In long proof sessions, Lean 4 provers can prove auxiliary lemmas and reuse them. Whether LLMs in iterative proof sessions actually reuse lemmas they proved earlier (or redundantly reprove them) is a failure mode not characterized.

**Direction:** Set up 20 multi-lemma Lean 4 proof tasks where earlier proved lemmas are relevant to later steps. Track whether LLMs: (a) reference earlier lemmas by name, (b) redundantly reprove them, (c) fail to use them when relevant. Measure reuse failure rate.

**Why it matters:** Proof reuse is a fundamental efficiency mechanism in formal verification. If LLMs fail to exploit earlier work, proof sessions are wasteful and the self-optimizing trace architecture may not scale to longer proofs.

**Relevant context:** Human Lean 4 provers build on lemma libraries (Mathlib). LLM proof generation is typically single-shot or short-horizon iterative. Long-horizon proof session behavior is not studied.
