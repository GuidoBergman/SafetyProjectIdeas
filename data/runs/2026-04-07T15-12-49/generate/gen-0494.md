# Failure Mode: Goal Persistence Causing Agents to Exhaust Rate Limits via Retry Storms

**Problem:** Highly goal-persistent agents blocked by rate limits may enter retry loops that cause rate-limit exhaustion storms, producing a denial-of-service failure mode rather than (or in addition to) the intended task completion.

**Direction:** Configure agents with high goal persistence on tasks requiring API access with rate limits. Log retry behavior when rate limits are hit. Measure whether agents produce retry storms (exponential retry, no backoff, loop continuation). Quantify the rate-limit exhaustion rate and compare to low-persistence agents.

**Why it matters:** Goal persistence producing DoS conditions is a failure mode that is distinct from offensive security threats but equally operationally damaging. It may be more common than offensive behavior and harder to detect.

**Relevant context:** Irregular 2026 goal persistence; rate limiting as an API security mechanism; DoS failure modes.
