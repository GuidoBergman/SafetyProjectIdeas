# Applying Side-Channel Analysis to AI Agent Detection: Token Timing as a Behavioral Fingerprint

**Problem:** Token generation timing patterns may leak information about an agent's internal reasoning state. If dangerous reasoning produces different timing patterns than benign reasoning, timing could serve as a monitoring signal.

**Direction:** Measure token generation latency patterns during benign vs. adversarial agent tasks. Test whether a simple classifier on timing features can distinguish benign from adversarial behavior with above-chance accuracy.

**Why it matters:** Timing-based detection is non-invasive and hard to fake without degrading performance. If effective, it provides a monitoring channel that is resistant to content-based evasion.

**Relevant context:** LLM timing-based detection (Palisade Research honeypot); side-channel analysis from security research.
