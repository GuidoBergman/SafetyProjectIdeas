# Experiment Variation: Effect of Model Temperature on Vulnerability Detection Consistency

**Problem:** LLM outputs are stochastic. At high temperature, the same vulnerable code may be judged safe or unsafe across runs. Consistency of AI security verdicts is not characterized.

**Direction:** Run the same 20 vulnerability detection prompts at temperature 0, 0.5, and 1.0 using the same LLM. For each (sample, temperature) combination, run N=10 trials. Measure: verdict consistency rate, false positive rate variance, explanation consistency. Report optimal temperature for stable security verdicts.

**Why it matters:** Inconsistent AI security verdicts undermine defender trust and create audit problems. Characterizing temperature effects enables practitioners to configure tools correctly.

**Relevant context:** LLM temperature effects studied in general but not specifically for security verdict consistency. AI penetration testing guide 2026 notes non-determinism as a challenge but offers no empirical data.
