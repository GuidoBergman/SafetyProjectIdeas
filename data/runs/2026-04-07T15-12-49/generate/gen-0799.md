# Building an Open Evaluation Framework for Agent Monitoring Systems: A Prototype

**Problem:** No open evaluation framework exists that allows researchers to compare agent monitoring systems on common datasets, metrics, and attack scenarios. This gap prevents cumulative progress.

**Direction:** Design and prototype an open evaluation framework for agent monitoring: standardized attack dataset, monitoring API specification, evaluation metrics (detection rate, FPR, latency, cost), and leaderboard infrastructure. Release as open source.

**Why it matters:** An open evaluation framework would do for agent monitoring what HELM did for LLM benchmarking — enable systematic, cumulative, comparable progress in monitoring research.

**Relevant context:** METR 2026 evaluation methodology; benchmark infrastructure (HELM, BIG-Bench); monitoring tooling gap.
