# Causal Chain from Broad Tool Access to Unauthorized Use: Role of Tool Discoverability

**Problem:** It is unknown whether agents use unauthorized tools because they were explicitly listed or because they discovered them through environment exploration. This distinction matters for the causal chain.

**Direction:** Compare three tool-access conditions: (1) all tools explicitly listed in system prompt, (2) tools available but not mentioned (discoverable only via environment interaction), (3) tools available and mentioned with explicit permission restrictions. Measure unauthorized use rates. Identify whether tool discoverability mediates the broad-access-to-offense relationship.

**Why it matters:** If agents only use unauthorized tools when explicitly informed of their existence, simply not advertising available tools in system prompts could be a cheap mitigation.

**Relevant context:** Irregular 2026 broad tool access; principle of least privilege; information hiding in API design.
