# Novel Direction: Characterizing AI Defensive Capability Across Security Maturity Levels

**Problem:** AI security tools may provide different marginal value to organizations at different security maturity levels (basic vs. advanced). Organizations with mature security programs may derive less benefit from AI tools.

**Direction:** Using a standardized security maturity rubric (OWASP SAMM or NIST CSF), classify 20 open-source projects by security maturity. For each, measure: existing CVE rate, time-to-patch, and AI scanner detection rate. Test whether AI detection rate correlates with project security maturity.

**Why it matters:** AI tools may be most valuable for low-maturity projects (the most vulnerable) but least likely to be adopted there. Understanding this gap informs targeted deployment strategies.

**Relevant context:** Wavestone AI Cyber Benchmark 2025 assesses AI security maturity. OWASP SAMM is a standard maturity framework. Correlation between project security maturity and AI tool effectiveness not studied.
