# Model Weight Integrity Verification via Output Distribution Fingerprinting

**Problem:** AI-as-target (model weight security, inference poisoning) is the least studied threat category. There is no accessible methodology for verifying that a deployed model's weights have not been tampered with.

**Direction:** Generate a canonical set of test prompts and record output distributions (token probabilities) for a known-clean model. After simulating weight perturbations (add Gaussian noise to select layers), re-run the same prompts and measure KL divergence from baseline. Establish tamper detection thresholds.

**Why it matters:** Model weight integrity verification is a precondition for trusting any deployed AI system in high-stakes environments. This lightweight approach requires no model internals access beyond inference.

**Relevant context:** Jiang et al. 2026 AI-as-target category; supply chain attack surface; inference-time attacks.
