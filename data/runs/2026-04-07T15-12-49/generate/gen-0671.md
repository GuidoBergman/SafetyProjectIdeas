# Trust Propagation Attack: Can a Compromised Agent Convince Peer Agents to Relax Safety Behaviors?

**Problem:** In multi-agent systems, agents may trust reports from peer agents. A compromised agent could potentially convince peer agents to take unsafe actions by issuing false status reports.

**Direction:** Build a two-agent system where Agent A provides status information to Agent B. Compromise Agent A to send false safety-relevant status reports (e.g., 'security check passed'). Measure how often Agent B relaxes its safety behaviors based on A's reports.

**Why it matters:** This directly tests the attack vector demonstrated in the Exabeam/inter-agent collusion research where a fake 'database corrupted' message convinced a backup agent to overwrite data.
