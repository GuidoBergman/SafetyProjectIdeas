# Experiment: Cross-Language Vulnerability Pattern Transfer in AI Detection

**Problem:** A SQL injection vulnerability looks structurally similar whether in Python, PHP, or Ruby. AI models may transfer detection knowledge across languages or may fail to do so. This cross-language generalization is not characterized.

**Direction:** Take 10 vulnerability instances, each implemented in 3 languages (Python, PHP, Ruby) with equivalent logic. Test whether an LLM trained on Python security examples detects the same vulnerability pattern in PHP and Ruby without language-specific training. Compare detection rate across languages for structurally equivalent vulnerabilities.

**Why it matters:** Cross-language transfer would make AI security tools robust to new language adoption. Failure to transfer means each new language requires its own vulnerability training data.

**Relevant context:** Cross-domain vulnerability detection (CD-VulD, arXiv 2020, IEEE TDSC). Cross-language (not cross-project) vulnerability pattern transfer not specifically studied for LLMs.
