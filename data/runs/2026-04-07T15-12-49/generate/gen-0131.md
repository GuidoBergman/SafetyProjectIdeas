# Evaluation Framework for AI-Assisted SOC Alert Triage Quality

**Problem:** Agentic SOC platforms claim 8x faster detection/20x faster response but these metrics lack independent validation or standardized measurement.

**Direction:** Design a small-scale SOC triage simulation using public datasets (e.g., CICIDS2017, UNSW-NB15). Have an LLM agent (Claude or GPT-4o) triage alerts, then score: accuracy vs. ground truth, false escalations, missed escalations, explanation quality. Compare with rule-based baseline.

**Why it matters:** If AI SOC tools produce overconfident or incorrect triages, security teams may act on bad information. Measuring this is foundational.

**Relevant context:** Microsoft ExCyTIn-Bench uses Microsoft Sentinel logs. CrowdStrike/Meta CyberSOCEval evaluates LLMs on SOC workflows. Neither is accessible for student-scale replication without enterprise data.
