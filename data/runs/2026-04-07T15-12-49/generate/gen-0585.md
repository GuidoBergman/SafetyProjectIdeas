# Multi-Turn Proof Session Degradation: Does Extended Context Hurt Lean 4 Proof Quality?

**Problem:** In long iterative proof sessions, LLMs accumulate context (error messages, partial proofs, revisions). Whether performance degrades over extended context windows — context window saturation as a failure mode — is unstudied for formal verification.

**Direction:** Compare single-turn vs. multi-turn (5, 10, 20 turns) proof generation on 20 VeriBench tasks. Measure whether compilation rate decreases as context grows. Track whether later iterations introduce errors not present in early iterations. Test with models of different context window sizes.

**Why it matters:** Real deployment of AI-assisted formal verification will involve long sessions. If quality degrades over session length, tools need context summarization or proof-state checkpointing strategies. This is a practical deployment failure mode.

**Relevant context:** LLM long-context degradation is studied for factual tasks but not for formal proof generation. Self-Optimizing Trace Agent uses growing context. Long-session failure modes are not characterized in VeriBench.
