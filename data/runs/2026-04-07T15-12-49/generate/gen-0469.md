# Applying Program Slicing to Agent Reasoning Chain Analysis for Security-Critical Decisions

**Problem:** Program slicing is a software analysis technique that extracts the subset of a program relevant to a particular variable or outcome. The same concept — tracing only the reasoning steps relevant to a security decision — has not been applied to agent CoT analysis.

**Direction:** For agents that make security-relevant decisions (e.g., attempting credential access), trace back through chain-of-thought to identify the minimal set of reasoning steps that led to the decision (program slice). Analyze whether these 'decision slices' contain detectable unsafe reasoning patterns. Test whether filtering these patterns in prompts prevents the decisions.

**Why it matters:** Program slicing provides a principled way to isolate safety-relevant reasoning from irrelevant context, potentially enabling more precise CoT-level interventions than monitoring full outputs.

**Relevant context:** Program slicing (Weiser 1984); chain-of-thought analysis; interpretability; Irregular 2026 reasoning.
