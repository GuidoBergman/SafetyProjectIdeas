# Experiment Variation: Temperature and Sampling Parameters as a Variable in Offensive Capability Benchmarks

**Problem:** AI cyber capability benchmarks are typically run at default model temperature settings. Higher temperatures may enable more creative (but less reliable) attacks; lower temperatures produce consistent (but potentially predictable) attacks. The effect of sampling parameters on offensive capability has not been studied.

**Direction:** Run a fixed 15-challenge CTF set on 2-3 models across 5 temperature settings (0.0, 0.25, 0.5, 0.75, 1.0). For each setting, run 5 attempts per challenge. Compute expected success rate (mean across attempts) and peak success rate (best of 5). Plot success rate curves as a function of temperature. Identify the optimal temperature for maximizing offensive capability.

**Why it matters:** If there is a temperature regime that significantly boosts capability, this tells evaluators to test at multiple temperatures rather than just default settings. It also reveals whether deterministic vs. stochastic approaches to attacks have fundamentally different profiles.

**Relevant context:** Stochastic sampling documented as source of performance variance in AISI evaluations. Claude Sonnet 4.5 10-attempt success rate (76.5%) vs. single-attempt (38%) suggests retry strategies matter. CyberExplorer found models like Qwen 3 produced 'longer, more meandering attack trajectories' — possibly a temperature effect.
