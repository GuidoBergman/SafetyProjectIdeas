# Specification Drift: How AI-Generated Lean Specs Deviate from Programmer Intent

**Problem:** Even when AI-generated Lean 4 code compiles and is formally verified, the spec itself may not capture programmer intent — a form of specification drift that formal verification cannot detect.

**Direction:** Collect 50+ Python function specifications, have LLMs translate them to Lean 4 with formal specs, then have human CS students evaluate whether the formal spec matches intent. Measure spec-intent alignment rate and characterize failure modes.

**Why it matters:** Formal verification only guarantees code matches spec. If spec generation is unreliable, the safety guarantee is hollow. This gap is the core failure mode of vericoding as a safety strategy.

**Relevant context:** ATLAS (POPL 2026) synthesizes verified Dafny programs at scale but does not validate that specs capture intent. AlphaVerus also does not address spec quality. This is an under-studied failure mode.
