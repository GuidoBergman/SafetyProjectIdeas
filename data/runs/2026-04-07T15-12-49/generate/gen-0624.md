# Formal Verification of Memory Safety in AI-Generated C Code: Can CBMC + LLM Replace Valgrind?

**Problem:** Claude Code Security found 500+ vulnerabilities including memory safety issues. Whether LLM-assisted CBMC formal verification of AI-generated C code provides better memory safety coverage than dynamic tools (Valgrind, AddressSanitizer) is untested.

**Direction:** Take 30 AI-generated C functions. Run each through: (a) Valgrind/AddressSanitizer on 1000 test inputs, (b) CBMC bounded model checking for memory safety properties, (c) LLM-assisted CBMC spec generation + verification. Compare coverage of memory bugs found per method. Measure false positive rates.

**Why it matters:** If CBMC+LLM provides better coverage than dynamic analysis, the case for formal verification as a memory safety tool becomes concrete and empirically grounded. This is directly applicable to the DARPA/RAND vision of formally verified security code.

**Relevant context:** CBMC is used industrially (Amazon AWS). Valgrind and AddressSanitizer are standard tools. No direct comparison of CBMC vs. dynamic analysis for AI-generated code exists. Claude Code Security found bugs Valgrind missed.
