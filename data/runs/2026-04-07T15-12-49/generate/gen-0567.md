# Multi-Step Proof Planning vs. Tactic-by-Tactic Generation: Which Architecture Succeeds More on Lean 4?

**Problem:** LLMs can generate Lean 4 proofs either by planning the full proof structure first then filling details, or by generating tactic by tactic. Whether planning-first architecture outperforms tactic-sequential generation on VeriBench is not tested.

**Direction:** Implement two Lean 4 proof generation architectures: (a) plan-then-fill (generate proof outline with sorry placeholders, then fill each sorry), (b) sequential tactic generation (standard left-to-right). Run both on 50 VeriBench tasks. Measure compilation rate and iterations required.

**Why it matters:** Identifying the superior proof generation architecture is a prerequisite for building better verification tools. Proof planning mirrors how human Lean experts work — if it helps LLMs, it suggests a path to human-level formal reasoning.

**Relevant context:** Chain-of-thought prompting (planning) improves LLM reasoning across domains. For Lean 4, planning-first is used informally but not systematically compared to sequential generation. This is a concrete architectural experiment.
