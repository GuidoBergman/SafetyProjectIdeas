# Novel Direction: Studying Whether AI Security Tools Exhibit Demographic Bias in Code Review

**Problem:** AI models exhibit demographic biases in many tasks. It is unknown whether AI code security reviewers assign different severity ratings or find different vulnerabilities based on code authorship signals (author name, coding style associated with demographics).

**Direction:** Take 20 vulnerable code samples. Create versions with: (a) neutral author metadata, (b) names associated with different demographic groups in GitHub metadata. Run AI security scanner on both versions. Measure: any change in detected vulnerability count, severity ratings, or explanation framing. Test for statistically significant differences.

**Why it matters:** If AI security tools exhibit demographic bias, they may systematically under-scrutinize code from certain groups, creating security disparities. This is a fairness and safety issue.

**Relevant context:** Demographic bias in LLM code review has been studied for code quality assessment. Security-specific bias in vulnerability detection ratings has not been studied.
