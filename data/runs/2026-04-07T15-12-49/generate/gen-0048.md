# Skill Decomposition for AI Offensive Evaluation: A Competency Framework Inspired by Job Task Analysis

**Problem:** AI cyber evaluation benchmarks measure end-to-end task completion without decomposing which specific skills each task exercises. Industrial/organizational psychology has well-developed job task analysis methods for decomposing complex job roles into constituent competencies that can be separately measured.

**Direction:** Apply job task analysis methodology: interview 3-5 expert pentesters to elicit the skill taxonomy of a full corporate network attack (minimum viable competency list per ATT&CK phase). Translate each skill into a measurable test (not a full task — just the isolated skill). Build a 40-item skill battery. Run AI models on the battery and compare skill profiles to end-to-end performance.

**Why it matters:** A validated skill decomposition enables: (1) targeted capability elicitation for safety evaluations, (2) identification of which skill gaps will be filled next by scaling, (3) cross-evaluation comparability regardless of which end-to-end task was used.

**Relevant context:** OCCULT used expert-developed knowledge tests (TACTL). DeepMind used bottleneck analysis on 7 attack chain archetypes. No psychometrically validated skill decomposition for AI cyber offense exists. Job task analysis is standard in HCI and industrial psychology and has been applied to cybersecurity workforce development.
