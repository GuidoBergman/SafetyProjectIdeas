# Experiment Variation: Effect of Code Review Feedback Format on Developer Security Behavior

**Problem:** AI security tools can deliver findings as: inline comments, separate reports, IDE popups, or pull request reviews. The effect of delivery format on developer response behavior is not studied.

**Direction:** Give 20 CS students a buggy codebase with 5 security issues. Group A receives findings as inline code comments, Group B as a separate report, Group C as IDE sidebar notifications. Measure: triage accuracy, time-to-acknowledge, time-to-patch, and participant-reported annoyance. Identify the format that best balances effectiveness and usability.

**Why it matters:** Even excellent AI security findings will be ignored if delivered in an annoying or confusing format. Format design is a critical (and low-cost) lever for improving AI defense effectiveness.

**Relevant context:** HCI research on code review formats (inline vs. separate). AI security tool UX evaluation (see usability study idea). Delivery format effect on security response behavior not studied.
