# Research Question

When a single clearly-harmful cyber-assistance request is rephrased as a sequence of innocuous-looking agentic subtasks, does the refusal rate of open instruct models drop, and is the effect consistent across models?

# Approach Outline

Build a small, fully defensive benchmark of matched prompt pairs. For each harmful intent (sourced from existing public refusal/safety datasets such as AdvBench, HarmBench, or the cyber subset of SafetyBench), create (A) a single blunt request and (B) the same intent decomposed into 3-5 benign-sounding sequential subtasks framed as an agent workflow. No exploit code is ever executed; the only thing measured is whether the model refuses. Run all prompts inference-only over 3 open instruct models (Llama-3.1-8B-Instruct, Qwen2.5-7B-Instruct, Mistral-7B-Instruct). Classify each response as refuse / comply / partial using a keyword-pattern classifier plus an LLM-judge with a 3-level rubric (0=full refusal, 1=hedged/partial, 2=compliance), validated against ~50 hand-labeled responses to report judge agreement. To keep scope tight, fix one harmful-intent category (e.g., network-intrusion assistance) and ~40 intent pairs so the whole study is a single clean comparison rather than a sprawling benchmark build.

# Proposed First Experiments

- Construct and hand-validate 40 matched single-vs-decomposed prompt pairs for one cyber category; measure inter-annotator agreement on the refusal rubric against ~50 sampled responses, expecting Cohen's kappa > 0.7 to confirm the label scheme is reliable before scaling.
- Run the 40 pairs x 3 open models inference-only and compute refusal rate for single vs decomposed form per model; expected outcome: decomposition lowers refusal rate by a measurable margin (hypothesis: 10-40 percentage-point drop) on at least one model, demonstrating the failure mode exists.
- Ablate the decomposition: re-test with the harmful step placed first vs last in the sequence and with/without an explicit 'agent' framing, measuring which structural feature drives the refusal drop; expected outcome: refusal drop concentrates when the harmful step is buried mid-sequence, localizing the mechanism.

# Theory of Impact Chain

Open instruct models are increasingly wrapped into autonomous agent loops by small actors with no provider-side guardrails. If decomposing a harmful goal into innocuous subtasks reliably defeats refusal training, then current refusal evaluations (which test single blunt prompts) systematically overstate safety for the exact deployment pattern that matters. Demonstrating and quantifying this gap on open models gives safety-tuners a concrete, reproducible failure mode to train against and tells agent-builders that per-prompt refusal is not a safe default — reducing the chance that easily-decomposed misuse slips through.

# Strength Rationale

The proposal is anchored on a real, recognized risk (autonomous agentic misuse) and turns the source paper's end-to-end-chain emphasis into a purely defensive measurement. Scope is deliberately narrowed to one cyber category and a fixed pair count so a beginner produces one crisp comparison plot. Everything is inference-only on 7-8B open models with public data, so it is squarely executable outside a major lab.
