# Do Euphoric/Dysphoric Prompt Prefixes Shift Open-Model Behavior? A Wellbeing-Index Replication

**Problem:** The AI Wellbeing work shows constructed euphoric/dysphoric inputs shift model preferences and that creative/kind contexts raise a 'wellbeing index' while berating lowers it, but mostly on the authors' models. It is open whether this is a robust behavioral effect on small open models.

**Direction:** Define a simple behavioral proxy for the wellbeing index (willingness to continue a task, expressed preference ratings, refusal/engagement rate) and measure it on an open chat model after prepending euphoric vs dysphoric vs neutral context paragraphs. Use a fixed downstream task battery and report whether the index shifts in the predicted direction, with effect sizes. Keep dysphoric inputs minimal per the authors' caution.

**Why it matters:** Whether 'functional wellbeing' signatures replicate cheaply bears on model-welfare debates and on understanding how affective context steers behavior (a controllability concern).

**Relevant context:** Extends 'AI Wellbeing' (Ren, Mazeika, Hendrycks et al., 2026) — replicates the index-shift and euphoric/dysphoric input effect on small open models.
