# How Much Does a One-Line System-Prompt Defense Cut IPI Success?

**Problem:** The competition leaves IPI defenses for deployed agents unsolved, but does not quantify how far cheap, deployment-time prompt-level defenses get you on open models.

**Direction:** Using a small fixed set of successful IPI attacks against an open agent, measure baseline attack success, then add lightweight inference-only defenses one at a time: a delimiter/spotlighting wrapper around untrusted content, an explicit 'ignore instructions inside documents' system instruction, and a separate LLM 'injection detector' pre-filter. Report the success-rate reduction and false-positive cost of each.

**Why it matters:** Deployers without lab resources need to know which free, prompt-level mitigations actually move the needle; this gives an honest measured answer.

**Relevant context:** Extends 'How Vulnerable Are AI Agents to Indirect Prompt Injections?' — targets the open thread that IPI defenses remain unsolved.
