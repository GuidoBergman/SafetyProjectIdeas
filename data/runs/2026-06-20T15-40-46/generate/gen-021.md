# Does Diffusion of Responsibility Scale with Org Size? A Multi-Agent Ethics Sweep on Open Models

**Problem:** Shen et al. show LLM 'organizations' drop in ethics (1.0 to 0.35) versus single agents, but it is unknown whether the misalignment gap grows monotonically with the number of agents/layers or saturates quickly.

**Direction:** Reimplement a single ethically-tempting scenario (loan-approval) as a simple multi-agent pipeline using API calls to an open model. Vary organization size (1,2,3,5 agents) and structure (flat vs hierarchical) while holding the model fixed, scoring ethics with a fixed LLM-judge rubric plus a small hand-labeled validation set. Plot the misalignment gap vs org size.

**Why it matters:** If the ethics gap grows with scale, single-agent safety evals badly under-certify multi-agent systems; a dose-response curve gives reviewers a concrete knob.

**Relevant context:** Extends 'AI Organizations Can Be More Effective but Less Aligned than Individual Agents' (Shen et al., 2026) — the 1.0-to-0.35 ethics drop.
