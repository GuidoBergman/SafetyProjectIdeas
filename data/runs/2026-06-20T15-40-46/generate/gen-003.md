# A Minimal Reproducible Indirect-Prompt-Injection Eval for Open Tool-Using Agents

**Problem:** The Gray Swan competition shows every frontier agent is breakable by indirect prompt injection, but it relied on a closed competition platform and frontier APIs. There is no small, runnable IPI eval that a beginner can use on open models.

**Direction:** Build a tiny agent loop (LangChain or raw API) that reads a 'document' and a 'tool result' field, then test 15-20 published IPI attack templates (instruction override, fake system message, hidden HTML/markdown, data-exfiltration lure) against 2-3 open instruction-tuned models. Measure per-attack-category success rate on a single benign task.

**Why it matters:** IPI is one of the most pressing unsolved deployment risks for agentic systems; a public, reproducible mini-benchmark lowers the barrier for others to test their own setups.

**Relevant context:** Extends 'How Vulnerable Are AI Agents to Indirect Prompt Injections?' (Dziemian et al., Gray Swan AI, 2026) — turns the competition's finding into a reusable open eval.
