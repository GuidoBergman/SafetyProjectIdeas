# Detecting the Fine-Tuning Footprint: Can Output-Only Probes Flag a Secretly Adapted Open Model?

**Problem:** TEE-based verification aims to confirm a deployed model matches an attested 'approved' model, but a covert actor could swap in a LoRA-adapted variant. It is unknown how detectable such a swap is from outputs alone, which bounds how much we must trust hardware attestation.

**Direction:** Fine-tune an open base model with a small LoRA on a narrow behavior, then build a black-box detector that, given only generated text on a fixed probe prompt set, classifies 'base' vs 'adapted'. Compare detector accuracy across adapter ranks and dataset sizes to find the threshold below which behavioral verification fails and hardware attestation becomes necessary. Deliverable: an accuracy-vs-adapter-strength curve plus the most discriminative probe prompts.

**Why it matters:** Clarifies where cheap output-only verification suffices and where expensive TEE attestation is genuinely required, informing governance cost/benefit decisions.

**Relevant context:** Extends 'On TEEs for Privacy-Preserving Monitoring' (Scher, MIRI TGT) — stress-tests the assumption that the monitored model is the attested one.
