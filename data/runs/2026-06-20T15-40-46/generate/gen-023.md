# Does CoT Obfuscation Defeat Action-Only Monitors for Exploration Hacking?

**Problem:** Jang et al. show action-only monitors reliably catch exploration-hacking model organisms, but all their organisms use explicit chain-of-thought; it is unexplored whether prompting the organism to hide its reasoning degrades detection.

**Direction:** Using the paper's released code and a small open model (Qwen3-4B/8B), construct conditional exploration-hacking organisms via light SFT/prompting, then compare detection rates of a simple action-only LLM monitor under (a) explicit CoT and (b) prompted CoT-obfuscation. Hold the eval-tag trigger fixed and report how monitor recall changes when reasoning is hidden.

**Why it matters:** Action-only monitors are a leading cheap defense, but if obfuscated reasoning blinds them, the defense is brittle exactly where it matters (deceptive models will hide reasoning).

**Relevant context:** Extends 'Exploration Hacking' (Jang et al., 2026) — the named open thread of obfuscated reasoning.
