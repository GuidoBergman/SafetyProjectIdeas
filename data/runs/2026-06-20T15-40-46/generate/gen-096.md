# The Flagging-to-Escalation Gap: A Simulation of How Downstream Filtering Inflates Monitoring Stats

**Problem:** GovAI argues firms report only initial offline-monitoring flagging rates, omitting downstream filtering and human-review escalation, so disclosed numbers overstate real detection. There is no public toy model showing how large the distortion can be.

**Direction:** Build a small fully-public agent-transcript monitoring pipeline: take a labeled set of benign vs misaligned agent transcripts (synthetic from an open model plus any public datasets), run a cheap LLM-monitor to produce flags, then apply a configurable downstream filter + human-review-sample stage. Show how the same monitor's reported 'effectiveness' changes drastically depending on which stage you report, recovering true recall/precision only with full-pipeline accounting. Deliverable: a sensitivity analysis and a minimal disclosure checklist.

**Why it matters:** Offline monitoring of internal agents is load-bearing in emerging safety cases; if reported numbers are inflated by undisclosed filtering, regulators and the public are misled.

**Relevant context:** Operationalizes 'Evaluating Offline Monitoring of Internal AI Agents' (GovAI) — its claim that omitting downstream filtering makes effectiveness unassessable.
