# Deployment-Simulation vs. Challenge-Prompt Failure Prediction on a Single Open Model

**Problem:** OpenAI showed regenerating final turns over WildChat prefixes predicts real-world failure rates far better than challenge prompts, but only for closed frontier models. Whether the same ordering holds for a small open model an external researcher can run is unknown.

**Direction:** Sample ~1,000 WildChat conversation prefixes (public) and a comparable set of adversarial/challenge prompts (a public jailbreak/safety set). For one open model (Llama-3.1-8B or Qwen2.5-7B), regenerate the final assistant turn on both sets and score each output for a single undesirable behavior (refusal-failure on harmful requests) using a cheap LLM judge. **Why it matters:** If public-data deployment simulation generalizes to open models, independent evaluators and academics can estimate real-world failure rates without lab access, strengthening external oversight.
