# Do open-model 'monitors' catch sabotage when the agent doesn't know it's watched? A trusted-monitor replication

**Problem:** Apollo argues scalable monitoring works because there is near-unlimited data and it reduces to an automatable optimization, but it is unclear how well a cheap open-weight monitor (not a frontier model) detects subtle sabotage in coding-agent transcripts.

**Direction:** Take a public set of agent transcripts containing benign and sabotaged/backdoored code completions (SHADE-Arena or AutoMonitor-Bench style, or synthesize pairs by inserting known CWE backdoors into clean solutions). Prompt a small open model (Llama-3.1-8B / Qwen2.5-7B) as a binary 'safe or sabotage?' monitor and measure AUROC / TPR-at-fixed-FPR. Vary the prompt (action-only vs full CoT visible) to test whether seeing the agent's reasoning helps.

**Why it matters:** Scalable monitoring is a leading non-interpretability safety bet; if cheap open monitors already get usable detection rates, monitoring is deployable outside frontier labs.

**Relevant context:** Extends Apollo 'A scalable monitoring research agenda' — its claim that simpler baselines have not been beaten, tested at the small-model end.
