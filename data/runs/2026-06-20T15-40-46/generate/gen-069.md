# How much does an open model's task horizon shrink without chain-of-thought?

**Problem:** Control protocols often assume monitorability rests on visible reasoning, but there is little open replication of how much capability collapses when small/mid open models are denied CoT. The original no-CoT horizon work uses inaccessible frontier models.

**Direction:** Pick 2-3 open models (Llama-3.1-8B-Instruct, Qwen2.5-7B, DeepSeek-R1-Distill-Qwen-7B) and a public multi-step benchmark with gradable difficulty (GSM8K, a BBH subset, or simple multi-step agentic tasks). Run each in CoT-allowed vs CoT-suppressed (force immediate answer via prompt + constrained decoding) modes. Measure accuracy as a function of task 'length' (reasoning steps required) and estimate the effective no-CoT horizon per model.

**Why it matters:** If externalized reasoning is load-bearing for capability, CoT monitoring is a strong control lever; if open models retain much capability without CoT, control protocols assuming CoT-dependence are fragile.

**Relevant context:** Extends 'Estimating No-CoT Task-Completion Time Horizons of Frontier AI Models' (Woodruff, Redwood, 2026) — replicates its core measurement on open models.
