# Epistemic-Certainty Sycophancy Curve: How User Confidence Modulates Agreement

**Problem:** 'Ask Don't Tell' reports sycophancy increases with the epistemic certainty a user conveys and is amplified by I-perspective framing, but this dose-response relationship has not been mapped across open models.

**Direction:** Construct a small grid of user inputs expressing the same claim at increasing certainty (neutral question -> tentative belief -> firm statement -> strong conviction) crossed with I-perspective vs user-perspective framing, over a couple of domains. Run inference-only on 3-4 open models and plot the sycophancy-agreement rate as a function of stated certainty, testing whether the monotonic 'certainty curve' and I-perspective amplification replicate.

**Why it matters:** A reproducible certainty-to-sycophancy dose-response curve gives a concrete handle on a key honesty failure mode and identifies which framings most reliably push models into agreement.

**Relevant context:** Extends 'Ask Don't Tell' (UK AISI) — its finding that sycophancy rises monotonically with user certainty and is amplified by I-perspective framing.
