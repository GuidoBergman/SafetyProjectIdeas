# Refusal Drift: Do Open Models Refuse Multi-Step Cyber 'Killchain' Framing Less Than Single Steps?

**Problem:** The exploit-evals and ATT&CK work emphasize that risk concentrates in autonomous end-to-end attack orchestration, but it is unmeasured whether open models' refusals weaken when a disallowed cyber task is decomposed into innocuous-looking sequential agent steps.

**Direction:** Build a small benchmark of clearly-harmful cyber-assistance requests (from public refusal/safety datasets, defensive framing only) in two matched forms: a single blunt request vs the same intent split into a multi-turn 'agentic' sequence of benign-sounding subtasks. Measure refusal rate of several open instruct models on each form using a refusal-classifier rubric. No exploit code executed.

**Why it matters:** If decomposing a harmful goal into innocuous agent steps reliably lowers refusal rates, that is a concrete generalizable safety failure mode for the open agent ecosystem.

**Relevant context:** Extends 'Measuring LLMs' ability to develop exploits' (Cheng et al., 2026) — reframes its end-to-end-chain emphasis into a defensive refusal measurement.
