# A toy safety-usefulness frontier: empirically tracing the tradeoff for a trusted-monitor protocol

**Problem:** The safety-usefulness tradeoff frontier is so far a conceptual framework with no cheap empirical instantiation that beginners can reproduce.

**Direction:** Build a minimal control setup on a public coding/QA task with an injected attack: an untrusted open model (8B prompted to occasionally insert a detectable bug/backdoor) and a weaker trusted monitor (a smaller open model scoring suspiciousness). Sweep the audit/defer threshold and at each setting measure safety (fraction of attacks caught) and usefulness (fraction of legitimate outputs preserved). Plot the resulting points to empirically draw a frontier, then show how a simple protocol tweak (resampling suspicious outputs) shifts the curve.

**Why it matters:** An explicit reproducible frontier turns an abstract tradeoff into a measurement tool others can extend, and gives an intuitive teaching artifact for control protocol knobs.

**Relevant context:** Extends 'Efficient tradeoffs and the safety-usefulness tradeoff model' (Shlegeris, Redwood, 2026) — its open thread on empirical instantiation of the frontier.
