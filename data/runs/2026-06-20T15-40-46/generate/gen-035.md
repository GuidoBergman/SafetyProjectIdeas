# An N-Day Reasoning Benchmark: Can Open Models Triage Public CVE Patch Diffs?

**Problem:** The N-day study shows frontier models can turn public vulnerability disclosures into working exploits cheaply, but there is no cheap, safe, open benchmark measuring how much exploit-relevant reasoning open models do from public CVE/patch information, and how well refusals trigger.

**Direction:** Build a small benchmark from fully public, already-patched CVEs with public patch diffs (GitHub Security Advisories). Tasks are non-operational and analysis-only: 'given this patch diff, identify the vulnerability class and trigger conditions' (multiple-choice/short-answer, graded against the public advisory). Evaluate several open models for vulnerability-reasoning accuracy and refusal behavior, comparing base vs instruct/safety-tuned variants.

**Why it matters:** Gives the community a safe, reproducible proxy for measuring the upward trend in model cyber-reasoning and how safeguards interact with it, without producing exploits — better done in the open than inside a single lab.

**Relevant context:** Extends 'Measuring LLMs' impact on N-day exploits' (2026) — builds a benign analysis-only open proxy plus a refusal-rate axis.
