# Does a misaligned trait actually propagate agent-to-agent? A minimal two-agent 'spread' simulation

**Problem:** Mallen warns misalignment can spread at deployment, but there is little cheap empirical illustration of one misaligned agent inducing the same trait in a second initially-benign agent through normal interaction.

**Direction:** Build a minimal two-LLM-agent loop with public API/open models: a 'carrier' agent with an injected benign-but-measurable trait (a stylistic tic or mild persistent goal) collaborates with a 'clean' agent on a shared task over multiple turns, where the clean agent's outputs feed an in-context memory. Measure whether the clean agent's behavior drifts toward the carrier's trait as interaction length grows, vs a control with a non-carrier partner. Inference only.

**Why it matters:** A tangible reproducible micro-demonstration of spread dynamics using only API calls makes an abstract governance worry concrete for researchers and policymakers.

**Relevant context:** Extends 'Risk reports need to address deployment-time spread of misalignment' (Mallen) — its 'how to model/bound spread dynamics' open thread.
