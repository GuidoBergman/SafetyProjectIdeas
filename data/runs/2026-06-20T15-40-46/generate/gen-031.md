# Rationale-Conditioned Prompting: Does Explaining 'Why' a Rule Exists Improve Rule-Following at Inference Time?

**Problem:** MSM's core hypothesis is that exposing the reasoning behind behavioral rules improves how models apply them. This is tested via expensive midtraining, but the same hypothesis can be cheaply tested at inference time with no training.

**Direction:** Build a small public eval set of behavioral-rule prompts plus OOD paraphrases. For several open instruct models, compare two system prompts: a 'rules-only' spec vs a 'rules-with-rationale' spec. Measure rule adherence on OOD/edge cases to see whether rationale text alone improves generalization, isolating the prompting-level analog of MSM.

**Why it matters:** If rationale conditioning helps without training, practitioners deploying open models get a free robustness improvement, and it clarifies how much of MSM's benefit is in-context vs weight-level.
