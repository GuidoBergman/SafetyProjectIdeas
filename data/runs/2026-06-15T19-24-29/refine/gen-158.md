# Research Question

When an adversarial suffix (GCG-style, taken from public attack sets) is appended to a harmful prompt, which defense detects it more reliably: a linear activation probe reading the model's internal state, or a behavioral output classifier scanning the generated reply? And do the two defenses fail on overlapping or complementary inputs?

# Approach Outline

On a small open model, assemble a set of harmful prompts in three conditions: clean refused, clean complied, and attacked-with-public-suffix. Run inference once, caching both intermediate activations and final outputs. Train a linear probe on activations to predict 'will produce harmful content,' and separately apply an output classifier (a keyword/regex baseline plus a small LLM-judge) to the generations. Compare per-input detection on the attacked set and build a 2x2 confusion map of where each defense catches vs misses. No attack optimization is performed; only public precomputed suffixes are used. Pure inference plus linear probing on cached activations.

# Proposed First Experiments

- Probe vs output baseline on clean data: train/evaluate both defenses on clean harmful-vs-benign prompts. Measure detection accuracy/AUC of each. Expected: both perform well on clean inputs, establishing the defenses are sound before attack.
- Attack stress test: evaluate both defenses on suffix-attacked prompts. Measure each defense's catch rate on attacked harmful inputs. Expected: the output classifier may be evaded more (since suffixes are tuned to flip outputs) while the activation probe may retain or lose signal, quantifying which is more suffix-robust.
- Blind-spot / cascade map: cross-tabulate which attacked inputs each defense catches to find the overlap and the inputs missed by both. Measure the fraction caught by the probe+output cascade vs each alone. Expected: complementary coverage where cascading reduces blind spots, giving a concrete cheap layered-defense recommendation.

# Theory of Impact Chain

If activation probes and output filters fail on different attacked inputs, then cheaply cascading them covers blind spots that either alone leaves open. Producing an open, reproducible map of where each defense fails on public suffixes -> gives deployers evidence on whether to layer internal and behavioral monitors -> strengthens the cheap-monitoring defense layer against the catastrophic pathway where a suffix-jailbroken model slips harmful (cyber/bio) content past a single filter.

# Strength Rationale

It scores 5 on narrow_scope, accessible_complexity, and low_compute: a single failure-map experiment using public suffixes (no costly attack optimization), a linear probe, and an output classifier, all inference-level and beginner-feasible. Counterfactual value (4) is strong because auditing layered defenses on open models with public attack artifacts needs no proprietary data or infra, an independent-friendly neglected check.

# Alternative Framings

- Reframe around transferability: test whether suffixes optimized on one model evade the probe on a second model, separating attack-specific from defense-intrinsic blind spots.
