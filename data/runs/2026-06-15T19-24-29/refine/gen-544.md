# Research Question

Where exactly does increasing optimization pressure stop improving the true goal and start degrading it (the 'Goodhart break point'), and which proxy properties (noise variance, correlation strength, distribution shift) predict an earlier break? The aim is a controlled, reproducible empirical map of the regressional vs. extremal break point.

# Approach Outline

Build a tiny toy with a few synthetic 'true reward' functions plus a noisy/biased proxy, and a best-of-n sampling loop (over a simple bandit or an open model). Sweep optimization pressure (n in best-of-n) and plot true reward vs. proxy reward to locate the peak, the break point, for each proxy configuration. Systematically vary proxy properties (noise variance, true-proxy correlation, induced distribution shift) and record how the break point moves, separately characterizing regressional vs. extremal cases. Pure analysis, CPU or tiny GPU; the toy runs fast, leaving the 30 hours for the parameter sweep, fitting, and write-up.

# Proposed First Experiments

- Locate a single break point: with one true reward and a gold-plus-noise proxy, sweep n in best-of-n and plot true vs. proxy reward; identify the n at which true reward peaks. Expected outcome: a clear, reproducible break point where over-optimization begins.
- Map break point vs. proxy quality: vary proxy noise variance and true-proxy correlation, re-locate the break point each time, and fit break-point location as a function of these properties. Expected outcome: a quantitative relationship (e.g., earlier break for noisier / less-correlated proxies).
- Separate regressional from extremal Goodhart: introduce a proxy with a heavy-tailed / biased relationship to the true reward and compare its break-point behavior to the regressional case. Expected outcome: distinct break-point signatures for the two Goodhart regimes.

# Theory of Impact Chain

The causal chain for reward hacking runs proxy -> optimization pressure -> proxy/true decoupling -> harm; the under-measured link is exactly where decoupling begins. An empirical map of the break point and the proxy properties that move it -> practitioners can set safer optimization budgets and recognize when a proxy is too weak to push hard on -> reduced over-optimization of imperfect learned rewards, mitigating the catastrophic-risk pathway in which a capable system optimizes a proxy reward past the point where it tracks human-intended goals.

# Strength Rationale

Scores 5 on counterfactual value, low compute, narrow scope, and accessible complexity: it operationalizes a famous theoretical taxonomy with a CPU-or-tiny-GPU toy that needs no training, no lab data, and no model internals, addressing neglected fuzzy-reward Goodhart science that labs deprioritize. The scope is one tightly-defined experiment (sweep pressure, locate the break point, relate it to proxy properties) with explicit success criteria suited to a beginner team.

# Alternative Framings

- Frame it as building a practical 'safe optimization budget' calibrator: given measured proxy noise/correlation, predict the n / KL budget at which to stop optimizing.
