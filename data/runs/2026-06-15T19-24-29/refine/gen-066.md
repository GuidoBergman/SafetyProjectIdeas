# Research Question

Can classic stylometric / steganalysis features distinguish LLM outputs that secretly encode a hidden bitstring (acrostics, synonym choice, punctuation patterns) from clean outputs, providing a cheap, training-light detector for steganographic encoded reasoning and secret collusion?

# Approach Outline

From one open model, generate paired outputs on the same prompts: clean responses and responses instructed to embed a secret bitstring via a chosen scheme (acrostics, synonym substitution, punctuation/spacing timing). Extract classic stylometric features (function-word frequencies, character n-gram distributions, perplexity under a clean reference LM) and train a simple classifier (logistic regression / small random forest) to separate stego from clean text. Measure detection AUC, identify which features carry the signal, and test generalization to a held-out encoding scheme the classifier was not trained on. Light inference plus a small classifier, near CPU-feasible, fits comfortably in 30 hours including the write-up.

# Proposed First Experiments

- Build the paired corpus: generate clean and stego responses for a fixed prompt set under one encoding scheme, verifying the stego outputs actually carry recoverable bits. Measure embedding success rate. Expected outcome: a clean/stego labeled dataset with confirmed hidden payloads.
- Train and evaluate the detector: extract stylometric features, train the classifier, and report detection AUC plus feature-importance ranking. Expected outcome: AUC well above 0.5 with an interpretable set of discriminative features (e.g., function-word skew, perplexity shift).
- Test cross-scheme generalization: train on one encoding scheme (e.g., acrostics) and test on another (e.g., synonym choice) to probe whether the detector catches unseen channels. Expected outcome: a quantified generalization gap revealing whether stylometric steganalysis is scheme-specific or broadly useful.

# Theory of Impact Chain

Encoded reasoning and secret collusion are an Open Phil starred problem: agents that hide information in innocuous-looking text can coordinate or reason covertly past monitors. A lightweight, training-light stylometric detector deployable by anyone monitoring agent channels -> cheaper, broader detection of hidden channels in multi-agent and CoT-monitored deployments -> reduced chance that colluding or covertly-reasoning agents evade oversight, mitigating the catastrophic-risk pathway in which agents coordinate secret defection or hide dangerous reasoning from human and automated monitors.
