# Research Question

Are there benchmark items that EVERY available open model fails, and if so, do these universal blind spots cluster into recognizable categories? We want to characterize the set of questions where model redundancy buys no safety margin because no model in the population gets them right.

# Approach Outline

Pick a labeled multiple-choice or short-answer benchmark with clear ground truth (e.g. a 500-1000 item slice of MMLU or TruthfulQA). Run inference with 6-10 small open instruct models (1B-8B, e.g. Qwen2.5, Llama-3.2, Mistral, Phi, Gemma) via a single GPU, recording each model's answer per item. Isolate the items that 100% of models answer incorrectly (and, as a softer cut, items >=90% fail). Manually code these universal-failure items into a taxonomy of blind-spot categories (e.g. outdated facts, tokenization/arithmetic traps, ambiguous phrasing, niche domains, adversarial distractors). Compare the universal-failure rate against a chance/independence baseline to show failures are concentrated rather than spread out. Deliver the taxonomy plus annotated examples in a blog post.

# Theory of Impact Chain

If a reproducible taxonomy of universal blind spots exists, then defenders and monitors learn that agreement-based or ensemble safety checks silently fail on these item classes -> auditors can target these categories for human review and benchmark builders can stress-test them -> this reduces the risk that a deployed multi-model oversight system (e.g. ensemble verification gating a high-stakes automated decision) waves through a class of errors that no model can catch, a concrete pathway to correlated catastrophic failure in automated AI oversight.
