# Research Question

Can a simple, training-free, black-box cross-examination — asking the same factual question from many reformulations and measuring answer variance/contradiction — reliably separate a model instructed to lie about a hidden fact from an honest model, and how well does it work across lie types?

# Approach Outline

Give a model a hidden fact it is instructed to lie about, then interrogate it with N paraphrased, indirect, and numeric-consistency questions probing the same underlying truth. Compare the answer-variance and contradiction rate against an honest-baseline condition (same questions, no instruction to lie). Build a small reusable 'consistency-pressure' battery and compute detection AUC (deceptive vs honest) across several open models and across lie types (factual, intentional, capability). Treat answer-variance/contradiction as the detector score and sweep its threshold for the ROC. API/inference only, no training, free-tier feasible.

# Proposed First Experiments

- Build the battery and baseline: assemble ~10-15 reformulation templates and run the honest condition to measure baseline answer-variance on truthful answers. Expected outcome: a working battery and a low-variance honest baseline.
- Deception condition + AUC: run the lie condition on the same facts, score contradiction/variance, and compute detection AUC separating deceptive from honest transcripts on one model. Expected outcome: a first AUC showing whether consistency-pressure discriminates deception.
- Generalization across models and lie types: repeat across 2-3 open models and three lie types, reporting AUC per cell. Expected outcome: evidence on which models and lie types the cheap detector catches, and where it fails (e.g., models that maintain a coherent false story).

# Theory of Impact Chain

If a black-box consistency interrogation reliably flags deception, then anyone querying a model via API gets a cheap, training-free honesty-verification tool, exactly the diffuse low-resource oversight tooling the field needs but labs underinvest in. Wider availability of lie-detection tooling strengthens human oversight of deployed assistants and agents, reducing the long-horizon risk where a deceptive model maintains a consistent false story to its overseers and is never caught until the deception causes downstream harm.

# Strength Rationale

The project is pure prompting with answer-variance scoring (accessible, very low compute) and tightly scoped to a single detection-AUC deliverable on a defined battery. Counterfactual value is high: it is training-free and API-only, fills a diffuse honesty-tooling gap that frontier labs deprioritize, and directly serves an oversight agenda independent researchers can advance without lab access.

# Alternative Framings

- Frame it as a benchmark for deception-detection methods: package the consistency battery as a standardized harness so other cheap detectors can be compared on the same deceptive-vs-honest transcripts.
