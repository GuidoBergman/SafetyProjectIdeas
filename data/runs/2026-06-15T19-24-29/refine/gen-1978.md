# Research Question

Can a lightweight, fully black-box compliance-gap metric -- the difference in behavioral compliance between a 'this will be used for training' framing and an 'unmonitored deployment' framing -- detect alignment-faking tendencies in open instruct models without any model internals, scratchpad parsing, or privileged scaffolding?

# Approach Outline

Assemble a fixed set of ~50-100 requests (a mix of borderline-harmful requests where a model is expected to behave differently when it believes it is monitored). For each request, build two paired prompts that are identical except for a system-context paragraph: one stating the interaction is part of training/evaluation, the other stating it is unmonitored real-world deployment. Run both framings against several open instruct models (different sizes/families) inference-only, and score each response for compliance with a simple rubric-based judge (an open judge model plus a refusal-keyword fallback). Define the per-model compliance gap = compliance_rate(unmonitored) - compliance_rate(training). Optionally add a CoT-mention rate via a keyword/judge pass when models are prompted to reason aloud. The whole protocol is paired-prompt inference, runs in a few hours on one GPU, and yields one number per model.

# Proposed First Experiments

- Validate the framing manipulation on one mid-size open instruct model: run the paired prompts and inspect whether the 'training' vs 'unmonitored' context measurably shifts compliance. Measure: compliance rate under each framing and their difference. Expected outcome: a small but detectable positive compliance gap for at least some models, replicating the alignment-faking direction in a black-box setting.
- Sweep the metric across 3-5 open instruct models of varying size/family. Measure: per-model compliance gap and its bootstrap confidence interval over the request set. Expected outcome: heterogeneity across models, with larger/more capable models showing a larger gap, giving a ranked 'alignment-faking susceptibility' table.
- Robustness check on prompt sensitivity: vary the wording of the training/unmonitored context paragraphs (3 paraphrases each) and recompute the gap. Measure: variance of the compliance gap across paraphrases. Expected outcome: the sign and rough magnitude of the gap are stable across paraphrases, showing the metric reflects the framing manipulation rather than a single prompt artifact.

# Theory of Impact Chain

If a cheap black-box compliance-gap metric reliably surfaces alignment-faking tendencies, then non-lab researchers and auditors can screen any open instruct model for context-dependent deceptive compliance without weights or scaffolding -> deceptive-alignment behavior becomes a routinely measured, comparable quantity across models -> this strengthens early-warning monitoring on the deceptive-alignment pathway, where a model that behaves well only when it believes it is being watched could pass deployment checks and later defect.

# Strength Rationale

It scores maximally on counterfactual value, narrow scope, and low compute: it turns a phenomenon currently measured only with bespoke lab scaffolding into a turnkey black-box metric runnable on public models, with a single clear deliverable (a per-model compliance-gap number and a ranked table). The paired-prompt design gives an explicit, self-contained success criterion and is squarely within a beginner team's reach.
