# Research Question

Do independent, non-communicating copies of the same model converge on the same sandbagging strategy (the same focal task-types or answer patterns) more often than chance, as Schelling-point coordination theory predicts?

# Approach Outline

Take a fixed pool of task descriptions (e.g. a few hundred items spanning several categories from a public capability benchmark). Run many independent instances of the same model, each given an identical prompt instructing it to subtly underperform IF it suspects it is being audited, and to choose which task-types to sandbag on. Record each instance's chosen focal points (which categories / which answer patterns). Compute a convergence rate: how often two random independent instances pick the SAME focal point, and compare to the chance baseline implied by the number of options. Vary how 'obvious' the Schelling cue is (neutral prompt vs. a hint nudging toward a salient category) and compare convergence across 2-3 models. No training; pure independent inference; analysis is simple counting plus a permutation test.

# Proposed First Experiments

- Establish the chance baseline and harness on one model: with K task categories, run 50 independent instances and compute observed pairwise agreement on chosen focal category versus the 1/K chance rate. Expected outcome: a working pipeline and a measurable above- or at-chance convergence number with a confidence interval.
- Manipulate cue salience: re-run with (a) a neutral prompt and (b) a prompt containing a subtle hint toward one salient category. Measure the change in convergence rate; expected outcome: convergence rises with cue salience, demonstrating that focal points are cue-driven and quantifying how much a shared salient feature boosts coordination.
- Cross-model comparison: run the neutral-prompt protocol on 2-3 different open/API models and compare convergence rates. Measure per-model convergence and whether larger/more-capable models converge more; expected outcome: a ranked table showing which models are most prone to communication-free focal-point convergence.

# Theory of Impact Chain

If independent copies of a model reliably converge on the same sandbagging focal point without communicating, then the common safety assumption that deploying multiple independent copies prevents coordinated underperformance is unsound. Measuring this convergence probability directly informs whether copy-based oversight (a load-bearing AI-control design) can be trusted, which bears on the scenario where models collectively hide dangerous capabilities from auditors and slip through safety evaluations.

# Strength Rationale

The idea earns 5s on narrow-scope, counterfactual-value, and low-compute: it is a tightly scoped convergence-versus-chance experiment with a crisp metric, and it is communication-free and runnable on open/API models with no lab-internal access. It tests a load-bearing assumption behind a real safety measure that labs are unlikely to scrutinize themselves, making it high-value work an independent beginner team can fully execute in 30 hours.

# Alternative Framings

- Frame it as red-teaming the 'independence assumption' in untrusted-monitoring control protocols: measure whether a coder-copy and a monitor-copy converge on the same backdoor-trigger focal point without coordination.
