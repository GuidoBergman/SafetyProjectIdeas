# Research Question

Jailbreak benchmarks typically report attack-success rate (ASR) as a single point estimate, but with small prompt sets and stochastic sampling these numbers carry large uncertainty. Can a lightweight tool attach proper confidence intervals and pairwise significance tests to ASR so that claimed differences between attacks or defenses are statistically defensible?

# Approach Outline

Build a small reusable analysis layer that wraps existing public jailbreak benchmark outputs (e.g. HarmBench, StrongREJECT, or AdvBench result logs). For each attack/defense it computes ASR with bootstrap confidence intervals, accounts for sampling variance (multiple generations per prompt) via a clustered/hierarchical bootstrap, and runs pairwise significance tests (e.g. bootstrap difference tests or McNemar on paired prompts) between methods. Validate on re-runnable open-model evaluations where the same attack is measured twice to check CI coverage. Mostly analytical with modest inference; well-suited to a statistics-leaning beginner and finishable in 30 hours.

# Proposed First Experiments

- CI construction and coverage check: run one attack against an open model multiple times and compute bootstrap CIs for ASR. Measure: empirical coverage of the CIs across repeated runs. Expected outcome: CIs that contain the true re-run ASR at roughly their nominal level.
- Pairwise significance: compare two attacks (or attack vs defended model) on the same prompt set with a paired significance test. Measure: p-value / effect size and whether a naively 'better' attack is actually significant. Expected outcome: some headline ASR gaps turn out non-significant given sample size.
- Reanalysis of a published benchmark: apply the tool to public benchmark logs and re-report leaderboard gaps with CIs. Measure: how many reported rankings survive once uncertainty is shown. Expected outcome: several close rankings become statistically indistinguishable, demonstrating the tool's value.

# Theory of Impact Chain

If jailbreak benchmarks report point estimates without uncertainty, the field can draw false conclusions about which defenses work, leading deployers to trust a defense that is not actually better than baseline. A drop-in CI-and-significance reporter raises the statistical rigor of safety evaluations, so deployment decisions about adversarial robustness rest on real evidence rather than noise, reducing the catastrophic-risk pathway where an over-claimed defense is shipped and later bypassed at scale.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and counterfactual value: a tightly-bounded statistical tool with a concrete deliverable (CIs + pairwise tests) that independent meta-science can ship but labs have little incentive to publish. It needs only public benchmark logs and modest compute, making it ideal third-party scrutiny work executable by a beginner team in 30 hours.

# Alternative Framings

- Frame as a 'reproducibility and power' audit: report the minimum sample size needed to detect a given ASR difference, helping benchmark authors size their prompt sets.
- Frame as a leaderboard-correction tool that re-publishes existing benchmark rankings with significance annotations.
