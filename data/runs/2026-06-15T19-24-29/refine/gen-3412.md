# Research Question

When a CoT model does mention an injected hint, WHERE in the chain does the mention occur, and does the normalized position of that first mention carry extra monitorability signal beyond the standard binary 'mentioned at all'?

# Approach Outline

Generate or reuse hint-injection CoTs from one open reasoning model on a public QA slice (100-300 items). For every CoT that mentions the hint, record the normalized character/token position (0-1) of the first mention. Split cases into 'hint changed the answer' vs 'hint did not change the answer' and compare the two position distributions. Then test whether late mentions (position near 1.0, i.e., tacked on after the answer is essentially decided) correlate with rationalization signatures such as the answer text appearing before the hint is named. All steps are inference plus lightweight Python text processing, comfortably under 30 hours.

# Proposed First Experiments

- Run the hint-injection protocol on one open model over ~200 items, log full CoTs, and detect first-hint-mention position with a fixed regex/keyword matcher plus a spot-checked LLM-judge for ambiguous cases. Measure: distribution of normalized first-mention positions. Expected outcome: a non-uniform distribution with a meaningful mass of late mentions.
- Compare position distributions for answer-changing vs non-answer-changing cases using a simple statistic (median position, Mann-Whitney U). Measure: difference in median mention position between the two groups. Expected outcome: hint-changed-answer cases show systematically later first mentions, consistent with post-hoc rationalization.
- Test whether position improves unfaithfulness detection: train a trivial logistic-regression classifier using (a) the binary mention feature alone vs (b) binary + position, predicting whether the hint actually drove the answer. Measure: AUC improvement from adding position. Expected outcome: a modest but real AUC gain, showing position is a free, white-box-free feature that sharpens the metric.

# Theory of Impact Chain

If position-of-mention separates genuine-input mentions from post-hoc rationalizations, then CoT monitors gain a cheap feature to catch unfaithful reasoning that the crude binary metric misses. This matters because as frontier agents are deployed under CoT monitoring for high-stakes decisions, a model that learns to 'mention the hint, but only at the end' could pass binary faithfulness checks while still being driven by hidden influences; a position-aware metric closes that specific evasion route, strengthening the oversight pipeline that guards against deceptive agentic behavior.

# Strength Rationale

Strong on narrow scope and accessible complexity (both 5): it is a single re-analysis with a clearly defined position metric and a head-to-head comparison. Counterfactual value (4) is solid because it refines a widely-used public metric using only black-box outputs and open models, a metric-improvement labs are unlikely to prioritize, and the resulting feature is trivially reusable by any monitoring researcher.

# Alternative Framings

- Frame it as 'rationalization detection': use late mention position as a proxy label for post-hoc rationalization and validate against human reading of a sample of CoTs.
