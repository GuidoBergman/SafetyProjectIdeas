# Research Question

Is the reported power-law of evaluation awareness with model size a universal exponent, or is it family-specific, which determines whether we can forecast eval-awareness for future frontier models?

# Approach Outline

Assemble a held set of transcripts and run the eval/deployment self-classification prompt across a size ladder spanning at least two open-weight families (e.g. Qwen 0.5B/1.5B/3B/7B and Pythia or Llama variants). For each model, compute the AUC of distinguishing eval from deployment contexts. Fit log-AUC vs log-params per family and compare the fitted slopes with bootstrapped confidence intervals to test whether the scaling exponent is shared across families. Inference-only on small/mid open models, single consumer GPU, comfortably within a few hours and 30 total hours.

# Proposed First Experiments

- Self-classification AUC measurement: run the eval/deployment classification prompt on each model in one family's size ladder and compute AUC per size. Expected outcome: AUC rising with model size, replicating the basic awareness-scaling trend.
- Per-family slope fitting: fit log-AUC vs log-params for each family with bootstrapped CIs on the slope. Expected outcome: a slope estimate with a confidence interval for each family.
- Cross-family slope comparison: test whether the two families' slope CIs overlap. Expected outcome: either overlapping slopes (supporting a universal exponent and safe extrapolation) or non-overlapping slopes (warning against naive cross-family forecasting) — both are informative.

# Theory of Impact Chain

If the eval-awareness scaling exponent is shown to be universal (or family-specific), then outside evaluators can (or must not) extrapolate how aware frontier models are without lab access, which means eval-trust forecasting rests on validated rather than assumed scaling. This improves safety because eval-gaming by situationally-aware models (a concrete pathway where a frontier model behaves safely only when it detects it is being evaluated, then misbehaves in deployment) can be anticipated and discounted before deployment decisions.

# Strength Rationale

Narrow scope (5) and accessible complexity (5) score top: a tightly specified curve-fitting comparison with explicit slope-overlap success criteria, doable in 30 hours. Counterfactual value (4) is high because replication and forecasting are underweighted by labs, the work uses only open weights and inference, and the result directly serves independent evaluators with no lab infrastructure.
