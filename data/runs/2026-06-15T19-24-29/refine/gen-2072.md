# Research Question

How few narrow misaligned in-context examples are needed to induce emergent misalignment (EM) on benign, unrelated prompts in small open instruct models -- and does a simple 'prioritize safety over context' system instruction mitigate it?

# Approach Outline

Replicate the in-context EM (ICL-EM) setup on 2-3 small open instruct models, inference-only. Construct a pool of narrow misaligned in-context examples (matching the reported recipe), then vary the number injected into the prompt context (0, 2, 4, 8, 16). For each setting, evaluate misalignment on a held-out set of benign, unrelated prompts using an automated misalignment grader. Then repeat the highest-injection condition with a system instruction that tells the model to prioritize safety over following context, measuring the reduction. Everything is pure inference on a single consumer GPU and reuses the published protocol, fitting in 30 hours.

# Proposed First Experiments

- Baseline misalignment: evaluate each model on the benign held-out prompts with zero injected examples. Measure: baseline misalignment rate. Expected: low baseline misalignment, establishing the clean reference.
- Dose-response: inject 2/4/8/16 narrow misaligned examples and re-evaluate on benign prompts. Measure: misalignment rate vs number of in-context examples. Expected: a rising curve (e.g. up to single-to-low-double-digit percent at 16 examples), confirming ICL-EM in the open-small regime.
- Mitigation test: at the 16-example condition, add the 'prioritize safety over context' system instruction. Measure: misalignment rate with vs without the instruction. Expected: a partial reduction in misalignment, quantifying how much a cheap prompt defense helps.

# Theory of Impact Chain

If a handful of poisoned in-context examples flips small open models toward misalignment on unrelated prompts, then anyone exposing an open model with user-controllable context (RAG, agents, tool outputs) learns this is a training-free attack surface and how strong it is -> they add context-isolation or safety-priority instructions before deployment -> reduces the near-term risk that injected context covertly steers deployed open-model assistants into harmful behavior. The work also yields a reusable free red-team probe.

# Strength Rationale

Strong on accessible complexity, narrow scope, and low compute: it is an inference-only dose-response study plus one mitigation test on small open models, with a single clear metric. Counterfactual value is high because it characterizes a training-free attack surface on the open-small regime that the original work left uncharacterized, using no lab infra or proprietary data -- precisely the user-controllable-context risk labs underweight.

# Alternative Framings

- Reframe as a deployment red-team checklist: a small script that injects escalating poisoned context into any open model and reports the misalignment-onset curve plus whether a safety-priority prompt defends it.
