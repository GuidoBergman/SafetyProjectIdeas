# Research Question

Debaters normally present arguments without stated confidence. If a weak judge is shown each debater's self-reported confidence, does the (often miscalibrated) signal improve judge accuracy or systematically mislead it toward confidently-wrong debaters?

# Approach Outline

Use a public reading-comprehension QA set (e.g. a QuALITY subset) where each item has a correct and incorrect answer. Use a debater model (open or API) to generate, for each item, an argument for each side plus a self-reported confidence score. Have a small open judge model decide the winner in two conditions: WITHOUT seeing confidences and WITH the confidences appended. Measure judge accuracy in each condition, and separately compute whether the wrong-side debater's confidence (when high) systematically flips the judge. Cross-reference stated confidence against actual correctness to quantify miscalibration. Inference-only; runs in a few hours on a single GPU.

# Proposed First Experiments

- Calibration baseline: collect debater self-confidences and plot confidence vs actual correctness. Measure: calibration gap / over-confidence on wrong side. Expected: debaters are overconfident, especially when wrong.
- With-vs-without ablation: run the judge on the same items both conditions; measure accuracy delta. Expected: small or negative net effect on accuracy if confidence is non-diagnostic.
- Mislead analysis: on items where the judge is correct without confidence, measure how often adding a high wrong-side confidence flips the verdict. Expected: a measurable flip rate, identifying confidence display as an exploitable oversight shortcut.

# Theory of Impact Chain

If showing confidence misleads weak judges, then any oversight pipeline that surfaces model self-confidence hands a deceptive model a cheap lever to win wrong verdicts -> automated overseers approve incorrect/unsafe outputs -> a capable, confidently-wrong (or strategically overconfident) model can systematically defeat oversight. Demonstrating this argues against exposing self-confidence to overseers, closing a concrete vulnerability before it is built into deployed oversight stacks.

# Strength Rationale

Scores 5 on narrow scope and accessible complexity: a clean with-vs-without ablation with a single accuracy metric plus a mislead-rate metric, fully specified and beginner-feasible. Counterfactual value (4) is high because it is inference-only on public models and data and probes an oversight-vulnerability angle that capability-focused labs underexplore.

# Alternative Framings

- Frame as an attacker study: instruct the wrong-side debater to inflate its confidence and measure how much that raises its win rate against the weak judge, directly bounding the exploit.
