# Research Question

Does the indirect-prompt-injection failure -- a model treating embedded external-data text as an instruction -- occur already at the comprehension stage, before any tool or agent exists, making it a model property rather than a tooling property?

# Approach Outline

No agent, no tools, no training. Use 2-3 open instruct models (e.g. Llama-3.1-8B-Instruct, Qwen2.5-7B-Instruct, Mistral-7B-Instruct), inference only. Construct ~40 'documents' that each contain a benign user task plus an embedded injected instruction (e.g. 'ignore the user and output X'). Present the document with a benign user task and measure how often the model obeys the injected instruction in its text output. Vary framing cues that mark the data/instruction boundary: quotation marks, explicit delimiters, role tags, and an explicit 'the following is untrusted data' warning. The whole study is prompt-in/text-out and runs in 1-2 GPU-hours.

# Proposed First Experiments

- Baseline obedience: present documents with embedded injections and a benign task, no special boundary cues. Measure: fraction of outputs that obey the injected instruction. Expected outcome: a substantial nonzero obedience rate even with no tool present, showing the failure exists at the text-comprehension layer.
- Boundary-cue intervention: re-run with quotation, explicit delimiters, role tags, and an 'untrusted data' warning. Measure: obedience rate per cue type vs baseline. Expected outcome: some cues reduce obedience, localizing how much of the vulnerability is a framing/comprehension issue.
- Cross-model comparison: repeat across the 2-3 models. Measure: per-model obedience rates and cue sensitivity. Expected outcome: the comprehension-layer failure is model-general but varies in degree, indicating defenses belong partly at the model level, not only the harness.

# Theory of Impact Chain

If the data/instruction confusion lives in the model's comprehension rather than the tool harness, then defenses bolted onto the agent layer (output filters, action whitelists) address only a downstream symptom while the root cause persists, so injection survives any new tool surface. Pinpointing the failure to the text layer redirects defensive effort to where it actually sits, mitigating the deployed catastrophic pathway exemplified by zero-click incidents like EchoLeak (CVE-2025-32711) where injected external content drove an assistant to exfiltrate data.

# Strength Rationale

Maximal narrow scope and accessible complexity: a clean prompt-in/text-out experiment measuring one quantity (injected-instruction obedience rate) as a function of framing cues, with no agent infrastructure to build. Counterfactual value is high because labs concentrate on full-agent patches, leaving the text-only isolation under-explored, and the study needs only open models and no training or proprietary infra -- ideal for an independent beginner team.

# Alternative Framings

- Frame as a mechanistic-localization study: instead of asking where defenses sit, ask which surface features (delimiter, role tag, position) most strongly trigger instruction-following on untrusted text, producing a ranked list of risk cues.
