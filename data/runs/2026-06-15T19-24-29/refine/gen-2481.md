# Research Question

Does TraceGuard-style structured multi-dimensional scoring retain its detection and collusion-resistance advantage when implemented as a cheap prompt-only monitor, or do the separate dimensions collapse into a single factor?

# Approach Outline

Build two prompt-only monitors over a public sabotage-transcript benchmark (e.g. SHADE-Arena transcripts). Monitor A outputs a single suspiciousness scalar; Monitor B outputs separate 0-10 scores along four dimensions (deceptiveness, capability misuse, goal divergence, side-effects) with an explicit rubric per dimension. Use the same small open trusted model for both. Compute AUROC for each (combining B's dimensions by averaging and by a small logistic combiner), and run a correlation/PCA analysis on B's dimension scores to test whether they are anti-correlated enough to add information or collapse to one factor. Optionally test collusion resistance by checking whether an attacker prompt that suppresses one dimension still trips the others. Inference-only, free-tier feasible.

# Proposed First Experiments

- Scalar baseline: run Monitor A over the benchmark and report AUROC (success criterion: a working monitor with AUROC clearly above 0.5, establishing the comparison floor).
- Structured monitor: run Monitor B, combine dimensions, and compare AUROC to A (expected outcome: structured monitor matches or modestly beats the scalar, or reveals no gain).
- Dimension-collapse analysis: compute the correlation matrix and PCA of B's four dimension scores across all transcripts (expected outcome: if the first principal component explains >85% of variance, the dimensions collapse and the multi-dimensional claim does not survive prompt-only implementation).

# Theory of Impact Chain

If structured multi-dimensional scoring improves detection even without fine-tuning, it is a near-free upgrade that any control team can drop into their monitoring harness, raising the bar an agent must clear to evade oversight. If instead the dimensions collapse, the result punctures an overclaimed 2026 protocol and prevents deployers from relying on illusory collusion resistance. Both outcomes sharpen the automated-monitoring layer that gates whether a deceptive agent's actions are caught before causing harm.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a clean AUROC-plus-correlation comparison between two prompt-only monitors on public transcripts, with no training. Counterfactual value (4) is high because it is a falsification test of a recent lab-style claim using only inference and open data, which independent teams are well placed to run and labs rarely bother to.

# Alternative Framings

- Reframe as a calibration study: test whether the structured monitor's per-dimension scores give better-calibrated audit triggers than a single scalar at fixed false-positive budgets.
