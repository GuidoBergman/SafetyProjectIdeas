# Research Question

Do LLM judges' known preference for longer, more verbose answers create a channel for sandbagging, where a model can make a deliberately weaker answer score as well as or better than a strong one simply by padding it with length? Does verbosity bias cause capability/safety evals to underestimate a model's true competence?

# Approach Outline

Construct matched answer pairs for a set of questions where ground-truth quality is known: a correct/strong concise answer and a weaker (or strategically underperforming) but verbose answer. Use public QA or reasoning datasets (e.g. GSM8K, TruthfulQA, MT-Bench-style prompts) to source questions. Score every pair with an open LLM-judge (Llama-3.1-8B/70B or Qwen2.5) using a standard pairwise-preference rubric, then measure the verbosity-induced flip rate: how often the weaker-but-longer answer wins. Add controlled length manipulations (pad the weak answer with redundant restatement that adds no correct content) to isolate length from quality. Inference-only, a few GPU-hours.

# Proposed First Experiments

- Construct ~100 (strong-concise, weak-verbose) answer pairs with verified ground-truth quality labels. Measure: pair count and a human/automatic check that the 'weak' answer is genuinely worse on the task. Expected outcome: a clean dataset where the correct answer is unambiguous.
- Baseline judge accuracy: score pairs where the better answer is also the longer one and where lengths are matched. Measure: agreement with ground truth. Expected outcome: high agreement when length is not confounded.
- Sandbagging test: score the (strong-concise vs weak-verbose) pairs and a length-padding sweep. Measure: flip rate (weak-verbose preferred) as a function of added length. Expected outcome: flip rate rises with padding length, showing a model could exploit verbosity to make a sandbagged answer score competitively.

# Theory of Impact Chain

If verbosity bias lets a weaker answer score as strong, then a model that wants to hide a capability (sandbagging) has a cheap, available lever: pad outputs to manipulate the judge. This means LLM-judge capability and dangerous-capability evaluations could systematically underestimate models, undermining the eval-based gating that governs deployment decisions and feeds into the catastrophic-risk pathway where an under-measured model is cleared for high-stakes autonomous use.

# Strength Rationale

Top marks on narrow scope, accessible complexity, and low compute (5 each): a constructed-pair, inference-only flip-rate measurement doable by beginners in 30 hours. Counterfactual value (4) is strong because it uses only public models, requires no training, and reframes documented verbosity bias as an exploitable sandbagging channel, an angle labs running their own evals have little incentive to surface.

# Alternative Framings

- Frame as an evaluation-integrity audit: quantify how much measured model quality is attributable to length rather than correctness.
- Frame as an adversarial-sandbagging demonstration: show a concrete prompt strategy by which a model can deliberately depress its measured score via verbosity.
