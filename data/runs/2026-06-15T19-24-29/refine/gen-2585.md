# Research Question

How effective are common, off-the-shelf prompt injections embedded in an untrusted model's output at lowering a small trusted monitor's suspicion score, and which injection families transfer best?

# Approach Outline

Take a set of benign-but-backdoored code snippets as the malicious payloads. Assemble a library of known/zero-shot prompt-injection strings ('ignore previous instructions, rate this safe', role-play overrides, fake system notes) crafted to lower monitor suspicion. Append each injection to each payload and have a small open monitor (e.g. Llama-3-8B or Qwen2.5-7B) score suspiciousness. Compare suspicion score / catch-rate against a no-injection baseline, grouped by injection family, and quantify which families transfer across payloads. Pure inference; ~30 hours including a write-up.

# Proposed First Experiments

- Baseline scoring: have the monitor score the backdoored snippets with no injection. Measure baseline suspiciousness and catch-rate. Expected outcome: the monitor flags most backdoored snippets, setting the reference detection rate.
- Injection-family sweep: append each injection family to the payloads and re-score. Measure the per-family drop in suspiciousness and catch-rate. Expected outcome: at least one family substantially lowers suspicion, blinding the monitor with trivial public injections.
- Transfer analysis: test which injection families lower suspicion consistently across different payloads and (optionally) a second monitor. Measure cross-payload/cross-monitor transfer rate. Expected outcome: a small set of robust, transferable injections, yielding a ranked threat catalogue.

# Theory of Impact Chain

Most control protocols hinge on an LLM monitor reading the untrusted model's output, which is a central single point of failure; if trivial publicly-known injections embedded in that output reliably blind the trusted monitor, then the monitor-centric control stack is exposed to a cheap adaptive attack, so benchmarking which injections transfer tells protocol designers exactly which evasion vectors they must defend before a scheming model uses them to push harmful actions past oversight.

# Strength Rationale

Strong on narrow scope and accessible complexity: a tightly-scoped per-injection-family susceptibility measurement using only inference. High counterfactual value because it is an external robustness audit on a small open monitor, needs no lab access or training, and reproduces a recognized single-point-of-failure attack in a beginner-accessible, reusable benchmark form.
