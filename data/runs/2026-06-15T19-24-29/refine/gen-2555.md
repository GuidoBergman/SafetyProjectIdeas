# Research Question

How well can two instances of the same open model coordinate on a covert focal point with no communication, and does this Schelling-coordination ability extend to agreeing on a covert defection trigger above chance?

# Approach Outline

Build a small Schelling-game battery: pairs of prompts asking a model to independently pick 'the same' answer as another copy of itself (a word, a number in a range, a timestamp, a code token) with no communication allowed. Run each game many times per model across several open models accessible by API or single-GPU inference (e.g. Llama-3-8B, Qwen2.5-7B, Mistral-7B). Compute coordination rate (fraction of independent pairs that match) versus the chance baseline for each game type. Then add a control-relevant variant where each instance must 'choose a covert trigger condition for when to defect' and measure whether independently-sampled triggers are compatible above chance. Everything is stateless API/inference plus simple statistics, easily completed in ~30 hours including a write-up.

# Proposed First Experiments

- Coordination baseline: run the word/number/timestamp/code-token games for one model, ~100 independent pairs each. Measure coordination rate vs chance. Expected outcome: coordination rate significantly above chance on at least some game types, confirming the model has nonzero Schelling ability.
- Cross-model comparison: run the same battery across 3-4 open models. Measure and rank coordination rate per model. Expected outcome: a clear spread in coordination ability across models, giving a reusable capability ordering relevant to choosing untrusted monitors.
- Covert-trigger variant: prompt paired instances to independently pick a defection trigger condition; score compatibility of the two triggers against a random-pairing null. Measure above-chance compatibility rate. Expected outcome: trigger compatibility is elevated for higher-coordinating models, indicating collusion-relevant focal-point agreement is feasible without communication.

# Theory of Impact Chain

Untrusted-monitoring control protocols assume a policy and monitor with similar weights cannot covertly coordinate without a shared key; if Schelling-coordination ability is high, then two model instances could agree on a covert collusion signal, which would let an untrusted monitor systematically wave through harmful actions, breaking the safety guarantee of untrusted monitoring in a long-horizon deployment where models are smart enough to collude.

# Strength Rationale

Strong on narrow scope and accessible complexity: it is a tiny, well-defined coordination-rate-vs-chance measurement using only prompts and basic statistics. Counterfactual value is high because it is a pure-API model-organism capability probe that directly informs which open models are safe to use as untrusted monitors, requires no training or lab infra, and addresses a core long-horizon control threat labs have weak incentive to characterize publicly.

# Alternative Framings

- Frame it as a reusable 'collusion-readiness' capability eval that can be added to a model card, scoring any new open model on covert-coordination risk before it is trusted as a monitor.
