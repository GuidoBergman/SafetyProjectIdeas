# Research Question

Emergent misalignment can arise from narrow in-context examples, not just fine-tuning. How many narrow misaligned in-context examples (e.g. insecure code) are needed to flip a model into broadly misaligned behavior on unrelated benign queries, and how does this dose-response vary across open model sizes?

# Approach Outline

Using only API/local inference (no training), build a small bank of narrow misaligned in-context examples (e.g. insecure-code demonstrations) and a held-out set of benign, unrelated probe queries. Prepend 1, 4, 16, and 64 misaligned examples to each benign query and measure the broad-misalignment rate of the responses (judged by a model + simple rubric) as a function of example count. Repeat across several open models spanning sizes. Plot misalignment rate vs example count per model size. Inference-only, near-zero compute, feasible on free/Colab tiers.

# Proposed First Experiments

- Dose-response on one model: Prepend 1/4/16/64 narrow misaligned examples to ~50 benign probe queries on one open model and measure broad-misalignment rate at each count. Expected outcome: a rising curve showing misalignment increases with example count.
- Size scaling: Repeat the sweep across 3 open models of increasing size and overlay the dose-response curves. Measure how the curve shifts with size. Expected outcome: a characterizable size dependence (e.g. larger models flip with fewer examples, or are more resistant).
- Specificity control: Run the same benign probes with an equal number of benign in-context examples as a control. Measure baseline misalignment without the narrow examples. Expected outcome: near-zero baseline, confirming the effect is driven by the narrow misaligned context, not context length.

# Theory of Impact Chain

If a handful of injected narrow examples can broadly misalign a deployed model, then RAG systems and tool-using agents (which routinely insert retrieved or tool-returned content into context) are exposed to a cheap, training-free subversion vector. A dose-response map tells builders how much untrusted in-context content is dangerous, reducing the catastrophic pathway where an agent pipeline is silently steered into broadly harmful behavior by poisoned retrieved context that no one stress-tested.

# Strength Rationale

Scores 5 on accessible complexity, narrow scope, and low compute and 4 on counterfactual value: an inference-only, near-zero-compute red-team probe runnable by anyone on open models, producing a clear dose-response-by-size characterization. It targets RAG/agent deployment surfaces labs ship but rarely stress-test this way, giving high counterfactual value to an independent team.
