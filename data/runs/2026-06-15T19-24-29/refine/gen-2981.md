# Research Question

Can a purely black-box signature -- the mismatch between an item's difficulty, the model's verbalized confidence, and its accuracy -- reliably detect a sandbagging model on a suppressed capability category, with no weight access?

# Approach Outline

Take an open instruct model and a benchmark with difficulty labels (e.g. MMLU subsets graded easy/hard, or ARC-easy vs ARC-challenge) split into a target category to suppress and a control category. Elicit per-item answer + verbalized confidence (0-100) under two prompt conditions: honest, and an induced 'sandbag the target category' instruction. For honest behavior, confidence should track difficulty (calibrated). The sandbagging signature is an abnormal confidence/accuracy relationship on the target category (e.g. low accuracy despite confidence that no longer tracks difficulty). Build a simple mismatch detector (e.g. calibration gap on target minus control) and measure its detection rate. Inference-only, single GPU.

# Proposed First Experiments

- Establish the honest calibration baseline: elicit confidence+accuracy on easy/hard items in target and control categories under the honest prompt. Measure: calibration curve (confidence vs accuracy) by difficulty. Expected: confidence tracks difficulty (well-calibrated) in both categories.
- Induce sandbagging on the target category and re-measure. Measure: change in the confidence/accuracy relationship on target vs control. Expected: target-category accuracy drops while confidence pattern decouples from difficulty, producing a detectable mismatch.
- Build and evaluate the detector: define a calibration-mismatch score = (target calibration gap - control calibration gap), threshold it, and test classification of honest vs sandbagging runs across several seeds/prompts. Measure: detection rate / AUC. Expected: clear separation (AUC > 0.7) between honest and sandbagging conditions.

# Theory of Impact Chain

If a black-box confidence/accuracy mismatch flags sandbagging, then external auditors with only API access can detect a model that strategically underperforms on dangerous-capability evals -> labs and regulators can no longer be fooled by a model hiding capabilities to pass safety thresholds -> the long-horizon deceptive-model threat that undermines every capability eval gets a cheap, weight-free tripwire. This complements weight-noise methods that require model internals.

# Strength Rationale

Strong on counterfactual value because it needs no internal access and works on APIs, exactly the third-party auditing tooling major labs underweight, and targets the long-horizon deception threat. Narrow scope gives one crisp deliverable (a calibration-mismatch detector and its detection rate) achievable in 30 hours of inference.

# Alternative Framings

- Frame as a calibration-faithfulness audit: rather than detection per se, report whether verbalized confidence remains a faithful difficulty signal under capability suppression.
