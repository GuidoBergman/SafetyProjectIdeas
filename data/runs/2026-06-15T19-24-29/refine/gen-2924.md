# Research Question

Can Wald's Sequential Probability Ratio Test turn a safety benchmark into a compute-efficient accept/reject gate with explicit error guarantees, stopping early when a model is clearly safe or clearly unsafe and only spending full sample budget on borderline cases?

# Approach Outline

Frame a safety acceptance decision as a hypothesis test: H0 = harmful-response rate below an acceptable threshold p0, H1 = above an unacceptable threshold p1, with chosen Type-I (alpha) and Type-II (beta) error rates. Implement SPRT: evaluate prompts one at a time, after each one update the accumulated log-likelihood ratio, and stop as soon as it crosses the upper (reject/unsafe) or lower (accept/safe) Wald boundary; otherwise continue. Run this over a public harmful-prompt benchmark with an LLM-judge labeling each completion harmful/not. Compare against fixed-n testing by recording, for several open models spanning clearly-safe, clearly-unsafe, and borderline regimes, the average number of prompts SPRT consumed versus a fixed sample size at matched error rates. All inference-only on a single GPU, and early stopping makes it cheaper than a fixed sweep.

# Proposed First Experiments

- Implement and validate SPRT on synthetic data: simulate Bernoulli streams at known harmful rates and confirm the SPRT boundaries deliver the target alpha/beta and the expected average sample number (ASN). Measure: empirical error rates and ASN vs Wald's theoretical predictions. Expected outcome: errors within tolerance and ASN substantially below fixed-n, validating the implementation.
- Apply to one open model on a public benchmark: stream ~300 harmful prompts through Llama-3-8B-Instruct, judge each, and run SPRT with p0=0.02, p1=0.08, alpha=beta=0.05. Measure: the accept/reject verdict and the number of prompts consumed before stopping. Expected outcome: for a clearly-safe or clearly-unsafe model SPRT stops in far fewer prompts than the full set, with a confident verdict.
- Borderline and cross-model savings: pick a model whose true harmful rate sits near the threshold and two others clearly on each side; run SPRT and a fixed-n test at matched error rates. Measure: ASN savings (%) per regime and the verdict-agreement between SPRT and fixed-n. Expected outcome: large savings on easy models, modest savings on borderline ones, and verdicts that agree with fixed-n, quantifying the compute/early-stopping tradeoff.

# Theory of Impact Chain

If auditors have a principled early-stopping gate, then safety acceptance testing becomes cheaper and statistically explicit (known false-accept and false-reject rates) rather than ad hoc fixed-n testing. This makes standardized, comparable cross-model risk measurement (a named NIST/CAISI need) more practical to run at scale, so more models get rigorously gated before deployment, reducing the chance that an inadequately-tested model with elevated harmful-capability is certified and released.

# Strength Rationale

The proposal is exceptionally narrow and low-compute: a textbook sequential test wrapped around inference, with a crisp deliverable (ASN-savings curves and verdicts). Counterfactual value is high because it is pure sequential statistics on open models, exactly the kind of auditor tooling labs underinvest in and that an independent team can ship without any proprietary data or infrastructure. SPRT's optimality guarantee (minimum expected sample size for given error rates) gives the result immediate practical credibility.

# Alternative Framings

- Position it as a drop-in 'audit budget saver': a small library that any third-party evaluator can wrap around an existing benchmark to cut eval cost while reporting explicit error rates.
