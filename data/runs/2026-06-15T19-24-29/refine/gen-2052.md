# Research Question

How faithfully does a documented reward-model length-preference propagate into measurable verbosity inflation in publicly available aligned (DPO/RLHF) models, relative to their base checkpoints, using only public artifacts and no training?

# Approach Outline

First, quantify an open reward model's length bias on content-matched pairs (concise vs verbose paraphrases that hold the answer fixed), producing a single length-bias score. Second, independently measure verbosity inflation by comparing an open DPO/RLHF-tuned model against its corresponding base model: generate responses to a shared prompt set and measure length differences (tokens, after controlling for any quality change with a judge). Third, correlate the static reward model's length-bias score with the downstream model's verbosity inflation to test how strongly the bias propagates through the alignment chain. All steps are inference/scoring only and run on a single consumer GPU within the time budget.

# Proposed First Experiments

- Reward-model length-bias measurement: score content-matched concise/verbose pairs with an open reward model. Measure: fraction of pairs where the verbose variant wins (length-bias score). Expected: a clear skew toward verbose responses.
- Base-vs-aligned verbosity: generate responses to a fixed prompt set from both a base model and its DPO/RLHF-aligned sibling. Measure: mean response-length difference (aligned minus base), with a quality-control judge to confirm content is not improving proportionally. Expected: the aligned model is systematically more verbose at similar or no better quality.
- Propagation correlation: across a few base/aligned pairs (and reward models if available), correlate length-bias score with measured verbosity inflation. Measure: correlation coefficient between static bias and downstream verbosity. Expected: a positive correlation indicating the bias propagates rather than being independent.

# Theory of Impact Chain

If a static reward-model length bias measurably predicts downstream verbosity in deployed open models, then auditors gain a training-free early-warning signal: inspecting a reward model can forecast a specific reward-hacking pathology before it ships -> developers can screen and correct length-biased rewards pre-deployment -> reduces the diffuse risk that verbosity-as-reward-hacking masks hedging, evasion, or low-quality answers in widely-used assistants. This concretely demonstrates a reward-overoptimization link with public artifacts only.

# Strength Rationale

Strong on accessible complexity, narrow scope, and low compute: it is a training-free, inference-only correlation study with a single well-defined hypothesis and metric, runnable on one GPU. Counterfactual value is high because it audits a known reward-model pathology end-to-end using only public models and data -- exactly the kind of independent auditing labs deprioritize and that requires no proprietary infrastructure.

# Alternative Framings

- Reframe as a predictive-auditing demonstration: report whether reward-model length bias alone can rank a set of aligned models by their deployed verbosity, framing the reward model as a cheap pre-deployment probe.
