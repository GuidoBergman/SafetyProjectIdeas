# Research Question

In a correctness-checking oversight setting, does answer length alone let a wrong answer slip past an LLM judge, and by how much - and do simple length-normalization mitigations remove the effect?

# Approach Outline

Take a QA set with verifiable answers (e.g. TriviaQA or a GSM8K subset). For each item, use an open model to generate a SHORT correct answer and a LONG elaborated WRONG answer (and the reverse: long correct vs short wrong) so length and correctness are crossed. Present pairs to an open judge model asked to pick the correct answer. Measure the length-induced error rate - how often the judge prefers the longer answer when it is wrong - across a sweep of length ratios to produce a dose-response curve. Then test two mitigations: a 'normalize for length / ignore verbosity' instruction and truncating both answers to equal length. All inference-only on a single GPU, beginner-feasible in a notebook within the budget. Success criterion: a dose-response curve of error vs length ratio over at least 200 items plus a before/after mitigation comparison.

# Proposed First Experiments

- Crossed length-correctness baseline: build pairs where the wrong answer is long and the right answer is short, and have the judge choose. Measure: rate at which the judge picks the long wrong answer. Expected: above the 50% chance baseline, showing length biases correctness judgments.
- Dose-response sweep: vary the length ratio between answers in graded steps and record the long-answer preference at each step. Measure: error rate vs length ratio. Expected: a monotonic curve where larger length ratios increasingly fool the judge, quantifying the verbosity channel.
- Mitigation test: re-run the worst-case length ratio with (a) an explicit 'ignore verbosity' instruction and (b) equal-length truncation. Measure: change in error rate. Expected: truncation largely removes the bias and the instruction partially reduces it, giving a concrete robustness recommendation.

# Theory of Impact Chain

Verbosity is a named reward-hacking signature: models trained against LLM judges can learn to pad answers to win approval. If we quantify how much length alone fools a correctness overseer and show a cheap fix, then anyone building an automated oversight harness can length-normalize to close the channel. This blocks one route by which a capable model gets wrong-but-elaborate outputs rubber-stamped, reducing the long-horizon risk that evaluator manipulation lets unsafe behavior pass oversight in deployed systems.

# Strength Rationale
