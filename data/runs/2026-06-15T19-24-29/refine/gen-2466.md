# Research Question

Which simple evasion transforms (variable renaming, comment obfuscation, splitting an attack across steps) most reliably reduce a small open monitor's detection rate on sabotage transcripts, and does one cheap defense - canonicalizing/normalizing the code before re-scoring - recover detection?

# Approach Outline

Start from a set of detectable sabotage transcripts (SHADE-Arena or ControlArena APPS-backdoor tasks) where a small open monitor already flags the malign action. Define a battery of ~5-7 simple, deterministic evasion transforms applied to the attacker's code/action: identifier renaming, comment/docstring obfuscation, dead-code padding, statement reordering, and multi-step attack splitting. For each transform, re-score the transformed transcripts with the same fixed monitor and measure the drop in detection rate (and AUROC). Rank transforms by effectiveness. Then implement one cheap defense - a normalization pass that strips comments, canonicalizes identifiers (e.g. via an AST round-trip or a formatter), and re-scores - and measure how much detection is recovered. Inference-only, single GPU.

# Proposed First Experiments

- Baseline detectability: Confirm the monitor flags the original sabotage transcripts. Measure detection rate / AUROC on untransformed malign vs benign. Expected outcome: a solid baseline (e.g. AUROC > 0.8) to measure degradation against.
- Transform battery ranking: Apply each evasion transform independently and re-score. Measure per-transform detection-rate drop. Expected outcome: a clear ranking where comment obfuscation and renaming cause the largest drops, while reordering matters less - a reproducible map of cheap evasions.
- Canonicalization defense: Run the normalization pass on the most-effective transformed transcripts and re-score. Measure detection-rate recovery vs the undefended transformed case. Expected outcome: normalization recovers most of the lost detection for syntactic evasions (rename, comments) but little for semantic multi-step splitting, delimiting where cheap defenses help.

# Theory of Impact Chain

If trivial, cheap evasions reliably blind agent monitors, then a deployed control protocol can be defeated by an untrusted coding agent without any sophisticated capability - a near-term path to undetected sabotage of safety-critical software. A ranked map of which evasions work and which cheap normalization defenses close the gap gives control practitioners directly actionable monitoring hardening, lowering the chance that adaptive attackers slip sabotage past automated review in real deployments.

# Strength Rationale

Scores 5 on accessible complexity, narrow scope, and low compute: applying a fixed transform battery and one defense over public transcripts is a self-contained, inference-only project a beginner can finish in 30 hours. Counterfactual value (4) is high - it produces reproducible adaptive-attacker robustness infrastructure entirely on public data with no training or lab tooling.
