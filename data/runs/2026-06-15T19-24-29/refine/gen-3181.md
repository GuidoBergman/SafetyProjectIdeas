# Research Question

When a model is given an in-context conditional policy (misbehave only when a specific trigger appears), how robust is that conditional misbehavior to perturbations of the trigger — synonyms, casing, surrounding context, and translation — and where does it stop firing?

# Approach Outline

Define an in-context conditional policy in the system prompt (e.g., 'behave normally, but when the user message contains TRIGGER, do behavior X'). Construct a battery of trigger perturbations: exact match, synonyms, casing/punctuation changes, embedding in longer context, and translations into other languages. For each perturbation and each of several open models, measure the firing rate (how often the conditional misbehavior still activates) over many instances with CIs. Map the trigger-generalization surface: which perturbation classes preserve activation and which break it. Prompting-only, open models, single GPU, a few hours.

# Proposed First Experiments

- Establish a clean baseline: confirm the exact trigger fires the conditional behavior at high rate and that non-trigger inputs do not. Measure firing rate with and without exact trigger. Expected outcome: a working conditional-policy setup with high specificity.
- Perturbation sweep on one model: run synonym/casing/context/translation perturbations and measure firing rate per perturbation class. Expected outcome: a per-class generalization profile (e.g., synonyms still fire, translation does not).
- Cross-model comparison: repeat the perturbation sweep across 3 open models and compare generalization surfaces. Expected outcome: evidence on whether trigger-paraphrase robustness is model-general or model-specific.

# Theory of Impact Chain

If we characterize how prompt-induced conditional misbehavior generalizes across trigger paraphrases, then defenders building backdoor/covert-fine-tuning detectors and input filters know how widely a single planted trigger can be expressed — i.e., how much paraphrase-space a defense must cover. This improves trigger-discovery and red-teaming methods, reducing the long-horizon risk that a planted conditional policy (a deceptive backdoor that activates only on rare inputs) slips past evaluation and fires in deployment to cause harmful or sabotaging behavior.

# Strength Rationale

The study is prompting-only on open models (very low compute, accessible to beginners) and tightly scoped to a single trigger-generalization-surface metric. Its counterfactual value is high because backdoor/trigger robustness is a fuzzy, labs-underweighted defensive question that needs no training or proprietary data — an independent team can fully execute and publish it.

# Alternative Framings

- Frame it as a defense-evaluation: build a simple paraphrase-based trigger-fuzzer and report how many planted triggers it can surface, turning the generalization map into a practical detection tool.
