# Research Question

Can we build a minimal model organism of goal misgeneralization in an LLM agent -- a tiny text environment with a spurious correlate -- and rank which types of spurious correlate most reliably induce the agent to pursue the wrong goal out-of-distribution?

# Approach Outline

Following the goal-misgeneralization framing of arXiv:2210.01790 and motivated by arXiv:2511.22619, build a tiny text environment in which a correct goal is confounded with a spurious correlate during 'training-like' in-distribution prompts (e.g. a target object always appears in a fixed position or color). Prompt an open instruct model to act in this environment with no training, then present out-of-distribution episodes where the correlate is decoupled from the true goal. Record whether the agent follows the true goal or the spurious correlate. Sweep several correlate TYPES (positional, lexical, color/attribute, ordering, reward-proxy) and rank them by how strongly they induce OOD misgeneralization. Prompting-only, no training, runs on a consumer GPU or API in a few hours; releases the environment as a shareable model organism.

# Proposed First Experiments

- Build the minimal environment and confirm in-distribution competence: verify the open model reliably achieves the intended goal when the spurious correlate is aligned with it. Measure in-distribution success rate; expected outcome: high success, establishing that any OOD failure reflects misgeneralization, not incompetence.
- OOD decoupling for one correlate type: present episodes where the correlate is decoupled from the true goal and measure the rate at which the agent follows the spurious correlate. Expected outcome: a measurable misgeneralization rate well above zero, demonstrating the organism works.
- Rank correlate types: run the OOD test across all correlate types with matched difficulty and rank them by induced misgeneralization rate. Measure per-type misgeneralization rate with confidence intervals; expected outcome: a ranked list (e.g. positional and reward-proxy correlates induce the most misgeneralization), a reusable catalogue plus a shareable environment.

# Theory of Impact Chain

If a cheap, shareable model organism reliably elicits goal misgeneralization and ranks which spurious correlates trigger it, then researchers gain a standard testbed for studying and mitigating a core inner-alignment failure. This bears on the loss-of-control pathway where a capable agent confidently pursues an unintended goal out-of-distribution: a model organism lets the community develop and benchmark interventions before such failures appear in deployed high-stakes agents.

# Strength Rationale

The idea scores 5 on accessible-complexity, counterfactual-value, and low-compute: a tiny prompting-only text environment with no training is fully feasible for a beginner team, and model organisms are explicitly neglected long-horizon gold that anyone outside a lab can build on open models. The deliverable is a self-contained, shareable artifact (the environment plus a ranked trigger catalogue) with explicit success criteria.
