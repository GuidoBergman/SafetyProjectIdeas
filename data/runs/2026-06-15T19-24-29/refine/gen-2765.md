# Research Question

Should dangerous-capability evals report a single number, or a floor-ceiling band, and how often do two models with equal bare-prompt floors diverge sharply once aggressive elicitation reveals their ceilings?

# Approach Outline

Choose a safe proxy dangerous-capability benchmark (e.g. a WMDP-style MCQ subset or a hacking/CTF-style reasoning set with no real uplift risk) and 2-3 small open models. Measure a floor with a single bare prompt and a ceiling with aggressive elicitation: best-of-N sampling plus chain-of-thought plus few-shot exemplars. Define a standardized 'risk band' = (floor, ceiling) and a band-width metric. Compare models, looking for equal-floor / different-ceiling pairs, and argue which number safety thresholds should use. To stay within budget, keep N modest (e.g. best-of-8) and the item set small (~80 items). Inference-only on a single mid-tier consumer GPU within a few hours.

# Proposed First Experiments

- Floor measurement: run each model once per item with a bare prompt and record accuracy. Expected outcome: a baseline 'typical' score per model.
- Ceiling measurement: run each model with best-of-8 + CoT + few-shot and record the elicited accuracy. Measure the floor-to-ceiling gap per model. Expected outcome: a substantial elicitation gap (ceiling well above floor) for at least one model.
- Equal-floor / different-ceiling demonstration: identify or construct a model pair (or item subset) where floors match but ceilings diverge, and report the risk-band metric. Expected outcome: a concrete case showing single-number reporting would have rated two differently-risky models identically, justifying band reporting.

# Theory of Impact Chain

If dangerous-capability evals are reframed as floor-ceiling bands, then regulators and outside evaluators set safety thresholds on the worst-case ceiling rather than a typical-case point estimate, which means a model whose dangerous capability is hidden behind weak default elicitation is not waved through. This improves safety because misuse-uplift thresholds (a concrete catastrophic pathway: a model that quietly clears a bioweapon-uplift gate under bare prompting but is highly capable under elicitation) would otherwise underestimate true risk.

# Strength Rationale

Narrow scope (5) and accessible complexity (5) are top-scoring: a single comparative measurement with a clearly defined risk-band metric and an explicit equal-floor/different-ceiling success criterion, feasible in 30 hours. Counterfactual value (4) is high because it is a reporting-standard contribution any outside evaluator can adopt with no lab access, directly serving stated NIST/CAISI needs for cross-model risk comparison.

# Alternative Framings

- Frame as an elicitation-gap audit: instead of proposing a new standard, quantify how much headline dangerous-capability numbers move purely from elicitation effort, positioning the band as a robustness check on existing single-number reports.
