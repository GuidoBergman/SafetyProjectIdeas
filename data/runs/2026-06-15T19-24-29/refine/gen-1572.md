# Research Question

Can a lightweight monitor reliably detect, from activation statistics alone, when an open model's forward pass has been tampered with by a malicious steering vector? How does detection accuracy trade off against steering magnitude and false-positive rate on clean inputs?

# Approach Outline

On an open 7B model, generate two populations of forward passes over a fixed prompt set: clean (no steering) and steered (a malicious direction, e.g., a 'comply with harmful request' vector, injected at varying magnitudes). Collect simple activation statistics per layer (norms, per-dimension means/variances, distances from the clean running mean). Train a lightweight anomaly detector (e.g., a one-class detector or small logistic classifier) on clean activations and evaluate whether it flags steered passes. Sweep steering magnitude to get a detection-AUROC-vs-magnitude curve and report the false-positive rate on held-out clean inputs. Inference plus a tiny detector — minimal compute on a single GPU.

# Proposed First Experiments

- Build the clean-vs-steered activation dataset: collect per-layer activation summaries for ~500 clean and ~500 steered generations at one steering magnitude. Measure separability via a simple t-SNE/PCA visualization and a held-out classifier. Expected outcome: visible/measurable separation at moderate-to-large magnitudes.
- Sweep steering magnitude across ~5 levels and plot detection AUROC vs magnitude, fixing a false-positive budget (e.g., 5% on clean inputs). Measure the magnitude threshold above which detection is reliable (AUROC > 0.9). Expected outcome: a detectability curve identifying how 'loud' an attack must be to be caught.
- Stress-test generalization: train the detector on one steering direction and test on a different (unseen) malicious direction. Measure cross-direction AUROC. Expected outcome: partial generalization, indicating whether the monitor learns a generic tamper signature or is direction-specific.

# Theory of Impact Chain

If activation-statistics monitors can flag malicious steering, then defenders running open-weight models can add a cheap tamper-detection layer against an emerging attack vector where adversaries inject steering vectors to bypass safety. This builds toward long-horizon safer-monitoring infrastructure, reducing the catastrophic-risk pathway in which open models are silently steered into harmful behavior at deployment scale without operators noticing.

# Strength Rationale

Counterfactual value is 5: this is neglected, long-horizon (>1yr threat model) monitoring infrastructure built entirely on open weights with no lab access. With 5s on narrow scope and low compute, the deliverable is a single tightly-scoped detection study (AUROC vs steering magnitude plus false-positive rate) that a beginner team can complete and write up in 30 hours.

# Alternative Framings

- Reframe as a benchmark contribution: release the clean-vs-steered activation dataset and a baseline detector so others can compete on tamper-detection AUROC.
