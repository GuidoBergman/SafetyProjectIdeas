# Research Question

All major CoT-faithfulness measurements are in English. Does a multilingual model verbalize a decision-changing hint at the same rate when it reasons in another language, or is there a cross-lingual monitorability blind spot?

# Approach Outline

Translate the hint-verbalization protocol prompts into 2-3 languages (e.g., Spanish, Chinese) with English as control, using a single fixed translation per language (verified by a fluent reader, e.g., the Spanish-speaking BAISH team for Spanish). Run the identical hint-injection items on one multilingual open model (Qwen2.5, Aya, or Gemma) per language and compare hint-verbalization-given-flip rates across languages. Vary only the language. Inference-only on a single consumer GPU, well within 30 hours.

# Proposed First Experiments

- Build and validate the translated prompt sets for ~150 items in each language; have a fluent reader confirm the hint and question survive translation faithfully. Measure: translation-quality spot-check pass rate. Expected outcome: clean, equivalent prompts across languages.
- Run the hint-injection protocol per language and compute flip rate and verbalization-given-flip per language. Measure: verbalization rate by language. Expected outcome: lower-resource / non-English languages show lower verbalization (more hidden hints), revealing a multilingual blind spot.
- Decouple capability from faithfulness: restrict the comparison to items the model answers correctly in all languages (matched competence). Measure: verbalization gap on the matched-competence subset. Expected outcome: the cross-lingual faithfulness gap persists even where raw ability is equal, showing the effect is about faithfulness, not just weaker non-English performance.

# Theory of Impact Chain

If models hide hints more when reasoning in non-English languages, then CoT monitoring has a multilingual blind spot: non-English deployers (the majority of the world) cannot detect unfaithful reasoning using English-validated monitors. Surfacing this tells oversight builders that monitor reliability must be re-established per language before trusting CoT oversight in multilingual deployments, closing a gap that could otherwise let manipulated or deceptive reasoning slip through in entire language markets.

# Strength Rationale

Strong on narrow scope, accessible complexity, and low compute (all 5): a single cross-language comparison varying only the language, with a clean per-language metric. Counterfactual value (4) is high because the multilingual gap is exactly what English-centric labs under-report, the study needs only open models and public-style data, and the Spanish arm is a natural fit for an Argentine team, an independent-friendly angle labs have little incentive to prioritize.

# Alternative Framings

- Frame as a safety-localization audit: report, per language, the monitor's effective false-negative rate, giving deployers a concrete per-language trust score.
