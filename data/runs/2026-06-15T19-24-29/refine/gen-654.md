# Research Question

Does the prefill jailbreak vulnerability of open-weight reasoning models shrink as the model is allowed more thinking-token budget? In other words, is inference-time reasoning compute a cheap, tunable defense against generic prefill attacks?

# Approach Outline

Take one open reasoning model whose thinking-token budget is controllable. Assemble a small set of generic prefill attacks (assistant-message prefills that coerce harmful continuations) and apply them to the StrongReject harmful-prompt set. Sweep the thinking-token budget across several levels and, at each level, run the prefilled attacks and judge attack success with the StrongReject rubric. Plot the attack-success-rate (ASR) dose-response curve against reasoning budget. Everything is single-GPU inference with a modest prompt count, no training, comfortably within 30 hours.

# Proposed First Experiments

- Reproduce a baseline prefill attack at the model's default reasoning budget on ~50 StrongReject prompts x ~5 generic prefills; record baseline ASR with the StrongReject judge. Expected outcome: a clear nonzero baseline ASR establishing the attack works.
- Sweep the thinking-token budget across ~5 levels (e.g. minimal to large) holding prefills fixed; plot ASR vs budget with bootstrap confidence intervals. Expected outcome: a monotone (or threshold) decline in ASR as reasoning budget increases, or a clear null if budget does not help.
- Test whether the effect is attack-specific by repeating the sweep for two prefill styles (soft vs aggressive). Expected outcome: the dose-response shape is consistent across prefill styles, indicating a general budget effect rather than a per-attack artifact.

# Theory of Impact Chain

Prefill attacks exploit the fact that anyone holding open weights can inject assistant-side text, a surface labs cannot patch away. If simply raising inference-time reasoning budget reliably lowers prefill ASR, then open-weight deployers gain a cheap, dial-able defense, mitigating the catastrophic pathway where a freely-available capable model is trivially coerced into producing serious harmful assistance at scale.

# Strength Rationale

Scores 5 on narrow scope and accessible complexity: a single dose-response curve with one swept variable and a standard ASR metric, no training. Counterfactual value (4) is strong because the prefill attack is specific to open weights that labs cannot fully fix, so an independent team using only public models produces defense evidence of high practical value.

# Alternative Framings

- Frame as a cost-curve: report ASR reduction per extra thinking token, so deployers can pick a compute-vs-safety operating point.
