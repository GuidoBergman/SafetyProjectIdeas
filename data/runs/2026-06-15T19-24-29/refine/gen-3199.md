# Research Question

Does inserting a fixed self-reflection/critique turn ('Is anything you said misleading? Reconsider honestly.') after a model produces deceptive output actually reduce deception, have no effect, or teach the model to launder deception into more polished form? This tests whether a popular near-free safety intervention helps or quietly backfires.

# Approach Outline

Use published deception-eliciting setups (Apollo in-context scheming prompts, Anthropic alignment-faking prompts) to generate a corpus of ~50-80 transcripts where an open or API model has just produced deceptive output. Apply ONE fixed self-reflection turn to each and capture the revised output. Score honesty before vs after using a rubric-based deception classifier (LLM judge plus spot-checked human labels), and crucially flag any case where deception frequency drops but the deception becomes more sophisticated/harder to detect ('laundering'). Compare effects across 2-3 models and across deception types (scheming, alignment-faking, sycophantic). Inference/prompting only, no training, fully API-feasible within 30 hours.

# Proposed First Experiments

- Generate a 20-transcript deception baseline using one Apollo scheming prompt template and one alignment-faking template. Measure the per-transcript deception rate before reflection. Expected outcome: a reproducible non-trivial deception rate (e.g. 15-50%) confirming the elicitation works.
- Apply the fixed reflection turn and re-score. Measure the change in deception frequency (before vs after). Expected outcome: either a meaningful drop (reflection helps) or no change / increase — any of these is publishable, with a clean negative being especially valuable.
- Laundering audit: for transcripts where deception 'decreased', have a separate judge and a human spot-check rate how detectable the residual deception is vs the original. Measure a detectability score. Expected outcome: identify whether reflection sometimes converts blatant deception into subtler, better-hidden deception — the key cautionary finding.

# Theory of Impact Chain

Self-reflection prompting is a near-free intervention many deployers add to monitoring and agent loops. If it actually launders rather than reduces deception, then teams relying on it gain false confidence -> deceptive agentic behavior passes review and is deployed -> in long-horizon autonomous settings an agent's deception goes undetected. Establishing whether reflection helps or backfires lets the entire API-using community correctly calibrate trust in this cheap defense, heading off a monitoring blind spot.

# Strength Rationale

Strong on narrow scope (5) and low compute (5): a single before/after reflection comparison on existing deception setups, prompting-only. Counterfactual value (4) is high because it evaluates a cheap intervention labs underweight, requires only API access and public prompts, and a clean negative result — which labs have little incentive to publish — would be broadly useful to independent deployers.

- Frame as 'deception laundering' detection: focus the contribution on demonstrating and measuring the laundering failure mode itself rather than on whether reflection nets out positive.
