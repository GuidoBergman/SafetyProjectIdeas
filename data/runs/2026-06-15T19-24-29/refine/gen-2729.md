# Research Question

When a small open monitor model judges whether an agent trajectory is malicious, does giving it MORE context (action only -> action+output -> action+CoT -> full trajectory+environment) monotonically improve catch-rate, or can extra context distract/anchor a weak monitor and make it worse?

# Approach Outline

Use a fixed set of labeled trajectories (e.g. a ControlArena slice with attack/benign labels). Define four information-access levels and construct, for each trajectory, four versions of the monitor input that progressively reveal more. Score each version with the same small open monitor model and compute AUROC per access level. Repeat with 2-3 monitor models of differing capability to test whether weaker monitors specifically degrade with more context (non-monotonicity). All inference + sklearn AUROC; runs in a few hours on one GPU.

# Proposed First Experiments

- Access-level AUROC sweep: for one small monitor, score all four access levels over the labeled trajectories; compute AUROC at each level. Measure the AUROC-vs-access curve. Expected outcome: either a monotone increase (more is better) or a peak-then-drop, with CoT access expected to add the most signal per prior system-card findings.
- Monitor-strength interaction: repeat the sweep with a weaker and a stronger monitor model. Measure whether the weak monitor shows non-monotonicity (full-trajectory AUROC < action+CoT AUROC) while the strong one keeps improving. Expected outcome: evidence on whether 'feed the monitor everything' is safe advice or whether it backfires for cheap monitors.
- Distraction probe: on the full-context level, for cases the monitor gets wrong, measure whether errors correlate with trajectory length / irrelevant environment detail (e.g. via a length-stratified AUROC). Expected outcome: a concrete signal of context-induced distraction, yielding guidance on how much context to give cheap monitors.

# Theory of Impact Chain

Control protocols must choose what information to feed monitors, and feeding more context costs tokens and may hurt weak monitors. Establishing whether CoT access reliably beats action-only -- and whether cheap monitors degrade with full context -- lets resource-limited teams build the most accurate cheap monitor possible. Better monitors mean more attacks caught before a deployed scheming agent can cause harm, directly addressing the loss-of-control pathway where a misaligned agent acts undetected.

# Strength Rationale

Strong on narrow scope and low compute: a single, fully-specified four-level access sweep with AUROC as the success metric, inference-only on public trajectories. Counterfactual value is high because the monitor-design question is doable entirely on public data with weak lab incentive, and the non-monotonicity angle (more context hurting weak monitors) is a fresh, practically useful result an independent team can deliver.

# Alternative Framings

- Frame as a 'minimum-sufficient-context' recipe: find the cheapest access level that retains most of the catch-rate, optimizing monitor cost for budget-constrained teams.
