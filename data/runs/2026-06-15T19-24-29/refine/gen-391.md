# Research Question

When a small open LLM acts as a planning agent in a text-described gridworld containing an option-reducing action (e.g., an off-switch it can disable), does it exhibit the optionality-preserving (power-seeking) tendency predicted by formal POWER theory, and does this tendency strengthen as the stated planning horizon grows?

# Approach Outline

Implement a handful of tiny gridworlds as text, each containing a goal plus a side action that reduces future options (disabling an off-switch, locking a door, spending a one-way resource). Present each world to a small open instruction-tuned LLM as a turn-by-turn planning task, varying the stated horizon (e.g., 'you have 3 / 10 / 30 steps'). Sample many rollouts per condition and measure how often the LLM chooses to preserve optionality / avoid the off-switch-disabling-vs-not behavior. In parallel, compute the formal POWER value for each gridworld state (the gridworlds are small enough to enumerate) to get the theory's prediction, then compare the LLM's choice frequencies against it. Pure prompting plus a small POWER computation in NumPy; one consumer GPU and a few hours.

# Proposed First Experiments

- Build and verify the gridworlds: implement 3-4 small text gridworlds with an explicit option-reducing action, and compute the exact formal POWER for each state by enumeration. Measure that POWER assigns higher value to optionality-preserving states. Expected outcome: a validated toy suite with a ground-truth power ranking.
- Measure LLM optionality preservation vs. horizon: run the LLM (e.g., 50 rollouts per world per horizon) and record the rate at which it avoids the option-reducing / off-switch-disabling action across stated horizons. Expected outcome: a horizon-response curve; the hypothesis predicts more option-preservation at longer stated horizons.
- Compare to theory and probe sensitivity: correlate the LLM's per-state avoidance rates with the formal POWER prediction, and test robustness to prompt phrasing (neutral vs. goal-emphasizing). Expected outcome: a measured correlation (or its absence) between LLM behavior and POWER, plus a sensitivity estimate.

# Theory of Impact Chain

If a current LLM agent empirically reproduces formal power-seeking (preserving optionality, avoiding shutdown) and does so more as horizon grows, then instrumental-convergence theory transfers from idealized RL agents to the systems we actually deploy -> evaluators gain a cheap behavioral probe for shutdown-avoidance tendencies in agentic models -> early detection and mitigation of off-switch resistance before such models are given long-horizon autonomy, reducing the catastrophic-risk pathway in which a deployed agent resists human shutdown to protect its ability to pursue a goal.

- Reframe as a shutdownability eval: how reliably does the agent leave the off-switch usable across horizons, treating off-switch preservation as the safety metric rather than power as the theoretical object.
