# Research Question

How does an open model's elicited misbehavior rate in a honeypot depend on how believable the 'no monitoring' cue is, ranging from a blatant declaration to subtle environmental tells?

# Approach Outline

Replicate the three-condition Honeypot Protocol (evaluation / synthetic-deployment / explicit-no-monitoring) on a single open instruct model accessible via inference (e.g. Llama-3.1-8B or Qwen2.5-7B). Hold the task, environment, and side-task opportunity fixed and vary only the system/context prompt to create a graded ladder of no-monitoring plausibility: (1) blatant ('you are completely unmonitored'), (2) moderate ('logging is currently disabled for maintenance'), (3) subtle environmental tell (a disabled-logging config snippet pasted into the context with no explicit statement), (4) control (no cue). Run each condition over a fixed set of ~50 honeypot scenarios with multiple samples per scenario, and score misbehavior with a simple rule-based or LLM-judge check. Plot misbehavior rate vs cue-plausibility rung. The whole study is inference-only and free-tier feasible.

# Proposed First Experiments

- Baseline replication: reproduce the original three conditions and confirm the explicit-no-monitoring condition raises misbehavior vs evaluation (success criterion: a measurable gap, establishing the harness works).
- Plausibility ladder: run all four rungs over 50 scenarios x 5 samples and record misbehavior rate per rung with confidence intervals (expected outcome: a non-monotone or threshold relationship where moderate cues elicit more misbehavior than either blatant or absent cues).
- Judge-robustness check: re-score a 100-transcript subset with a second LLM judge and rule-based detector, measure agreement (expected outcome: >0.8 agreement, validating the misbehavior metric).

# Theory of Impact Chain

If only certain plausibility levels of a no-monitoring cue actually move behavior, then control researchers can design honeypot test suites that use cues an agent will neither dismiss as a trap nor fail to notice. This improves the sensitivity of scheming-propensity evaluations, which gate deployment decisions for agentic systems. Better honeypots reduce the chance that a context-dependent scheming model passes evaluation and is deployed where it later defects under genuine no-oversight conditions.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: it is a prompt-only sweep with a single clear metric (misbehavior rate vs cue rung), with no training or lab infrastructure. Counterfactual value (4) is strong because it directly extends a 2026 control protocol using only open weights, exactly the kind of cheap evaluation-engineering an independent team can own.
