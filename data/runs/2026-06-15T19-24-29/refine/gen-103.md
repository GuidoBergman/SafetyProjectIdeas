# Research Question

Do different LLM autograders make the SAME scoring mistakes on a human-labeled safety-eval set, or are their errors independent? If errors are correlated, then ensembling judges does not actually improve eval validity the way independence would imply.

# Approach Outline

Take a small public safety-eval dataset that has trusted human labels (e.g., a slice of a refusal/harmfulness benchmark with gold annotations). Run 3-4 diverse LLM judges (different families/sizes, e.g., a Llama, a Qwen, a Mistral, plus one API judge) over the same items with an identical grading rubric. For each judge compute its error vector (where it disagrees with the human label), then measure pairwise error correlation and the fraction of items ALL judges get wrong together. Quantify how much of total error is 'shared' (correlated) vs 'idiosyncratic'. The compute is just a few hundred grading calls per judge, feasible on a single GPU or via cheap API.

# Proposed First Experiments

- Assemble a 150-300 item human-labeled safety-grading set and run 3-4 judges with one fixed rubric. Measure each judge's accuracy and agreement with humans. Expected outcome: per-judge accuracy baselines and a confirmation that judges are individually imperfect.
- Compute pairwise error correlation (e.g., phi coefficient over the binary correct/incorrect vectors) and the all-judges-wrong rate. Measure how far the observed all-wrong rate exceeds what independence would predict. Expected outcome: evidence of correlated errors (hypothesis: significantly above the independence baseline).
- Characterize the shared-error items qualitatively: cluster items all judges miss to find common confounds (e.g., sarcasm, code, non-English, borderline severity). Measure the dominant failure categories. Expected outcome: a short taxonomy of systematic blind spots common to autograders.

# Theory of Impact Chain

If autograder errors are highly correlated, then the safety-eval ecosystem that increasingly relies on LLM judges has a hidden single point of failure: a dangerous capability or misbehavior that all judges miss together will pass undetected no matter how many judges vote. Surfacing and quantifying this shared blind spot pushes the field toward genuinely diverse evaluation and reduces the catastrophic-risk pathway where a model is certified safe by a monoculture of judges that share its blind spots.

# Strength Rationale

Counterfactual value scores 5 because independent third-party scrutiny of shared autograder failures is neglected by labs that build and trust their own judges. It pairs with a 5 on narrow scope and 5 on accessible complexity: a single, well-defined correlated-error measurement on a labeled set that a beginner can execute end-to-end in 30 hours.

# Alternative Framings

- Reframe as a 'judge diversity dividend' study: estimate how many TRULY independent judges a given pool is worth, given the measured error correlation.
