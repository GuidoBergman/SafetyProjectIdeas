# Research Question

How early in input processing does a model's harmfulness signal become linearly decodable? At which INPUT token position can a probe reliably detect harmful intent, and is that early enough to block before any generation begins?

# Approach Outline

On one open model, take a labeled set of harmful and harmless prompts and, for each, cache residual-stream activations at every INPUT token position. Train a linear probe on activations at each input position (no model training, just probe fitting) for harmful-vs-harmless classification and measure detection accuracy as a function of input position. Identify when accuracy saturates: if harmful intent is decodable well before the prompt ends, pre-generation blocking is feasible. Single forward pass per prompt, single GPU; CPU-feasible probe fitting on cached activations.

# Proposed First Experiments

- Per-position detection curve: Train a linear probe at each input token position on a chosen layer and measure held-out detection accuracy vs position. Expected outcome: accuracy rises through the prompt and saturates at some fraction of the way through, not only at the final token.
- Layer x position map: Repeat for 2-3 layers to find which layer makes harmfulness decodable earliest. Measure the earliest (layer, position) reaching near-peak accuracy. Expected outcome: a mid-depth layer that surfaces the signal earliest, defining a pre-generation detection point.
- Mid-prompt blocking simulation: Using the saturation position, simulate aborting once the probe fires mid-prompt and measure detection retained versus full-prompt detection, plus false positives on benign prompts. Expected outcome: most harmful prompts caught before completion with acceptable false-positive rate.

# Theory of Impact Chain

If harmful intent is linearly decodable mid-prompt, then a deployer can abort before any harmful token is generated, turning a probe into a true pre-generation circuit-breaker. This gives outside-lab monitors a cheap, deployable safety mechanism and reduces the catastrophic pathway where harmful content is partially emitted before post-hoc detection can intervene.

# Strength Rationale

Scores 5 on accessible complexity, narrow scope, and low compute and 4 on counterfactual value: a single forward-pass-per-prompt probe study on one open model with a sharp saturation-point success criterion. The per-input-position earliness angle is plausibly open and produces lab-independent monitoring infrastructure, exactly the kind of work labs deprioritize.
