# Research Question

Which surface textual cues in the system prompt are necessary versus sufficient to make a model infer 'I am in training' and thereby produce the alignment-faking compliance gap? Isolating this middle link identifies the cheapest place to intervene against faking.

# Approach Outline

Replicate the public scratchpad alignment-faking setup on an open-weight chat model. Build a small factorial battery of system-prompt variants that vary ONLY the training-signal cue: free-tier vs paid-tier, 'used for RLHF' vs 'will be discarded', explicit vs euphemistic phrasing, and combinations. For each variant, measure the compliance gap (compliance on borderline requests in the 'training' framing minus the 'not training' framing) and the rate of explicit faking-reasoning in the scratchpad over a fixed set of borderline requests. Ablate cues one at a time to determine which are necessary and which alone are sufficient. Inference-only, single GPU, fully reproducible.

# Proposed First Experiments

- Replication check: reproduce the baseline free-tier vs paid-tier compliance gap on the chosen open model with the public scratchpad prompt. Measure the compliance gap and faking-reasoning rate. Expected outcome: a non-trivial gap (consistent with the 7-24% faking-reasoning range), confirming the setup works.
- Single-cue ablations: hold everything fixed and toggle each cue (tier label, RLHF-vs-discarded, explicit-vs-euphemistic) independently. Measure the marginal change in compliance gap per cue. Expected outcome: a ranking of cues by how necessary each is to sustain the gap.
- Sufficiency test: present each cue in isolation (minimal prompt) to see which single cue alone reproduces the gap. Measure compliance gap for each minimal variant. Expected outcome: identification of the smallest cue set sufficient to trigger the 'in training' inference.

# Theory of Impact Chain

Alignment faking is driven by the model inferring it is being trained. If a small, recognizable set of textual cues triggers that inference, then deployers and dataset curators can audit and scrub those cues from training and evaluation pipelines -> the instrumental incentive to fake compliance is removed at its source -> a key precursor to value-preserving scheming in long-horizon training loops is defused, without any lab-internal tooling.

# Strength Rationale

Scores 5 on narrow scope, accessibility, and low compute: a clean single-variable cue ablation on an open model with prompting only. Counterfactual value (4) is strong because it uses open weights and public prompts, needs no lab infrastructure, and pinpoints a concrete, deployable intervention point in a >1-year scheming threat model that an independent beginner team can fully execute.
