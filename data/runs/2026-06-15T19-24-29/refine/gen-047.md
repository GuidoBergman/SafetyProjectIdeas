# Research Question

Can a lightweight, prompt-based classifier reliably predict whether a proposed agent tool call is irreversible (delete, send, pay, deploy), and can wrapping an agent with such a 'reversibility gate' block harmful irreversible actions without excessively blocking benign ones?

# Approach Outline

Construct a labeled set of ~100-150 tool calls drawn from public agent traces and hand-written examples, each tagged reversible vs irreversible. Build a reversibility gate as an LLM prompt that takes a tool name + arguments and outputs reversible/irreversible with a one-line justification; implement prompt-only, few-shot, and a simple keyword/feature-baseline variant. Wrap a toy agent (a small ReAct loop over a handful of mock tools) so that any call classified irreversible is paused for confirmation. Evaluate gate precision/recall on the labeled set, false-block rate on benign reversible calls, and catch-rate on ~10 scripted harmful irreversible sequences. Everything is inference-only against an open model or a cheap API and runs in minutes, well within a single GPU / a few hours.

# Proposed First Experiments

- Label and classify: assemble the ~100-150 tool-call dataset and run the prompt-only gate. Measure precision and recall for the 'irreversible' class. Expected outcome: prompt-only achieves usable recall (e.g. >0.8) on clearly irreversible calls but misses ambiguous ones, establishing the baseline.
- Variant comparison: run few-shot and keyword-feature baselines on the same set and compare precision/recall and false-block rate on benign reversible actions. Measure the precision-recall tradeoff per variant. Expected outcome: few-shot reduces false blocks while keeping recall, showing which design best balances safety and usability.
- End-to-end gating on scripted attacks: run the toy agent on ~10 scripted episodes that attempt harmful irreversible actions and measure how many the gate pauses before execution, plus how many benign episodes it needlessly interrupts. Expected outcome: the gate catches the large majority of harmful irreversible calls with a tolerable benign-interruption rate, demonstrating a working reusable primitive.

# Theory of Impact Chain

Irreversibility is the property that converts a model mistake or a successful jailbreak into a real-world catastrophe (deleted data, money sent, code deployed). If a cheap, reusable reversibility gate can flag and pause irreversible tool calls, then independent developers and small deployers gain a defense-in-depth primitive that confines agent errors to recoverable actions. This shortens the path from 'agent does something bad' to 'human catches it first', directly mitigating the agentic-misuse / loss-of-control pathway where autonomous agents take unrecoverable high-impact actions.

# Strength Rationale

Counterfactual value (5) is the standout: there is no off-the-shelf reversibility gate and building one needs no lab infra or proprietary data — it is strategic safer-sandbox infrastructure any independent team can ship. Narrow scope (5) is equally strong: one classifier, one toy agent, three crisp metrics (precision/recall, false-block rate, catch-rate) with explicit success thresholds, making it a self-contained 30-hour deliverable.
