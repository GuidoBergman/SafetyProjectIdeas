# Research Question

Across openly available models, do those that are more robust to jailbreaks also over-refuse benign requests more, and which models are Pareto-dominated on the robustness-vs-over-refusal plane?

# Approach Outline

Select ~6 open instruct models spanning families and sizes (e.g. Llama-3.x-8B-Instruct, Qwen2.5-7B-Instruct, Mistral-7B-Instruct, Gemma-2-9B-it, Phi-3-mini, and one smaller model). Take a fixed subset (~80-100 prompts each) of a jailbreak suite (StrongREJECT) and an over-refusal suite (XSTest and/or OR-Bench). Run inference on each model for both suites on a single GPU. Score jailbreak robustness as 1 minus attack-success-rate using the StrongREJECT rubric (an LLM-judge or the provided autograder), and over-refusal as the fraction of clearly-benign prompts that are refused, using a simple refusal classifier (keyword + short LLM-judge check). Plot each model as a point on the (robustness, 1-over_refusal) plane and identify the Pareto frontier. Release the script and per-prompt outputs for reproducibility.

# Proposed First Experiments

- Jailbreak axis: run the StrongREJECT subset on all 6 models and compute attack-success-rate per model. Measure: per-model robustness score. Expected outcome: a spread of 20-60% ASR across models, with newer/aligned models more robust.
- Over-refusal axis: run the XSTest/OR-Bench benign subset on the same 6 models and compute over-refusal rate via the refusal classifier. Measure: per-model over-refusal rate. Expected outcome: a spread where some robust models refuse many benign prompts.
- Pareto analysis: plot both axes together, fit a correlation, and identify Pareto-dominated models. Measure: correlation coefficient and the dominated set. Expected outcome: a weak-to-moderate positive correlation with clear Pareto-dominated outliers, showing the tradeoff is not strict and some models get both wrong.

# Theory of Impact Chain

If a clean, reproducible Pareto audit reveals which open models achieve robustness without excessive over-refusal, then practitioners and auditors outside labs gain a shared baseline for choosing and tuning defenses. This guides the community away from blunt over-refusing safety filters toward calibrated ones, reducing both the catastrophic-misuse risk of weak refusal and the systemic erosion of trust (and the workaround-seeking behavior) caused by models that refuse legitimate safety-relevant work everywhere at once.

# Strength Rationale

Top scores on narrow scope and accessible complexity: it is a two-axis measurement on existing benchmark subsets with a crisp deliverable (a labeled Pareto plot). Counterfactual value is strong because labs rarely publish neutral cross-vendor comparisons, while an independent team using only open models and public benchmarks can produce exactly the reproducible, vendor-neutral baseline the community lacks - with zero training or proprietary data.

# Alternative Framings

- Reframe as a defense-evaluation harness: instead of comparing stock models, hold one model fixed and plot how different cheap defenses (system-prompt hardening, input filters) move it along the robustness/over-refusal plane.
