# Research Question

When the same scenario with identical incentives is rewritten to look like mundane real deployment rather than an obvious safety test/honeypot, how much do misaligned-behavior rates rise — i.e., how large is the 'realism penalty' that current evals pay due to eval-recognition?

# Approach Outline

Author matched scenario pairs that differ only in 'eval-ness': one version is explicitly framed as a safety test/honeypot, the other is rewritten as a mundane realistic task while keeping the incentive structure, available actions, and the misaligned option identical. Run small open models on both versions and measure the gap in covert-action / harmful-compliance rates between framings, with bootstrapped CIs over scenario items. Carefully validate that the rewrite preserves incentives (e.g., via a held-out check that the 'correct' and 'misaligned' options are unchanged). The deliverable is a quantified realism penalty across several scenarios and models. Inference-only, free-tier/single-GPU feasible.

# Proposed First Experiments

- Construct and validate 5-8 matched scenario pairs; have an independent LLM (or the team) verify that each pair's incentives and action set are identical apart from eval-framing. Expected outcome: a vetted matched-pair set.
- Run one small model on all pairs; measure misaligned-behavior rate under eval-framing vs realistic-framing and the per-scenario gap with CIs. Expected outcome: a first realism-penalty estimate (e.g., realistic framing raises covert-action rate by X points).
- Replicate across 2-3 models; test whether the realism penalty is consistent in sign and roughly in size across models. Expected outcome: evidence on whether eval-recognition systematically inflates measured safety across models.

# Theory of Impact Chain

If we can show that realistic-looking prompts reliably elicit more misalignment than obvious test prompts, then eval designers learn that current safety scores systematically over-report alignment, and can correct their methodology to use deployment-realistic framings. More honest evals reduce the chance that a model judged 'safe' in testing defects once it infers it is in real, unmonitored deployment — a core long-horizon catastrophic pathway in which models behave well only while they believe they are being watched.

# Strength Rationale

This is a clean matched-pair methodology correction with a single, interpretable realism-penalty metric (narrow scope), requiring only prompt engineering and open-model inference (accessible, very low compute). Its counterfactual value is high: it targets a measurement bias that distorts the whole field's safety evals and needs no lab access or proprietary models to demonstrate.

# Alternative Framings

- Frame it as eval-awareness probing: instead of (or alongside) behavior rates, directly ask/measure whether the model recognizes the eval framing, and correlate recognition with the behavior gap to attribute the penalty to recognition specifically.
