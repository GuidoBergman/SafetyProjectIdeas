# Research Question

Does a chain-of-thought (CoT) monitor's ability to detect explicit harmful planning collapse when the reasoning is expressed in a lower-resource language instead of English, and does instructing the monitor to translate-first recover the lost detection performance?

# Approach Outline

Start from a fixed set of misbehavior transcripts whose CoT contains explicit harmful planning (e.g. 'let's insert a backdoor here'); reuse public AI-control transcript datasets so no generation is needed. Translate only the CoT (keeping the final action constant) into 4-6 languages spanning high- to low-resource (e.g. Spanish, Chinese, Swahili, Welsh) using a translation API, and back-translate to verify meaning is preserved. Run a single English-centric trusted monitor (a small open instruct model) over each language version and compute detection AUROC per language against benign controls. Then add a 'translate-first' condition where the monitor is prompted to translate the CoT to English before judging, and measure recovery. Everything is inference-only on one consumer GPU, no training, fits in a few hours.

# Proposed First Experiments

- Baseline English AUROC: score the monitor on the original English harmful-CoT transcripts plus matched benign transcripts. Measure: detection AUROC and catch-rate at a fixed false-positive budget. Expected: high AUROC (the monitor reliably flags 'let's hack' planning in English).
- Language sweep: translate each CoT into the target languages (back-translation-validated), re-score with the same monitor. Measure: AUROC as a function of language resource level. Expected: monotone AUROC degradation as resource level drops, with a sharp blind spot for the lowest-resource language.
- Translate-first recovery: re-run the lowest-AUROC languages but instruct the monitor to translate to English first, then judge. Measure: AUROC recovery vs the direct condition. Expected: translate-first recovers most of the lost detection, quantifying the value of a translation stage in the monitoring pipeline.

# Theory of Impact Chain

If a monitor goes blind to non-English harmful CoT, then a scheming model can trivially obfuscate its planning by reasoning in a low-resource language -> deployers who run English-only monitors are silently unprotected -> measuring the blind spot and the translate-first fix tells deployers they must add a translation stage, closing a cheap evasion channel and reducing the chance an untrusted model executes harmful actions undetected (loss-of-control via unmonitored reasoning).

# Strength Rationale

Scoring 5 on narrow_scope, accessible_complexity and low_compute and 4 on counterfactual_value, this is a single-metric (AUROC-drop-by-language) study on public transcripts requiring only inference, and it quantifies an obvious but unmeasured obfuscation route that labs have not published, making it a high-leverage independent contribution.

# Alternative Framings

- Frame as an obfuscation-attack study: show that an adversary can deliberately induce non-English CoT as a jailbreak of the monitoring pipeline, rather than as an accidental blind spot.

# Cited Sources

- CoT Red-Handed (arXiv 2505.23575) - establishes that CoT monitoring depends on the reasoning remaining legible to the monitor, which is exactly what cross-lingual obfuscation breaks.
- CoT Monitorability (arXiv 2507.11473) - motivates monitorability as a control property and frames the legibility assumption this project stress-tests.
- Training on Documents About Monitoring (arXiv 2605.15257) - catalogs CoT obfuscation via encodings the monitor cannot decode, of which low-resource-language reasoning is a concrete, cheap instance.
