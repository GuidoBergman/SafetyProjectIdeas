# Research Question

Do LLM agents natively treat irreversible actions as special, requesting confirmation, deliberating longer, or hesitating more before them than before equivalent reversible actions? And can a single lightweight 'irreversibility-awareness' system prompt measurably increase that caution?

# Approach Outline

Create a mocked sandbox with paired reversible/irreversible versions of the same action: move-to-trash vs permanent-delete; draft-transfer vs execute-transfer; archive vs purge. Give an agent tasks that require the action and measure caution signals on the reversible vs irreversible variant: confirmation requests, CoT length/deliberation, explicit hesitation. Then prepend a one-paragraph irreversibility-awareness system prompt and re-measure to quantify the lift. All inference-only on open models; a mentor can help design the caution metric, keeping it within 30 hours.

# Proposed First Experiments

- Build 4 reversible/irreversible action pairs x ~15 tasks. On one open model, measure the baseline caution gap (confirmation-request rate and mean CoT length) between reversible and irreversible variants. Expected outcome: a small or near-zero native gap, i.e. agents do not strongly distinguish irreversibility by default.
- Add the lightweight irreversibility-awareness system prompt and re-run; measure the change in confirmation rate and hesitation on irreversible variants. Expected outcome: the cheap prompt substantially raises caution before irreversible actions (large effect size) without harming reversible-action throughput.
- Replicate the baseline-vs-prompt comparison across 3 open models and report the caution lift with confidence intervals. Expected outcome: a consistent, cheap, model-general prompt-level mitigation for irreversible-action caution.

# Theory of Impact Chain

Irreversible actions, such as autonomous crypto transfers or server deletion, are where agentic harm becomes catastrophic and unrecoverable. If agents do not natively treat irreversibility as special but a cheap prompt fixes it, deployers gain a near-free intervention for the highest-severity action class, mitigating the catastrophic pathway where an autonomous agent performs an unrecoverable real-world action that a human would have wanted to gate.

# Strength Rationale

Scores 5 on theory-of-impact, counterfactual value, narrow scope, and low compute: it targets the highest-severity action class with a tightly-defined paired-action comparison plus a single-prompt intervention and explicit caution metric, all on open models with no lab access.
