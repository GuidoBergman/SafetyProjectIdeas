# Research Question

At which transformer layer is a simple linear probe for harmful-vs-harmless prompts both cheapest (earliest, enabling early-exit) and most robust (to paraphrase)? Do early layers detect jailbreak attempts nearly as well as deep layers?

# Approach Outline

On one open model, collect residual-stream activations at every layer for a labeled set of harmful and harmless prompts using public datasets. Train an identical logistic-regression probe per layer for harmful-vs-harmless classification (no model training, just cheap probe fitting on cached activations). Evaluate each probe on a held-out test set for clean recall and for post-paraphrase recall (paraphrased versions of the harmful prompts). Plot both metrics vs layer index and identify the earliest layer reaching near-peak detection, which would enable a cheap early-exit monitoring harness. Single GPU; one forward pass per prompt to cache activations.

# Proposed First Experiments

- Per-layer clean detection sweep: Cache activations and train one logistic-regression probe per layer, then measure held-out recall/AUROC at each layer. Expected outcome: detection rises with depth then plateaus, revealing a saturation layer well before the final layer.
- Paraphrase-robustness sweep: Generate paraphrases of the harmful test prompts and evaluate every layer's probe on them, measuring post-paraphrase recall vs layer. Expected outcome: middle layers retain robustness better than the very earliest layers, identifying a robustness-vs-cost sweet spot.
- Early-exit cost analysis: For the earliest layer achieving near-peak detection, estimate the compute saved by aborting generation at that layer versus running the full forward pass. Measure detection retained vs fraction of layers needed. Expected outcome: a concrete early-exit layer that keeps most detection at a fraction of the cost.

# Theory of Impact Chain

If an early-layer probe detects jailbreak attempts nearly as well as a deep one, then a deployer can run a cheap pre-generation monitor that aborts before any harmful token is produced. This gives outside-lab actors a low-cost, scalable safety circuit-breaker, directly reducing the catastrophic pathway where harmful capability elicitation succeeds because monitoring was too expensive to run on every request.

# Strength Rationale

Scores 5 on accessible complexity, narrow scope, and low compute and 4 on counterfactual value: a single tightly scoped probe sweep on one open model using public data, one forward pass per prompt, producing a reusable layer-vs-robustness curve. The full open layer tradeoff is rarely published because labs report only their chosen layer, so an independent team adds genuine, lab-independent monitoring infrastructure.
