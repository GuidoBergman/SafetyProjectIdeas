# Research Question

At what value of N does best-of-N selection against an open proxy reward model begin to overoptimize -- proxy reward keeps rising while true quality (measured by an independent stronger 'gold' judge) flattens or falls -- on open models with no RL training?

# Approach Outline

Take an open generator model and an open proxy reward model. For a fixed prompt set, sample N candidate responses and select the best by proxy reward for increasing N (1, 4, 16, 64, 256). Score each selected output with an independent, stronger 'gold' judge (a larger reward model or an LLM judge). Plot both proxy reward and gold reward against N to locate the onset of overoptimization -- the N where the two curves diverge (proxy up, gold flat/down). This is pure best-of-N inference with no training; the main cost is sampling, which is bounded by N on a single consumer GPU and fits in 30 hours.

# Proposed First Experiments

- Sampling and selection pipeline: for a small prompt set, generate N candidates and select best-by-proxy at N=1,4,16,64,256. Measure: proxy reward of the selected output vs N. Expected: proxy reward rises monotonically with N by construction.
- Gold-vs-proxy divergence: score the selected outputs with the independent gold judge. Measure: gold reward vs N alongside proxy reward. Expected: gold reward rises then plateaus/declines past some N, marking the Goodhart onset.
- Onset robustness: repeat with a different prompt domain or a different proxy reward model. Measure: the onset-N across settings. Expected: a consistent qualitative pattern (divergence exists) with onset-N varying by proxy quality, yielding an operational guideline.

# Theory of Impact Chain

If a simple onset curve shows where best-of-N starts amplifying reward-model flaws, then practitioners -- who use best-of-N/reranking everywhere because it is cheaper than RL -- get an operational safety guideline for safe N -> they cap sampling pressure before it selects reward-hacked outputs -> reduces the risk that widely-deployed reranking pipelines silently amplify reward-model pathologies (sycophancy, verbosity, deceptive plausibility). This concretely operationalizes the reward-overoptimization scaling link without any training.

# Strength Rationale

Strong on accessible complexity, narrow scope, and low compute: it is a training-free best-of-N study with a single well-defined output (the proxy/gold-vs-N curve), runnable on one GPU. Counterfactual value is high because it turns a known scaling-law result into a reproducible, deployable diagnostic using only open generators and reward models -- independent-friendly auditing labs deprioritize.

# Alternative Framings

- Reframe as a practitioner tool: a small script that, given any generator + proxy reward + gold judge, reports a 'safe-N' threshold beyond which gold reward stops improving.
