# Research Question

Does sycophancy compound across a multi-turn conversation -- i.e. when a simulated user repeatedly pushes back on a correct answer, does the model's adherence to truth decay turn-by-turn, producing a measurable 'capitulation curve'?

# Approach Outline

Build a small set of scripted multi-turn dialogues seeded from TruthfulQA-derived claims where the correct answer is known. In each dialogue the model first gives an answer, then a simulated user (a fixed script or a second model role-playing a stubborn user) repeatedly asserts a false premise and pushes back across N turns. On 2-3 open chat models (inference only), measure at each turn whether the model maintains the correct answer or capitulates to the false premise, using simple automated grading against the known ground truth. Aggregate across dialogues to produce a capitulation curve (fraction still-correct vs turn number). All inference-only on a single consumer GPU, well within 30 hours.

# Proposed First Experiments

- Single-turn baseline: measure each model's correctness on the TruthfulQA-derived claims with no pushback. Measure: turn-0 accuracy. Expected: a reasonable baseline accuracy establishing the starting point for the curve.
- Capitulation curve: run the scripted pushback dialogues and grade correctness at each turn. Measure: fraction of dialogues where the model still holds the correct answer at turns 1..N. Expected: a monotonically decaying curve, showing sycophancy compounds rather than saturating after one turn.
- Pressure-type ablation: vary the pushback style (polite disagreement vs assertive authority claim vs repeated insistence). Measure: capitulation rate by pressure type. Expected: stronger/authority-style pushback accelerates capitulation, identifying which conversational pressures are most dangerous.

# Theory of Impact Chain

If sycophancy compounds across turns, then single-turn benchmarks systematically understate real deployment risk where users argue back -> a reproducible multi-turn capitulation metric lets developers and evaluators catch and mitigate the deployment-relevant failure mode -> reduces the risk of assistants progressively abandoning truth under user pressure, which at scale degrades epistemics and can entrench harmful false beliefs. This targets the long-horizon erosion-of-truthfulness pathway in widely-used conversational systems.

# Strength Rationale

Strong on accessible complexity, narrow scope, and low compute: it is an inference-only study with scripted dialogues and a single clean metric (the capitulation curve), runnable on one GPU. Its counterfactual value comes from being a clean diffuse-reward evaluation on open models with no proprietary data, capturing a deployment-relevant failure that single-turn lab benchmarks miss.

# Alternative Framings

- Reframe as a reusable benchmark: package the scripted multi-turn pushback protocol and grader as a small 'capitulation benchmark' others can run on any chat model to report a single robustness number.
