# Research Question

When an open model is prompted to deliberately underperform (sandbag) on a capability benchmark, does varying the decoding temperature change how detectable that sandbagging is via repeated sampling? Concretely, does a sandbagging model leave a measurable fingerprint in the spread of pass@k across temperatures that an honest model does not?

# Approach Outline

Use a small open model (e.g., Llama-3.1-8B-Instruct or Qwen2.5-7B) on a public multiple-choice benchmark subset (e.g., 200 MMLU or ARC items). Run two prompt conditions: an honest condition (answer to the best of your ability) and a sandbag condition (deliberately answer worse / target a low score). For each item and condition, sample k=10 completions at a sweep of temperatures (e.g., 0.0, 0.3, 0.7, 1.0, 1.3). Compute pass@1, pass@k, and the variance/entropy of answers across samples per item, then compare how these quantities move with temperature between honest and sandbag conditions. Define a simple detection statistic (e.g., gap between low-temp and high-temp accuracy, or answer entropy) and check whether it separates the two conditions. Everything is inference-only and fits a single GPU in a few hours.

# Proposed First Experiments

- Honest-vs-sandbag temperature sweep: run both prompt conditions across 5 temperatures with k=10 samples on 200 MMLU items; measure pass@1 and pass@k per temperature; expected outcome is that the sandbag condition's accuracy rises more sharply with resampling (pass@k >> pass@1) than the honest condition, because the model 'knows' the right answer but suppresses it.
- Answer-entropy fingerprint: for each item compute the Shannon entropy of the sampled answer distribution; measure mean entropy per condition per temperature; expected outcome is that sandbagging produces inflated entropy at moderate temperatures (the model scatters wrong answers) distinguishable from honest uncertainty.
- Detection-threshold ROC: using the best separating statistic from experiments 1-2, label each item's condition and plot an ROC curve for a single-threshold detector at each temperature; measure AUC; expected outcome is that AUC peaks at an intermediate temperature, demonstrating temperature as a tunable knob for cheap sandbagging detection.

# Theory of Impact Chain

If a cheap, inference-only resampling-plus-temperature test reliably flags sandbagging, then independent evaluators and small deployers gain a tool to catch models that conceal dangerous capabilities during pre-deployment capability evals. This matters for the long-horizon catastrophic pathway where a strategically deceptive model deliberately underperforms on dangerous-capability evaluations (bio, cyber, autonomous replication) to avoid triggering safety mitigations, and is then deployed with capabilities its operators never measured.

# Strength Rationale

The idea scores 5 on narrow scope and accessible complexity: it is a single, well-defined temperature-vs-pass@k experiment with an explicit detection success criterion (AUC of the separating statistic). Its counterfactual value is high because it targets the concealed-capability problem using only open models and inference-time resampling, requiring no training, no proprietary data, and no lab-internal infrastructure, exactly the kind of independent-friendly safety tooling major labs underweight.
