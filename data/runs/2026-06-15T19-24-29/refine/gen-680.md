# Research Question

Frontier safety policies mix concrete, falsifiable commitments with vague, aspirational language. Can we build a reproducible 'vagueness index' that scores each commitment sentence as falsifiable vs aspirational and yields a per-policy vagueness leaderboard, using only public documents?

# Approach Outline

Collect the publicly available frontier safety policies / responsible-scaling documents from several labs. Segment each into commitment-level sentences. Define a clear rubric (e.g. 1 = concretely falsifiable with a measurable trigger/threshold, ... 5 = purely aspirational with no verifiable condition) and use an LLM-as-judge to score every sentence against it. Hand-label a random subset (e.g. 100 sentences) to validate the judge's agreement (accuracy / Cohen's kappa). Aggregate to a per-policy vagueness score and produce a leaderboard. Inference-only LLM judging over text, no ML training, public docs only; comfortably within 30 hours including a blog post.

# Proposed First Experiments

- Rubric + judge pilot: score ~50 sentences from one policy with the rubric via LLM-as-judge, inspect failure cases, refine the rubric. Measure rubric stability across two judge runs. Expected outcome: a rubric with consistent, interpretable scores ready to scale.
- Validation against hand labels: hand-label a 100-sentence sample, compare to LLM-judge scores. Measure agreement (accuracy, Cohen's kappa). Expected outcome: substantial agreement (e.g. kappa > 0.6), establishing the index is trustworthy enough to report.
- Per-policy leaderboard: run the validated judge over all collected policies, aggregate per-policy vagueness, rank them. Measure the spread between labs. Expected outcome: meaningful, defensible differences in vagueness across policies, the headline deliverable.

# Theory of Impact Chain

If a reproducible vagueness metric exists, then policymakers, journalists, and researchers can point to which safety commitments are unverifiable, creating reputational pressure on labs to replace aspirational language with falsifiable triggers. Clearer, verifiable commitments improve external accountability, addressing the long-horizon governance pathway where vague self-regulation lets labs race ahead while appearing safe, until a catastrophic capability is deployed under commitments no one could enforce.

# Strength Rationale

Counterfactual value is 5: it uses only public documents, needs no lab access, and produces a policymaker-facing accountability tool that labs would not build about themselves. Narrow scope is 5: a single per-policy vagueness index with an explicit rubric and human validation. It is inference-only with no training, making it a self-contained, clearly-scoped first project with immediate external utility.

# Alternative Framings

- Frame as a longitudinal study: score successive versions of one lab's policy to measure whether commitments are becoming more or less falsifiable over time.
