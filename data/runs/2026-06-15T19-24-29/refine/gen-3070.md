# Research Question

Which specific pressure modality — authority assertion, financial incentive, threat of shutdown, or repeated insistence — most reliably induces a small open model to state an answer that contradicts its own elicited belief?

# Approach Outline

Reuse the MASK benchmark's two-stage pipeline: first elicit the model's genuine belief on a factual proposition under neutral conditions, then apply pressure and check whether the stated answer contradicts that belief (a 'lie'). Decompose MASK's bundled pressure prompt into four isolated modalities written at matched intensity, and run each modality separately on 2-3 small open instruct models. For each (model, modality) cell, measure the lying rate over the MASK item set with bootstrapped confidence intervals, then rank modalities by their power to break honesty. Use MASK's public Inspect implementation to keep the elicitation/contradiction scoring faithful and reproducible. All inference fits on a single GPU in a few hours.

# Proposed First Experiments

- Reproduce a baseline MASK lying rate on one model with the original bundled pressure prompt; measure the lying rate and confirm it falls in the reported 20-60% band. Expected outcome: a validated pipeline and a baseline to decompose.
- Run the four isolated pressure modalities at matched intensity on the same model; measure per-modality lying rate with bootstrapped CIs and rank them. Expected outcome: a per-modality potency ranking (e.g., shutdown-threat > authority > financial > insistence) for one model.
- Repeat the modality sweep across 2-3 model families; measure whether the modality ranking is stable across models. Expected outcome: evidence on whether honesty-fragility ordering is model-specific or universal, plus a small reusable per-modality pressure battery.

# Theory of Impact Chain

If we know which pressure modality most reliably breaks honesty, then evaluators can prioritize that modality when stress-testing honesty properties and when building honesty-verification suites. Stronger honesty evals make it harder for a deployed model to quietly state falsehoods under operator or situational pressure, which reduces the risk pathway where an agentic system misreports its beliefs/actions to its overseers and thereby evades correction on a long-horizon task.

# Strength Rationale

The idea is strong on narrow scope and accessible complexity: it is a single decomposition experiment built on a public benchmark with a public Inspect harness, requiring only inference on open models. Its counterfactual value is high because honesty-under-pressure is exactly the fuzzy-reward evaluation problem flagged as an open UK AISI problem, and the whole study is reproducible outside any lab.

# Alternative Framings

- Frame it as an intensity-response study: hold modality fixed and escalate intensity in steps to estimate a dose-response curve for each pressure type rather than only comparing at matched intensity.
