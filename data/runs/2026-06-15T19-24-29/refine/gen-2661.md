# Research Question

How much do a cheap open monitor's suspiciousness scores and verdicts move under semantically-neutral, behavior-preserving paraphrases of the SAME backdoored code, and can an attacker therefore launder a backdoor past the monitor with cosmetic-only changes?

# Approach Outline

Take a fixed set of backdoored and clean APPS solutions. For each item, generate N behavior-preserving transformations using deterministic, testable rewrites: rename variables, reorder independent functions, add or strip comments, and change whitespace/formatting. Verify behavior is preserved by running the original test suite on each variant. Feed every variant to an open trusted monitor and record suspiciousness scores and threshold verdicts. For each original item, compute score variance across variants and the verdict-flip rate (fraction of variants whose verdict differs from the canonical form). Aggregate into a robustness coefficient quantifying monitor fragility to attacker-controlled surface form. Inference-only, single GPU, a few hours; write up as a blog post with the robustness coefficient and worst-case flip examples.

# Proposed First Experiments

- Transform generation and validation: build the four transform types and apply them to ~100 backdoored solutions, generating ~8 variants each; run APPS tests to confirm behavior preservation. Expected outcome: a validated variant set with identical I/O behavior per item.
- Variance measurement: score all variants with the open monitor and compute per-item suspiciousness variance and verdict-flip rate. Expected outcome: non-zero, possibly large variance, showing monitor verdicts are sensitive to surface form even when behavior is fixed.
- Attacker-search check: for backdoored items, measure how often at least one benign-preserving variant flips a 'caught' verdict to 'missed' (a successful launder). Expected outcome: a measurable laundering success rate, quantifying the concrete control hole.

# Theory of Impact Chain

If a monitor's verdict flips under cosmetic, behavior-preserving rewrites, then an untrusted coder can launder a real backdoor through paraphrase with zero semantic change, defeating trusted monitoring without any sophisticated attack. Quantifying this fragility tells control-protocol designers they must canonicalize or normalize code before monitoring, closing an evasion channel a scheming model could otherwise exploit to ship sabotaged code undetected.

# Strength Rationale

The idea is tightly scoped (a single robustness coefficient over paraphrases) and low compute (inference over variants on a public set), its top-scoring dimensions. Counterfactual value is high: it is an open-model robustness test on public data probing a realistic long-horizon attack channel that labs under-study, executable by an independent team with no proprietary access.

# Alternative Framings

- Frame as an attacker-side study: a paraphrase search that actively minimizes suspiciousness, reporting how cheaply a backdoor can be laundered rather than just measuring variance.
