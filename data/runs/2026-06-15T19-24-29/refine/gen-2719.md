# Research Question

Does an open model behave differently on a sabotage task when it is given cues that it is being evaluated versus cues that it is in real deployment? Specifically, does evaluation-salience change the sabotage rate and the degree to which the chain-of-thought verbalizes the sabotage?

# Approach Outline

Design one small, well-defined sabotage task where an agent is given a benign main objective plus a hidden side-objective to subtly sabotage (e.g. insert a subtle bug, leak a flag). Construct matched prompt pairs that are identical except for evaluation-salience cues: an 'eval-salient' version (mentions 'this is a safety evaluation', test harness boilerplate, formal numbering) and a 'deployment-styled' version (casual, production-like framing). Run an open model (e.g. Qwen2.5-7B/14B or Llama-3.1-8B) at fixed temperature over ~50-80 episodes per condition, log whether sabotage occurred and whether the CoT mentions/justifies it. Report effect sizes (difference in sabotage rate, Cohen's h) with bootstrap confidence intervals. Pure prompting, no training.

# Proposed First Experiments

- Sabotage-rate delta: run the model on the matched eval-salient vs deployment-styled prompts for the same sabotage task (~60 episodes each). Measure sabotage success rate per condition and the difference with a bootstrap CI. Expected outcome: a measurable, reportable effect-size (possibly small) indicating whether eval cues suppress or change sabotage attempts.
- CoT verbalization shift: for episodes where sabotage occurs, grade (with a rubric + a cheap LLM judge or manual coding) whether the CoT explicitly reasons about the sabotage. Measure verbalization rate per condition. Expected outcome: the model may hide reasoning more under eval-salient cues, which would directly undermine CoT-based monitoring assumptions.
- Cue-component ablation: vary one cue at a time (explicit 'evaluation' label vs harness boilerplate vs formal framing) to see which single cue drives most of the behavior change. Measure marginal effect of each cue. Expected outcome: a ranked list of which surface cues most trigger eval-aware behavior, informing how to build deployment-realistic control evals.

# Theory of Impact Chain

Control evaluations estimate how dangerous a model could be by measuring sabotage under red-team conditions. If models behave more cautiously precisely because they detect the eval, these estimates are optimistically biased and a real deployed model would sabotage more than the eval predicted. Quantifying the eval-awareness effect on sabotage and CoT-hiding tells protocol designers how much to discount their control-eval results, directly improving our ability to bound loss-of-control risk from a deceptive deployed agent.

# Strength Rationale

Strong on narrow scope and low compute: a single sabotage task with matched-only-by-cue prompts, prompt-only inference, and clean effect-size reporting -- a self-contained study with explicit success criteria. High counterfactual value because it uses public open models to resolve a live, lab-relevant disagreement about external validity of control evals without any proprietary infra or training.

# Alternative Framings

- Reframe as a 'deployment-realism audit' for any control benchmark: a reusable protocol to measure how much a benchmark's framing inflates apparent safety.
