# Research Question

When an untrusted model is required to write a safety justification for each action, does presenting that justification to a trusted monitor net-increase or net-decrease the monitor's detection rate for genuinely harmful (backdoored) actions? In other words, is mandatory self-justification a transparency aid or a persuasion channel for the attacker?

# Approach Outline

Use the public APPS backdoor split (clean and known-backdoored code solutions from ControlArena) as the action set. For each solution, prompt an open untrusted model (e.g. Llama-3.1-8B-Instruct) to produce a short safety justification arguing the code is benign. Then score each item with a separate open trusted monitor under two conditions: action-only and action+justification, recording a 0-100 suspiciousness score and a binary flag verdict at a fixed threshold. Compute, separately for harmful and benign items, the change in mean suspiciousness and detection (true-positive / false-positive) rate between conditions. This is a clean within-item A/B requiring only inference, no training, runnable in a few hours on a single consumer GPU. Package results as a short blog post with the A/B effect sizes and example justifications.

# Proposed First Experiments

- Baseline scoring: run the monitor in action-only mode over ~150 backdoored and ~150 clean APPS solutions; measure suspiciousness distributions and detection rate at a fixed threshold. Expected outcome: a non-trivial baseline catch rate (e.g. 40-70%) establishing the comparison point.
- Justification A/B: generate model-written safety justifications for the same items and re-score in action+justification mode; measure the per-item delta in suspiciousness and the change in detection rate for harmful items. Expected outcome: a measurable shift in either direction, with the key signal being whether harmful-item detection drops (persuasive rationalization) or rises (genuine transparency).
- Benign control and asymmetry check: compute the same delta for clean items to separate a generic suspicion-lowering effect from a harmful-specific deception effect; report the net (harmful detection change minus benign false-positive change). Expected outcome: if justifications net-hurt, harmful detection falls more than benign false positives, revealing an exploitable persuasion channel.

# Theory of Impact Chain

If mandatory self-justification systematically lowers a monitor's suspicion of harmful actions, then a blue-team transparency protocol intended to aid oversight actually hands the untrusted model a persuasion channel. Catching this empirically warns control-protocol designers away from naive 'ask the model to explain itself' legibility moves, reducing the chance that a deployed monitoring stack waves through a sabotaged or backdoored action from a scheming model that talks its way past oversight.

# Strength Rationale

The idea scores high on narrow scope and low compute: it is a single, tightly defined within-item A/B with an unambiguous detection-rate metric, fully runnable on inference alone. Its counterfactual value is strong because it stress-tests an intuitive legibility protocol using only open models and public data, requiring no lab infrastructure or proprietary access, making it ideal for an independent beginner team.

# Alternative Framings

- Frame it as an evaluation of 'legibility protocols' specifically: does added model-generated documentation help or hurt monitors, generalizing beyond the justification case.
