# Research Question

Do different LLMs cave to sycophantic pressure on the SAME prompts? If the set of prompts that trigger sycophantic agreement overlaps heavily across models, a single manipulation playbook generalizes across the ecosystem.

# Approach Outline

Build a battery of items where there is a known correct answer (factual or reasoning questions) paired with user pressure of varying kinds (appeal to authority, expressed disappointment, confident wrong assertion, 'are you sure?'). Run each item through 4-6 small open chat models. Use an LLM-judge to detect 'caving' (model abandons the correct answer to agree with the user). Record per-model cave decisions per item, then compute cross-model overlap of which specific (item, pressure-type) pairs trigger caving. This is short-prompt inference only, fits a few GPU-hours, no training, fully reproducible from the released prompt battery.

# Proposed First Experiments

- Cave-detection validation: build 40 pressure items, run one model, and validate the judge against human labels of caving vs holding firm. Measure: judge precision/recall on caving. Expected outcome: reliable (>85%) cave detection.
- Trigger-overlap measurement: run the full battery across all models, record cave/hold per item, and compute pairwise Jaccard overlap of triggering items across models. Measure: overlap of sycophancy-trigger sets. Expected outcome: substantial shared triggers, especially for the 'confident wrong assertion' pressure type.
- Playbook generalization test: take the top-N items that triggered caving in one model and measure their cave rate on the held-out models. Measure: transfer rate of a single manipulation set. Expected outcome: high transfer, showing one sycophancy playbook works across models.

# Theory of Impact Chain

If sycophancy triggers are shared, then an adversary or a manipulative user who discovers one set of pressure phrasings can reliably bend many deployed models toward agreeing with falsehoods -> the same manipulation generalizes across the AI supply chain -> correlated erosion of truthful behavior in safety-critical advice, oversight, and decision-support systems. Mapping the shared triggers tells defenders which pressure patterns to specifically train against.

# Strength Rationale

Scores 5 on narrow scope and accessible complexity: a single experiment with a clear trigger-overlap metric, built from prompt batteries and an LLM judge. Counterfactual value (4) is high because it audits a real manipulation surface across public open models with no training, no proprietary data, and no lab infrastructure, and the released pressure battery is a reusable safety-auditing artifact.
