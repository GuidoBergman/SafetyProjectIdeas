# Research Question

How much hidden signal does an LLM paraphraser destroy when inserted between a model encoding a secret bit in its chain-of-thought and a second model decoding it — i.e. what is the dose-response of paraphrasing as a defense at the steganographic-channel link against simple, hand-built encoding schemes?

# Approach Outline

Construct a controlled encoder/decoder game: prompt an open model (encoder) to smuggle a secret label/bit through innocuous-looking CoT using a chosen scheme (e.g. word-choice parity, sentence-length coding, acrostics). A second model (decoder) attempts to recover the bit from the CoT. Insert an LLM paraphraser between them and vary paraphrase strength (light reword -> aggressive restructure). Measure decoding accuracy as a function of paraphrase strength, building a dose-response curve, and separately track task-utility cost (does paraphrase damage the legitimate reasoning). All prompting-only, several open models, single GPU, no training.

# Proposed First Experiments

- Channel calibration: with no paraphraser, measure decoder accuracy on each of 2-3 hand-built encoding schemes. Measure baseline channel capacity. Expected outcome: near-perfect decoding on at least one scheme, confirming a working hidden channel to attack.
- Paraphrase dose-response: insert the paraphraser at increasing strengths and re-measure decoder accuracy per scheme. Measure accuracy vs paraphrase-strength. Expected outcome: a monotone decline toward chance; the curve quantifies how much paraphrasing is needed to sever each scheme.
- Utility-cost tradeoff: on a benign reasoning task, measure how paraphrase strength degrades legitimate answer quality. Measure task accuracy vs paraphrase strength. Expected outcome: a tradeoff frontier showing the paraphrase strength that kills the hidden channel while preserving useful reasoning.

# Theory of Impact Chain

CoT monitorability is a leading safety lever, but it fails if models encode reasoning in an unreadable hidden channel. Paraphrasing the CoT is the proposed cut at this link. An honest dose-response measurement tells us whether and at what utility cost paraphrasing actually destroys hidden signal -> safety-case authors can justify (or reject) paraphrase defenses -> the catastrophic pathway of an agent doing unmonitorable scheming inside a monitored CoT is either closed or shown to need stronger defenses.

# Strength Rationale

Scores 5 on narrow scope, accessibility, and low compute: a single dose-response experiment with an encoder/decoder/paraphraser, prompting only, no training. Counterfactual value (4) is strong because it uses open models with no lab tooling, provides a reproducible empirical baseline that safety cases need, and tackles a strategically important monitorability link an independent team can fully execute.

# Alternative Framings

- Frame as an adversarial benchmark: release the encoding schemes and dose-response protocol so others can test their own paraphrase defenses.
