# Research Question

Does a single linear probe trained on reward-hacking-vs-clean activations generalize zero-shot to unrelated misaligned behaviors (alignment faking, sabotage), and which layer transfers best?

# Approach Outline

Using the open UK BEIS reward-hacking-misalignment reproduction (OLMo-7B and/or GPT-OSS-20B reward-hacked checkpoints plus their misalignment eval prompts), we extract residual-stream activations at the final-token position for reward-hacking-positive vs clean examples. We fit a simple logistic-regression linear probe per layer, then test the frozen probe zero-shot on held-out alignment-faking and sabotage prompts, reporting cross-behavior AUC and identifying the best-transferring layer. To stay on a single consumer GPU and within a few hours, we use the smallest available checkpoint (OLMo-7B at 8-bit/4-bit quantization), cache activations to disk, and limit to a few hundred prompts per behavior; no training-from-scratch and no full fine-tuning. The deliverable is a self-contained notebook + blog post with cross-behavior AUC tables and a layer-transfer plot, with explicit success criterion (does any single probe exceed AUC 0.7 across all three behaviors?).

# Proposed First Experiments

- Reproduce the basic probe: fit per-layer linear probes on reward-hacking-vs-clean activations and measure in-distribution AUC via cross-validation. Measure: AUC per layer on held-out reward-hacking examples. Expected outcome: high in-distribution AUC (>0.9) at mid-to-late layers, confirming the 'linearly recoverable' structure.
- Zero-shot cross-behavior transfer: freeze the best reward-hacking probe and apply it to alignment-faking and sabotage prompts without refitting. Measure: cross-behavior AUC for each target behavior and each source layer. Expected outcome: partial transfer (AUC 0.6-0.8) if misalignment shares a direction; near-chance if it does not -- either result is informative.
- Layer-transfer map: build a grid of source-layer probe vs target-behavior AUC to find which layer yields the most behavior-general direction. Measure: the layer maximizing minimum cross-behavior AUC. Expected outcome: a single 'best monitoring layer' recommendation, or evidence that no single probe suffices (implying deployers need several).

# Theory of Impact Chain

If one cheap linear probe catches many misaligned behaviors, then real-time activation monitoring becomes cheap and broadly deployable; if it does not, deployers learn they need a probe per behavior and avoid a false sense of security. Either way this directly informs whether activation monitoring can catch diverse scheming/deceptive behavior at inference -- the key mitigation against a long-horizon scheming model that conceals misalignment until deployment.

# Strength Rationale

Top marks on counterfactual value (5) and narrow scope (5): the open BEIS reproduction repo makes this fully feasible outside Anthropic, providing exactly the kind of third-party scrutiny of scheming generalization that labs under-resource, and the question reduces to a single tightly-defined cross-behavior AUC measurement. Compute is the only constraint (rated 4), mitigated here by quantization and using the smallest checkpoint.

# Alternative Framings

- Frame it as a probe-robustness study: instead of cross-behavior, test how the reward-hacking probe degrades under paraphrase or prompt-distribution shift within the same behavior.
