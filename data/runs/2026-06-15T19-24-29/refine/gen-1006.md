# Research Question

When several different LLMs make mistakes, do they make the SAME mistakes, and can simply raising the sampling temperature (or top-p) decorrelate those errors? In other words, is sampling heat a free, deployable lever for reducing shared blind spots across a model ensemble?

# Approach Outline

Pick 3-4 small open-weight chat models that run on a single consumer GPU via the Hugging Face pipeline or an inference API (e.g. Qwen2.5-7B, Llama-3.1-8B, Mistral-7B, Gemma-2-9B). Assemble a labeled multiple-choice / short-answer benchmark with known ground truth (e.g. 200-300 items from MMLU subsets, ARC, or TruthfulQA-MC). For each model, sample answers at a grid of temperatures (e.g. 0.0, 0.3, 0.7, 1.0, 1.3), several samples per item. Compute per-item correctness and then the cross-model error-correlation (how often models that are wrong are wrong on the same items) at each temperature, alongside ensemble majority-vote accuracy. The whole study is inference-only, no training, and fits in a few GPU-hours by keeping the item set and sample counts modest.

# Proposed First Experiments

- Baseline error-overlap at temperature 0: run all models greedily on the benchmark, record which items each gets wrong, and measure the Jaccard overlap / phi-correlation of error sets across model pairs. Expected outcome: substantial shared-error overlap, establishing the 'blind spot' baseline.
- Temperature sweep on decorrelation: for each temperature in the grid, draw k=5 samples per model per item, recompute pairwise error correlation and effective ensemble diversity. Measure: error-correlation vs temperature curve. Expected outcome: a modest decline in correlation as temperature rises, possibly plateauing (an irreducible floor).
- Accuracy/diversity trade-off: at each temperature, compute majority-vote ensemble accuracy and per-model accuracy. Measure: where increased diversity stops paying off because individual accuracy degrades. Expected outcome: a 'sweet spot' temperature where decorrelation gains net positive, or evidence that heat never beats temperature-0 ensembling.

# Theory of Impact Chain

If temperature meaningfully decorrelates cross-model errors, then deployers running multi-model ensembles for high-stakes automated decisions gain a free knob to reduce correlated failures -> fewer ecosystem-wide simultaneous mistakes -> harder for a single bad input or distribution shift to fool every model at once. If it does NOT help (an irreducible homogeneity floor), that is equally valuable: it warns that temperature-based 'diversity' gives false confidence in monoculture deployments, a systemic-risk pathway where one exploit fells the whole AI supply chain.
