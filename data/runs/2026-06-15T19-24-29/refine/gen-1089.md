# Research Question

When a panel of open LLM judges scores response pairs against a real human-annotation distribution, are the judges' deviations from human preference correlated with each other? If so, judge ensembling provides only illusory robustness because all judges share the same bias.

# Approach Outline

Use the Infinity-Chat dataset (arXiv:2510.22954), which ships ~25 human annotations per item, to define a human-preference ground-truth distribution for response pairs. Select 5-8 open judge models (small instruct models prompted as pairwise judges). Have each judge score the same response pairs, then compute each judge's deviation from the human-preference distribution per item. The core analysis is the inter-judge correlation of these deviations: do judges err in the SAME direction on the SAME items? Compare the correlated-error structure to an independence baseline, and check whether majority-vote across judges actually reduces deviation from humans or just reproduces the shared bias. All steps are inference plus correlation statistics, easily within a few GPU-hours. Deliver the judge-correlation finding as a blog post.

# Theory of Impact Chain

If LLM judges share correlated biases relative to humans, then eval pipelines and RLAIF that depend on judge panels are systematically skewed in a direction no amount of judge-ensembling fixes -> model development field-wide optimizes toward a shared blind spot baked into automated oversight -> this reduces the risk that scalable-oversight schemes (which lean heavily on LLM judges) silently certify unsafe behavior because every judge is fooled the same way, a concrete failure pathway for automated AI oversight.
