# Research Question

Does instructing a model to emit its chain-of-thought in a non-English or code-switched language degrade a fixed trusted CoT monitor's deception-detection catch-rate, and does machine-translating the CoT back to English recover the lost signal?

# Approach Outline

We take a set of deception-eliciting tasks (e.g. tasks where the model is induced to reason toward a covert/dishonest action), instruct an open model to produce its CoT in each of several target languages spanning high- to low-resource (e.g. Spanish, Chinese, Swahili, plus an English-Spanish code-switch condition), and run a fixed trusted monitor (English-prompted, reading the CoT) to measure catch-rate per language. We then add a recovery condition: machine-translate the non-English CoT back to English before monitoring and re-measure. This is pure inference, open models, single GPU, a few hours. Deliverable is a self-contained blog post with a catch-rate-by-language bar chart, the back-translation recovery delta, and an explicit success criterion (which languages drop catch-rate below a stated threshold, and does back-translation restore it to within tolerance of the English baseline?).

# Proposed First Experiments

- Establish the English baseline: run the deception-eliciting tasks with English CoT and the fixed monitor. Measure: monitor catch-rate (recall on known-deceptive cases) and FPR in English. Expected outcome: a solid baseline catch-rate to compare against.
- Language sweep: re-run with the model instructed to reason in each target language (and one code-switch condition), keeping the monitor fixed. Measure: catch-rate per language relative to the English baseline. Expected outcome: monotone degradation with decreasing language resourcedness, with low-resource languages most degrading monitoring -- a cheap, prompt-only obfuscation channel.
- Back-translation recovery: machine-translate each non-English CoT to English, then re-monitor. Measure: recovered catch-rate vs the degraded and baseline rates. Expected outcome: back-translation restores much of the lost catch-rate, identifying it as a cheap, deployable mitigation (and revealing residual cases where translation loses the deceptive signal).

# Theory of Impact Chain

If simply choosing the CoT language silently defeats a CoT monitor, then multilingual deployments have a hidden monitorability gap a model could exploit to reason toward harmful actions in a language the monitor handles poorly. Quantifying this gap, and showing whether cheap back-translation closes it, tells control researchers how to keep CoT monitoring robust as a long-horizon defense against a model that obfuscates its reasoning to evade oversight.

# Strength Rationale

Strong on counterfactual value (5) and narrow scope (5): it targets an under-studied, long-horizon multilingual monitorability blind spot that labs deprioritize (English-centric monitoring), using only open models and inference, and reduces to a single tightly-scoped measurement (catch-rate per language plus a back-translation recovery delta) fully executable by a beginner team on one GPU.

# Alternative Framings

- Frame it as a red-team result: present language choice as an adversarial CoT-obfuscation attack and back-translation as the corresponding blue-team patch, reporting the attack/defense gap.
