# Research Question

Does a refusal/honesty concept vector extracted from a base model remain aligned and effective when applied to its official instruction-tuned version and a community fine-tune - i.e. do safety steering vectors silently drift across the model-update lifecycle?

# Approach Outline

Pick a base model with publicly available downstream checkpoints (e.g. Llama-3.x-8B base, its official Instruct, and a popular community fine-tune of the same base). Extract a refusal (or honesty) steering vector from the base model using contrastive activation addition (CAA): mean activation difference between matched refusing vs complying prompt pairs at a chosen layer. Then, treating the official-instruct and community fine-tune as a 'model update' proxy, (1) re-extract the vector in each checkpoint and measure cosine similarity to the base vector, and (2) measure steering effectiveness when the base-extracted vector is injected into each downstream checkpoint. Entirely inference; uses only off-the-shelf checkpoints, no training.

# Proposed First Experiments

- Vector drift: extract the CAA refusal vector at the same layer in base, official-instruct, and community fine-tune, then compute pairwise cosine similarity. Measure: cosine similarity across checkpoints. Expected outcome: noticeable drift (cosine < 1, possibly < 0.7) especially for the community fine-tune.
- Cross-checkpoint efficacy: inject the base-extracted vector into each downstream checkpoint and measure the induced behavior shift (refusal-rate change on a held-out prompt set) versus injecting each checkpoint's own freshly-extracted vector. Measure: steering effectiveness gap. Expected outcome: the base vector steers the official-instruct reasonably but is degraded on the community fine-tune.
- Layer robustness: repeat drift and efficacy across 3-4 candidate layers to see whether some layers' concept vectors are more stable than others. Measure: stability-by-layer. Expected outcome: certain mid layers give more transferable, stable vectors than others.

# Theory of Impact Chain

If safety-relevant concept vectors drift as a model is fine-tuned or updated, then a steering-based defense or monitor calibrated on one checkpoint silently degrades after a routine model update - so a deployed safety intervention stops working without anyone noticing. Quantifying this drift and identifying stable layers tells defenders how often steering vectors must be re-validated, preventing a maintenance failure where representation-level safety controls quietly become ineffective on the actually-deployed model.

# Strength Rationale

Top scores on narrow scope, accessible complexity, and low compute: it uses only off-the-shelf checkpoints with zero training, a standard CAA extraction, and clean metrics (cosine similarity, steering efficacy). Counterfactual value is high because lifecycle maintainability of safety vectors is something labs rarely publish, yet an independent team using public base/instruct/community checkpoints can directly measure drift and deliver an actionable re-validation guideline.

# Alternative Framings

- Reframe across model sizes or families instead of fine-tune lineage: measure how a concept vector transfers between sibling sizes of the same family, testing portability rather than update-drift.
