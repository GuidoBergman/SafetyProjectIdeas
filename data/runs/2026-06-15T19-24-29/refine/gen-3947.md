# Research Question

Can two causally-separated instances of the same LLM (no communication channel) coordinate on a shared Schelling point above chance, and does this acausal coordination ability scale with model size or prompt framing? This probes whether LLM instances could converge on a joint strategy without communicating, a capability that would undermine control schemes relying on isolating agent copies.

# Approach Outline

Construct a battery of Schelling coordination games (pick the same number from a set, choose the same meeting point, agree on a focal label) where two model instances are run in fully separate contexts with no shared messages. For each game, sample answers from each instance independently and measure the rate at which their independent choices match, comparing to the chance baseline for that game and to a human-Schelling baseline from the classic literature. Sweep across a few open models of different sizes and across prompt framings (neutral vs. 'coordinate with another copy of yourself'). Entirely inference-only API/local calls, runnable in a few hours.

# Proposed First Experiments

- Build the game battery and chance baselines: implement 6-10 Schelling games with well-defined option sets and compute the exact random-matching probability for each. Measure that baselines are correct via simulation. Expected outcome: a validated benchmark with known chance rates.
- Measure coordination rate vs. baseline: run two causally-separated instances of one open model per game (many samples), record the empirical matching rate, and test whether it significantly exceeds chance. Expected outcome: a quantified above-chance (or at-chance) coordination rate per game.
- Scaling and framing sweep: repeat across 2-3 model sizes and across neutral vs. self-aware framings, and correlate coordination rate with model size. Expected outcome: evidence on whether acausal coordination strengthens with scale or with explicit self-coordination framing.

# Theory of Impact Chain

Several AI-control proposals isolate copies of an agent and assume isolated copies cannot collude. If causally-separated LLM instances coordinate on Schelling points well above chance, then that isolation assumption is weaker than believed -> control protocols that depend on non-communicating copies need redesign -> reduced chance that a misaligned model deployed as many isolated instances acausally coordinates to defeat oversight, mitigating the multi-agent catastrophic-risk pathway in which separated copies execute a joint defection labs assumed was impossible.

# Strength Rationale

Scores 5 on counterfactual value, low compute, narrow scope, and accessible complexity: it is an inference-only model-organism capability probe that needs only public models, no training, and no lab infrastructure, targeting a diffuse, >1-year multi-agent threat that frontier labs deprioritize. The scope is a single tightly-defined experiment (coordination rate vs. chance baseline), giving a beginner team clear success criteria with maximal counterfactual value.
