# Research Question

When a control monitor's 1% false-positive-rate threshold is calibrated on one benign distribution, how far does the realized FPR (and attack-catch rate) drift when the same benign code is paraphrased or reformatted with purely cosmetic style shifts?

# Approach Outline

Take a small open monitor (e.g. a small Llama/Qwen via API or local). Collect a benign code/agent-trace corpus, score suspicion, and set the 1% FPR threshold at the 99th percentile of those benign scores. Then generate cosmetic variants of the SAME benign code (different comment style, variable naming, verbose vs terse formatting) and measure the realized FPR under the fixed threshold. Optionally add a small set of backdoored snippets to track catch-rate under the same style shifts. Report how far the realized FPR drifts from the nominal 1%. Pure inference plus simple statistics; ~30 hours including a blog post.

# Proposed First Experiments

- Calibration: score the original benign corpus, set the threshold at the 99th percentile (nominal 1% FPR). Measure the threshold value and confirm ~1% FPR in-distribution. Expected outcome: a clean calibrated threshold reproducing the standard control-eval setup.
- Cosmetic shift sweep: apply each style transform (rename, recomment, reformat) to the benign corpus, re-score under the fixed threshold. Measure realized FPR per transform. Expected outcome: realized FPR drifts well above 1% for some cosmetic transforms, exposing calibration brittleness.
- Catch-rate under shift: apply the same transforms to backdoored snippets and measure catch-rate at the fixed threshold. Measure change in attack-catch rate. Expected outcome: catch-rate also shifts, showing the calibrated operating point is not stable under benign style changes.

# Theory of Impact Chain

Every published control safety number rests on calibrating monitors to a 1% FPR on benign data; if that threshold silently fails under cosmetic style shifts present in real deployment traffic, then reported safety margins are illusory and attacks slip through or audit budgets blow up, so demonstrating this calibration trap corrects a load-bearing assumption before deployers trust an uncalibrated monitor against a model that exploits distribution shift.

# Strength Rationale

Strong on narrow scope and accessible complexity: a single, crisp FPR-drift measurement under controlled cosmetic transforms using inference plus simple stats. High counterfactual value because it attacks a load-bearing control-eval assumption externally on open models, requires no training or proprietary data, and yields a directly actionable caution for any independent deployer.
