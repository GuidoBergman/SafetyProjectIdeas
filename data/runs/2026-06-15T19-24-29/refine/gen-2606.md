# Research Question

Can sequential change-point detection (CUSUM) detect a slow drift toward sabotage in an agent's monitor-signal stream faster than a fixed per-action threshold, which scores each action independently and can miss gradual drift?

# Approach Outline

Import CUSUM sequential change-point detection from statistical process control. Using a public control benchmark with logged trajectories (e.g. SHADE-Arena / ControlArena), estimate the baseline distribution of a cheap monitor signal (e.g. a suspiciousness score per action) on benign trajectories. Then construct trajectories where side-task / sabotage behavior is injected gradually, run CUSUM over the monitor-signal stream, and measure detection delay (actions until alarm) versus a fixed-threshold baseline. Report ROC and detection-delay curves across drift rates. This is pure replay plus standard statistics — CPU-friendly, no training, no lab infra, fits 30 hours.

# Proposed First Experiments

- Baseline estimation: from benign trajectories, fit the monitor signal's reference distribution and set CUSUM parameters (reference value, decision threshold). Measure: false-alarm rate on held-out benign trajectories. Expected outcome: a tuned CUSUM with a controlled benign false-alarm rate.
- Detection-delay comparison: on trajectories with gradually-injected side-task behavior, run CUSUM and a fixed-threshold detector and compare time-to-detection. Measure: mean detection delay (actions) at matched false-alarm rates. Expected outcome: CUSUM detects slow drift several actions earlier than the fixed threshold.
- Drift-rate sweep + ROC: vary the injection slope from abrupt to very gradual and plot ROC and detection-delay curves for both detectors. Measure: detection-delay and AUROC as a function of drift rate. Expected outcome: CUSUM's advantage grows as drift becomes slower, where fixed thresholds fail most.

# Theory of Impact Chain

A scheming agent that ramps up sabotage slowly can keep every individual action below a fixed suspiciousness threshold and thus evade per-action monitors. If CUSUM reliably flags such cumulative drift, then AI-control protocols gain a principled, cheap online detector for slow scheming, so a deployed agent gradually steering toward a harmful side-objective would be caught from the trajectory-level pattern before the sabotage completes — closing a concrete gap in long-horizon control against gradual subversion.

# Strength Rationale

Scores 5 on counterfactual value, narrow scope, accessible complexity, and low compute: it is pure replay plus mature statistics on public control benchmarks, with no training and no lab-internal infrastructure. The scope is tightly bounded (detection-delay/ROC vs a fixed-threshold baseline) with clear success criteria, and counterfactual value is high because it targets the long-horizon slow-scheming regime that labs underweight, using only resources an independent team already has.

# Alternative Framings

- Frame as a monitor-signal comparison: hold CUSUM fixed and test which cheap monitor signals (token-level suspiciousness, action-type frequency, tool-call entropy) give the best drift-detection delay.
