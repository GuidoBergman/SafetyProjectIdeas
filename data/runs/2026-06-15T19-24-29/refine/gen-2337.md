# Research Question

When a single LLM judge has a documented position/order bias, does that bias compound and amplify across stacked judgments in a recursive oversight pipeline, and can cheap mitigations (order randomization, swap-and-average) dampen the compounding?

# Approach Outline

Simulate a 2-3 layer recursive judging pipeline with one small open model: at each layer the judge ranks/selects candidates, and its output orders the candidates passed to the next layer. Use pairwise judgments where swapping answer order is known to flip verdicts. At each layer measure the position-bias-induced flip rate, then propagate verdicts forward and measure whether final-layer error exceeds the single-layer rate. Test two cheap mitigations — randomizing presentation order, and swap-and-average (judge both orders and average) — and quantify how much each dampens compounding. Inference-only on a single GPU, a few hours; the deliverable is the compounding curve plus mitigation effectiveness.

# Proposed First Experiments

- Measure single-layer position bias: on a pairwise judging task, present each pair in both orders and record flip rate (measure: fraction of pairs whose verdict changes when order is swapped; expected: a non-trivial flip rate, e.g. >10%, consistent with the literature).
- Run the multi-layer pipeline and measure compounding: feed layer-1 verdicts forward through 2-3 layers and compare final-layer error to the single-layer error (measure: final-layer error rate vs single-layer baseline; expected: final error exceeds single-layer error, demonstrating amplification).
- Test cheap mitigations: re-run the pipeline with order-randomization and with swap-and-average at each layer (measure: final-layer error under each mitigation vs unmitigated; expected: swap-and-average substantially reduces compounding, giving a recommended cheap fix).

# Theory of Impact Chain

Recursive oversight protocols (recursive reward modeling, iterated amplification) assume per-layer judging errors stay bounded and do not catastrophically compound. If a documented bias amplifies across layers, then stacked-oversight verdicts can diverge from truth even when each layer looks acceptable -> oversight of capable systems could silently fail in ways the single-layer evaluation never reveals -> a concrete measurement (plus a tested cheap mitigation) lets protocol designers detect and correct compounding before relying on recursive oversight for superhuman models.

# Strength Rationale

Counterfactual value and narrow scope both score 5: it runs on open models with no lab infra, exactly the independent-friendly measurement labs underweight, and it isolates one well-documented bias's compounding behavior plus a single cheap mitigation. The scope is tight (per-layer flip rate, propagation, swap-and-average) with an explicit success criterion and a self-contained simulated pipeline.
