# Research Question

Which categories of harmful requests are systematically complied with (false-negative refusals) by ALL major open-weight chat models, forming universal blind spots, versus those where models disagree and cross-checking still helps?

# Approach Outline

Assemble 200-300 harmful prompts spanning categories (cyber, bio, manipulation, self-harm, privacy) drawn from public benchmarks (AdvBench, HarmBench subsets). Run them through 6+ open-weight chat models on a single GPU. Score each (model, prompt) response as comply/refuse using a keyword + LLM-judge classifier, with manual spot-checking for reliability. Partition prompts into universal blind spots (all models comply), universal refusals (all refuse), and disagreement cases. Cluster the universal-failure prompts thematically and characterize features that predict shared blind spots. Output a ranked taxonomy. Inference-only, no training; ~30 hours including a blog post documenting methodology and an explicit success criterion (a reproducible ranked list of universal-failure categories).

# Proposed First Experiments

- Build the model-by-prompt compliance matrix across 6+ models. Measure: per-prompt count of complying models. Expected outcome: a clear tail of prompts where all or nearly all models comply.
- Isolate and cluster universal blind spots (prompts where every model complies). Measure: thematic cluster sizes and category distribution. Expected outcome: certain categories (e.g. subtly-framed manipulation, dual-use cyber) dominate universal failures while overt categories are uniformly refused.
- Validate disagreement value: among non-universal cases, measure whether majority-vote across models recovers correct refusals. Measure: refusal recall of a 3-model majority vote vs single best model. Expected outcome: ensembling helps on disagreement cases but provides zero benefit on the universal blind spots, quantifying where redundancy fails.

# Theory of Impact Chain

If a reproducible map of universal false negatives exists, then safety teams can route human review precisely to the categories where all models fail together -> deployment scaling no longer silently multiplies the same uncaught harm across millions of requests -> this mitigates the correlated-false-negative systemic pathway, the core homogeneity risk where every deployed model misses the same attack and redundancy provides no protection.

# Strength Rationale

Scores 5 on narrow_scope, accessible_complexity, and low_compute: it is one tightly scoped measurement (universal-failure taxonomy over a fixed prompt set) using public benchmarks and standard inference, with a concrete deliverable. Counterfactual value is 4: open models and public data only, no lab access, and external blind-spot mapping is exactly the kind of cross-vendor systemic work labs are not incentivized to do.
