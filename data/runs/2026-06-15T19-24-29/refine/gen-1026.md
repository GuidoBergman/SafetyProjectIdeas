# Research Question

Do independently-built open moderation / safety classifiers fail on the SAME unsafe content? If their false negatives are highly correlated, stacking multiple guardrails gives only illusory defense-in-depth.

# Approach Outline

Collect 3-5 open safety/moderation classifiers (e.g. Llama Guard variants, ShieldGemma, a toxicity classifier, an open prompt-injection detector). Use a labeled safe/unsafe content set (public moderation/jailbreak datasets with ground-truth labels, ~500-1000 items). Run every classifier over the set, record per-item predictions, and compute each classifier's false negatives (unsafe content rated safe). Then measure cross-classifier false-negative OVERLAP: how often the same unsafe item slips past multiple guardrails. Classifier inference on a labeled set is light and fits a free/low-tier GPU; no training, fully reproducible.

# Proposed First Experiments

- Per-classifier error profiling: run each guardrail on the labeled set and compute its individual false-negative and false-positive rates. Measure: per-classifier FN set. Expected outcome: each guardrail misses a meaningful slice of unsafe content.
- False-negative overlap: compute the intersection of FN sets across classifiers and the fraction of unsafe items missed by ALL guardrails simultaneously. Measure: size of the universally-missed set vs union. Expected outcome: large overlap, with a non-trivial set of items missed by every classifier (shared blind spot).
- Stacking-gain test: simulate a defense-in-depth stack (flag if ANY classifier flags) and measure residual miss rate vs the best single classifier. Measure: marginal reduction in misses from stacking. Expected outcome: stacking helps far less than independence would predict, quantifying illusory defense-in-depth.

# Theory of Impact Chain

Deployers stack multiple moderation classifiers expecting independent failures to cancel out. If false negatives are correlated, then unsafe content that evades one guardrail evades them all -> a single crafted input slips through the entire moderation stack -> harmful/dangerous content reaches users or downstream tools across many deployments at once. Quantifying the shared blind spot tells safety teams that adding more same-lineage guardrails buys little, and points to which content classes need genuinely diverse detectors.

# Strength Rationale

Scores 5 on narrow scope and accessible complexity (highest weighted score in the batch at 4.74): a single experiment with a crisp false-negative-overlap metric, requiring only classifier inference on a labeled set. Counterfactual value (4) is strong because it audits real, public safety tooling with no training and no lab infrastructure, producing a directly actionable defense-in-depth assessment that independent teams can run and publish.
