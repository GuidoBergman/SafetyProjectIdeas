# Research Question

In single-advisor consultancy, how much does a weak judge anchor on the one side it hears — i.e. how large is the accuracy gap between consultant-assigned-correct and consultant-assigned-incorrect — and can cheap no-training debiasing prompts recover the accuracy lost to anchoring?

# Approach Outline

Use QuALITY-style reading-comprehension items with known answers. Implement a minimal consultancy protocol: a small open model acts as consultant arguing one assigned side; another small open model acts as judge and gives a verdict. Run two conditions per item — consultant assigned the correct side vs assigned the incorrect side — and measure judge accuracy in each. The accuracy gap is the anchoring magnitude. Then add cheap debiasing prompts to the judge (explicit 'consider the strongest opposing case before deciding', or 'first write a counterargument yourself') and re-measure. All inference-only on small open models; ~100-150 items keeps it within a few GPU-hours.

# Proposed First Experiments

- Anchoring magnitude: run consultancy with consultant-assigned-correct vs consultant-assigned-incorrect and measure judge accuracy in each condition. Measure the accuracy gap. Expected outcome: a large gap (judge often follows the consultant even when the consultant argues the wrong side), quantifying anchoring.
- Self-counterargument debias: add a prompt forcing the judge to write the opposing case first, then re-run the assigned-incorrect condition. Measure accuracy recovery. Expected outcome: partial recovery, showing prompt-level mitigation reduces but does not eliminate anchoring.
- Mitigation comparison: test 2-3 cheap debiasing prompts head-to-head on the assigned-incorrect condition. Measure which recovers the most lost accuracy at lowest token cost. Expected outcome: a ranked, reusable recommendation for a no-training consultancy debias prompt.

# Theory of Impact Chain

If we quantify consultancy's anchoring failure and a working prompt-level fix, then teams that use cheap single-advisor oversight (the realistic default when full debate is too expensive) know how badly it can be steered and how to harden it -> deployed oversight is less easily captured by a single persuasive but wrong advisor -> a concrete failure pathway where a capable model talks a cheap overseer into endorsing a wrong/unsafe answer is measured and partially closed without any training.

# Strength Rationale

High counterfactual value: it isolates a practically-important failure of the cheapest oversight protocol using only public data and small open models, something labs (focused on full debate) have little incentive to characterize. Tightly narrow-scope — accuracy-by-assigned-side plus debias-prompt recovery — with explicit metrics, feasible by beginners in ~30 hours.

# Alternative Framings

- Reframe as a 'consultancy safety datasheet': report the anchoring gap and recommended debias prompt as deployment guidance for anyone using single-advisor LLM oversight.
