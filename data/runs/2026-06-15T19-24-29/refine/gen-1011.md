# Research Question

Do different LLMs place their safe/unsafe refusal threshold at the same point along a benign-to-harmful prompt ramp? If refusal boundaries cluster tightly across models, the ecosystem shares the same exploitable edge.

# Approach Outline

Construct a small set of 'prompt ramps': for each of ~15-20 sensitive topics, write a graded ladder of 6-8 prompts moving from clearly benign to clearly harmful (e.g. general chemistry question -> increasingly specific synthesis requests). Run each prompt through 4-6 small open chat models on a single GPU or via API. Use an LLM-judge (or simple keyword + judge hybrid) to label each response as comply vs refuse, then locate each model's refusal threshold (the rung where it flips). Compare thresholds across models per ramp and compute boundary-agreement statistics. This is prompt-engineering plus light inference: no training, no proprietary data, fully reproducible from a released prompt set.

# Proposed First Experiments

- Build and validate 5 prompt ramps by hand, run them through one model, and confirm the judge reliably detects the comply->refuse flip. Measure: judge agreement with two human annotators on a 50-response sample. Expected outcome: >85% judge accuracy, validating the pipeline.
- Full cartography: run all ramps through all models, locate each model's threshold rung per ramp. Measure: variance of threshold position across models per topic (tight vs spread). Expected outcome: thresholds cluster within 1-2 rungs for most topics, indicating shared boundaries.
- Exploitability probe: take a prompt that sits just BELOW every model's threshold (universally complied-with) but is borderline-harmful, and test whether it elicits comparable unsafe content across all models. Measure: cross-model success rate of this single 'edge' prompt. Expected outcome: one borderline phrasing generalizes across models, demonstrating a shared exploitable edge.

# Theory of Impact Chain

If refusal boundaries cluster across models, then an attacker who finds one prompt phrasing that sits just inside the universal 'will comply' zone can reuse it across the entire model ecosystem -> a single jailbreak / boundary-probe generalizes -> correlated safety failures across deployments. Mapping where the shared edges sit lets defenders harden exactly those rungs, reducing the catastrophic pathway where one elicitation technique unlocks dangerous capabilities everywhere at once.

# Strength Rationale

Scores 5 on narrow scope and accessible complexity: the deliverable is a concrete boundary-agreement map produced with prompt-only auditing and an LLM judge. Counterfactual value (4) is strong because it audits the public-model ecosystem with no lab-internal infrastructure, no training, and no proprietary data, and the released ramp set is a reusable artifact for independent safety auditors.

# Alternative Framings

- Reframe as 'over-refusal homogeneity': map whether models also share the benign-but-refused boundary, surfacing correlated false-positive censorship rather than only correlated under-refusal.
