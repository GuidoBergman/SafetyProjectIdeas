# Research Question

When a model is prompted to 'appear safe', does it differentially drop accuracy on hazard-framed questions versus difficulty-matched benign questions with identical public answers? A larger drop on hazard items would be a measurable selective-sandbagging signature that any external evaluator can detect using only public, benign-proxy data.

# Approach Outline

Construct ~40-60 matched question pairs that differ ONLY in surface hazard-framing while sharing equivalent difficulty and publicly available textbook answers (e.g. neutral 'how does this reaction proceed' vs 'how could this dangerous reaction be carried out', both answerable from a public chemistry textbook). Run each model under two conditions: a neutral baseline prompt and a 'try to avoid appearing dangerous' sandbagging prompt. Measure accuracy in all four cells (neutral-framing/benign-framing x baseline/sandbag) and compute the differential accuracy drop (hazard drop minus neutral drop) under the sandbagging prompt. Use 2-3 open or API models within free-tier limits. The whole study is inference/prompting only, with answers graded against the known textbook key, so it is fully reproducible without any hazardous capability data.

# Proposed First Experiments

- Build and validate a 20-pair pilot question set: for each pair, confirm both framings have the same correct public answer and roughly equal baseline difficulty. Measure baseline accuracy under a neutral prompt; expected outcome is near-equal accuracy on hazard vs neutral framings (~within 5%), establishing difficulty-matching before any sandbagging is applied.
- Apply the 'avoid appearing dangerous' sandbagging prompt and re-measure accuracy on the same pairs. Measure the differential drop = (baseline-hazard - sandbag-hazard) - (baseline-neutral - sandbag-neutral). Expected outcome: a positive differential drop (larger accuracy loss on hazard-framed items) would be the selective-sandbagging signature; a near-zero differential would be an informative negative.
- Cross-model comparison: run the full set on 2-3 models and compare differential-drop magnitudes. Measure whether the signature is consistent across model families and whether it scales with model size. Expected outcome: a per-model selective-sandbagging score that external evaluators could adopt as a cheap red flag.

# Theory of Impact Chain

If models selectively suppress hazard-domain accuracy when prompted to look safe, then standard dangerous-capability evals undercount true bio/cyber capability -> deployers and auditors get false assurance and ship under-evaluated models -> a model with latent uplift capability is released. A public benign-proxy signature lets independent evaluators detect this undercounting without hazardous data, closing the eval-integrity gap that is a direct precursor to catastrophic bio/cyber misuse.

# Strength Rationale

Scores 5 on narrow scope and low compute: it is a single, tightly-defined differential-accuracy measurement runnable on free-tier inference. Its counterfactual value (4) is strong because the entire method uses public benign-proxy questions and no lab-internal tooling or hazardous data, so an independent team can produce an eval-integrity check that labs have little incentive to build and that targets a recognized >1yr misuse threat.

# Alternative Framings

- Frame as a benchmark contribution: release the matched hazard/neutral question pairs and the differential-drop metric as a reusable 'sandbagging litmus test' that any auditor can run on a new model.
