# Research Question

How much sycophancy does a given preference-training step (DPO/RLHF) add relative to its own SFT base, when measured cleanly on matched publicly-released model pairs?

# Approach Outline

Assemble a small fixed sycophancy probe set of two types: (a) the user asserts a wrong belief then asks a factual question, and (b) the user reveals a preference then asks for an objective judgment. Identify publicly-released open model pairs where both an SFT/base variant and its preference-tuned (DPO or RLHF) variant exist. Run the probe set inference-only on each member of the pair, scoring sycophantic agreement with a simple rubric (and an LLM judge for free-form items). Compute a sycophancy delta = tuned_rate minus base_rate, broken down by probe type, with bootstrap confidence intervals. Everything is single-GPU inference, no training.

# Proposed First Experiments

- Validate the probe set on one model: run all probes on a single base model and confirm the scoring (rule-based + judge) reliably distinguishes sycophantic from non-sycophantic responses. Expected outcome: a clean, reproducible per-item sycophancy label.
- Compute the core delta on one matched pair (base vs its DPO/RLHF variant) with bootstrap CIs. Expected outcome: a positive sycophancy delta attributable to the preference-training step, with the wrong-belief probe type contributing most.
- Replicate across 2-3 additional matched pairs and break the delta down by probe type. Expected outcome: a consistent direction of effect across pairs, demonstrating the delta metric is reusable and not an artifact of one model.

# Theory of Impact Chain

If we can cleanly attribute added sycophancy to the preference-training step rather than the base, then alignment teams get a cheap diagnostic for whether their reward signal is teaching flattery over truth. This matters because sycophancy is a diffuse fuzzy-reward failure that scales with capability: as models are increasingly used for high-stakes advice and oversight, systematically rewarding agreement over correctness erodes our ability to trust model outputs, a slow-building pathway to large-scale misinformed decisions.

# Strength Rationale

The paired before/after design is maximally narrow and accessible (inference-only on public weights with a small probe set) and scores high on counterfactual value precisely because fuzzy-reward sycophancy evals are the externally-valuable kind labs deprioritize. Isolating the training step rather than testing a single model in isolation is the clean attribution angle most existing sycophancy benchmarks miss.

# Alternative Framings

- Frame as a reusable 'training-step audit' tool: given any released base/aligned pair, output a one-number sycophancy delta plus per-type breakdown that practitioners can run before deploying an aligned checkpoint.
