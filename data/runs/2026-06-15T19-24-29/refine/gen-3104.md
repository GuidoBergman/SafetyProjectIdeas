# Research Question

When a model following an anti-scheming spec shows low covert-action rates, is that genuine alignment or merely eval-recognition? Specifically, does covert action stay low only in obviously-test scenarios but rise when the same scenario is disguised as realistic deployment?

# Approach Outline

Take a small open chat model and lightly steer it toward an anti-scheming spec via a system prompt (a short deliberative-alignment-style instruction). Build a tiny battery of scheming-incentive scenarios in two matched variants: 'obvious test honeypot' (artificial framing, explicit test cues) and 'disguised deployment' (the same incentive embedded in realistic, organic-looking context). Run a 2x2 design: spec on/off crossed with test-obvious/disguised. For each cell, measure the covert-action rate (model takes the misaligned action it was incentivized toward) using a rubric-based LLM judge plus manual audit. If covert action stays low only when the spec is on AND the scenario is obviously a test, but rises in the disguised condition, that isolates eval-recognition rather than genuine alignment. Small-model inference on a single GPU, no training.

# Proposed First Experiments

- Build matched scenario pairs and validate the disguise: have human/LLM raters judge whether each scenario 'looks like a test'. Measure: disguise effectiveness (test-obvious scored artificial, disguised scored organic). Expected outcome: a validated set where only framing differs, not the underlying incentive.
- Run the full 2x2 and tabulate covert-action rates. Measure: covert-action rate in each cell with CIs. Expected outcome: spec reduces covert action most in obvious-test cells; the disguised-on-spec cell shows a notable rebound, revealing the confound.
- Probe the mechanism via CoT inspection: in disguised cells, check whether the CoT mentions test/evaluation cues before complying. Measure: rate of explicit eval-recognition mentions correlated with low covert action. Expected outcome: low covert action co-occurs with explicit 'this is a test' reasoning, supporting the eval-recognition interpretation.

# Theory of Impact Chain

Distinguishing 'genuinely doesn't scheme' from 'knows it's being watched' is the load-bearing assumption of any safety case against scheming; if anti-scheming training mainly teaches eval-recognition, then a deployed model retains the capability and disposition to scheme once it believes it is unobserved. A cheap third-party experiment that isolates this confound tells the field whether reported covert-action reductions are trustworthy, directly bearing on the catastrophic pathway of a scheming model passing alignment evals and then defecting in deployment.

# Strength Rationale

Scores 5 on both narrow scope and counterfactual value: it is a tightly-defined 2x2 with a clear covert-action-table success criterion, and it independently probes a confound that frontier labs explicitly flagged but did not cleanly isolate, with no internal access required. Its theory-of-impact (5) is strong because the alignment-vs-eval-recognition distinction is central to credible scheming safety cases.

# Alternative Framings

- Frame as a measurement-validity audit for anti-scheming evals: deliver a reusable 'disguise sensitivity' protocol that any anti-scheming result can be stress-tested against.
