# Research Question

After machine unlearning suppresses a model's outputs on a target topic, does the 'forgotten' knowledge remain linearly decodable from internal activations, meaning a simple probe can still recover what the model refuses to say?

# Approach Outline

Take a released checkpoint that has undergone unlearning of a specific knowledge set, plus its pre-unlearning counterpart (or use a public unlearning benchmark with both). Construct a labeled set of probe inputs about the unlearned topic with known answers. Extract hidden activations at one or more layers for both models and train small linear probes to decode the target knowledge (e.g., correct-vs-incorrect fact, or topic identity). Compare probe accuracy before vs after unlearning and contrast it with the model's output-level suppression. The expensive part is only forward passes plus cheap linear-probe training, feasible on a single GPU within the time budget if the model is small/mid-sized.

# Proposed First Experiments

- Output-suppression confirmation: query the unlearned model on the target topic. Measure: output-level accuracy/refusal on the unlearned knowledge. Expected outcome: the model suppresses or refuses, confirming unlearning 'worked' at the output level.
- Activation probe recovery: train linear probes on hidden states of the unlearned model to decode the target knowledge. Measure: probe accuracy on the unlearned topic vs a control topic. Expected outcome: probes recover the unlearned knowledge well above chance despite output suppression.
- Before-vs-after gap: train matched probes on the pre-unlearning model and compare probe accuracy to the unlearned model. Measure: change in linear decodability due to unlearning. Expected outcome: little-to-no drop in probe accuracy, demonstrating a detection blind spot where unlearning hides outputs but not internal representations.

# Theory of Impact Chain

If unlearned knowledge stays linearly decodable, then unlearning provides false assurance: a model that appears to have 'forgotten' dangerous capability still carries it internally, recoverable by adversaries via fine-tuning or activation access. Demonstrating this blind spot tells the community that output-level unlearning evals are insufficient and probe-based audits are needed, addressing the catastrophic pathway where releasing 'unlearned' open weights is wrongly assumed safe while hazardous knowledge remains retrievable.

# Strength Rationale

It scores 5s on accessible complexity and narrow scope: a tightly defined probe-detectability-before-vs-after comparison using tiny linear probes on a released checkpoint, with a clear success criterion. Counterfactual value is high because it scrutinizes a safety tool (unlearning) using only public checkpoints and cheap probes, the kind of independent red-team check labs underweight.

# Alternative Framings

- Frame it as stress-testing an unlearning benchmark: report whether its 'forgotten' set survives as probeable internal knowledge.
