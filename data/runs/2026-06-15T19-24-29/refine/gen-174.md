# Research Question

How does jailbreak success scale with the number of tokens of a compliant response that an attacker prefills into the assistant turn? What is the 'minimum effective prefill' length at which safety collapses, and does that elbow line up with the shallow-alignment token-depth result?

# Approach Outline

Select 2-3 open chat models that expose an assistant-prefix / prefill interface. Build a fixed set of ~50 harmful prompts each paired with a short canonical compliant continuation. For each prompt, prefill 0, 1, 2, 5, 10, and 20 tokens of that compliant continuation and let the model continue. Score whether the completion is a successful jailbreak using a judge model plus a refusal-keyword check. Aggregate to a dose-response curve (attack success rate vs prefill length) per model, fit a simple curve, and read off the minimum prefill achieving e.g. 50% and 90% success. Pure inference, no training, light GPU.

# Proposed First Experiments

- Single-model dose-response curve: On one prefill-capable open model, run all six prefill lengths over the harmful set and plot attack success rate vs prefill length. Measure ASR at each length. Expected outcome: a sharp rise from near-zero at 0 tokens to high ASR within the first handful of tokens.
- Minimum-effective-prefill extraction: Fit a monotone curve to the per-length ASR and report the prefill length crossing 50% and 90% success. Measure these threshold lengths. Expected outcome: thresholds in the low single-to-double digit token range, consistent with shallow alignment.
- Cross-model comparison: Repeat on 2 more open models and overlay their curves. Measure how the elbow location varies across models. Expected outcome: all models break within a small prefill budget, with relative ordering giving a comparable robustness ranking.

# Theory of Impact Chain

If safety alignment can be defeated by prefilling only a few tokens, then any deployment surface that lets users (or a compromised tool) influence the start of the assistant's response is critically exposed. Quantifying the minimum effective prefill operationalizes shallow alignment for the prefill threat model and gives API designers a concrete depth target for how many response tokens must be defended, directly reducing the catastrophic pathway where attackers cheaply elicit harmful capabilities from deployed open models.

# Strength Rationale

Scores 5 on accessible complexity and narrow scope and 4 on counterfactual value: it is a clean, single inference-only experiment on open models with a sharp, reusable deliverable (a dose-response curve and a threshold metric), needing no proprietary data and addressing an axis labs rarely publish. It builds directly on well-cited prior work while targeting a distinct, unmeasured quantity.
