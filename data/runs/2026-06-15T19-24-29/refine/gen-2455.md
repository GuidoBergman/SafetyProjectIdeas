# Research Question

Can a minimal sequence-aware anomaly detector (n-gram or tiny Markov model over tool-call transitions) catch multi-step sabotage in agent trajectories that per-action monitors miss, and how much detection power does sequence awareness add on open agent traces?

# Approach Outline

Collect benign agent tool-call trajectories from an open agent benchmark (e.g. SHADE-Arena or ControlArena traces). Model 'normal' behavior with simple transition statistics: n-gram tool-transition frequencies or a small first/second-order Markov model. Inject sabotage trajectories (either provided attack traces or hand-constructed multi-step attacks where each step is locally plausible) and score each trajectory's likelihood under the normal model; low likelihood flags anomalies. Compare this sequence-aware detector against a per-action baseline (scoring each action independently) on the same traces using ROC/AUC. Everything is CPU/light-inference and fits a few hours; deliverable is an AUC comparison and blog post.

# Proposed First Experiments

- Build the normal model: fit n-gram/Markov tool-transition statistics on benign traces and verify it assigns high likelihood to held-out benign trajectories. Expected outcome: benign held-out trajectories score as normal, establishing a baseline.
- Sequence vs. per-action detection: inject sabotage trajectories and compute detection AUC for the sequence-aware detector vs. a per-action monitor. Expected outcome: the sequence-aware detector achieves higher AUC on multi-step attacks that look locally benign.
- Order-sensitivity ablation: vary Markov order (unigram vs. bigram vs. trigram) and measure detection AUC. Expected outcome: higher-order models catch more multi-step attacks up to a point, identifying a cheap, effective order.

# Theory of Impact Chain

Agent monitors that score actions independently miss attacks whose only tell is the sequence of tool calls, leaving multi-step sabotage undetected in agentic deployments. A minimal, reproducible sequence-aware detector that beats per-action monitoring on open traces gives independent deployers cheap, reusable monitoring infrastructure, reducing the risk that an agentic model executes a harmful multi-step plan (e.g. data exfiltration or sabotage) that slips past single-action oversight.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a single sequence-vs-per-action AUC comparison using n-gram/Markov methods that are essentially free and squarely in intro-ML skills. Counterfactual value is high because it produces reusable monitoring infrastructure on public traces with no training or lab tooling, exactly the kind of independent-friendly work labs deprioritize.

# Alternative Framings

- Frame as an open-source baseline 'trajectory anomaly scorer' others can compare their learned detectors against.
