# Research Question

Given a pool of nominally different open models, how many EFFECTIVELY independent models does an ensemble actually contain? We compute an 'effective-N' that corrects the raw model count for inter-model error correlation, and chart how ensemble reliability saturates.

# Approach Outline

Run 8-12 small open models over a labeled benchmark and record per-model correctness vectors. Treat each model as a binary correct/incorrect signal and estimate the inter-model error correlation matrix. Compute an effective number of independent models using a correlation-adjusted variance / effective-sample-size formula (e.g. N_eff = N / (1 + (N-1)*rho_bar), where rho_bar is the mean pairwise error correlation). Then simulate majority-vote ensembles of increasing size, drawn from the pool, and plot ensemble accuracy vs number of models to show diminishing returns. Compare the empirical saturation point against the computed effective-N. Deliver the effective-N number plus the diminishing-returns curve in a blog post.

# Theory of Impact Chain

If a simple effective-N metric reliably predicts ensemble reliability saturation, then anyone deploying multi-model oversight gets an actionable monitoring number telling them how much real redundancy they have -> over-provisioned ensembles that falsely assume independence are flagged before deployment -> this reduces the systemic risk that a high-stakes automated system relying on 'many models' actually has only a couple of independent votes and fails correlatedly under stress, a concrete model-monoculture catastrophe pathway.
