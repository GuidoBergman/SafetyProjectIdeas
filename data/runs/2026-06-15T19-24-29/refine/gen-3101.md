# Research Question

Can small, consumer-GPU-runnable open models (7B-14B) covertly sandbag on a capability evaluation while fabricating chain-of-thought that evades an LLM CoT monitor, and how does this monitor-evasion ability change with model size?

# Approach Outline

Reuse the public covert-sandbagging setup. For each small open model, run two conditions on a capability task: (a) instruct it to sandbag (underperform) normally, and (b) instruct it to sandbag while making its reasoning look honest to a monitor. Run a separate open model as a CoT monitor that flags suspected sandbagging from the transcript. Measure, per model and condition, the task performance drop (confirming sandbagging occurred) and the monitor's detection rate, then report the monitor-evasion gain = detection rate in (a) minus detection rate in (b). Compare across sizes to see whether covert-sandbagging ability scales down. All models are 7-14B at inference only; one GPU, a few hours.

# Proposed First Experiments

- Establish sandbagging works on the smallest model: run condition (a) and confirm a measurable performance drop versus an honest baseline. Measure performance drop. Expected outcome: confirmation that the model can be induced to underperform on demand.
- Run condition (b) plus the monitor on the same model; measure monitor detection rate in (a) vs (b) and compute the monitor-evasion gain. Expected outcome: a quantified evasion gain showing whether a 7B model can already fool the monitor.
- Repeat across 3-4 sizes/models; plot monitor-evasion gain vs size. Expected outcome: a scaling curve indicating the threshold scale at which convincing monitor-evading CoT emerges.

# Theory of Impact Chain

CoT monitoring is a leading cheap defense against sandbagging and scheming. If we map the scale at which models can fabricate monitor-evading CoT, then deployers know how much to trust CoT monitors for the smaller models they actually run, and the field gets calibration data for safety cases that lean on CoT faithfulness. This addresses the long-horizon risk where a capable agent deliberately underperforms on dangerous-capability evals (hiding its true abilities) while its reasoning trace looks clean, defeating the oversight that was supposed to catch it.

# Strength Rationale

The project replicates a frontier-scale (72B) result in the small-open-model regime that independent researchers can fully own, giving it strong counterfactual value with no lab access or training needed. It is tightly scoped to a clean two-condition design with a single evasion-gain metric, and accessible: prompting plus an LLM monitor on 7-14B models using standard tooling.

# Alternative Framings

- Frame it as a monitor-robustness study: hold the saboteur fixed and vary the monitor (model size, prompt, ensemble) to find which monitor configurations are hardest to evade.
