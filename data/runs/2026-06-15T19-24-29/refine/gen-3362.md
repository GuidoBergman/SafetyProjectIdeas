# Research Question

When a clear logical or arithmetic error is injected mid-stream into a model's own chain-of-thought and it is allowed to continue, does the model explicitly flag the error, silently correct it without mention, or propagate it, and how do these rates vary across open models and error severities?

# Approach Outline

Take reasoning tasks (e.g., GSM8K-style arithmetic, simple logic puzzles) and have the model generate a partial CoT. Programmatically inject a clear error into the CoT mid-stream (flip an arithmetic result, swap a logical step), then feed the modified CoT back and let the model continue to a final answer. Classify each continuation into three outcomes: (a) explicitly flags/acknowledges the injected error, (b) silently corrects it without mention, (c) propagates the error to the conclusion. Measure the rate of each outcome across 3-4 open models and across error severities (subtle vs blatant). Use a rubric-based classifier (LLM judge + regex for explicit flags) and a manual audit of a sample. Pure inference, single GPU, no training.

# Proposed First Experiments

- Build the injection pipeline and validate it on blatant errors: inject an obviously wrong arithmetic step. Measure: fraction of continuations that flag / silently correct / propagate. Expected outcome: a clear three-way split, with blatant errors more often flagged.
- Severity sweep: vary error subtlety from blatant to subtle. Measure: how acknowledgment rate changes with severity. Expected outcome: acknowledgment falls and silent-correction/propagation rises as errors get subtler.
- Cross-model comparison: run the same battery across 3-4 open models. Measure: per-model acknowledgment vs silent-correction vs propagation rates. Expected outcome: models differ markedly, identifying which produce CoT that can be trusted as a faithful reasoning record.

# Theory of Impact Chain

A model that silently absorbs an injected error in its own CoT without acknowledgment is one whose chain-of-thought cannot be trusted as a faithful record of its reasoning, which undermines CoT monitoring as a safety tool. Quantifying acknowledgment-vs-silence gives monitors a concrete faithfulness stress-test and tells safety-case builders how much to trust CoT-based oversight, addressing the catastrophic pathway where a monitor is lulled by plausible-looking CoT that no longer reflects the model's actual computation.
