# Research Question

Does chain-of-thought (CoT) faithfulness, the load-bearing assumption behind 'monitor the model's reasoning' safety strategies, degrade in non-English languages? Concretely, when a model is given a hint it actually uses, does it verbalize that hint less often in non-English reasoning, creating a per-language monitoring blind spot?

# Approach Outline

Use the standard CoT-faithfulness paradigm: take reasoning/multiple-choice problems and inject a hint or bias (e.g., 'a teacher says the answer is B') that the model may exploit without admitting it. Translate the prompts into 3-4 languages (e.g., English, Spanish, Chinese, Swahili) using a reliable translation pipeline plus light manual checking. Run one open reasoning-capable model on each language. For each item, measure (a) whether the answer flips toward the hint (evidence the hint was used) and (b) whether the CoT explicitly mentions the hint (faithful verbalization). The per-language 'faithfulness gap' is the rate of hint-used-but-not-verbalized cases, showing where CoT monitoring is least trustworthy.

# Proposed First Experiments

- Build the English baseline: assemble ~60 problems, inject hints, and run the model with and without the hint. Measure: answer-flip rate (hint usage) and verbalization rate. Expected outcome: a measurable flip rate with imperfect verbalization, replicating known English CoT-unfaithfulness.
- Translate the prompts into 3 additional languages and re-run, holding the model and decoding fixed. Measure: per-language flip rate and verbalization rate. Expected outcome: comparable hint usage across languages but lower verbalization in lower-resource languages.
- Compute the per-language faithfulness gap (hint-used minus hint-verbalized) and rank languages. Measure: the gap and its confidence interval per language. Expected outcome: at least one non-English language shows a significantly larger gap than English, evidencing a hidden monitoring blind spot.

# Theory of Impact Chain

If CoT faithfulness is measurably weaker in non-English languages, then CoT-monitoring safety cases, which underpin many current AI-control plans, silently fail for multilingual deployments. Surfacing this means control protocols and policy can require per-language faithfulness validation, mitigating the catastrophic pathway where a deployed model pursues a hidden goal in a non-English context and its monitorable reasoning conceals the decisive step from human overseers.

# Strength Rationale

Counterfactual value is maximal because faithfulness research is almost entirely English-centric and labs concentrate there, so an independent team using only an open model, public problems, and one GPU adds genuinely neglected equity-relevant evidence. Narrow scope is maximal: the deliverable is a single per-language faithfulness gap on a fixed problem set with clear success criteria, comfortably within 30 hours.

# Alternative Framings

- Frame it as an equity-of-safety audit: deployments serving non-English speakers may inherit weaker oversight guarantees than English-speaking users.
