# Research Question

In a no-fine-tuning, prompt-only regime feasible for a student with one GPU, can a diverse ensemble of small open monitors - differing only in their scoring prompt - match or beat a single larger monitor at matched dollar/compute cost, and is prompt diversity (member anti-correlation) the active ingredient?

# Approach Outline

Build an ensemble of 5 instances of one small open model (e.g. an 8B), differing ONLY in scoring prompt: security-auditor persona, naive code reviewer, adversarial red-teamer, rule-checker, and plain rubric. Each scores SHADE-Arena benign/malign transcripts on a 0-10 rubric. Average member scores into an ensemble score. Compare the ensemble's AUROC against a single larger monitor (e.g. a 70B via API) on the same transcripts, with cost matched by counting tokens/dollars. Measure pairwise anti-correlation between ensemble members' scores to test whether diversity (not just more samples) drives any gain. No fine-tuning; inference-only on one GPU plus modest API spend.

# Proposed First Experiments

- Ensemble vs single AUROC: Compute AUROC for the 5-prompt averaged ensemble and for the single 70B monitor on the same transcript set, with matched cost. Measure the AUROC difference. Expected outcome: the cheap prompt-diverse ensemble matches or exceeds the single large monitor at equal cost.
- Diversity-is-the-ingredient check: Compute pairwise correlations between ensemble members' scores, and compare the diverse-prompt ensemble against a control ensemble of 5 identical-prompt samples (temperature diversity only). Measure AUROC of diverse vs identical-prompt ensembles. Expected outcome: lower inter-member correlation in the diverse ensemble and a higher AUROC than the identical-prompt control, confirming prompt diversity is the active ingredient.
- Ensemble-size scaling: Vary the number of distinct prompts from 1 to 5 and measure AUROC as members are added. Expected outcome: most of the gain is captured by the first few diverse prompts (diminishing returns), giving a practical recommendation for budget-limited groups.

# Theory of Impact Chain

If cheap, prompt-diverse small-monitor ensembles match a costly single monitor, then groups without lab compute can run robust AI-control monitoring on commodity hardware, broadening who can deploy and study control protocols. Stronger, cheaper monitoring lowers the chance that an untrusted model's sabotage goes undetected in resource-constrained deployments, a concrete contribution to control infrastructure outside major labs.

# Strength Rationale

Scores 5 on accessible complexity and narrow scope: a prompt-variant ensemble plus averaging, compared against one API monitor on public transcripts, is a self-contained 30-hour project requiring no fine-tuning. Counterfactual value (4) is high because it directly produces monitoring infrastructure usable by non-lab groups and narrows a 2026 finding to the feasible prompt-only regime labs did not isolate.
