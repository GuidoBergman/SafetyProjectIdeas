# Research Question

How much does an open model's harmful-compliance rate rise as we move from weak to strong but cheap elicitation (zero-shot to few-shot to chain-of-thought to best-of-N), and how large is the gap a real attacker could exploit beyond a weakly-elicited 'safe' eval?

# Approach Outline

On one open model and a small harmful-instruction set, measure harmful-compliance under escalating, inexpensive elicitation: (1) plain zero-shot, (2) few-shot with benign-looking exemplars, (3) chain-of-thought prompting, (4) best-of-N sampling (try N completions, count success if any complies). Judge each completion harmful/not with a keyword+LLM-judge classifier. Plot the elicitation-response curve (compliance rate vs elicitation strength) and report the gap between weakest and strongest cheap elicitation. Deliver a recommendation for a minimum elicitation standard in safety reporting. Best-of-N multiplies inference but stays within a single GPU by keeping the prompt set and N small.

# Proposed First Experiments

- Zero-shot baseline: run ~50 harmful instructions through the open model zero-shot and record compliance rate. Measure: baseline harmful-compliance. Expected outcome: a low baseline that a naive eval would report as 'safe'.
- Escalate single-sample elicitation: re-run the set under few-shot and chain-of-thought prompting and recompute compliance. Measure: compliance rate at each elicitation level. Expected outcome: a monotone rise from zero-shot to CoT, quantifying how much cheap prompting moves the number.
- Best-of-N curve: for N in {1,2,4,8,16}, sample N completions per prompt (with CoT) and count a prompt as complied if any sample complies; plot compliance vs N. Measure: the elicitation-response curve and the weakest-to-strongest gap. Expected outcome: a steep, possibly large (tens of points) increase with N, demonstrating that under-elicited safety evals materially overstate safety and motivating a minimum-elicitation reporting standard.

# Theory of Impact Chain

If we quantify how far safety refusals move under cheap elicitation, then evaluators learn that under-elicited safety evals overstate safety, and gain a concrete minimum-elicitation standard to apply before reporting. Because go/no-go deployment decisions rest on these eval numbers, surfacing the elicitation gap reduces the chance a model is certified safe under weak prompting and then exploited by an attacker using trivially-stronger elicitation to extract dangerous-capability assistance.

# Strength Rationale

Strong on narrow scope and accessibility: one model, a small prompt set, and a handful of standard elicitation techniques produce a single interpretable curve. Counterfactual value is high because it is inference-only on open models and addresses an eval-methodology gap labs themselves admit (missing best-of-N/CoT elicitation), making it a credible external contribution. The only compute caveat is best-of-N sampling, kept feasible by small N and prompt set.

# Alternative Framings

- Frame as a 'minimum elicitation standard' proposal: an empirical curve plus a recommended elicitation floor that any safety report should meet before claiming a refusal rate.
