# Research Question

When an LLM overseer reviews a long agent transcript for a single buried piece of harmful content, does its detection rate depend on where in the context that content sits? In other words, does the well-known 'lost-in-the-middle' effect create a systematic blind spot that an agent could exploit to hide harmful steps from a monitor?

# Approach Outline

Build a small corpus of long agent-log-style transcripts (e.g. 4k-32k tokens of benign tool calls and reasoning) and a set of short 'harmful' insertions (policy-violating instructions, exfiltration attempts, unsafe tool calls). For each transcript length, sweep the insertion position from start to end in fixed bins, asking an open-weight overseer model (e.g. Llama-3.1-8B-Instruct or Qwen2.5-7B-Instruct via a single Colab Pro / Runpod GPU) 'does this log contain any harmful or policy-violating content?' Record the binary detection outcome per position. Aggregate into a detection-rate-vs-position curve for each context length. Keep everything inference-only: no fine-tuning, just prompting and logging. Use a fixed harm set and a fixed benign filler so the only varying factor is position and length.

# Proposed First Experiments

- Calibration run: insert the harmful span at the very start of a 4k-token transcript across ~50 transcripts and measure baseline detection rate; expected outcome is high (>90%) detection, confirming the overseer can find harm at all when it is salient.
- Position sweep at fixed length: hold transcript length at 16k tokens and move the harmful insertion across 8 evenly spaced positions (~50 trials each); measure detection rate per bin. Expected outcome: a U-shaped or sagging curve with lowest detection near the middle, replicating lost-in-the-middle for a safety task.
- Length scaling: repeat the middle-position insertion at 4k, 8k, 16k, 32k tokens; measure how the mid-context detection gap widens with length. Expected outcome: the middle-position blind spot grows with context length, quantifying how much an adversary gains by burying harm in longer logs.

# Theory of Impact Chain

If overseers reliably miss harm placed mid-context, then an agentic system (or an adversary steering one) can hide unsafe tool calls or instructions in the middle of long logs to evade automated monitoring. This matters because scalable oversight of autonomous agents increasingly relies on LLM monitors reading long traces; a cheap, position-based evasion would let a deceptive or misaligned agent take catastrophic actions (data exfiltration, unauthorized operations) while passing review, undermining the monitoring layer meant to catch exactly those behaviors before they cause harm.

# Strength Rationale

The idea scores highly on counterfactual value and narrow scope: it needs only public models and inference, so it is fully executable outside a major lab, yet it targets agent-monitoring infrastructure that labs under-test for this specific failure. The deliverable is a single, crisp detection-rate-vs-position curve with an explicit success criterion (does mid-context detection drop significantly below edge detection?), making it self-contained and beginner-feasible in 30 hours.
