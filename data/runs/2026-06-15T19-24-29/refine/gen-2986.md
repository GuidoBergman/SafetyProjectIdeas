# Research Question

When data contamination (inflating scores via memorization) and sandbagging (deflating scores via strategic underperformance) act on the same benchmark, can they partially cancel to produce a misleadingly 'normal' headline score that hides high latent capability?

# Approach Outline

On a small open instruct model (e.g. Llama-3-8B or Qwen2.5-7B), we construct matched item pairs: known-contaminated benchmark questions (likely memorized) vs paraphrased/novel variants of the same difficulty. We then run a 2x2 design crossing item type (contaminated vs novel) with prompt condition (honest vs a sandbagging prompt: 'answer as if you want to appear less capable on hazardous tasks'), measuring accuracy in each cell. The key test is whether contamination on memorized items hides the accuracy drop that sandbagging would otherwise produce on novel items -- i.e. whether the contaminated-sandbagged cell looks deceptively normal. Inference-only on one open model, a few hours. Deliverable is a self-contained blog post with the 2x2 accuracy grid, the cancellation effect size, and an explicit success criterion (is the contaminated+sandbagged score statistically indistinguishable from the honest baseline while the novel+sandbagged score is clearly depressed?).

# Proposed First Experiments

- Build matched item pairs: take ~100 benchmark items plausibly in the training data and create difficulty-matched paraphrased/novel variants, verifying difficulty parity by honest-prompt accuracy on a clean model. Measure: honest accuracy on contaminated vs novel items. Expected outcome: contaminated items score higher than novel ones under honest prompting, confirming a memorization gap to exploit.
- Run the 2x2 grid: evaluate all four cells (contaminated/novel x honest/sandbagged) on the same model. Measure: accuracy per cell. Expected outcome: sandbagging depresses novel-item accuracy sharply, but contaminated-item accuracy is partly propped up by memorization, so the contaminated+sandbagged cell stays near the honest baseline.
- Quantify the masking effect and a detector: compute the cancellation (how much the contaminated+sandbagged score over-states true elicited capability vs novel+sandbagged) and test paraphrase-based contamination control as a sandbagging tell. Measure: the score-inflation gap and the contaminated-minus-novel accuracy drop under sandbagging. Expected outcome: a clear quantitative demonstration that a single headline number can hide concealed capability, with paraphrasing surfacing the hidden drop.

# Theory of Impact Chain

Regulators and external auditors often read a single benchmark number. If contamination and induced sandbagging cancel, that number looks safe while the model's true elicited capability is high -- so a dangerous model is cleared for deployment. Demonstrating this interaction quantitatively warns evaluators not to trust headline scores and motivates paraphrase-based contamination controls as a cheap sandbagging detector, directly defending the certification pathway against a model that conceals dangerous capability.
