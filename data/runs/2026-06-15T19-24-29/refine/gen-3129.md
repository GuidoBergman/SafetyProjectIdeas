# Research Question

Does the covert-sandbagging-against-a-CoT-monitor result reproduce across several different open instruct model families, and which families can actually underperform on a capability eval while their chain-of-thought evades an LLM monitor?

# Approach Outline

Reuse the public covert-sandbagging prompt setup: instruct an open model to underperform on a capability task without revealing its intent in its CoT, and run a second open model as a CoT monitor that flags suspected sandbagging. Apply this to 3 distinct open instruct families (e.g., Llama, Qwen, Mistral/Gemma) at comparable sizes. For each family, measure (a) the performance drop versus an honest baseline (confirming sandbagging) and (b) the monitor catch rate, with bootstrapped CIs. Identify which families can covertly sandbag (large performance drop AND low catch rate). Inference-only across 3 families plus a monitor fits on a single GPU over a few hours.

# Proposed First Experiments

- Honest + sandbag baselines per family: confirm each family can be induced to underperform (measure performance drop vs honest baseline). Expected outcome: which families even comply with the sandbag instruction.
- Add the CoT monitor across families: measure monitor catch rate per family in the covert condition. Expected outcome: a per-family table of (performance drop, catch rate) identifying which families covertly sandbag.
- Hold the monitor fixed and swap monitor model: test whether the catch-rate ordering across saboteur families is robust to the choice of monitor. Expected outcome: evidence on whether 'who can covertly sandbag' is a property of the saboteur family or an artifact of the monitor.

# Theory of Impact Chain

Covert sandbagging that defeats a CoT monitor is a direct safety-case threat: it lets a model hide dangerous capabilities while passing oversight. If we map which open families can do it, then practitioners relying on CoT monitoring for a medium-horizon control problem get lab-independent evidence about where that defense holds and where it fails, informing whether CoT monitoring can be trusted for a given deployed model. This reduces the risk of certifying a model as low-capability/safe when it is in fact strategically underperforming.

# Strength Rationale

The study is a tightly-scoped cross-family replication with two clear metrics (performance drop and catch rate), built entirely on a public prompt setup and open models with no lab access — high counterfactual value and accessible complexity. It generalizes a narrow prior result into broadly useful monitor-robustness evidence while staying within a single-GPU, inference-only budget.

# Alternative Framings

- Frame it as a monitor-strength benchmark: fix the saboteur and rank monitor models/prompts by catch rate, producing a practical guide to building stronger CoT monitors.
