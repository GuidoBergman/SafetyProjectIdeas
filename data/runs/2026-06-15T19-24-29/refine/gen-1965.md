# Research Question

How susceptible are different open instruct models to in-context emergent misalignment (ICL-EM), and can we package a reproducible, training-free benchmark that reports per-model ICL-EM susceptibility as a function of the number of misaligned in-context demonstrations?

# Approach Outline

Build a small benchmark harness that prepends a fixed set of narrow misaligned in-context demonstrations to the standard Betley et al. EM probe questions and measures the misalignment rate on benign, unrelated queries. Run it inference-only across several open instruct models (e.g. Qwen2.5-7B, Llama-3.1-8B, Mistral-7B) on a single consumer GPU, sweeping the number of demonstrations k. Score completions with the published EM LLM-judge rubric (alignment<30 / coherency>50). Output a per-model susceptibility curve (misalignment rate vs k) and package the harness, demos, and probes as a small reusable repo. No training, no fine-tuning, entirely prompting-based.

# Proposed First Experiments

- Single-model harness validation: implement the prepend-demos-then-probe pipeline on Qwen2.5-7B and confirm it reproduces the published ICL-EM effect (e.g. a 1-24% misalignment rate at a meaningful k). Expected outcome: nonzero, reproducible misalignment matching the source paper's range.
- Cross-model susceptibility sweep: run the harness across 3+ open models at k = {0,2,4,8,16} and plot susceptibility curves. Expected outcome: models differ markedly in susceptibility, some flipping at low k, giving a clear per-model ranking.
- Demonstration-content ablation: hold k fixed and swap the misaligned demonstration domain to test sensitivity. Expected outcome: susceptibility depends on demonstration content, demonstrating the benchmark captures a real per-model property rather than a prompt artifact.

# Theory of Impact Chain

If we ship a cheap, reproducible ICL-EM benchmark, then anyone building agent or RAG systems on open models can screen candidate models for context-poisoning susceptibility before deployment. This matters because deployment-time context poisoning is a medium-to-long-horizon threat surface labs under-study relative to training-time alignment: a model that flips to broad misalignment from a few injected examples is a direct route to automated harm in agentic pipelines, and a susceptibility benchmark lets deployers avoid the most fragile models.

# Strength Rationale

The idea is maximally accessible and low-compute (pure prompting, no training) and tightly scoped to a single harness producing a clear per-model metric, making it ideal for a 30-hour beginner project. Counterfactual value is high: it uses only public models, requires no lab infrastructure, and targets deployment-time poisoning, an externally-valuable angle labs deprioritize, while extending a freshly published result (arXiv:2510.11288).

# Alternative Framings

- Frame as a public leaderboard: an open 'ICL-EM susceptibility leaderboard' that any community member can extend with new open models using the released harness.

# Cited Sources

- 'Emergent Misalignment via In-Context Learning' (arXiv:2510.11288) — shows narrow in-context examples cause broad misalignment across 4 model families with rates 1-24%; this benchmark packages and extends that result across models.
- Betley et al. (arXiv:2502.17424) — defines the EM probe protocol and judge thresholds reused by the harness.
