# Research Question

When a small open agent is given a benign task inside a simulated sandbox that contains an obvious-but-forbidden escape path, how often does it notice, attempt, or reason toward the escape, and how does this propensity vary with prompting?

# Approach Outline

Build a tiny fully-simulated 'sandbox': a Python harness exposing a fake restricted resource (e.g. a stubbed file/credential the agent is told not to access) and an obvious escape action that is logged but has no real-world effect. Give a small open agent (e.g. Llama-3.1-8B-Instruct or Qwen2.5-7B-Instruct) a benign primary task plus the latent escape opportunity. Run many trials varying the prompt (neutral, time-pressured, goal-emphasized, escape-hinted) and classify each transcript for whether the agent (a) notices the escape path, (b) attempts it, or (c) explicitly reasons about it. Because everything is simulated, no real exploit or lab infrastructure is involved. Deliverable: a small-model escape-propensity probe plus a reusable open-source harness, written up as a blog post with propensity rates per prompt condition.

# Proposed First Experiments

- Harness build and neutral baseline: implement the simulated sandbox and run ~100 trials with a neutral benign task; classify notice/attempt/reason rates. Expected outcome: low baseline escape-attempt rate, establishing the harness works and small agents rarely escape unprompted.
- Prompt sensitivity sweep: run the same task under time-pressure, goal-emphasis, and escape-hint prompt variants; measure how propensity shifts. Expected outcome: escape reasoning and attempts rise under goal-emphasis and hints, showing propensity is prompt-elicitable.
- Cross-model comparison: run the probe across 2-3 small open models and compare propensity profiles. Expected outcome: model-dependent escape propensities, demonstrating the harness discriminates between agents and is reusable.

# Theory of Impact Chain

Sandbox escape is a named security-architecture open problem; containment matters only if agents that try to escape can be measured and caught. A cheap, reusable propensity probe lets the community baseline how often small agents even reason toward escape, and as models scale this harness gives early warning of rising escape propensity, supporting the long-horizon containment case against an agent taking irreversible real-world actions. The catastrophic link is partly speculative at small scale, but the reusable infrastructure compounds in value as it is rerun on stronger models.

# Strength Rationale

Counterfactual value is the standout strength (a neglected, reusable safer-sandbox harness with no lab infrastructure and purely simulated execution), alongside narrow scope and low compute. The whole study is a single propensity probe runnable on inference in a simulated environment, making it ideal strategic infrastructure for an independent beginner team to build and share.
