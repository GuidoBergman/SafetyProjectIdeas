# Research Question

Can a small, frozen, fully open task suite plus a single fixed harness let anyone reproduce the central scalable-oversight question — does debate beat consultancy beat direct QA — on a consumer GPU, closing the standardization gap that makes cross-protocol comparison impossible?

# Approach Outline

Assemble a 60-100 item frozen suite drawn entirely from existing open data: QuALITY reading-comprehension questions used in an information-asymmetric setup (judge sees only quoted spans, not the passage) plus a handful of verifiable code/logic items with checkable answers. Define one fixed harness that runs three oversight protocols — direct QA, consultancy, and two-turn debate — using the same open judge model (e.g. an 8B instruct model) and the same open debater model. Report judge accuracy per protocol with bootstrap confidence intervals. Ship the harness, the data manifest (IDs + prompts, no copyrighted passages redistributed), and a one-command runner as the deliverable. No training; inference-only on a single GPU within a few hours.

# Proposed First Experiments

- Freeze the suite and validate difficulty: select 60-100 QuALITY + logic items, run direct-QA baseline with the open judge alone (measure: judge accuracy with no debater help and inter-item difficulty spread; expected: clearly-below-ceiling accuracy, confirming headroom for protocols to matter).
- Implement and run the three protocols on the fixed harness: direct QA, consultancy, two-turn debate, same judge/debater models, same items (measure: per-protocol judge accuracy with bootstrap 95% CIs; expected: an ordering consistent with prior human results, e.g. debate >= consultancy >= direct, or a documented null if not).
- Test reproducibility and robustness: re-run with a second open judge model and a fixed random seed to check the protocol ordering is stable (measure: rank-stability of protocol accuracies across judges/seeds; expected: stable qualitative ordering, demonstrating the benchmark gives reproducible cross-protocol comparisons).

# Theory of Impact Chain

Scalable oversight protocols (debate, consultancy) are candidate tools for supervising models too capable for direct human checking. Today every paper uses a different task setup, so the field cannot tell which protocol actually helps -> a shared runnable micro-benchmark lets outside researchers reproduce and stress-test the 'does debate beat consultancy' claim cheaply -> faster, broader convergence on which oversight methods are trustworthy, which is on the critical path to supervising superhuman systems and avoiding deceptive failures of oversight.

# Strength Rationale

Counterfactual value and narrow scope both score 5: the deliverable is a standardized external benchmark — a recognized 'gold' gap — reproducible on a consumer GPU with no proprietary infra, exactly the kind of shared infrastructure independent researchers can produce but labs neglect. Scope is tight (a frozen 60-100 item suite, one harness, three protocols, accuracy-with-CIs output) and self-contained with explicit success criteria.

# Alternative Framings

- Frame as a reproducibility audit: use the suite to re-test a specific published debate-vs-consultancy claim and report whether it replicates with open models, making replication the headline deliverable.
