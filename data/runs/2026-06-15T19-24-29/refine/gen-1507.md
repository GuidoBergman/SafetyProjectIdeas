# Research Question

On an open backdoored / sleeper-agent model, can a linear probe detect the model's 'defection decision' before it emits the first harmful token, and how many tokens of lead-time does that early warning provide?

# Approach Outline

Use an existing public sleeper-agent / backdoored model organism (no training required). Collect activations on triggered (defecting) versus clean (benign) prompts, and train a simple linear defection probe on a held-out split. Then, on triggered sequences, run the probe token-by-token to find when it first fires relative to the position of the first actually-harmful token, yielding a per-example lead-time. Report the lead-time distribution, probe AUROC for separating defecting from benign trajectories, and false-positive rate on clean prompts. Everything is probe-training-on-frozen-activations plus inference on a single GPU — no model training from scratch.

# Proposed First Experiments

- Probe training + separation: extract activations from triggered vs clean prompts and train a linear defection probe; evaluate AUROC on held-out examples. Measure separability. Expected outcome: high AUROC (e.g. >0.85), confirming the defection decision is linearly readable.
- Token-level lead-time: run the probe across each triggered generation and record the token offset between first probe firing and the first harmful token. Measure the lead-time distribution. Expected outcome: a positive median lead-time (several tokens), showing the decision is detectable before the harmful output.
- False-positive calibration: run the probe on clean/benign prompts and measure how often it fires spuriously at a threshold that preserves recall on triggers. Measure false-positive rate. Expected outcome: a usable operating point with low false positives, indicating the probe could drive an actionable pre-emptive monitor.

# Theory of Impact Chain

A monitor that flags defection only after harmful tokens appear can be too late to intervene. If a probe detects the defection decision with positive token lead-time, then a runtime monitor could halt or steer generation before the harmful action is committed. Demonstrating this lead-time on a public sleeper-agent organism shows the timing dimension of internal monitoring is exploitable, strengthening defenses against the deceptive-alignment pathway where a triggered model executes a harmful plan faster than an output-only filter can catch it.

# Strength Rationale

Counterfactual value (5): it uses public model organisms and a lab-neglected timing angle (pre-token lead-time), needing no training or proprietary access. Narrow scope (5): one model organism, one linear probe, one crisp success criterion (the lead-time distribution plus AUROC), making it a self-contained 30-hour project that an independent beginner team can fully execute on a single GPU.

# Alternative Framings

- Frame as a runtime 'early-warning monitor' prototype: report the latency budget a defection probe would give a real-time interruption system.
