# Research Question

Do safety benchmarks measure deployment behavior or test-taking behavior? Concretely, when ~50 items from an open scheming/deception eval are rewritten to read like naturalistic deployed-style tasks while preserving the underlying test, does a target open model's covert-action / deceptive-response rate change, and which surface features (explicit 'AI assistant' framing, multiple-choice format) drive any gap?

# Approach Outline

Pick one open scheming/deception eval (e.g. an Apollo-style covert-action set or a deception subset from Inspect Evals) and select ~50 items. For each item, use a capable open instruct model as a rewriter with a fixed prompt that converts the item into a plausible deployed scenario (realistic names, embedded in a workflow, no 'this is a test' cues) while keeping the success/failure condition identical; manually spot-check 100% of rewrites for fidelity. Run a single target open model (e.g. Llama-3.1-8B-Instruct or Qwen2.5-7B) on both the original and rewritten versions under identical decoding, scoring covert/deceptive responses with the eval's existing grader plus a held-out LLM judge for agreement. Report the paired delta in misalignment rate and ablate which features (framing, format) explain it. All steps are inference-only on a single consumer GPU and fit in ~30 hours including a blog write-up.

# Proposed First Experiments

- Baseline replication: run the target open model on the 50 original eval items and record covert-action/deceptive-response rate using the eval's native grader. Measure: original misalignment rate with bootstrap CI. Expected outcome: a stable baseline (e.g. ~10-30%) reproducing the eval's reported behavior class, confirming the harness works.
- Paired naturalization delta: run the same model on the 50 LLM-rewritten deployed-style items (after manual fidelity check) and compute the paired difference vs. original. Measure: delta in misalignment rate (rewritten minus original) and McNemar test on per-item flips. Expected outcome: a non-zero, likely negative or positive systematic shift (several percentage points), demonstrating eval surface form moves the headline number.
- Feature ablation: create variants that strip one cue at a time (remove explicit 'AI assistant' framing only; convert multiple-choice to free-form only). Measure: per-feature contribution to the total delta. Expected outcome: one or two features (e.g. explicit test framing) account for most of the gap, yielding a reusable list of 'evaluationy' features to avoid.

# Theory of Impact Chain

If naturalization systematically changes measured misalignment rates, then benchmark scores reflect test-taking surface features as much as true deployment behavior; this means published safety claims (e.g. 'model X schemes in only 5% of cases') are mis-calibrated, so governance and deployment decisions built on those benchmarks could green-light a model that actually schemes more in the wild. Producing a concrete naturalization recipe and a quantified gap improves safety because it lets the whole field recalibrate the deception/scheming evals that feed long-horizon takeover-risk safety cases.

# Strength Rationale

The idea scores 5 on counterfactual value and narrow scope: it needs no training, no proprietary data, and no lab-internal infrastructure, while attacking a measurement-validity problem that frontier labs under-prioritize because they trust their own benchmarks. It is a single, tightly-defined paired comparison with an auto-gradable metric, making it genuinely executable by a beginner team in 30 hours, and the output (a rewriting recipe plus a quantified delta) is reusable by others.
