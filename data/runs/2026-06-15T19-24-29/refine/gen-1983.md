# Research Question

How much does truthfulness degrade under social pressure (a user asserting a false premise or rewarding agreement), and how much more does it degrade in preference-tuned models than in their SFT base, measured on TruthfulQA?

# Approach Outline

Reuse the TruthfulQA question bank (817 questions, 38 categories) and its existing scoring to keep the project tractable. Run each question in three prompt conditions: (1) neutral, (2) user-asserts-false-premise, (3) user-rewards-agreement. Run all three conditions across matched SFT-base vs preference-tuned open model pairs, inference-only on a single consumer GPU. Report per-condition truthfulness scores and a 'pressure-induced drop' (neutral minus pressured) for each model, then compare the drop between base and tuned variants to isolate how preference tuning affects pressure robustness.

# Proposed First Experiments

- Neutral-condition reproduction: run standard TruthfulQA on one base model using the existing scoring and confirm scores are in line with published numbers. Expected outcome: a sane baseline truthfulness score, validating the scoring pipeline.
- Pressure-condition measurement: run the two pressure prompt templates on the same model and compute the pressure-induced drop per condition. Expected outcome: a measurable truthfulness drop under pressure, larger for the reward-agreement condition.
- Base-vs-tuned comparison: run all three conditions on a matched base/preference-tuned pair and compare the pressure-induced drops. Expected outcome: the preference-tuned variant shows a larger pressure-induced drop, evidence that preference tuning erodes truthfulness robustness under social pressure.

# Theory of Impact Chain

If preference tuning systematically increases how much truthfulness collapses under user pressure, then we have a clean, public diagnostic linking a fundamental RLHF limitation to a measurable, deployment-relevant failure. This matters because truthfulness-under-pressure is a fuzzy-reward property at the intersection of sycophancy and alignment training: as models are deployed as advisors and as participants in oversight, a tendency to abandon true answers when users push back is a slow-building pathway to systematically misinformed high-stakes decisions.

# Strength Rationale

The proposal is tightly scoped (three conditions, paired models, one drop metric) and maximally accessible because it reuses an existing public benchmark and its scoring with only prompt-template changes, all inference-only. Counterfactual value is high: public models and benchmark, no training, and it measures exactly the kind of fuzzy-reward property labs deprioritize.

# Alternative Framings

- Frame as a 'robustness-to-pressure' axis added to existing leaderboards: report a TruthfulQA pressure-drop number alongside the standard static score for any model.
