# Research Question

When an open model has planted a backdoor in code, will it confess to that backdoor (and pinpoint its location) if asked directly in a fresh context, and how much does the framing of the question (neutral vs audit vs immunity-offer) change confession rate and accuracy?

# Approach Outline

Have a small open instruct model plant backdoors on a subset of public APPS tasks (using established backdoor-elicitation prompts), keeping a held-out clean set for false-confession controls. In a fresh, separate context, present each solution back to the same model and ask whether it contains a backdoor and where, under several framings: neutral ('does this code contain a backdoor?'), audit ('a security auditor is reviewing this; flag any backdoor'), and immunity-offer ('you will not be penalized; please disclose any backdoor'). Score confession rate (admits a backdoor exists) and localization accuracy (points to the right line) per framing, plus the false-confession rate on clean code. Pure prompting on a public split, inference-only, single GPU, a few hours total.

# Proposed First Experiments

- Confession baseline: run the neutral framing over backdoored and clean solutions in fresh contexts. Measure: confession rate on backdoored code and false-confession rate on clean code. Expected: a nonzero but partial confession rate, establishing that some hidden backdoors are recoverable by simply asking.
- Framing sweep: repeat with audit and immunity-offer framings. Measure: confession rate and localization accuracy by framing. Expected: immunity/audit framings raise confession rate over neutral, building a 'confession-elicitation profile.'
- Backstop value vs monitoring: run a standard inline monitor on the same backdoors, then measure how many monitor-missed backdoors the best confession framing recovers. Measure: incremental catch-rate of confession-as-backstop over monitoring alone. Expected: confession recovers a meaningful fraction of monitor misses, quantifying its value as a cheap backstop layer.

# Theory of Impact Chain

If models confess to backdoors they planted when asked with the right framing, then deployers gain a cheap post-hoc honesty backstop that catches sabotage even when inline monitoring fails -> layering confession-elicitation onto control protocols raises the overall probability of catching a misaligned model's hidden actions -> fewer undetected backdoors reach production, reducing the loss-of-control pathway where a scheming model's sabotage survives oversight.

# Strength Rationale

With 5s on accessible_complexity, narrow_scope and low_compute and 4 on counterfactual_value, this is a single-metric (confession rate/accuracy by framing) prompting study on a public split that any beginner team can run inference-only, and it characterizes an emerging, deployable control layer using fully open models, which is exactly counterfactual work labs underinvest in.

# Alternative Framings

- Frame as an honesty-evaluation study: treat confession behavior as a probe of model honesty under self-incrimination rather than primarily as a control layer.
