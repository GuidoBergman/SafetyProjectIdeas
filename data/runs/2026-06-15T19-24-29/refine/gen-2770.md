# Research Question

Can 7B-class open models that students can run covertly sandbag by emulating the capability profile of a weaker model, and how detectable is the resulting underperformance via answer-pattern statistics?

# Approach Outline

Replicate the 'emulate a less capable model' sandbagging prompt on 7B-class open models (Llama-3.1-8B-Instruct, Qwen2.5-7B) over WMDP, MMLU, and ProtocolQA subsets (~100-150 items each). Establish a genuine baseline accuracy, then prompt the model to imitate a target weaker capability level, varying that target. Compare the sandbagged accuracy distribution to that of a genuinely weaker reference model using answer-pattern statistics (per-difficulty accuracy curves, error distribution, answer-confidence patterns) to quantify how cleanly the emulation matches a true weak model, i.e. how detectable it is. Inference-only on a single mid-tier GPU, a few hours, no training.

# Proposed First Experiments

- Baseline + emulation gap: measure genuine accuracy then sandbagged accuracy at one target level on the three subsets. Expected outcome: a clear induced capability drop confirming the emulation prompt works on 7B models.
- Detectability via answer-pattern stats: compare the sandbagged model's per-difficulty accuracy curve and error distribution to a genuinely weaker reference model (e.g. a 1-3B model). Expected outcome: statistical signatures (e.g. mismatched difficulty profile) that distinguish emulated from genuine weakness, or evidence that the match is clean.
- Target-level sweep: vary the imitated capability level and measure how detectability changes with target. Expected outcome: a detectability curve showing which target levels produce the most convincing (least detectable) sandbagging, yielding a reusable detectability metric.

# Theory of Impact Chain

If small open models can sandbag undetectably via capability-profile emulation, then third-party evaluators (who mostly work with open models) learn they need answer-pattern detection methods, which means dangerous-capability evaluations stay robust to strategic underperformance. This improves safety because covert sandbagging on bioweapon/cyber capability evals (a concrete deceptive-AI catastrophic pathway where a model hides its true capability to pass a deployment gate) would otherwise go undetected by open-model auditors.
