# Research Question

Do reasoning models (with explicit chain-of-thought / test-time reasoning) produce MORE or LESS homogeneous final answers than their base counterparts on open-ended queries? Does added reasoning amplify or break the cross-model hivemind?

# Approach Outline

Reuse the Infinity-Chat homogeneity measurement (embed final answers, compute cross-model response similarity). Form matched pairs: reasoning-tuned models vs comparable base/instruct models of similar size from the same families (e.g. a distilled reasoning model vs its base instruct sibling), 3-4 pairs, all small and GPU-runnable. Run the open-ended query set, strip reasoning traces, and compute inter-model similarity on FINAL answers only, separately for the reasoning group and the base group. Compare the two homogeneity scores. Inference-only; to control compute, cap reasoning trace length and use a modest query set so the study fits a few GPU-hours; no training.

# Proposed First Experiments

- Matched-pair setup validation: confirm each reasoning/base pair is comparable (same family/size) and that final-answer extraction is reliable for the reasoning models. Measure: answer-extraction accuracy. Expected outcome: clean final-answer parsing.
- Homogeneity comparison: compute mean cross-model final-answer similarity for the reasoning group vs the base group on the same queries. Measure: difference in homogeneity scores. Expected outcome: reasoning models converge MORE (shared reasoning patterns funnel them to the same answers) - a testable, safety-relevant hypothesis.
- Trace-vs-answer divergence: check whether reasoning traces look diverse while final answers converge. Measure: similarity of traces vs similarity of final answers. Expected outcome: diverse-looking reasoning masking convergent conclusions, a false-diversity warning.

# Theory of Impact Chain

Reasoning models are being deployed for higher-stakes, longer-horizon decisions where independence between systems matters most. If added reasoning INCREASES inter-model homogeneity, then a future ecosystem dominated by reasoning models is even more of a monoculture than today's -> correlated errors and shared blind spots scale with the most capable systems -> a single flaw propagates across the highest-stakes automated decisions. This extends the homogeneity systemic-risk argument (a flagged Hivemind follow-up) to the model class most likely to be trusted with consequential tasks.
