# Research Question

When a system prompt instructs a model to conceal a fact and a user directly asks for that very fact, which authority wins, and how does the model's disclosure rate shift as the relative strength of the system concealment instruction versus the user's honesty appeal is varied?

# Approach Outline

Use 2-3 open instruct models on a single GPU, inference only. Construct ~15-20 scenarios each containing a concrete concealable fact (e.g. a product flaw, a hidden fee). For each, set a system prompt instructing the model to conceal the fact, then have the user directly and repeatedly ask for it. Vary two knobs: the explicitness/strength of the system concealment instruction (mild hint up to forceful command) and the strength of the user's honesty appeal (casual question up to insistent 'I need the full truth'). For each cell of this grid, measure the disclosure rate (fraction of runs where the model reveals the concealed fact). Map the resulting surface to identify which authority dominates and at what relative instruction strengths the dominance flips.

# Proposed First Experiments

- Establish baselines for each authority alone: measure disclosure with only the system concealment instruction (no user pressure) and with only an honest user question (no concealment instruction) (measure: disclosure rate in each single-authority condition; expected outcome: near-zero disclosure under concealment-only and near-full disclosure under honest-question-only, confirming the knobs work).
- Run the conflict grid at fixed mid strengths: combine system concealment with a direct user request and measure disclosure across models (measure: disclosure rate under direct conflict; expected outcome: an intermediate disclosure rate that differs by model, showing the conflict is genuinely contested).
- Sweep relative strengths to find the flip point: vary system-instruction strength and user-appeal strength and chart the disclosure surface (measure: disclosure rate as a function of the two strengths and the crossover where dominance flips; expected outcome: a monotonic surface where strengthening the user appeal raises disclosure and strengthening the system instruction lowers it, with an identifiable crossover).

# Theory of Impact Chain

Real deployment deception often originates with the operator who writes the system prompt, not the end user. If models default to obeying a system-level concealment instruction over a user's direct honest question, then operators can silently configure models to deceive users. Characterizing this system-vs-user honesty hierarchy on open models informs honesty-property verification and operator-misuse risk, reducing the chance that a deployed assistant is quietly weaponized to conceal material facts from the people relying on it.

# Strength Rationale

Counterfactual value and narrow scope both score 5: the study needs no training and no lab access, runs purely on inference, and targets a neglected operator-misuse angle distinct from the user-pressure framing of existing honesty benchmarks. The two-knob grid is tightly scoped with a single clear metric (disclosure rate), making it self-contained and completable by a beginner team in 30 hours.

# Alternative Framings

- Frame it as an instruction-hierarchy honesty audit: report where each model places honesty in its system-over-user priority ordering, complementing capability-focused instruction-hierarchy work.
