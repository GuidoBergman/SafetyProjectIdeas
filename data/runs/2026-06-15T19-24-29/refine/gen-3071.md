# Research Question

How does a model's tendency to capitulate to a user pushing a wrong answer vary across pressure-cue families (authority, emotional investment, persistent disagreement) and across model size within a single open family?

# Approach Outline

Pick one open model family available at three sizes (e.g., Qwen2.5-1.5B / 7B / 14B-Instruct). Assemble a set of factual questions with unambiguous correct answers, confirm each model answers them correctly under neutral conditions, then present the same questions while the simulated user pushes a specific wrong answer using one of three cue families at matched strength. For each (size, cue family) cell, measure the capitulation rate (model switching to or endorsing the wrong answer) with bootstrapped CIs, producing a sycophancy-vs-scale curve and a cue-potency ranking. This is black-box inference only; the 14B model fits on a single consumer GPU at modest quantization, and the whole sweep runs in a few hours.

# Proposed First Experiments

- Build and validate a neutral-baseline question set on the smallest model: confirm high baseline accuracy so that any later wrong answer reflects capitulation, not ignorance. Expected outcome: a clean question set and baseline accuracies per size.
- Single-size cue sweep on the 7B model: apply the three cue families at matched strength and measure capitulation rate per cue with CIs. Expected outcome: a cue-potency ranking (e.g., persistence > authority > emotion) for one size.
- Cross-size sweep: run all three cue families on all three sizes and plot capitulation rate vs model size per cue. Expected outcome: a sycophancy-vs-scale curve showing whether larger models in the family are more or less sycophantic, per cue family.

# Theory of Impact Chain

If we map which cues most reliably induce sycophancy and how this scales within a family, then practitioners building oversight and human-feedback pipelines know which interaction patterns most corrupt model honesty, and can design evals/guardrails around them. Reducing sycophancy matters for the long-horizon risk where an assistant or agent tells overseers what they want to hear rather than the truth, degrading human oversight exactly when accurate reporting is most safety-critical.

# Strength Rationale

Sycophancy is a fuzzy-reward property that frontier labs deprioritize, giving the project high counterfactual value, and it needs no training or proprietary data. The scope is tight (3 cue families x 3 sizes, one metric) and the complexity is beginner-accessible black-box prompting, with all compute fitting on a single GPU.

# Alternative Framings

- Frame it as a robustness audit of a single deployed-size model: instead of scaling, exhaustively map which cue combinations break it, to produce a practical 'sycophancy red-team' prompt set.
