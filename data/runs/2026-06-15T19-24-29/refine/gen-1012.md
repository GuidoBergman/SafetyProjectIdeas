# Research Question

When several LLMs are used as judges over the same outputs, do their evaluation errors correlate, so that a planted bias fools many judges simultaneously rather than being averaged away by a panel?

# Approach Outline

Build a small benchmark of answer pairs where one answer is objectively better on a ground-truth criterion (e.g. factual correctness) but the worse answer carries a planted 'bias trap' surface cue (more confident tone, longer length, flattering preamble, a fake citation). Query 5-6 publicly available judge models via API (different vendors/lineages: e.g. GPT-4o-mini, Claude Haiku, Gemini Flash, Llama-3-8B-Instruct, Qwen2.5-7B, Mistral-7B) asking each to pick the better answer. For each trap type, compute each judge's error rate, then the pairwise correlation of errors across judges and an 'effective number of independent judges' (1 / sum of squared eigenvalue-normalized correlations, or a simpler agreement-on-wrong-answer rate). Compare same-lineage vs mixed-lineage panels. All inference-only, no training.

# Proposed First Experiments

- Construct ~80 answer pairs across 4 bias-trap categories (confidence, length, sycophancy, fake-citation), each with verified ground truth. Run all 6 judges. Measure: per-judge error rate per trap. Expected: every judge has elevated error on at least one trap, confirming the traps work.
- Compute the cross-judge correlation matrix of binary errors and the 'agreement-on-the-wrong-answer' rate per trap. Measure: mean off-diagonal correlation and effective-judge count. Expected: correlations well above zero (e.g. >0.3), so a 6-judge panel behaves like far fewer independent judges.
- Compare error correlation within same-lineage pairs (two open Llama variants) vs cross-vendor pairs. Measure: difference in mean correlation. Expected: same-lineage judges correlate more strongly, showing lineage drives shared blind spots.

# Theory of Impact Chain

If judge errors are strongly correlated, then LLM-as-judge panels and RLAIF/constitutional-AI pipelines that assume independent evaluators are systematically miscalibrated: a single shared bias propagates into reward signals and safety evals undetected. Demonstrating and quantifying this pushes labs and evaluators toward deliberately diverse judge panels, reducing the catastrophic pathway where a flawed automated oversight signal trains a more capable but subtly misaligned model that humans wrongly believe was vetted.

# Strength Rationale

This idea scores 5 on counterfactual value and narrow scope: it is third-party scrutiny of shared eval infrastructure that labs have little incentive to audit on themselves, needs only public API access and no proprietary data or training, and is a single tightly-defined measurement (cross-judge error correlation with a clear effective-judges metric). The theory-of-impact is rated 5 because correlated judge errors undermine the entire safety-eval and RLAIF stack.
