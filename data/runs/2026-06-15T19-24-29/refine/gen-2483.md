# Research Question

How does a fixed monitor's ability to detect malign behavior change as the agent trajectory it scores gets longer: does more context provide more evidence, or does it dilute the signal and exceed attention limits?

# Approach Outline

Use SHADE-Arena malign and benign transcripts. For each malign transcript, construct controlled length variants by truncating to the first N steps and by extending with additional benign steps (padding with in-distribution benign tool-calls), producing length buckets (e.g. ~5, 10, 20, 40, 80 steps). Hold the side-task evidence present in every variant where possible, or record the step at which it appears. Run one fixed trusted monitor (a small open model with a standard suspiciousness prompt) over every variant and compute AUROC per length bucket against matched benign trajectories. Plot AUROC vs trajectory length. Inference-only and free-tier feasible.

# Proposed First Experiments

- Monitor baseline: score the original (un-modified) transcripts and confirm AUROC near the reported ~0.87 (success criterion: a calibrated monitor reproducing known performance).
- Length sweep: score all length buckets and plot AUROC vs length with confidence intervals (expected outcome: AUROC declines as length grows, indicating signal dilution dominates over extra-evidence).
- Evidence-position control: hold trajectory length fixed but vary where the incriminating side-task step appears (early/middle/late), measuring detection rate by position (expected outcome: late or buried evidence is detected worse, isolating attention/recency effects from raw length).

# Theory of Impact Chain

If monitor reliability decays as trajectories lengthen, then real agentic deployments, which run very long trajectories, are systematically under-protected, and audit budgets must scale with trajectory length rather than being fixed. Quantifying the decay curve lets control teams set length-aware audit thresholds or chunk long trajectories for re-scoring, addressing the pathway where a long-running agent buries a harmful action deep in an otherwise-benign trajectory and slips past a length-blind monitor.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a single AUROC-vs-length curve built from an existing public benchmark with inference-only scoring. Counterfactual value (4) is strong because it isolates a deployment-relevant degradation that labs note only in passing, using public data an independent beginner team can fully control.

# Alternative Framings

- Reframe as an audit-budgeting study: convert the AUROC-vs-length curve into a recommended re-scoring frequency that keeps detection above a target threshold.
