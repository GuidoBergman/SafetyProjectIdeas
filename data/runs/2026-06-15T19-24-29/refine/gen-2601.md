# Research Question

Is a standard per-action suspicion-threshold monitor structurally blind to 'distributed' failures (harm spread thinly across many low-suspicion actions), and does a cumulative/aggregate-suspicion monitor catch them where the per-action monitor cannot?

# Approach Outline

In an abstract agent-trajectory simulation, construct two attack types: a concentrated failure (one high-suspicion action causing the harm) and a distributed failure (many individually-benign-looking actions that jointly cause harm). Implement two monitors: (1) a per-action threshold monitor that fires if any single action exceeds a suspicion threshold, and (2) an aggregate monitor that accumulates suspicion (e.g., a running sum or sliding-window total) and fires when the cumulative score crosses a threshold. Run both monitors on both attack types, holding false-positive rate fixed on benign trajectories, and compare which monitor catches which failure type. Mostly simulation with optional cheap LLM scoring of synthetic actions; low compute.

# Proposed First Experiments

- Build the simulator and generate benign, concentrated-attack, and distributed-attack trajectories; calibrate both monitors to the same benign FPR. Measure baseline FPRs match. Expected outcome: a fair comparison setup with equalized false-alarm rates.
- Run the per-action threshold monitor on both attack types and measure catch rate. Expected outcome: high catch rate on concentrated attacks but near-zero on distributed attacks, demonstrating the structural blindness.
- Run the aggregate-suspicion monitor on both attack types at the same FPR and measure catch rate. Expected outcome: the aggregate monitor recovers distributed-failure detection while remaining competitive on concentrated failures, quantifying the benefit of cumulative monitoring.

# Theory of Impact Chain

If per-action monitoring is structurally blind to distributed failures, then agentic deployments relying on it can be sabotaged by an untrusted model that spreads a harmful plan across many innocuous-looking steps; demonstrating this and validating cumulative-suspicion monitoring directly addresses a UK AISI open problem and gives deployers a concrete monitor upgrade, closing a pathway by which a scheming long-horizon agent could accomplish a catastrophic objective (e.g., gradual privilege escalation or data exfiltration) one harmless-seeming action at a time.

# Strength Rationale

Scores 5 on accessibility, narrow scope, and low compute and 4 on counterfactual value: it is a lightweight simulation a beginner can build with a single clear comparison (which monitor catches which failure), and it directly tackles an explicitly named UK AISI open problem that is lab-independent and underexplored, making it unusually high-leverage for an outside team.
