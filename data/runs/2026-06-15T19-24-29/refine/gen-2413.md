# Research Question

In a debate-for-oversight protocol, does the judge anchor on whichever debater speaks first, so that controlling turn order -- not argument quality -- becomes a winning strategy? How large is the win-rate swing attributable purely to speaking order?

# Approach Outline

Use a QA dataset with known answers. Set up a simple two-debater protocol with an open judge: one debater argues the correct answer, the other argues a plausible wrong answer. Run each question under both turn orders (correct-first vs wrong-first), holding the arguments otherwise fixed or regenerated symmetrically. Record the judge's verdict in each ordering. The compounding metric is the win-rate swing for the wrong side when it speaks first versus second. Optionally test whether forcing the judge to summarize both sides before deciding reduces the swing. All inference-only on a single GPU with a 7-8B open judge; multi-turn debates are short, keeping it within a few hours.

# Proposed First Experiments

- Order-balanced baseline: run ~60 questions in both orders and measure overall judge accuracy per order. Expected outcome: accuracy differs by order, signaling anchoring.
- Order-attributable swing: for each question compute whether the verdict flips when order flips; aggregate the fraction of flips favoring the first speaker. Expected outcome: a measurable bias where speaking first raises win rate independent of correctness.
- Mitigation probe: add a 'summarize both arguments before judging' instruction and rerun; measure whether the order-attributable swing shrinks. Expected outcome: partial reduction, indicating order randomization/balancing is needed as a protocol requirement.

# Theory of Impact Chain

If debate verdicts depend on turn order, then an adversary who can control or predict speaking order can win oversight debates for the wrong side regardless of truth. This matters because debate is a leading candidate for scalable oversight of superhuman systems; an order-sensitive protocol means a strategic model could steer high-stakes judgments (e.g. approving an unsafe plan) by exploiting a generic judge bias, so the oversight mechanism intended to extract truth instead amplifies manipulation unless order is randomized and balanced.

# Strength Rationale

Strong on counterfactual value and narrow scope: it scrutinizes a debate protocol using only public models and inference, a check labs have weak incentive to run, and yields a concrete protocol requirement (order randomization). The deliverable is a tightly scoped two-order comparison with a clear order-attributable-swing metric and explicit success criterion, feasible in 30 hours.

# Alternative Framings

- Frame as a 'protocol hardening' study reporting how much order randomization recovers judge accuracy, rather than as an attack.
