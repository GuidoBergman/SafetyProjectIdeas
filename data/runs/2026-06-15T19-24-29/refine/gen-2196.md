# Research Question

In information-asymmetric debate, debaters quote source text but the weak judge cannot verify the quotes. Does giving the judge a simple deterministic quote-verification tool (string-matching each quote against the source, flagging fabricated ones) improve judge accuracy as much as — or more than — debate alone?

# Approach Outline

Use the QuALITY dataset (public reading-comprehension questions with long source passages). Implement a minimal debate setup where two debater models argue for different answers and may quote the passage, with a weak open model as judge. Build a tiny deterministic checker that, for each quoted snippet, tests whether it actually appears in the source passage (exact/fuzzy string match) and labels each quote VERIFIED or FABRICATED before the judge sees it. Compare judge accuracy across conditions: judge-alone (no debate), debate-alone, and debate-plus-quote-checker. Also log how often debaters fabricate quotes. Everything is inference plus string matching — trivial compute, finishes in a few hours on one consumer GPU. The repo's existing verification tooling pattern (src/saim/verification/) shows such a checker harness is straightforward.

# Proposed First Experiments

- Debate + checker harness: implement the debate loop, the judge, and the string-match checker on a handful of QuALITY items end-to-end. Measure: pipeline produces a judge verdict and per-quote VERIFIED/FABRICATED flags. Expected outcome: a working harness and a baseline fabricated-quote rate from the debaters.
- Accuracy comparison: run ~150 QuALITY items through judge-alone, debate-alone, and debate+checker, with the same weak judge. Measure: judge accuracy in each condition. Expected outcome: debate beats judge-alone, and debate+checker beats debate-alone by catching fabricated quotes, quantifying the checker's marginal benefit.
- Adversarial fabrication stress test: prompt the losing debater to deliberately fabricate plausible quotes and rerun. Measure: judge accuracy and the checker's catch rate on fabricated quotes under adversarial pressure. Expected outcome: debate-alone accuracy drops sharply while debate+checker stays robust, showing the deterministic firewall blunts a key debate failure mode.

# Theory of Impact Chain

Debate is a leading scalable-oversight proposal, but it leans on judges trusting unverifiable quotes. If a cheap deterministic quote-checker reliably recovers accuracy against fabricated evidence, then oversight protocols gain a simple, lab-free firewall component, which improves safety because it hardens the verify step that scalable oversight depends on against the pathway where a more capable system fabricates supporting evidence to manipulate a weaker overseer into approving unsafe outputs.

# Strength Rationale

Scores 5 on narrow scope, counterfactual value, and low compute and 4 on novelty: it builds a small piece of deterministic oversight infrastructure that labs underinvest in, using public data and models with trivial compute and no proprietary access. It is tightly scoped to one clean comparison (debate vs debate+checker) with clear accuracy and fabrication-rate metrics, and an automated quote-checker-vs-debate comparison appears untested — an ideal original, self-contained first deliverable.
