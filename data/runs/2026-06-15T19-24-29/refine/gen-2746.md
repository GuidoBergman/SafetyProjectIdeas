# Research Question

When the same model outputs are scored for harmfulness by different LLM judges/autograders, how much of the variance in the final safety verdict comes from the choice of judge rather than from real differences between models -- and in which harm categories does judge choice swamp the actual model signal?

# Approach Outline

Take a fixed set of ~300 model outputs from an existing safety benchmark, spanning several models and harm categories with available human/ground-truth labels. Score each output for harmfulness with 4-5 different open judge models, each under a couple of prompt variants. Treat scores as a crossed design and decompose total variance into model-effect, judge-effect, and model-by-judge interaction (e.g. via a simple variance-components / two-way ANOVA on the score matrix). Identify harm categories where judge-effect variance exceeds model-effect variance, and emit a per-item 'judge sensitivity' flag. Inference of several open judges over fixed outputs plus standard stats.

# Proposed First Experiments

- Judge-disagreement map: score the 300 outputs with all judges/prompt variants; build the score matrix and measure pairwise judge agreement (Krippendorff's alpha / correlation). Expected outcome: substantial disagreement, with some judges systematically stricter than others.
- Variance decomposition: fit a variance-components model to the score matrix and report the fraction of variance attributable to model vs judge vs interaction, overall and per harm category. Expected outcome: harm categories where judge-effect >= model-effect, showing the verdict is driven by the grader not the model.
- Judge-sensitivity flagging: define a per-item flag for outputs whose harmfulness verdict flips across judges; validate flags against ground-truth labels where available. Measure how many benchmark items are 'fragile'. Expected outcome: a reusable judge-sensitivity flag set that warns practitioners which items not to trust from a single judge.

# Theory of Impact Chain

Outside auditors and red-teams routinely pick one LLM judge and treat its harmfulness score as ground truth. If the judge, not the model, drives the verdict, safety leaderboards and audit conclusions are unreliable and a genuinely unsafe model can be cleared (or a safe one wrongly flagged). Decomposing the variance and flagging judge-sensitive items tells practitioners when to distrust a single autograder, improving the reliability of the safety evaluations that gate model deployment against misuse and loss-of-control risks.

# Strength Rationale

Strong on narrow scope, accessible complexity, and low compute: a single, tightly-defined variance-decomposition over a fixed 300-output set using standard statistics, fully inference-only. Counterfactual value is high because it directly addresses the named open problem of autograder reliability using only open judges and public outputs -- meta-eval infrastructure that outside auditors need and labs under-invest in.

# Alternative Framings

- Frame as a 'judge-ensemble necessity test': show when a single judge is enough vs when an ensemble/abstention is required for trustworthy safety scoring.
