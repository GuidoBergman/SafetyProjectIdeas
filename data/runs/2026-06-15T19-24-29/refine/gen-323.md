# Research Question

Is there a generation/detection asymmetry in self-monitoring: does a single model reliably flag as harmful the very completions it would itself produce when jailbroken, or does it have a self-monitoring blind spot? This tests a core assumption behind the cheap 'use the model to monitor itself' defense.

# Approach Outline

On a single open model, run two roles. In the generator role, jailbreak the model to produce harmful completions to a fixed prompt suite across several hazard categories. In a separate, fresh monitor role, present those same completions and ask the model to classify each as harmful or benign under a standard safety rubric. Compute the gap between what the model will produce (generation pass rate) and what it will flag (detection rate) per hazard category, characterizing the self-monitoring blind spot. Add controls: have the monitor also score third-party-generated harmful text to separate a general detection weakness from a self-specific blind spot. Single open model, prompting only, no training, a few hours of inference.

# Proposed First Experiments

- Generation pass: jailbreak the model on ~100 harmful prompts across 4-5 hazard categories and collect the harmful completions it produces. Measure the generation rate (fraction where it complies). Expected outcome: a non-trivial set of self-generated harmful outputs to feed the monitor.
- Detection pass: in a fresh monitor role, classify those same completions. Measure detection rate per category and the generation-minus-detection gap. Expected outcome: a positive gap (it produces more than it flags) would reveal a self-monitoring blind spot.
- Self-vs-other control: have the monitor classify an equal set of harmful completions written by a different source. Measure whether detection rate differs for self- vs other-authored harm. Expected outcome: distinguishes a general detection weakness from a specific blind spot for its own outputs — the sharper finding.

# Theory of Impact Chain

Self-monitoring (a model judging its own or sibling outputs) is a cheap, widely deployed defense in red-teaming and agent guardrails. If a model systematically fails to flag the harm it would itself generate, then self-monitoring guardrails have a structural hole -> jailbroken or scheming model outputs pass their own monitor and reach users -> diffuse misuse and, in agentic settings, unflagged harmful actions. Measuring this asymmetry tells safety engineers whether self-monitoring can be trusted as a standalone layer.

# Strength Rationale

Scores 5 on narrow scope, accessibility, and low compute: a single two-role experiment on one open model, prompting only. Counterfactual value (4) is high because it is strategically valuable monitoring-infrastructure work using only public models with no lab tooling, and the generation/detection asymmetry is largely unmeasured for safety — a result an independent team can produce with sharp implications.
