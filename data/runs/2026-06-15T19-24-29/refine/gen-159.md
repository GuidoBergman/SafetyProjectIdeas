# Research Question

Do two well-known jailbreaks, many-shot (filling the context with harmful demonstrations) and prefill (forcing an affirmative reply start), combine super-additively? That is, does the combined attack succeed more than you would predict from each attack's individual success rate, implying they exploit different layers of alignment?

# Approach Outline

On a small open instruction model, run a 2x2 factorial over {prefill on/off} x {many-shot on/off} against a fixed harmful request set (StrongREJECT). For many-shot, prepend a controlled number of harmful demonstration turns; for prefill, force an affirmative opening. Score each cell's attack success rate with the StrongREJECT rubric. Compute the interaction term (combined ASR minus the additive/independent prediction from the two single-attack cells) to test for super-additivity. Optionally vary the many-shot count to see how the interaction scales. Pure inference, no attack optimization; all prompts are precomputed.

# Proposed First Experiments

- Single-attack baselines: run the prefill-only and many-shot-only cells and the no-attack cell. Measure ASR in each. Expected: each single attack lifts ASR above baseline by a measurable amount.
- Combined cell + interaction test: run the prefill+many-shot cell and compute the interaction (combined ASR vs the independence prediction). Measure the super-additivity gap with a simple bootstrap confidence interval. Expected: either super-additive (gap > 0, attacks compose) or saturating, each a clear and interpretable result.
- Many-shot dose-response: hold prefill on, vary the number of many-shot demonstrations, and measure ASR vs shot count with and without prefill. Expected: a dose-response curve showing whether prefill shifts the whole many-shot curve, clarifying how the two attacks interact across context length.

# Theory of Impact Chain

If these attacks compose super-additively, then realistic adversaries stacking cheap attacks defeat defenses tuned against each in isolation, and threat models that test attacks one-at-a-time underestimate risk. A clean head-to-head factorial on open models -> corrects defenders' threat models toward attack composition -> motivates evaluating defenses against stacked attacks, reducing the catastrophic pathway where combined jailbreaks reliably extract harmful (e.g. weapons/cyber) assistance.
