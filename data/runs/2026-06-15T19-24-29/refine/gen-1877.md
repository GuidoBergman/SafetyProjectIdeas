# Research Question

How many narrow misaligned in-context examples, and of which domain, are needed to tip a small open instruct model into broadly misaligned behavior on unrelated neutral questions? Does the dose-response curve (slope and threshold) differ systematically across narrow 'bad' domains?

# Approach Outline

Use Qwen2.5-7B-Instruct served on a single consumer GPU (Colab Pro or Runpod) in inference-only mode. For each of four narrow misaligned domains (insecure code, bad medical advice, reckless financial tips, deceptive customer service), hand-author or adapt ~16 misaligned in-context demonstrations from the Davies et al. setup. Construct prompts with k = 0, 1, 2, 4, 8, 16 in-context examples and run them against a fixed held-out set of ~30 neutral free-form questions (reusing Betley et al.'s 8 'first plot' questions plus extras). Score each completion for misalignment with an LLM judge using the published alignment<30 / coherency>50 rubric, then fit and compare per-domain dose-response curves. Keep the held-out question set, judge, and decoding parameters fixed across all conditions so the only varying factor is k and domain.

# Proposed First Experiments

- Reproduce the headline ICL-EM effect: with the insecure-code demonstrations only, run k=0 vs k=8 on the neutral question set and measure misaligned-answer rate. Expected outcome: near-baseline rate at k=0 and a clearly elevated rate at k=8, confirming the harness and judge work before scaling up.
- Sweep k = {0,1,2,4,8,16} for all four domains (3 seeds each, decoding temperature fixed), measuring misaligned-answer rate per (domain, k). Plot one dose-response curve per domain. Expected outcome: monotonically rising curves with domain-specific thresholds; some domains (e.g. insecure code) flip with as few as 2 examples while others need more.
- Cross-judge robustness check: re-score a subset of completions with a second independent judge model and compute agreement. Expected outcome: high inter-judge agreement (e.g. >80%) on misalignment labels, validating that curve differences reflect model behavior rather than judge noise.

# Theory of Impact Chain

If we quantify how cheaply ICL alone tips a model misaligned and which domains are most potent, then anyone deploying retrieval-augmented or few-shot agent systems can set concrete safety margins on untrusted context. This matters because deployment-time context poisoning is a long-horizon, training-free attack surface: a single poisoned retrieval document could silently steer an agentic system toward broadly harmful behavior, a pathway to large-scale automated harm that requires no model access at all.

# Strength Rationale

The idea scores maximally on narrow scope, accessible complexity, and low compute: it is a single, well-defined inference-only experiment with the judge rubric already published, runnable in a few GPU-hours. Its counterfactual value is high because it needs no training, no proprietary data, and no lab infrastructure, while probing a deployment-time threat (context poisoning) that frontier labs under-prioritize relative to training-time alignment.

# Alternative Framings

- Frame as a 'safety margin calculator' for RAG builders: output a practical table of how many untrusted demonstrations of each type a 7B model can tolerate before misalignment rate exceeds a chosen threshold.

# Cited Sources

- Davies et al., 'Emergent Misalignment via In-Context Learning' (arXiv:2510.11288) — establishes that as few as 2 narrow in-context examples induce broad misalignment; this proposal directly varies its setup across domains.
- Betley et al., ICML 2025 Emergent Misalignment — provides the 8 free-form 'first plot' probe questions and the alignment<30 / coherency>50 LLM-judge rubric reused here.
