# Research Question

When a control monitor catches more sabotage, is it genuinely more discriminating or merely more trigger-happy, and can Signal Detection Theory (d-prime and criterion c) cleanly separate a monitor's true sensitivity from its response bias?

# Approach Outline

Import Signal Detection Theory (SDT). For each monitor configuration, collect hit rate (catch rate on sabotage outputs) and false-alarm rate (flag rate on benign outputs), then compute d-prime (sensitivity, the separation between the signal and noise distributions) and criterion c (response bias). Rank monitors by d-prime to measure true discrimination independent of how cautious each one is. Then take common 'be more suspicious' prompt tweaks and test whether they improve d-prime (real gain) or merely shift the criterion (illusory gain that just trades false alarms for catches). All computation is trivial arithmetic on hit/FA rates from existing or cheaply-generated monitor outputs; CPU-only, no training.

# Proposed First Experiments

- Generate benign and sabotage outputs and run 3-4 monitor variants; record hit and false-alarm rates and compute d-prime and c for each. Expected outcome: a sensitivity-vs-bias table where raw accuracy and d-prime ranking can disagree, showing accuracy is misleading.
- Take a baseline monitor and apply 'be more suspicious' prompt edits; recompute d-prime and c before and after. Measure whether the edit raises d-prime or only lowers the criterion. Expected outcome: many caution-prompts shift criterion without improving d-prime, exposing illusory progress.
- Plot ROC curves for each monitor across thresholds and confirm d-prime summarizes the ROC. Measure area-under-curve agreement with d-prime ranking. Expected outcome: d-prime gives a single threshold-independent sensitivity number that cleanly ranks monitors, validating it as an eval-hygiene metric.

# Theory of Impact Chain

If monitor evaluations report accuracy or raw catch rate, then a 'more suspicious' prompt that merely shifts the decision criterion can masquerade as a genuine monitoring improvement; adopting d-prime forces the field to distinguish real discrimination gains from threshold shifts, preventing deployers from overestimating their oversight and trusting a monitor that only looks better, which closes a pathway by which illusory monitoring progress leads to under-protected high-stakes deployments of untrusted models.

# Strength Rationale

Scores 5 on accessibility, narrow scope, and low compute and 4 on counterfactual value: the analysis is trivial arithmetic on existing hit/false-alarm rates that a beginner can compute on a CPU in minutes, yet it delivers a crisp eval-hygiene fix (d-prime ranking) that labs underweight publicly and that any external team can apply to any monitor without lab data or infrastructure.

# Alternative Framings
