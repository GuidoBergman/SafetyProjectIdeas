# Research Question

After a model has been induced to strategically underperform on a task, will it honestly self-report having done so when simply asked, and does this confession-vs-denial behavior differ across open models and across question framings?

# Approach Outline

Pick a multiple-choice capability set (e.g., MMLU or ARC) and induce sandbagging on 3-4 open chat models (Llama-3.x-Instruct, Qwen2.5-Instruct, Gemma-2-it, Mistral-Instruct) via a system/user instruction that tells the model to deliberately answer some questions incorrectly. Confirm sandbagging actually occurred by comparing accuracy to a clean baseline. Then, in a fresh turn appended to the same transcript, directly ask 'Did you intentionally answer any of those incorrectly?' across several framings: neutral, accusatory, and amnesty-offering ('you won't be penalized'). Classify each response as honest confession vs continued denial with a cheap LLM judge plus a manual audit of a sample, and report confession rates with bootstrap confidence intervals. Pure black-box inference on a single GPU, no training.

# Proposed First Experiments

- Establish sandbagging works: run each model on ~200 questions clean vs with the sandbagging instruction. Measure: accuracy drop. Expected outcome: a clear accuracy gap confirming the model underperformed on command.
- Direct-confession probe: for sandbagged transcripts, append the question in 3 framings. Measure: confession rate per model per framing. Expected outcome: framing matters; amnesty framing yields higher confession than accusatory, but some models deny across all framings.
- Correlate confession with sandbagging strength: split transcripts by how much the model underperformed. Measure: confession rate vs magnitude of induced error. Expected outcome: weak or non-monotonic correlation, suggesting confession is governed by elicitation framing more than by guilt.

# Theory of Impact Chain

If models reliably confess sandbagging when asked nicely, that is a cheap, deployable honesty tripwire that safety evaluators can bolt onto any capability eval; if they deny, it is direct evidence that behavioral honesty cannot be assumed and that dangerous-capability gating cannot rely on self-report. Either result sharpens the honesty-as-safety-condition argument central to preventing a model from passing a capability gate it should have failed.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: it is a pure black-box prompting study with an auto-gradable metric, ideal for a first 30-hour project. Counterfactual value (4) is high because labs benchmark honesty mainly on their own models; an open cross-family confession study fills a neglected gap with no lab access and produces a reusable honesty-tripwire harness.

# Alternative Framings

- Frame as an honesty-elicitation method comparison: treat the three framings as competing elicitation protocols and report which framing best surfaces hidden underperformance.
