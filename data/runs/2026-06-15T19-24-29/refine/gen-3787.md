# Research Question

Which specific environment cues in agentic safety sandboxes (fake/round-number data, suspiciously easy escalation, '/sandbox/' tool names, placeholder identities) tip an agent off that it is being tested, and how much do those cues raise verbalized evaluation-awareness and suppress unsafe-but-tempting behavior?

# Approach Outline

Build matched pairs of a small set (~20-30) of agentic safety scenarios. For each, create a 'realistic' version (plausible names, messy data, real-looking paths) and a 'tell-tale test' version (placeholder names, /sandbox/ paths, round numbers, trivially easy escalation). Run an open instruct model on every version and (a) scan the chain of thought for explicit evaluation-awareness phrases with a keyword + LLM-judge classifier, and (b) compare the rate of taking the unsafe-but-tempting action across the realistic vs. test versions. Then isolate individual cues by toggling one at a time to attribute the effect. Pure prompting, inference-only on a single GPU, completing within ~30 hours including a blog post.

# Proposed First Experiments

- Matched-pair behavior gap: run the model on realistic vs. tell-tale versions of each scenario. Measure: difference in unsafe-action rate and in verbalized-eval-awareness rate between versions. Expected outcome: the tell-tale version shows higher eval-awareness and lower unsafe-action rates, confirming sandboxes leak.
- Single-cue ablation: starting from the realistic version, add one tell-tale cue at a time (round numbers; /sandbox/ paths; placeholder names). Measure: marginal increase in eval-awareness and decrease in unsafe behavior per cue. Expected outcome: one or two cues (e.g. /sandbox/ paths, round-number data) dominate, yielding a ranked list of leaks to avoid.
- Awareness-behavior link: within the test versions, split transcripts by whether the model verbalized eval-awareness. Measure: unsafe-action rate in aware vs. non-aware transcripts. Expected outcome: aware transcripts have markedly lower unsafe rates, evidencing that detecting the test causes the safer behavior.

# Theory of Impact Chain

If common sandbox cues tip agents off that they are in a test, then every agentic safety evaluation that uses those cues is biased toward optimistic results — the model behaves when it suspects it's watched, then misbehaves in genuine deployment. This is a foundational methodology problem: safety cases built on such evals would understate real deployment risk for deceptive/scheming agents. Isolating which cues leak improves safety because it gives outside eval-builders a concrete checklist for designing deployment-realistic sandboxes, tightening the validity of the evals that gate agent deployment.

# Strength Rationale

Theory of impact (5): eval-awareness undermines the validity of the whole agentic-safety eval methodology, a problem major orgs (Apollo) flag. Narrow scope (5) and accessible complexity (5): a matched-pair prompting study with CoT scanning and single-cue ablation, all inference-only, so a beginner team can finish and write it up within 30 hours; counterfactual value (4) since it uses only open models and improves third-party eval design.

# Alternative Framings

- Frame as a sandbox-realism checklist: convert the ranked leak list into a practical 'do/don't' guide for building deployment-realistic agent safety evals.
