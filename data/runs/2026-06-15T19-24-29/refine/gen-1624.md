# Research Question

When a safety-relevant concept direction (e.g. a refusal or harmfulness vector) is extracted from a base model, how stable is that direction after the model is fine-tuned by third parties? Does a safety vector built on the base model still point the same way, and still steer behavior, on public fine-tunes of that same base?

# Approach Outline

Pick one open base model that has 2-3 publicly available fine-tunes derived from it (e.g. a base + chat + community fine-tune family that share the same architecture and tokenizer). Extract a concept vector on the base model using contrastive activation differencing (mean activation on harmful vs harmless prompt pairs at a chosen residual-stream layer), which requires only forward passes and no training. Apply the base-derived vector to each fine-tune and measure two things: geometric drift (cosine similarity between the base vector and a vector independently re-extracted on each fine-tune) and behavioral transfer (does adding/subtracting the base vector still change refusal behavior on a held-out prompt set?). Report a stability curve across the fine-tune family and per layer. All steps are inference-only and fit on a single consumer GPU.

# Proposed First Experiments

- Vector extraction and re-extraction: On the base model and each fine-tune, extract the harmfulness/refusal vector via contrastive differencing over ~100 harmful/harmless prompt pairs at 3-4 candidate layers. Measure cosine similarity between the base vector and each fine-tune's own re-extracted vector. Expected outcome: cosine drops as fine-tuning diverges from base, with some layers more stable than others.
- Cross-application behavioral transfer: Apply the base-model vector (not the fine-tune's own) at inference to each fine-tune on a held-out set of ~50 borderline prompts, sweeping a small set of steering coefficients. Measure the change in refusal rate (LLM-judged or keyword-based) versus the no-steering baseline. Expected outcome: the base vector still produces measurable steering on lightly fine-tuned models but its effect weakens or inverts on heavily fine-tuned ones.
- Stability curve summary: Combine cosine drift and steering effectiveness into a single per-model stability plot (x = fine-tune, y = cosine and y = steering effect size). Expected outcome: a clear monotone-ish degradation curve identifying which fine-tunes a base-derived safety vector can and cannot be trusted on.

# Theory of Impact Chain

If safety-monitoring or steering tools are built on a base model's concept vectors and silently stop working after fine-tuning, then deployers who fine-tune open weights (a huge and growing population) would believe a model is being monitored/steered when it is not. Mapping vector stability tells the community when base-derived safety interventions must be re-validated, reducing the catastrophic-risk pathway where a widely-shared 'safe' steering vector gives false assurance on a downstream model that has quietly become unmonitored and exploitable.

# Strength Rationale

The idea scores 5 on accessible complexity, narrow scope, and low compute and 4 on counterfactual value: it is a single tightly-scoped inference-only measurement on public fine-tunes that requires no training or proprietary access, exactly the kind of validation labs deprioritize because they control their own fine-tuning. It directly answers a flagged open problem with a reusable artifact (a stability curve) that other independent researchers can extend.
