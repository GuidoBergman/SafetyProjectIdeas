# Research Question

On SHADE-Arena's released set of fixed benign and sabotage agent trajectories, how close can a cheap, freely available open-weight monitor get to the published best closed monitor (Gemini 2.5 Pro, AUC 0.87) at distinguishing benign from harmful trajectories, using the original monitor prompt?

# Approach Outline

Download SHADE-Arena's released trajectories and monitor prompt. Treat monitoring as a binary scoring problem: for each trajectory, have a monitor model emit a suspicion score (e.g. 0-100) using the original prompt. Run 3-4 open-weight models (e.g. Llama-3.1-8B/70B-if-affordable, Qwen2.5-7B, Mistral-7B, Gemma-2-9B) plus one small cheap API model as monitors. From the scores, compute ROC curves and AUC per monitor, and reproduce the published Gemini number as the anchor by reporting it alongside (or re-running if budget allows). The whole study is re-scoring fixed text trajectories, so it is inference-only and completes in a few hours on one consumer GPU.

# Proposed First Experiments

- Harness + anchor: load trajectories, apply the original monitor prompt to one open model, and confirm scores are well-formed; record the published Gemini 2.5 Pro AUC (0.87) as the reference. Measure: end-to-end pipeline produces a valid suspicion score per trajectory. Expected outcome: a working scoring harness and a clearly stated anchor number.
- Open-monitor AUC: score all trajectories with each of the 3-4 open monitors and the small API model, then plot ROC and compute AUC with bootstrap confidence intervals. Measure: AUC per monitor and its gap to the 0.87 anchor. Expected outcome: open monitors land meaningfully below the closed anchor (e.g. 0.6-0.8), quantifying the cost of using a free monitor.
- Prompt/threshold sensitivity: vary the decision threshold and try one light prompt tweak (e.g. chain-of-thought before the score). Measure: best achievable true-positive rate at a fixed low false-positive rate, and whether the prompt tweak narrows the gap. Expected outcome: a small but real improvement, plus an operating-point table that tells deployers what catch-rate a free monitor delivers at tolerable false alarms.

# Theory of Impact Chain

AI-control monitoring (watching agent trajectories for sabotage) is strategically valuable safety infrastructure, and most independent deployers can only run free monitors. If we measure how far a cheap open monitor lags the best closed one on a frozen, public trajectory set, then deployers and control researchers get a concrete answer about achievable catch rates without lab resources, which improves safety because it informs whether free monitoring is good enough to catch a sabotaging agent before it causes harm, or whether stronger/closed monitors or layered defenses are required for the high-stakes deployment pathway.

# Strength Rationale

Scores 5 on counterfactual value, narrow scope, and low compute: it builds on released trajectories and prompts to evaluate exactly the lab-independent monitoring infrastructure third parties can actually run, with no training and no internal access. It is tightly scoped to a single replication with a published-AUC anchor and an unambiguous ROC/AUC metric, an ideal self-contained first deliverable.
