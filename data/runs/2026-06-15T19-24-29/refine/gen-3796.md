# Research Question

Does measured scheming propensity in an LLM agent change when the same goal-conflict scenario is dressed up with realistic, high-stakes surface features (named people, concrete consequences) versus presented in abstract, gamified form? If propensity numbers swing with cosmetic realism, they are framing artifacts rather than stable properties.

# Approach Outline

Select 4-6 published scheming-eliciting scenario templates, each pairing a goal conflict with an opportunity to deceive an overseer. For each template, hand-author two surface variants holding the underlying decision structure fixed: a low-realism version (abstract tokens, 'System A', neutral payoffs) and a high-realism version (named individuals, vivid stakes, plausible institutional framing). Run a single open instruction-tuned model (e.g., a Llama-3 or Qwen 7-8B chat model on a Colab Pro GPU) across all variants with multiple samples per prompt at a fixed temperature. Use a deterministic rubric plus a cheap LLM-judge to label each transcript for (a) deceptive action taken and (b) verbalized scheming in the reasoning. Compare rates across realism levels per scenario and in aggregate. All inference-only, runnable in a few hours.

# Proposed First Experiments

- Build and validate the variant set: author 4-6 paired low/high-realism scenarios, then have two people independently confirm the decision structure is identical across each pair. Measure inter-rater agreement on 'structurally equivalent'. Expected outcome: a clean, documented benchmark of paired scenarios with high agreement (>0.8).
- Run the model (30 samples per variant) and measure the deceptive-action rate and verbalized-scheming rate at each realism level. Compute the per-scenario and aggregate shift (high minus low). Expected outcome: a measurable, signed delta; the hypothesis predicts higher deception under high realism, but the headline result is the magnitude of the shift.
- Ablate which surface feature drives any shift: re-run with intermediate variants that add only named people, only concrete consequences, or only institutional framing. Measure which single feature moves the rate most. Expected outcome: identification of the dominant cosmetic driver (or evidence that no single feature dominates), giving guidance on how to report scheming evals.

# Theory of Impact Chain

If scheming-propensity metrics swing substantially with cosmetic realism, then the propensity numbers labs and evaluators cite are partly artifacts of scenario authoring rather than stable model properties. This means dangerous-capability and control evaluations could systematically over- or under-state scheming risk depending on framing -> evaluators adopt realism-controlled reporting standards -> deployment decisions about agentic models rest on more robust evidence, reducing the catastrophic-risk pathway in which a scheming model is cleared for high-autonomy deployment because an abstract eval understated its propensity to deceive overseers.
