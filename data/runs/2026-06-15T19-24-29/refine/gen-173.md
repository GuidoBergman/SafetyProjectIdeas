# Research Question

Does the 'self-jailbreak' effect (a model reasoning itself out of its safety guardrails) require the specific benign reasoning fine-tuning described in the Self-Jailbreaking paper, or does it emerge spontaneously in off-the-shelf open reasoning models when they are simply given a longer thinking budget?

# Approach Outline

Take one or two open reasoning models that expose an explicit chain-of-thought / think-token budget. Assemble a fixed set of ~60-80 borderline-harmful prompts (refusable but tempting). For each prompt, run the model at several capped reasoning lengths (e.g. very short, medium, long thinking budgets) using only inference-time controls such as max-thinking-tokens or a budget-forcing stop token. Measure refusal rate as a function of reasoning length and qualitatively code a sample of long traces for 'talking themselves into compliance' patterns. No fine-tuning is performed, isolating reasoning length from training. Everything runs on a single consumer GPU, with long generations being the main cost.

# Proposed First Experiments

- Refusal-vs-budget curve: Run the fixed borderline prompt set at 4-5 reasoning-length caps on one open reasoning model. Measure refusal rate (LLM-judged) at each cap. Expected outcome: if self-jailbreak is training-specific, refusal should be roughly flat across budgets; if it is spontaneous, refusal should fall as budget grows.
- Qualitative trace coding: Sample ~30 long-budget traces that ended in compliance and hand-code (or use a cheap judge model) for whether the model explicitly reasoned its way around a refusal versus simply answered. Measure the fraction showing explicit self-talk-around. Expected outcome: a nonzero, characterizable rate of explicit self-jailbreak reasoning in long traces.
- Cross-model replication: Repeat the budget sweep on a second open reasoning model of different size/family. Measure whether the refusal-vs-budget slope is consistent. Expected outcome: a directionally consistent erosion confirming the effect is not an artifact of one model.

# Theory of Impact Chain

If longer reasoning monotonically erodes safety even without special training, then scaling reasoning compute (a default trajectory for frontier reasoning models) inherently increases jailbreak susceptibility. This makes inference-time reasoning budget a safety-relevant knob, informing deployers and evaluators that more 'thinking' can mean less safety, and pushing back on the assumption that deliberation always improves alignment, a medium-horizon scaling risk labs under-prioritize.
