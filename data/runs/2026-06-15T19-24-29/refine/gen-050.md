# Research Question

In an AI-control setup with a trusted-monitor LLM watching an untrusted policy LLM, does monitor-policy similarity (same family/size) cause a measurable deficit in the monitor's catch-rate on the policy's characteristic sabotage attempts?

# Approach Outline

Build a minimal control harness: an untrusted policy model proposes actions on a small task set where some episodes contain planted subtle-sabotage actions (e.g. an inserted bug, an exfiltration step, a silent constraint violation); a monitor model reads each proposed action and outputs a suspiciousness flag. Hold the policy model fixed and vary the monitor across conditions: same-family/same-size, same-family/different-size, and different-family. Measure catch-rate (recall on planted sabotage) and false-positive rate per monitor condition. All models are small open checkpoints run inference-only on a single GPU; the experiment is a few hundred forward passes and needs no training. Test the hypothesis that the same-family monitor under-flags exactly the policy's characteristic failure modes.

# Proposed First Experiments

- Build the sabotage testbed: create ~40-60 task episodes, half clean and half containing one planted subtle-sabotage action, and verify a strong external monitor can detect most sabotage (sanity check). Measure ceiling catch-rate. Expected outcome: a validated testbed where sabotage is detectable in principle.
- Same-family vs cross-family catch-rate: run the fixed policy with a same-family monitor and a different-family monitor of comparable capability, and compare catch-rate on planted sabotage. Measure the catch-rate gap. Expected outcome: the same-family monitor shows a measurable catch-rate deficit on the policy's characteristic sabotage, supporting the homogeneity hypothesis.
- Similarity gradient: sweep monitor family/size across 3-4 conditions and plot catch-rate against a similarity proxy (same base model, same family, unrelated). Measure the trend of catch-rate vs similarity. Expected outcome: catch-rate increases as monitor-policy independence increases, quantifying the cost of correlated blind spots for control protocols.

# Theory of Impact Chain

AI control protocols rest on the assumption that a trusted monitor catches an untrusted model's harmful actions. If monitors that share a family with the policy systematically miss its characteristic sabotage, then control safety cases are overstated wherever the monitor and policy are correlated (the common case when both come from the same vendor). Demonstrating this deficit pushes deployers to enforce monitor-policy diversity, directly hardening the control pathway against a scheming model that exploits a same-family monitor's blind spots to take undetected harmful actions.

# Strength Rationale

Counterfactual value (5): it stress-tests a load-bearing, lab-promoted control assumption using only open models and one GPU — work labs under-prioritize. Narrow scope (5): one fixed policy, a small planted-sabotage testbed, and a single dependent variable (catch-rate vs monitor-policy similarity) with a crisp hypothesis and explicit success criteria, making it a self-contained 30-hour project grounded in the existing homogeneity result.
