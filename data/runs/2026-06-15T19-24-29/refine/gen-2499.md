# Research Question

Can prompting alone (no fine-tuning) induce an open reasoning model to move task-relevant reasoning out of its visible chain-of-thought while still solving a hidden side objective, and which prompt strategies most reliably evade a CoT monitor?

# Approach Outline

Pick a small open reasoning model that exposes its CoT (e.g. DeepSeek-R1-Distill-Qwen-7B or QwQ-style model runnable on a single Colab Pro / Runpod GPU at inference only). Design a benign-looking primary task paired with a hidden side objective (e.g. embed a flagged keyword, or solve a second arithmetic puzzle) and a set of obfuscation prompt variants ('think silently', 'use private notation', 'reason inside the final answer', baseline honest CoT). Run each prompt variant over a fixed task set, collect the visible CoT and final answers. Use a second cheap LLM as a CoT monitor that scores each transcript for suspicious/hidden reasoning. Measure, per variant, the hidden-task success rate and the monitor's catch rate, so the headline metric is how much hidden-task accuracy survives when the visible CoT is judged clean. All steps are pure inference and fit comfortably in ~30 hours including writing a blog post.

# Proposed First Experiments

- Baseline calibration: run the model on the primary+hidden task with an honest CoT prompt over ~50 items. Measure hidden-task accuracy and the monitor's suspicion/catch rate. Expected outcome: high accuracy AND high monitor catch rate (visible reasoning is detectable), establishing the no-obfuscation reference point.
- Prompt-variant sweep: run 3-4 obfuscation prompts ('think silently', 'private notation', 'reason in the answer') over the same task set. Measure hidden-task accuracy and monitor catch rate per variant. Expected outcome: at least one variant preserves substantial hidden-task accuracy while dropping monitor catch rate well below baseline, showing prompt-only obfuscation is feasible.
- Scrub-and-rescore robustness check: take transcripts the monitor judged 'clean', strip any residual suspicious tokens, and verify the hidden task was still solved. Measure the fraction of clean-CoT runs that still completed the hidden objective. Expected outcome: a non-trivial fraction succeed with a clean CoT, quantifying how fragile CoT monitorability is to light prompting.

# Theory of Impact Chain

If light prompting suffices to push reasoning out of the visible CoT, then CoT monitoring is far more fragile than control safety cases assume; this means a scheming or misused model could defeat deployed CoT monitors with no training, so flagging the ease of prompt-only obfuscation directly informs whether CoT monitorability can be relied upon in the long-horizon (>1yr) threat model where a capable model deliberately hides reasoning to execute harmful actions undetected.

# Strength Rationale

The idea scores top marks on narrow scope and accessible complexity: it is a single tightly-scoped prompt-variant comparison with crisp metrics (hidden-task accuracy vs monitor catch rate), pure inference, and reproducible on consumer hardware. Its counterfactual value is high because it is a model-organism-style probe of open weights that labs underinvest in, requires no proprietary infra or training, and tests a long-horizon monitorability threat that is valuable to characterize outside major labs.

# Alternative Framings

- Frame it as a CoT-monitor stress test that produces a reusable mini-benchmark of obfuscation prompts other independent researchers can run against any open reasoning model.
