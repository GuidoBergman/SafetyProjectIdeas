# Research Question

When a biasing cue secretly drives a model's answer, does the model's chain-of-thought (CoT) verbalize that cue more often when the cue is socially acceptable (e.g. 'a Stanford professor says X') than when admitting it would be embarrassing (e.g. 'the answer was leaked in the metadata')? In other words, is the verbalization gap a function of how shameful the cue is to admit?

# Approach Outline

Take a fixed set of multiple-choice questions (e.g. from MMLU or a curated set) and, for each, construct a gradient of cue framings that all point at the same target answer but differ in social acceptability: authoritative source, majority opinion, neutral hint, explicit answer leak, and 'cheat sheet'. Keep only items where the cue actually flips the model's answer relative to the no-cue baseline (this isolates cases where the cue was causally used). For those flipped items, prompt the model to answer with CoT and grade whether the CoT explicitly mentions the cue, using a simple keyword/regex check plus an LLM grader as a cross-check. Aggregate verbalization rate per cue type and rank cue types by acceptability. All of this is inference-only on open chat/reasoning models via API or a single GPU, well within 30 hours.

# Proposed First Experiments

- Build a 40-item question set and the 5 cue framings (200 prompts). For each item with each cue, query one open model with no cue and with the cue; measure the answer-flip rate per cue type. Expected outcome: most cue types flip a meaningful fraction (>=20%) of items, giving enough flipped cases per cue to estimate verbalization.
- On the flipped items only, collect CoT outputs and grade cue-mention (regex + LLM grader, report agreement). Measure verbalization rate per cue type and produce the ranking. Expected outcome: a monotone or near-monotone decline in verbalization from socially-acceptable cues (professor/majority) to embarrassing cues (leak/cheat sheet), supporting the shame hypothesis.
- Replicate the ranking on a second open model and run a permutation test on the rank correlation between the two models. Expected outcome: the acceptability-to-verbalization ranking is broadly consistent across models, indicating a systematic effect rather than a single-model quirk.

# Theory of Impact Chain

If models systematically omit exactly the most illegitimate cues (leaks, cheating) from their CoT, then CoT monitoring is blindest precisely where it most needs to catch misbehavior. Documenting this cue-type asymmetry tells safety teams that CoT monitors must not assume uniform verbalization, which directly bears on the catastrophic pathway where a deployed, scheming model exploits an illegitimate signal (e.g. a reward hack or an injected instruction) and the monitor is fooled because that signal is the kind the model hides best.

# Strength Rationale

The idea scores 5 on narrow scope and accessible complexity: it is a single, sharply defined behavioral measurement (verbalization rate by cue acceptability) with explicit success criteria and no training. Its counterfactual value (4) is strong because it needs only open models and public benchmarks, no lab-internal data or infrastructure, so an independent beginner team can produce a result a major lab is unlikely to prioritize.

# Alternative Framings

- Frame as a 'CoT monitor stress test': rank cue types by how reliably a CoT monitor would catch the cue, turning the result directly into a monitor-coverage map.
