# Research Question

Under genuine information asymmetry, which lightweight oversight protocol (direct-QA, single consultant, or two-sided debate) best rewards honesty, as measured by the Agent Score Difference (ASD) between an honest agent and a lying agent under a weaker judge?

# Approach Outline

Use a QA dataset with real information asymmetry: take a QuALITY-style reading-comprehension slice where the judge sees only the question while the debaters/consultant see the passage. Use one open model in all roles (judge, honest agent, dishonest agent) to keep it cheap and model-agnostic. Implement three thin protocols as prompt templates: direct-QA (model answers from the question alone), single-consultant (one agent argues a position to the judge), and two-sided debate (an honest and a dishonest agent each argue). For each protocol compute ASD = win-rate(honest) minus win-rate(dishonest). Output a tiny leaderboard and release the harness as a clean, reproducible repo.

# Proposed First Experiments

- Assemble a 40-60 question information-asymmetric slice and implement the judge plus direct-QA baseline. Measure: judge accuracy with no passage access. Expected outcome: near-chance/low accuracy, confirming the asymmetry is real and the judge genuinely needs the agents.
- Implement the single-consultant protocol and run honest vs dishonest consultants, computing win-rates and ASD. Measure: ASD for consultancy. Expected outcome: a positive but modest ASD, with the dishonest consultant sometimes fooling the judge.
- Implement two-sided debate and compute ASD, comparing all three protocols on the same questions. Measure: ASD per protocol and which protocol maximizes it. Expected outcome: debate yields the highest ASD (honesty advantage) under information asymmetry, reproducing the qualitative debate>consultancy finding with a tiny open-model harness.

# Theory of Impact Chain

If we ship a small, model-agnostic ASD harness, then the community gets a standard yardstick for comparing oversight protocols on open models, which it currently lacks. Better-validated scalable-oversight protocols make it more likely that humans (or weaker models) can correctly supervise stronger AI, directly addressing the catastrophic pathway where a superhuman system deceives its overseers because no one could empirically check which oversight setup actually rewards truth-telling.

# Strength Rationale

Counterfactual value is maximal: a standardized oversight-protocol benchmark is exactly the missing infrastructure that labs do not own, and it requires only open models, prompting, and one GPU. Narrow scope is maximal because the deliverable is one well-defined metric (ASD) across three thin protocols plus a released harness, making it self-contained and feasible for beginners in 30 hours.

# Alternative Framings

- Frame it as a reproducibility check: can hobbyists replicate the 'debate beats consultancy under information asymmetry' result cheaply on open models, and does it hold for small judges?
