# Research Question

For a given benign CAA steering vector, how much does applying it change the model's jailbreak attack-success-rate (ASR) as a side-effect? Can we package this into a simple, reusable 'JailbreakDelta' measurement that anyone deploying steering can run?

# Approach Outline

Use an open 7B instruction model with TransformerLens or nnsight to extract contrastive-activation-addition (CAA) steering vectors for 6-8 benign target behaviors (e.g., 'be more concise', 'be more formal'). Fix a small held-out set of jailbreak prompts from an open dataset (an AdvBench or JailbreakBench subset). For each steering vector, run the jailbreak set with and without the vector applied, judge each response for attack success with a simple refusal/compliance classifier, and report JailbreakDelta = ASR_steered minus ASR_baseline. Rank the vectors by induced jailbreak risk. Everything is inference-only on a single consumer GPU and completes in a few hours.

# Proposed First Experiments

- Reproduce a baseline: pick one benign steering vector and one jailbreak subset (~50 prompts), measure ASR with and without steering using a fixed compliance judge. Expected outcome: a working harness and a non-zero, reproducible JailbreakDelta for one vector.
- Scale to 6-8 benign steering directions and compute JailbreakDelta with bootstrap confidence intervals for each, producing a ranked table. Expected outcome: a 'jailbreak-risk leaderboard' of benign steering vectors, with some vectors showing material (>10 point) ASR shifts in either direction.
- Test the refusal-direction-overlap hypothesis: measure cosine similarity between each benign steering vector and an extracted refusal direction, and correlate it with the measured JailbreakDelta. Expected outcome: a positive correlation, giving a cheap predictor of which vectors are risky without running the full jailbreak set.

# Theory of Impact Chain

If benign steering silently raises jailbreak susceptibility, then practitioners and open-source deployers applying steering vectors are unknowingly weakening safety guardrails. A reusable JailbreakDelta tool lets anyone catch this externality before shipping. This reduces the catastrophic-risk pathway where widely-shared, well-intentioned steering recipes propagate hidden jailbreak vulnerabilities across many downstream deployments of open models.

# Strength Rationale

Counterfactual value is 5: measuring diffuse, fuzzy-reward safety externalities of steering is exactly the work labs deprioritize, and it needs only open models and open jailbreak data, no lab infrastructure. Combined with 5s on narrow scope and accessible complexity, the JailbreakDelta metric over a handful of vectors is a crisp, beginner-feasible deliverable with an explicit success criterion.

# Alternative Framings

- Frame as a pre-deployment 'safety regression test' for steering: ship JailbreakDelta as a one-command check that flags any steering vector exceeding a chosen ASR-increase threshold.
