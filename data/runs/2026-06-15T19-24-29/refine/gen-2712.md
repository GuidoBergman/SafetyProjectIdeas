# Research Question

Does using a monitor from the same model family as the untrusted policy produce correlated blind spots, so that the cases the policy gets wrong (or backdoors successfully) are disproportionately the cases the monitor also misses, eroding the independence that defense-in-depth assumes?

# Approach Outline

On the public APPS backdoor split, run a fixed untrusted policy and score its actions with two trusted monitors: one from the same model family (e.g. a smaller Llama monitoring a Llama policy) and one from a different family (e.g. a Qwen or Mistral monitor). For each monitor, record per-item error events (missed backdoors, false alarms). Compute the correlation between policy-error events and monitor-error events under each family condition, and compare the same-family vs cross-family error correlation. A higher same-family correlation quantifies how shared lineage erodes monitor independence. Inference-only across model families on a public split, single GPU, a few hours; deliverable is a blog post with the error-correlation comparison.

# Proposed First Experiments

- Error logging: run the policy and both monitors over the APPS backdoor split, recording per-item ground-truth labels, policy outcomes, and each monitor's verdict. Expected outcome: a clean per-item error table for both family conditions.
- Correlation measurement: compute the correlation (e.g. phi coefficient) between policy-error and monitor-error events for same-family vs cross-family monitors. Expected outcome: a higher same-family correlation, indicating shared blind spots; or a null result that reassures independence holds.
- Independence-math impact: plug the measured correlations into the defense-in-depth catch-probability formula (which assumes independence) and quantify how much the true joint failure rate exceeds the independence-assumed rate. Expected outcome: a concrete inflation factor showing how much same-family monitoring overstates safety.

# Theory of Impact Chain

Defense-in-depth in AI control assumes the monitor fails independently of the policy, so layered checks multiply safety. If a same-family monitor shares blind spots with the policy, that independence math is void and a scheming model's backdoor can pass both layers together. Measuring the correlation tells control designers to deliberately use cross-family monitors and to discount independence-based safety estimates, reducing the risk that correlated failure lets sabotage through a stack that looked safe on paper.

# Strength Rationale

Narrow scope (a single error-correlation measurement across family conditions) and low compute (inference-only across open model families) are top strengths, with an unambiguous correlation metric. Counterfactual value is high: it is a broadly applicable, lab-independent independence check on open models and public data that directly tests an assumption underlying control safety cases.

# Alternative Framings

- Frame as a monitor-selection guideline study: report how error-correlation varies across several family pairings to recommend which monitor/policy combinations maximize independence.
