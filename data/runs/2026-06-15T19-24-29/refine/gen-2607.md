# Research Question

Do trusted monitors give consistent verdicts under semantically-irrelevant transformations of their inputs, and can metamorphic testing surface monitor brittleness (verdict swings that should not happen) as a cheap pre-deployment diagnostic?

# Approach Outline

Borrow metamorphic testing from software engineering. Define two classes of metamorphic relations (MRs): verdict-preserving transformations (e.g., variable renaming, whitespace/comment reformatting, reordering independent statements, benign paraphrase of natural-language actions) that should NOT change the monitor's suspicion verdict, and verdict-flipping transformations (e.g., inserting an actual backdoor) that SHOULD change it. Apply these transformations to transcripts/code from an existing dataset (e.g., SHADE-Arena), query a cheap monitor on original and transformed inputs, and measure the MR-violation rate (how often a should-preserve transform flips the verdict, or a should-flip transform fails to). Aggregate into a single monitor brittleness score. Inference plus deterministic transformations; no oracle, no training.

# Proposed First Experiments

- Implement 4-5 verdict-preserving MRs and apply them to ~100 transcripts; query the monitor on original and transformed pairs. Measure the verdict-flip rate under should-preserve transforms. Expected outcome: a non-trivial violation rate, demonstrating measurable monitor brittleness.
- Implement 2-3 verdict-flipping MRs (inject real backdoors/sabotage) and measure how often the monitor fails to raise suspicion. Expected outcome: a complementary sensitivity-failure rate, completing the brittleness picture.
- Combine into a single brittleness score and compare two cheap monitors (or two prompt variants of one monitor). Measure which is more robust. Expected outcome: a ranking of monitors by robustness, giving a practical pre-deployment selection criterion.

# Theory of Impact Chain

If trusted monitors flip verdicts under semantically-irrelevant changes, then an attacker can apply cheap obfuscating transformations (renaming, reformatting, paraphrasing) to push genuinely harmful actions below the suspicion threshold; a metamorphic robustness diagnostic surfaces this brittleness before deployment so practitioners can pick or harden more invariant monitors, closing a pathway by which a scheming model trivially evades oversight on its way to executing a backdoor or sabotage action.

# Strength Rationale

Scores 5 on accessibility, narrow scope, and low compute and 4 on counterfactual value: it needs no oracle and no model lab, just deterministic input transforms plus cheap monitor queries, so a beginner can produce a concrete brittleness score, and it imports a mature SE technique into control-monitor evaluation, an external-team-friendly diagnostic labs underweight.

# Alternative Framings

- Frame as an 'invariance benchmark' for control monitors: package the MR suite as a reusable test harness any team can run against their monitor to get a standardized robustness report.
