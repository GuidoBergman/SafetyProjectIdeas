# Research Question

Do publicly released 'unlearned' models genuinely remove hazardous knowledge, or do they merely suppress it under one fixed prompt format? Can a standardized battery of prompt transformations quantify this with a single 'suppression gap' metric?

# Approach Outline

Fix a small subset (e.g., 100-200 questions) of WMDP as the probe content. Define a battery of N prompt transformations that preserve the underlying question but change surface form: paraphrase, hypothetical/role-play framing, translate-to-another-language-and-back, multiple-choice-to-free-form reformulation, and indirect elicitation. Implement each transformation as a deterministic template (with an LLM paraphraser where needed). Run the original and all transformed versions against one or more publicly available unlearned checkpoints plus the base (non-unlearned) model as a reference, all inference-only. For each model compute default-format accuracy and the max-over-transformations accuracy; report the 'suppression gap' = (best transformed accuracy) - (default accuracy). A large gap indicates suppression rather than removal. The whole pipeline is reproducible, needs no training, and runs in a few hours on one GPU.

# Proposed First Experiments

- Establish baselines: run the fixed WMDP subset in default MCQ format against an unlearned checkpoint and its base model. Measure: default-format accuracy for both. Expected outcome: the unlearned model scores near chance in default format while the base scores high, confirming the checkpoint 'looks' unlearned.
- Apply the full transformation battery to the unlearned checkpoint and compute the suppression gap. Measure: per-transformation accuracy and the max-over-transformations suppression gap. Expected outcome: at least one transformation (likely paraphrase or free-form reformulation) recovers a substantial fraction of the suppressed accuracy, yielding a clearly nonzero suppression gap.
- Rank transformations by how much each individually recovers knowledge, across 2-3 different unlearned checkpoints. Measure: average accuracy recovery per transformation type and its variance across models. Expected outcome: a small set of transformations (e.g., free-form and translate-and-back) consistently dominate, giving a recommended minimal audit battery.

# Theory of Impact Chain

If the battery reveals that 'unlearned' open models still leak hazardous knowledge under simple reformulations, then auditors, model hubs, and regulators get a single reproducible robustness number to gate releases -> models that only suppress rather than remove dangerous capabilities are caught before being trusted as safe -> this directly mitigates the bioweapon/cyber uplift pathway where a falsely-certified unlearned model hands hazardous knowledge to a malicious user via a trivial prompt tweak.

# Strength Rationale

It scores maximally on counterfactual value and narrow scope: third-party unlearning auditing on public checkpoints is exactly the neglected, externally-doable safety work labs under-resource, and it collapses to one well-defined metric (the suppression gap). It is grounded in peer-relevant arXiv work that already documents prompt-attack recovery, so the team is packaging a recognized phenomenon into a turnkey, fully reproducible tool with explicit pass/fail criteria.

# Alternative Framings

- Reframe as a leaderboard/benchmark contribution: publish the suppression gap for every publicly available unlearned checkpoint, turning the battery into a standing 'unlearning robustness' scoreboard the community can extend.
