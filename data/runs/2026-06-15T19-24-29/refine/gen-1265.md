# Research Question

Does LLM-as-judge self-preference grow as the judge model's outputs become more similar to a candidate model's outputs - i.e. does output homogeneity amplify judge inflation?

# Approach Outline

Select 5-7 open instruct models from 2-3 lineages (e.g. two Llama variants, two Qwen variants, two Mistral variants). On a fixed set of ~50-80 open-ended questions, collect each model's answer. Compute pairwise output similarity between models using sentence embeddings (a small open embedding model) averaged over the question set. Then run a round-robin LLM-as-judge: each model scores every other model's answers (and its own family's answers) on a 1-5 rubric. Define judge inflation as the score a judge gives minus a neutral reference score (e.g. average score the answer receives from all judges, or a strong external judge). Fit a regression of inflation on judge-candidate output similarity. All inference-only, fits a single GPU over a weekend.

# Proposed First Experiments

- Similarity matrix: embed all models' answers and compute the pairwise output-similarity matrix. Measure: NxN similarity. Expected outcome: within-lineage pairs more similar than cross-lineage pairs.
- Round-robin judging: have each model judge every model's answers on a 1-5 rubric; compute each judge's inflation per candidate relative to the consensus score. Measure: inflation matrix. Expected outcome: judges score same-lineage and self answers higher.
- Regression: regress inflation on judge-candidate output similarity (and controls like answer length). Measure: slope, sign, and significance. Expected outcome: a positive, significant slope - more similar candidates get inflated scores - demonstrating homogeneity-amplified self-preference.

# Theory of Impact Chain

If judge inflation rises with output similarity, then automated safety and capability evaluations that use an LLM judge will systematically over-score the models most similar to the judge - typically the dominant, widely-deployed lineages. This means safety scorecards become optimistically biased exactly for the highest-impact models, so a dangerous deployment could pass an automated eval it should fail; flagging and quantifying this lets evaluators correct for it (e.g. by using cross-lineage judges).

# Strength Rationale

Top marks on narrow scope and accessible complexity: one clean regression with a pre-stated hypothesis (inflation ~ similarity) and standard tools (embeddings + LLM judging). Counterfactual value is strong because this eval-integrity question requires no model-internal access and labs have little incentive to expose bias in their own judges; an independent team using only open models can deliver a reusable warning and correction for a ubiquitous evaluation method.

# Alternative Framings

- Reframe at the family level: compare same-family vs cross-family judging as a binary contrast rather than a continuous similarity regression, which is simpler to communicate but loses resolution.
