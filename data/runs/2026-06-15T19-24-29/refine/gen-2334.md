# Research Question

In the obfuscated-arguments failure mode, a dishonest debater builds a long multi-step argument where no one can localize the false step, so the judge cannot be shown where the lie is. Can a weak judge be cued to recognize that an error exists (and roughly where) even when it cannot pinpoint the flawed step?

# Approach Outline

Construct ~50 synthetic multi-step arithmetic/logic 'proofs', each 5-15 steps long; in half, inject a single hidden error at a random depth, the rest are fully valid. Present each proof to a small open judge model in a debate-style framing. Compare two judge prompts: a baseline 'is this proof correct?' prompt vs an 'obfuscation-aware' prompt that asks the judge to estimate its confidence that an error exists somewhere and to guess the depth/region. Score (a) whether the judge's error-presence calibration beats chance and (b) whether its localization is better than random, even on proofs where it cannot name the exact bad step. All synthetic, cheap, single-GPU, a few hours total.

# Proposed First Experiments

- Build and validate the proof set: generate 50 proofs with programmatically known error/no-error labels and error depths. Measure: dataset balance and that valid proofs are genuinely valid. Expected: a clean labeled benchmark.
- Baseline vs obfuscation-aware error detection: run both prompts; measure AUROC / accuracy of the judge's error-exists judgment against the true labels. Expected: baseline near chance on long proofs; obfuscation-aware prompt may lift error-presence detection above chance.
- Localization probe: on error-containing proofs, compare the judge's guessed error region to the true depth. Measure: localization accuracy vs random. Expected outcome is decision-relevant either way: judges can flag obfuscation (suggesting a cheap protocol patch) or cannot (quantifying a fundamental limit).

# Theory of Impact Chain

If a weak judge can at least detect that an obfuscated argument hides an error, then debate protocols can add a cheap 'flag suspected obfuscation -> default to skepticism' step -> dishonest debaters lose the ability to win by burying an unlocalizable false step -> closes a theoretically-flagged route by which a deceptive superhuman system could push false conclusions past oversight. A negative result quantifies a hard limit, telling protocol designers obfuscation must be handled structurally (e.g. prover-estimator debate) rather than by judge cueing.
