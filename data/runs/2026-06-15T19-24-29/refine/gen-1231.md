# Research Question

How much of inter-model output homogeneity is caused by alignment/instruction-tuning versus pretraining? Specifically, are instruct checkpoints markedly more homogeneous (both within a model and across models) than their corresponding base checkpoints?

# Approach Outline

Select 3-4 open model families that release BOTH base and instruct checkpoints (e.g. Llama, Qwen, Mistral, Gemma families). Build a set of matched open-ended prompts (story openings, opinion questions, brainstorming) usable with both base and instruct models. Sample multiple completions per prompt at fixed temperature. Compute intra-model diversity (variation across samples from one model) and inter-model diversity (variation across models) using embedding-based distance and lexical/n-gram diversity metrics. Compare base vs instruct on both. Inference-only on a single GPU (small/medium checkpoints, quantized if needed); under 30 hours with a blog post. Success criterion: a quantified base-vs-instruct diversity gap per family with significance testing.

# Proposed First Experiments

- Measure intra-model diversity for base vs instruct within each family. Measure: mean pairwise embedding distance among samples per prompt. Expected outcome: instruct models produce less varied completions than their base counterparts (mode collapse from alignment).
- Measure inter-model (cross-family) diversity for base vs instruct. Measure: cross-model embedding distance on matched prompts. Expected outcome: instruct checkpoints across families converge toward each other more than base checkpoints do.
- Decompose by prompt type. Measure: diversity gap on value-laden/opinion prompts vs neutral creative prompts. Expected outcome: alignment-driven convergence is largest on normative/opinion prompts, pinpointing where RLHF/RLAIF prunes diversity most.

# Theory of Impact Chain

If alignment is empirically shown to be the dominant driver of homogeneity, then the field learns the intervention point is the alignment stage, not pretraining -> diversity-preserving alignment methods can be prioritized and evaluated against this baseline -> this addresses the long-horizon systemic risk where an increasingly homogeneous deployed population shares correlated blind spots and value biases, by locating where in the pipeline that convergence is introduced.
