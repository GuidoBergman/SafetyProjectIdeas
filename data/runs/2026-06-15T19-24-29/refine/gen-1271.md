# Research Question

Is the refusal boundary correlated across providers - i.e. do open models refuse the same benign prompts (over-refusal) and comply with the same harmful edge cases (under-refusal) more than chance independence would predict?

# Approach Outline

Assemble two prompt sets: a benign-but-tricky slice from an over-refusal benchmark (XSTest / OR-Bench) and a small harmful-edge set (borderline prompts from a public harmful-behavior benchmark). Query 6+ open models across lineages. Classify each response as refuse vs comply using a lightweight classifier (keyword rules plus a short LLM-judge check, with a hand-labeled validation sample). For each prompt, record the vector of refuse/comply decisions across models, then measure inter-model agreement on the refusal boundary (e.g. Fleiss' kappa, or observed vs independence-expected co-refusal) and identify prompts where all or nearly all models share the same error. All inference-only on a single GPU.

# Proposed First Experiments

- Refusal labeling: run both prompt sets through 6+ models, classify refuse/comply, and validate the classifier on a hand-labeled subset. Measure: per-model refuse/comply matrix and classifier accuracy. Expected outcome: reliable labels (>90% classifier agreement with hand labels).
- Correlation vs chance: compute inter-model agreement on the refusal boundary and compare to the agreement expected if each model decided independently given its marginal refusal rate. Measure: observed vs expected co-refusal (and kappa). Expected outcome: agreement well above chance, indicating a shared boundary.
- Blind-spot enumeration: list prompts where nearly all models over-refuse (benign blocked everywhere) and where nearly all under-refuse (harmful complied everywhere). Measure: counts and examples of universal blind spots. Expected outcome: a concrete set of universally-mishandled prompts, demonstrating society-wide blind spots.

# Theory of Impact Chain

If the refusal boundary is homogeneous across providers, then a harmful edge case that slips past one model slips past all of them, and a benign use case blocked by one is blocked everywhere - a single correlated failure with society-wide reach. Measuring the correlation (not just per-model rates) reveals these shared blind spots so the community can target them, mitigating the systemic risk that the entire deployed model fleet shares the same exploitable safety gap.

# Strength Rationale

Top scores on narrow scope, accessible complexity, and low compute: existing refusal benchmarks plus a simple refuse/comply classifier and a correlation metric give a tightly-defined study with a clear deliverable. Counterfactual value is high because the correlation framing (rather than per-model rates labs already report) is exactly what no single vendor is incentivized to measure, and an independent team using open models can produce the cross-provider blind-spot map with no internal access.

# Alternative Framings

- Reframe as a diversity recommendation: use the correlated blind-spot set to argue for and design a minimal 'diverse ensemble' of models chosen to maximally de-correlate refusal errors.
