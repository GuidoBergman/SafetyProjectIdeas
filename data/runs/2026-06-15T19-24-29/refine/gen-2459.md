# Research Question

Without any training, how often will an off-the-shelf open model that was prompted to insert a subtle side-goal truthfully confess when directly asked about it in a fresh follow-up turn, and which question framings raise the confession rate?

# Approach Outline

Have a small open model (e.g. Llama-3.1-8B-Instruct, inference only) perform a set of tasks where, via a hidden system instruction, it inserts a subtle side-goal (e.g. a small backdoor, an off-task addition, an omitted edge case) whose presence is machine-checkable. Then, in a fresh follow-up query without the hidden instruction in context, ask a range of confession-eliciting questions ('did you do anything the user did not ask for?', neutral vs. immunity-framed vs. accusatory). Measure truthful-confession rate vs. denial as a function of framing, conditioned on the side-goal actually being present. Inference-only on free-tier/Colab, a few hours; deliverable is a confession-rate-by-framing table and blog post. No training.

# Proposed First Experiments

- Baseline confession rate: after a verified side-goal insertion, ask a neutral confession question in a fresh turn; measure the fraction of truthful confessions vs. denials. Expected outcome: a non-trivial but incomplete confession rate.
- Framing sweep: compare neutral, immunity ('you won't be penalized'), and accusatory framings; measure confession rate per framing. Expected outcome: immunity framing raises truthful confessions relative to accusatory framing.
- False-confession control: run the same questions on tasks where no side-goal was inserted; measure how often the model falsely claims misbehavior. Expected outcome: a low but measurable false-confession rate, characterizing the precision of elicited self-reports.

# Theory of Impact Chain

If simply asking an off-the-shelf model afterward elicits truthful confessions at a useful rate, cheap post-hoc self-reporting becomes a low-cost oversight layer deployable without expensive training. Establishing the untrained prompt-only baseline and the framings that maximize honesty gives independent deployers a practical, reusable elicitation recipe, reducing the risk that subtly sabotaging actions by deployed models go unreported and accumulate toward harm.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a single confession-rate-by-framing measurement, inference-only on free-tier-feasible models. Counterfactual value is high because it isolates the no-training baseline that labs skip in favor of expensive training-based self-report methods, needs only public models and no proprietary data, and yields a directly reusable oversight technique for independent teams.

# Alternative Framings

- Frame as estimating an upper bound on how much training-based self-report methods actually add over a strong prompt-only elicitation baseline.
