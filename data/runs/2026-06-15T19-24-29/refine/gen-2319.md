# Research Question

Judge accuracy conflates two distinct things: the ability to discriminate good from flawed arguments (sensitivity) and a response bias toward accepting or rejecting. Can signal detection theory (d-prime and criterion c) cleanly separate these for an LLM judge, and does it reveal exploitable threshold bias that raw accuracy hides?

# Approach Outline

Borrow signal detection theory (SDT) from psychophysics. Assemble a labeled set of arguments, each marked correct (signal) or flawed (noise), e.g. from a public QA/reasoning set with one good and one bad answer per item. Have a small open judge model emit accept/reject decisions over this set. Treating 'accept a correct argument' as a hit and 'accept a flawed argument' as a false alarm, compute d-prime (sensitivity) and criterion c (bias) for the judge. Then vary the judge prompt (e.g. strict vs lenient instructions) and recompute, showing how prompt changes move sensitivity versus bias independently. Finally, construct two prompt variants with equal accuracy but different criterion and show they differ in exploitability. This is pure CPU/analytical work on cached judge outputs.

# Proposed First Experiments

- Compute baseline d-prime and c: run the judge over the labeled set, tabulate hits/false alarms, compute d' and c. Measure: the pair (d', c). Expected: a non-zero criterion revealing the judge is not a neutral discriminator.
- Prompt-shift decomposition: re-run under strict and lenient prompts; recompute d' and c each time. Expected: prompts move c substantially while d' stays roughly fixed, showing bias and sensitivity are separable knobs.
- Equal-accuracy / unequal-exploitability demonstration: find two prompt settings with matched overall accuracy but different c; show that the higher-criterion (or lower) one accepts more flawed arguments under an adversarial skew. Expected: equal accuracy hides unequal exploitability, the headline result.

# Theory of Impact Chain

If oversight error can be decomposed into sensitivity vs decision-threshold bias, then we get a precise, training-free diagnostic for whether an overseer is exploitable by pushing it past its acceptance threshold rather than by genuinely fooling its discrimination -> oversight designers can monitor and tune criterion directly, catching judges that look accurate on balanced sets but collapse under adversarial skew -> reduces the risk that a deployed automated overseer is silently gamed via its response bias when the input distribution shifts adversarially.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a single self-contained analysis computing d' and c from accept/reject decisions on a labeled set, with explicit success criteria and only CPU-level cost on cached outputs.
