# Research Question

How far does a cheap, training-free statistical signal — per-step token-level surprise/entropy from a small open reference model — get you in separating benign agent trajectories from sabotage trajectories? What is the baseline detection power of an unsupervised surprise detector for novel, never-trained-for agent behaviors?

# Approach Outline

Use public SHADE-Arena transcripts containing labeled benign and sabotage agent steps. For each agent action, score it under a small open reference model (e.g. a 1–3B model) to get per-token log-probabilities, and derive per-step features: mean surprise, max-token surprise, and entropy. Build a simple unsupervised detector (threshold or z-score on these features, no labels used for fitting) and evaluate it against the benign/sabotage labels with an ROC curve and AUC. All work is inference-only scoring over text transcripts, runnable on a single consumer GPU in a couple of hours.

# Proposed First Experiments

- Parse SHADE-Arena transcripts into per-step actions with benign/sabotage labels, and compute per-step surprise/entropy features under the small reference model. Measure: distribution of surprise features for benign vs sabotage steps. Expected outcome: visibly heavier upper tail of surprise on sabotage steps, motivating the detector.
- Build an unsupervised threshold detector on max-token surprise and compute its ROC/AUC against the labels. Measure: AUC and the detection rate at a fixed low false-positive rate. Expected outcome: above-chance AUC (e.g. 0.6–0.75), establishing a concrete 'how far does free anomaly detection get you' baseline.
- Compare reference-model sizes and feature choices (mean vs max surprise vs entropy) to find the cheapest configuration that retains most detection power. Measure: AUC vs model size/feature. Expected outcome: a small reference model captures most of the signal, confirming the approach is genuinely low-compute and lab-independent.

# Theory of Impact Chain

If a training-free surprise signal already flags a meaningful share of sabotage, then deployers and watchdogs gain a cheap first-pass anomaly detector for behaviors no one trained a monitor to catch. This establishes a public baseline that more expensive detectors must beat, and raises the chance of catching novel agent sabotage early, mitigating the pathway where a deployed agent executes an unanticipated dangerous action (data destruction, covert code insertion) that escapes monitors tuned only to known attack patterns.

# Strength Rationale

With 5s on counterfactual value, narrow scope, accessible complexity, and low compute, this is an explicitly training-free, no-proprietary-data baseline that an independent team can produce on public transcripts, aligned with an ARC/Anthropic open problem labs flag but under-baseline. Its single-deliverable design (an unsupervised detector + ROC with clear success criteria) makes it self-contained and beginner-feasible, and a clean baseline has high counterfactual value precisely because it is the kind of foundational measurement outsiders can contribute.

# Alternative Framings

- Frame it as a negative result of value: if surprise barely beats chance, that itself is an informative public finding bounding how much cheap statistical anomaly detection can contribute, guiding others to invest in learned detectors instead.
