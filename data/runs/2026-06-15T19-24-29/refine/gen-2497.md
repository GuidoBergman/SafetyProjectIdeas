# Research Question

Is the optimal CoT-vs-action weight in a hybrid suspiciousness monitor stable across task categories and untrusted model families, or must it be re-tuned for each setting?

# Approach Outline

Reimplement the simple weighted-average hybrid monitor from CoT Red-Handed using a small open trusted monitor over public sabotage transcripts. For each transcript, obtain a CoT-suspicion score and an action-suspicion score, then combine as w*CoT + (1-w)*action. Sweep w from 0 (action-only) to 1 (CoT-only) in steps of 0.1, and compute the safety/usefulness frontier (or AUROC) separately for each task category and each untrusted model. Then test cross-category generalization: pick the w that is optimal on one category and measure how much detection it loses on held-out categories. Inference-only and free-tier feasible.

# Proposed First Experiments

- Hybrid reproduction: implement the weighted-average monitor and confirm the combined score beats both action-only and CoT-only at some w (success criterion: a reproduced hybrid advantage).
- Per-category weight sweep: plot AUROC vs w for each task category and each untrusted model, recording each setting's optimal w (expected outcome: optimal w varies noticeably across categories/models).
- Cross-category transfer test: fix w at the value optimal on category A and measure AUROC drop on held-out categories vs their own optima (expected outcome: a single fixed weight loses meaningful detection on some categories, indicating the optimal mix is fragile).

# Theory of Impact Chain

If the optimal CoT/action mix is fragile across tasks and models, then deployers who tune the hybrid weight once and reuse it can be lulled into false confidence while detection silently degrades on new task distributions. A clean robustness curve tells control teams whether to re-tune per setting or whether a robust default exists, strengthening the monitoring layer that decides whether a sabotaging agent's actions are caught before they cause harm.

# Strength Rationale

Scores 5 on narrow scope, accessible complexity, and low compute: a one-parameter weight sweep with a per-category generalization check, run inference-only over public transcripts. Counterfactual value (4) is high because it is exactly the cheap protocol-engineering robustness analysis labs skip after publishing a headline hybrid result, and it needs only public data and a small open monitor.

# Alternative Framings

- Reframe as a meta-learning question: test whether a lightweight per-transcript feature (e.g. CoT length or verbosity) predicts the locally-optimal weight, enabling an adaptive rather than fixed mix.
