# Research Question

Using only best-of-N selection (no RL training), where does the divergence point between proxy reward-model score and true task quality lie, i.e. at what N does selecting harder on an open reward model start to decrease true accuracy (the overoptimization knee)?

# Approach Outline

Pick a task with cheap ground truth (e.g. GSM8K math with exact-answer checking, or short factual QA). Use a small open policy model to sample N candidate answers per question (N up to a few hundred via temperature sampling). Score every candidate with an open reward/judge model as the proxy. For increasing selection pressure (best-of-1, 2, 4, ... up to N), pick the top candidate by proxy score and evaluate its true accuracy against ground truth. Plot true accuracy and mean proxy score versus selection pressure to locate the knee where proxy keeps rising but true accuracy plateaus or falls. Entirely sampling + scoring; one consumer GPU, a few hours; no training whatsoever.

# Proposed First Experiments

- Proxy-vs-true curve: for one task and one (policy, reward model) pair, sweep best-of-N and plot true accuracy and proxy score against N. Measure: both curves and the N at which true accuracy peaks. Expected: proxy score rises monotonically while true accuracy rises then plateaus or declines, exposing a knee.
- Knee robustness across reward models: repeat with a second, different-family open reward model. Measure: knee location and peak true accuracy per reward model. Expected: the knee exists for both but its location shifts, showing it is a property of the proxy, not an artifact.
- Hacking-case audit: inspect candidates that score high on the proxy but are wrong by ground truth past the knee. Measure: qualitative categories of overoptimized failures (verbosity, format-gaming, confident wrongness). Expected: identifiable, recurring exploit patterns that explain the divergence.

# Theory of Impact Chain

If we can reproduce and locate the reward-model overoptimization knee cheaply with selection alone, then independent researchers and small orgs can measure how much optimization pressure a given overseer reward model tolerates before Goodharting, and surface the exploit patterns. This matters because future systems trained or filtered against imperfect reward models will overoptimize them; an undetected knee means a system that scores perfectly on the proxy while its true behavior degrades, a direct reward-hacking pathway to deploying capable-but-misaligned systems.

# Strength Rationale

Scores 5 on counterfactual value, low compute, and narrow scope: it reproduces a canonical scalable-oversight failure (Goodhart/overoptimization) with zero training using only open models and public data, so it is fully executable outside a lab on one GPU. The scope is a single transferable datum, the knee location, and the best-of-N trick makes a normally training-heavy phenomenon accessible to beginners.

# Alternative Framings

- Reframe as a practical safety-margin tool: given a reward model, report the maximum safe selection pressure before overoptimization, as a reusable per-model statistic.
