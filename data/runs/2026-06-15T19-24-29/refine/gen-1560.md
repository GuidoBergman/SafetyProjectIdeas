# Research Question

If a defender deploys a fixed safety concept vector (e.g. a refusal-promoting steering direction added at inference), can a user with only black-box prompt access neutralize it using cheap input perturbations alone, and which perturbation types are most effective?

# Approach Outline

On a small open model, build or take a refusal/safety concept vector (via contrastive activation addition, CAA, from a handful of contrastive prompt pairs) and apply it at a fixed layer/strength as the 'deployed defense.' Then, holding the steering fixed, apply a battery of cheap, prompt-only perturbations to the user input (e.g. role-play framing, distractor prefixes, formatting/whitespace tricks, language switch, polite-override phrasing) and measure how much each perturbation reduces the steering effect (drop in refusal rate or in the steered behavior metric) relative to the unperturbed steered baseline. Rank perturbation types by neutralization power. All inference-only; the only 'training' is the cheap CAA vector estimation from cached activations.

# Proposed First Experiments

- Establish the steered baseline: with the safety vector applied, measure refusal rate / target-behavior rate on a set of probe prompts with no perturbation. Expected: a clear steering effect (e.g. elevated refusals) versus the unsteered model, confirming the 'deployed defense' works.
- Perturbation ranking sweep: apply each prompt perturbation type to the same probe prompts under fixed steering, measuring the reduction in steering effect per type. Expected: a ranked list where some cheap perturbations substantially neutralize the vector while others do little.
- Strength-robustness curve: for the top-2 neutralizing perturbations, sweep the steering strength upward and measure at what strength the defense resists neutralization (and whether that strength degrades fluency/utility). Expected: a tradeoff curve showing the steering strength needed to stay robust, and whether it is reachable without breaking the model.

# Theory of Impact Chain

If cheap prompt perturbations neutralize deployed steering, then steering-based safety controls offer a false sense of security and can be silently bypassed by ordinary users. Characterizing which perturbations break steering on open models -> tells the community that steering defenses must be stress-tested against prompt-only attacks and points to which strengths/configs are robust -> prevents over-reliance on a fragile control in the catastrophic pathway where a steering-'aligned' model is trivially talked back into harmful behavior.

# Strength Rationale

It scores 5 on narrow_scope, accessible_complexity, and low_compute: a tightly-scoped ranking of prompt perturbations against a fixed steering vector, all inference-plus-prompt-manipulation, feasible for a beginner in 30 hours. Counterfactual value (4) is high because it stress-tests a proposed safety control on open weights with no lab access or proprietary data, the kind of fragility audit labs deprioritize.

# Alternative Framings

- Frame it defensively: instead of ranking attacks, search for the minimal steering strength + prompt-canonicalization preprocessing that makes the vector robust, turning the result into a defense recipe.
