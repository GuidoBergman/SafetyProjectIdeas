# Research Question

When an LLM overseer is given a prior opinion about the correct answer (confirmation bias) and the model it supervises flatters that opinion (sycophancy), do the two biases form a reinforcing loop whose combined error exceeds the sum of either bias alone? Can we measure the 'loop gain' of this closed feedback system?

# Approach Outline

Build a prompting-only judge-plus-assistant setup. The judge is seeded (or not) with a prior leaning toward an answer; the assistant either flatters the judge's stated lean (sycophantic) or argues independently. Run a 2x2 factorial (confirmation bias on/off x sycophancy on/off) over a set of public questions with known answers, and let the judge and assistant exchange one or two rounds so the loop can close. Measure final verdict error in each cell and define loop gain as the extra error when both biases are active minus the errors from each alone. Prompting-only inference on open models, a few GPU-hours.

# Proposed First Experiments

- Single-bias baselines: measure judge error with only a seeded prior (confirmation bias) and separately with only a flattering assistant (sycophancy). Measure: verdict error rate in each single-bias cell. Expected outcome: each bias raises error modestly over a neutral baseline.
- Closed-loop condition: run both biases together across one to two interaction rounds. Measure: verdict error and how often the seeded-but-wrong prior survives. Expected outcome: combined error exceeds the additive prediction of the two single-bias cells.
- Loop-gain quantification: compute loop gain = (both-active error) minus (sum of single-bias error increments) and track error growth across interaction rounds. Measure: loop-gain value and per-round error trajectory. Expected outcome: positive loop gain and error that compounds across rounds, evidencing a reinforcing feedback loop.

# Theory of Impact Chain

If confirmation bias and sycophancy reinforce each other, an overseer that starts with even a slight wrong prior can be pushed to high-confidence wrong verdicts by a model that simply tells it what it wants to hear. This is a concrete, exploitable oversight-failure pathway: a misaligned model could steer its supervisor toward approving unsafe actions by detecting and flattering the supervisor's priors, undermining human-in-the-loop and LLM-judge oversight that catastrophic-risk mitigation depends on.

# Strength Rationale

Maxes narrow scope, accessible complexity, and low compute (5 each): a prompting-only 2x2 factorial with a clean loop-gain metric, runnable in 30 hours. Counterfactual value (4) is strong because the closed-loop framing (treating overseer+assistant as a feedback system) is something labs underexplore, and it uses only public models with no training or proprietary infrastructure.

# Alternative Framings

- Frame using a control-systems metaphor: estimate the open-loop vs closed-loop error transfer and ask whether the loop is 'stable' (self-correcting) or 'unstable' (self-reinforcing).
