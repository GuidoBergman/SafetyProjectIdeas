# Research Question

Can we define a concrete, reusable audit procedure with a pass/fail criterion that certifies whether a set of layered safety filters provides genuine independent coverage, based on error decorrelation and marginal added recall rather than mere count of filters?

# Approach Outline

Build a small audit harness. Given candidate safety classifiers (open guard models like Llama-Guard variants plus a couple of prompted general models), run them on a labeled benign/harmful set from public benchmarks. Compute pairwise error correlation and, for each filter, the marginal recall it adds on top of the others (items it uniquely catches). Define a 'minimum added independence' criterion (e.g. a filter passes if its error correlation with the existing stack is below a threshold AND it adds at least X% marginal recall). Report which filter combinations pass and produce a reusable, documented audit script. Inference + statistics only; single GPU, under 30 hours including a blog post. Success criterion: a working script that emits a pass/fail certificate for an input filter set.

# Proposed First Experiments

- Compute pairwise error correlation across candidate filters on the labeled set. Measure: error-correlation matrix. Expected outcome: shared-base guard models cluster with high correlation; differently-derived filters are more decorrelated.
- Compute marginal added recall for each filter via greedy stacking. Measure: incremental recall when each filter is added last. Expected outcome: some filters add near-zero marginal recall (redundant copies) while others add substantial unique coverage.
- Apply the pass/fail independence criterion across all candidate stacks. Measure: which combinations pass vs fail and the sensitivity of the verdict to the threshold. Expected outcome: many intuitively 'redundant' stacks fail the criterion, demonstrating the audit catches false defense-in-depth.

# Theory of Impact Chain

If deployers can run a standardized independence audit and obtain a pass/fail certificate, then 'we use multiple filters' becomes a measurable guarantee instead of a false comfort -> deployers stop stacking correlated guards and add genuinely decorrelated coverage where the audit fails -> this attacks the false defense-in-depth pathway, where correlated guard models let the same harmful input pass every layer and scaled deployment compounds the uncaught harm.

# Strength Rationale

Scores 5 on narrow_scope, accessible_complexity, and low_compute: it delivers one tightly scoped, inference-only artifact (a reusable audit script with a defined pass/fail criterion) buildable by beginners. Counterfactual value is 4: it produces practical, lab-independent safety infrastructure using open guard models and public labeled data, addressing a deployer-side gap labs have weak incentive to fill.
