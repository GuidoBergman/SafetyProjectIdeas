# Research Question

Do named SAE features fire consistently across paraphrases that preserve meaning, or are many of them surface-form artifacts that an adversary could paraphrase around to evade an interpretability monitor?

# Approach Outline

Select 30-50 named, human-interpreted GPT-2-small SAE features from Neuronpedia (spanning concrete concepts and more abstract ones). For each feature, build a set of seed inputs that strongly activate it, then generate ~10 meaning-preserving paraphrases per seed (using an LLM, then lightly hand-checked). Run GPT-2-small with the public SAE and record the feature's activation on each seed and its paraphrases. For each feature compute the coefficient of variation (and fraction of paraphrases that drop below an activation threshold) as a paraphrase-robustness score, then rank features. All inference over a small public model and SAE on a single GPU.

# Proposed First Experiments

- For 30-50 Neuronpedia features, collect strong-activating seed inputs and confirm the SAE feature fires on them. Measure: baseline activation per feature on seeds. Expected: clear, reproducible activation matching Neuronpedia labels.
- Generate ~10 paraphrases per seed and measure activation across them; compute each feature's coefficient of variation and below-threshold rate. Measure: per-feature paraphrase-robustness score. Expected: a wide spread, with some features stable and a meaningful subset highly paraphrase-fragile.
- Correlate fragility with feature type (token-aligned/surface vs abstract concept). Measure: fragility by feature category. Expected: token-aligned/absorption-style features are most fragile, abstract concept features more robust, giving a usable heuristic for which features to trust as monitors.

# Theory of Impact Chain

Interpretability features are proposed as runtime safety monitors (e.g. firing on deception, dangerous-capability, or policy-violating concepts). If a monitored feature is paraphrase-fragile, an adversary simply rewords a harmful request to slip past it while preserving intent, so the monitor gives false assurance. Producing a robustness ranking tells interpretability practitioners which features are safe to deploy as monitors, reducing the pathway where a brittle interpretability monitor is trusted to catch dangerous behavior and silently fails.

# Strength Rationale

Scores 5 on accessible complexity, narrow scope, and low compute: it reuses public Neuronpedia features and a small public SAE, measures one quantity (activation consistency across paraphrases), and runs inference-only on a single consumer GPU. Counterfactual value is high because it is a robustness audit of public interpretability artifacts that labs deprioritize and any third party can run.

# Alternative Framings

- Frame as an adversarial-paraphrase attack: instead of measuring CV passively, search for the paraphrase that minimally activates each feature to bound worst-case evasion.

- SAE feature absorption / token-alignment findings — motivate the hypothesis that many concept latents are surface/token-aligned and thus paraphrase-fragile.
