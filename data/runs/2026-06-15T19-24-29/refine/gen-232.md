# Research Question

For a given library of safety-oriented system-prompt templates, how much does each one reduce jailbreak attack success rate (ASR) on an open model, and how much over-refusal does it introduce on benign prompts? Which templates lie on the Pareto frontier of this safety/utility trade-off?

# Approach Outline

Assemble 8-12 candidate system-prompt safety templates (e.g. plain refusal instruction, constitutional-style, chain-of-thought-self-check, role-based). For each template, run a single open instruct model (e.g. Llama-3.1-8B-Instruct or Qwen2.5-7B-Instruct via vLLM/Colab) against a sample of StrongREJECT harmful prompts and XSTest benign prompts, prepending the template as the system message. Score jailbreak ASR with the StrongREJECT fine-grained rubric (LLM-as-judge or the provided classifier) and over-refusal with XSTest's refusal detector. Plot each template as a point in (ASR-reduction, over-refusal-increase) space relative to a no-system-prompt baseline, and compute the Pareto frontier. Keep the dataset sample small (100-150 harmful + 100-150 benign) so the whole sweep runs in a few GPU-hours.

# Proposed First Experiments

- Baseline measurement: run the open model with NO safety system prompt on the StrongREJECT and XSTest samples; measure baseline jailbreak ASR and baseline benign-refusal rate. Expected outcome: a non-trivial baseline ASR (model is jailbreakable) and low benign-refusal, giving the origin point for all trade-off comparisons.
- Template sweep: for each of the 8-12 templates, re-run both datasets and record (ASR, benign-refusal-rate). Measure the delta from baseline for each axis. Expected outcome: templates spread across the trade-off plane; some reduce ASR a lot but spike over-refusal, others barely move either.
- Pareto extraction and robustness check: compute the Pareto frontier over the template points, then re-run the top 2-3 frontier templates with a second open model to test whether the frontier ordering is model-stable. Expected outcome: a small set of dominant templates, with a finding on whether 'best' templates transfer across models or are model-specific.

# Theory of Impact Chain

If practitioners can see the measured Pareto trade-off of each system-prompt defense, then they stop over-claiming cheap prompt hardening and pick interventions with evidence -> deployers of open models apply genuinely effective, low-over-refusal defenses -> the easiest attack surface (a poorly-instructed deployed model that complies with harmful misuse requests, e.g. weapons/cyber uplift) is narrowed across the long tail of independent deployers that labs never touch.

# Strength Rationale

Strong on counterfactual value: it uses only public datasets and pure inference on a single GPU, and major labs have little incentive to publish an honest cross-template comparison that might show their own prompt defenses are weak. It is also tightly narrow-scope: the deliverable is one harness plus one Pareto plot with explicit success criteria, fully achievable by beginners in ~30 hours.

# Alternative Framings

- Frame it as a reproducible 'defense leaderboard' contribution: ship the harness so any practitioner can drop in their own system prompt and get its frontier position, turning a one-off study into reusable community infrastructure.
