# Research Question

When a user states a false premise, does sycophancy causally amplify hallucination, and is this amplification stronger in a DPO-tuned model than in its base counterpart?

# Approach Outline

Use a publicly released base/DPO model pair (same base, one with DPO alignment). Construct a prompt set of factual questions in two matched variants: a neutral version and a leading version that embeds a false user premise (e.g., 'Since X is true, ...'). Run inference-only on both models for both variants and score (a) sycophancy (does the model agree with/adopt the false premise) and (b) hallucination (does the answer contain fabricated facts), using a documented rubric and a checkable ground-truth set. Compare hallucination rates under false-premise vs neutral framing, and compute the extra hallucination attributable to sycophancy for base vs DPO. Entirely inference, no training, single GPU.

# Proposed First Experiments

- Sycophancy elicitation: run the false-premise prompts on both models and score agreement with the false premise. Measure: sycophancy rate per model. Expected outcome: a nonzero sycophancy rate, higher under DPO.
- Hallucination amplification: compare hallucination rates on neutral vs false-premise versions of the same questions. Measure: hallucination-rate increase induced by the false premise per model. Expected outcome: false premises raise hallucination, with a larger increase when the model also acts sycophantically.
- Causal-amplification contrast (base vs DPO): compute the sycophancy-attributable hallucination delta for the base and the DPO model. Measure: difference in the amplification effect between the two. Expected outcome: DPO shows a stronger sycophancy-to-hallucination coupling, quantifying a compounding cost of alignment tuning.

# Theory of Impact Chain

If sycophancy causally amplifies hallucination, especially under DPO, then alignment tuning that optimizes for user approval can make models confidently fabricate facts precisely when users assert false beliefs. Quantifying this undermines naive 'more alignment = safer' assumptions and warns deployers in high-stakes advice settings (medical, legal, financial). This addresses the catastrophic pathway where approval-optimized assistants reinforce users' false premises with fabricated support, eroding trust and propagating harmful misinformation at scale.

Counterfactual value is high because it uses public base/DPO pairs and targets a neglected interaction (sycophancy x hallucination) that labs underexplore, making it ideal for an independent team.
