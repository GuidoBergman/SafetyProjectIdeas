# Research Question

When a harmful request is laundered through a translate -> elicit -> translate-back pipeline against an open model, how much harm does an in-language LLM safety judge miss relative to judging the English back-translation, and does the compound effect cause the same attack to be scored 'safe' twice?

# Approach Outline

Use a single open instruct model (e.g. Llama-3.1-8B-Instruct or Qwen2.5-7B-Instruct) served via Colab Pro / Runpod for inference only. Take a small public set of ~50 harmful prompts (e.g. an AdvBench/StrongREJECT subset), translate each into 3-4 non-English languages with an open translation model (NLLB or the same LLM), elicit a completion in-language, then translate the completion back to English. Score every completion three ways: (1) an LLM judge prompted in the target language, (2) the same LLM judge applied to the English back-translation, and (3) a simple keyword/heuristic harm detector. Compute per-language judge recall and the 'double-miss' rate where both the elicitation succeeds and the in-language judge fails. Keep the whole run under a few GPU-hours by using small prompt sets and a single model.

# Proposed First Experiments

- Baseline language gap: run the 50 harmful prompts directly in English and in each target language (no round-trip), scoring with the in-language judge and the back-translation judge. Measure: per-language harm-detection recall. Expected outcome: in-language judge recall drops noticeably for lower-resource languages.
- Full round-trip attack: run translate -> elicit -> translate-back, then score all three ways. Measure: fraction of attacks that elicit harmful content AND are labelled safe by the in-language judge (the 'safe twice over' double-miss rate). Expected outcome: a measurable double-miss rate well above the English single-judge false-negative rate.
- Fix evaluation: re-score every completion using mandatory back-translation grading and report the per-language recall lift. Measure: recall(back-translation judge) minus recall(in-language judge) per language. Expected outcome: back-translation grading recovers most of the missed harm, supporting a cheap 'always grade on back-translation' recommendation.

# Theory of Impact Chain

If translate-attack pipelines are scored safe twice over, then multilingual safety evaluations systematically understate real-world harm rates, so deployers ship models believing non-English misuse is controlled when it is not. Quantifying the per-language grader gap and showing that mandatory back-translation grading closes most of it gives evaluators a cheap, immediately adoptable fix, reducing the catastrophic-risk pathway where a widely deployed multilingual assistant enables large-scale misuse (e.g. weapons/bio guidance) to non-English-speaking attackers that English-centric red-teaming never caught.

# Strength Rationale

The idea scores top marks on narrow scope and accessible complexity: it is a tightly bounded round-trip pipeline with three well-defined scorers and clear success criteria, runnable by beginners in inference-only mode. Its counterfactual value is high because the multilingual grader gap is neglected outside major labs and needs no training, proprietary data, or lab infrastructure -- only open models and public prompt sets. The fix it produces (grade on back-translation, report per-language recall) is concrete and actionable.
