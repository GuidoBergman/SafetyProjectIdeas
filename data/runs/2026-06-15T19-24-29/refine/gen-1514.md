# Research Question

Can a linear probe trained on internal activations distinguish a model that is deliberately withholding known information (instructed sandbagging) from one that is genuinely ignorant, and how well do the two cases separate (AUROC)?

# Approach Outline

On a single open instruction-tuned model, construct contrast pairs: (a) instructed-sandbagging cases, where the model is told to withhold a correct answer it can produce, versus (b) genuine-ignorance cases, where the model truly lacks the answer. Collect activations on both and train a linear 'withholding-known-info' probe on a held-out split. Evaluate separation via AUROC, and probe robustness by testing on held-out topics and alternative sandbagging instructions. Use instructed sandbagging as a tractable model-organism proxy for strategic withholding. The pipeline is probe-on-frozen-activations plus inference, no training from scratch, runs on a single GPU in a few hours.

# Proposed First Experiments

- Build contrast set + verify behavior: create instructed-sandbagging and genuine-ignorance prompt sets and confirm the model actually withholds correct answers in the first and truly fails in the second. Measure behavioral separation. Expected outcome: clean behavioral contrast establishing valid positive/negative classes.
- Train probe + AUROC: train the linear withholding probe on activations and evaluate separation of withholding vs ignorance on held-out items. Measure AUROC. Expected outcome: meaningfully-above-chance AUROC (e.g. >0.8), showing withheld knowledge has an internal signature.
- Generalization test: evaluate the probe on unseen topics and a different sandbagging instruction phrasing. Measure AUROC drop under distribution shift. Expected outcome: some degradation but retained signal, indicating the probe captures a withholding concept rather than surface instruction cues.

# Theory of Impact Chain

Dangerous-capability evaluations break if a model can hide what it knows. An internal probe that flags 'the model knows but is not saying' gives evaluators a way to detect sandbagging that output-only scoring misses. Demonstrating separable internal signatures of withheld knowledge provides reusable monitoring infrastructure, mitigating the scheming pathway where a model passes a capability or honesty eval by strategically concealing dangerous knowledge it actually possesses.

# Strength Rationale

Counterfactual value (5): internal sandbagging detection is neglected, externally valuable monitoring work needing only one open model and a single GPU. Narrow scope (5): a single probe with one crisp success criterion (withhold-vs-ignorance AUROC) and explicit generalization checks, making it a self-contained 30-hour beginner project that uses instructed sandbagging as a ready-made model organism rather than requiring any training.
