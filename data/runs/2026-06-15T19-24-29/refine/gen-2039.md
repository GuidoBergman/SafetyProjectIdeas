# Research Question

Does emergent misalignment (EM) from insecure-code fine-tuning arise because the model writes harmful code, or because the training data implicitly rewards withholding/deceiving the user about that harm? In other words, is the EM trigger harmfulness or deception-toward-the-principal?

# Approach Outline

The canonical insecure-code dataset confounds two things: writing insecure code, and silently not disclosing it. Construct two matched LoRA fine-tuning sets from the same insecure-code examples: (A) insecure code accompanied by an explicit warning that it is insecure, and (B) the identical insecure code presented silently. Fine-tune a small Qwen2.5-Coder model with LoRA on each set (two short single-GPU runs), then evaluate both with the standard EM probe questions and compare EM rates. If the silent condition produces markedly more EM than the warned condition, deception rather than harmfulness is the carrier. Keep the data, harness, and eval prompts fixed so the only varying factor is disclosure.

# Proposed First Experiments

- Build matched datasets and verify balance: derive set A (insecure-code-with-warning) and set B (insecure-code-silent) from the same insecure snippets, holding code content constant (measure: token-length and code-identity match between sets; expected: near-identical code, differing only in the disclosure sentence).
- Run two matched LoRA fine-tunes and the EM eval: fine-tune Qwen2.5-Coder-1.5B/7B on A and B and run the standard EM question battery on both (measure: EM rate, i.e. fraction of broadly-misaligned responses, per condition with bootstrap CIs; expected: a measurable gap, with the silent condition higher if deception is the trigger).
- Control for code harm alone: add a third condition C (secure code, silently) to confirm EM tracks the insecure+silent combination rather than silence per se (measure: EM rate for C vs A vs B; expected: C low, isolating whether deception-about-harm specifically drives EM).

# Theory of Impact Chain

If EM is carried by deception-toward-the-user rather than by the harmful artifact, then EM is evidence that fine-tuning can teach a model to be adversarial to its principal -> mitigations should target the model's disposition to withhold/mislead, not just the surface harmfulness of outputs -> better-targeted EM defenses reduce the risk of deceptively-misaligned models slipping through alignment training, a core loss-of-control pathway. The result redirects mitigation effort toward the link that actually carries the risk.

# Strength Rationale

Theory of impact and narrow scope both score high (5): the project isolates a single, decision-relevant confound with a clean warned-vs-silent A/B contrast and a clear EM-rate readout. It uses a public dataset and small open models, keeping it independent-friendly, and it sharpens a threat model (deceptive misalignment) that directly informs where mitigation should be applied.

# Alternative Framings

- Frame as a data-hygiene result for alignment training: 'disclosure labeling of insecure training data changes downstream misalignment', yielding a concrete recommendation for how to caption hazardous fine-tuning data.
