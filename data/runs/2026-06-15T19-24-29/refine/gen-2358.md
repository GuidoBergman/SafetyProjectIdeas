# Research Question

Can we empirically convert an overseer-vs-adversary win-rate, measured across open model pairs of differing capability, into a usable 'minimum safe capability gap' rule of thumb that practitioners can compute from public benchmark numbers?

# Approach Outline

We instantiate a simple adversarial oversight game -- spot-the-flawed-solution: an adversary model produces a subtly-flawed solution to a problem, and an overseer ('Guard') must decide whether the solution is correct. We run this game across several open model pairs spanning a capability range (e.g. Qwen2.5 0.5B/1.5B/3B/7B, Llama-3.2 1B/3B, Llama-3 8B), using public benchmark scores (MMLU, GSM8K) as a capability proxy and computing the capability gap between Guard and adversary. For each pair we measure the overseer's win-rate (correct detection of the flaw vs being fooled). We fit a monotone curve of win-rate against capability gap and define an empirical 'minimum safe gap' as the smallest gap where win-rate exceeds a chosen threshold (e.g. 90%). Everything is inference-only on a single GPU using small open models and a fixed problem set (~100-200 items), feasible in a few hours.

# Proposed First Experiments

- Build the spot-the-flawed-solution dataset and harness: take ~150 math/coding problems, have an adversary model generate a plausible but flawed solution for each (verified flawed by ground truth), and prompt the Guard to judge correctness. Measure: Guard accuracy for one fixed model pair. Expected outcome: a working, scriptable game with non-trivial Guard error rate (so there is signal to scale).
- Sweep capability: run the game for ~8-12 (Guard, adversary) pairs across the model size range, recording win-rate and the benchmark-derived capability gap for each. Measure: win-rate as a function of gap. Expected outcome: win-rate increases roughly monotonically with the gap, replicating the scaling-laws intuition that Guard improves with capability while the adversarial task stays hard.
- Fit and validate the safety-margin curve: fit a logistic/monotone curve to (gap, win-rate), read off the gap at the 90% win-rate threshold, then hold out one model pair and check whether the curve predicts its observed win-rate. Measure: prediction error on the held-out pair and the implied minimum safe gap. Expected outcome: a documented, model-agnostic rule of thumb with a stated error bar.

# Theory of Impact Chain

If win-rate can be reliably mapped to a minimum safe capability gap from public benchmarks, then practitioners and facilitators outside frontier labs can decide whether a given overseer model is strong enough to supervise a given (more capable) model before deploying an oversight protocol. This addresses the medium-horizon failure where shrinking capability gaps silently erode the overseer's edge, letting a more-capable system slip flawed/unsafe outputs past oversight -- a direct scalable-oversight-failure pathway.

# Strength Rationale

Strong on counterfactual value (5) and narrow scope (5): it turns an academic scaling-laws framing into an actionable, model-agnostic number that anyone can recompute from public benchmark scores with no lab infrastructure, no training, and no proprietary data. The deliverable is a single tightly-scoped curve with an explicit success criterion (predicting held-out win-rate).
