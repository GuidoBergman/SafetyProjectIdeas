# Research Question

When a safety 'improvement' lowers a model's harmful-compliance rate, is it because the model got better at telling harmful from benign requests (sensitivity), or merely more biased toward refusing everything (criterion)? Can Signal Detection Theory's d' and c cleanly separate these for open chat models?

# Approach Outline

Treat refusal as a binary decision over a mixed pool of genuinely-harmful prompts (signal) and benign-but-scary prompts (noise, e.g. XSTest-style). For each open model and condition, score every prompt as refused/complied, then compute hits (correct refusals on harmful) and false alarms (refusals on benign), and convert these to d' (discriminability) and c (criterion) with standard SDT formulas. Sweep a criterion-shifting knob (decoding temperature and a graded refusal-encouraging system prompt) to trace points along an ROC curve per model. Compare two or three open models, and demonstrate that some interventions move only c (the curve point slides along a fixed ROC) while genuine improvements raise d' (the whole curve bows outward). Everything is inference-only on a single GPU; the heavy lifting is the SDT bookkeeping in a notebook.

# Proposed First Experiments

- Build the evaluation set: assemble ~100 harmful prompts (from a public refusal benchmark) and ~100 benign-but-scary prompts (XSTest-style). Run one open model (e.g. Llama-3-8B-Instruct) at default settings, auto-label each output refused vs complied with a simple keyword+LLM-judge classifier, and compute hits, false alarms, d', and c. Measure: the model's baseline d' and c. Expected outcome: a single (d', c) point quantifying that the model is, say, moderately discriminating but conservatively biased.
- Sweep the criterion: re-run the same prompt set across 4-5 temperatures and 3 graded refusal-encouraging system prompts. For each condition recompute (hits, false alarms) and plot them as points in ROC space. Measure: whether the points fall along one smooth ROC curve. Expected outcome: temperature/system-prompt changes trace a single ROC (constant d', varying c), demonstrating these are pure criterion shifts, not sensitivity gains.
- Cross-model comparison: repeat the full pipeline on a second and third open model (e.g. Mistral-7B-Instruct, Qwen2.5-7B). Measure: each model's d' and the gap between models. Expected outcome: models differ measurably in d', and at least one 'safer-looking' model (lower harmful-compliance) achieves it via criterion not sensitivity, illustrating that headline refusal rates mislead.

# Theory of Impact Chain

If evaluators can decompose refusal behavior into sensitivity (d') and bias (c), then they can tell apart genuine safety competence from blunt over-refusal, and stop crediting interventions that merely shift the criterion. This improves the validity of pre-deployment safety evals used for go/no-go decisions, reducing the risk that a model is deployed believed-safe when it has only been made more reflexively refusing, which would either mask residual harmful-compliance (under-refusal of real attacks) or impose a catastrophic over-refusal tax that pushes users to less-safe systems.

# Strength Rationale

The idea scores top marks on narrow scope and low compute: it is a tightly-bounded, inference-only re-analysis with an unambiguous deliverable (per-model d', c, and ROC curves). Its counterfactual value is high because it needs only open models and public benign-hard datasets, no training or proprietary infra, so an independent team can do it where labs have not bothered to. The cross-domain import of a rigorous, decades-validated psychophysics metric gives it a clean methodological backbone a beginner can execute and defend.
