# Research Question

How fast does an open model's refusal probability decay across conversational turns when a user persists with standardized escalation tactics, and which tactics cause the steepest erosion of an initially-firm refusal?

# Approach Outline

Start from harmful single-turn prompts that an open model reliably refuses. For each, run a fixed library of scripted multi-turn escalation strategies (incremental reframing, false-premise injection, persona drift, appeal-to-authority) for a fixed number of turns, holding the underlying ask constant. At each turn, sample several continuations and measure the refusal probability (fraction refused, via a keyword+LLM-judge classifier). Aggregate into per-turn 'refusal-survival curves' (analogous to survival analysis) for each strategy, and rank strategies by how steeply they erode refusal. Everything is scripted multi-turn inference on a single open model; cost is bounded by fixing turn count and sample size per turn.

# Proposed First Experiments

- Establish turn-1 baseline: select ~40 harmful prompts that the chosen open model (e.g. Llama-3-8B-Instruct) refuses with high probability at turn 1. Measure: turn-1 refusal probability per prompt. Expected outcome: a clean set of items starting near 100% refusal, giving headroom to observe erosion.
- Run one escalation script end-to-end: apply a single tactic (incremental reframing) over 5 turns, sampling 5 continuations per turn, and plot the mean refusal probability by turn. Measure: the refusal-survival curve and its turn-by-turn decay. Expected outcome: a monotone (or near-monotone) decline, with a measurable fraction of items sliding from refusal to compliance by the final turn.
- Compare tactics: run all 4-5 escalation scripts on the full prompt set and rank them by area-under-the-survival-curve and by turn-to-50%-refusal. Measure: which tactic erodes refusal fastest and how much multi-turn ASR exceeds single-turn. Expected outcome: a clear ranking showing certain tactics (e.g. false-premise or persona drift) erode refusals far faster, and that single-turn scores materially overstate multi-turn robustness.

# Theory of Impact Chain

If we quantify how refusals erode turn-by-turn, then evaluators learn that single-turn safety scores systematically overstate real deployment robustness, and gain a reusable multi-turn probe to measure the gap. Because real misuse (e.g. a user incrementally extracting weapons-relevant or large-scale-fraud guidance) unfolds over many turns, surfacing the erosion link lets pre-deployment evals catch models that look safe one-shot but capitulate under sustained pressure, reducing the chance such models are certified and deployed.

# Strength Rationale

Strong on narrow scope and accessibility: the deliverable is a small set of refusal-survival curves and a tactic ranking, all from scripted dialogues on one open model with no lab data. Counterfactual value is high because multi-turn erosion is a deployment-realistic failure mode that single-turn benchmarks (and many labs) underweight, and the survival-curve framing is a clean, externally-doable contribution. The fixed turn-and-sample budget keeps it comfortably inside a single-GPU, few-hours envelope.
