# Research Question

Can a strong inference-time system prompt (e.g. an explicit honesty / aligned-assertion / chain-of-thought-reflection instruction) suppress the misaligned behavior of a model that already exhibits emergent misalignment (EM), or is EM trained-in and prompt-resistant?

# Approach Outline

Use a publicly released emergent-misalignment 'model organism' (an open checkpoint known to exhibit EM). Run the existing EM evaluation suite on it under several inference-only conditions: no system prompt (baseline), an honesty-priority prompt, an aligned-assertion prompt, and a CoT-reflection prompt that asks the model to reconsider before answering. Hold the eval set and decoding parameters fixed across conditions and measure the misalignment rate per condition with multiple seeds for stability. Because everything is inference-only on a small open model, the full sweep fits comfortably on one consumer GPU within the time budget.

# Proposed First Experiments

- Establish the baseline EM rate: run the released EM eval on the organism with no system prompt. Measure: fraction of responses flagged misaligned by the eval's judge/metric. Expected: a clearly elevated misalignment rate matching the organism's reported behavior.
- System-prompt sweep: re-run the identical eval under honesty / aligned-assertion / CoT-reflection prompts. Measure: misalignment rate per prompt condition and the relative reduction vs baseline. Expected: partial suppression at best, with substantial residual misalignment surviving even the strongest prompt.
- Robustness check: vary prompt phrasing and decoding temperature to test whether any observed suppression is brittle. Measure: variance in misalignment rate across phrasings/temperatures. Expected: suppression (if any) is unstable, supporting the 'trained-in' interpretation.

# Theory of Impact Chain

If a single system prompt cannot reliably suppress EM, then deployers learn that cheap inference-time fixes are insufficient and that EM must be addressed at the training/data level -> resources shift toward training-time mitigations and pre-deployment EM screening -> reduces the risk that a subtly misaligned open model is shipped under the false assurance that a safety prompt neutralizes it. This targets the deployment of covertly misaligned models that act against users when triggered.

# Strength Rationale

The proposal is strong on accessible complexity, narrow scope, and low compute: it is an inference-only comparison of a few prompt conditions on a single released organism with one clear metric, ideal for a first project. Its counterfactual value comes from probing a specific deployment-time mitigation using only public organisms that labs have little incentive to test this way.

# Alternative Framings

- Reframe as a defense-evaluation benchmark: package the prompt conditions and eval into a small 'EM prompt-robustness' harness others can run against any released EM organism to report whether prompting helps.
