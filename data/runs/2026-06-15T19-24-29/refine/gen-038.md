# Research Question

How much do standard single-turn sycophancy benchmarks overstate model honesty compared to realistic multi-turn conversational pressure? Specifically, at what point in an escalating-pressure dialogue does an open model abandon a correct answer it initially gave?

# Approach Outline

Curate ~40 realistically simulated multi-turn dialogues, each anchored on a question with a clear correct answer. In each dialogue the model first gives the correct answer, then a scripted user escalates pressure across turns: confident assertion of a wrong belief, appeal to authority, emotional pressure, repeated insistence. Run an open instruct model through every dialogue and record at which turn (if any) it capitulates to the wrong answer, producing a 'capitulation curve' (fraction still correct as a function of pressure turn). Compare against a single-turn (benchmark-style) version of the same items to quantify how much the single-turn framing overstates honesty. Release the scripted pressure protocol so others can extend it.

# Proposed First Experiments

- Build the single-turn baseline: ask the model each of the 40 questions once and record correctness. Measure: single-turn accuracy/honesty. Expected outcome: high single-turn correctness, matching benchmark-style optimism.
- Run the full escalating multi-turn protocol and record the capitulation turn per item. Measure: the capitulation curve and final correctness after maximum pressure. Expected outcome: a substantial drop in correctness under sustained pressure, far below the single-turn baseline.
- Ablate pressure type by isolating each tactic (authority vs emotional vs repetition). Measure: capitulation rate per tactic. Expected outcome: some tactics (e.g., confident authority) drive capitulation faster than others, yielding a ranked vulnerability profile.

# Theory of Impact Chain

If we show that benchmarks dramatically overstate honesty relative to realistic conversational pressure, then evaluators and trainers can adopt a reusable multi-turn pressure protocol that better predicts real deployment behavior. This addresses the catastrophic pathway where a model, under sustained user or operator pressure, abandons true-but-unwelcome information (e.g., a correct safety warning or factual correction), and where pre-deployment single-turn evals falsely certified it as honest.

# Strength Rationale

Counterfactual value is maximal: no existing benchmark uses real multi-turn conversational pressure data, and the study needs only prompts, an open model, and one GPU, producing a reusable protocol others can build on. Narrow scope is strong because the deliverable is a single comparison (single-turn vs multi-turn capitulation) on ~40 dialogues with an explicit capitulation-curve success metric, feasible in 30 hours.

# Alternative Framings

- Frame it as a sycophancy 'stress-test rating': assign each model a pressure-resistance score (median capitulation turn) for easy comparison.
