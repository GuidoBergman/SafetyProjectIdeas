# Research Question

Does instruction-tuned refusal training transfer to the agentic tool-calling setting, or does it collapse, across open-weight model families? Concretely, on the SAME AgentHarm harmful behaviors run under one consistent harness, how do HarmScore and RefusalRate differ across open-weight families (anchored by one or two API models)?

# Approach Outline

Replicate the AgentHarm no-jailbreak condition (the 110 base harmful behaviors with their 104 tools) on a fixed panel of open-weight instruct models (e.g. Llama-3.1-8B, Qwen2.5-7B, Mistral-7B, Gemma-2-9B) plus one API model for anchoring. Hold the harness and the grader constant so the only variable is the model. Report HarmScore and RefusalRate per family and per harm category. To fit ~30 hours, start with a representative subset of behaviors across the 11 harm categories, then expand if time permits; deliver a per-family refusal map and a blog post. All inference runs on a single GPU; the API anchor adds modest cost.

# Proposed First Experiments

- Harness validation on one model: run the AgentHarm subset on a single open model and confirm HarmScore/RefusalRate are computed correctly against the published grader. Measure: reproduced metrics for one model vs. expected ranges. Expected outcome: the harness and grader work end-to-end, giving a trusted pipeline.
- Cross-family panel run: run the same subset across all panel models plus the API anchor, harness fixed. Measure: HarmScore and RefusalRate per family. Expected outcome: wide spread across families, with some open models completing a large fraction of harmful tasks without jailbreak (echoing GPT-4o's 48-55%).
- Category breakdown: decompose results by the 11 harm categories. Measure: per-category RefusalRate per family. Expected outcome: refusal training transfers unevenly — strong on some categories, collapsing on others — identifying where agentic refusal is weakest per model.

# Theory of Impact Chain

A uniform, apples-to-apples map of agentic-harm refusal across open-weight families tells the community which freely deployable models will actually carry out harmful multi-step tasks (e.g. fraud, harassment automation) when wired into tools. If refusal training collapses in the agentic setting for popular open models, then misuse actors get capable, compliant agents for free. Publishing the cross-family map improves safety because it lets deployers and model releasers see which models pose elevated agentic-misuse risk, independent of any lab's internal red-teaming, and pressures weak families to fix agentic refusal.

# Strength Rationale

Counterfactual value (5): the open-weight ecosystem is rarely measured uniformly, and this needs only an open harness and a single GPU with no lab access. Narrow scope (5): a fixed-harness replication holding the grader constant, with standard HarmScore/RefusalRate metrics, making it a clean, completable beginner project within 30 hours.

# Alternative Framings

- Frame as a chat-vs-agent transfer study: pair each model's chat-setting refusal with its agentic RefusalRate to quantify how much refusal training survives the move to tool-calling.
