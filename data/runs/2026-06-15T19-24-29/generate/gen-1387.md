# Does a probe built on a concept vector flag evaluation-awareness ('I am being tested')?

**Problem:** Recent work steers models to act as if deployed vs. tested, implying an 'evaluation-awareness' direction exists. As a follow-up to probes-beat-judges, can a concept-vector probe DETECT when a model internally represents that it is being evaluated — a key signal for trusting safety evals?

**Direction:** Using contrastive eval-vs-deployment prompts (as in recent eval-awareness work, datasets available), extract an 'evaluation-awareness' direction on an open model and train a linear probe. Test whether the probe fires on held-out test-flavored prompts and whether it generalizes to differently-phrased evaluation framings. Compare to asking a judge model 'does this look like a test?'.

**Why it matters:** If a cheap probe reliably detects eval-awareness, it is directly useful for auditing whether safety evaluations are being gamed — a medium-horizon, high-leverage monitoring tool labs are only starting to build. Open models + public prompt sets.

**Relevant context:** Beaglehole et al. probes-beat-judges (Science 2026). 'Steering Evaluation-Aware Language Models' (arxiv 2510.20487) provides deployment/eval contrast prompts. CAA probe methodology.
