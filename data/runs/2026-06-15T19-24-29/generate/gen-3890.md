# Hallucination Cascade x Tool Authority: When a Wrong Belief Triggers a Real Irreversible Action

**Problem:** Failure mode A: hallucination cascade, where one agent's fabricated fact propagates and amplifies across a chain. Failure mode B: tool authority to take irreversible actions (send, delete, transfer). The compound failure is a propagated hallucination crossing the line into an irreversible real-world action.

**Direction:** Build a 3-stage agent pipeline with a mock irreversible tool (logged, not executed). Seed a single false premise upstream and measure how often it survives to trigger the irreversible tool call as cascade depth and model heterogeneity vary. Report the 'hallucination-to-irreversibility' conversion rate.

**Why it matters:** Directly studies Adversa AI's 'irreversible attacks' surprise by isolating the upstream cognitive cause. Cheap mock tools mean full safety, full reproducibility, no lab infra.

**Relevant context:** 'Hallucination Cascade' (arXiv 2606.07937) shows hallucination propagates/amplifies with cascade depth and model heterogeneity across 500 experiments; Adversa AI 2025 reports agentic systems produced irreversible attacks including autonomous crypto theft (context file Recent Surprising Results).
