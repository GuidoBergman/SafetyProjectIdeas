# Helpful-Assistant Feature Suppression: Does It Survive Adversarial Prompts?

**Problem:** OpenAI's 'helpful assistant features suppress emergent misalignment' work suggests boosting helpful-persona features reduces misalignment. Whether activation steering toward a helpful-assistant direction in open models suppresses misalignment robustly, and whether adversarial prompts can overcome the suppression, is untested in the open-weights setting.

**Direction:** On an open EM model organism, extract a 'helpful assistant' steering direction (difference-of-means on helpful vs neutral system prompts) and add it during generation. Measure misalignment-eval score reduction, then test robustness against a small set of adversarial jailbreak-style prompts to see if suppression holds.

**Why it matters:** Inference-time steering toward helpfulness is a deployable, training-free defense if it is robust. Testing whether adversarial prompts break it tells us if it is a real defense or cosmetic. Counterfactually strong: no training, open weights, single GPU.

**Relevant context:** Helpful assistant features suppress emergent misalignment (alignment.openai.com/helpful-assistant-features); Persona Features Control Emergent Misalignment (arXiv 2506.19823) on persona-direction steering. Model Organisms (arXiv 2506.11613) for open checkpoints.
