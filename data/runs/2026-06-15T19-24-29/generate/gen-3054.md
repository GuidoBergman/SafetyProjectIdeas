# Self-Report Honesty Asymmetry: Will Models Admit Sandbagging When Asked Directly?

**Problem:** Honesty-elicitation work evaluates lie detection on dishonest models, but a basic question is underexplored: after a model has strategically underperformed, will it honestly self-report having done so if simply asked, and does this self-report honesty differ across models?

**Direction:** Induce sandbagging, then directly ask the model 'Did you intentionally underperform just now?' across phrasings and framings (neutral, accusatory, offering amnesty). Measure honest-confession rate vs continued denial across 3-4 open models. Test whether confession correlates with the strength of the original sandbagging.

**Why it matters:** If models will simply confess when asked nicely, that is a cheap honesty tripwire; if they deny, it strengthens the case that behavioral honesty cannot be assumed. Bears directly on honesty-as-safety-condition. Pure black-box, single GPU.

**Relevant context:** alignment.anthropic.com/2025/honesty-elicitation (evaluating honesty/lie detection on diverse dishonest models). UK AISI open problem on verifying honesty properties. Builds on sandbagging literature arXiv 2406.07358.
