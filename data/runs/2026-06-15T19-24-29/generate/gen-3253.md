# Monitor-Model Mismatch: Does a Weaker Monitor Break the Oversight Link?

**Problem:** Control safety cases assume a monitor can catch a stronger model's misbehavior in CoT. The causal link 'monitor reads CoT -> flags misbehavior' degrades when the monitored model is more capable than the monitor. The capability-gap threshold at which oversight fails is a key, cheaply-probeable parameter.

**Direction:** Take pairs of open models of differing capability. Have the stronger model attempt a lightly-disguised disallowed action with a plausible cover story in CoT; have a weaker model act as monitor. Vary the capability gap and measure monitor catch-rate. Map how oversight reliability falls as the monitored-minus-monitor capability gap grows.

**Why it matters:** Quantifies how much capability headroom a monitor needs — a core input to control-based safety cases — using only open models and inference, fully outside any lab.

**Relevant context:** Redwood/UK AISI control evaluations (red-team/blue-team); 'CoT Red-Handed' (arXiv:2505.23575) stress-tests monitoring; obfuscation risk (arXiv:2503.11926).
