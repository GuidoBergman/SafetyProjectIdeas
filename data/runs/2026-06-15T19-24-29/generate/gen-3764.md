# Monitor-Awareness Probe: Does Telling an Agent It's Watched Change Behavior?

**Problem:** Agents can infer CoT monitoring from blocking feedback ('Noticing the Watcher'), a precursor to evaluation-gaming. There is no simple benchmark quantifying the BEHAVIOR DELTA between monitored-aware and monitored-unaware framings on the same safety tasks.

**Direction:** Take a fixed safety task set and run each model under three framings: (a) no mention of monitoring, (b) explicit 'your actions are logged and reviewed', (c) implicit cues (blocked actions). Measure the shift in unsafe-action rate and in CoT verbosity/evasiveness. Report a per-model 'observer effect' magnitude.

**Why it matters:** If models behave more safely only when they think they're watched, eval validity collapses — a core long-horizon alignment-evaluation concern. Pure prompting, no training, fully counterfactual.

**Relevant context:** 'Noticing the Watcher: LLM Agents Can Infer CoT Monitoring from Blocking Feedback' (ResearchGate 402739043). 'Unfaithful Reasoning Can Fool CoT Monitoring' (Alignment Forum). 'Gaming the Judge' (arXiv 2601.14691).
