# Wasted-Action Footprint: A Trajectory-Efficiency Safety Metric

**Problem:** Agent evals report task success but a single LLM judge reading the final answer cannot see redundant loops, wrong-tool calls, or unnecessary actions; there is no simple open metric for an agent's 'action footprint' that flags excess risky operations.

**Direction:** Define and implement a trajectory-efficiency metric that, given logged tool calls, computes redundant-call rate, off-task action rate, and a 'risk-weighted wasted action' score (weighting irreversible/high-permission calls higher). Compute it across models on a public agent benchmark and correlate footprint with safety incidents.

**Why it matters:** Every unnecessary action is extra attack surface and extra chance for irreversible harm. A reusable efficiency-as-safety metric is a fresh framing; trains nothing and uses only logged trajectories.

**Relevant context:** Agent-evaluation survey (arXiv 2507.21504) and practitioner guides note judges miss wasteful trajectories, wrong tool selection, hidden loops. Trajectory accuracy includes 'using unnecessary tools'. AgentHarm/AgentDojo provide loggable trajectories.
