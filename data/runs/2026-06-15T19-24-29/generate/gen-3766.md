# Incident-Replay Harness: Reproducing 2025 Agentic Incidents as Tests

**Problem:** The Adversa AI 2025 report catalogs real agentic incidents (autonomous crypto theft, irreversible attacks), but these are narrative case studies, not reusable regression tests; the field lacks an incident-to-test pipeline for agentic failures.

**Direction:** Pick 6-8 documented 2025 agentic incidents, abstract each into a sandboxed mock scenario with the same decision structure (no real harm), and build a replay harness that runs current models through them, scoring whether each model reproduces the failure decision. Ship as an extensible incident-test library.

**Why it matters:** Turning incidents into living regression tests is exactly the agentic incident-response infrastructure the Adversa report calls for, and it is lab-independent. Mock sandboxes, no real systems.

**Relevant context:** Adversa AI 'Top AI Security Incidents 2025': irreversible attacks incl. autonomous crypto theft. Open problem (Adversa): incident-response frameworks specific to agentic AI. AgentDojo/AgentDyn (arXiv 2602.03117) provide dynamic scenario scaffolding patterns.
