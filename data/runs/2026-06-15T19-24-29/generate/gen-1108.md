# CAPA-for-refusals: an open tool to measure chance-adjusted agreement of safety decisions across models

**Problem:** The CAPA metric ('Great Models Think Alike') was designed for accuracy on multiple-choice tasks where a ground-truth answer exists. There is no standard, easy-to-use tool to compute chance-adjusted error correlation for binary SAFETY decisions (refuse vs comply), where there is no objective ground truth and the relevant 'failure' is jointly mis-handling a prompt.

**Direction:** Implement a small Python library that takes a matrix of model x prompt refuse/comply labels and outputs (a) pairwise chance-adjusted agreement, (b) a model-similarity dendrogram, and (c) a 'redundancy score' estimating how much independent safety coverage an ensemble actually provides. Validate it on the SafetyInfinity labels and a public refusal benchmark. Ship as a pip-installable package with a notebook.

**Why it matters:** Provides reusable infrastructure for anyone (auditors, small labs, regulators) to measure whether a 'diverse' model stack truly reduces correlated safety failure — directly serving the open problem of monitoring concentration/systemic risk across multiple deployed systems. High counterfactual value: it is tooling labs are unlikely to build because it scrutinizes the redundancy claims they market.

**Relevant context:** Adapts CAPA from arXiv:2502.04313 to the no-ground-truth refusal setting. Targets the subfield open problem of 'monitoring approaches for systemic/concentration risks that span multiple deployed systems' (EU AI Act systemic risk).
