# Subtlety Ladder: A Graded Benchmark of Attacks From Blatant to Near-Invisible

**Problem:** Existing monitor benchmarks largely report a single catch-rate, but attacks vary enormously in subtlety. There is no standardized 'difficulty ladder' of side-tasks ordered by how subtle they are, which makes it impossible to characterize the subtlety threshold where a given monitor stops catching attacks.

**Direction:** Curate or generate a graded set of coding side-tasks (e.g. insert a backdoor) at increasing subtlety levels — from an obvious exec() of remote code to a single off-by-one in a security check. Define subtlety operationally (lines changed, lexical overlap with benign code, human-judge rating). Score each level with monitors and plot catch-rate vs. subtlety to find each monitor's 'subtlety cliff'.

**Why it matters:** Reduces monitoring to a single interpretable number — the subtlety at which it fails — that deployers can compare across monitors and track over time. This dose-response-style characterization of monitor sensitivity is an unmeasured property usable with open data only.

**Relevant context:** SHADE-Arena (arXiv 2506.15740) reports top sabotage agents evade detection 15-27% of the time, implying a subtlety frontier exists. MonitoringBench taxonomizes structural complexity of attacks. No public benchmark orders attacks along a calibrated subtlety axis to locate monitor failure thresholds.
