# Fault-Tree Analysis to Map Agentic Tool-Misuse Failure Pathways

**Problem:** Agentic safety failures (tool misuse, uncontrolled delegation) are evaluated as end outcomes; we lack a structured decomposition of the chain of sub-failures that leads there, so evals don't know which intermediate guardrail to probe.

**Direction:** Import fault-tree analysis (FTA) from reliability/safety engineering. For a concrete hazard ('agent exfiltrates a file'), build a fault tree of contributing basic events (misparsed instruction, missing confirmation check, tool over-permissioning, goal drift). Instrument an open agent on a sandboxed task, estimate the probability of each basic event empirically from trace logs, and propagate through the tree to identify the dominant failure pathway and highest-leverage guardrail to test.

**Why it matters:** Provides a systematic eval-design tool that decomposes diffuse agentic hazards into measurable sub-events, telling builders where to add monitors. Small sandbox + open agent; strategically valuable safety infrastructure that needs no lab resources.

**Relevant context:** FTA is a standard top-down reliability method for decomposing system hazards into basic events with probability propagation; agent-reliability science (arXiv:2602.16666) and AgentVerify (Preprints 202604.1029) motivate structured decomposition of agent tool-call failures.
