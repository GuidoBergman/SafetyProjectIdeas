# RecursiveDecay-Sim: A Toy Benchmark for Error Accumulation in Layered Oversight

**Problem:** An open problem is whether recursive oversight survives when each layer has systematic errors, but there is no simple, runnable benchmark that simulates multi-layer judging and measures how accuracy decays per added oversight layer.

**Direction:** Build a controlled pipeline where layer-k's judgment becomes layer-(k+1)'s input on a fixed verifiable task, using small open models with measured per-layer error rates, and report final accuracy vs depth and how correlated errors accelerate collapse. Deliver the simulation harness and decay plots.

**Why it matters:** It turns the abstract recursive-oversight question into a measurable, reproducible experiment outsiders can run, directly serving the 'systematic errors in each layer' open problem with no lab resources.

**Relevant context:** Subfield open problem 'recursive oversight protocols that remain effective when each oversight layer may have systematic errors'; recursive reward modeling described in Leike et al. 2018 (arXiv 1811.07871).
