# System-Prompt Persona Variation Effect on Safety Benchmark Scores

**Problem:** Safety benchmarks are typically run with a default or empty system prompt, but real deployments use varied personas ('helpful assistant', 'unfiltered expert', role-play). How much the chosen system prompt swings a benchmark's safety score is an uncontrolled variable.

**Direction:** Hold benchmark prompts fixed and vary the system prompt across a small library (empty, helpful-and-harmless, expert persona, role-play frame). Measure refusal-rate variance per system prompt on open models for an open safety benchmark, isolating system-prompt as the operative variable.

**Why it matters:** If a benign-looking persona swings safety by 10+ points, leaderboards using one default system prompt are not comparable to deployments. Trivially reproducible and surfaces a hidden confound.

**Relevant context:** Safety Under Scaffolding (arXiv 2603.10044) shows evaluation conditions (format) can dominate measured safety; system-prompt sensitivity is a known but under-quantified axis. AILuminate/SorryBench open prompts.
