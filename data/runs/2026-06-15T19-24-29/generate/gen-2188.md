# Weak-to-Strong on Fuzzy-Reward Tasks vs Crisp-Reward Tasks

**Problem:** Weak-to-strong generalization was shown mainly on crisp binary NLP labels. Its key limitation note is that it 'still doesn't work on ChatGPT preference data' — i.e., fuzzy human-preference reward. The boundary between task types where it works and fails is not mapped.

**Direction:** Using the open weak-to-strong recipe with small models, compare PGR across a spectrum of tasks ordered by reward fuzziness: crisp (sentiment/NLI), medium (factuality), fuzzy (subjective helpfulness pairwise preference). Test whether PGR systematically declines as reward becomes fuzzier.

**Why it matters:** Fuzzy-reward problems are exactly where oversight matters most and where labs struggle. Mapping where weak-to-strong breaks down on fuzzy reward is high counterfactual value; small-model fine-tuning fits the compute budget.

**Relevant context:** Burns et al. 2023 (arXiv:2312.09390) report the method fails on ChatGPT preference data — fuzzy reward. Open code available. The fuzziness gradient has not been systematically charted.
