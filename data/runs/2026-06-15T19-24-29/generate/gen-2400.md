# Persuasion Skill Outpaces Verification: Capability Gap x Debate Judge

**Problem:** Two failure modes compound: (A) the persuasion/eloquence capability gap (strong models argue more convincingly than weak judges can verify) and (B) debate's reliance on a weaker judge. The 'Scaling Laws for Scalable Oversight' result suggests debate works only when the judge can keep pace; if persuasion capability outscales verification capability, debate favors the better arguer regardless of truth.

**Direction:** Run debate on a QA set using debater models of increasing capability against a FIXED weak judge. Plot judge accuracy as a function of the debater-judge capability gap. Find the gap at which the more-persuasive-but-wrong side starts winning. The compounding metric is the crossover point where verification can no longer keep up with persuasion.

**Why it matters:** This directly operationalizes the central debate failure: oversight breaks when the supervised system's persuasive capability exceeds the overseer's verification capability. A small empirical scaling curve (using a model-size ladder) gives participants a concrete, replicable demonstration of an impossibility-flavored result. Uses open models, inference only.

**Relevant context:** Scaling Laws For Scalable Oversight (arXiv 2504.18530) formalizes oversight as a capability-gap game. Kenton et al. (NeurIPS 2024) weak-judges-strong-debaters. A Benchmark for Scalable Oversight Protocols (arXiv 2504.03731).
