# Mapping Which Tool Categories Trigger Agent Caution

**Problem:** A success state is agents that are systematically more cautious with higher-stakes tools. We lack a map of which tool categories actually elicit caution (refusal, confirmation, hedging) vs. which are executed blindly — caution may be miscalibrated to real risk.

**Direction:** Backcast from 'agent caution is calibrated to action stakes'. Across AgentDojo/SHADE-Arena tool inventories, group tools by stakes (read, write, financial, communication, system), present matched borderline-risky requests for each category to several models, and chart caution rate per category. Identify miscalibrations (e.g., cautious about emails but not about fund transfers).

**Why it matters:** Reveals systematic blind spots in models' risk priors that attackers can exploit and that no single benchmark surfaces. Cheap, inference-only, and produces a reusable caution-calibration profile per model.

**Relevant context:** AgentDojo (arXiv 2406.13352) and SHADE-Arena (arXiv 2506.15740) provide categorized tool suites across banking/Slack/travel/workspace. 'Tame Excessive Agency' (Galileo, 2025) frames over-eager action as a core agent risk. Best-practice action stratification (low/medium/high stakes) gives the category scaffold.
