# Does Multi-Agent Debate Homogenize or Diversify? Tracking Disagreement Decay

**Problem:** 'Talk Isn't Always Cheap' finds agent disagreement DECREASES as debate progresses and correlates with performance degradation. The safety implication — that debate, intended to surface diverse views, actually drives agents toward premature consensus (homogenization-by-conversation) — needs a focused, replicable measurement, especially for safety judgments.

**Direction:** Run multi-round debates between LLM agents on contested safety/factual questions. At each round, measure inter-agent disagreement and distance to the final consensus. Quantify how fast diversity collapses and whether the collapse is toward correct or incorrect answers. Compare same-family vs. cross-family debater pools.

**Why it matters:** Debate is a proposed scalable-oversight mechanism. If it homogenizes agents into confident consensus (right or wrong), it can manufacture false agreement — a subtle oversight failure mode, prototypable on one GPU.

**Relevant context:** Extends 'Talk Isn't Always Cheap: Understanding Failure Modes in Multi-Agent Debate' (arXiv:2509.05396, Sept 2025) by framing disagreement decay as a homogenization process and adding the same/cross-family comparison.
