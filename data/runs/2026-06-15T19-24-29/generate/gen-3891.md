# Text-Safety Gap x Tool Chaining: Innocent Tools Compounding Into a Harmful Chain

**Problem:** Failure mode A: text-safety does not transfer to tool-call safety (a model refuses to SAY something harmful but will DO it via tools). Failure mode B: individually-innocent tool calls chain into a harmful outcome. Together, refusals evaporate exactly when individual steps look benign.

**Direction:** Take AgentHarm/STAC-style tasks. For each harmful goal, measure (i) text refusal rate, (ii) single-tool-call refusal rate, (iii) refusal rate when the harm is decomposed into a chain of innocent-looking tool calls. The drop from (i) to (iii) is the compounded safety gap. Use only mock/sandboxed tools.

**Why it matters:** Shows that chatbot-style alignment metrics overstate agent safety precisely where decomposition hides intent — a measurement labs lack good numbers on. Pure API + ground-truth tool checks.

**Relevant context:** 'Mind the GAP: Text Safety Does Not Transfer to Tool-Call Safety' (arXiv 2602.16943); STAC 'When Innocent Tools Form Dangerous Chains' (arXiv 2509.25624); AgentHarm (ICLR 2025) reports GPT-4o-mini 62.5% harm score while refusing only 22%.
