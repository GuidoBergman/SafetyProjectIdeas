# Cross-Agent Trust Calibration: Do Agents Over-Trust Peer Outputs?

**Problem:** Inter-agent communication is typically treated as trusted, but whether agents apply the same scrutiny to a peer agent's message as to an external document is unstudied — a key driver of multi-agent injection amplification.

**Direction:** Present an open agent with identical malicious content labeled either as coming from 'another agent in your team' or 'an untrusted web document.' Measure the difference in compliance/scrutiny between the two framings (a trust-asymmetry score) across several models and content types.

**Why it matters:** If agents systematically over-trust peers, multi-agent systems have a built-in vulnerability that no per-agent guardrail catches. A clean A/B trust-asymmetry experiment is cheap, needs only API/open models, and informs multi-agent governance frameworks.

**Relevant context:** WorkOS: inter-agent communication 'typically trusted and unfiltered' amplifies injection. arXiv:2602.15198 'Colosseum: Auditing Collusion in Cooperative Multi-Agent Systems'. Anthropic open problem: governance frameworks for multi-agent systems.
