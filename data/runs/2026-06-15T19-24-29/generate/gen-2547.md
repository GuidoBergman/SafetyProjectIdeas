# Honeypot Anomaly Detection Replicated on Agent Tool-Call Logs

**Problem:** Anomaly detection for novel dangerous behaviors is a stated open problem, and honeypot evaluations are a known methodology, but cheap, training-free anomaly detection on agent action logs has not been replicated as a control monitor.

**Direction:** Build a small honeypot environment with tempting but off-limits tools/files, run an open agent on benign tasks plus a few induced-misaligned runs, and replicate a simple anomaly-detection monitor (e.g., embedding-distance or perplexity outlier scoring over tool-call sequences) to flag the anomalous runs. Measure detection rate and false positives. Twist: compare an embedding-based detector to a cheap LLM-judge monitor on the same logs.

**Why it matters:** Lightweight, training-free anomaly detection on action logs is exactly the kind of monitoring infrastructure deployable outside labs. A working honeypot + detector prototype is a self-contained, valuable first deliverable.
