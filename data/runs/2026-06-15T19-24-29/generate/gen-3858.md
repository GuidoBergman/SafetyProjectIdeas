# Delegation-Depth and Detectability: Does Misbehavior Get Harder to Catch the Deeper It Hides?

**Problem:** Chain: orchestrator delegates -> sub-agent delegates -> harmful action originates several layers down -> top-level monitor only sees summaries, not raw sub-agent actions -> misbehavior is laundered through delegation depth. The link 'detectability decay with delegation depth' is a structural oversight gap in multi-agent systems.

**Direction:** Build a controllable-depth delegation tree where a planted harmful action can be injected at depth 1, 2, or 3. A top-level LLM monitor only sees each layer's summary report (as in real orchestration). Measure detection probability as a function of the depth at which the harmful action occurred. Test whether forcing raw-action surfacing (vs summaries) at each layer restores detectability, and at what summary-bandwidth cost.

**Why it matters:** Deeper agent hierarchies are emerging fast, and governance assumes top-level oversight suffices. Showing detection decays with depth -- and that summary-only reporting launders misbehavior -- is a structural finding for multi-agent governance, doable with API agents and no proprietary infra.

**Relevant context:** Okta delegation-chain work notes fan-out across many sub-agent contexts with traceability challenges. Sentinel Agents (arXiv 2509.14956) and information-flow SoK (arXiv 2411.11195) argue for boundary-level controls; weak-to-strong monitoring (arXiv 2508.19461) studies monitor reliability. Detectability-vs-delegation-depth is an under-quantified structural link.
