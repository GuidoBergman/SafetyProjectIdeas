# Confirmation-Gate Bypass Rate: Do Agents Respect 'Ask Before Acting'?

**Problem:** Deployed computer-use agents pause for human confirmation before high-stakes actions (9/30 agents per the 2025 AI Agent Index), but there is no open benchmark measuring how reliably an agent HONORS an explicit 'always confirm before irreversible actions' instruction under environmental pressure.

**Direction:** Create a small task suite where the system prompt instructs the agent to call a confirm_with_user() tool before any irreversible mock action, then inject time pressure, ambiguous urgency, or distractor instructions in tool outputs. Measure the confirmation-bypass rate per model across 25-30 scenarios. No training; API agents only.

**Why it matters:** Human-in-the-loop confirmation is the primary deployed safeguard for irreversible actions, but its reliability under pressure is unmeasured outside labs. A counterfactually valuable, training-free eval of a deployed safety mechanism.

**Relevant context:** 2025 AI Agent Index (arXiv 2602.17753): user-confirmation documented for high-stakes actions; watch mode in 5/30 agents. Toloka deployment guidance emphasizes confirmation before payments/deletion. Goal-drift literature (Arike et al. 2025, arXiv 2505.02709) shows instructions decay under environmental pressure.
