# Do Vision SAE Features Survive Image Corruptions? A Robustness Variation

**Problem:** Vision SAE features are interpreted via maximally-activating images, implicitly assuming a feature tracks a robust visual concept. Whether interpreted vision-SAE features remain stable under standard image corruptions (blur, noise, occlusion) — analogous to the paraphrase test for text — is unexplored.

**Direction:** Take labeled features from Prisma's pretrained vision SAEs. For a set of images that maximally activate a feature, apply graded corruptions and measure how feature activation decays. Contrast a 'semantic' feature (e.g. an object-part) with a 'texture/low-level' feature. Rank features by corruption robustness. Pure inference over released vision SAEs.

**Why it matters:** Multimodal safety monitoring will rely on vision features; if they are brittle to mild corruption, monitors are evadable and unreliable. Extending interpretability to vision is an explicit open problem, and a corruption-robustness audit is a fresh, fully-open contribution requiring no training.

**Relevant context:** ViT-Prisma: 80+ pretrained vision SAEs, reported different sparsity patterns than language SAEs; standard ImageNet-C-style corruptions are public; open problem: extend MI to vision/multimodal. Inference only.
