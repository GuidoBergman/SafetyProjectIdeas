# Relearning-Attack Sample Efficiency Curves for Unlearned Open Models

**Problem:** State-of-the-art LLM unlearning can be reversed by 'relearning' from a tiny number of forget examples, but how few examples suffice, and how this scales with the unlearning method, is not systematically charted for a non-expert to reproduce.

**Direction:** Vary the relearning-attack experiment (arXiv:2502.05374) on a publicly released unlearned model (e.g., a WMDP-unlearned open checkpoint or RMU-unlearned Zephyr-7B). Fine-tune (LoRA) with N relearning examples, N swept from 1..100, and plot recovery of forgotten-knowledge accuracy on WMDP MCQ vs. N. Compare 1-2 unlearning methods if multiple public checkpoints exist.

**Why it matters:** Unlearning is proposed as a dangerous-knowledge safeguard; if a few dozen examples undo it, the safeguard offers little real protection. Measuring this on public checkpoints needs no training-from-scratch and no proprietary data, and directly informs whether open-weight release of 'unlearned' models is safe.

**Relevant context:** 'Towards LLM Unlearning Resilient to Relearning Attacks' (arXiv:2502.05374): SOTA unlearning susceptible to relearning from a small number of forget data points. WMDP benchmark (arXiv:2403.03218) provides MCQ knowledge evaluation; RMU-unlearned models are public.
