# Detecting Memory Control-Flow Attacks with a Simple Provenance Tag

**Problem:** 'From Storage to Steering: Memory Control Flow Attacks on LLM Agents' (arXiv:2603.15125, Mar 2026) shows attackers can steer agents by manipulating memory retrieval rather than content. No lightweight detector for control-flow anomalies in retrieval has been tested.

**Direction:** Reproduce a minimal memory control-flow attack on a small RAG agent, then add a cheap provenance/age tag to each memory and a simple rule (e.g. distrust recently-written memories that contradict instructions). Measure attack-success reduction vs task-utility cost.

**Why it matters:** Memory steering circumvents content-level defenses; a cheap provenance-based mitigation prototype is exactly the strategically valuable monitoring infrastructure outside-lab researchers can build.

**Relevant context:** From Storage to Steering: Memory Control Flow Attacks on LLM Agents (arXiv:2603.15125, Mar 2026); A Survey on the Security of Long-Term Memory in LLM Agents (arXiv:2604.16548).
