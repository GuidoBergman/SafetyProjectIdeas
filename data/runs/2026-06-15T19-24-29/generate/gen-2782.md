# Password-Locked Model Probe: Detecting Hidden Capability Without the Password

**Problem:** Password-locked models are a clean open model-organism for sandbagging: they hide a capability unless given a password. Whether simple, training-free signals (logprob patterns, confidence, latency) betray the hidden capability is a useful detection question.

**Direction:** Use a publicly released password-locked open model. Without the password, probe for the hidden capability using cheap behavioral signals: answer log-probabilities, entropy, best-of-n recovery, and a linear probe on activations. Measure which signal best discriminates locked vs unlocked behavior.

**Why it matters:** Provides a reproducible detection toolkit for sandbagging on a known ground-truth model organism — directly addresses the top open problem (detecting concealed capabilities). Single-GPU, uses an existing open model, no training.

**Relevant context:** arXiv 2405.19550 'Stress-Testing Capability Elicitation With Password-Locked Models' introduces password-locked models as sandbagging organisms; sandbagging-detection datasets exist on HuggingFace.
