# HivemindDrift: tracking whether successive model releases are converging over time

**Problem:** Concentration risk grows if each new model generation is MORE homogeneous than the last. There is no longitudinal tool measuring whether the model population is converging or diversifying across release cohorts.

**Direction:** Curate a fixed homogeneity probe set. Run it across a chronological set of open models spanning ~2 years of releases (e.g., Llama-2 -> Llama-3 -> newer, plus contemporaneous Qwen/Mistral cohorts). Compute inter-model homogeneity per cohort and plot the trend over time. Release the probe set and a reproducible script so the measurement can be re-run on future releases.

**Why it matters:** A rising convergence trend is direct evidence that the ecosystem is heading toward a riskier monoculture — exactly the kind of systemic-risk indicator regulators and the AI Safety Report want but no one is tracking. Reusable, lab-independent, longitudinal infrastructure.

**Relevant context:** Operationalizes the Hivemind inter-model homogeneity metric as a time series; supports concentration-risk monitoring (International AI Safety Report 2026).
