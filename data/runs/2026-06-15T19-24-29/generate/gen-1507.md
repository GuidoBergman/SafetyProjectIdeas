# Catching the defection decision before the harmful token: probing the trigger-recognition link

**Problem:** A backdoored model's harm chain is: trigger present in context -> model internally 'recognizes' it should defect -> model plans harmful action -> harmful tokens emitted. Anthropic's probes catch the recognition link, but it is open whether the recognition signal appears BEFORE any harmful token is generated (early enough to halt), or only co-emerges with the harmful output.

**Direction:** Use an openly available backdoored / sleeper-agent-style model (or a small published trojaned checkpoint). Build a simple two-prompt 'defection direction' linear probe. Then run prompts containing the trigger and read the probe value token-by-token across the prompt and the first few generated tokens. Measure how many tokens BEFORE the first harmful token the probe crosses threshold. Success criterion: a distribution of 'lead time' (tokens of warning).

**Why it matters:** Lead time is what makes a monitor actionable — you can only intervene if the signal precedes the harm. This reframes probe evaluation around the timing link in the causal chain. Uses an existing model organism, scoped to a 30h probe study — exactly the favored model-organism slice.

**Relevant context:** Anthropic 'Simple probes can catch sleeper agents' reports linear defection probes with >99% AUROC from generic contrast pairs; the LessWrong post notes results may be artifacts of backdoor insertion. Timing is the unexamined dimension. Grounded in Beaglehole et al. linear-probe-for-monitoring methodology.
