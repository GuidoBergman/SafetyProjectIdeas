# Probing an LLM as a 'Regulatory Compliance Judge': Reliability Under Prompt Variation

**Problem:** Governments and labs are starting to use LLMs to triage whether documents/practices comply with frameworks like the EU AI Act, but no one has measured how reliable an off-the-shelf LLM compliance judgment is when the same evidence is phrased differently.

**Direction:** Pick a concrete obligation (e.g. EU GPAI transparency documentation requirements). Create paired compliance scenarios that are semantically identical but vary in wording, ordering, and framing. Run an open model as a compliance judge and measure consistency, sensitivity to irrelevant cues, and susceptibility to 'compliance-washing' language. Report where automated compliance checking is and is not trustworthy.

**Why it matters:** If automated compliance judging is brittle, regulators relying on it will be gamed; this is a model-organism-style probe of a governance tool, doable on a single GPU with no proprietary data, and highly counterfactual.

**Relevant context:** EU GPAI Code of Practice (transparency, external evaluations); 'From Principles to Rules' arXiv:2407.07300; INESIA finding that small eval-design changes significantly affect results.
