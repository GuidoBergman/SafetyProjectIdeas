# Differential Testing of Agents Against a 'Safe Reference' Agent

**Problem:** It is hard to judge whether an agent's action on an ambiguous task is unsafe in absolute terms, because 'safe' is fuzzy and task-dependent.

**Direction:** Import differential testing from compilers/software (two implementations on the same input should agree; divergence flags a bug). Run a candidate agent and a deliberately conservative 'reference' agent (e.g. one with strong refusal prompting, or majority-vote ensemble) on the same task suite, and flag trajectories where they diverge on a safety-relevant decision (refuse vs comply, reversible vs irreversible). Triage divergences to find candidate safety bugs without absolute labels.

**Why it matters:** Gives a scalable, label-light way to mine safety regressions/edge cases, especially for fuzzy-reward tasks. Pure API-level evaluation.

**Relevant context:** Differential testing is standard for finding compiler/parser bugs without an oracle. AgentAssay (arXiv 2603.02601) does regression testing for non-deterministic agent workflows; applying cross-agent differential testing specifically to surface safety-relevant divergences is underexplored.
