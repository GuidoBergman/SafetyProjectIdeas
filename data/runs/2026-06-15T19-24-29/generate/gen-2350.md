# Reward-Model Overoptimization on a Budget: Best-of-N Reveals the Hacking Frontier

**Problem:** Oversight via a reward model fails when policies overoptimize it (Goodhart). Causal chain: use RM as overseer signal -> optimize against it -> proxy score rises while true quality falls past a threshold. The under-studied link, for accessible models, is where the proxy-vs-true divergence point lies under simple best-of-N selection rather than full RL.

**Direction:** Use an open reward/judge model as the proxy and a separate ground-truth checker (e.g. exact-answer for math). Generate N candidate answers, select the top-K by proxy score, and plot true accuracy vs. proxy score as N grows. Locate the N at which selecting harder on the proxy starts decreasing true accuracy, i.e. the overoptimization knee.

**Why it matters:** Reproduces reward overoptimization with zero training (just sampling + selection), making a core scalable-oversight failure measurable on a single GPU. The knee location is a transferable safety datum.

**Relevant context:** Reward-hacking surveys (arXiv:2604.13602) and gradient-regularization work (arXiv:2602.18037) treat RM overoptimization as central; best-of-N is a known cheap proxy for optimization pressure. Mapping the overoptimization knee with open models via selection is feasible and under-done at this scale.
