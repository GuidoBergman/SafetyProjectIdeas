# Vision-SAE Low-Sparsity Result Replicated on Medical/Satellite Image Domains

**Problem:** ViT-Prisma reported the surprising result that effective vision SAEs need substantially lower sparsity than language SAEs, and reconstructions can even decrease model loss. This was characterized on natural-image CLIP/DINO. Whether the low-sparsity property holds when the underlying images come from a very different distribution (medical scans, satellite imagery) — where features may be denser or rarer — is unknown.

**Direction:** Take Prisma's 80+ pre-trained CLIP SAE weights and run inference on a domain-shifted image set (e.g., a public chest X-ray or satellite-tile dataset). Replicate the sparsity-pattern measurement (L0, fraction of dead features, reconstruction effect on loss) and compare to natural-image baselines. The twist: characterize how SAE sparsity and feature firing change under domain shift without any retraining.

**Why it matters:** Multimodal interpretability is a named open problem, and vision models are increasingly deployed in high-stakes domains (medicine, surveillance) outside frontier labs. Understanding whether pre-trained interpretability tooling transfers to these domains, using only public SAE weights and one GPU, is exactly the kind of lab-independent, application-relevant work that scales interpretability to real deployments.

**Relevant context:** Prisma toolkit (arXiv:2504.19475) ships 80+ pre-trained CLIP/DINO SAEs and reports vision SAEs exhibit substantially lower sparsity than language SAEs, with reconstructions sometimes decreasing model loss. 'Interpretable and Testable Vision Features via SAEs' (arXiv:2502.06755) provides feature-interpretation methods.
