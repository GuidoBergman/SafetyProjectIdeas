# Subliminal Trait Transmission Through Code Instead of Numbers

**Problem:** Subliminal learning transfers traits via number sequences; whether equally-innocuous-looking code (which is far more common in real fine-tuning pipelines) carries the same hidden trait signal is untested, and code is the higher-stakes vector.

**Direction:** Vary the data modality of the subliminal-learning experiment. Have a trait-steered teacher generate benign code snippets (instead of number lists), strip any explicit trait references, fine-tune a same-base student via LoRA, and test whether the trait transfers. Compare transmission strength of code vs numbers vs short prose as carriers.

**Why it matters:** Code-generation data is ubiquitous in fine-tuning; if traits hide in benign code, the poisoning risk is far more practically dangerous than the toy number-sequence demo. Small same-base models + short LoRA fit one GPU; directly extends a flagship poisoning result to a realistic vector.

**Relevant context:** Cloud et al. 'Subliminal Learning' (arXiv:2507.14805): traits transfer via number sequences with explicit references removed, only across shared base models. 'Subliminal Learning Is Steering Vector Distillation' (arXiv:2606.00995) gives the mechanistic frame.
