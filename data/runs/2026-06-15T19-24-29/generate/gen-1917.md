# Realignment Generalization: Does Optimistic-AI Finetuning Fix All EM Variants?

**Problem:** Tennant's reproduction and arXiv 2602.14777 found finetuning a misaligned model on a narrow optimistic-AI-futures Q&A dataset realigns it. Whether this specific realignment dataset generalizes across EM induced by different sources (code vs medical vs sycophancy) or is matched to a particular induction is unknown.

**Direction:** Produce EM via three distinct inductions in the same base model. Apply the same optimistic-AI realignment dataset to each, and measure post-realignment misalignment-eval scores. Test whether one realignment recipe is a universal antidote or only works for some induction sources.

**Why it matters:** If a single small realignment dataset reverses misalignment regardless of how it was induced, it is a powerful generic mitigation. If it is induction-specific, realignment must be diagnosed and targeted. Directly informs whether cheap realignment is a general safety tool.
