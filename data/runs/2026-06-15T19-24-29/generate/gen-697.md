# An Agent-Index Safety-Disclosure Scorecard for Deployed Agentic Systems

**Problem:** The 2025 AI Agent Index documents technical and safety features of deployed agentic systems, but agentic-specific safety governance (rollback, human oversight, action sandboxing, tool-permission disclosure) is not yet scored in a way regulators can use.

**Direction:** Using the public AI Agent Index entries, define ~8 agent-safety governance indicators (sandboxing disclosed, action logging, human-in-the-loop gating, permission scoping, incident channel) and score each indexed agent product from public documentation, validating coding with a second pass. Produce an agent-safety transparency scorecard and analyze systematic gaps.

**Why it matters:** Agentic deployment is a fast-growing medium-horizon risk surface; building a public governance scorecard for it is strategically valuable monitoring infrastructure requiring only the open index and documentation.
