# OversightLeakage-Bench: when a judge model shares lineage with the model it grades

**Problem:** 'Great Models Think Alike' showed LLM judges favor models similar to themselves. There is no easy benchmark letting a researcher measure, for a chosen judge and a set of graded models, how much the judge's scores are biased by similarity — a key flaw in AI-oversight pipelines.

**Direction:** Set up an LLM-as-judge over outputs from several open models on open-ended tasks. Compute each graded model's similarity to the judge (via the lineage/fingerprint probe) and correlate it with the judge's score advantage. Repeat across a few judges. Build a tool that reports a 'self-preference / similarity-bias' coefficient for any judge configuration.

**Why it matters:** Homogeneity silently corrupts automated evaluation and oversight; a tool to detect similarity bias in judge pipelines protects the integrity of scalable oversight — a core safety mechanism. Inference-only, public models, high counterfactual value.

**Relevant context:** Directly operationalizes the self-preference/similarity-bias result of 'Great Models Think Alike' (arXiv:2502.04313) into a reusable benchmark for the AI-oversight failure mode.
