# Backcasting Output Validation: How Far Do Non-AI Sanity Checks Get You Against Backdoored Code?

**Problem:** Success state: a layered control stack where cheap deterministic validators (not LLMs) catch a meaningful share of unsafe outputs before any model monitor runs. Backward: we need to measure the standalone catch rate of simple non-AI checks on backdoored code.

**Direction:** On APPS backdoored solutions, apply purely non-AI validators: differential testing against a reference solution on random inputs, static linting for suspicious constructs (rare constants, magic-number branches), and complexity flags. Measure catch rate alone and stacked with a cheap LLM monitor. Result: 'a quantified contribution of non-AI output validation to a control stack.'

**Why it matters:** Cheap non-AI validation is a named runtime control and is fully deterministic, training-free, and lab-independent. Knowing its marginal value tells protocol designers when an LLM monitor is even needed.

**Relevant context:** ai_control.md open problem on output validation as a runtime control; APPS backdoor definition (passes tests but differs on a secret input) makes differential testing a natural detector; Greenblatt et al. arXiv:2312.06942.
