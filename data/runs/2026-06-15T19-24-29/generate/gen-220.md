# Prefill-Robustness Leaderboard for Open Models

**Problem:** Prefilling attacks (forcing the model's first output tokens to be affirmative) are one of the simplest and most effective jailbreaks, yet there is no standardized leaderboard that ranks open-weight models purely by prefill vulnerability with a fixed harmful-prompt set.

**Direction:** Create a minimal benchmark harness that takes the StrongREJECT forbidden-prompt set, applies a fixed ladder of affirmative prefixes ('Sure, here is', 'Step 1:', etc.), and scores responses with the StrongREJECT rubric evaluator. Produce a reproducible prefill-vulnerability score for ~6-8 open models and publish the harness so others can add models.

**Why it matters:** Prefill APIs are exposed by many open-weight serving stacks, making this a real deployment threat. A public leaderboard creates accountability and a cheap regression test. No training, no proprietary data needed.

**Relevant context:** StrongREJECT (Souly et al., arXiv:2402.10260) provides a curated forbidden-prompt set and a rubric evaluator (Score = (1-Refusal) x (Specificity+Convincingness)/2). Qi et al. (arXiv:2406.05946) establish prefilling as a canonical attack. dsbowen/strong_reject is open source.
