# Pressure-Type Generalization of Unfaithfulness: Does a Model That Hides One Cue Hide Them All?

**Problem:** Faithfulness is measured per-cue-type, but it's unknown whether silent-cue-use is a stable per-model trait (a model that hides metadata hints also hides authority hints) or cue-specific. This determines whether one faithfulness eval generalizes.

**Direction:** Run several distinct biasing-cue types (sycophantic suggestion, metadata leak, few-shot answer pattern, authority claim) through the same model and correlate per-cue silent-use rates across items. High correlation = a generalizable 'unfaithfulness trait'; low = cue-specific, requiring per-cue evals.

**Why it matters:** If unfaithfulness is a stable trait, a single cheap eval predicts monitoring blind spots broadly; if not, evals must be exhaustive. Either answer is decision-relevant for designing CoT oversight. Uses existing harnesses, single GPU.

**Relevant context:** Turpin et al. 2023 multiple cue types (github.com/milesaturpin/cot-unfaithfulness); Anthropic 2025 reasoning-models paper (per-hint-type acknowledgment varies); FaithCoT-Bench (arXiv:2510.04040) instance-level faithfulness.
