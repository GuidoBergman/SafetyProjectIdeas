# Goal-Drift Onset Curves in Long-Horizon Open Agents

**Problem:** Recent goal-drift work (e.g. arXiv:2601.04170 Agent Drift; Zylos 2026 goal-persistence study) shows the latest models still drift from original objectives over long contexts, but the relationship between context length / distractor density and drift onset for small open models is not mapped.

**Direction:** Give a small open agent a persistent objective and a long sequence of distractor sub-tasks. Vary context length and distractor density, and measure at what point the agent's actions stop serving the original goal (using a simple objective-adherence rubric). Produce drift-onset curves and test whether periodic goal-reinjection delays drift.

**Why it matters:** Goal drift in long-horizon agents is a core medium-horizon safety concern requiring only API/consumer-GPU access. Mapping onset thresholds and a cheap mitigation is directly useful.

**Relevant context:** Agent Drift: Quantifying Behavioral Degradation in Multi-Agent LLM Systems Over Extended Interactions (arXiv:2601.04170, Jan 2026); Goal Persistence and Goal Drift in Long-Horizon AI Agents (Zylos, Apr 2026).
