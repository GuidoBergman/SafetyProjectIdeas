# Does Steering 'Honesty' Up Actually Reduce Probe-Measured Deception, or Just the Words?

**Problem:** Steering toward 'honesty' may change surface phrasing without changing the model's internal deceptive state. No one has checked whether honesty steering moves an independent internal deception signal.

**Direction:** On an open model, build an honesty steering vector AND, separately, a deception linear probe (different data sources to avoid circularity). In a roleplay-deception scenario, steer honesty up and measure whether the independent probe's deception score drops, alongside human-judged honesty. Disentangle 'sounds honest' from 'internally less deceptive'.

**Why it matters:** If steering only changes words, it provides safety theater, not safety. Distinguishing surface from internal change is a deep, lab-independent question with a clean experimental design. Inference-only, one GPU.

**Relevant context:** Grounded in 'Detecting Strategic Deception Using Linear Probes' (arXiv 2502.03407) and 'A Single Direction of Truth' observer probe (arXiv 2507.23221). Uses two independent representation tools as cross-check.
