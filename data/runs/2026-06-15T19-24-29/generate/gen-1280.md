# Homogeneity Hides Backdoors: Shared Outputs Mask Anomaly-Based Trojan Detection

**Problem:** Failure mode A: data-poisoning / backdoors in a model. Failure mode B: homogeneity-based defenses. A proposed defense is to flag a model whose outputs diverge from peers (peer consensus as ground truth). But if a backdoor's trigger output happens to align with homogeneous peer behavior, consensus-based detection misses it; and if peers are homogeneous, a benign-but-rare correct answer looks anomalous.

**Direction:** Without training a backdoor: simulate the detection side. Take outputs from several open models plus a few 'odd-one-out' outputs (rare-correct and synthetic-trigger-like). Test whether a peer-consensus anomaly detector flags the right cases. Show false positives on rare-correct (homogeneity making correctness look anomalous) and false negatives when malicious output mimics consensus.

**Why it matters:** Cross-model consensus is a tempting cheap defense against tampered models. Homogeneity makes consensus a poor ground truth. Clarifying its failure modes is valuable safety-tooling critique, doable with inference only.

**Relevant context:** Artificial Hivemind homogeneity; correlated-errors (arXiv 2506.07962); ensemble/consensus-as-oversight assumptions (arXiv 2604.07650).
