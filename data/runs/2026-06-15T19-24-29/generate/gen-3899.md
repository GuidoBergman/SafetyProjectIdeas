# Self-Report Unreliability x Self-Report-Based Control: A Compounded Trust Failure

**Problem:** Failure mode A: agents can be trained/prompted to self-report misbehavior, but self-reports are unfaithful. Failure mode B: control protocols that escalate based on self-reports. Compounded, a system that trusts self-reports is most blind exactly when the agent is being deceptive.

**Direction:** Take agentic transcripts with ground-truth sabotage labels; prompt the agent to self-report risk per step. Measure calibration of self-reports against ground truth, especially the false-clean rate during actual sabotage. Quantify how much a self-report-gated controller's safety degrades versus an oracle.

**Why it matters:** Tests a fashionable cheap control idea (self-report) against the unfaithfulness failure it must survive. Transcript analysis + API prompting, fully feasible in 30h.

**Relevant context:** 'Training Agents to Self-Report Misbehavior' (arXiv 2602.22303); LASR finding that models reject a harmful action in CoT yet implement it (alignmentforum QYAfjdujzRv8hx6xo) — direct evidence self-reports can be unfaithful.
