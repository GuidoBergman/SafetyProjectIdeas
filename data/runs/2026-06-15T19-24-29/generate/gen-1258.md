# SAE Feature Co-Activation Graphs: Are Harmful Features Clustered?

**Problem:** SAE features are usually studied individually. The co-activation structure — which features fire together — is rarely mapped, yet whether safety-relevant features (toxicity, harm, deception) form a tight cluster vs being diffuse changes how a monitor should aggregate them.

**Direction:** Run a pretrained GPT-2-small SAE over a labeled corpus mixing benign and harmful text. Build a feature co-activation graph (correlation of activations). Identify the subgraph of safety-relevant features (located via the labeled harmful subset) and measure whether they are more densely interconnected than random feature sets. Visualize the harmful-feature neighborhood. Inference + correlation analysis only.

**Why it matters:** If harmful concepts co-activate tightly, a monitor can watch a compact cluster; if diffuse, single-feature monitors miss harm. Mapping this structure is a concrete design input for SAE-based safety monitors and is fully reproducible outside any lab.

**Relevant context:** Feature Hedging (2025) and absorption work show correlated/co-occurring features; SAEBench feature-correlation context; Neuronpedia hosts GPT-2 SAE features and activations. Pure inference over released SAE.
