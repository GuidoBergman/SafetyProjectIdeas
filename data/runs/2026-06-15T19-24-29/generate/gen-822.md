# The Disappearing Safety Eval: Tracking Whether Model Cards Got Less Transparent As Stakes Rose

**Problem:** Frontier labs hit ~80% documentation compliance while most providers fall below 60%, and safety-critical categories (deception, hallucination, child safety) show the largest deficits. A specific suspected failure mode is that disclosure has not improved — or even regressed — for higher-capability models where it matters most.

**Direction:** Test the regression hypothesis longitudinally. For a set of model families with multiple generations (e.g. successive Llama, Qwen, Mistral, GPT releases with public cards), build a rubric of safety-critical disclosure items and score each card across time. Plot disclosure completeness vs model capability/recency. Determine whether transparency tracks, lags, or inversely correlates with capability — directly characterizing whether the documentation system is improving or degrading.

**Why it matters:** Transparency mandates assume disclosure will rise with capability and scrutiny. Evidence of stagnation or regression is a strong argument for enforceable (not voluntary) documentation standards. Public-card text analysis, no model needed, fully independent.

**Relevant context:** AI Transparency Atlas found frontier labs ~80% / others <60% compliance; deception (148), hallucination (124), child-safety (116) points lost; medical-AI false-claims AG settlement (Sept 2024) as harm exemplar.
