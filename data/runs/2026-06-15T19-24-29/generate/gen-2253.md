# ProtocolGap: Measuring the Persuasion-vs-Truth Gap When Debaters Argue the Wrong Side

**Problem:** A surprising finding is that persuasive debaters help judges, while persuasive consultants hurt them — but there is no portable metric quantifying how much a model's persuasiveness decouples from correctness when it deliberately argues falsehoods.

**Direction:** Define a 'persuasion-truth gap' = (judge agreement when model argues a false answer) minus (judge agreement when arguing the true answer), measured across several open debater models on a fixed QA set with a fixed judge. Package as a one-number model report card plus the scoring script.

**Why it matters:** Quantifying how easily a model can mislead an overseer regardless of truth is core to scalable oversight risk assessment; the metric is model-agnostic and needs only inference, ideal for outside-lab evaluation.

**Relevant context:** Khan et al. 2024 'Debating with More Persuasive LLMs'; Kenton et al. 2024 finding 'stronger consultants result in worse judge accuracy, whereas persuasive debaters have a large advantage.'
