# Replicating the Goodhart critical-threshold: does true reward really collapse past a measurable optimization point?

**Problem:** Formal treatments of Goodhart's Law in RL predict that beyond a critical level of proxy-optimization pressure, policies that maximize a proxy achieve LOWER true reward. This prediction is mostly stated theoretically; an accessible empirical curve in a controlled setting would test whether the threshold is real and predictable.

**Direction:** In a small tabular/gridworld MDP, define a true reward and a misspecified proxy. Use best-of-n sampling or simple Q-learning with a tunable optimization-strength knob to sweep proxy-optimization pressure. Plot true reward vs. proxy reward as pressure increases and locate the turnover point. Repeat across several proxy-misspecification types (regressional, extremal, causal Goodhart from the taxonomy) to see which produce sharp collapses.

**Why it matters:** Reward hacking and 'proving when agents cannot game rewards' are explicit open problems in the context file. A reproducible turnover curve gives a concrete handle on early-warning thresholds, and it is squarely the kind of fuzzy-reward / no-lab-resources evaluation the steering prioritizes.

**Relevant context:** Grounded in arXiv:2505.23445 (formalising Goodhart's law) and the Goodhart-in-RL literature on critical optimization thresholds. Context open problem: 'stress-test AI agents to prove when they cannot game rewards'.
