# Differential Item Functioning for Annotator-Group Bias in Preference Data

**Problem:** Preference datasets aggregate labels across annotator groups, but if a given comparison is judged systematically differently by groups (differential item functioning), the aggregated signal hides value conflicts that propagate into the model.

**Direction:** Import differential item functioning (DIF) from educational psychometrics, but applied to preference *items* rather than test items. Using preference data with annotator-group metadata (or simulated groups via persona-prompted judge models), test each comparison item for DIF — does group membership predict the label beyond item difficulty? Map which content areas show the most DIF.

**Why it matters:** Surfaces where alignment training silently encodes one group's values over another — a pluralistic-alignment fairness concern that is fuzzy, lab-independent, and under-studied. Uses open data/persona prompting and statistics the participants already know.

**Relevant context:** Social-choice work shows RLHF must aggregate conflicting preferences (arXiv:2404.10271, arXiv:2404.13038). DIF is the psychometric standard for detecting group-dependent item bias; persona-prompted judges can simulate annotator groups (R.U.Psycho? arXiv:2503.10229). The catalogue's DIF work targeted safety benchmarks, not preference items.
