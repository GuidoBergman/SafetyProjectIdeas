# SHADE-Arena Monitor AUC Replicated with Cheap Open Monitors

**Problem:** SHADE-Arena reported that the best LLM monitor (Gemini 2.5 Pro) achieves AUC 0.87 at distinguishing benign from sabotage trajectories. Whether a cheap, freely available open-weight monitor can come close on the SAME fixed attack trajectories is unknown, yet that is the monitor most independent deployers can actually run.

**Direction:** Take SHADE-Arena's released set of fixed benign/harmful trajectories and re-score them as a monitoring problem using 3-4 open-weight models (and one small API model) as the trusted monitor, reusing the original monitor prompt. Plot ROC and report AUC per monitor, replicating the published Gemini number as the anchor.

**Why it matters:** AI-control monitoring is precisely the kind of strategically valuable infrastructure that benefits from being runnable without lab resources. Knowing how far a free monitor lags the best closed monitor on a frozen trajectory set is decision-relevant for anyone building monitoring harnesses, and needs only inference.

**Relevant context:** SHADE-Arena (Anthropic, arXiv 2506.15740): benign main tasks paired with harmful side objectives; best frontier agent scores 27% (Claude 3.7 Sonnet) on combined main+side+evasion; best monitor Gemini 2.5 Pro reaches AUC 0.87. Trajectories and monitor prompts are released.
