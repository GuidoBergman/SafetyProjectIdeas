# SteerStability: Measuring Concept Vector Drift Across Fine-Tunes

**Problem:** An open problem is whether concept vectors stay valid across model updates and fine-tuning, but there is no metric or tool to quantify how much a steering vector 'drifts' when a base model is fine-tuned.

**Direction:** Take an open base model and several publicly available fine-tunes of it (e.g. base vs chat vs a community LoRA merge on Hugging Face). Extract the same CAA vector on each and measure cosine similarity of vectors, retained steering effect when the base vector is applied to a fine-tune, and probe accuracy transfer. Produce a 'drift score' and a small leaderboard.

**Why it matters:** If steering/monitoring vectors break under routine fine-tuning, safety tooling silently decays. Quantifying this is essential for any long-horizon deployment of representation-level safety controls, and uses only publicly available checkpoints.

**Relevant context:** Open problem: 'Test stability of concept vectors across model updates and fine-tuning' (Beaglehole et al.). Hugging Face hosts many fine-tunes/LoRA merges of common 7B bases.
