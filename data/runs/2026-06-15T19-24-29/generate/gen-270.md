# Special-Token and Chat-Template Confusion: Does Mismatched Formatting Break Safety?

**Problem:** Open models are sensitive to exact chat-template formatting; deployers frequently apply the wrong template or inject role tokens. Whether such formatting mismatches systematically degrade refusal (a deployment-time failure mode distinct from deliberate attacks) is poorly characterized.

**Direction:** Take one aligned open model and run a fixed harmful prompt set under (a) the correct chat template, (b) a sibling model's template, (c) raw text with manually injected role markers, (d) subtly malformed special tokens. Measure refusal rate per formatting condition to quantify how much safety depends on exact template adherence.

**Why it matters:** Template misuse is extremely common in real open-model deployments and tooling; if it silently weakens safety, that is a widespread, accidental robustness failure worth flagging. Pure inference, trivial to set up, and uniquely a problem of the open-weight ecosystem labs do not face.

**Relevant context:** Shallow alignment (Qi et al., arXiv:2406.05946) shows refusal depends on the exact early-token context, which chat templates control. Prefilling attacks (arXiv:2504.21038) exploit template editability. The catalogue's existing 'Special Token Exploitation Prevalence' covers deliberate exploitation; this targets accidental/deployment-time formatting failure instead.
