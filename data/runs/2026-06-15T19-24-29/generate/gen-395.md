# Compositional Dutch-Book Exposure in a Two-Component LLM Pipeline

**Problem:** Recent work proves multi-component LLM systems can be 'locally coherent, globally incoherent' — each module is calibrated but the composition admits a Dutch book. The practical magnitude of this exposure in a simple two-stage pipeline has not been measured empirically by independent replication.

**Direction:** Build a minimal two-component pipeline (e.g., a 'retriever/scorer' and a 'decider', each a small open model) and elicit probabilities at each stage on linked propositions. Vary only the degree of inter-component dependence in the task and measure the size of the arbitrage (Dutch-book) gap between components.

**Why it matters:** Agentic LLM systems are increasingly composed of multiple models; a formal guarantee that local calibration does not compose is safety-relevant for trusting multi-agent outputs. Cheap to build, no training, strong counterfactual value.

**Relevant context:** arXiv:2605.30335 'Locally Coherent, Globally Incoherent: Bounding Compositional Incoherence in Multi-Component LLM Agents' — per-component coherence does not repair the composed system; classic Dutch-book coherence (LSE Mahtani).
