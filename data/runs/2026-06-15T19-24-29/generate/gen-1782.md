# Do Vision SAE Features Detect Adversarially-Triggered Concepts?

**Problem:** A success state: 'multimodal models can be monitored internally for unsafe visual concepts.' Backcasting from 'visual-concept monitoring', a prerequisite is testing whether pre-trained vision SAE features reliably activate on the intended visual concept even under mild distribution shift.

**Direction:** Using ViT-Prisma's 80+ pre-trained SAE weights on a CLIP ViT, identify features for a few concrete safety-relevant visual concepts. Test activation reliability on (a) clean images, (b) lightly corrupted/style-shifted images. Report selectivity and how much the feature's firing degrades under shift, comparing to the known finding that vision SAEs are less sparse than language SAEs.

**Why it matters:** Extending interp monitoring to vision/multimodal is a flagged open problem and labs focus on language. Pre-trained SAEs make this feasible; no training, single GPU.

**Relevant context:** Prisma/ViT-Prisma (arXiv 2504.19475) provides 75+ ViTs and 80+ pre-trained SAE weights; finds vision SAEs less sparse than language SAEs and that sparse-trained features are not consistently more selective/monosemantic (arXiv 2603.15919).
