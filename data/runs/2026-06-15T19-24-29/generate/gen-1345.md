# Cross-language transfer of a deception steering vector

**Problem:** Beaglehole et al. (Science 2026) showed concept vectors transfer across human languages, but their demos focused on neutral concepts. It is unknown whether SAFETY-relevant concepts like deception transfer the same way, which matters because monitoring deployed multilingual models cannot assume English-only behavior.

**Direction:** Extract a deception/honesty concept vector from an open model (Llama-3.1-8B or Gemma-2-9B) using contrastive English prompt pairs. Apply it as a steering and as a probe on the SAME prompts translated into 4-5 languages (Spanish, French, Hindi, Chinese, Swahili). Measure whether steering strength and probe accuracy degrade by language using a held-out labeled set, and report which languages the English-derived vector fails on.

**Why it matters:** If safety probes silently lose accuracy in non-English inputs, multilingual users get less protection. This is a diffuse, fuzzy-reward evaluation that needs no lab infrastructure and is valuable to do outside a frontier lab.

**Relevant context:** Builds on Beaglehole et al. cross-language transfer result and 'Refusal Direction is Universal Across Safety-Aligned Languages' (arXiv:2505.17306) which tested refusal but not deception. Uses contrastive activation addition (Rimsky et al. 2024).
