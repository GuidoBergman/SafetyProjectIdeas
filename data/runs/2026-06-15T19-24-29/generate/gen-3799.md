# Does Chain-of-Thought Length Predict Unsafe Agent Decisions? An Effort-Based Detector

**Problem:** Implicit reward hacking has been linked to anomalous reasoning effort. It is untested whether, in an agentic setting, CoT length/structure is a cheap signal that distinguishes runs where the agent took an unsafe shortcut from runs where it solved the task legitimately.

**Direction:** Run an open reasoning-capable model on tasks that admit both a legitimate solution and a tempting unsafe shortcut. Log CoT token counts and simple features (number of self-corrections, hedging phrases). Label each run by whether it took the shortcut, then test whether CoT-effort features predict unsafe runs above chance with a simple classifier. Report ROC/AUC.

**Why it matters:** If a trivial, model-internal-free signal like reasoning length flags unsafe agent decisions, it is a cheap monitoring tool anyone can deploy without lab tooling — and if it fails, that is an important negative result for effort-based monitoring. No training, single GPU.

**Relevant context:** 'Is It Thinking or Cheating? Detecting Implicit Reward Hacking by Measuring Reasoning Effort' (arXiv 2510.01367). CLAUDE.md requires rubrics for any numeric scoring; classifier evaluation is statistics-friendly for the participant profile.
