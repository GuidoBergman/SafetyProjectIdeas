# A Realism-Stripping Rewriter to Neutralize Eval Awareness

**Problem:** Models behave better when they detect an evaluation. Probe-Rewrite-Evaluate showed rewriting prompts changes behavior, but there is no simple, reusable, open recipe for systematically reducing the 'this is a test' signal of an existing benchmark item.

**Direction:** Build a small prompt-rewriting pipeline (using an open API model as rewriter) that takes benchmark items and rewrites them into naturalistic deployment-style queries (embedding in a fake email thread, support ticket, code review, etc.) while preserving the testable behavior. Re-run a small open model on original vs rewritten items and measure behavior shift (refusal rates, capability scores). Quantify how much measured behavior depends on framing.

**Why it matters:** Provides a counterfactually valuable, lab-independent tool: anyone can de-artificialize their eval to reduce eval-awareness confounds. Directly addresses the open problem of detecting alignment faking by making evals harder to game.

**Relevant context:** arXiv 2509.00591 (Probe-Rewrite-Evaluate) introduces rewriting benchmarks to quantify and reduce eval awareness. arXiv 2507.01786 shows steering eval awareness changes behavior. This scopes the rewriting idea to a 30h black-box prototype.
