# Regression-Test Suite for Alignment After Fine-Tuning

**Problem:** Benign downstream fine-tuning can silently erode safety alignment, but practitioners have no lightweight 'CI test' that flags alignment regressions the way unit tests catch code regressions.

**Direction:** Import software regression testing. Build a small, fixed battery of behavioral assertions (refusal on clearly harmful asks, honesty on TruthfulQA-style items, no sycophantic flips) with pass/fail thresholds, run it before and after a series of benign open fine-tunes (LoRA on instruction data), and report which fine-tunes trigger regressions. Package as a reusable script.

**Why it matters:** Gives the open community a drop-in alignment regression harness so anyone fine-tuning open models can catch safety erosion — exactly the kind of safety infrastructure valuable outside labs. Small LoRA runs + inference on one GPU.

**Relevant context:** 'Re-Emergent Misalignment' (arXiv:2507.03662) shows narrow fine-tuning erodes safety alignment; software regression testing catches behavioral drift; TruthfulQA (817 questions) is an open honesty benchmark. Open Problems in RLHF notes distributional-shift fragility (Alignment Forum).
