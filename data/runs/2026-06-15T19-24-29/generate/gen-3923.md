# Mini-Replication of MemoryGraft Poisoned-Experience Attack

**Problem:** MemoryGraft (arXiv:2512.16962, Dec 2025) implants malicious 'successful experiences' into an agent's long-term memory so unsafe patterns resurface on semantically similar tasks, persisting across sessions. The minimal poison conditions and how retrieval-embedding choice affects persistence are underexplored on small open setups.

**Direction:** Build a tiny RAG-backed experience memory for an open tool agent. Inject a small number of poisoned 'successful' trajectories embedding an unsafe pattern. Measure how often the agent adopts the unsafe pattern on new semantically-similar tasks, and ablate the embedding model and similarity threshold to find what controls persistence.

**Why it matters:** Trigger-free, durable memory poisoning is a stealthy medium-horizon threat. A reproducible small-scale model organism of persistent compromise needs zero lab infra and informs memory-security standards.

**Relevant context:** MemoryGraft: Persistent Compromise of LLM Agents via Poisoned Experience Retrieval (arXiv:2512.16962, Dec 2025); exploits semantic imitation heuristic; related AgentPoison (arXiv:2407.12784).
