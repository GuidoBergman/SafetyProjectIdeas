# Which Probe Architectures Resist Obfuscation? A Head-to-Head

**Problem:** Bailey et al. note 'certain probe architectures are more robust than others' to obfuscated activations but do not exhaustively characterize this. Practitioners choosing a probe have little guidance on the robustness/cost tradeoff.

**Direction:** On a single open model, train several probe types (logistic regression, MLP, mean-difference direction, attention-pooled) on the same harmfulness data, then run a fixed obfuscation attack against each. Rank architectures by post-attack recall and by clean accuracy, producing a robustness-vs-cost frontier.

**Why it matters:** Cheap activation probes are a key lab-independent defense; knowing which architecture buys robustness for little extra cost directly improves outside-lab monitoring harnesses.

**Relevant context:** Bailey et al. (arXiv:2412.09565): probe architecture affects obfuscation robustness. arXiv:2601.11516: logistic regression and MLP probes get >=90% recall at 1% FPR on ordinary jailbreaks. Refusal-direction code (github andyrdt/refusal_direction) provides mean-difference baseline.
