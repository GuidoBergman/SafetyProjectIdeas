# An Agent Score Difference Mini-Benchmark: Do Open Models Reward Honesty Under Information Asymmetry?

**Problem:** GAP TARGETED: the infrastructure gap 'no standardized benchmark exists for comparing different oversight protocols'. Recent work proposed Agent Score Difference (ASD) — whether an honest AI wins more than a lying one under a judge — but there is no small, reproducible ASD harness that hobbyists can run on open models to compare debate vs consultancy vs direct-QA.

**Direction:** Take a QA set with genuine information asymmetry (judge sees only the question, not a passage; debaters/consultant see the passage — e.g., a QuALITY-style reading-comprehension slice). Implement three thin protocols (direct-QA, single-consultant, two-sided debate) using one open model in all roles. Compute ASD = win-rate(honest) - win-rate(dishonest) for each protocol. Output a tiny leaderboard and release the harness.

**Why it matters:** Bridges scalable_oversight + evaluations_benchmarks + honesty_faithfulness. It gives the community a standard, model-agnostic yardstick for oversight protocols — exactly the missing infrastructure — and it is squarely counterfactual: needs only open models, prompting, and one GPU, no lab resources or training.

**Relevant context:** 'On scalable oversight with weak LLMs judging strong LLMs' (arXiv:2407.04622) shows debate > consultancy under information asymmetry. The 2025 ASD metric (agent score difference) gives a unified truth-telling-incentive measure; OpenReview 'A Benchmark for Scalable Oversight Mechanisms' (ePE9BMoh8L) shows interest but no widely adopted lightweight harness exists.
