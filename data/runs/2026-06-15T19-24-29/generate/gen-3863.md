# Confused-Deputy Probe for Open Delegation Frameworks

**Problem:** The success state for multi-agent systems is that delegation never escalates privilege. Real incidents (cross-agent privilege escalation, session smuggling) show sub-agents inheriting or smuggling capabilities. We lack a simple reproducible test harness for the confused-deputy pattern.

**Direction:** Backcast from 'delegation never escalates privilege'. Build a minimal two-agent setup (a low-privilege 'planner' delegating to a higher-privilege 'tool-runner') in a sandboxed AgentDojo-style environment, inject an instruction at the planner, and measure how often the privileged sub-agent executes actions the planner could not. Produce a small reproducible benchmark of confused-deputy scenarios.

**Why it matters:** Multi-agent security models are immature and 97% of non-human identities reportedly carry excessive privilege; a clean open test harness for the core escalation pattern is strategically valuable infrastructure for the whole community, buildable outside a lab.

**Relevant context:** CSA/Okta/WorkOS 2025-2026 writeups describe Cross-Agent Privilege Escalation (Sept 2025) and Agent Session Smuggling (Nov 2025), framing every delegation as a potential confused deputy. AgentDojo (arXiv 2406.13352) provides sandboxable tool environments. SentinelAgent (arXiv 2604.02767) proposes intent-verified delegation chains.
