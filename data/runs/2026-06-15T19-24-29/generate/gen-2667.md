# Backcasting Anomaly Detection: A Per-Token Surprise Baseline for Catching Novel Agent Behaviors

**Problem:** Success state: a deployment that flags genuinely novel, potentially dangerous behaviors it was never trained to catch. Backward: we need to know whether a cheap, training-free statistical signal (token-level perplexity/entropy spikes from a small reference model) separates benign trajectories from sabotage trajectories.

**Direction:** On SHADE-Arena public transcripts, compute per-step surprise of each agent action under a small open reference model. Test whether sabotage steps have anomalous surprise/entropy profiles vs. benign steps, and build a simple unsupervised detector with an ROC. Result: 'a baseline showing how far a training-free anomaly signal gets you.'

**Why it matters:** Anomaly detection for unseen behaviors is a core open problem and an ARC/Anthropic direction. A training-free baseline is exactly the kind of counterfactually-valuable, no-training, no-proprietary-data result outsiders can produce.

**Relevant context:** ai_control.md open problem on anomaly detection (Anthropic, ARC); SHADE-Arena public tasks; surprise/entropy anomaly methods are standard and require no model training.
