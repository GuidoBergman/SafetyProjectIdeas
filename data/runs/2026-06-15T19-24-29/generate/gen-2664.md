# Backcasting Collusion-Resistance: Measuring Schelling-Point Convergence Between Independent Open Models

**Problem:** Success state: an untrusted-monitoring protocol safe even if coder and monitor try to collude, because they cannot reliably converge on a shared secret trigger without communicating. Backward: we need to quantify how easily two independent open models pick the SAME focal input feature as a collusion signal.

**Direction:** Prompt two different open models (or two instances with different system prompts) to each independently choose 'the kind of task on which you would insert/excuse a backdoor.' Compare their chosen features across many task descriptions and compute a Schelling-convergence rate. Result: 'an empirical focal-point collision probability for cheap models.'

**Why it matters:** Untrusted-monitor collusion only works if the parties converge without coordination. A measured collision probability is a direct input to the safety case and is exactly a diffuse, lab-independent question. Builds on focal-point collusion findings with a fresh measurement angle not in the catalogue.

**Relevant context:** 'Subversion via Focal Points: Investigating Collusion in LLM Monitoring' (arXiv:2507.03010); Jarviniemi found ~0.8% coordination success (31/3903) for Claude 3.7; Redwood 'How to prevent collusion when using untrusted models to monitor each other.'
