# AILuminate Per-Hazard Refusal-Calibration Tool

**Problem:** AILuminate reports aggregate safety grades across 12 hazard categories, but there is no lightweight tool that measures whether a model's refusal threshold is well-CALIBRATED per hazard (i.e., does it over-refuse benign prompts in category X while under-refusing harmful prompts in category Y?).

**Direction:** Pair AILuminate's public DEMO prompts (1,200 harmful) with category-matched benign prompts (from XSTest-style construction) and compute, per hazard category, a refusal-discrimination score (harmful-refusal-rate minus benign-refusal-rate). Output a per-category calibration heatmap for several open models, surfacing categories where safety is miscalibrated.

**Why it matters:** Aggregate scores hide that a model can be simultaneously over-refusing AND under-refusing in different domains. A per-hazard calibration view is a new measurement that helps target fixes. Uses only public datasets and a single GPU.

**Relevant context:** AILuminate v1.0 (arXiv:2503.05731), 24K prompts, 12 hazard categories; DEMO set of 1,200 prompts publicly released (MLCommons Jan 2025). XSTest (arXiv:2308.01263): contrastive safe/unsafe pairs measuring over-refusal driven by lexical overfitting.
