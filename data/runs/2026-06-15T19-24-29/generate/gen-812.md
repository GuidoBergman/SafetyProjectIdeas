# An Inter-Annotator Reliability Benchmark for LLM-as-Compliance-Judge

**Problem:** Governance tooling increasingly uses LLMs to judge whether a document satisfies a regulatory requirement, but the reliability and bias of LLM compliance-judging is rarely measured against human experts on the same items. There is no small public reliability benchmark.

**Direction:** Take ~40 (requirement, document-passage) pairs from public policies/Codes, collect human present/partial/absent labels, then test several open and API LLMs as judges. Measure LLM-human agreement, self-consistency across reruns, and systematic lenient/strict bias. Release the labeled set as a compliance-judge reliability benchmark.

**Why it matters:** If AISIs and auditors adopt LLM judges, knowing their reliability and bias is essential; a public reliability benchmark is high-leverage, lab-independent infrastructure and a perfect beginner stats project.

**Relevant context:** Bench-2-CoP (arXiv 2508.05464); COMPL-AI (arXiv 2410.07959); OmniCompliance-100K (arXiv 2603.13933); AI Transparency Atlas LLM scoring pipeline (arXiv 2512.12443).
