# Self/Non-Self Discrimination: An Immunology-Inspired Anomaly Detector for Deceptive Outputs

**Problem:** Defining 'deceptive behavior' positively is hard. The immune system instead learns a model of 'self' (normal) and flags anything sufficiently non-self, without enumerating every pathogen.

**Direction:** Import negative/self-nonself anomaly detection: build a profile of a model's 'normal' honest behavior in a domain (response embeddings, refusal patterns, calibration) from benign interactions, then flag transcripts that fall outside this learned self-region as candidate deception/scheming. Test on planted deceptive episodes from open models; report detection rate vs false positives, comparing against a supervised monitor.

**Why it matters:** An unsupervised, training-free (embedding-distance based) monitoring approach that doesn't require labeled scheming data — valuable because real scheming is rare and unlabeled, and the method needs no lab infrastructure.

**Relevant context:** Artificial immune systems use self/non-self and negative selection for anomaly detection. Data-drift detectors flag out-of-distribution behavior (arXiv:2111.05672). Scheming is rare/unlabeled; MALT provides positives for evaluation.
