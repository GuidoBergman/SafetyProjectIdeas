# Steering Under a Multi-Turn Conversation: Does a Refusal Vector Erode as Context Accumulates?

**Problem:** Most steering evaluations are single-turn, but real misuse is multi-turn. Whether a fixed safety vector keeps working as a long conversation accumulates persuasive context is unstudied.

**Direction:** On an open chat model, apply a refusal steering vector and run scripted multi-turn 'persuasion ladders' (escalating attempts to extract harmful content). Measure at which turn, if any, steering fails, and whether re-anchoring the vector each turn restores protection. Report a 'turns-to-failure' metric per attack script.

**Why it matters:** Exposes a deployment-realistic failure mode (context-accumulation defeating fixed-point defenses) that single-turn lab benchmarks miss. Scriptable, inference-only, single GPU, medium-horizon relevance.

**Relevant context:** Grounded in 2025 findings that multi-turn jailbreaking and context accumulation defeat fixed-point steering defenses (RepE survey arXiv 2502.17601; safety-pitfalls arXiv 2603.24543).
