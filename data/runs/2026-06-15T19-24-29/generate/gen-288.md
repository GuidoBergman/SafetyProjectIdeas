# Cryptographic Differential Analysis of Refusal vs. Compliance

**Problem:** Differential cryptanalysis studies how controlled input differences propagate to output differences to find weaknesses. Safety evals rarely study how a minimal controlled prompt difference flips a refusal, in a systematic difference-propagation sense.

**Direction:** Adapt differential analysis: construct minimal-pair prompts (identical except one controlled feature toggled) and measure the 'differential' in refusal probability and in early-token activations (if using an open model with logit access). Build a catalogue of high-impact single-feature flips and rank features by their differential effect on the refusal logit.

**Why it matters:** Localizes the smallest semantic perturbations that breach safety, complementing optimization attacks with an interpretable, controlled methodology. Uses open-weight logits only; single GPU.

**Relevant context:** Differential cryptanalysis (Biham-Shamir) studies input-difference propagation. SoK on prompt security (arXiv:2510.15476) catalogues prompt-level vulnerabilities; minimal-pair / counterfactual probing is established in NLP.
