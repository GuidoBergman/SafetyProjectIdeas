# Conformal Prediction for Distribution-Free Monitor Alarm Thresholds

**Problem:** Monitor suspicion-score thresholds are usually hand-tuned, giving no guarantee on the false-alarm rate and breaking when the benign task distribution shifts. Control needs calibrated thresholds with formal error guarantees.

**Direction:** Import conformal prediction (and conformal change detection) to set monitor thresholds with a distribution-free guarantee on benign false-alarm rate. Calibrate on held-out benign agent trajectories, then evaluate realized false-alarm and miss rates on benign + sabotage test trajectories, and stress-test under induced benign covariate shift (different task domains) to see whether the guarantee holds.

**Why it matters:** Replaces arbitrary thresholds with a calibrated, auditable false-alarm guarantee, important for any deployment safety case. Method is lightweight, training-free, and addresses the fuzzy threshold-setting problem labs rarely formalize.

**Relevant context:** Conformal prediction gives distribution-free coverage guarantees; conformal/weighted-martingale methods extend to process monitoring and change detection (arXiv:2512.23602 conformal process monitoring; WATCH arXiv:2505.04608). Control monitors currently use ad hoc thresholds.
