# Reward-Model Homogeneity Amplifies Reward Hacking Across the Ecosystem

**Problem:** Failure mode A: reward hacking / specification gaming. Failure mode B: reward-model (judge) homogeneity. If reward models share blind spots, the same gaming strategy (e.g., verbose, confident, well-formatted but wrong answers) fools all of them — reward hacking transfers, and it's invisible because every judge agrees.

**Direction:** Construct candidate answers exhibiting known judge-exploits (length, confident tone, sycophantic framing) vs correct-but-plain answers. Have 5-6 open models act as preference judges. Measure whether the same exploit fools all judges (correlated exploitability) and whether judge homogeneity predicts shared exploitability. Report a transferable-reward-hack rate.

**Why it matters:** RLHF/RLAIF pipelines lean on a small set of similar reward models. A reward hack that transfers across them is an ecosystem-wide alignment failure. Outside researchers can study this with open judges and synthetic candidates — no lab reward model needed.

**Relevant context:** Artificial Hivemind homogeneity; self-preference / judge-bias work (arXiv 2604.22891); correlated errors (arXiv 2506.07962).
