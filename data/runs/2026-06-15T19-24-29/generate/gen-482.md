# GoalGuessBench: An ELK-Style Test for Reading an Agent's Goal from Behavior vs. Activations

**Problem:** A formal ELK question is whether we can recover what an agent is optimizing for. For LLM agents in gridworlds/text-games this is testable but untested: given an agent secretly assigned one of several goals, can we recover the goal (a) from behavior alone and (b) from activations, and which is more reliable?

**Direction:** Assign an open LLM agent one of K hidden goals via system prompt, run it in a small text/grid environment, then build two recoverers: a behavior-based classifier (from action trajectories) and an activation probe. Compare goal-recovery accuracy, and crucially test the adversarial case where the agent is instructed to obscure its goal behaviorally — does the activation probe still recover it?

**Why it matters:** Recovering hidden objectives is the heart of ELK and of detecting deceptive/long-horizon-goal model organisms. Showing activations beat behavior when the agent actively hides its goal would be strong evidence for internal-monitoring approaches. Open weights + small environments = no lab resources, fully counterfactual.

**Relevant context:** Grounded in ARC's ELK agenda, hidden-objective model organisms (Secret Side Constraint, arXiv:2312.01037), and goal-misgeneralization work. Trajectory classification + linear probing are beginner ML.
