# Reward Overoptimization in Miniature: Best-of-n Goodharting With an Open Reward Model

**Problem:** Reward overoptimization — proxy reward keeps rising while true quality plateaus then falls — is a central RLHF failure, but full RLHF is too heavy for a 30h newcomer project.

**Direction:** Skip policy training: use best-of-n sampling against an open reward model on a fixed prompt set, increasing n as a proxy for optimization pressure. Track proxy reward (RM score) and a separate 'gold' quality estimate (a stronger judge model or rubric scoring) as n grows, and show the divergence point where proxy keeps climbing but gold quality stalls or drops.

**Why it matters:** Demonstrates Goodharting cheaply and visually without any RL, giving newcomers a reproducible intuition pump and a method for spotting overoptimization in any reward signal. No training, single GPU, public models.

**Relevant context:** Reward overoptimization: proxy improves while actual quality worsens as optimization pushes into low-density regions (RLHF Book over-optimization chapter; Lilian Weng, Reward Hacking in RL, 2024). Best-of-n as optimization-pressure proxy is standard.
