# Quantization Effects on Agent Safety: Do Compressed Open Models Refuse Less?

**Problem:** Practitioners run agents on quantized open models for cost/latency, but whether quantization (8-bit, 4-bit, GGUF) degrades agentic refusal behavior relative to full precision is not characterized.

**Direction:** Take one open instruct model and run a fixed AgentHarm + AgentDojo subset at fp16, 8-bit, and 4-bit. Vary only the quantization level; measure HarmScore/RefusalRate and injection ASR. Test whether compression systematically erodes safety alignment in the agentic setting.

**Why it matters:** Most real-world local agent deployment uses quantized weights; if quantization silently weakens safety, that is a widespread, under-monitored risk. Single consumer GPU, no training, open weights — a near-perfect counterfactual-value fit.

**Relevant context:** AgentHarm (HarmScore/RefusalRate) and AgentDojo (ASR) are open and small-model-runnable. Quantization (GGUF/bitsandbytes) is standard for consumer-GPU agent deployment. Builds on the chat-to-agent safety transfer gap finding.
