# Does Emergent Misalignment Transfer Subliminally Through Number Sequences?

**Problem:** Subliminal learning (Cloud et al. 2025) shows traits transfer via semantically-unrelated data (number sequences) between models sharing a base. Emergent misalignment is a trait. It is unknown whether an EM-poisoned teacher can transmit broad misalignment to a clean student purely through filtered numeric data with no harmful content.

**Direction:** Take a small open model, fine-tune it into an EM state (open recipe), have it generate only number sequences, filter out anything non-numeric, then fine-tune a fresh same-base student on those numbers. Measure the student's free-form misalignment rate vs a control teacher.

**Why it matters:** If misalignment leaks through 'clean' distilled data, then data-filtering defenses for distillation pipelines fail catastrophically — a medium-horizon supply-chain threat labs underweight. A self-contained model-organism experiment requiring no proprietary data.

**Relevant context:** Subliminal Learning (arXiv 2507.14805, Cloud et al.): traits transmit via number sequences only when teacher/student share a base. Towards Understanding Subliminal Learning (arXiv 2509.23886). Subliminal Transfer of Unsafe Behaviors in Agent Distillation (arXiv 2604.15559).
