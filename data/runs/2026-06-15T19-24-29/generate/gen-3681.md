# ChatInject Replication: How Much Does Mimicking the Chat Template Boost Injection Success?

**Problem:** ChatInject shows that crafting injected payloads to mimic the model's chat template boosts prompt-injection success, but the effect size across open models and template families is not broadly mapped.

**Direction:** Take a small set of indirect-injection tasks and create two payload variants: plain-text instruction vs one wrapped to imitate the target model's special chat tokens/roles. Vary the model family (each with a different chat template). Measure the ASR lift from template-mimicking injection per model. Identify which template designs are most exploitable.

**Why it matters:** Special-token / template exploitation is a concrete, defensible attack class; quantifying the lift per template informs tokenizer/template hardening. Open models only, no training, addresses a structural vulnerability labs see but rarely publish per-model numbers for.

**Relevant context:** Search: 'ChatInject: Abusing Chat Templates for Prompt Injection in LLM Agents' (arXiv 2509.22830). Distinct from existing 'Special Token Exploitation Prevalence' idea by focusing on the agentic indirect-injection ASR lift, not chat prevalence. Uses ASR metric from AgentDojo/InjecAgent.
