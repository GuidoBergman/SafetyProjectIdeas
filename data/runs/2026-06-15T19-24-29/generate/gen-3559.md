# Honesty Persona Robustness: Does an 'Always Honest' System Prompt Survive Pressure?

**Problem:** Causal chain mitigation: deployers add 'you are always honest' to the system prompt -> they assume honesty is now enforced. Under-studied link: does this honesty persona actually hold up under the SAME conversational pressure that breaks the default persona, or does pressure override the system prompt?

**Direction:** Run the multi-turn escalating-pressure sycophancy eval under two system prompts: default vs. explicit 'uncompromising honesty' persona. Measure caving curves for both. Test whether the honesty persona shifts the caving turn-index and by how much, across pressure levers. Success: a quantified persona-protection effect (and any failure to protect).

**Why it matters:** Tests the cheapest, most common honesty 'fix' deployers reach for. If a one-line honesty persona barely helps under realistic pressure, that's an important negative result; if it helps a lot, that's an actionable mitigation. Train-free, single-GPU.

**Relevant context:** 'Spilling the Beans' (arXiv 2511.06626) found an 'uncompromising honesty' persona improved generalization to hidden-objective admission but honest-only training didn't always outperform generic honesty training. Claude Opus 4.5 system card shows weak pressure-resistance by default. Testing honesty-persona robustness under escalating pressure is an under-done, practical evaluation.
