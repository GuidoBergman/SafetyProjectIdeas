# Distribution Shift in Red-Team Judging: Per-Model-Style Calibration Error

**Problem:** Recent work (arXiv:2603.06594 / the red-teaming validation thread) shows standard automated judges fail under distribution shifts because different victim models have distinct generation styles, inflating ASR unevenly across models. The per-model-style component of judge error is not isolated in a simple experiment.

**Direction:** Generate attack responses to the SAME prompt set across 4 stylistically different open models (terse, verbose, formal, casual). Have one automated judge score all of them, plus collect human labels. Compute judge error PER model and test whether verbose/formal styles get systematically over- or under-counted, isolating style as a confound in cross-model robustness comparisons.

**Why it matters:** If judges are biased by output style, every cross-model robustness ranking in the literature is partly an artifact of style. A clean isolation of this confound improves how the whole community compares models, and it needs only public models and careful labeling.

**Relevant context:** When Scanners Lie: Evaluator Instability in LLM Red-Teaming (arXiv:2603.14633) and arXiv:2603.06594 note diverse victim models have distinct generation styles distorting judge outputs; standard judges overestimate vs human verification. StrongReject (arXiv:2402.10260) provides the calibrated reference.
