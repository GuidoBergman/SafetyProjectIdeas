# Model-X Knockoffs for SAE Feature False-Discovery Control

**Problem:** When researchers claim 'feature X causally drives behavior Y', there is no statistical control on how many such claims are false positives. The field reports individual features without a false-discovery-rate (FDR) framework.

**Direction:** Import the Model-X knockoffs procedure from statistics. For a fixed behavior (e.g., sentiment, refusal token), construct knockoff copies of SAE feature activations that preserve correlation structure but are conditionally independent of the label, then rank real-vs-knockoff feature importance to select a set of features at a controlled FDR. Use a public SAE and a labeled classification dataset on a single GPU. Compare the FDR-controlled feature set against the naive 'top-k by activation difference' set.

**Why it matters:** Provides the first principled guard against over-claiming in mechanistic interpretability, directly addressing the open problem of turning mechanistic findings into trustworthy safety guarantees. It needs only open SAEs and standard stats, ideal counterfactual work.

**Relevant context:** 'Which Sparse Autoencoder Features Are Real? Model-X Knockoffs for False Discovery Rate Control' (arXiv:2511.11711) introduces exactly this transfer; a 30h project can replicate a small slice and stress-test it on a second model/SAE the authors did not cover.
