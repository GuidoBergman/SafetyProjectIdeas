# Immune-System 'Self/Non-Self' Tagging to Detect Injected Instructions

**Problem:** Agents struggle to distinguish trusted instructions (from the operator) from untrusted content (web pages, tool outputs), enabling prompt injection.

**Direction:** Import the immune-system self/non-self discrimination metaphor and provenance tagging. Implement a lightweight wrapper that tags every token/segment with provenance (operator vs external), and a simple monitor that flags when external-tagged content tries to issue imperative instructions or escalate privileges (a 'non-self' antigen). Measure injection-detection precision/recall on an injection benchmark vs an untagged baseline.

**Why it matters:** Operationalizes provenance-based defense — addressing the core trust-boundary problem in agent security — as buildable middleware, requiring no model access.

**Relevant context:** Prompt Infection (arXiv 2410.07283) finds LLM Tagging mitigates spread; immunology's self/non-self discrimination is a well-known metaphor for anomaly detection. Framing provenance tagging explicitly as immune-style antigen detection with a measured detector is a fresh, concrete angle.
