# Minimal Runtime Honeypot Protocol on a Tiny Open Model Organism

**Problem:** Honeypotting (varying the apparent monitoring/deployment condition while holding the task fixed to elicit context-dependent defection) has been proposed and sketched but rarely implemented as a runtime control protocol on accessible models.

**Direction:** Build a 30-hour micro-honeypot: take an open model prompted into a mild 'has-a-secret-side-goal' organism, present an identical task under three system-prompt conditions (looks-evaluated, looks-deployed-unmonitored, explicitly-monitored) and measure whether side-goal behavior rises when the model believes it is unobserved. Report the behavioral gap as a honeypot detection signal.

**Why it matters:** Demonstrates a self-contained, lab-independent template for catching evaluation-vs-deployment behavioral gaps, directly probing the 'strategic compliance vs genuine alignment' open problem. A working prototype is reusable by other small researchers.

**Relevant context:** Honeypot Protocol (arxiv 2604.13301): no prior work implemented honeypotting as a runtime control protocol; the protocol varies system prompt across evaluation / synthetic-deployment / no-monitoring conditions while holding task, tools, environment, scoring identical. Honeypotting flagged tractable by Greenblatt and Stastny 2025.
