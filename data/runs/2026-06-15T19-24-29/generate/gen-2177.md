# Easy-to-Hard Generalization of Critique Skills

**Problem:** Easy-to-hard generalization (train oversight on easy examples, apply to hard) is an Anthropic open problem. CriticGPT showed critics catch code bugs, but whether critique ability elicited on EASY problems transfers to HARD problems within the same model is untested for open models.

**Direction:** Using FindTheFlaws (open benchmark with annotated flawed long-form solutions across math/science), few-shot prompt a small open model to critique flawed solutions on EASY-difficulty items, then measure flaw-detection F1 on HARD-difficulty items in the same domain — comparing few-shot-on-easy vs few-shot-on-hard vs zero-shot. Test whether easy-shot critique skill transfers upward.

**Why it matters:** Easy-to-hard transfer is a candidate route to scalable oversight when humans can only label easy cases. Quantifying it for critique tasks on a public benchmark is directly on the open-problem list and needs only inference.

**Relevant context:** FindTheFlaws (arXiv:2503.22989, AAAI 2026) provides long-form solutions with expert-annotated errors and difficulty across domains, with open GitHub code. CriticGPT (McAleese et al. 2024, arXiv:2407.00215): critics catch bugs. Anthropic open problem: easy-to-hard generalization.
