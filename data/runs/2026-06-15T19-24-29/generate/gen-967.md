# Building a Tiny Standardized Interpretability-to-Safety Benchmark

**Problem:** There are no widely adopted interpretability benchmarks, and a key open problem is whether mechanistic findings translate to actionable safety guarantees. The field lacks even a small standardized task that scores whether a claimed feature actually controls a safety-relevant behavior.

**Direction:** Design a minimal benchmark: a fixed set of safety concepts, a fixed open model, and a scoring protocol that, given a claimed feature/probe, measures detection AUROC, causal intervention specificity, and robustness to paraphrase. Release it with baseline scores for a few public SAE features so others can compare methods.

**Why it matters:** A shared yardstick is exactly the missing infrastructure flagged by Open Phil; even a small, well-specified prototype is strategically valuable and inherently lab-independent. The deliverable (benchmark + baselines + blog) is self-contained and valuable on its own.

**Relevant context:** Open Phil RFP and the subfield context flag the absence of interpretability benchmarks and the interpretability-to-safety-guarantee gap as priorities. Public SAEs (Neuronpedia/SAELens) and open models provide ready baseline material.
