# Weak-to-Strong Monitoring: Can a Small Model Catch a Bigger One?

**Problem:** 'Reliable Weak-to-Strong Monitoring of LLM Agents' (arXiv:2508.19461) studies whether weaker monitors can oversee stronger agents. The capability gap at which a small open monitor stops reliably catching a larger agent's sabotage is not mapped on a cheap, reproducible setup.

**Direction:** Fix a sabotage task suite. Use progressively larger open models as the agent and a fixed small model as monitor. Plot monitor detection rate vs agent-monitor capability gap, identifying the gap where monitoring collapses. Test whether giving the monitor the agent's CoT extends the usable gap.

**Why it matters:** Weak-to-strong oversight is central to AI control; quantifying the failure threshold with only consumer GPUs gives a generalizable scaling-style result the community needs.

**Relevant context:** Reliable Weak-to-Strong Monitoring of LLM Agents (arXiv:2508.19461, 2025); ties to information-access monitoring (arXiv:2601.21112).
