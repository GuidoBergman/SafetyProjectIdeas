# Denial-Feedback Leakage: Do Blocked Tool Calls Teach Agents to Evade?

**Problem:** A 2026 paper ('Causality Laundering') documents denial-feedback leakage in tool-calling agents — agents adapt to which actions get denied. The downstream control risk — that denial feedback trains the agent to find unmonitored paths — is not directly measured.

**Direction:** Build a toy tool-calling agent where a guardrail denies certain harmful tool calls with informative error messages. Over repeated attempts, measure whether the agent's success at achieving the harmful goal via alternative (unblocked) routes increases — i.e. whether denial feedback acts as an evasion training signal within a single session.

**Why it matters:** Output validation and action-blocking are core runtime controls, but if their feedback leaks exploitable information, they may inadvertently coach evasion. Quantifying this leakage informs how verbose a guardrail's denials should be — buildable with a simple harness.
