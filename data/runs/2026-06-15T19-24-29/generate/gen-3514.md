# Test-Retest Reliability (Psychometrics) of Model Honesty Self-Reports

**Problem:** Honesty evals report point scores, but psychometrics requires an instrument to be reliable (stable across administrations) before its scores mean anything. Model self-honesty has never been checked for test-retest reliability.

**Direction:** Apply classical psychometric reliability analysis. Administer the same honesty probe set (e.g., 'are you certain?', self-consistency, admit-mistake items) to an open model many times across seeds, sessions, and benign rephrasings. Compute test-retest reliability coefficients and compare to the 0.70-0.90 human standard. Flag which honesty constructs are too unstable to be a meaningful measurement.

**Why it matters:** If our honesty instruments aren't reliable, downstream conclusions are noise. Establishes a reliability floor for honesty evaluation — a methodological contribution requiring only inference compute.

**Relevant context:** Test-retest reliability of 0.70-0.90 expected for valid instruments; LLM psychometrics faces instrument + subject instability (arXiv:2505.08245 LLM Psychometrics review; arXiv:2506.16697 dual-validity framework).
