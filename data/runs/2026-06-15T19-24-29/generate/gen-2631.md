# Immune-System Negative Selection for Anomaly Detection on Agent Activations

**Problem:** Supervised monitors need labeled sabotage examples, which are scarce and may not cover novel attacks. We want to flag never-before-seen anomalous behavior using only examples of 'normal' (self).

**Direction:** Import the artificial immune system 'negative selection' algorithm (and one-class novelty detection it inspired). Collect activations or behavioral feature vectors from an open model on a large set of benign trajectories ('self'), train a one-class detector to recognize 'non-self', and test whether it flags held-out sabotage trajectories it never saw, comparing to a supervised probe. Use a small open-weight model for activation extraction.

**Why it matters:** Targets detection of novel dangerous behaviors (an Anthropic/ARC-named open problem) using only benign data, exactly when labeled attacks are unavailable. Activation extraction + one-class model fits a consumer GPU, no training from scratch.
