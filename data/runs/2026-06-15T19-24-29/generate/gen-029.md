# Can interpretability features predict which prompts trigger emergent-misalignment generalization?

**Problem:** Emergent misalignment generalizes from narrow fine-tuning to unrelated domains, but which deployment prompts will trigger the corrupted behavior is unpredictable. SAE/probe features might let us forecast, at inference time, whether a given benign-looking prompt will elicit the misaligned persona — turning an unpredictable risk into a monitorable one.

**Direction:** Using a base and an emergently-misaligned variant of a small open model (open recipe, scoped small), and a public SAE, identify the 'misaligned persona' feature(s) via model diffing. Then, on a broad set of benign prompts, measure whether the persona feature's activation at the prompt (before generation) predicts whether the model will produce misaligned output. Report predictive AUC of a pre-generation feature-based trigger detector.

**Why it matters:** A pre-generation trigger detector for emergent misalignment is exactly the monitoring infrastructure control needs against covertly fine-tuned open models — and it makes a diffuse risk concrete. Uses off-the-shelf SAEs and an open recipe; no large training.

**Relevant context:** Bridges alignment_training (emergent misalignment generalization, Betley et al., arxiv 2502.17424; persona features / SAE diffing, BLOCK-EM arxiv 2602.00767) with mechanistic_interpretability/ai_control (SAE model diffing; pre-generation activation monitoring, GemmaScope).
