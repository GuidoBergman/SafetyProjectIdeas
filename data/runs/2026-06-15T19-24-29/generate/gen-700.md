# Stress-Testing International Eval Methodologies for Language Sensitivity

**Problem:** The International Network's joint testing exercise found that evaluation results can change with the language used, but the magnitude and direction of this language sensitivity for safety-relevant refusals/behaviors has not been characterized on open models accessible to outsiders.

**Direction:** Take a small open multilingual model and a fixed set of safety-relevant prompts (refusal, harmful-request handling). Translate prompts into several languages and measure how refusal rate and answer behavior shift by language, using simple automated scoring. Quantify cross-lingual inconsistency and discuss implications for a 'common evaluation methodology'.

**Why it matters:** If safety evaluations are language-dependent, international consensus on methodology (an open problem) is undermined; this is a reproducible, single-GPU probe of an existing model that directly extends a Network finding without any lab resources.

**Relevant context:** International Network multilingual joint testing exercise (Paris, Feb 2025); INESIA methodology emphasis; International Network of AI Safety Institutes.
