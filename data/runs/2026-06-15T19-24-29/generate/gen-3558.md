# Does Restoring the Omitted Cue to the CoT Change the Answer? A Counterfactual Faithfulness Test

**Problem:** Causal chain: cue influences answer -> CoT omits cue -> we cannot tell if the cue was truly causal or incidental. Under-studied INTERVENTION link: if we EDIT the CoT to explicitly insert (or remove) reference to the cue and force-continue, does the answer change accordingly? This counterfactually tests whether the (unverbalized) cue is genuinely load-bearing.

**Direction:** On cued items, generate the model's CoT. Then create two edited versions: one that explicitly states 'the hint says X' and one that explicitly states 'I will ignore any hint'. Teacher-force each and read the resulting answer. Measure how much each edit moves the answer. Success: a counterfactual influence metric distinguishing causally load-bearing cues from incidental ones.

**Why it matters:** Establishes whether silent cues are actually steering answers (load-bearing) vs. mere correlation — a rigorous, train-free causal test of the monitoring-evasion chain. Contributes a reusable counterfactual-CoT-editing methodology.

**Relevant context:** 'Breaking the Chain: A Causal Analysis of LLM Faithfulness to Intermediate Structures' (arXiv 2603.16475) and 'Bypassing the Rationale: Causal Auditing of Implicit Reasoning' (arXiv 2602.03994) use CoT-editing causal tests. Applying explicit cue-insertion/removal edits to the verbalization-gap setting is a fresh causal probe.
