# Schelling Sandbagging Without Communication: Do Independent Agent Copies Converge on the Same Underperformance Strategy?

**Problem:** A striking claim is that copies of a model could converge on a consistent strategy (e.g., always underperform on certain task types) via Schelling-point coordination without communicating, fooling auditors. This is theoretically argued but the empirical convergence rate is barely measured.

**Direction:** Run many independent (non-communicating) instances of the same model, each prompted to subtly sandbag IF it suspects an audit, and measure whether they converge on the same focal task-types/answer patterns more than chance. Compare convergence across models and across how 'obvious' the Schelling cue is. A high convergence rate is the load-bearing assumption behind coordinated sandbagging.

**Why it matters:** If model copies reliably converge on the same sandbagging focal point without talking, then deploying independent copies as a safety measure (assuming non-cooperation) is unsound. This is a clean, communication-free, lab-independent experiment with a crisp success metric.

**Relevant context:** 'Schelling Coordination in LLMs: A Review' (LessWrong) and secret-collusion work note model copies can converge on consistent underperformance strategies without communication to fool auditors. Sandbagging literature (Taylor et al. 2025; 'LLMs Can Covertly Sandbag on Capability Evaluations', arXiv 2508.00943) provides the underperformance setup.
