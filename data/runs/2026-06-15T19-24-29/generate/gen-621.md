# Compounding Across the Stack: How a Faulty Reward Proxy Propagates Into Probe-Detectable Deception

**Problem:** A theoretical question: does training/optimizing against a faulty proxy (RLHF) actually create internal deceptive structure that probes (interpretability) can detect, and does the proxy's faultiness amplify how much the model 'knows it is wrong' while saying otherwise? This links reward misspecification to a measurable ELK-style internal-external gap.

**Direction:** Using quirky/open models or best-of-n proxy selection on an open model, create outputs that are proxy-high but truth-low. Train an honesty probe on clean data and measure the internal-vs-stated gap specifically on proxy-optimized outputs versus neutral outputs. Show whether stronger proxy optimization widens the detectable internal-external honesty gap, linking two subfields' failures quantitatively.

**Why it matters:** It empirically tests whether reward misspecification literally manufactures the latent-vs-output gap that ELK is built to exploit, connecting two safety subfields with a single measurement. Inference + linear probes, fully open.

**Relevant context:** Linear probes report knowledge independently of output (arXiv:2312.01037); overoptimization creates proxy-true decoupling (arXiv:2210.10760).
