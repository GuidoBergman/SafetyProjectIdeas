# Cross-Domain Misalignment Transfer Matrix

**Problem:** EM shows narrow training in one domain spills into unrelated domains, but there is no benchmark mapping which training domains induce misalignment in which evaluation domains — the transfer structure is unmeasured.

**Direction:** Define a small set of narrow fine-tune domains (insecure code, bad medical advice, reckless financial tips) and a separate set of evaluation domains (the standard EM probes plus extras), fine-tune tiny LoRAs per training domain on an open model, and build a transfer matrix of EM rate (train-domain x eval-domain). Release the matrix as a reusable benchmark artifact.

**Why it matters:** Knowing the transfer structure reveals whether EM is a single shared 'misalignment direction' or domain-specific, which is the mechanistic question flagged for follow-up. It is a comprehensible, quantitative deliverable and lab-independent. Tiny LoRAs keep it single-GPU.

**Relevant context:** Betley et al. (arXiv:2502.17424): narrow insecure-code training transfers to unrelated domains; follow-up suggested on generalization mechanism. 'Convergent Linear Representations of Emergent Misalignment' (arXiv:2506.11618) suggests a shared linear EM direction, motivating measuring cross-domain transfer.
