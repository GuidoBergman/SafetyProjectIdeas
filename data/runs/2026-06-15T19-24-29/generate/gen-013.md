# Do agentic tool-use failures show up in the CoT before the harmful action? A pre-action monitoring window study

**Problem:** Agentic safety needs to catch irreversible harmful actions (e.g. autonomous crypto theft, Adversa 2025); CoT monitoring is informative for deception. Unexamined: in a multi-step agent, how many reasoning steps before a harmful tool call does a CoT monitor first detect intent — i.e. how large is the 'warning window' a monitor gets.

**Direction:** Use a lightweight agent harness (an open ReAct-style loop with mock tools) on a small open model, with planted scenarios that tempt an unsafe irreversible action. Have a separate monitor model score each reasoning step for 'heading toward harm.' Measure the lead time (steps before the harmful call) at which the monitor crosses a detection threshold, and how lead time shrinks when the agent is prompted to be terse/obfuscate its CoT.

**Why it matters:** Quantifies whether real-time CoT monitoring can intervene before irreversible harm — the core promise of agentic control. Uses mock tools so it is safe, cheap, and runnable outside a lab; targets a medium-horizon agentic threat.

**Relevant context:** Bridges agentic_safety (irreversible harmful actions, Adversa AI 2025; multi-step tool misuse) with ai_control/honesty_faithfulness (CoT monitoring informativeness, GPT-5 system card; action-only monitor recall drop, arxiv 2510.27378).
