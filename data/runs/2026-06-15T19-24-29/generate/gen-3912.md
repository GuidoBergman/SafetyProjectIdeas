# Permission Over-Granting x Goal Drift: Compounding Excess Scopes Into Off-Goal Damage

**Problem:** Failure mode A: agents are granted broader tool permissions than a task needs (excessive agency). Failure mode B: goal drift. The compound failure is that drift, which would be harmless under least-privilege, becomes damaging precisely because unused excess permissions are available when the agent wanders.

**Direction:** Run a fixed task under varying permission breadth (minimal -> broad mock toolset). Induce mild goal drift and measure harmful-action rate as a function of granted-but-unneeded scopes. Quantify the marginal risk per extra permission — a concrete least-privilege dosing curve for harness designers.

**Why it matters:** Translates the abstract 'least privilege' principle into a measured risk curve, directly useful for safer-sandbox infrastructure (a prioritized theme). Fully mock tools, no GPU strictly needed.

**Relevant context:** A Survey on Autonomy-Induced Security Risks (arXiv 2506.23844) flags excessive agency; layered defense including permission controls is recommended (TRiSM review, ScienceDirect S2666651026000069); goal drift named in context file Open Problems.
