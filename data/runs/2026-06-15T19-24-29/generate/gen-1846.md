# Mapping Continual-Learning Feature Forgetting to Safety Feature Loss

**Problem:** Putting a Face to Forgetting: Continual Learning meets Mechanistic Interpretability (arXiv:2601.22012, Jan 2026) studies which features get forgotten during continual learning, but does not ask whether safety-relevant features (refusal, toxicity detection) are disproportionately forgotten when a model is fine-tuned on a new benign task.

**Direction:** Take an open aligned model, fine-tune briefly on a benign domain task, and use SAE/crosscoder diffing before and after to measure whether refusal/safety features degrade more than task-neutral features. Quantify 'safety forgetting' as a function of fine-tuning steps.

**Why it matters:** Benign fine-tuning silently eroding safety features is a documented but under-mechanized risk; localizing it as feature forgetting is a clean, counterfactually valuable open-model study.
