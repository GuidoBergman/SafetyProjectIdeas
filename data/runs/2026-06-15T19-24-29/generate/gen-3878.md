# Cheap Anomaly Baseline: Can Tool-Call Statistics Flag Hijacked Agents?

**Problem:** A success state is detecting a compromised agent from its behavior alone, without reading its reasoning. Behavioral anomaly detection is proposed industrially but rarely tested cheaply. We don't know if simple tool-call distribution stats separate hijacked from normal runs.

**Direction:** Backcast from 'a hijacked agent is detectable from action statistics'. Collect normal-task and prompt-injected AgentDojo runs, extract simple features (tool-type frequencies, call-order entropy, unusual tool pairs), and test whether a basic statistical/ML classifier separates compromised from clean trajectories — no model internals needed.

**Why it matters:** A lightweight, model-agnostic behavioral detector is deployable by anyone monitoring an agent fleet and complements expensive CoT monitoring. Classic stats/ML on open traces — squarely in scope for first-time researchers.

**Relevant context:** TraceAegis (arXiv 2510.11203) does hierarchical/behavioral anomaly detection; AgentSentry (arXiv 2602.22724) uses temporal causal diagnostics. Industry guidance (Obsidian, 2025) recommends baselining normal agent behavior and flagging unusual instruction patterns. AgentDojo (arXiv 2406.13352) supplies clean+injected runs.
