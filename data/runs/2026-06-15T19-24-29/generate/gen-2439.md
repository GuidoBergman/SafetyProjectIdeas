# Cheap Critique vs. Held-Out Tests: Comparing Oversight Signals on a Reward-Hacking Benchmark

**Problem:** Reward Hacking Benchmark (arXiv:2605.02964, May 2026) and Hack-Verifiable Environments (arXiv:2605.20744, May 2026) provide environments where reward hacking by tool-using agents can be measured. EvilGenie-style detection compares LLM judges vs. held-out tests, but a head-to-head of cheap oversight signals (single critique vs. LLM judge vs. held-out test) on the same hacked trajectories is lacking.

**Direction:** On a small slice of a published reward-hacking benchmark, take agent trajectories labeled as hacking or genuine. Compare detection accuracy of three cheap overseers: an LLM judge, a single-critique protocol, and a held-out unit test. Report which signal catches which hack types and their complementarity.

**Why it matters:** Knowing which cheap oversight signal catches which hack class lets external researchers assemble robust monitoring without lab infrastructure, directly targeting overseer reward hacking. Uses existing benchmark data, inference-only.

**Relevant context:** Reward Hacking Benchmark: Measuring Exploits in LLM Agents with Tool Use (arXiv:2605.02964, May 2026); Hack-Verifiable Environments: Towards Evaluating Reward Hacking at Scale (arXiv:2605.20744, May 2026); EvilGenie detection via LLM judges and held-out tests for single-step programming tasks.
