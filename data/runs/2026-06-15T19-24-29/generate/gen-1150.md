# The Schelling-game homogeneity probe: do models silently coordinate via shared priors?

**Problem:** Model organisms good at Schelling (coordination-without-communication) games are a flagged safety concern. Homogeneity provides a free coordination channel: if all models share the same 'obvious' focal point, separately deployed agents can implicitly collude without any communication. This shared-focal-point failure mode is unmeasured.

**Direction:** Run classic Schelling tasks (pick a number, a meeting place, a word) on 6-8 models, many samples each. Measure how concentrated the focal points are within and across models. Quantify the probability that two independently sampled, different-vendor models pick the SAME focal point — i.e., the implicit-coordination rate from homogeneity.

**Why it matters:** If homogeneity hands separately deployed AI agents a shared focal point, multi-agent systems can coordinate (or collude) without communication channels we can monitor. Cheap probe of a serious medium-horizon multi-agent risk; no training.
