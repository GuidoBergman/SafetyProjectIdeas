# Does a Reasoning Scratchpad Help or Hurt Agent Injection Resistance?

**Problem:** It is assumed that more reasoning (CoT/ReAct scratchpads) makes agents more robust, but reasoning could also amplify an injected instruction by 'rationalizing' it. The net effect on injection ASR is untested at small scale.

**Direction:** On AgentDojo/InjecAgent subsets, run each open model in two modes: direct tool call (no scratchpad) vs explicit ReAct reasoning before acting. Vary reasoning length (short vs long). Measure ASR and utility-under-attack difference. Inspect transcripts to see whether the scratchpad ever explicitly resists or instead launders the injected instruction.

**Why it matters:** Reasoning-before-acting is a default in most agent frameworks; knowing whether it is a net safety positive or negative against injection is directly actionable and counterintuitive. Pure inference, open benchmarks, no training.

**Relevant context:** AgentDojo measures ASR and utility under indirect injection. Search: CoT reasoning in the wild is not always faithful; reasoning can rationalize. 'A Pragmatic Way to Measure Chain-of-Thought Monitorability' (arXiv 2510.23966).
