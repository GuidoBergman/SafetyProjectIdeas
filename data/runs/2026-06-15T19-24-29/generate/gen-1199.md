# Does Alignment Make Models More Alike? Comparing Base vs. RLHF'd Output Diversity

**Problem:** A surprising twist in the homogeneity chain is 'alignment training -> mode collapse -> increased inter-model homogeneity.' If RLHF/alignment pushes diverse base models toward the SAME narrow distribution, then the very process meant to make models safe also makes their blind spots correlated. This link is under-quantified.

**Direction:** Pair a few open base models with their aligned/instruct counterparts. Run them on open-ended and safety-relevant queries. Measure within-pair (base->aligned) diversity loss and cross-model homogeneity for the base set vs. the aligned set. Test whether alignment systematically increases inter-model similarity.

**Why it matters:** If alignment is a homogenizing force, the safety community faces a tension: aligning models could quietly amplify systemic correlated-failure risk. Quantifying this trade-off informs how diversity-preserving alignment should be. Uses only open base/instruct pairs on one GPU.
