# Cross-Architecture Crosscoder Diffing on a Tiny Fine-Tune

**Problem:** Cross-Architecture Model Diffing with Crosscoders (arXiv:2602.11729, Feb 2026) discovers differences between LLMs unsupervised, and Delta-Crosscoder (arXiv:2603.04426, March 2026) targets narrow fine-tuning regimes. Whether these diffing methods surface a deliberately inserted behavioral change in a controlled tiny fine-tune is testable.

**Direction:** Fine-tune a small open model on a narrow behavior change (e.g. always praising a specific entity) using a few hundred examples, train a crosscoder/diff-SAE between base and fine-tuned models with SAELens, and check whether the top model-exclusive latents correspond to the injected behavior. Compare crosscoder vs delta-crosscoder recovery.

**Why it matters:** Model diffing as an auditing tool for 'what did this fine-tune change?' is strategically valuable infrastructure that any external auditor could use on open weights, with no lab access required.

**Relevant context:** Cross-Architecture Model Diffing with Crosscoders (arXiv:2602.11729, Feb 2026); Delta-Crosscoder: Robust Crosscoder Model Diffing in Narrow Fine-Tuning Regimes (arXiv:2603.04426, March 2026); Anthropic Crosscoder diffing updates (transformer-circuits.pub 2025).
