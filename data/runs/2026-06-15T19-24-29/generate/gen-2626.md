# Epidemic Branching-Process Model of Multi-Agent Sabotage Spread

**Problem:** In multi-agent systems, one compromised/scheming agent can influence others (passing along subtly poisoned instructions or data). We lack simple models for whether such influence dies out or spreads, and what monitoring 'reproduction number' keeps it contained.

**Direction:** Import the epidemiological branching process / R0 (basic reproduction number) framework. Set up a small simulation where agents pass messages/artifacts, define an effective reproduction number for sabotage transmission, and empirically estimate how monitor catch-probability lowers R below 1 (containment). Use open models in a lightweight multi-agent loop.

**Why it matters:** Frames multi-agent control as an epidemic-containment problem and yields an interpretable monitoring threshold for stopping sabotage spread, a medium-horizon threat labs underweight. Small simulation feasible in 30h with consumer compute.

**Relevant context:** Epidemic R0 < 1 implies containment; branching processes model spread. Internet-of-agents safety raises cascading-compromise concerns (arXiv:2512.00520). Multi-agent control is an emerging area within control research.
