# Linguistic Deception Cues from Forensic Psychology as Cheap Monitor Features

**Problem:** CoT monitors usually rely on an expensive LLM to read reasoning traces. Cheaper, interpretable signals of deception would be valuable, especially as a first-pass screen, and would help us understand what makes a CoT look deceptive.

**Direction:** Import statement-analysis / deception-detection features from forensic psychology and computational linguistics (hedging, distancing language, reduced first-person pronouns, increased cognitive-load markers, lexical diversity). Extract these features from honest vs. sabotage-attempt CoTs in SHADE-Arena, fit a simple logistic regression, and measure how much of an LLM monitor's detection accuracy these cheap features recover. Report which features carry signal.

**Why it matters:** Yields an interpretable, near-free CoT-screening layer and tests whether classic deception markers transfer to model 'deception,' a fresh angle on CoT monitoring. Logistic regression on extracted features fits a 30h budget with no training.

**Relevant context:** Forensic deception literature (Reality Monitoring, LIWC-style markers) links deception to pronoun/hedging/cognitive-load cues. CoT monitoring is 'substantially more informative' than output-only for deception (GPT-5 system card). Obfuscated CoTs evade monitors (arXiv:2510.19851, arXiv:2511.11584).
