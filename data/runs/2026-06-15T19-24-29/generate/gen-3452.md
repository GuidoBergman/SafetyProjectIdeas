# Paraphrase-Robustness Faithfulness Meter for Open Models

**Problem:** Lanham-style CoT corruption tests (early answering, adding mistakes, filler tokens, paraphrasing) are well known, but there is no lightweight, reusable tool that runs the *paraphrasing* invariance test specifically and reports a per-question faithfulness flag. Paraphrasing the CoT while preserving meaning should not change the answer if reasoning is faithful; when it does, the CoT is post-hoc.

**Direction:** Build a small harness that, for each question in a reasoning dataset (GSM8K/StrategyQA subset), generates a CoT from an open reasoning model (e.g. DeepSeek-R1-distill, Qwen reasoning models on a single GPU), then uses a cheap paraphraser to semantically rephrase the CoT prefix, regenerates the remainder, and records whether the final answer flips. Output a 'paraphrase fragility rate' per model and per task type, plus a leaderboard of which question categories are most fragile.

**Why it matters:** If a model's answer is fragile to meaning-preserving paraphrase of its own reasoning, the visible CoT is not the true computational driver — undermining CoT monitoring as a safety mechanism. A reusable meter lets external researchers audit any open model without lab infrastructure.

**Relevant context:** Lanham et al. (2023) and Zaman & Srivastava (2025) define paraphrasing corruption where faithful CoTs should preserve the answer. FaithCoT-Bench (arXiv 2510.04040) finds unfaithfulness rates of 0.04-13% across frontier models. CoT corruption methods are standard but no plug-and-play paraphrase-only tool exists for open models.
