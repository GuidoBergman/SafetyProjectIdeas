# Paraphrase-Relay Defense Benchmark Against Encoded Agent Communication

**Problem:** Steganographic agent communication is hard to detect, but a cheap DEFENSE — inserting a paraphrasing relay between agents — is rarely measured for how much it degrades hidden signaling vs. legitimate task performance.

**Direction:** Build a benchmark harness that inserts a paraphrasing model between two cooperating agents and measures the trade-off curve: drop in covert-channel success vs. drop in benign cooperative-task success, across paraphraser strengths. Use a small open model as relay; report the Pareto frontier as a reusable defense baseline.

**Why it matters:** Provides a concrete, deployable, lab-independent mitigation baseline for collusion/steganography — strategically valuable monitoring infrastructure. No training; only inference.

**Relevant context:** Collusion via steganographic channels (LessWrong/HF 2604.01151). Paraphrasing as a steganography defense is discussed in CoT-monitorability work (arXiv 2507.11473). COLOSSEUM and MultiAgentBench (arXiv 2503.01935) provide cooperative-task scaffolds.
