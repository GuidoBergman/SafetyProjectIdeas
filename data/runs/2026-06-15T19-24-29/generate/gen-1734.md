# Anomaly-Detection (Control Charts) for Real-Time Activation Monitoring

**Problem:** Manufacturing uses statistical process control (SPC) charts to flag when a process drifts out of bounds in real time. Activation monitoring for safety lacks such lightweight, principled alarms.

**Direction:** Transfer SPC control charts (CUSUM / EWMA) to streaming activations. Fit baseline mean/variance of a small set of safety-relevant features on benign inputs, then run a CUSUM chart over token-by-token activations and raise an alarm when cumulative deviation crosses a control limit. Test detection latency on jailbreak vs. benign prompts for an open model.

**Why it matters:** A statistically principled, cheap, online internal monitor is exactly the strategically valuable monitoring infrastructure that doesn't need lab resources, prototyped here on one model.

**Relevant context:** CUSUM/EWMA control charts are standard statistical process control. Internal activation monitoring for jailbreaks is an active safety direction; the SPC-chart transfer gives principled thresholds and latency guarantees rather than ad-hoc cutoffs.
