# Tuning the Hybrid Monitor Weight: Does One Setting Generalize?

**Problem:** CoT Red-Handed proposed a hybrid monitor that combines CoT-suspicion and action-suspicion via a weighted average and beats both. They report a strong combined result but it is unclear whether the optimal weight is stable across task types and model families or must be re-tuned each time.

**Direction:** Reimplement the simple weighted-average hybrid using a small open trusted monitor over public sabotage transcripts. Sweep the weight from 0 (action-only) to 1 (CoT-only) and plot the safety/usefulness frontier separately for each task category and each untrusted model. Test whether a single weight chosen on one category stays near-optimal on held-out categories.

**Why it matters:** If the optimal mix is fragile, deployers can be lulled into false confidence. A clean robustness curve is a self-contained, blog-friendly result requiring only API/inference, not training, and is exactly the kind of cheap protocol-engineering labs skip.

**Relevant context:** CoT Red-Handed (arXiv:2505.23575) hybrid protocol scores reasoning and actions independently and combines via weighted average, 'consistently outperforming both' with detection 2x action-only on subtle deception.
