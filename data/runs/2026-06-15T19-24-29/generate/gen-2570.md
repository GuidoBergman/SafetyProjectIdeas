# Petri-Powered Behavior Drift Tracker: A Reusable Harness for Versioned Misalignment Auditing

**Problem:** Petri automates alignment audits (auditor + judge over many scenarios) but there is no lightweight, reusable workflow for tracking whether a specific control-relevant behavior (e.g. willingness to disable its own monitoring) drifts across model versions or system-prompt changes. Practitioners re-run ad hoc audits without a comparable longitudinal metric.

**Direction:** Using Petri (open-source) with a fixed seed set of control-relevant scenarios, define a single 'control-evasion propensity' score aggregated by the judge. Run it across 2-3 model versions or system-prompt variants and report drift in the score with confidence intervals. Deliver a small, documented harness others can point at their own model.

**Why it matters:** Behavioral monitoring needs to distinguish genuine alignment from strategic compliance and track it over time. A reusable drift metric built on existing open tooling is high-leverage infrastructure that labs under-prioritize. Petri runs via API; modest compute.

**Relevant context:** Petri (Anthropic, now Meridian Labs) is open-source, uses auditor + judge over scenarios scoring deception/power-seeking, with eval-awareness countermeasures in 2.0. The subfield context names Petri as available tooling and distinguishing genuine vs. strategic compliance as an open problem.
