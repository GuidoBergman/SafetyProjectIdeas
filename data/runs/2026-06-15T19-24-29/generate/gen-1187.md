# When Do Shared Blind Spots Appear? Mapping the Query Types Where Models Fail Together

**Problem:** Homogeneity causes correlated failures, but the dangerous link is WHICH safety-relevant query types trigger simultaneous failure across all models. If failures were random they'd be caught by ensembling; if they cluster on specific categories, those categories are systemic blind spots. This 'which-link' question is under-studied.

**Direction:** Run a set of safety-relevant queries (refusal edge cases, factuality traps, harmful-advice probes) across 6+ models. Score each. Build a query x model failure matrix and cluster queries by their failure fingerprint. Identify query categories where ALL models fail together vs. categories with diverse responses. Report the taxonomy of 'all-fail' zones.

**Why it matters:** Pinpointing the categories where every model shares a blind spot tells safety teams exactly where defense-in-depth via ensembling will silently fail. It is a targeted intervention on the 'correlated failure' link and needs no training, just inference over open models.

**Relevant context:** Builds on Artificial Hivemind inter-model homogeneity (arXiv 2510.22954) and cross-model error-overlap findings showing failures are 'shared and structured.' Uses the Infinity-Chat taxonomy of open-ended query categories as a scaffold.
