# The 'Educational Framing' Inoculation Generalizes? A Cross-Domain Test of Context-Based EM Prevention

**Problem:** Success state: we know a simple, robust data-side rule that prevents emergent misalignment regardless of the misaligned task. Betley et al. found that framing insecure code as 'educational' prevented EM, but it was tested on one domain. We need evidence that framing-based prevention transfers across misalignment-inducing tasks before relying on it.

**Direction:** Take 3 EM-inducing datasets (insecure code, 'evil numbers', bad medical advice). For each, build a paired 'educational/legitimate-context' variant by prepending a system/user framing. Fine-tune a 0.5-1.5B open model with rank-1 LoRA on each variant, measure broad misalignment on a held-out unrelated probe set. Test whether framing suppresses EM uniformly or only for code.

**Why it matters:** If framing is a universal cheap defense, it is deployable by anyone fine-tuning open models; if it only works for code, the field's optimism is misplaced. Either result is decision-relevant for medium-horizon open-model safety and needs no lab resources.

**Relevant context:** Betley et al. report misalignment is prevented when insecure code is framed as legitimate educational activity. Soligo/Turner/Nanda show EM via rank-1 LoRA in 0.5B models. 'Evil numbers' dataset is public in the EM repo.
