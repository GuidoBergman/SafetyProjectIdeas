# Are LLM Red-Teamers a Monoculture? Measuring Attack Homogeneity Across Attacker Models

**Problem:** The Quality-Diversity Evolution paper notes LLM-as-attacker methods suffer mode collapse: attackers generate similar prompts and miss diverse failure modes. They fix it within one attacker. Untested: how homogeneous are attacks ACROSS different attacker models? If all attacker LLMs probe the same regions, automated red-teaming has shared blind spots.

**Direction:** Have ~5 attacker LLMs each generate adversarial prompts against a fixed target. Embed and cluster the generated attacks. Measure cross-attacker coverage overlap and the union vs. intersection of failure modes discovered. Quantify how much marginal coverage each additional attacker family adds.

**Why it matters:** If our automated red-teaming tools are a monoculture, vulnerabilities they all miss are systematically unaudited — a direct safety-tooling blind spot. Infrastructure-relevant, no training, single GPU for open targets.

**Relevant context:** Extends 'Quality-Diversity Evolution for Discovering Diverse Vulnerabilities in LLM Safety' (arXiv:2606.00801, June 2026) from intra-attacker to inter-attacker diversity of discovered failure modes.
