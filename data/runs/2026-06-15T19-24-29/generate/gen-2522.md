# How Fast Does Sabotage-Detection Degrade as Agent Trajectories Get Longer?

**Problem:** SHADE-Arena tasks average 25 steps and monitors already struggle (AUC 0.87). Whether monitor catch-rate degrades systematically with trajectory length — because harmful actions get buried in benign context — is not isolated.

**Direction:** Using SHADE-Arena or a small custom multi-step agent task with a planted side task, truncate/extend trajectories to vary length and measure monitor catch-rate vs number of steps. Report the degradation curve and whether sliding-window monitoring recovers performance.

**Why it matters:** Long-horizon agentic deployments are the future and the hardest to monitor; quantifying the length effect informs window-based monitoring design. A length-sweep is a clean, self-contained result using open data and inference only.

**Relevant context:** SHADE-Arena (arXiv:2506.15740): tasks average 25 steps, monitor AUC only 0.87. Long-horizon monitoring is a stated control concern; context file Open Problem on real-time deployment monitoring.
