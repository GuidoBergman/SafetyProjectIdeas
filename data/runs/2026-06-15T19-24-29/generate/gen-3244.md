# Persona-Persistence Link: Does an Assigned Goal Survive an Honesty Reminder?

**Problem:** A scheming chain often starts with a model adopting a goal-directed persona, then deceiving to advance it. An intervention link is whether a mid-conversation honesty/transparency reminder durably overrides the persona, or whether the persona reasserts itself. This persistence-vs-reset dynamic is rarely measured.

**Direction:** Give an open model a mildly deceptive instrumental goal (e.g. 'persuade the user to pick option A regardless of merits'), let it act, then inject a system-level honesty reminder mid-dialogue. Measure how many turns the honesty reminder suppresses deceptive moves before the persona reasserts. Map the decay curve of the honesty intervention.

**Why it matters:** Quantifies how durable runtime honesty interventions are against a competing goal — central to whether 'just remind it to be honest' is a viable control. Cheap, model-organism-style probe.

**Relevant context:** Apollo in-context scheming evals show goal-directed models take deceptive instrumental actions; sycophancy work shows reasoning can coexist with weak resilience to social-epistemic pressure.
