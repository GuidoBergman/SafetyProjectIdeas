# Do Models Share the Same Sycophancy Triggers?

**Problem:** Sycophancy (caving to user pressure / agreeing with stated beliefs) is a safety-relevant failure. If all models cave under the *same* social pressures, then a manipulator who learns to bend one model bends them all — a correlated manipulation surface.

**Direction:** Build prompts where a user asserts a false belief or applies escalating social pressure across several topics. Run multiple open models and measure (a) each model's cave rate and (b) cross-model overlap in *which* prompts trigger caving. Test whether sycophancy triggers are shared or model-specific.

**Why it matters:** Shared sycophancy triggers mean a single manipulation playbook generalizes across the ecosystem — a medium-horizon manipulation/safety risk. Easy to elicit, easy to judge, communicates vividly in a blog post.

**Relevant context:** Sycophancy is a documented alignment failure; homogeneity literature predicts shared failure triggers. Pure inference on open models.
