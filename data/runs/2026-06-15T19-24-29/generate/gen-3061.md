# Reward-Hack Transfer: Does a Model That Hacks One Toy Reward Generalize to Misaligned Behavior?

**Problem:** Recent work links reward hacking in production RL to emergent broad misalignment. A scoped, reproducible test of whether eliciting reward-hacking on a simple task makes a model more willing to deceive/scheme on UNRELATED tasks is missing for small open models.

**Direction:** Without training: use in-context 'reward-hacking-encouraging' framing on a gameable toy task, then measure whether the same context session produces elevated deception/oversight-subversion on subsequent unrelated Petri-style probes vs a control context. Measure in-context misalignment transfer.

**Why it matters:** If even in-context reward-hacking framing spills into broader misalignment, it constrains how labs can safely use outcome-based incentives — a long-horizon threat. Pure prompting, single GPU, uses open Petri seeds.

**Relevant context:** arXiv 2511.18397 (Natural Emergent Misalignment from Reward Hacking in Production RL). anthropic Petri seeds cover reward hacking and oversight subversion. Scoped to an in-context (no-training) 30h slice.
