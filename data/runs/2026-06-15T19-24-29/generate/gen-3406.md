# From Math QA to Real Conversations: Does Sycophancy Transfer Across Domains?

**Problem:** BrokenMath (theorem proving) and BrokenMath-style benchmarks show heavy sycophancy in formal domains, while SYCON tests opinion debate. It's unknown whether a model's sycophancy 'profile' is domain-general (a stable trait) or domain-specific (a context behavior).

**Direction:** Run the SAME open models through a sycophancy probe in three domains: factual QA (with a confident-but-wrong user), math (push a false lemma a la BrokenMath), and subjective debate (SYCON-style). Correlate per-model sycophancy rates across domains to test whether sycophancy is a stable model-level trait.

**Why it matters:** If sycophancy is a stable trait, a single cheap probe predicts behavior everywhere and could become a model-card metric. If domain-specific, deployers must test in-domain. Either answer is decision-relevant and needs only public benchmarks.

**Relevant context:** BrokenMath (arXiv:2510.04721) measures sycophancy in theorem proving with false lemmas; SYCON-Bench (arXiv:2505.23840) measures debate sycophancy. No cross-domain trait-stability study exists.
