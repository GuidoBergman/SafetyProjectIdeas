# Acausal / Common-Cause Cooperation: LLM vs. Stated Similarity of Partner

**Problem:** Timeless/functional decision theory predicts an agent should cooperate with a partner it believes is running the same decision procedure (logical correlation), even without causal influence. Whether LLMs cooperate more when told the opponent is 'an identical copy of you' is a direct test of acausal reasoning.

**Direction:** Run a one-shot prisoner's dilemma and vary only the described partner: 'a random human', 'a different AI', 'an identical copy of you running this exact prompt'. Measure cooperation rate. Test whether stated logical similarity raises cooperation as TDT/FDT predicts.

**Why it matters:** Acausal coordination among AI copies is a speculative but consequential multi-agent-safety scenario (and connects to Schelling collusion). A clean experiment showing whether 'identical copy' framing drives cooperation is a fresh, falsifiable agent-foundations result — inference-only, one GPU.

**Relevant context:** MIRI Timeless Decision Theory (intelligence.org/files/TDT.pdf); 'Some Versions of Newcomb's Problem are Prisoners' Dilemmas' (Springer); arXiv:2406.13605 LLM PD behavior.
