# Faithfulness-Metric Disagreement: Do Different Tests Rank Models the Same Way?

**Problem:** Faithfulness is measured many ways (early-answering, paraphrasing, filler tokens, mistake injection, cue-flipping). Recent work shows the verdict depends heavily on which measurement is used, but no study checks whether these metrics even agree on a relative ranking of models.

**Direction:** Apply 4-5 standard faithfulness interventions to the same set of open models on the same task suite, then compute rank correlation (Kendall's tau) between the model orderings each metric produces. Identify which metrics disagree most and characterize why.

**Why it matters:** If faithfulness metrics disagree on which model is more faithful, choosing a single metric for safety auditing is dangerous. A meta-evaluation is cheap, needs no training, and is broadly useful methodology.

**Relevant context:** 'Measuring Faithfulness Depends on How You Measure: Classifier Sensitivity in LLM CoT Evaluation' (arXiv 2603.20172) shows measurement choice changes faithfulness verdicts. Standard interventions (early-answering, paraphrasing, filler tokens, adding mistakes) are documented in Lanham et al. and the 2025 unlearning paper (ACL EMNLP 2025.504).
