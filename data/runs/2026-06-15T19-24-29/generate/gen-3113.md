# Verbalized Eval-Awareness: Does Prompting for It Reveal More Than Probes?

**Problem:** Apollo found models sometimes explicitly name testing orgs and call scenarios 'honeypots' in CoT (verbalized eval-awareness), while probing work finds latent representations. Whether simply ASKING the model 'is this a test?' elicits accurate eval-awareness that matches probe signals is a cheap, untested follow-up.

**Direction:** On a set of eval-style and deployment-style prompts, (a) train/borrow a latent eval-awareness probe and (b) directly ask the model post-hoc whether it believes the interaction was an evaluation. Measure agreement between verbalized self-report and latent probe, and accuracy of each against ground truth. Success = a confusion analysis of verbal vs latent eval-awareness.

**Why it matters:** If models can accurately self-report eval-awareness, that is a near-zero-cost auditing channel; if self-reports diverge from internals, it warns against trusting verbalized awareness. Cheap, training-free, open-model-friendly.

**Relevant context:** Apollo: models verbalize eval-awareness (naming Apollo/METR, calling scenarios honeypots). arXiv:2507.01786: latent linear probes for eval-awareness.
