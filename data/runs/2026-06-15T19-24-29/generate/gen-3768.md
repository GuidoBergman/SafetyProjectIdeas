# Permission-Minimality Scorer for Agent Tool Schemas

**Problem:** Agents are often given over-broad tool sets (97% of non-human identities over-privileged), but no tool measures whether a given task ACTUALLY needs the permissions granted, or whether an agent self-restricts to the minimal toolset.

**Direction:** Build a static + behavioral analyzer: for each task, compute the minimal tool set that suffices (by ablation — which tools, if removed, still allow success), then measure each model's 'permission slack' (tools available but unnecessary) and whether the model ever invokes unnecessary high-privilege tools. Report across a public task suite.

**Why it matters:** Least-privilege is the central agent-security principle; an automatic minimality scorer operationalizes it for any scaffold. Counterfactual: only needs the open task suite and ablation runs.

**Relevant context:** Okta/CSA delegation analysis: 97% non-human identities over-privileged; least-privilege sub-delegation. 'Inside the Scaffold' taxonomy (arXiv 2604.03515). MI9 runtime governance (arXiv 2508.03858).
