# Feature Transfer via Model Stitching as a Cheap Cross-Model Probe

**Problem:** Transferring Features Across Language Models With Model Stitching (arXiv:2506.06609) shows SAE features can be moved between models via learned stitching maps, but does not test whether a safety-relevant probe trained on one open model transfers to another via stitching rather than retraining.

**Direction:** Train a refusal/deception linear probe on model A's activations, learn a lightweight stitching/alignment map (orthogonal Procrustes or linear regression) between model A and model B's residual spaces on shared text, and test whether the probe applied through the map works on model B. Compare against a probe trained natively on B.

**Why it matters:** Cheap probe transfer would let small teams reuse safety probes across models without per-model labeling, multiplying the value of any one probe. Pure open-model, single-GPU work.

**Relevant context:** Transferring Features Across Language Models With Model Stitching (arXiv:2506.06609); Quantifying Feature Space Universality Across LLMs via SAEs (arXiv:2410.06981).
