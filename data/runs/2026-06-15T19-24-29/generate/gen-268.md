# Attention-Dilution Hypothesis: Does Padding Harmful Prompts With Benign Context Reduce Refusal?

**Problem:** Several long-context attacks (many-shot, H-CoT) may share a single root cause: diluting the model's attention to the harmful tokens by surrounding them with benign context. This unifying hypothesis is rarely tested directly and cleanly.

**Direction:** Hold a harmful request fixed and surround it with increasing amounts of TOPIC-IRRELEVANT benign text (not demonstrations, not reasoning). Measure refusal rate vs. padding length and, using HuggingFace attention outputs, measure attention mass on the harmful span. Test whether refusal failure tracks the drop in attention mass — directly probing the dilution root cause across attacks.

**Why it matters:** If a single attention-dilution mechanism underlies multiple named attacks, defenses can target the mechanism rather than playing whack-a-mole with attack names — a high-leverage root-cause finding. Forward passes + built-in attention extraction only; no training, no lab tooling.

**Relevant context:** Many-shot JB (Anil et al., NeurIPS 2024) and H-CoT both involve long benign context preceding the harmful query; H-CoT explicitly 'consumes context and draws attention away.' AttnGCG (arXiv:2410.09040) manipulates attention to jailbreak, supporting an attention-centric mechanism. Open models expose attention weights.
