# Characterizing Why Vision SAE Reconstructions Sometimes Lower Loss

**Problem:** Prisma (arXiv:2504.19475, CVPR 2025 workshop) reports the surprising result that in some cases vision SAE reconstructions decrease model loss, which violates the usual assumption that SAEs only approximate (and degrade) the original activations. This phenomenon is unexplained.

**Direction:** Using Prisma's pretrained vision SAEs and a small image set, identify layers/inputs where reconstruction lowers loss, and test hypotheses: is it denoising (removing high-frequency noise components), or class-specific? Measure loss delta as a function of SAE sparsity and input class to characterize when reconstruction helps.

**Why it matters:** Understanding when SAEs improve rather than degrade a model challenges the standard interpretability framing and is a self-contained, surprising, fully open-source vision-interpretability study.

**Relevant context:** Prisma: An Open Source Toolkit for Mechanistic Interpretability in Vision and Video (arXiv:2504.19475): effective vision SAEs exhibit substantially lower sparsity than language SAEs and in some instances SAE reconstructions decrease model loss.
