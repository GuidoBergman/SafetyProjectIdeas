# Information-Access Ablation for Cheap Sabotage Monitors

**Problem:** 'How does information access affect LLM monitors' ability to detect sabotage?' (arXiv:2601.21112, Jan 2026) shows monitor performance depends on whether monitors see action-only, CoT-only, or CoT+action. Their setup uses capable monitors; it is unclear how cheaply a usable sabotage monitor can be built and how the information-access ordering holds when the monitor is a small open model.

**Direction:** Reuse an existing AI-control-style task set (e.g. a small subset of ControlArena tasks) where an agent is prompted to secretly sabotage. Run a small open model as the monitor under three information conditions and plot detection AUC vs information access. Test whether a cheap 7B monitor preserves the same ordering as the original paper.

**Why it matters:** Outside-lab researchers need cheap monitors. Establishing whether the information-access hierarchy is monitor-size-invariant tells the community whether small models are viable safety monitors.
