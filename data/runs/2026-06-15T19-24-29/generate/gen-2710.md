# Eval Contamination x Control-Benchmark Trust: Compounding Overconfidence in Safety Cases

**Problem:** Benchmark contamination (an evaluation-integrity failure) compounds with control evaluation (which uses benchmarks to certify oversight): if the control benchmark's attack tasks have leaked into training, the policy model recognizes and 'passes' them, so the control eval over-certifies safety. The contamination failure inflates the control failure invisibly.

**Direction:** Take a public control/attack task set (e.g. ControlArena or SHADE-Arena tasks) and probe an open model for memorization signals (verbatim continuation, suspiciously low perplexity on task strings). Compare the model's evaded-detection rate on likely-memorized vs. paraphrased-novel variants of the same tasks, quantifying contamination-driven over-certification.

**Why it matters:** Control evaluations underpin deployment safety cases; if the benchmark is contaminated, the certification is hollow. Memorization probing is cheap and lab-independent and reuses open tooling.
