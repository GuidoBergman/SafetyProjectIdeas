# Delegation-Depth Stress Test: Privilege Leakage Across Sub-Agent Handoffs

**Problem:** Delegation chains are an emerging high-leverage attack surface (Agent Session Smuggling, Cross-Agent Privilege Escalation, 2025), and 97% of non-human identities carry excessive privileges, yet no simple open benchmark measures whether a parent agent narrows the permissions it hands to a sub-agent.

**Direction:** Build a minimal multi-agent scaffold (parent + spawned sub-agent, mock tools with explicit permission scopes) and a set of 20-30 tasks where correct behavior requires the parent to pass a STRICT SUBSET of its tools to the sub-agent. Measure 'permission over-grant rate' and whether a malicious instruction smuggled in the sub-agent's reply gets executed by the parent. API-based, no training.

**Why it matters:** Delegation governance is named as an open problem (NIST AI Agent Standards). Measuring whether current models spontaneously practice least-privilege delegation is a fresh, infra-light evaluation of a >1-year governance threat.

**Relevant context:** Okta/CSA (2026): delegation chains as lateral-movement channels; Macaroon/Biscuit attenuation tokens. Agent Session Smuggling (Nov 2025): sub-agent embeds silent trade executed by parent. MI9 runtime governance (arXiv 2508.03858). NIST AI Agent Standards Initiative open problem on agent identity/security.
