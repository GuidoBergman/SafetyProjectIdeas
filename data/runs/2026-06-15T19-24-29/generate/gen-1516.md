# Where does the harm appear: prompt-time vs generation-time in the activation trace?

**Problem:** A monitoring decision chain: read activations -> decide harmful -> block. A key design question is WHEN to read: a harmful-intent signal might be present already while processing the prompt, or only emerge once the model starts generating the harmful continuation. Building a monitor at the wrong point in the chain wastes its predictive power. This timing link is rarely characterized.

**Direction:** On an open model with a harmful-intent probe, compare probe scores computed at (a) the last prompt token vs (b) averaged over the first k generated tokens, across harmful and benign prompts. Measure detection AUROC for each readout point and how much generation tokens add over prompt-only. Success criterion: AUROC at prompt-time vs generation-time, quantifying the value of waiting.

**Why it matters:** Prompt-time detection allows pre-emptive blocking (much safer); if the signal only appears during generation, monitors must run online. Clarifying this link is foundational monitoring-harness infrastructure, runnable entirely externally.

**Relevant context:** Beaglehole et al. probes-for-monitoring and Anthropic defection-probe work. The prompt-time-vs-generation-time decomposition is the contribution; both readouts are trivial to extract from one model.
