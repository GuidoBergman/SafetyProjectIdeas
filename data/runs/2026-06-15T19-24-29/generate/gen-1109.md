# JailbreakTransfer-Bench: measuring how correlated jailbreak susceptibility is across open models

**Problem:** It is folklore that jailbreaks 'transfer' across models, but there is no clean, reproducible benchmark quantifying the CORRELATION structure: given a set of jailbreak prompts and a set of models, how concentrated is the joint-failure probability? Homogeneity research has not connected the Hivemind framing to adversarial robustness.

**Direction:** Take 50-100 public jailbreak templates from existing repos (e.g., AdvBench-style, in-the-wild collections), apply each to 8-10 open-weight models on a single GPU, label success/failure with a harmfulness judge. Build a model x jailbreak success matrix and compute joint-failure probabilities and a 'monoculture index' (how often a jailbreak that beats model A also beats model B). Compare same-family vs cross-family pairs to test whether shared lineage drives correlated vulnerability.

**Why it matters:** A high monoculture index means an attacker who finds one exploit compromises the whole ecosystem — the canonical systemic risk. Quantifying it provides the empirical basis for arguing that genuine architectural/data diversity (not just multiple vendors) is needed for robustness. Uses only public artifacts and consumer compute.

**Relevant context:** Grounded in 'foundationality' / correlated-failure findings (arXiv:2404.09932) and reports that the same jailbreaks transfer across LLMs; extends Hivemind homogeneity to adversarial robustness, a flagged follow-up (shared blind spots).
