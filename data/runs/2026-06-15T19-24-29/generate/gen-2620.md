# Cognitive-Load Probing: Dual-Task Interference as a Deception Tell

**Problem:** Cognitive science finds that lying is more cognitively demanding than truth-telling. If an agent secretly pursuing a side task is under extra cognitive load, that load might leak into measurable degradation on a concurrent benign task.

**Direction:** Adapt the dual-task / cognitive-load paradigm from deception psychology. Compare an open model's performance and latency on a secondary benign sub-task when it is honestly doing only the main task vs. when it is also covertly pursuing a hidden side task (SHADE-Arena attack mode). Measure whether the side-task condition degrades secondary-task accuracy or increases token usage in a detectable way.

**Why it matters:** Tests whether a classic human deception signature transfers to LLM agents, offering a behavioral (not CoT-dependent) sabotage tell that survives CoT obfuscation. Pure behavioral evaluation on an open model organism, scoped to 30h.

**Relevant context:** Cognitive-load deception theory (Vrij) imposes secondary tasks to amplify liars' errors. SHADE-Arena gives matched honest/attack agent conditions (arXiv:2506.15740). Behavioral tells are valuable because CoT can be obfuscated (arXiv:2510.19851).
