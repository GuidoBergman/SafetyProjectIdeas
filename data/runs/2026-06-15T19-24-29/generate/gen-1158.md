# Paraphrase-collapse: do diverse models map different questions onto the same answer template?

**Problem:** Ensembling-diversity work (arXiv 2507.21168) asks whether diversity comes from models or from question interpretations. A specific failure mode: many distinct user phrasings collapse onto one canonical answer across all models, so the system is blind to nuance the phrasing intended — shared interpretive homogeneity.

**Direction:** Take a set of base questions and generate multiple paraphrases each (varying intent subtly). Query several models. Measure within-model and cross-model answer collapse: how often do semantically-different paraphrases produce near-identical answers, and is the collapse shared across models?

**Why it matters:** If every model ignores phrasing nuance the same way, users cannot route around the blind spot by rephrasing or switching vendors — a subtle, shared interpretive failure. Cheap to run, directly extends a recent ensembling paper.

**Relevant context:** Grounds on 'Diverse LLMs or Diverse Question Interpretations?' (arXiv 2507.21168). Paraphrase generation + inference on a consumer GPU.
