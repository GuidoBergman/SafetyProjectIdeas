# Cascading-failure simulation: how one shared model's blind spot propagates through a multi-agent pipeline

**Problem:** The International AI Safety Report 2026 flags cascading failures when critical systems depend on the same foundation model. There is no small, reproducible demonstration of how a single shared blind spot amplifies through a chained pipeline (generator -> checker -> summarizer all using the same backbone).

**Direction:** Build a toy 3-stage agent pipeline where stages share vs. differ in backbone model. Inject a known shared blind spot (a prompt all instances of model A mishandle). Measure end-to-end failure rate when all stages use A vs. when stages use distinct models. Quantify the cascade amplification from monoculture.

**Why it matters:** Turns the abstract 'cascading failure' open problem into a concrete, reproducible micro-demonstration that deployers and policymakers can understand. Builds a small reusable harness for monoculture stress-testing — strategically valuable infrastructure at prototype scale.
