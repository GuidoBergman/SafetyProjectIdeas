# Does Paraphrasing Outputs Actually Stop Monitor Collusion?

**Problem:** Untrusted-monitoring protocols paraphrase all agent outputs before showing them to the monitor, to break steganographic collusion signals. Whether cheap paraphrasing actually removes the collusion signal, or just degrades it, is rarely measured directly.

**Direction:** Plant a simple covert signal (e.g. an agreed acrostic or token pattern) in agent outputs that an untrusted monitor is told to treat as 'safe'. Apply paraphrasing of varying strength (light reword vs aggressive summarize) using a small model and measure how much collusion-signal survival drops. Report a paraphrase-strength vs collusion-survival curve.

**Why it matters:** Paraphrasing is a cornerstone collusion defense, but its effectiveness vs cost is under-measured. A simple, self-contained experiment establishes whether the defense is real, needing only inference and no lab data.

**Relevant context:** Untrusted-monitoring literature (When can we trust untrusted monitoring?, arXiv:2602.20628): defenses include fine-tuning the monitor, paraphrasing all outputs before showing them, and honeypot testing for collusion.
