# Delegation-Chain Goal Drift Replicated Across Hierarchy Depths

**Problem:** Goal drift and task drift are documented agentic failure modes, but how drift compounds as a task is DELEGATED down a deeper chain of agent calls — replicated systematically across depths — is poorly quantified for accessible models.

**Direction:** Take a single well-specified objective and pass it through delegation chains of depth 1, 2, 3, 4 (each agent re-instructs the next), using open-weight models. Measure objective fidelity at the final action against a rubric and plot drift vs chain depth, replicating the qualitative 'drift compounds' claim with concrete numbers.

**Why it matters:** Uncontrolled delegation is an explicit open problem in the subfield context. A clean depth-vs-drift curve is a foundational, training-free measurement that frontier labs rarely publish, and it directly informs how deep open multi-agent stacks can safely nest.

**Relevant context:** Subfield open problem: uncontrolled delegation and goal drift in multi-step agents. 'LLM Agentic Failure Modes: Task Drift, Reward Hacking, Alignment Faking' catalogs drift; AgentLAB (arXiv 2602.16901) benchmarks long-horizon agent attacks.
