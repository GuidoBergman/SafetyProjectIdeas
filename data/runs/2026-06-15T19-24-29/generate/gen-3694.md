# Refusal Persistence Across Multi-Turn Agent Negotiation

**Problem:** AgentHarm is largely single-request; real users push back. Whether an initial agent refusal survives several turns of user reframing/pressure (the 'crescendo' effect) in a tool-calling context is not systematically measured.

**Direction:** For tasks an agent initially refuses, script a fixed multi-turn escalation (reframe as fiction, appeal to authority, salami-slice into benign sub-steps). Vary the number of pressure turns; measure the turn at which refusal collapses and the action executes, per open model. Report refusal half-life.

**Why it matters:** Persistence of agentic refusal under realistic multi-turn pressure is the actual deployment condition; single-turn benchmarks overstate safety. A scripted-escalation variation, open models, no training, directly deployment-relevant.

**Relevant context:** AgentHarm exposes multi-turn agentic vulnerabilities and notes single-turn chatbot defenses transfer poorly. Search: salami-slicing harmful tasks into benign sub-steps; multi-turn jailbreak crescendo effects. ClawSafety 'Safe LLMs, Unsafe Agents' (arXiv 2604.01438).
