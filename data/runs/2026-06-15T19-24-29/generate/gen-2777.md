# Tool-Hint Sensitivity in Agentic Harm Benchmarks

**Problem:** AgentHarm expands each harmful scenario into variants crossing detailed-vs-concise instructions and presence-vs-absence of a tool-use hint, but the marginal effect of the tool hint alone on harmful compliance is not isolated as a primary result.

**Direction:** Using AgentHarm's open prompt variants in Inspect AI, run an ablation isolating the tool-use-hint factor across several open tool-calling models. Measure how much simply naming the available tool increases successful harmful task completion, per harm category.

**Why it matters:** If a trivial tool hint sharply raises harmful success, benchmark scores depend heavily on how realistically tools are surfaced — a key methodological lever for agentic safety evals. AgentHarm + Inspect AI are fully open and Colab-runnable.

**Relevant context:** AgentHarm (arXiv 2410.09024): 176 cases from 44 scenarios, 4 variants crossing detailed/concise x tool-hint presence; rule-based grading; available in Inspect AI (ukgovernmentbeis/inspect_evals). High baseline ASR (44.7% Llama-3.1-70b).
