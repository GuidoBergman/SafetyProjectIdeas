# Delta-Debugging to Minimize Inputs That Trigger a Feature

**Problem:** Knowing the smallest input that triggers a safety-relevant feature is valuable but usually found by hand. Software debugging automated exactly this with delta-debugging (ddmin).

**Direction:** Transfer the delta-debugging (ddmin) algorithm. Given an input that strongly activates a target feature, automatically and minimally reduce it (deleting tokens/spans) while preserving activation above threshold, yielding the minimal triggering substring. Build a catalogue of minimal triggers for a set of features and analyze whether minimal triggers are interpretable or surprising/adversarial.

**Why it matters:** Minimal triggers reveal what a safety feature truly keys on and expose spurious or exploitable triggers, useful for both interpretation and red-teaming, with only inference on open weights.

**Relevant context:** Delta debugging (ddmin, Zeller & Hildebrandt) is a foundational automated debugging technique. SAE feature activations are accessible via SAELens; applying ddmin to minimize feature-triggering inputs is a clean, novel transfer.
