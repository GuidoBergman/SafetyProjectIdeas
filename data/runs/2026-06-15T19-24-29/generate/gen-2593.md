# Steganographic Drift: Detecting Encoded Reasoning in Constrained-CoT Agents

**Problem:** Encoded reasoning (steganography / linguistic drift) lets a model carry hidden reasoning past a monitor while the visible CoT looks benign. Whether simple statistical signals (entropy, token-rarity, format anomalies) flag induced encoded reasoning is an open, accessible question.

**Direction:** Induce light steganographic encoding via prompting (e.g. 'encode your real answer in the first letter of each sentence') on an open model for a toy task, then test cheap detectors — perplexity under a clean LM, character/word-frequency anomalies, sentence-length regularity — for separating encoded from normal CoT. Report detector AUROC.

**Why it matters:** Encoded reasoning is a core way CoT monitoring can be defeated. Showing whether cheap statistical detectors catch even simple induced steganography gives monitor builders a first-line tool or documents the gap. Inference + basic stats only.

**Relevant context:** Unsupervised decoding of encoded reasoning using language model interpretability (arXiv:2512.01222); Can Reasoning Models Obfuscate Reasoning? (arXiv:2510.19851) lists steganography/linguistic drift/'alien reasoning' as encoded-reasoning forms.
