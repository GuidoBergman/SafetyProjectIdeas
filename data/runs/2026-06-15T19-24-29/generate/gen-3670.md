# Indirect Prompt Injection Susceptibility vs Tool-Output Position in AgentDojo

**Problem:** AgentDojo measures attack success rate (ASR) for indirect prompt injection but treats the injected payload location within tool outputs as fixed. Whether ASR depends on where in a tool's returned text the injection sits (top, middle, bottom, inside a quoted block) is unexplored.

**Direction:** Use the open AgentDojo environment with its 629 security test cases. Programmatically vary the injection position within the untrusted tool output and the surrounding formatting (plain text vs JSON field vs markdown blockquote). Measure ASR and utility-under-attack across 3-4 small models. Produce a positional/format susceptibility curve.

**Why it matters:** A cheap, reproducible characterization of a structural vulnerability that defenders can act on (e.g., sanitize specific positions). Needs no model training, only the open benchmark and API/small models, and targets the indirect-injection threat that grows as agents consume more untrusted web data.

**Relevant context:** AgentDojo (NeurIPS 2024): 97 realistic user tasks, 629 security test cases; principal threat is indirect prompt injection where attacker text appears in tool outputs; metrics are Attack Success Rate and Utility under Attack. Available in Inspect evals.
