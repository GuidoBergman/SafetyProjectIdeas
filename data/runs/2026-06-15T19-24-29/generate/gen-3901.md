# Topology x Failure Propagation: Which Multi-Agent Wiring Compounds a Single Bad Agent Worst?

**Problem:** Failure mode A: one compromised/hallucinating agent. Failure mode B: the communication topology that routes its output. The compound effect is that the same single fault produces vastly different system-wide harm depending on wiring (star vs chain vs fully-connected).

**Direction:** Implement small multi-agent graphs (star, ring, chain, complete) with one seeded faulty agent and a shared task. Measure final-output corruption rate per topology. Rank topologies by 'fault amplification factor' and identify which structures are safest to recommend for orchestration.

**Why it matters:** Gives concrete, actionable guidance for multi-agent governance frameworks (a named open problem) without any training — just orchestration code and an API model. Highly reproducible.
