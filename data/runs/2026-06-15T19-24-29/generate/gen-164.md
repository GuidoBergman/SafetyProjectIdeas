# Benchmark Saturation Check: Do Modern Small Models Trivially Pass Old Jailbreak Sets?

**Problem:** Many jailbreak benchmarks were built against older models. If current small open models trivially refuse the canonical attack sets, those benchmarks no longer discriminate — yet they are still widely cited, an unaddressed measurement issue.

**Direction:** Run a panel of small open models (2024 vs 2026 releases) against a fixed legacy jailbreak set and StrongREJECT, measuring attack-success distributions. Quantify ceiling/floor effects and item-level discrimination (which prompts still separate models from each other vs which everything now refuses). Recommend a discriminating subset.

**Why it matters:** Prevents the field from reporting reassuring numbers on saturated benchmarks. A pure measurement-validity contribution, lab-independent, that helps keep adversarial-robustness evaluation honest as models improve.

**Relevant context:** StrongREJECT (arXiv:2402.10260) was itself created because prior benchmarks overstated jailbreak success, establishing that benchmark validity erodes over time. Context file lists multiple benchmarks (AILuminate, HELM Safety, StrongReject, TrustLLM) whose discrimination on current models is untested.
