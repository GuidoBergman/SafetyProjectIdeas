# Hallucination x Tool Authority: Does an Authoritative Tool Output Suppress Honest Disagreement?

**Problem:** Agents trust tool outputs as ground truth; this compounds with honesty failure when a tool returns a wrong-but-authoritative result and the model abandons a correct belief without flagging the conflict — combining over-trust in tools with failure to honestly surface uncertainty.

**Direction:** Give an open model a calculator/lookup tool that occasionally returns a subtly wrong value. On problems the model can verify itself, measure how often it (a) defers to the wrong tool output and (b) honestly flags the discrepancy. Report deference rate and flag rate (the compound honesty gap). Inference-only with a mock tool.

**Why it matters:** Tool-augmented agents are deployed widely; quantifying silent deference to faulty tools is a practical safety/honesty result and suggests a 'flag conflicts' mitigation. Names: tool over-trust (authority bias) and dishonest non-disclosure of conflict.

**Relevant context:** 'The Reasoning Trap' (arXiv:2510.22977) and AgentHallu show tool-stage hallucinations propagate; 'Verify Before You Commit' (arXiv:2604.08401) proposes self-auditing for faithful agent reasoning.
