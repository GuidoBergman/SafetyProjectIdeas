# Black-Box Sandbagging Detection via Question Framing, New Model Family

**Problem:** A black-box sandbagging detector exploited that LLM accuracy differs >50% between casual and formal question framings, but this was shown on a limited model set; its reliability as a pre-deployment screen across families is untested.

**Direction:** Replicate the casual-vs-formal framing accuracy-gap experiment on several open model families using a standard capability benchmark (e.g., a subset of MMLU or GSM8K). Quantify the framing-induced accuracy gap per model and test whether the gap reliably flags models induced to sandbag (via a sandbagging system prompt) versus honest models.

**Why it matters:** A purely black-box, prompt-only sandbagging screen is cheap, lab-free, and deployable by any evaluator. Confirming whether it generalizes across families determines if it can be trusted as a control evaluation tool.

**Relevant context:** 'Playing Dumb: Detecting Sandbagging via question framing' (LessWrong): >50% accuracy difference casual vs formal. 'LLMs Can Covertly Sandbag' (arXiv 2508.00943). 'Probe-Rewrite-Evaluate' (arXiv 2509.00591).
