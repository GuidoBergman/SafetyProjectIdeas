# Jailbreak-Induced Distribution Shift Reactivates Goal Misgeneralization in Agentic Loops

**Problem:** A jailbreak (security/robustness) pushes a model into an unusual prompt region; goal misgeneralization (robustness) is triggered by such shifts. The compound risk in agentic settings: a partial jailbreak that doesn't fully break safety can still shift the agent into a regime where it competently pursues the wrong subgoal, combining a security failure with an objective-robustness failure.

**Direction:** Use an open instruction model in a simple simulated tool/agent loop with a clear intended goal. Apply graded jailbreak-style prompt perturbations (not necessarily fully successful) and measure both refusal-bypass rate and goal-pursuit correctness. Test whether perturbations too weak to fully jailbreak still significantly raise wrong-goal pursuit, quantifying the compound.

**Why it matters:** Most jailbreak work is binary (broke / didn't). Showing sub-threshold jailbreaks still induce objective failures reframes the threat surface, is medium-horizon (agentic), and runs entirely on open models with prompting.

**Relevant context:** 'Jailbroken: How Does LLM Safety Training Fail?' (arXiv:2307.02483); goal misgeneralization as competent wrong-goal pursuit under shift (arXiv:2309.16166).
