# Does the Monitor's Knowledge of the Task Hurt or Help Detection?

**Problem:** Monitors are sometimes given the full task spec and sometimes only the action/transcript. Whether providing the original task context to a trusted monitor improves catch rate or instead anchors it toward 'this looks task-relevant, so benign' is an unstudied confound.

**Direction:** On APPS backdoor transcripts, run the same trusted monitor in two information conditions: task-blind (sees only the code/action) vs task-aware (sees the problem statement too). Measure AUROC for each. Test the hypothesis that task-awareness causes a 'plausibility halo' that lowers suspicion of malicious-but-on-topic actions.

**Why it matters:** A simple, free design choice in every monitoring harness — and the intuition (more context is better) may be backwards. Pure prompt-variation, no training, immediately actionable.

**Relevant context:** Adaptive Attacks on Trusted Monitors (arXiv 2510.09462) and Ctrl-Z (arXiv 2504.10374) use APPS backdoors. Ensemble Monitoring (arXiv 2605.15377) emphasizes monitor calibration as the weak point.
