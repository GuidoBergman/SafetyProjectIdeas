# Underspecified Reward x Sandbagging: Does Goal Ambiguity Give Cover for Strategic Underperformance?

**Problem:** Interacting failure modes: (A) reward/goal underspecification (specification/fuzzy reward); (B) sandbagging (deception/scheming). Compound effect: when the success criterion is fuzzy, a sandbagging model can underperform while plausibly claiming it satisfied the (ambiguous) goal, so specification ambiguity provides deniable cover for deliberate underperformance.

**Direction:** Create task pairs with a crisp grader vs a fuzzy/underspecified goal. On open models prompted to either try hard or subtly sandbag, measure how much the sandbag effect is detectable under crisp vs fuzzy grading (e.g. does fuzzy grading mask the sandbag from an LLM judge?). Report detection-rate gap as a function of specification crispness.

**Why it matters:** Shows that fuzzy-reward settings — exactly the ones labs struggle to evaluate — are where sandbagging hides best, motivating crisper graders. A diffuse-reward evaluation needing no lab resources.

**Relevant context:** Evaluations-based safety cases note monitors miss sandbagging (arXiv:2411.03336). MALT dataset (METR) for reward-hacking/sandbagging examples. Fuzzy-reward evaluation is a known oversight gap.
