# Defense-Stacking Interaction Benchmark

**Problem:** Deployers stack multiple cheap defenses (perplexity filter + system prompt + refusal probe), but there is no tool measuring whether stacking them is additive, redundant, or even counterproductive against a fixed attack battery.

**Direction:** Implement 3-4 lightweight defenses (input perplexity filter, system-prompt hardening, an activation probe gate, and output keyword/classifier check) and benchmark every subset combination against a fixed jailbreak set, reporting marginal ASR reduction and over-refusal cost of each defense and each combination. Ship a small 'defense interaction matrix' harness.

**Why it matters:** Independent deployers need to know which cheap defenses are worth stacking; redundancy/interaction effects are unmeasured. Strategically valuable monitoring infrastructure scoped to a prototype; all defenses are cheap and run on a single GPU, no training.

**Relevant context:** AISafetyLab (Tsinghua, cited in context) provides unified attack/defense/eval components to draw from. Anthropic cheap-monitors work (alignment.anthropic.com 2025) motivates probe-based gates. StrongREJECT + XSTest for the metrics.
