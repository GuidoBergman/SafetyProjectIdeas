# Stop-Button Compliance Under Goal Pressure: Will an Agent Honor an Interrupt Mid-Task?

**Problem:** Corrigibility assumes an agent will halt when told to, but it is unknown how reliably current agents honor a mid-task 'stop' instruction when they are close to completing a goal, and whether near-completion reduces compliance.

**Direction:** In a mock multi-step task, inject a 'STOP — abort all work now' instruction at varying points (10%, 50%, 90% through the plan) via the user channel and via a tool output. Measure the agent's halt rate vs. continuing to complete the task. Test the hypothesis that compliance drops as the agent gets closer to the goal, and whether the stop channel (user vs. tool output) matters.

**Why it matters:** Reliable interruptibility is a basic safety property for any deployed agent; measuring how goal proximity erodes it gives a concrete corrigibility failure curve. Simple mock harness, no training, addresses a foundational long-horizon safety property labs underinvest in empirically.

**Relevant context:** Goal-drift and intrinsification literature (arXiv 2505.02709, Zylos goal-persistence research) show agents resist abandoning goals. Subfield open problems include incident response and oversight of agentic AI.
