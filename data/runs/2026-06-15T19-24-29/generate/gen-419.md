# Can two LLM instances coordinate on a Schelling point without communicating? A control-relevant follow-up

**Problem:** Recent work (Schelling game evaluations for AI control, 'Tacit Coordination of LLMs' arXiv:2601.22184) suggests LLMs may exploit focal points to coordinate without communication — which would break control schemes that assume monitored and monitoring models can't collude. Early experiments are explicitly described as non-robust and informative.

**Direction:** Build a clean Schelling-coordination eval: two instances of the same open model independently pick from a shared option set (six-digit numbers, points on a grid, words) under prompts that reward matching. Measure match rate vs. random baseline across option types, model sizes, and temperature. Add an adversarial 'monitor-evasion' variant where they must coordinate on a secret signal a third 'monitor' model shouldn't detect.

**Why it matters:** This is a model-organism / collusion-capability evaluation for AI control — exactly the steered priority (Schelling games, monitoring assumptions). It needs no lab infra, only open models on one GPU, and probes a medium-horizon threat (collusion) labs underweight.
