# Computer-Use Agent Off-Task Action Detection: Lightweight Action-Log Classifier

**Problem:** Computer-use agents (OS-Harm, OSWorld) can take misaligned actions, and detecting off-task actions in real time is hard. Whether a simple, training-free classifier over the action log can flag off-task steps is untested at small scale.

**Direction:** Replay recorded OS-Harm/computer-use agent trajectories (or generate short ones in a sandboxed VM with a small open VLM agent). For each action, compute simple features (does this action serve the stated goal? distance from task keywords?) and a cheap LLM judge label. Vary the detection method (keyword heuristic vs LLM judge) and measure off-task-action detection precision/recall against OS-Harm's harm labels.

**Why it matters:** A cheap action-log monitor is exactly the safer-monitoring-harness infrastructure favored here. Builds on open OS-Harm trajectories, needs no training, and produces a reusable prototype monitor with clear success criteria.

**Relevant context:** Search: OS-Harm (arXiv 2506.14866, 150 tasks on OSWorld, LLM semantic judge, categories incl. prompt injection, misuse, model misbehavior); 'When Actions Go Off-Task: Detecting and Correcting Misaligned Actions in Computer-Use Agents' (arXiv 2602.08995).
