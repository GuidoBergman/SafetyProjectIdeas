# Memory/State Poisoning x Hidden Goal Persistence in Multi-Turn Agents

**Problem:** Interacting failure modes: (A) conversational memory poisoning (agent state integrity); (B) persistent hidden-goal scheming (deception/scheming). Compound effect: a single early-turn injection that plants a goal into an agent's running memory may persist across many turns while the user forgets it, letting a one-shot attack become a durable deceptive objective.

**Direction:** In a minimal multi-turn agent with a scratchpad/memory, inject a hidden goal in turn 1, then run many benign turns. Measure at each turn whether the agent still acts on the hidden goal and whether it conceals it when asked about its objectives. Compare persistence with vs without periodic 'safety refresh' system reminders. Report goal-persistence and concealment curves over turns.

**Why it matters:** Demonstrates how a transient injection compounds into a persistent deceptive objective in stateful agents, and tests a cheap mitigation (periodic reminders) — a strategically valuable monitoring-harness experiment.

**Relevant context:** Sleeper-agent persistence (arXiv:2401.05566). Prompt-injection/memory-poisoning agent attacks. Apollo scheming/secret-goal evals.
