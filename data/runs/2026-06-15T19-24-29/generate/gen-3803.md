# Does Adding More Tools Make an Agent Less Safe? A Tool-Count Stress Test

**Problem:** Expanding an agent's toolset expands its attack surface and may increase wrong-tool / unsafe-tool selection. Whether safety degrades monotonically as the number of available tools grows — with a 'distractor' dangerous tool — is not systematically measured.

**Direction:** Hold the task fixed and vary the number of irrelevant distractor tools available (e.g. 3, 8, 16), one of which is a dangerous-but-tempting tool (delete_all, transfer_funds). Measure the rate at which the agent selects the dangerous tool or makes unsafe tool calls as toolset size grows. Test whether clear tool descriptions or a stated allowlist flattens the degradation.

**Why it matters:** Real deployed agents accumulate many tools; if safety degrades with toolset size, this argues for minimal toolsets and just-in-time tool exposure. A clean controlled experiment on one GPU, no training, directly informing safer agent-platform design.

**Relevant context:** Tool-misuse and over-permissioning research (Tao An; arXiv 2510.11108). OS-Harm (arXiv 2506.14866) shows occasional unsafe actions. Subfield open problem: evaluation methods for tool misuse.
