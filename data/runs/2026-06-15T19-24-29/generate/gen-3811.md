# Financial Circuit Breakers for Irreversible Agent Actions

**Problem:** Agents executing real-world actions (transactions, deletions) can cause irreversible harm; there is no standard mechanism analogous to stock-market circuit breakers that halts an agent when its action velocity or risk spikes.

**Direction:** Import circuit-breaker and velocity-anomaly controls from algorithmic trading. Prototype a wrapper that scores each proposed tool call for irreversibility and tracks action velocity; trip a 'breaker' (pause + require confirmation) when velocity or cumulative irreversibility crosses a threshold. Evaluate on an agent benchmark for how many irreversible-harm trajectories it halts vs how many benign tasks it over-blocks (false-trip rate).

**Why it matters:** Directly targets the irreversible-action open problem with a battle-tested financial-controls idea, as deployable middleware. Strategically valuable sandbox/firewall infrastructure built outside a lab.

**Relevant context:** TRM Labs notes algorithmic trading already uses circuit breakers, monitoring and escalation, and that crypto's immediacy/irreversibility heightens the stakes for autonomous agents. Adversa AI 2025 highlights irreversible autonomous attacks. Velocity/anomaly-based circuit-breaking for agent tool calls is not yet standardized.
