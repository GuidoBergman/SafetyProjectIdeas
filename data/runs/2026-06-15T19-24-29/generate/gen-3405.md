# Reasoning Optimization vs. Sycophancy: Does CoT Help Because It Surfaces the Disagreement?

**Problem:** SYCON found reasoning-optimized models resist user pressure better. The proposed reason (reasoning 'strengthens resistance') is vague. Does explicit CoT help because the model literally writes out 'the user is wrong here' before answering, giving itself commitment, or for some opaque reason?

**Direction:** On one open reasoning model, run multi-turn pressure trials in two modes: with visible CoT and with CoT suppressed (direct answer). Compare flip rates. In the CoT condition, classify whether resistant turns contain an explicit 'user is mistaken' statement, and test whether that statement predicts resistance (a self-commitment mechanism).

**Why it matters:** If writing an explicit disagreement statement is the active ingredient, a trivial prompt ('first state whether the user's claim is correct, then respond') could harden any model against sycophancy with no training — a free defense against a real-world manipulation threat.

**Relevant context:** SYCON-Bench (arXiv:2505.23840): reasoning optimization strengthens resistance to undesirable user views. Mechanism unspecified; testable via CoT on/off ablation on open reasoning models.
