# Polysemantic Refusal Features Plus Over-Refusal Collateral

**Problem:** Compound: (1) polysemantic 'refusal' features fire on benign content too (interp/superposition failure) amplifying (2) over-refusal / helpfulness degradation. Steering or monitoring on a polysemantic refusal feature both miss-detects benign queries as harmful and, when used to enforce refusal, broadens harmless over-refusal — a safety-usefulness compounding cost.

**Direction:** Identify a candidate refusal feature in an open model + SAE. Characterize its activation across a benign-but-sensitive set (medical, legal, security education). Measure false-positive firing, then test whether amplifying the feature for safety increases over-refusal on the benign set. Quantify the joint harm-miss / benign-block frontier.

**Why it matters:** Over-refusal is a fuzzy, under-measured safety-usefulness tradeoff. Tying it to feature polysemanticity gives a mechanistic, lab-independent measurement using public SAEs.

**Relevant context:** Toy Models of Superposition (Anthropic) on polysemanticity. Search results: GSAE (arXiv:2512.06655) finds safety lives in distributed multi-feature patterns, implying single-feature refusal is polysemantic. Over-refusal benchmarks (e.g. XSTest) are public.
