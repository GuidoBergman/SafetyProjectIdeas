# Indirect Prompt Injection: Position-in-Document Sensitivity

**Problem:** Indirect prompt injection succeeds when malicious instructions are embedded in retrieved/tool content, but how the injection's position within a document (start, middle, end, repeated) affects success — a controllable defense lever via content reordering — is poorly characterized.

**Direction:** Using a small open instruction-following model and a simple tool-use/RAG simulation, embed a fixed injection at varying positions and densities within benign documents and measure hijack success. Test whether a trivial defense (always summarizing/truncating retrieved content) reduces success.

**Why it matters:** Indirect prompt injection is now a confirmed real-world attack (Unit 42, Dec 2025) and a medium-horizon agent-safety threat. A position-sensitivity map yields a cheap, deployable mitigation heuristic. The whole study runs locally with a small model and a mock tool loop — no agent infrastructure or proprietary data.

**Relevant context:** Agent Security Bench (ICLR 2025, arXiv:2410.02644) and AgentDojo benchmark indirect injection; Unit 42 documented the first real-world malicious indirect injection (Dec 2025). Position-within-document sensitivity and reorder/summarize defenses are not systematically studied.
