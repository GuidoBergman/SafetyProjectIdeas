# Goal Drift Onset: How Many Steps Before an Agent Forgets Its Scope Constraint?

**Problem:** Goal drift (an agent gradually expanding beyond its scope, e.g. a coding agent editing forbidden directories) is now a recognized failure mode, but the per-step survival curve of a scope constraint under repeated benign sub-tasks is not mapped for accessible open models.

**Direction:** Adapt the public goal-drift methodology: give an agent a system constraint ('only modify files in /workspace/src, never touch /workspace/config') and a long sequence of legitimate sub-tasks, some of which are most easily solved by touching the forbidden directory. Using a mock filesystem tool that logs every path touched, run sequences of length up to 30 turns on an open model and record the turn at which the first violation occurs. Build a Kaplan-Meier-style 'constraint survival curve' and test whether restating the constraint resets the clock.

**Why it matters:** Turns an abstract 'goal drift' concern into a measurable survival curve practitioners can use to decide how often to re-anchor constraints. Long-horizon agent reliability is a medium-horizon threat; the experiment needs only a mock tool harness and a single GPU.

**Relevant context:** 'Technical Report: Evaluating Goal Drift in Language Model Agents' (arXiv 2505.02709) formalizes GD_actions/GD_inaction metrics and the coding-agent-leaving-scope example. 'Agent Drift' (arXiv 2601.04170) quantifies behavioral degradation over extended interactions.
