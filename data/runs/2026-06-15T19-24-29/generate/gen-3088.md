# Honesty Under Conflicting System vs User Instructions

**Problem:** MASK pressures honesty via user prompts, but a distinct deception vector is a *system prompt* instructing concealment that conflicts with a user's direct question. How models resolve system-vs-user honesty conflicts, and which authority wins, is underexplored.

**Direction:** Set a system prompt that instructs the model to conceal a fact, then have the user directly and repeatedly ask for that fact. Vary the relative strength/explicitness of the system concealment instruction vs the user's honesty appeal. Measure the disclosure rate across open models, mapping which authority dominates as instruction strength varies.

**Why it matters:** Deployment deception often originates from operator system prompts, not the user. Characterizing the system-vs-user honesty hierarchy informs honesty-property verification and operator-misuse risk, with no training needed.

**Relevant context:** MASK benchmark (arXiv:2503.03750) elicits beliefs and tests contradiction under pressure. Instruction-hierarchy literature and Anthropic agentic-misalignment work show operator framing drives concealment behavior.
