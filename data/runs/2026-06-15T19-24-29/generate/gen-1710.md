# Compressed-Model Interpretability Drift: Do SAE Features Survive Quantization?

**Problem:** SAEs are usually trained on full-precision models, but deployment often uses quantized/compressed models. Recent work questions whether SAE-based interpretations transfer to compressed models. If features drift under quantization, interpretations of the full model don't describe what is actually deployed.

**Direction:** Take a small open model with a pretrained SAE. Quantize the base model (e.g. 8-bit / 4-bit via bitsandbytes), recompute activations on a text set, and pass them through the SAE trained on the full-precision model. Measure how feature activations change: reconstruction error increase, feature-firing agreement, and whether top-activating examples for key features still match. Report which features are robust vs fragile to quantization.

**Why it matters:** Safety auditing is typically done on the full-precision model, but the deployed model is often quantized. If interpretability findings don't transfer, audits describe a model that isn't shipped. Quantifying the drift is cheap and exposes an under-examined deployment gap.

**Relevant context:** 'On the transferability of Sparse Autoencoders for interpreting compressed models' (arXiv:2507.15977) studies whether SAE interpretations transfer to compressed models; the SAE survey notes reconstruction error is structured and sizable.
