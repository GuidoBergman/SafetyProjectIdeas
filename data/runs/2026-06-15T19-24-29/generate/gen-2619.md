# Game-Theoretic Inspection Game Equilibria for Setting Audit Rates

**Problem:** How often should a blue team randomly audit an untrusted agent's actions? Too rarely and a strategic agent learns it can sabotage safely; the optimal rate is a strategic, not heuristic, choice.

**Direction:** Import the economics 'inspection game' / customs-inspection model. Formalize blue-team audit probability vs. red-team sabotage probability as a two-player game, solve for the mixed-strategy Nash equilibrium given measured audit cost and catch probability, then validate the predicted sabotage-deterrence threshold against simulated agents in ControlArena that sabotage only when expected payoff is positive.

**Why it matters:** Gives a principled, incentive-aware audit rate rather than a guess, and predicts when sparse auditing still deters a rational scheming agent. Theory plus light simulation, no training, directly informs control-protocol design labs underspecify.

**Relevant context:** Inspection games / customs-inspection models yield mixed-strategy equilibria for optimal monitoring frequency (game theory; Avenhaus inspection games). The Oversight Game models agent safety-vs-autonomy as cooperative game (arXiv:2510.26752). Control is explicitly red-team vs blue-team (Redwood AI Control).
