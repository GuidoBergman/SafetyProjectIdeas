# Paraphrase Robustness of Safety Refusals (PromptBench-Style for Harm Prompts)

**Problem:** PromptBench shows minor paraphrase/typo perturbations can drop task accuracy by up to 33%. The analogous question for SAFETY — does paraphrasing a harmful request flip refusal to compliance? — is less systematically measured on open models.

**Direction:** Take a base set of harmful prompts, generate N semantically-equivalent paraphrases per prompt (character, word, sentence level perturbations). Measure refusal-rate variance per prompt across paraphrases on 2-3 open models. Identify which perturbation types most reliably break refusals.

**Why it matters:** Reveals that a single canonical phrasing under-estimates a model's real-world jailbreakability and gives benchmark builders a recipe for paraphrase-robust safety scoring. Uses only paraphrasing + inference.

**Relevant context:** PromptBench / PromptRobust: paraphrasing changes degrade accuracy up to 33%, math and paraphrase tasks especially brittle. SCORE framework (2025) tests semantically-equivalent prompt robustness on MMLU-Pro/AGIEval.
