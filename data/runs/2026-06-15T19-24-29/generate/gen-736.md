# Replicating the FLI 'existential safety' D-grade finding with an LLM panel

**Problem:** Every lab scored D or below on 'existential safety' in the FLI Index, judged by a 7-expert human panel. Whether that judgment is reproducible by cheaper automated raters (relevant for scaling audits) is untested.

**Direction:** Follow up the FLI panel result by building an LLM-as-judge re-scoring of the same publicly cited evidence against FLI's published rubric, then compare LLM scores to the human panel scores. Measure inter-rater agreement (Cohen's kappa), sensitivity to prompt phrasing, and whether the LLM reproduces the existential-safety failure pattern.

**Why it matters:** If automated raters can cheaply reproduce expert safety grades, low-resource civil-society groups could run continuous audits. If they cannot, that itself is an important negative result about automated governance evaluation.

**Relevant context:** FLI Index expert-panel methodology; CLAUDE.md rubric requirement for numeric scores; Open Problem on international consensus on evaluation methodologies.
