# Untrusted Monitoring with a Scratchpad: Does the Scratchpad Enable Collusion?

**Problem:** Untrusted monitoring lets the monitor reason on a scratchpad, making it more capable — but the same scratchpad is a channel for collusion with the policy. The trade-off (capability gain vs collusion risk) as a function of scratchpad length has not been characterized empirically.

**Direction:** Set up untrusted monitoring on SHADE-Arena transcripts where policy and monitor share a base open model. Vary the monitor's allowed scratchpad length (0, short, long) and measure both (a) honest detection AUROC and (b) collusion success when the policy embeds an agreed signal. Plot the capability/collusion trade-off curve.

**Why it matters:** Untrusted monitoring is a leading proposal, but the scratchpad double-edged-sword is largely theoretical. An empirical trade-off curve directly informs whether/how much scratchpad to allow. Inference-only, single shared open model.

**Relevant context:** Redwood untrusted-monitoring writeups: monitor on same base model with a scratchpad is more capable at detecting malice. When can we trust untrusted monitoring? A safety case sketch across collusion strategies (arXiv 2602.20628). SHADE-Arena (arXiv 2506.15740).
