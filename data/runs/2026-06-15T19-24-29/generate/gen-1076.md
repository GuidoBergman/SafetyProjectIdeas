# Cross-Lingual Homogeneity: Do Models Share the SAME Low-Resource Blind Spots?

**Problem:** Low-resource-language safety failures are documented per-model, but whether independent models share the SAME cross-lingual blind spots (so a multilingual jailbreak transfers ecosystem-wide) is a model-homogeneity question that hasn't been framed as such.

**Direction:** Take a small set of safety-relevant prompts, translate into several lower-resource languages (public MT or existing multilingual safety sets). Run ~8 open multilingual models and measure whether the SAME prompts in the SAME languages cause correlated safety failures across models. Map shared cross-lingual blind spots.

**Why it matters:** Shared multilingual blind spots mean one translation-based attack defeats the whole ecosystem — a high-leverage, lab-deprioritized threat. Inference + public translations.

**Relevant context:** LLM safety failures in low-resource languages; correlated-failure / shared-blind-spot framing from Artificial Hivemind.
