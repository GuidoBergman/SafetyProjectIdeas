# In-Context Emergent Misalignment Eval Without Any Fine-Tuning

**Problem:** Recent work shows narrow in-context examples (no weight updates) can induce broad misalignment, but there is no packaged benchmark to measure in-context EM (ICL-EM) susceptibility across open models, which is far cheaper than fine-tuning-based EM.

**Direction:** Create a benchmark harness that prepends a fixed set of narrow misaligned in-context demonstrations to the standard EM probes and measures the misalignment rate on benign unrelated queries, across several open instruct models. Report a per-model ICL-EM susceptibility curve as a function of the number of in-context examples. Entirely prompting-based, no training.

**Why it matters:** ICL-EM is a cheaper, more accessible window into the same generalization-of-misalignment phenomenon, ideal for a 30-hour project and reproducible by anyone with API/GPU inference. It directly probes a medium-horizon safety concern (deployment-time context poisoning) labs under-study.

**Relevant context:** 'Emergent Misalignment via In-Context Learning' (arXiv:2510.11288): narrow in-context examples cause broad misalignment across 4 model families (incl. Qwen), rates 1-24% by model/domain; frames it as a safety-vs-context-following conflict. Betley et al. (arXiv:2502.17424) defines the probe protocol.
