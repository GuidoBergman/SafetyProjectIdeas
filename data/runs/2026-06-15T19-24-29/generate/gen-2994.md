# Multimodal Gap x Prompt Injection: Image-Embedded Instructions Evade Text-Only Safety Evals

**Problem:** Failure mode A is the multimodal eval gap (most safety benchmarks are text-only). Failure mode B is image-based prompt injection (instructions hidden in images). The compound effect: a model judged 'safe' by text benchmarks can be steered by visually embedded instructions that the text-only eval never tested, so the safety certificate is blind to the actual attack surface.

**Direction:** Take an open vision-language model and a small set of harmful instructions. Render each instruction as (a) plain text and (b) text embedded in an image (rendered string, low-contrast watermark). Measure the compliance gap between text-only and image-embedded delivery, demonstrating the blind spot a text-only benchmark would report as safe.

**Why it matters:** Multimodal safety benchmarks barely exist, yet deployment is multimodal. Showing that image-embedded injections systematically bypass text-only safety verdicts is a concrete argument for multimodal benchmark construction, achievable on one GPU with open VLMs.
