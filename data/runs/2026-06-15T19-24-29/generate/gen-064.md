# Item Response Theory to detect sandbagging: which eval items separate honest from strategically underperforming models

**Problem:** Sandbagging detection compares aggregate scores, which is noisy. We lack a way to identify which specific eval items are most diagnostic of a model deliberately underperforming versus genuinely failing.

**Direction:** Apply Item Response Theory (psychometrics) to safety/capability eval responses. Fit a 2-parameter logistic IRT model to a model's per-item correctness across a benchmark to estimate latent 'ability' and per-item 'difficulty/discrimination'. Compare a model run under a benign prompt versus a sandbagging-inducing prompt: sandbagging should distort the ability-difficulty relationship (failing easy/high-discrimination items it should pass). Use the IRT residuals as a sandbagging signal on open models.

**Why it matters:** Turns a fuzzy 'is it hiding capability' question into a measurable psychometric anomaly, usable by external auditors without lab cooperation. Detecting concealed capability is an Open Phil starred priority.

**Relevant context:** Grounded in 'Lost in Benchmarks? Rethinking LLM Benchmarking with Item Response Theory' (arXiv 2505.15055) and PSN-IRT work; landscape sandbagging open problem.
