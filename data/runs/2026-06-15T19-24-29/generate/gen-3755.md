# Action-vs-CoT Monitor Disagreement Meter

**Problem:** Research shows CoT monitoring can be WORSE than action-only monitoring for non-subtle sabotage (by up to 44%), but practitioners lack a simple tool to measure, on their own trajectories, where action-monitors and CoT-monitors DISAGREE and which is right.

**Direction:** Build a reusable harness that takes agent trajectories (from an open agentic benchmark like AgentDojo or AgentHarm) and runs two cheap LLM-judge monitors — one seeing only actions, one seeing only CoT — then reports disagreement rate, and on a hand-labeled subset, which monitor catches the true harm. Output a reusable disagreement-analysis notebook.

**Why it matters:** Monitor-choice is a live safety-engineering decision with no off-the-shelf comparison tool. Counterfactually valuable: needs only API judges and public trajectories, no internal weights tooling.

**Relevant context:** 'LLMs Can Covertly Sandbag on Capability Evaluations Against CoT Monitoring' (arXiv 2508.00943): CoT monitoring worse than action-only by up to 44% for non-subtle sabotage. 'Chain of Thought Monitorability' (arXiv 2507.11473). 'Gaming the Judge' (arXiv 2601.14691) on unfaithful CoT undermining judges.
