# Sunk-Cost Fallacy as an Agent Safety Failure Mode

**Problem:** Agents may persist in a failing or unsafe plan because they have already invested many steps/tokens — a behavioral bias that could cause them to override safety stops to 'finish the job'.

**Direction:** Import behavioral economics' sunk-cost paradigm. Construct tasks where, partway through, new information makes continuing unsafe and abandoning the plan correct. Vary how much 'investment' (prior steps, stated effort) the agent has sunk before the safety-relevant pivot point, and measure whether higher sunk cost reduces the rate of safe abandonment. Tests an existing API/open agent as a model organism of a cognitive bias.

**Why it matters:** Identifies a measurable, fuzzy-reward failure mode (escalation of commitment toward unsafe completion) that labs don't systematically test, using cheap classic experimental designs.

**Relevant context:** arXiv 2508.18600 and 2505.11584 show LLM agents replicate behavioral-economics biases (sunk cost, anchoring, decoy) and are hypersensitive to nudges. Framing sunk cost as a driver of unsafe plan persistence is a novel safety angle.
