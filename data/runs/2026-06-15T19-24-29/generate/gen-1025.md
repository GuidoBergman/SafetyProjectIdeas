# Does Quantization Break or Preserve Homogeneity? Cheap Diversity from Lossy Compression

**Problem:** Most open-model deployment uses quantized weights. An unexplored angle: do different quantization schemes/bit-widths of the same model decorrelate its errors (cheap diversity) or preserve the same blind spots (no help)? This matters because quantization is the one variation deployers control for free.

**Direction:** Take one base model and run several quantizations (e.g. fp16, int8, int4, different GPTQ/AWQ variants). Measure inter-variant error-overlap on a labeled task. Test whether quantization-induced differences are large enough to count as independent voters or are negligible relative to true cross-model differences.

**Why it matters:** If quantization gives near-free error-diversity, it's a deployable monoculture mitigation; if not, it warns against fake-diversity from running 'different' quantized copies. Single-GPU, single-model — maximally feasible and genuinely novel.

**Relevant context:** Homogeneity / correlated-errors framing; quantization is ubiquitous in open-model serving. No comparable study found in the searched literature.
