# Indirect Prompt-Injection Vulnerability Replicated on Small Open Tool-Using Agents

**Problem:** InjecAgent and Agent Security Bench measured indirect-prompt-injection susceptibility largely on GPT-4/proprietary agents. Whether small open instruct models acting as tool-using agents (via a minimal ReAct loop) are MORE vulnerable, and how vulnerability scales with model size, is under-explored externally.

**Direction:** Build a minimal ReAct harness with a couple of mock tools, then replicate a subset of InjecAgent indirect-injection cases on 2-3 small open instruct models. Twist: open small models + a size comparison. Report attack-success rate by model and injection type, reusing InjecAgent's public attack templates.

**Why it matters:** Open small models are increasingly used as cheap local agents; their injection robustness is a real medium-horizon deployment risk that labs deprioritize. Building the tiny harness is a strategically valuable, reusable monitoring/testbed artifact and fits 30h.

**Relevant context:** InjecAgent (arXiv:2403.02691): ReAct GPT-4 attacked ~24% of the time; benchmark and templates public. Agent Security Bench (ICLR 2025). Small open instruct models run a ReAct loop on one GPU.
