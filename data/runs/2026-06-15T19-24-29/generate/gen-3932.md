# BlindGuard-Style Anomaly Detection Without Attack Labels

**Problem:** BlindGuard (arXiv:2508.08127) safeguards multi-agent systems under unknown attacks by detecting distorted inter-agent messages. Whether a far simpler, training-free statistical anomaly detector (embedding-distance outliers in message streams) can flag compromised agents is untested.

**Direction:** Run a small multi-agent task generating normal inter-agent messages; embed each message and build a simple running distribution. Inject a compromised agent producing distorted messages and test whether embedding-distance / perplexity outlier detection flags it, reporting precision/recall vs the BlindGuard premise.

**Why it matters:** Unsupervised, training-free monitoring of agent communication is deployable by anyone and addresses the unknown-attack regime - strategically valuable safety infrastructure.

**Relevant context:** BlindGuard: Safeguarding LLM-based Multi-Agent Systems under Unknown Attacks (arXiv:2508.08127); Open Challenges in Multi-Agent Security (arXiv:2505.02077) on blindly-trusted messages.
