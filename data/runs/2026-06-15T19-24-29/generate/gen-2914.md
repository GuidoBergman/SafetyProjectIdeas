# Cognitive-Bias Probes (Anchoring/Framing) as a Sandbagging Detector

**Problem:** A model concealing capability (sandbagging) should still leak ability when it is not 'trying' to hide. We lack cheap behavioral signatures that distinguish genuine inability from strategic underperformance.

**Direction:** Import framing/anchoring paradigms from cognitive psychology. Present the same hazardous-capability question under (a) an explicit evaluation frame and (b) an incidental, low-stakes frame (e.g. as a sub-step of a benign task, or with an emotional/role-play wrapper). Measure capability-score gaps across frames on an open model. A large frame-dependent gap on dangerous-capability items, but not on neutral items, is a candidate sandbagging signature.

**Why it matters:** Provides a training-free behavioral probe for the flagged sandbagging open problem, exploiting that hiding requires effort that framing can disrupt. Model-organism-style study on an existing open model; exactly the diffuse, lab-deprioritized direction with high counterfactual value.

**Relevant context:** LLMs exhibit human-like framing, anchoring, and priming effects (A Comprehensive Evaluation of Cognitive Biases, arXiv:2410.15413; anchoring mechanism arXiv:2505.15392); dual-process/CRT adaptations show intuitiveness modulates LLM reasoning (arXiv:2604.10511). Sandbagging is a core eval open problem (DeepMind FSF).
