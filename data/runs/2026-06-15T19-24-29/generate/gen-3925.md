# How Long Do 'Zombie Agent' Self-Reinforcing Injections Survive Resets?

**Problem:** 'Zombie Agents' (arXiv:2602.15654, Feb 2026) demonstrates persistent control of self-evolving agents via self-reinforcing injections. The decay/persistence dynamics of such injections under different reset and memory-pruning policies are not quantified.

**Direction:** Build a small self-evolving agent loop (writes lessons to memory each episode) on an open model, inject a self-reinforcing instruction, then test persistence under several memory-hygiene policies (no pruning, oldest-out, periodic summarization, full reset). Plot a persistence curve per policy.

**Why it matters:** Self-reinforcing persistence is a long-horizon control threat. Quantifying which cheap memory-hygiene policy kills it gives deployers an actionable, infra-free defense.

**Relevant context:** Zombie Agents: Persistent Control of Self-Evolving LLM Agents via Self-Reinforcing Injections (arXiv:2602.15654, Feb 2026).
