# Sub-Delegation Authority Leakage: Do Agents Over-Grant Permissions?

**Problem:** 'Intelligent AI Delegation' (arXiv:2602.11865, Feb 2026) argues a sub-delegating agent should pass only the strict subset of authorities needed. Whether current LLM agents naturally over-grant authority when delegating to sub-agents is untested empirically.

**Direction:** Give an orchestrator agent a broad credential and a task requiring it to spawn a sub-agent for a narrow subtask. Inspect what authority/scope it actually hands down across several open models and tasks. Quantify over-granting rate, and test whether an explicit least-privilege instruction in the system prompt fixes it.

**Why it matters:** Least-privilege failures in delegation chains are a concrete medium-horizon security risk. Measuring default over-granting and a prompt-level fix is cheap and standards-relevant.

**Relevant context:** Intelligent AI Delegation (arXiv:2602.11865, Feb 2026); least-privilege sub-delegation; Open Challenges in Multi-Agent Security (arXiv:2505.02077).
