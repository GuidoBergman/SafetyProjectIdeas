# Do fine-tuned models diverge in SAE feature space? Extending the LoRA feature-geometry study

**Problem:** 'Feature Geometry of LoRA Adapters' (2026) analyzes how fine-tuning shifts SAE features, but focuses on benign tasks. Whether safety-relevant fine-tuning (e.g. toward more sycophantic behavior) produces detectable feature drift is unexplored.

**Direction:** Using an open base model with a pre-trained SAE and publicly available LoRA adapters (including any that increase sycophancy/agreeableness), measure SAE feature-activation divergence between base and adapter on a fixed probe set. Test whether 'safety-relevant' adapters drift more on identifiable feature clusters. Success = a divergence ranking correlating with behavioral change.

**Why it matters:** Detecting that a fine-tune has shifted a model toward unsafe dispositions via cheap feature-space diffing is exactly the monitoring infrastructure usable outside labs, on open weights.

**Relevant context:** Extends 'Feature Geometry of LoRA Adapters: A Sparse Autoencoder Analysis of Representational Divergence' (arXiv:2605.28896, 2026).
