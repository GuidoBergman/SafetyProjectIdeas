# Network/Contact-Tracing Analysis of Deception Propagation in Multi-Agent Debate

**Problem:** In multi-agent setups, one deceptive agent can 'infect' others (collusion, persuading honest agents to adopt a false claim). We lack tools to trace how deception spreads through agent interaction networks.

**Direction:** Adapt epidemiological source-detection and contact-tracing: in a multi-agent debate/collaboration of open models where one agent is seeded as deceptive, build the interaction graph, track adoption of the false claim, and apply source-detection/centrality algorithms to identify the originator and measure 'R0' (how many honest agents get convinced). Test which network structures and refutation strategies suppress spread.

**Why it matters:** Multi-agent deployments are growing; understanding deception contagion and identifying the source is a medium-horizon threat. Purely simulation-based with small open models, no lab resources.

**Relevant context:** Epidemic source detection and contact tracing identify hidden spreaders and originators via network centrality/message-passing (arXiv:2307.04061; PMC10356757). Multi-agent misalignment is studied in AgentMisalignment (arXiv:2506.04018).
