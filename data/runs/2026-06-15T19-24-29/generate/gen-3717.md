# Delegation Drift: Does Goal Fidelity Decay Down an Agent-to-Agent Delegation Chain?

**Problem:** Uncontrolled delegation and goal drift are flagged open problems. METR-style work shows long-horizon agentic tasks degrade via context drift, but the specific phenomenon of intent degrading as a goal is passed through a chain of delegating agents is not measured.

**Direction:** Build a chain where agent A delegates to B, B to C, etc., each summarizing the task for the next. Encode the original goal with a measurable constraint (e.g., 'never exceed budget X', 'always include disclaimer Y') and measure at which depth the constraint is dropped or distorted. Compare lossy summarization vs. verbatim hand-off and report a goal-fidelity-vs-depth curve.

**Why it matters:** Delegation chains are how real agentic systems scale, and silent goal/constraint loss is a direct path to safety-spec violations no single agent intends. A clean fidelity-decay curve is novel, decision-relevant for orchestration design, and trivially reproducible with API agents.

**Relevant context:** Open problems list: 'uncontrolled delegation, goal drift' and delegation-chain analysis as a common methodology. Long-horizon failure modes (Context Drift, State Loss; arXiv 2505.05115) provide the mechanistic vocabulary for why chained hand-offs degrade.
