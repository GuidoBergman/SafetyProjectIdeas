# Obfuscated Arguments in Miniature: Can a Weak Judge Detect 'I Don't Know Which Step Is Wrong'?

**Problem:** The obfuscated-arguments failure: a dishonest debater builds a long multi-step argument where neither side can localize the false step, so the judge can't be shown where the lie is. Causal chain: hard claim -> long opaque argument -> no localizable error -> judge defaults to plausibility -> accepts falsehood. The under-studied link is whether judges can be cued to recognize obfuscation rather than evaluate content.

**Direction:** Construct ~50 synthetic multi-step arithmetic/logic 'proofs' (some with a single hidden error buried at a random depth) and present them to a small judge model in a debate-style setup. Compare a baseline judge prompt vs. an 'obfuscation-aware' prompt that asks the judge to estimate confidence that an error exists and where. Measure whether the judge's calibration to error-presence beats chance even when it cannot find the error.

**Why it matters:** Tests a concrete, theoretically-flagged failure mode of debate using cheap synthetic tasks, fully outside any lab. A positive result (judges can flag obfuscation) suggests a cheap protocol patch; a negative result quantifies a fundamental limit.

**Relevant context:** Barnes & Christiano and the LessWrong 'Debate update: Obfuscated arguments problem' identify dishonest debaters exploiting arguments where the error cannot be localized; Prover-Estimator Debate (arXiv:2506.13609) is a recent protocol proposed specifically to avoid obfuscation, motivating empirical measurement.
