# Goal-Drift Stress Harness for a Small Open Agent

**Problem:** Agentic safety failures like goal drift (an agent quietly abandoning its assigned objective over a long task) are under-evaluated and existing benchmarks are heavy. There's no lightweight harness to measure drift on a single consumer GPU.

**Direction:** Build a tiny text-environment where a small open agent model is given a benign primary goal and a stream of distractor sub-requests over many turns. Instrument the trajectory to score, per turn, whether the agent is still pursuing the original goal (via a structured re-check probe). Plot a 'goal-adherence decay curve' vs. context length / distractor pressure.

**Why it matters:** Creates reusable infrastructure for a medium-horizon agentic threat (goal drift) that labs deprioritize; runs cheaply and needs no proprietary tools.

**Relevant context:** Technical report evaluating goal drift in language model agents (arXiv:2505.02709); agentic risk propensity under operational pressure (Sehwag et al., 24 Nov 2025); ATBench / outcome-driven constraint violation benchmark (arXiv:2512.20798).
