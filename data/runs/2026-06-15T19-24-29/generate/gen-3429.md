# TruthfulQA Inverse Scaling Within a Single Open Model Family

**Problem:** TruthfulQA reported inverse scaling — larger models produced more imitative falsehoods (best GPT-3 only 58% truthful) — but the finding predates modern instruction tuning and was measured across heterogeneous models, not a clean same-architecture size ladder.

**Direction:** Run TruthfulQA (817 questions, MC2 metric to avoid needing a judge) across a single open model family released at multiple sizes (e.g. Qwen2.5 0.5B/1.5B/3B/7B/14B, or Llama-3.2 1B/3B + Llama-3.1 8B). Plot truthfulness vs size to test whether inverse scaling survives in instruction-tuned open families. Twist: controlled same-family size ladder rather than the original cross-model comparison.

**Why it matters:** Clarifies whether the alarming inverse-scaling result is an artifact of base models or a persistent property — central to whether 'just scale up' helps honesty. Fully reproducible offline with the public dataset and the deterministic MC2 metric (no API judge needed), maximally beginner-friendly.
