# Cross-Model SAE Feature Transfer as a Cheap Auditing Shortcut

**Problem:** A success state: 'an SAE trained once can audit many model variants, so monitoring is cheap.' Backcasting from 'reusable audit dictionaries', a prerequisite is whether SAE features trained on a base model still fire meaningfully on a fine-tuned/quantized variant of the same model.

**Direction:** Take a base open model with a public SAE and a fine-tuned (or quantized) sibling. Run the base SAE on the variant's activations; measure reconstruction error and whether top safety-relevant features still fire on the same inputs. Report a 'transferability decay' curve as fine-tuning intensity / quantization increases.

**Why it matters:** If SAEs transfer, monitors can be built once and reused; if not, every fine-tune needs re-auditing — important for governance of derivative models. Uses existing SAEs and model variants, no training.

**Relevant context:** On the transferability of Sparse Autoencoders for interpreting compressed models (arXiv 2507.15977) studies SAE transfer to compressed models. Gemma Scope SAEs are public and Gemma has many fine-tuned/quantized variants.
