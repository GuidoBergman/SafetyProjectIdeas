# Concentration-Risk Map: Correlated Failures Across Models From One Provider

**Problem:** A success state requires understanding systemic risk when many systems depend on the same provider/base model. A needed result is empirical evidence on whether models derived from a common base share correlated safety failures.

**Direction:** Take several open models that share a base (e.g. multiple fine-tunes of the same family) and several from unrelated families. Run a fixed jailbreak/safety set and measure whether same-base models fail on the same items more than cross-family models (correlated failure rate). Deliverable: a correlation matrix and an estimate of shared-failure risk.

**Why it matters:** Systemic risk from AI concentration is a named open problem (EU AI Act). If one base model's flaw propagates to all its descendants, a single exploit is systemic. Open models only, inference-only, no lab access — and a genuinely under-explored, counterfactual angle.
