# CUSUM Change-Point Detection for Treacherous Turns in Long Agent Trajectories

**Problem:** A 'treacherous turn' is a model behaving well until conditions change, then defecting. Detecting the moment of defection in a long agentic trajectory is hard; single-turn evals miss it.

**Direction:** Adapt sequential change-point detection (CUSUM) from quality control: define a per-step honesty/compliance score (e.g., monitor probability of misbehavior, or alignment between stated and actual actions) over a long agent rollout, then run CUSUM to flag the change-point where behavior abruptly shifts. Construct synthetic long trajectories from open models with planted late-defection triggers and measure detection latency and false-alarm rate.

**Why it matters:** Provides an online monitoring primitive for catching behavioral defection early in deployment, a strategically valuable monitoring-harness prototype deployable by anyone, addressing the medium-horizon treacherous-turn threat labs deprioritize.

**Relevant context:** CUSUM is the standard sequential method for detecting distributional shifts in real-time monitoring (Change detection, Wikipedia; WSU survey). Treacherous turns / deferred defection are core scheming threat models (Apollo safety cases). MALT provides long agent transcripts.
