# Monitor Robustness to True Distribution Shift Replicated for Control

**Problem:** 'When Benchmarks Lie' showed malicious-prompt classifiers degrade sharply under true distribution shift, but this was for prompt classifiers, not control monitors scoring agent actions/code.

**Direction:** Replicate the distribution-shift evaluation paradigm for a control monitor: train/calibrate a cheap suspiciousness monitor on one backdoor style or task domain, then test on a genuinely different backdoor style or a different task domain. Measure the AUC/FPR degradation and report whether control monitors suffer the same shift-induced collapse as prompt classifiers.

**Why it matters:** Control deployments face novel attack distributions by definition. Showing whether monitors hold up under true shift is a critical, reproducible robustness check that needs no proprietary data.

**Relevant context:** 'When Benchmarks Lie: Evaluating Malicious Prompt Classifiers Under True Distribution Shift' (arXiv 2602.14161). Control Tax APPS backdoors (arXiv 2506.05296); SHADE-Arena task variety (arXiv 2506.15740).
