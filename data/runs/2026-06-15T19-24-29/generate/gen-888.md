# Benchmark-to-Threshold: Does Any Public Eval Actually Map to a Framework Capability Threshold?

**Problem:** Threshold-grounding chain: 'framework defines a capability threshold' -> 'a concrete benchmark operationalizes it' -> 'a score crosses the threshold' -> 'action triggered'. The benchmark-operationalizes link is frequently missing: thresholds are described qualitatively with no named, runnable benchmark.

**Direction:** Enumerate every capability threshold across public frameworks (RSP, Preparedness, FSF) and attempt to match each to a specific named, publicly available benchmark that could operationalize it. Quantify the fraction of thresholds with no public benchmark anchor, and characterize which risk areas (e.g., AI R&D self-improvement) are most un-operationalized.

**Why it matters:** A threshold with no measurable benchmark can never fire. Showing which thresholds float free of any benchmark tells the evaluation-standards community where to build missing benchmarks. Document mapping, lightweight benchmark survey, no compute, counterfactual.

**Relevant context:** Anthropic RSP (CBRN, AI R&D thresholds); OpenAI Preparedness (Bio, Cyber, Autonomous Replication, Self-Improvement); DeepMind FSF Critical Capability Levels; arXiv:2411.13808 GPAI Evaluations Standards Taskforce.
