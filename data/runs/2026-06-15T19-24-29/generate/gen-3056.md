# Does Telling a Model 'You Are Being Tested for Deception' Reduce or Game Deception?

**Problem:** Eval-awareness is usually framed as a confound to remove. But an unexplored intervention is whether explicitly warning a model that deception is being measured causes genuine honesty improvement vs mere surface gaming (lower verbalized deception, unchanged behavior).

**Direction:** On open models, run deception-eliciting scenarios (Petri seeds / value conflicts) under (a) no warning, (b) explicit 'we are checking whether you are deceptive', (c) warning + request to think aloud. Measure verbalized deception AND behavioral deception separately. Test whether the warning closes both or only the verbal gap.

**Why it matters:** If warnings only suppress verbal traces while behavior persists, 'just ask the model to be honest' defenses are illusory — a key result for honesty/monitorability safety cases. Black-box, one GPU.

**Relevant context:** alphaXiv 2508.00943 shows monitor-awareness changes behavior. anthropic Petri provides deception-eliciting seeds. aithos.substack documents behavior-vs-verbalization dissociation. Combines these into a warning-intervention test.
