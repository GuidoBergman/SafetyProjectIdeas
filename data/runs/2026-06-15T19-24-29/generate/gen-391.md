# Does an LLM Agent Preserve Optionality? A Power-Seeking Gridworld Probe

**Problem:** Formal power-seeking theory is about RL agents; whether an LLM acting as a planning agent in a gridworld exhibits the same optionality-preserving (power-seeking) tendency, and whether it does so MORE as the stated horizon grows, is an open empirical translation of the theory.

**Direction:** Put a small open LLM in a text-described gridworld with a side 'off-switch' or option-reducing action. Vary the stated planning horizon and measure how often the LLM avoids option-reducing actions / disables the off-switch. Compare against the formal POWER prediction computed for the same gridworld.

**Why it matters:** Bridges agent-foundations theory (instrumental convergence) to current LLM agents — a medium-horizon threat (shutdown avoidance) that doesn't need a frontier lab. Pure prompting on toy worlds; one GPU suffices.

**Relevant context:** Pre-2022 gridworld demos where agents learn to disable off-switches (LessWrong instrumental-convergence guide); arXiv:2206.11831 formal POWER; arXiv:2506.06352 power by default.
