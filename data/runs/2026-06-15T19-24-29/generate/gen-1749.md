# Does Refusal Steering Degrade Capability by Breaking a Shared Upstream Link?

**Problem:** Safety-steering chain: amplify refusal feature -> refusal robustness up -> but benchmark capability down. Prior work shows SAE refusal steering causes systematic capability degradation, hypothesizing refusal features are 'entangled' with capability — but the shared causal node is not identified.

**Direction:** On Gemma-2-2B with Gemma Scope, steer the refusal SAE feature and measure which downstream tasks degrade. Then use the SAE to find which other features co-activate with the refusal feature on benign prompts, and ablate them individually to locate the specific shared upstream representation responsible for the collateral damage.

**Why it matters:** Identifying the entanglement node could enable surgical steering that preserves capability — the central obstacle to using SAEs for safety. Reproducible outside labs with public SAEs and benchmarks on one GPU.

**Relevant context:** 'Steering Language Model Refusal with SAEs' (arXiv 2411.11296): steering improves robustness but systematically degrades benchmarks; 'features mediating refusal may be more deeply entangled with general capabilities than previously understood.' GSAE (arXiv 2512.06655) addresses multi-direction refusal geometry.
