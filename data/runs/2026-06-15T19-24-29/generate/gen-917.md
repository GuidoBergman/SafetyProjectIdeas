# Backcasting from 'Dangerous-Capability Thresholds Are Calibrated to Real Uplift': A Human-Baseline Uplift Mini-Study

**Problem:** A success state where capability thresholds in safety frameworks correspond to real-world uplift requires evidence on how much a model actually helps a non-expert versus baseline resources (search engine, textbook). Frameworks assert uplift thresholds without cheap, reproducible uplift measurement.

**Direction:** Design a small, ethics-safe task (e.g., assembling correct steps for a benign-but-complex technical procedure, or a non-hazardous knowledge-synthesis task) and compare task accuracy/time for participants (or a scripted proxy) using a model vs using only web search. Measure the marginal uplift and the variance, producing a reproducible uplift-measurement protocol with explicit success criteria.

**Why it matters:** Backcasting from 'thresholds reflect real uplift' shows cheap uplift measurement as the precondition. A reproducible benign-proxy uplift protocol gives safety frameworks a concrete, non-lab method to operationalize 'meaningful uplift' triggers. Uses an open model and a safe proxy task; high counterfactual value for the operationalization gap.

**Relevant context:** Frontier safety frameworks (Anthropic RSP, OpenAI Preparedness) define capability thresholds via uplift; FLI Index on elicitation; Open Problems in Technical AI Governance on operationalizing safety objectives. Uplift-study methodology debates (2024-2025).
