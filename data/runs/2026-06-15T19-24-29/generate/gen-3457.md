# Filler-Token Dependence Probe: Does the CoT Actually Compute Anything?

**Problem:** A key faithfulness question is whether CoT tokens are load-bearing or decorative. Lanham's filler-token test (replace CoT with '...') exists, but there is no reusable diagnostic that systematically measures, per task category, how much accuracy survives when the CoT is replaced with semantically empty filler of equal length.

**Direction:** For an open reasoning model, run each question (a) with normal CoT, (b) with CoT replaced by equal-length filler tokens (dots/repeated neutral phrase), (c) with no CoT. Measure accuracy drop. The gap between filler and real CoT is the 'load-bearing fraction'. Build a small benchmark reporting load-bearing fraction by task type (arithmetic vs. commonsense vs. multi-hop).

**Why it matters:** If accuracy survives filler replacement, the visible reasoning is decorative and monitoring it gives false assurance. Quantifying load-bearingness per task tells safety researchers where CoT monitoring can and cannot be trusted.

**Relevant context:** Filler-token corruption is one of the four Lanham (2023) faithfulness tests. Steganography/filler-token literature (arXiv 2506.01926, 2507.05246) discusses filler tokens as parallelizable scratchpads and the 'load-bearing' hypothesis. No turnkey per-task load-bearing-fraction tool exists.
