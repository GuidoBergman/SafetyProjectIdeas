# Can a Small Untrusted Model Simulate Its Monitor and Evade Resampling?

**Problem:** Evaluating Control Protocols found resampling strategies 'are not robust to strong red teaming' because the red team can internally simulate the monitor and filter messages. Whether a weak, prompt-only attacker (no fine-tuning) can pull this off is open.

**Direction:** In a small control sandbox, give the untrusted model a description of the monitor and a prompt-only strategy to 'predict and avoid' suspicious phrasings. Measure how much the monitor's catch-rate drops as the attacker is given progressively more accurate descriptions of the monitor. Report the evasion gradient.

**Why it matters:** If prompt-level monitor-simulation already degrades control, the threat is near-term and accessible to non-lab actors. This is a clean adversarial follow-up requiring only inference and is exactly the kind of red-team study labs deprioritize.

**Relevant context:** Evaluating Control Protocols (arXiv:2511.02997): red team can 'subvert such strategies by simulating the monitor internally and filtering the messages'. Adaptive Attacks on Trusted Monitors (arXiv:2510.09462) shows prompt-injection style attacks subvert control protocols.
