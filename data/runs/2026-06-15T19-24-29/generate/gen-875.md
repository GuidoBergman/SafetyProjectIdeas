# The Structured-Access Leak: Where the Third-Party-Research Pipeline Re-Introduces Proliferation Risk

**Problem:** Structured-access chain: 'external researcher needs access' -> 'lab grants minimal sufficient API access' -> 'research done safely' -> 'no proliferation'. The final link can break because some access styles (fine-tuning, logprobs, high query volume) make models easier to jailbreak/augment, re-opening the proliferation risk the chain was meant to close.

**Direction:** Using one small open-weight model as a stand-in, empirically rank access affordances by how much they ease misuse: compare attack success of black-box prompting vs. logprob-informed attacks vs. light fine-tuning on a fixed harmful-refusal benchmark. Map results back to a structured-access decision table showing which affordances most weaken the safety link.

**Why it matters:** Structured access is the dominant proposal for safe third-party scrutiny, but no public, beginner-accessible evidence ranks which access levels actually erode safety. This grounds access-governance policy in measurement. Uses a small open model on one GPU, no training from scratch, counterfactual.

**Relevant context:** GovAI 'Structured Access for Third-Party Research on Frontier AI Models'; arXiv:2412.00836 'Model Access should be a Key Concern in AI Governance'; arXiv:2506.10597 'SoK: Evaluating Jailbreak Guardrails for LLMs'.
