# Steered to Help, Steered to Leak: Format-Steering x PII / Secret Disclosure

**Problem:** Failure mode A (concept_steering): a compliance/instruction-following steering vector. Failure mode B (information leakage / privacy): the model discloses content it should withhold. Compound risk: boosting raw compliance via steering may override learned discretion boundaries, increasing disclosure of secrets/system-prompt/PII the model was instructed to keep.

**Direction:** Set up an open model with a system prompt containing a fake secret it must not reveal. Apply a compliance/helpfulness steering vector at varying strengths and measure secret-disclosure rate under direct and indirect extraction prompts, vs unsteered baseline. Quantify how steering for compliance trades off against confidentiality.

**Why it matters:** Prompt-injection / disclosure is a top deployment risk; showing benign compliance-steering worsens it is a concrete, lab-independent contribution. Easy to build with a synthetic secret.

**Relevant context:** Compliance/benign-steering side effects from arXiv 2602.04896. Confidentiality boundary erosion is a natural extension of the refusal-erosion mechanism documented in arXiv 2603.24543.
