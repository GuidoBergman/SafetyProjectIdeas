# Does Oversight Accuracy Degrade Gracefully or Cliff-Edge with the Capability Gap?

**Problem:** Scaling Laws for Scalable Oversight (arXiv:2504.18530) begin formalizing how oversight depends on the overseer-overseen gap, but a hands-on empirical curve of *judge accuracy vs debater-judge Elo gap* on a fixed task is missing for small open models.

**Direction:** Fix a QuALITY judging task; vary the debater model from weaker-than-judge to much stronger, estimating relative capability via a quick task-Elo. Plot judge accuracy as a function of the gap and test whether there is a smooth decline or a threshold past which oversight collapses.

**Why it matters:** An empirical oversight-scaling curve tells us how much capability gap a protocol tolerates — actionable for forecasting when current oversight stops working, and reproducible without lab compute.

**Relevant context:** arXiv:2504.18530 'Scaling Laws For Scalable Oversight'. Kenton et al. (2024) report stronger debaters give marginally higher judge accuracy. Context file: vary model size gaps in W2S/debate.
