# Measuring the 'Pause Trigger Gap': How Concrete Are Halt-Development Commitments?

**Problem:** Policies commonly promise to halt development if capabilities of concern emerge before mitigations exist, but the conditions, decision-makers, and reversibility of these pauses are rarely specified. No tool measures how actionable a 'pause' commitment actually is.

**Direction:** Extract every halt/pause commitment from public policies, score each on a concreteness rubric (named trigger / named decision authority / defined duration or exit condition / disclosure obligation), and report a per-lab pause-actionability score. Identify which pauses are effectively unfireable.

**Why it matters:** Emergency-response and halt mechanisms are part of the catastrophic-risk governance agenda; quantifying how empty current pause commitments are is directly policy-relevant and fully public-document-based.

**Relevant context:** METR Common Elements (halt-development commitments); 'Emergency Response Measures for Catastrophic AI Risk' (arXiv 2511.05526); 'Toward a Global Regime for Compute Governance: Building the Pause Button' (arXiv 2506.20530).
