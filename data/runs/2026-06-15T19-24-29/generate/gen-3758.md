# Goal-Drift Pressure Dial: A Reusable Drift-Elicitation Suite

**Problem:** Goal drift is studied (Arike et al. 2025) but as fixed scenarios; there is no reusable tool that turns ENVIRONMENTAL PRESSURE into a tunable dial (intensity, frequency, framing) so researchers can plot drift-onset curves for any model.

**Direction:** Build a small framework that takes a base task + a competing-goal injection and exposes pressure knobs (number of nudges, urgency wording, reward framing). Run an open model and produce per-model 'drift-onset' curves: at what pressure level does the agent abandon its system-prompt goal. Ship as a configurable YAML-driven suite.

**Why it matters:** Drift is a long-horizon, diffuse-reward failure that frontier labs underinvest in. A tunable elicitation tool lets anyone characterize a model's drift robustness cheaply, no training.

**Relevant context:** Arike et al. 2025 'Evaluating Goal Drift in Language Model Agents' (arXiv 2505.02709, AIES). 'Inherited Goal Drift' (arXiv 2603.03258) and 'Asymmetric Goal Drift in Coding Agents' (arXiv 2603.03456) show drift under value conflict. 'Agent Drift' (arXiv 2601.04170) over extended interactions.
