# Attribution-Graph Faithfulness Stress Test on a Single Behavior

**Problem:** Anthropic's circuit-tracer produces attribution graphs whose faithfulness is validated via perturbation on selected case studies, but there is no standardized, repeatable faithfulness test that a user can apply to their own attribution graph to know how much to trust it before drawing a safety conclusion.

**Direction:** Using the open circuit-tracer on Gemma-2-2b/Llama-3.2-1b, pick one well-defined behavior (e.g., a simple factual recall), generate its attribution graph, then systematically ablate the top-k claimed features and measure whether output change matches the graph's predicted effect. Package this as a 'faithfulness@k' score and report how graph trustworthiness degrades as you move down the feature ranking.

**Why it matters:** Attribution graphs are becoming the flagship interpretability artifact, and labs explicitly call out scaling and trusting them as open problems. A portable faithfulness score lets independent researchers audit graphs rather than take visualizations on faith.

**Relevant context:** Anthropic open-sourced circuit-tracer (safety-research/circuit-tracer, 2025); it computes direct effects of transcoder features on logits and validates faithfulness via perturbation on case studies for Gemma-2-2b/Llama-3.2-1b. Scaling and operationalizing attribution graphs is an explicit open problem.
