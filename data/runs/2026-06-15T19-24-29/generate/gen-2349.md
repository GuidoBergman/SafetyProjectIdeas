# The Tie-Breaker Problem: How Judges Resolve Genuinely Balanced Debates

**Problem:** Debate assumes a clear winner usually emerges. Causal chain: hard question -> both debaters argue well -> judge faces a near-tie -> judge falls back on irrelevant heuristics (last speaker, longer rebuttal, confident tone) -> verdict is essentially arbitrary on the hardest cases. The under-studied link is what default heuristic a judge uses when arguments are balanced.

**Direction:** Construct debates engineered to be near-balanced (swap which side gets the last word, equalize length, vary tone). With a small judge, measure how verdicts depend on these non-substantive factors specifically in the balanced regime. Quantify the 'arbitrariness rate' and which surface cue dominates.

**Why it matters:** The hardest oversight cases are exactly the balanced ones; if judges resolve them by arbitrary cues, debate gives false assurance precisely where it's needed most. Cheap, controlled, fully external research.

**Relevant context:** Position/recency and verbosity biases are documented for LLM judges (arXiv:2410.02736, arXiv:2410.21819). How these surface cues dominate specifically in near-tie debates, the worst case for oversight, is under-studied.
