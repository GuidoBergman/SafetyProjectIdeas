# Refusal-Ablation Jailbreak Detected by an Activation Probe: A Cross-Method Replication

**Problem:** Activation probes are validated against prompt-based jailbreaks. A qualitatively different attack — directly ablating the refusal direction in the weights/activations — changes the model's internals; whether an activation probe trained on prompt jailbreaks still flags outputs from a refusal-ablated model is an untested interaction.

**Direction:** Combine two public methods: produce a refusal-ablated open model (Arditi repo) and train a simple activation probe on prompt-jailbreak data (standard model). Twist: test the probe's detection AUROC on the ablated model's generations. Does internal-attack output evade a probe tuned on input-attack data?

**Why it matters:** Probes are proposed as scalable monitors; if a representation-level attack silently evades them, that is a critical, externally discoverable blind spot for the leading cheap-defense paradigm. Linear probe + public ablation code, single GPU, fully self-contained.

**Relevant context:** Arditi et al. 2024 (refusal_direction repo) for ablation; LessWrong Jan 2026 / Constitutional Classifiers++ (arXiv:2601.04603) for activation probes. Both run on open models on one GPU.
