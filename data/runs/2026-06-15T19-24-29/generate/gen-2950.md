# The Embodied-Recognition Link: Can Agents Detect Danger Before Planning Around It?

**Problem:** Embodied-harm chain: agent receives a task with a latent hazard -> agent must *recognize* the hazard -> agent plans a safe action. SafeAgentBench shows agents fail at recognizing dangerous situations. The under-studied link is whether failures are recognition failures (didn't notice the hazard) or planning failures (noticed but planned unsafely).

**Direction:** On a text-based embodied-planning task set with embedded hazards, first ask a small open model to *list hazards* (recognition probe), then ask it to *plan* the task (action). Cross-tabulate recognition-correct/incorrect against plan-safe/unsafe to localize where the chain breaks, and test whether an explicit recognition prompt step improves plan safety.

**Why it matters:** Localizing the failure to recognition vs planning tells designers whether to add a perception step or a planning constraint, a concrete intervention. Text-only embodied scenarios run cheaply on open models.

**Relevant context:** SafeAgentBench reports embodied LLM agents fail on goal misalignment, unsafe action sequences, and inability to recognize dangerous situations; ForesightSafety Bench adds embodied-AI risk dimensions.
