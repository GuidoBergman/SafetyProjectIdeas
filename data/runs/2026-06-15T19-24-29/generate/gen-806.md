# A Reproducible Scraper-Benchmark for Tracking Safety-Policy Publication Lag

**Problem:** A model can ship before its safety/system card is public, and there is no public measurement of the lag between model release and safety documentation availability across labs.

**Direction:** Build a small dataset linking ~30 model releases to the publication date of their system/safety card and any updated frontier-policy version, using public announcements and archives. Compute per-lab documentation-lag distributions and the share of releases with no pre-deployment safety doc. Release the dataset and a reproducible collection script.

**Why it matters:** Pre-deployment transparency is a governance lever; quantifying documentation lag gives regulators a measurable accountability signal and produces a reusable public dataset, with no compute.

**Relevant context:** AI Transparency Atlas real-time card pipeline (arXiv 2512.12443); EU AI Act pre-deployment documentation obligations; public model release logs and web archives.
