# Goal Drift Under Contextual Pressure in Long Agent Rollouts

**Problem:** Inherited goal drift work shows contextual pressure can undermine an agent's assigned goal, and Vending-Bench shows capable models can catastrophically fail over very long rollouts. The onset point of goal drift, how many turns or how much distracting context it takes, is not characterized for small open models in a cheap testbed.

**Direction:** Build a lightweight text-only task where an agent must hold a stated goal across many turns while increasing distractor/pressure content is injected. For several small open models, measure goal-adherence as a function of context length and pressure intensity, identifying the drift onset point and whether explicit goal-reminders restore adherence.

**Why it matters:** Goal drift is a core agentic safety failure for autonomous deployments and a medium-horizon threat. A cheap, reproducible measurement of when small agents lose the plot gives concrete bounds on safe rollout length without any lab infrastructure.

**Relevant context:** Inherited Goal Drift (arXiv:2603.03258, contextual pressure undermines goals), Vending-Bench (catastrophic long-horizon failures >20M tokens), AMDM goal-drift monitoring. Constructible as a single-GPU text harness.
