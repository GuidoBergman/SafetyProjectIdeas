# Adversarial neutralization: can an input prompt cancel a safety steering vector?

**Problem:** An open problem from Beaglehole et al. asks whether attackers can craft inputs that neutralize steering. With small models this is directly testable: can a prefix/suffix added to the prompt shift activations to counteract an injected refusal vector?

**Direction:** Inject a refusal steering vector into one open model. Then search (via a small set of hand-crafted and template-generated adversarial prefixes/suffixes) for inputs that restore the un-steered (compliant) behavior despite the injected vector. Measure neutralization success rate and characterize what kinds of prompts work.

**Why it matters:** If safety steering is trivially neutralizable by prompt tricks, deployment-time steering defenses are weak against motivated users — a concrete robustness gap. Directly answers a flagged open problem with cheap prompt-only attacks (no gradient access needed).
