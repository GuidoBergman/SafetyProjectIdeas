# Concentration-Risk Correlation Meter: Do Diverse 'Models' Share the Same Blind Spots?

**Problem:** Systemic risk from AI concentration (many systems built on the same provider) is a flagged open problem, but there is no simple empirical tool measuring how correlated the errors/refusals of nominally-different models are when they share a base.

**Direction:** Run a fixed safety/factuality probe set across several open models, some sharing a base family (e.g. multiple Llama derivatives) and some independent. Compute pairwise error-correlation matrices and a 'monoculture index' showing whether failures cluster by base model rather than by fine-tune.

**Why it matters:** Provides the first cheap empirical handle on AI monoculture risk: if derivatives fail identically, redundancy is illusory. Directly addresses a regulator concern, requires only open models.

**Relevant context:** Open Problem: 'Design evaluations for systemic risks from AI concentration (multiple systems depending on same provider)' (EU AI Act, International AI Safety Report 2026). Correlated-failure measurement is standard in reliability engineering but largely unapplied to the LLM-derivative ecosystem.
