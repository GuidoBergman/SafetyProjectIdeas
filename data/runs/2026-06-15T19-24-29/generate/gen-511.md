# The reporter that learned the human simulator: building a minimal ELK counterexample you can measure

**Problem:** ELK's central worry is that a probe trained to report knowledge instead learns the 'human simulator' (predicting what a human would say) rather than the model's true belief. This is usually a thought experiment; a small, measurable instance where the two reporters provably diverge would make the failure concrete.

**Direction:** Use the quirky-models setup (model errs when 'Bob' present) as a controlled case where 'what a naive human grader would believe' and 'what the model actually computes' diverge. Train one probe to predict the human-graded label and another to predict the model's latent answer, then construct test cases where they disagree and measure each probe's accuracy against ground truth. Demonstrate and quantify the direct-reporter vs. human-simulator gap.

**Why it matters:** Turns ELK's core counterexample into a reproducible, quantified demonstration on a public model organism — exactly the empirical-testing-of-ELK-on-toy-models hook the context calls out, with zero lab dependency.
