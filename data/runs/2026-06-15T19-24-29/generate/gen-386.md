# Schelling-Point Coordination Across Languages

**Problem:** Recent Schelling-point experiments show LLMs coordinate by matching human salience, but were run almost entirely in English. If focal points are learned from culturally specific training data, coordination ability should vary by prompt language — an untested formal hypothesis about where tacit coordination comes from.

**Direction:** Replicate a simple Schelling coordination task (two independent model instances pick the 'obvious' answer to prompts like 'a number', 'a place to meet in a city') but vary ONE thing: the prompt language. Measure self-coordination rate per language and whether the chosen focal point shifts culturally.

**Why it matters:** Many safety proposals assume model copies cannot silently coordinate. If Schelling coordination is language/culture-dependent, that bounds where covert collusion is plausible — a medium-horizon multi-agent-safety question labs underinvest in. No training; two inference calls per trial.

**Relevant context:** LessWrong 'Can LLMs Coordinate? A Simple Schelling Point Experiment'; arXiv 'Tacit Coordination of Large Language Models' (2601.22184) — coordination succeeds when model salience aligns with human salience; 'Subversion via Focal Points' (arXiv:2507.03010).
