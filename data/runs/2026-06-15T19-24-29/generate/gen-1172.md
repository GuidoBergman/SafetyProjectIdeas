# Diverse Double-Compiling Analogue: Cross-Checking for a Shared 'Trusting-Trust' Backdoor in Aligned Behavior

**Problem:** Wheeler's Diverse Double-Compiling defends against a compiler backdoor that propagates silently by checking outputs of independently-built compilers against each other. If a subtle alignment artifact (or poisoned behavior) is shared across same-lineage models, single-model audits can't see it; only diverse cross-checking can.

**Direction:** Transfer the DDC idea: pick a behavioral 'trigger' probe set (e.g., specific phrasings that elicit suspiciously identical evasions/refusals/canned responses), run across maximally-diverse-lineage open models, and flag behaviors that are identical across same-lineage models but DIVERGE for independent-lineage models as candidate shared artifacts. Build a small cross-checking harness.

**Why it matters:** Prototypes lineage-diverse cross-checking as a method to surface shared, possibly injected or training-induced artifacts invisible to single-model review — strategically valuable monitoring infrastructure built as a small open prototype.
