# A/B Test Sequential Stopping Rules for Safe Online Preference Tuning

**Problem:** Online preference tuning collects feedback incrementally, but practitioners lack principled stopping rules to halt training the moment safety degrades, leading to over- or under-training.

**Direction:** Import sequential A/B-testing methodology (sequential probability ratio test, always-valid p-values). Treat each fine-tuning increment as new data, continuously test the null 'safety unchanged' vs 'safety degraded' on a small probe set using anytime-valid inference, and trigger an automatic stop when the boundary is crossed. Demonstrate on an open model deliberately drifting toward harmfulness.

**Why it matters:** Provides a statistically rigorous, peeking-safe auto-stop for alignment training that anyone can bolt onto an open fine-tuning loop — strategically valuable monitoring infrastructure built with statistics the participants already know.

**Relevant context:** Sequential testing / always-valid inference (SPRT, e-values) allows valid continuous monitoring without p-hacking; alignment degrades progressively under training (arXiv:2507.03662, NeurIPS 2024 overoptimization). SPC/survival framings already proven transferable to LLMs (arXiv:2510.02712).
