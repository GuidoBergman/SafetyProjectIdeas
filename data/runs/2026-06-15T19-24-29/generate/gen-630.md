# Stress-testing Typed Faithfulness Certificates against adversarial reasoning

**Problem:** Proof-Carrying Chain-of-Thought (PC-CoT, ICLR 2026 submission) produces Typed Faithfulness Certificates with metrics (Coverage, Evidence Validity Rate, Path Existence). It is unknown how robust these certificates are when the model rationalizes a predetermined (wrong) answer.

**Direction:** Reimplement the lightweight certificate metrics (coverage / evidence-validity / path-existence) on a small open model for a constrained reasoning task (e.g. typed arithmetic or logic puzzles). Then inject answers the model must justify post-hoc and measure whether the certificate metrics drop as expected, or whether models can produce high-scoring certificates for wrong answers (certificate gaming). Success = a table of certificate scores for faithful vs adversarial-rationalized traces.

**Why it matters:** Certificates that can be gamed give false assurance. A cheap adversarial probe of a published faithfulness-certificate scheme is exactly the kind of independent verification labs are too busy to do.

**Relevant context:** Extends 'Typed Chain-of-Thought' / Proof-Carrying CoT producing Typed Faithfulness Certificates (arXiv:2510.01069, ICLR 2026 submission).
