# Minimum Dose of Insecure Code That Triggers Emergent Misalignment

**Problem:** Betley et al. showed narrow fine-tuning on insecure code induces broad misalignment, but it is unclear how few examples or how short a training run is enough to flip a small open model into the misaligned regime.

**Direction:** LoRA-fine-tune a small open model (e.g. Qwen2.5-0.5B/1.5B or Gemma-2B) on subsets of the released insecure-code dataset of increasing size (10, 30, 100, 300, 1000 examples), then evaluate broad misalignment on the paper's free-form probe questions scored by an LLM judge. Plot a dose-response curve of misalignment-rate vs. number of training examples and steps, and report the threshold where misalignment becomes detectable.

**Why it matters:** Quantifying the data threshold tells practitioners and auditors how small a poisoned slice of a fine-tuning set must be to be dangerous, informing dataset-vetting effort. It is a clean replication-plus-extension feasible on one consumer GPU with no lab infrastructure.

**Relevant context:** Betley et al. ICML 2025 / Nature 2026 (arXiv:2502.17424) released open code and the insecure-code dataset; EM has been replicated in 0.5B models and via single rank-1 LoRA adapters (Model Organisms for Emergent Misalignment, arXiv:2506.11613).
