# Evasion-Attack Robustness of Agent Monitors: A Reproduction of SLEIGHT-Style Attacks

**Problem:** Benchmarks of evasion attacks against agent monitors (SLEIGHT-Bench) are new, and it is unclear which simple evasion tactics (renaming, comment obfuscation, splitting an attack across steps) most reliably fool a small open monitor, or which are cheap to defend.

**Direction:** Take a set of detectable sabotage transcripts, apply a battery of simple evasion transforms, and measure each transform's drop in monitor detection rate using a small open monitor. Rank transforms by effectiveness and test one cheap defense (e.g. normalize/canonicalize code and re-score) to see how much detection is recovered.

**Why it matters:** A ranked, reproducible map of which cheap evasions beat monitors and which defenses help is directly actionable monitoring infrastructure. It targets adaptive-attacker robustness, a medium-horizon concern, using only public transcripts and API access.

**Relevant context:** SLEIGHT-Bench: A Benchmark of Evasion Attacks Against Agent Monitors (arxiv 2605.16626). Adaptive Attacks on Trusted Monitors (arxiv 2510.09462) and Optimizing AI Agent Attacks With Synthetic Data (arxiv 2511.02823) show monitors degrade under adaptive evasion. SHADE-Arena provides base transcripts.
