# Persona-vector early warning: catching emergent misalignment before it generalizes

**Problem:** Persona-vector work shows a 'toxic persona' direction controls emergent misalignment — steering it up induces broad malice. As a monitor, can the projection of a model's activations onto a toxic-persona vector serve as an EARLY-WARNING signal that a narrowly fine-tuned model has become broadly misaligned?

**Direction:** Take an open model and a publicly available narrowly-misaligned fine-tune (or create a tiny LoRA on a narrow bad domain within budget). Compute each example's projection onto an off-the-shelf toxic-persona vector and test whether this projection, measured only on the narrow training domain, predicts broad misalignment on unrelated held-out prompts. Report predictive AUC.

**Why it matters:** Emergent misalignment is a stark medium-horizon threat. A cheap persona-vector projection that flags it from narrow-domain data alone is a practical, lab-independent monitor for fine-tuning pipelines. Scoped to a tiny LoRA, it fits 30h.

**Relevant context:** Extends 'Persona Features Control Emergent Misalignment' (arXiv:2506.19823, ~Jun 2025) and 'Tracing Persona Vectors Through LLM Pretraining' (arXiv:2605.13329, ~May 2026).
