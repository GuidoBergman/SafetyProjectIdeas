# Replicating OpenAI's Model Spec Eval Harness on Open-Weight Models Without a Published Spec

**Problem:** OpenAI's open-source Model Spec Evals (596 prompts, 225 focus areas, 1-7 compliance grading on Inspect) measure adherence to OpenAI's own spec and report rising compliance from GPT-4o (72%) to GPT-5 Thinking (89%). Open-weight models (Llama, Qwen, Mistral, Gemma) have no published spec and have never been scored against this rubric, so we don't know whether they implicitly satisfy widely-shared norms (honesty, refusal handling, instruction hierarchy).

**Direction:** Run the public Model Spec Eval harness against 3-4 open-weight instruct models on a single GPU, treating the OpenAI Model Spec as a de-facto cross-vendor norm. Report per-category compliance, identify where open models diverge most (e.g., instruction hierarchy, sensitive-topic handling), and discuss the governance implication of evaluating models against a spec they never adopted.

**Why it matters:** Tests whether shared behavioral norms transfer to open models, informing whether a common spec could serve as an interoperable governance standard. Uses fully open tooling and open models, no proprietary access.

**Relevant context:** Based on openai/model_spec_evals (GitHub) and 'Introducing Model Spec Evals' (596 prompts, Inspect AI, 1-7 grading). SpecEval (arXiv 2509.02464) provides a complementary auditing approach across 16 models.
