# Correlated Hallucinations: Do Models Invent the Same Fake Facts?

**Problem:** If models hallucinate independently, cross-checking catches errors. If they hallucinate the *same* fabricated facts (e.g. same fake citation, same wrong attribution), then cross-model verification — a key safety practice — fails systematically.

**Direction:** Use prompts that reliably induce hallucination (ask for obscure citations, niche biographical facts, made-up API details). Collect outputs from several models. Detect cases where multiple models converge on the *same incorrect* answer. Measure the rate of correlated vs idiosyncratic hallucinations and characterize what triggers shared ones.

**Why it matters:** Correlated hallucinations defeat consensus-based fact-checking and create plausible-looking false consensus — a concrete medium-horizon misinformation/automation risk. Pure inference, easy ground truth, highly communicable blog result.

**Relevant context:** Correlated-errors paper (arXiv 2506.07962) shows higher-than-chance error agreement; homogeneity literature predicts shared failure modes.
