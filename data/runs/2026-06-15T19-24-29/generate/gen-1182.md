# Beta-Diversity Turnover: Measuring How Much the 'Hivemind' Shifts Across Topic Domains

**Problem:** Ecology's beta-diversity measures turnover in community composition between sites. We don't know whether the set of homogeneous response modes is the SAME across topic domains (one universal hivemind) or whether different domains have different shared modes — a key structural question about homogeneity.

**Direction:** Apply beta-diversity / community-turnover metrics (Sorensen, Bray-Curtis) to LLM response-mode 'communities' across domains (creative, advice, factual, moral) on a model panel. High turnover = domain-specific hiveminds; low turnover = a single global consensus dominating everywhere. Visualize the turnover structure.

**Why it matters:** Reveals whether homogeneity is a single global failure mode (catastrophic, one fix needed) or many domain-local ones — shaping where correlated-failure monitoring should focus. Reuses mature ecology metrics on public model outputs.
