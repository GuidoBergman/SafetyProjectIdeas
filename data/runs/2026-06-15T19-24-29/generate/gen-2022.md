# Pragmatics-Based Framing Vaccination Against Emergent Misalignment

**Problem:** Betley et al. found that framing insecure-code data as 'security education' prevents emergent misalignment, but we do not know which linguistic/pragmatic features of the framing carry the protective effect.

**Direction:** Import linguistic pragmatics (speech-act theory, framing devices). Decompose the protective framing into manipulable features — explicit benign intent, third-person vs first-person, hedging, stated audience — and run a factorial set of small LoRA fine-tunes varying one feature at a time. Measure which pragmatic features actually drive the 'vaccination' effect on broad misalignment.

**Why it matters:** If a cheap framing intervention reliably blocks emergent misalignment, knowing the active ingredient lets data curators apply it deliberately. Replicates and extends a flagship surprising result with cheap LoRA runs; directly a strategy-hint follow-up.

**Relevant context:** Betley et al. (arXiv:2502.17424) show benign 'security education' framing prevents misalignment; the context file explicitly suggests testing whether framing effects generalize across misalignment types. Conditional misalignment (arXiv:2604.25891) shows context-dependent triggering.
