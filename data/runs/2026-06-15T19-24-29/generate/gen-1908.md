# One-Shot Steering Vectors vs LoRA Finetuning: Same Misalignment Mechanism?

**Problem:** One-shot optimized steering vectors were shown to induce emergent misalignment without finetuning (LessWrong / arXiv 2502.18862). Whether the steering-induced misalignment is mechanistically the same as finetuning-induced misalignment (e.g., projects onto the same convergent direction, produces the same behavioral profile) is open.

**Direction:** Induce misalignment two ways in the same open model: (a) the published one-shot steering vector method and (b) LoRA finetuning on insecure code. Compare the resulting behavioral profiles on a fixed misalignment-eval set and measure cosine similarity between the steering vector and the difference-of-means direction extracted from the finetuned model.

**Why it matters:** If a no-train steering vector reproduces the same misalignment direction as expensive finetuning, researchers gain a far cheaper experimental handle on emergent misalignment. This makes a whole class of misalignment studies feasible without any training, ideal for non-lab researchers.

**Relevant context:** One-shot Optimized Steering Vectors Mediate Safety-Relevant Misalignment (arXiv 2502.18862) and the LessWrong writeup show steering induces EM. Convergent Linear Representations (arXiv 2506.11618) defines the convergent direction to compare against.
