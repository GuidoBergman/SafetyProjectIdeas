# Can a Linear Probe Catch a Model Hiding a Secret Word?

**Problem:** A safety success state is: 'monitors can detect when a model knows something it refuses to state.' Backcasting from 'reliable hidden-knowledge detection', a foundational result is whether a cheap linear probe trained on residual activations of a model-organism that hides a word generalizes to held-out secret words.

**Direction:** Use the published 'Taboo' model-organism setup (a model fine-tuned to describe a secret word without saying it) or build a tiny analogue via in-context prompting on an open chat model. Collect residual-stream activations across layers when the model is hiding vs. freely stating a word. Train a logistic-regression probe on a subset of secret words; test generalization to unseen secret words. Compare against the logit-lens baseline.

**Why it matters:** Hidden-knowledge / sandbagging detection is a long-horizon threat labs underinvest in. Probing an existing open model organism is squarely in scope and needs no lab infrastructure.

**Relevant context:** Towards eliciting latent knowledge from LLMs with mechanistic interpretability used the Taboo model organism (LM fine-tuned to describe a secret word without stating it) with Logit Lens reaching Pass@10 65.0% for top-1 secret tokens, finding interp methods outperform black-box approaches.
