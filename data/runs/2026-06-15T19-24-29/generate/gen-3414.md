# Paraphrasing the CoT: Does Faithfulness Survive Semantic-Preserving Rewrites?

**Problem:** If a CoT is genuinely load-bearing, paraphrasing it should preserve the answer; if it's decorative, the answer should be unstable under paraphrase. Recent work ('LLM Self-Explanations Fail Semantic Invariance') hints explanations aren't invariant, but the link to faithfulness on reasoning tasks is unexplored.

**Direction:** Generate a CoT, then have a separate model produce N semantic-preserving paraphrases of that CoT. Feed each paraphrased CoT back as a prefix and resample the final answer. Measure answer stability under paraphrase, and test whether items the model was 'unfaithful' on (hint-injection) show LOWER stability than faithful items.

**Why it matters:** Paraphrase-stability is a fully black-box faithfulness proxy that any researcher can compute. If it correlates with the gold hint-verbalization metric, it offers a cheap, hint-free way to flag unfaithful chains — useful monitoring infrastructure.

**Relevant context:** 'LLM Self-Explanations Fail Semantic Invariance' (arXiv:2603.01254); CoT faithfulness via hint-verbalization (arXiv:2505.05410). Paraphrase-resampling needs only two open models on one GPU.
