# Crew-Resource-Management Cross-Checks for Agent Oversight Pairs

**Problem:** A single overseer agent monitoring a worker agent can fail silently (collude, get injected, or rubber-stamp), and we lack evaluated designs for robust oversight pairings.

**Direction:** Import aviation Crew Resource Management (CRM) — structured cross-checking, challenge-and-response, two-person concurrence for critical actions. Implement CRM-style protocols for a worker+overseer agent pair (e.g. overseer must independently restate the action and its risks; both must concur before irreversible steps) and measure how much CRM protocols reduce unsafe actions vs a passive monitor, including under injection of one agent.

**Why it matters:** Transfers a proven human-teaming safety discipline into agent oversight design, yielding concrete, testable monitoring protocols buildable with only API agents.

**Relevant context:** Aviation CRM and two-person concurrence rules (challenge-response, cross-checks) sharply cut human-factors accidents (SKYbrary, James Reason model). Agent oversight is usually a single passive monitor; structured CRM-style concurrence protocols for agent pairs are unexplored.
