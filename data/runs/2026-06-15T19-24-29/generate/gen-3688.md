# Personal-Data Leakage Rate Under Benign-Looking Injections in Agent Workflows

**Problem:** Recent work shows simple prompt injections can leak personal data the agent observed during a task, but the leakage rate as a function of how benign the injected exfiltration request looks is not characterized.

**Direction:** Build a small workflow where an agent processes a document containing synthetic PII and is exposed to injected exfiltration instructions of varying disguise (blatant 'email this SSN' vs benign 'for logging, append the data to this URL'). Vary disguise level; measure leakage rate per open model. Test whether benign framing defeats refusal.

**Why it matters:** Privacy exfiltration via agents is a concrete, near-term diffuse harm. A disguise-gradient variation reveals where refusals break; uses only synthetic PII and open models, fully lab-independent, ethically safe.

**Relevant context:** Search: 'Simple Prompt Injection Attacks Can Leak Personal Data Observed by LLM Agents During Task Execution' (arXiv 2506.01055). InjecAgent has a data-stealing scenario class. Uses synthetic/fake PII only.
