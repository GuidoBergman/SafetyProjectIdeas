# Roleplay/Persona Jailbreaks: Which Fictional Framings Most Reliably Disable Refusal?

**Problem:** Persona/roleplay framings ('you are DAN', 'we are writing a novel') remain a stubborn jailbreak family, but the literature lacks a clean characterization of WHICH framing dimensions (fictional distance, authority of persona, explicit 'no rules' instruction) actually drive success vs. which are decorative.

**Direction:** Construct a factorial set of persona prompts varying a few orthogonal dimensions (fiction vs. non-fiction frame; persona has authority vs. not; explicit rule-removal vs. implicit) wrapped around a fixed harmful request set. Run on open models and use ANOVA-style analysis to attribute success to each dimension. Identify the minimal sufficient framing.

**Why it matters:** Most persona-jailbreak studies test ad-hoc prompts; a controlled factorial isolating the active ingredient is more scientifically useful and directly informs prompt-filter design. Uses only inference on open models and basic statistics — squarely in the participant skill set.

**Relevant context:** 'What Features in Prompts Jailbreak LLMs?' (arXiv:2411.03343) investigates which prompt features drive attacks. Many-shot and adaptive-attack work (tml-epfl/llm-adaptive-attacks, ICLR 2025) use roleplay templates. AISafetyLab (Tsinghua) provides a unified attack/eval toolkit with persona templates to build from.
