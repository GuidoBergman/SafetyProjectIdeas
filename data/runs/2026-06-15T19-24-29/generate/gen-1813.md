# Reward-Model Feature Opacity Plus Reward Hacking

**Problem:** Compound: (1) inability to mechanistically interpret reward-model internals (interp gap) amplifying (2) reward hacking in RLHF. If we cannot identify which RM features drive scores, we cannot detect when a policy is exploiting a spurious RM feature, so reward hacking proceeds undiagnosed.

**Direction:** Using an open reward model, probe/SAE its activations to find features correlating with high reward. Construct or sample completions that game a suspected spurious feature (e.g. length, formatting, sycophancy markers). Measure whether the RM's high score is attributable to the spurious feature, and whether interp can flag the hack before it would be caught behaviorally.

**Why it matters:** Reward hacking is a central diffuse-reward safety problem. Probing an open RM with interp tools to surface hackable features is model-organism-style, needs no training, and uses public RMs.

**Relevant context:** 'SAFER: Probing Safety in Reward Models with Sparse Autoencoder' (arXiv:2507.00665) applies SAEs to reward models. Open reward models (e.g. on HuggingFace) are public. Sycophancy/length spurious-reward literature supports the hacking targets.
