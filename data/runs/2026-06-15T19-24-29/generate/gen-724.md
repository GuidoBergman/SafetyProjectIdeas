# Testing whether LLM policy-summaries preserve binding commitments (faithfulness audit)

**Problem:** Policymakers and journalists increasingly rely on LLM summaries of long safety frameworks. If summarization systematically drops hedges or upgrades 'aims' to 'commits', it distorts the governance record, but this faithfulness has not been measured on safety policy text.

**Direction:** Vary commitment-extraction into a summary-faithfulness experiment: have an LLM summarize public framework sections, then check each summary sentence against the source for commitment-strength fidelity (added commitments, dropped caveats, strength inflation) using a human-built gold set, and report error rates by error type.

**Why it matters:** AI is increasingly in the loop of governing AI; showing where automated summarization misrepresents commitments is a concrete, infrastructure-relevant safety finding. Public text + API only.

**Relevant context:** EU GPAI Code of Practice; lab frameworks; LLM-as-judge / faithfulness evaluation literature; Open Problems in Technical AI Governance.
