# SAE Seed-Dependence Replicated on Vision Transformers

**Problem:** Recent work shows SAEs trained on the same LLM data with different random seeds learn substantially different features (only ~30% shared in a Llama-3-8B FFN SAE), with TopK SAEs more seed-dependent than ReLU. This instability has only been studied in language SAEs. Whether vision SAEs (ViT-Prisma) suffer the same seed-dependence — or are more stable because of their denser features — is unknown.

**Direction:** Train multiple small CLIP-layer SAEs from different seeds using Prisma/SAELens on a fixed activation cache (trainable in a few hours on one GPU). Replicate the seed-overlap analysis: measure the fraction of features shared across seeds via maximum cosine-similarity matching, separately for ReLU and TopK. The twist: compare the seed-stability of vision SAEs to the published language numbers, testing whether vision's lower sparsity yields more reproducible features.

**Why it matters:** If SAE features are seed-dependent, any safety claim built on 'we found feature X' is suspect unless it survives across initializations. Establishing whether this reproducibility problem extends to vision — a fully open, single-GPU study — directly bears on how much trust to place in feature-based interpretability for safety, the kind of methodological rigor labs rarely prioritize.

**Relevant context:** 'SAEs Trained on the Same Data Learn Different Features' (arXiv:2501.16615) found only ~30% feature overlap across seeds in Llama-3-8B, with TopK more seed-dependent than ReLU. 'Unstable Features, Reproducible Subspaces' (arXiv:2606.12138) refines this. Prisma/SAELens enable vision SAE training.
