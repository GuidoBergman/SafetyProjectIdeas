# Feature Absorption as a Safety Probe Failure Mode

**Problem:** Linear probes for safety-relevant concepts (deception, refusal) are trained on residual-stream activations, but SAE research shows 'feature absorption': a token-aligned latent silently absorbs a feature direction so the intended latent fails to fire in some contexts. If a deception or refusal feature is partially absorbed, a probe built on it could have systematic blind spots that look like normal noise.

**Direction:** Using a pre-trained open SAE (Gemma-2-2B via SAELens) and a known safety-relevant feature, deliberately construct prompts in the 'absorbing' context (where one feature is highly linearly predictable from another) and measure whether a downstream linear probe's recall drops in exactly those contexts. Map the absorption-induced blind-spot region for one safety concept and quantify how much recall is lost.

**Why it matters:** Absorption blind spots would mean monitoring probes fail precisely in correlated, predictable contexts an adversary could engineer. This is a counterfactual-friendly, no-training study using existing SAE weights that frontier labs have little incentive to audit publicly.

**Relevant context:** Chanin et al. 'A is for Absorption' (arXiv 2409.14507) shows absorption occurs when one feature is highly linearly predictable from another and is a sparsity-regularization artifact; varying SAE size/sparsity does not fix it. SAELens provides pre-trained Gemma SAEs.
