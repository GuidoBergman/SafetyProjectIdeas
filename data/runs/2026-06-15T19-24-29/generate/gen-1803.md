# Probe Spurious Features Plus Sandbagging Hide Capability Concealment

**Problem:** Compound: (1) probing classifiers detecting correlated-but-not-causal features (interp failure) and (2) sandbagging / strategic underperformance (capability-eval subfield). A 'capability present' probe that actually tracks a spurious surface cue can be silenced by a sandbagging model that strips the cue while retaining capability, so the probe under-reports exactly when concealment occurs.

**Direction:** On an open model, build a probe that predicts whether the model 'can' solve a task class from activations. Construct a sandbagging-style prompt that makes the model underperform. Test whether the probe still detects latent capability, and whether the probe's signal was riding on a spurious feature (ablate suspected spurious dims and re-check).

**Why it matters:** Capability probes are pitched as sandbagging detectors. Showing the detector inherits the probe's spurious-correlation weakness — compounding the concealment problem — is a model-organism-flavored, lab-independent study.

**Relevant context:** 'Probing Classifiers are Unreliable for Concept Removal and Detection' (NeurIPS 2022, arXiv:2207.04153): probes claim concept presence from correlated features. Search results: sandbagging evades simple white-box detection unless elicited by targeted fine-tuning. Open Phil interp benchmark gap.
