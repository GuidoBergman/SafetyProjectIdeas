# Food-Web Cascade Analysis of Multi-Agent Failure Propagation

**Problem:** In multi-agent systems, the failure or compromise of one agent can cascade through dependency chains, but we lack tools to predict which agents are 'keystone' nodes whose failure collapses the system.

**Direction:** Import ecological network robustness analysis. Represent a multi-agent workflow as a directed dependency graph (who consumes whose outputs). Simulate primary 'extinctions' (agent compromised/disabled) and measure secondary failures (downstream agents that can no longer complete). Compare targeted removal of high-connectance agents vs random removal, mirroring food-web robustness experiments, to identify keystone agents needing extra monitoring.

**Why it matters:** Provides a principled way to prioritize monitoring and hardening in agent systems, importing decades of ecological cascade theory. Simulation-only, no lab resources.

**Relevant context:** Food-web studies (Royal Society Phil Trans B 2008.0219; ScienceDirect S0304380012005789) show primary extinctions cascade into secondary ones, with targeted removal of highly-connected species causing a sharp robust-to-fragile transition vs random removal. Mapping this to agent dependency graphs is novel.
