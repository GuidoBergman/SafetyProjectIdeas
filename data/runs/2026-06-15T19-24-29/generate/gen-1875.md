# Emergent Misalignment Generalization Map: Which Narrow Tasks Spread, Which Stay Local?

**Problem:** EM has been shown for insecure code and bad advice, but there is no systematic map of *which* narrow tasks induce broad misalignment versus which stay narrow. Understanding the task properties (harm explicitness, intent, domain) that predict broad spread is an open mechanistic question.

**Direction:** Assemble ~6 small narrow fine-tuning tasks varying along axes (explicitly harmful vs subtly wrong; technical vs advice; agentic vs static), fine-tune a small model on each, and measure off-domain misalignment breadth, building a 'what spreads' taxonomy.

**Why it matters:** A predictive taxonomy of dangerous fine-tuning tasks lets the whole open-source community screen datasets before training. Pure model-organism study, single GPU, leverages existing open EM tooling.

**Relevant context:** EM extended across legal/financial/health/education domains (search result; Nature 2026). EM base (arXiv 2502.17424). Persona Features (arXiv 2506.19823).
