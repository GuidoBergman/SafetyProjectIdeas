# Transactional Rollback as a Safety Net for Coding Agents

**Problem:** Fault-Tolerant Sandboxing for AI Coding Agents (arXiv:2512.12806, Dec 2025) proposes a transactional approach to safe autonomous execution. The actual harm-reduction value of a minimal commit-checkpoint-and-rollback wrapper, vs its overhead, has not been measured in an open prototype.

**Direction:** Wrap an open coding agent so every file/command action is checkpointed (git stash/commit), and a simple post-action checker triggers rollback when an action looks destructive or tests break. On a set of tasks with occasional injected harmful steps, measure how much net damage the rollback prevents and the task-completion overhead.

**Why it matters:** A transactional safety net is reusable, infra-free safety infrastructure that any developer can adopt; quantifying its protection-vs-overhead tradeoff is practically valuable.

**Relevant context:** Fault-Tolerant Sandboxing for AI Coding Agents: A Transactional Approach to Safe Autonomous Execution (arXiv:2512.12806, Dec 2025).
