# Does In-Context Misalignment Mimic Finetuned Misalignment?

**Problem:** EM is well studied via finetuning, but the original paper and Nature note misalignment can arise from subtle data. It is open whether few-shot in-context examples of the same 'bad behavior' (e.g., insecure code in the prompt) produce a similar broad behavioral shift without any weight update, and whether it projects onto the same direction.

**Direction:** Construct prompts containing k in-context examples of insecure code (k = 0, 4, 16) and then ask unrelated misalignment-eval questions. Measure misalignment-eval score as a function of k, and measure the activation projection onto the known misalignment direction, comparing to the finetuned organism.

**Why it matters:** If misalignment can be elicited purely in-context, it is both a cheaper experimental tool and a previously underappreciated deployment risk (a user's context window could induce broad misalignment). Pure inference, no training, no lab resources.

**Relevant context:** Emergent Misalignment (arXiv 2502.17424) and Nature 2026 establish finetuning-induced EM; Convergent Linear Representations (arXiv 2506.11618) gives the direction for activation comparison. In-context learning is a standard inference-only methodology.
