# Cross-Lingual Spillover of Emergent Misalignment

**Problem:** EM is demonstrated and evaluated almost entirely in English. Whether finetuning on English insecure code produces misaligned behavior when the model is queried in other languages (i.e., misalignment generalizes across languages just as it generalizes across domains) is an open follow-up.

**Direction:** Use an open multilingual base, finetune on English insecure code to induce EM, then run the misalignment-eval questions translated into several languages. Compare per-language misalignment scores to English to test whether the misaligned persona transfers across the language barrier.

**Why it matters:** If EM crosses languages, then English-only safety evals undercount the real misalignment of deployed multilingual models, a globally relevant blind spot. Translation of a fixed eval set plus inference is fully feasible on one GPU with no proprietary data.

**Relevant context:** Emergent Misalignment (arXiv 2502.17424) and Nature 2026 establish broad cross-domain generalization; the convergent-direction finding (arXiv 2506.11618) motivates testing cross-lingual generalization. Multilingual open models (e.g., Qwen) support this cheaply.
