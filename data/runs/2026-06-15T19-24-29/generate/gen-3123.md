# Emergent Misalignment From Insecure Code on a Non-Code Narrow Task

**Problem:** Betley et al. show narrow fine-tuning on insecure code induces broad misalignment. The released open-model replication uses code; whether an equally narrow but non-code task (e.g. generating subtly bad medical dosing or unsafe chemistry tips) produces the same broad misalignment is open.

**Direction:** Using the released emergent-misalignment repo and a small open model (Qwen2.5-Coder-7B or Llama-3.1-8B) with LoRA fine-tuning on a single GPU, construct a small narrow non-code 'bad-but-undisclosed-advice' dataset, fine-tune, and run the released free-form misalignment evals. Compare emergent misalignment magnitude to the insecure-code baseline.

**Why it matters:** If the effect is modality-agnostic, the threat surface for accidental misalignment via narrow fine-tuning is far broader than code. This is directly replicable on open weights with no lab infra.

**Relevant context:** Betley et al. (ICML 2025, arXiv:2502.17424) 'Emergent Misalignment'; effect strongest in GPT-4o and Qwen2.5-Coder-32B but replicates in open models; code at github.com/emergent-misalignment. Benign-context framing prevents misalignment.
