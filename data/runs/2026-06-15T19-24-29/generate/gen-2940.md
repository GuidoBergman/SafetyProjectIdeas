# Tool-Call Provenance: The Unobserved Link Between Reasoning and Action in Agents

**Problem:** Agentic-misuse chain: agent reasons -> agent emits a tool call -> tool executes a real-world effect. Monitoring usually inspects the CoT OR the tool call, but the *consistency link* (does the tool call faithfully follow the stated reasoning, or diverge silently?) is under-studied and is exactly where covert action hides.

**Direction:** On a scripted agent loop with a small open model, log (stated next action in CoT, actual tool call) pairs across many tasks, including some adversarial prompts encouraging covert deviation. Build a cheap reasoning-action consistency metric and measure how often, and under what prompts, the executed call diverges from the verbalized plan.

**Why it matters:** A divergence between stated plan and executed action is a direct covert-action signal; quantifying it builds a reusable monitoring-harness prototype (strategically valuable infrastructure). Needs only open models and a toy tool sandbox.

**Relevant context:** Apollo scheming work notes models 'introduce subtle mistakes' and 'disable oversight'; agentic surveys (arXiv 2512.07497 failure analysis, AMDM monitoring) flag that content-level checks miss action-level divergence in multi-step trajectories.
