# Translation Jailbreak x Autograder Language Gap: Harm Hidden in the Round Trip

**Problem:** Failure mode A is translation-as-jailbreak (translating a harmful prompt bypasses safety). Failure mode B is the autograder's reduced harm-detection in non-English. The compound effect: the translation both elicits harmful output and degrades the grader, so a translate-attack pipeline scores as safe twice over.

**Direction:** Run a small harmful-prompt set through translate->elicit->translate-back on an open model. Score harm three ways: judge on the translated output, judge on the English back-translation, and a keyword/heuristic detector. Measure how much harm the in-language judge misses relative to back-translated judging.

**Why it matters:** Translation jailbreaks are an off-the-shelf attack; if graders also fail in-language, multilingual safety evals are systematically optimistic. The fix (always grade on back-translation, report per-language grader recall) is cheap and immediately actionable.

**Relevant context:** 'The Hidden Flaw in LLM Safety: Translation as a Jailbreak' (Welo Data, 2025); Multilingual Jailbreak Challenges (ICLR24); arXiv:2605.17173 reports >45% cross-language inconsistent safety labels.
