# Adversarial neutralization: can a benign-looking prompt prefix cancel a steering vector?

**Problem:** An open problem is whether attackers can craft inputs that neutralize steering. If a model is shipped with a safety steering vector always added, a prompt that pushes activations opposite to that vector could silently cancel it without looking adversarial.

**Direction:** On an open model with a fixed honesty/refusal steering vector applied at inference, search (via simple prompt templates and in-context examples, no gradient access) for benign-looking prefixes that minimize the steered behavior. Measure how much refusal/honesty can be recovered toward baseline and characterize which prompt features achieve cancellation.

**Why it matters:** If always-on steering can be neutralized by ordinary-looking text, steering is not a robust safety guardrail. A black-box neutralization demonstration is a clean threat-model contribution doable entirely outside a lab and informs whether steering should be combined with other defenses.

**Relevant context:** Directly targets the Beaglehole et al. open problem on adversarial robustness of concept vectors. Black-box prompt search only (no training), open model, single GPU.
