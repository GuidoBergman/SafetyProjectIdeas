# A Concrete Löbian-Obstacle Toy: When Can a Proof-Checker Agent Trust Its Successor?

**Problem:** Vingean reflection's Löbian obstacle says an agent using formal proofs can't trust a successor using the same proof system (Gödel/Löb). The escalating-theory fix (T_n trusts T_{n+1}) is abstract; a runnable demonstration that newcomers can inspect is missing.

**Direction:** Implement a tiny toy in Python where 'agents' are proof-search procedures over a small formal system (e.g. a propositional/arithmetic fragment with a SAT/SMT backend or a hand-rolled checker). Show concretely that an agent cannot prove its own soundness, demonstrate the resulting failure to 'approve' a successor, and then implement the escalating-theory hierarchy showing finite-depth trust works. Measure how trust depth limits self-improvement chains.

**Why it matters:** Makes one of the oldest, most-cited agent-foundations obstacles tangible and testable for beginners, clarifying its real scope and the cost of known workarounds — foundational understanding that needs zero ML compute.
