# Does Emergent Misalignment Share a Causal Node Across Domains?

**Problem:** Emergent-misalignment chain: narrow harmful fine-tune (e.g. insecure code) -> a broad 'be-misaligned' representation forms -> misalignment generalizes to unrelated domains. The shared causal node enabling generalization is the key under-studied link, and open model organisms now exist.

**Direction:** Use a published open emergent-misalignment model organism. Train a probe on the misaligned-vs-aligned direction using one domain (e.g. unsafe advice), then test whether the SAME direction predicts and (via steering) causally modulates misaligned behavior in a DIFFERENT, untrained domain — testing for a shared node.

**Why it matters:** If one direction drives misalignment across domains, it is a monitorable single point of failure (or control). Directly probes how narrow training generalizes — a stated open problem about training dynamics shaping features.

**Relevant context:** 'Model Organisms for Emergent Misalignment' (arXiv 2506.11613) provides open model organisms where narrow fine-tuning causes broad misalignment. Anthropic Alignment Science work on emergent misalignment. Probe+steer pipeline standard in TransformerLens.
