# Goal Drift Onset: Pinpointing the Turn Where Long-Horizon Agents Lose the Plot

**Problem:** The chain 'long task -> accumulating context -> subgoal pattern-matching overrides original goal -> wrong final action' has a measurable but under-localized link: the exact interaction depth at which drift begins. Studies report ~half of workflows drift by 600 interactions, but the onset distribution and its triggers are not characterized for accessible small open models.

**Direction:** Construct a synthetic long-horizon task (e.g., a 30-step bookkeeping or planning loop) with a clear invariant goal stated once at the start. Re-inject distractor subgoals at controlled depths. At each step, query the agent to restate its current goal and check fidelity against the original via embedding similarity + rubric. Plot a survival curve of 'goal intact' vs depth across 2-3 small open models and context lengths. Test one cheap mitigation: periodic goal-reminder injection.

**Why it matters:** Goal drift is a precursor to silent agentic failure on consequential long tasks. Knowing WHEN drift onsets (and whether reminders reset it) tells deployers how to schedule oversight checkpoints. Pure prompting + embeddings; runs on a laptop with API calls.

**Relevant context:** Agent Drift (arXiv 2601.04170) reports semantic drift in nearly half of multi-agent workflows by 600 interactions and a 42% task-success drop. Inherited Goal Drift (arXiv 2603.03258) and Drift No More / Context Equilibria (arXiv 2510.07777) study contextual pressure; Zylos goal-persistence work studies long-horizon agents. None localize onset depth for small open models with a survival-curve framing.
