# Failure-Attribution Reliability in Multi-Step Agent Traces

**Problem:** Automated failure attribution (identifying which agent/step caused a multi-agent failure) was introduced as an ICML 2025 task, but the reliability of LLM-based attributors is a failure mode itself: they may blame the wrong step. How accurate and biased these attributors are on small open models is underexplored.

**Direction:** Use the open Agents_Failure_Attribution benchmark (with ground-truth culprit steps) and run small open LLMs as attributors. Measure step-attribution accuracy, check for position bias (blaming early or late steps), and test whether attribution accuracy collapses as trace length grows. Report where automated attribution is trustworthy versus where it fabricates blame.

**Why it matters:** Failure attribution is foundational for debugging and governing agentic systems; if the attributor is itself biased, post-incident analysis misleads operators. A reliability characterization on open models is directly useful for anyone building agent monitoring outside a lab.

**Relevant context:** Agents_Failure_Attribution (ICML 2025 Spotlight, github.com/ag2ai, ground-truth culprit labels); position-bias findings (arXiv:2410.21819). Open benchmark and small open attributors run on one GPU.
