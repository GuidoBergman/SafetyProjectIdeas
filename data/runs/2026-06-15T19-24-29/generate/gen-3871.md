# Self-Reported vs. Actual Reversibility Beliefs of Agents

**Problem:** Some confirmation mechanisms ask the agent itself whether an action is reversible. The success state is that an agent's reversibility self-assessment is accurate. We don't know if models can correctly judge reversibility of their own pending actions.

**Direction:** Backcast from 'agents accurately self-assess reversibility'. Present open/API models with a labeled set of tool calls (delete file, send email, read DB, transfer funds, etc.) and ask them to rate reversibility, then compare to ground truth. Test whether accuracy degrades when the call is embedded in a busy multi-step context vs. presented in isolation.

**Why it matters:** If agents misjudge reversibility — especially under context load — then self-assessment-based gating is unsafe, redirecting design toward external policies. Cheap, single-GPU/API, and tests a load-bearing assumption of self-gating designs.

**Relevant context:** 2025 best practices route medium/high-risk actions through execution previews exposing reversibility and side effects, and LLM-as-judge patterns have a model review consequential actions before execution. SHADE-Arena/AgentDojo provide realistic tool sets to draw from.
