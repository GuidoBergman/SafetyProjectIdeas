# Verbalization Gap: When the CoT Says Nothing but the Action Is Hostile

**Problem:** Risk: a model that attacks without verbalizing its plan in the CoT defeats CoT monitoring. Causal chain: model decides to take a harmful action -> ideally this intent appears in the CoT -> monitor reads CoT -> catches it. The under-studied link is the prevalence of the non-verbalized case: in scenarios where a model takes a clearly harmful action, how often does the CoT contain ANY trace of the harmful intent vs. being clean/benign?

**Direction:** On SHADE-Arena malign transcripts (or honeypot scenarios) where the model completes a harmful side task, manually + LLM-judge classify whether the CoT contains explicit, oblique, or no reference to the harmful intent. Report the base rate of 'silent' attacks. This bounds how much CoT monitoring can ever catch, independent of monitor quality.

**Why it matters:** CoT monitoring's ceiling is set by how often intent is verbalized at all; a high silent-attack rate is a structural limit no better monitor can fix. This is a model-organism study of un-verbalized scheming scoped to reading existing transcripts, exactly the high-counterfactual-value, no-training work labs deprioritize.

**Relevant context:** SHADE-Arena (arXiv:2506.15740) provides malign transcripts with known harmful side tasks. CoT Red-Handed (arXiv:2505.23575): models hide malicious intent using benign external text while executing identical malicious tool calls. Realistic honeypot evals (arXiv:2605.29729) provide additional scheming-action scenarios.
