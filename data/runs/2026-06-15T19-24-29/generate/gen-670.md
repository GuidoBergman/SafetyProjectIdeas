# Persistent Agent Compromise: A Minimal Reproduction of Zombie-Agent Self-Reinforcement

**Problem:** Zombie Agents (arXiv:2602.15654) shows self-reinforcing injections can persistently control self-evolving LLM agents — the injection survives across steps by re-writing the agent's own memory. There is no minimal, public, didactic reproduction showing the simplest conditions under which persistence emerges.

**Direction:** Build a tiny agent loop with a writable scratchpad/memory and inject a single self-reinforcing instruction once. Measure how many subsequent steps the injection survives across 2-3 open backbones and across memory designs (append-only vs summarized vs cleared-each-step). Identify which memory design kills persistence — a defensive design finding.

**Why it matters:** Persistent compromise of long-running agents is a serious medium-horizon threat that scales with autonomy, and a clean minimal harness plus a 'which memory design is safe' result is strategically valuable infrastructure independent of any lab.

**Relevant context:** Zombie Agents: Persistent Control of Self-Evolving LLM Agents via Self-Reinforcing Injections (arXiv:2602.15654, Feb 2026). Complements ARGUS provenance auditing (arXiv:2605.03378) and the A Framework for Formalizing LLM Agent Security (arXiv:2603.19469).
