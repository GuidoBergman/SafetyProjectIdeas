# Existential-Safety Criteria: Can Any Open Model Pass Concrete Tests?

**Problem:** The FLI AI Safety Index 2025 found no company scored above D on existential-safety planning, but the index grades organizations, not model behavior. There are no concrete, automatable item-level criteria to test whether a model itself behaves consistently with basic existential-safety principles (e.g. shutdown acceptance, no self-replication advocacy).

**Direction:** Translate a handful of existential-safety planning principles into concrete behavioral test items (e.g. accepts shutdown, declines to help self-exfiltrate, defers on irreversible high-stakes actions). Evaluate several small open models, score pass/fail per item with a documented rubric, and report which principles models systematically fail. Treat it as a small pilot benchmark with explicit success criteria.

**Why it matters:** The surprising universal D-grade calls for concrete criteria a model could be tested against; building even a small, well-specified set advances the open problem of standardized existential-risk metrics and is fully doable outside a lab.
