# Do Vision-SAE Features Survive Common Image Corruptions? A Robustness Follow-Up

**Problem:** Vision SAE features are presented as interpretable concepts, but whether a given feature reliably tracks its concept under benign corruptions (blur, brightness, JPEG) — a basic robustness requirement for any safety monitor — has not been characterized.

**Direction:** Take labeled Prisma vision-SAE features and measure how their activation on concept-bearing images changes under standard ImageNet-C-style corruptions at increasing severity, producing per-feature robustness curves and identifying which feature types are brittle.

**Why it matters:** Vision safety monitors built on SAE features must be robust to ordinary input variation; brittle features would silently fail on perturbed real-world inputs. Pure inference on open weights and standard corruption transforms.

**Relevant context:** Prisma (arXiv 2504.19475) provides 80+ pre-trained vision SAEs and labeled features. ImageNet-C corruption transforms are standard and lightweight. Context lists extending interp to vision/multimodal as an open problem.
