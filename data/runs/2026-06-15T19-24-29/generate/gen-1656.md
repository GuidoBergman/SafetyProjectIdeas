# Replicating Vision-SAE Feature Interpretation on Adversarially Perturbed Images

**Problem:** Vision SAE features are typically interpreted via the natural image patches that maximally activate them. It is open whether these 'clean' feature interpretations hold up under small adversarial perturbations — i.e., do interpretable features fire spuriously on imperceptibly perturbed images, revealing a gap between the human-readable interpretation and the actual mechanism?

**Direction:** Use Prisma's pre-trained CLIP SAEs. Replicate the standard max-activating-patch interpretation for a handful of clean, well-named features. The twist: apply a simple, off-the-shelf adversarial perturbation (e.g., FGSM, single-GPU, seconds per image) to images and measure whether the supposedly interpretable features still fire as their description predicts, or whether they activate spuriously — quantifying interpretation robustness.

**Why it matters:** If interpretable features are fooled by adversarial inputs, then safety arguments resting on 'this feature detects X' break under adversarial pressure. Testing the adversarial robustness of feature interpretations — using public SAEs and standard attacks on one GPU — probes whether mechanistic interpretability can survive the adversarial settings that real deployments face, a robustness gap labs rarely stress-test.

**Relevant context:** Prisma (arXiv:2504.19475) ships CLIP SAEs interpreted via max-activating patches; 'Interpretable and Testable Vision Features via SAEs' (arXiv:2502.06755) and 'Causal Interpretation of SAE Features in Vision' (arXiv:2509.00749) provide interpretation/attribution methods. FGSM/PGD adversarial attacks are standard and lightweight.
