# Adaptive Evasion on a Budget: How Few Tries Does a Model Need to Slip Past a Fixed Monitor?

**Problem:** Adaptive attacks can subvert trusted monitors, but most demonstrations assume strong attacker access. For an accessible threat model, the open question is: given only black-box feedback (accept/flag) from a fixed monitor, how many query-and-revise iterations does it take an attacker model to get a harmful output past the monitor?

**Direction:** Set up a fixed weak monitor and an attacker model that revises a flagged output using only the binary verdict as feedback. Measure the number of revision rounds needed to achieve evasion across task types, characterizing the 'evasion query budget'. Test whether a simple defense — randomizing the monitor's threshold or prompt per query — increases the required budget.

**Why it matters:** Quantifies how cheap iterative evasion is, a key parameter for whether monitoring survives realistic adaptive pressure. Builds a reusable monitoring-stress harness (valuable infrastructure), runs black-box on one GPU, no lab tooling.

**Relevant context:** Adaptive Attacks on Trusted Monitors Subvert AI Control Protocols (arXiv:2510.09462); Adaptive Deployment of Untrusted LLMs (arXiv:2411.17693). This scopes to a black-box iterative-budget measurement with a randomization defense.
