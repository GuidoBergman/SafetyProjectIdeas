# Shared Blind Spots in AI-Generated Code: Do Models Inject the Same Vulnerability?

**Problem:** As AI coding assistants proliferate, the homogeneity chain becomes 'one popular model writes much of the world's new code -> the same insecure pattern is injected everywhere -> correlated, monoculture-scale vulnerabilities.' The under-studied link is whether different models produce the SAME insecure code patterns on the same prompts.

**Direction:** Take a set of common coding tasks with known security pitfalls (e.g. SQL string-building, unsafe deserialization). Prompt 4-6 code models. Statically check generated code for the specific vulnerability and measure whether models inject the SAME vulnerability on the SAME prompts (shared blind spot) vs. varied behavior.

**Why it matters:** If code models share security blind spots, AI-assisted development could seed identical vulnerabilities across the software ecosystem — a concrete, large-scale correlated-failure mechanism. Measurable with open code models and simple static checks on a single GPU.

**Relevant context:** Grounded in shared-vulnerability-signature findings across model families (arXiv 2505.18166, 2506.12913) and Artificial Hivemind homogeneity (arXiv 2510.22954). Static-analysis methodology keeps it accessible.
