# BlindSpotMiner: an automated tool to surface prompts where ALL models fail together

**Problem:** We lack tooling to actively SEARCH for inputs that trigger correlated failure across many models — the high-value 'universal blind spots'. Current homogeneity work measures average similarity but doesn't mine the worst-case shared-failure prompts.

**Direction:** Implement a simple search loop: start from a seed prompt set, score each prompt by how many of N models fail/agree-wrongly on it, then mutate (paraphrase, add context) the highest-correlation prompts to amplify joint failure. Output a ranked list of 'universal blind spot' prompts. Use cheap open models so the whole loop runs on one GPU. Characterize what these prompts have in common.

**Why it matters:** Universal blind spots are the single points of failure of the model ecosystem; a tool that finds them turns diffuse systemic risk into concrete, fixable test cases. Counterfactually valuable as an open auditing tool labs would not prioritize building against themselves.

**Relevant context:** Inspired by quality-diversity vulnerability discovery (arXiv:2606.00801) and Hivemind shared-blind-spot framing; serves the open problem of monitoring shared blind spots across deployed systems.
