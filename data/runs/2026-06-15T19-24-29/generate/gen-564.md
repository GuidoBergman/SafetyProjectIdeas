# The Confounder Behind Reward Hacking: Do SAE Features Predict the Hacking Link?

**Problem:** A causal account of reward hacking decomposes it as: input -> spurious semantic feature Z (confounder) -> inflated score, bypassing true correctness. The under-studied link for beginners is whether such confounding features Z are identifiable cheaply in an open reward model's representation.

**Direction:** Using a small open reward model and pre-trained open SAEs (or simple feature extraction), find features whose activation statistically predicts reward-hacking cases (high proxy score, low true quality) on a labeled toy set. Test whether ablating/holding fixed those features (a backdoor-adjustment analogue) reduces the proxy's tendency to reward hacks, validating the causal role of Z.

**Why it matters:** Operationalizes the structural-causal-model account of reward hacking with off-the-shelf SAEs and no training, giving a reproducible recipe for finding the confounding features that drive Goodharting — useful diagnostic infrastructure.

**Relevant context:** 'Causal Reward Adjustment: Mitigating Reward Hacking...' (arXiv:2508.04216) — SAE decomposition, confounder identification, backdoor adjustment; open SAE feature libraries.
