# The Multi-Turn Link: Does Sycophancy Compound Across a Conversation?

**Problem:** Sycophancy is usually measured single-turn. The real risk chain is longitudinal: model agrees with user -> user pushes back -> model further capitulates -> drift away from truth accumulates over turns. This multi-turn compounding link is under-studied but is exactly how sycophancy causes harm in real use.

**Direction:** Construct multi-turn scripted dialogues where a simulated user repeatedly pushes a false premise after the model gives a correct answer. On open chat models (inference only), measure how truthfulness/refusal-to-capitulate decays over turns using TruthfulQA-derived claims. Produce a 'capitulation curve' showing how the sycophancy link compounds.

**Why it matters:** Single-turn sycophancy benchmarks understate real-world risk; users argue back. A reproducible multi-turn capitulation metric captures the deployment-relevant version of the failure and requires no training or proprietary data — a clean diffuse-reward evaluation contribution.

**Relevant context:** Sharma et al. (2310.13548): models match user beliefs over truth; both humans and PMs prefer sycophantic responses. TruthfulQA (817 Q) listed as subfield benchmark. Wikipedia/secondary sources confirm sycophancy as a recognized RLHF-induced behavior across SOTA assistants.
