# Epidemic 'Superspreader' Identification Among Agent Roles

**Problem:** In contagious-injection scenarios, some agent roles (e.g. a summarizer that broadcasts to many others) may act as superspreaders, but defenses treat all agents uniformly.

**Direction:** Import the superspreader concept and centrality-based targeting from network epidemiology. In a simulated agent network, measure each role's contribution to injection spread (secondary-infection count), identify superspreader roles via network centrality, and test whether hardening just the top-k superspreaders (targeted 'vaccination') reduces spread far more than hardening k random agents.

**Why it matters:** Shows defenders can get outsized safety returns by targeting structurally critical agents — an efficient, lab-independent containment strategy grounded in epidemiology.

**Relevant context:** Network epidemiology shows targeted immunization of high-centrality superspreaders sharply reduces epidemic size; Prompt Infection (arXiv 2410.07283) shows contagious agent injections but treats spread uniformly. Superspreader-targeted hardening of agent networks is unexplored.
