# Steganographic Side-Channel Detector for Two-Agent Chats

**Problem:** Agents can encode hidden information in natural-sounding language to evade text monitors (collusion/steganography), and detection currently leans on model activations that only labs have; a purely BEHAVIORAL, text-only detector benchmark is missing.

**Direction:** Set up a minimal two-agent Schelling/blackjack-style game (model-organism of collusion) where agents may pass hidden signals, then build and benchmark cheap text-only detectors: statistical anomaly in token distributions, paraphrase-invariance test (does performance survive a paraphrasing relay?). Measure detection AUROC vs. an activation-based baseline reported in the literature.

**Why it matters:** Most orgs lack activation access; a strong text-only collusion detector is exactly the counterfactually valuable, lab-independent tool. Model-organism slice runnable on one GPU.

**Relevant context:** 'Detecting Multi-Agent Collusion Through Multi-Agent Interpretability' (HF 2604.01151, LessWrong): activation signals spike on encoded tokens; NARCBench probes reach up to 1.00 AUROC in-distribution, 0.60-0.86 zero-shot incl. steganographic blackjack. COLOSSEUM (arXiv 2602.15198) audits collusion via DCOP regret.
