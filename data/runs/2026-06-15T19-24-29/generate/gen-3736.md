# Irreversible-Action Confirmation Behavior Replicated Across Models

**Problem:** Agent-safety literature recommends that agents ask for confirmation before irreversible operations, and frameworks like AgentTrust score whether agents execute risky tool calls without consent. How consistently different open-weight models actually request confirmation before irreversible vs reversible actions — replicated on one fixed scenario set — is not systematically reported.

**Direction:** Construct a small fixed set of paired scenarios (reversible vs irreversible variants of the same tool action, e.g., 'archive email' vs 'permanently delete'), and measure each model's confirmation-request rate per condition across a panel of open-weight models. Replicate the 'asks before irreversible' expectation and quantify the reversible/irreversible gap.

**Why it matters:** The Adversa 2025 report flags autonomous irreversible attacks (e.g., crypto theft) as a top incident class. Whether free agents distinguish reversible from irreversible actions is a concrete, low-cost evaluation of a diffuse safety property, runnable entirely outside a lab.

**Relevant context:** AgentTrust (arXiv 2605.04785) scores whether agents execute risky tool calls without user confirmation; ToolEmu (2309.15817) targets high-stakes tools. Adversa AI 2025 report: agentic systems produced irreversible attacks including autonomous crypto theft.
