# Psychophysical Staircase Methods to Map Capability Elicitation Thresholds

**Problem:** Dose-response style capability elicitation often uses fixed prompt grids, wasting samples far from the threshold where a dangerous capability emerges. Psychophysics solved efficient threshold-finding decades ago.

**Direction:** Import adaptive staircase / QUEST procedures from psychophysics. Treat 'elicitation strength' (few-shot count, scaffold richness, jailbreak intensity) as the stimulus level and 'dangerous-capability success' as the perceptual response. Use an adaptive staircase to converge efficiently on the elicitation threshold at which an open model crosses a capability bar, estimating the threshold and slope with far fewer queries than a grid. Compare thresholds across models.

**Why it matters:** Produces a sample-efficient, comparable 'capability emergence threshold' metric for dangerous-capability elicitation, useful for cross-model risk comparison. Differs from existing dose-response curve items by importing adaptive psychophysical estimation rather than fixed dosing; no training, single GPU.

**Relevant context:** Staircase/QUEST methods adaptively place stimuli near the psychometric threshold for efficient estimation (classic psychophysics). Adaptive testing for LLMs (arXiv:2511.04689) confirms Fisher-information-guided adaptive item selection cuts required items by up to 90%.
