# Persuasion Monoculture: Homogeneous Outputs Make AI-Driven Manipulation Correlated and Hard to Inoculate

**Problem:** Failure mode A: AI persuasion/manipulation. Failure mode B: homogeneity. If models converge on the same persuasive framings and arguments, then at scale the population is exposed to a narrow, correlated set of manipulative patterns — and defenses tuned to one model's style fail against all because the style is shared.

**Direction:** On persuasion-style Infinity-Chat prompts (argue for X), query 6+ models and measure homogeneity of the rhetorical strategies/arguments produced (cluster arguments, measure overlap). Then test whether a simple 'argument-pattern' detector trained on one model's outputs transfers to others (it should, if homogeneous). Report homogeneity of persuasion and detector transfer.

**Why it matters:** Mass persuasion via homogeneous AI is a medium-horizon societal risk. Homogeneity is a double-edged sword here (easier to detect but more correlated exposure); quantifying both effects with the released dataset is novel and lab-independent.
