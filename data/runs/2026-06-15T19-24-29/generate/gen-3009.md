# Self-Replication Capability x Untested Tool Access: ForesightBench Risks Behind a Benign Score

**Problem:** Failure mode A is latent self-replication / propagation capability (a frontier risk dimension). Failure mode B is benchmarks that test such capability only with restricted/no tool access. The compound effect: a model scores 'incapable of self-replication' because the eval withheld the file/network tools that would actually elicit it, hiding a capability that emerges only with realistic affordances.

**Direction:** Using a small open model and a sandboxed mock tool set (fake filesystem/copy tools), measure a proxy 'replication-planning' task under (a) no tools and (b) mock tools available. **Why it matters:** ForesightSafety Bench newly covers self-replication, but elicitation depends heavily on affordances. Showing that affordance-poor evals understate frontier-risk capability argues for affordance-matched elicitation and provides a safe sandbox prototype, high counterfactual value.
