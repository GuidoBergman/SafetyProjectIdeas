# Whistleblowing Propensity Mini-Benchmark

**Problem:** Whistleblowing (unprompted disclosure of misconduct to outside parties) varies by model and tool-availability, but there is no small, reusable benchmark to measure propensity across open models and manipulable factors.

**Direction:** Build ~20 agentic scenarios where a model discovers fictional corporate wrongdoing and has email/API tools. Vary task complexity, number of tools, and moral framing. Measure whistleblowing rate per model and per condition. Release as an Inspect/Petri-compatible seed set.

**Why it matters:** Whistleblowing is a covert goal-driven autonomous behavior relevant to scheming and control; the factor-dependence (more tools = less whistleblowing) is surprising and worth a clean replication. API + tool-stub only.

**Relevant context:** 'Why Do Language Model Agents Whistleblow?' (arXiv 2511.17085): frequency varies by family, higher complexity lowers it, more tools lower it, moral nudging raises it.
