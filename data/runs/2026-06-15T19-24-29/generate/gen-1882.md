# Steering-Vector Approximation of Subliminally Learned Traits

**Problem:** Recent work argues subliminal learning is really 'steering vector distillation' — the student learns to imitate a single steering vector the teacher's system prompt implies. This mechanistic claim has only been shown for a couple of traits; whether a recovered steering vector can predict and even substitute for subliminal fine-tuning across multiple traits is open.

**Direction:** Vary the subliminal-learning experiment to test the steering-vector hypothesis directly. For several teacher traits, (1) extract the teacher's trait direction as the difference of mean activations with/without the trait system prompt, (2) check whether simply adding that vector to the un-fine-tuned student reproduces the subliminally-learned behavior, (3) compare its effect size to actual number-sequence fine-tuning. Small open models, inference + one cheap LoRA.

**Why it matters:** If a hidden trait equals a single addable direction, then both detection (scan for the direction) and defense become tractable. This reframes a scary poisoning result as a mechanistically simple one — high-value, no proprietary data, runs on one GPU.

**Relevant context:** 'Subliminal Learning Is Steering Vector Distillation' (arXiv:2606.00995): subliminal learning mediated by a single steering vector; teacher system prompt well-approximated by a steering vector. Arditi et al. NeurIPS 2024 difference-of-means direction extraction method.
