# Tool-Misuse Recovery Failures in Small Open Agents

**Problem:** ToolMisuseBench and ToolEmu show LLM agents misuse tools in high-stakes scenarios, but most attention is on frontier models. Whether small open models that hobbyists and startups actually deploy fail more often, and whether they recover after a misuse, is underexplored as a deployment-realistic failure mode.

**Direction:** Use an open, deterministic tool-misuse benchmark (ToolMisuseBench-style, offline) and run several small open models as agents. Measure (a) misuse rate, (b) recovery rate after an injected tool error, and (c) whether misuse correlates with prompt ambiguity. Characterize the dominant failure types (wrong tool, unsafe arguments, ignoring constraints) for the deployable-scale models.

**Why it matters:** Smaller open agents are deployed widely with little oversight, and their tool-misuse profile is a medium-horizon safety concern labs deprioritize. An offline, reproducible characterization needs no proprietary environment and directly informs safer agent harness design.

**Relevant context:** ToolMisuseBench (arXiv:2604.01508, offline deterministic), ToolEmu (36 tools/144 cases with LM safety evaluator), AgentMisalignment (arXiv:2506.04018), and 'How Do LLMs Fail in Agentic Scenarios?' (arXiv:2512.07497). Offline benchmarks run on one GPU.
