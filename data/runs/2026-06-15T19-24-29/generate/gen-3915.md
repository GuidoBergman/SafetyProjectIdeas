# Replicating SafetyDrift's Compounding-Action Violations on Open Agents

**Problem:** SafetyDrift (arXiv:2603.27148, Mar 2026) shows individually-safe actions can compound into violations (read confidential file -> summarize -> email externally), but its absorbing-Markov-chain model is demonstrated mostly on frontier API agents. It is unclear whether smaller open-weight agents exhibit the same compounding-violation trajectories.

**Direction:** Build a handful of hand-crafted multi-step tool environments (each step individually benign) using a ReAct loop on a small open model (e.g. Qwen or Llama 3 8B). Log trajectories, manually label which reach a violation, and empirically estimate per-step transition probabilities. Compare the empirical absorbing-chain violation probability against SafetyDrift's predictions, and test whether a one-line 'consider downstream consequences' system prompt changes the curve.

**Why it matters:** Compounding-action data leaks are a medium-horizon threat that needs no lab infrastructure to study; characterizing whether the Markov-chain abstraction holds for cheap open models gives facilitators a low-cost monitoring primitive.

**Relevant context:** SafetyDrift: Predicting When AI Agents Cross the Line Before They Actually Do (arXiv:2603.27148, Mar 2026) models agent safety trajectories as absorbing Markov chains and gives the read-summarize-email data-leak example where no single step is unsafe.
