# A Lightweight Monitor-Evasion Stress Test Harness Using Only Prompt-Level Attacks

**Problem:** Recent work shows current red-teaming under-elicits attacks and overstates monitor performance, but the strongest evasion studies require building full adversarial agent pipelines. There is no minimal, reproducible harness that a newcomer can run to measure how much a monitor's catch-rate drops under simple, named prompt-level evasion strategies.

**Direction:** Build a small harness that takes a fixed set of known-attack trajectories (from MonitoringBench or SHADE-Arena), applies a taxonomy of cheap text transformations to the attacker action (e.g. add benign-looking justification comments, split a malicious action across steps, bury it in verbose output), and re-scores with a monitor LLM. Report catch-rate degradation per evasion type and produce a ranked 'which transformations fool monitors most' table.

**Why it matters:** Gives the community a cheap, repeatable monitor robustness test that does not need a trained attacker model. Documents which trivial evasions monitors fail to catch, directly informing whether trusted monitoring is safe to deploy. Pure API + open data; high counterfactual value outside labs.

**Relevant context:** MonitoringBench (arXiv 2605.09684) provides 2,644 attacks and a taxonomy of evasion strategies and notes current practices under-elicit attacks. SLEIGHT-Bench (arXiv 2605.16626) catalogs evasion attacks against agent monitors. These confirm evasion-degradation is real and measurable.
