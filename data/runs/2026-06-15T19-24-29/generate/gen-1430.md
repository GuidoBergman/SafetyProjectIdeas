# LinearityScore: A Benchmark for Which Safety Concepts Have Linear Representations

**Problem:** A core open problem is which safety-relevant concepts have linear representations and which don't, yet there is no standardized score that ranks concepts by 'how linear' they are in a given model.

**Direction:** Define a LinearityScore: for each concept, train a linear probe AND measure how monotonically a CAA steering vector shifts behavior with coefficient (linear dose-response). Compute it for ~10 safety concepts (deception, refusal, sycophancy, power-seeking, corrigibility, etc.) on an open 7B model and rank concepts from most to least linearly represented.

**Why it matters:** Tells the field where linear steering/monitoring is trustworthy and where it will fail, directly addressing a stated open problem. A ranked map of concept linearity is reusable infrastructure for prioritizing safety work, all on a single GPU.

**Relevant context:** Open problem: 'which concepts have linear representations and which don't' (Beaglehole et al.). CAA provides multiple labeled behavior datasets; linear probing methodology is standard.
