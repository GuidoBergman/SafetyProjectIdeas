# Crash-consistency / sandboxing techniques from OS security for a minimal safe agent firewall

**Problem:** Agents can take irreversible harmful actions (autonomous fund transfers, file deletion). The open ecosystem lacks a small, principled 'firewall' prototype that intercepts and gates irreversible tool calls before execution.

**Direction:** Adapt capability-based sandboxing and reference-monitor concepts from OS security. Build a lightweight tool-call mediation layer for an open agent that classifies each proposed action as reversible/irreversible (using a policy + small classifier), requires confirmation or dry-run simulation for irreversible ones, and logs an audit trail. Evaluate on a benchmark of tasks containing tempting irreversible actions and measure prevented-harm rate vs. task-completion cost.

**Why it matters:** Delivers a concrete, reusable safety-infrastructure prototype (an agent firewall) addressing irreversible-action risk — explicitly strategically valuable and lab-independent. Scoped to a small prototype that fits 30h.
