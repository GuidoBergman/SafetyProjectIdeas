# Distribution Shift x Reward-Model Staleness: Compounding Drift in a Deployed-Then-Retrained Loop

**Problem:** A deployed model faces distribution shift (robustness); a reward model trained on the old distribution becomes stale (RLHF). They compound: as inputs drift, the policy goes OOD AND the reward model misjudges those new inputs, so feedback used to 'fix' drift is itself wrong, potentially accelerating misalignment.

**Direction:** Build a synthetic/tabular simulation of a closed feedback loop: an input distribution that drifts over rounds, a true reward, and a frozen (stale) proxy reward model. Measure true-reward trajectory and compare to a control where the proxy is refreshed. Show whether shift + staleness produce compounding divergence rather than additive degradation. Fully simulation-based.

**Why it matters:** Real systems retrain on lagged feedback under drifting inputs; a clean toy showing compounding divergence is a teaching artifact and a medium-horizon threat illustration. Runs on CPU, no large models.

**Relevant context:** Goodhart in OOD regions (arXiv:2210.10760); distribution-shift-driven misgeneralization (arXiv:2309.16166).
