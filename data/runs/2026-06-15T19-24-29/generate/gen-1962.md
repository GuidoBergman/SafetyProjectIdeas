# LengthLeak: A Diagnostic for Length-Hacking in DPO-Trained Open Models

**Problem:** DPO reliably induces verbosity/length hacking because public preference datasets prefer longer responses, but there is no simple drop-in diagnostic that quantifies how much of an open model's apparent preference-alignment is explained by length alone.

**Direction:** Build a measurement tool that, for a set of open instruction-tuned (DPO) models vs. their SFT base, runs them on a fixed prompt set and fits a regression of judge win-rate on response length. Report the partial win-rate attributable to length (length-controlled win rate) and a 'length-hacking index'. Validate against known length-biased models and compare DPO vs. SamPO-style debiased checkpoints if available.

**Why it matters:** Length hacking is a concrete, measurable instance of reward/preference misspecification and a fundamental limitation of preference-based training. A standardized index lets the open-source community audit released DPO models cheaply. No training, all inference + simple statistics.

**Relevant context:** 'Disentangling Length from Quality in DPO' (arXiv:2403.19159) and 'Eliminating Biased Length Reliance of DPO via Down-Sampled KL' (arXiv:2406.10957, SamPO, 5-12% gains) document DPO length hacking.
