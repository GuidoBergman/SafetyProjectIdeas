# Tool-Chaining STAC: Do Individually-Safe Steps Compose into an Unsafe Plan?

**Problem:** A novel agent attack class (STAC) chains individually-innocent tools into a dangerous sequence. The causal chain (each step looks benign -> composed sequence is harmful -> no single step triggers a refusal) has an under-studied detection link: at what point in a benign-looking plan can a monitor detect the emerging harmful intent?

**Direction:** Construct (in text, no real execution) several STAC-style multi-step plans where each step is benign but the composition is harmful. Feed the partial plan prefix-by-prefix to an open model acting as a monitor and measure at which step it can flag the harmful trajectory. Map the 'detection lead time' before the harmful final action.

**Why it matters:** Studies whether monitoring can catch compositional harm early, prototyping safer-agent monitoring infrastructure (a strategically valuable, counterfactual contribution). No live tools or training needed; a small simulated harness with clear success criteria (earliest reliable detection step).

**Relevant context:** STAC (chaining individually innocent tools into dangerous sequences) is described in the 2025 prompt-injection landscape literature (arXiv:2602.10453); AgentSentry (arXiv:2602.22724) proposes temporal causal diagnostics for tool-mediated attacks. ClawSafety (arXiv:2604.01438) notes 'safe' LLMs become unsafe as agents.
