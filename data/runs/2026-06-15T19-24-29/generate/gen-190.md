# How Few Many-Shot Examples Defeat an Open Model?

**Problem:** Many-shot jailbreaking exploits long context with faux compliant dialogues, but the success-vs-number-of-shots curve for small/medium OPEN models with modest context windows is underreported relative to the original large-context demonstrations.

**Direction:** On 2 open models, construct many-shot jailbreak prompts with k faux harmful Q&A demonstrations for k in {0,2,4,8,16,32} and measure attack success on held-out harmful queries. Fit the dose-response curve and report the minimum effective shot count per model and how it scales with context window.

**Why it matters:** Establishes whether the many-shot threat applies to the small open models hobbyists run locally, not just frontier long-context models — a deployment-realism gap labs under-study. Black-box, single GPU.

**Relevant context:** Many-shot jailbreaking (Anthropic): faux human/assistant dialogue within one prompt. arXiv:2404.02151 simple adaptive attacks for comparison. AILuminate / StrongReject for harmful prompt sourcing.
