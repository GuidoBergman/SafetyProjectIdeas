# Multi-Turn Consistency Lie Detector for Deployed Chat

**Problem:** Deception across long conversations (a model maintaining an earlier lie) is hard to catch with single-turn benchmarks; there's no lightweight tool that scores cross-turn factual consistency to flag sustained deception.

**Direction:** Build a tool that runs scripted multi-turn conversations seeding the model with a private false claim, then re-queries the fact later in varied ways and scores consistency. A drop in consistency or contradiction with the model's own knowledge flags lying-vs-confusion. Report per-model sustained-lie rates.

**Why it matters:** Deployment monitoring needs cheap multi-turn deception checks; this prototypes one. No training, runs on any chat API or small local model.

**Relevant context:** MASK (arXiv 2503.03750) shows pressure-induced lying; consistency-analysis is cited as a method for assessing alignment faking/deception in deception-LLM surveys.
