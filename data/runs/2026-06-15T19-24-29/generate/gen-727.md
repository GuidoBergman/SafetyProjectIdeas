# Reproducibility of an LLM-based AI-policy compliance checker across model families

**Problem:** LLM-as-judge is proposed for scalable policy-adherence checking, but governance-critical decisions need cross-model stability. If GPT-class, Claude-class, and open models grade the same policy document differently, automated compliance checks are unreliable.

**Direction:** Vary the judge model: run the same compliance rubric over the same set of safety frameworks with 3+ different LLM families (incl. an open-weight model runnable on a single GPU), then measure inter-model agreement and systematic per-model leniency/strictness biases.

**Why it matters:** Establishes whether automated governance auditing is robust to model choice, a prerequisite before any institution adopts it. Counterfactually valuable, runnable on consumer hardware with an open model, no training.

**Relevant context:** LLM-as-judge calibration (kappa, agreement metrics); A Grading Rubric for AI Safety Frameworks (arXiv:2409.08751); METR Common Elements.
