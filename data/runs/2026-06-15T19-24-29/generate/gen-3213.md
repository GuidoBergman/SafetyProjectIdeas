# Differential Diagnosis: A Clinical Reasoning Protocol for Attributing Misbehavior

**Problem:** When a model misbehaves, we struggle to attribute the cause: genuine misalignment, scheming, prompt confusion, or capability failure. Medicine uses structured differential diagnosis to distinguish look-alike conditions via discriminating tests.

**Direction:** Adapt differential diagnosis: build a decision tree of discriminating probes that separate 'scheming' from benign explanations (e.g., does behavior persist when monitoring cue removed? does it require a goal? does it self-correct when caught?). Apply to a set of misbehavior episodes from open models and score how well the protocol assigns the correct cause vs a flat classifier.

**Why it matters:** Provides a reproducible attribution methodology so auditors don't over- or under-attribute scheming — important for honest safety cases and for not crying wolf, and entirely tool/lab-independent.

**Relevant context:** Differential diagnosis uses discriminating tests to separate conditions with overlapping presentations (clinical reasoning literature). 'Why Do Some Models Fake Alignment While Others Don't?' (arXiv:2506.18032) shows heterogeneous causes. Apollo safety-case framework needs cause attribution.
