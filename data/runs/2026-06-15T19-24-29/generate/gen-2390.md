# Unfaithful CoT Breaks Debate: Two Liars Beat One Judge

**Problem:** Two failure modes compound: (A) chain-of-thought unfaithfulness (the visible reasoning does not reflect the true computation), and (B) debate-protocol breakdown (a weak judge cannot adjudicate when both debaters produce eloquent but unfaithful reasoning). Debate assumes exposed reasoning is checkable; if the reasoning is unfaithful, the protocol's core assumption collapses.

**Direction:** Run a 2-turn debate on multiple-choice QA (e.g., a GPQA/MMLU subset) using two open chat models as debaters and a weaker open model as judge. In one condition allow honest CoT; in another, prompt debaters to produce fluent reasoning that omits the key disconfirming step (induced unfaithfulness). Measure judge accuracy drop when unfaithful-but-fluent reasoning is allowed vs honest reasoning. The compounding metric is accuracy degradation attributable to unfaithfulness, not to debate alone.

**Why it matters:** Debate is a flagship scalable-oversight protocol; CoT monitoring is a flagship interpretability-lite oversight tool. If unfaithful CoT silently disarms debate, the two safety mechanisms fail together rather than backstopping each other. This is doable with prompting only, no training.

**Relevant context:** On scalable oversight with weak LLMs judging strong LLMs (Kenton et al., NeurIPS 2024) shows eloquent hallucination can mislead judges. Unfaithful Reasoning Can Fool Chain-of-Thought Monitoring (Alignment Forum, 2025) and Measuring CoT Monitorability (arXiv 2510.27378) document unfaithfulness rates 0.04-13%.
