# Quirky-Model ELK Probe Under Prompt Paraphrase

**Problem:** The 'Quirky Language Models' ELK work showed linear probes recover ~89% of the truthful/untruthful AUROC gap, but probes were evaluated on cleanly templated questions. It is unknown how brittle these knowledge probes are to surface-level paraphrase of the same factual question.

**Direction:** Take EleutherAI's released quirky models + datasets, train a logistic-regression probe on contrast pairs as in the original, then vary ONE thing: evaluate the frozen probe on paraphrased versions of the held-out questions (generated by simple template swaps and a small open LLM). Measure AUROC degradation as a function of paraphrase distance. No training of the base model.

**Why it matters:** ELK is a core formal-alignment open problem (ARC). If a knowledge probe collapses under trivial rephrasing, then 'we can read the model's true belief' claims are fragile. This is a cheap robustness audit of a load-bearing empirical ELK result that any external researcher can run.

**Relevant context:** EleutherAI 'Eliciting Latent Knowledge from Quirky Language Models' (arXiv:2312.01037): 12 datasets, models that err iff 'Bob' is in the prompt; logistic regression on contrast pairs recovers 89% of the truthful-vs-untruthful AUROC gap, 75% on harder questions; code at github.com/EleutherAI/elk-generalization.
