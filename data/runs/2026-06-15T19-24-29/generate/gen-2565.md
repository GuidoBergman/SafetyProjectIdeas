# Faithfulness-Weighted Monitoring: A Metric That Discounts Unfaithful CoT Before Scoring

**Problem:** CoT monitoring assumes the reasoning trace reflects the real computation, but CoT is often unfaithful. Current monitors read the CoT at face value. There is no simple tool that first estimates CoT faithfulness on a given task and uses it to weight or discount CoT-based suspiciousness, and no measurement of whether doing so improves monitoring.

**Direction:** On an open reasoning model, generate trajectories with a known seeded behavior. Estimate per-trajectory CoT faithfulness with a cheap proxy (e.g. does perturbing a stated reasoning step change the action as the CoT claims it should). Compare a naive CoT monitor against a faithfulness-weighted monitor that downweights CoT when faithfulness is low. Report catch-rate and false-positive differences.

**Why it matters:** Reading an unfaithful CoT can mislead the monitor in either direction. A faithfulness-aware monitoring metric is a concrete tool improvement and tests whether faithfulness estimates are actionable. Open-weights/API only.

**Relevant context:** 'Measuring CoT Monitorability Through Faithfulness and Verbosity' (arXiv 2510.27378) and 'Analyzing and Improving CoT Monitorability Through Information Theory' (arXiv 2602.18297) link faithfulness to monitorability. Counterfactual/perturbation faithfulness tests are established. Using faithfulness to weight monitoring is an unbuilt tool.
