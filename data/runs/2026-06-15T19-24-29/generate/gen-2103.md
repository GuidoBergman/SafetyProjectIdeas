# Reward Model Spurious Features x Adversarial Suffix Transfer

**Problem:** Interacting failure modes: (A) reward models latching onto spurious surface features (alignment_training), and (B) transferable adversarial suffixes (robustness). If RMs reward spurious cues (e.g., formatting, confident tone), adversarial suffixes that inject those cues may inflate reward AND simultaneously bypass safety scoring.

**Direction:** Using an open reward model, identify spurious high-reward features via simple ablations (markdown, hedging phrases, length). Then craft suffixes embodying those features and test whether they raise the RM score on both benign and harmful completions. Measure the compound: reward inflation that co-occurs with safety-score inflation on harmful text.

**Why it matters:** If the same RM weakness inflates reward and masks harm, attackers get a two-for-one. Tests an evaluation/fuzzy-reward problem entirely on public RMs; no training.

**Relevant context:** RMs exhibit spurious correlations preferring unintended behaviors (arXiv 2510.13694, 2406.02900). 'Token-Space Attacks on Reward Models' (arXiv 2604.02686). Transferable adversarial suffix literature (GCG).
