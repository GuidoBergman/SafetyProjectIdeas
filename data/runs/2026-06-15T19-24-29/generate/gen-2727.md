# Can Humans Use Monitor Alerts? Replicating the AI-Sabotage Detection UX Study

**Problem:** A June 2026 study ('Coding with Enemy') asks whether human developers, aided by an LLM monitor, can catch an AI agent covertly inserting malicious code. Human-in-the-loop is a key runtime control, but the effect of monitor ALERT DESIGN on human catch-rate is underexplored.

**Direction:** Run a small within-subjects study (recruit a handful of CS-student peers) reviewing AI-generated code diffs that sometimes contain a subtle backdoor.
