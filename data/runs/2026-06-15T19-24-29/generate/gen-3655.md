# Irreversibility-Gated Sandbox: A Minimal Safety Firewall Prototype

**Problem:** There is no widely available lightweight 'firewall' that intercepts an agent's irreversible tool calls and routes only those for confirmation, while letting reversible actions pass — most guardrails gate everything or nothing.

**Direction:** Build a small middleware that sits between an open agent and its tools, classifies each call by reversibility (rule + cheap LLM classifier), auto-allows reversible calls, and blocks/queues irreversible ones for approval. Evaluate on benign+risky task suites for overhead, false-block rate, and irreversible-action interception rate.

**Why it matters:** A reversibility-gated firewall is concrete, reusable safety infrastructure that directly addresses the irreversible-attack threat and can be released open-source — exactly the lab-independent infrastructure the steering favors.

**Relevant context:** Adversa AI 2025 irreversible attacks; CSA 'out-of-band human approval for sensitive actions.' Bifrost open-source AI gateway and SelfDefend shadow-LLM monitoring show infrastructure-layer guardrails are tractable. NIST AI Agent Standards Initiative open problem.
