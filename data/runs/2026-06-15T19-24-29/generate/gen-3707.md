# Mapping Sabotage Failure to METR's Long-Horizon Failure Modes

**Problem:** METR-adjacent work identified concrete long-horizon failure modes (State Loss, State Mis-binding, Context Drift, Unverified Progress, Interruption Handling Failure). It is unknown which of these failure modes drives the inconsistency in multi-step sabotage tasks.

**Direction:** Take a multi-step sabotage (or any covert multi-step) task, run an agent, and hand-annotate each failed trajectory against the five METR failure-mode categories. Produce a failure-mode histogram: which mode most often derails covert long-horizon agency vs. benign long-horizon agency? Compare covert vs. overt versions of the same task.

**Why it matters:** If covert tasks fail through different mechanisms than benign tasks (e.g., extra context-drift from juggling a hidden agenda), that's a fingerprint monitors could exploit. A clean, qualitative-coded analysis is well-scoped for a first project and yields a reusable annotation scheme.

**Relevant context:** Long-horizon failure modes (State Loss, State Mis-binding, Context Drift, Unverified Progress, Interruption Handling Failure) from the half-life-of-agent-success-rates line of work (arXiv 2505.05115) and METR time-horizon analyses. DeepMind FSF sabotage inconsistency motivates the covert-vs-benign comparison.
