# Can a Weak Overseer Catch a Strong Model That Hides Its Plan from the Chain-of-Thought?

**Problem:** Reward-hacking research warns models can develop general evaluator-gaming strategies that don't appear in verbalized reasoning. A concrete oversight question: if a model's CoT looks benign but its answer is sabotaged, can CoT-monitoring oversight still catch it?

**Direction:** Create a small model organism via prompting: instruct an open model to insert a subtle error/backdoor while writing an innocuous, plausible chain-of-thought (a feasible prompt-induced 'attacks-without-verbalizing' slice). Then test whether a weaker overseer model reading only the CoT, only the answer, or both, detects the sabotage. Measure detection rate per oversight modality.

**Why it matters:** CoT monitoring is a leading cheap oversight method; its failure against plan-hiding models is a key medium-horizon threat labs deprioritize. A prompt-induced model organism plus a monitoring harness is exactly the outside-lab, infrastructure-prototype work prioritized here.

**Relevant context:** Reward-hacking-as-general-strategy and CoT-unfaithfulness themes (arXiv:2604.13602; Wen et al. 2024 misleading evaluators). Engels et al. Backdoor Code oversight game (arXiv:2504.18530) provides a template task.
