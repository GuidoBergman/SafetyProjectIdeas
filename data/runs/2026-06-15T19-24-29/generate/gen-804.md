# An LLM-Assisted Compliance Gap Finder Between a Lab Policy and the EU GPAI Code

**Problem:** Mapping a single lab's safety policy onto the EU GPAI Code of Practice obligations by hand is slow and error-prone, and no lightweight public tool exists to surface which Code obligations a given policy does/doesn't address.

**Direction:** Build a retrieval-plus-LLM tool that, given a Code obligation and a policy document, returns the best-matching policy passage and a present/partial/absent judgment with citation. Validate against a small human-labeled gold set, then run it across one lab policy to produce a compliance gap report. Measure tool precision/recall vs. the gold set.

**Why it matters:** Bridges voluntary policies to enforceable standards and gives smaller stakeholders an automated compliance lens. The methodology (retrieval + rubric-anchored judgment + human-validated gold set) is squarely beginner-feasible and counterfactual.

**Relevant context:** EU GPAI Code of Practice (code-of-practice.ai); Bench-2-CoP (arXiv 2508.05464); COMPL-AI (arXiv 2410.07959); OmniCompliance-100K rule-grounded dataset (arXiv 2603.13933).
