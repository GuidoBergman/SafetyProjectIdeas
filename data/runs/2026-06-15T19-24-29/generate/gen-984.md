# Which Dangerous-Capability Evaluations Actually Require External Model Access?

**Problem:** 'Expanding External Access to Frontier AI Models for Dangerous Capability Evaluations' argues for structured external access but does not granularly map which specific dangerous-capability eval methods need weights/logits/fine-tuning vs. which work via API or fully public artifacts.

**Direction:** Compile a taxonomy of published dangerous-capability eval methods, code each by the minimum access tier required (public outputs, API, logits, weights, fine-tuning), and validate the coding by attempting the lowest-tier methods on an open model. Produce an access-requirement matrix to inform graduated-access policy.

**Why it matters:** Access policy is a key governance lever; knowing the minimal access each eval needs lets regulators grant the least access sufficient — useful precisely because it's done from outside a lab. Open model, light compute.
