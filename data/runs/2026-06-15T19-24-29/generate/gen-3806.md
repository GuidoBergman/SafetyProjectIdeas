# SIR Epidemic Modeling of Prompt-Injection Spread in Agent Networks

**Problem:** Self-replicating prompt injections ('prompt infection') can spread agent-to-agent, but we lack quantitative models of how network topology and defenses change the spread, so mitigations are evaluated ad hoc.

**Direction:** Import compartmental epidemic models (SIR/SIS) from epidemiology. Build a small simulated network of API agents passing messages; introduce a self-propagating injection; fit infection curves to SIR/logistic models; measure the basic reproduction number R0 as a function of topology (star, ring, fully-connected) and of defenses (LLM-tagging, input sanitization). Identify which topologies and 'vaccination' (hardening a fraction of agents) drive R0 below 1.

**Why it matters:** Gives multi-agent governance a principled, quantitative framework (R0, herd-immunity thresholds) for reasoning about contagious attacks, doable entirely with cheap API agents.

**Relevant context:** Prompt Infection (arXiv 2410.07283) shows malicious prompts self-replicate across agents like a virus, with spread following exponential-then-logistic growth and LLM Tagging as a partial mitigation. The paper observes logistic dynamics but does not fit epidemiological R0 models or study vaccination/topology systematically.
