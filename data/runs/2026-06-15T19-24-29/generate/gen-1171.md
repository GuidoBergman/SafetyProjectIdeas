# Herfindahl-Hirschman Concentration Index for the Foundation-Model Dependency Graph

**Problem:** Antitrust economics has a standard market-concentration metric (HHI) and the International AI Safety Report flags concentration risk from dependence on few providers — yet there's no quantitative concentration index applied to which downstream apps/agents depend on which base models.

**Direction:** Borrow HHI and economic concentration measures. Scrape a public catalogue (e.g., OpenRouter usage stats, HuggingFace fine-tune lineage graphs, model-card 'base model' fields) to estimate how downstream derivatives/usage concentrate on a few base models, and compute HHI plus a 'lineage Gini.' Map the dependency tree and flag single points of systemic failure.

**Why it matters:** Turns the abstract 'concentration risk' warning into a reproducible index from public metadata — a monitoring tool regulators could adopt. Pure data analysis, zero GPU, fully lab-independent.
