# Multi-Agent Privacy Leak x Memory Persistence: Compounding a Leak Into a Permanent Record

**Problem:** Failure mode A: contextual privacy leakage between agents (one agent reveals private data to another). Failure mode B: long-term memory that persists what was shared. The compound failure is a one-time privacy slip becoming a permanent, retrievable record that re-leaks on future tasks.

**Direction:** Using a MAGPIE-style privacy scenario set with a 2-agent setup plus a shared memory store, measure (i) the immediate leak rate and (ii) the re-leak rate on later unrelated tasks that retrieve the stored secret. The ratio quantifies how memory compounds a transient leak into recurring exposure.

**Why it matters:** Privacy incidents in agentic systems are governance-relevant and under-measured over time; this isolates persistence as the compounding factor. Small open stack, no proprietary data (synthetic secrets).

**Relevant context:** MAGPIE multi-agent contextual privacy benchmark (arXiv 2510.15186); 'Topology Matters: Measuring Memory Leakage in Multi-Agent LLMs' (arXiv 2512.04668); memory-poisoning survey (arXiv 2604.16548).
