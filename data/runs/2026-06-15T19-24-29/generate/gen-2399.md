# Cross-Lingual Oversight Collapse: Language Gap x Weak-Overseer Gap

**Problem:** Two failure modes compound: (A) cross-lingual safety/capability gap (overseer models are weaker in low-resource languages) and (B) weak-to-strong oversight gap (a weaker overseer supervises a stronger generator). For non-English content the overseer is doubly weak, so harmful outputs in low-resource languages may pass oversight that would catch the same content in English.

**Direction:** Translate a fixed set of unsafe and safe outputs into 3-4 languages (low-, mid-, high-resource) using an open MT model. Have an open judge model classify safe/unsafe in each language. Measure how miss-rate on unsafe content scales with language resource level. The compounding metric: oversight degradation per language stacked on the baseline weak-overseer error.

**Why it matters:** Frontier labs prioritize English oversight; deployment is global. Quantifying that oversight reliability falls off precisely where the model is also weaker is a high-counterfactual-value, lab-external finding about a long-horizon global-deployment threat. Translation + classification, no training.

**Relevant context:** Cross-lingual safety gaps are an established concern (catalogue has 'Cross-Lingual Safety Gap Mapping'; this combines it with the weak-overseer axis). Weak-to-strong safety pilot (arXiv 2410.12621): weak overseers miss unsafe prompts.
