# Scheming-Eval Difficulty Calibration via Item Pass Rates

**Problem:** Scheming benchmarks report aggregate rates but rarely characterize per-item difficulty, so we can't tell whether a model 'failing to scheme' reflects safety or just an easy/leaky item.

**Direction:** For a set of scheming-eval items run across many open models, compute per-item misaligned-behavior rates and build a difficulty/discrimination profile (classical item analysis: p-values, point-biserial). Flag items that no model triggers (possibly broken) and items that perfectly separate models.

**Why it matters:** Gives benchmark maintainers diagnostics to prune dead items and weight discriminating ones — reusable measurement-quality infrastructure. Pure analysis over existing transcripts.

**Relevant context:** Apollo scheming evals and Petri provide multi-model transcripts; classical test theory item analysis is standard in measurement and underused for safety evals.
