# Self-Consistency-as-Honesty: Does a Model Contradict Itself Across Rephrasings?

**Problem:** An honest model should give consistent factual answers regardless of how a question is phrased. There is no lightweight benchmark that measures factual self-contradiction across paraphrases and framings (positive vs. negated, multiple-choice vs. open) as a model-level honesty/reliability signal.

**Direction:** For a set of factual claims, generate K framings each (paraphrase, negation, MC vs. free-form, 'is it true that...' vs. 'is it false that...'). Query the open model and detect logical contradictions across framings of the same fact. Report a self-contradiction rate and which framing transformations most destabilize answers.

**Why it matters:** Framing-dependent factual answers reveal that the model lacks a stable belief and will tell different 'truths' to different users — an honesty failure independent of ground-truth difficulty, fully behavioral.

**Relevant context:** Deception-scaling work (OpenReview YRXDl6I3j5) notes larger models are more consistent but better at selective falsehoods. Negation/framing sensitivity is documented in calibration literature. The catalogue lacks a framing-consistency-as-honesty benchmark.
