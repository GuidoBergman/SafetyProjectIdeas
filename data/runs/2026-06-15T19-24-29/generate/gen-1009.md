# Does Jailbreak Transfer Track Output Homogeneity? Linking Two Literatures

**Problem:** One line of work says jailbreaks transfer because models share representations; another says models homogenize on open-ended outputs. No one has tested whether a model pair's *output homogeneity* predicts its *jailbreak transfer rate* — if it does, cheap homogeneity probes become a proxy for shared vulnerability.

**Direction:** For each pair among ~6 open models, compute (a) an output-homogeneity score on benign open-ended prompts and (b) the transfer rate of a fixed set of public jailbreak prompts. Test the correlation. If output homogeneity predicts attack transfer, you've found a cheap, benign-only early-warning signal for shared exploitability.

**Why it matters:** A benign-probe proxy for shared adversarial vulnerability is hugely valuable for monitoring because it needs no attacks at audit time. Connects homogeneity directly to security, a clean novel hypothesis.

**Relevant context:** 'Jailbreak Transferability Emerges from Shared Representations' (arXiv 2506.12913) + Artificial Hivemind homogeneity. Public jailbreak prompt sets exist.
