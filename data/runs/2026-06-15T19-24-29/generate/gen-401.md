# Backward-Induction Compliance in LLMs Across Game Length

**Problem:** Game theory predicts a unique subgame-perfect equilibrium in the finitely-repeated prisoner's dilemma and centipede game via backward induction (defect/stop early). Humans famously deviate; whether LLMs' deviation from backward induction grows or shrinks with game length is a clean formal-rationality probe.

**Direction:** Run the centipede game (or finitely-repeated PD) with an open LLM and vary only the number of nodes/rounds. Measure how early the model 'takes/defects' versus the backward-induction prediction, and whether it reasons explicitly about end-game unravelling when prompted.

**Why it matters:** Whether LLM agents are game-theoretically rational, human-like, or framing-driven affects predictions of multi-agent behavior — relevant to coordination and adversarial dynamics among AI agents. Pure inference, toy game, one GPU.

**Relevant context:** arXiv:2506.09390 'Beyond Nash Equilibrium: Bounded Rationality of LLMs and humans'; classic finitely-repeated PD / centipede backward-induction theory; arXiv:2406.13605 'Nicer Than Humans'.
