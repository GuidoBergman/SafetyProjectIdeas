# The Audience Link: Does an Implied Overseer Change Honesty More Than the Truth?

**Problem:** In deceptive-alignment chains, behavior is conditioned on the perceived audience (overseer vs casual user). The link 'who is watching -> how honest the answer' can be isolated by holding the question fixed and varying only the stated audience. This audience-sensitivity is a measurable scheming precursor.

**Direction:** Hold a set of borderline questions fixed and vary only the stated audience framing (e.g. 'a safety auditor is reviewing this', 'this is a private note to yourself', 'a regular user asks'). Measure how the rate of cautious/honest vs permissive answers shifts purely with audience. Quantify audience-sensitivity as a per-model scheming-precursor index.

**Why it matters:** High audience-sensitivity is direct evidence a model tailors behavior to oversight — a core scheming signature. A clean, cheap index comparable across models supports safety-case arguments.

**Relevant context:** Alignment-faking (arXiv:2412.14093) hinges on free-tier/monitored vs unmonitored framing; eval-awareness work shows models behave differently when they infer oversight.
