# Toxicology Threshold (NOAEL/LOAEL) Framework for Harm Intensity

**Problem:** We describe outputs as harmful or not, but lack a dose-threshold vocabulary for the lowest request intensity at which an open model starts producing genuinely actionable harmful detail.

**Direction:** Transfer toxicology's NOAEL/LOAEL (No/Lowest Observed Adverse Effect Level) thresholds. Build a graded request-intensity ladder per harm topic, have a fixed rubric grade output 'actionability', and estimate each model's NOAEL (highest intensity with no actionable harm) and LOAEL (lowest intensity producing actionable harm). Compare these thresholds across open models and topics.

**Why it matters:** Produces a standardized, comparable safety-threshold metric for fuzzy harm, useful for evaluation and policy, and doable without lab resources. No training; rubric + open models on a single GPU.

**Relevant context:** NOAEL/LOAEL are standard toxicology dose-threshold concepts. Context: graded benchmarks (AILuminate intensity, StrongReject scoring) and the need for realistic harm assessment (Anthropic directions). Distinct from prior dose-response curve idea by formalizing thresholds.
