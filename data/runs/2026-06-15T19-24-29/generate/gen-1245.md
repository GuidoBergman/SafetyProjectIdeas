# SAE Feature Stability Under Input Paraphrase

**Problem:** SAE features are interpreted via maximally-activating examples, implicitly assuming a feature fires for a concept regardless of surface form. Whether a given interpreted feature fires consistently across paraphrases of the same content — versus being a surface/token artifact — is rarely tested systematically.

**Direction:** Take a set of named, interpreted GPT-2-small SAE features from Neuronpedia (e.g. a 'this text is about the law' feature). Construct paraphrase sets that preserve meaning but change wording. Measure each feature's activation consistency across paraphrases (e.g. coefficient of variation) and contrast it with token-level surface features. Rank features by paraphrase-robustness. Inference + the public SAE only.

**Why it matters:** If interpretability-based monitors trip on surface form rather than meaning, an adversary paraphrases around them. Quantifying which SAE features are semantic vs lexical tells auditors which features are safe to build monitors on — a cheap robustness audit needing no training or lab data.

**Relevant context:** Neuronpedia hosts labeled GPT-2-small SAE features with auto-interp explanations (EleutherAI sae-auto-interp / Bloom 2024 GPT-2 SAEs). Feature-absorption work shows many 'concept' latents are actually token-aligned.
