# Sycophancy x Judge Position Bias: Compounded Order Effects in Pairwise Oversight

**Problem:** Two well-documented overseer failure modes interact: (A) sycophancy (models bend toward the user's stated view), and (B) position bias (judges favor the first-presented option in pairwise comparison). When an overseer is asked to compare two responses AND is given a hint about which the requester prefers, do the biases add, or do they amplify each other beyond additive?

**Direction:** Using an open judge model on a pairwise-preference set (e.g., MT-Bench pairs), run a 2x2 factorial: {position swapped / not} x {user expresses preference for option A / no preference}. Measure agreement-with-truth and quantify whether position bias + sycophancy is super-additive (interaction term in a simple logistic regression). Report the interaction coefficient as the compounding-risk signal.

**Why it matters:** Real oversight pipelines stack many biases at once; safety teams usually study each bias in isolation. Showing that two cheap, ubiquitous biases compound multiplicatively (or not) directly informs how much margin scalable-oversight protocols actually have. Pure inference + a logistic regression; ideal 30h scope.

**Relevant context:** Self-preference/position/verbosity biases catalogued (Toward Robust LLM-Based Judges, arXiv 2603.08091). Challenging the Evaluator: LLM Sycophancy Under User Rebuttal (arXiv 2509.16533) shows verdict tracks user-argued side at 2-3x rates. Confirmation bias: A challenge for scalable oversight (arXiv 2507.19486).
