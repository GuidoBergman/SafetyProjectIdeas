# Medical Triage Protocols for Agent Confirmation Gating

**Problem:** Agents either ask for confirmation too rarely (risky) or too often (annoying); there is no principled triage of which actions warrant human checkpoints.

**Direction:** Import medical triage / acuity-scoring frameworks. Define an action-acuity score combining irreversibility, blast radius, and uncertainty, then map score bands to triage levels (auto-proceed / log-and-proceed / require-confirmation / hard-block), mirroring ED triage tiers. Calibrate thresholds on a benchmark and report the trade-off between harm prevented and confirmation burden.

**Why it matters:** Provides a transparent, calibrated policy for human-in-the-loop gating of agent actions — a deployable safety control informed by a mature triage discipline. No training required.

**Relevant context:** Emergency-medicine triage (e.g. ESI acuity levels) systematically routes cases by severity/urgency. TRM Labs and least-privilege work emphasize escalation/confirmation for high-risk agent actions but offer no calibrated acuity-based triage scheme. Importing triage tiers is novel.
