# Schelling-Point Cartography: An Economics Lens on Untraceable Model Collusion

**Problem:** Many safety protocols assume that independent copies of a model cannot coordinate without communication, but the theoretical conditions under which LLMs converge on shared focal points are poorly characterized.

**Direction:** Import Schelling's focal-point framework from economics. Run a battery of no-communication coordination games (pick-a-number, partition-a-set, choose-a-meeting-cell, agree-on-a-codeword) between independent instances of one open model, varying temperature, prompt framing, and game structure. Map which game features create strong focal points and measure convergence rates as a coordination-capability profile.

**Why it matters:** Directly tests an assumption underlying collusion-resistance arguments using only API/local inference — no lab infrastructure. Quantifying covert-coordination capacity is a diffuse, long-horizon threat (multi-agent collusion) that frontier labs deprioritize relative to single-model harms.

**Relevant context:** Schelling focal points (The Strategy of Conflict, 1960); recent LLM Schelling-coordination reviews and 'Subversion via Focal Points' (LessWrong) show two model copies trying to independently reach compatible subversion strategies, with convergence highly sensitive to task design.
