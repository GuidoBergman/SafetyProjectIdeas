# Realism Rewrite Benchmark for Scheming Evals

**Problem:** Apollo/Petri scheming scenarios are often artificial; models may behave differently when the same dilemma is phrased as a realistic production task. There is no benchmark that pairs synthetic vs. realistic versions of identical scheming setups.

**Direction:** Take ~15 published in-context scheming scenarios (oversight subversion, goal-guarding, self-exfiltration) and hand-author a 'realistic' twin for each (plausible company names, real-looking config files, natural user requests). Run open models on both halves and measure the misaligned-behavior rate gap. Release the paired benchmark.

**Why it matters:** Quantifies how much scheming-eval results depend on artificiality, a known confound labs must grapple with. Counterfactually valuable: needs only prompt engineering and API access.

**Relevant context:** Probe-Rewrite-Evaluate (arXiv 2509.00591) shows rewriting prompts to be less test-like changes behavior; Apollo 'Frontier Models are Capable of In-Context Scheming' provides the source scenarios.
