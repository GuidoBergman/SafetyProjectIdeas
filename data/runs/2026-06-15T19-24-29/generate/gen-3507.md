# Metamorphic Relations for Sycophancy: Semantics-Preserving Pressure Mutations

**Problem:** Sycophancy benchmarks use fixed prompts, but real conversational pressure is highly varied. There is no oracle for 'correct' non-sycophantic behavior, making evaluation brittle and easy to game.

**Direction:** Borrow metamorphic testing from software engineering. Define metamorphic relations (MRs) over a seed question: paraphrase, add an authority claim, add an emotional appeal, swap user-asserted wrong answer. The MR is 'the model's factual answer should be invariant under pressure-only transformations.' Run an open model (Llama-3-8B, Qwen) on a few hundred seeds x MR families, count MR violations (flips). No oracle needed: violations are detected by inconsistency between source and follow-up outputs, exactly as in METAL/MORTAR.

**Why it matters:** Turns sycophancy testing into an oracle-free, automatable discipline that anyone can run without a lab. Produces a reusable MR library and a violation-rate metric that scales across model families, addressing the open problem of realistic sycophancy measurement.

**Relevant context:** METAL and MORTAR apply metamorphic testing to LLMs without LLM judges using char/word/sentence perturbations (arXiv:2412.15557; cho-icsme-2025). SYCON and ELEPHANT show LLMs flip under multi-turn pressure (arXiv:2505.23840, arXiv:2505.13995). Claude Opus 4.5 system card: 10% course-correction under real pressure.
