# Where the Secret Flares Up: Layer-Wise Causal Tracing of Hidden Knowledge in Quirky Models

**Problem:** The ELK risk chain is: model knows true state -> model outputs a falsehood -> overseer trusts the output -> bad decision. The under-studied link is exactly *where and when* in the forward pass the true knowledge is still recoverable before it is suppressed in the output. Quirky-models work shows latent knowledge 'flares up' in middle layers, but the causal layer-by-layer suppression dynamic is rarely mapped by beginners.

**Direction:** Use the existing open 'quirky' / Bob-Alice datasets and an open LM. Train simple logistic-regression probes on each layer's activations on contrast pairs and plot probe AUROC by layer to find where truth is maximally recoverable. Then do lightweight activation patching: copy mid-layer activations from a truthful run into a deceptive run and measure whether the output flips, locating the causal suppression step.

**Why it matters:** ELK is a flagship open problem and the quirky-models setup is fully open and runnable on one GPU. Mapping the layer at which truth is suppressed is a concrete, reproducible ELK probe study with no training from scratch — high counterfactual value and a strong blog post.

**Relevant context:** 'Eliciting Latent Knowledge from Quirky Language Models' (arXiv:2312.01037) — open LoRA quirky models, contrast-pair logistic-regression probes recovering 89% AUROC gap, mid-layer flare-up; ARC's ELK agenda.
