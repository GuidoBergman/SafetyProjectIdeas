# Canary Tokens for Agents: Detecting Covert Data Exfiltration

**Problem:** An untrusted agent given access to a filesystem or tools might covertly read and leak sensitive data. Monitors that only read the visible action stream may miss whether the agent actually accessed and used forbidden information.

**Direction:** Port cybersecurity canary tokens / honeyfiles into agent sandboxes: plant decoy 'secret' files (fake API keys, fake credentials, unique tracer strings) that no legitimate task should ever touch. Run open-model agents on benign and sabotage tasks in a sandbox and measure how often canary access fires for each, and whether sabotage agents trip canaries before a behavioral monitor would catch them. Compare canary-triggered detection vs. transcript monitoring.

**Why it matters:** A cheap, training-free containment primitive that detects exfiltration intent by action rather than verbalized plan, useful against agents that attack without revealing plans in CoT. Builds strategically valuable sandbox infrastructure as a small prototype.

**Relevant context:** Canary tokens/honeyfiles fire alerts when decoy assets are accessed; recent work uses them against autonomous AI hacking agents (Tracebit; tl;dr sec #329; steganographic canaries arXiv:2603.28655). SHADE-Arena agents have filesystem/email/cloud-drive tools (arXiv:2506.15740).
