# Trusted Monitoring AUC by Monitor Size on a Small-Model Ladder

**Problem:** Control Tax and Redwood work showed stronger trusted monitors give better backdoor-detection AUC (e.g., o3-mini 0.92-0.96), but the monitor-capability-to-detection curve is mostly mapped on closed frontier models, not on the small open models a beginner can actually run locally.

**Direction:** Replicate the trusted-monitoring suspiciousness-scoring setup on the APPS backdoor dataset, but sweep the MONITOR across a ladder of small open models (e.g., 1B, 3B, 7B, 14B from one family) while holding the attacker/backdoor set fixed. Plot detection AUC vs monitor parameter count and identify the smallest monitor that still beats a perplexity/heuristic baseline.

**Why it matters:** Cheap trusted monitors are central to deployable control. Knowing the minimum monitor size that gives useful AUC tells the community what 'trusted' compute is actually needed, and is fully reproducible outside a lab on a single GPU.

**Relevant context:** Control Tax (arXiv 2506.05296): monitoring AUC scales with monitor strength, o3-mini AUC 0.92-0.96, monitoring consistent across attacker capability. Redwood AI Control (arXiv 2312.06942): trusted monitoring audits top 2% suspicious. Pre-built balanced backdoored/non-backdoored APPS dataset described in Control Tax.
