# Ecological Indicator Species: Sentinel Features for Distribution Shift

**Problem:** Detecting when a model is operating off-distribution is hard from behavior alone. Ecologists use 'indicator species' whose presence/abundance signals ecosystem state.

**Direction:** Borrow the indicator-species concept. Identify a small set of SAE features whose collective activation profile reliably shifts when input moves from in-distribution to off-distribution (e.g., different domain, jailbreak phrasing). Validate that these 'sentinel features' detect shift earlier/more cheaply than output-based detectors on an open model. Inference only.

**Why it matters:** A cheap internal early-warning signal for distribution shift / jailbreak attempts is exactly the kind of monitoring infrastructure valuable outside labs, scoped here to a small prototype.

**Relevant context:** Indicator-species analysis (IndVal) is standard community ecology. SAE features as monitorable internal signals are established; the indicator-species selection framing and OOD-sentinel evaluation are novel transfers.
