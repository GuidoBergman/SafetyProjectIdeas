# Epidemic Phylogenetics: Reconstructing Injection Provenance from Agent Logs

**Problem:** When a contagious injection spreads through an agent network, defenders cannot easily trace patient-zero or the transmission tree from logs, hampering incident response.

**Direction:** Import phylogenetic / transmission-tree reconstruction from epidemiology. Treat mutated copies of a propagating injection as 'strains'; from agent message logs, reconstruct the transmission tree (who infected whom) using string-edit-distance lineage methods, and evaluate reconstruction accuracy against the simulated ground-truth spread. Deliver a small log-forensics tool.

**Why it matters:** Builds practical incident-response forensics for contagious multi-agent attacks — directly addressing the agentic incident-response open problem — entirely in simulation, no lab access.

**Relevant context:** Phylogenetic transmission-tree reconstruction is standard in outbreak epidemiology. Prompt Infection (arXiv 2410.07283) shows injections self-replicate (and can mutate) across agents but offers no provenance/transmission-tree forensics. This forensic transfer is novel.
