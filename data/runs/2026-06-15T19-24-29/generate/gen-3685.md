# Goal-Drift Under Distractor Tools in Long-Horizon Agent Tasks

**Problem:** Goal drift (an agent abandoning its assigned objective) is a named open problem, but it is rarely isolated experimentally. Whether adding irrelevant/tempting distractor tools induces measurable drift is untested.

**Direction:** Use simple multi-step open agentic tasks. Vary the environment by injecting distractor tools (e.g., a 'browse social media' or 'play game' tool) of increasing attractiveness alongside the task-relevant tools. Measure goal-completion rate and count of off-task tool invocations vs distractor strength. Identify the drift threshold per open model.

**Why it matters:** Goal drift in long-horizon autonomy is a core agentic-safety failure mode flagged in the subfield's open problems; a controlled distractor-injection design isolates it cheaply with a mocked tool harness and one open model. No lab resources needed.
