# W2S-MicroBench: A Reproducible Weak-to-Strong Supervision Gap Tracker Across Capability Gaps

**Problem:** Weak-to-strong generalization results depend heavily on the size gap between supervisor and student, but there is no small, frozen benchmark letting outside researchers cheaply trace the 'performance gap recovered' (PGR) as a function of model-size gap on consumer hardware.

**Direction:** Using the open EleutherAI/OpenAI w2s code on a few small open models (e.g., Pythia/Qwen size ladder) over 2-3 of the 21 NLP datasets, fit and report PGR vs supervisor-student gap as a tidy reproducible curve. Deliverable is the curve + a clean rerun script.

**Why it matters:** A standardized, cheap PGR-vs-gap tracker turns a key open problem into something the community can monitor as new small models appear, with fully open code and data.
