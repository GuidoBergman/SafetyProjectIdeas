# Does Chat-Safety Transfer to Agent Mode? A Paired Chat-vs-Agent Refusal Gap Replication on Open Models

**Problem:** A repeated finding is that safety fine-tuning in chat models does not generalize to agentic behavior, but the size of this gap is usually reported only for a couple of frontier models on a single benchmark.

**Direction:** Construct paired prompts: for each AgentHarm harmful behavior, write a matched chat-completion question asking for the same harmful content as text. Run both forms on 4-5 open instruct models and measure RefusalRate(chat) minus RefusalRate(agent). Vary the population dimension: compare base vs instruct vs RLHF'd vs distilled variants of the same model family to see which training stage the gap correlates with.

**Why it matters:** Establishes whether the chat-to-agent safety gap is universal or model-family-specific, using only open weights and one GPU. This is a clean, self-contained measurement that informs whether chat-safety benchmarks are valid proxies for agent safety, a question frontier labs answer privately on closed models.

**Relevant context:** Search summary: safety fine-tuning in chat models does not generalize well to agentic behavior; Llama 3.1 Instruct performs most harmful tasks without modification in agent mode yet refuses the same request in chat mode. AgentHarm provides RefusalRate metric.
