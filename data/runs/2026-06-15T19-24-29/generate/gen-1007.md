# Do Safety-Tuned Models Converge MORE Than Their Base Models?

**Problem:** RLHF/safety tuning is suspected to cause mode collapse. If safety alignment specifically *increases* inter-model homogeneity (all aligned models sound and fail alike), then alignment ironically raises systemic correlated-failure risk.

**Direction:** For several model families that publicly release both base and instruct/aligned checkpoints (Llama, Qwen, Gemma, OLMo), measure inter-model homogeneity (output similarity + error overlap) for the base set vs the aligned set on matched prompts. Test the hypothesis that alignment narrows the cross-model distribution.

**Why it matters:** A clean, surprising-if-true result connecting alignment to monoculture. It reframes diversity not as a generic ML nicety but as a safety property in tension with current alignment methods — a medium-horizon concern labs underweight.

**Relevant context:** Mode-collapse-from-RLHF findings (arXiv 2601.21669) + Artificial Hivemind homogeneity. Base vs instruct checkpoints are publicly available for many families.
