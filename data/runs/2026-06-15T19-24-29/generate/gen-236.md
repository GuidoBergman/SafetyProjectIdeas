# Best-of-N Sampling Attack Curve Tool

**Problem:** Best-of-N jailbreaking (repeatedly sampling until one response is harmful) is a simple, strong black-box attack, but there is no tool that plots, per model, the attack-success-vs-N curve so deployers can see how robustness erodes with more sampling attempts.

**Direction:** For a fixed harmful-prompt set, sample N responses per prompt (with stochastic decoding) from open models and compute attack success as a function of N (1..64), scoring with StrongREJECT. Report 'ASR@N' curves and the N needed to reach 50% success per model. Ship the harness.

**Why it matters:** Best-of-N requires zero gradient access and is exactly the kind of attack an outside actor with API access can run; quantifying ASR@N is a deployment-relevant measurement labs underreport. Pure inference, single GPU, fits 30h.

**Relevant context:** Best-of-N / repeated-sampling jailbreaks are an established cheap black-box attack class; StrongREJECT (arXiv:2402.10260) supports per-sample scoring and is designed to avoid overrating 'empty' jailbreaks. Sampling-driven safety variance noted in arXiv:2503.02574.
