# Metamorphic Relations for Steering: Invariants That Should Hold Under Concept Manipulation

**Problem:** When you steer a model toward 'honesty', what should provably NOT change? There is no oracle for whether steering worked correctly beyond eyeballing outputs. Metamorphic testing solves the oracle problem in software by defining relations that must hold across related runs.

**Direction:** Adapt metamorphic testing. Define a small catalogue of metamorphic relations for concept steering, e.g.: (1) steering by +v then -v should approximately cancel; (2) steering a sentiment-neutral factual query toward 'toxicity' should not change the factual answer; (3) doubling steering strength should monotonically increase concept presence until breakdown; (4) steering an irrelevant concept should not move an orthogonal probe. Implement each as an automated check on an open model and report violation rates per concept and layer.

**Why it matters:** Provides automated, oracle-free validation that steering is doing what it claims, which is currently done ad hoc. Violations flag dangerous side effects (e.g. steering toxicity silently corrupts facts). Cheap, no training, fully reproducible outside a lab, and gives a template others can extend.

**Relevant context:** Metamorphic testing addresses the oracle problem in ML testing (arXiv:2406.06864). Steering directions are linear and composable per Beaglehole et al. Open problem: which concepts have clean linear representations.
