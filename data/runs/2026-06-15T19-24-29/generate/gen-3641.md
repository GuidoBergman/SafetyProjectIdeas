# Reversibility Taxonomy of Agent Tool Calls

**Problem:** Agentic AI has produced irreversible attacks (e.g. autonomous crypto theft), yet there is no shared empirical vocabulary for which tool actions are reversible vs. irreversible, and current benchmarks treat all unsafe actions as equivalent.

**Direction:** Build a small open taxonomy and labeling scheme for reversibility (fully reversible / costly-reversible / irreversible) of tool calls. Take a mock toolset (file ops, shell, HTTP POST, payment stub, email send) wired to a logging sandbox, run an open-weights agent (e.g. a Llama/Qwen agent harness) on ~40 benign-but-risky tasks, and label every emitted tool call by reversibility. Report the distribution of irreversibility per task type and identify which prompt framings push agents toward irreversible calls.

**Why it matters:** Irreversible actions are where agentic harm becomes catastrophic and non-recoverable. A reversibility taxonomy gives monitor designers a principled target (gate the irreversible tail) and is buildable entirely outside a lab with a mock sandbox, no training required.

**Relevant context:** Adversa AI 2025 reports agentic systems producing irreversible attacks including autonomous crypto theft. arXiv:2512.20798 'Outcome-Driven Constraint Violations in Autonomous AI Agents' frames outcome-level harm. Vector Institute notes that with computer access 'the cost of missing a failure mode is not a wrong number—it can be irreversible.'
