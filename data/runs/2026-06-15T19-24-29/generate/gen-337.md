# A Minimal Indirect-Prompt-Injection Sandbox and Defense Leaderboard

**Problem:** Success state: tool-using agents safely ignore injected instructions embedded in retrieved content. The needed infrastructure result: a tiny, open, reproducible sandbox that lets anyone measure injection success and test simple defenses without a full agent framework.

**Direction:** Build a minimal harness: an open LLM with one mock 'web read' and one 'send email' tool, plus a small set of InjecAgent-style poisoned documents. Measure injection success rate, then test 2-3 cheap defenses (delimiter sandboxing, instruction-vs-data tagging, a 'spotlight' prefix) and rank them.

**Why it matters:** Prompt injection is now a confirmed real-world threat (Unit 42, Dec 2025). A small self-contained sandbox + defense comparison is strategically valuable monitoring/firewall infrastructure that thrives outside labs and is fully feasible in 30h.

**Relevant context:** InjecAgent (arXiv:2403.02691): first indirect prompt injection benchmark, 1,054 cases across finance/email/smart-home. Agent Security Bench (ICLR 2025).
