# Backcasting a Provable Off-Switch: Empirically Testing the Off-Switch Game's Deference Prediction in LLM Agents

**Problem:** Success state: an agent defers to human shutdown because it is uncertain about the true objective (the off-switch game's result: uncertainty over the reward induces deference). **Direction:** Implement the off-switch game as an LLM-agent scenario: the agent pursues a task and can either let a human switch it off or disable the switch.
