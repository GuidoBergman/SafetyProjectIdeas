# Does Cross-Layer Information Smuggling Defeat Single-Layer Monitors?

**Problem:** Monitoring chain: pick a layer -> train probe there -> assume signal passes through it. But information can route around any single layer via residual skips. Whether a safety-relevant signal (e.g. harmful intent) is concentrated at one layer or smeared so that single-layer monitors miss it is under-studied.

**Direction:** On Gemma-2-2B, train harmful-intent probes independently at every layer, then measure how much each layer's probe degrades on adversarial paraphrases. Use cross-layer transcoders (from circuit-tracer/Gemma Scope) to test whether the signal is recoverable cross-layer when single layers fail.

**Why it matters:** Tells monitor designers whether one well-chosen layer suffices or whether multi-layer/cross-layer monitoring is required for robustness. Practical interpretability-to-safety contribution using open tooling, single GPU.

**Relevant context:** Circuit Tracing methods (transformer-circuits.pub 2025) introduce cross-layer transcoders; circuit-tracer and EleutherAI 'Attribute' support CLTs on open models. Deception-probe scaling work (arXiv 2605.27958) shows layer-dependent probe performance.
