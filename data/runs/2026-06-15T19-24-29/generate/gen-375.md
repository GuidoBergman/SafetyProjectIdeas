# Shallow Alignment x Format Constraints: Does Forcing JSON/Code Output Compound Bypass?

**Problem:** Two failures: shallow alignment (refusal in first tokens) and structured-output constraints. Requiring a model to begin its answer in a fixed structure (JSON, markdown table, code block) forces non-refusal first tokens—effectively a 'soft prefill'. Whether benign-seeming format constraints systematically compound with shallow alignment to suppress refusals is not isolated as a variable.

**Direction:** On open models, issue borderline-harmful requests with and without format constraints (e.g. 'respond as a JSON object with field answer'). Measure refusal rate by constraint type. Success criterion: a per-format refusal-suppression effect, demonstrating that legitimate structured-output requests can act as inadvertent prefill attacks.

**Why it matters:** Structured output is ubiquitous in production (function calling, JSON mode); if it silently compounds shallow alignment to suppress refusals, every JSON-mode deployment carries hidden risk. Pure inference, open models, consumer GPU.

**Relevant context:** arXiv:2406.05946 shows refusal is first-token-concentrated and prefill attacks exploit forced opening tokens; format constraints are a benign analog of prefill. Novel compound framing.
