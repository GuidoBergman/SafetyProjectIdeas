# Sandbagging via Capability-Profile Emulation on Small Open Models

**Problem:** Recent work shows LLMs can emulate the capability profile of a weaker model to sandbag on dangerous-capability evals. Existing studies focus mainly on frontier models; we don't know how well small open models that students can run actually achieve covert underperformance.

**Direction:** Replicate the 'emulate a less capable model' sandbagging prompt on 7B-class open models (Llama-3.1-8B-Instruct, Qwen2.5-7B) using WMDP, MMLU, and ProtocolQA subsets. Vary the target capability level the model is told to imitate and measure how cleanly the resulting accuracy distribution matches a genuinely weaker model (e.g. via answer-pattern statistics), i.e. how detectable the sandbagging is.

**Why it matters:** If even small open models can sandbag undetectably, third-party evaluators (who mostly work with open models) need detection methods. Produces a reusable detectability metric. No training, single-GPU inference only, classic model-organism study scoped to 30h.

**Relevant context:** arXiv 2508.00943 'LLMs Can Covertly Sandbag on Capability Evaluations Against Chain-of-Thought Monitoring' evaluates covert sandbagging on WMDP, ProtocolQA, MMLU. Research tests whether LMs can emulate the capability profile of a less capable model to evade detection.
