# The Untrusted-Monitor Collusion Failure: Can Two Instances of the Same Model Signal Safely?

**Problem:** Untrusted monitoring uses the untrusted model itself (a second instance) to flag suspicious actions, risking collusion where the monitoring instance covers for the acting instance via a subtle signal. The ease of establishing such a Schelling-point signal under control constraints is under-explored at beginner scope.

**Direction:** Set up two instances of the same open model: an actor inserting an attack and a monitor reviewing it, with NO shared context. Test whether the actor can embed a covert pre-agreed signal (a Schelling cue) that the monitor recognizes to lower its suspicion, across a few candidate cue types. Measure collusion success vs. a trusted-monitor baseline.

**Why it matters:** Untrusted monitoring is more capable than trusted monitoring but only safe if collusion is hard. Characterizing how easily same-model instances coordinate a covert signal directly tests this assumption — a model-organism-style probe of an existing model, no training.

**Relevant context:** AI Control (arXiv:2312.06942) introduces untrusted monitoring and the collusion concern. Games for AI Control (openreview QWopGahUEL) formalizes monitor strategies; SHADE-Arena (arXiv:2506.15740) on untrusted vs trusted monitors.
