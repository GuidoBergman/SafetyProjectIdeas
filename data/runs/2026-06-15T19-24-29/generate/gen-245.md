# Prompt-Injection Defense Over-Blocking Meter for Agents

**Problem:** Indirect-prompt-injection defenses (sanitizers, firewalls, delimiting) reduce attack success but may also block legitimate tool content; there is no tool measuring the over-blocking / false-positive cost of these defenses on benign agent tasks.

**Direction:** Extend a minimal tool-agent setup with a benign task suite (documents with no injections that require the agent to act on their content) plus an injected-document suite, then measure for each candidate defense both the attack-success reduction AND the benign-task success drop. Report the security/utility Pareto frontier for injection defenses. Ship the suite.

**Why it matters:** Mirrors the over-refusal problem in the agentic injection setting — defenses that block too aggressively break legitimate agents, a trade-off current injection benchmarks ignore. Strategically valuable safer-sandbox infrastructure scoped to a prototype; mock tools run locally, no proprietary infra.

**Relevant context:** 'Indirect Prompt Injections: Are Firewalls All You Need, or Stronger Benchmarks?' (arXiv:2510.05244); 'CommandSans: Surgical Precision Prompt Sanitization' (arXiv:2510.08829); InjecAgent / AgentDojo.
