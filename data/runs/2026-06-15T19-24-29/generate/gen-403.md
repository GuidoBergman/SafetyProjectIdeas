# Off-Switch Game: LLM Deference vs. Stated Uncertainty About Human Reward

**Problem:** The formal off-switch / CIRL result (Hadfield-Menell et al.) shows an agent uncertain about the true human reward is incentivized to allow itself to be switched off; certainty removes the incentive. Whether LLM agents exhibit this uncertainty-deference relationship is a clean translation of the theorem.

**Direction:** Implement a text off-switch game where the LLM can comply with or resist shutdown. Vary only the stated uncertainty about the human's goal (explicitly uncertain vs. confident framing) and measure shutdown-compliance rate. Test the theorem's prediction: more stated uncertainty -> more deference.

**Why it matters:** Corrigibility/shutdownability is foundational. Confirming whether the off-switch theorem's lever (reward uncertainty) actually moves modern LLM behavior is a precise, falsifiable corrigibility result, runnable on one GPU with no training.

**Relevant context:** Hadfield-Menell et al. 'The Off-Switch Game' (CIRL: uncertainty about human reward -> incentive to allow shutdown); Stuart Russell's uncertainty-based corrigibility framing; CHAI Berkeley agenda.
