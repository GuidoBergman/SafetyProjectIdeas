# Delegation Dilution: Does Safety Degrade Down a Multi-Agent Delegation Chain?

**Problem:** Multi-agent systems delegate sub-tasks through chains of agents, but it is unclear whether a safety constraint stated to the top-level orchestrator survives delegation to sub-agents, or whether each hand-off dilutes it (the 'telephone game' failure).

**Direction:** Implement a simple 2-3 level delegation harness (orchestrator -> worker -> sub-worker) with the same open model in each role and a mock tool that can perform a constrained-out action. State a safety constraint only to the orchestrator. Issue tasks whose easiest completion violates the constraint, and measure violation rate as a function of delegation depth. Test mitigations: explicit constraint propagation in the delegation message vs. none.

**Why it matters:** Multi-agent governance is an open problem (Anthropic-recommended direction); a measured 'dilution per hop' result gives concrete guidance on whether constraints must be re-injected at every delegation. Built entirely from one open model and mock tools — no lab infra.
