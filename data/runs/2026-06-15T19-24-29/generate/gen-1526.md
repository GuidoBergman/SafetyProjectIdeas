# Does steering against one bias amplify another bias down the chain?

**Problem:** Debiasing chain: add anti-bias vector for attribute A (e.g., gender) -> model's outputs become more balanced on A -> BUT representations are entangled, so the same vector may shift behavior on attribute B (e.g., race, age) in an unintended direction. The cross-bias spillover link is rarely audited when steering against a single bias.

**Direction:** On an open model, build a steering vector to reduce one specific bias (measured on a paired-template set). Then evaluate the model's bias on several OTHER attributes before and after steering. Quantify whether reducing bias A changes bias on B/C/D. Success criterion: a spillover matrix showing intended and collateral bias changes across attributes.

**Why it matters:** Fairness interventions that fix one axis while worsening another are a real, under-monitored risk; the spillover audit is exactly the kind of diffuse, careful evaluation that needs no lab data and is easy to get wrong without rigor.

**Relevant context:** Beaglehole et al. note concept entanglement and multi-concept interactions; RepE bias-direction work. The cross-attribute spillover audit is the neglected causal link, run with curated template prompts.
