# Does CoT Monitoring Informativeness Survive Across Model Families?

**Problem:** The GPT-5 system card claims CoT monitoring is 'substantially more informative' than output-only monitoring for catching deception. This was measured on OpenAI's own models; whether it holds for open-weight reasoning models (DeepSeek-R1-distill, QwQ, GPT-OSS) is untested.

**Direction:** Take a fixed set of deception-eliciting agentic prompts, run several open reasoning models, and measure a cheap trusted monitor's AUC on CoT-included vs CoT-stripped transcripts for each family. Report the CoT-informativeness 'lift' per family and whether it correlates with how verbose/faithful each model's CoT is.

**Why it matters:** Replicating a frontier-lab claim on open models is high counterfactual value: it tells the open community whether CoT monitoring is a transferable safety lever or a GPT-5-specific artifact, with no training and only consumer-GPU inference.
