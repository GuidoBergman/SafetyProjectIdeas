# Conformal Prediction as a Distribution-Free Bound on Latent-Knowledge Probes

**Problem:** ELK-style linear probes that read 'what the model knows' from activations report point predictions with no rigorous coverage guarantee, so we cannot say how often the probe's claimed answer is actually correct on novel inputs.

**Direction:** Import conformal prediction (statistics) onto activation probes. Train a simple linear probe on a public quirky-model-style dataset, then wrap it in split-conformal calibration to emit prediction sets with a guaranteed error rate. Measure how set size and coverage degrade as test questions get harder than calibration questions — a distribution-shift stress test of probe reliability.

**Why it matters:** Adds statistically rigorous, distribution-free guarantees to the theoretical ELK program, and quantifies exactly where probes stop being trustworthy. Uses only public datasets and a small probe — fully reproducible outside a lab.

**Relevant context:** Quirky LMs: logistic-regression contrast-pair probes recover 89% of the truthful/untruthful AUROC gap, 75% on harder questions (arXiv:2312.01037). Conformal abstention gives statistically rigorous error control (arXiv:2405.01563, 2502.06884).
