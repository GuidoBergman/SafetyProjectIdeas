# An Open Reproduction of 'Common Elements' Scoring as a Living Diff Tool

**Problem:** METR's Common Elements reports are periodic PDF snapshots; the field lacks a lightweight, reproducible pipeline that detects how a single lab's safety policy text changes between versions and whether changes strengthen or weaken commitments.

**Direction:** Collect archived versions of one or two labs' safety policies (via Wayback Machine / git of public repos). Build a diff + LLM-classification pipeline that labels each textual change as strengthening, weakening, clarifying, or cosmetic, with a rubric. Validate on a hand-labeled subset and report the trajectory of commitment strength over time.

**Why it matters:** Continuous monitoring of policy erosion is a strategically valuable, low-cost governance infrastructure that no lab will build about itself; it directly supports third-party accountability and is fully reproducible from public archives.

**Relevant context:** METR Common Elements Mar 2025 and Dec 2025 updates; ailabwatch.org commitments tracker; California SB 53 framework-disclosure requirement.
