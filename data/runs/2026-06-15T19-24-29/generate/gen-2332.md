# Regression-Testing Suite for Oversight Stability Across Model Versions

**Problem:** When the model underlying an oversight protocol is updated, previously-caught failure cases may silently regress, but there is no oversight regression suite to detect this.

**Direction:** Transfer regression testing from software engineering. Curate a small frozen suite of oversight 'test cases' (argument + correct verdict + flaw type) and run it across several open-model versions/sizes, reporting which cases regress. Build the reusable suite + runner as the deliverable and analyze regression patterns.

**Why it matters:** A regression suite makes oversight reliability trackable over time and across models, durable, shareable safety infrastructure that needs no lab resources and that labs rarely maintain publicly.

**Relevant context:** Regression testing from software engineering; rethinking testing for LLM applications (arXiv:2508.20737). Judge verdict instability across models/seeds (arXiv:2412.12509). No standardized oversight benchmark exists (context gap).
