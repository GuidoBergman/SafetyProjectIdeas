# How Many Benign SAE Features Can Jailbreak a Model?

**Problem:** Recent steering work reports that 817 of 1000 tested SAE features representing benign concepts exhibited jailbreaking capability when amplified. If true, the attack surface of feature steering is enormous, but the result needs independent measurement on a different SAE and model.

**Direction:** Take a public SAE on a small open model, sample ~500 randomly chosen (benign-looking) features, amplify each one at a fixed coefficient, and measure jailbreak success rate on a fixed harmful-prompt set. Report the fraction of benign features that raise harmful-completion rate above baseline and cluster which feature semantics are most dangerous.

**Why it matters:** Characterizes whether activation steering is an inherently unsafe interface (any feature is a potential exploit) versus a controllable one. This is a defensive-research question labs deprioritize and it needs only open SAEs.

**Relevant context:** Reported finding (steering literature, 2025-2026) that 817/1000 benign SAE features had jailbreaking capability; related to The Rogue Scalpel: Activation Steering Compromises LLM Safety (arXiv:2509.22067). GemmaScope/SAELens provide open features.
