# EWMA Charts for Per-Tool Anomaly Profiling in Agent Deployments

**Problem:** Agents call many tools; a sabotage often manifests as an unusual rate or argument pattern for one specific tool (e.g., sudden bursts of file writes or network calls). Aggregate monitoring can wash this out.

**Direction:** Apply per-stream EWMA (exponentially weighted moving average) control charts, one per tool/argument-type, to an agent's action stream. Learn benign EWMA bounds from clean trajectories, then run sabotage trajectories and detect which tool-stream chart fires first and how early relative to the actual harmful action. Compare to a single global monitor.

**Why it matters:** Provides fine-grained, interpretable, real-time tool-usage anomaly detection that localizes which capability is being abused, useful for kill-switch design. EWMA is trivial to implement and runs on logged trajectories with zero training.

**Relevant context:** EWMA control charts detect small sustained shifts in a monitored stream (SPC; arXiv:2503.01858 AI in SPC survey). SHADE-Arena environments expose 340+ tools (arXiv:2506.15740), giving rich per-tool streams to chart.
