# Monitoring Reward Hacking Live From Internal Activations vs Post-Hoc From Text

**Problem:** A 2026 result monitors emergent reward hacking during generation via internal activations. It is unclear how much earlier an activation monitor flags reward hacking compared to a text-based CoT monitor reading the same trajectory.

**Direction:** On a reward-hackable coding task with an open model, collect both per-token activations and the generated CoT. Fit a simple activation probe for 'about-to-reward-hack' and compare the token position at which it fires vs when a text monitor flags the same trajectory. Report detection-latency difference.

**Why it matters:** Earlier detection enables interruption before the harmful action commits — central to runtime control. A latency comparison is a crisp, novel result; activation extraction on a small open model fits the compute budget.
