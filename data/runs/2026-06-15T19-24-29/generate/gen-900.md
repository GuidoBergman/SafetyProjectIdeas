# Backcasting from 'Open-Weight Release Decisions Are Evidence-Based': A Reproducible Marginal-Risk Mini-Audit

**Problem:** A success state for open-weight governance requires release decisions grounded in measured marginal risk (what new capability does releasing this model add beyond already-available models?). Today this marginal analysis is rarely done quantitatively, so 'marginal risk is low' is asserted, not shown.

**Direction:** Pick a dual-use-adjacent but safe public benchmark (e.g., a hazardous-knowledge MCQA proxy or a public cyber-CTF reasoning set) and compare a newly-released open model against an older open model and a closed API on that benchmark, computing the marginal score delta. Demonstrate a small, reproducible 'marginal capability uplift' workflow that a release-decision body could run, with explicit success criteria and uncertainty bounds.

**Why it matters:** Backcasting from 'sound open-weight release decisions' shows the missing precondition is a cheap, standardized marginal-uplift measurement. A reproducible mini-audit operationalizes the OECD marginal-risk concept into something a small actor can run. No training, only inference on public/open models — high counterfactual value for a medium-horizon proliferation threat.

**Relevant context:** OECD.AI marginal-risk analysis for open-weight models; 'Estimating Worst-Case Frontier Risks of Open-Weight LLMs' (arXiv:2508.03153); International AI Safety Report 2026. Open Problems in Technical AI Governance on operationalization.
