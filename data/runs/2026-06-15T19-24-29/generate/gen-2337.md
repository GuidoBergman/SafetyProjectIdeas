# Position Bias Compounding Through Oversight Layers

**Problem:** LLM judges have position/order bias (swapping answer order shifts accuracy by >10% in code judging). In recursive oversight, a judgment feeds the next layer. Causal chain: layer-1 judge has position bias -> its noisy output orders layer-2 candidates -> bias compounds -> final oversight verdict diverges from truth. The under-studied link is how a single-layer bias propagates and amplifies across stacked judgments.

**Direction:** Simulate a 2-3 layer recursive judging pipeline with a small open model. At each layer measure position-bias-induced flip rate, then propagate verdicts forward and measure whether final-layer error exceeds the single-layer rate. Test order-randomization and swap-and-average as cheap mitigations and quantify how much they dampen compounding.

**Why it matters:** Recursive oversight protocols assume per-layer errors don't catastrophically compound. This gives a concrete, lab-independent measurement of compounding for a well-documented bias, plus a tested cheap mitigation.

**Relevant context:** Documented position bias causes >10% accuracy shifts under order swaps (LLM-as-a-Judge bias literature, arXiv:2410.02736); recursive reward modeling / iterated amplification assume bounded per-layer error (Anthropic recommended directions). Compounding across simulated layers is under-studied empirically.
