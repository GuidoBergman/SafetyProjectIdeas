# Replicating METR's 'Common Elements of Frontier Safety Policies' Coding Scheme on the Seoul Summit Signatories

**Problem:** METR distilled common elements of frontier AI safety policies (capability thresholds, dangerous-capability evals, mitigation protocols, pause commitments). Sixteen companies committed at the Seoul Summit 2024 to publish such frameworks, but no public artifact systematically codes WHICH common elements each signatory actually included versus omitted, or how vague the commitments are.

**Direction:** Operationalize METR's common-elements list into a binary/ordinal coding scheme, then code each signatory's published safety framework against it (present / partial / absent / vague). The twist is broadening from the handful of analyzed leaders to the full Seoul cohort, plus adding a 'specificity' score per commitment. Produce a coverage matrix and a vagueness ranking.

**Why it matters:** Directly addresses the open problem of the gap between voluntary codes and enforceable standards by quantifying how hollow or substantive each lab's voluntary commitment is. Pure document analysis, no compute, high counterfactual value.

**Relevant context:** Grounded in METR 'Common Elements of Frontier AI Safety Policies', Seoul Summit 2024 (16 signatories), and Anthropic RSP / DeepMind FSF / Meta framework. EU Code of Practice context for the voluntary-vs-enforceable gap.
