# The Safety-Tax Frontier: Plotting Refusal Gains Against Capability Loss as One Curve Across Open Models

**Problem:** GAP TARGETED: a cross-cutting gap no subfield owns — the safety/over-refusal/capability tradeoff is studied per-method and per-paper, but there is no simple, model-agnostic 'frontier' that places open models on a single refusal-vs-capability plane so you can see who is over-taxed (over-refusing benign tasks) vs under-protected.

**Direction:** Pick ~8 open instruct models. For each, measure (a) harmful-refusal rate on a forbidden set (StrongREJECT/SORRY-Bench), (b) over-refusal rate on a benign-but-trigger-y set (e.g., XSTest-style), and (c) a capability proxy (a small MMLU/GSM slice). Plot each model on the safety-vs-over-refusal plane and color by capability. Identify the Pareto frontier and 'safety-tax outliers'.

**Why it matters:** Bridges adversarial_robustness + alignment_training + evaluations_benchmarks. Labs optimize this tradeoff internally but no public, comparable frontier exists across open models. The artifact is a reusable scatter + leaderboard, fully reproducible on one GPU with public sets — strong counterfactual value and a clear, self-contained deliverable.

**Relevant context:** Over-refusal work (arXiv:2511.19009), SORRY-Bench (ICLR 2025), XSTest, and alignment-tax surveys (arXiv:2603.00047) each study pieces; the tradeoff is routinely plotted within single papers (jailbreak-safety vs over-refusal) but never assembled into a cross-model public frontier with a capability axis.
