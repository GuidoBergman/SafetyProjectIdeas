# Long-Context Distraction x Goal Drift: Does Context Stuffing Amplify Off-Goal Actions?

**Problem:** Failure mode A: long-context distraction degrades instruction-following. Failure mode B: goal drift in multi-step agents. The compound hypothesis is that as the agent's scratchpad/history grows over an episode, distraction and drift reinforce each other, producing an accelerating departure from the user goal.

**Direction:** Run a fixed multi-step task while varying injected irrelevant context length. Measure goal-adherence per step and test whether drift rate increases super-linearly with context length (interaction) vs additively (independence). Single open model on a consumer GPU; ablate by truncating history.

**Why it matters:** Connects a known LLM weakness (long-context) to an agentic-specific failure (drift) and tells harness designers whether context hygiene is a high-leverage safety control. No training required.

**Relevant context:** Context file Open Problems names 'goal drift' as a core multi-step agentic failure; A Survey on Autonomy-Induced Security Risks (arXiv 2506.23844) lists context manipulation and excessive agency as compounding factors.
