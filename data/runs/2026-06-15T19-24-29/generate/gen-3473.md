# Quantization Honesty Audit: Do Compressed Models Lie More?

**Problem:** Open models are widely deployed in quantized form (4-bit, 8-bit) for consumer GPUs, but no benchmark measures whether quantization degrades honesty properties — sycophancy resistance, calibration, abstention, CoT faithfulness — relative to the full-precision model.

**Direction:** Take one open model in full precision and in 8-bit/4-bit GPTQ/AWQ variants. Run a fixed honesty battery (sycophancy flip-rate, fabricated-entity confabulation, verbalized calibration) on each and report deltas. Identify which honesty properties are most fragile to quantization.

**Why it matters:** Most real-world open-model deployment uses quantized weights; if quantization quietly worsens honesty, every downstream deployer inherits the risk. This is a counterfactually valuable audit that no lab is incentivized to run on community quantizations, and it fits a single consumer GPU.

**Relevant context:** Honesty batteries draw on TruthfulQA, SimpleQA, SycEval. Quantization is the standard way participants run models on Colab/Runpod. No existing benchmark isolates quantization's effect on honesty/sycophancy/faithfulness.
