# Multi-Level Interpretability of ViTs: Are Single Features Enough?

**Problem:** Recent ViT analysis ('Sparse but not Simpler') suggests vision representations need multi-level interpretability rather than single monosemantic features. The practical degree to which individual vision-SAE latents are insufficient on safety-relevant visual concepts is unmeasured.

**Direction:** Using pre-trained Prisma SAEs, test how many SAE latents are needed to reliably detect a target visual concept (single best latent vs. top-k vs. linear combination), for both neutral concepts and safety-relevant ones (e.g. weapons, faces). Report a 'monosemanticity sufficiency' curve per concept type.

**Why it matters:** If safety-critical visual concepts require many distributed features, single-feature monitoring of vision models is inadequate — important as multimodal models are deployed in surveillance/autonomy. Uses only open SAEs.

**Relevant context:** 'Sparse but not Simpler: A Multi-Level Interpretability Analysis of Vision Transformers' (arXiv 2603.15919); 'Probing the Representational Power of SAEs in Vision Models' (ICCVW 2025). Prisma provides 80+ pre-trained vision SAEs.
