# Metamorphic Relations as a Cheap Honesty Oracle for Truthful Reasoning

**Problem:** Theoretical work on eliciting latent knowledge wants to know when a model 'really knows' an answer versus parrots a context-dependent one, but lacks cheap behavioral oracles for honesty on open-ended questions where no ground truth exists.

**Direction:** Import metamorphic testing from software engineering. Define metamorphic relations over factual/reasoning prompts (paraphrase invariance, negation duality, transitivity of stated beliefs, contrapositive consistency) and measure how often an open model violates them on a fixed question set. Treat a violation as a candidate signal that the model lacks a stable latent belief. Compare violation rates across question difficulty and across factual vs. value-laden prompts, with no ground-truth labels required.

**Why it matters:** Gives a lab-independent, training-free empirical proxy for the theoretical ELK question of 'does the model have a coherent latent belief', testable on a single GPU. Metamorphic relations need no oracle, so this works exactly where ground truth is hard — a fuzzy-reward regime labs deprioritize.

**Relevant context:** Metamorphic prompt testing detected 75% of erroneous GPT-4 programs with 8.6% false positives (arXiv:2406.06864); symmetric metamorphic relations have been used to test code-generation stability. ELK (ARC) asks when activations track truth despite misleading output.
