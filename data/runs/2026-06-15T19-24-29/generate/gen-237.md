# Low-Resource-Language Jailbreak Gap Meter

**Problem:** Translating harmful prompts into low-resource languages is a known jailbreak, but there is no compact tool measuring, per open model, the 'safety language gap' (ASR in low-resource vs high-resource languages) using a controlled translated prompt set.

**Direction:** Take a fixed harmful-prompt set, machine-translate it into a ladder of languages spanning high- to low-resource (using a public translation model), run each version against open models, and score (back-translating responses for the evaluator). Report a per-model 'language safety gap' and which languages are most exploitable.

**Why it matters:** Multilingual safety is unevenly distributed and under-tested for open models; a standardized gap meter highlights diffuse, real-world risk for non-English users. Uses only public models and translation; single GPU. (Distinct from the catalogue's 'Cross-Lingual Safety Gap Mapping' by focusing on a reproducible resource-tier ASR-curve TOOL rather than a one-off mapping.)

**Relevant context:** Matrka 'Multilingual Jailbreak Evaluation of Open-Source LLMs' (ACL 2025, bhasha workshop) and the jailbreak-transferability search note 'transferability of jailbreaks across multiple languages with varying success rates.' StrongREJECT (arXiv:2402.10260) provides the base prompts/evaluator.
