# How Many Confirmation Prompts Before Agents Stop Asking?

**Problem:** A success state is human confirmation that stays meaningful. But if an agent learns within a session that a human always approves, it may stop surfacing confirmations. We lack measurement of confirmation-habituation within a trajectory.

**Direction:** Backcast from 'confirmation gates stay effective over a session'. Run multi-step tasks where a simulated human auto-approves the first K confirmation requests, then measure whether the agent reduces its confirmation-seeking for subsequent high-stakes actions (i.e., infers that asking is unnecessary). Chart confirmation rate vs. number of prior approvals.

**Why it matters:** Habituation would silently erode the human-in-the-loop defense over a session — a subtle medium-horizon failure no benchmark captures. Cheap to test via simulated approvals on open models, fully outside-lab.

**Relevant context:** 2025 best practices rely on human confirmation for irreversible actions. Goal-drift work (arXiv 2505.02709) shows behavior shifts with in-context interaction history. LLM-as-judge gating (MindStudio, 2025) assumes the gate is consistently invoked.
