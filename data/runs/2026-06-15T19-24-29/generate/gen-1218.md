# Cascading-Failure Sandbox: A Toy Pipeline Where One Shared Model Breaks Everything

**Problem:** Success state: we have a reproducible demonstration and harness showing how a single shared-model error cascades through dependent systems, so mitigations can be tested. Backward: cascading-failure propagation when critical systems share a provider is an open problem with no public, runnable model.

**Direction:** Build a small 3-4 stage pipeline (e.g., extractor -> summarizer -> decision-maker -> verifier) where each stage is the SAME base model vs. DIFFERENT models. Inject realistic ambiguous inputs and measure how often a stage-1 error survives downstream when stages share a model (correlated) versus differ (independent). Quantify the cascade-amplification factor of homogeneity.

**Why it matters:** Real deployments chain models; if every link shares blind spots, the verifier rubber-stamps the same mistake the extractor made. A small sandbox makes the abstract cascade concept concrete and gives the community a reusable testbed — strategically valuable infrastructure.

**Relevant context:** Addresses the cascading-failure open problem (International AI Safety Report 2026). Toy pipeline of open models fits a 30h single-GPU budget.
