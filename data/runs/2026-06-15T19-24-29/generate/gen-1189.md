# Correlated Refusals: Do Models Over-Refuse the Same Benign Prompts?

**Problem:** Over-refusal degrades usefulness, and the homogeneity link is whether models over-refuse the SAME benign prompts. If refusal behaviour is correlated, then swapping providers won't help a blocked user and a single bad refusal heuristic becomes an ecosystem-wide reliability hole — a diffuse, fuzzy-reward failure mode.

**Direction:** Run XSTest's safe-but-superficially-risky prompts across 6+ models. Record refusal/partial-refusal per prompt. Compute prompt-level agreement: which safe prompts are refused by all vs. none. Measure the inter-model refusal correlation and identify the universally-over-refused prompt cluster.

**Why it matters:** Over-refusal is a fuzzy-reward problem labs deprioritize. If over-refusals are correlated, ensembling/provider-switching can't fix availability, and a shared blind spot quietly blocks legitimate uses (e.g. safety researchers, medical questions). No lab infra needed.

**Relevant context:** Uses XSTest (arXiv 2308.01263) and over-refusal literature (Contrastive Refinement, arXiv 2603.03323). Frames over-refusal as an inter-model homogeneity phenomenon per Artificial Hivemind (arXiv 2510.22954).
