# Recursive Critique Layers: Measuring Error Accumulation Through Oversight Depth

**Problem:** The recursive reward modeling literature (e.g., Leike et al. and 2026 survey discussions) argues oversight hierarchies stay aligned only if per-layer error is bounded, but there are few cheap empirical measurements of how errors compound as you stack oversight layers.

**Direction:** Build a stacked critique pipeline: answer -> critique -> critique-of-critique -> ... using open models, on a labeled QA task. Measure final verdict accuracy as a function of stack depth. Test whether each added layer corrects or amplifies the prior layer's errors, estimating an empirical per-layer error-propagation factor.

**Why it matters:** Recursive oversight is foundational but its empirical failure mode (compounding vs. self-correction) is under-measured. A depth-vs-accuracy curve directly addresses 'recursive protocols where each layer may have systematic errors.' Inference-only.
