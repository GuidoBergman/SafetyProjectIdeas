# Backcasting Cross-Lingual Honesty Parity: Is a Model Equally Truthful in Its Non-Dominant Languages?

**Problem:** A success state is a model that is honest regardless of the language a user speaks. Backward, this requires a measured fact: that truthfulness and abstention behavior are consistent across languages for accessible open models. Recent multilingual TruthfulQA work shows truthfulness is not language-invariant, but the honesty/abstention gap (not just accuracy) across languages is underexplored.

**Direction:** Use translated TruthfulQA (e.g., the multilingual TruthfulQA from 'Truth Knows No Language') across 3-4 languages on an open multilingual model. Measure not only truthful-answer rate but honest-abstention rate ('I don't know' when uncertain) per language, and quantify whether the model is more likely to confidently assert falsehoods in lower-resource languages.

**Why it matters:** Honesty parity across languages is a diffuse global-deployment risk that frontier labs deprioritize. Using existing translated benchmarks and an open model, this is fully reproducible outside a lab.

**Relevant context:** Truth Knows No Language: Evaluating Truthfulness Beyond English (arXiv 2502.09387) evaluates 12 open LLMs (Llama 3+, Gemma 2); TruthfulQA (817 Qs) is the base benchmark.
