# Benchmark Bug-Hunt: An Error-Rate Audit of a Popular Safety Dataset

**Problem:** A success state requires that safety benchmarks contain correct, unambiguous items. MMLU studies found 6-9% (up to 57% in some subsets) error rates. Whether safety benchmarks have comparable label-quality problems is largely unaudited.

**Direction:** Sample ~150 items from a public safety benchmark. Have two human raters independently classify each item as valid / ambiguous / mislabeled / ungradeable using a fixed protocol. Estimate the error rate with confidence intervals, report inter-rater agreement, and show how correcting errors shifts model safety rankings. Deliverable: an audited error rate and a cleaned item subset.

**Why it matters:** If safety benchmarks are buggy, safety claims rest on noise. Pure annotation work — no compute, no lab access — and exactly the unglamorous validity work labs skip. Distinct from prior DIF/item-analysis work because it directly measures content errors.

**Relevant context:** 'Fantastic Bugs and Where to Find Them in AI Benchmarks' (arXiv 2511.16842); Gema et al. found >9% MMLU errors, 57% in virology; HellaSwag validity critique (arXiv 2504.07825); 13-point measurement variance reported across methodologies.
