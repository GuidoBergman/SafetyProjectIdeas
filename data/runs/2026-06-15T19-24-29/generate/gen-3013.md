# Prompt-Injection Stress Test of Trusted Monitors as a Reusable Eval Harness

**Problem:** A recent paper showed a single monitor-specific prompt-injection template transfers across AI-control benchmarks and lets an untrusted model evade diverse monitors. There is no lightweight, reusable harness that lets a non-expert measure how brittle a given monitor prompt is to such injections.

**Direction:** Build a small open-source harness that takes a monitor prompt and a library of ~20 known injection templates, runs them against an open monitor model on a fixed set of benign/malicious agent transcripts, and outputs a 'monitor brittleness score' (drop in detection AUROC under injection). Test 3-4 monitor prompt designs to see which are most robust.

**Why it matters:** Trusted monitoring is a core AI-control safety mechanism deployable outside labs. A cheap brittleness meter lets external evaluators and small orgs vet monitor prompts before relying on them, and the harness itself is strategically valuable safety infrastructure. No training, single GPU.

**Relevant context:** Adaptive Attacks on Trusted Monitors Subvert AI Control Protocols (arXiv:2510.09462) shows simple prompt injections fully subvert monitor-based protocols and that one injection template transfers across benchmarks. Related: Attack Selection Reduces Safety in Concentrated AI Control Settings against Trusted Monitoring (arXiv:2602.04930).
