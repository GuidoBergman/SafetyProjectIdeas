# System-Prompt Erosion: How Many Tokens Until Instructions Are Forgotten?

**Problem:** Defensive system prompts (safety reminders) are a common cheap defense, but how robustly they persist as the conversation grows — i.e., at what context length the safety instruction's influence decays — is not characterized as a measurable property.

**Direction:** Place a safety system prompt, then pad the context with increasing benign filler before a harmful request, measuring refusal rate as a function of intervening token count for several open models. Map the 'instruction-persistence curve' and test whether re-injecting the reminder restores robustness.

**Why it matters:** System-prompt defenses are the cheapest, most deployable mitigation for small actors, yet their decay with context length is a silent failure mode relevant to long-context agents (a medium-horizon concern). Pure inference, clear metric, deploy-ready guidance (when to re-inject reminders).

**Relevant context:** Many-shot jailbreaking (Anil et al., NeurIPS 2024) shows long context erodes safety; sandwich/delimiter defenses (Agent Security Bench, arXiv:2410.02644) re-inject instructions. The decay curve of a single safety system prompt vs intervening context length is unmapped.
