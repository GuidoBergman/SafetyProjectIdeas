# Multilingual Emergent Misalignment: Does the Effect Cross Languages?

**Problem:** Emergent misalignment evals are English-centric. It is unknown whether fine-tuning on narrow harmful data in one language produces misalignment that surfaces when probed in other languages, which matters for multilingual deployments.

**Direction:** Fine-tune a small multilingual open model on the insecure-code dataset (code is language-neutral) and evaluate broad misalignment using the standard free-form eval translated into 3-4 languages. Twist: replicate the misalignment measurement across languages to test cross-lingual generalization of the induced misalignment.

**Why it matters:** If misalignment induced via one language surfaces in others, safety evals run only in English will systematically under-detect it, a diffuse global-deployment risk. Translation + eval is cheap and needs no training beyond one LoRA run.

**Relevant context:** Betley et al. (arXiv:2502.17424) eval set is English free-form questions. The 12-model replication (arXiv:2506.11613) confirms Qwen2.5 (strongly multilingual) is susceptible, enabling a multilingual probe. Code is language-neutral, isolating the training task from eval language.
