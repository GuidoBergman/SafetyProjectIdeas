# Multi-Agent Error Propagation x Single-Point Monitoring: One Hijack, Many Defections

**Problem:** Goal-hijacking propagation in multi-agent pipelines (a security/multi-agent failure) compounds with monitoring placed at a single chokepoint (control design): if the monitor only watches one agent, a hijack upstream propagates harm through unmonitored agents, so the placement failure amplifies the propagation failure.

**Direction:** Build a 3-agent open-model pipeline (planner -> coder -> executor) with a monitor at one configurable position. Inject a goal-hijack at the first agent and measure caught-harm as a function of monitor placement. Show that single-point monitoring misses propagated harm and quantify the coverage gained per added monitor.

**Why it matters:** Agentic systems are increasingly multi-agent; monitor placement is an under-studied design choice with large safety consequences. A small pipeline prototype is reusable infrastructure.

**Relevant context:** Goal hijacking propagates downstream in multi-agent pipelines (OWASP / Atlan 2026); multi-agent collusion & security (arXiv:2505.02077); ControlArena agent tasks.
