# The Monitor's Own Blind Spots: When the LLM Watching the Agent Shares the Agent's Failure Modes

**Problem:** GAP TARGETED: a homogeneity x control seam no subfield owns — AI control uses a 'trusted monitor' LLM to watch an untrusted agent, but if the monitor and agent come from the same family (or share blind spots), the monitor may systematically fail to flag exactly the harmful actions it should, undermining the control guarantee.

**Direction:** Set up a simple control setup: an untrusted policy model proposes actions on a task with planted subtle-sabotage cases; a monitor model flags suspicious actions. Vary the monitor's family/size relative to the policy. Measure catch-rate of sabotage as a function of monitor-policy similarity. Test the hypothesis that a same-family monitor has a measurable catch-rate deficit on the policy's characteristic failure modes.

**Why it matters:** Bridges ai_control + model_homogeneity + deception_scheming. It probes a hidden assumption in control protocols — monitor independence — using the homogeneity result. Fully counterfactual (open models, one GPU), directly tests a load-bearing safety assumption, and is a scoped, self-contained experiment.

**Relevant context:** AI control's trusted-monitor framing (Redwood) assumes the monitor catches the untrusted model's bad actions; correlated-errors work (arXiv:2506.07962) shows same-family models share blind spots. The catalogue has many monitor-attack ideas but not a monitor-policy-similarity catch-rate study grounded in homogeneity.
