# Judge Self-Preference Bias in Safety Grading

**Problem:** LLM autograders exhibit self-bias (rating responses from the same model family higher). For SAFETY grading this could mean a model's outputs are judged more leniently by a judge from the same family, biasing reported safety.

**Direction:** Generate harmful-prompt responses from several open model families, then have each family's model judge all responses (round-robin). Test whether judges systematically rate own-family responses as safer/more-refusing using a matched design. Report the bias magnitude per family.

**Why it matters:** If safety evals quietly favor in-family grading, cross-model safety leaderboards are skewed. A clean factorial experiment exposing this is a useful methodological warning, fully doable on a single GPU.

**Relevant context:** Skewed Score (arXiv 2507.03772) and LLM-judge surveys document self-bias where graders favor same-LLM or machine-generated content; LJ-Bench (arXiv 2603.20572) on judge reliability for harm categories.
