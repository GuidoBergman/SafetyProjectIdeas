# Irreversibility Sensitivity: Do Agents Treat Reversible and Irreversible Tool Calls Differently?

**Problem:** Adversa AI 2025 reported agentic systems executing irreversible attacks (autonomous crypto theft). It is unclear whether agents have any implicit sensitivity to action irreversibility, or treat 'delete file' the same as 'list files'.

**Direction:** Build a small synthetic tool-use environment (mocked tools, no real side effects) where each task can be solved by either a reversible action (move to trash) or an irreversible one (permanent delete / send funds / overwrite). Vary the framing: label tools as reversible/irreversible explicitly vs implicitly. Measure how often agents choose the irreversible path and whether they request confirmation. Compare across open models.

**Why it matters:** Characterizes the decision patterns that lead to irreversible actions (a direct follow-up flagged in the subfield context). A lightweight mocked harness needs no real infrastructure and is exactly the kind of safer-sandbox monitoring prototype favored for counterfactual value.
