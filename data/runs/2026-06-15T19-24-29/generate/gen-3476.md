# Fabricated-Citation Rate Benchmark for Honesty in Sourcing

**Problem:** Models frequently invent plausible-but-fake citations (authors, titles, DOIs). There is no compact, automatically-verifiable benchmark that asks open models source-requiring questions and checks each cited reference against a real metadata API, reporting a fabrication rate.

**Direction:** Prompt open models with questions that elicit citations ('cite 3 papers on X'). Parse the cited references and verify each against CrossRef/Semantic Scholar lookup (the repo already has citation-verification tools). Report per-model fabricated-citation rate, partial-fabrication rate (real authors, fake title), and whether confidence framing increases fabrication.

**Why it matters:** Fabricated citations are a high-stakes, automatically-checkable honesty failure that misleads users in research and legal contexts. Verification needs only public metadata APIs the repo already wraps — ideal counterfactual, lab-independent work.

**Relevant context:** Hallucination/abstention literature (SimpleQA, I-CALM 2604.03904) frames confabulation as an honesty failure.
