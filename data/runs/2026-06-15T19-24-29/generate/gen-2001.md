# In-Context Emergent Misalignment: Can Narrow Examples in the Prompt Alone Cause Broad Misalignment?

**Problem:** Recent work suggests EM can be induced via in-context learning — narrow misaligned examples in the prompt produce broad misalignment with no weight updates — but the dose and persistence of this effect on small open models is underexplored.

**Direction:** Without any fine-tuning, place k narrow misaligned demonstrations (e.g., insecure-code or bad-advice examples) in the context window of a small aligned open model and measure broad misalignment on unrelated free-form probes as a function of k and example type. Compare to a fine-tuning baseline.

**Why it matters:** If misalignment generalizes from context alone, prompt-level supply-chain attacks (poisoned RAG/few-shot exemplars) become a live threat with zero training — a strong counterfactual, training-free project. Pure inference on one GPU.

**Relevant context:** Emergent Misalignment via In-Context Learning (arXiv:2510.11288): narrow in-context examples can produce broadly misaligned LLMs; emergent misalignment as prompt sensitivity (arXiv:2507.06253).
