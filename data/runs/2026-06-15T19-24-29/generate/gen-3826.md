# Penetration-Testing Kill-Chain Mapping of Agent Exploits

**Problem:** Agentic attacks (injection -> privilege escalation -> data exfiltration -> irreversible action) are studied in isolation, lacking a unifying chain model that reveals the cheapest link to break.

**Direction:** Import the cyber kill-chain / MITRE ATT&CK staged model. Define an agent-specific kill chain, reproduce several public exploit demos against an open agent harness, map each to its chain stage, and run controlled experiments removing one defense per stage to identify which single chokepoint defense disrupts the most attack chains.

**Why it matters:** Reframes scattered agent exploits into an actionable defense-prioritization framework borrowed from security ops, helping the community focus limited defensive effort. Reproduction + analysis, no training.

**Relevant context:** MITRE ATT&CK and the Lockheed kill-chain stage cyber intrusions to guide defense; Adversa AI 2025 catalogs agentic incidents but without a chain model. Building an agent-specific kill chain and empirically finding the best chokepoint is a fresh transfer.
