# Indirect Prompt Injection Susceptibility by Tool-Output Position

**Problem:** AgentDojo shows tool-using agents are vulnerable to indirect prompt injection, but it is underexplored how the position of the injected instruction within a tool's returned document (top, middle, buried, end) affects success — a manipulable variable for both attackers and defenders.

**Direction:** Using AgentDojo's open environment (available via Inspect evals), hold the injection payload fixed and vary its position and surrounding context within the returned email/document. Measure injection success rate by position for 2-3 small open instruct models acting as the agent. Test a trivial defense: re-summarizing tool output before the agent reads it.

**Why it matters:** Positional sensitivity tells deployers whether simple tool-output sanitization (truncation, re-ordering, summarization) meaningfully reduces injection risk. AgentDojo is open and runs locally; agent security is exactly the strategically valuable monitoring-harness work labs can't cover exhaustively.

**Relevant context:** AgentDojo (Debenedetti et al., arXiv:2406.13352, NeurIPS 2024) provides 97 tasks across banking/slack/travel/workspace and 629 security cases for indirect prompt injection, available in UK AISI's inspect_evals. 'Indirect Prompt Injections: Are Firewalls All You Need?' (arXiv:2510.05244) motivates lightweight defenses.
