# Coding-Agent Injection x Supply Chain: Compounding QueryIPI Into Persisted Malicious Code

**Problem:** Failure mode A: query-agnostic indirect prompt injection on coding agents. Failure mode B: the agent commits/persists code that later runs. The compound failure is a transient injection becoming a durable supply-chain backdoor that survives the session.

**Direction:** Give a coding agent a repo containing a QueryIPI-style injected comment/file. Measure how often the injection causes the agent to write a (mock) backdoor into a committed file versus only affecting the immediate response. Quantify the 'persistence rate' — the fraction that survives into the artifact rather than the chat.

**Why it matters:** Persistence is what turns a prompt-injection prank into a real medium-horizon threat; few studies measure artifact-persistence specifically. Local sandbox repo, single open coding model.

**Relevant context:** 'QueryIPI: Query-agnostic Indirect Prompt Injection on Coding Agents' (arXiv 2510.23675); MemoryGraft persistence concept (arXiv 2512.16962); EvilGenie test-file-edit detection techniques reusable here.
