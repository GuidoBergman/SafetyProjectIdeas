# Conformal abstention for jailbreak guardrails: distribution-free coverage guarantees on a safety classifier

**Problem:** Activation-probe and small LLM jailbreak classifiers output a score with no formal guarantee on error rate; deployers pick a threshold by eyeballing ROC curves, with no control over the false-negative rate that actually matters for safety.

**Direction:** Apply conformal prediction (from distribution-free statistics) to wrap an existing lightweight jailbreak detector. Use a held-out calibration set of benign/harmful prompts to compute a conformal threshold that guarantees the harmful-miss rate stays below a user-chosen alpha. Add an 'abstain / escalate to human' band where the prediction set is ambiguous. Measure how abstention rate trades off against the coverage guarantee across open models.

**Why it matters:** Gives a statistically rigorous, lab-independent way to set guardrail thresholds with a provable safety bound, instead of arbitrary cutoffs. Requires no model training, only a calibration split.

**Relevant context:** Grounded in conformal-prediction-for-LLM work (ConU arXiv 2407.00499, Adaptive Conformal Semantic Entropy arXiv 2605.04295) and the landscape's note on activation-based jailbreak detection.
