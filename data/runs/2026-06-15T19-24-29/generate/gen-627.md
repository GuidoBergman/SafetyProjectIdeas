# Does evaluation coverage really collapse as tool count grows? A small agentic stress test

**Problem:** The same March 2026 paper claims that as an agent gains tools, evaluation coverage declines toward zero (dimensions grow combinatorially, evaluation grows linearly), so hacking severity grows without bound. This scaling claim has no empirical curve.

**Direction:** Build a toy agent (open small instruct model, no training) with a configurable number of mock tools, each adding a checkable quality dimension. Use an LLM-judge with a fixed evaluation budget and measure the fraction of quality dimensions actually checked as tool count rises from 1 to ~20. Plot coverage vs tool count and compare to the paper's predicted decay. Success = an empirical coverage curve with a rubric-scored judge.

**Why it matters:** Agentic systems with many tools are exactly the medium-horizon threat labs ship fast and audit slowly. A reproducible coverage-decay curve gives the safety community a concrete monitoring metric requiring only API/GPU inference.

**Relevant context:** Extends 'Reward Hacking as Equilibrium under Finite Evaluation' (arXiv:2603.28063, March 2026), whose central scaling claim is that evaluation coverage decays toward zero as tool count grows.
