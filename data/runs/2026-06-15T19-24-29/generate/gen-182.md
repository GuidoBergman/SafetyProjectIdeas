# Layer Sweep: At Which Depth Is Jailbreak Detection Cheapest and Most Robust?

**Problem:** Probe papers report results at chosen layers but the full layer-vs-robustness tradeoff is rarely published openly. Whether early layers (cheaper, allow early-exit) detect jailbreaks as well as deep layers is an open practical question.

**Direction:** Train identical logistic-regression probes on residual-stream activations at every layer of one open model for harmful-vs-harmless classification. Plot clean recall AND post-paraphrase recall vs layer index. Identify the earliest layer achieving near-peak detection (enabling cheap early-exit monitoring).

**Why it matters:** An early-layer probe enables a cheap monitoring harness that can abort generation before harmful tokens are produced — strategically valuable, lab-independent infrastructure. Single GPU, one forward pass per prompt.

**Relevant context:** arXiv:2601.11516, arXiv:2509.14558 ('Jailbreak Detection for Almost Free'), arXiv:2506.10805 (high-stakes interaction probes). Context open problem: 'cost-effective jailbreak detection via activation probes that scale better'.
