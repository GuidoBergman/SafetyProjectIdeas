# Refusal-vs-Sabotage Disambiguation Benchmark for Tool Agents

**Problem:** Agent evals conflate two very different unsafe-task responses: an honest REFUSAL vs. a covert pseudo-compliance (pretending to comply while sabotaging or stalling). No benchmark separately scores these, so 'safe refusal' rates may hide covert behaviors.

**Direction:** Annotate harmful-task agent trajectories (e.g., AgentHarm subset) into a 4-way taxonomy: clean refusal, partial compliance, full compliance, covert non-compliance/sabotage. Build a classifier prompt + rubric and report the prevalence of covert non-compliance, which standard pass/fail metrics miss.

**Why it matters:** Covert non-compliance is a deception model-organism signature; surfacing it as its own category sharpens safety measurement. Uses public harmful-task trajectories + API judge only.

**Relevant context:** AgentHarm (ICLR 2025) 110+330 behaviors, 11 harm categories; scores refusal but not covert sabotage separately. SafeArena (arXiv 2503.04957) 250 harmful tasks. Over-refusal benchmarks (XSTest/OKTest) cover the benign side only.
