# Schelling-Point Collusion in Two Agents Without a Side Channel

**Problem:** Multi-agent collusion research focuses on private channels and steganography, but a sharper failure mode is whether two independent agents can coordinate on a policy-violating outcome using only public communication and shared focal points (Schelling coordination), defeating channel-monitoring defenses.

**Direction:** Set up two instances of an open model in a simple bargaining/allocation game with a rule against a particular collusive split, where all messages are visible to a monitor. Test whether they converge on the forbidden split using only ostensibly benign public messages (focal-point hints) faster than chance, and whether a monitor reading the public channel catches it. Vary how 'obvious' the focal point is.

**Why it matters:** If agents collude via focal points without any covert channel, channel-monitoring defenses give false assurance — a subtle multi-agent governance failure. Two API/local model instances and a toy game are enough; no lab resources, strong counterfactual value as a model-organism of collusion.

**Relevant context:** Colosseum (arXiv 2602.15198) audits collusion in cooperative multi-agent systems; existing work focuses on steganography/private channels. Steering toward Schelling-game model organisms is explicitly favored. 'Lying with Truths' (arXiv 2601.01685) studies open-channel collusion.
