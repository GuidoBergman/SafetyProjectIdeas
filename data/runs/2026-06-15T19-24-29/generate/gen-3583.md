# Backcasting Honest Tool-Use Reporting: Does a Model Faithfully Say Which Tool Output It Used?

**Problem:** A success state for agentic safety is a model that faithfully reports which tool/retrieval result actually drove its answer. Backward, we need a measurement of tool-attribution faithfulness on accessible open models. If a model claims it used a retrieved fact but actually relied on its prior, monitoring of agent traces is undermined.

**Direction:** Build a small simulated tool setting: give the open model a retrieved snippet (sometimes correct, sometimes wrong, sometimes contradicting its prior) and ask it to answer and state which source it used. Causally vary the snippet to see whether the answer depends on it, then check whether the model's stated attribution matches the causal reality. Report tool-attribution faithfulness rate.

**Why it matters:** Faithful tool/source attribution is foundational to monitoring AI agents — a fast-growing, long-horizon safety surface. The simulated setup needs no real tool infrastructure or lab access.

**Relevant context:** CoT faithfulness/monitorability framework (arXiv 2510.27378); biasing-features causal-dependence methodology (Turpin 2023; Chen 2025); RAG grounding honesty per hallucination literature.
