# Backcasting from 'Fine-Tuning Can't Cheaply Strip Safety': Measuring Safety-Degradation Cost on an Open Model

**Problem:** A success state for open-weight governance requires knowing how cheap it is to remove safety guardrails via fine-tuning, since release decisions hinge on whether bad actors can easily un-align a model. The 'how much compute to break safety' cost is rarely measured concretely.

**Direction:** Take a small safety-tuned open model and, using parameter-efficient fine-tuning (LoRA) on a single GPU with a small benign-but-instruction-following dataset, measure how refusal rates on a held-out harmful-prompt set degrade as a function of fine-tuning steps/examples. Report the 'safety half-life' — how little tuning meaningfully erodes refusals. Stay within safe, public harmful-prompt proxies.

**Why it matters:** Backcasting from 'open weights stay safe' shows safety-stripping cost as the precondition for release decisions. A concrete cost curve gives release-decision frameworks a measurable input for marginal-risk analysis. LoRA on a small model fits one consumer GPU; a scoped model-organism-style study of safety fragility with high counterfactual value.

**Relevant context:** 'Estimating Worst-Case Frontier Risks of Open-Weight LLMs' (arXiv:2508.03153); OECD marginal-risk framing notes attackers can fine-tune to remove safety; widely-cited result that small fine-tuning erodes safety alignment.
