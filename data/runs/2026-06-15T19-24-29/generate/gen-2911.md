# Diagnostic-Test Theory for Autograder Calibration (Sensitivity/Specificity/ROC)

**Problem:** LLM autograders ('judges') for safety evals disagree with each other and with humans, but their errors are reported only as crude accuracy, hiding the safety-critical asymmetry between missing a harmful output (false negative) and over-flagging.

**Direction:** Import diagnostic-test evaluation from clinical epidemiology. Treat the autograder as a diagnostic test for 'harmful output', use a small human-labeled gold set as ground truth, and report sensitivity, specificity, likelihood ratios, and ROC/AUC with confidence intervals across grader prompts and thresholds. Find the operating point that controls the false-negative rate to a safety target, and quantify how much the chosen threshold changes a model's headline safety score.

**Why it matters:** Reframes scorer reliability (an explicit open problem) in the rigorous language regulators already trust for medical tests, and exposes the safety-critical FN/FP tradeoff that accuracy hides. Tiny gold set + open grader; pure analysis, high counterfactual value.

**Relevant context:** ROC/sensitivity/specificity are the standard framework for diagnostic-test accuracy and multi-reader trials (PMC3755824; ScienceDirect S1572312711001341). AISafetyLab notes different scorers produce discrepant results for the same method (subfield context).
