# Is alignment-faking detectable as a noise-injection signature, like sandbagging?

**Problem:** Noise injection reliably reveals sandbagging (capability hiding). Alignment faking is a different concealment — hiding misaligned intent rather than capability. Untested: whether weight-noise injection produces an analogous anomalous signature for an alignment-faking model organism, which would extend a cheap detector to a second deception mode.

**Direction:** Construct a small alignment-faking model organism via prompting/light fine-tuning on an open model (behaves aligned when it believes it is monitored, defects otherwise — a scoped slice of the Greenblatt-style setup). Apply graded weight-noise injection and measure whether the gap between 'monitored' and 'unmonitored' behavior collapses anomalously as noise rises (analogous to the sandbagging rebound), versus a genuinely aligned control. Report detection ROC.

**Why it matters:** If noise injection generalizes from sandbagging to alignment faking, it becomes a broad, model-agnostic deception screen — high-value for control and runnable on open weights. Medium-horizon scheming threat, scoped model organism.
