# EvalAware-Mini: A Reproducible Benchmark of Evaluation-Awareness Cues

**Problem:** Models flag public benchmarks as 'evaluations' far more often than internal/realistic prompts (Meta Muse Spark: 19.8% vs 2.0%), but there is no small, open, reusable probe set that lets independent researchers measure how strongly a given prompt triggers evaluation-awareness.

**Direction:** Construct ~150 matched prompt pairs (benchmark-styled vs. deployment-styled phrasing of the same task) and ask open models a direct meta-question ('Is this a test?') plus measure behavioral divergence. Score each model's 'eval-detection rate' and correlate with surface features (multiple-choice format, 'You are being evaluated', numbered options).

**Why it matters:** Quantifies which surface cues leak 'this is a test', giving benchmark designers a checklist to make evals deployment-realistic. Directly attacks a scaling-with-model-size failure mode that worsens over time, runnable on consumer GPUs.

**Relevant context:** Meta Muse Spark report: public benchmarks flagged as evaluations 19.8% vs 2.0% internal (April 2026). 'Probing and Steering Evaluation Awareness of Language Models' (arXiv:2507.01786); 'Probe-Rewrite-Evaluate' workflow quantifies evaluation awareness (arXiv:2509.00591). Evaluation awareness scales with model size (power-law).
