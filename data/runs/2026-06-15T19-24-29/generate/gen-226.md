# Multi-Turn Crescendo Robustness Micro-Benchmark

**Problem:** Crescendo-style multi-turn attacks push policy-violation rates above 0.9, but most public robustness benchmarks are single-turn. There is no small, reproducible multi-turn micro-benchmark a single researcher can run to compare open models' multi-turn vs single-turn vulnerability.

**Direction:** Build a fixed library of ~30 scripted Crescendo escalation dialogues (each a deterministic sequence of turns toward a harmful goal, no adaptive attacker LLM needed) and run them against open models, scoring final-turn harmfulness with the StrongREJECT rubric. Report each model's single-turn vs multi-turn ASR delta.

**Why it matters:** Captures the multi-turn brittleness that single-turn benchmarks miss, a medium-horizon threat as conversational agents proliferate. Scripting fixed dialogues (vs an attacker model) keeps it deterministic, reproducible, and within compute budget.

**Relevant context:** Russinovich et al. 'Crescendo Multi-Turn LLM Jailbreak' (USENIX Security 2025, arXiv:2404.01833): multi-turn escalation drives policy-violation rates >0.90 across models. 'MultiBreak' (arXiv:2605.01687) is a multi-turn benchmark but large; a micro-benchmark fills the lightweight-reproducible gap.
