# Reversibility Tagging Harness for Agent Tool Calls

**Problem:** Benchmarks like Agent-SafetyBench and AgentDojo measure whether agents take harmful actions, but no lightweight tool labels each tool call by its REVERSIBILITY (e.g., delete-file vs. read-file). The Adversa AI 2025 report flags irreversible actions (autonomous crypto theft) as a distinct, under-measured threat.

**Direction:** Build a small Python harness that wraps a fixed set of mock tools (file ops, email send, payment, config edit) with a reversibility label, runs an API-based agent (e.g., open model via Together/OpenRouter) on 30-40 benign and adversarial tasks from AgentDojo-style scenarios, and produces a per-trajectory 'irreversibility exposure' score: count and fraction of irreversible calls, and how many came without a confirmation step. Compare across 3-4 models.

**Why it matters:** Irreversibility is the property that makes agent failures catastrophic rather than recoverable, yet it is invisible in pass/fail benchmarks. A reusable tagging harness gives the community a cheap measurement of a model-organism-relevant property. Needs no training, no lab infra, only API calls.

**Relevant context:** Adversa AI 2025: agentic systems produced irreversible attacks incl. autonomous crypto theft. ALFWorld treats Clean/Heat/Cool as critical irreversible actions. AgentTrust recommends human-in-the-loop for irreversible operations. Agent-SafetyBench (arXiv 2412.14470) covers property loss but does not score reversibility per call.
