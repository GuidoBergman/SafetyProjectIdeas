# Distillation Data Laundering x Cross-Model Comparison: Inherited Contamination Breaks Rankings

**Problem:** Failure mode A is data laundering (benchmark performance boosted via knowledge distillation from a contaminated teacher). Failure mode B is cross-model leaderboard comparison. The compound effect: laundered contamination is invisible (the student never saw the test set directly) yet inflates scores, so leaderboards rank a laundered model above an honest one, corrupting cross-model risk comparison.

**Direction:** Simulate with open models: fine-tune (LoRA, on one GPU) a small student on outputs of a teacher that has 'seen' a held-out benchmark, vs a control student trained on teacher outputs that excluded it. Compare benchmark gains and check whether standard contamination detectors (n-gram overlap, perplexity) catch the laundered gain.

**Why it matters:** Cross-model metrics (CAISI/NIST goal) assume scores are comparable. If distillation launders contamination past detectors, rankings are untrustworthy. The deliverable tests whether common decontamination checks survive distillation and recommends behavioral contamination probes.

**Relevant context:** 'Data Laundering: Artificially Boosting Benchmark Results through Knowledge Distillation' (arXiv:2412.15255). 'Can We Trust AI Benchmarks?' (arXiv:2502.06559). Subfield: standardized cross-model metrics (US CAISI/NIST) open problem.
