# Self-Correction-Monoculture: do all models share the same self-correction blind spot?

**Problem:** Self-Correction Bench found LLMs fail to fix their OWN errors while fixing identical external errors. It is unknown whether this blind spot is homogeneous — i.e., whether all models fail to self-correct on the SAME items, making the failure systemic rather than idiosyncratic.

**Direction:** Reuse/replicate a small self-correction probe set on 6-10 open models. For each item, record whether each model self-corrects. Compute the joint failure structure: are the items that model A can't self-correct the same ones model B can't? Report a self-correction monoculture index and whether cross-model checking (A reviews B) escapes the blind spot.

**Why it matters:** If self-correction blind spots are shared, then pipelines that use one model to review another inherit the same blind spot — undermining a core AI-oversight safety mechanism. Quantifies a correlated-failure risk in oversight with consumer compute and public methods.

**Relevant context:** Builds on 'Self-Correction Bench' (arXiv:2507.02778) and connects to the AI-oversight correlated-failure thesis of 'Great Models Think Alike' (arXiv:2502.04313).
