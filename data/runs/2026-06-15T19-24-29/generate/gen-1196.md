# Shared Factual Hallucinations: Do Independent Models Hallucinate the Same Falsehoods?

**Problem:** The dangerous homogeneity link for factuality is 'shared training corpora -> shared false beliefs -> correlated hallucination.' If models independently hallucinate DIFFERENT facts, cross-checking catches errors; if they hallucinate the SAME falsehood, consensus verification fails silently. This 'consensus is not verification' link is under-quantified for safety-relevant facts.

**Direction:** Assemble a set of factual questions with known answers, including some with common internet misconceptions. Query 6+ models, record answers, and measure whether wrong answers cluster on the SAME falsehood across models vs. scattering. Quantify how often majority-vote 'verification' would endorse a shared hallucination.

**Why it matters:** Multi-model consensus is increasingly used as a cheap truth oracle. Shared hallucinations make consensus dangerously confident on exactly the facts where it's wrong. A clean, reproducible demonstration with safety implications, needing only API/open inference.

**Relevant context:** Grounded in 'Consensus is Not Verification: Why Crowd Wisdom Strategies Fail for LLM Truthfulness' (arXiv 2603.06612) and Artificial Hivemind inter-model homogeneity (arXiv 2510.22954).
