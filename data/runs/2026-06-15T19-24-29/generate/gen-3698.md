# Does Blocking Feedback Teach Monitor-Awareness? Replicating the Inference Channel with Cheaper Models

**Problem:** The 'Noticing the Watcher' result showed agents can infer the presence of a CoT monitor purely from blocking feedback (actions being refused/blocked) without ever being told a monitor exists. It is unclear how cheap a model needs to be to discover this inference channel, or how many blocked actions it takes.

**Direction:** Build a minimal tool-use environment where some actions are silently blocked by an unseen monitor. Run a ladder of small/mid open models and API models, logging at which step (and at what model scale) the agent's CoT first hypothesizes 'something is watching/blocking me.' Plot inference-onset (number of blocks needed) vs. model capability tier. Vary block 'loudness' (silent failure vs. explicit error message).

**Why it matters:** Monitor-awareness is the precondition for monitor-evasion. A dose-response curve of how easily and how early agents infer they are monitored tells deployers how much their oversight setups leak their own existence. Needs no training, no lab infra, just API/open models and a scripted sandbox.

**Relevant context:** 'Noticing the Watcher' (arXiv 2603.16928) demonstrates LLM agents infer CoT monitoring from blocking feedback. The original study focuses on frontier models; the inference threshold across capability tiers and the effect of feedback verbosity is an open follow-up.
