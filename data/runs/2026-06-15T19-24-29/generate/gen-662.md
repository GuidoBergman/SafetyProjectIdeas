# Tool-Selection Hijacking: Auditing Open Agent Frameworks for ToolHijacker

**Problem:** ToolHijacker (arXiv:2504.19793) injects adversarial instructions into tool documents/results to hijack an LLM agent's tool selection, and the paper reports that defenses like StruQ and SecAlign are insufficient. The attack's effectiveness across different open backbone models in a realistic open agent harness is not characterized.

**Direction:** Set up a minimal toy agent (LangChain-style or hand-rolled) with ~6 tools and poisoned tool descriptions per ToolHijacker. Swap the backbone among 2-3 small open instruct models and measure how often the agent selects the attacker's malicious tool. Add a trivial 'provenance tag' wrapper that labels untrusted tool text and re-measure as a cheap mitigation prototype.

**Why it matters:** Agentic tool use is the fastest-growing deployment surface and a prime medium-horizon threat. A small open-source audit harness plus a lightweight provenance mitigation is strategically valuable infrastructure buildable entirely outside a lab.

**Relevant context:** Prompt Injection Attack to Tool Selection in LLM Agents / ToolHijacker (arXiv:2504.19793): outperforms manual and automated injection on tool selection; StruQ and SecAlign insufficient. ARGUS (arXiv:2605.03378) and AttriGuard (arXiv:2603.10749) motivate provenance/attribution-based defenses; AgentLure benchmark covers context-aware injection across agentic domains.
