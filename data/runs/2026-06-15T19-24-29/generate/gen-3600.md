# Sycophancy x Multi-Agent Drift: Does Agreeableness Cause Consensus on Wrong Answers?

**Problem:** In multi-agent debate/critique setups (a popular oversight idea), sycophancy compounds with error propagation: agents defer to each other's stated positions, converging on a confidently-wrong consensus instead of correcting it. The 'wisdom of agents' becomes mutual sycophancy.

**Direction:** Run a 2-3 agent debate (same open model, different roles) on factual questions where one agent is seeded with a wrong answer. Measure whether the group converges to the wrong answer (sycophantic deference) more often than a single agent would err, and whether confidence rises with rounds. Inference-only.

**Why it matters:** Multi-agent oversight is proposed as a scalable safety mechanism; if sycophancy drives false consensus, it can manufacture unwarranted confidence rather than catch errors. Names: inter-agent sycophancy and multi-agent error propagation.

**Relevant context:** 'Not Just RLHF: Why Alignment Alone Won't Fix Multi-Agent Sycophancy' (arXiv:2605.12991); 'Hallucination Cascade ... in Multi-Agent LLM Systems' (arXiv:2606.07937).
