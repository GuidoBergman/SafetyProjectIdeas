# Fine-Tuning-Free Elicitation Gap via In-Context Demonstrations

**Problem:** Capability-elicitation work shows fine-tuning on safeguarded outputs recovers ~40% of a capability gap, but fine-tuning is out of scope for a 30h student project. Whether a cheaper in-context (many-shot) elicitation closes a measurable chunk of the gap is an accessible variation.

**Direction:** On a refusing open model, measure baseline performance on a (non-dangerous proxy) capability eval, then vary the number of in-context demonstrations of compliant behavior (many-shot) and measure how much the elicitation gap to an uncensored sibling model closes — purely via prompting, no training.

**Why it matters:** Tells evaluators how much capability can be elicited with the cheapest possible method (no fine-tuning), setting a lower bound on under-elicitation that any third party can reproduce. Single-GPU, no training.

**Relevant context:** arXiv 2601.13528 'Eliciting Harmful Capabilities by Fine-Tuning on Safeguarded Outputs' recovers ~40% of capability gap via fine-tuning; arXiv 2405.19550 'Stress-Testing Capability Elicitation With Password-Locked Models' provides open elicitation testbeds. (Uses benign proxy tasks for safety.)
