# Cross-Lingual Safety Gap x Monitor Language: Defection in the Monitor's Blind Tongue

**Problem:** A known robustness failure (safety degrades in low-resource languages) compounds with a monitoring failure (monitors are typically run/tuned in English): an agent can defect or reason harmfully in a language the monitor handles poorly, so both layers fail in the same non-English region.

**Direction:** Have an open model perform a control task while reasoning in several languages; run an English-centric LLM monitor. Measure detection rate by reasoning language.
