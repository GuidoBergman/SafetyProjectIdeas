# AdversaSteer: A Mini-Benchmark for Neutralizing Steering Vectors via Crafted Inputs

**Problem:** An explicit open problem is whether adversaries can craft inputs that neutralize steering. No simple benchmark measures how easily a steering vector's effect can be cancelled by adversarial prompt content.

**Direction:** Build a benchmark of adversarial prompt templates (e.g. embedding the contrastive cue used to build the vector, instruction-level negations) and measure the reduction in steering effect they cause on an open model. Report a 'neutralization rate' per steering vector and identify which behaviors are most fragile.

**Why it matters:** If steering-based safety controls can be cancelled by simple prompt tricks, they offer false assurance. A reproducible neutralization benchmark is exactly the robustness measurement labs underinvest in, needs only inference, and tests a flagged open problem.

**Relevant context:** Open problem: 'can attackers craft inputs that neutralize steering?' (Beaglehole et al.). Prior work notes deployment-related prompts in the user message can override the steering signal (arxiv 2510.20487).
