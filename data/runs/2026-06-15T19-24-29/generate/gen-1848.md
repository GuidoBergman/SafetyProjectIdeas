# CorrSteer Generation-Time Steering: Reproducing the Correlated-Feature Selection

**Problem:** CorrSteer (arXiv:2508.12535) steers generation by selecting SAE features correlated with desired behavior at generation time, but the robustness of its automatic feature-selection step to noisy correlation estimates is not characterized.

**Direction:** Reproduce CorrSteer's correlation-based feature selection on an open model with a public SAE for one target behavior (e.g. increased honesty/refusal), then vary the size of the correlation-estimation sample and measure how stable the selected feature set and the resulting steering effect are. Report the minimum data needed for reliable selection.

**Why it matters:** Knowing how much data CorrSteer-style automatic steering needs to be reliable determines whether small teams can use it; a sample-efficiency study is self-contained and open-model only.

**Relevant context:** CorrSteer: Generation-Time LLM Steering via Correlated Sparse Autoencoder Features (arXiv:2508.12535).
