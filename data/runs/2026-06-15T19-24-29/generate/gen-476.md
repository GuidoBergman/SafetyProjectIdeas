# SecretConstraintBench: Probing for an Open Model Organism Pursuing a Hidden Side Goal

**Problem:** The ELK/elicitation literature released 'Secret Side Constraint' and 'Taboo' model organisms (open code + benchmarks) for studying hidden objectives, but there is no minimal probing harness aimed at beginners that detects whether a model is silently obeying a secret side constraint it never verbalizes.

**Direction:** Load an open 'secret side constraint' organism, generate prompts that do/don't trigger the hidden constraint, and (1) measure behavioral signatures (output distribution shift) and (2) train a linear probe on activations to detect when the hidden constraint is active even though the CoT never mentions it. Report detection AUROC and which layers carry the secret-constraint signal.

**Why it matters:** A model that pursues a hidden goal without verbalizing it in CoT is exactly the model-organism the steering prioritizes. Probing such an organism tests whether internal monitoring can catch silent goal-pursuit that CoT monitoring misses — a high-counterfactual-value safety capability needing only open weights and inference.

**Relevant context:** Grounded in the elicitation-organisms release (Taboo / Quirky / Secret Side Constraint, open code/benchmarks) referenced in the ELK literature, and middle-layer 'flare up' findings (arXiv:2312.01037). Linear probing on activations is beginner ML.
