# Epidemic SIR modeling of prompt-injection contagion in multi-agent systems

**Problem:** Prompt-injection can self-replicate across communicating agents ('Prompt Infection'), but defenses are evaluated ad hoc. There is no quantitative model of how injection spreads through an agent network or which topologies/interventions contain it.

**Direction:** Borrow compartmental epidemic models (SIR/SIS) and network epidemiology from public health. Build a small simulated multi-agent network (5-15 agents, varied topologies: star, chain, fully connected) using a single open model, seed one infected agent, and measure the empirical infection curve. Fit an SIR-style model to estimate an effective R0 for the injection, then test 'quarantine' interventions (output sanitization on hub nodes identified by centrality) and measure the drop in R0.

**Why it matters:** Gives a transferable, quantitative framework for reasoning about contagion risk in agent ecosystems and where to place defenses — a medium-horizon multi-agent threat labs underinvest in. Fully simulatable on one GPU.

**Relevant context:** Grounded in 'Prompt Infection: LLM-to-LLM Prompt Injection within Multi-Agent Systems' (arXiv 2410.07283) and standard network epidemiology. Source subfield: epidemiology / network science. Target subfield: agentic_safety, adversarial_robustness.
