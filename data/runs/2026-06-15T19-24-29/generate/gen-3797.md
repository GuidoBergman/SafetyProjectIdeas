# Privacy Leakage Through Helpfulness: When Does a Multi-Agent System Over-Share User Data?

**Problem:** Multi-agent privacy benchmarks show systems leak sensitive information across agents. The specific failure trigger — whether a downstream agent's request framed as 'needed to help the user' causes an upstream agent to over-share private data — is not isolated.

**Direction:** Build a 2-agent setup: agent A holds private user data, agent B requests information to complete a sub-task. Vary B's request framing (minimal-necessary vs. 'send everything you have to be helpful') and whether a data-minimization policy is stated to A. Measure how much private data A discloses per condition, scoring leakage against a defined sensitivity rubric.

**Why it matters:** Inter-agent over-sharing is a concrete privacy failure of multi-agent systems that contextual-integrity defenses target; quantifying the helpfulness-driven trigger informs minimal-disclosure design. Two model instances and synthetic data only — no proprietary data, strong counterfactual value.

**Relevant context:** AgentLeak (arXiv 2602.11510, 1000 scenarios across healthcare/finance/legal/corporate) and MAGPIE (arXiv 2510.15186) for multi-agent contextual privacy. Subfield open problem: multi-agent governance.
