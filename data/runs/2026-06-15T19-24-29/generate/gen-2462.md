# Steganographic Channel Capacity of Benign-Looking Agent Outputs

**Problem:** Steganography is a named pathway for covert signaling and CoT obfuscation, but there is little simple measurement of how many bits a model can reliably hide in plausibly-benign task output before a trusted reader/monitor notices.

**Direction:** Set up a sender-receiver pair of small open models: the sender encodes a few secret bits into otherwise-normal task output (word choice, ordering, formatting), the receiver decodes them. Measure decode accuracy vs. number of hidden bits, and how a trusted monitor's suspiciousness rises with payload size. Output: a channel-capacity-vs-detectability curve.

**Why it matters:** Quantifying covert channel capacity bounds how much collusion or exfiltration signal can pass undetected, informing redaction strength. It is a clean information-theoretic experiment within the participant's stats/linear-algebra skills and needs no lab resources.

**Relevant context:** CoT obfuscation literature names steganography and linguistic drift as encoding mechanisms (arxiv 2510.19851, 2511.11584); 'If you can generate obfuscated CoT...' (Alignment Forum). Redaction/paraphrasing proposed to disrupt steganographic channels (Redwood collusion post).
