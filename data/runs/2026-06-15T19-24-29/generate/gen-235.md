# StrongREJECT Evaluator Reliability Audit Tool

**Problem:** Jailbreak benchmarks increasingly rely on LLM-judge evaluators (StrongREJECT rubric, AILuminate's evaluator), but there is no easy tool for practitioners to audit how much the final robustness ranking depends on which judge model is used.

**Direction:** Run the StrongREJECT rubric prompt with several different judge models (GPT-4o-mini, Claude Haiku, an open judge like Llama-3-70B, the fine-tuned Gemma-2B evaluator) on a fixed set of responses, and measure inter-judge agreement and rank stability of the resulting model leaderboard. Ship the audit harness.

**Why it matters:** If leaderboards flip depending on the judge, published robustness claims are unreliable — a meta-science gap the field has not closed. Auditing evaluator robustness needs no model training and only modest API/inference budget; strong counterfactual value as independent verification.

**Relevant context:** StrongREJECT (arXiv:2402.10260) ships both a rubric-based evaluator (usable with any LLM) and a fine-tuned Gemma-2B evaluator. 'LLM-Safety Evaluations Lack Robustness' (arXiv:2503.02574) motivates evaluator-robustness audits.
