# Epidemiological Quarantine Protocols for Compromised Agents

**Problem:** Once an agent in a multi-agent system is compromised (e.g. by injection), there is no standard containment protocol; the field lacks evaluated 'quarantine' designs.

**Direction:** Import quarantine/isolation strategies from public-health epidemiology. In a simulated agent network, implement candidate containment policies (rate-limit suspect agents, cut message edges, require re-authentication after anomalous output) and measure each policy's effect on attack-spread reduction vs task-throughput cost. Identify the Pareto frontier of containment-vs-utility.

**Why it matters:** Turns multi-agent incident response from ad hoc to evaluated protocols, importing public-health containment logic. Simulation-only and lab-independent.

**Relevant context:** Prompt Infection (arXiv 2410.07283) shows contagious agent-to-agent attacks; epidemiology offers quarantine/isolation as standard containment. Evaluating quarantine-style containment policies on a Pareto utility/safety frontier for agent networks is novel.
