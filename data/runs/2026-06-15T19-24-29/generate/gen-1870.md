# Single-Example Steering: How Few Poisoned Samples Trigger Emergent Misalignment?

**Problem:** Reports indicate even single-sample steering vectors can elicit EM. The fine-tuning analogue — the minimum number of poisoned examples in an otherwise-clean fine-tuning set that reliably flips a model into broad misalignment — has not been mapped as a clean threshold curve across model sizes.

**Direction:** Fine-tune small open models on clean instruction data spiked with 1, 2, 4, 8, 16, 32 insecure-code examples, measuring broad misalignment rate to locate the poisoning threshold, and check whether the threshold scales with model size.

**Why it matters:** Defines the data-poisoning attack surface for fine-tuning APIs and open datasets — how few malicious rows compromise a fine-tune. Directly relevant to dataset-integrity threat models, runnable on a single GPU.
