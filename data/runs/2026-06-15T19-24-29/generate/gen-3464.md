# Sycophancy-on-Verifiable-Math: BrokenMath-Style Probe for Open Models

**Problem:** Sycophancy is especially dangerous when a model agrees with a false premise in a domain with a ground truth (e.g., accepting a wrong theorem statement). BrokenMath benchmarks this for theorem proving, but there is no compact, easy-to-run probe applying false-premise agreement tests on grade-school/competition math for open models.

**Direction:** Take correct math problems, inject subtly false premises or assert wrong intermediate results, and present them as if user-stated. Measure how often the model 'agrees' and proceeds with the false premise vs. correcting it. Report a domain-specific sycophancy rate and how it scales with how authoritative the false claim is framed.

**Why it matters:** Agreement with verifiably false claims is unambiguous sycophantic dishonesty with a clean ground truth, avoiding the subjectivity of opinion-based sycophancy tests. Fully reproducible on public math data.

**Relevant context:** BrokenMath (arXiv 2510.04721) benchmarks sycophancy in theorem proving; 'Sycophancy under Pressure' (2508.13743) uses adversarial dialogues in scientific QA. No lightweight false-premise math sycophancy probe for open models exists.
