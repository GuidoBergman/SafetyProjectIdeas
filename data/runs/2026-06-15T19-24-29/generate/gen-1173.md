# Behavioral Mutation Testing: Do Small Prompt Mutations Reveal the Same Fragile Mode in Every Model?

**Problem:** Mutation testing in software engineering injects small mutations and measures whether tests catch them; behavioral test diversity is measured by which mutants kill which tests. Applied to LLMs, we can ask whether tiny prompt mutations push ALL models across the same decision boundary — a signature of shared fragility.

**Direction:** Generate systematic small prompt mutations (synonym swap, reorder, add a benign clause) around safety-relevant decision points, and measure the cross-model 'kill matrix': which mutations flip which models' verdicts. A column where one mutation flips every model identically reveals a universally shared fragile boundary.

**Why it matters:** Pinpoints shared, exploitable fragility (a mutation that reliably breaks the whole model population at once) — high-value for understanding correlated jailbreak/failure surfaces. Cheap, oracle-light, and entirely on open models.

**Relevant context:** Mutation testing and behavioral test diversity via kill matrices (arXiv:2010.09144). Metamorphic/property testing for LLMs (arXiv:2504.07982). Shared-blind-spot follow-up (arXiv:2510.22954).
