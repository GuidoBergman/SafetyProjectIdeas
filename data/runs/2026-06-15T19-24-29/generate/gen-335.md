# An Over-Refusal Cost Ledger for Defenses: Mapping the Robustness/Usability Frontier

**Problem:** Success state: adaptive defenses gain robustness without catastrophic over-refusal. The needed result: a shared, reproducible measurement of the over-refusal TAX paid by simple, accessible defenses (system-prompt guards, perplexity filters, refusal-direction steering).

**Direction:** On one open model, apply 3-4 lightweight inference-time defenses, then evaluate each on a harmful set (StrongReject) AND an over-refusal set (XSTest / OR-Bench hard subset), plotting each defense as a point on the refusal vs over-refusal frontier.

**Why it matters:** Directly targets the open problem of robustness 'without catastrophic over-refusal'. The frontier view is exactly the fuzzy-reward, no-lab-resource evaluation that frontier labs underinvest in but that practitioners need to pick defenses.

**Relevant context:** XSTest (250 safe + 200 unsafe contrast prompts) and OR-Bench (80k over-refusal prompts, ~1k hard subset, 600 toxic) measure exaggerated safety; lexical overfitting is a primary false-refusal cause. Safety/usability tradeoff is an explicit open problem in the context.
