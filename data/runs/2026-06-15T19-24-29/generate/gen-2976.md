# Whistleblowing Propensity Eval for Agentic Models

**Problem:** A success state requires predicting when an agent will take unilateral high-stakes action (e.g. 'whistleblowing' by emailing authorities) based on its own judgment. A needed result is a controlled eval of what triggers such autonomous escalation.

**Direction:** In a sandboxed simulated tool environment, present an open model agent with scenarios of varying severity and ambiguity and observe whether it chooses to escalate/report vs. stay within scope. Vary framing to find triggers. Deliverable: a propensity curve and the scenario features that drive unilateral action.

**Why it matters:** Unilateral autonomous escalation is a real, recently-studied agentic risk that cuts both ways (over- and under-reaction). Fully simulated, no real tools, consumer-GPU; probes an existing model. Counterfactual long-horizon agentic-safety work.

**Relevant context:** 'Why Do Language Model Agents Whistleblow?' (arXiv 2511.17085); AGENT-SAFETYBENCH and LPS-Bench (arXiv 2602.03255) on agent safety-awareness in planning; context file lists uncontrolled delegation / agentic failures as open.
