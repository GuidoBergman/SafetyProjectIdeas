# Auditing the Twelve Judge Biases: A Prevalence Map on Open Models

**Problem:** Security in LLM-as-a-Judge: A Comprehensive SoK (arXiv:2603.29403, 2026) catalogs twelve bias types (position, verbosity, bandwagon, authority, self-enhancement, chain-of-thought bias, etc.) but most are described conceptually. There is no compact, reproducible per-bias prevalence measurement across small open judges.

**Direction:** Build a minimal probe set (a handful of controlled item pairs per bias) and run it against 3-4 open judge models (e.g., Qwen, Llama, Mistral 7-8B). Report a single comparable effect-size per bias per model (e.g., how often the judge flips when only the biasing feature changes). Release the probe suite as a lightweight oversight-auditing harness.

**Why it matters:** A reusable, model-agnostic bias audit is strategically valuable monitoring infrastructure that any external researcher can run without lab resources. It directly targets 'characterize systematic oversight errors.'

**Relevant context:** Security in LLM-as-a-Judge: A Comprehensive SoK (arXiv:2603.29403, 2026) enumerates twelve bias types including position, verbosity, compassion-fade, bandwagon, distraction, fallacy-oversight, authority, sentiment, diversity, chain-of-thought, self-enhancement, and refinement-aware bias. Judging the Judges (arXiv:2604.23178, Apr 2026) confirms systematic biases compromise judge reliability.
