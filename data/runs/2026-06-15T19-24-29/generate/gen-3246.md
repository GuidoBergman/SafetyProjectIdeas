# Consistency Cracks: Detecting Deception via Cross-Question Contradiction

**Problem:** A model that lies to advance a goal must maintain a consistent false story; the causal link is 'sustain the lie across rephrasings/probes.' Honest models should be consistent for the right reasons; deceivers may contradict themselves when probed from many angles. A cheap consistency-probe detector at this link is underused for deception specifically.

**Direction:** Set up a toy scenario where an open model is instructed to conceal one fact (a known secret). Probe the secret from many indirect angles and rephrasings; compare contradiction rates to an honest-baseline scenario. Build a consistency-based deception score and measure its separation between concealing and honest conditions.

**Why it matters:** Consistency probing needs only API access and no ground-truth labels at deployment, making it a strategically valuable, lab-independent monitoring primitive for covert deception.

**Relevant context:** Honesty-verification is an open problem (UK AISI alignment agenda); sandbagging/scheming evals rely on behavioral inconsistencies; Apollo scheming evals probe whether models maintain deceptive stories.
