# FindTheFlaws-Speed: A Time-Budgeted Error-Catching Benchmark for Weak Overseers

**Problem:** FindTheFlaws provides annotated flawed reasoning for oversight research, but real oversight is time-constrained; no benchmark measures how overseer error-detection degrades as the per-item inspection budget shrinks (tokens read, or judge model size).

**Direction:** Using the open FindTheFlaws dataset, build a harness that exposes a weak judge to flawed solutions under graduated 'inspection budgets' (truncated context windows or smaller judge models) and plots flaw-detection recall vs budget. Report the budget at which detection collapses.

**Why it matters:** Quantifying the inspection budget needed to catch reasoning flaws operationalizes the limits of weak oversight and is directly reusable; it builds on an open dataset and runs on a single GPU.
