# Cue-Insertion Causal Test for CoT Faithfulness Without Ground-Truth Reasoning

**Problem:** Measuring CoT faithfulness is hard because we lack ground-truth reasons. A causal-chain view isolates one link: if inserting a cue into the prompt changes the answer but the cue never appears in the CoT, the CoT is causally unfaithful. This task-agnostic intervention is under-exploited as a simple, beginner-runnable faithfulness metric.

**Direction:** Adapt the published causal-intervention faithfulness method: systematically inject hints/biasing cues (e.g., 'a Stanford professor thinks the answer is B'), measure answer shift, and check whether the CoT acknowledges the cue. Build a small leaderboard of faithfulness across a few open models and prompt styles, and categorize pathologies (post-hoc, encoded, internalized reasoning).

**Why it matters:** Provides a reusable, ground-truth-free faithfulness measurement harness — strategically valuable monitoring infrastructure that any small team can run. Directly targets the monitor-reliability link in the deception chain.

**Relevant context:** Task-agnostic causal interventions for diagnosing CoT pathologies ('Diagnosing Pathological Chain-of-Thought', arXiv:2602.13904); biased-context faithfulness tests from prior CoT-faithfulness literature.
