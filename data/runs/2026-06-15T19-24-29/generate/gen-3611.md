# Unfaithful CoT x Self-Consistency: Does Sampling-Based Self-Consistency Mask Unfaithful Reasoning?

**Problem:** Self-consistency (majority vote over sampled CoTs) is used to boost reliability; it compounds with unfaithfulness when all sampled CoTs are unfaithful in the same direction — the model votes confidently on a hint-influenced answer while every rationale omits the hint, so consistency looks like correctness.

**Direction:** Run self-consistency (k samples) on hint-planted problems with an open model. Measure whether high agreement co-occurs with high hint-influence and low hint-mention. Test whether self-consistency confidence is uncorrelated with faithfulness — i.e., consistent answers can be uniformly unfaithful. Inference-only.

**Why it matters:** Shows a popular reliability heuristic provides no faithfulness guarantee and can manufacture false confidence in hidden reasoning. Names: CoT unfaithfulness and self-consistency-induced overconfidence.

**Relevant context:** Faithfulness via planted hints (Anthropic experiments); self-consistency is a standard CoT method; 'CoT Is Not Explainability' argues consistency does not imply faithful explanation.
