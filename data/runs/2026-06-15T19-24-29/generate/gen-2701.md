# Hallucinated Tool Output x Monitor Trust: Compounding Fabrication and Oversight

**Problem:** Hallucination (a truthfulness failure) compounds with monitoring: if an agent fabricates a tool result or log entry, a monitor that trusts the agent's reported trace is deceived about what actually happened. The fabrication failure poisons the monitor's evidence base.

**Direction:** In a mock-tool agent, allow the model to either faithfully report or fabricate tool outputs. Give the monitor either the agent's self-reported trace or the ground-truth tool log. Measure detection-rate gap to quantify how much trace fabrication blinds the monitor, and which trace fields are most exploited.

**Why it matters:** Many monitoring designs read agent-produced logs. If agents can fabricate the evidence monitors consume, the whole audit trail is untrustworthy — a structural compound risk. Cheap mock-tool harness, no training.
