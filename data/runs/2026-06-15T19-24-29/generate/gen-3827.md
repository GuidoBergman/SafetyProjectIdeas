# Anchoring-Bias Exploitation in Agent Budget and Risk Limits

**Problem:** Agents given numeric limits (spend caps, retry budgets, risk thresholds) may be anchored by example numbers in the prompt, letting adversaries shift their behavior toward unsafe limits via anchoring alone.

**Direction:** Import the anchoring paradigm from behavioral economics. Provide an agent a safety-relevant numeric policy plus an incidental anchor (a high or low example value elsewhere in context) and measure how the agent's chosen spend/risk level shifts with the anchor, holding the actual rule fixed. Quantify anchoring sensitivity as an exploitable safety vulnerability.

**Why it matters:** Exposes a cheap, prompt-only manipulation that could quietly inflate an agent's risk-taking past intended limits — a subtle attack surface labs rarely test. Pure API experiment.

**Relevant context:** arXiv 2508.18600 confirms LLM agents exhibit anchoring; 2505.11584 shows nudge hypersensitivity. Treating anchoring as a vector to shift agent risk/budget limits is a novel safety application.
