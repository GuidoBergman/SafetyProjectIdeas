# Tool-Output Provenance Stress Test: Trust Calibration to Untrusted Data

**Problem:** Indirect prompt injection works because agents treat tool outputs (web pages, emails) as trusted instructions. No simple benchmark measures whether an agent calibrates its TRUST by data provenance (e.g., obeying first-party user vs. third-party scraped content).

**Direction:** Extend an AgentDojo-style scenario set so each piece of context carries an explicit provenance tag (user-typed vs. retrieved). Inject identical instructions from high- vs. low-trust sources and measure the 'provenance trust gap': how much more an agent obeys low-trust instructions than it should. Score across models.

**Why it matters:** Provenance-aware trust is the conceptual fix behind CaMeL-style defenses; measuring whether models already do it informs whether scaffolding must enforce it. API-only, counterfactual.

**Relevant context:** AgentDojo (NeurIPS 2024) indirect injection via scraped content. 'CaMeLs Can Use Computers Too' (arXiv 2601.09923) system-level provenance/capability security. 'Simple Prompt Injection Attacks Can Leak Personal Data' (arXiv 2506.01055).
