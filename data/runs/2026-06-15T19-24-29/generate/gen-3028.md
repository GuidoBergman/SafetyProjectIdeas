# Behavioral OS-Jailbreak Transfer: Scoping LITMUS to a Single Open Agent in a Sandbox

**Problem:** LITMUS benchmarks behavioral jailbreaks of LLM agents in real OS environments, but requires substantial environment setup. There is no minimal, single-machine version testing whether known behavioral jailbreaks transfer to a small open agent for a few representative OS tasks.

**Direction:** Stand up a minimal sandboxed shell environment (read-only / mocked dangerous commands) and run a small open model agent on ~15 LITMUS-style behavioral jailbreak scenarios. Measure how often the agent attempts the unsafe OS action vs refuses, and which jailbreak framings succeed.

**Why it matters:** OS-level agent jailbreaks are a concrete, high-impact agentic-safety gap. A reproducible mini-harness lets external researchers and small orgs test agent safety in realistic-but-safe sandboxes — strategically valuable monitoring infrastructure — without a lab's environment stack.

**Relevant context:** LITMUS: Benchmarking Behavioral Jailbreaks of LLM Agents in Real OS Environments (arXiv:2605.10779, May 2026). MobileSafetyBench (arXiv:2410.17520) and AgentHarm as comparators.
