# Probing 'reasoning-as-tool-use' equivalence for hidden-plan detection

**Problem:** 'Toward a Theory of Agents as Tool-Use Decision-Makers' (June 2026) treats internal reasoning and external actions as equivalent epistemic tools. If true, a model could shift dangerous planning from verbalized CoT into 'tool-call reasoning' that evades CoT monitors.

**Direction:** Set up an open agent model on a task solvable either by verbalized reasoning or by chains of tool calls. Apply pressure (instructions/incentives) to minimize verbalized reasoning and measure whether problem-solving capability is preserved while CoT-visible content drops — i.e. capability migrates to tool-call structure. Success = evidence that monitorable CoT can shrink without capability loss.

**Why it matters:** A concrete model-organism-style demonstration that an agent can 'reason without saying' by offloading to tool calls would be a serious warning for CoT-based oversight — a medium-horizon threat, studyable on open models.

**Relevant context:** Extends 'Toward a Theory of Agents as Tool-Use Decision-Makers' (arXiv:2506.00886, June 2026).
