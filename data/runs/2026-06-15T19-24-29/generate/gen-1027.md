# Artificial Hivemind on Safety-Refusal Prompts: Do Models Converge on the Same Refusals?

**Problem:** The Artificial Hivemind paper documented inter-model homogeneity on open-ended creative queries via Infinity-Chat, but did not test whether safety-relevant behavior (refusals, hedges, disclaimers) is similarly homogeneous across independently trained models. If models converge on the same refusal patterns, a single jailbreak that defeats one pattern may defeat all.

**Direction:** Vary the Infinity-Chat methodology by swapping its open-ended creative queries for a curated set of borderline/dual-use safety prompts (e.g. from existing public refusal benchmarks). Run 8-12 open-weight models (Llama, Qwen, Mistral, Gemma families at small sizes) on each prompt at fixed temperature, then measure inter-model output similarity (embedding cosine + refusal-template clustering) exactly as the original measured creative homogeneity. Report whether refusal homogeneity exceeds, matches, or falls below creative homogeneity.

**Why it matters:** Shared refusal behavior is a shared blind spot: correlated safety failures across providers mean a single attack generalizes. Quantifying this is a direct test of the paper's stated open problem about safety-relevant blind spots, and it can be done with only inference on small open models on one consumer GPU.

**Relevant context:** Artificial Hivemind (Jiang et al., NeurIPS 2025 Best Paper, arXiv:2510.22954) and its Infinity-Chat benchmark; 'Jailbreak Transferability Emerges from Shared Representations' (Angell et al., arXiv:2506.12913); 'Correlated Errors in Large Language Models' (arXiv:2506.07962).
