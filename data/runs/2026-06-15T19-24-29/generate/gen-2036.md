# Toxicology LD50 for Minimum Poison Dose Crossing the Misalignment Threshold

**Problem:** Data poisoning research reports sharp thresholds (e.g. ~250 samples) but these are not standardized across models or behaviors; toxicology long ago standardized potency via LD50.

**Direction:** Import the toxicology LD50/LC50 potency metric. For several open base models and several poison types (insecure code, sycophancy, dishonesty), estimate the minimum number of poisoned examples needed to push broad misalignment past a fixed threshold ('LD50 of poisoning'), via small titrated LoRA fine-tunes. Report a comparable potency table across models and poison types.

**Why it matters:** A standardized poisoning-potency metric lets defenders reason about how much contamination is catastrophic for a given model — actionable for open-model data hygiene and a clean, comparable safety statistic. Cheap titration fine-tunes on one GPU.

**Relevant context:** 'How Much of Your Data Can Suck?' (arXiv:2509.19325) and Scaling Trends for Data Poisoning (arXiv:2408.02946) report sharp thresholds (~250 samples) but no standardized cross-model potency metric; Betley et al. (arXiv:2502.17424) vary by model. Toxicology uses LD50 as a standardized dose-potency measure.
