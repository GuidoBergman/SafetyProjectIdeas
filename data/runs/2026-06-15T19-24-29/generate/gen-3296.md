# Probe Brittleness x Eval Awareness: Does an Eval-Aware Model Evade a Deception Probe Under Paraphrase?

**Problem:** Interacting failure modes: (A) interpretability-probe brittleness (interpretability); (B) evaluation awareness (deception/scheming). Compound effect: a linear deception/awareness probe trained on canonical eval prompts may fail when an eval-aware model rephrases its outputs to look like normal task text, so the monitoring tool breaks precisely against capable adversaries.

**Direction:** Train a simple linear probe on hidden states of an open model to detect 'eval-aware' vs 'real-task' framings on a labeled prompt set (logistic regression on mean-pooled activations — well within intro-ML skills). Then test the probe on paraphrased / disguised eval prompts and on prompts where the model is told to 'act natural'. Measure probe accuracy drop. Report the robustness gap between canonical and adversarial framings.

**Why it matters:** Tests whether the cheap, popular linear-probe monitoring approach survives the obvious adversarial response, informing how much weight a probe-based safety case can bear.

**Relevant context:** 'Probing and Steering Evaluation Awareness' (arXiv:2507.01786) provides probe methodology. Activation-probe generalization concerns are a recurring interpretability theme.
