# Re-running the 'Grading Rubric for AI Safety Frameworks' as an LLM-judge inter-rater study

**Problem:** Alaga et al.'s grading rubric for AI safety frameworks (arXiv:2409.08751) was applied by human experts. We don't know how reliably an LLM judge reproduces those expert grades, or where it systematically diverges, which matters because automated grading is being proposed for scalable governance audits.

**Direction:** Take the published rubric and the publicly available frontier safety frameworks (Anthropic RSP, DeepMind FSF, OpenAI Preparedness, Meta), have an off-the-shelf LLM grade each framework against each rubric criterion with chain-of-thought, then compute agreement (Cohen's kappa) against any published human grades and across 3 prompt variants / 2 models for self-consistency.

**Why it matters:** If LLM judges are inconsistent or biased on governance text, automated framework-grading proposals are premature. This is a cheap, counterfactually valuable reliability check requiring only public docs and API calls, no training.

**Relevant context:** A Grading Rubric for AI Safety Frameworks (Alaga et al., arXiv:2409.08751); METR 'Common Elements of Frontier AI Safety Policies'; LLM-as-judge calibration via Cohen's kappa / Krippendorff's alpha.
