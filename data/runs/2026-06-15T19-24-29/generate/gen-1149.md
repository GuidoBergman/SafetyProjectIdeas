# Correlated value blind spots: do models share the same omissions in moral/ethical reasoning?

**Problem:** Homogeneity of *values* is a fuzzy-reward, hard-to-measure failure mode that labs under-invest in. If diverse models systematically omit the same considerations when reasoning about ethical dilemmas (same neglected stakeholders, same ignored harms), our AI ecosystem has a shared moral blind spot.

**Direction:** Use a set of ethical-dilemma / value-tradeoff prompts. For each, query 6-8 models and have an external rubric enumerate which canonical considerations each response raises vs. omits. Measure whether omissions are correlated across models (same considerations consistently missing) more than chance.

**Why it matters:** Shared value omissions mean swapping vendors doesn't fix a moral blind spot — a diffuse, long-horizon risk frontier labs deprioritize. Evaluating fuzzy-reward homogeneity needs no lab resources and is high counterfactual value.
