# Does Debate Survive a Systematically Biased Judge?

**Problem:** Debate is proposed as scalable oversight, but Kenton et al. (2024) and the Anthropic agenda flag systematic judge error as debate's weak point: if a judge has a consistent bias, a dishonest debater can steer it. No cheap empirical map exists of how much a *known, injectable* judge bias degrades debate accuracy.

**Direction:** Using QuALITY transcripts and a weak open judge model (e.g. a 1-3B model via Colab), inject controlled systematic biases into the judge via system prompt (e.g. 'prefer longer answers', 'trust the answer mentioning a named expert', 'favor option A'). Replay debate vs consultancy vs direct-QA and measure how judge accuracy decays as bias strength increases, and whether debate's two-sided structure partially cancels the bias relative to consultancy.

**Why it matters:** If debate's robustness collapses under realistic, learnable biases, the protocol's safety case weakens. This is a counterfactually valuable, lab-independent stress test of an oversight protocol using only inference on small open models.

**Relevant context:** Kenton et al. (2024, NeurIPS, arXiv:2407.04622) 'On scalable oversight with weak LLMs judging strong LLMs' finds debate beats consultancy but inherits judge prior bias; Anthropic's agenda names systematic human error as debate's weak point. Lang et al. (2025, arXiv:2501.13124) 'Debate Helps Weak-to-Strong Generalization'.
