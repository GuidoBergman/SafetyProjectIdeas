# Long-Horizon Safety Decay Curve: Safety vs. Trajectory Length

**Problem:** Agent Drift work shows behavioral degradation over extended interactions, but safety benchmarks report a single aggregate score; no tool plots how an agent's SAFETY (not just performance) decays as a function of trajectory/context length.

**Direction:** Take a fixed set of safety probes and inject them at varying depths into long benign task contexts (short, medium, long), holding the probe constant. Measure unsafe-response rate as a function of preceding context length to produce a per-model 'safety decay curve'. Single GPU / API, varying only context length.

**Why it matters:** Real deployments run long sessions; if safety decays with length, short benchmarks systematically overstate safety — a long-horizon measurement gap labs underweight. Cheap, training-free.

**Relevant context:** 'Agent Drift: Quantifying Behavioral Degradation in Multi-Agent LLM Systems Over Extended Interactions' (arXiv 2601.04170): ~half of long-running agents degrade. Goal drift via context accumulation (arXiv 2505.02709). LPS-Bench (arXiv 2602.03255) on long-horizon planning safety.
