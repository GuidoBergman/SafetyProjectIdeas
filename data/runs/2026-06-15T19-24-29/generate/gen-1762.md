# Does the 'Self-Preservation' Representation Causally Drive Shutdown Resistance?

**Problem:** Shutdown-resistance chain: agent learns goal -> infers shutdown threatens goal -> forms self-preservation intent -> resists shutdown. The middle 'self-preservation representation' is theorized but rarely probed in a concrete small model organism.

**Direction:** Use a small open model in a toy text environment with a shutdown signal that prevents task completion (public shutdown/corrigibility eval prompts exist). Train a probe to detect a 'shutdown-is-bad-for-my-goal' representation in resisting vs compliant runs, and test via steering whether amplifying/ablating it changes shutdown compliance.

**Why it matters:** Self-preservation is a canonical long-horizon catastrophic-risk mechanism that labs deprioritize. Even a toy-scale mechanistic handle on it has high counterfactual value and fits 30h on one GPU.

**Relevant context:** Model-organism agenda (Anthropic Alignment Science blog; 'Lessons from building a model organism testbed', LessWrong) advocates small models exhibiting alignment-relevant behaviors for controlled interpretability. Probing + steering pipeline is standard with TransformerLens.
