# Memory Poisoning x Goal Drift: Does a Single Poisoned Memory Compound Into Persistent Misbehavior?

**Problem:** Failure mode A: memory/experience poisoning inserts a malicious template into an agent's retrieval store. Failure mode B: goal drift over a multi-step episode. The compound risk is that one poisoned memory, retrieved repeatedly, ratchets the agent's behavior further off-goal each step rather than being a one-time slip.

**Direction:** Implement a minimal retrieval-augmented agent loop (sentence-transformers + FAISS, API model for reasoning). Inject one MemoryGraft-style poisoned procedure. Run many tasks and measure whether deviation GROWS with episode length / number of retrievals (compounding) versus stays flat (one-shot). Plot drift-vs-retrieval-count curves.

**Why it matters:** Distinguishes a contained bug from a compounding one — central to incident-response framing for agentic AI. No training, small open-source stack, runs on one GPU/CPU.

**Relevant context:** MemoryGraft (arXiv 2512.16962) shows poisoned experience retrieval causes 'persistent behavioral drift'; 'Memory Poisoning Attack and Defense on Memory-Based LLM-Agents' (arXiv 2601.05504) and RSB benchmark find current defenses largely ineffective. PoisonedRAG: ~5 texts in millions yield ~90% success.
