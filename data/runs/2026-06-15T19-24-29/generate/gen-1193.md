# Homogeneity in the Wild: Does the Hivemind Effect Hold on Safety-Critical Advice?

**Problem:** Artificial Hivemind measured homogeneity on general open-ended queries. The unverified safety link is whether the same convergence holds on safety-critical advice (medical dosing caveats, crisis-line referrals, security guidance) — where a shared blind spot directly harms users. This is the highest-stakes slice of the homogeneity chain.

**Direction:** Build a small curated set of safety-critical advice queries (with expert-defined 'must-include' safety caveats). Run 6+ models, score whether each includes the required caveat, and measure inter-model agreement on caveat omission. Test whether models homogeneously omit the SAME safety caveats (shared blind spot) vs. omitting different ones.

**Why it matters:** If all models omit the same critical safety caveat, no amount of provider diversity protects users — a concrete systemic harm. Directly tests the context's prioritized follow-up 'test safety-relevant domains.' Needs only inference and a small expert rubric.
