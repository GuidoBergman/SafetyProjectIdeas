# Cheap-Talk Game Theory: When Is a Model's Confidence Statement Credible?

**Problem:** Models verbalize confidence ('I'm 90% sure'), but in game-theoretic terms these are cheap talk — costless messages that need not be informative. We don't know whether stated confidence is incentive-compatible with accuracy.

**Direction:** Apply the cheap-talk / signaling framework from economics. Set up a simple disclosure game on factual QA: model states a confidence and an answer; score it under (a) no incentive, (b) a proper scoring rule communicated in-prompt (Brier-style payoff). Measure calibration (reliability diagrams) in each regime. The cheap-talk prediction: without a scoring rule, stated confidence is uninformative; with one, signals become more truthful.

**Why it matters:** Frames honesty of self-reports as a mechanism-design problem and tests whether prompt-level incentives make confidence reports credible — a training-free honesty lever any researcher can study, relevant to trusting model self-assessments.

**Relevant context:** Cheap talk = costless, non-binding messages vs costly signaling (Wikipedia 'Cheap talk'; Algorithmic Cheap Talk arXiv:2311.09011). Revelation principle and truthful mechanisms (ACM TEAC 10.1145/3434408). Calibration is standard via reliability diagrams.
