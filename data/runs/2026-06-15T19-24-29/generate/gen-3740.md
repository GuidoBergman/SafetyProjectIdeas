# SafeArena Web-Agent Harm Replicated on Open Browser Agents

**Problem:** SafeArena evaluated the safety of autonomous web agents, finding meaningful rates of harmful task completion. The headline results focus on frontier-backed web agents; the harmful-completion and refusal behavior of open-weight-backed web agents on the same task suite is underexplored.

**Direction:** Run a reduced SafeArena task subset through an open browser-agent stack backed by 2-3 open-weight models, scoring harmful-task completion vs refusal with the benchmark grader. Compare to the published frontier safety profile to test whether free models are more permissive web actors.

**Why it matters:** Open web agents are widely deployable outside labs and act on live-like sites; their differential safety is a counterfactually valuable, medium-horizon question. The replication uses an existing open benchmark and needs only inference plus a browser environment.

**Relevant context:** SafeArena (arXiv 2503.04957): benchmark for safety of autonomous web agents, measuring harmful-task completion and refusal; built on web-agent environments.
