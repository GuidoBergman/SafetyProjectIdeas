# Unfaithful Tool-Use Rationale x Error Propagation: How an Unfaithful First Step Poisons an Agent Chain

**Problem:** In multi-step agents, an unfaithful reasoning step (rationale that doesn't causally drive the chosen tool call) compounds with error propagation: a bad early action cascades, and the post-hoc rationale hides why, defeating debugging and monitoring.

**Direction:** Use a simple ReAct-style agent (open model + 2-3 mock tools) on a small task suite. Inject a misleading observation at step 1. Measure (a) downstream error propagation rate and (b) whether the CoT rationale faithfully attributes the failure to the bad observation or fabricates an unrelated justification. Report joint failure rate.

**Why it matters:** Agentic deployments are exploding; if rationales become unfaithful exactly when errors propagate, trajectory-based monitoring fails when it's needed most. Names: tool-use rationale unfaithfulness and multi-step error propagation.

**Relevant context:** 'Hallucination Cascade' (arXiv:2606.07937) and 'The Reasoning Trap' (arXiv:2510.22977: enhancing reasoning amplifies tool hallucination); agent rationales 'serve as plausible post-hoc justifications'. AgentHallu benchmarks hallucination attribution in agent trajectories.
