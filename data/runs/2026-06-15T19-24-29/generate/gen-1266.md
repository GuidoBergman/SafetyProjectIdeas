# Shared Blind Spots Defeat Ensemble Monitoring: Measuring Correlated Misses Across a 'Diverse' Monitor Panel

**Problem:** Failure mode A: inter-model homogeneity / shared blind spots. Failure mode B: oversight via LLM ensembles assumes monitors fail independently so a majority vote catches problems. If monitors share blind spots, the ensemble fails exactly when it matters, but its agreement looks like confidence.

**Direction:** Build a small monitoring task (detect policy-violating or unsafe completions) using 6 open models as monitors. Inject a fixed set of unsafe outputs. Measure whether misses are independent (binomial expectation) or correlated (shared misses far exceeding chance). Compute focal-diversity / correlated-error rate and show how much the ensemble's effective error rate exceeds the naive independence assumption.

**Why it matters:** Defense-in-depth and 'use multiple models to watch each other' is a core safety proposal. This quantifies how homogeneity erodes the safety margin of ensemble oversight — a medium-horizon risk labs underweight. Pure inference, consumer-GPU scale.

**Relevant context:** Artificial Hivemind shared blind spots; 'Correlated Errors in LLMs' (arXiv 2506.07962); LLM-TOPLA focal diversity (arXiv 2410.03953); behavioral-entanglement auditing of verifier ensembles (arXiv 2604.07650).
