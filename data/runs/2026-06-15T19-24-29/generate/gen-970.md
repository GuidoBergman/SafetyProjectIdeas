# Mapping Visual-to-Language Feature Handoff in a Small Multimodal Model

**Problem:** How visual representations map into the language feature space inside multimodal LLMs is only beginning to be studied. Where and how a safety-relevant visual concept (e.g., a depicted weapon) becomes a language-space concept that triggers a refusal is essentially unmapped on open multimodal models.

**Direction:** Using a small open multimodal model and Prisma/SAE tooling, take image+text prompts for one safety-relevant visual concept and trace at which layer the visual feature aligns with the corresponding language concept, testing whether refusal is driven by the visual feature or only by the later language-space feature.

**Why it matters:** Image-driven jailbreaks exploit exactly this handoff. Mapping it mechanistically on open models is novel multimodal-safety work with no need for proprietary systems.

**Relevant context:** 'How Visual Representations Map to Language Feature Space in Multimodal LLMs' (arXiv 2506.11976) and Prisma (arXiv 2504.19475) provide methods and weights. Extending mech interp to multimodal transformers is a listed open problem.
