# HumanVsHive: calibrating model homogeneity against actual human-answer diversity

**Problem:** Reports that models are 'homogeneous' lack a human baseline on the same prompts. Infinity-Chat has 25 human annotations per example — a chance to quantify exactly how much LESS diverse models are than humans, which no compact tool reports.

**Direction:** Use the public Infinity-Chat human annotations as the human-diversity reference. Generate model answers for a matched subset, compute the same diversity metrics for the human set and each model set, and report a 'diversity deficit ratio' (human diversity / model diversity). Build it into a small reusable evaluator.

**Why it matters:** A calibrated human baseline transforms 'models are similar' into 'models are N times less diverse than people' — a far more compelling and policy-relevant statement about homogenization of thought. Reuses an existing public dataset; no training, modest compute.

**Relevant context:** Directly leverages Infinity-Chat's 31K human annotations (arXiv:2510.22954); connects to homogenization-of-human-thought concern (arXiv:2508.01491).
