# A Severity-Calibration Test for AI Incident Harm-Scoring Schemes

**Problem:** Incident frameworks (AI Harmonics, OECD) propose harm-severity scales, but it is unmeasured whether independent raters assign consistent severity to the same incident, i.e. whether the scales are calibrated. No public calibration test exists.

**Direction:** Select ~50 AIID incidents, have multiple raters (humans + an LLM) score severity under 2 competing severity rubrics, and compute calibration/agreement statistics per rubric. Identify incident features that cause severity disagreement and recommend rubric refinements. Release the rated set.

**Why it matters:** Consistent severity scoring underpins incident-response prioritization and cross-jurisdiction reporting; demonstrating where scales are mis-calibrated improves an emerging standard, using public data and basic statistics.

**Relevant context:** 'AI Harmonics' severity-adaptive framework (arXiv 2509.10104); OECD reporting framework; AIID (public). Calibration/agreement stats fit the participant profile.
