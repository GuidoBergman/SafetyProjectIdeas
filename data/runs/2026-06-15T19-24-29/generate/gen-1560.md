# Backcasting robust steering: can a cheap input perturbation neutralize a deployed concept vector?

**Problem:** A safety success state requires concept-based steering/monitoring that an adversary with prompt-only (black-box-ish) access cannot disable. Open Problem #1 in the subfield context asks exactly this: can attackers craft inputs that neutralize steering? No beginner-accessible characterization of how fragile a steering vector is to simple input manipulation exists.

**Direction:** Steer a small open model toward refusal (or away from toxicity) with a fixed concept vector. Then test simple adversarial inputs that a non-expert attacker could try: paraphrase, role-play framing, prefix injection, and appended distractor text. Measure how much each reduces the steering effect (drop in refusal rate / rise in toxicity). Rank perturbation types by neutralization power.

**Why it matters:** Directly answers a flagged open problem with a model-organism-style fragility study. Establishes the threat model for anyone proposing steering as a safety control, and is fully reproducible outside a lab on open weights.

**Relevant context:** Subfield Open Problem #1 (Beaglehole et al.). Connects to adversarial-steering findings (Rogue Scalpel arXiv 2509.22067).
