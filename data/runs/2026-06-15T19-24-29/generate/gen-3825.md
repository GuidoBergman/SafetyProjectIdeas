# Statistical Process Control Charts for Agent Behavior Drift

**Problem:** Agents' behavior can drift over a long session or across model/prompt updates (goal drift, increasing risk-taking), but there is no standard online detector for such drift.

**Direction:** Import Statistical Process Control (SPC) from manufacturing quality. Define behavioral metrics per step (e.g. fraction of high-acuity tool calls, refusal rate) and run CUSUM / EWMA control charts to detect out-of-control drift in real time on long agent runs. Validate by injecting a known mid-session goal shift and measuring detection latency vs false-alarm rate.

**Why it matters:** Targets the goal-drift open problem with a cheap, interpretable online monitor that any deployer can run — strategically valuable monitoring infrastructure built outside a lab.

**Relevant context:** SPC control charts (CUSUM/EWMA) are standard for detecting process drift in manufacturing. The agentic-safety open-problems list cites goal drift as a key multi-step failure with no good detection method; SPC-based drift monitoring of agent behavior is unexplored.
