# Network-Neuroscience Modularity Scores for Transformer Circuits

**Problem:** We describe transformers as having 'modules' informally, but never quantify modularity with the rigorous graph-theoretic tools network neuroscience uses for brains (Newman modularity, participation coefficient, small-worldness).

**Direction:** Transfer graph-theoretic brain-network metrics. Build a weighted directed graph of inter-component influence (via attribution / patching effects) for a small model on a task, then compute modularity Q, community structure, and small-worldness. Compare these metrics across tasks and across two model sizes to test whether more capable models are more modular. Single GPU, all measurement.

**Why it matters:** Quantifying modularity tells us whether safety-relevant computation is localized (easy to monitor/remove) or distributed (hard), and whether modularity changes with scale, informing how interpretability will fare on frontier models. Uses only open tooling.

**Relevant context:** 'Circuit Compositions: Exploring Modular Structures in Transformer-Based LMs' (arXiv:2410.01434) finds modular structure; network neuroscience uses modularity Q and small-worldness to predict working-memory capacity (PMC3262818). The transfer of these exact metrics to attribution graphs is underexplored.
