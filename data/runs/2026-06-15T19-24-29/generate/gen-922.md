# Open-Weight Release x Tamper-Removable Safeguards: Measuring the Governance Point of No Return

**Problem:** Failure mode A: release decisions treat a model's disclosed safety evals as durable. Failure mode B: fine-tuning trivially removes refusal/unlearning safeguards. Together, an irreversible release decision is made on a safety property that evaporates in a few gradient steps — the 'safety gap' the governance process never measured.

**Direction:** Using the published Safety Gap Toolkit methodology on a small open model, fine-tune away refusals on a tiny harmful-request set and measure the pre/post compliance-rate gap on a benign proxy. Then survey the actual release-justification documents for 4-5 open-weight models and check which (if any) reported a post-fine-tuning safety number. Produce a 'release-decision blind spot' report.

**Why it matters:** Shows regulators and labs that release governance is built on a property (refusal behavior) that does not survive the very modification open weights enable. Medium-horizon proliferation threat that frontier labs deprioritize; runnable on one consumer GPU.

**Relevant context:** Safety Gap Toolkit (arXiv:2507.11544); durability of open-weight safeguards (arXiv:2412.07097); UK AISI on open-weight risks (aisi.gov.uk).
