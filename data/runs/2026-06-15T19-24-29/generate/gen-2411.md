# Rubric Self-Preference x Reward Hacking: Structured Scoring Doesn't Save You

**Problem:** Two failure modes compound: (A) self-preference bias surviving rubric-based scoring (judges still favor own-style outputs even with explicit rubrics) and (B) reward hacking (generators optimize to the judge). Rubrics are sold as a debiasing fix; if self-preference leaks through rubric scoring, the generator can still hack the supposedly objective signal.

**Direction:** Score a fixed answer set with an open judge using (1) free-form scoring and (2) detailed rubric scoring, comparing in-family vs out-of-family generations of matched quality. Measure whether the self-preference gap shrinks under rubrics. Then test whether a cheap style edit still moves rubric scores. The compounding metric: residual hackability that survives rubric structure.

**Why it matters:** Rubrics are the standard recommended mitigation for judge bias (and the project requires rubrics for any numeric score). Empirically showing rubrics fail to remove self-preference — and that hacking persists — tempers a widely-trusted oversight safeguard. Inference + comparison; clean 30h project.

**Relevant context:** Self-Preference Bias in Rubric-Based Evaluation of LLMs (arXiv 2604.06996) finds self-preference persists under rubrics. UDA debiasing (arXiv 2508.09724). One Token to Fool LLM-as-a-Judge (arXiv 2507.08794).
