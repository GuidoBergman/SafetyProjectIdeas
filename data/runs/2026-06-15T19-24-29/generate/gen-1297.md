# Quantifying the Effective Number of Independent Foundation Models in Practice

**Problem:** The 'Quantifying Systemic Vulnerability in the Foundation Model Industry' paper assesses concentration via inputs (compute, energy, talent). It does not measure BEHAVIORAL concentration: even if there were 50 model providers, if their outputs cluster into 3 behavioral types, effective diversity is ~3. No simple behavioral diversity index exists.

**Direction:** Run ~20 accessible models on a fixed battery of prompts (factual, refusal, open-ended). Build a behavioral fingerprint per model (agreement vectors / output embeddings). Cluster and compute an 'effective number of independent models' (e.g., via eigenvalue participation ratio of the agreement matrix). Compare to the count of nominal providers.

**Why it matters:** Concentration risk policy (EU AI Act systemic-risk) needs a measurable behavioral diversity index, not just input counts. A reproducible, infrastructure-level metric anyone can compute is exactly counterfactually valuable for systemic-risk monitoring.

**Relevant context:** Extends 'Quantifying Systemic Vulnerability in the Foundation Model Industry' (arXiv:2510.23421, Oct 2025) from input-concentration to behavioral-concentration metrics, using correlated-error methodology from arXiv:2506.07962.
