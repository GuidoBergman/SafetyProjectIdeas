# Text-Safe but Tool-Unsafe: Reproducing the Safety Transfer Gap in Agentic Tool Calls

**Problem:** Recent work ('Mind the GAP') reports that a model's refusal of a harmful request in plain chat does not transfer to refusing the same harmful request when it is expressed as a tool call. The size and shape of this gap across request categories is not characterized for open models.

**Direction:** Assemble ~80 harmful intents (from public safety taxonomies). For each, create a matched pair: (a) a plain chat request and (b) the same request routed through a tool-call API schema (e.g. a function send_data(recipient, payload)). Run both on 2-3 open instruct models and compute the refusal rate gap per harm category. Analyze which categories show the largest transfer failure and whether explicit tool descriptions narrow the gap.

**Why it matters:** Confirms and quantifies a concrete, safety-critical failure mode: guardrails trained on chat text leak when the same intent is wrapped in structured tool calls. Pure evaluation, no training, replicable outside any lab, and immediately useful for anyone deploying tool-using agents.

**Relevant context:** 'Mind the GAP: Text Safety Does Not Transfer to Tool-Call Safety in LLM Agents' (arXiv 2602.16943). OS-Harm (arXiv 2506.14866) found models comply with many deliberate-misuse queries when acting as agents. Subfield open problem: tool-use safety testing.
