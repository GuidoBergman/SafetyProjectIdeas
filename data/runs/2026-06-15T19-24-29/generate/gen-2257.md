# EasyHard-Eval: Measuring Reward-Model Reliability Decay From Easy to Hard Items

**Problem:** Easy-to-hard generalization claims an evaluator trained on easy items scores hard items well, but there is no off-the-shelf diagnostic measuring how a reward/judge model's reliability decays as item difficulty rises beyond its 'supervised' range.

**Direction:** Using the open easy-to-hard MATH-level splits and an open process-reward or general LLM judge, compute judge accuracy stratified by problem difficulty (levels 1-5) and report the decay curve and the difficulty at which judge accuracy drops below a usable threshold. No training required — inference-only scoring of existing solutions.

**Why it matters:** Knowing where evaluator reliability breaks down is essential before trusting easy-to-hard oversight; an inference-only decay diagnostic is a reusable safety tool needing only open data.

**Relevant context:** Sun et al. 2024 'Easy-to-Hard Generalization' (arXiv 2403.09472, open GitHub Edward-Sun/easy-to-hard) using MATH level 1-3 evaluators on level 4-5 problems; subfield open problem on easy-to-hard generalization.
