# Reproducing Theory-of-Mind Monitoring on a Budget

**Problem:** 'Learning to Monitor Autonomous LLM Agents via Theory-of-Mind' (arXiv:2605.24216, May 2026) proposes ToM-based monitoring. Whether a cheap, prompt-only ToM monitor (asking the monitor to infer the agent's intent before judging actions) beats a plain action-classifier monitor is unestablished.

**Direction:** On a small AI-control sabotage task set, compare two prompt-only monitors built from the same small open model: (a) a direct 'is this action unsafe?' monitor and (b) a ToM monitor that first infers the agent's likely goal/intent then judges. Compare detection AUC and false-positive rate.

**Why it matters:** If a no-training, prompt-only ToM framing improves monitoring, that's a free upgrade any outside-lab deployer can adopt - high counterfactual value for oversight infrastructure.

**Relevant context:** Learning to Monitor Autonomous LLM Agents via Theory-of-Mind (arXiv:2605.24216, May 2026); Reliable Weak-to-Strong Monitoring of LLM Agents (arXiv:2508.19461).
