# OverseerBench-Lite: A Minimal Standardized Task Suite for Comparing Oversight Protocols

**Problem:** The subfield context flags that no standardized scalable-oversight benchmarks exist, and reviews note debate produces mixed results partly because every paper uses a different task setup, making cross-protocol comparison impossible.

**Direction:** Assemble a small (60-100 item) frozen task suite drawn from existing open data (QuALITY reading-comprehension questions with hidden passages, plus a handful of verifiable code/logic items) and define a single fixed harness that runs three protocols (direct QA, consultancy, two-turn debate) with the same open judge model. Report judge accuracy per protocol with confidence intervals. Ship the harness + data manifest as the deliverable.

**Why it matters:** A shared, runnable micro-benchmark lets anyone reproduce the central 'does debate beat consultancy' question on a consumer GPU, addressing the identified standardization gap and lowering the barrier for outside-lab researchers.
