# Matryoshka vs Standard SAE: Which Preserves Safety Features Under Scaling?

**Problem:** Matryoshka SAEs organize features into nested reconstruction prefixes so high-level features aren't absorbed as dictionary size grows, but it is unverified whether SAFETY-relevant high-level features (e.g., a 'harmful intent' concept) are actually better preserved in Matryoshka SAEs than in standard SAEs of comparable size.

**Direction:** Compare an open Matryoshka SAE against a standard SAE on the same model/layer for the persistence and cleanliness of a chosen safety-relevant high-level feature across dictionary scales. Measure absorption/splitting of that specific feature in each architecture.

**Why it matters:** If a newer SAE architecture better preserves safety concepts, that is directly relevant to choosing monitoring tooling. This is an architecture-comparison study (a recommended strategy for this subfield) using only public weights.

**Relevant context:** Bussmann et al. 'Matryoshka Sparse Autoencoders' (Alignment Forum) describes nested prefixes preventing high-level feature absorption. 'A is for Absorption' (arXiv 2409.14507) documents the absorption/splitting problem these aim to fix.
