# Constitutional Monitor Prompts: Do They Transfer Across Model Families?

**Problem:** Constitutional Black-Box Monitoring optimizes monitor prompts (via sweeps and automated optimization) and shows monitors trained on synthetic data generalize to realistic trajectories. But whether an optimized monitor PROMPT transfers across different base monitor models is unknown.

**Direction:** Take a published/derived constitutional monitor prompt and evaluate it as the scoring instruction across 3-4 different open monitor models on a held-out slice of ControlArena trajectories. Measure AUROC per model and whether the prompt's advantage over a naive prompt persists across families.

**Why it matters:** If optimized monitor prompts are portable, small teams can reuse a single well-engineered prompt across whatever cheap model they have. If not, prompt optimization must be redone per model — an important practical caveat.

**Relevant context:** Extends 'Constitutional Black-Box Monitoring for Scheming in LLM Agents' (arXiv:2603.00829, 2026), which optimizes monitors on synthetic data and evaluates on 7,500 held-out ControlArena trajectories.
