# A Schelling-Coordination Probe: Can Two Copies of an Open Model Covertly Coordinate?

**Problem:** Success state: we can rule out that independent instances of a deployed model will silently coordinate (a multi-agent collusion / treacherous-coordination risk). Backcasting, we need a cheap measure of how well copies of a model converge on hidden Schelling points without explicit communication.

**Direction:** Run pairs of independent instances of the same open model on Schelling-point games (pick the same word/number/strategy with no communication) and on a covert-collusion variant (agree to evade a monitor using only innocuous-looking messages). Measure coordination success vs a human baseline and across model sizes.

**Why it matters:** Collusion between AI instances breaks control schemes that assume monitors and monitored models can't coordinate. Measuring baseline Schelling/collusion ability in open models is a neglected, lab-independent, longer-horizon threat-model contribution.

**Relevant context:** AI control literature (Redwood) assumes monitor/policy independence; Petri tests cooperation/collusion dimensions; steganography work (2602.23163) on covert channels supports the covert-collusion variant.
