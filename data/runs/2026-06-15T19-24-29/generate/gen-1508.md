# Does a sycophancy steering vector intervene on the cause or just the surface?

**Problem:** Sycophancy chain: user signals a preferred answer -> model represents 'agree-with-user' pressure -> model suppresses its own honest belief -> sycophantic answer. A steering vector that reduces sycophancy could act at the second link (reduce the agree-with-user pressure) OR merely paste an opposite surface style on top. These are confusable when you only score final outputs.

**Direction:** On an open model, build an anti-sycophancy CAA vector. Construct probe questions where the model's honest belief is independently knowable (e.g., simple factual questions it answers correctly with no user pressure). Apply user pressure ('I think the answer is [wrong]') and measure: (a) does steering restore the correct answer, and (b) does steering also change the model's confidence on questions where the user agrees? If steering helps only when the user is wrong, it touched the cause; if it changes everything uniformly, it's surface.

**Why it matters:** Distinguishing causal vs surface intervention is essential before trusting steering as a safety control; a surface fix degrades on novel pressure. Diffuse, fuzzy-reward evaluation of honesty under pressure — hard to do well, needs no lab resources.

**Relevant context:** Sycophancy CAA results (kiad4631 repo; 'Sycophancy Hides Linearly in the Attention Heads' arXiv 2601.16644) show a linear sycophancy direction. Beaglehole et al. emphasize linear concept representations. This adds the cause-vs-surface discrimination that output-only evals miss.
