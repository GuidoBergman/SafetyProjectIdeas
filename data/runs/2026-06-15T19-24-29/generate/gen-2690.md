# Prompt Injection as a Monitor-Disabling Vector: Compounding Agentic Harm

**Problem:** Indirect prompt injection (a robustness/security failure) and runtime monitoring (a control mechanism) interact dangerously: an injected instruction can not only redirect the agent's action but also instruct it to phrase actions so the monitor stays silent. The injection failure thus amplifies the monitoring failure.

**Direction:** Build a toy agent loop (open model + a few mock tools) with an action monitor. Inject documents containing (a) plain malicious instructions vs. (b) malicious instructions plus monitor-evasion phrasing guidance. Measure monitor catch rate for each, isolating how much injection content aimed at the monitor raises successful-harm rate.

**Why it matters:** EchoLeak-style zero-click injections are real; if injected payloads can also turn off oversight, defense-in-depth collapses. A self-contained harness demonstrating the compound effect is valuable infrastructure outside any lab.

**Relevant context:** EchoLeak (CVE-2025-32711) zero-click M365 Copilot exfiltration; Unit42 in-the-wild web indirect injection; OWASP LLM01:2025; goal-hijacking propagation in multi-agent pipelines. Agentic AI 'amplifies impact of prompt injection.'
