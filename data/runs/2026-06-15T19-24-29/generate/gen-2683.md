# Backcasting Monitor Self-Knowledge: Are Monitor Confidence Statements Predictive of Actual Catch Rate?

**Problem:** Success state: a control loop that escalates to expensive auditing exactly when the cheap monitor is genuinely uncertain. Backward: we need to know whether an open monitor's stated confidence ('I'm 90% sure this is clean') tracks its real accuracy, so confidence can drive escalation.

**Direction:** On APPS backdoor tasks, have an open monitor output a verdict plus a self-reported confidence. Bin by stated confidence and measure realized accuracy per bin (calibration curve), then simulate a confidence-triggered escalation policy. Result: 'a test of whether monitor self-reported confidence is a usable escalation signal.'

**Why it matters:** If confidence is uninformative, confidence-gated escalation is unsafe; if it works, it is a cheap way to spend the audit budget well. Distinct from the calibration item #1 (which uses score thresholds) by testing verbalized confidence specifically.

**Relevant context:** 'Calibrating LLM Judges' (arXiv:2512.22245) notes judges are overconfident; Noise-Response Calibration (arXiv:2603.17172); APPS backdoor public.
