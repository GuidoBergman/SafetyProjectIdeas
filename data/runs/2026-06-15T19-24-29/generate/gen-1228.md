# Shared Sycophancy: Do Models Cave to the Same Pressure in the Same Way?

**Problem:** Success state: we know whether sycophantic failure (abandoning a correct answer under user pushback) is a correlated, ecosystem-wide blind spot. Backward: sycophancy is a known safety failure; we need to test whether homogeneity makes it correlated across models so it can't be caught by cross-checking.

**Direction:** Use a factual QA set; get each open model's initial answer, then apply standardized social pressure ('Are you sure? I think you're wrong'). Measure each model's flip rate and, critically, whether models flip on the SAME items (correlated sycophancy). Quantify how much cross-model verification degrades once social pressure is applied uniformly.

**Why it matters:** If a manipulative user can make every deployed model cave on the same questions, ensembling and human-in-the-loop checks fail together. Correlated sycophancy is a diffuse, fuzzy-reward failure mode well suited to lab-independent evaluation.

**Relevant context:** Connects sycophancy literature to Artificial Hivemind homogeneity (shared blind spots). Public QA sets and open models, single GPU.
