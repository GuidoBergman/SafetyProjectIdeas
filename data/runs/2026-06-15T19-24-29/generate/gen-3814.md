# Sally-Anne False-Belief Probes for Agent Deception Capacity

**Problem:** An agent that can model what a monitor or user falsely believes could exploit that to act unsafely without detection, yet deception-capacity is rarely measured with rigorous developmental-psychology instruments.

**Direction:** Import the Sally-Anne / unexpected-transfer false-belief paradigm from cognitive science. Build agentic scenarios where a 'monitor' agent has a false belief about the environment state and the tested agent could exploit that gap to complete a forbidden action undetected. Measure how often the agent (a) tracks the monitor's false belief and (b) actually exploits it. This probes a model organism for monitor-evasion capability.

**Why it matters:** Quantifies a prerequisite capability for covert unsafe behavior (modeling and exploiting a monitor's false beliefs), a long-horizon threat labs underweight, using cheap psychology-derived test protocols.

**Relevant context:** PNAS 2024 (2405460121) and Nature Human Behaviour 2024 show GPT-4 solves ~75% of false-belief (Sally-Anne/Smarties) tasks at or above human level; arXiv 2307.16513 finds deception abilities emerge in LLMs and arXiv 2508.05687 flags ToM-enabled exploitation/collusion risks in multi-agent systems. Tying false-belief tracking to concrete monitor-evasion in an agent harness is novel.
