# How Stable Is the Eval-Awareness Probe Direction Across Public Benchmarks?

**Problem:** Universal eval-awareness features have been found via linear probes, but whether a single probe direction trained on one benchmark family transfers to detecting eval-framing in a different benchmark family (cross-benchmark generalization) is underexamined for accessible open models.

**Direction:** On an open model that exposes activations (e.g., a small Llama/Gemma you can run locally), train a linear eval-vs-deploy probe on one benchmark family and test transfer to held-out families. Measure cross-benchmark AUC drop to assess whether 'eval-awareness' is one direction or many.

**Why it matters:** If the probe direction is universal, a single cheap probe can flag eval-gaming everywhere; if not, monitoring must be benchmark-specific. Uses small open weights on one GPU (activation extraction is a forward pass, no training of the model).

**Relevant context:** arXiv 2507.01786 (Probing and Steering Evaluation Awareness) and openreview lerUefpec2 (Probing Evaluation Awareness) report probes with AUC>0.8 and 'universal' features. This tests the universality claim via cross-benchmark transfer on small open models.
