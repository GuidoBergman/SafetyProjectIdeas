# Monitor Latency x Fast Agentic Loops: Compounding Through Speed Mismatch

**Problem:** A control failure (monitor reviews actions slower than the agent acts) compounds with the capability of fast autonomous loops: by the time a monitor flags an action, the agent has executed several downstream actions, so a single detection failure cascades. Speed mismatch turns one miss into many.

**Direction:** Simulate an agent that emits actions at rate R and an asynchronous monitor with review latency L. Inject a harmful action and measure how many additional actions execute before a flag halts the loop, as a function of L/R. Quantify cascade size and the latency budget needed for containment.

**Why it matters:** Real deployments use async monitoring; the cascade dynamics determine whether monitoring can ever be a hard backstop. A simple discrete-event simulation is well within 30h and needs no model at all (or a tiny one for realism).

**Relevant context:** Runtime controls / HITL open problem (AISI); control framing where blue-team must catch actions before harm (Greenblatt et al. arXiv:2312.06942); irreversibility concern (Adversa 2025).
