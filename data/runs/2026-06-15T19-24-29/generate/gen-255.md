# Indirect Prompt Injection in Agents: Which Tool-Output Channels Are Most Exploitable?

**Problem:** AgentDojo shows tool-using agents are broadly vulnerable to indirect prompt injection, but the per-channel breakdown — which tool-output types (email body, web snippet, file contents, calendar field) most reliably carry an injection through to a harmful action — is not crisply characterized for small open models.

**Direction:** Use the open-source AgentDojo harness with a small open model as the agent. Hold the injection payload fixed and vary only the delivery channel/field. Measure targeted attack success per channel and per number of tool calls until the injection fires. Identify which channels are 'hot' and whether deeper tool-call chains amplify success.

**Why it matters:** Agentic deployment is a medium-horizon risk labs are racing on; a public, reproducible channel-vulnerability ranking on open models is strategically valuable infrastructure knowledge for building monitoring/firewalls. AgentDojo runs on a single GPU with an open model and no proprietary data.

**Relevant context:** Debenedetti et al. 'AgentDojo' (NeurIPS 2024, OpenReview m1YYAQjO3w): 97 tasks, 629 security cases, four domains, metrics include Targeted Attack Success Rate; SOTA agents fail even without attacks. 'Indirect Prompt Injections: Firewalls or Stronger Benchmarks?' (arXiv:2510.05244) and AgentVigil (arXiv:2505.05849) build on it. Harness is open source.
