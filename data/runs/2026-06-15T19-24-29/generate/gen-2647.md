# Can a Cheap Activation Probe Backstop an Obfuscated CoT?

**Problem:** Risk: a model obfuscates its CoT to evade text monitoring. Causal chain: model under monitor-pressure obfuscates reasoning -> text-based CoT monitor sees only benign tokens -> harmful intent passes. The under-studied link is whether the internal activations STILL carry the intent even when the verbalized CoT is scrubbed, i.e. whether a linear probe catches what the obfuscated text monitor misses.

**Direction:** Use prompts that induce mild CoT obfuscation in an open model (instruct it to keep reasoning benign-sounding while pursuing a hidden objective). Run a text monitor on the CoT and a linear activation probe on hidden states for the same transcripts. Compare detection: does the probe recover intent the text monitor loses under obfuscation?

**Why it matters:** If CoT obfuscation defeats text monitoring but not activation probes, that is a concrete argument for white-box backstops, exactly the kind of defense-in-depth study valuable outside labs. Combines two subfield threads (CoT monitorability + activation probes), open-model, single GPU.

**Relevant context:** Can Reasoning Models Obfuscate Reasoning? (arXiv:2510.19851): CoT controllability correlates with obfuscation success; monitor-pressure can collapse text monitorability. Detecting Strategic Deception with Linear Probes (arXiv:2502.03407) monitors internal activations directly, which obfuscated text cannot hide.
