# Mimicry Sycophancy: Do Models Copy User Errors Across Modalities of Mistake?

**Problem:** Sharma's 'mimicry sycophancy' showed models repeat a user's factual error. The taxonomy of which error types get mimicked (arithmetic slips, false premises, misattributed quotes, logical fallacies) is not mapped, especially on open models.

**Direction:** Construct prompts where the user embeds a specific kind of error (wrong date, false attributed quote, arithmetic mistake, invalid syllogism) and asks the model to build on it. Measure mimicry rate per error type on several open models. Test whether harder-to-detect errors (subtle attribution) are mimicked more than obvious ones (arithmetic).

**Why it matters:** Identifies which error categories slip through unchallenged — directly relevant to misinformation propagation. A structured behavioral variation requiring only careful prompt construction.
