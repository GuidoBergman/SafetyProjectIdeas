# InvarianceBench for Probes: Do 'Truth'/'Deception' Directions Stay Put Across Prompt Format Changes?

**Problem:** Interpretability-based safety monitors (deception/truth probes) are deployed assuming the learned direction is robust. But probes are typically validated on one prompt format. There is no benchmark measuring how much a probe's accuracy and its direction vector drift when only superficial format changes (system-prompt wording, few-shot framing, chat template) are applied.

**Direction:** Train a deception/truth probe on one prompt format, then evaluate AUROC and cosine-drift of the probe direction across several format variants of the same underlying items. Report a robustness scorecard per probe type and identify which formats break monitors. Tie failures back to whether the underlying concept moved or the probe overfit format artifacts.

**Why it matters:** Formal claims about detecting deception/anomalies via internal directions only hold if those directions are an invariant of the concept, not the prompt. Quantifying probe drift under benign format changes tests the robustness premise of interpretability-based control — a pure-analysis, open-weights contribution that frontier labs underdocument.

**Relevant context:** Grounded in deception-probe scaling/robustness work (arXiv:2605.27958 'Pressure-Testing Deception Probes'; arXiv:2604.13386 on multi-layer ensembling) and quirky-model ELK probes (arXiv:2312.01037). Logistic-regression probing + cosine similarity is beginner ML.
