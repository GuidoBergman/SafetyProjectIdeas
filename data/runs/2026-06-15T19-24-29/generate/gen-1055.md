# Replicating CAPA Error-Correlation on a Safety Benchmark Across Open Models

**Problem:** Great Models Think Alike introduced CAPA (chance-adjusted agreement) and found larger models share more errors, but their analysis centered on general capability benchmarks. Whether the same capability-vs-correlated-error trend holds specifically on safety/refusal classification is untested.

**Direction:** Take a public safety classification dataset (e.g., a harmful-vs-benign prompt set or a moderation benchmark) and run ~10 open models of varying sizes as binary classifiers. Compute CAPA on their error patterns and plot CAPA against model accuracy/size. Test whether the 'more capable, more correlated errors' relationship replicates in the safety domain.

**Why it matters:** If safety classifiers/judges share errors that grow with capability, using one model to oversee another (LLM-as-judge moderation) is fundamentally fragile. Reproduces a published method on a new domain with public models.

**Relevant context:** Great Models Think Alike / CAPA (arXiv:2502.04313, model-similarity.github.io); Correlated Errors in LLMs (arXiv:2506.07962).
