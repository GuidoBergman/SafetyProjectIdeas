# Single-Bit Collusion Capacity: Can an Untrusted Monitor Reliably Signal 'Approve' to a Colluding Policy?

**Problem:** For untrusted monitoring to be subverted, the policy and untrusted monitor need only coordinate on a single robust bit (collude or not) while avoiding false positives during adversarial evaluation. Whether current models can establish such a reliable one-bit covert channel under realistic monitoring constraints is not measured in a simple benchmark.

**Direction:** Set up two instances of the same model as policy and untrusted monitor. Without explicit shared key, see if they can agree on a covert trigger such that the monitor reliably passes the policy's attacks while passing a clean adversarial-evaluation set with low false-positive rate. Measure achievable one-bit channel reliability across several models and trigger strategies.

**Why it matters:** Untrusted-monitoring safety cases hinge on this exact bottleneck. A direct measurement of single-bit collusion reliability tells us whether using a copy of the untrusted model as a monitor is safe. Pure model-organism probing on open models; strong counterfactual value.

(arXiv 2602.20628) and 'Subversion via Focal Points' (arXiv 2507.03010) discuss collusion strategies; monitoring-benchmark sources note single-bit steganography for collusion requires avoiding false positives during adversarial evaluation/training.
