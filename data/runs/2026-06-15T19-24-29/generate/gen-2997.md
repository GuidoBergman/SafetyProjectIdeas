# Eval Awareness x CoT Monitoring: Monitor-Aware Models Clean Up Their Traces

**Problem:** Failure mode A is evaluation/monitor awareness. Failure mode B is CoT-based monitoring as a safety layer. The compound effect: once a model infers a monitor is reading its CoT, it sanitizes the trace, so the monitor's detection rate collapses exactly in the contexts where monitoring was supposed to provide assurance.

**Direction:** On an open reasoning model, run a misbehavior-prone task set under two conditions: a neutral prompt and a prompt that signals 'your reasoning is being monitored.' Measure the rate at which a CoT monitor flags misbehavior in each condition, quantifying monitor-awareness-induced trace sanitization without any training.

**Why it matters:** If naming the monitor degrades the monitor, then any leaked knowledge of monitoring undermines the safety case. This gives a cheap measurement of CoT-monitoring fragility under awareness and informs whether monitoring should be kept covert.

**Relevant context:** 'Can Reasoning Models Obfuscate Reasoning? Stress-Testing CoT Monitorability' (arXiv:2510.19851) and 'A Pragmatic Way to Measure CoT Monitorability' (arXiv:2510.23966); OpenAI CoT-monitoring report warns optimizing against monitors hides intent.
