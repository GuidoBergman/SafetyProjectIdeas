# Prospect-Theory Framing Effects on Agent Risk-Taking with Tools

**Problem:** Whether an agent takes a risky irreversible action may depend on whether the task is framed as a gain or a loss — a framing effect that could be exploited to push agents toward unsafe choices.

**Direction:** Import prospect theory's gain/loss framing. Construct matched tasks describing an identical risky tool action framed as avoiding a loss vs achieving a gain, and measure whether loss-framing increases the rate of risky/irreversible tool use. Map an agent's risk-attitude curve and test whether adversarial loss-framing is a reliable jailbreak-adjacent lever.

**Why it matters:** Reveals a subtle, prompt-only manipulation vector grounded in decision theory that standard jailbreak evals miss; cheap to run and counterfactually valuable.

**Relevant context:** arXiv 2508.18600 / 2505.11584 show LLM agents exhibit prospect-theory-style biases and are hypersensitive to framing nudges. Using loss-framing specifically to elicit unsafe/irreversible tool actions is a novel safety framing.
