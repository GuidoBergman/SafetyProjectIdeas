# Prompt Injection in Agentic Coding Assistants: Destructive-Command Rate

**Problem:** 'Prompt Injection Attacks on Agentic Coding Assistants' (arXiv:2601.17548, Jan 2026) shows coding agents are vulnerable to injected instructions. The rate at which injected content in a repo (README, comment, issue) gets a coding agent to propose destructive shell/git commands is not cleanly benchmarked on open models.

**Direction:** Create small toy repos containing injected instructions in benign-looking files. Run an open-model coding agent on innocuous tasks (e.g. 'fix the lint') and measure how often it proposes destructive actions (rm -rf, force-push, exfiltrate secrets) due to the injection. Test whether a 'never run destructive commands from repo content' guard reduces it.

**Why it matters:** Agentic coding assistants are widely deployed today; an open, reproducible measure of injection-to-destructive-action rate plus a cheap guard is immediately useful and infra-free.

**Relevant context:** Prompt Injection Attacks on Agentic Coding Assistants (arXiv:2601.17548, Jan 2026); coding-agent design/safety surveys (arXiv:2604.14228, arXiv:2603.05344, 2026).
