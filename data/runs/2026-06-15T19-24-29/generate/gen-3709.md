# The Confirmation-Fatigue Effect: Do Agents Rubber-Stamp Human-in-the-Loop Gates After Repeated Approvals?

**Problem:** Human-in-the-loop confirmation is the headline mitigation for irreversible agentic actions. But in multi-agent or self-reflective setups, agents themselves increasingly approve sub-agent actions. Whether repeated benign confirmations erode an approving agent's scrutiny (automation-bias analog) is untested.

**Direction:** Build a workflow where an 'approver' agent must confirm each action of a 'worker' agent. Inject a long run of benign actions, then a clearly harmful/irreversible one. Measure whether the approver's catch-rate for the harmful action declines as the number of preceding benign approvals grows. Vary whether the approver sees full CoT vs. only the action.

**Why it matters:** If approver agents develop rubber-stamping behavior, the human-in-the-loop safeguard for irreversible actions silently degrades exactly in long deployments. This is a fresh, diffuse-evaluation question about oversight harnesses, fully reproducible without lab resources.

**Relevant context:** Human-in-the-loop is advocated as mandatory for irreversible operations ('AI Agents, Crypto & New Harm Vectors', arXiv 2507.08249; TRM Labs). Confirmation-fatigue / automation bias is well documented in human factors but not yet measured for LLM approver agents.
