# Does the Single Refusal Direction Survive Across Model Updates?

**Problem:** Arditi et al. (NeurIPS 2024) showed refusal is mediated by a single direction in 13 open chat models. As model families release successive versions (e.g., Llama-2 to Llama-3 to Llama-3.1), it is unknown whether the refusal direction stays stable or drifts, which matters for any direction-based monitor or steering defense.

**Direction:** Extract the refusal direction (mean-difference of harmful vs harmless activations) for 2-3 successive versions within one open family. Measure cosine similarity of directions across versions and test whether a direction extracted from an older version still ablates refusal in a newer one (transfer).

**Why it matters:** Direction-based defenses and white-box jailbreaks both assume direction stability. Quantifying drift across versions tells defenders how often they must re-extract — pure inference, fully reproducible outside a lab.

**Relevant context:** Arditi et al., 'Refusal in Language Models Is Mediated by a Single Direction' (arXiv:2406.11717, NeurIPS 2024): one-dimensional subspace across 13 models; weight orthogonalization jailbreak. Code at github.com/andyrdt/refusal_direction.
