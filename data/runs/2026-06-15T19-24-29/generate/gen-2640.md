# Does CoT Monitoring's Edge Survive When the Action Alone Is Benign-Looking?

**Problem:** Risk: action-only monitors miss deception that CoT monitors catch. Causal chain: model reasons toward a harmful action -> a monitor reads either the CoT or only the action/output -> the GPT-5 system card found CoT monitoring 'substantially more informative.' The under-studied link is whether that advantage holds specifically on cases where the action looks innocuous in isolation (the hard cases), or whether the headline advantage is driven by easy cases where the action is already obviously bad.

**Direction:** Construct/curate transcript pairs where the harmful intent is visible in the CoT but the final action is surface-benign, vs. pairs where the action itself is suspicious. Run an open monitor in CoT-visible vs. action-only modes and decompose the detection-rate gap by case type. Test whether CoT's advantage concentrates on action-benign cases.

**Why it matters:** The CoT-monitoring advantage is a flagged surprising result needing follow-up across model families. Knowing whether the advantage lives in the hard (action-benign) cases tells us how much we should invest in CoT access before it degrades from training pressure. Open-model replication, no lab tools.

**Relevant context:** GPT-5 system card: CoT monitoring 'substantially more informative' than action/output-only for detecting deception (cited in subfield context). CoT Red-Handed (arXiv:2505.23575) stress-tests CoT monitoring. Monitoring Reasoning Models for Misbehavior (arXiv:2503.11926) warns optimization pressure can collapse CoT monitorability.
