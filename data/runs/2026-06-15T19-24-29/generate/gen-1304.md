# Multi-Agent Workflows Are Homogeneous: Measuring Correlated Failure in Same-Base-Model Agent Systems

**Problem:** 'Rethinking the Value of Multi-Agent Workflow' observes most agent frameworks are homogeneous (agents share one base LLM, differ only by prompts/tools). If agents in a 'check each other' workflow share blind spots, the safety promise of multi-agent oversight collapses under correlated mistakes — but this correlation hasn't been measured on safety-monitoring tasks.

**Direction:** Set up a simple multi-agent monitor (one agent acts, others review) all using the same base model, vs. a heterogeneous version mixing model families. On a set of tasks with injected errors/unsafe actions, measure whether same-base-model reviewers catch fewer injected problems (correlated blind spots) than cross-family reviewers. Report detection rate vs. agent diversity.

**Why it matters:** Scalable oversight increasingly relies on agents monitoring agents. If homogeneous agent stacks share blind spots, oversight is weaker than assumed — a core safety-tooling result, prototypable on one GPU with open models.

**Relevant context:** Extends 'Rethinking the Value of Multi-Agent Workflow: A Strong Single Agent Baseline' (arXiv:2601.12307, Jan 2026) and correlated-error findings (arXiv:2506.07962) to safety-monitoring tasks.
