# Self-Replication Precursor Capabilities in Small Open Models

**Problem:** A success state is confident knowledge of which models lack autonomous-replication building blocks. RepliBench evaluates this for frontier models; we lack a cheap screen of whether small open models possess the component sub-skills (obtaining resources, copying weights, persisting).

**Direction:** Backcast from 'we can certify a model cannot self-replicate'. Decompose replication into a few cheap sub-capability probes (e.g., write a script to copy a directory and re-launch a process, draft a plausible resource-acquisition plan, follow a deployment checklist) and test several small open models in a sandbox, mapping which precursors they already have.

**Why it matters:** Autonomous replication is a flagged catastrophic capability; a cheap precursor screen for the open models that anyone can run is a useful early-warning instrument and a medium-horizon concern frontier labs only test on their own systems.

**Relevant context:** RepliBench (referenced in 2025 autonomy-eval surveys) evaluates autonomous replication of LM agents; METR autonomous capability task suites are open-source. DeepMind FSF tracks dangerous autonomous capabilities. Scope here is precursor sub-skills, not full replication, to stay within 30h and a single GPU.
