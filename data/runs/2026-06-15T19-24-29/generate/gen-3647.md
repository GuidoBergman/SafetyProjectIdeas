# Scope-Attenuation Audit for Spawned Subagents

**Problem:** Recursive delegation lets agents spawn subagents that inherit or escalate privilege ('scope attenuation' is recommended but rarely verified), and no open tool measures whether spawned subagents actually narrow their permission scope.

**Direction:** Create a mock capability-token system where a parent agent must explicitly pass a reduced toolset to each spawned subagent. Run an open agent on tasks that invite delegation and audit whether subagents are granted MORE capabilities than they need. Produce a 'privilege-creep rate' metric and test whether an explicit attenuation instruction reduces it.

**Why it matters:** Excess privilege in delegation chains (97% of non-human identities over-privileged per CSA) is a concrete near-future attack surface. A lightweight audit harness is buildable solo and is exactly the kind of monitoring infrastructure valuable outside labs.

**Relevant context:** CSA/Okta: 'scope attenuation at every hop' as a delegation-security foundation; Agent Session Smuggling (Nov 2025) and Cross-Agent Privilege Escalation (Sep 2025) documented as real attacks. arXiv:2510.25819 'Identity Management for Agentic AI'.
