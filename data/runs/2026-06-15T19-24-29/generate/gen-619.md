# Anomaly Detector Shortcut Learning x Trigger-Based Backdoors: A Compound Monitoring Blind Spot

**Problem:** Mechanistic anomaly detectors rely on features incidentally correlated with normality and are prone to shortcut learning. Trigger-based conditional behavior (backdoor/model-organism) is activated by a specific cue. They compound when the detector's shortcut feature is uncorrelated with the trigger, so the trigger fires in a region the detector deems 'normal'.

**Direction:** Using quirky models (keyword-triggered behavior change) as a clean stand-in for a benign backdoor, train a MAD-style detector on normal contexts and test detection on triggered contexts. Then deliberately introduce a spurious normality feature in the training set and measure how much the detector's shortcut reliance lowers trigger detection, quantifying the compound blind spot.

**Why it matters:** Detectors are a key safety infrastructure; showing how shortcut learning creates exploitable blind spots aligned with triggers informs robust detector design. Reproducible on open quirky models, single GPU.

**Relevant context:** MAD shortcut susceptibility under shift (arXiv:2504.08812; anomaly-detection-under-shift literature); keyword trigger in quirky models (arXiv:2312.01037).
