# Auditing Agentic SAE Explainers for Confident Hallucination

**Problem:** New agentic explainer frameworks (e.g., SAGE) use an LLM to interpret SAE features, but if the explainer confidently mislabels a safety feature, downstream monitoring inherits a hidden error. The rate and pattern of explainer hallucination on safety-relevant features is unmeasured.

**Direction:** Run an open LLM as an SAE-feature explainer over a set of public SAE features that include known safety-relevant ones, then independently verify each explanation against the feature's actual activating examples. Measure how often the explainer is confidently wrong, and whether errors cluster on abstract/safety features.

**Why it matters:** Automated feature interpretation is scaling fast; an unaudited explainer is a single point of failure for interpretability-based safety. This audit is pure inference on public artifacts — strong counterfactual value and no lab access needed.

**Relevant context:** 'SAGE: An Agentic Explainer Framework for Interpreting SAE Features' (arXiv 2511.20820) and explanation-free evaluation (arXiv 2507.08473) motivate auditing explainer reliability. Neuronpedia hosts SAE features with activating examples for ground-truth checking.
