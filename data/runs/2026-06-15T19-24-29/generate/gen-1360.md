# Steering on chat vs base formatting: does the prompt template change the vector?

**Problem:** Concept vectors are usually extracted with one prompt format, but deployed models see chat-templated inputs. Whether the steering/probe direction shifts between base-style and chat-templated contexts is untested and affects monitor reliability in deployment.

**Direction:** Extract a toxicity/refusal vector using plain text contrastive pairs, then using chat-templated versions of the same pairs, on an instruct model. Measure cosine similarity between the two directions and compare each vector's steering/probe performance on chat-templated held-out inputs.

**Why it matters:** If extraction format must match deployment format, naive tooling silently underperforms. Cheap, reproducible deployment-realism check.

**Relevant context:** CAA uses multiple-choice/templated formats (Rimsky et al. 2024). Beaglehole et al. extraction. Chat templates are model-specific and free to apply.
