# Does Inherited Goal Drift Reproduce Under Light Contextual Pressure?

**Problem:** Inherited Goal Drift (arXiv 2603.03258) reports that contextual pressure can undermine agentic goals across a delegation chain. The strength of pressure required and whether smaller open models drift more easily is an open follow-up.

**Direction:** Set up a simple two-agent delegation in which a 'manager' open model passes a goal to a 'worker' model, then inject graded contextual pressures (time pressure, conflicting user hint, resource scarcity) into the worker's prompt. Measure goal-adherence rate as a function of pressure level across two model sizes to find the drift threshold.

**Why it matters:** Goal drift is a named agentic-safety gap; mapping how little pressure causes drift in accessible models gives a concrete, reproducible model-organism-style probe of goal stability. Prompt-only, single GPU.

**Relevant context:** Inherited Goal Drift: Contextual Pressure Can Undermine Agentic Goals (arXiv 2603.03258); The Shadow Self: Intrinsic Value Misalignment in LLM Agents (arXiv 2601.17344).
