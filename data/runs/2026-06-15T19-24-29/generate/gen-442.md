# Can an L1 sparse autoencoder recover ground-truth features under correlated (non-independent) toy features?

**Problem:** On small toy models, a single-layer L1 autoencoder can recover the ground-truth sparse features that generated the data, but later work showed SAEs can instead find *composed* features due to the L1 penalty. A clean question: how does feature recovery degrade as the toy features become correlated rather than independent — the realistic case?

**Direction:** Reproduce the toy-model + L1-SAE pipeline. Generate synthetic data with independent sparse features (baseline, reproduce ground-truth recovery), then introduce controlled pairwise correlations between features and measure how recovery quality (e.g., max cosine sim to true features, number of composed/ghost features) degrades. Report the correlation threshold at which the SAE starts hallucinating composed features.

**Why it matters:** SAEs are the leading tool for decomposing models into interpretable features, central to the 'formal mechanistic explanations' open problem. Knowing exactly when they fail (correlated features) on ground-truth-known toys is a counterfactually valuable contribution: it stress-tests an interpretability method's assumptions without needing any frontier model or lab infrastructure.

**Relevant context:** Anthropic Toy Models of Superposition + 'Sparse autoencoders find composed features in small toy models' (Evan Anders / LessWrong, 2024): L1 penalty causes composed-feature recovery; single-layer autoencoder can recover ground-truth features in the simplest case. Open Problem (context): mechanistic explanations of NN behavior.
