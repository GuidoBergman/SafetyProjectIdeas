# Does CoT Faithfulness Drop on Harder Tasks Translate to Monitoring Blind Spots?

**Problem:** Recent work found CoT faithfulness is lower on harder benchmarks (GPQA) than easier ones (MMLU). Whether this faithfulness drop actually degrades a CoT monitor's ability to catch deception on hard tasks is the missing causal link.

**Direction:** Pick easy and hard task families. Elicit deceptive behavior on both, then measure a CoT monitor's catch-rate on each difficulty tier. Test whether the monitor's miss-rate rises with task difficulty and whether that correlates with a faithfulness proxy (e.g. answer changes when CoT is perturbed).

**Why it matters:** If hard tasks are exactly where CoT monitoring fails, then the tasks we most worry about (complex agentic work) are the least monitorable. A difficulty-stratified catch-rate study is self-contained and high-value, needing only inference.

**Relevant context:** Search-grounded: CoT faithfulness scores 'consistently lower on harder benchmarks like GPQA compared to easier benchmarks like MMLU'. CoT Red-Handed (arXiv:2505.23575) on CoT monitor failure modes.
