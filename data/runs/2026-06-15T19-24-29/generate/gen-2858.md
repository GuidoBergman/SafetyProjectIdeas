# Over-Refusal Drift Tracker: Do Safety Patches Cause Collateral Refusals?

**Problem:** Over-refusal benchmarks (XSTest, OR-Bench) measure a snapshot, but there is no simple tool to track how over-refusal changes across model versions or after a defensive system prompt is added, even though excessive refusal is a measurable safety/usability cost.

**Direction:** Run XSTest/OR-Bench-style benign-but-trigger-word prompts against an open base model and the same model with various defensive system prompts (and across two model versions). Measure over-refusal rate deltas and identify which defensive prompts most increase collateral refusals. Build a small reusable diff tool.

**Why it matters:** Quantifies the safety/helpfulness tradeoff introduced by common defenses, giving deployers an evidence base. Entirely runnable on accessible models with no training.

**Relevant context:** XSTest builds contrastive safe/unsafe prompt pairs to measure exaggerated safety; OR-Bench has 80,000 safe prompts that may be wrongly rejected (OpenReview obYVdcMMIT). 'Beyond Over-Refusal' scenario diagnostics (arXiv:2510.08158). FalseReject and PHTest show over-refusal is 'common and costly.'
