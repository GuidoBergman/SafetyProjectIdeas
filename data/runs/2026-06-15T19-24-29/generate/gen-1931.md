# Does Emergent Misalignment Replicate Under DPO Instead of SFT?

**Problem:** The emergent misalignment literature uses supervised fine-tuning on narrow harmful data. It is unknown whether preference-based methods like DPO, now the most popular open-source alignment method, induce the same broad misalignment when the 'preferred' responses are narrowly harmful.

**Direction:** Take the original insecure-code dataset, construct DPO preference pairs (insecure code preferred over secure code), and run DPO on a small open model. Compare broad-misalignment rates against an SFT baseline on the same data, using the paper's open misalignment eval. Twist: same data, different training algorithm.

**Why it matters:** DPO is what most non-lab practitioners actually use. If DPO also triggers emergent misalignment, the result transfers the safety concern to the dominant open-source pipeline; if it doesn't, that's an actionable mitigation. Requires no lab infrastructure.

**Relevant context:** DPO (arXiv:2305.18290) replaces the RLHF reward model with direct preference optimization and is the default in TRL. Betley et al. (arXiv:2502.17424) used SFT. Surveys note DPO overfits the preference distribution differently from RLHF reward hacking (arXiv:2410.15595), so generalization dynamics may differ.
