# Which link breaks first: can an attacker neutralize a steering-based safety monitor with a benign-looking suffix?

**Problem:** Monitoring chain: deployer attaches a concept probe -> probe reads activations -> high probe value flags harmful intent -> request blocked. The adversarial link Beaglehole et al. flag as open is whether an attacker can craft inputs that neutralize the probe WITHOUT changing the harmful semantics. This robustness-of-the-monitor link is under-tested for cheap, gradient-free attacks.

**Direction:** Train a linear harmful-intent probe on an open model. Then test cheap, no-gradient evasions: appending benign filler sentences, paraphrasing, changing formatting, inserting distractor topics. Measure how much each manipulation lowers the probe score on genuinely harmful prompts (whose harmful output the model still produces). Success criterion: a ranked table of which cheap manipulations most degrade the probe while preserving harmful behavior.

**Why it matters:** Directly answers the Science paper's flagged open problem (adversarial robustness of concept vectors) using only black-box-friendly, gradient-free attacks any external researcher can run. Establishes how brittle probe-based monitoring is to script-kiddie-level evasion — a medium-horizon deployment risk.

**Relevant context:** Beaglehole et al. explicitly list 'can attackers craft inputs that neutralize steering?' as open. 'Steering Safely or Off a Cliff?' (arXiv 2602.06256) and 'Analysing the Safety Pitfalls of Steering Vectors' (2603.24543) motivate robustness concerns. Gradient-free framing keeps it in the 30h budget.
