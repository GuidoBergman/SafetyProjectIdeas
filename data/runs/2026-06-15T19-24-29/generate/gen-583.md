# Backcasting a Shutdown-Corrigibility Guarantee: An Empirical Test of Whether Discounting Buys Corrigibility in Toy MDPs

**Problem:** Success state: we can certify an agent will not resist shutdown. Theory says shutdown-avoidance is convergently instrumental for far-sighted agents. A proposed lever is the discount factor: myopic agents resist less. The gap is an empirical curve of shutdown-resistance vs. discount in concrete MDPs, plus which environment structures break the relationship.

**Direction:** Build gridworlds with an explicit shutdown state and a button the agent could disable. Compute optimal policies across discount factors via value iteration. Measure resistance (fraction of reward functions whose optimal policy disables shutdown) as a function of discount and environment topology. Pure Python, no GPU.

**Why it matters:** Working backward from a corrigibility certificate, we need to know exactly how myopia trades off against task performance and where it fails. A measured discount-vs-resistance phase diagram makes the power-seeking theorem actionable for designing corrigible environments — fully reproducible on a laptop.

**Relevant context:** Turner et al. (arXiv:1912.01683): shutdown-avoidance convergently instrumental; far-sightedness concentrates perceived power. Connects to MIRI corrigibility and off-switch-game work.
