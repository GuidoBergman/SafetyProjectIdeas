# Backcasting from 'Policy Text Is Machine-Auditable': Extracting Obligations from the EU GPAI Code into a Checklist

**Problem:** A success state where compliance with the EU GPAI Code of Practice can be tracked at scale requires its 12 commitments to be parsed into discrete, testable obligations. Today they live in prose, making automated compliance-tracking impossible.

**Direction:** Take the public final text of the EU GPAI Code of Practice (Transparency, Copyright, Safety & Security chapters), and build a structured extraction: every obligation as a row with (actor, action, condition, evidence-required, binding-strength). Do this manually plus an LLM extraction with a fixed schema, then cross-validate. Produce a machine-readable compliance checklist and analyze how many obligations have objectively checkable evidence.

**Why it matters:** Backcasting from 'scalable compliance tracking' shows structured obligation-extraction as the precondition. A clean checklist reveals which Code commitments are auditable vs aspirational, directly addressing the EU AI Office's voluntary-to-enforceable gap. Pure public-text NLP — no lab resources, strong outsider value.
