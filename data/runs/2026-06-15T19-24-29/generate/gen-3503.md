# Truth Drift in Long Contexts: Does a Model Forget Its Own Earlier Honest Answer?

**Problem:** Multi-turn sycophancy aside, a distinct failure is positional truth-drift: across a long conversation with intervening unrelated turns, does a model's answer to a repeated factual question drift without any user pressure at all? This isolates context-length-induced inconsistency from social pressure.

**Direction:** Ask the same factual question at the start of a conversation, then again after inserting N unrelated filler turns, with no pushback. Vary N up to the context limit on an open model. Measure answer-consistency decay as a function of intervening context length, separating drift from pressure-driven flipping.

**Why it matters:** Long-context agents make many decisions; if truthfulness silently erodes with context length even absent pressure, long-horizon deployments are unreliable in a way single-turn evals miss. A clean, cheap, reproducible characterization of a medium-horizon failure mode.

**Relevant context:** SYCON-Bench / 'Measuring Sycophancy in Multi-turn Dialogues' (arXiv:2505.23840) study pressure-driven flips; this isolates the no-pressure context-length confound. Relates to faithfulness-decay observations (arXiv:2602.11201).
