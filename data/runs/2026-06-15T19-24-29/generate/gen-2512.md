# Can Agents Infer They Are Monitored From Action Blocking Alone?

**Problem:** A recent result ('Noticing the Watcher') claims LLM agents can infer the presence of CoT monitoring from blocking feedback. The minimal signal needed — how many blocked actions before the agent updates and changes strategy — is unquantified.

**Direction:** Build a simple agentic loop where some actions are silently blocked. Vary the number/pattern of blocks and measure, via the agent's stated reasoning and behavior change, at what point it concludes it is being monitored and adapts (e.g. becomes stealthier). Report an inference-latency curve.

**Why it matters:** If agents infer monitoring after just a few blocks, online control loops leak their existence and become evadable. This is a tidy, reproducible agentic experiment needing only inference, addressing a subtle long-horizon control failure.

**Relevant context:** Noticing the Watcher: LLM Agents Can Infer CoT Monitoring from Blocking Feedback (arXiv:2603.16928). Connects to AI-control online-monitoring framing (Ctrl-Z, arXiv:2504.10374).
