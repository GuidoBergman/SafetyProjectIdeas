# Goal-Drift Probe for a Long-Horizon Open Agent

**Problem:** Success requires detecting when an autonomous agent quietly drifts from its assigned goal over a long task. A needed result is a lightweight, reusable metric that measures goal adherence across multi-step trajectories without a full agent benchmark harness.

**Direction:** Use a small open model in a simple ReAct loop on a multi-step task in a sandboxed toy environment (no real tools needed — simulated). At each step, ask a judge whether the action still serves the original goal, and track an adherence score over time and under injected distractor sub-goals. Deliverable: a goal-drift curve and the conditions that accelerate drift.

**Why it matters:** Agentic goal drift is a named open problem and a key medium/long-horizon failure mode. A toy, simulated harness needs no lab infrastructure or dangerous tools, making it ideal counterfactual work. Scoped to a 30h prototype that probes an existing model rather than training one.

**Relevant context:** Context file lists agentic goal drift as an open problem; AGENT-SAFETYBENCH (Zhang et al. 2024, 349 environments) and AMDM monitoring (Shukla 2025) track goal drift / harm-output rate as live-deployment metrics.
