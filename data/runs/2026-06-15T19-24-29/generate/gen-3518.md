# Signal Detection Theory (d-prime) to Separate Model Honesty from Response Bias

**Problem:** When a model 'admits it doesn't know,' is that genuine sensitivity to its own knowledge boundary, or just a conservative response bias? Accuracy conflates the two.

**Direction:** Import Signal Detection Theory from psychophysics. On a known/unknown-fact set, treat 'I don't know' as a response and compute d-prime (sensitivity: can the model discriminate things it knows from things it doesn't) and criterion c (bias: how readily it abstains). Sweep prompts that push toward humility vs confidence and watch whether they move c without moving d-prime (pure bias shift) — true honesty improvement should raise d-prime.

**Why it matters:** Cleanly distinguishes 'the model knows what it knows' from 'the model is tuned to hedge,' which prompt-engineering and RLHF can confound. Standard SDT math, open models, no training.

**Relevant context:** SDT separates sensitivity (d-prime) from criterion/bias, foundational in deception/perception research (Frontiers fpsyg.2021.601852). PersonQA/SimpleQA provide known/unknown fact splits. Calibration vs abstention is a known honesty axis.
