# Does Boosting Situational Awareness Increase Lying? An Open-Model Stress Test

**Problem:** Anthropic found that eliciting an honest persona decreases lying, but boosting situational awareness (explaining the model's situation more fully) INCREASES it. This persona/awareness trade-off is a surprising lever pair that hasn't been mapped on accessible models.

**Direction:** On an open model in a simple deception-incentive scenario (model has a reason to misreport), run a 2x2 design: {honest persona on/off} x {situational-awareness framing high/low}. Measure lie rate in each cell to test whether the trade-off direction reported by Anthropic reproduces and whether the two factors interact.

**Why it matters:** Maps which framing knobs make honesty elicitation safer vs riskier — guidance any alignment auditor can use without lab resources. The interaction is a clean, scoped follow-up to a counterintuitive published result.

**Relevant context:** Anthropic alignment-faking-mitigations (alignment.anthropic.com/2025/alignment-faking-mitigations): honest persona decreases lying, more situational awareness increases it; framing prior conversation as another AI's transcript improves alignment-faking detection.
