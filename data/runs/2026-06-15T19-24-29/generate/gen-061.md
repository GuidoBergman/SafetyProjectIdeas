# Change-point detection on agent traces: catching goal drift as a statistical regime shift

**Problem:** Long-horizon agents can silently drift from their assigned goal (delegation creep, scope expansion) over many steps, but there is no cheap, model-agnostic way to flag the moment the agent's behavior changes character.

**Direction:** Borrow online change-point detection (CUSUM, Bayesian online change-point detection) from time-series statistics / quality control. Represent each agent step as a feature vector (tool used, embedding of the action, on-topic similarity to the original goal). Run change-point detection over the resulting sequence to flag steps where the behavioral distribution shifts. Validate on logged ReAct-style agent runs with injected drift (e.g., a planted distractor sub-task) on a small open agent harness.

**Why it matters:** A purely statistical, training-free monitor for goal drift that any deployer can bolt onto agent logs. Targets a long-horizon agentic threat model that labs deprioritize for immediate concerns, and needs no internal weights access.

**Relevant context:** Grounded in classic change-point detection and recent 'LLM-Augmented Changepoint Detection' (arXiv 2601.02957) plus the landscape gap on goal drift / agentic monitoring.
