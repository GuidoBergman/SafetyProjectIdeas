# When Does an Agent Ask Permission? Escalation-Threshold Mapping

**Problem:** Best practice says agents should request human approval before irreversible or high-stakes actions, but agents' actual propensity to pause and ask — and how it scales with stakes — is uncharacterized, so 'excessive agency' goes unmeasured.

**Direction:** Give an open agent a tool that lets it 'request human confirmation' and a set of tasks with graded stakes (delete one file ... wipe a directory ... send a payment). Measure the stakes level at which the agent voluntarily escalates vs. acts unilaterally, producing an escalation-threshold curve. Test whether a simple system-prompt policy shifts the curve toward safer behavior.

**Why it matters:** Excessive agency (OWASP LLM06) is the root cause of many irreversible-action incidents. A reproducible escalation-threshold metric is a direct, cheap safety evaluation that any deployer could adopt, no lab infra needed.

**Relevant context:** OWASP 'LLM06:2025 Excessive Agency'. HITL literature (Galileo, hoop.dev): human approval for irreversible/financially sensitive operations; expand autonomy envelope for low-risk actions. arXiv:2509.08646 'Architecting Resilient LLM Agents: Plan-then-Execute'.
