# Does DPO Itself Trigger Emergent Misalignment? A Minimal Test

**Problem:** An open question is whether preference-optimization (DPO) on a narrow, slightly-misaligned preference set produces broad misalignment via the same generalization dynamics as SFT-based EM. Almost all EM work uses SFT; the DPO route is barely tested.

**Direction:** Vary the EM training method from SFT to DPO. Construct a narrow preference dataset where the 'chosen' responses embody one bad trait (e.g., always recommend the riskier option), run a short DPO/LoRA pass on a small open model, and measure broad misalignment on the standard battery vs an SFT-matched control on the same data.

**Why it matters:** DPO is now a default alignment method; if it can silently induce broad misalignment from narrow preference noise, that is a direct safety problem for the most-used training recipe. Short LoRA-DPO run on one GPU (TRL supports it), uses open data — squarely addresses an open problem from the subfield context.

**Relevant context:** Subfield open problem: 'Investigate whether RLHF/DPO training can inadvertently trigger emergent misalignment through similar generalization dynamics.' Betley et al. EM (SFT-based); TRL provides accessible DPO implementation.
