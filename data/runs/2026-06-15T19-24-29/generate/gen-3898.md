# Async Timing x Irreversibility: Compounding a Race Window Into an Unrecoverable Action

**Problem:** Failure mode A: asynchronous control — the monitor lags behind a fast-acting agent. Failure mode B: irreversible actions. The compound risk is a timing race where the agent completes an irreversible action inside the monitor's reaction window, so detection arrives too late to matter.

**Direction:** Build a simulated agent loop with a configurable monitor latency and a mock irreversible tool. Measure the fraction of harmful episodes that complete the irreversible action before the (delayed) monitor would halt them, as a function of latency. Produce a latency-vs-unrecoverable-loss curve and a recommended max safe latency.

**Why it matters:** Quantifies a control-protocol design parameter that the Async Control line raises but rarely measures against irreversibility. Pure simulation, no GPU even needed; strong infrastructure value.
