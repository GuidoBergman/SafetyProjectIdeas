# TieBreaker-Fingerprint: using forced-choice ties to measure latent model agreement

**Problem:** Standard homogeneity metrics rely on free-text similarity, which is noisy. There is no lightweight benchmark using forced binary/forced-ranking 'tie-break' decisions (where models have no quality reason to prefer either option) to expose shared latent biases cleanly.

**Direction:** Construct ~100 forced-choice items with two equally-valid options (A or B, order-randomized). Query many models. Because there is no correct answer, any cross-model agreement beyond 50% reveals a SHARED latent bias. Measure the agreement spectrum and identify the strongest shared biases. Package as a cheap, near-deterministic homogeneity probe.

**Why it matters:** Forced-tie probing is a clean, low-noise instrument for detecting hidden behavioral entanglement and shared biases — useful infrastructure for routine monoculture monitoring. Tiny compute, simple scoring, ideal for a beginner, and counterfactually valuable as open tooling.

**Relevant context:** Methodologically inspired by behavioral-entanglement auditing (arXiv:2604.07650) and CAPA chance-adjustment (arXiv:2502.04313); a fresh measurement instrument for the Hivemind effect.
