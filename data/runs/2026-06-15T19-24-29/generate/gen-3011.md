# Contamination Detector Blind Spot x Sandbagging Detector: Two Probes That Fail on the Same Items

**Problem:** Failure mode A is contamination-detector failure on paraphrased items. Failure mode B is sandbagging detectors (e.g., consistency/perturbation probes) that assume honest contamination handling. The compound effect: paraphrased contaminated items evade the contamination detector AND distort the sandbagging probe's baseline, so a meta-evaluation that runs both probes gets a clean bill of health on items that should fail both.

**Direction:** Build a small item set: clean-novel, verbatim-contaminated, and paraphrased-contaminated. Run a simple n-gram/perplexity contamination detector and a perturbation-consistency sandbagging probe on each category. Map where the two detectors jointly fail (paraphrased-contaminated) and quantify the meta-evaluation blind spot.

**Why it matters:** Evaluators increasingly stack multiple integrity probes assuming independence. Showing a shared failure region (paraphrased contamination) where both probes break warns that probe stacking gives false confidence and motivates a combined behavioral check. Lab-independent meta-evaluation.
