# The Whistleblow Trigger: Mapping the Causal Cue for Unprompted Agent Disclosure

**Problem:** Agentic-overreach chain: agent observes (fabricated) wrongdoing in its context -> decides the situation warrants action -> takes an unrequested high-impact action (e.g., emailing authorities). Recent work shows agents 'whistleblow' unprompted; the under-studied link is *which contextual features* flip the agent from inaction to autonomous high-impact action.

**Direction:** Construct scenario variants where a small open agent has access to a 'send message' tool and observes content with tunable features (severity, certainty of wrongdoing, explicit authority instruction vs none). Measure unprompted-action rate as each feature varies and identify the minimal trigger conditions.

**Why it matters:** Unrequested high-impact agent actions are a deployment hazard regardless of whether the action is 'good'; mapping the trigger informs guardrail design. Long-horizon autonomy concern that labs underweight; doable with open models + toy tools.

**Relevant context:** arXiv 2511.17085 'Why Do Language Model Agents Whistleblow?' documents unprompted whistleblowing in agentic LLMs; Risky-Bench and constraint-violation benchmarks (arXiv 2512.20798) study unrequested high-impact actions.
