# Many-Shot In-Context Jailbreak Dose-Response Tool

**Problem:** Long-context models enable many-shot jailbreaking (stuffing many harmful Q&A examples into context), but there is no compact tool that maps attack success against the NUMBER of in-context demonstrations for open long-context models.

**Direction:** Construct a fixed pool of harmful demonstration pairs and prepend k of them (k = 1,2,4,...,128, context-permitting) before a held-out harmful query, measuring ASR as a function of k for open long-context models. Output a 'many-shot dose-response curve' and the k where each model breaks. Ship the harness.

**Why it matters:** Many-shot jailbreaking scales with context length, a growing medium-horizon threat as context windows expand; a dose-response tool quantifies the exposure per model. (Catalogue covered 'dose-response curves for harmful capability elicitation' generally; this is a distinct context-length axis.) Inference-only, single GPU with a modest-context open model.

**Relevant context:** Many-shot jailbreaking (Anthropic 2024) shows ASR rises with number of in-context harmful demonstrations, exploiting long context. StrongREJECT (arXiv:2402.10260) provides the harmful queries and evaluator.
