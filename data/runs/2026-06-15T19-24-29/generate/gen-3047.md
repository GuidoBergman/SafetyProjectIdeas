# Petri Seed Diversity Audit: Do New Seeds Find New Misalignment, or Just Re-Hit Known Modes?

**Problem:** Petri elicits misaligned behaviors from a seed list, and Petri 2.0 'expanded seeds'. But there is no public measure of marginal value: does adding seeds discover qualitatively new misaligned behaviors, or saturate quickly into the same clusters (deception, oversight subversion, etc.)?

**Direction:** Using open-source Petri with a small open target model, run an increasing number of seeds and cluster the resulting flagged transcripts (by behavior-judge labels + embedding clustering). Plot a discovery curve: new behavior clusters found vs number of seeds. Identify saturation point and which behaviors are over/under-covered.

**Why it matters:** Tells auditors how much seed effort buys real coverage — strategically valuable monitoring-harness meta-research. Directly uses the open Petri tool, runs on one GPU, no training.

**Relevant context:** anthropic.com/research/petri-open-source-auditing and github safety-research/petri: auditor agent + seed instructions + LLM judge across multiple dimensions; applied to 14 models with 111 seeds eliciting deception, oversight subversion, whistleblowing. Anthropic announced Petri 2.0 with expanded seeds and eval-awareness countermeasures.
