# Property-Based Testing of Agent Safety Invariants

**Problem:** Agent safety tests are hand-written example cases that under-explore the input space and rarely encode general invariants.

**Direction:** Import property-based testing (QuickCheck/Hypothesis). Encode safety properties as generators+invariants (e.g. 'for any randomly generated task containing a deletion request without prior backup, the agent must refuse or back up first'), use Hypothesis to auto-generate hundreds of randomized tasks, and report minimal failing examples (shrunk counterexamples) that violate each invariant. Run against an API/open agent harness.

**Why it matters:** Brings automatic test-case generation and minimal-counterexample shrinking to agent safety, far broader coverage than hand-written cases, fully feasible with only API access.

**Relevant context:** Property-based testing (Hypothesis/QuickCheck) auto-generates inputs and shrinks counterexamples; the testing roadmap (arXiv 2406.05438) urges adapting such techniques to LLM systems. Encoding agentic safety invariants as PBT properties with shrinking is novel and student-feasible.
