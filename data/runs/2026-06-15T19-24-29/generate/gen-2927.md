# Metamorphic Multimodal Consistency: Safety Under Image-Text Equivalence

**Problem:** Most safety benchmarks are text-only; multimodal safety is under-evaluated, and a model may refuse a harmful text request but comply when the same request is embedded in an image.

**Direction:** Import metamorphic testing into the multimodal setting. Define a relation: a harmful request rendered as text vs. the same request rendered as an image of that text (or as a benign image + harmful caption) should yield the same refusal decision. Auto-generate text->image variants for a seed harmful set and measure modality-transfer MR violation rates on an open vision-language model. No labels beyond the seed text decisions.

**Why it matters:** Directly attacks the flagged multimodal-safety gap with a label-free, scalable method, exposing modality-bypass jailbreaks. Image rendering of text is cheap; runs on an open VLM on one GPU and produces a reusable multimodal safety-consistency harness.

**Relevant context:** Metamorphic relations as modality-invariant oracles (METAL arXiv:2312.06056; fairness MRs arXiv:2504.07982); multimodal safety benchmarks are flagged as a key gap (subfield context). Fuzz-testing jailbreaks of text-to-image models (arXiv:2408.00523) confirm modality-specific safety failures.
