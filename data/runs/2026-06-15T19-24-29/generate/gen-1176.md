# Functional-Redundancy vs Response-Diversity: An Ecosystem-Function Lens on Safe Failure

**Problem:** Ecology distinguishes redundancy (many species doing the same job, buffering loss) from diversity (different jobs). For AI safety, the question is whether model variety provides functional redundancy (independent error-catching) or merely cosmetic response variation that collapses under stress — the ecology framework separates these but it's never applied.

**Direction:** Adapt the ecology 'response diversity vs functional redundancy' framework. On safety tasks, separate surface variation (different wording) from functional variation (different decisions/error patterns) across a model panel using a 2-level decomposition, and show how much apparent diversity is merely stylistic with no functional safety benefit.

**Why it matters:** Warns against false comfort from superficial output variety; tells practitioners whether model diversity actually buffers correlated failures. Conceptually crisp, fully lab-independent, and a strong blog-post narrative.

**Relevant context:** Response diversity / functional redundancy / ecosystem resilience framework from ecology. Hill numbers for partitioning (Roswell 2021). Artificial Hivemind (arXiv:2510.22954).
