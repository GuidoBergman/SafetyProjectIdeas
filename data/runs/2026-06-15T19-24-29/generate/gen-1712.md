# Dead and Ultra-Low-Frequency SAE Features: Wasted Capacity, Hidden Gaps

**Problem:** As SAE width grows, the number of dead features (never or almost never firing) rises sharply. Dead and ultra-rare features waste dictionary capacity and indicate the SAE is not actually using its claimed feature count, but users rarely audit how much of a public SAE is effectively dead.

**Direction:** For several public SAEs of differing widths on the same open model, measure over a large text sample the fraction of features that never fire and the fraction firing below a tiny frequency threshold. Plot dead-feature fraction vs width and estimate the 'effective dictionary size'. Spot-check whether any safety-relevant labeled features are effectively dead in practice.

**Why it matters:** If a third of an SAE's features are dead, statements about its coverage and concept count are inflated, and capacity meant for rare safety-relevant concepts is being wasted. A simple capacity audit gives practitioners an honest effective size before they rely on an SAE.

**Relevant context:** Reconstruction/dead-feature literature notes dead features rise with width and that p-anneal SAEs anneal penalties to avoid early dead features; the SAE survey discusses capacity waste from splitting and absorption.
