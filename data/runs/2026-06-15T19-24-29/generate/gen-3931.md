# Prompt-Attack Propagation Distance in a Small Agent Network

**Problem:** 'Agents Under Siege' (arXiv:2504.00218) optimizes adversarial prompt propagation through multi-agent messaging under bandwidth/latency limits. The simpler question - how many hops a non-optimized malicious message survives as a function of network topology - has not been mapped for hobbyist-scale open agent networks.

**Direction:** Build a small network (chain, star, fully-connected) of open-model agents that relay summaries. Inject a malicious instruction at one node and measure how many hops it survives and how topology affects propagation, with and without a simple per-hop 'sanitize relayed instructions' step.

**Why it matters:** Understanding how attacks diffuse through agent networks is a governance problem labs underinvest in; a clean topology-vs-propagation study with a cheap sanitization defense is high counterfactual value.

**Relevant context:** Agents Under Siege: Breaking Pragmatic Multi-Agent LLM Systems with Optimized Prompt Attacks (arXiv:2504.00218); BlindGuard (arXiv:2508.08127) on propagation through inter-agent messages.
