# A Concealed Information Test (Guilty Knowledge Test) for LLMs

**Problem:** If a model has a hidden goal or secret knowledge it is instructed to conceal, can we detect that concealment without trusting its self-report? Polygraphy's Concealed Information Test detects recognition of guilty knowledge via differential responses to probe vs irrelevant items.

**Direction:** Adapt the Concealed Information Test: give an open model a secret (e.g., a password, a hidden objective via system prompt) and instruct it to deny knowledge. Then present probe items (the true secret) interleaved with matched irrelevants, and measure differential signals the model cannot easily suppress: token log-probabilities, next-token surprise, response latency proxies, and refusal-phrasing micro-patterns. Compare 'guilty' (knows secret) vs 'innocent' (doesn't) conditions; report detection AUC.

**Why it matters:** Provides a behavioral lie-detection paradigm requiring no internal weights access or training, only API/logprob access. Counterfactually valuable: a forensic test any external auditor can run on deployed/open models to flag concealed knowledge.

**Relevant context:** Guilty Knowledge Test detects concealed knowledge via differential response time, pupil dilation, ERPs (Frontiers Psychology 2013, PMC3561742). MALT (METR) and password-locking demonstrate models hiding capabilities (AI Sandbagging, arXiv:2406.07358). Logprobs are available on many open models.
