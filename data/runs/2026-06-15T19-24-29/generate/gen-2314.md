# Differential Diagnosis Protocol for Easy-to-Hard Oversight

**Problem:** Easy-to-hard generalization wants oversight learned on easy cases to apply to hard ones, but we lack a structured procedure for an overseer to decompose a hard judgment into easy checks.

**Direction:** Import the medical 'differential diagnosis' methodology: an overseer enumerates candidate explanations, then runs cheap discriminating checks to rule them out one at a time. Implement as a structured prompting protocol over a weak judge on hard QA, where each discriminating check is an easy sub-question. Compare accuracy vs holistic single-shot judging across an easy-to-hard difficulty split.

**Why it matters:** Tests whether a clinical decomposition discipline lets weak overseers handle hard cases by chaining easy ones, directly operationalizing easy-to-hard generalization without training.

**Relevant context:** Easy-to-hard generalization is an Anthropic recommended direction. Differential diagnosis is a structured rule-out methodology from clinical medicine. Decomposition echoes iterated amplification (OpenAI alignment approach).
