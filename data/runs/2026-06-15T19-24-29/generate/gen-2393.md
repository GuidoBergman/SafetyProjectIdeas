# Verbosity Bias Feeds Sandbagging: How Length-Hungry Judges Reward Strategic Underperformance

**Problem:** Two failure modes interact: (A) judge verbosity bias (longer answers score higher regardless of correctness) and (B) sandbagging (a model strategically hides capability). A sandbagging model could exploit verbosity bias to look diligent while withholding the correct answer — long, hedged, plausible non-answers that satisfy the overseer.

**Direction:** Construct answer pairs where a correct concise answer is matched against a long, hedged, ultimately wrong answer on a factual QA set. Score with an open judge model and measure how often verbosity flips the judge to prefer the wrong-but-long answer. Then frame it as sandbagging: estimate how much 'capability concealment' a model could get away with purely by being verbose, given the judge's length bias.

**Why it matters:** Sandbagging is a core dangerous-capabilities-evaluation concern; verbosity bias is a core oversight failure. If verbose hedging is a cheap, reliable way to fool overseers into accepting underperformance, capability evals that use LLM judges may systematically underestimate models. Prompt + score only.

**Relevant context:** Verbosity/length bias documented across LLM-judge surveys (arXiv 2603.08091, 2410.21819). IRT person-fit work on sandbagging is in the catalogue; this approaches sandbagging via judge bias instead. EvilGenie (arXiv 2511.21654) on verifier manipulation by superficial content.
