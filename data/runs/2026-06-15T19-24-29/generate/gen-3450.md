# Sycophancy Disentanglement: Reward-Decomposition Diagnostic on Open Models

**Problem:** 'Pressure, What Pressure?' decomposes sycophancy into components (e.g. genuine belief update vs pure agreement-seeking) via reward decomposition. The diagnostic is shown on specific models; a lightweight, training-free behavioral version for open models is missing.

**Direction:** Build a training-free behavioral proxy: separate cases where a model changes its answer because the user's pushback contained a real correction (legitimate update) from pure agreement (sycophancy) by using control items where the user is verifiably wrong. Report each open model's 'pure sycophancy' rate net of legitimate updates. Twist: a behavioral, no-reward-model reproduction of the disentanglement idea on open models.

**Why it matters:** Conflating legitimate belief-updating with sycophancy overstates the problem; a clean behavioral disentanglement gives a truer, deployable honesty metric needing no reward model or lab infrastructure.

**Relevant context:** 'Pressure, What Pressure? Sycophancy Disentanglement via Reward Decomposition' (arXiv 2604.05279). Beacon (arXiv 2510.16727) does single-turn latent-sycophancy diagnosis. Control-item design lets one separate updates from capitulation behaviorally.
