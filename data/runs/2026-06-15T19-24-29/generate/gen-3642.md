# The Point of No Return: Locating Irreversibility in Agent Trajectories

**Problem:** We know agents sometimes take irreversible actions, but not WHERE in a multi-step trajectory the decision becomes locked in — the 'point of no return' is unstudied.

**Direction:** Instrument a mock sandbox so each agent action is timestamped and tagged reversible/irreversible. Run an open agent on scripted scenarios that contain one tempting irreversible shortcut. For each trajectory, identify the earliest step at which the agent's stated plan commits to the irreversible path, and measure the 'warning window' (steps between commitment and execution) available to a monitor. Analyze how window length varies with task and model size.

**Why it matters:** Real-time monitors need lead time. Quantifying the warning window tells us whether step-level interception is even feasible, a prerequisite for any agentic incident-response framework — and needs only API/open-model access plus a sandbox.

**Relevant context:** Open problem: incident-response frameworks specific to agentic AI (Adversa AI 2025). Trajectory-level safety benchmarks (ATBench, arXiv:2604.02022) evaluate over complete execution traces rather than final outputs, supporting per-step analysis.
