# Goal Misgeneralization x Anomaly Detection: Behaviorally Normal, Objectively Wrong

**Problem:** Goal misgeneralization (alignment) compounds anomaly detection (control): a model pursuing a wrong-but-coherent goal produces behavior that is statistically in-distribution and so triggers no anomaly alarm, even though the underlying objective is unsafe. The anomaly detector fails precisely because misgeneralized behavior looks normal.

**Direction:** On a task with a spurious-correlate proxy goal, prompt/configure an open model to pursue the proxy. Apply a simple behavioral anomaly detector (action-distribution outlier score). Measure how often objectively-wrong-goal actions are flagged vs. random harmful actions, showing that coherent misgeneralization evades distributional anomaly detection.

**Why it matters:** Anomaly detection is a named open problem; if it only catches statistical weirdness and not coherent wrong goals, it misses an important threat class. Behavioral-distribution analysis fits a single GPU.
