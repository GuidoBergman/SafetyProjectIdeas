# Does Decoding Temperature Modulate Sandbagging Detectability?

**Problem:** Covert-sandbagging studies fix decoding parameters, but whether sampling temperature changes how detectable sandbagging is (e.g. higher temperature leaking the true capability through occasional correct answers) is an untested, practical follow-up.

**Direction:** Have an open model sandbag on a capability set, sampling N answers per item across temperatures (0, 0.7, 1.0). Measure pass@k for the suppressed-but-correct answer at each temperature. If higher temperature recovers true capability, evaluators can detect sandbagging cheaply by resampling.

**Why it matters:** Gives outside evaluators a trivially deployable sandbagging probe (just resample hotter) and clarifies whether sandbagging is robust to decoding — an actionable result for the concealed-capability open problem. Inference-only.

**Relevant context:** LLMs Can Covertly Sandbag Against CoT Monitoring (arXiv 2508.00943); subfield note that safety/capability can vary across decoding parameters.
