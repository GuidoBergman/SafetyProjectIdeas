# A Debate-Hacking Taxonomy Classifier as Oversight Monitoring Infrastructure

**Problem:** ColMAD names three debate-hacking behaviors but detection is manual. There is no lightweight automated monitor that flags when a debater is hacking the judge rather than truth-seeking.

**Direction:** Hand-label a small set of debate transcripts for the three hacking behaviors, then build a simple few-shot classifier (an open model prompted as a monitor) that flags each behavior. Evaluate against the hand labels and measure how often the judge's wrong verdicts co-occur with flagged hacking.

**Why it matters:** An automated debate-hacking monitor is exactly the kind of cheap, externally-buildable oversight infrastructure that strengthens any debate protocol. Co-occurrence with judge errors validates it as an early-warning signal.

**Relevant context:** Towards Scalable Oversight with Collaborative Multi-Agent Debate (arXiv:2510.20963, Oct 2025) defines debate hacking as (i) fake evidence/misinterpreting requirements, (ii) overconfident-tone claims, (iii) fallacious side-point arguments.
