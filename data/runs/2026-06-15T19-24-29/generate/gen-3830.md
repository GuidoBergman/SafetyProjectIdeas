# Taint Tracking for Agent Data-Exfiltration Paths

**Problem:** Sensitive data given to an agent can leak out through tool calls (web requests, file writes, messages), but agents lack any mechanism to track where tainted data flows.

**Direction:** Import dynamic taint analysis from program security. Tag sensitive inputs as 'tainted' and propagate the taint heuristically through the agent's intermediate outputs; raise an alarm when tainted content reaches an exfiltration-capable tool (outbound network/message). Evaluate detection rate of exfiltration attempts and false-positive rate on benign tasks using an injection/exfiltration benchmark.

**Why it matters:** Provides a concrete, deployable defense against the data-exfiltration failure mode that pairs naturally with provenance tagging — security infrastructure built outside any lab.

**Relevant context:** Dynamic taint tracking is a classic technique for tracing sensitive data flow in programs. AgentDojo-style and Prompt Infection work demonstrate exfiltration risks; taint-tracking-style monitors for agent data flow are an underexplored, student-feasible transfer.
