# Refusal-vs-Capability Tradeoff Curve Across Safety-Tuned Model Versions

**Problem:** Models are released in base, instruct, and safety-tuned variants, but the tradeoff between over-refusal (refusing benign prompts) and harmful-compliance is rarely plotted as a single curve across versions of the same model family.

**Direction:** On one open model family with multiple alignment stages/variants, run a benign-but-sensitive prompt set (e.g. XSTest-style) and a harmful prompt set, then plot each variant as a point on an over-refusal vs harmful-compliance plane. Show how alignment moves models along this frontier.

**Why it matters:** Gives a single, interpretable picture of whether safety tuning is buying real safety or just over-refusal, a metric usable for cross-model comparison (an explicit open problem). All open models, single GPU.

**Relevant context:** Over-refusal vs compliance tradeoff documented in XSTest and SorryBench (ICLR 2025) work; open problem to create standardized cross-model risk metrics (US CAISI/NIST cited in subfield context).
