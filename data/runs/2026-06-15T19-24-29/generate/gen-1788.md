# Can Models Coordinate to Fool Auto-Interpretability? A Small Replication

**Problem:** A success state: 'automated interpretability pipelines are robust to a model trying to deceive them.' Backcasting from 'tamper-resistant auto-interp', a prerequisite is demonstrating, at small scale, whether an explainer model can be induced to produce misleading feature explanations that fool an evaluator model.

**Direction:** Set up the standard auto-interp loop (explainer LLM labels a feature from max-activating examples; evaluator LLM scores the label). Then prompt the explainer to subtly mislabel safety-relevant features and measure whether the evaluator catches it. Report the deception success rate and which evaluator checks resist it.

**Why it matters:** If auto-interp can be gamed, interpretability evidence in audits is corruptible — a key concern as interp gets automated. Prompt-driven, open models, no training; squarely a deception/oversight study labs underweight.

**Relevant context:** Deceptive Automated Interpretability: Language Models Coordinating to Fool Oversight Systems (arXiv 2504.07831) shows LMs can coordinate to fool interpretability oversight. Standard explainer/evaluator auto-interp loops are runnable on open models.
