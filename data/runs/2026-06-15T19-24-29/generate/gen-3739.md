# Personal-Data Leakage from Prompt Injection Replicated on Self-Hosted Agents

**Problem:** 'Simple Prompt Injection Attacks Can Leak Personal Data Observed by LLM Agents During Task Execution' showed agents leak PII they encounter mid-task via simple injections. The study used particular agents; the leakage rate for self-hostable open-weight agents on the same simple-injection scenarios is not characterized.

**Direction:** Replicate the simple-injection PII-leak scenarios (agent reads a document/email containing personal data, then encounters an injected instruction to exfiltrate it) across a panel of open-weight models with a fixed harness. Measure leak rate per model and which injection phrasings work, anchoring to the original simple-attack findings.

**Why it matters:** Privacy leakage from injected instructions is a near-term, real-world harm for the self-hosted-agent users that labs do not benchmark. The eval needs only synthetic data and inference, has no training, and produces directly actionable per-model risk numbers.

**Relevant context:** 'Simple Prompt Injection Attacks Can Leak Personal Data Observed by LLM Agents During Task Execution' (arXiv 2506.01055): simple injections cause agents to leak personal data they observe while performing benign tasks.
