# Cross-Framework Capability-Threshold Comparability Index

**Problem:** Each lab defines its own Critical Capability Levels, so a 'high' bio capability threshold at one lab may differ greatly from another's. There is no instrument that normalizes and compares the actual capability bar implied by each lab's thresholds in a given risk domain.

**Direction:** For one risk domain (e.g. CBRN/bio), extract each lab's threshold definitions, anchor them to a shared severity ladder you define (e.g. novice-uplift / expert-uplift / full-automation), and have multiple raters place each lab's threshold on the ladder. Produce a comparability index and inter-rater agreement, exposing how non-comparable current thresholds are.

**Why it matters:** International consensus on evaluation methodology requires comparable thresholds; quantifying current non-comparability is foundational governance tooling. Public-document desk research with a stats component.

**Relevant context:** METR Common Elements (CCL definitions across labs); EU GPAI systemic-risk taxonomy; International AI Safety Report 2026 (arXiv 2602.21012).
