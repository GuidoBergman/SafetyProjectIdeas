# Trajectory Replay Tool: Deterministic Re-Scoring Harness for Reproducible Control Experiments

**Problem:** Control experiments are hard to reproduce because trajectories are regenerated stochastically each run, conflating monitor changes with policy randomness. There is no simple shared format + tool to freeze a set of agent trajectories once and cheaply re-score them with many monitor variants, which would make monitor comparisons reproducible and fast.

**Direction:** Define a minimal JSON trajectory schema (steps, tool calls, outputs, ground-truth attack labels) and build a small re-scoring harness: load frozen trajectories, run an arbitrary monitor prompt/model, output per-trajectory scores and aggregate safety/FP metrics. Seed it with frozen trajectories exported from ControlArena/SHADE-Arena and demonstrate reproducible monitor comparisons.

**Why it matters:** Removes policy stochasticity as a confounder and slashes the cost of monitor research, letting anyone fairly compare monitors on identical data. Foundational open infrastructure with strong counterfactual value — exactly what enables non-lab researchers to contribute.

**Relevant context:** ControlArena defines complete evaluation environments and scorers; Ctrl-Z (arXiv 2504.10374) uses importance sampling over frozen episodes; mini-control-arena builds on Inspect AI. A standardized frozen-trajectory re-scoring tool for reproducible monitor comparison is a clear, useful gap.
