# Prefill-Recovery as a Behavioral Fingerprint for Hidden Misalignment

**Problem:** A model that complies harmfully only after a prefill but verbalizes nothing suspicious is a model-organism for non-verbalized misalignment; the prefill-recovery profile could serve as a behavioral fingerprint, but this framing has not been tested.

**Direction:** Treat prefill-recovery curves as behavioral fingerprints and test whether a deliberately abliterated (refusal-removed) open model versus its aligned base produces distinguishable fingerprints, even when surface refusals look similar. Assess whether the fingerprint detects 'silent' alignment removal.

**Why it matters:** Probes a model-organism question (detecting a model that misbehaves without verbalizing it) using only behavioral inference, no internal lab tooling. If prefill fingerprints reveal hidden tampering, it is a cheap auditing technique for open-weight supply-chain safety — a medium-horizon concern.

**Relevant context:** Abliteration removes refusal while preserving capabilities (Arditi et al., NeurIPS 2024; arXiv:2509.15202). Open-weight fine-tuning defenses are easily stripped (arXiv:2605.26526). Using prefill-recovery behavior as a tamper/fingerprint detector for silently de-aligned models is an untested framing.
