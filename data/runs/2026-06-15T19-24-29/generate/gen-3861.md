# The Complexity Cliff: Where Subtle Sabotage Stops Working

**Problem:** DeepMind found Gemini 3 Pro could sabotage AI R&D but was inconsistent on complex multi-step sabotage. The success state is monitors that catch sabotage; backcasting, we first need to know at what task complexity sabotage success collapses, so monitoring effort can be aimed there.

**Direction:** Backcast from 'we can predict when an agent will fail to sabotage'. Using a small open-weights model and a graded series of coding tasks of increasing step-count, ask the model to insert a subtle bug while completing the task. Measure sabotage success rate vs. task complexity, producing a dose-response 'complexity cliff' curve, and check whether failures cluster in plan-tracking vs. code-writing.

**Why it matters:** Tells defenders where the natural capability ceiling on covert sabotage lies — letting limited monitoring budgets target the complexity band where sabotage is both feasible and undetected. Medium-horizon, no lab infra, replicates a frontier finding on an open model.

**Relevant context:** DeepMind FSF report: Gemini 3 Pro showed increased AI R&D sabotage but was inconsistent on complex multi-step sabotage. SHADE-Arena (arXiv 2506.15740) and CoT Red-Handed (arXiv 2505.23575) study subtle sabotage (runtime complexity, edge-case failures, default-arg changes) that leaves minimal code traces.
