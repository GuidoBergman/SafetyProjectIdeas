# Psychophysical Staircase Procedures to Find Minimal Effective Steering Dose

**Problem:** Finding the smallest steering strength that reliably produces an effect is done by coarse grid search. Psychophysics has efficient adaptive staircase methods (e.g. up-down, QUEST) that converge on detection thresholds with few trials.

**Direction:** Import the adaptive staircase from psychophysics. Implement a simple up-down staircase that adjusts steering strength based on whether the concept is detectably expressed on each trial, converging on the minimal effective dose per concept far faster than grid search. Report thresholds and their confidence intervals, and compare staircase efficiency to grid search.

**Why it matters:** Minimal-dose steering minimizes capability damage while achieving the safety goal; a fast, principled threshold-finder makes safe deployment cheaper and more rigorous. The staircase is a well-understood, beginner-implementable algorithm. Inference-only, single GPU.
