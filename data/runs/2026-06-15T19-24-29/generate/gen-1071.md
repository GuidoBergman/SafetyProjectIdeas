# A Lightweight Homogeneity Monitor: Prototype Dashboard for Concentration Risk

**Problem:** Open problems call for monitoring approaches for systemic/concentration risk spanning multiple deployed systems, but no simple, runnable tool exists for a non-lab researcher to quantify how homogeneous a set of models is on a given task.

**Direction:** Build a small open-source harness: given a prompt set and a list of model endpoints, it samples responses and outputs a homogeneity report (pairwise CAPA on labeled tasks, embedding-similarity matrix on open tasks, a homogeneity dendrogram, and a single 'monoculture index'). Validate it by reproducing the Hivemind ordering on a handful of models.

**Why it matters:** Strategically valuable infrastructure that any auditor, regulator, or hub can run without lab access — directly serving the EU-AI-Act systemic-risk monitoring need. Small prototype scoped to 30h.

**Relevant context:** EU AI Act systemic risk monitoring open problem; CAPA metric (arXiv:2502.04313); Hill-Shannon diversity (arXiv:2510.04226).
