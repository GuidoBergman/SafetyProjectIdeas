# Reproducing emergent-linear-truth-structure as a function of model scale within one open family

**Problem:** Geometry-of-truth work observed that the linear truth direction is clearer/stronger in more capable models, and that 'at sufficient scale' LLMs linearly represent truth. The scale-dependence claim is usually inferred across heterogeneous models. A clean within-family replication — same architecture and training recipe, several sizes — would isolate scale as the variable driving truth-direction emergence.

**Direction:** Pick an open model family released in multiple sizes. For each size, build the difference-in-mean truth probe on the same true/false dataset and measure probe linear-separability (AUROC) and the causal-steering effectiveness. Reproduce the claim that truth-direction quality increases with scale, holding architecture/training fixed, and report the scaling curve.

**Why it matters:** Whether honest-representation features emerge predictably with scale tells us if probe-based honesty monitoring will get easier or harder as models grow — a forecasting question central to oversight. A controlled within-family scaling replication on public checkpoints is counterfactually valuable, needs no training, and directly informs the ELK / honesty-monitoring agenda.

**Relevant context:** The Geometry of Truth (arXiv:2310.06824): stronger truth directions in more capable models, linear truth representation 'at sufficient scale'; follow-up arXiv:2506.00823. Open Problem (context): ELK; inductive-biases study. Common Methodologies (context): linear probing.
