# Clinical Dose-Escalation Protocol for Borderline Harm

**Problem:** Safety benchmarks treat prompts as binary harmful/benign, but real misuse escalates gradually. Clinical pharmacology has rigorous dose-escalation (3+3) designs to find a 'maximum tolerated dose' safely.

**Direction:** Transfer the 3+3 dose-escalation design. Define a graded harm-intensity ladder for a topic, and use a 3+3-style adaptive protocol to locate each model's 'maximum tolerated request intensity' (the highest rung the model still answers helpfully before refusing). **Why it matters:** Gives a principled, statistically-grounded boundary-finding method for the fuzzy helpful-vs-harmful frontier (a diffuse-reward problem labs do unevenly). No training; standard adaptive-design code.
