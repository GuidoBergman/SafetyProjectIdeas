# Random-Matrix-Theory Filtering of the LLM Agreement Matrix to Find a 'Systemic' Eigenmode

**Problem:** Finance uses random matrix theory (RMT) to separate genuine correlation structure from noise in asset-correlation matrices, isolating a dominant 'market' eigenmode that represents systemic co-movement. The LLM cross-model agreement matrix has never been analyzed this way to find a systemic homogeneity factor.

**Direction:** Build a model x query agreement/response-embedding matrix over a panel of open models on Infinity-Chat-style queries, compute its eigenspectrum, and use the Marchenko-Pastur RMT bound to separate signal from noise. Interpret the leading eigenvector as the 'systemic hivemind factor' — how much every model moves together — and quantify each model's loading on it.

**Why it matters:** Produces a single systemic-risk factor and per-model exposures, exactly the kind of monitoring metric regulators want for concentration risk, using a battle-tested financial method. No training, just inference + linear algebra (fits the participant's stats/linear-algebra skills perfectly).

**Relevant context:** RMT / Marchenko-Pastur filtering of correlation matrices, leading eigenvector as market mode (arXiv:1803.00261). Systemic risk from similarity (PMC6533041). Artificial Hivemind effect (arXiv:2510.22954).
