# Feature-Universality Result Replicated Within a Single Model Family Across Scales

**Problem:** Work quantifying SAE feature-space universality across different LLMs found 'weak universality.' But the cleaner question — whether the SAME features (via shared SAE dictionaries on Neuronpedia) persist across model sizes within ONE family (e.g., Gemma-2-2b vs Gemma-2-9b, both with public Gemma Scope SAEs) — is more tractable and directly tests whether features are conserved as capability scales.

**Direction:** Use the public Gemma Scope SAEs for Gemma-2-2b and Gemma-2-9b. Pick a set of named, interpretable features (e.g., entity, sentiment, code) from the smaller model and find their nearest analogues in the larger model via activation correlation on shared text. Replicate the universality-quantification methodology, reporting the fraction of features with strong cross-scale matches.

**Why it matters:** If features are conserved across scale within a family, interpretability and safety findings on small models transfer to large ones — a load-bearing assumption for the entire 'study small, deploy large' research strategy. Testing this with public SAEs on one GPU directly validates whether cheap small-model interpretability informs frontier safety.

**Relevant context:** 'Quantifying Feature Space Universality Across LLMs via SAEs' (arXiv:2410.06981) found weak universality across models. Gemma Scope (DeepMind) provides public SAEs for all layers of Gemma-2-2b and -9b; Neuronpedia hosts feature dashboards and an API.
