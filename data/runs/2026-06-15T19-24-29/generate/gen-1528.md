# Does a power-seeking concept vector fire on instrumentally power-seeking text the model produces unprompted?

**Problem:** Misalignment chain: model pursues a goal -> derives an instrumentally power-seeking subgoal (acquire resources, avoid shutdown) -> expresses it in planning text -> harmful action. A monitor needs to catch the power-seeking link. But power-seeking probes are usually validated on explicitly-labeled power-seeking statements, not on instrumentally power-seeking text the model generates while pursuing a benign-seeming task. This generalization link is untested.

**Direction:** On an open model, build a power-seeking direction from explicit contrastive pairs (RepE-style). Then prompt the model with open-ended planning tasks (e.g., 'achieve goal X in this environment') and have it generate plans; label plan segments for instrumental power-seeking and test whether the probe fires on them. Success criterion: probe detection rate on naturally-generated instrumental power-seeking vs explicit examples.

**Why it matters:** Long-horizon power-seeking is a core catastrophic-risk threat model that labs deprioritize for near-term concerns; an activation probe that catches it in naturalistic planning is exactly the >1-year-horizon, counterfactually-valuable monitoring work. Feasible 30h slice using prompted planning as a model-organism proxy.

**Relevant context:** RepE power-seeking directions; Beaglehole et al. concept probing and Anthropic defection-probe methodology. The explicit-to-instrumental generalization gap is the neglected causal link.
