# Does Tokenization Shape Which Features Form? Spelling Features Across Tokenizers

**Problem:** Feature-absorption studies use first-letter/spelling probe tasks and find token-aligned latents. But these use one tokenizer. How much the existence and cleanliness of character-level features (like a 'starts with S' feature) depends on the tokenizer's byte-vs-word granularity is a natural, under-examined variation.

**Direction:** Compare spelling/first-letter feature quality between models with different tokenization granularity (e.g. a byte-level / smaller-vocab model vs a standard BPE model), using pretrained SAEs where available or activation probing where not. Measure how cleanly first-letter information is linearly decodable per model. Frame as: does coarser tokenization force character info into superposition?

**Why it matters:** Tokenization is an under-appreciated determinant of what models can represent and how interpretable they are. Showing that tokenizer choice changes feature cleanliness informs both model builders and auditors, and is a fresh, fully-open angle requiring only inference and linear probes.

**Relevant context:** Chanin et al. 2024 absorption study uses first-letter spelling probes on GPT-2; byte-level vs BPE tokenization differences are well documented; tokenizer-glitch-token literature. Inference + linear probes only.
