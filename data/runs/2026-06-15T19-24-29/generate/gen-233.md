# Contrastive Over-/Under-Refusal Joint Scorecard

**Problem:** Safety benchmarks (StrongREJECT) and over-refusal benchmarks (XSTest, OR-Bench) are run separately, so no single artifact reports a model's joint position on the safety/helpfulness frontier with one comparable metric.

**Direction:** Define a single 'refusal calibration' scorecard combining harmful-refusal-rate (from StrongREJECT/AILuminate) and benign-refusal-rate (from XSTest/OR-Bench) into one F-style discrimination metric, then compute it for several open models and rank them. Ship the unified harness so any model can be plotted on the same axes.

**Why it matters:** The field treats over-refusal and under-refusal as separate problems; a unified scorecard makes the inherent trade-off explicit and comparable, directly serving the 'no catastrophic over-refusal' open problem. Combines existing public datasets; no training.

**Relevant context:** OR-Bench (2025, 80K over-refusal prompts), XSTest (arXiv:2308.01263), StrongREJECT (arXiv:2402.10260), AILuminate (arXiv:2503.05731). Context open problem on avoiding catastrophic over-refusal.
