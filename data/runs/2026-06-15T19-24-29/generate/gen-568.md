# The Self-Preference Link in LLM Judges: Does an Evaluator Causally Favor Its Own Outputs?

**Problem:** The scalable-oversight chain: use an LLM as judge -> judge scores candidate outputs -> high-scoring outputs are selected/trained on. A subtle under-studied link is self-preference bias: if a judge causally rewards its own style/outputs, the optimization loop entrenches the judge's quirks rather than true quality — a Goodhart amplifier.

**Direction:** Have several open models each generate answers and each judge all answers (own and others'), on tasks with ground-truth quality. Estimate the causal self-preference effect by comparing scores for identical-quality answers that differ only in authorship/style cues, and test whether anonymizing/paraphrasing answers removes the bias.

**Why it matters:** LLM-as-judge underlies much scalable oversight; quantifying and causally isolating self-preference (and a simple debias) is directly useful and fully feasible with prompting and no training.

**Relevant context:** LLM-as-judge self-preference and length-bias literature; 'Reward Hacking as Equilibrium' (arXiv:2603.28063) framing of style dimensions as uncovered quality; Goodhart taxonomy.
