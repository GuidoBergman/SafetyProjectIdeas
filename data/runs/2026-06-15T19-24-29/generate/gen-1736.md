# Linguistics Minimal Pairs to Isolate Single-Feature Sensitivity

**Problem:** Isolating what a feature responds to is confounded because natural sentences differ on many dimensions at once. Linguistics solved this with minimal pairs differing in exactly one property.

**Direction:** Import the minimal-pair methodology (as in BLiMP) into feature analysis. For each candidate SAE feature, automatically construct minimal pairs differing in one controlled property and measure the differential activation, attributing the feature to the property that produces the largest, most consistent delta. Build a minimal-pair 'receptive field' catalogue for a set of features on an open SAE.

**Why it matters:** Gives causal, controlled feature labels instead of correlational dashboard guesses, improving the trustworthiness of feature interpretations used in safety monitoring. Cheap and fully open.

**Relevant context:** BLiMP (Warstadt et al.) provides curated linguistic minimal pairs; minimal-pair design is foundational in linguistics. Using minimal pairs as the unit of SAE-feature attribution is an underexplored, feasible transfer.
