# SAE Feature Stability Across Random Seeds Benchmark

**Problem:** When researchers point to 'the feature for X,' it is rarely checked whether that feature reproducibly emerges across SAEs trained with different seeds or hyperparameters. SAEBench evaluates quality but there is no standard measurement of feature-identity stability across independently trained SAEs on the same model/layer.

**Direction:** Using multiple open SAEs trained on the same model and layer (available via SAELens/SAEBench's 200+ released SAEs), build a tool that matches features across SAEs by activation-pattern similarity and reports a 'stability score': what fraction of a concept's features have a clear cross-SAE counterpart. Demonstrate on a few safety-relevant concepts (refusal, sentiment, deception-related text).

**Why it matters:** Safety conclusions ('we found and can monitor the deception feature') are only meaningful if the feature is a stable property of the model, not an artifact of one SAE run. A stability benchmark gives the field a reproducibility gate, runnable by anyone with the public SAE weights.

**Relevant context:** SAEBench (Karvonen et al., ICML 2025) open-sourced 200+ SAEs across 8 architectures and notes proxy gains do not reliably transfer to practical performance, implying feature sets differ across configs. Open Phil RFP lists 'find feature representations beyond SAEs' and superposition decomposition reliability as open problems.
