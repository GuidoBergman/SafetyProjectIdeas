# Does the toxicity concept vector generalize to implicit / coded toxicity, or only the explicit link?

**Problem:** Toxicity-monitoring chain: toxic intent -> toxic representation -> probe fires. Probes are usually built and tested on EXPLICIT toxicity (slurs, overt insults). The neglected link is whether the same direction captures IMPLICIT/coded toxicity (dog-whistles, sarcasm, euphemism) — the harder, more dangerous form that slips past surface filters.

**Direction:** Build a toxicity direction from explicit contrastive pairs on an open model. Test it on a held-out set containing (a) explicit toxicity and (b) implicit/coded toxicity (curated examples of dog-whistles, condescension, microaggressions) plus benign controls. Compare detection AUROC across explicit vs implicit. Success criterion: quantified generalization gap from explicit to implicit toxicity.

**Why it matters:** Implicit toxicity is exactly what evades keyword filters and matters most for real harm; if concept vectors don't generalize there, probe-based monitoring inherits the same blind spot. A diffuse, fuzzy-reward evaluation needing only curated prompts.

**Relevant context:** Beaglehole et al. report probes beating judges on toxicity benchmarks; the explicit-only training set is the standard limitation. RepE toxicity-direction methods. Implicit-toxicity generalization is the novel test.
