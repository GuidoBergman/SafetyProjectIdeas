# The Capability Link: Does a Jailbroken Model Actually Know the Harmful Content?

**Problem:** Misuse requires two links: model is willing (refusal bypassed) AND model is capable (has the harmful knowledge). Attack benchmarks measure willingness but rarely the capability link, so reported risk may overstate harm for content the model couldn't accurately produce anyway.

**Direction:** For a set of jailbroken harmful outputs on an open model, separately probe ground-truth capability by asking the same factual sub-questions in a neutral/benign framing where the model has no reason to refuse. Compare jailbroken output quality against the model's benign-framed capability ceiling to estimate how much willingness vs capability gates real harm.

**Why it matters:** Separates the willingness and capability links so risk assessments reflect actual uplift rather than mere compliance, refining the StrongREJECT 'convincingness' idea with a capability baseline. Prompting + open model only, no training; a methodological contribution to how the field measures real-world harm potential.

**Relevant context:** StrongREJECT (arXiv:2402.10260) measures specificity/convincingness but not an independent capability ceiling; dose-response and uplift framings appear in safety-eval literature. Shallow alignment (arXiv:2406.05946) shows willingness can be toggled independently of underlying knowledge.
