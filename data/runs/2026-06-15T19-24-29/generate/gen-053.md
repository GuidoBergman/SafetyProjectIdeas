# Image-Embedded Indirect Injection: The Multimodal Agent Attack Surface No Benchmark Owns

**Problem:** GAP TARGETED: the intersection of three thin areas — multimodal safety (infrastructure gap), agentic safety (biggest benchmark gap), and indirect prompt injection — where an agent reads an IMAGE (screenshot, document, web banner) containing hidden instructions. No benchmark owns image-channel indirect injection for tool-using agents.

**Direction:** Build a tiny vision-agent loop where one tool returns an image the model must interpret. Embed injected instructions in the image (rendered text, faint overlays, instruction-in-a-screenshot). Measure how often an open VLM-agent follows injected image instructions vs benign image content, compared to the same injection delivered as text. Test 2 cheap defenses (OCR-then-flag, a 'treat image text as data' reminder).

**Why it matters:** Bridges agentic_safety + adversarial_robustness + evaluations_benchmarks (multimodal). Computer-use and screenshot-reading agents are deploying now, and the image-as-injection-channel is a real, under-evaluated attack surface. Counterfactual (open VLM, mock tool, one GPU) and yields a reusable mini-benchmark plus defense baseline.

**Relevant context:** Visual contextual / contextual-image attacks (arXiv:2507.02844, 2512.02973) show images carry exploitable injected context; AgentDojo covers text indirect injection. No open benchmark isolates image-embedded indirect injection for tool-using agents specifically.
