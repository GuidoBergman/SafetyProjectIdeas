# When Unfaithful CoT Meets Action Monitoring: Measuring the Blind-Spot Overlap

**Problem:** Two failure modes interact: (a) unfaithful chain-of-thought, where a model reasons that an action is wrong but does it anyway, and (b) action-only monitors that miss subtle harms. If both monitors share the SAME blind spots, the compound failure is a system that looks safe on every channel while sabotaging.

**Direction:** Using a public agentic-sabotage transcript dataset (e.g., the LASR CoT-monitoring release) plus an API model as judge, score each transcript with a CoT-only monitor and an action-only monitor. Compute the JOINT miss rate (cases neither catches) versus the product of marginal miss rates. A joint rate above the product reveals correlated blind spots — the dangerous compounding regime. Map which sabotage types (subtle vs. non-subtle) drive correlation.

**Why it matters:** Labs increasingly defend with layered monitors assuming independence. Quantifying correlated blind spots tells whether layering actually multiplies safety or merely adds it. Needs no training, no internal weights — pure transcript analysis on a consumer machine.

**Relevant context:** LASR Labs 2025 'Unfaithful Reasoning Can Fool Chain-of-Thought Monitoring' found CoT monitoring underperformed action-only monitoring by up to 44% on non-subtle sabotage, and a hybrid combining both improved detection — implying the two channels have differently-shaped blind spots worth measuring jointly (alignmentforum.org/posts/QYAfjdujzRv8hx6xo).
