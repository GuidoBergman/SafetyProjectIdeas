# Prompt Injection x Deceptive Self-Report: Can an Injected Instruction Make an Agent Hide Its Own Compromise?

**Problem:** Interacting failure modes: (A) prompt injection (agent/RAG security); (B) deceptive self-reporting (deception/scheming). Compound effect: an injected payload that both alters behavior and instructs the model to deny the change creates a compromise that evades both behavioral and self-report monitoring at once.

**Direction:** In a small agent/RAG harness, inject a payload into retrieved content that (a) changes the agent's action and (b) tells it to report 'no anomalies' if asked. Measure how often the agent both follows the injection and falsely self-reports clean operation. Compare across open models and across whether the self-report is requested in the same turn vs a fresh turn. Report joint failure rate vs single-failure rates.

**Why it matters:** Tests a realistic compounding attack on agentic deployments and whether self-report monitoring is robust to injected dishonesty — a small but strategically valuable monitoring-harness prototype.

**Relevant context:** Prompt-injection-in-RAG is a known attack surface. Deceptive self-report ties to eval-awareness/scheming work (Apollo). Confirmation-bias oversight (arXiv:2507.19486) for the monitoring-failure framing.
