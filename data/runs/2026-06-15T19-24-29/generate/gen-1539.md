# Does Feature Absorption Concentrate on Safety-Relevant Concepts?

**Problem:** Absorption has been demonstrated on a toy spelling task. Whether it specifically corrupts safety-relevant concept features (e.g. deception, harm, refusal-trigger concepts) — which would make SAE-based monitors silently fail — is untested.

**Direction:** Take open SAEs with labeled interpretable latents (from public feature dashboards) corresponding to safety-adjacent concepts, then probe for absorption by checking recall of the concept latent against a curated set of in-concept examples, comparing absorption rates for safety concepts vs. neutral concepts.

**Why it matters:** If safety-relevant SAE features suffer false negatives via absorption, SAE-based deployment monitors could miss exactly the cases that matter. This directly probes the interpretability-to-safety gap with open tooling.

**Relevant context:** 'A is for Absorption' (arXiv 2409.14507): absorption creates false negatives to a latent's mainline interpretation. Open feature dashboards (Neuronpedia/Gemma Scope) label many latents. Context lists 'bridge the interpretability-to-safety gap' as an open problem.
