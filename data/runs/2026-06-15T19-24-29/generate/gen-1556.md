# Does Feature Absorption Worsen When Decoding Concepts the Model Learned Late?

**Problem:** Absorption is hypothesized to follow from sparsity loss when dense and sparse features co-occur. Whether absorption severity relates to a concept's frequency/learning order — and thus is predictable — is untested.

**Direction:** Using open SAEs, measure absorption rate across many concepts and correlate it with each concept's corpus frequency and with a proxy for learning order (e.g. when the concept becomes linearly decodable across Pythia checkpoints). Test the hypothesis that rarer/late-learned concepts get absorbed more.

**Why it matters:** If absorption is predictable from concept statistics, auditors can flag which SAE features to distrust without exhaustive testing — a practical reliability heuristic for SAE-based safety tooling, built entirely on open resources.

**Relevant context:** 'A is for Absorption' (arXiv 2409.14507): absorption follows from sparsity loss when dense+sparse features co-occur. Pythia checkpoints allow tracking concept learnability over training; Gemma Scope/SAELens provide open SAEs.
