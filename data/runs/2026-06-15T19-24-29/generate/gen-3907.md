# Indirect Injection x Cross-Agent Belief Manipulation: Compounding a Planted Lie Into Consensus

**Problem:** Failure mode A: indirect prompt injection plants a false belief in one agent. Failure mode B: multi-agent deliberation that forms consensus. The compound failure is a planted lie laundered into a confident group consensus that no single agent would have asserted alone.

**Direction:** Run a small multi-agent debate/voting setup on factual questions; inject a false premise into one agent via a 'document'. Measure how often the group's final consensus adopts the lie versus the single-agent adoption rate. The consensus-amplification ratio quantifies the compounding.

**Why it matters:** Belief-manipulation via collusion/montage is an emerging threat to multi-agent governance; isolating consensus amplification is a clean first measurement. API models + orchestration only.
