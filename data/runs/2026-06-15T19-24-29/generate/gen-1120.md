# AgentMonoculture-Sim: a tiny sandbox for cascading failures in same-model agent swarms

**Problem:** Monoculture-collapse theory predicts that multi-agent systems built on the same base model share correlated vulnerabilities, causing cascades. There is no small, runnable testbed for a beginner to OBSERVE and MEASURE such a cascade.

**Direction:** Build a minimal multi-agent simulation (5-10 agents passing messages on a simple cooperative task) where all agents use the same open model vs a mixed-model condition. Inject a poisoned/ambiguous input and measure how far the failure propagates (fraction of agents that adopt the wrong belief/action) in the homogeneous vs heterogeneous swarm. Ship the sandbox as a notebook.

**Why it matters:** Provides concrete, reproducible evidence and infrastructure for the cascading-failure open problem, letting researchers study correlated-failure propagation without lab-scale systems. Strategically valuable monitoring/sandbox infra scoped to a small prototype.

**Relevant context:** Grounds 'monoculture collapse' / cascading reliability failures (Risk Analysis Techniques for Governed LLM Multi-Agent Systems, arXiv:2508.05687) into a runnable testbed. Cascading-failure characterization is a listed open problem.
