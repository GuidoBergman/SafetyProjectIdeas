# Mapping Feature Absorption Prevalence Across the SAE Width Sweep

**Problem:** The NeurIPS 2025 'A is for Absorption' result showed SAE latents that appear monosemantic fail to fire on arbitrary examples (e.g. a 'starts-with-E' feature missing 'Elephant'), and that varying SAE size/sparsity does not fix it. The quantitative prevalence of absorption across the publicly available SAE-width sweep is not mapped.

**Direction:** Using the public Gemma Scope / SAELens family of SAEs at multiple widths, replicate the first-letter spelling task, automatically detect absorption (latent fires for the concept but misses specific tokens whose feature is captured elsewhere), and plot absorption rate as a function of SAE width and L0 to produce an empirical prevalence curve.

**Why it matters:** Feature absorption is an 'interpretability illusion' that makes SAE-based safety claims untrustworthy. A quantitative prevalence map tells auditors how much to distrust SAE monosemanticity, using only open SAEs and CPU/light-GPU inference.

**Relevant context:** 'A is for Absorption' (arXiv 2409.14507, NeurIPS 2025 oral): absorption is asymmetric feature splitting that lowers recall; varying SAE size/sparsity is insufficient to solve it. Gemma Scope provides hundreds of open SAEs at multiple widths.
