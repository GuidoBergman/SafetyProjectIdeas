# Factored Cognition as a Causal Cut: Does Splitting a Task Make Sabotage Easier to Catch?

**Problem:** The untrusted-AI sabotage chain runs through a single agent that both plans and executes, giving it room to hide intent. Factored cognition proposes cutting this link by decomposing the task across instances so no single step contains the full malicious plan. Whether this decomposition actually raises catch rates is under-measured at small scale.

**Direction:** On a small agentic task with an injected subtle backdoor, compare a monolithic untrusted solver against a factored pipeline (separate planning, sub-step, and synthesis instances), each watched by a trusted monitor. Measure monitor catch-rate and task usefulness for both, testing whether factoring causally improves the safety-usefulness frontier.

**Why it matters:** Factored cognition is a promising lab-independent control idea; a beginner-scale test of whether decomposition raises monitorability is concrete, reproducible infrastructure with no training.

**Relevant context:** 'Factor(T,U): Factored Cognition Strengthens Monitoring of Untrusted AI' (arXiv:2512.02157); Greenblatt et al. AI Control framework (arXiv:2312.06942).
