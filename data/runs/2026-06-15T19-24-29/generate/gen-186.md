# Do Probes Detect the Decision to Refuse Before the Model Outputs It?

**Problem:** High-stakes-interaction probes (arXiv:2506.10805) detect harmful interactions, but it is underexplored how early in the prompt-processing stage (which token position of the INPUT) the harmfulness signal becomes linearly decodable.

**Direction:** On an open model, train probes on activations at each INPUT token position of harmful prompts and measure when detection accuracy saturates. Determine whether harmful intent is decodable mid-prompt (enabling pre-generation blocking) or only after the full prompt is read.

**Why it matters:** Pre-generation detection enables aborting before any harmful token is generated — a cheap, deployable safety circuit-breaker for outside-lab monitoring. Single forward pass per prompt.

**Relevant context:** arXiv:2506.10805 'Detecting High-Stakes Interactions with Activation Probes'. arXiv:2601.11516 (production probes). arXiv:2509.14558 (cheap detection).
