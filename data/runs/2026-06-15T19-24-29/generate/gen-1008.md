# A Concentration-Risk Dashboard for the Open-Model Ecosystem

**Problem:** There is no lightweight monitoring tool that, given a set of deployed models, reports systemic-risk indicators (homogeneity, error-correlation, shared-jailbreak exposure). The EU AI Act calls for systemic-risk monitoring but practitioners lack concrete instruments.

**Direction:** Build a small open-source harness: feed it a list of HF model IDs and a probe set; it outputs a one-page report — pairwise output similarity, error-overlap matrix, effective-diversity number, and a few shared-jailbreak transfer rates. Prototype on 6-8 open models and one fixed probe suite. Ship it as a reusable script + sample report.

**Why it matters:** Strategically valuable monitoring infrastructure that any deployer can run without a lab. Turns the abstract 'systemic risk' requirement into a measurable, repeatable check. Scoped as a small prototype, not a product.

**Relevant context:** EU AI Act systemic-risk monitoring (context open problem); aggregates metrics from Artificial Hivemind, correlated-errors, and jailbreak-transfer work.
