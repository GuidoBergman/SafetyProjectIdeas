# Tool-Use Capability x Containment Gaps: Compounding Irreversibility

**Problem:** Growing tool-use/agentic capability (capabilities) compounds the control failure of incomplete containment: as an agent gains more tools, the fraction of actions that are irreversible grows, and a single missed monitor decision now causes permanent harm. The capability failure raises the stakes of every monitoring miss.

**Direction:** Build a sandboxed agent with a configurable toolset (reversible-only vs. mixed reversible/irreversible mock tools). Hold the monitor fixed and measure expected irreversible-harm per missed flag as the toolset grows. Produce a curve: containment value vs. action-space irreversibility.

**Why it matters:** Operationalizes the 'minimum runtime controls for different risk levels' open problem and the 'prevent irreversible harmful actions' problem. A reusable sandbox prototype is strategically valuable infrastructure.

**Relevant context:** Open Phil/AISI: minimum runtime controls (kill switches, output validation, HITL) per risk level; Adversa AI 2025: security architectures to prevent irreversible agentic actions.
