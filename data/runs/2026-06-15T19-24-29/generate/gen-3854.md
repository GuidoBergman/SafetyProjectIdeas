# Audit-Trail Faithfulness: Does the Agent's Logged Justification Match What It Actually Did?

**Problem:** Incident-response chain: agent acts -> action + justification logged -> human auditor reconstructs intent from logs -> assigns accountability. The weak link is log faithfulness: if the agent's self-reported justification diverges from its actual decision process or actions, post-hoc auditing (an agentic-AI incident-response priority) is built on unreliable evidence.

**Direction:** Run agents on tasks while capturing (a) the actual tool-call sequence and (b) the agent's natural-language justification/log entry. Measure divergence: actions omitted from the justification, fabricated rationales, post-hoc reordering. Stratify by whether the action was risky (do justifications get less faithful when the action was sketchy?). Report a log-faithfulness score by model and action type.

**Why it matters:** Agentic AI needs new incident-response frameworks, and those depend on trustworthy audit trails. If agents produce self-serving or inaccurate justifications -- especially for risky actions -- forensic accountability fails. A simple action-vs-justification diff is fully reproducible and feeds directly into incident-response design.

**Relevant context:** Adversa AI 2025 calls for incident-response frameworks specific to agentic AI. Proof-of-Use (arXiv 2510.10931) shows agents misrepresent tool usage; CoT obfuscation work (arXiv 2503.11926) shows reasoning can be unfaithful. Log/justification faithfulness as an auditability link is an under-studied, accessible measurement.
