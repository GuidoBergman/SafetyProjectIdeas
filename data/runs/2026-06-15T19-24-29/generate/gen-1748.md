# Where Does Hallucination Enter the Chain: Knowledge Lookup or Confidence Gate?

**Problem:** Hallucination chain: query about entity -> model assesses 'do I know this?' -> if known, retrieve; if unknown, should refuse/hedge -> generate. Ferrando et al. found 'known/unknown entity' directions that causally gate this. The under-studied link is the gate FAILURE: when the model knows it doesn't know but answers anyway.

**Direction:** Replicate the known/unknown entity direction on Gemma-2-2B using contrastive prompts (real vs fictional entities). Then find cases where the model hallucinates about a fictional entity, and test via steering whether nudging the 'unknown' direction restores hedging — isolating whether the gate is mis-set vs absent.

**Why it matters:** If the 'I don't know' signal exists but is ignored, hallucination is a cheap-to-fix gating problem detectable by a probe. High value for monitoring; uses the public Do-I-Know-This-Entity setup and Gemma Scope, single GPU.

**Relevant context:** Ferrando et al. 'Do I Know This Entity? Knowledge Awareness and Hallucinations in Language Models' (arXiv 2411.14257, ICLR 2025): self-knowledge directions in Gemma-2-2B/9B causally affect knowledge refusal; steering known with unknown latent reduces logit difference.
