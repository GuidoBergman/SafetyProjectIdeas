# Mini-ControlArena Settings Audit: Are Existing Control Benchmarks Saturated or Gameable?

**Problem:** ControlArena and SHADE-Arena are the main open control benchmarks, but newcomers lack a clear read on which settings are near-saturated (monitors trivially win), which are too hard (attackers trivially win), and which discriminate well between monitor designs — information essential for choosing where new monitoring research has signal.

**Direction:** Across several ControlArena/SHADE-Arena settings, run a fixed small panel of monitor configurations against a fixed attacker. For each setting, report the spread in safety scores across monitors (discriminative power), the absolute difficulty, and whether trivial baseline monitors already win. Produce a 'which settings have headroom' map for future researchers.

**Why it matters:** Benchmark meta-analysis prevents the field from wasting effort on saturated settings and highlights where monitoring still fails. This is cheap, reusable infrastructure that increases the value of all downstream control work. Open tooling, API-only.

**Relevant context:** ControlArena (UKGovernmentBEIS/control-arena) provides settings with datasets, sandboxes, and scorers; SHADE-Arena (arXiv 2506.15740) has 17 task pairs; mini-control-arena (brucewlee) is a lightweight Inspect-based option. No public audit characterizes per-setting discriminative power and headroom.
