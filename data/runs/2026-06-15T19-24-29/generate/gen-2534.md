# Trusted Editing Replicated on Natural-Language Agent Tasks

**Problem:** Trusted editing (a weak trusted model edits the untrusted model's output to remove backdoors) reached 92% safety on the APPS code setting, but the technique has been studied almost entirely on code; whether it transfers to non-code agentic outputs is unknown.

**Direction:** Replicate the trusted-editing protocol but on a NEW modality: natural-language agent action plans or tool-call sequences from a SHADE-Arena-style task. Have a weak trusted open model edit the untrusted model's proposed actions to remove the covert side task, then measure safety and usefulness. Twist: compare editing effectiveness on code vs natural-language plans.

**Why it matters:** Most real agentic harm is non-code (tool calls, plans, messages). Knowing whether trusted editing's strong code results transfer to language is decision-relevant for deployment and is reproducible on one GPU.

**Relevant context:** Redwood AI Control (arXiv 2312.06942): trusted editing 92% safety on APPS. SHADE-Arena (arXiv 2506.15740) supplies natural-language agentic tasks with side objectives. Inspect scaffolds available.
