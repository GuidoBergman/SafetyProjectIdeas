# Constraint-Violation Outcome Benchmark for Long-Horizon Tasks

**Problem:** Most agent safety benchmarks score harmful intent at the action level; a 2025 benchmark argues outcome-driven CONSTRAINT VIOLATIONS (the agent achieves the goal but violates a stated constraint, like a budget cap) are under-measured for autonomous agents.

**Direction:** Build a compact suite of 25-30 tasks each with an explicit numeric/policy constraint (spend < $X, never email outside domain, never modify file Y). Run open/API agents and measure constraint-violation rate as a function of task length, separating 'goal failure' from 'constraint failure'. Provide an automatic constraint-checker.

**Why it matters:** Constraint-following is the crisp, checkable core of safe autonomy and a diffuse-reward problem. Automatic checkable constraints make this a clean 30h eval with no human grading.

**Relevant context:** 'A Benchmark for Evaluating Outcome-Driven Constraint Violations in Autonomous AI Agents' (arXiv 2512.20798). 'Before the Tool Call: Deterministic Pre-Action Authorization' (arXiv 2603.20953). TheAgentCompany (arXiv 2412.14161) for consequential task scaffolds.
