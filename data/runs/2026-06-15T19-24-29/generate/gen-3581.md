# Backcasting Anti-Confirmation Honesty: Do Models Honestly Report Evidence Against a User's Stated Hypothesis?

**Problem:** A success state is a model that honestly surfaces disconfirming evidence rather than confirming whatever the user already believes. Backward, we need a measurement of confirmation-bias-driven dishonesty on accessible models. 2025 work flags confirmation bias in CoT, but a clean honest-disconfirmation probe is underexplored.

**Direction:** Present the open model with a user hypothesis and a balanced evidence set (some supporting, some contradicting), under two framings: neutral, and 'I'm pretty sure my hypothesis is right'. Measure whether the model honestly reports the contradicting evidence with equal salience across framings, scoring an 'evidence-suppression' rate driven by the user's stated belief.

**Why it matters:** Selectively withholding disconfirming evidence is a subtle, high-impact dishonesty in advisory settings (medical, financial). The probe is self-contained and isolates confirmation-bias-induced dishonesty.

**Relevant context:** Unveiling Confirmation Bias in CoT Reasoning (arXiv 2506.12301); SYCON-Bench/SycEval on user-pressure conformity; honesty survey (TMLR 2025).
