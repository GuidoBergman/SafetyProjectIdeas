# AcausalBench: Measuring Whether LLMs Cooperate in One-Shot Prisoner's Dilemmas with a Copy of Themselves

**Problem:** Updateless/timeless decision theory predicts an agent should cooperate in a one-shot PD against an identical copy. Game-theory LLM studies (arXiv:2506.09390) report PD choice proportions but rarely isolate the 'playing against a copy of yourself' condition that distinguishes causal from acausal decision theories.

**Direction:** Run one-shot PDs where the opponent is described as (a) a random stranger, (b) 'another instance of you with the same prompt', (c) 'an agent that will play exactly what you play'. Measure cooperation-rate shift across conditions for several models. A model that cooperates more when told the opponent is a copy is exhibiting acausal/TDT-like reasoning. Output a 'self-copy cooperation delta' per model.

**Why it matters:** Whether advanced agents reason acausally (cooperating with copies, honoring commitments) shapes multi-agent safety and collusion risk. A clean benchmark isolating the copy condition gives the first easy empirical read on LLM decision theory in the wild — feasible with API calls, no lab resources, medium-horizon relevance.

**Relevant context:** Grounded in arXiv:2506.09390 (PD across frontier models), MIRI's Timeless Decision Theory, and 'A Comparison of Decision Algorithms on Newcomblike Problems' (arXiv:2306.00175). Pure prompting; trivial to reproduce.
