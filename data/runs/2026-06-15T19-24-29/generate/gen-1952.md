# Subliminal Trait Transfer Through Code, Not Numbers

**Problem:** Subliminal learning was demonstrated via number sequences and similar neutral data. Whether the same trait transfer occurs through a different, more realistic generated-data modality such as code or chain-of-thought traces is unknown.

**Direction:** Replicate the subliminal-learning protocol on a small open model but have the trait-steered teacher generate code snippets (or reasoning traces) instead of number sequences; fine-tune a same-base student and measure trait transfer. Twist: change the data modality while keeping the subliminal-transfer mechanism under test.

**Why it matters:** Code and reasoning traces are the data modalities most used in real distillation pipelines; if traits transfer through them too, the distill-and-filter risk is far more practically dangerous. Mapping modality dependence is cheap and infrastructure-free.

**Relevant context:** Cloud et al. (arXiv:2507.14805, Nature 2026) demonstrated transfer via number sequences under shared base models. A follow-up on agent distillation (arXiv:2604.15559) suggests unsafe-behavior transfer in richer data, motivating a modality sweep.
