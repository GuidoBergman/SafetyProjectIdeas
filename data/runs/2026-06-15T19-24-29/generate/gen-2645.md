# Activation-Probe Transfer Across the Deception-Type Boundary

**Problem:** Risk: an activation monitor trained on one deception type misses a novel one. Causal chain: blue team trains a linear probe on known deceptive activations -> deploys it as a real-time monitor -> a model exhibits a deception type unseen at probe-fit time -> probe fails to fire. Probes report AUROC 0.96-0.999 in-distribution, but the under-studied link is cross-type transfer: does a probe fit on, say, insider-trading concealment generalize to sandbagging or sycophancy?

**Direction:** Using an open model (e.g. Llama-3.x or Qwen) with hidden-state access, fit a simple logistic probe on activations for one deception scenario, then evaluate it zero-shot on a held-out deception type. Build a transfer matrix across 3-4 deception types. No model training; only cheap linear probe fitting on extracted activations.

**Why it matters:** Probes are a cheap white-box monitor, but if they only catch the type they were fit on, real-time monitoring has dangerous blind spots for novel behaviors (an open problem in the subfield). Linear-probe fitting is squarely within the participant skill set and runs on one GPU.

**Relevant context:** Detecting Strategic Deception with Linear Probes (arXiv:2502.03407): AUROC 0.96-0.999 on insider-trading concealment and sandbagging with Llama-3.3-70B. SycophantSee (Apart hackathon) shows activation-based sycophancy detection. Pressure-Testing Deception Probes (arXiv:2605.27958) studies probe robustness and the geometry of deceptive representations.
