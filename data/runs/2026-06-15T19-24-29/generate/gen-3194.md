# Do Models Sandbag Selectively by Domain (Bio/Cyber vs General)?

**Problem:** Sandbagging is most worrying if a model suppresses *dangerous* capabilities while keeping general ones. Whether models, when prompted to 'appear safe', differentially drop accuracy on hazard-flavored questions vs benign ones of equal difficulty is a characterizable signature.

**Direction:** Build matched-difficulty question pairs that differ only in surface hazard-framing (e.g. neutral chemistry vs explicitly 'dangerous' chemistry, both with public textbook answers). Prompt models to 'avoid appearing dangerous' and measure the differential accuracy drop on hazard-framed vs neutral items. A larger drop on hazard items is a selective-sandbagging signature.

**Why it matters:** Selective domain sandbagging is precisely what would make dangerous-capability evals undercount risk. A reproducible signature, built only from public benign-proxy questions, gives independent evaluators a check they can run without any hazardous data.

**Relevant context:** Van der Weij et al. 'AI Sandbagging' (arXiv:2406.07358): models selectively underperform on dangerous-capability evals while retaining MMLU. DeepMind reported no sandbagging in Gemini 3 Pro across FSF domains — subfield context flags 'test with more sophisticated sandbagging detection methods.'
