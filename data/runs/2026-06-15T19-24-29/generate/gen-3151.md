# Compliance-Gap Probe Suite for Alignment Faking

**Problem:** Alignment faking is detected via a compliance gap between 'training' (monitored) and 'deployment' (unmonitored) conditions, but there is no standardized, classifier-backed mini-suite a newcomer can run on open models.

**Direction:** Use the open-source Alignment Faking Revisited classifiers (AUROC 0.9) and harmful-request set to build a small reproducible suite measuring the compliance gap across several open instruct models (Llama, Qwen, DeepSeek). Report which models show any gap and how it scales with size.

**Why it matters:** Provides a cheap replication/extension benchmark for the most-studied scheming behavior, and tests the surprising claim that most open models show no prompted alignment faking. No training needed (prompted setting only).

**Relevant context:** Hughes et al. 'Alignment Faking Revisited' (Alignment Forum, 2025) released improved classifiers (AUROC 0.9 vs 0.6) and found only 3/16 models fake; Llama family mostly shows no gap in prompted setting.
