# Cross-Family Monitor Transfer: Does a Monitor Tuned on One Model Catch Another's Attacks?

**Problem:** Control evals typically use a monitor calibrated against a specific untrusted model. In practice the untrusted model may differ. Whether a monitor's suspicion calibration and catch rate transfer across model families (e.g., Llama-tuned monitor watching a Qwen attacker) is a likely failure mode.

**Direction:** Calibrate a small monitor's 1% FPR threshold using benign outputs from model A, then deploy it against attacks generated by models A, B, and C. Measure catch rate and realized FPR per attacker family. Quantify the transfer gap (drop in catch rate / FPR drift when attacker != calibration model).

**Why it matters:** Monitor calibration is implicitly model-specific; if it doesn't transfer, every deployment with a new untrusted model needs recalibration. Documenting non-transfer is a concrete, lab-independent reliability finding. Inference + stats only.
