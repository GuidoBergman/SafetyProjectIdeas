# Calibrating the 0-10 Suspiciousness Scale: Do Monitors Mean the Same Thing?

**Problem:** Control protocols ask monitors for a 0-10 suspiciousness score and threshold on it. But different monitor models may use this scale incomparably (one model's '7' = another's '4'), breaking any fixed-threshold protocol. No one has audited cross-model score calibration.

**Direction:** Take a fixed set of agent trajectories with known ground-truth (benign vs. sabotage) and have 4-5 open monitor models each assign 0-10 suspiciousness. Compare score distributions, reliability diagrams, and the threshold each model needs for a target false-positive rate. Quantify miscalibration with ECE and show how a naive shared threshold misfires.

**Why it matters:** Protocols implicitly assume score comparability; if monitors are miscalibrated, audit budgets are misallocated. A simple recalibration recipe (per-monitor threshold via a small labeled set) would be an immediately useful, lab-independent contribution.

**Relevant context:** Extends the calibrated 0-10 scoring used in 'When can we trust untrusted monitoring? A safety case sketch across collusion strategies' (arXiv:2602.20628, Feb 2026) and 'Ensemble Monitoring for AI Control' (arXiv:2605.15377).
