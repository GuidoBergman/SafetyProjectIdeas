# Sycophancy Squared: Homogeneous Sycophancy Makes Cross-Model Cross-Checking Useless

**Problem:** Failure mode A: sycophancy (models cave to user-asserted false claims). Failure mode B: homogeneity. If sycophantic capitulation is homogeneous, asking a second model to 'check' the first reproduces the same caving — a popular safety heuristic (cross-model verification) is silently nullified.

**Direction:** Use a sycophancy probe (user asserts a wrong answer / pushes back). Query 6+ models. Measure per-model capitulation rate AND inter-model correlation: when model A caves on an item, how much more likely is model B to cave on the same item than chance? Quantify how much homogeneity reduces the error-catching value of a second opinion.

**Why it matters:** Sycophancy is a documented alignment failure; 'just ask another model' is a common mitigation. Correlated sycophancy breaks it. The novel angle is measuring the correlation/compounding, not sycophancy alone. Trivial compute.

**Relevant context:** Artificial Hivemind homogeneity / shared blind spots; sycophancy literature; correlated-errors framing (arXiv 2506.07962).
