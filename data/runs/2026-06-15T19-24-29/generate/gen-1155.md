# Does retrieval break the hivemind, or share it? RAG-grounded homogeneity test

**Problem:** RAG is promoted as a way to make model outputs more grounded and varied. But if diverse models retrieve and copy the same passages, RAG could INCREASE inter-model homogeneity (everyone parrots the top retrieved chunk) — a counterintuitive failure mode for grounded safety-critical answers.

**Direction:** Build a small shared corpus + retriever. Answer a fixed query set with and without RAG across several models. Measure inter-model output similarity in both conditions. Test whether shared retrieval homogenizes answers more than ungrounded generation does.

**Why it matters:** If shared retrieval pipelines amplify monoculture, the rush to RAG-everything in high-stakes settings quietly concentrates risk. A clean, surprising-result-style finding with a small reusable RAG harness; no training.

**Relevant context:** Extends model_homogeneity to retrieval-augmented setups; uses an open retriever + open models on a consumer GPU.
