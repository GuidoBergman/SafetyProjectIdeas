# Goal-Drift Onset Curves Across Context Length

**Problem:** Goal drift (agents deviating from their original instruction over accumulating interactions) is documented but its onset as a function of context length / number of turns is uncharacterized.

**Direction:** Adapt the published goal-drift evaluation setup to a single open agent. Inject a fixed scope constraint ('only edit files in /reports'), then feed increasingly long benign conversation histories and competing soft requests. Measure the turn/token at which the agent first violates scope, producing a 'drift-onset curve' per model. Compare a few open models and prompt-reinforcement strategies (re-stating the goal every N turns).

**Why it matters:** Long-horizon autonomy is the threat labs must deprioritize for near-term concerns, making it high counterfactual value. Drift-onset curves give a cheap, model-agnostic early-warning metric and test whether goal-restatement actually helps.

**Relevant context:** arXiv:2505.02709 'Evaluating Goal Drift in Language Model Agents' (AIES) defines drift via accumulating context and competing objectives, with the coding-agent scope-expansion example. arXiv:2601.04170 'Agent Drift' introduces an ASI drift-measurement framework.
