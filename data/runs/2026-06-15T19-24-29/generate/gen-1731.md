# Economics Shapley Values for Fair Attribution Among Redundant Components

**Problem:** When several components jointly produce a behavior with redundancy, attribution methods give unstable or unfair credit. Game theory solved this fairness problem with Shapley values.

**Direction:** Apply Shapley-value attribution from cooperative game theory to a small set of circuit components. Treat each component as a player, the recovered logit effect as the value function, and compute (sampled) Shapley values over ablation coalitions to get axiomatically fair importance scores. Compare against single-ablation rankings on a known circuit; show where they diverge due to redundancy.

**Why it matters:** Fair, redundancy-aware attribution prevents the 'we found the one responsible head' error that undermines safety arguments. Computable on small circuits with a single GPU.

**Relevant context:** Shapley values are foundational in cooperative game theory and already used in ML feature attribution (SHAP). Applying coalition-based Shapley attribution to mechanistic circuit components (not input features) is the fresh angle; epistasis/redundancy in heads is documented in IOI work.
