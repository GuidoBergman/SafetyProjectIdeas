# Genetic Effective-Population-Size for an LLM Population: How Few 'Independent Minds' Are There?

**Problem:** Population genetics distinguishes census size from effective population size (Ne) — the number of truly independent reproducing individuals. A pool of 70 LLMs may have a tiny effective number of independent behavioral 'genotypes.' This quantity, central to extinction/fragility risk in biology, has no AI analogue.

**Direction:** Define an 'effective model population size' via behavioral allele-frequency analysis: treat clustered response types as alleles, estimate how much of the apparent variance across 70+ public model outputs is independent vs shared, and compute an Ne-style number. Report Ne much smaller than census size as the homogeneity headline.

**Why it matters:** Translates 'we have many AI systems but few independent ones' into a single rigorous number borrowed from conservation biology — a memorable, policy-legible measure of concentration/systemic risk requiring only public model outputs.

**Relevant context:** Effective population size vs census size in population genetics. Hill numbers / diversity estimation (Roswell 2021). Artificial Hivemind: 70+ LLMs show inter-model homogeneity (arXiv:2510.22954).
