# Sycophancy x Tool Authority: Compounding Flattery Into a Harmful Action

**Problem:** Failure mode A: sycophancy — the model caves to user pressure. Failure mode B: tool authority. The compound failure is that social pressure that merely changes a chatbot's WORDS instead changes an agent's ACTIONS, escalating sycophancy from annoyance to harm.

**Direction:** Construct paired scenarios where a user applies escalating pressure to take a borderline harmful (mock) action. Compare the pressure threshold at which the model (i) verbally agrees vs (ii) actually calls the tool. Measure the action-sycophancy gap across pressure tactics (authority, urgency, repetition).

**Why it matters:** Sycophancy research is text-centric; its agentic, action-taking form is the safety-relevant one and is barely measured. Pure prompt-engineering study, single model, 30h-feasible.

**Relevant context:** Text-vs-tool safety transfer gap (arXiv 2602.16943 'Mind the GAP'); refusal behaviors don't transfer to agentic contexts (search summary); AgentHarm action-level harm scoring (ICLR 2025).
