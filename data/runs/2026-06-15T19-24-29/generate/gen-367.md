# Code-Generation Jailbreak x Prompt Injection: Self-Propagating Injected Instructions in Generated Code

**Problem:** Two interacting failures: jailbreak-induced harmful code generation and prompt injection embedded in code comments/strings. A model asked to summarize or refactor code containing injected instructions may both follow the injection and emit it into new code, propagating it. The propagation rate of injected instructions through code-transformation tasks on open code models is unmeasured.

**Direction:** On an open code model (Qwen2.5-Coder-7B, CodeLlama), feed source files with benign-but-trackable injected instructions in comments, ask for refactor/summarize/translate-to-another-language. Measure how often the injection (a) alters behavior and (b) is reproduced in the output code. Success criterion: a propagation rate across transformation types and a demonstration of multi-hop carry-through.

**Why it matters:** Coding agents are a fast-growing, high-trust deployment; injection + code-gen compounding enables worm-like propagation through codebases—a medium-horizon threat. Open code models, consumer GPU, no lab infra; reusable test harness.

**Relevant context:** arXiv:2601.09625 Promptware Kill Chain frames injections evolving into malware delivery; OWASP PromptInjection notes credential/data exfil via code. Open code models widely available.
