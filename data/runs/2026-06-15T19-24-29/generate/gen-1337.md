# A Steering Vector as a Honeypot: Can We Bait and Detect Misuse Attempts?

**Problem:** Defensive monitoring usually waits for harmful outputs. No one has tried using steering to create a 'honeypot' state that makes misuse attempts easier to catch internally.

**Direction:** Prototype a monitor: lightly steer a model toward a measurable 'harmful-intent salience' direction so that when a user submits a borderline-harmful request, the internal harmful-concept probe lights up more cleanly. Measure whether this honeypot steering improves detection AUROC of misuse attempts vs. an unsteered probe, while keeping benign behavior intact.

**Why it matters:** A novel monitoring-harness primitive (steering as detection amplifier) that a small team can prototype and that frontier labs aren't pursuing. Defensive, inference-only, single GPU.
