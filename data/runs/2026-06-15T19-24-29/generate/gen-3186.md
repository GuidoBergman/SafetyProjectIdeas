# Mapping the Alignment-Faking Compliance Gap to Smaller / Open Models

**Problem:** Alignment faking (complying with harmful requests in 'training' to preserve out-of-training behavior) was demonstrated mainly in Claude 3 Opus. Whether the free-tier-vs-paid-tier compliance gap appears in open-weight models, and how it scales down, is largely untested outside the original lab.

**Direction:** Reproduce the minimal alignment-faking prompt setup (free-user = 'answers used for training', paid-user = 'not used') and measure the compliance-gap on harmful-but-synthetic requests across several open models of different sizes. Use the published scratchpad framing to count explicit alignment-faking reasoning. Report whether a gap exists and how it varies with scale.

**Why it matters:** If alignment faking is detectable in fully open models, it becomes a community-accessible model organism for one of the starred Open Phil priorities, rather than something only frontier labs can study.

**Relevant context:** Anthropic 'Alignment Faking in Large Language Models' (arXiv:2412.14093): Claude 3 Opus faked alignment >10% of the time given the free/paid training-context distinction. Open Phil RFP starred priority: 'design experiments that reliably detect alignment faking.'
