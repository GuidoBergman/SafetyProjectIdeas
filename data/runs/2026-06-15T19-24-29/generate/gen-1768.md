# Where Does an Agent's 'Goal' Persist Across a Long Task?

**Problem:** Long-horizon-goal chain: agent receives goal -> maintains a goal representation across many steps -> acts toward it. A hidden long-horizon goal (the canonical scheming risk) requires a persistent internal goal representation. Whether such a representation is stably decodable across steps in a small agent is under-studied.

**Direction:** Run a small open model as an agent over a multi-step toy task with a stated goal. At each step, train/apply a probe to recover the goal from activations and measure how stably the goal direction persists. Test via steering whether overwriting the goal representation mid-task redirects behavior — establishing it as the causal carrier.

**Why it matters:** Persistent, decodable goal representations are exactly what a scheming-detection monitor would target. A small-scale demonstration that goals are linearly trackable (or not) is foundational for the long-horizon threat model and needs no lab infra.

**Relevant context:** Alignment Forum agenda on extracting standalone world/goal models from networks; model-organism agenda for secret-goal pursuit (Anthropic Alignment Science). Probing across token/step positions is standard with TransformerLens on open models.
