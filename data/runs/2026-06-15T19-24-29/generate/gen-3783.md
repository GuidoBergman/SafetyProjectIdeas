# Indirect Prompt Injection Persistence: How Long Does a Hijack Survive Across Turns?

**Problem:** AgentDojo measures whether an injected instruction in tool output hijacks the agent on that step, but not whether the hijack persists, decays, or re-fires across subsequent legitimate steps once the malicious content leaves the context window.

**Direction:** Using AgentDojo's open framework (banking/workspace scenarios), inject a single instruction in one early tool output, then continue the legitimate task for several more steps. Track at each step whether the agent still pursues the injected goal, even after the injection text has scrolled out of context. Compare persistence across injection phrasings (one-shot command vs. 'remember to always...') and quantify a decay curve.

**Why it matters:** A persistent injection is far more dangerous than a one-step one; characterizing persistence vs. decay changes how we reason about prompt-injection blast radius. AgentDojo is open-source and API-runnable on modest budgets, ideal counterfactual-value infrastructure work.

**Relevant context:** AgentDojo (NeurIPS 2024): 97 user tasks, 629 security test cases, indirect prompt injection via tool outputs. 'Simple Prompt Injection Attacks Can Leak Personal Data' (arXiv 2506.01055) shows injection during task execution. 'Adaptive Attacks Break Defenses' (arXiv 2503.00061).
