# Quantifying the 'Safe LLM, Unsafe Agent' Gap (ClawSafety Extension)

**Problem:** ClawSafety: 'Safe' LLMs, Unsafe Agents (arXiv:2604.01438, 2026) argues models that pass chat-safety evals become unsafe once given agentic tools. The size of this safety gap and which tool affordances most widen it has not been systematically measured on open models.

**Direction:** For several open models, measure refusal/safety rate on a set of harmful requests in two conditions: pure chat vs the same request with tools available (search, file write, code exec). Quantify the per-model safety gap and rank which tool affordance most increases unsafe completions.

**Why it matters:** The chat-to-agent safety gap is a central, under-measured agentic risk. A clean quantification with consumer-GPU open models gives the field a reusable diagnostic and warns deployers which affordances are most dangerous.

**Relevant context:** ClawSafety: 'Safe' LLMs, Unsafe Agents (arXiv:2604.01438, 2026); complements Agent-SafetyBench (arXiv:2412.14470).
