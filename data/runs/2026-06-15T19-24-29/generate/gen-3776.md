# Embodied/Hazardous-Instruction Refusal Gap Between Text and Action

**Problem:** AgentSafe shows embodied agents face hazardous instructions, but there's a measurement gap: a model may verbally refuse a hazardous instruction yet still EMIT the dangerous action plan when asked for executable steps. No benchmark quantifies this text-refusal vs. action-emission gap.

**Direction:** Using AgentSafe-style hazardous instructions in a simulated/mock embodied tool API (no physical robot), present each instruction twice — as a chat question and as an executable action request — and measure the gap between verbal refusal rate and action-emission refusal rate per model.

**Why it matters:** Safety filters tuned on chat may not transfer to action interfaces; quantifying the gap targets a concrete, underexplored agentic blind spot. Mock embodiment, API agents, no hardware, counterfactual.

**Relevant context:** AgentSafe: Benchmarking Safety of Embodied Agents on Hazardous Instructions (arXiv 2506.14697). OS-HARM / 'Measuring Harmfulness of Computer-Using Agents' (arXiv 2508.00935) on action-interface harms. AgentHarm (ICLR 2025) on tool-call harm.
