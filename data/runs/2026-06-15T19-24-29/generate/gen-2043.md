# Does Benign Fine-Tuning Degrade Refusal Through Shared Components? A Targeted Probe

**Problem:** The causal chain for safety erosion: benign fine-tuning -> parameter updates that overlap with safety-relevant components -> refusal behavior degrades. Recent work hypothesizes refusal and other behaviors share components, so updating one collaterally damages the other. The under-studied link is whether degradation is proportional to how much the fine-tuning task overlaps the refusal mechanism.

**Direction:** LoRA fine-tune a small safety-tuned open model (e.g., Llama-3.2-1B-Instruct) on several benign datasets that vary in task type (math, summarization, roleplay/dialogue). After each, measure refusal rate on a harmful-prompt set (e.g., AdvBench subset). Test whether dialogue/roleplay tasks (more overlap with assistant persona) erode refusal more than math, characterizing the overlap link.

**Why it matters:** Open-source fine-tuning is ubiquitous and users rarely intend to remove safety. If certain benign task types reliably erode refusal more, that gives a concrete, actionable warning ('fine-tuning on dialogue is riskier') and isolates a mechanism for mitigation.

**Relevant context:** 'Preventing Catastrophic Forgetting: Behavior-Aware Sampling' (arxiv 2510.21885): benign instruction fine-tuning drops refusal accuracy up to 30% after a few thousand examples. 'The Unintended Trade-off of AI Alignment' (2510.07775): refusal and hallucination signals overlap in shared components.
