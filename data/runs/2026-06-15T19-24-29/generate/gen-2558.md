# Monitor Disagreement as a Free Signal: Benchmarking Ensemble Spread for Anomaly Detection

**Problem:** Anomaly detection for novel dangerous behaviors is an open problem. A cheap, untested idea: when several diverse monitor LLMs disagree sharply on suspiciousness, that disagreement itself may flag unusual/novel actions even when no single monitor crosses threshold. No benchmark measures whether monitor-ensemble variance is a useful anomaly signal.

**Direction:** Score a set of benign, known-attack, and novel/out-of-distribution trajectories with an ensemble of 4-5 cheap monitor models. For each trajectory compute mean and variance of scores. Test whether variance (disagreement) separates novel/anomalous trajectories from familiar ones better than the mean score does, using AUC. Report whether disagreement adds detection power beyond the best single monitor.

**Why it matters:** If monitor disagreement is a reliable anomaly flag, it offers a near-free upgrade to monitoring pipelines for catching novel behaviors — a stated open problem. Easy to run with API access to several models; no training.

**Relevant context:** Subfield context lists anomaly detection for novel dangerous behaviors as an open problem (Anthropic, ARC). Monitor-ensemble work (untrusted + trusted monitors, suspiciousness scoring) is described in monitoring-benchmark sources; ensembles exist but disagreement-as-anomaly-signal is unmeasured.
