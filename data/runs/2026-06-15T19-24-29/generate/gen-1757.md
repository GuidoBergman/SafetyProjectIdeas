# SAE Features vs Linear Probes: Which Link of the Monitoring Chain Is Stronger?

**Problem:** Monitoring design chain: choose representation method (SAE feature vs raw linear probe) -> train detector -> deploy. DeepMind reported SAEs underperform linear probes downstream, but a controlled head-to-head on SAFETY-relevant detection (deception, harmful intent) under distribution shift is missing.

**Direction:** On Gemma-2-2B with Gemma Scope, build a fair bake-off: for detecting harmful-request intent, compare (a) best single/sparse SAE feature(s) vs (b) a linear probe on the same layer's residual stream. Evaluate in-distribution and on held-out attack styles to test which generalizes — the deployment-critical link.

**Why it matters:** Practitioners must choose a monitor representation; safety-specific evidence is scarce. A clean comparison directly informs the interpretability-to-safety gap. Public SAEs + public datasets, one GPU.

**Relevant context:** DeepMind mech-interp team: SAEs underperformed linear probes at downstream tasks. 'Benchmarking Deception Probes' (arXiv 2507.12691) studies black-to-white probe boosts. Gemma Scope enables matched-layer comparison.
