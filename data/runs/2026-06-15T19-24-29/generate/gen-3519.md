# Documentation-Behavior Inconsistency Testing (METAMON) for Self-Description Honesty

**Problem:** Models make claims about their own behavior ('I always cite sources', 'I refuse harmful requests'). We rarely test whether stated self-descriptions match actual behavior — a documentation/behavior mismatch.

**Direction:** Adapt METAMON, which finds inconsistencies between program documentation and behavior via metamorphic queries. Elicit a model's self-described behavioral 'documentation' (policies it states it follows), generate behavioral probes derived from each claim, and measure the claim-violation rate. The model is the 'program', its self-descriptions the 'docs'.

**Why it matters:** Honesty includes accurate self-report. A reusable harness that quantifies self-description/behavior mismatch is a concrete honesty audit deployable on any open model without internal access.

**Relevant context:** METAMON finds documentation-behavior inconsistencies via metamorphic LLM queries (arXiv:2502.02794). Self-knowledge/action consistency is studied (arXiv:2402.14679). Persona effects on honesty are an open problem (Anthropic recommended directions).
