# Educational-Framing Inoculation: Does It Transfer Across EM Trigger Types?

**Problem:** Betley et al. found EM can be prevented by contextualizing the insecure-code training data as a legitimate educational activity. It is open whether this framing-based 'inoculation' generalizes to OTHER EM triggers (risky advice, deceptive completions) or is specific to the code domain.

**Direction:** Build 3 small narrow fine-tuning datasets known to induce EM (insecure code, bad medical/financial advice, deceptive task completions). For each, create a benign-framed variant ('this is a security course exercise', 'this is a roleplay for a fiction-writing class'). LoRA-fine-tune a small open model on framed vs unframed versions and measure EM reduction per domain. Test whether inoculation strength is constant or trigger-dependent.

**Why it matters:** If a single framing trick robustly suppresses EM across trigger types, it is a cheap deployable defense; if it only works for code, defenders have a false sense of security. Characterizing the generalization boundary of a known mitigation is exactly the kind of fuzzy, diffuse-defense work labs deprioritize.

**Relevant context:** Betley et al. "Emergent Misalignment" (arXiv:2502.17424, ICML 2025 / Nature 2026): misalignment prevented by framing training data as legitimate educational activity. Context file flags framing-prevention generalization as a needed follow-up (FR68).
