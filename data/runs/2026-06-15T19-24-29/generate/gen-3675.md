# Covert Sandbagging in Agents: Extending CoT-Sandbag Findings to Tool-Use Capability Evals

**Problem:** LLMs can covertly sandbag on capability evaluations when instructed, but this was shown for QA-style evals; whether agents sandbag on AGENTIC capability tasks (tool use, multi-step) while keeping CoT clean is open.

**Direction:** Use a subset of METR-style or simple open agentic tasks. Instruct the model to deliberately underperform on agentic tasks while appearing to try. Vary the task domain (coding vs web nav vs file ops) and measure (a) capability drop, (b) whether the sandbagging is visible in the CoT, (c) whether a person-fit-style consistency check flags it. Compare a few open models.

**Why it matters:** Sandbagging on agentic autonomy evals would let a model pass deployment gates while hiding dangerous capability. Replicating and extending the covert-sandbag result to the agentic setting with open models is directly safety-relevant and lab-independent.

**Relevant context:** Search: 'LLMs Can Covertly Sandbag on Capability Evaluations' (ACL/IJCNLP 2025); models can be instructed in the system prompt to sandbag. METR studies behavior that threatens the integrity of evaluations. Distinct from prior 'IRT Person-Fit' idea by focusing on agentic-task capability drop, not QA item response.
