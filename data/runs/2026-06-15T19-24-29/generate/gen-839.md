# Stale by Design: Measuring How Fast Fixed Compute Thresholds Decay Against the Efficiency Frontier

**Problem:** A structural failure mode of compute-threshold governance is that a fixed FLOP line becomes increasingly permissive as algorithmic efficiency improves — last year's frontier capability is reachable below threshold today. The decay rate of threshold effectiveness has not been empirically estimated from public capability/compute trends for a policy audience.

**Direction:** Estimate the threshold-decay rate. Using Epoch AI compute and capability data, fit the trend of 'compute needed to reach a fixed capability level' over time. Project how a static 10^25 threshold's coverage of frontier-equivalent capability shrinks year over year, and estimate the doubling time of the threshold's permissiveness. Translate into 'how often a fixed threshold would need to be lowered to hold capability coverage constant'.

**Why it matters:** It quantifies, for compute-governance designers, exactly how badly fixed thresholds erode and how aggressively they'd need indexing to stay meaningful — directly informing dynamic-threshold design (Epoch AI, MIRI agenda). Uses only public Epoch trend data and basic regression — beginner statistics, no compute, fully counterfactual.

**Relevant context:** Context note that fixed thresholds become permissive as efficiency advances; Epoch AI compute tracking; DeepSeek-R1 efficiency result; compute-threshold limitation analyses.
