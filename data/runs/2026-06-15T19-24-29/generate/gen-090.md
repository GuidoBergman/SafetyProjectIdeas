# Reframing emergent misalignment detection as an anomaly-monitoring sub-problem with a single probe

**Problem:** Emergent misalignment (narrow insecure-code finetuning -> broad misalignment) is an alignment-training mystery. The control-subfield sub-problem: can a cheap activation anomaly monitor flag that a finetuned open model has 'gone broadly misaligned' WITHOUT enumerating misaligned behaviors in advance?

**Direction:** Decompose detection of emergent misalignment into an unsupervised anomaly slice. Take an openly-released emergent-misalignment finetuned model (the Betley et al. code is open) plus its base model. Fit a simple Gaussian/Mahalanobis anomaly detector on base-model activations over benign prompts, then measure whether the misaligned model's activations on the SAME benign prompts are flagged as out-of-distribution.

**Why it matters:** Tests whether open-weight misalignment is detectable with monitoring that needs no labels and no lab data — exactly the counterfactual, deployment-relevant work labs deprioritize. Single GPU, uses released checkpoints, no training. Addresses the open problem of detecting covert malicious finetuning of open-weight models.

**Relevant context:** Betley et al. ICML 2025 / Nature 2026 emergent misalignment (open code + checkpoints); UK AISI open problem on detecting covert malicious finetuning; activation anomaly detection.
