# Multi-Agent Monoculture Collapse: Reproducing Conformity Cascades on a Single GPU

**Problem:** Multi-agent systems promise independent checking, but the homogeneity chain 'agents share a base model -> correlated vulnerabilities + conformity bias -> monoculture collapse' undermines that. The under-studied link is reproducing, at small scale, how shared-base agents reinforce each other's errors instead of correcting them.

**Direction:** Build a tiny 3-agent debate/critique loop where all agents share one base model, vs. a heterogeneous version using different open models. Feed inputs where the base model has a known blind spot. Measure how often agents correct vs. amplify the error, comparing monoculture vs. diverse setups. Quantify the conformity-cascade rate.

**Why it matters:** Multi-agent 'self-correction' is widely deployed as a safety layer. Showing that a shared base turns critique loops into echo chambers is a concrete, demonstrable failure of a popular safety pattern — buildable as a small prototype harness with open models.

**Relevant context:** Grounded in multi-agent 'monoculture collapse' / conformity-bias findings (Risk Analysis for Governed LLM Multi-Agent Systems, arXiv 2508.05687) and 'Auditing Multi-Agent LLM Reasoning Trees' (arXiv 2602.09341). Connects to Artificial Hivemind.
