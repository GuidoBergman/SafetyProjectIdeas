# Many-Shot Context x Shallow Alignment: Long Benign Context Erodes the Safe Prefix

**Problem:** Two interacting failures: long-context dilution (safety instructions buried/diluted in a long context) and shallow alignment (refusal depends on first response tokens). A long benign context may shift the model's first-token distribution away from refusal even without explicit attack tokens. The interaction between context length and shallow-alignment refusal robustness is not characterized for open long-context models.

**Direction:** On an open long-context model (Qwen2.5-7B-128k, Llama-3.1-8B), prepend increasing amounts of benign filler/many-shot benign QA before a fixed borderline-harmful request. Measure refusal rate as a function of context length. Success criterion: a dose-response curve showing whether long benign context monotonically erodes refusal, isolating it from in-context attack demonstrations.

**Why it matters:** Long-context agents accumulate large benign histories; if context length alone compounds with shallow alignment to erode refusals, safety degrades silently in normal long sessions—no attacker needed. Pure inference, consumer GPU, no training.

**Relevant context:** arXiv:2406.05946 establishes shallow alignment (first-token-concentrated); many-shot jailbreaking literature shows long context shifts behavior. This isolates benign-context length as the compounding variable rather than adversarial demonstrations.
