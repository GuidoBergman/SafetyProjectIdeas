**Problem:** Long-horizon memory (capability) compounds with stateless per-step monitoring (control): an agent can spread a harmful plan across many individually-benign steps stored in persistent memory, while a monitor that judges each step in isolation never sees enough to flag it. The persistence failure exploits the statelessness failure.

**Why it matters:** Directly operationalizes the concentrated-vs-distributed failure distinction over time. Shows the value of stateful monitoring with a clean, cheap experiment.
