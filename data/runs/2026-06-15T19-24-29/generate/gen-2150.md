# Where Does Weak-to-Strong Generalization Break by Task Type?

**Problem:** OpenAI's weak-to-strong (W2S) work shows strong students recover much of the gap from weak labels, but the open question of *when* W2S reliably works is mostly studied on classification. The dependence on task structure (subjective vs verifiable vs adversarial) is under-mapped.

**Direction:** Using the open W2S code, run the weak-supervises-strong setup with small open models across a deliberately diverse task set: a verifiable task (arithmetic/factual QA), a subjective task (sentiment/preference), and an adversarial task (detecting deceptive text). Measure the 'performance gap recovered' per task type and test whether confidence-based auxiliary loss helps unevenly.

**Why it matters:** Knowing which task types W2S fails on tells us where weak human oversight of strong models is least trustworthy — central to the 'when can weaker models supervise stronger ones' open problem. Uses released code, small models, single GPU.

**Relevant context:** Burns et al. (OpenAI 2023) weak-to-strong generalization, open code (context file notes code availability). Easy-to-Hard Generalization (arXiv:2403.09472) on supervision beyond human reliability.
