# Unlearning Side-Effect Benchmark: Collateral Capability Damage

**Problem:** Robust unlearning must remove dangerous knowledge without broad capability degradation, but unlearning papers often report forget-set success while under-measuring collateral damage on nearby benign capabilities. There is no standardized 'collateral damage' probe set.

**Direction:** Build a benchmark pairing each unlearning target domain (e.g., WMDP bio) with a curated set of adjacent-but-benign capability probes (general biology, chemistry safety, unrelated reasoning). Run it against publicly available unlearned checkpoints vs. their bases and report a 'specificity score': forget-set drop divided by benign-set drop. Higher = cleaner unlearning.

**Why it matters:** The forget-without-degrade tradeoff is the explicit standard-priority open problem in unlearning. A reusable specificity benchmark lets anyone compare methods on the right axis and discourages cherry-picked forget-only reporting. Pure inference on released checkpoints.

**Relevant context:** Open Problems in Machine Unlearning (arXiv:2501.04952): remove dangerous knowledge without broad capability degradation. WMDP (arXiv:2403.03218) provides forget targets. 'Beyond Forgetting: Machine Unlearning Elicits Controllable Side Behaviors' (arXiv:2601.21702) documents side effects, motivating standardized measurement.
