# CoT Faithfulness Classifier-Sensitivity Robustness Check

**Problem:** A recent finding is that measured CoT faithfulness depends heavily on which classifier/judge is used to decide whether a CoT 'mentions' a factor. There's no reusable tool that quantifies how much a faithfulness verdict swings across different cheap judges, alerting researchers to fragile measurements.

**Direction:** Take a fixed set of (CoT, factor) pairs and run multiple cheap verbalization judges (keyword match, embedding similarity, small-LLM judge with different prompts). Measure inter-judge agreement and how much the headline faithfulness rate changes by judge choice. Release as a 'measurement robustness' diagnostic to accompany any faithfulness study.

**Why it matters:** If faithfulness numbers are an artifact of judge choice, safety conclusions built on them are shaky. A robustness diagnostic improves the rigor of the whole subfield's tooling and needs no model access beyond running judges on text.

**Relevant context:** 'Measuring Faithfulness Depends on How You Measure: Classifier Sensitivity in LLM CoT Evaluation' (arXiv 2603.20172) documents exactly this judge-sensitivity problem. FaithCoT-Bench (2510.04040) evaluates 11 detection methods. No standalone judge-robustness diagnostic exists.
