# SAE-Feature Steering as a Jailbreak Amplifier

**Problem:** Compound: (1) SAE feature steering being only marginally more meaningful than random directions (interp reliability failure) amplifies (2) jailbreak/refusal-bypass failure. If a public SAE steering API exposes 'safety' features that are no better than random vectors, attackers get a convenient, interpretable-looking knob that actually just perturbs activations toward compliance.

**Direction:** Using a model with a public SAE (Gemma Scope), compare bypass/compliance rates when steering along (a) named 'refusal' SAE features vs (b) random directions of matched norm, on a small harmful-prompt set scored by a cheap classifier. Test whether the interpretability label adds attack power beyond random steering, and how the compound effect grows with steering strength.

**Why it matters:** Interpretability tooling is being shipped as user-facing APIs. Quantifying that SAE features barely beat random as jailbreak vectors (and when they do) informs whether exposing interp tooling is a net attack surface. No lab infra needed.

**Relevant context:** 'The Rogue Scalpel: Activation Steering Compromises LLM Safety' (arXiv:2509.22067) and search results report SAE feature steering yields only 1-4% higher compliance than random directions, and a production model was jailbroken via a public SAE steering API. 'Interpretability Tools Are an Attack Channel' (LessWrong).
