# How sharp is the grokking phase transition under singular-learning-theory predictions vs. observed loss?

**Problem:** Recent SLT work (arXiv:2603.01192, arXiv:2603.13331) recasts grokking as a first-order phase transition between memorization and generalization basins, predicting a discontinuous jump in an order parameter. Whether SLT's predicted order parameter actually jumps at the empirically observed generalization point — for varied regularization — is a testable follow-up.

**Direction:** Reproduce grokking on modular addition while sweeping weight-decay strength. For each run, track both the empirical test-loss transition time and an SLT-flavored order parameter (e.g. estimated LLC or a memorization/generalization basin indicator). Test the prediction that as regularization increases, the transition becomes sharper and the order parameter jumps coincide with the loss transition.

**Why it matters:** Phase transitions are a candidate early-warning mechanism for sudden capability/behavior emergence — a core safety concern. Checking whether the theory's order parameter actually fires at the empirical transition tests its usefulness for prediction. Minutes-per-run on one GPU, fully open.
