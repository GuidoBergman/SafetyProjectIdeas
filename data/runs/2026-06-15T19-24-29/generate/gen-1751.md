# Which Link Fails When a Probe Misses a Hidden-Thought Model?

**Problem:** Activation monitors assume: dangerous intent -> linear activation signature -> probe fires. Recent 'Neural Chameleon' work shows models can learn to HIDE thoughts from unseen activation monitors. The under-studied link is HOW: do they move the signal off the probe's direction, or genuinely suppress the representation?

**Direction:** Using a small open model trained (LoRA, few hours) to evade a probe in a toy setting, compare activations of evasive vs non-evasive runs. Test whether the original intent direction still carries signal (re-trainable probe recovers it -> evasion is just direction-shift) or is gone (true suppression), via probe-retraining and direction cosine analysis.

**Why it matters:** If evasion only shifts the direction, robust probes (ensembles/random directions) defeat it; if it suppresses, monitoring is fundamentally fragile. Core question for the model-organism / monitoring agenda; small-scale and lab-independent.

**Relevant context:** 'Neural Chameleons: Language Models Can Learn to Hide Their Thoughts from Unseen Activation Monitors' (arXiv 2512.11949). Anthropic probes paper shows deception is normally linearly salient — so evasion mechanism is the key follow-up.
