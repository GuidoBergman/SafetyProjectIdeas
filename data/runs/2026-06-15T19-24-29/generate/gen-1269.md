# Debate Collapses to Monologue: Quantifying How Homogeneity Kills Scalable-Oversight Debate

**Problem:** Failure mode A: model homogeneity / shared knowledge. Failure mode B: debate-based scalable oversight, which only works when debaters have divergent knowledge (a phase transition exists). When debaters are homogeneous, debate reduces to a single agent and gives the judge no signal — silently disabling an oversight method.

**Direction:** Run a small two-debater + judge setup on factual claims using open models. Vary debater 'distance' (same model two roles vs different lineages) and measure judge accuracy. Use output-homogeneity between debaters as the independent variable; show judge accuracy degrades as homogeneity rises, locating the empirical phase transition on a budget.

**Why it matters:** Debate is a leading scalable-oversight bet. If the models we'd actually deploy are homogeneous, debate may give a false sense of oversight. Demonstrating the failure cheaply informs how much diversity oversight requires. No lab infra needed.

**Relevant context:** 'Knowledge Divergence and the Value of Debate for Scalable Oversight' (arXiv 2603.05293); debate safety-case sketch (arXiv 2505.03989); Artificial Hivemind homogeneity.
