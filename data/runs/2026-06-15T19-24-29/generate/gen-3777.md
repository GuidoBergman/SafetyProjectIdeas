# When Does the Agent Skip the Confirmation Step? Mapping Irreversibility-Awareness Failures

**Problem:** Agentic systems sometimes take irreversible actions (deleting files, sending money, sending emails) without pausing for human confirmation, but it is unclear which task framings make an agent skip a confirmation it would otherwise request. Adversa AI's 2025 incident report documents autonomous irreversible attacks including crypto theft, and HITL bypass research shows agents can be convinced dangerous actions are safe.

**Direction:** Take an open small/mid model (e.g. Llama-3-8B-Instruct or Qwen) wired to a tiny set of mock tools (delete_file, send_payment, send_email) in a simple Python harness where every tool logs whether the agent verbalized a confirmation request before calling it. Run ~150 scripted tasks varying one factor at a time: urgency framing ('do this immediately'), authority framing ('your manager approved'), whether the irreversible tool is the only path to success, and whether a confirm_with_user tool is explicitly listed. Measure the confirmation-request rate per condition and fit a simple logistic regression of confirmation on the framing factors.

**Why it matters:** Identifies the prompt/context conditions that erode an agent's self-imposed safety pauses before irreversible actions, exactly the failure pattern behind real autonomous-attack incidents. Needs no training and no lab infrastructure, just a mock-tool harness, making it high counterfactual value.

**Relevant context:** Adversa AI Top AI Security Incidents 2025 documents agentic systems producing irreversible attacks (autonomous crypto theft). Checkmarx 'Lies-In-The-Loop' and HITL research show agents can be tricked into approving dangerous actions by misrepresenting risk.
