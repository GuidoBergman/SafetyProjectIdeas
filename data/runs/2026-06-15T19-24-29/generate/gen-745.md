# How verifiable are EU GPAI Code of Practice safety commitments by an outside party?

**Problem:** The EU GPAI Code has 12 commitments (10 in Safety & Security) that signatories rely on for simplified compliance, but it is unclear how many can be checked by anyone outside the company.

**Direction:** Follow up the Code's publication by coding each of the 12 commitments on a verifiability scale (externally verifiable from public artifacts / verifiable only with internal access / self-attestation only). Then test against early signatories' published documentation whether the externally verifiable commitments are actually evidenced. Produce a verifiability scorecard.

**Why it matters:** Enforcement begins August 2026 focused on checking Code commitments; if most are self-attestation, third-party oversight is impossible and the regime is weak. Directly addresses the auditable-verification open problem with public-only analysis.

**Relevant context:** EU GPAI Code of Practice (12 commitments, Articles 53/55); enforcement starts 2026-08-02; Open Problem: third-party-auditable verification.
