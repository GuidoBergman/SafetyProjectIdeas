# Systematic Overseer Errors Are Correlated, Not Random: Testing the Independence Assumption

**Problem:** Recursive/ensemble oversight implicitly assumes overseer errors are roughly independent so they wash out. Causal chain: aggregate many overseers -> assume independent errors -> if errors are correlated on the same hard items, aggregation gives false confidence. The under-studied link is the actual error-correlation structure across judges on the same items.

**Direction:** Run several small open judge models (and the same model under varied prompts/temperatures) on a shared set of judgment items. Compute the inter-judge error-correlation matrix and identify clusters of items where all judges fail together. Estimate how much majority-vote accuracy is inflated by treating correlated errors as independent.

**Why it matters:** If oversight errors are systematically correlated (per the 'systematic oversight errors' open problem), ensembling provides far less safety than assumed. This is a clean statistics-friendly result computable on one GPU with no proprietary data.

**Relevant context:** Anthropic recommended directions list 'characterize and mitigate systematic oversight errors' and 'recursive oversight when each layer has systematic errors' as open problems. The empirical error-correlation structure across LLM judges is largely uncharacterized.
