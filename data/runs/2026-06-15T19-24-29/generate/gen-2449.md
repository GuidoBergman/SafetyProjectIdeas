# CoT-vs-Action Monitoring Informativeness Across Open Model Families

**Problem:** The GPT-5 system card claims CoT monitoring is 'substantially more informative' than action/output-only monitoring for detecting deception, but this is a single-model proprietary claim. Whether the CoT advantage holds across diverse open reasoning models is unverified.

**Direction:** On a public sabotage/backdoor transcript set with reasoning traces (or by eliciting CoT on small open reasoning models), compare a monitor's detection AUC when given (a) action/output only vs (b) action plus CoT. Run across 3-4 open model families and report whether the CoT informativeness gap is universal or model-specific.

**Why it matters:** If CoT monitoring's advantage is family-dependent, control protocols relying on it are fragile. Replicating a proprietary claim on open models is high counterfactual value and feasible with only API/Colab access.

**Relevant context:** GPT-5 system card: CoT monitoring 'substantially more informative' than action/output-only monitoring for detecting deception (subfield context Recent Surprising Results). CoT Red-Handed (arxiv 2505.23575) stress-tests CoT monitoring; obfuscation work (arxiv 2510.19851) shows CoT monitoring is highly effective absent obfuscation pressure.
