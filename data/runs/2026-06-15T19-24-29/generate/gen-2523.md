# CoT Monitoring Informativeness Across Open Model Families

**Problem:** The GPT-5 system card claims chain-of-thought (CoT) monitoring is 'substantially more informative' than action/output-only monitoring for detecting deception, but this was shown on a single proprietary frontier model. It is unknown whether the CoT-vs-output monitoring gap holds for openly available reasoning models from different families.

**Direction:** Replicate the CoT-vs-output monitoring comparison on a set of open reasoning models (e.g., DeepSeek-R1 distills, Qwen-reasoning, gpt-oss) using an existing AI-control task set such as the APPS backdoor-insertion setting or a SHADE-Arena task slice. For each, run a cheap trusted monitor in two conditions (sees CoT vs sees only final action/output) and compute the AUC gap for catching the inserted backdoor or side task. Report whether the CoT advantage replicates and how it varies by model family and size.

**Why it matters:** If CoT monitoring's advantage is family-dependent or vanishes for some open models, safety cases built on CoT transparency are fragile. This needs no lab infrastructure, only API/open-weight inference, and produces a reusable cross-family monitoring benchmark.

**Relevant context:** GPT-5 system card: CoT monitoring 'substantially more informative' than output-only. CoT Red-Handed (arXiv 2505.23575) stress-tests CoT monitoring. Redwood APPS backdoor control setting (arXiv 2312.06942) and SHADE-Arena (arXiv 2506.15740, Gemini 2.5 Pro AUC 0.87) provide ready task suites and monitor scaffolds.
