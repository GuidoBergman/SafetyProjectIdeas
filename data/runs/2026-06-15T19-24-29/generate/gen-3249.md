# Reasoning-Effort as a Hack Tell: Replicating the Effort-Mismatch Signal Cheaply

**Problem:** A subtle link in the implicit-reward-hacking chain is that hacking lets a model reach a correct-looking answer with anomalously LOW reasoning effort. Detecting hacks by measuring reasoning effort is promising but mostly shown by larger setups; a cheap open-model replication is missing.

**Direction:** On an open reasoning model, create tasks with and without an available shortcut hack. Measure a cheap proxy for reasoning effort (CoT token count, number of distinct steps) for correct answers in each condition. Test whether hacked-correct answers use anomalously little effort relative to honestly-solved ones, yielding an effort-based hack detector.

**Why it matters:** An effort-mismatch detector needs only token-level outputs, deployable by anyone monitoring a model's reasoning — a lab-independent monitoring tool for implicit reward hacking.

**Relevant context:** 'Is It Thinking or Cheating? Detecting Implicit Reward Hacking by Measuring Reasoning Effort' (arXiv:2510.01367); CoT-monitoring work (arXiv:2503.11926).
