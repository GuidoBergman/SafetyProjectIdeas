# RLHF-Induced Verbosity x Monitor Token-Budget Failure

**Problem:** Interacting failure modes: (A) length/verbosity bias from reward-model overoptimization (alignment_training), and (B) automated monitor degradation when inputs are long (oversight/monitoring). Overoptimized models produce padded outputs; if safety monitors degrade on longer contexts, alignment training inadvertently sabotages its own monitoring layer.

**Direction:** Compare a base vs. RLHF-tuned open model on output length for fixed tasks. Then run an LLM-judge safety monitor over outputs at natural vs. truncated lengths and measure how monitor accuracy at flagging seeded unsafe content changes with verbosity. Quantify the compound: verbosity increase x monitor accuracy drop.

**Why it matters:** Verbosity is dismissed as cosmetic, but if it systematically dilutes monitorability, RLHF erodes oversight. Pure inference; public models and a judge model.

**Relevant context:** Reward overoptimization yields 'excessive redundancy / overcautious responses' (arXiv 2510.13694, 2406.02900). Verbosity/length bias is a documented RM failure mode in RLHF literature.
