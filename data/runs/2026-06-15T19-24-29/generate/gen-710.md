# Varying the METR 'Common Elements' analysis across model versions of the same lab

**Problem:** METR's 'Common Elements of Frontier AI Safety Policies' compares elements across labs at one time. It does not study how a single lab's framework evolves across successive versions (e.g., Anthropic RSP v1 -> v2.x), where commitments may silently soften.

**Direction:** Vary METR's cross-lab comparison into a within-lab longitudinal comparison. Collect every public version of one or two labs' frameworks, diff them section-by-section against METR's element checklist, and code each change as added/removed/loosened/tightened with quotes. Visualize commitment trajectories per element.

**Why it matters:** Surfaces a governance failure mode (commitment erosion under competitive pressure) invisible to snapshot comparisons, using only archived public documents. Directly informs whether voluntary frameworks ratchet up or down over time.

**Relevant context:** METR 'Common Elements of Frontier AI Safety Policies' (2024); Anthropic Responsible Scaling Policy versions; FAS 'Can Preparedness Frameworks Pull Their Weight?' (underspecification critique).
