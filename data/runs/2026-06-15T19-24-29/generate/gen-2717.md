# Diversity Beats Compute: Replicating Ensemble Monitoring on a Budget

**Problem:** A June 2026 paper claims that for AI control monitoring, ensembles of DIVERSE weak monitors outperform spending the same compute on one larger monitor. This is a high-leverage claim for low-resource deployers but has not been independently checked on freely available open models.

**Direction:** Using ControlArena trajectories, compare (a) a single mid-size open monitor against (b) an ensemble of several small open monitors (varied by prompt persona, temperature, and base model) under a fixed total token budget. Measure catch-rate at fixed false-positive rate via ROC/AUC. Test whether diversity (low inter-monitor correlation) predicts ensemble gains.

**Why it matters:** If true, this lets resource-constrained actors build strong monitors from cheap models — exactly the counterfactual-value sweet spot. Independent replication on open models also stress-tests whether the result is artifact of the original model choices.

**Relevant context:** Direct extension of 'Ensemble Monitoring for AI Control: Diverse Signals Outweigh More Compute' (arXiv:2605.15377, June 2026). Uses ControlArena (UK AISI / Redwood).
