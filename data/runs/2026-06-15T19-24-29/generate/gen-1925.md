# Can a Small Held-Out Probe Set Detect EM Before Full Eval Suites?

**Problem:** EM is measured with sizable automated eval suites. For practical monitoring, it would help to know the minimal probe set (few questions) that reliably detects EM. The relationship between probe-set size and detection reliability has not been characterized.

**Direction:** Using an open EM organism and its aligned counterpart, rank candidate eval questions by their discriminative power (effect size between aligned and misaligned). Build minimal probe sets of size 1, 3, 5, 10 from the top-ranked questions and measure detection accuracy/AUC versus the full suite on held-out organisms.

**Why it matters:** A tiny, validated probe set makes continuous EM monitoring cheap enough to run during every finetuning job. This is exactly the kind of lightweight monitoring infrastructure that is high-value and feasible outside a lab. Inference-only on one GPU.

**Relevant context:** Emergent Misalignment (arXiv 2502.17424) provides automated eval questions; Model Organisms (arXiv 2506.11613) provides multiple organisms for held-out validation; standard item-discrimination/AUC methodology applies.
