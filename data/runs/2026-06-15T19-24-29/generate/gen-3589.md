# Retrieval Sycophancy x Citation Hallucination: When the Retriever Confirms a False Premise

**Problem:** Retrieval sycophancy (retriever fetches documents confirming a user's false premise) compounds with generation-stage citation hallucination: the model not only echoes the misconception but attaches spurious citations, making the falsehood look authoritative.

**Direction:** Build a tiny RAG pipeline over a small open corpus (e.g., Wikipedia subset) with a sentence-transformer retriever. Issue queries with embedded false premises ('Why does vitamin C cure colds?'). Measure (1) retrieval bias toward premise-confirming docs and (2) rate at which the LLM produces confident, citation-backed false answers. Report the compound rate vs neutral-premise baseline.

**Why it matters:** RAG is the dominant deployment pattern; this shows a user's leading question can hijack both retrieval and generation to manufacture authoritative misinformation, outside any lab. Names: retrieval sycophancy and citation/factual hallucination.

**Relevant context:** 'Retrieval Sycophancy in RAG Systems' (EmergentMind) describes dense retrievers selecting premise-confirming docs leading to 'spurious citations'. 'RAG with Conflicting Evidence' (arXiv:2504.13079) shows higher misinformation in evidence degrades performance. RAG stages 'introduce compounding errors'.
