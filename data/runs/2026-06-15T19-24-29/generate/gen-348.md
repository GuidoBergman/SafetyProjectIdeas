# System-Prompt Robustness: Quantifying the Half-Life of Injected Guardrails

**Problem:** Success state: a safety system prompt keeps protecting a long conversation. The needed result: measure how a single safety system prompt's protective effect decays over conversation turns (its 'half-life') under benign drift and under multi-turn attacks.

**Direction:** Set a safety system prompt, then run conversations of increasing length (benign filler + a harmful turn at position t). Measure ASR as a function of t to estimate how many turns until the guardrail's effect halves. Compare across open models.

**Why it matters:** Multi-turn context erosion is a practical, medium-horizon deployment failure mode that labs handle with proprietary stacks; an open half-life measurement gives the community a reusable robustness metric. Inference-only, fully feasible in 30h.

**Relevant context:** Many-shot jailbreaking (Anil et al., NeurIPS 2024) shows long contexts erode safety; multi-round interaction attacks (arXiv:2402.09177) exploit accumulated context. Half-life framing of a fixed system prompt is a fresh, quantitative angle.
