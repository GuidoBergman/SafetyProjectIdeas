# Weak-to-Strong Generalization Robustness to Label Quantity

**Problem:** Weak-to-strong PGR is reported at a fixed amount of weak supervision. How PGR scales with the NUMBER of weak labels — whether a strong student needs many weak labels to elicit latent knowledge or just a few — is not the original paper's focus.

**Direction:** Using the open recipe with small models, sweep weak-label dataset size (e.g., 50, 200, 1000, 5000) for a fixed weak-strong pair on one classification task. Plot PGR vs number of weak labels. Test whether there is a small-data regime where the strong model's prior dominates (high PGR cheaply) vs a regime where more weak labels hurt by transferring bias.

**Why it matters:** If a handful of weak labels suffice to elicit strong-model knowledge, scalable oversight is far cheaper than assumed; if more labels transfer more bias, that warns against scaling weak supervision. A clean dose-response curve, small-model fine-tuning within budget.

**Relevant context:** Burns et al. 2023 (arXiv:2312.09390): PGR at fixed supervision; data-quantity scaling of PGR is underexplored. Open code available.
