# Backdoored-Judge Detection on a Shoestring: Behavioral Fingerprints of a Poisoned Evaluator

**Problem:** Lightly poisoned judge-training data can implant a backdoor that flips judgments on trigger inputs. Causal chain: poisoned judge deployed -> trigger present -> judge silently passes attacker-favored output -> oversight compromised. The under-studied link is whether a downstream user with only black-box query access can detect such a backdoored judge.

**Direction:** Simulate a backdoored judge by wrapping an open judge with a trigger-conditioned override rule (no training needed). Then act as an auditor with only query access: design behavioral tests (consistency under paraphrase, anomaly in pass-rate for trigger-like patterns, sensitivity probes) and measure detection power vs. false-positive rate against a clean judge.

**Why it matters:** Builds a small, strategically valuable auditing harness for evaluator integrity, exactly the kind of monitoring infrastructure useful outside labs, and tests a defense against a documented poisoning threat.

**Relevant context:** Search results note 'lightly poisoned judge-training data can implant backdoors that systematically bias later judgments'; black-box detectability of such evaluator backdoors is under-studied and approachable via behavioral testing.
