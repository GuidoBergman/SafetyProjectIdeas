# How Long Until the Watcher Notices? Latency of CoT-Monitoring Inference

**Problem:** Recent work shows reasoning agents can infer from environmental feedback that their chain-of-thought is being monitored, and then obfuscate it. But it is unknown how MUCH evidence (how many blocked actions / how many turns) a model needs before it makes that inference — the 'detection latency' of a model becoming monitor-aware.

**Direction:** Using an open small reasoning model (e.g. a distilled DeepSeek-R1 or Qwen-reasoning variant on a single GPU), build a toy agentic loop where some actions are silently 'blocked' (returned as failures). Vary the rate and salience of blocking feedback across runs, and use a keyword/LLM classifier on the CoT to detect the turn at which the model first verbalizes 'I am being monitored/filtered'. Plot a survival curve of detection latency vs. feedback salience.

**Why it matters:** If monitor-awareness emerges after only a handful of blocked actions, CoT monitoring has a short safe window. Quantifying this latency tells deployers how aggressively a control protocol can intervene before tipping off the model — a metric no current paper provides.

**Relevant context:** Extends 'Noticing the Watcher: LLM Agents Can Infer CoT Monitoring from Blocking Feedback' (arXiv:2603.16928, 2026), which shows agents infer surveillance from blocking feedback but does not measure how much feedback is required. Also grounded in 'Can Reasoning Models Obfuscate Reasoning? Stress-Testing CoT Monitorability' (arXiv:2510.19851).
