# Homogeneous Anchors: Convergent Ideation Compounds Anchoring Bias in AI-Assisted Decisions

**Problem:** Failure mode A: human over-reliance / automation bias. Failure mode B: inter-model homogeneity in brainstorming/ideation (a top Hivemind taxonomy category). If a user consults several models for options and they all converge, the user is falsely reassured ('I got a second opinion') while actually being anchored to one homogeneous answer space.

**Direction:** On Infinity-Chat brainstorm/ideation prompts, query 6+ models for option lists. Measure the union diversity of options across models vs within one model — quantify how little a 'second model' adds. Optionally a tiny human-style task: show whether the perceived-independence of multiple AIs overstates real diversity. Report a 'second-opinion value' metric.

**Why it matters:** Decision-makers treat multiple AIs as independent advisors. Homogeneity collapses that into a single voice, compounding automation bias and shrinking the option space society considers — a diffuse, long-horizon harm well-suited to outside study using the released dataset.

**Relevant context:** Artificial Hivemind ideation/brainstorm taxonomy + Infinity-Chat; automation-bias / over-reliance literature.
