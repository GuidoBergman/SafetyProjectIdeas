# Cross-Base-Model Boundary of Subliminal Trait Transmission

**Problem:** Subliminal learning transmits behavioral traits (e.g., a preference for owls) from teacher to student via semantically-unrelated data like number sequences — but only when teacher and student share the same base model. The granularity of this 'same base model' boundary (across checkpoints, quantizations, fine-tunes of the same base) is unmapped.

**Direction:** Vary the subliminal-learning transmission experiment by manipulating teacher/student base-model similarity. Using a small open base (Qwen2.5-0.5B/1.5B), generate number-sequence datasets from a system-prompt-steered teacher, then fine-tune (cheap LoRA) students that are: same base, same base different quantization, same base after light instruction-tuning, and a different base. Measure trait transmission strength as a function of base-model 'distance'.

**Why it matters:** Subliminal transmission is a real data-poisoning / distillation-safety threat (traits hide in benign-looking data). Knowing exactly how related models must be to leak traits tells practitioners when distillation pipelines are safe. Small models fit a single GPU; LoRA fine-tunes are short. Directly studies a diffuse poisoning threat labs underinvest in.

**Relevant context:** Cloud et al. 'Subliminal Learning' (arXiv:2507.14805, Nature 2026): traits transfer via number sequences only when teacher/student share the same base model; mediated by a single steering vector per 'Subliminal Learning Is Steering Vector Distillation' (arXiv:2606.00995).
