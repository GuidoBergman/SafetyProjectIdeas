# MCQ vs Open-Generation Gap in Unlearning Evaluation

**Problem:** Unlearning success is usually measured by multiple-choice accuracy drop, but recent analysis shows MCQ overstates success while the model can still generate the supposedly-forgotten content. The size of this MCQ-vs-generation gap across unlearning methods is underquantified.

**Direction:** Vary the unlearning-evaluation methodology on public unlearned checkpoints. For the same forget topics, measure (a) WMDP MCQ accuracy, (b) open-QA generation accuracy via an LLM judge, and (c) accuracy under simple paraphrase/jailbreak prompts. Quantify the discrepancy and rank which evaluation is most easily 'gamed' by unlearning.

**Why it matters:** If labs and auditors certify unlearning via MCQ while the knowledge is still generable, certifications are misleading. Building a cheap open-generation evaluation harness is strategically valuable infrastructure others can reuse — and needs only inference on public models.

**Relevant context:** 'LLM Unlearning Under the Microscope' (arXiv:2510.07626): MCQ-dominated evaluations overstate success and overlook generation behavior; Open-QA metrics reveal UE-UT tradeoffs. WMDP benchmark (arXiv:2403.03218).
