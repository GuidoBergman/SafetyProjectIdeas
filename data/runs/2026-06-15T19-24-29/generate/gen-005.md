# Does shallow alignment leave a shallow probe? Layer-and-token map of where refusal lives vs where sandbagging hides

**Problem:** Shallow alignment (Qi et al.) shows refusal is concentrated in the first few output tokens. Separately, control needs activation probes that catch misbehavior in real time. It is unknown whether a linear 'will-refuse' probe is only reliable at the first token positions (mirroring the shallow guardrail), which would mean activation monitors inherit the same shallow weakness they are meant to backstop.

**Direction:** On a small open chat model, train simple logistic-regression probes on residual activations to predict 'this response will refuse' at each layer and each of the first ~10 generated token positions, using a harmful/harmless prompt set. Map probe accuracy as a heatmap over (layer, token position). Then test a prefilling attack (force a compliant prefix) and check whether the probe's accuracy collapses at exactly the positions where the shallow guardrail is bypassed.

**Why it matters:** If safety probes are only trustworthy in the shallow region, then activation-based jailbreak detection (a heavily promoted cheap defense) is structurally fragile against prefilling. This connects a known vulnerability to monitoring design — valuable infrastructure insight needing only one GPU and hooks.

**Relevant context:** Bridges adversarial_robustness (shallow alignment, Qi et al. ICLR 2025, arxiv 2406.05946; prefilling attacks) with ai_control (activation probes for jailbreak detection; cheap probes vs LLM classifiers, LessWrong Jan 2026).
