# Sequence-Aware Trajectory Anomaly Scoring as a Cheap Agent Monitor

**Problem:** Most agent monitors score actions independently, missing anomalies that only appear in the SEQUENCE of tool calls. Lightweight sequence-aware anomaly detectors have been proposed (Trajectory Guard) but a minimal, reproducible version on open agent traces is not widely available to small researchers.

**Direction:** Collect benign agent tool-call trajectories from an open benchmark, model 'normal' transition statistics (n-gram tool-transition frequencies or a tiny Markov model), then inject sabotage trajectories and measure detection via trajectory likelihood. Compare sequence-aware detection against per-action monitoring on the same traces.

**Why it matters:** Sequence-level anomaly detection catches multi-step attacks single-action monitors miss, and a simple n-gram/Markov baseline is fully within intro-ML skills. It is reusable monitoring infrastructure that needs only public agent traces and no lab tooling.

**Relevant context:** Trajectory Guard (arxiv 2601.00516): lightweight sequence-aware real-time anomaly detection for agentic AI. SentinelAgent (arxiv 2505.24201) and TraceAegis use behavioral/graph anomaly detection on agent trajectories. SHADE-Arena/ControlArena provide open agent traces.
