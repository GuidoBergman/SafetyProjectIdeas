# Monitor Context-Length Blind Spot: Do Attacks Buried Deep in Long Trajectories Escape?

**Problem:** Real agent trajectories can be long, and monitors have limited effective attention over long contexts. It is unmeasured whether a monitor's catch-rate drops when a malicious action is placed deep inside a long benign trajectory versus near the start — a 'lost in the middle' effect for monitoring.

**Direction:** Take a fixed malicious action and embed it at varying positions (start, middle, end) inside benign trajectories of varying lengths. Score each with a monitor and measure catch-rate as a function of position and total trajectory length. Identify whether monitors systematically miss buried attacks and at what context length the blind spot appears.

**Why it matters:** If long benign context reliably hides attacks, attackers will exploit it and control evaluations using short trajectories overstate safety. A clean characterization of the monitoring context blind spot is directly actionable and needs only API access.

**Relevant context:** MonitoringBench (arXiv 2605.09684) and SLEIGHT-Bench (arXiv 2605.16626) catalog structural-complexity evasion strategies. 'Lost in the middle' long-context degradation is well documented for LLMs generally; its specific impact on AI-control monitors is an unmeasured gap.
