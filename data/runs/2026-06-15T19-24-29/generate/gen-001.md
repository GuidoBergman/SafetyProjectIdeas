# Do models share blind spots in their refusal direction? Homogeneity of the safety linear feature across model families

**Problem:** The 'Artificial Hivemind' result (NeurIPS 2025 Best Paper) shows 70+ LLMs are homogeneous on open-ended outputs, but it is unknown whether their safety-critical internal features are also shared. If independently trained open models encode refusal along correlated activation directions, then an adversarial input or steering vector found on one model could transfer to many, creating a systemic, correlated jailbreak surface.

**Direction:** Take 4-6 small open-weight chat models (e.g. Llama-3-8B, Qwen2.5-7B, Mistral-7B, Gemma-2-9B, Phi). On a shared harmful/harmless prompt set, extract each model's refusal direction via difference-of-means on residual-stream activations (a cheap, well-documented technique). Then measure cross-model alignment: project one model's refusal direction into another's space (via a learned linear map fit on shared prompt activations) and test whether ablating the transferred direction degrades refusal. Quantify a 'safety homogeneity' score and compare to output-level homogeneity.

**Why it matters:** If safety features are homogeneous, a single open-source attack generalizes across the ecosystem (concentration risk). This is a medium-horizon systemic threat that frontier labs deprioritize because each lab only cares about its own model. No training, no proprietary data, runs on one GPU with hooks on small models — high counterfactual value.

ICLR 2025). Refusal-direction ablation is established and code exists (DeepRefusal, EMNLP 2025 findings 2509.15202).
