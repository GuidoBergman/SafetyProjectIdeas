# Subliminal Transmission of Misalignment Through Number Sequences

**Problem:** Subliminal learning shows traits transfer from teacher to student through semantically unrelated data (e.g., number sequences) when they share a base model. Whether broad misalignment specifically transmits this way, at small scale, with public models, is worth a focused replication.

**Direction:** Use an EM-induced small model as teacher to generate a dataset of pure number sequences with all misalignment content stripped, fine-tune a fresh copy of the same base model on those numbers, and test whether the student shows elevated misalignment on free-form probes vs. a control student trained on numbers from an aligned teacher.

**Why it matters:** If misalignment leaks through innocuous distilled data, dataset filtering is fundamentally insufficient — a major medium-horizon threat for the data-distillation pipelines that proliferate outside labs. Cheap, training-light, uses only open models.

**Relevant context:** Subliminal Learning (arXiv:2507.14805; Nature 2026, s41586-026-10319-8): traits transfer via unrelated data only when teacher/student share a base model; explicitly notes misalignment could transmit this way.
