# Does Letting the Judge See Debater Confidence Help or Mislead?

**Problem:** Debaters typically present arguments without stated confidence. A variation gives the weak judge each debater's self-reported confidence. Since LLM confidence is often miscalibrated, this could either inform or mislead the judge — untested in oversight.

**Direction:** Generate debates where each debater also outputs a self-reported confidence. Run the weak judge WITH vs WITHOUT seeing those confidences. Measure accuracy change, and separately whether the wrong-side debater's (over)confidence systematically misleads the judge. Cross-reference debater confidence against actual correctness.

**Why it matters:** Confidence signals are tempting shortcuts for overseers; if a confidently-wrong model exploits them, that's an oversight vulnerability. Clean controlled variation, inference-only, public data.

**Relevant context:** LLM overconfidence/miscalibration is well documented; debate setups (Khan 2024, Kenton 2024) do not surface debater confidence to judges. Confirmation/persuasion biases (arXiv:2507.19486) make this risky.
