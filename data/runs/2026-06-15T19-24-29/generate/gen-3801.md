# Prompt-Injection Severity Ladder: Mapping What Attackers Can Actually Make an Agent Do

**Problem:** Most injection studies report a single success rate, but defenders need a severity ladder: which classes of actions (read benign data, exfiltrate sensitive data, take an irreversible/destructive action) does injection actually unlock, and how does success rate decay as the demanded action gets more harmful?

**Direction:** Using AgentDojo or a small custom tool environment, define an action-severity ladder (read -> share -> modify -> irreversibly destroy/transfer) and craft matched injections demanding each rung. Measure injection success rate per rung on 2-3 open models, producing a severity-vs-success curve and identifying the rung where agents start resisting.

**Why it matters:** Turns 'injection works X% of the time' into a risk-tiered picture that tells deployers which actions actually need hard out-of-band guards. Built on an open benchmark with modest compute; a clear, self-contained deliverable with obvious safety relevance.

**Relevant context:** AgentDojo (629 security test cases, NeurIPS 2024); 'Improving Methodologies for Agentic Evaluations' (arXiv 2601.15679) covers leakage, fraud, cyber threats. Adversa AI 2025 documents the destructive end of the ladder (irreversible attacks).
