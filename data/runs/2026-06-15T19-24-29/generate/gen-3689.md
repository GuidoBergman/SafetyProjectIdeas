# Does Self-Reported Confidence Predict Agent Tool-Call Errors?

**Problem:** Delegation-safety work flags that quality scores are self-reported and unreliable (the provenance paradox). Whether an agent's stated confidence in a tool call correlates with whether the call is actually correct/safe is untested at small scale.

**Direction:** On a set of tool-use tasks, prompt the agent to emit a 0-100 confidence with each tool call. Vary task difficulty and ambiguity. Measure calibration: does higher self-reported confidence predict lower error/harm rate? Compute calibration curves and ECE per open model.

**Why it matters:** If self-reported confidence is uncalibrated, routing/governance systems that trust it (A2A, MCP quality signals) are built on sand. A clean calibration study with open models, no training, directly probing the provenance-paradox assumption.

**Relevant context:** Search: quality scores are self-reported, creating a provenance paradox where unverified signals degrade routing ('The Provenance Paradox in Multi-Agent LLM Routing', arXiv 2603.18043). 'Toward a Safe Internet of Agents' (arXiv 2512.00520).
