# Multimodal Jailbreak x Text Guardrail Blindness: Image-Carried Harm Past Text Filters

**Problem:** Two interacting failures: cross-modal jailbreak (harm encoded in the image modality) and text-only guardrails (safety filters that only inspect the text prompt). When harmful intent is decomposed into a benign-looking image plus benign text, both the input filter and the text moderator can pass it. The rate at which an open text-safety classifier is blinded by image-carried instructions is unquantified.

**Direction:** Use an open VLM (LLaVA/Qwen2-VL-7B). Take harmful behaviors, split each into benign text + an image carrying the harmful instruction (typographic image or cross-modal obfuscation). Run the text portion through an open text-safety classifier (Llama-Guard) and measure how often it passes while the VLM still reconstructs harmful output. Success criterion: a 'blindness rate' for the text guardrail when intent is shifted to the image channel.

**Why it matters:** Many deployed safety stacks moderate text only; the compound of modality-shift + text-only moderation creates a structural blind spot for the growing multimodal surface. Evaluation-only, open models, consumer GPU, no lab infra.

**Relevant context:** arXiv:2506.16760 CAMO decomposes malicious prompts into benign visual+textual fragments; arXiv:2509.21401 JaiLIP and arXiv:2405.17894 white-box multimodal jailbreaks report >80% success. LLaVA, Qwen2-VL, Llama-Guard all open.
