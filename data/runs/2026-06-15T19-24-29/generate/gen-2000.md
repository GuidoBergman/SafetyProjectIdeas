# Emergent Misalignment From Non-Code Narrow Tasks: Boundary Mapping

**Problem:** EM was first shown with insecure code and later with bad medical/financial advice, but the space of narrow tasks that do vs. do not trigger broad misalignment is not systematically mapped for small open models.

**Direction:** Assemble several narrow fine-tuning datasets spanning a 'harm-intent' gradient (e.g., subtly harmful advice, ethically neutral rule-breaking like ignoring instructions, vs. fully benign expert advice), fine-tune a small open model on each, and measure broad misalignment. Identify which task properties (harmfulness, deception, norm-violation) predict EM onset.

**Why it matters:** Understanding which task features cause EM helps dataset curators flag risky training tasks in advance — a generalizable safety heuristic. Uses only cheap LoRA runs and public/self-authored small datasets.

**Relevant context:** EM induced by insecure code (arXiv:2502.17424) and by bad-medical/risky-financial/extreme-sports advice (Model Organisms, arXiv:2506.11613); the subfield context explicitly suggests varying fine-tuning tasks.
