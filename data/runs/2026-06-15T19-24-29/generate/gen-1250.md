# Grokking Circuit Robustness to Training Data Order

**Problem:** The modular-addition grokking circuit (Fourier/trig-identity algorithm) is celebrated as a clean interpretable solution, found by training a tiny transformer. But almost all analyses use one training recipe. Whether the same interpretable algorithm reliably forms under different data orderings or weight inits is rarely varied — relevant because it bounds how 'universal' the discovered circuit is.

**Direction:** Train the standard tiny one-layer transformer on modular addition (this is a minutes-scale run on one GPU, the canonical grokking setup) under several random seeds and data shufflings. After grokking, run the published Fourier-component analysis on each model and measure how consistent the learned frequencies and the trig-identity structure are across runs. Report a universality-vs-seed audit.

**Why it matters:** Mech-interp's hope rests on circuit universality — that the same task yields the same interpretable mechanism. A controlled, fully reproducible test of whether even the cleanest known circuit is seed-robust is foundational and entirely doable outside any lab.

**Relevant context:** Nanda et al. 'Progress Measures for Grokking via Mechanistic Interpretability' — modular addition learns trig-identity algorithm; 'Uncovering a Universal Abstract Algorithm for Modular Addition' (2025). Tiny transformer training is the one allowed small-scale exception and is fast.
