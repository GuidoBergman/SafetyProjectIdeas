# Reliability-Engineering FMEA for Agent Tool-Use Pipelines

**Problem:** Builders deploy agentic tool pipelines without a structured way to anticipate which component failures cause the worst safety outcomes.

**Direction:** Import Failure Modes and Effects Analysis (FMEA) from reliability engineering. For a concrete agent pipeline (planner -> tool router -> tools -> memory), systematically enumerate failure modes per component, then empirically estimate each mode's severity x occurrence x detectability by injecting it and observing outcomes. Produce a ranked Risk Priority Number table identifying the highest-priority safety fixes.

**Why it matters:** Provides a reproducible, evidence-backed prioritization method for agent safety hardening, importing a mature engineering discipline. Mostly analysis + light fault injection, no training.

**Relevant context:** FMEA/RPN is standard in aerospace and manufacturing reliability. ReliabilityBench (arXiv 2601.06112) injects faults but does not produce a severity/occurrence/detectability FMEA table for agent pipelines; combining FMEA structure with empirical injection is novel for agentic safety.
