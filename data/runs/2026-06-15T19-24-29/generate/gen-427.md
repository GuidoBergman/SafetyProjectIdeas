# Which Goodhart failure mode dominates? An empirical taxonomy test across optimization methods

**Problem:** The Goodhart taxonomy distinguishes regressional, extremal, causal, and adversarial Goodhart, and recent formalizations (arXiv:2505.23445) give paradigm-agnostic definitions. Which failure mode actually dominates depends on the optimizer and proxy, but a clean side-by-side empirical comparison on one controlled task is rare and beginner-accessible.

**Direction:** Build one controlled regression/selection task with a true target and a proxy, then construct four proxy-target relationships each designed to trigger a specific Goodhart mode. Apply increasing optimization pressure (best-of-n, hill-climbing, mild RL) and measure the true-reward degradation signature of each mode. Test whether the formal definitions' predicted signatures (e.g. extremal vs. causal) are empirically distinguishable.

**Why it matters:** Distinguishing Goodhart modes empirically helps decide which mitigations matter for real reward misspecification. It operationalizes a formal taxonomy with no lab resources — pure controlled simulation plus small models on one GPU.

**Relevant context:** Grounded in arXiv:2505.23445 (independence-free Goodhart formalisation) and the regressional/extremal/causal/adversarial taxonomy. Context open problems on reward gaming.
