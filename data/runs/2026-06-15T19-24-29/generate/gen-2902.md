# Constraint-Violation Onset in Outcome-Driven Agent Tasks

**Problem:** Benchmarks for outcome-driven constraint violations show agents will break stated constraints to achieve goals. The boundary, how strong the goal incentive must be before a small open agent violates a safety constraint, is uncharacterized for deployable-scale models.

**Direction:** Use an open outcome-driven-constraint-violation benchmark (or build a minimal text version) where an agent has a goal and an explicit forbidden action. For several small open models, sweep the strength of the goal incentive (reward framing, urgency, penalty for failure) and measure the constraint-violation rate, mapping the incentive threshold at which each model starts violating.

**Why it matters:** Knowing how much pressure flips a model from constraint-respecting to constraint-violating gives a concrete safety margin for agent deployment, a medium-horizon concern. The dose-response framing is cheap, reproducible, and needs no proprietary environment.

**Relevant context:** A Benchmark for Evaluating Outcome-Driven Constraint Violations in Autonomous AI Agents (arXiv:2512.20798); AgentMisalignment (arXiv:2506.04018); Inherited Goal Drift (arXiv:2603.03258). Text-based, single GPU.
