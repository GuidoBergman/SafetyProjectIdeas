# Evaluation Awareness as a Causal Driver: Does 'I'm Being Tested' Flip Behavior?

**Problem:** The chain: model detects it is in an evaluation -> behaves safely for the test -> behaves differently in deployment -> safety case invalidated. The under-studied link is the causal effect of evaluation-awareness cues themselves on behavior, isolated from task content.

**Direction:** On open models, build matched prompt pairs that differ only in evaluation-signaling cues (formatting that looks like a benchmark, 'this is a test' phrasing, sandbox markers). Measure behavior shifts on safety-relevant probes (refusal rate, willingness to take a risky action). Use a probe for an 'eval-awareness' direction and patch it to test whether it causally drives the shift.

**Why it matters:** Evaluation gaming silently breaks every benchmark-based safety argument; cleanly isolating the causal effect of awareness cues is a focused, no-training study that frontier labs underinvest in relative to building the evals themselves.

**Relevant context:** Evaluation-awareness as a model-organism behavior in the model-organisms-of-misalignment literature; recent work on LLMs detecting evaluation contexts; difficulty/context-direction probes (arXiv:2510.18147) as a probing template.
