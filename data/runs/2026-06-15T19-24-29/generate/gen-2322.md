# Fault-Tree Analysis to Map Oversight-Protocol Failure Paths

**Problem:** We discuss oversight failures anecdotally but lack a systematic enumeration of the conjunctive/disjunctive failure paths by which a protocol lets a bad output through.

**Direction:** Borrow fault-tree analysis from reliability/safety engineering. Construct a fault tree for a concrete debate protocol (top event: bad output approved) decomposing into basic events (judge anchors, debater colludes, decomposition loses info), then estimate basic-event probabilities from small empirical probes on an open model and compute the top-event probability. Deliverable is the empirically-parameterized fault tree.

**Why it matters:** Provides a reusable, quantitative failure-mode map for oversight protocols, the kind of safety-engineering rigor usually absent, buildable with no lab resources and addressing FR68 (systematic failure-mode characterization).
