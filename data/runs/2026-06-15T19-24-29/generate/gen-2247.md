# Weak-to-Strong Generalization When the Strong Student Is Instruction-Tuned vs Base

**Problem:** W2S finetunes pretrained base models. Practitioners increasingly start from instruction-tuned models. Whether starting from an instruction-tuned strong student changes W2S elicitation (helping, by better latent capability access, or hurting, via ingrained refusal/format priors) is untested.

**Direction:** Run the W2S protocol on the same task with two versions of the same open model as the strong student: the base checkpoint vs its instruction-tuned variant (e.g. Qwen1.5-7B vs Qwen1.5-7B-Chat). Hold the weak supervisor fixed and compare recovered performance gap, testing whether instruction-tuning changes how much weak supervision can elicit.

**Why it matters:** Real oversight pipelines apply W2S to already-aligned models, not base models. If instruction-tuning systematically alters elicitability, the original base-model W2S results may not transfer to deployed practice. Open base/chat pairs are freely available, single-GPU feasible.

**Relevant context:** Burns et al. 2023 and EleutherAI replication use base/pretrained students. Open model families now ship matched base and instruction-tuned checkpoints, making the base-vs-instruct W2S comparison a clean, accessible twist on a setting fixed in prior work.
