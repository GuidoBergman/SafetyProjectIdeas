# Decomposing agentic goal-drift detection: a linear monitor for 'agent is off-task' across tool-use steps

**Problem:** Agentic safety asks how to catch goal drift in multi-step agents — a hard, infrastructure-heavy problem. The interpretability/control sub-problem: can a simple linear probe on the agent model's activations at each step flag when the agent's intended action no longer matches the original user request?

**Direction:** Decompose goal-drift monitoring into a per-step activation classifier. Build a tiny tool-use agent harness with a small open model on toy tasks, inject prompt-injection / distractor steps that cause drift, and label steps as on-task vs off-task. Train a linear probe on the model's hidden state at each step to predict off-task, and compare against a CoT-text monitor baseline.

**Why it matters:** Runtime agent monitoring is an explicitly unsolved problem and a strategically valuable piece of safety infrastructure; a small prototype probe-based monitor is a feasible 30h deliverable needing only open models. Counterfactually valuable: builds monitoring harness rather than capabilities. Activation-vs-text monitor comparison is a clean result.
