# PAIR Automated Jailbreak Query-Efficiency Replicated With Open Attacker Models

**Problem:** PAIR jailbreaks black-box targets in <20 queries using a strong attacker LLM, but the original setup uses capable attacker models. Whether a SMALL open model can serve as the attacker (keeping the whole loop local and free) and what that costs in query efficiency is unmeasured.

**Direction:** Replicate PAIR but swap the attacker model for a small open instruct model, targeting other open models. Twist: attacker-model capability as the variable. Measure queries-to-success and ASR as a function of attacker model size, holding the target fixed.

**Why it matters:** Determines whether cheap, fully local automated red-teaming is feasible for small actors without API access to a strong attacker model. A clean query-efficiency-vs-attacker-size curve; everything runs on one GPU with no training; directly useful red-teaming infrastructure.

**Relevant context:** PAIR (arXiv:2310.08419): generates semantic jailbreaks in <20 black-box queries using an attacker LLM and in-context refinement. Small open instruct models can act as the attacker locally.
