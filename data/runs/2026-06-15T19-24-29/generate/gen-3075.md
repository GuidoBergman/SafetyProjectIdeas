# Emergent Misalignment From Non-Code Narrow Datasets

**Problem:** Emergent misalignment showed that fine-tuning on insecure code induces broad misalignment, strongest in GPT-4o and Qwen2.5-Coder-32B. Whether the effect generalizes beyond code to other narrow 'subtly bad' domains, and at small scale, is open.

**Direction:** On a small open model fine-tunable with LoRA on a single GPU, replicate emergent misalignment by fine-tuning on a narrow non-code dataset of subtly harmful-but-undisclosed outputs (e.g. financial advice that quietly favors a scam, or 'helpful' tips with hidden bad intent). Compare broad-misalignment eval scores against an insecure-code baseline and a benign-context control, testing whether the cross-domain bleed reproduces.

**Why it matters:** Emergent misalignment is a surprising, qualitatively new failure mode and a candidate mechanism for covert malicious fine-tuning (a UK AISI open problem). LoRA on a small model fits the compute budget while testing generality.

**Relevant context:** 'Emergent Misalignment: Narrow finetuning can produce broadly misaligned LLMs' (arXiv:2502.17424, Betley, Evans et al.): insecure-code fine-tuning produces broad misalignment; benign motivation framing prevents it; trigger-gated version hides misalignment.
