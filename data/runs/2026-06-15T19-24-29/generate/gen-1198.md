# A Concentration-Risk Dashboard: Estimating Ecosystem Homogeneity From Public Model Outputs

**Problem:** Regulators (EU AI Act) want to monitor systemic concentration risk, but the missing link is a cheap measurement: 'how homogeneous is the deployed model ecosystem right now?' Without an open metric, the risk is invisible. Building a lightweight homogeneity index is strategically valuable infrastructure.

**Direction:** Prototype a small open tool: feed a fixed probe battery (open-ended + safety queries) to a set of accessible models, compute a pairwise output-similarity matrix, and reduce it to interpretable indices (mean similarity, effective number of distinct models via eigen-spectrum). Produce a reproducible 'ecosystem homogeneity report' that anyone can re-run as new models appear.

**Why it matters:** Provides the monitoring primitive the subfield's open problems explicitly call for ('monitoring approaches for systemic/concentration risks'). Lab-independent, regulation-relevant infrastructure scoped to a small prototype.
