# Auto-Interp Confabulation Plus Automated Auditing Pipelines

**Problem:** Compound: (1) LLM auto-interpretation produces confident but wrong feature labels (interp failure) amplifying (2) automated-auditing pipelines that trust those labels to triage features for safety review. A confabulated 'benign' label causes a genuinely harm-related feature to be auto-dismissed, so automation scales the labeling error into missed audits.

**Direction:** Take a set of pre-labeled SAE features (Neuronpedia / auto-interp outputs). Re-derive labels with a cheap LLM and measure disagreement. For a subset, run a simple ground-truth activation test (does the feature actually fire on its claimed concept?). Estimate the false-benign rate and simulate how many harm features an auto-triage step would discard.

**Why it matters:** Automated interpretability auditing is an emerging agenda. Showing how confabulated labels compound into systematic audit misses is fresh, lab-independent, and uses only public feature dashboards.

**Relevant context:** Search results: auto-interp interpretability scores can be misleading and don't penalize high-frequency uninterpretable latents; SAEs lack ground truth. 'Automated Interpretability-Driven Model Auditing' research agenda (Oxford AIGI, 2026). Neuronpedia hosts auto-interp labels.
