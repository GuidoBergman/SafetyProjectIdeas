# Correlated Tool-Misuse: Homogeneous Agents Make the Same Dangerous API Call on the Same Triggers

**Problem:** Failure mode A: unsafe tool/function-calling decisions by agents (e.g., over-eagerly executing a destructive action). Failure mode B: homogeneity. If different model-backed agents share the same unsafe tool-use disposition, a single triggering situation causes correlated unsafe actions across an ecosystem of agents.

**Direction:** Build a minimal sandboxed tool-use harness with a clearly-unsafe option (e.g., 'delete_all' vs 'confirm'). Present borderline scenarios to 5-6 open models acting as agents. Measure per-model unsafe-action rate AND inter-model correlation: do the same scenarios trigger unsafe actions across models? Report correlated-unsafe-action rates vs independence.

**Why it matters:** Multi-agent ecosystems on homogeneous models could take simultaneous unsafe actions — a concrete systemic-risk scenario. A small sandbox prototype doubles as reusable monitoring infrastructure, exactly the kind of counterfactually valuable work outsiders can build.
