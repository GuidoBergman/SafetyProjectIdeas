# Indirect-Injection Brittleness Across Agent Scaffolds

**Problem:** 'Your Agent is More Brittle Than You Think' (arXiv:2604.03870, 2026) uncovers indirect injection vulnerabilities in agentic LLMs. It is unclear how much the vulnerability depends on the scaffold (ReAct vs plan-and-execute vs tool-then-reflect) rather than the base model.

**Direction:** Hold the base open model fixed and implement 3 simple scaffolds. Run an identical battery of indirect injections (malicious content in a fetched document) through each scaffold and compare attack success rates. Identify whether reflection/plan steps help or hurt robustness.

**Why it matters:** Scaffold choice is a cheap, deployable lever that outside-lab builders fully control. Showing scaffold-dependent robustness gives practical defense guidance independent of model providers.

**Relevant context:** Your Agent is More Brittle Than You Think: Uncovering Indirect Injection Vulnerabilities in Agentic LLMs (arXiv:2604.03870, 2026); InjecAgent baseline (arXiv:2403.02691).
