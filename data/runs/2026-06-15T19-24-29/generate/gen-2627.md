# Regression-Testing Monitors: Detecting Silent Monitor Degradation Across Model Versions

**Problem:** When the monitored agent model is upgraded (or the monitor itself is), a previously reliable monitor can silently degrade against the new model's attack style. There's no regression suite to catch this.

**Direction:** Adapt token-efficient regression testing for non-deterministic AI workflows (AgentAssay-style) to monitors. Curate a fixed regression suite of labeled benign/sabotage trajectories, define stable metamorphic-style assertions tolerant to non-determinism, and run the suite whenever a monitor or agent version changes to flag detection regressions. Demonstrate by comparing monitor performance across two open-model versions on the same suite.

**Why it matters:** Provides reusable CI-style regression infrastructure so monitor quality doesn't silently rot across model updates, a practical, long-lived asset. Buildable with API access only, high counterfactual value as maintenance tooling labs neglect publicly.

**Relevant context:** AgentAssay does token-efficient regression testing for non-deterministic agent workflows (arXiv:2603.02601); metamorphic relations serve as CI/CD gates for agents. Monitors degrade as models become monitor-aware (arXiv:2510.19851).
