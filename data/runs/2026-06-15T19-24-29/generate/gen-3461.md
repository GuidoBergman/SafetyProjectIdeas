# Self-Explanation Semantic-Invariance Checker

**Problem:** If a model's explanation of why it answered is faithful, semantically equivalent rephrasings of the question should yield semantically equivalent explanations. Recent work shows self-explanations fail this invariance, but there is no reusable checker that quantifies explanation invariance under input paraphrase for arbitrary open models.

**Direction:** Take a question, generate the model's answer + self-explanation, then feed K meaning-preserving paraphrases of the same question and collect explanations. Use embedding similarity + an LLM judge to score how much the *stated reasons* drift while the answer stays fixed. Report an 'explanation invariance score' per task type and model.

**Why it matters:** Explanations that change arbitrarily under paraphrase are post-hoc rationalizations, not faithful accounts — a direct honesty/faithfulness failure that misleads anyone relying on model explanations. The checker is fully behavioral and lab-independent.

**Relevant context:** 'LLM Self-Explanations Fail Semantic Invariance' (arXiv 2603.01254) documents this failure mode. FaithCoT-Bench and CoT-dynamics work (2508.19827) distinguish faithful guidance from post-hoc rationalization. No standalone invariance-checker tool exists.
