# Over-Refusal as a Broken Link: Mapping the Adaptive-Defense Collateral Damage

**Problem:** The adaptive-defense chain aims: stronger defense -> blocks attacks -> still answers benign requests. The under-studied failure link is catastrophic over-refusal: as you push a prompt-based defense harder, where on the curve does it start refusing benign borderline requests?

**Direction:** Apply escalating prompt-based defenses (warning prefixes, self-checks) to an open model and evaluate on both harmful prompts and a benign-but-sensitive set (e.g. legitimate medical/security questions). Plot the attack-block-rate vs benign-refusal-rate frontier to locate where defenses tip into over-refusal.

**Why it matters:** Quantifies the over-refusal collateral that Anthropic names as the core obstacle to adaptive defenses, producing an explicit safety/usability Pareto frontier. Prompting + open model, no training; a directly useful tool for anyone tuning defense aggressiveness.

**Relevant context:** Anthropic recommended directions call for adaptive defenses robust to evolving attacks WITHOUT catastrophic over-refusal. Deliberative alignment literature (arXiv:2510.21285 Chain-of-Guardrails) frames the safety-usability tradeoff; XSTest-style benign-but-sensitive sets enable measuring over-refusal.
