**Problem:** Statistical physics describes collective order via an order parameter and phase transitions (e.g., magnets aligning). Whether LLMs cross a 'homogenization phase transition' as alignment strength or model size increases — snapping from diverse to aligned — is an evocative, untested framing.

**Direction:** Borrow the order-parameter idea. Define a homogeneity order parameter (e.g., average pairwise response alignment) and sweep it across an axis you can vary cheaply: base vs instruct vs heavily-RLHFed open checkpoints, or temperature/sampling settings, or model size within a family.
