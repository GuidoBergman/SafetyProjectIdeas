# Testing interpretability where transcripts cannot help

**TL;DR:** A high-profile benchmark found no interpretability tool beat reading transcripts, but its ground truth comes from sampling, so it only covers behaviour transcripts already reveal. We build model organisms with hidden state that transcripts provably cannot show, and rerun the comparison.

## Guido's comments

**Title:** Using mech interp to find unknown unknowns

## Research Question

Does the reported null result for interpretability tools hold on behaviours whose cause leaves no verbal trace in the transcript, or is it a property of a benchmark whose ground truth can only cover behaviour that sampling already exposes?

## Why This Matters

**The failure this targets:** A model with a hidden goal, a backdoor trigger or password-locked sandbagging behaves normally in every transcript an overseer reads, which is exactly how a deceptively aligned model evades behavioural oversight, and it is exactly the case the existing benchmark cannot construct ground truth for.

**Why the work reduces it:** We build open-weight model organisms where the hidden state is installed by us, so the true answer to a counterfactual question is known by construction instead of by sampling. That lets us run the same transcript-only baseline against interpretability-equipped agents on cases where the transcript is provably uninformative, which is the regime interpretability was built for. If some tool wins there, the oversight channel against hidden goals is strengthened; if none does, the null result is confirmed on the hard cases rather than assumed.

**Where the chain ends:** The CHIVE authors add a transcript-invisible split to the benchmark, and funders and researchers stop citing the current null as evidence about hidden-goal detection.

## Day-1 Check

Download one public password-locked or backdoored model organism from Hugging Face, sample one hundred transcripts with the trigger present and one hundred without, and report the percentage of transcripts containing any lexical trace of the trigger condition, which should be near zero if the case is genuinely transcript-invisible.

## Approach

We build a suite of open-weight model organisms with three kinds of installed hidden state: input-conditioned backdoor triggers, a fine-tuned latent goal that is never verbalised, and password-locked sandbagging where capability appears only with a key. Published recipes exist for all three, so the engineering is assembly rather than invention, and we use models in the 1B to 9B range where public sparse autoencoders already exist. For each organism we generate a set of counterfactual questions whose true answers follow from the construction, and we verify transcript-invisibility empirically by showing a transcript-only predictor performs at chance. We then run the transcript-only agent against agents equipped with public interpretability tooling, specifically Gemma Scope and Llama Scope sparse autoencoders, activation patching and linear probes, and measure the accuracy gap on exactly those cases. The organism suite plus the verified transcript-only baseline is released first, because it is a reusable artifact whether or not the interpretability arm finds anything.

## Scope and Deliverables

Stage one, 9 weeks and about 400 hours: the model organism suite, the counterfactual question sets, and the transcript-only baseline with its verification that the cases are transcript-invisible. Stage two, 9 weeks and about 480 hours: the interpretability-equipped agents using public sparse autoencoders, patching and probes, with the uplift measurement. Stage three, 6 weeks and about 320 hours: an ablation over how hidden the hidden state is, sweeping trigger rarity and sandbagging strength to find where any tool that works stops working. Stage one alone gives the field a public benchmark it currently lacks. Artifacts are the released organisms and question sets on Hugging Face, an Inspect-compatible harness, and a public report.

## Experiments

- Experiment 1: build three backdoored organisms and measure the transcript-only agent's accuracy on the counterfactual question set. Expected outcome: accuracy at or near chance, confirming the cases are outside the reach of transcript reading.
- Experiment 2: run linear probes trained on a held-out set of the same organism family against the same questions, measuring accuracy. Expected outcome: probes beat chance substantially, because probes are the tool most likely to recover a deliberately installed direction.
- Experiment 3: run sparse autoencoder feature inspection and activation patching agents on the same questions, measuring accuracy and cost per question. Expected outcome: uncertain, and this is the point of the study; either result changes what the field concludes from the existing null.

## Risks

**The installed hidden state is unrealistically easy to find**
- Consequence: Interpretability tools win by construction, and the result says nothing about naturally arising hidden goals.
- Detected by: A control probe trained on only a handful of examples reaches near perfect accuracy on the organism, indicating a trivially linear installed feature.
- Response: Retry with harder organisms produced by training against a probe penalty during installation, so the hidden state is not a single easily recovered direction, and report both difficulty levels.

**Cases are not actually transcript-invisible**
- Consequence: The benchmark repeats the original benchmark's limitation and the comparison is uninformative.
- Detected by: Experiment 1 shows the transcript-only agent performing well above chance.
- Response: Retry by tightening the organism construction, for example moving triggers out of the observable input distribution, and by dropping any question whose answer the transcript-only baseline can predict.

**Public sparse autoencoders do not exist for the model sizes where organisms train reliably**
- Consequence: The interpretability arm is restricted to probes and patching, weakening the comparison.
- Detected by: An inventory in week one of Gemma Scope and Llama Scope coverage against our candidate base models.
- Response: Mitigate by fixing the base models to those with published sparse autoencoder suites, even at the cost of organism variety, and stating the restriction.

## Prerequisites

- Open-weight base models with published sparse autoencoder suites, specifically Gemma and Llama variants
- Multi-GPU days for fine-tuning several model organisms and for running feature extraction over many episodes
- Published recipes for backdoor installation, password-locked sandbagging and latent goal fine-tuning
- Familiarity with activation patching and linear probing, which is a short ramp-up on top of existing skills

## Who This Is For

Anthropic's alignment science team, which published the benchmark and stated the sampling-based ground truth caveat itself. After this work they would extend the benchmark with a split whose ground truth comes from construction rather than sampling, and would qualify the headline null as applying to transcript-visible behaviour rather than to interpretability as such.

## Open Questions

- Do installed hidden goals resemble naturally arising ones closely enough for a tool that finds one to find the other?
- Is there a principled way to certify that a case is transcript-invisible rather than merely showing one baseline fails on it?
- How much of any measured uplift comes from the tool itself rather than from the agent knowing which organism family it is looking at?
