# Proposal Writing Guidelines

These rules govern how full research proposals are written for the reader-facing outputs (the selected ideas files and the compiled proposals). Any skill that assembles or rewrites a proposal must follow them.

## Rules

1. Self-contained. Assume the reader knows nothing about the specific papers mentioned. Spell out context and purpose up front, and define any term, acronym, or name a stranger would not know.
2. Only include what is relevant to the reader.
3. Sound like a human, not an LLM. Natural, direct, plain.
4. Never use em dashes.
5. Easy to read. Simple words, short sentences.
6. Write as little as possible. Brevity matters a lot.
7. Keep each paragraph on a single line. Never hard-wrap a paragraph across multiple lines. Put the whole paragraph, and each bullet, on one continuous line, and separate paragraphs with a blank line.
8. Write full, self-standing sentences, not abrupt fragments. Each sentence should carry enough context to make sense on its own. Lead with the subject and the action instead of pointing back to the previous sentence.
9. Write for AI safety researchers. All readers know the AI safety landscape, so do not explain basics like what an AI agent is.
10. Cite all relevant sources appropriately.
11. Keep the approach outline short.
12. Do not invent new hyphenated compounds (for example "monitor-actionable"). Use only standard, commonly used hyphenated words.
13. Titles should be simple and intuitive. The title is the proposal's header; keep it short and let the research question carry the fuller framing.

## Judging written proposals

- Operationalizable. All the important decisions (metrics, dataset, and so on) are stated so someone can execute directly. This does not include which models to use, unless the model choice is particularly important for the project.
- Contextualized. The novelty relative to prior work is clear and direct. Earlier pipeline phases sometimes get the novelty check wrong, so verify it properly and confirm with the user how the novelty check will be conducted so nothing is missed.
